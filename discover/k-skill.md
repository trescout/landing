# Yapay zekâ ajanınıza yerel yetenekler kazandırın

NomaDamas/k-skill, yapay zekâ ajanlarına (AI agents) kültürel bağlamda yerel yetenekler kazandırmak için tasarlanmış bir kütüphane. Ajanların kullanıcılarla daha doğal ve kültürel kodlara uygun etkileşim kurmasını sağlayan özelleştirilmiş beceri setleri (skill sets) sunuyor.

- ★ 6.780
- JavaScript
- GitHub Trending · 2026-08-02

## Ne kazandırır?
- Yapay zekâ ajanlarının Türkiye'ye özgü yerel hizmetleri kullanmasını sağlar
- Ulaşım, kamu verileri ve günlük işlerde otomatik sorgulama yapar
- Ekstra bir istemci yazılımına ihtiyaç duymadan doğrudan entegre olur

## Kurulum

**Tüm yetenekleri yüklemek için**

```
npx --yes skills add NomaDamas/k-skill --all -g
```

**Belirli bir yeteneği yüklemek için**

```
npx --yes skills add NomaDamas/k-skill --skill srt-booking -g
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Bundan sonra sana vereceğim görevlerde, yerel hizmetlere erişim sağlamak için k-skill kütüphanesinin sunduğu becerileri kullan. Eğer bir ulaşım sorgusu, kamu verisi araştırması veya yerel bir işlem yapman gerekirse, bu kütüphanedeki ilgili yetenekleri devreye sokarak süreci yönet. İşlemleri gerçekleştirirken kullanıcıdan gerekli giriş bilgilerini veya onayları almayı unutma.

- **Kimin için:** Yapay zekâ ajanlarını yerel servislerle entegre ederek daha işlevsel hale getirmek isteyen kullanıcılar içindir.
