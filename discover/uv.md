# Python projeleri için yüksek hızlı yönetim aracı

Rust programlama diliyle geliştirilen uv, Python paketlerini ve projelerini yönetmek için tasarlanmış yüksek hızlı bir araçtır. Geleneksel paket yöneticilerine (pip, pip-tools) performans odaklı bir alternatif sunar.

## Ne kazandırır?

- Paket yönetimi işlemlerini geleneksel araçlara göre 10 ile 100 kat daha hızlı tamamlar.
- Programlama dili Python sürümlerini bilgisayarınıza indirir ve projelerinize göre düzenler.
- Kütüphane bağımlılıklarını yöneten paket yöneticisi pip gibi araçların işlevlerini tek başına yerine getirir.

## Kurulum

**macOS ve Linux için kurulum**

```
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows için kurulum**

```
# On Windows.
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Çalıştırma

**Aracı güncelleme**

```
uv self update
```
