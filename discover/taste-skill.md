## Nasıl kullanılır?

Skill'i AI agent'ınıza eklediğinizde (adımlar tasteskill.dev adresinde), arayüz üretimi sırasında otomatik devreye girerek tasarım kalitesini bir üst seviyeye taşır.

## Nasıl kurulur, nasıl kullanılır?
🤖 Kod bilmiyorsanız · yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Terminalde 'npx skills add https://github.com/Leonxlnx/taste-skill' komutunu çalıştırarak Taste Skill becerilerini kur; sonra ajandan arayüz yaparken bu beceriyi takip ederek daha iyi düzen, tipografi ve animasyona sahip premium bir tasarım üretmesini iste.

**Tüm becerileri kur**

```
npx skills add https://github.com/Leonxlnx/taste-skill
```

**Tek bir beceriyi kur**

```
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

Lisans: MIT · özgürce kullanabilir, uyarlayabilir, ticari işte kullanabilirsiniz.
