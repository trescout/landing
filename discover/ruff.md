# Hızlı python kod denetleyicisi ve biçimlendiricisi

Ruff, Rust programlama diliyle geliştirilmiş oldukça hızlı bir Python kod denetleyicisi (linter) ve kod biçimlendiricisidir (formatter). Yazılım geliştirme süreçlerinde kod kalitesini artırmak ve biçimlendirme işlemlerini hızlandırmak amacıyla kullanılır.

## Ne kazandırır?

- Mevcut araçlara kıyasla onlarca kat daha hızlı çalışır

- Python projelerinde otomatik hata düzeltme desteği sunar

## Kurulum

**pip ile kurulum**

```
pip install ruff
```

**uv ile kurulum**

```
uv tool install ruff@latest
```

## Çalıştırma

**kod denetimi çalıştırma**

```
ruff check
```

**kod biçimlendirmesi çalıştırma**

```
ruff format
```
