## Kurulum

**macOS ve Linux için kurulum**

```
curl -fsSL https://raw.githubusercontent.com/rlaope/oh-my-hermes/main/install.sh | sh
```

**Homebrew paket yöneticisi ile kurulum**

```
brew install rlaope/tap/omh
```

## Çalıştırma

**Kurulum sonrası yapılandırma**

```
omh setup
```
