# GhostTrack

Python tabanlı GhostTrack, mobil numaralar üzerinden konum takibi yapılmasına olanak tanıyan bir araçtır. Açık kaynaklı bu yazılım, hedef numaranın coğrafi verilerini tespit etmek amacıyla geliştirilmiştir.

- ★ 13.874
- GitHub Trending · 2026-06-08

## Ne kazandırır?
- Mobil numaralar üzerinden konum bilgisi toplama.
- Sosyal medya kullanıcı adları ile bilgi edinme.
- IP adresi üzerinden hedef takibi yapma.

## Kurulum

**Klonla + bağımlılıklar (Linux · Python 3)**

```
git clone https://github.com/HunxByts/GhostTrack.git && cd GhostTrack && pip3 install -r requirements.txt
```

## Çalıştırma

**Çalıştır**

```
python3 GhostTR.py
```
