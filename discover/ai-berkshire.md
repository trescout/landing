# yapay zekâ ile değer yatırımı araştırması

AI-berkshire, Claude Code altyapısını kullanarak Warren Buffett ve Charlie Munger gibi yatırımcıların metodolojilerini uygulayan bir değer yatırımı araştırma çerçevesidir (research framework). Sistem, çoklu yapay zekâ ajanı (multi-agent) yapısıyla finansal verileri analiz ederek karşıt görüşlü incelemeler yürütmektedir.

- ★ 2.500
- Python
- GitHub Trending · 2026-06-26

## Ne kazandırır?
- Dört yatırım ustasının metodolojisiyle yapılandırılmış analiz
- Çoklu yapay zekâ ajanı ile karşıt görüşlü derinlemesine inceleme
- Sayısal verilerde yüksek doğruluk ve hata denetimi

## Kurulum

**Claude Code kurulumu**

```
npm install -g @anthropic-ai/claude-code
```

**Araç setini kopyalama**

```
git clone https://github.com/xbtlin/ai-berkshire.git

# 复制 skills 到 Claude Code 全局 commands 目录
cp ai-berkshire/skills/*.md ~/.claude/commands/
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Sen bir yatırım analisti olarak, Warren Buffett, Charlie Munger, Duan Yongping ve Li Lu'nun metodolojilerini kullanarak seçtiğim şirketi analiz et. Analizinde sadece finansal verileri değil, iş modelinin sürdürülebilirliğini, rekabet avantajlarını (hendek), yönetim kalitesini ve olası riskleri dört farklı perspektiften değerlendir. Bilgileri doğrulamak için bağımsız kaynaklar kullan, belirsiz durumlarda 'bilmiyorum' demeyi tercih et ve yatırım kararı için net bir fiyat aralığı ile stratejik öneri sun.

- **Kimin için:** Yatırım kararlarında duygusal önyargılardan arınmış, disiplinli ve çok yönlü bir araştırma süreci arayan yatırımcılar içindir. 
- **Lisans:** MIT
