# GitHub depolarını etkileşimli şemalara dönüştürün

Gitdiagram, GitHub depolarındaki karmaşık dosya yapılarını ve kod ilişkilerini görselleştiren bir araçtır. Yazılım projelerinin mimarisini anlamayı kolaylaştıran etkileşimli şemalar oluşturur.

- ★ 16.568
- TypeScript
- GitHub Trending · 2026-09-19

## Ne kazandırır?
- Karmaşık kod yapılarını görselleştirerek mimariyi hızlıca kavrayın.
- Şema üzerindeki bileşenlere tıklayarak ilgili kaynak kod dosyasına gidin.
- Oluşturulan şemaları görsel veya metin formatında dışa aktarın.

## Kurulum

**Yerel ortamı hazırlama ve başlatma**

```
git clone https://github.com/ahmedkhaleel2004/gitdiagram.git
cd gitdiagram
bun install
cp .env.example .env
bun run dev
```

**Projeyi doğrulama ve derleme**

```
bun run lint
bun run typecheck
bun run test
bun run build
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
GitDiagram aracını kullanarak incelediğim GitHub deposunun mimarisini, sistem düzeyinde bir grafik olarak oluştur. Kod yapısındaki bileşenleri, aralarındaki ilişkileri ve çalışma mantığını net bir şekilde gösteren etkileşimli bir şema hazırla. Şemayı oluştururken dosya yollarını ve önemli modülleri temel alarak sistemin genel işleyişini özetle.

- **Kimin için:** Yazılım projelerinin mimarisini anlamak isteyen geliştiriciler ve kod tabanlarını hızlıca analiz etmeye ihtiyaç duyan teknik ekipler için tasarlanmıştır.
