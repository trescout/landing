# Turbovec

TurboQuant altyapısı üzerine inşa edilen turbovec, Rust diliyle geliştirilmiş yüksek performanslı bir vektör dizini (vector index) aracıdır. Python bağlamaları (bindings) sayesinde geliştiricilerin vektör tabanlı arama işlemlerini hızlı ve verimli bir şekilde gerçekleştirmesine olanak tanır.

- ★ 7.703
- Python
- GitHub Trending · 2026-06-08

## Ne kazandırır?
- Vektör verilerini yüksek oranda sıkıştırarak bellek kullanımını düşürür.
- Eğitim aşaması gerektirmeden anlık veri ekleme ve hızlı arama sağlar.
- Filtreleme işlemlerini arama sırasında gerçekleştirerek performansı korur.

## Kurulum

**Python için kurulum**

```
pip install turbovec
```

**Rust için kurulum**

```
cargo add turbovec
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Python veya Rust projelerimde vektör tabanlı arama işlemlerini hızlandırmak için turbovec kütüphanesini kullanmak istiyorum. TurboQuant algoritması üzerine kurulu bu aracın temel dizin oluşturma, veri ekleme ve arama fonksiyonlarını kullanarak bir RAG sistemi veya vektör veritabanı yapısı kurmama yardımcı ol. Özellikle bellek tasarrufu sağlayan 4-bit genişliğindeki dizinleri nasıl yapılandıracağımı ve arama sırasında filtreleme özelliklerini nasıl uygulayacağımı örnek kodlarla açıkla.

- **Kimin için:** Bellek verimliliği, düşük gecikme süresi ve yerel gizlilik odaklı RAG uygulamaları geliştiren yazılımcılar için uygundur.
