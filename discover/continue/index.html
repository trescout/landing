Kodlama süreçleri için yapay zekâ desteği

Continue, yazılım geliştirme süreçlerini otomatikleştirmek için tasarlanmış açık kaynaklı bir kodlama ajanıdır (coding agent). Geliştiricilerin kendi yerel dil modellerini (LLM) kullanarak kod yazma, hata ayıklama ve yeniden yapılandırma (refactoring) işlemlerini IDE içerisinde gerçekleştirmelerine olanak tanır.

  • ★ 35.282
  • GitHub Trending · 2026-06-18

TreScout notu: Kod yazarken yardımcı olan yapay zekâ asistanı. Hazır asistanlardan farkı, hangi modeli kullanacağınıza sizin karar vermeniz: Kendi anahtarınızı ya da bilgisayarınızda çalışan bir modeli bağlarsınız, kodunuz dışarı çıkmaz. Karşılığında kurulum ve model seçimi sizin işiniz olur, deneyim hazır ürünler kadar cilalı değildir.

Güncelleme

  • 2 Ağustos 2026: Yıldız 34.017 → 35.282, son sürüm v2.0.0-vscode (19 Haziran 2026).

Ne kazandırır?

  • Kod yazma ve hata ayıklama süreçlerini hızlandırır
  • Yerel dil modelleri ile güvenli çalışma alanı sunar
  • VS Code ve JetBrains gibi yazılım geliştirme ortamlarıyla entegre olur

Kurulum

npm ile CLI kurulumu (Global)
npm i -g @continuedev/cli
VS Code eklentisi olarak kurulum
code --install-extension Continue.continue

Çalıştırma

CLI üzerinden Continue ajanını çalıştır
cn

Kaynak: npm (@continuedev/cli) · VS Code Marketplace (Continue.continue)

Kod bilmiyorsanız

🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın

Bir yazılım geliştirme asistanı olarak, yerel dil modellerini kullanarak kod yazma, mevcut kod bloklarını yeniden yapılandırma ve hata ayıklama süreçlerinde bana rehberlik et. Çalışma ortamımdaki dosyaları analiz ederek kod kalitesini artıracak öneriler sun ve karmaşık mantıksal hataları tespit etmemde yardımcı ol.

Kimin içinKod yazma süreçlerini otomatikleştirmek ve yerel yapay zekâ modellerinden faydalanmak isteyen yazılım geliştiriciler için uygundur.
