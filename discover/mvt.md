# Mobil cihazlarda siber saldırı izlerini arayın

Mobile Verification Toolkit, mobil cihazlarda güvenlik ihlallerini tespit etmek için kullanılan bir adli bilişim aracıdır. Python diliyle geliştirilen bu yazılım, cihaz verilerini analiz ederek olası siber saldırı izlerini ortaya çıkarır.

## Ne kazandırır?
- Android ve iOS cihazlarda adli bilişim izlerini toplar
- Bilinen casus yazılım kampanyalarının izlerini tarar
- Komut satırı araçlarıyla güvenlik analizi yapar

## Kurulum

**pip ile kur**

```
pip3 install mvt
```

**uv ile kur**

```
uv tool install mvt
```

## Çalıştırma

**Tamamlama betiği oluştur**

```
mvt completion bash
```
