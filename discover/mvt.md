# MVT

Mobil Doğrulama Araç Seti (Mobile Verification Toolkit), mobil cihazlarda potansiyel güvenlik ihlallerini tespit etmek için adli bilişim incelemeleri yapılmasına olanak tanır. Python tabanlı bu araç, cihaz verilerini analiz ederek siber saldırı izlerini ortaya çıkarmayı hedefler.
