# Donanımınıza uygun yapay zekâ modellerini bulun

Rust diliyle geliştirilen llmfit, yüzlerce büyük dil modelini (large language model) ve sağlayıcıyı tarayarak donanımınızla uyumlu olanları tek bir komutla tespit etmenizi sağlıyor. Araç, yerel sistem kaynaklarına en uygun modelleri bulma sürecini otomatikleştiriyor.

## Kurulum

**macOS veya Linux için kurulum**

```
brew install AlexsJones/llmfit/llmfit
```

**Hızlı kurulum**

```
curl -fsSL https://llmfit.axjns.dev/install.sh | sh
```

## Çalıştırma

**Etkileşimli arayüzü başlatma**

```
llmfit
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Sistemimin donanım özelliklerini analiz et ve mevcut RAM, CPU ve GPU kapasiteme göre çalıştırabileceğim en iyi yapay zekâ modellerini öner. Modelleri performans, bellek kullanımı ve kalite kriterlerine göre sıralayarak bana en uygun olanları listele.

- **Kimin için:** Yerel bilgisayarında hangi yapay zekâ modellerinin verimli çalışacağını merak eden kullanıcılar içindir.
