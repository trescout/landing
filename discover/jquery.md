# Özel jquery sürümleri oluşturun

jQuery, web sayfalarında etkileşimli öğeler oluşturmayı kolaylaştıran bir JavaScript kütüphanesidir. Geliştiricilerin belge nesne modeli (DOM) üzerinde işlem yapmasını ve olay yönetimini basitleştiren araçlar sunar.

## Ne kazandırır?

- Kendi özel jquery kütüphanenizi derleyin.
- İhtiyacınız olmayan modülleri çıkararak boyutu küçültün.
- Tüm sürüm dosyalarını toplu olarak oluşturun.

## Kurulum

**Bağımlılıkları yükleyip projeyi derleyin**

```
cd jquery
npm install
npm run build
```

**Tüm sürüm dosyalarını oluşturun**

```
npm run build:all
```
