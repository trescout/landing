# Kod tabanınızda yapay zekâ işlemleri yürütün

Anthropics tarafından geliştirilen Claude Code Action, geliştiricilerin kod tabanları üzerinde doğrudan yapay zekâ destekli işlemler gerçekleştirmesini sağlayan bir araçtır. Bu TypeScript tabanlı çözüm, kod düzenleme ve analiz süreçlerini otomatize ederek yazılım geliştirme iş akışlarını hızlandırmayı hedefler.
