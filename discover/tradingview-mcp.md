# TradingView için yapay zekâ entegrasyonu

TradingView-mcp, Claude Code ile TradingView masaüstü uygulamasını birbirine bağlayarak grafik analiz süreçlerini otomatize etmeyi sağlıyor. Bu entegrasyon, kullanıcıların yapay zekâ destekli model bağlamı (Model Context Protocol) üzerinden teknik analiz iş akışlarını kişiselleştirmesine olanak tanıyor.

- ★ 4.930
- JavaScript
- GitHub Trending · 2026-07-22

## Ne kazandırır?
- Yapay zekâ ile Pine Script kodlama ve hata ayıklama
- Grafik üzerinde otomatik çizim ve analiz yönetimi
- Fiyat alarmlarını ve sembolleri komutla kontrol etme

## Kurulum

**Dosyaları indirme ve kurulum**

```
git clone https://github.com/tradesdontlie/tradingview-mcp.git
cd tradingview-mcp
npm install
```

**macOS üzerinde başlatma**

```
./scripts/launch_tv_debug_mac.sh
```

## Çalıştırma

**CLI üzerinden doğrudan kullanım**

```
# Install globally (optional)
npm link

# Or run directly
node src/cli/index.js 
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
TradingView masaüstü uygulamam ile bağlantı kurdun. Şimdi grafik üzerinde teknik analiz yapmanı, Pine Script kodlarını incelemeni veya grafik ayarlarını değiştirmemi istediğimde bu aracı kullanarak TradingView arayüzüne müdahale etmeni istiyorum. Lütfen grafik verilerini okumak, gösterge değerlerini analiz etmek veya yeni çizimler eklemek için gerekli komutları çalıştır.

- **Kimin için:** TradingView masaüstü uygulamasını kullanan ve grafik analiz süreçlerini yapay zekâ desteğiyle otomatize etmek isteyen profesyonel kullanıcılar içindir.
