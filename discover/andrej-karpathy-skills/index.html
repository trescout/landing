Kodlama Ajanları için Karpathy Yönergeleri

Andrej Karpathy’nin LLM’lerin kodlama hatalarına ilişkin gözlemlerinden türetildiği belirtilen bu yönerge paketi, kodlama ajanlarının çalışma biçimine rehberlik eder. Claude Code plugin’i, proje başına CLAUDE.md ve Cursor kuralları için seçenekler sunar.

  • ★ 205.391
  • GitHub Trending · 2026-08-23

Bu araç ne yapar?

Andrej Karpathy Skills, bağımsız bir model veya coding agent runtime’ı değildir. Mevcut kodlama ajanlarını yönlendirmek için tek bir CLAUDE.md ve plugin tarzı yönergeler içerir. Paket; Kodlamadan Önce Düşünme, Önce Sadelik, Cerrahi Değişiklikler ve Hedef Odaklı Yürütme ilkelerine dayanır.

Kimin için?

Claude Code ya da Cursor kullanan ve kodlama ajanlarına proje veya araç düzeyinde ek yönergeler vermek isteyen geliştiriciler.

Ne beklememeli?

Bağımsız bir LLM, kod editörü, coding agent runtime’ı veya hazır bir uygulama arıyorsanız size uygun değildir.

Öne çıkanlar

  • Claude Code plugin’i, proje başına CLAUDE.md ve Cursor kuralları için kurulum seçenekleri içerir.

İlk kullanım akışı
