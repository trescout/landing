# Üç boyutlu modeller için doku boyama

ArmorPaint, üç boyutlu modeller üzerinde gerçek zamanlı doku boyama işlemleri yapan bir grafik tasarım aracıdır. Yazılım, fizik tabanlı işleme (PBR) desteğiyle dijital sanatçılara karmaşık doku oluşturma süreçlerinde esneklik sağlar.

## Ne kazandırır?
- Modeller üzerinde gerçek zamanlı doku boyama yapın
- Fizik tabanlı işleme desteğiyle profesyonel sonuçlar alın
- Karmaşık doku oluşturma süreçlerini hızlandırın

## Kurulum

**Dosyaları bilgisayarınıza indirin**

```
git clone https://github.com/armory3d/armorpaint
cd armorpaint/paint
```

## Çalıştırma

**Linux üzerinde çalıştırma**

```
../base/make --run
```
