## Ne kazandırır?

- Node.js ile uyumlu hızlı çalışma zamanı

## Kurulum

**Kurulum betiği ile yükleme**

```
curl -fsSL https://bun.com/install | bash
```

**Windows üzerinde yükleme**

```
powershell -c "irm bun.sh/install.ps1 | iex"
```

## Çalıştırma

**Paket yükleme**

```
bun install <pkg>
```

**Dosya çalıştırma**

```
bun run index.tsx
```
