## Kurulum

**Bağımlılıkları yükleme**

```
pnpm install
```

## Çalıştırma

**Geliştirme ortamını başlatma**

```
pnpm dev
```

**Masaüstü uygulamasını derleme**

```
pnpm --dir apps/desktop tauri build
```
