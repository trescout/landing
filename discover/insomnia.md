# Kapsamlı yapay zekâ destekli API istemcisi

Insomnia, GraphQL, REST, WebSockets, SSE ve gRPC protokollerini destekleyen açık kaynaklı bir uygulama programlama arayüzü (API) istemcisidir. Yazılım, bulut tabanlı, yerel ve Git üzerinden depolama seçenekleriyle çapraz platform desteği sunar.

- TypeScript
- GitHub Trending · 2026-06-19

## Ne kazandırır?
- GraphQL, REST ve gRPC gibi popüler protokolleri hata ayıklama desteği
- Yerel, Git veya bulut tabanlı esnek depolama seçenekleri
- Yerleşik OpenAPI düzenleyicisi ile görsel API tasarımı

## Nasıl başlanır?

Insomnia'yı kullanmaya başlamak için resmî web sitesi olan https://insomnia.rest adresine giderek işletim sisteminize uygun kurulum dosyasını indirip çalıştırabilirsiniz. Uygulamayı hesap oluşturmadan yerel Scratch Pad özelliğiyle kullanmaya başlayabilir veya daha fazla özellik için ücretsiz bir hesap oluşturabilirsiniz.
- [Resmî kaynak →](https://insomnia.rest)

- **Kimin için:** API geliştirme, test etme ve dokümante etme süreçlerini tek bir platform üzerinden yönetmek isteyen yazılım geliştiriciler için uygundur. 
- **Lisans:** Apache-2.0
