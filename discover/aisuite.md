# yapay zekâ modellerini tek arayüzde yönetin

Andrew Ng tarafından geliştirilen aisuite, farklı üretken yapay zekâ (generative AI) sağlayıcılarını tek bir arayüz üzerinden yönetmeyi sağlayan bir Python kütüphanesidir. Geliştiricilerin çeşitli model servisleri arasında kod değişikliği yapmadan geçiş yapmasına olanak tanır.

- ★ 14.220
- Python
- GitHub Trending · 2026-06-14

## Ne kazandırır?
- Farklı yapay zekâ sağlayıcılarını tek bir arayüzle yönetme
- Kod değişikliği yapmadan modeller arası geçiş yapabilme
- Python fonksiyonlarını yapay zekâya araç olarak tanımlama

## Kurulum

**Temel kütüphane kurulumu**

```
pip install aisuite # base package, no provider SDKs
```

**Tüm sağlayıcılarla kurulum**

```
pip install 'aisuite[all]' # with all provider SDKs
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Aisuite kütüphanesini kullanarak farklı yapay zekâ modellerini tek bir arayüz üzerinden nasıl yönetebilirim? Özellikle OpenAI ve Anthropic gibi farklı sağlayıcılar arasında geçiş yaparken kod yapımı nasıl kurmalıyım ve Python fonksiyonlarımı modele araç olarak nasıl tanıtabilirim? Lütfen aisuite kütüphanesinin sunduğu Chat Completions ve Agents API yapılarını kullanarak basit bir örnek oluştur.

- **Kimin için:** Üretken yapay zekâ modellerini tek bir standart arayüz üzerinden yönetmek isteyen yazılımcılar ve masaüstü ortamında çalışan bir yapay zekâ asistanı arayan kullanıcılar içindir.
