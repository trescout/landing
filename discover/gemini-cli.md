# Komut satırından yapay zekâ erişimi

Google tarafından geliştirilen gemini-cli, Gemini yapay zekâ modeline doğrudan uçbirim (terminal) üzerinden erişim sağlayan açık kaynaklı (kaynak kodları herkesin erişimine açık) bir araçtır. Yazılım, kullanıcıların komut satırı ortamında hızlı ve hafif bir şekilde yapay zekâ istemleri oluşturmasına olanak tanır.

## Ne kazandırır?

- Kod tabanlarınızı doğrudan komut satırı üzerinden inceleyebilir ve düzenleyebilirsiniz.
- Görsellerden ya da metin belgelerinden yeni uygulamalar üretebilirsiniz.
- Sık tekrarlanan işlerinizi komut dizileriyle otomatikleştirebilirsiniz.

## Kurulum

**Paket yöneticisi npm ile küresel kurulum**

```
npm install -g @google/gemini-cli
```

**Paket yöneticisi Homebrew ile kurulum**

```
brew install gemini-cli
```

## Çalıştırma

**Kurulum yapmadan doğrudan çalıştırma**

```
# Using npx (no installation required)
npx @google/gemini-cli
```
