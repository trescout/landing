# Yapay zekâ modelleri için açık kaynaklı platform

Google tarafından geliştirilen TensorFlow, makine öğrenimi (machine learning) modelleri oluşturmak ve eğitmek için kullanılan açık kaynaklı bir kütüphane. Geliştiricilerin karmaşık sinir ağlarını (neural networks) tasarlamasına ve bu modelleri ölçeklenebilir şekilde dağıtmasına olanak tanıyor.

## Ne kazandırır?

- Makine öğrenimi uygulamaları oluşturmayı ve dağıtmayı sağlar
- Python ve C++ programlama dilleri için kararlı arayüzler sunar
- GPU ve CPU desteği ile esnek bir ekosistem barındırır

## Kurulum

**Kütüphaneyi kurmak için**

```
pip install tensorflow
```

**Sadece CPU içeren sürümü kurmak için**

```
pip install tensorflow-cpu
```

## Çalıştırma

**Python ortamını başlatmak için**

```
python
```
