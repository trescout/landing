# Şirketinize özel yapay zekâ çalışma alanı

Cloudflare, şirket içi verilerle belge oluşturma, uygulama geliştirme ve yapay zekâ ajanlarını çalıştırma süreçlerini destekleyen bir ajan çalışma alanı (agent workspace) sundu. Cloudflare Workers üzerinde çalışan bu platform, kurumsal sistemlerle entegre bir geliştirme ortamı sağlıyor.

- ★ 10.697
- TypeScript
- GitHub Trending · 2026-10-04

## Ne kazandırır?
- Yapay zekâ ajanlarına komut vererek sunumlar veya küçük kişisel uygulamalar üretebilirsiniz.
- Oluşturulan uygulamaları izole alanlarda çalıştırarak güvenlik sızıntılarını engelleyebilirsiniz.
- Güvenlik katmanı sayesinde ajanların gerçekleştirdiği eylemleri denetleyip onaylayabilirsiniz.

## Nasıl başlanır?

Sistemi hızlıca denemek için os.cloudflare.app/deploy web adresini ziyaret ederek bulut hizmeti Cloudflare hesabınıza dağıtım yapabilirsiniz. Alternatif olarak resmî dokümantasyondaki adımları takip ederek projeyi kendi bilgisayarınızda yerel olarak çalıştırabilirsiniz.
- [Resmî kaynak →](https://os.cloudflare.app)

- **Kimin için:** Yapay zekâ ajanları ve özel uygulamalar ile şirket içi verimliliği güvenli şekilde artırmak isteyen kurumlar içindir. 
- **Lisans:** Apache-2.0
