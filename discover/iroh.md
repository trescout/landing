# anahtar tabanlı esnek ağ bağlantıları

Iroh, IP adresleri yerine anahtar tabanlı (key-based) adresleme kullanarak ağ bağlantılarını daha esnek hale getiren modüler bir ağ yığınıdır (networking stack). Rust diliyle geliştirilen bu araç, ağ kesintilerine karşı dayanıklı ve doğrudan veri aktarımı sağlayan bir altyapı sunar.

- ★ 9.418
- Rust
- GitHub Trending · 2026-06-17

## Ne kazandırır?
- IP adresi yerine genel anahtar ile doğrudan bağlantı
- ağ kesintilerine karşı otomatik delik açma ve röle desteği
- QUIC tabanlı şifreli ve hızlı veri aktarımı

## Nasıl başlanır?

Iroh, öncelikli olarak bir Rust kütüphanesidir. Başlamak için resmî dokümantasyon sitesi olan iroh.computer adresini ziyaret ederek kurulum adımlarını inceleyebilir veya Rust projelerinize 'cargo add iroh' komutuyla dahil ederek geliştirmeye başlayabilirsiniz. Diğer programlama dilleri için ise GitHub üzerindeki iroh-ffi deposuna göz atabilirsiniz.
- [Resmî kaynak →](https://iroh.computer)

- **Kimin için:** Doğrudan ve dayanıklı ağ bağlantıları kurmak isteyen Rust geliştiricileri ile kendi ağ protokollerini oluşturmak isteyen yazılımcılar için uygundur.
