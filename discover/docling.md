# Docling

Docling, karmaşık belge formatlarını üretken yapay zekâ (generative AI) modellerinin işleyebileceği temiz metin veya yapılandırılmış verilere dönüştüren bir Python kütüphanesidir. PDF, Word ve HTML gibi farklı dosya türlerini analiz ederek verilerin yapay zekâ uygulamalarında kullanılmasını kolaylaştırır.
