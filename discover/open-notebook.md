# Kendi verilerinizle yapay zekâ asistanı

Open-notebook, Google NotebookLM'in açık kaynaklı bir alternatifini sunarak kullanıcıların kendi verileri üzerinde özelleştirilebilir yapay zekâ destekli not analizi (AI-powered note analysis) yapmalarına olanak tanıyor. TypeScript ile geliştirilen bu proje, orijinal platforma kıyasla daha fazla esneklik ve genişletilmiş özellik seti sağlıyor.

## Ne kazandırır?
- Verilerinizi tamamen yerel ortamda gizli tutarak analiz edin.
- 18'den fazla yapay zekâ sağlayıcısı ile esnek model seçimi yapın.
- PDF, video ve ses dosyalarınızdan profesyonel podcast'ler oluşturun.

## Kurulum

**Yapılandırma dosyasını indirme**

```
curl -o docker-compose.yml https://raw.githubusercontent.com/lfnovo/open-notebook/main/docker-compose.yml
```

## Çalıştırma

**Servisleri başlatma**

```
docker compose up -d
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Open Notebook aracını kurmak istiyorum. Docker Desktop yüklü durumda. Öncelikle curl komutu ile docker-compose.yml dosyasını indirmem, ardından dosya içindeki OPEN_NOTEBOOK_ENCRYPTION_KEY kısmını kendime özel bir şifre ile değiştirmem gerekiyor. Son aşamada ise docker compose up -d komutunu çalıştırarak kurulumu tamamlamam lazım. Bu süreçte dikkat etmem gereken başka bir ayar veya adım var mı?

- **Kimin için:** Kendi verileri üzerinde tam kontrol sahibi olmak isteyen, gizlilik odaklı yapay zekâ destekli not analizi ve içerik üretimi arayan kullanıcılar için uygundur.
