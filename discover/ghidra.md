# Yazılım tersine mühendislik için analiz çerçevesi

Ulusal Güvenlik Ajansı (NSA) tarafından geliştirilen Ghidra, yazılım tersine mühendislik (software reverse engineering) süreçleri için kullanılan kapsamlı bir analiz çerçevesidir. Java diliyle yazılan bu araç, ikili dosyaların kod yapısını çözümleyerek güvenlik araştırmacılarına detaylı inceleme imkânı sunar.

## Nasıl başlanır?

Resmî internet sitesindeki yayınlar sayfasından güncel sürümü indirin ve bilgisayarınıza Java Geliştirme Kiti (JDK) 21 64-bit kurun. İndirdiğiniz dosyayı klasöre çıkartın ve işletim sisteminize göre ghidraRun veya ghidraRun.bat dosyasını çalıştırarak uygulamayı başlatın. Daha detaylı bilgi için kurulum klasöründeki Getting Started dokümanını inceleyebilirsiniz.
- [Resmî kaynak →](https://www.nsa.gov/ghidra)

- **Kimin için:** Yazılımın nasıl çalıştığını anlamak isteyen güvenlik araştırmacıları ve tersine mühendislik uzmanları için tasarlanmıştır. 
- **Lisans:** Apache-2.0
