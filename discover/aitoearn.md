# Yapay zekâ ile gelir yönetimi

AiToEarn, kullanıcıların yapay zekâ destekli otomasyonlar aracılığıyla gelir elde etme süreçlerini yönetmelerini sağlayan bir TypeScript tabanlı platformdur. Proje, otonom görev yürütme ve yapay zekâ tabanlı kazanç modellerini (AI-driven earning models) bir araya getirerek geliştiricilere açık bir altyapı sunuyor.

## Ne kazandırır?

- Yapay zekâ destekli içerik oluşturma ve otomatik yayınlama süreçlerini yönetir.
- CPS, CPE ve CPM modelleriyle içeriklerden gelir elde etmeyi sağlar.
- Birden fazla sosyal medya platformunda eş zamanlı etkileşim ve takipçi yönetimi sunar.

## Kurulum

**Docker ile Hızlı Kurulum**

```
git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn
docker compose up -d
```

**OpenClaw Eklentisi Kurulumu**

```
npx -y @aitoearn/openclaw-plugin-cli
```

## Çalıştırma

**Docker ile Başlatma**

```
docker compose up -d
```

## Kod bilmiyorsanız

Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın

AiToEarn platformunu kullanarak içerik üretim süreçlerimi otomatize etmek istiyorum. Öncelikle aitoearn.ai veya aitoearn.cn üzerinden bir hesap oluşturup API Key'imi aldım. Bu anahtarı kullanarak Claude, Cursor veya OpenClaw gibi araçlara entegrasyonu nasıl tamamlayabilirim? Ayrıca, içeriklerimi birden fazla sosyal medya platformunda eş zamanlı yayınlamak ve gelir elde etme modellerini (CPS, CPE, CPM) aktif etmek için izlemem gereken temel adımları açıklar mısın?

Depo: https://github.com/yikart/AiToEarn. Kurulum ve çalıştırmada bu deponun README dosyasındaki resmî talimatları esas al.

Başlamadan önce hangi işletim sisteminde çalıştığımızı ve gerekli araçların (ör. Python, Node.js, Git, Docker) kurulu olup olmadığını kontrol et; eksik olanları bu sisteme göre adım adım kur.

Çalışmak için yeni ve boş bir klasör oluştur. Bu klasörün dışındaki dosyalarıma dokunma, hiçbir şeyi silme. Her komutu çalıştırmadan önce ne yapacağını bir cümleyle söyle.

Bir API anahtarı gerekirse onu sohbete yazmamı isteme. .env dosyasına nasıl ekleyeceğimi göster ve bu dosyanın Git'e gönderilmediğinden emin ol.

Her adımın sonunda ekranda ne görmem gerektiğini söyle. Bir hata oluşursa hata mesajını sana olduğu gibi yapıştıracağım, birlikte düzeltelim.
