# Modern web geliştirme rehberlerini kalibre edin

GoogleChrome/modern-web-guidance-src, modern web geliştirme rehberlerinin oluşturulması, kalibre edilmesi ve değerlendirilmesi için gerekli kod ve dokümantasyonu içeren bir kaynak deposudur. TypeScript diliyle geliştirilen bu proje, web standartlarına yönelik rehber içeriklerinin yönetilmesini sağlar.

## Ne kazandırır?

- Yapay zekâ kodlama ajanlarının eski kod yazma alışkanlıklarını güncel web standartlarıyla değiştirir.
- Tarayıcı uyumluluğu ve performans odaklı hazır geliştirme rehberlerini doğrudan ajanın bağlamına aktarır.
- Gereksiz kütüphaneler yerine tarayıcının yerleşik özelliklerini ve hafif çözümlerini ön plana çıkarır.

## Kurulum

**Etkileşimli sihirbaz ile kurulum**

```
npx modern-web-guidance@latest install
```

**Seçenekli alternatif kurulum**

```
npx modern-web-guidance@latest install --choose
```

## Çalıştırma

**Rehber arama ve koddaki eski yapıları ta**

```
# Search for relevant guides
npx modern-web-guidance@latest search "animate a dialog modal backdrop"

# Retrieve a guide by ID
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"

# Scan a codebase for legacy patterns to modernize
npx modern-web-guidance@latest legacy-scan .
```
