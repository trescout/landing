# Gerçek zamanlı yapay zekâ ses araçları

Moonshine, sesli arayüzler ve yapay zekâ ajanları için düşük gecikmeli konuşmayı metne dönüştürme (speech to text), niyet tanıma (intent recognition) ve metni sese dönüştürme (text to speech) yetenekleri sunuyor. C++ diliyle geliştirilen bu kütüphane, gerçek zamanlı ses işleme süreçlerini optimize etmeyi hedefliyor.

## Kurulum

**Python ile kurulum**

```
pip install moonshine-voice
moonshine-voice mic --language en
```

**Raspberry Pi kurulumu**

```
sudo pip install --break-system-packages moonshine-voice
moonshine-voice mic --language en
```

## Çalıştırma

**Mikrofon üzerinden canlı transkripsiyon**

```
moonshine-voice mic --language en
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Moonshine kütüphanesini kullanarak sesli bir arayüz geliştirmek istiyorum. Mikrofonumdan gelen sesi gerçek zamanlı olarak metne dönüştürmek ve bu metin üzerinden niyet tanıma işlemleri yapmak için gerekli temel Python kod yapısını oluşturmama yardımcı ol. Ayrıca, sistemin düşük gecikmeli çalışması için dikkat etmem gereken yapılandırma ayarlarını açıkla.

- **Kimin için:** Cihaz üzerinde çalışan, düşük gecikmeli ve gizlilik odaklı sesli yapay zekâ uygulamaları geliştirmek isteyen yazılımcılar içindir.
