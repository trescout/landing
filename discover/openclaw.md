## Kurulum

**Otomatik yükleme betiğini çalıştırma (ma**

```
# macOS / Linux / WSL2
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Node.js paket yöneticisi npm ile küresel**

```
npm install -g openclaw@latest --allow-scripts=openclaw
```
