## Ne kazandırır?

- İnternet bağlantısına ihtiyaç duymadan konuşmalarınızı anında metne çevirir
- Ses verilerini bulut sunucularına göndermeyerek kişisel gizliliğinizi korur
- Klavyeden belirlediğiniz bir kısayola basarak doğrudan aktif metin alanına yazdırır

## Kurulum

**Debian veya Ubuntu tabanlı Linux sisteml**

```
sudo apt install ./Handy_*.deb
```
