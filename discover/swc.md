## Kurulum

**Proje bağımlılığı (npm)**

```
npm i -D @swc/core
```

**npm ile global**

```
npm install -g @swc/cli @swc/core
```

## Çalıştırma

**TypeScript dosyasını derle**

```
swc index.ts -o index.js
```

**Kaynak:** Resmî kaynak: https://github.com/swc-project/swc
