Yapay zekâ asistanınıza SwiftUI uzmanlığı

SwiftUI-Agent-Skill, arayüz geliştirme aracı SwiftUI için yapay zekâ modellerine özel yetenek paketleri (skills) sunuyor. Bu kaynak, Claude Code ve Codex gibi yapay zekâ kodlama asistanlarının SwiftUI bileşenlerini daha tutarlı ve hızlı oluşturmasına yardımcı oluyor.

Ne kazandırır?

  • Apple arayüz kütüphanesi SwiftUI ile yazılan kodlardaki performans ve erişilebilirlik hatalarını yapay zekâya denetletir.
  • Büyük dil modellerinin eski uygulama arayüzlerini (API) kullanmasını ve ekran okuma sorunlarını önler.
  • Kodlama yardımcıları Claude Code ve Codex içine kolayca entegre edilerek modern kod standartları kazandırır.

Kurulum

Paket yöneticisi Homebrew ile Node ortam
brew install node
SwiftUI Pro yeteneğini yapay zekâ asista
npx skills add https://github.com/twostraws/swiftui-agent-skill --skill swiftui-pro

Kod bilmiyorsanız

🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın

Bilgisayarıma yazılım çalıştırma ortamı Node kurulu değilse 'brew install node' komutunu kullanarak yükle. Ardından kodlama asistanıma SwiftUI uzmanlığı kazandırmak için 'npx skills add https://github.com/twostraws/swiftui-agent-skill --skill swiftui-pro' komutunu çalıştır ve bu yeteneği projelerimde kullanıma hazır hale getir.
