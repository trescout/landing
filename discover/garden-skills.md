# Web tasarımı için açık kaynaklı beceriler

Garden-skills é uma coleção de habilidades (skills) de código aberto desenvolvida para diversas funções, como web design, aquisição de informações e criação visual. O objetivo é acelerar os processos de desenvolvimento reunindo funções modulares que os desenvolvedores de software podem integrar aos seus projetos.

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Garden Skills kütüphanesini kullanarak yapay zekâ ajanıma web tasarımı ve sunum hazırlama yetenekleri ekle. Projemin ihtiyaçlarına göre web-design-engineer veya web-video-presentation modüllerini aktif et ve bu modüllerin sunduğu tasarım sistemlerini, stil reçetelerini ve görselleştirme kurallarını kullanarak çıktı üret.

- **Kimin için:** Yapay zekâ kodlama ajanlarını kullanarak web projeleri geliştiren ve tasarım süreçlerini otomatize etmek isteyen yazılımcılar içindir.
