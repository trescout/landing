## Ne kazandırır?

- Web tasarımı, bilgi edinme ve görsel oluşturma alanlarında hazır yetenek paketleri sunar
- Yazı, ders ve demoları video sunumlarına dönüştüren yapay zekâ iş akışları barındırır
- Farklı arayüz prototipleri ve tasarım sistemleri için pratik kılavuzlar içerir

## Kurulum

**Tüm yetenekleri yükleme**

```
npx skills add ConardLi/garden-skills
```

**Tek bir yeteneği yükleme**

```
npx skills add ConardLi/garden-skills -s web-design-engineer
```

## Çalıştırma

**Yüklü yetenekleri listeleme**

```
npx skills list
```
