# Claude için güvenlik uzmanı becerileri

Claude-Red, yapay zekâ modeli Claude'un yetenek sistemine entegre edilen saldırı odaklı güvenlik becerileri (offensive security skills) kütüphanesidir. SQL enjeksiyonu ve uç nokta koruma sistemlerini atlatma gibi konularda uzman seviyesinde metodolojiler sunarak güvenlik testlerini otomatize etmeyi amaçlar.

## Kurulum

**Tüm becerileri indirme**

```
git clone https://github.com/SnailSploit/claude-red ~/.claude/skills/claude-red
```

**Etkileşimli kurulum**

```
./install.sh # interactive
./install.sh --target ~/.claude/skills # explicit target
./install.sh --category web # single category
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Şu andan itibaren bir sızma testi uzmanı gibi davranmanı istiyorum. Paylaştığım beceri dosyalarındaki metodolojileri kullanarak güvenlik açıklarını analiz et, saldırı yüzeylerini değerlendir ve siber güvenlik araştırmalarımda bana rehberlik et.

- **Kimin için:** Sızma testi yapan güvenlik araştırmacıları ve siber güvenlik alanında eğitim alan operatörler için uygundur.
