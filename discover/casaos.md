# Kişisel bulut sunucunuzu yönetin

CasaOS, Docker tabanlı uygulamaları yönetmeyi kolaylaştıran açık kaynaklı bir kişisel bulut sistemi (personal cloud system) sunuyor. Go diliyle geliştirilen bu arayüz, kullanıcıların kendi sunucularını görsel bir panel üzerinden basit şekilde yönetmelerine imkan tanıyor.

- ★ 34.992
- Go
- GitHub Trending · 2026-06-26

## Ne kazandırır?
- Docker uygulamalarını tek tıkla kurun
- Görsel arayüzle dosya yönetimi yapın
- Sunucu kaynaklarını widget ile izleyin

## Kurulum

**Kurulum komutu**

```
curl -fsSL https://get.casaos.io | sudo bash
```

## Çalıştırma

**Güncelleme komutu**

```
curl -fsSL https://get.casaos.io/update | sudo bash
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Kişisel sunucumda Docker tabanlı uygulamaları yönetmek için CasaOS kullanıyorum. Sistem kaynaklarımı izlemek, yeni uygulamalar kurmak ve dosya yönetimini görsel bir panel üzerinden yapmak istiyorum. Bu süreçte karşılaştığım teknik zorlukları ve Docker ekosistemindeki uygulamaları nasıl daha verimli yönetebileceğimi adım adım açıkla.

- **Kimin için:** Ev sunucusu veya kişisel bulut sistemi kurmak isteyen, kod yazmadan Docker uygulamalarını yönetmeyi hedefleyen kullanıcılar içindir. 
- **Lisans:** Apache-2.0
