# Modern içerik ve bülten platformu

Ghost é um sistema de gerenciamento de conteúdo (CMS) de código aberto desenvolvido para publicação moderna, gerenciamento de membros e envio de boletins informativos. É uma plataforma baseada em JavaScript que fornece aos criadores de conteúdo a infraestrutura necessária para criar modelos de receita baseados em assinatura.

## Kurulum

**Komut satırı aracını yükleyin**

```
npm install ghost-cli -g
```

## Çalıştırma

**Yerel kurulumu başlatın**

```
ghost install local
```

**Sunucu üzerinde kurulumu başlatın**

```
ghost install
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Ghost platformunu kullanarak profesyonel bir içerik sitesi kurmak istiyorum. Node.js tabanlı bu içerik yönetim sistemini (CMS) kendi sunucumda veya yerel ortamımda çalıştırmak için izlemem gereken adımları, Ghost CLI aracını kullanarak nasıl yapılandıracağımı ve kurulum sonrası dikkat etmem gereken temel yönetim ipuçlarını adım adım açıkla.

- **Kimin için:** Profesyonel yayıncılık yapmak, içeriklerinden abonelik geliri elde etmek ve bültenlerini yönetmek isteyen içerik üreticileri için uygundur.
