## Kurulum

**Komut satırı aracını yükleyin**

```
npm install ghost-cli -g
```

## Çalıştırma

**Yerel kurulumu başlatın**

```
ghost install local
```

**Sunucu üzerinde kurulumu başlatın**

```
ghost install
```
