# Kod tabanınızı yapay zekâya haritalandırın

Codegraph, kod tabanlarını önceden dizinleyerek yapay zekâ modellerine sunan yerel bir bilgi grafiği (knowledge graph) aracıdır. Kod değişikliklerini otomatik eşitleyerek Claude Code veya Cursor gibi kodlama asistanlarının daha az belirteç (token) ve araç çağrısı kullanmasını sağlar.

## Ne kazandırır?
- Kodlama yaparken yapay zekâ modellerinin daha az belirteç tüketmesini sağlayan yerel bilgi grafiği oluşturur.
- Kod değişikliklerini arka planda otomatik eşitleyerek indeksi her zaman güncel tutar.
- Kodlama asistanı Cursor gibi araçları doğrudan projenizin mimarisiyle bağlar.

## Kurulum

**Paket yöneticisi npm ile küresel kurulum**

```
npm i -g @colbymchenry/codegraph
```

## Çalıştırma

**Aracı doğrudan npx ile çalıştırma ve bağ**

```
npx @colbymchenry/codegraph
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Projemde paket yöneticisi npm aracılığıyla `npm i -g @colbymchenry/codegraph` komutunu çalıştırarak Codegraph aracını kurun. Ardından yapay zekâ asistanlarını yapılandırmak için `npx @colbymchenry/codegraph` komutunu çalıştırarak işlemi tamamlayın.

- **Kimin için:** Yapay zekâ destekli kodlama asistanlarının karmaşık kod tabanlarını daha az belirteç harcayarak hızlıca anlamasını isteyen geliştiriciler içindir.
