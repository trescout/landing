# Kullanıcı etkileşimleriyle gelişen yapay zekâ

NousResearch tarafından geliştirilen Hermes Agent, kullanıcı etkileşimleriyle öğrenerek zaman içinde gelişen bir otonom ajan (autonomous agent) altyapısı sunuyor. Python tabanlı bu sistem, kişiselleştirilmiş iş akışları oluşturmak için sürekli öğrenen bir yapı (continuous learning) kullanıyor.

## Kurulum

**Linux, macOS ve WSL2 için kurulum**

```
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

## Çalıştırma

**Arayüzü başlatma**

```
hermes
```

## Kod bilmiyorsanız

Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın

Hermes Agent ile çalışırken otonom öğrenme döngüsünden faydalanmak istiyorum. Sistemin geçmiş konuşmalarımı hatırlaması, görevler üzerinden yeni beceriler oluşturması ve zamanla kişiselleşmesi için hangi komutları kullanmalıyım? Özellikle farklı modeller arasında geçiş yapmak ve mesajlaşma platformlarını sisteme bağlamak için izlemem gereken temel adımları açıklar mısın?
