Claude kodlama asistanı için eklentiler

Anthropic, Claude Code için geliştirilen yüksek kaliteli eklentileri (plugins) tek bir merkezde toplayan resmi bir dizin sunuyor. Bu Python tabanlı yapı, geliştiricilerin kodlama asistanları için hazırlanan araçları (tools) standart bir formatta paylaşmasını ve keşfetmesini sağlıyor.

Nasıl başlanır?

Claude Code arayüzü içerisinde '/plugin > Discover' menüsünü kullanarak mevcut eklentilere göz atabilirsiniz. Eklentileri yüklemek için Claude Code komut satırında '/plugin install {plugin-name}@claude-plugins-official' komutunu kullanmanız yeterlidir.
