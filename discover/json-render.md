# JSON Render

Vercel Labs tarafından geliştirilen json-render, üretken arayüz (generative UI) kurguları için veri yapılarını görsel bileşenlere dönüştüren bir çerçeve (framework). Geliştiricilerin yapay zekâ modellerinden gelen yapılandırılmış verileri, web arayüzlerinde dinamik ve etkileşimli öğeler olarak sunmasını sağlıyor.
