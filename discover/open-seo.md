## Kurulum

**Yapay zekâ ajanına yetenek ekleme**

```
npx skills add every-app/open-seo --skill '*'
```

**Docker ile yerel kurulum**

```
docker compose pull
docker compose up -d
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın
