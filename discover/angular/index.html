Kurulum

Komut satırı arayüzünü kurma
npm install -g @angular/cli

Çalıştırma

Yeni bir çalışma alanı oluşturma
ng new [PROJECT NAME]
Uygulamayı yerelde başlatma
cd [PROJECT NAME]
ng serve
