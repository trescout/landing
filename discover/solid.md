# Yapay zekâ dostu hızlı arayüzler

Solid, kullanıcı arayüzleri oluşturmak için kullanılan bildirimsel (declarative) bir JavaScript kütüphanesidir. Sanal belge nesne modeli (Virtual DOM) kullanmak yerine şablonları doğrudan gerçek belge nesne modeli (DOM) düğümlerine derleyerek ince taneli tepkisellik (fine-grained reactivity) ile güncellemeler yapar.

- ★ 36.669
- TypeScript
- GitHub Trending · 2026-11-19

## Güncelleme

- **19 Kasım 2026:** Yıldız 36.662 → 36.669, son sürüm @solidjs/diagnostics@2.0.1 (18 Kasım 2026).

## Ne kazandırır?

- Arayüz yönetim yapısı Virtual DOM yerine doğrudan gerçek tarayıcı düğümlerini güncelleyerek hız kazanır.
- Bileşenleri sadece bir kez çalıştırarak işlemci üzerindeki yükü minimize eder.
- Veri değişimlerini otomatik takip eden yapısıyla sadece etkilenen küçük parçaları yeniler.

## Kurulum

**Hazır şablonla yeni proje oluşturma**

```
npx degit solidjs/templates/solid-v2/basic my-app
cd my-app
npm install
npm run dev
```

## Çalıştırma

**Geliştirme aracı Vite projesine dahil et**

```
npm i solid-js @solidjs/web
npm i -D vite @solidjs/vite-plugin
```
