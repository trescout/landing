# Yapay zekâ kodlama ajanı

QwenLM/qwen-code, terminal, editör, masaüstü ve tarayıcı üzerinde çalışan açık kaynaklı (open-source) bir kodlama yapay zekâ ajanıdır. TypeScript diliyle geliştirilen bu araç, yazılım geliştirme süreçlerini farklı platformlarda desteklemeyi amaçlar.

- ★ 29.939
- TypeScript
- GitHub Trending · 2026-11-13

## Güncelleme

- **13 Kasım 2026:** Yıldız 29.931 → 29.939, son sürüm sdk-typescript-v0.1.33 (13 Kasım 2026).

## Ne kazandırır?

- Terminal, masaüstü, tarayıcı ve editör üzerinde kodlama yapmanızı sağlar
- Otomatik bellek, yetenekler ve alt ajanlarla dinamik iş akışları sunar
- Çoklu protokol desteğiyle farklı yapay zekâ servislerini ve yerel modelleri kullanır

## Kurulum

**NPM ile Yükleme**

```
npm install -g @qwen-code/qwen-code@latest
```

**Homebrew ile Yükleme**

```
brew install qwen-code
```

## Çalıştırma

**Başlatma**

```
qwen
```
