# Görsel ve yerel hata ayıklama aracı

Epic Games tarafından geliştirilen raddebugger, C diliyle yazılmış yerel ve görsel bir hata ayıklayıcıdır (debugger). Çoklu süreç (multi-process) desteği sunan bu araç, yazılım geliştiricilerin uygulama hatalarını tespit etmesi için kullanıcı modunda çalışır.

## Güncelleme

- **7 Ekim 2026:** Yıldız 7.693 → 7.702, son sürüm v0.9.29-alpha (30 Eylül 2026).

## Ne kazandırır?

- Görsel arayüze sahip hata ayıklayıcı Raddebugger ile uygulamalarınızdaki yazılım hatalarını kolayca tespit edebilirsiniz.
- Kod bağlama aracı RAD Linker sayesinde büyük yazılım projelerindeki derleme sürelerini kısaltabilirsiniz.
- Özel veri formatı RDI ile hata ayıklama bilgilerini hızlıca dönüştürüp performans kazanabilirsiniz.

## Nasıl başlanır?

Projenin GitHub sayfasında yer alan sürümler (releases) bölümünden sisteminize uygun hazır derlenmiş dosyaları indirebilirsiniz. İndirdiğiniz klasörün içindeki kullanım kılavuzunu takip ederek aracı hemen çalıştırmaya başlayabilirsiniz.

- **Kimin için:** Windows platformunda C diliyle büyük yazılımlar geliştiren ve görsel bir hata ayıklama arayüzüne ihtiyaç duyan geliştiriciler içindir.
