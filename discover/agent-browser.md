# Yapay zekâ ajanları için tarayıcı otomasyon aracı

Vercel Labs tarafından geliştirilen agent-browser, yapay zekâ ajanları için tarayıcı otomasyonu sağlayan bir komut satırı arayüzü (CLI). Rust diliyle yazılan bu araç, sayfaları erişilebilirlik ağacı (accessibility tree) olarak okuyup komut satırı üzerinden web öğeleriyle etkileşime girilmesine olanak tanıyor.

## Ne kazandırır?

- Sayfaları erişilebilirlik ağacı olarak metin şeklinde okur
- Komut satırı üzerinden web öğeleriyle etkileşime girer
- Arka plandaki sunucuyla tarayıcıyı komut komut yönetir

## Kurulum

**Genel Kurulum**

```
npm install -g agent-browser
agent-browser install           # download Chrome for Testing (first time only)
```

## Çalıştırma

**Hızlı Başlangıç**

```
agent-browser open example.com
```

## Kod bilmiyorsanız

Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın

Lütfen agent-browser aracını kurarak yapılandırmayı tamamla. Kurulum için npm install -g agent-browser komutunu kullan.

Depo: https://github.com/vercel-labs/agent-browser. Kurulum ve çalıştırmada bu deponun README dosyasındaki resmî talimatları esas al.

Başlamadan önce hangi işletim sisteminde çalıştığımızı ve gerekli araçların (ör. Python, Node.js, Git, Docker) kurulu olup olmadığını kontrol et; eksik olanları bu sisteme göre adım adım kur.

Çalışmak için yeni ve boş bir klasör oluştur. Bu klasörün dışındaki dosyalarıma dokunma, hiçbir şeyi silme. Her komutu çalıştırmadan önce ne yapacağını bir cümleyle söyle.

Her adımın sonunda ekranda ne görmem gerektiğini söyle. Bir hata oluşursa hata mesajını sana olduğu gibi yapıştıracağım, birlikte düzeltelim.

- **Kimin için:** Tarayıcı otomasyonunu komut satırından yönetmek isteyen yapay zekâ geliştiricileri içindir.
- **Lisans:** Apache-2.0
