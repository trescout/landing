# Yapay zekâ ajanları için masaüstü kontrol aracı

Vercel Labs tarafından geliştirilen agent-desktop, yapay zekâ ajanlarının işletim sistemi erişilebilirlik ağacı üzerinden masaüstü uygulamalarını okumasını ve yönetmesini sağlayan bir komut satırı arayüzüdür (CLI). Rust diliyle yazılan bu araç, ajanların bilgisayar kullanım (computer use) yeteneklerini geliştirmeyi amaçlıyor.

## Ne kazandırır?

- İşletim sistemi erişilebilirlik ağacı üzerinden masaüstü uygulamalarını okur
- Piksel eşleştirmeye gerek duymadan ögeler üzerinde işlem yapar
- JSON formatında hızlı ve yapılandırılmış yanıtlar üretir

## Kurulum

**Paket yöneticisiyle kur**

```
npm install -g agent-desktop
agent-desktop version
```

**Yetenek ekle**

```
npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop
```

## Kod bilmiyorsanız

Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın

agent-desktop version komutunu çalıştır ve ajan yeteneklerini eklemek için npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop komutunu kullan.

Depo: https://github.com/vercel-labs/agent-desktop. Kurulum ve çalıştırmada bu deponun README dosyasındaki resmî talimatları esas al.

Başlamadan önce hangi işletim sisteminde çalıştığımızı ve gerekli araçların (ör. Python, Node.js, Git, Docker) kurulu olup olmadığını kontrol et; eksik olanları bu sisteme göre adım adım kur.

Çalışmak için yeni ve boş bir klasör oluştur. Bu klasörün dışındaki dosyalarıma dokunma, hiçbir şeyi silme. Her komutu çalıştırmadan önce ne yapacağını bir cümleyle söyle.

Her adımın sonunda ekranda ne görmem gerektiğini söyle. Bir hata oluşursa hata mesajını sana olduğu gibi yapıştıracağım, birlikte düzeltelim.

- **Kimin için:** Masaüstü uygulamalarını otomatik olarak yönetmek ve test etmek isteyen yapay zekâ geliştiricileri için uygundur.
