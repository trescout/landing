# Modern JavaScript ve TypeScript çalışma zamanı

Deno, JavaScript ve TypeScript dilleri için tasarlanmış modern bir çalışma zamanı (runtime) ortamıdır. Rust diliyle geliştirilen bu araç, güvenlik ve performans odaklı yapısıyla geleneksel Node.js platformuna alternatif bir altyapı sunar.

## Ne kazandırır?
- JavaScript, TypeScript ve WebAssembly dillerini güvenli bir şekilde çalıştırır.
- V8 motoru ve Rust dili ile yüksek performans sağlar.
- Web sunucuları geliştirmek için modern ve pratik bir altyapı sunar.

## Kurulum

**Mac veya Linux sistemlerde kurulum**

```
curl -fsSL https://deno.land/install.sh | sh
```

**Mac üzerinde Homebrew ile kurulum**

```
brew install deno
```

## Çalıştırma

**Hazırlanan sunucu dosyasını başlatma**

```
deno run --allow-net server.ts
```
