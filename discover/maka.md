## Kurulum

**Geliştirme ortamını başlatma**

```
git clone https://github.com/apache/maka.git
cd maka
npm ci
npm run dev
```

**Tüm çalışma alanlarını oluşturma**

```
npm run dev:full
```

## Çalıştırma

**Terminal arayüzünü başlatma**

```
npm run cli:dev
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Maka çalışma alanında bir projeyi analiz etmen, gerekli araçları kullanarak dosyaları düzenlemen ve yaptığın tüm işlemleri izlenebilir bir kayıt günlüğünde saklaman gerekiyor. İş akışın boyunca izinleri kontrol et, model mesajlarını koru ve hata durumunda süreci kurtarılabilir bir şekilde yönet.

- **Kimin için:** Projelerini yerel ortamda, verileri üzerinde tam kontrole sahip olarak yönetmek isteyen yazılımcılar ve yapay zekâ ajanı geliştiricileri için uygundur. 
- **Lisans:** Apache-2.0
