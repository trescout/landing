Tek kodla çoklu platform uygulaması

Google tarafından geliştirilen Flutter, tek bir kod tabanı kullanarak mobil, web ve masaüstü platformları için hızlı bir şekilde kullanıcı arayüzü (user interface) oluşturulmasına olanak tanıyor. Dart programlama dilini temel alan bu açık kaynaklı çerçeve (framework), yüksek performanslı ve görsel açıdan zengin uygulamalar geliştirmek için yaygın olarak tercih ediliyor.

  • GitHub Trending · 2026-06-25

Güncelleme

  • 2 Ağustos 2026: Yıldız 177.494 → 178.068, son sürüm 3.19.0-0.1.pre (11 Ocak 2024).

Ne kazandırır?

  • Tek kod tabanıyla mobil, web ve masaüstü desteği
  • Anlık değişiklikleri görmeyi sağlayan hot reload özelliği
  • Donanım hızlandırmalı yüksek performanslı grafikler

Kurulum

macOS (Homebrew)
brew install --cask flutter

Çalıştırma

Ortam kontrollerini doğrula
flutter doctor
Yeni proje oluştur ve çalıştır
flutter create my_app
cd my_app
flutter run

Kaynak: Homebrew Cask (flutter) · resmî Flutter dokümantasyonu (docs.flutter.dev)

Nasıl başlanır?

Flutter ile geliştirmeye başlamak için resmî web sitesi olan flutter.dev adresini ziyaret etmeniz gerekmektedir. Kurulum adımları ve işletim sisteminize uygun indirme seçenekleri için sitedeki 'Get Started' bölümünü takip ederek rehberli kurulumu tamamlayabilirsiniz.
