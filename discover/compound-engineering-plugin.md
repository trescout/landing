## Kurulum

**Claude Code marketplace’ini ekle**

```
/plugin marketplace add EveryInc/compound-engineering-plugin
/plugin install compound-engineering
```

## Çalıştırma

**Kurulum sihirbazını başlat**

```
/ce-setup
```

Kaynak: Resmî kaynak: https://github.com/EveryInc/compound-engineering-plugin

## Nasıl başlanır?

Yapay zekâ asistanınıza eklenti olarak kurabilir, ardından becerileri ve ajanları iş akışınıza dahil edebilirsiniz.

## Nasıl kurulur, nasıl kullanılır?
🤖 Kod bilmiyorsanız · yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Claude Code'da çalışıyorsan şu iki komutu sırayla çalıştırarak Compound Engineering eklentisini kur: '/plugin marketplace add EveryInc/compound-engineering-plugin' ve ardından '/plugin install compound-engineering'; kurulum bitince herhangi bir projede '/ce-setup' komutunu çalıştırarak ortamı hazırla.

Lisans: MIT · özgürce kullanabilir, değiştirebilir, ticari kullanabilirsiniz.
