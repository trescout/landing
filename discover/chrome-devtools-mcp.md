# yapay zekâ için tarayıcı hata ayıklama

Chrome Geliştirici Araçları (Chrome DevTools) için geliştirilen bu sunucu, kodlama yapan yapay zekâ ajanlarının (coding agents) tarayıcı tabanlı hata ayıklama süreçlerini yönetmesini sağlıyor. Model Bağlam Protokolü (Model Context Protocol) üzerinden çalışan bu araç, ajanların web uygulamalarını doğrudan incelemesine ve hata giderme işlemlerini otomatize etmesine olanak tanıyor.

- ★ 45.204
- TypeScript
- GitHub Trending · 2026-07-03

## Ne kazandırır?
- Canlı tarayıcıyı doğrudan kontrol etme
- Performans analizlerini otomatikleştirme
- Ağ isteklerini ve konsol hatalarını inceleme

## Kurulum

**Claude Code ile kurulum**

```
claude mcp add chrome-devtools --scope user npx chrome-devtools-mcp@latest
```

**Codex ile kurulum**

```
codex mcp add chrome-devtools -- npx chrome-devtools-mcp@latest
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Chrome DevTools MCP sunucusunu kullanarak aktif tarayıcı oturumuma bağlan ve web uygulamamdaki performans verilerini analiz et. Ağ isteklerini kontrol et, konsol hatalarını incele ve karşılaştığım sorunları gidermek için gerekli hata ayıklama adımlarını gerçekleştir.

- **Kimin için:** Tarayıcı tabanlı web uygulamalarını geliştiren ve hata ayıklama süreçlerini yapay zekâ ajanları ile otomatize etmek isteyen yazılımcılar için uygundur. 
- **Lisans:** Apache-2.0
