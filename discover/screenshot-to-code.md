# Ekran görüntülerini çalışan koda dönüştürün

Screenshot-to-code, ekran görüntüsü dosyalarını analiz ederek bunları temiz HTML, Tailwind, React veya Vue koduna dönüştüren bir yazılım aracıdır. Geliştiricilerin arayüz tasarımlarını hızlıca çalışan kod bloklarına (code snippets) çevirmesine olanak tanır.

- ★ 75.377
- Python
- GitHub Trending · 2026-08-28

## Ne kazandırır?
- Ekran görüntülerini ve tasarım dosyalarını temiz HTML veya React koduna çevirir
- Web sitesi kayıtlarını işlevsel prototiplere dönüştürür
- Tailwind CSS ve çeşitli popüler arayüz kütüphanelerini destekler

## Kurulum

**Docker ile hızlı kurulum**

```
echo "OPENAI_API_KEY=sk-your-key" > .env
docker-compose up -d --build
```

**Arayüzü başlatma**

```
cd frontend
pnpm install
pnpm dev
```

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
Ekran görüntüsünü analiz et ve görseldeki tasarımı birebir yansıtan, temiz ve işlevsel bir kod yapısı oluştur. Çıktıyı Tailwind CSS kullanarak HTML veya React formatında hazırla. Görseldeki gerçek logoları ve varlıkları ayıklayarak koda dahil et, tasarımın tüm öğelerini duyarlı (responsive) bir şekilde kodla.

- **Kimin için:** Arayüz tasarımlarını hızlıca çalışan kod bloklarına dönüştürmek isteyen tasarımcılar ve yazılımcılar için uygundur.
