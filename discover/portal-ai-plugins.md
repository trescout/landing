# Spotify portal verilerini kodlama asistanina tasiyin

Spotify tarafından geliştirilen portal-ai-plugins, Spotify Portal sistemini Claude Code, Codex, Cursor ve pi gibi yapay zekâ destekli kodlama araçlarına entegre etmeyi sağlıyor. TypeScript diliyle yazılan bu eklentiler, geliştiricilerin çalışma ortamlarında Spotify kaynaklı verilere erişimini kolaylaştırıyor.

- ★ 3.084
- TypeScript
- GitHub Trending · 2026-11-04

## Ne kazandırır?

- yazilim katalogunda dogal dille arama yapin
- servis ozetleri ve durum raporlari uretin
- portal islemlerini guvenli sekilde calistirin

## Nasıl başlanır?

Spotify Portal sistemini Claude Code, Codex, Cursor veya pi aracina entegre etmek icin resmi repository sayfasinda yer alan kurulum adimlarini takip edebilirsiniz.

- **Kimin için:** Yazilim kataloguna erismek ve portal islemlerini calistirmak isteyen gelistiriciler icin uygundur.
- **Lisans:** Apache-2.0
