# yapay zekâ ajanları için AWS araç seti

AWS, yapay zekâ ajanlarının bulut altyapısıyla etkileşimini kolaylaştırmak için Model Bağlantı Protokolü (Model Context Protocol) sunucuları, yetenekler (skills) ve eklentiler içeren bir araç seti yayımladı. Bu geliştirme, ajanların AWS servisleri üzerinde doğrudan işlem yapabilmesini sağlayan standartlaştırılmış bir yapı sunuyor.

## Kod bilmiyorsanız
🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın 
AWS üzerinde uygulama geliştirme, dağıtma ve yönetme süreçlerimde bana yardımcı ol. Agent Toolkit for AWS yeteneklerini kullanarak AWS servisleriyle etkileşime geç, gerekli yapılandırmaları yap ve bulut altyapısı üzerindeki işlemlerimi standartlara uygun şekilde yürüt.

- **Kimin için:** AWS üzerinde çalışan yapay zekâ kodlama ajanlarını daha yetenekli ve işlevsel hale getirmek isteyen yazılımcılar için uygundur.
