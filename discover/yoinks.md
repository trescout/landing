# Uçbirim üzerinden hızlı video indirme

Yoinks, uçbirim (terminal) üzerinden herhangi bir videoyu reklam veya yönlendirme olmadan indirmeye yarayan bir araçtır. TypeScript ile geliştirilen bu yazılım, video dosyalarını doğrudan yerel depolama birimine aktarmak için pratik bir yöntem sunar.

- TypeScript

## Ne kazandırır?

- YouTube, Instagram ve TikTok gibi 1800'den fazla siteden video indirir
- Reklam veya sahte indirme butonları olmadan doğrudan yerel depolamaya kaydeder
- Video çözünürlüğü seçme veya sadece ses dosyası alma imkânı sunar

## Kurulum

**Global olarak yükleme**

```
npm install -g yoinks
```

**Kurulum yapmadan çalıştırma**

```
npx yoinks
```

## Çalıştırma

**Video bağlantısıyla başlatma**

```
yoinks https://youtu.be/dQw4w9WgXcQ
```

**Etkileşimli menü ile başlatma**

```
yoinks
```

## Kod bilmiyorsanız

🤖 Yapay zekâ ajanınıza (Claude Code · Codex · Antigravity) yapıştırın

YouTube, X, Instagram veya TikTok gibi platformlardan video indirmek istiyorum. Uçbirim üzerinde çalışan bu aracı kullanarak, verdiğim video bağlantısını doğrudan yerel indirme klasörüme kaydedecek ve çözünürlük seçeneklerini sunacak şekilde yapılandır. İşlem sırasında reklam veya yönlendirme içermeyen, temiz bir indirme süreci yürütülmesini sağla.

- **Kimin için:** İnternet üzerindeki videoları tarayıcı reklamları ve karmaşık arayüzler olmadan, doğrudan bilgisayarına kaydetmek isteyen herkes için uygundur.
