# Jellyfin medya kütüphanenize masaüstü erişimi

Jellium-desktop, medya sunucusu Jellyfin için Rust diliyle geliştirilmiş resmi olmayan bir masaüstü istemcisidir (desktop client). Yazılım, kullanıcıların medya kütüphanelerine doğrudan işletim sistemi üzerinden erişmelerini sağlayan yerel bir arayüz sunar.

- ★ 1.342
- Rust
- GitHub Trending · 2026-07-20

## Ne kazandırır?
- Jellyfin medya sunucunuza yerel uygulama üzerinden erişin
- CEF ve mpv altyapısı ile optimize edilmiş medya oynatma
- Windows, macOS ve Linux üzerinde yerel arayüz desteği

## Nasıl başlanır?

Jellium Desktop uygulamasını kullanmaya başlamak için GitHub sayfasındaki indirme bağlantılarını kullanabilirsiniz. İşletim sisteminize uygun olan sürümü (Windows, macOS veya Linux) indirdikten sonra kurulum dosyasını çalıştırarak uygulamayı sisteminize kurun ve Jellyfin sunucu bilgilerinizi girerek erişim sağlayın.
- [Resmî kaynak →](https://github.com/andrewrabert/jellium-desktop)

- **Kimin için:** Jellyfin medya sunucusunu tarayıcı yerine yerel bir masaüstü uygulaması üzerinden kullanmak isteyen kullanıcılar içindir.
