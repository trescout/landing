## Kurulum

**Tüm özelliklerle PyPI üzerinden kur**

```
pip install 'markitdown[all]'
```

## Çalıştırma

**Dosyayı Markdown’a dönüştür**

```
markitdown belge.pdf > belge.md
```

**Kaynak:** Resmî kaynak: https://github.com/microsoft/markitdown
