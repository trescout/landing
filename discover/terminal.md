# Modern Windows komut satırı deneyimi

Microsoft, Windows Terminal ve geleneksel Windows konsol ana bilgisayarını (console host) tek bir çatı altında birleştiriyor. C++ diliyle geliştirilen bu açık kaynaklı proje, komut satırı deneyimini modern arayüz ve özelleştirilebilir sekmelerle yeniden yapılandırıyor.

Windows Terminal uygulamasını Microsoft Store üzerinden kolayca indirebilirsiniz. Alternatif olarak GitHub üzerindeki Releases sayfasından güncel sürümü manuel olarak indirebilir veya winget, Chocolatey ya da Scoop gibi paket yöneticilerini kullanarak bilgisayarınıza kurabilirsiniz.
