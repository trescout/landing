## Kurulum

**npm ile kur**

```
npm install supermemory
```

## Çalıştırma

**Claude için MCP sunucusunu ekle**

```
npx -y install-mcp@latest https://mcp.supermemory.ai/mcp --client claude --oauth=yes
```

**Kaynak:** Resmî kaynak: https://github.com/supermemoryai/supermemory
