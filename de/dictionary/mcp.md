# Was ist MCP?

> Model Context Protocol

Es ist der Standard, der es Modellen der künstlichen Intelligenz ermöglicht, sicher mit Daten aus der Außenwelt zu kommunizieren.

## Definition
Model Context Protocol (MCP) ist eine universelle Brücke, die es KI-Modellen ermöglicht, sicher mit Daten und Software von der Außenwelt zu kommunizieren. Es ermöglicht verschiedenen Anwendungen, mit künstlicher Intelligenz dieselbe Sprache zu sprechen.

## So funktioniert es
Mit MCP verbinden Entwickler KI sicher mit Datenbanken oder Dateisystemen. Das Modell ruft die benötigten Daten über dieses Protokoll ab.

## Wo es eingesetzt wird
Es kommt dort zum Einsatz, wo unternehmensinterne Privatdokumente durch künstliche Intelligenz gelesen oder Berichte aus Live-Datenbanken abgerufen werden müssen.

## Häufig verwechselt mit
Gemischt mit API; Während es sich bei der API um ein Tor handelt, handelt es sich bei MCP um eine Reihe von Regeln, die sicherstellen, dass die Daten, die dieses Tor passieren, in einer Standardsprache gesprochen werden.

## Häufige Fragen
**Warum ist MCP notwendig?**
Es erhöht die Sicherheit und Effizienz, indem es einem Standardpfad folgt, anstatt für jede Anwendung separate Verbindungen herzustellen.

**Ist MCP Open Source?**
Ja, es handelt sich um einen offenen Standard, der entwickelt wurde, um die Interoperabilität des Ökosystems der künstlichen Intelligenz zu verbessern.
