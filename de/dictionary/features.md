# Was ist Features?

*Glossar · Dev · Zuletzt aktualisiert: 16. Juli 2026*

Die besonderen Fähigkeiten und Funktionen, die eine Software oder ein Produkt den Benutzern bietet.

## Definition

Features sind Features, die definieren, was eine Anwendung tun kann. In einer Fotobearbeitungsanwendung sind beispielsweise „Rote Augen korrigieren“ oder „Anwenden eines Filters“ Funktionen. Diese Merkmale verkörpern die Vorteile, die das Produkt dem Benutzer bietet.

***Analogie:** Die Klimaanlage eines Autos ist wie eine Zusatzausrüstung, die das Fahrerlebnis verbessert, etwa ein Tempomat oder eine Rückfahrkamera.*

## So funktioniert es

Entwickler entscheiden, welche Funktionen der Software hinzugefügt werden sollen, indem sie die Bedürfnisse der Benutzer analysieren. Diese Funktionen werden codiert, getestet und dem Benutzer mit Updates angeboten.

## Wo es eingesetzt wird

Es wird häufig in Softwareentwicklungsprozessen, Produktmanagement-Meetings und Anwendungswerbung eingesetzt.

## Häufig verwechselt mit

Kann mit Tool verwechselt werden; Eine Funktion ist Teil des Produkts, während ein Tool ein externer Helfer ist, der die Aufgabe erledigt.

## Häufige Fragen

**Sind alle Funktionen gut?**

Nein, manchmal wird die Anwendung durch das Hinzufügen zu vieler Funktionen komplizierter und es entsteht Bloatware.
