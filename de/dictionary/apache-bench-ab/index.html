Was ist ab (ApacheBench)?

ApacheBench

Ein einfaches Leistungstest-Tool, mit dem gemessen werden kann, wie viele Personen ein Webserver gleichzeitig verarbeiten kann.

Definition

Wenn Sie eine Website erstellen, fragen Sie sich, wie viele Besucher diese gleichzeitig bewältigen kann. ApacheBench, oder kurz ab, wird über die Befehlszeile ausgeführt und sendet Hunderte von gefälschten Anfragen gleichzeitig an Ihren Server. So sehen Sie im Voraus, wann Ihr Server abstürzt oder langsamer wird.

Analogie: Das ist so, als würde man bei einem neu eröffneten Café einen gleichzeitigen Einlasstest machen, um zu sehen, ob die Tür hält, wenn sich hundert Personen gleichzeitig davor drängeln.

So funktioniert es

Sie öffnen das Terminal und geben die Befehle ein, die die Webadresse, die Sie testen möchten, und die Anzahl der zu sendenden Anfragen angeben. Das Tool gibt Ihnen einen numerischen Bericht darüber, wie viele Vorgänge pro Sekunde Sie ausführen können.

Wo es eingesetzt wird

Es wird verwendet, um die Serverleistung zu messen, kurz bevor eine große Verkehrswelle erwartet wird oder um nach Systemoptimierungen einen Geschwindigkeitstest durchzuführen.

Häufige Fragen

Simuliert es echte Benutzer?

Nicht genau, es überhäuft das Ziel lediglich sehr schnell nacheinander mit Anfragen.

Funktioniert es nur auf Apache-Servern?

Nein, obwohl es ApacheBench heißt, kann es jede im Internet zugängliche Webadresse testen.
