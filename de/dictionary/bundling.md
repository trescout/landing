# Was ist Bundling?

Dabei handelt es sich um die Kombination vieler kleiner Codedateien, die für das Funktionieren von Websites erforderlich sind und in einem einzigen Paket zusammengefasst werden.

## Definition
Moderne Webprojekte bestehen aus Hunderten kleiner Dateien. Browser laden diese Dateien nur langsam einzeln herunter. Der Verpackungsprozess optimiert und kombiniert diese Dateien, wodurch die Website viel schneller geladen wird.

## So funktioniert es
Webentwickler stellen Dateien zusammen und bereinigen unnötige Teile mithilfe von Tools wie Webpack oder Vite.

## Wo es eingesetzt wird
Frontend wird in Webentwicklungsprozessen eingesetzt, insbesondere in großen Anwendungen.

## Häufig verwechselt mit
Dabei geht es nicht nur um das Kopieren von Dateien, sondern auch um deren Komprimierung und Optimierung.

## Häufige Fragen
**Warum kombinieren wir Dateien?**
Um die Ladegeschwindigkeit der Website zu erhöhen, indem der Browser weniger Anfragen an den Server sendet.
