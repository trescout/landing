# Was ist Interface?

*Entwicklung · Zuletzt aktualisiert: 12. Oktober 2026*

Es ist die gemeinsame Kommunikationsgrenze, die es einem Benutzer ermöglicht, ein System zu verwalten, oder die es zwei Softwarekomponenten ermöglicht, miteinander zu kommunizieren.

## Definition

Eine Schnittstelle (Interface) bezeichnet den Treffpunkt, an dem zwei unabhängige Systeme oder ein Mensch und ein Computer interagieren. In der Softwarewelt ist es ein übergeordneter Begriff, der jede Art von Kontaktfläche definiert, von grafischen Bildschirmen (UI) bis hin zu Datenbrücken zwischen Systemen (API). In der objektorientierten Programmierung fungiert sie als verbindlicher technischer Vertrag, der angibt, welche Funktionen eine Komponente der Außenwelt zur Verfügung stellt.

***Analogie:** Das Lenkrad und die Pedale eines Autos sind die Schnittstelle, die es dem Fahrer ermöglicht, den Motor zu steuern; die Standardstecker, an denen die Motorkabel unter der Motorhaube miteinander verbunden sind, sind die Schnittstellen der Komponenten untereinander.*

## So funktioniert es

Der komplexe Mechanismus im Hintergrund des Systems wird verborgen und es werden Standard-Kontrollwege definiert, auf die die Außenwelt zugreifen kann. Für Menschen wird diese Interaktion über Schaltflächen und Formulare angeboten, während sie für Software über Code-Funktionen erfolgt, die an bestimmte Regeln gebunden sind. Selbst wenn die interne Struktur oder der Code von Grund auf erneuert wird, funktioniert die Verbindung weiter, solange die Schnittstellenregeln beibehalten werden.

## Wo es eingesetzt wird

Sie wird in Navigationsmenüs von Websites, auf Bildschirmen mobiler Anwendungen, in Befehlszeilen von Betriebssystemen und in Hintergrunddiensten verwendet, über die Server Daten miteinander austauschen.

## Häufig verwechselt mit

Sie wird oft mit der Benutzeroberfläche (UI) verwechselt, die nur das Bildschirmdesign umfasst. Dabei ist die UI nur der auf den Menschen ausgerichtete Teil der Schnittstelle; auch APIs, über die Maschinen miteinander kommunizieren, sind Schnittstellen.

## Fragen und Antworten

**Sind Schnittstelle und UI dasselbe?**

Nein: Die UI umfasst direkt die Bildschirme, die der Mensch sieht und berührt, während die allgemeine Schnittstelle (Interface) ein breiterer Begriff ist, der auch die unsichtbaren Kontaktpunkte einschließt, über die Software auf Code-Ebene miteinander kommuniziert.

**Warum ist ein Interface in der Softwareentwicklung wichtig?**

Es ermöglicht, dass von verschiedenen Teams geschriebener Code nahtlos integriert werden kann, ohne die Details des jeweils anderen kennen zu müssen, ausschließlich basierend auf festgelegten Regeln.
