# Was ist SVG?

> Scalable Vector Graphics

Es handelt sich um eine mit mathematischen Formeln erstellte digitale Bilddatei, die beliebig vergrößert werden kann, ohne an Qualität zu verlieren.

## Definition
SVG ist ein Grafikformat, das mithilfe mathematischer Definitionen wie Linien, Punkte und Kurven anstelle von Pixeln gezeichnet wird. Auf diese Weise verliert das Bild nicht an Klarheit und wird nicht verpixelt, egal wie stark Sie es vergrößern. Es wird häufig bevorzugt, insbesondere für Logos und Symbole auf Websites.

## So funktioniert es
Es wird mithilfe eines Grafikdesignprogramms oder durch Schreiben von Code erstellt. Der Inhalt ist eigentlich eine Textdatei, sodass Sie die darin enthaltenen Codes sogar mit einem Texteditor auf Ihrem Computer sehen können.

## Wo es eingesetzt wird
Es wird in Websites, mobilen Anwendungen und Druckdesigns verwendet.

## Häufig verwechselt mit
Es wird mit pixelbasierten Bildformaten wie JPEG oder PNG gemischt.

## Häufige Fragen
**Warum bleibt SVG in jeder Größe klar?**
Weil es aus mathematischen Koordinaten besteht, nicht aus Pixeln.

**Kann SVG für Fotos verwendet werden?**
Nein, SVG eignet sich besser für Illustrationen und Logos; Pixelbasierte Formate eignen sich besser für realistische Fotos.
