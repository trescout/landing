# Was ist System Prompts?

Dabei handelt es sich um eine Reihe grundlegender Anweisungen, die bestimmen, wie sich künstliche Intelligenz verhält und welchen Regeln sie folgt.

## Definition
Systemaufforderungen sind geheime Befehle, die einem KI-Modell vor Beginn eines Gesprächs gegeben werden. Diese Anweisungen bestimmen die Identität des Modells, seinen Sprechstil und seine Einschränkungen. Es stellt das grundlegende Funktionsprinzip des Modells dar, unabhängig von den Nachrichten, die vom Benutzer kommen.

## So funktioniert es
Entwickler fügen Systemaufforderungen im Einstellungsbereich des Modells oder über die API hinzu. Hier werden klare Grenzen gezogen, etwa „Du bist Lehrer“ oder „Antworten nur in Fachbegriffen“. Das Modell merkt sich diese Anweisungen bei jeder neuen Nachricht und gestaltet seine Antworten entsprechend.

## Wo es eingesetzt wird
Es wird im Hintergrund von Chatbots wie ChatGPT, in den Konfigurationsdateien von Anwendungen der künstlichen Intelligenz und in speziell entwickelten KI-Tools verwendet.

## Häufig verwechselt mit
Kann mit Benutzeraufforderungen verwechselt werden; Die Benutzeraufforderung ist Ihre aktuelle Frage, während die Systemaufforderung den allgemeinen Charakter des Modells darstellt.

## Häufige Fragen
**Kann der Benutzer die Systemaufforderung sehen?**
Normalerweise nein, diese Anweisungen werden im Hintergrund ausgeführt, aber mit einigen fortgeschrittenen Methoden kann das Modell aufgefordert werden, diese Regeln zu sagen.

**Warum ist die Systemaufforderung wichtig?**
Dadurch kann das Modell irrelevante Themen vermeiden und eine konsistente Persönlichkeit präsentieren.
