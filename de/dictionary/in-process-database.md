# Was ist In-process Database?

Es handelt sich um ein leichtes Datenspeichersystem, das direkt in der Anwendung ausgeführt wird, ohne dass ein separater Server erforderlich ist.

## Definition
Diese Arten von Datenbanken funktionieren als Teil Ihrer Anwendung. Anstatt Daten an einen anderen Ort zu senden oder eine Verbindung über das Internet herzustellen, werden die Daten direkt im Speicher des von Ihnen verwendeten Programms gespeichert. Auf diese Weise geht es sehr schnell und die Installation ist recht einfach.

## So funktioniert es
Sie fügen es Ihrer Anwendung als Bibliothek oder Datei hinzu. Sie verwenden Standardbefehle zum Lesen oder Schreiben von Daten. Wenn die Anwendung geschlossen wird, werden die Daten normalerweise in einer lokalen Datei gespeichert.

## Wo es eingesetzt wird
Es wird bevorzugt in mobilen Anwendungen, kleiner Desktop-Software oder Rapid-Prototyping-Prozessen eingesetzt.

## Häufig verwechselt mit
Es wird mit Client-Server-basierten Datenbanken gemischt; Dieses System ist lokal, während eine Remoteverbindung erforderlich ist.

## Häufige Fragen
**Sind diese Datenbanken für Big Data geeignet?**
Serverbasierte Systeme sind im Allgemeinen für kleine und mittlere Datenmengen konzipiert und eignen sich besser für große Systeme.

**Ist die Installation schwierig?**
Nein, Sie können es normalerweise sofort verwenden, indem Sie einfach eine Bibliotheksdatei hinzufügen.
