# Was ist Scripting Language?

*Entwicklung · Zuletzt aktualisiert: 23. Oktober 2026*

Eine Art von Programmiersprache, die zur Automatisierung von Softwareprozessen und zur zügigen Ausführung von Aufgaben verwendet wird und in der Regel keinen Kompilierungsschritt erfordert.

## Definition

Eine Skriptsprache (scripting language) ist eine Sprache, die von einem Interpreter Zeile für Zeile ausgeführt wird, anstatt wie herkömmliche Sprachen im Voraus in Maschinencode kompiliert zu werden. Sie wird im Allgemeinen bevorzugt, um bestehende Systeme miteinander zu verknüpfen, Routineaufgaben zu automatisieren oder Webseiten Dynamik zu verleihen. Python, JavaScript und Bash gehören zu den beliebtesten Skriptsprachen.

***Analogie:** Anstatt der finalen, von Anfang bis Ende zusammengesetzten Kopie eines Films ähnelt sie eher einem praktischen Theatertext, dem die Schauspieler Szene für Szene auf der Bühne folgen.*

## So funktioniert es

Der Entwickler schreibt den Code und gibt direkt den Befehl zum Ausführen. Eine Hilfssoftware (ein Interpreter) liest diesen Code sofort ein und leitet ihn als Befehl an das Betriebssystem oder den Browser weiter. Da es keinen Kompilierungsschritt gibt, verläuft der Entwicklungs- und Testzyklus äußerst schnell.

## Wo es eingesetzt wird

Sie wird häufig zur Automatisierung von Routineaufgaben in der Systemverwaltung, zur Erstellung interaktiver Benutzeroberflächen in Webbrowsern und in Datenanalyse-Workflows verwendet.

## Häufig verwechselt mit

Sie wird oft mit Systemprogrammiersprachen verwechselt. Während Systemsprachen wie C oder Rust direkt auf Hardware-Ebene für hohe Leistung kompiliert werden, konzentrieren sich Skriptsprachen auf Praktikabilität und Entwicklungsgeschwindigkeit.

## Fragen und Antworten

**Sind Skriptsprachen langsam?**

In Bezug auf die reine Rechenleistung sind sie im Vergleich zu direkt kompilierten Sprachen meist langsamer, aber dank moderner Optimierungen für die meisten alltäglichen Aufgaben und Webanwendungen mehr als schnell genug.

**Ist Python eine Skriptsprache?**

Ja, Python ist sowohl eine Allzweck-Programmiersprache als auch eine weit verbreitete und leistungsstarke Skriptsprache.
