# Was ist Infrastructure as Code?

> IaC

Eine Methode zur Automatisierung von Systeminstallationen wie Server und Netzwerk durch das Schreiben von Codedateien, anstatt sie manuell durchzuführen.

## Definition
Früher dauerte es Tage, Server manuell einzurichten und zu konfigurieren. Mit IaC schreiben Sie diese Einstellungen in Textdateien und führen sie wie Software aus. So ist Ihr System immer gleich eingestellt und Fehler werden minimiert.

## So funktioniert es
Es werden Codedateien erstellt, die die Systemanforderungen spezifizieren, und diese Dateien werden von IaC-Tools auf Server angewendet.

## Wo es eingesetzt wird
Es wird im Cloud Computing, bei der Verwaltung großer Systeme und bei der kontinuierlichen Veröffentlichung von Software eingesetzt.

## Häufige Fragen
**Warum schreiben wir Code, anstatt ihn manuell zu installieren?**
Denn bei manuellen Vorgängen kann eine kleine vergessene Einstellung große Probleme verursachen, während der Code immer das gleiche Ergebnis liefert.
