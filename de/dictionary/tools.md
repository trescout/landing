# Was ist Tools?

Dabei handelt es sich um Hilfsfunktionen oder Tools, die es der Software ermöglichen, mit der Außenwelt zu interagieren, um bestimmte Vorgänge auszuführen.

## Definition
In der Welt der KI ermöglichen „Tools“ dem Modell, Aufgaben zu erledigen, die es alleine nicht erledigen kann (z. B. das Durchsuchen des Internets, die Verwendung eines Taschenrechners oder das Lesen einer Datei). Wenn das Modell ein Werkzeug verwenden muss, geschieht dies als Funktionsaufruf. Dies ermöglicht es dem Agenten, sich von einem System, das lediglich Text produziert, in einen Assistenten zu verwandeln, der mit der Welt interagiert.

## So funktioniert es
Fügen Sie Anweisungen (Systemaufforderungen) hinzu, die Ihrem Agenten mitteilen, welches Tool er wann verwenden soll. Definieren Sie das Eingabe- und Ausgabeformat des Tools klar, damit das Modell keine Fehler macht.

## Wo es eingesetzt wird
Es wird in agentenbasierten Systemen, Automatisierungstools und RAG-Systemen eingesetzt.

## Häufig verwechselt mit
Es ähnelt Plugins; Bei Tools handelt es sich um Funktionen, die meist auf Code-Ebene integriert werden, während Plugins umfassendere Features bieten.

## Häufige Fragen
**Kann künstliche Intelligenz Fahrzeuge selbstständig auswählen?**
Ja, fortgeschrittene Agenten können entscheiden, welches Tool welches Problem löst.

**Wie baue ich mein eigenes Fahrzeug?**
Sie können dies tun, indem Sie eine Funktion schreiben und diese über eine API oder Bibliothek für den Agenten definieren.
