# Was ist Traces?

*Glossar · Dev · Zuletzt aktualisiert: 27. Juni 2026*

Hierbei handelt es sich um Überwachungsaufzeichnungen, die Schritt für Schritt zeigen, welche Phasen eine Transaktion im System durchläuft.

## Definition

Moderne Software besteht aus vielen Teilen. Wenn Sie eine Anfrage senden, durchläuft diese viele Dienste. Traces zeichnet auf, welche Wege diese Anfrage von Anfang bis Ende genommen hat und wo und wie viel Zeit sie verschwendet hat.

***Analogie:** Es ist, als würde man ein Frachtpaket verfolgen; Sie sehen Schritt für Schritt, zu welcher Filiale die Ladung ging, wann sie abfuhr und wo sie wartet.*

## So funktioniert es

An jedem Teil des Systems ist ein spezielles Identifikationsetikett angebracht, über das die Fahrt verfolgt werden kann.

## Wo es eingesetzt wird

Es wird in komplexen Softwarearchitekturen und zur Lösung von Leistungsproblemen eingesetzt.

## Häufig verwechselt mit

Es wird mit Baumstämmen vermischt; Protokolle beantworten die Frage „Was ist passiert?“ und Spuren beantworten die Frage „Wo und wie lange hat es gedauert“.

## Häufige Fragen

**Warum sind Spuren wichtig?**

Damit können Sie herausfinden, welcher Teil einer langsam laufenden Anwendung blockiert ist.
