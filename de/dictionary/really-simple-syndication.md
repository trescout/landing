# Was ist Really Simple Syndication?

> RSS

Es handelt sich um ein Inhaltsverteilungssystem, das es ermöglicht, Aktualisierungen oder Neuigkeiten auf Websites von einem einzigen Ort aus zu verfolgen, ohne dass die Websites einzeln aufgerufen werden müssen.

## Definition
RSS verwandelt Inhalte im Internet in einen „Feed“. Wenn Sie einen RSS-Reader verwenden, benachrichtigt Sie dieses System automatisch, wenn die Websites, denen Sie folgen, neue Inhalte veröffentlichen. Dadurch wird die Zeit, die Sie mit dem Surfen im Internet verbringen, deutlich reduziert.

## So funktioniert es
Laden Sie eine RSS-Reader-App herunter. Fügen Sie dieser Anwendung die RSS-Links der Websites hinzu, denen Sie folgen möchten. Jetzt werden alle Updates auf einem einzigen Bildschirm angezeigt.

## Wo es eingesetzt wird
Es wird beim Blog-Tracking, auf Nachrichtenseiten und auf Plattformen zur Inhaltskuration verwendet.

## Häufig verwechselt mit
Es kann mit Newsletter verwechselt werden, aber RSS unterliegt vollständig Ihrer Kontrolle und erfordert keine E-Mail.

## Häufige Fragen
**Ist RSS tot?**
Obwohl seine Beliebtheit zurückgegangen ist, ist es immer noch eine der effizientesten und saubersten Methoden zur Inhaltsverfolgung.

**Ist es bezahlt?**
Nein, es ist ein völlig offener und kostenloser Standard.
