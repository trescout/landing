# Was ist Scraping?

*Entwicklung · Zuletzt aktualisiert: 21. November 2026*

Es ist der Prozess des automatischen Kopierens und Extrahierens von Daten aus Websites.

## Definition

Es ist eine Methode, bei der der Code hinter Websites durchsucht wird, um die gesuchten Informationen automatisch zu extrahieren und zu speichern. Anstatt Daten manuell zu kopieren und einzufügen, ermöglicht es Ihnen, mit Hilfe von Software innerhalb von Sekunden Daten von Tausenden von Seiten zu sammeln. Es wird häufig für Aufgaben wie Marktanalyse, Preisverfolgung oder Inhaltsaggregation verwendet.

***Analogie:** Es ist wie ein superschneller Assistent, der schnell Fotos von Hunderten von Büchern in einer Bibliothek macht und sie digital zusammenführt, anstatt jede Seite manuell nach Sätzen zu durchsuchen, die Ihr gesuchtes Wort enthalten.*

## So funktioniert es

Speziell geschriebene Software oder Skripte senden Anfragen an die Zielwebsite und laden den HTML-Code der Seite herunter. Anschließend werden die gewünschten Texte, Bilder oder Tabellen gemäß bestimmten Regeln aus diesem Code extrahiert und auf Ihrem Computer gespeichert.

## Wo es eingesetzt wird

Es wird häufig auf Preisvergleichswebsites, Nachrichtensaggregationsplattformen, in Data-Science-Projekten und Marktforschungsberichten verwendet.

## Häufig verwechselt mit

Es bedeutet im Grunde dasselbe wie Web-Scraping, bei dem Webbrowser im Hintergrund Daten durchsuchen, konzentriert sich hier jedoch direkt auf das Extrahieren von Daten.

## Fragen und Antworten

**Ist Scraping legal?**

Im Allgemeinen ist das Sammeln öffentlich zugänglicher Daten legal, aber das unbefugte Sammeln personenbezogener Daten oder das Senden so intensiver Anfragen, dass die Server der Websites abstürzen, kann rechtliche Probleme verursachen.

**Mit welchen Programmiersprachen wird es gemacht?**

Am häufigsten werden die Programmiersprache Python und Bibliotheken wie BeautifulSoup, Selenium und Scrapy bevorzugt.
