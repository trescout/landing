# Was ist Edge Computing?

Dabei handelt es sich um die Verarbeitung von Daten auf oder in unmittelbarer Nähe des Geräts selbst, wo die Daten erzeugt werden, ohne dass sie an einen zentralen Server gesendet werden.

## Definition
Bei herkömmlichen Systemen wurden die Daten an ein entferntes Zentrum gesendet und dort verarbeitet. Edge Computing verlagert diesen Prozess an den „Edge“, also auf das Gerät oder das lokale Netzwerk des Benutzers. Dieser Ansatz reduziert die Latenz und ermöglicht, dass das System auch bei schlechter Internetverbindung funktioniert.

## So funktioniert es
Auf dem Gerät werden lokale Verarbeitungsfunktionen hinzugefügt. Anstatt in die Zentrale zu gehen, wird der Datenfluss sofort vom geräteeigenen Prozessor analysiert.

## Wo es eingesetzt wird
Es wird in Smart-Home-Geräten, autonomen Fahrzeugen und Industriesensoren eingesetzt, die eine sofortige Reaktion erfordern.

## Häufig verwechselt mit
Es wird mit Cloud Computing verwechselt; Die Cloud ist zentral, der Rand ist lokal.

## Häufige Fragen
**Warum schicken wir nicht alles in die Cloud?**
Denn es braucht Zeit, die Daten an die Zentrale zu senden, und wenn das Internet unterbrochen wird, stoppt das System.

**Ist Edge Computing sicher?**
Im Hinblick auf den Datenschutz gilt es allgemein als sicherer, da die Daten das Gerät nicht verlassen.
