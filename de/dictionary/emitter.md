# Was ist Emitter?

Dabei handelt es sich um den Mechanismus, der verarbeitete Daten oder Code in ein Ausgabeformat umwandelt, das ein anderes System oder Tool verwenden kann.

## Definition
Der Emitter ist normalerweise in der letzten Phase eines Parsers oder Compilers beteiligt. Nachdem der Parser die Daten analysiert und verstanden hat, schreibt der Emitter diese Informationen in eine Sprache oder Datei, die die Zielplattform versteht. Dies kann in Form einer Konvertierung in Maschinencode oder der Generierung einer JSON-Ausgabe erfolgen, die von einer API akzeptiert wird.

## So funktioniert es
Es nimmt die abstrakte Datenstruktur auf und exportiert sie gemäß vordefinierten Vorlagen oder Regeln. Die Ausgabe kann eine Datei, ein Netzwerkpaket oder direkt die Eingabe einer anderen Funktion sein.

## Wo es eingesetzt wird
Es kommt häufig in Compilern, Datenkonvertierungstools und ereignisgesteuerten Systemen vor.

## Häufige Fragen
**Was ist der Unterschied zwischen Emitter und Parser?**
Parser importiert und analysiert die Daten, während Emitter die verarbeiteten Daten in einem geeigneten Format nach außen präsentiert.
