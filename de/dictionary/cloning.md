# Was ist Cloning?

*Glossar · Dev · Zuletzt aktualisiert: 26. Juni 2026*

Dabei handelt es sich um den Vorgang des Duplizierens eines Softwareprojekts oder ganzer Daten durch Kopieren an einen anderen Ort.

## Definition

Klonen wird vor allem in der Softwarewelt verwendet, um die aktuelle Version eines Projekts auf den eigenen Computer herunterzuladen. Auf diese Weise erhalten Sie eine Kopie des Projekts mit seinem gesamten Verlauf und allen Dateien. Auf diese Weise können Sie Änderungen am Originalprojekt vornehmen, ohne es zu beschädigen.

***Analogie:** Es ist, als würde man ein Buch fotokopieren; Das Original bleibt an Ort und Stelle und Sie haben eine Kopie, mit der Sie arbeiten können.*

## So funktioniert es

Normalerweise kopieren Sie den Link zum Projekt mit dem Befehl „clone“ über ein Versionskontrollsystem (wie Git). Das System lädt alle Dateien auf Ihr Gerät herunter.

## Wo es eingesetzt wird

Es wird beim Importieren von Open-Source-Projekten von Plattformen wie GitHub auf den eigenen Computer verwendet.

## Häufig verwechselt mit

Es kann mit Backup verwechselt werden; Beim Klonen handelt es sich eher um ein Kopieren zum Zweck der Bearbeitung.

## Häufige Fragen

**Ändert es das ursprüngliche Projekt?**

Nein, Änderungen, die Sie an Ihrer Kopie vornehmen, haben keine Auswirkungen auf das Originalprojekt.

**Ist eine Internetverbindung erforderlich?**

Zu diesem Zeitpunkt ist nur das Kopieren erforderlich; Anschließend können Sie offline arbeiten.
