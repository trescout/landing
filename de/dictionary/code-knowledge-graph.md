# Was ist Code Knowledge Graph?

*Glossar · Dev · Zuletzt aktualisiert: 3. Oktober 2026*

Eine Struktur, die Code-Elemente in Softwareprojekten und die Beziehungen zwischen ihnen in Form eines Wissensgraphen abbildet.

## Definition

Der Code Knowledge Graph ist eine spezielle Wissenslandkarte, die Elemente wie Funktionen, Klassen, Variablen und Abhängigkeiten in einem Softwareprojekt als Knoten und Kanten organisiert. Sie ermöglicht es Systemen der künstlichen Intelligenz, nicht nur die Textstruktur des Codes, sondern auch die dahinter liegende logische Architektur ganzheitlich zu verstehen. Auf der TreScout-Plattform wird er häufig eingesetzt, um KI-Agenten komplexe Codebasen zu erklären und den korrekten Kontext bereitzustellen.

***Analogie:** Das ist vergleichbar damit, anstelle einer einfachen Adressliste einer Stadt eine detaillierte Stadtkarte zu verwenden, die zeigt, welche Straße wohin führt und welche Durchgänge zwischen Gebäuden existieren.*

## So funktioniert es

Zunächst wird die Codebasis durchsucht und alle Komponenten werden mithilfe von Werkzeugen zur statischen Analyse extrahiert. Anschließend werden die Aufruf-, Ableitungs- oder Datenübertragungsbeziehungen dieser Komponenten untereinander in einer Graphendatenbank verarbeitet. Wenn die künstliche Intelligenz eine Code-Abfrage erhält, greift sie direkt auf den relevanten Code-Knoten und die damit verbundenen Nachbarkomponenten zu, um die richtige Antwort zu generieren.

## Wo es eingesetzt wird

Er wird bei der Codeanalyse in großen Softwareprojekten, in automatisierten Code-Review-Tools und in KI-gestützten Programmierassistenten eingesetzt. Darüber hinaus wird er bevorzugt, um architektonische Abhängigkeiten bei der Modernisierung von Altsystemen zu verstehen.

## Häufig verwechselt mit

Er unterscheidet sich von klassischen textbasierten Suchsystemen; anstelle einer Textübereinstimmung legt er die semantischen und architektonischen Verbindungen des Codes offen.

## Häufige Fragen

**Warum wird anstelle einer einfachen Textsuche ein Code Knowledge Graph verwendet?**

Eine einfache Textsuche findet heraus, wo ein Wort vorkommt, kann aber nicht zeigen, welche Klassen diese Funktion beeinflusst; der Wissensgraph hingegen stellt das gesamte Beziehungsnetzwerk bereit.

**Wie beeinflusst die Erstellung dieser Struktur die Leistung der künstlichen Intelligenz?**

Sie verhindert, dass die künstliche Intelligenz unvollständige oder fehlerhafte Schlussfolgerungen über den Code zieht, und sorgt durch die Bereitstellung des korrekten Kontexts für die Generierung von konsistenterem Code.
