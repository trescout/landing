# Was ist Prompt as Code?

Dabei handelt es sich um die Verwaltung, Versionierung und Prüfung von Befehlen der künstlichen Intelligenz wie Softwarecode.

## Definition
So wie wir in der Softwarewelt unsere Codes in Versionskontrollsystemen speichern, ist es ein Ansatz, die Befehle, die wir der künstlichen Intelligenz geben, mit der gleichen Disziplin zu verwalten. Mit dieser Methode können Sie den Befehlsverlauf verfolgen, eine falsche Änderung wiederherstellen und die Leistung von Befehlen testen. Dadurch werden die Ergebnisse, die Sie durch künstliche Intelligenz erhalten, konsistenter und zuverlässiger.

## So funktioniert es
Speichern Sie Ihre Befehle als Textdateien und verfolgen Sie sie mit Tools wie Git. Speichern Sie jede neue Befehlsänderung als „Commit“ und überprüfen Sie die Auswirkungen dieser Befehle auf die künstliche Intelligenz mit automatisierten Tests.

## Wo es eingesetzt wird
Es wird in Softwareentwicklungsprozessen eingesetzt, insbesondere in der durch künstliche Intelligenz unterstützten Automatisierung und in Projekten, in denen komplexe Systeme verwaltet werden.

## Häufig verwechselt mit
Es kann mit Prompt Engineering verwechselt werden; Aber das ist der technische Management- und Prozessteil des Jobs.

## Häufige Fragen
**Warum sollte ich Befehle wie Code verwalten?**
Denn so lässt sich in komplexen Systemen leichter nachvollziehen, welcher Befehl funktioniert oder warum er ausfällt.

**Was bedeutet Testen?**
Dabei wird automatisch überprüft, ob der Befehl bei unterschiedlichen Eingaben das erwartete Ergebnis liefert.
