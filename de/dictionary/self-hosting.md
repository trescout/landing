# Was ist Self-hosting?

Dabei handelt es sich um eine Methode zum Hosten von Software auf Ihren eigenen Servern oder Computern.

## Definition
Beim Selbsthosting verwalten Sie einen Dienst oder eine Software auf Ihrer eigenen Hardware oder einem dedizierten Server, den Sie gemietet haben, anstatt sie auf dem Server einer anderen Person auszuführen. Es gewährleistet Datenschutz und vollständige Kontrolle.

## So funktioniert es
Sie besorgen sich einen Server oder einen leistungsstarken Rechner, installieren dort die nötige Software und machen diese über das Internet zugänglich. Sämtliche Aktualisierungen und Datensicherungen liegen in Ihrer Verantwortung.

## Wo es eingesetzt wird
Es wird verwendet, um Ihren eigenen Cloud-Speicher einzurichten, Ihre persönlichen KI-Modelle auszuführen oder datenschutzbewusste Websites zu verwalten.

## Häufig verwechselt mit
Es wird mit Cloud Computing verwechselt, aber während Sie den Server eines anderen in der Cloud nutzen, haben Sie hier die vollständige Kontrolle über die Hardware und Software.

## Häufige Fragen
**Warum wird Selbsthosting bevorzugt?**
Es wird bevorzugt, dass Ihre Daten nicht in die Hände von Drittunternehmen gelangen und Sie die volle Kontrolle über das System haben.

**Erfordert es technisches Wissen?**
Ja, es erfordert grundlegende Serveradministrations- und Netzwerkkenntnisse.
