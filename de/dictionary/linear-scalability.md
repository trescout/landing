# Was ist Linear Scalability?

Mit zunehmender Menge an Ressourcen, die dem System hinzugefügt werden, erhöht sich auch die Leistung.

## Definition
Es bezieht sich auf die Wachstumskapazität eines Systems. Wenn Ihr System doppelt so viel Arbeit leisten kann, wenn Sie doppelt so viele Server hinzufügen, ist das System linear skalierbar. Dies ist der größte Beweis dafür, dass das System wachsen und gleichzeitig seine Effizienz beibehalten kann.

## So funktioniert es
Die Systemarchitektur ist darauf ausgelegt, die Arbeitslast in Teile aufzuteilen und auf verschiedene Ressourcen zu verteilen.

## Wo es eingesetzt wird
Cloud-Computing-Systeme, Datenbanken und stark frequentierte Webdienste.

## Häufig verwechselt mit
Es geht nicht nur darum, schnell zu sein, sondern dass die Leistungssteigerung proportional zur Zunahme der Ressourcen ist.

## Häufige Fragen
**Warum kann nicht jedes System linear skalieren?**
Denn wenn das System wächst, steigt die Kommunikationslast zwischen den Teilen, wodurch möglicherweise einige der zusätzlichen Ressourcen verschwendet werden.
