# Was ist Foundation Model?

Dabei handelt es sich um umfassend trainierte Mainstream-KI-Modelle, die die Grundlage für viele verschiedene Anwendungen bilden.

## Definition
Foundation Models sind umfassende und vielseitig trainierte Basismodelle der künstlichen Intelligenz, auf denen andere Anwendungen aufbauen. Diese Modelle werden einmal trainiert und dann verwendet, indem sie an unterschiedliche Bedürfnisse angepasst werden.

## So funktioniert es
Sie absolvieren eine allgemeine Schulung zu großen Datenmengen. Dabei erlernen sie die Grundregeln der Sprache, der Logik oder des Visuellen.

## Wo es eingesetzt wird
Den meisten modernen Anwendungen der künstlichen Intelligenz liegt ein Grundlagenmodell zugrunde. Beispielsweise handelt es sich bei Modellen wie der GPT-Serie oder Llama um Grundmodelle.

## Häufig verwechselt mit
Sie werden fälschlicherweise nur für einen Chatbot gehalten; Dennoch sind sie die Grundlage für viele Dinge, vom Schreiben von Code bis zur Bildverarbeitung.

## Häufige Fragen
**Reicht das Foundation-Modell allein aus?**
Für allgemeine Arbeiten reicht es aus, für berufliche Zwecke werden jedoch häufig zusätzliche Verbesserungen vorgenommen.

**Kann jeder sein eigenes Fundamentmodell erstellen?**
Es wird normalerweise von großen Technologieunternehmen hergestellt, da es eine große Menge an Rechenleistung und Daten erfordert.
