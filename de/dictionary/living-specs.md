# Was ist Living Specs?

*Entwicklung · Zuletzt aktualisiert: 27. Oktober 2026*

Hierbei handelt es sich um technische Anforderungen, die während des Softwareentwicklungsprozesses automatisch mit dem Code aktualisiert werden und den aktuellen Stand des Projekts widerspiegeln.

## Definition

Die herkömmliche Dokumentation wird mit fortschreitendem Projekt veraltet, aber diese Methode macht die Dokumentation zu einem Teil des Codes. Diese Anforderungen werden jedes Mal aktualisiert, wenn eine Änderung an der Software vorgenommen wird. Auf diese Weise haben Entwickler immer eine aktuelle Roadmap.

***Analogie:** Es ist, als ob eine Karte einer Stadt eine digitale Anzeige wäre, die automatisch aktualisiert wird, wenn Straßen gebaut werden.*

## So funktioniert es

Dank Kommentaren im Code oder automatisierten Tools werden technische Dokumente mit der aktuellen Version des Codes synchronisiert.

## Wo es eingesetzt wird

Es wird zur Komplexitätsbewältigung in großen Softwareprojekten und Teamarbeit eingesetzt.

## Häufig verwechselt mit

Es unterscheidet sich von herkömmlichen technischen Dokumenten, die statisch sind und mit der Zeit veraltet sind.

## Fragen und Antworten

**Warum verwenden wir keine statischen Dokumente?**

Denn statische Dokumente veralten sehr schnell und können Entwickler in die Irre führen.

**Ist das schwierig zu installieren?**

Es erfordert Automatisierungstools, spart aber auf lange Sicht viel Zeit.
