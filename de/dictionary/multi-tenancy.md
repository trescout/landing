# Was ist Multi-tenancy?

Dabei handelt es sich um die Fähigkeit einer einzelnen Software, vielen verschiedenen Benutzern oder Unternehmen gleichzeitig unabhängige Dienste bereitzustellen.

## Definition
Denken Sie an ein Mehrfamilienhaus; Jeder nutzt das gleiche Gebäude, aber jeder hat seine eigene Wohnung. In der Softwarewelt bedeutet Mandantenfähigkeit, dass verschiedene Kunden, die sich denselben Server und dasselbe Programm teilen, in ihren eigenen Bereichen arbeiten, ohne die Daten des anderen zu sehen.

## So funktioniert es
Die Software weist jedem Benutzer ein eindeutiges „Tag“ in der Datenbank zu. Das System gleicht eine Anfrage eines Benutzers nur mit Daten mit diesem Tag ab, sodass keine Verwirrung entsteht.

## Wo es eingesetzt wird
Es wird in SaaS-Plattformen (Software as a Service), cloudbasierten Anwendungen und Unternehmensverwaltungssoftware verwendet.

## Häufig verwechselt mit
Es kann mit einem gemeinsam genutzten Server verwechselt werden. Was hier jedoch geteilt wird, ist nicht nur die Hardware, sondern der logische Aufbau der Software.

## Häufige Fragen
**Warum ein einzelnes Programm verwenden?**
Weil die Installation eines separaten Programms für jeden Benutzer sehr kostspielig und schwierig zu verwalten ist; Es ist viel einfacher, von einem einzigen Zentrum aus zu aktualisieren.
