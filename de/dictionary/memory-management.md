# Was ist Memory Management?

Dabei handelt es sich um die regelmäßige Platzierung und Bereinigung von Daten, um den temporären Speicher des Computers effizient zu nutzen.

## Definition
RAM, der temporäre Speicher von Computern, verfügt nur über begrenzten Speicherplatz. Bei der Speicherverwaltung handelt es sich um eine Systemverwaltung, die darüber entscheidet, welche Daten wie lange im Speicher verbleiben und wie sie am Ende gelöscht werden.

## So funktioniert es
Während Programme laufen, schreiben sie die benötigten Daten in den Speicher. Das System behält den Überblick über diese Daten und löscht, was nicht mehr benötigt wird, um Platz für neue Daten zu schaffen.

## Wo es eingesetzt wird
Es läuft im Hintergrund auf Betriebssystemen, Game-Engines und jeder Software, die eine hohe Leistung erfordert.

## Häufig verwechselt mit
Nicht zu verwechseln mit Speicher (Festplatte); Dieser Vorgang betrifft nur den temporären Speicher (RAM).

## Häufige Fragen
**Was passiert, wenn die Speicherverwaltung schlecht ist?**
Der Computer kann langsamer werden, einfrieren oder Programme können abstürzen und geschlossen werden.

**Soll ich das tun?**
Die meisten modernen Sprachen erledigen dies automatisch, aber wenn Sie Software auf Systemebene entwickeln, kann eine manuelle Überprüfung erforderlich sein.
