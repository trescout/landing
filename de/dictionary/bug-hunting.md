# Was ist Bug Hunting?

*Entwicklung · Zuletzt aktualisiert: 17. November 2026*

Ein systematischer Überprüfungsprozess zur Findung von Fehlern, die die Sicherheit oder Stabilität einer Software beeinträchtigen können.

## Definition

Eine sorgfältige Suchaktion, die durchgeführt wird, um Schwachstellen, Sicherheitslücken oder unerwartete Fehler in Programmen im Voraus zu entdecken. Sie wird regelmäßig durchgeführt, um das System vor böswilligen Personen zu schützen.

***Analogie:** Das ist vergleichbar damit, Türen und Fenster eines neu gebauten Gebäudes einzeln zu überprüfen, um Schwachstellen zu finden, durch die Einbrecher eindringen könnten.*

## So funktioniert es

Sicherheitsexperten oder Softwareentwickler untersuchen den Code mit speziellen Werkzeugen oder probieren Szenarien aus, die das System an seine Grenzen bringen.

## Wo es eingesetzt wird

Es kommt bei Cybersecurity-Tests, in den Endphasen des Softwareentwicklungszyklus und bei Bug-Bounty-Programmen zum Einsatz.

## Häufig verwechselt mit

Es unterscheidet sich von alltäglichen Debugging-Prozessen; das Ziel hierbei ist es meist, tiefgreifende Sicherheitslücken aufzudecken.

## Fragen und Antworten

**Was ist Bug Bounty (prämienbasiertes Suchen)?**

Das sind Systeme, bei denen Unternehmen unabhängigen Sicherheitsforschern, die Schwachstellen finden, Geldprämien zahlen.
