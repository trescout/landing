# Was ist Grounded Summary?

Es handelt sich um eine zusammenfassende Methode, die keine Erfindung beinhaltet und durch künstliche Intelligenz erstellt wird, indem nur die bereitgestellten Quelldokumente berücksichtigt werden.

## Definition
Eine fundierte Zusammenfassung liegt vor, wenn künstliche Intelligenz zusammenfasst, indem sie sich auf die Informationen in den vom Benutzer bereitgestellten Dokumenten konzentriert, anstatt auf ihr eigenes Allgemeinwissen. Mit dieser Methode kann das Modell zuverlässige Ergebnisse liefern, indem es die Vorstellungskraft oder Fehlinformationen (Halluzinationen) ausschaltet. Es wird insbesondere zur Erhöhung der Genauigkeit juristischer oder technischer Texte eingesetzt.

## So funktioniert es
Zunächst werden die zusammenzufassenden Texte in das System geladen und die künstliche Intelligenz angewiesen, über diese Texte nicht hinauszugehen. Das System erstellt eine zusammenhängende Zusammenfassung, indem es Schlüsselpunkte im Text identifiziert und sie der Quelle zuordnet.

## Wo es eingesetzt wird
Es wird bei der Zusammenfassung von Fallakten in Anwaltskanzleien, bei der Analyse langer Berichte in Konzernen und in der akademischen Forschung eingesetzt.

## Häufig verwechselt mit
Kann mit Halluzination verwechselt werden; Grounded Summary ist eigentlich eine Technik zur Vorbeugung von Halluzinationen.

## Häufige Fragen
**Warum ist eine geerdete Zusammenfassung wichtig?**
Es verhindert, dass künstliche Intelligenz falsche Informationen liefert und stellt sicher, dass sie sich an die vorgegebene Quelle hält.

**Liefert es immer genaue Ergebnisse?**
Wenn der Quelltext ungenau ist, ist auch die Zusammenfassung ungenau, aber es minimiert die Möglichkeit, dass das Modell selbst Informationen erstellt.
