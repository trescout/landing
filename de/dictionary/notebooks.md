# Was ist Notebooks?

*Glossar · Dev · Zuletzt aktualisiert: 20. Juni 2026*

Dabei handelt es sich um interaktive Arbeitsumgebungen, in denen Sie sich beim Schreiben von Code Notizen machen und die Ergebnisse sofort sehen können.

## Definition

Notebooks sind Arbeitsbereiche, in denen Code und Text miteinander verflochten sind und insbesondere in Datenwissenschafts- und Softwareentwicklungsprozessen verwendet werden. Wenn Sie einen Codeblock ausführen, sehen Sie das Ergebnis direkt unten, sodass Sie den Prozess beim Experimentieren Schritt für Schritt verfolgen können. Diese Struktur ist auch sehr nützlich, um anderen komplexe Analysen zu erklären.

***Analogie:** Es ist wie das Labornotizbuch, das ein Wissenschaftler bei der Durchführung seiner Experimente verwendet; Sie behalten sowohl die Aktion als auch das Ergebnis des Experiments auf dem gleichen Stand.*

## So funktioniert es

In dieser Umgebung, die im Browser ausgeführt wird, schreiben Sie Ihren Code in Bereiche, die in Zellen unterteilt sind. Wenn Sie auf die Schaltfläche „Ausführen“ klicken, wird der Code verarbeitet und die Ausgabe wird direkt darunter angezeigt.

## Wo es eingesetzt wird

Es wird in der Datenanalyse, beim Modelltraining für künstliche Intelligenz und bei Rapid-Code-Prototyping-Prozessen eingesetzt.

## Häufig verwechselt mit

Der Unterschied zu Standard-Code-Editoren besteht darin, dass Sie den Code Stück für Stück ausführen und das Ergebnis sofort sehen können.

## Häufige Fragen

**Können Leute, die nicht wissen, wie man programmiert, es verwenden?**

Normalerweise dient es der Codierung, für einfache Analysen können jedoch vorgefertigte Vorlagen verwendet werden.

**Welches ist das beliebteste?**

Jupyter Notebooks werden am häufigsten verwendet.
