# Was ist Web Compiler?

*Glossar · Dev · Zuletzt aktualisiert: 17. Juni 2026*

Es handelt sich um ein Tool, das Ihre Codes direkt über Ihren Internetbrowser ausführbar macht, ohne dass etwas auf Ihrem Computer installiert werden muss.

## Definition

Traditionell erfordert die Entwicklung von Software komplexe Installationen auf Ihrem Computer. Der Web-Compiler überträgt diesen Vorgang an den Browser. Durch die Verarbeitung der Codes, die Sie auf Servern in der Cloud schreiben, können Sie sofortige Ergebnisse erzielen.

***Analogie:** Anstatt alle Zutaten und Herde zu Ihnen nach Hause zu bringen, um in der Küche zu kochen, ist es so, als würden Sie sich über das Internet mit einer professionellen Küche verbinden und dort Ihr Essen kochen und servieren.*

## So funktioniert es

Sie öffnen Ihren Browser, gehen zur entsprechenden Website, geben Ihren Code ein und klicken auf „Ausführen“. Das System kompiliert Ihren Code im Hintergrund und zeigt Ihnen das Ergebnis auf Ihrem Bildschirm an.

## Wo es eingesetzt wird

Es wird bevorzugt auf Code-Lernplattformen, beim Rapid Prototyping oder wenn die Hardware Ihres Computers nicht ausreicht.

## Häufig verwechselt mit

Kann mit nativen Compilern gemischt werden; Der Web-Compiler nutzt das Internet, während die lokalen Compiler die Leistung Ihres Computers nutzen.

## Häufige Fragen

**Muss ich eine Codedatei auf meinem Computer behalten?**

Normalerweise nein, Ihre Projekte werden in Ihrem Cloud-Konto gespeichert.

**Was passiert, wenn mein Internet ausfällt?**

Die Verarbeitung Ihres Codes stoppt, da die Verarbeitung auf dem Remote-Server und nicht im Browser erfolgt.
