# Was ist Containers?

*Glossar · Dev · Zuletzt aktualisiert: 12. Juni 2026*

Dabei handelt es sich um leichtgewichtige Pakete, die alles enthalten, was für die Ausführung einer Software erforderlich ist, und die problemlos in verschiedene Umgebungen verschoben werden können.

## Definition

Container fassen alle Bibliotheken und Einstellungen, die eine Anwendung benötigt, in einer einzigen Box zusammen. Auf diese Weise funktioniert die Anwendung auf dem Server oder einem anderen Gerät genauso wie auf Ihrem Computer. Es beschleunigt den Entwicklungsprozess, indem es die Installationskomplexität eliminiert.

***Analogie:** Es ist so, als würde man eine Mahlzeit nicht mit dem Rezept, sondern als Fertiggericht-Box mit allen Zutaten und Kochutensilien bei sich tragen; Wo auch immer Sie es einnehmen, das Ergebnis wird das gleiche sein.*

## So funktioniert es

Entwickler machen die Anwendung zu einem Container-Image. Dieses Image erstellt überall dort, wo es ausgeführt wird, dieselbe Umgebung.

## Wo es eingesetzt wird

Es wird im Cloud Computing, bei der Bereitstellung von Webanwendungen und in Microservice-Architekturen verwendet.

## Häufig verwechselt mit

Es ist viel leichter als virtuelle Maschinen und startet schneller.

## Häufige Fragen

**Warum sind Container so beliebt?**

Weil sie das Problem „Es funktionierte auf meinem Computer“ vollständig beseitigen.

**Wie verwalte ich Container?**

Sie werden normalerweise mit Tools wie Docker erstellt und verwaltet.
