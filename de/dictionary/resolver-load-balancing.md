# Was ist Resolver Load Balancing?

Dabei handelt es sich um den Prozess, eine Systemüberlastung zu verhindern, indem Internet-Adressabfragen auf mehrere Server verteilt werden.

## Definition
Wenn der Internetverkehr sehr hoch ist, kann ein einzelner Server nicht alle Anfragen bewältigen. Diese Methode verhindert, dass das System abstürzt, indem Anfragen wie ein Verkehrspolizist an verschiedene Server umgeleitet werden. Dadurch ist jederzeit eine schnelle und unterbrechungsfreie Verbindung gewährleistet.

## So funktioniert es
Installieren Sie eine Load-Balancer-Software und verteilen Sie eingehende DNS-Anfragen gleichmäßig auf die von Ihnen definierten Server.

## Wo es eingesetzt wird
Es wird auf großen Websites und Netzwerkinfrastrukturen mit hohem Datenverkehr eingesetzt.

## Häufig verwechselt mit
Es kann sein, dass man es nur mit Server-Clustering verwechselt, aber diese Methode konzentriert sich speziell auf die Verwaltung des Abfragedatenverkehrs.

## Häufige Fragen
**Wird die Website dank dieses Systems schneller?**
Ja, die Antwortzeiten sind kürzer, da die Belastung des Servers reduziert wird.

**Was passiert, wenn ein einzelner Server ausfällt?**
Der Load Balancer hält die Site am Laufen, indem er sie auf andere Server umleitet.
