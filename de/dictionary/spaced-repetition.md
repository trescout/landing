# Was ist Spaced Repetition?

Dies ist eine Lernmethode, bei der Informationen in bestimmten Zeitabständen wiederholt werden, um das Vergessen zu verhindern.

## Definition
Diese Technik basiert darauf, das Gehirn zu den optimalen Zeitpunkten an Informationen zu erinnern, damit diese im Langzeitgedächtnis gespeichert werden. Wenn die Information kurz davor steht, vergessen zu werden, wird sie erneut präsentiert, um sie im Gedächtnis aufzufrischen. Sie ist besonders effektiv beim Sprachenlernen oder beim Auswendiglernen komplexer Informationen.

## So funktioniert es
Sie schreiben die Information, die Sie lernen möchten, auf eine Karte. Beim ersten Mal wiederholen Sie sie sofort, danach vergrößern Sie die Abstände (z. B. nach einem Tag, nach drei Tagen, nach einer Woche). Wenn Sie Schwierigkeiten beim Erinnern haben, personalisieren Sie den Prozess, indem Sie die Wiederholungsintervalle verkürzen.

## Wo es eingesetzt wird
Es wird häufig in Sprachlern-Apps, Prüfungsvorbereitungssystemen und Tools zur persönlichen Wissensverwaltung eingesetzt.

## Häufig verwechselt mit
Es könnte mit reinem Auswendiglernen verwechselt werden; diese Methode ist jedoch eher eine strategische Verwaltung des Gedächtnisses als bloßes Auswendiglernen.

## Häufige Fragen
**Warum sollte ich ständig wiederholen?**
Ihr Gehirn löscht Informationen, die es als unnötig erachtet; diese Methode beweist Ihrem Gehirn, dass die Information wichtig ist.
