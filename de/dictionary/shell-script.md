# Was ist Shell Script?

*Glossar · Dev · Zuletzt aktualisiert: 17. August 2026*

Hierbei handelt es sich um kleine Skripte, die das Betriebssystem des Computers anweisen, die erforderliche Arbeit in der richtigen Reihenfolge auszuführen.

## Definition

Ein Shell-Skript ist eine Liste von Befehlen, die Sie in einer Datei speichern und gemeinsam ausführen können, anstatt sie einzeln auf Ihrem Computer einzugeben. Diese Dateien kommunizieren mit der Befehlszeilenschnittstelle des Betriebssystems und automatisieren Aufgaben wie das Kopieren von Dateien, das Starten von Programmen oder das Ändern von Systemeinstellungen. Sie sind wie eine digitale Anleitungsliste, mit der Sie komplexe Aufgaben mit einem einzigen Klick erledigen können.

***Analogie:** Überlegen Sie sich ein Rezept; Anstatt die Zutaten einzeln zuzubereiten, geben Sie der Küchenmaschine ein Blatt Papier mit allen Schritten darauf und sie folgt dem Rezept von Anfang bis Ende selbstständig.*

## So funktioniert es

Es ist normalerweise als Textdatei geschrieben und enthält Befehle, die Sie im Terminal ausführen können. Nachdem der Datei die Ausführungsberechtigung erteilt wurde, werden alle darin enthaltenen Vorgänge nacheinander mit einem einzigen Befehl über das Terminal ausgeführt.

## Wo es eingesetzt wird

Es wird häufig zur Automatisierung von Aufgaben in der Serververwaltung, bei Sicherungsvorgängen und bei Softwareentwicklungsprozessen verwendet.

## Häufig verwechselt mit

Es ist dasselbe wie Bash-Skript, nur ein allgemeinerer Begriff.

## Häufige Fragen

**Muss ich Code kennen?**

Sie müssen nur grundlegende Befehle kennen, Sie müssen keine komplexen Programmiersprachen beherrschen.

**Funktioniert es auf jedem Computer?**

Wird normalerweise in Terminalumgebungen auf Systemen wie Linux oder macOS ausgeführt. Für Windows sind möglicherweise spezielle Einstellungen erforderlich.
