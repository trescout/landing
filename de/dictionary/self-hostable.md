# Was ist Self-hostable?

Dies bedeutet, dass eine Software auf Ihrer eigenen Infrastruktur ausgeführt werden kann, anstatt sie auszulagern.

## Definition
Selbsthosting bedeutet, dass eine Anwendung auf Ihrem eigenen Server oder Computer gehostet werden kann, ohne auf Cloud-Dienste angewiesen zu sein. Mit diesem Ansatz haben Sie die vollständige Kontrolle über Ihre Daten. Anstatt Daten an die Server von Drittanbietern zu senden, führen Sie die Software auf Hardware zu Hause oder im Büro aus.

## So funktioniert es
Normalerweise laden Sie den Quellcode oder die Installationsdateien der Software herunter und führen sie aus, indem Sie sie mit Tools wie Docker auf Ihrem eigenen Server installieren. Sie sind für alle Updates und Datensicherungen nach der Installation verantwortlich.

## Wo es eingesetzt wird
Es wird auf persönlichen Cloud-Speichersystemen, privaten Medienservern oder zum Ausführen datenschutzorientierter KI-Tools verwendet.

## Häufig verwechselt mit
Es kann mit SaaS-Modellen (Software as a Service) verwechselt werden. Bei SaaS verwaltet jemand anderes den Dienst, während bei einer selbst gehosteten Struktur die gesamte Verwaltung bei Ihnen liegt.

## Häufige Fragen
**Warum sollte ich mich für eine selbsthostbare Software entscheiden?**
Es wird aus Gründen des Datenschutzes, der Vermeidung von Abonnementgebühren und der Freiheit, die Anwendung auch ohne Internetverbindung nutzen zu können, bevorzugt.

**Erfordert es technisches Wissen?**
Ja, für Installations- und Wartungsprozesse sind möglicherweise grundlegende Serveradministrations- oder Befehlszeilenkenntnisse erforderlich.
