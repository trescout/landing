# Was ist Backend?

Dies ist der Teil einer Anwendung, der für den Benutzer nicht sichtbar ist, in dem Daten verarbeitet werden und der auf dem Server läuft.

## Definition
Die Schaltflächen oder Menüs, die Sie sehen, wenn Sie eine Website aufrufen, sind das Frontend. Im Hintergrund ist das Backend der Teil, der die ganze schwere Arbeit erledigt, wie das Überprüfen Ihrer Passwörter, das Abrufen von Informationen aus der Datenbank oder die Durchführung von Zahlungsvorgängen. Der Benutzer sieht nur das Ergebnis, während das Backend die Küche ist, die dieses Ergebnis vorbereitet.

## So funktioniert es
Der auf dem Server laufende Code empfängt eingehende Anfragen, kommuniziert mit der Datenbank und sendet das Ergebnis nach Durchführung der erforderlichen logischen Operationen an den Benutzer zurück.

## Wo es eingesetzt wird
Es ist in allen modernen Webanwendungen, im Hintergrund von mobilen Anwendungen und in API-Systemen vorhanden.

## Häufig verwechselt mit
Es kann mit dem Frontend verwechselt werden; das Frontend interagiert mit Ihnen, während das Backend die Arbeit erledigt.

## Häufige Fragen
**Warum führen wir Code im Backend aus?**
Weil es notwendig ist, die Sicherheit der Daten zu gewährleisten und komplexe Berechnungen durchzuführen, ohne das Gerät des Benutzers zu belasten.
