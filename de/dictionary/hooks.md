# Was ist Hooks?

Dies sind Verbindungspunkte, die es Ihnen ermöglichen, zu bestimmten Zeitpunkten im Ablauf der Software einzugreifen und spezielle Vorgänge auszuführen.

## Definition
Während eine Software läuft, sind dies spezielle Tore, die Entwickler hinterlassen, damit sie ihren eigenen Code in den Hauptablauf injizieren können. Auf diese Weise können Sie Ihre eigenen Befehle ausführen lassen, wenn ein bestimmtes Ereignis eintritt, ohne das Hauptprogramm zu verändern. Sie können beispielsweise einen Hook verwenden, um automatisch eine Sicherungskopie zu erstellen, wenn eine Datei gespeichert wird.

## So funktioniert es
Softwareentwickler setzen Markierungen in den Hauptcode, nach dem Motto: 'Wenn du hier ankommst, führe diese Funktion aus'. Sie verbinden Ihren eigenen Code mit diesen Markierungen, um den Prozess zu personalisieren. Dank dieser Methode funktionieren die von Ihnen hinzugefügten Funktionen auch dann weiter, wenn die Hauptsoftware aktualisiert wird.

## Wo es eingesetzt wird
Sie begegnen ihnen häufig im Hintergrund von Websites, in Anwendungsentwicklungs-Frameworks und in Plugin-Systemen.

## Häufig verwechselt mit
Sie können mit Plugins verwechselt werden; während Hooks eher Verbindungspunkte auf Code-Ebene sind, bieten Plugins umfassendere Funktionen.

## Häufige Fragen
**Warum ändern wir nicht direkt den Hauptcode?**
Das Ändern des Hauptcodes führt dazu, dass alle Ihre Änderungen gelöscht werden, wenn die Software aktualisiert wird; Hooks hingegen sind von Updates nicht betroffen.
