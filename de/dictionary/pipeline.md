# Was ist Pipeline?

Dabei handelt es sich um eine Reihe automatischer Schritte, die Daten von einem Rohzustand bis zu einem verarbeiteten Ergebnis durchlaufen.

## Definition
Eine Pipeline ist eine Produktionslinie, bei der Daten an einem Ende eingehen und am anderen Ende als aussagekräftiges Ergebnis wieder herauskommen. Bei jedem Schritt werden die Daten bereinigt, transformiert oder analysiert. Diese Struktur macht manuelle Arbeit überflüssig und stellt sicher, dass der Prozess wiederholbar und fehlerfrei ist.

## So funktioniert es
Die Datenquelle wird ermittelt, anschließend werden die Verarbeitungsschritte (z. B. Bereinigung, Transformation) definiert. Das System führt diese Schritte automatisch der Reihe nach aus.

## Wo es eingesetzt wird
Es wird in Datenverarbeitungsprozessen, Softwareverteilung und Modelltraining für künstliche Intelligenz eingesetzt.

## Häufig verwechselt mit
Es sollte nicht nur mit einer Datenbank verwechselt werden; Eine Pipeline ist ein Prozess, der Daten verarbeitet, kein Ort, an dem sie gespeichert werden.

## Häufige Fragen
**Was passiert, wenn die Pipeline kaputt geht?**
Der Prozess kann ins Stocken geraten oder falsche Daten liefern, daher ist die Überwachung (Beobachtbarkeit) sehr wichtig.

**Sollte es immer automatisch sein?**
Ja, die Automatisierung ist der Kern des Pipeline-Konzepts.
