# Was ist Static Site Generator?

*Glossar · Dev · Zuletzt aktualisiert: 3. August 2026*

Ein Tool, das vorgefertigte Inhalte und Vorlagen in feste Webseiten umwandelt, die dem Benutzer präsentiert werden können.

## Definition

Herkömmliche Websites rufen für jeden Besucher Informationen aus der Datenbank ab. Der statische Site-Generator hingegen führt diesen Vorgang einmal durch, erstellt die Seiten im Voraus und sendet nur die fertigen Dateien an den Besucher. Dadurch wird sichergestellt, dass Ihre Website sehr schnell lädt und sicherer ist.

***Analogie:** Es ist, als würde man fertige Sandwiches zur Schau stellen und sie dem Kunden sofort servieren, anstatt sie in einem Restaurant auf Bestellung zuzubereiten.*

## So funktioniert es

Sie schreiben Ihre Inhalte in Markdown oder ähnlichen Dateien. Das Tool kombiniert diese Inhalte mit Designvorlagen und erstellt HTML-Dateien. Sie laden diese Dateien auch ins Internet hoch.

## Wo es eingesetzt wird

Es wird häufig in Blogs, Dokumentationsseiten und persönlichen Portfolios bevorzugt.

## Häufig verwechselt mit

Es ist mit CMS (Content Management System) gemischt; CMS verwendet eine Datenbank, während dieses Tool nur Dateien erstellt.

## Häufige Fragen

**Wie aktualisiere ich meine Website?**

Indem Sie den Inhalt ändern und das Tool erneut ausführen, generieren Sie neue Dateien und laden sie hoch.

**Keine Datenbank erforderlich?**

Nein, es ist keine Datenbank erforderlich, was es sehr schnell macht.
