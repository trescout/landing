# Was ist Common Libraries?

Vorbereitete Codepakete, damit Softwareentwickler häufig verwendete Vorgänge problemlos ausführen können.

## Definition
Dabei handelt es sich um vorgefertigte Lösungen, mit denen man bei der Softwareentwicklung nicht jedes Mal das Rad neu erfinden muss. Mit diesen Bibliotheken können Sie viele komplexe Aufgaben, von mathematischen Operationen bis hin zur Dateiverwaltung, mit einem einzigen Befehl erledigen. Das Hinzufügen zu Ihrem Projekt spart Zeit und verringert das Fehlerrisiko.

## So funktioniert es
Sie binden die benötigte Bibliothek in Ihr Projekt ein und rufen die vorgefertigten Funktionen in Ihrem eigenen Code auf.

## Wo es eingesetzt wird
Es wird in fast jedem Softwareprojekt verwendet, beispielsweise bei der Datenverarbeitung, bei Netzwerkverbindungen oder bei der Erstellung visueller Schnittstellen.

## Häufig verwechselt mit
Es kann mit Framework verwechselt werden; Das Framework zeichnet das Grundgerüst des Projekts und die Bibliothek bietet Ihnen nur das Werkzeug, das Sie benötigen.

## Häufige Fragen
**Ist jede Bibliothek sicher?**
Nein, wie jeder externe Code sollten Bibliotheken auf Aktualität und Zuverlässigkeit überprüft werden.

**Kann ich meine eigene Bibliothek erstellen?**
Ja, Sie können die Codes, die Sie häufig verwenden, verpacken und in Ihren anderen Projekten wiederverwenden.
