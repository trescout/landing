# Was ist Continuous Integration?

> CI

Dieser Prozess stellt sicher, dass Fehler frühzeitig erkannt werden, indem die von Softwareentwicklern geschriebenen Codes automatisch kombiniert und getestet werden.

## Definition
Continuous Integration (CI) sorgt dafür, dass Codes während des Softwareentwicklungsprozesses häufig an ein zentrales System gesendet und dort automatischen Tests unterzogen werden. Auf diese Weise fällt es sofort auf, wenn der von einem Softwareentwickler geschriebene Code mit dem Code anderer in Konflikt steht. Fehler werden behoben, bevor sie größer werden, während sie sich noch in der Entwicklung befinden.

## So funktioniert es
Sobald der Entwickler seinen Code in das System hochlädt, kompilieren im Hintergrund laufende Roboter den Code automatisch und führen vorgegebene Tests durch.

## Wo es eingesetzt wird
Dies ist eine gängige Praxis in großen Softwareteams und modernen Softwareentwicklungszyklen (DevOps).

## Häufige Fragen
**Warum führen wir keine manuellen Tests durch?**
Manuelle Tests sind langsam und anfällig für menschliches Versagen; CI hingegen arbeitet bei jeder Änderung mit der gleichen Akribie.
