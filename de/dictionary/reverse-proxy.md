# Was ist Reverse Proxy?

*Glossar · Dev · Zuletzt aktualisiert: 7. Juni 2026*

Dabei handelt es sich um einen Traffic-Router, der Anfragen aus dem Internet entgegennimmt, diese an entsprechende Server verteilt und für Sicherheit sorgt.

## Definition

Wenn Sie eine Website betreten, gelangen Sie nicht direkt zum Hauptserver. Zuerst stoßen Sie auf einen Reverse-Proxy, der ein Gatekeeper ist. Es empfängt Ihre Anfrage, prüft deren Sicherheit und leitet Sie an den richtigen Server weiter.

***Analogie:** Sie ist wie die Empfangsdame einer großen Firma; Begrüßt ankommende Besucher, versteht, wer sie sind und leitet sie an die zuständige Abteilung weiter.*

## So funktioniert es

Eingehender Datenverkehr gelangt zu diesem Zwischenserver. Das Tool analysiert den Datenverkehr, gleicht die Last aus und leitet ihn an die Backserver weiter, auf denen sich die eigentlichen Daten befinden.

## Wo es eingesetzt wird

Es wird in Webservern, Firewalls und Websites mit hohem Datenverkehr verwendet.

## Häufig verwechselt mit

Es kann mit einem normalen Proxy verwechselt werden; Ein normaler Proxy verbirgt den Benutzer, ein Reverse-Proxy verbirgt und schützt den Server.

## Häufige Fragen

**Warum verbinden wir uns nicht direkt mit dem Server?**

Eine Zwischenschicht ist hinsichtlich Sicherheit, Geschwindigkeit und Lastverteilung immer effizienter.

**Ist das Software?**

Es handelt sich sowohl um eine Software- als auch um eine Serverschicht, auf der diese Software ausgeführt wird.
