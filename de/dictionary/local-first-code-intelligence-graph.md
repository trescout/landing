# Was ist Local-first Code Intelligence Graph?

Es handelt sich um ein System, das die Beziehungen von Codeteilen in Softwareprojekten auf Ihrem lokalen Computer abbildet, ohne dass das Internet erforderlich ist.

## Definition
Dieses System verbindet alle Dateien und Funktionen in Ihrer Codebasis wie ein Netzwerk. Ihre Daten bleiben privat, da sie direkt auf Ihrem Gerät ausgeführt werden und keine Verbindung zum Internet herstellen. Es hilft Ihnen, die Struktur Ihres Codes zu verstehen und schnell durch komplexe Projekte zu navigieren.

## So funktioniert es
Es wird in Ihre Softwareentwicklungsumgebung integriert und erstellt durch das Scannen Ihres Codes ein Beziehungsnetzwerk. Wenn Sie eine Funktion ändern, wird Ihnen sofort angezeigt, welche Dateien von dieser Änderung betroffen sind.

## Wo es eingesetzt wird
Es wird in komplexen Softwareprojekten, bei der Entwicklung von Unternehmenssoftware, bei denen der Datenschutz im Vordergrund steht, und in Situationen eingesetzt, die Offline-Arbeit erfordern.

## Häufig verwechselt mit
Es kann mit allgemeinen Code-Analysetools oder internetbasierten Code-Indizierungsdiensten verwechselt werden.

## Häufige Fragen
**Warum heißt es „Local-First“?**
Denn der gesamte Analyseprozess findet direkt auf Ihrem eigenen Computer statt, nicht auf Cloud-Servern.

**Funktioniert es, wenn ich kein Internet habe?**
Ja, das System benötigt keine Internetverbindung, da es komplett lokal arbeitet.
