# Was ist Patch?

*Glossar · Dev · Zuletzt aktualisiert: 9. Juli 2026*

Dabei handelt es sich um einen kleinen Update-Patch, der zur Behebung von Fehlern oder zur Beseitigung von Mängeln in der Software eingesetzt wird.

## Definition

Anstatt das gesamte Programm neu zu installieren, wird einfach der kleine Teil ersetzt oder verbessert, der problematisch ist. Es dient dazu, Sicherheitslücken zu schließen oder die Leistung zu verbessern.

***Analogie:** Es ist, als würde man mit einem Flicken einen kleinen Riss in Ihrem Kleidungsstück vernähen, anstatt das gesamte Kleidungsstück wegzuwerfen.*

## So funktioniert es

Softwareentwickler finden den Fehler, beheben ihn und veröffentlichen eine kleine Datei mit diesem Fix. Sie können Ihr Programm aktualisieren, indem Sie diese Datei ausführen.

## Wo es eingesetzt wird

Es wird in Betriebssystemen, Spielen und allen Anwendungsupdates verwendet.

## Häufig verwechselt mit

Es kann mit einem Vollversions-Update verwechselt werden; Der Patch ist nur eine kleine Korrektur, während das Versionsupdate große Neuerungen mit sich bringt.

## Häufige Fragen

**Warum ist Patch wichtig?**

Es schützt das System und repariert fehlerhafte Teile.

**Sollte ich es immer installieren?**

Ja, insbesondere sicherheitsorientierte Patches schützen Ihr System vor Angriffen.
