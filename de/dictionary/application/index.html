Was ist Application?

Dabei handelt es sich um ein Softwareprogramm, das darauf ausgelegt ist, eine bestimmte Aufgabe auf Geräten wie Computern, Telefonen oder Tablets auszuführen.

Definition

Anwendungen sind digitale Werkzeuge, die den Nutzern die tägliche Arbeit erleichtern. Vom Eingeben eines Textes über das Bearbeiten eines Fotos bis hin zum Surfen im Internet geschieht alles über eine App. Diese Software läuft auf dem Betriebssystem und bietet dem Benutzer eine visuelle Schnittstelle.

Analogie: Wenn Sie sich das Betriebssystem als Fundament und Wände eines Hauses vorstellen, sind Anwendungen die Möbel und Gegenstände im Haus; Jeder dient einem anderen Zweck.

So funktioniert es

Der Benutzer führt die aus App-Stores oder dem Internet heruntergeladene Datei aus. Die Anwendung verarbeitet die Befehle des Benutzers mithilfe der Ressourcen des Geräts und zeigt die Ergebnisse auf dem Bildschirm an.

Wo es eingesetzt wird

Es erscheint ständig auf Smartphones, Desktop-Computern und Webbrowsern.

Häufig verwechselt mit

Es kann mit dem Betriebssystem verwechselt werden; Während das Betriebssystem das gesamte Gerät verwaltet, erledigt die Anwendung nur eine bestimmte Aufgabe.

Häufige Fragen

Sind Anwendungen und Software dasselbe?

Eine Anwendung ist eine Teilmenge der Software. Jede Anwendung ist Software, aber nicht jede Software ist eine Anwendung (Treiber sind beispielsweise Software, aber keine Anwendungen).

Wie aktualisiere ich Apps?

Entwickler aktualisieren App-Dateien, um Fehler zu beheben oder neue Funktionen hinzuzufügen, die automatisch oder manuell auf Ihr Gerät heruntergeladen werden.
