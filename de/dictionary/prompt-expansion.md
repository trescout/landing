# Was ist Prompt Expansion?

*Künstliche Intelligenz · Zuletzt aktualisiert: 12. November 2026*

Dies ist eine Methode, bei der das System die vom Benutzer geschriebenen kurzen Befehle anreichert und detaillierter gestaltet, um eine qualitativ hochwertigere Antwort vom KI-Modell zu erhalten.

## Definition

Prompt-Erweiterung ist eine Technik, die einfache oder unvollständige Benutzereingaben automatisch anreichert. KI-Systeme fügen dem ursprünglichen Befehl mithilfe von im Hintergrund laufenden Regeln oder Hilfsmodellen Kontext, Rollen und zusätzliche Details hinzu. Dadurch versteht das Hauptmodell viel klarer, was der Benutzer meint, und generiert präzisere Ergebnisse.

***Analogie:** Es ist vergleichbar damit, wenn Sie in einem Restaurant nur 'Suppe' bestellen und der Kellner diese Information detailliert an die Küche weitergibt: 'Bitte eine Portion der frischen Gemüsesuppe des Tages, serviert mit warmem Brot'.*

## So funktioniert es

Wenn ein Benutzer eine kurze Anfrage in das System eingibt, erfasst das System diesen Text zunächst. Eine Hilfsvorlage oder ein separates KI-Modell fügt der Eingabe geeignete Qualifizierer und Anweisungen hinzu. Dieser neue, erweiterte Text wird an das Hauptmodell weitergeleitet, um die endgültige Antwort zu generieren.

## Wo es eingesetzt wird

Es wird häufig verwendet, um die Benutzererfahrung in Suchmaschinen, Bildgenerierungstools und KI-gestützten Chat-Assistenten zu verbessern.

## Häufig verwechselt mit

Es kann mit Prompt Engineering verwechselt werden. Während Prompt Engineering im Allgemeinen die Kunst des Schreibens effektiver Befehle ist, ist Prompt-Erweiterung ein spezifischer Schritt dieses Prozesses, der automatisch vom System ausgeführt wird.

## Fragen und Antworten

**Verändert die Prompt-Erweiterung die Absicht des Benutzers?**

Nein, sie ergänzt fehlende Details, ohne die grundlegende Absicht des Benutzers zu verfälschen, und erhöht die Qualität der Ausgabe.

**Verlängert dieser Prozess die Antwortzeit?**

Da ein zusätzlicher Verarbeitungsschritt erforderlich ist, kann es zu einer Verzögerung im Millisekundenbereich kommen, aber die erzielte Antwortqualität macht diesen Unterschied vernachlässigbar.
