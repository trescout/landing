# Was ist Cookies?

*Glossar · Dev · Zuletzt aktualisiert: 12. Oktober 2026*

> HTTP Cookies

Dies sind kleine Datendateien, die von Websites im Browser gespeichert werden, um Benutzereinstellungen und den Sitzungsstatus zu speichern.

## Definition

Cookies sind kleine Textfragmente, die von einem Webserver an Ihren Browser gesendet und bei Ihren späteren Besuchen an den Server zurückgesendet werden. Sie verhindern, dass Benutzer bei jedem Seitenwechsel ihr Passwort erneut eingeben müssen, schützen den Inhalt des Warenkorbs und speichern Website-Einstellungen. Während Erstanbieter-Cookies für die eigenen Funktionen der Website verwendet werden, werden Drittanbieter-Cookies verwendet, um das Surfverhalten über verschiedene Websites hinweg zu verfolgen und zielgerichtete Werbung bereitzustellen.

***Analogie:** Das ist wie die Nummer, die Sie erhalten, wenn Sie Ihre Jacke an der Garderobe abgeben; wenn Sie zurückkommen, zeigen Sie die Nummer vor, und selbst wenn der Mitarbeiter Sie nicht kennt, weiß er, welche Jacke Ihnen gehört.*

## So funktioniert es

Der Webserver fügt dem an den Browser gesendeten HTTP-Antwortheader den Befehl Set-Cookie hinzu. Der Browser liest diesen Befehl und speichert das angegebene Schlüssel-Wert-Paar auf der lokalen Festplatte. Wenn der Benutzer eine neue Anfrage an dieselbe Domain sendet, sendet der Browser diese Daten automatisch im Cookie-Header an den Server zurück.

## Wo es eingesetzt wird

Sie werden in der BenutzerSitzungsverwaltung (Session), bei der Warenkorbverfolgung auf E-Commerce-Websites und in der digitalen Marketinganalyse verwendet.

## Häufig verwechselt mit

Es wird mit dem Geräte-Fingerabdruck (Fingerprint) verwechselt; während Cookies ganz einfach über die Browsereinstellungen gelöscht werden können, lässt sich ein Fingerabdruck aufgrund seiner Abhängigkeit von Hardwaremerkmalen nicht so einfach löschen.

## Häufige Fragen

**Schadet das Löschen von Cookies meinem Computer?**

Nein; es werden lediglich geöffnete Internetsitzungen geschlossen und Ihre Themen- oder Spracheinstellungen auf Websites zurückgesetzt.

**Warum werden Drittanbieter-Cookies blockiert?**

Sie werden von modernen Browsern standardmäßig blockiert, da sie Ihre Privatsphäre verletzen, indem sie Ihre Aktivitäten auf verschiedenen Websites verfolgen.
