# Was ist Declarative?

*Entwicklung · Zuletzt aktualisiert: 19. November 2026*

Ein Programmieransatz, bei dem der Programmierer angibt, was getan werden soll, während sich die Software darum kümmert, wie es gemacht wird.

## Definition

Deklarative Programmierung ist eine Methode, bei der Sie das gewünschte Endergebnis beschreiben, anstatt dem Computer Schritt-für-Schritt-Anweisungen zu geben. Sie sagen einfach, was Sie wollen, und das zugrundeliegende System wählt und erreicht den Weg, der am besten zu diesem Ergebnis führt.

***Analogie:** Es ist so, als würden Sie in ein Taxi steigen und dem Fahrer einfach die Adresse nennen, anstatt ihm Schritt für Schritt zu sagen, in welche Straße er abbiegen soll. Wie der Weg zurückgelegt wird, bleibt dem Fachwissen des Fahrers überlassen.*

## So funktioniert es

Anstatt sich beim Schreiben von Code mit Schleifen oder temporären Variablen herumzuschlagen, nutzen Sie die Regeln, die von vorgefertigten Bibliotheken bereitgestellt werden. Bei der Entwicklung von Benutzeroberflächen definieren Sie beispielsweise, wie der Bildschirm basierend auf dem Datenstatus aussehen soll, und der Browser verwaltet die Änderungen im Hintergrund selbst.

## Wo es eingesetzt wird

Es wird häufig in modernen Web-Frameworks, Datenbankabfragesprachen und Tools zur Verwaltung von Cloud-Infrastrukturen eingesetzt.

## Häufig verwechselt mit

Es wird oft mit dem imperativen Programmieransatz verwechselt, bei dem jeder Schritt einzeln geschrieben werden muss.

## Fragen und Antworten

**Warum wird deklarativer Code bevorzugt?**

Er ermöglicht es Ihnen, weniger Code zu schreiben, und erhöht die Lesbarkeit des Codes, wodurch das Risiko von Fehlern verringert wird.

**Wird es nur in Projekten der künstlichen Intelligenz verwendet?**

Nein, es ist eine weit verbreitete Philosophie in der allgemeinen Softwareentwicklungswelt.
