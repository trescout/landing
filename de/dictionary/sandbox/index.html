Was ist Sandbox?

Es handelt sich um einen isolierten Arbeitsbereich, in dem neue Software oder Codes sicher getestet werden können, ohne das Hauptsystem zu beschädigen.

Definition

Eine Sandbox ist ein Spielplatz auf Ihrem Computer oder Server, der wie in einer realen Umgebung funktioniert, jedoch von der Außenwelt abgekoppelt ist. Hier gemachte Fehler oder die Ausführung gefährlicher Codes können Ihrem eigentlichen System niemals schaden. Sie können dieses Feld einfach zurücksetzen, wenn das Experiment beendet ist.

Analogie: Es ist wie ein Sandkasten auf einem Kinderspielplatz; Kinder können dort jedes Schloss bauen und zerstören, die allgemeine Ordnung des Parks wird dadurch nicht beeinträchtigt.

So funktioniert es

Wenn Softwareentwickler eine neue Funktion entwickeln oder eine verdächtige Datei öffnen, führen sie diese in einer Sandbox aus. Wenn das System abstürzt, ist nur dieser kleine Sandbox-Bereich betroffen, Ihr Computer bleibt jedoch intakt.

Wo es eingesetzt wird

Es wird in Cybersicherheitstests, in Softwareentwicklungsphasen und für Browser zur sicheren Ausführung von Websites verwendet.

Häufig verwechselt mit

Kann mit virtuellen Maschinen gemischt werden; Ein Sandkasten ist ein isolierter Raum, der im Allgemeinen leichter und auf eine bestimmte Anwendung spezialisiert ist.

Häufige Fragen

Warum ist eine Sandbox notwendig?

Es ist notwendig zu verstehen, ob eine unbekannte Software infiziert ist oder ob neuer Code das System beschädigen kann.

Können Daten aus der Sandbox gelangen?

Eine gut strukturierte Sandbox schränkt die Kommunikation mit der Außenwelt vollständig ein und verhindert Leckagen.
