# Was ist Git Push?

Dabei handelt es sich um den Vorgang, bei dem die Softwareänderungen, die Sie auf Ihrem lokalen Computer vornehmen, auf einen gemeinsam genutzten Server im Internet hochgeladen werden.

## Definition
Wenn Sie Software entwickeln, schreiben und bearbeiten Sie Ihre Codes auf Ihrem eigenen Computer. Der „Push“-Befehl wird verwendet, um diese Änderungen mit dem Rest des Teams zu teilen. Auf diese Weise werden alle von Ihnen vorgenommenen Aktualisierungen an ein zentrales Repository gesendet.

## So funktioniert es
Dies erfolgt durch Eingabe des Befehls „git push“ über ein Terminal oder einen Code-Editor.

## Wo es eingesetzt wird
Es wird in Softwareentwicklungsprozessen eingesetzt, insbesondere auf Plattformen wie GitHub oder GitLab.

## Häufig verwechselt mit
Es wird mit Git Pull verwechselt; Während Pull den Code aus dem Internet abruft, sendet Push ihn an das Internet.

## Häufige Fragen
**Was passiert, wenn ich nicht drücke?**
Die von Ihnen vorgenommenen Änderungen bleiben nur auf Ihrem Computer und Ihr Team kann sie nicht sehen.
