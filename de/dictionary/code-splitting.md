# Was ist Code Splitting?

Um die Ladegeschwindigkeit der Website zu erhöhen, werden große Codedateien in kleine Teile aufgeteilt und nur bei Bedarf geladen.

## Definition
Wenn der Benutzer Ihre Website betritt, lädt er nicht alle Codes herunter, sondern nur die Codes, die für die Seite erforderlich sind, die er gerade betrachtet. Die Codes anderer Seiten werden im Hintergrund geladen, wenn der Benutzer auf diese Seiten klickt.

## So funktioniert es
Der Entwickler macht im Code Markierungen wie „Diesen Teil jetzt laden, den Rest später laden“.

## Wo es eingesetzt wird
Es wird in großen Webanwendungen und Websites verwendet, bei denen die Benutzererfahrung im Vordergrund steht.

## Häufig verwechselt mit
Kann mit Bündelung verwechselt werden; Während beim Bündeln Dateien zusammengefasst werden, werden sie beim Code-Splitting auf intelligente Weise in Teile aufgeteilt.

## Häufige Fragen
**Wird es eine Verzögerung geben, wenn der Benutzer auf die Seite klickt?**
Es mag eine sehr kurze Zeit sein, aber das Gesamterlebnis ist besser, da die anfängliche Ladegeschwindigkeit viel schneller ist.
