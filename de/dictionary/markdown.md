# Was ist Markdown?

*Glossar · Dev · Zuletzt aktualisiert: 3. Juni 2026*

Eine leichte Formatierungssprache zum Formatieren von Text, die das Schreiben mit einfachen Zeichen ermöglicht.

## Definition

Markdown ist eine leichte und einfache Auszeichnungssprache zum Formatieren von Texten, ohne komplexe Codes schreiben zu müssen. Es ermöglicht Ihnen, beim Schreiben mit ein paar einfachen Zeichen Änderungen wie Überschriften, Listen oder Fettschrift vorzunehmen.

***Analogie:** Es ist, als würde man schnell formatieren, als würde man mit einem Stift Notizen auf Papier machen, anstatt mit Menüs in einem Texteditor herumzufummeln.*

## So funktioniert es

Dem Text werden Zeichen wie Sternchen oder Nummernzeichen hinzugefügt. Wenn Sie beispielsweise am Anfang und am Ende eines Wortes ein Sternchen einfügen, wandelt das System diesen automatisch in kursiven Text um.

## Wo es eingesetzt wird

Dies ist die von Softwareentwicklern am meisten bevorzugte Methode beim Schreiben von Dokumentationen, beim Erstellen von Inhalten in Notizanwendungen oder auf Websites.

## Häufig verwechselt mit

Es wird mit HTML verwechselt, aber während HTML viel komplexer und detaillierter ist, dient Markdown ausschließlich der Verbesserung der Lesbarkeit.

## Häufige Fragen

**Warum sollte ich Markdown anstelle von Word verwenden?**

Markdown ist viel schneller, weniger ablenkend und auf jeder Plattform leicht sichtbar.

**Wie öffne ich Markdown-Dateien?**

Sie können es mit jedem Texteditor öffnen, aber mit speziellen Viewern können Sie es einfacher formatiert lesen.
