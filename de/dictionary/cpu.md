# Was ist CPU?

> Central Processing Unit

Es ist das Hauptgehirn des Computers, das alle Vorgänge ausführt und verwaltet.

## Definition
Der Prozessor ist der Teil, der jeden Befehl verarbeitet, den Sie an Ihren Computer geben. Wenn Sie eine Taste drücken oder eine Anwendung öffnen, empfängt die CPU diese Anfrage, berechnet sie und sendet das Ergebnis an Ihren Bildschirm. Es ist die mathematische Intelligenz des Computers.

## So funktioniert es
Es funktioniert, indem es Milliarden kleiner Operationen pro Sekunde ausführt. Die Geschwindigkeit Ihrer Software hängt weitgehend davon ab, wie schnell die CPU diese Vorgänge ausführen kann.

## Wo es eingesetzt wird
Es ist das Herzstück aller Arten digitaler Geräte, vom Smartphone bis zum Supercomputer.

## Häufig verwechselt mit
Gemischt mit GPU; Während sich die GPU mit visuellen und parallelen Aufgaben befasst, kümmert sich die CPU um allgemeine logische Aufgaben.

## Häufige Fragen
**Was bedeutet CPU-Kern?**
Dabei handelt es sich um kleine unabhängige Verarbeitungseinheiten innerhalb eines Prozessors, die mehrere Aufgaben gleichzeitig ausführen können.
