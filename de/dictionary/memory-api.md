# Was ist Memory API?

Port, der es Software ermöglicht, Daten zum Speicher der künstlichen Intelligenz hinzuzufügen oder vorhandene Informationen abzufragen.

## Definition
Es ist der Verbindungspunkt, der es der Software ermöglicht, Daten zum Speicher der künstlichen Intelligenz hinzuzufügen oder vorhandene Informationen abzufragen. Diese Schnittstelle ermöglicht es Entwicklern, der KI auf einfache Weise ein Langzeitgedächtnis zu geben.

## So funktioniert es
Der Entwickler sendet Befehle über die API an die Speicher-Engine. Mit diesen Befehlen werden Informationen gespeichert, aktualisiert oder bei Bedarf abgerufen.

## Wo es eingesetzt wird
Es wird von Softwareentwicklern verwendet, die Anwendungen für künstliche Intelligenz entwickeln, um die Anwendung intelligenter zu machen.

## Häufig verwechselt mit
Es wird mit Datenbankoperationen verwechselt, dabei handelt es sich jedoch um Speicherverwaltung speziell in einem Format, das von Modellen der künstlichen Intelligenz verstanden wird.

## Häufige Fragen
**Kann jeder die Memory API nutzen?**
Wenn Sie über Kenntnisse in der Softwareentwicklung verfügen, können Sie der bereitgestellten Dokumentation folgen und diese in Ihre Anwendungen integrieren.

**Was kann mit dieser API gespeichert werden?**
Alle Informationen, die sich künstliche Intelligenz merken muss, wie z. B. Benutzerpräferenzen, vergangene Gespräche, Projektdetails.
