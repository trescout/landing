Was ist Adblocker?

Dabei handelt es sich um ein Software-Plug-in, das verhindert, dass Werbung in Ihrem Internetbrowser erscheint.

Definition

Adblocker ist ein Tool, das automatisch Anzeigen erkennt und ausblendet, die beim Besuch von Websites erscheinen. Diese Tools verhindern, dass Anzeigen geladen werden, wodurch Seiten schneller geöffnet werden und Sie nicht abgelenkt werden. Sie werden in der Regel als Browser-Add-Ons installiert.

Analogie: Stellen Sie sich vor, Sie lesen eine Zeitschrift und schneiden mit einer Schere alle Anzeigen auf der Seite aus; Adblocker erledigt genau das für Sie in der digitalen Welt.

So funktioniert es

Wenn Sie ein Adblocker-Plugin aus dem Store Ihres Browsers herunterladen und installieren, beginnt dieses Tool im Hintergrund zu arbeiten. Während Websites geladen werden, blockiert das Plugin Verbindungen zu Ad-Servern. Auf diese Weise gelangen Anzeigen nie auf Ihren Bildschirm.

Wo es eingesetzt wird

Es wird als Add-on in Internetbrowsern wie Chrome, Firefox oder Safari verwendet.

Häufig verwechselt mit

Es kann mit einer Firewall verwechselt werden, aber während es den gesamten Internetverkehr kontrolliert, zielt der Adblocker nur auf Werbeinhalte ab.

Häufige Fragen

Schädigt die Verwendung von Adblockern Websites?

Viele Websites erzielen ihre Einnahmen durch Werbung; Aus diesem Grund bemerken einige Websites möglicherweise, dass Sie einen Werbeblocker verwenden, und fordern Sie auf, Werbung zu deaktivieren.

Blockiert es jede Anzeige?

Es blockiert die meisten Anzeigen, einige Websites sind jedoch möglicherweise schwieriger zu blockieren, da sie Anzeigen mit Inhalten kombinieren.
