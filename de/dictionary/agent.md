# Was ist Agent?

*Glossar · AI · Zuletzt aktualisiert: 9. Juli 2026*

Eine intelligente Softwareeinheit, die selbstständig Entscheidungen treffen und Tools nutzen kann, um die angestrebte Aufgabe auszuführen.

## Definition

Ein Agent für künstliche Intelligenz reagiert nicht nur auf Ihre Eingaben; Es kann in Ihrem Namen das Internet durchsuchen, Dateien bearbeiten oder andere Software steuern. Diese Strukturen gehen Schritt für Schritt vor, indem sie komplexe Ziele in kleine Teile zerlegen. Dank seiner Fähigkeit, eigene Entscheidungen zu treffen, kann er Dinge zum Erfolg führen, auch wenn Sie nicht auf ihn aufpassen.

***Analogie:** Ein gewöhnliches KI-Modell ist wie eine Enzyklopädie, an die man nur Fragen stellen kann. Der Agent ist wie ein Assistent, der die Enzyklopädie liest, in die Bibliothek geht, für Sie recherchiert und den Bericht auf Ihrem Schreibtisch liegen lässt.*

## So funktioniert es

Agenten beginnen mit der Analyse eines primären Ziels, das ihnen vorgegeben wird. Sie entscheiden, welche Tools sie verwenden möchten (z. B. einen Taschenrechner oder einen Webbrowser). Wenn beim Ausführen des Vorgangs eine Fehlermeldung angezeigt wird, versuchen sie es erneut und präsentieren Ihnen schließlich das Endergebnis.

## Wo es eingesetzt wird

Sie werden häufig in Kundendienst-Bots, automatisierten Softwareentwicklungstools und komplexen Datenanalyseprozessen eingesetzt.

## Häufig verwechselt mit

Nicht zu verwechseln mit Standard-KI-Modellen, die nur Text produzieren; Agenten gehen über das Produzieren von Text hinaus und ergreifen Maßnahmen.

## Häufige Fragen

**Treffen Agenten immer die richtige Entscheidung?**

Nein, manchmal wählen sie möglicherweise das falsche Werkzeug oder weichen vom Ziel ab. Deshalb ist es wichtig, sie unter Kontrolle zu halten.

**Können Agenten meinen Computer überprüfen?**

Ja, sie können Ihre Dateien verwalten oder Ihre Anwendungen ausführen, wenn Sie ihnen die erforderlichen Berechtigungen und Tools erteilen.
