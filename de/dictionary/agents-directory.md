# Was ist Agents Directory?

*AI · Zuletzt aktualisiert: 11. Oktober 2026*

Es handelt sich um eine spezielle Ordnerstruktur in Softwareprojekten, die das Verhalten, die Werkzeuge und die Regeln von KI-Agenten an einem Ort bündelt.

## Definition

Das Agents Directory ist ein Verzeichnis in einer Codebasis, das die Anweisungen und Tool-Verknüpfungen von KI-Agenten enthält, die für verschiedene Aufgaben entwickelt wurden. Es ermöglicht Ihnen, die Aufgabengrenzen und Verhaltensmuster mehrerer autonomer Helfer, die in Ihrem Projekt arbeiten, an einem einzigen Standardort zu organisieren. Entwicklungstools und Orchestrierungs-Engines scannen dieses Verzeichnis, um projektspezifische Agenten automatisch zu erkennen.

***Analogie:** Ähnlich wie der HR-Ordner in einem Unternehmen, in dem die Arbeitsplatzbeschreibung, Befugnisse und Handbücher jedes Fachangestellten ordentlich aufbewahrt werden.*

## So funktioniert es

Entwickler erstellen im Stammverzeichnis des Projekts normalerweise einen Ordner namens .agents oder agents. In diesem Ordner werden Konfigurationsdateien für jeden einzelnen Agenten hinzugefügt, der Tests schreibt, Code überprüft oder Dokumentationen erstellt. Agentenunterstützte Entwicklungstools lesen diese Dateien, um zu bestimmen, welche Rollen der Agent übernehmen und welche Funktionen er aufrufen kann.

## Wo es eingesetzt wird

Es wird häufig in agentenbasierten Softwareentwicklungsumgebungen, KI-Orchestrierungsplattformen und modernen Code-Editoren verwendet.

## Häufig verwechselt mit

Es kann mit dem allgemeinen Konzept des „Agent Workspace“ verwechselt werden: Während der Arbeitsbereich den temporären Speicher und die temporären Dateien bezeichnet, die ein Agent während der Arbeit nutzt, ist das Agents Directory das permanente Dateiverzeichnis, in dem der Quellcode und die Regeldefinitionen der Agenten gespeichert werden.

## Häufige Fragen

**Können KI-Agenten ohne diesen Ordner nicht arbeiten?**

Sie können arbeiten, aber Sie müssten die Systemanweisungen und die verfügbaren Werkzeuge für jeden Agenten einzeln und manuell angeben; die Verzeichnisstruktur automatisiert und standardisiert diesen Prozess.

**Können die Agenten im Ordner automatisch miteinander kommunizieren?**

Ja: Systeme mit einer Multi-Agenten-Architektur listen die Agenten in diesem Verzeichnis auf und nutzen es als Leitfaden, um eine Aufgabe an einen anderen Agenten zu übergeben.
