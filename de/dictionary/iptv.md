# Was ist IPTV?

> Internet Protocol Television

Dabei handelt es sich um eine Methode zur digitalen Übertragung von Fernsehsendungen über eine Internetverbindung anstelle einer herkömmlichen Antenne oder eines Satelliten.

## Definition
Mit IPTV können Fernsehinhalte mithilfe des Internetprotokolls (IP) zu Ihnen nach Hause gelangen, anstatt über herkömmliche Kabel- oder Satellitenübertragungen. In diesem System werden Sendungen in Teile geteilt, über Ihre Internetleitung an Sie gesendet und auf Ihrem Gerät wieder zusammengesetzt. Im Gegensatz zu herkömmlichen Sendungen ermöglicht es interaktive Funktionen wie das Auswählen und Stoppen der Inhalte, die Sie ansehen möchten.

## So funktioniert es
Das von Ihrem Internetdienstanbieter kommende Datenpaket wird über ein Modem oder eine spezielle Box (Set-Top-Box) verarbeitet. Diese Box wandelt das aus dem Internet kommende Signal in ein Bildformat um, das Ihr Fernseher verstehen kann. Wenn Sie den Kanal wechseln, fordert das System im Hintergrund den Datenstrom dieses Kanals an und spiegelt ihn auf Ihrem Bildschirm wider.

## Wo es eingesetzt wird
Es wird in Smart-TVs, speziellen IPTV-Boxen oder Anzeigeanwendungen auf Computern und Telefonen eingesetzt.

## Häufig verwechselt mit
Es kann mit Streaming-Plattformen wie Netflix oder YouTube verwechselt werden, aber IPTV ist eine Infrastrukturtechnologie, die im Allgemeinen die Übertragung von Live-Fernsehkanälen abdeckt.

## Häufige Fragen
**Ist zum Ansehen von IPTV Highspeed-Internet erforderlich?**
Ja, eine stabile Internetverbindung mit ausreichender Geschwindigkeit ist erforderlich, damit HD-Übertragungen unterbrechungsfrei übertragen werden können.

**Ist IPTV legal?**
IPTV ist eine Übertragungstechnologie und legal; Raubkopien von Streaming-Diensten, die Inhalte anbieten, die gegen Urheberrechte verstoßen, sind jedoch illegal.
