Was ist Redaction?

Es ist der Prozess der dauerhaften Unkenntlichmachung oder Löschung sensibler oder vertraulicher Informationen aus Dokumenten.

Definition

Redaktion ist die Zensur vertraulicher Elemente in einem Text, Bild oder einer Datenbank aufgrund rechtlicher, organisatorischer oder Sicherheitsanforderungen. Daten wie Identifikationsnummern, medizinische Akten oder Geschäftsgeheimnisse werden vor der Weitergabe durch dieses Verfahren unleserlich gemacht. Bei einem echten Schwärzungsprozess wird auch die Textebene unter den entfernten Informationen vollständig aus der Datei entfernt.

Analogie: Es ist vergleichbar damit, die Namen von Vertraulichkeitspersonen auf einer Kopie eines offiziellen Dokuments mit einem schwarzen Filzstift zu verdecken und den Text anschließend vollständig von der Seite zu kratzen.

So funktioniert es

KI-Algorithmen oder regelbasierte Systeme erkennen sensible Muster im Dokument automatisch. Die ausgewählten Bereiche werden sowohl visuell abgedeckt als auch physisch aus der Datenebene im Hintergrund des Dokuments gelöscht. Auf diese Weise kann selbst beim Kopieren von Text aus dem Dokument auf die vertraulichen Informationen in keiner Weise zugegriffen werden.

Wo es eingesetzt wird

Es wird verwendet, wenn Beweismittelakten in Gerichtsverfahren weitergegeben, Gesundheitsakten anonymisiert und öffentlich zugängliche Berichte veröffentlicht werden.

Häufig verwechselt mit

Es wird oft mit dem bloßen Zeichnen einer schwarzen Form über den Text verwechselt; während bei oberflächlichen Zeichnungen der darunter liegende Text kopiert werden kann, werden die Daten beim echten Schwärzungsprozess vollständig aus der Datei entfernt.

Häufige Fragen

Reicht es aus, Text in einer PDF-Datei schwarz zu färben, um eine Schwärzung vorzunehmen?

Nein: Wenn Sie nur ein visuelles Feld einfügen, kann der darunter liegende Text kopiert werden. Für einen sicheren Vorgang muss die Textebene vollständig gelöscht werden.

Wie wird KI in Schwärzungsprozessen eingesetzt?

Sie beschleunigt den Schwärzungsprozess, indem sie sensible personenbezogene Daten in Dokumenten automatisch erkennt und markiert.
