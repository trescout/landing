# Was ist Localhost?

Dies bezeichnet den Zustand, in dem eine Software nicht im Internet, sondern ausschließlich auf dem aktuell verwendeten Computer ausgeführt wird.

## Definition
Wenn Entwickler eine Website erstellen, laden sie diese nicht sofort ins Internet hoch. Zuerst testen sie diese auf ihrem eigenen Computer unter der Adresse 'localhost'. Das ist so, als würde Ihr Computer sich selbst sagen: 'Ich bin ein Server'. Niemand von außen kann dies sehen, nur Sie.

## So funktioniert es
Indem Sie 'localhost' in die Adresszeile Ihres Browsers eingeben, greifen Sie auf die Software zu, die auf Ihrem eigenen Computer läuft.

## Wo es eingesetzt wird
Es wird in Softwareentwicklungsprozessen und Testphasen verwendet.

## Häufig verwechselt mit
Es kann mit einer Website verwechselt werden; jedoch ist localhost nur für Ihren eigenen Computer bestimmt.

## Häufige Fragen
**Warum verwenden wir localhost?**
Um Fehler sicher auf dem eigenen Computer zu beheben, ohne sie ins Internet zu stellen.
