# Was ist Model Context Protocol?

*Glossar · AI · Zuletzt aktualisiert: 20. Juli 2026*

> MCP

Eine gemeinsame Sprache, die es KI-Systemen ermöglicht, sicher mit Daten und Tools zu kommunizieren.

## Definition

Das Model Context Protocol ist eine Standardkommunikationsmethode, die Modelle künstlicher Intelligenz verwenden, wenn sie eine Verbindung zu Datenquellen oder Softwaretools in der Außenwelt herstellen. In der Vergangenheit musste jede KI-Anwendung spezielle Verbindungen für unterschiedliche Datenquellen herstellen. MCP beseitigt diese Verwirrung und stellt sicher, dass alle Modelle Daten erfassen und nach denselben Regeln verarbeiten.

***Analogie:** Es ist so, als würden Menschen aus verschiedenen Ländern eine gemeinsame Sprache wie Englisch verwenden, um einander zu verstehen; MCP ist die gemeinsame Sprache zwischen künstlicher Intelligenz und Datenbanken.*

## So funktioniert es

Mithilfe von MCP verbindet ein Entwickler den KI-Assistenten mit der Datenbank oder Kalenderanwendung Ihres Unternehmens. Dank des Protokolls weiß der Assistent, wo sich die Daten befinden und wie er sie lesen kann. Sie stellen Ihrem Assistenten einfach eine Frage, und er erhält die erforderlichen Daten sicher über MCP und antwortet Ihnen.

## Wo es eingesetzt wird

Es wird in von künstlicher Intelligenz unterstützten Code-Editoren, Tools zur Analyse von Unternehmensdaten und Plattformen für intelligente Assistenten verwendet.

## Häufig verwechselt mit

Kann mit API gemischt werden; Während API jedoch eine allgemeine Kommunikationsmethode ist, handelt es sich bei MCP um einen spezialisierten Standard, der sich speziell auf den Kontext und die Datenanforderungen künstlicher Intelligenz konzentriert.

## Häufige Fragen

**Warum ist MCP notwendig?**

Anstatt für jede Anwendung separate Verbindungscodes zu schreiben, können Sie mit MCP einmal eine Standardverbindung herstellen und diese in vielen verschiedenen Modellen der künstlichen Intelligenz verwenden.

**Ist MCP sicher?**

Ja, MCP verfügt über eine Struktur, die die Datenzugriffsberechtigungen unter Kontrolle hält und so sicherstellt, dass künstliche Intelligenz nur auf zulässige Daten zugreifen kann.
