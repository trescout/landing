# Was ist Native?

Dies bedeutet, dass eine Software speziell für das Betriebssystem des Geräts, auf dem sie läuft, entwickelt wurde und darauf ausgelegt ist, die höchste Leistung zu erbringen.

## Definition
Native Anwendungen können direkt auf die Hardware und das Betriebssystem des Geräts zugreifen. Da sie die Sprache des Geräts sprechen, ohne eine zusätzliche Ebene zu benötigen, arbeiten sie schneller und flüssiger. Sie nutzen in der Regel die spezifischen Funktionen des jeweiligen Geräts mit voller Kapazität.

## So funktioniert es
Entwickler schreiben Code unter Verwendung der geräteeigenen Softwareentwicklungstools. Dadurch kann die Anwendung alle vom Betriebssystem gebotenen Möglichkeiten direkt nutzen. Da keine Übersetzungsschicht dazwischengeschaltet ist, kommt es zu keiner Verzögerung.

## Wo es eingesetzt wird
Wir finden sie in App-Stores auf Smartphones, in Software auf Betriebssystemebene und in Spielen, die eine hohe Leistung erfordern.

## Häufig verwechselt mit
Webbasierte Anwendungen oder hybride Anwendungen nutzen eine Zwischenschicht, wie etwa einen Browser, um mit dem Gerät zu kommunizieren.

## Häufige Fragen
**Ist eine native Anwendung immer besser?**
In Bezug auf die Leistung meistens ja, aber die Entwicklung dauert länger und für jedes Gerät muss separater Code geschrieben werden.

**Wie funktionieren nicht-native Anwendungen?**
Sie laufen in der Regel innerhalb eines Browsers oder über eine Übersetzungsschicht, was manchmal zu Verlangsamungen führen kann.
