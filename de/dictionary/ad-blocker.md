# Was ist Ad Blocker?

Ein Software-Tool, das Werbeinhalte auf Internetseiten stoppt, bevor sie geladen werden.

## Definition
Ein Werbeblocker ist ein Hilfsmittel, das verhindert, dass Ihr Browser beim Öffnen einer Website mit Werbeservern kommuniziert. Diese Tools fangen Werbecodes ab, bevor sie Ihren Computer erreichen, und lassen deren Platz auf der Seite leer, wodurch die Website sauberer aussieht. Da die Werbung nicht geladen wird, öffnen sich die Seiten zudem schneller und Ihr Datenverbrauch sinkt.

## So funktioniert es
Sie installieren es als Erweiterung in Ihrem Browser, und diese Erweiterung verfolgt eine Liste von Servern, die Werbung hosten. Wenn die Website geladen wird und der Browser versucht, eine Verbindung zu den Adressen auf dieser Liste herzustellen, unterbricht die Erweiterung diese Verbindung. Auf diese Weise wird die Werbung gar nicht erst angezeigt.

## Wo es eingesetzt wird
Es wird normalerweise als Erweiterung in Webbrowsern verwendet oder ist in einigen Browsern als integrierte Funktion enthalten.

## Häufig verwechselt mit
Manchmal kann das Blockieren von Werbung mit dem Blockieren von Website-Inhalten verwechselt werden, aber diese Tools zielen nur auf Werbeserver ab.

## Häufige Fragen
**Schadet die Verwendung eines Werbeblockers den Websites?**
Da er die Werbeeinnahmen der Website blockiert, kann dies zu einem Einnahmeverlust für die Ersteller von Inhalten führen.

**Blockiert es jede Anzeige?**
Er blockiert die meisten Werbeanzeigen, aber einige Websites können Werbeblocker erkennen und den Zugriff einschränken.
