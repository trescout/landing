# Was ist Analytics Snippets?

Dabei handelt es sich um kleine Codestücke, die Websites ihren Seiten hinzufügen, um das Besucherverhalten zu verfolgen.

## Definition
Ein Analytics-Snippet ist ein auf einer Website platzierter Code, der aufzeichnet, wo Besucher auf die Website gelangt sind und wie viel Zeit sie auf welchen Seiten verbracht haben. Diese Daten helfen Websitebesitzern, ihre Websites zu verbessern. Es läuft normalerweise unbemerkt im Hintergrund der Seite.

## So funktioniert es
Der Websitebesitzer fügt diesen vom Analysedienst erhaltenen Shortcode zu den Quelldateien der Website hinzu. Wenn der Benutzer die Seite öffnet, wird der Code ausgeführt und sendet die Besuchsinformationen an den Analyseserver.

## Wo es eingesetzt wird
Es wird auf Plattformen wie Google Analytics erstellt und in den HTML-Codes von Websites platziert.

## Häufig verwechselt mit
Es wird oft mit Cookies verwechselt; Während Cookies Daten in Ihrem Browser speichern, ist Snippet das Tool, das Daten sammelt und an den Server sendet.

## Häufige Fragen
**Werden diese Codes meine persönlichen Daten stehlen?**
Sie sammeln oft anonyme Daten; Allerdings müssen Websites transparent darüber sein, wie sie diese Daten verwenden.

**Warum steht es auf jeder Website?**
Websitebesitzer möchten ein besseres Erlebnis bieten, indem sie messen, was den Benutzern gefällt und was nicht.
