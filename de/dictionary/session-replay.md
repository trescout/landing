# Was ist Session Replay?

*Glossar · Dev · Zuletzt aktualisiert: 17. Juli 2026*

Es handelt sich um eine Technologie, die es Ihnen ermöglicht, alle Bewegungen des Benutzers auf Ihrer Website wie in einem Film aufzuzeichnen und anzusehen.

## Definition

So können Sie Schritt für Schritt sehen, wohin ein Benutzer die Maus bewegt hat, auf welche Schaltfläche er geklickt hat oder wo er hängengeblieben ist. Dies ist der effektivste Weg, technische Probleme oder Verwirrungen des Benutzers zu verstehen.

***Analogie:** Es ist, als würde man durch eine Überwachungskamera beobachten, wie ein Kunde ein Geschäft betritt. Sie sehen live, auf welches Regal der Kunde geschaut hat und welches er zurückgelassen hat (oder welchen Knopf er nicht drücken konnte).*

## So funktioniert es

Sie fügen Ihrer Website einen kleinen Code hinzu. Dieser Code zeichnet alle Bewegungen des Nutzers im Browser anonym auf und präsentiert sie Ihnen wie einen Videoplayer.

## Wo es eingesetzt wird

Es wird in User Experience (UX)-Tests und technischen Debugging-Prozessen verwendet.

## Häufig verwechselt mit

Es wird mit Analytics (Statistik) verwechselt; Analyse „Wie viele Leute haben geklickt?“ sagt, Sitzungswiederholung: „Wie hat es Klick gemacht?“ beantwortet die Frage.

## Häufige Fragen

**Wie sieht es mit der Privatsphäre der Benutzer aus?**

Gute Systeme maskieren automatisch sensible Daten (wie Passwörter).

**Nimmt es viel Platz ein?**

Moderne Systeme sind recht leichtgewichtig, da sie nur Bewegungsdaten aufzeichnen.
