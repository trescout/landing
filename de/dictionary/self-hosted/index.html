Was ist Self-hosted?

Dabei wird eine Software auf Ihrem eigenen Computer oder dedizierten Server gehostet und nicht auf einem Cloud-Dienst eines Drittanbieters.

Definition

Durch den selbst gehosteten Ansatz haben Sie die vollständige Kontrolle über Ihre Daten. Da Sie die Software auf Ihrer eigenen Hardware betreiben, sind Sie nicht auf die Server eines externen Unternehmens angewiesen. Dies bietet vollständige Kontrolle, insbesondere in Bezug auf Datenschutz- und Sicherheitsfragen.

Analogie: Es ist, als würde man ein eigenes Haus bauen und all seine Habseligkeiten dort unterbringen, anstatt in einem Hotel zu übernachten. Sie haben die vollständige Kontrolle.

So funktioniert es

Laden Sie den Quellcode oder die Installationsdatei der gewünschten Software herunter. Bereiten Sie einen Server oder lokalen Computer vor und installieren und führen Sie die Software dort aus. Führen Sie Updates und Wartung selbst durch.

Wo es eingesetzt wird

Persönlicher Cloud-Speicher wird bei allen Projekten bevorzugt, die spezielle Modelle der künstlichen Intelligenz und Privatsphäre erfordern.

Häufig verwechselt mit

Nicht zu verwechseln mit Cloud-Diensten; In der Cloud mieten Sie den Computer eines anderen, im Self-Hosted nutzen Sie einen Bereich unter Ihrer eigenen Kontrolle.

Häufige Fragen

Erfordert es technisches Wissen?

Ja, möglicherweise sind grundlegende Kenntnisse der Systemadministration erforderlich, um Installations- und Wartungsprozesse zu verwalten.

Ist es sicherer?

Es ist sicherer im Hinblick auf den Datenschutz, aber es liegt ausschließlich in Ihrer Verantwortung, die Sicherheit zu gewährleisten.
