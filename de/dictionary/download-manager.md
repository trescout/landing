# Was ist Download Manager?

Dabei handelt es sich um ein Hilfstool, das das Herunterladen von Dateien aus dem Internet beschleunigt und unterbrochene Downloads dort fortsetzt, wo sie unterbrochen wurden.

## Definition
Verbindungsabbrüche oder Verlangsamungen können beim Herunterladen großer Dateien über das Internet ärgerlich sein. Dieses Tool teilt die Datei in kleinere Teile auf und lädt sie gleichzeitig herunter, wodurch die Download-Geschwindigkeit erhöht wird. Außerdem sparen Sie Zeit, da Sie dort weitermachen können, wo Sie aufgehört haben, anstatt von vorne zu beginnen, wenn die Verbindung unterbrochen wird.

## So funktioniert es
Es wird normalerweise als Add-on zu Ihrem Browser oder als Software auf Ihrem Computer installiert. Wenn Sie auf einen Datei-Download-Link klicken, kommt dieses Tool ins Spiel und verwaltet den Vorgang anstelle des Download-Managers Ihres Browsers.

## Wo es eingesetzt wird
Es wird auf Filesharing-Sites, beim Herunterladen großer Softwarepakete oder bei langsamen Internetverbindungen verwendet.

## Häufig verwechselt mit
Es kann mit den einfachen Download-Managern der Browser verwechselt werden, aber diese Tools bieten viel erweiterte Funktionen.

## Häufige Fragen
**Beschleunigt es jede Datei?**
Nein, wenn die Dateigröße klein ist, ist der Geschwindigkeitsunterschied nicht spürbar, bei großen Dateien ist dies jedoch recht effektiv.

**Ist es kostenlos?**
Es stehen viele kostenlose und Open-Source-Optionen zur Verfügung.
