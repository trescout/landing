# Was ist Network Stack?

Dies ist die Gesamtheit der Softwareebenen, die ein Computer benötigt, um eine Verbindung zum Internet herzustellen und Daten auszutauschen.

## Definition
Wenn Sie Daten über das Internet senden, gelangen diese nicht in einem einzigen Schritt ans Ziel. Der Netzwerk-Stack besteht aus Software-Regeln, die den gesamten Prozess steuern – von der Paketierung der Daten über die Übertragung durch das Kabel bis hin zur Wiederzusammensetzung auf der Gegenseite. Diese Ebenen bilden die Brücke zwischen der Hardware und den Anwendungen, die Sie verwenden.

## So funktioniert es
Ihr Betriebssystem führt diese Ebenen im Hintergrund automatisch aus, sobald Sie eine Verbindung zum Internet herstellen; Sie öffnen lediglich den Browser.

## Wo es eingesetzt wird
Er ist als grundlegende Komponente in Servern, PCs und Netzwerk-Routern vorhanden.

## Häufig verwechselt mit
Dies ist dasselbe Konzept wie Networking-Stack.

## Häufige Fragen
**Verwalte ich diese Ebenen selbst?**
Nein, Ihr Betriebssystem und die Netzwerktreiber verwalten diesen Prozess für Sie.

**Warum ist es wichtig?**
Wenn eine dieser Ebenen fehlerhaft arbeitet, wird Ihre Internetverbindung unterbrochen oder es kommt zu Datenverlusten.
