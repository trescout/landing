# Was ist Superset?

Es handelt sich um eine umfassendere Struktur, die alle Funktionen eines vorhandenen Systems umfasst und neue Funktionen hinzufügt.

## Definition
Wenn etwas eine Obermenge ist, bedeutet das, dass es alles enthält, was ihm zugrunde liegt. Beispielsweise kann eine andere Sprache, die eine Obermenge einer Programmiersprache ist, den gesamten Code der ersten Sprache ausführen, bietet aber zusätzliche neue Funktionen. Dies wird verwendet, um das System zu verbessern und gleichzeitig die Abwärtskompatibilität aufrechtzuerhalten.

## So funktioniert es
Beim Entwerfen einer neuen Sprache oder eines neuen Tools werden bestehende Regeln beibehalten und neue Ebenen darauf aufgebaut, um die Gewohnheiten alter Benutzer nicht zu stören.

## Wo es eingesetzt wird
Es wird häufig in Programmiersprachen (z. B. TypeScript ist eine Obermenge von JavaScript) und Softwarearchitekturen verwendet.

## Häufige Fragen
**Ist es vorteilhaft, eine Obermenge zu verwenden?**
Ja, denn es ermöglicht Ihnen, auf neue Technologien umzusteigen, ohne die mit dem alten System geschriebenen Codes wegzuwerfen.
