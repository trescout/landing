# Was ist AI Coding Assistants?

*Glossar · Dev · Zuletzt aktualisiert: 14. Juli 2026*

Dabei handelt es sich um Tools der künstlichen Intelligenz, die Softwareentwicklern beim Schreiben von Code Vorschläge machen, Fehler finden und den Entwicklungsprozess beschleunigen.

## Definition

AI Coding Assistants verhalten sich wie die Kollegen eines Entwicklers. Beim Schreiben von Code sagt es die nächste Zeile voraus, erklärt komplexe Funktionen oder prüft den von Ihnen geschriebenen Code auf Fehler. Mit diesen Tools können Entwickler weniger Fehler machen und schneller Code erstellen.

***Analogie:** Er oder sie ist wie ein sehr sachkundiger Redakteur, der Ihnen beim Schreiben eines Artikels immer zur Seite steht, die richtigen Wörter vorschlägt, Rechtschreibfehler korrigiert und Ihre Sätze vervollständigt.*

## So funktioniert es

Es wird als Plugin in Ihrem Code-Editor installiert. Wenn Sie mit dem Schreiben von Code beginnen, läuft dieser im Hintergrund und zeigt seine Vorschläge auf Ihrem Bildschirm an.

## Wo es eingesetzt wird

Es wird in Softwareentwicklungsumgebungen (IDE) wie VS Code und IntelliJ verwendet.

## Häufig verwechselt mit

Es kann mit „AI Coding Agent“ verwechselt werden, der Code völlig selbstständig schreibt; Assistenten arbeiten normalerweise unter Ihrer Kontrolle.

## Häufige Fragen

**Werden diese Tools Softwareentwickler ersetzen?**

Nein, es handelt sich um ein Hilfstool, das die Arbeit des Softwareentwicklers einfacher und produktiver macht.
