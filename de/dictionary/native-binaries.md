# Was ist Native Binaries?

*Glossar · Dev · Zuletzt aktualisiert: 6. Oktober 2026*

Dies sind Programmdateien, die direkt für ein bestimmtes Betriebssystem und eine bestimmte Prozessorenarchitektur lauffähig kompiliert wurden.

## Definition

Native Binaries (native Binärdateien) sind Dateien, die es ermöglichen, dass geschriebener Code direkt von der Computerhardware verstanden wird, ohne dass eine Vermittlersoftware erforderlich ist. Da diese Dateien speziell für das Zielbetriebssystem und den Prozessortyp vorbereitet sind, bieten sie die höchste Leistung. Im Gegensatz zu Sprachen wie Java oder Python benötigen sie keine auf dem Computer installierte virtuelle Maschine oder einen Interpreter, um zu funktionieren.

***Analogie:** Man kann sich das so vorstellen, als würde man sich direkt mit einer Person unterhalten, die dieselbe Muttersprache spricht wie Sie, ohne einen Übersetzer zu benötigen. Es gibt keine Zeitverschwendung dazwischen und Sie kommunizieren direkt.*

## So funktioniert es

Entwickler konvertieren ihren geschriebenen Code mithilfe von Tools namens Compilern direkt in Maschinensprache. Während dieses Prozesses wird die Zielhardware angegeben, und der Compiler erzeugt eine Datei aus Nullen und Einsen, die nur diese Hardware versteht. Diese erstellte Datei kann direkt durch Doppelklick des Benutzers ausgeführt werden.

## Wo es eingesetzt wird

Sie werden häufig in der Systemprogrammierung, in Spiel-Engines und in eingebetteten Systemen eingesetzt, bei denen Geschwindigkeit und Effizienz entscheidend sind. Darüber hinaus werden die modernen Befehlszeilentools und schnell laufenden Desktop-Anwendungen, die Sie auf TreScout prüfen, im Allgemeinen mit dieser Struktur vertrieben.

## Häufig verwechselt mit

Sie werden oft mit Zwischencode-Dateien verwechselt, die auf einer virtuellen Maschine ausgeführt werden. Während Zwischencode-Dateien einen Vermittler benötigen, um auf jedem Computer zu laufen, funktionieren native Binärdateien nur direkt auf dem spezifischen System, für das sie erstellt wurden.

## Häufige Fragen

**Funktionieren native Binärdateien auf jedem Computer?**

Nein. Sie funktionieren nur auf dem Betriebssystem und der Prozessorenarchitektur, für die sie kompiliert wurden. Beispielsweise kann eine für Windows kompilierte Datei nicht direkt auf einem Mac-Computer ausgeführt werden.

**Welche Sprachen erzeugen native Binärdateien?**

Systemprogrammiersprachen wie Rust, C++, Go und Zig sind so konzipiert, dass sie direkt native Binärdateien erzeugen.
