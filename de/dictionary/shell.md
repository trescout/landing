# Was ist Shell?

Dabei handelt es sich um eine Schnittstelle, mit der Sie den Computer steuern können, indem Sie anstelle einer grafischen Oberfläche Textbefehle direkt eingeben.

## Definition
Es fungiert als Brücke zwischen Ihnen und dem Kern des Betriebssystems. Sie können Dateien verwalten, Programme ausführen und Systemeinstellungen ändern, indem Sie Befehle über die Tastatur eingeben, anstatt eine Maus zu verwenden. Es ist der einfachste und leistungsstärkste Arbeitsbereich für Softwareentwickler.

## So funktioniert es
Sie öffnen einen schwarzen Bildschirm und geben dort bestimmte Befehle ein. Wenn Sie beispielsweise „ls“ eingeben und die Eingabetaste drücken, wird Ihnen eine Liste aller Dateien in dem Ordner angezeigt, in dem Sie sich gerade befinden.

## Wo es eingesetzt wird
Es ist in alle Systeme von Linux, macOS und Windows integriert; Es ist für Softwareentwicklungsprozesse unverzichtbar.

## Häufig verwechselt mit
Es wird mit dem Terminal verwechselt; Terminal ist das Fenster, das diese Schnittstelle anzeigt, und Shell ist der Befehlsinterpreter, der in diesem Fenster ausgeführt wird.

## Häufige Fragen
**Ist es schwierig, Shell zu lernen?**
Es mag auf den ersten Blick etwas ungewohnt erscheinen, aber sobald Sie ein paar grundlegende Befehle gelernt haben, wird die Verwaltung des Computers viel schneller.
