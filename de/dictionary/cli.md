# Was ist CLI?

> Command Line Interface

Dabei handelt es sich um eine Methode, dem Computer durch geschriebene Texte Befehle zu erteilen.

## Definition
CLI ist eine Methode zur Verwaltung des Computers durch die Eingabe textbasierter Befehle statt durch Klicken mit der Maus. Es ist schnell und ein sehr leistungsfähiges Steuerungstool, insbesondere für Softwareentwickler.

## So funktioniert es
Es öffnet sich ein schwarzer Bildschirm und dort werden bestimmte Befehle eingegeben. Der Computer liest diese Befehle und führt sie sofort aus.

## Wo es eingesetzt wird
Es wird in Softwareentwicklungsprozessen, bei der Serververwaltung und zum Ausführen von Modellen der künstlichen Intelligenz auf dem lokalen Computer verwendet.

## Häufig verwechselt mit
Es wird mit einer grafischen Oberfläche (GUI) verwechselt, aber die CLI ist vollständig textbasiert und bietet viel mehr Anpassungsmöglichkeiten.

## Häufige Fragen
**Ist es notwendig, CLI zu lernen?**
Obwohl es für die meisten modernen Werkzeuge nicht unbedingt erforderlich ist, bietet es eine hohe Geschwindigkeit für die Arbeit auf professionellem Niveau.

**Was passiert, wenn ich den falschen Befehl eingebe?**
Normalerweise gibt das System Fehler aus, aber es gibt auch kritische Befehle, die Vorsicht erfordern.
