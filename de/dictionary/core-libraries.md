# Was ist Core Libraries?

*Glossar · Dev · Zuletzt aktualisiert: 7. August 2026*

Dabei handelt es sich um Standardcodepakete, die eine Software benötigt, um ihre Grundfunktionen auszuführen.

## Definition

Kernbibliotheken sind vorgefertigte Codebibliotheken, die die grundlegendsten Bausteine ​​einer Programmiersprache oder Plattform enthalten. Mit diesen Bibliotheken können Entwickler Standardvorgänge schnell ausführen, anstatt jedes Mal Code von Grund auf neu schreiben zu müssen. Wie die Fundamentsäulen eines Gebäudes sind sie unverzichtbare Teile, die dafür sorgen, dass die Software überlebt und ordnungsgemäß funktioniert.

***Analogie:** Es ist wie mit einfachen Gewürzen und einfachen Kochutensilien in einer Küche; Sie müssen nicht jedes Mal, wenn Sie kochen, Salz erfinden, sondern können das Rezept mit diesen grundlegenden Werkzeugen vervollständigen.*

## So funktioniert es

Durch die Einbindung dieser Bibliotheken in ihre Projekte können Entwickler komplexe mathematische Operationen, Datenverwaltung oder Dateioperationen mit einzeiligen Befehlen abwickeln.

## Wo es eingesetzt wird

Es wird in fast allen Programmiersprachen und Betriebssystementwicklungen verwendet.

## Häufig verwechselt mit

Es kann mit Framework oder SDK verwechselt werden, aber Kernbibliotheken beziehen sich auf die Grundfunktionalität und Frameworks auf ein breiteres Anwendungsgerüst.

## Häufige Fragen

**Warum sind Kernbibliotheken wichtig?**

Es beschleunigt den Softwareentwicklungsprozess, reduziert Fehler und sorgt für einen stabileren Codebetrieb.
