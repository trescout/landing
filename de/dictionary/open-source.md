# Was ist Open Source?

Dabei handelt es sich um Software, deren Quellcodes für jedermann zugänglich und entwicklungsfähig sind.

## Definition
Unter Open Source versteht man die gemeinsame Nutzung des Quellcodes einer Software auf eine Weise, die es jedem ermöglicht, sie zu prüfen, zu ändern und zu verbreiten. Dieser Ansatz stellt sicher, dass die Software von der Community transparent entwickelt und weiterentwickelt wird.

## So funktioniert es
Entwickler teilen ihren Code auf Plattformen wie GitHub. Freiwillige Entwickler aus der ganzen Welt arbeiten an diesem Code, beheben Fehler und fügen neue Funktionen hinzu.

## Wo es eingesetzt wird
Es ist der Kern moderner Technologie, von Betriebssystemen (wie Linux) bis hin zu Modellen der künstlichen Intelligenz. Unternehmen entscheiden sich oft dafür, Kosten zu senken und Vertrauen zu schaffen.

## Häufig verwechselt mit
Es wird mit freier Software verwechselt, aber Open-Source-Code ist kostenlos, frei zu sein ist ein Nebeneffekt.

## Häufige Fragen
**Ist Open Source sicher?**
Ja, weil Tausende von Augen den Code untersuchen, werden Schwachstellen oft schneller gefunden und geschlossen als bei Closed-Source-Software.

**Kann jemand den Code ändern?**
Ja, aber die Aufnahme von Änderungen in das Hauptprojekt hängt in der Regel von der Zustimmung der Projektleiter ab.
