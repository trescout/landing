# Was ist API Gateway?

*Glossar · Dev · Zuletzt aktualisiert: 17. Juni 2026*

Es handelt sich um ein zentrales Eingangstor, das alle Anfragen von außen entgegennimmt, sie an die richtigen Orte leitet und Sicherheitskontrollen durchführt.

## Definition

Moderne Anwendungen bestehen aus vielen verschiedenen Teilen. API Gateway ist wie ein Verkehrspolizist, der vor all diesen Teilen steht. Es nimmt die eingehende Anfrage entgegen, prüft den Absender und leitet sie an den entsprechenden Dienst weiter.

***Analogie:** Es ist wie der Empfang eines großen Unternehmens; Alle Besucher kommen zuerst hierher, ihre Registrierung erfolgt und es wird festgelegt, in welche Abteilung sie gehen.*

## So funktioniert es

Es überwacht den eingehenden Datenverkehr, sorgt für Sicherheit, schränkt Anfragen bei Bedarf ein und gibt die Ergebnisse an den Benutzer zurück.

## Wo es eingesetzt wird

Es wird in großen Softwaresystemen mit Microservice-Architektur eingesetzt.

## Häufig verwechselt mit

Es ist nicht nur ein Router; Darüber hinaus übernimmt es Sicherheits- und Verwaltungsaufgaben.

## Häufige Fragen

**Warum ist das nötig?**

Anstatt jeden Dienst einzeln für die Außenwelt zu öffnen, sorgt die Verwaltung von einem einzigen Punkt aus für Sicherheit und Ordnung.
