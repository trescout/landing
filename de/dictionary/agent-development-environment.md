# Was ist Agent Development Environment?

Dabei handelt es sich um eine spezialisierte Softwareentwicklungsumgebung zum Erstellen, Testen und Verwalten von Assistenten für künstliche Intelligenz.

## Definition
Die Entwicklung von KI-Agenten ist etwas komplizierter als die Entwicklung normaler Software, da Sie die Entscheidungsprozesse der Agenten überwachen müssen. In diesen Umgebungen können Sie sehen, wie Agenten denken und ihre Fehler korrigieren.

## So funktioniert es
In dieser Umgebung legen Entwickler fest, auf welche Informationen der Agent zugreifen und welche Tools er verwenden kann. Anschließend verfolgen sie die Entscheidungen des Agenten Schritt für Schritt, erkennen logische Fehler oder Fehlleitungen und nehmen Verbesserungen vor.

## Wo es eingesetzt wird
Es wird in Softwareprojekten mit Schwerpunkt auf künstlicher Intelligenz und auf den Computern von Teams verwendet, die agentenbasierte Systeme entwickeln.

## Häufig verwechselt mit
Nicht zu verwechseln mit Standard-Texteditoren, die lediglich Code schreiben. Hier gibt es auch Tools, um den „Denkprozess“ des Agenten zu überwachen.

## Häufige Fragen
**Warum ist eine besondere Umgebung erforderlich?**
Weil Agenten der künstlichen Intelligenz manchmal unerwartete Entscheidungen treffen können; Diese Umgebungen ermöglichen es uns, den Grund für diese Entscheidungen zu verstehen.
