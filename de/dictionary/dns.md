# Was ist DNS?

*Entwicklung · Zuletzt aktualisiert: 23. Oktober 2026*

> Domain Name System

Es ist ein globales Verzeichnissystem, das Internet-Domainnamen in numerische IP-Adressen übersetzt, damit Computer sich gegenseitig finden können.

## Definition

Das Domain Name System (DNS) ist ein Netzwerkprotokoll, das die Verwendung aussagekräftiger Website-Namen anstelle komplexer IP-Adressen ermöglicht, die sich Menschen nur schwer merken könnten. Wenn Sie eine Adresse in Ihren Browser eingeben, greifen DNS-Server ein, um diesen Namen der IP-Adresse des jeweiligen Servers zuzuordnen. Als einer der grundlegenden Infrastrukturpfeiler des Internets gewährleistet es eine unterbrechungsfreie Kommunikation.

***Analogie:** Dies ist vergleichbar damit, den Namen einer Person in einem Telefonbuch nachzuschlagen, um ihre Nummer zu finden und den Anruf über diese Nummer zu tätigen.*

## So funktioniert es

Wenn ein Benutzer einen Domainnamen in den Browser eingibt, wird die Anfrage zunächst an den lokalen DNS-Cache und anschließend schrittweise an die autoritativen DNS-Server weitergeleitet. Sobald die richtige IP-Adresse gefunden ist, wird sie an den Browser zurückgegeben und die Verbindung hergestellt. Dieser Abfragevorgang ist in der Regel innerhalb von Millisekunden abgeschlossen.

## Wo es eingesetzt wird

Es wird beim Zugriff auf Webseiten, in E-Mail-Übertragungsinfrastrukturen und bei Weiterleitungen zwischen Cloud-Servern verwendet.

## Häufig verwechselt mit

Es wird oft mit dem Konzept der IP-Adresse verwechselt. Die IP-Adresse ist die tatsächliche numerische Identität des Geräts, während das DNS das System ist, das diese Identität mit für Menschen lesbaren Namen verknüpft.

## Fragen und Antworten

**Kann man bei einem DNS-Ausfall noch auf das Internet zugreifen?**

Domainnamen können nicht aufgelöst werden, aber wenn die direkten IP-Adressen der Websites bekannt sind, kann über den Browser darauf zugegriffen werden.

**Was ist ein DNS-Cache?**

Es ist die temporäre Speicherung der IP-Adressen häufig besuchter Websites auf dem Gerät, wodurch die Notwendigkeit entfällt, jedes Mal beim Server nachzufragen.
