# Was ist Godot Engine?

Es handelt sich um eine völlig kostenlose Open-Source-Softwareplattform für die Spieleentwicklung.

## Definition
Godot Engine ist eine leistungsstarke Spiele-Engine, mit der Sie sowohl 2D- als auch 3D-Spiele erstellen können. Mit seiner benutzerfreundlichen Oberfläche und seiner eigenen proprietären Programmiersprache ist es bei Neulingen in der Welt der Spieleentwicklung sehr beliebt. Dank seines Open-Source-Charakters bietet es eine kostenlose Entwicklungsumgebung, in der jeder einen Beitrag leisten kann.

## So funktioniert es
Benutzer platzieren Objekte in der Szene, codieren die Bewegungen der Charaktere und legen die Spielregeln fest. Die Engine verwandelt all diese Designs in Software, die der Spieler spielen kann.

## Wo es eingesetzt wird
Es wird von unabhängigen Spieleentwicklern in PC-, Konsolen- und Mobilspielprojekten verwendet.

## Häufig verwechselt mit
Im Gegensatz zu anderen kommerziellen Spiele-Engines ist sie völlig kostenlos und es fallen keine Lizenzgebühren an.

## Häufige Fragen
**Muss ich Code kennen?**
Das Erlernen der grundlegenden Codelogik erleichtert Ihre Arbeit erheblich, aber dank visueller Tools können Sie viele Dinge auch ohne Code erledigen.

**Welche Art von Spielen können gemacht werden?**
Sie können alles entwickeln, von einfachen Puzzlespielen bis hin zu komplexen 3D-Abenteuerspielen.
