# Was ist Unit Testing?

Dabei handelt es sich um eine Testmethode, die überprüft, ob kleinste Teile der Software selbstständig korrekt funktionieren.

## Definition
Dabei handelt es sich um die grundlegenden Tests, die durchgeführt werden, um sicherzustellen, dass jede Funktion oder Methode bei der Entwicklung von Software fehlerfrei funktioniert. Man kann es sich so vorstellen, als würde man die Teile eines großen Puzzles einzeln prüfen. Sind Kleinteile intakt, erhöht sich die Zuverlässigkeit des Gesamtsystems.

## So funktioniert es
Entwickler schreiben für jeden Codeabschnitt spezifische Testszenarien. Diese Szenarien prüfen automatisch, ob der Code die erwartete Ausgabe zur erwarteten Eingabe liefert. Schlägt der Test fehl, ist sofort klar, um welches Kleinteil es sich handelt.

## Wo es eingesetzt wird
Es wird ganz am Anfang des Softwareentwicklungsprozesses verwendet, während der Code geschrieben wird oder unmittelbar nachdem er geschrieben wurde.

## Häufig verwechselt mit
Es kann mit End-to-End-Tests verwechselt werden; Während das gesamte System getestet wird, konzentriert sich der Unit-Test auf nur einen Teil.

## Häufige Fragen
**Warum sollte ich jedes Teil testen?**
Um Fehler sehr früh zu erkennen und größere Probleme zu verhindern, die später im gesamten System auftreten.

**Geschieht das automatisch?**
Ja, es wird normalerweise vom Entwickler mithilfe von Testtools automatisiert.
