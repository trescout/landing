# Was ist IaaS?

> Infrastructure as a Service

Dabei handelt es sich um die Vermietung grundlegender Hardware-Ressourcen wie virtuelle Server und Speicherplatz über das Internet.

## Definition
Wenn Ihr Computer keinen Strom mehr hat oder Sie einen Server benötigen, mieten Sie einen Teil der riesigen Rechenzentren riesiger Unternehmen (wie Amazon, Microsoft). Bei diesem Modell installieren Sie das Betriebssystem und die Software und sie sind für die Hardware verantwortlich.

## So funktioniert es
Virtuelle Computer werden über ein Panel über das Internet erstellt und verwaltet.

## Wo es eingesetzt wird
Es wird bei Cloud-Anbietern wie AWS, Azure und Google Cloud eingesetzt.

## Häufig verwechselt mit
Kann mit PaaS verwechselt werden; IaaS stellt die grundlegende Hardware bereit, während PaaS eine fertige Betriebsumgebung bereitstellt.

## Häufige Fragen
**Ist IaaS sicher?**
Ja, aber Sie sind für die Sicherheit des Betriebssystems und der Software verantwortlich.
