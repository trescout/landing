# Was ist Bundler?

Es handelt sich um ein Tool, das mehrere Dateien in einem Softwareprojekt kombiniert und optimiert und sie in eine einzige Struktur umwandelt, die von Browsern ausgeführt werden kann.

## Definition
Moderne Webprojekte bestehen aus Hunderten kleiner Dateien. Es fällt Browsern schwer, so viele Dateien einzeln herunterzuladen. Bundler nimmt diese Dateien, verknüpft sie miteinander und verbessert die Leistung durch Bereinigen unnötiger Teile.

## So funktioniert es
Während der Entwicklungsphase arbeiten Sie mit Dateien einzeln. Wenn Sie das Projekt veröffentlichen, kommt Bundler ins Spiel und verpackt alle Dateien so, dass der Browser sie verstehen kann.

## Wo es eingesetzt wird
Es ist in JavaScript-basierten Webentwicklungsprojekten unverzichtbar.

## Häufig verwechselt mit
Kann mit Compiler gemischt werden; Der Compiler übersetzt den Code in eine andere Sprache, der Bundler fügt die Dateien zusammen.

## Häufige Fragen
**Warum packen wir nicht alles in eine Datei?**
Sehr große Dateien können den Browser verlangsamen; Daher teilt der Bundler Dateien manchmal in intelligente Teile auf.
