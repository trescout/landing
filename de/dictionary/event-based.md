# Was ist Event-based?

*Entwicklung · Zuletzt aktualisiert: 17. November 2026*

Eine Architektur, die auf dem Prinzip basiert, dass das System ausgelöst wird und arbeitet, wenn ein bestimmter Zustand oder eine bestimmte Aktion eintritt.

## Definition

Dies ist einer der Ansätze in der Softwarewelt, der bestimmt, wie Abläufe im Hintergrund ablaufen. Im Gegensatz zur klassischen Methode wartet das System nicht in einer Schlaufe, sondern funktioniert wie eine Klingel, die Bescheid gibt, sobald etwas passiert. Wenn beispielsweise ein Benutzer auf eine Schaltfläche drückt, erwacht das System zum Leben und erledigt die erforderliche Arbeit.

***Analogie:** Es ist vergleichbar damit, dass die Klingel im Inneren ertönt, wenn auf die Türklingel gedrückt wird; das System wartet still, bis Sie drücken, und wird in dem Moment aktiv, in dem gedrückt wird.*

## So funktioniert es

Bei der Einrichtung dieser Struktur definieren Entwickler Trigger, die auf bestimmte Ereignisse lauschen. Wenn Daten eintreffen oder ein Prozess abgeschlossen ist, wird die entsprechende Funktion automatisch aufgerufen.

## Wo es eingesetzt wird

Es wird häufig in modernen Webanwendungen, Instant-Messaging-Diensten und Hintergrund-Datenströmen verwendet.

## Häufig verwechselt mit

Es kann mit kontinuierlich laufenden und schleifenbasierten Strukturen verwechselt werden; hier gibt es keine ständige Überprüfung, sondern es wird nur dann reagiert, wenn ein Ereignis eintritt.

## Fragen und Antworten

**Warum wird es bevorzugt?**

Es ist äußerst effizient, da es keine Ressourcen verschwendet und nur dann arbeitet, wenn es benötigt wird.
