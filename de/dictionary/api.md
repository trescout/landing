# Was ist API?

> Application Programming Interface

Es handelt sich um eine digitale Brücke, die es zwei verschiedenen Softwareprogrammen ermöglicht, miteinander zu kommunizieren.

## Definition
API ist eine Standardsprache, die es Software ermöglicht, miteinander zu kommunizieren. Es ermöglicht einer Anwendung, ihre Fähigkeiten anderen Anwendungen zur Verfügung zu stellen.

## So funktioniert es
Eine Software sendet eine Anfrage an eine bestimmte Adresse. Andere Software empfängt diese Anfrage, verarbeitet sie und gibt das Ergebnis zurück. Dieser Prozess erfolgt vollständig regelbasiert und automatisch.

## Wo es eingesetzt wird
Es wird für Wetteranwendungen verwendet, um Daten vom Meteorologiezentrum abzurufen oder um über das Internet auf Modelle der künstlichen Intelligenz zuzugreifen.

## Häufig verwechselt mit
Es wird mit der Website selbst verwechselt, aber die API ist dafür konzipiert, dass Maschinen mit Maschinen kommunizieren, nicht mit Menschen.

## Häufige Fragen
**Kann jeder die API nutzen?**
Im Allgemeinen erfolgt der Zugang durch Autorisierung mit einem Schlüssel, es handelt sich also um einen kontrollierten Prozess.

**Warum ist die API sicher?**
Da es nur die Weitergabe zulässiger Daten ermöglicht, öffnet es nur den relevanten Teil des Systems, nicht das gesamte System.
