# Was ist Server-side Rendering?

> SSR

Dabei handelt es sich um eine Methode, mit der Webseiten auf dem Server vorbereitet und schnell angezeigt werden können, bevor sie an den Benutzer gesendet werden.

## Definition
Normalerweise nimmt der Browser die Seite als leeres Feld und füllt es selbst aus. Bei SSR sendet der Server die Seite vollständig fertig an den Browser. Dadurch kann die Seite viel schneller geladen werden und von Suchmaschinen leichter gefunden werden.

## So funktioniert es
Wenn die Benutzeranfrage eintrifft, erstellt der Server die Seite, platziert die Daten darin und sendet die fertige Version.

## Wo es eingesetzt wird
Es wird auf E-Commerce-Websites und allen Webprojekten verwendet, bei denen SEO wichtig ist.

## Häufig verwechselt mit
Kann mit clientseitigem Rendering verwechselt werden; Auf der Clientseite wird die meiste Arbeit im Browser erledigt, und auf der SSR-Seite wird die meiste Arbeit auf dem Server erledigt.

## Häufige Fragen
**Warum verwendet nicht jede Website SSR?**
Es erhöht die Serverlast und ist komplexer zu installieren; Es ist möglicherweise nicht für jedes Projekt erforderlich.
