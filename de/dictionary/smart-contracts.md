# Was ist Smart Contracts?

Dabei handelt es sich um digitale Verträge, die bei Erfüllung bestimmter Bedingungen automatisch funktionieren und keinen Vermittler erfordern.

## Definition
Bei herkömmlichen Verträgen muss ein Vermittler, beispielsweise ein Anwalt oder eine Bank, prüfen, ob sich jemand an die Regeln hält. Smart Contracts hingegen werden in Code geschrieben und die Transaktion wird automatisch abgeschlossen, wenn die Bedingungen erfüllt sind (z. B. wenn eine Zahlung erfolgt). Diese Codes sind unveränderlich und transparent.

## So funktioniert es
Dabei handelt es sich um Codeteile, die in Blockchain-Netzwerken ausgeführt werden. Die vorgegebenen Regeln werden vom Netzwerk kodiert, verifiziert und automatisch ausgeführt.

## Wo es eingesetzt wird
Es wird bei Finanztransaktionen, Eigentumsübertragungen und der Verwaltung digitaler Vermögenswerte eingesetzt.

## Häufig verwechselt mit
Es kann mit einer einfachen digitalen Signatur verwechselt werden, aber Smart Contracts enthalten eine Transaktionslogik.

## Häufige Fragen
**Kann es geändert werden?**
Nein, sobald sie in die Blockchain hochgeladen wurden, können sie nicht mehr geändert werden.

**Ist es sicher?**
Der Code muss fehlerfrei geschrieben sein; Falsche Codes können zu Schwachstellen führen.
