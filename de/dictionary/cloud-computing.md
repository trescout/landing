# Was ist Cloud Computing?

Dabei handelt es sich um die Bereitstellung von Computerdiensten über Remote-Server über das Internet.

## Definition
Damit können Sie Transaktionen nicht auf Ihrem eigenen Computer, sondern auf leistungsstarken Servern am anderen Ende des Internets durchführen. Auf diese Weise können Sie auch bei geringer Hardwarekapazität große Datenmengen verarbeiten oder Anwendungen ausführen. Dabei handelt es sich um eine Art digitalen Mietlager- und Rechenleistungsdienst.

## So funktioniert es
Sie laden Ihre Anwendungen oder Daten auf Remote-Server hoch, auf die über das Internet zugegriffen werden kann. Der Dienstleister verwaltet diese Infrastruktur und Sie konzentrieren sich nur auf Ihre Software oder Daten.

## Wo es eingesetzt wird
Es wird beim Hosten von Websites, Big-Data-Analysen und Backup-Systemen verwendet.

## Häufig verwechselt mit
Es kann mit Internetspeicher verwechselt werden, aber es handelt sich nicht nur um Speicher, sondern auch um einen Rechenleistungsdienst.

## Häufige Fragen
**Warum benutze ich nicht meinen eigenen Computer?**
Denn es erspart Ihnen die enormen Hardwarekosten, die für professionelles Arbeiten erforderlich sind, und ermöglicht den Zugriff von überall.

**Ist es sicher?**
Bei richtiger Konfiguration ist es im Allgemeinen sicherer als Personalcomputer.
