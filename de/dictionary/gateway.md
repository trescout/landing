# Was ist Gateway?

Es handelt sich um den Port, der den Datenverkehr zwischen verschiedenen Netzwerken verwaltet und weiterleitet.

## Definition
Es ist wie eine Brücke, die es zwei verschiedenen Netzwerken ermöglicht, miteinander zu kommunizieren. Beispielsweise ist das Gerät, das das Internet in Ihrem Zuhause mit dem Internet in der Außenwelt verbindet, ein Gateway. Es prüft, ob die Daten an die richtige Adresse gelangen.

## So funktioniert es
Es untersucht die eingehenden Daten, entscheidet, an welches Netzwerk sie weitergeleitet werden sollen, und leitet den Datenverkehr.

## Wo es eingesetzt wird
Man findet es in Heimmodems, Unternehmensnetzwerk-Ports und Cloud-Systemen.

## Häufig verwechselt mit
Kann mit API Gateway verwechselt werden; Während API Gateway Dienste in der Softwarewelt verwaltet, arbeitet das Gateway auf physischer oder Netzwerkebene.

## Häufige Fragen
**Kann ich ohne Gateway auf das Internet zugreifen?**
Nein, Ihr lokales Netzwerk kann keine Verbindung zur Außenwelt herstellen und bleibt isoliert.
