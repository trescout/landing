# Was ist Agent Skills Tool?

*Glossar · AI · Zuletzt aktualisiert: 14. Oktober 2026*

Ein Werkzeug, mit dem KI-Agenten neue Funktionen und Fähigkeiten verliehen werden.

## Definition

KI-Agenten benötigen genau wie Menschen, die einen neuen Beruf erlernen, unterschiedliche Fähigkeiten. Dieses Tool sorgt dafür, dass Agenten nachträglich zum System hinzugefügte Fertigkeiten sicher erlernen und anwenden können.

***Analogie:** Das ist so, als würde man einem sehr talentierten Koch ein neues Küchengerät oder ein Rezeptbuch schenken.*

## So funktioniert es

Es funktioniert, indem der Hauptstruktur des Agenten von außen Module hinzugefügt werden. Die benötigte Fähigkeit wird über den entsprechenden Befehl aufgerufen.

## Wo es eingesetzt wird

Es wird bei der Entwicklung intelligentere Agenten und in modularen KI-Anwendungen eingesetzt.

## Häufig verwechselt mit

Im Gegensatz zu allgemeinen Agentenstrukturen ist es ein spezifischer Helfer, der direkt auf die Vermittlung von Fähigkeiten ausgerichtet ist.

## Häufige Fragen

**Wozu dient es?**

Es erhöht die Kapazität von KI-Agenten.
