# Was ist User Identifiers?

Dabei handelt es sich um eindeutige Identitätsmarker, mit denen jeder Benutzer in digitalen Systemen unterschieden werden kann.

## Definition
Hierbei handelt es sich um spezielle Codes oder Benutzernamen, die dem System zugewiesen werden, um Sie bei der Eingabe einer Bewerbung zu erkennen. Dank dieser Kennungen kann das System Ihre vergangenen Transaktionen, Einstellungen und Daten gezielt für Sie darstellen, ohne diese zu vermischen. Sie können es sich wie Ihre Mitgliedsnummer in einer Bibliothek vorstellen.

## So funktioniert es
Wenn Sie sich im System registrieren oder anmelden, wird es automatisch im Hintergrund erstellt und in der Datenbank mit Ihnen abgeglichen.

## Wo es eingesetzt wird
Es wird zur Benutzerverfolgung auf Websites, mobilen Anwendungen und Unternehmenssoftware verwendet.

## Häufig verwechselt mit
Es kann mit einem Benutzernamen verwechselt werden, es handelt sich jedoch um eine technischere und allgemeinere Struktur, die es dem System ermöglicht, Sie zu erkennen.

## Häufige Fragen
**Warum erhalte ich für jedes System eine andere ID?**
Zu Ihrer Sicherheit; Wenn Sie Ihre Identität nicht in einem System in einem anderen System verwenden, sind Ihre Daten sicherer.
