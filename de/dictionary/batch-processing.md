# Was ist Batch Processing?

Dabei handelt es sich um die automatische Ausführung vieler Vorgänge im Hintergrund als Gruppe und nicht einzeln.

## Definition
Die Stapelverarbeitung ist eine von Computersystemen verwendete Methode zur effizienten Verwaltung intensiver Arbeitslasten. Anstatt sofort verarbeitet zu werden, werden Transaktionen in einer Warteschlange gesammelt und alle auf einmal zu einem geeigneten Zeitpunkt verarbeitet. Auf diese Weise werden die Systemressourcen gleichmäßiger genutzt.

## So funktioniert es
Das System sammelt eingehende Daten in einem Ordner oder einer Datenbank. Wenn die festgelegte Zeit erreicht ist oder die Warteschlange voll ist, empfängt und verarbeitet eine Software diese Daten nacheinander. Der Benutzer sieht nicht, dass diese Vorgänge im Hintergrund ausgeführt werden.

## Wo es eingesetzt wird
Es wird beim Training von Modellen der künstlichen Intelligenz, bei der Big-Data-Analyse, bei Gehaltszahlungssystemen und beim E-Mail-Versand eingesetzt.

## Häufig verwechselt mit
Kann mit Echtzeitverarbeitung verwechselt werden; Die Echtzeitverarbeitung reagiert sofort, während die Stapelverarbeitung wartet.

## Häufige Fragen
**Warum führen wir eine Massenverarbeitung durch?**
Dies ist eine effizientere Methode, um eine Überlastung des Systems zu vermeiden und die Kosten zu senken.

**Wie hoch ist die Fehlerquote?**
Wenn innerhalb einer Gruppe ein Fehler auftritt, meldet das System normalerweise, welche Daten den Fehler verursacht haben, und verarbeitet den Rest weiter.
