# Was ist Parser?

Dabei handelt es sich um einen Parser, der komplexe Daten oder Code in sinnvolle Teile zerlegt, die der Computer Schritt für Schritt verarbeiten kann.

## Definition
Ein Parser nimmt einen Text- oder Datenblock und wandelt ihn in eine Struktur um, die das Programm logisch verstehen kann. Es funktioniert beispielsweise wie ein Interpreter, der es dem Computer ermöglicht, eine einfache Codezeile, die Sie schreiben, als „hier ist eine Variable, hier wird eine Operation ausgeführt“ zu verstehen. Durch die Aufteilung der Daten in Teile wird eine Baumstruktur erstellt.

## So funktioniert es
Es verwendet Rohdaten als Eingabe, scannt diese Daten gemäß den Regeln der Sprache oder des Formats und erstellt schließlich ein Datenmodell oder eine Baumstruktur. Wenn sich in den Daten ein Tippfehler befindet, bemerkt der Parser ihn sofort.

## Wo es eingesetzt wird
Es wird in Compilern zum Lesen von HTML in Webbrowsern und in jeder Software verwendet, die Datenformate (JSON, XML) verarbeitet.

## Häufig verwechselt mit
Es kann mit dem Parsen von Dokumenten verwechselt werden. Parser ist jedoch ein allgemeineres Konzept und wird für alle Arten von Datenstrukturen verwendet.

## Häufige Fragen
**Was passiert, wenn der Parser einen Fehler ausgibt?**
Wenn der Parser die Daten in einem Format findet, das er nicht verstehen kann, gibt er einen „Syntaxfehler“ aus und verhindert, dass der Prozess fortgesetzt wird.
