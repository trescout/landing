# Was ist Continuous Deployment?

> CD

Codes, die den Test bestehen, werden automatisch und ohne menschliches Eingreifen in Betrieb genommen.

## Definition
Es handelt sich um eine Methode, die den Softwareentwicklungsprozess beschleunigt. Sobald Sie Ihren Code schreiben, durchläuft er automatische Tests und wird, wenn keine Hindernisse vorliegen, direkt in das von den Benutzern verwendete System hochgeladen. Es stellt sicher, dass die Software ständig aktualisiert wird, indem manuelle Genehmigungsprozesse entfallen.

## So funktioniert es
Der Entwickler übermittelt den Code an das System, das System führt automatisierte Tests durch und bei Erfolg wird der Code an den Live-Server übertragen.

## Wo es eingesetzt wird
Moderne Webanwendungen, SaaS-Plattformen und digitale Produkte, die schnelle Updates erfordern.

## Häufig verwechselt mit
Kann mit Continuous Delivery verwechselt werden; Bei der Bereitstellung erfordert die Go-Live-Phase möglicherweise eine manuelle Genehmigung, während sie bei der Bereitstellung vollständig automatisch erfolgt.

## Häufige Fragen
**Was passiert, wenn wir einen Fehler machen?**
Das System versucht dank automatischer Tests, den Fehler zu erkennen, bevor es in Betrieb geht, birgt aber dennoch Risiken; Daher müssen die Tests sehr robust sein.
