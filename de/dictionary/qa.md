# Was ist QA?

> Quality Assurance

Dabei wird sichergestellt, dass eine Software den festgelegten Standards entspricht, fehlerfrei und von hoher Qualität ist, bevor sie den Benutzer erreicht.

## Definition
Qualitätssicherung (QA) ist eine Reihe von Tests und Prüfungen, die am Ende oder während des Softwareentwicklungsprozesses durchgeführt werden. Sein Zweck besteht darin, Fehler, auf die der Benutzer stoßen könnte, im Voraus zu erkennen und zu beheben. Ein guter QA-Prozess erhöht die Zuverlässigkeit des Produkts und sorgt für die Zufriedenheit der Benutzer.

## So funktioniert es
Definieren Sie zunächst das erwartete Verhalten der Software und überprüfen Sie dieses Verhalten mit manuellen oder automatisierten Tests. Erstellen Sie Testszenarien und prüfen Sie bei jedem Update der Software, ob diese Szenarien funktionieren.

## Wo es eingesetzt wird
Es wird in jeder Phase des Softwareentwicklungslebenszyklus verwendet, insbesondere bei Endkontrollen vor der Veröffentlichung.

## Häufige Fragen
**Sind Qualitätssicherung und Tests dasselbe?**
Beim Testen geht es darum, Fehler zu finden, während sich die Qualitätssicherung auf die Einrichtung von Prozessen konzentriert, die das Auftreten von Fehlern verhindern.

**Wie erfolgt die Qualitätssicherung in Projekten zur künstlichen Intelligenz?**
Dazu werden die Ausgaben des Modells überprüft, Halluzinationen getestet und überprüft, wie das System auf verschiedene Eingaben reagiert.
