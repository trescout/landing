# Was ist Assets?

Es ist die Gesamtheit aller digitalen Teile, die ein Projekt ausmachen.

## Definition
Alle externen Ressourcen, die Sie bei der Entwicklung von Software oder Spielen verwenden, werden als „Assets“ bezeichnet. Hierbei handelt es sich nicht um den Code selbst, sondern um die Hilfsmaterialien, die der Code benötigt. Sie sind das visuelle, akustische oder strukturelle Rohmaterial eines Projekts.

## So funktioniert es
Sie werden in separaten Ordnern in Ihren Projektdateien gespeichert und Sie rufen sie auf, indem Sie beim Schreiben von Code auf diese Dateien verweisen.

## Wo es eingesetzt wird
Es wird in allen Spieleentwicklungs-, Webdesign- und mobilen Anwendungsprojekten verwendet.

## Häufige Fragen
**Werden Codedateien als Vermögenswerte betrachtet?**
Im Allgemeinen nein, obwohl Code als Hauptstruktur betrachtet wird; Bilder, Töne und 3D-Modelle werden als Vermögenswerte klassifiziert.
