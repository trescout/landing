# Was ist GUI?

*Glossar · Dev · Zuletzt aktualisiert: 5. Juli 2026*

> Graphical User Interface

Es handelt sich um eine Schnittstelle, die es Ihnen ermöglicht, Computerprogramme visuell mit Symbolen, Menüs und Fenstern zu verwalten, anstatt Text einzugeben.

## Definition

GUI ist die visuelle Ebene, die Technologie für jedermann zugänglich macht. Es ermöglicht jemandem, der nicht weiß, wie man programmiert, den Computer per Mausklick zu steuern. Es ist der Grundstein moderner Betriebssysteme.

***Analogie:** Anstelle eines Kochs (Code), der komplexe Gerichte in der Küche eines Restaurants kocht, ist er wie ein Kellner und eine Menükarte, die es Ihnen ermöglicht, aus dem Menü auszuwählen und zu bestellen.*

## So funktioniert es

Jede Schaltfläche, jedes Fenster und jedes Symbol, die Sie auf Ihrem Bildschirm sehen, ist ein GUI-Element. Wenn Sie auf eine Schaltfläche klicken, erhalten im Hintergrund laufende Codes diesen visuellen Befehl und starten den entsprechenden Prozess.

## Wo es eingesetzt wird

Es ist in Smartphones, Computer-Betriebssystemen und jeder von Ihnen verwendeten mobilen App zu finden.

## Häufig verwechselt mit

Im Gegensatz zu CLI (Command Line Interface); Im CLI wird nur Text geschrieben, während im GUI die Visualität im Vordergrund steht.

## Häufige Fragen

**Hat jede Software eine GUI?**

Nein, einige professionelle Tools funktionieren nur textbasiert (CLI).

**Beeinflusst die grafische Benutzeroberfläche die Leistung?**

Das Zeichnen visueller Elemente erfordert Rechenleistung, daher werden auf sehr einfachen Systemen manchmal textbasierte Schnittstellen bevorzugt.
