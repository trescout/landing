# Was ist ORM?

> Object-Relational Mapping

Es handelt sich um eine Brücke, die Datenbanktabellen in Objekte im Code umwandelt.

## Definition
Es ermöglicht Ihnen, diese Daten wie Objekte in einer Programmiersprache zu verwenden, anstatt sich bei der Entwicklung von Software mit komplexen Tabellen in der Datenbank herumschlagen zu müssen. Auf diese Weise können Sie Daten verwalten, ohne komplexe Abfragen wie SQL schreiben zu müssen. Dadurch wird Ihr Code lesbarer und verwaltbarer.

## So funktioniert es
Es fungiert als Schicht zwischen der Datenbank und dem Anwendungscode. Wenn Sie Daten in Ihrem Code speichern, wird dieser Vorgang im Hintergrund in die entsprechende SQL-Abfrage übersetzt. Selbst wenn sich die Datenbankstruktur ändert, müssen Sie Ihren Code auf diese Weise nur geringfügig ändern.

## Wo es eingesetzt wird
Es wird häufig in Webanwendungen, Unternehmenssoftware und datenbankintensiven Projekten verwendet.

## Häufig verwechselt mit
Es kann zu einer Verwechslung mit dem Datenbanktreiber kommen. Der Treiber stellt die Rohverbindung bereit, während das ORM diese Verbindung ermöglicht.

## Häufige Fragen
**Warum sollte ich ORM verwenden?**
Es beschleunigt Datenbankvorgänge und reduziert Codefehler.

**Reduziert es die Leistung?**
Bei sehr komplexen Abfragen kann manuelles SQL manchmal schneller sein, aber in den meisten Fällen lohnt sich der Komfort.
