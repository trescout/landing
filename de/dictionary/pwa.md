# Was ist PWA?

> Progressive Web App

Hierbei handelt es sich um Webseiten, die über einen Internetbrowser funktionieren, aber wie eine Anwendung auf Ihrem Telefon oder Computer installiert werden können.

## Definition
Die PWA-Technologie stellt Websites anwendungsähnliche Funktionen bereit. Sie haben die Möglichkeit, offline zu arbeiten, Benachrichtigungen zu senden und auf die Hardware des Geräts zuzugreifen. Es kann direkt aus dem Browser installiert werden, ohne dass ein zusätzlicher App Store erforderlich ist.

## So funktioniert es
Entwickeln Sie eine Website und fügen Sie ihr eine kleine Hintergrunddatei namens „Service Worker“ hinzu. Wenn der Benutzer Ihre Website besucht, kann er die Anwendung installieren, indem er im Browser auf „Zum Startbildschirm hinzufügen“ klickt.

## Wo es eingesetzt wird
Es wird häufig in Nachrichtenseiten, E-Commerce-Plattformen und einfachen Widget-Anwendungen verwendet.

## Häufig verwechselt mit
Nicht zu verwechseln mit nativen Apps; PWA ist eigentlich eine Website.

## Häufige Fragen
**Wird es aus dem App Store heruntergeladen?**
Nein, es wird direkt über den Browser geladen.

**Funktioniert es, wenn ich kein Internet habe?**
Ja, dank der Caching-Funktion funktionieren Grundfunktionen auch dann, wenn kein Internet vorhanden ist.
