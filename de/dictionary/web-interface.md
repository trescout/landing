# Was ist Web Interface?

Dabei handelt es sich um eine visuelle Schnittstelle, die es Ihnen ermöglicht, komplexe Software oder Modelle künstlicher Intelligenz einfach über Ihren Internetbrowser zu verwalten.

## Definition
Software kann manchmal nur aus Codezeilen bestehen und ist schwierig zu verwenden. Über die Weboberfläche können Sie die Leistung dieser Codes über Schaltflächen, Menüs und Felder nutzen. Der normale Bildschirm, den Sie sehen, wenn Sie Ihren Browser öffnen und eine Adresse eingeben, ist eigentlich das Bedienfeld eines riesigen Systems, das im Hintergrund läuft.

## So funktioniert es
Entwickler kombinieren komplexe Prozesse hinter den Kulissen mit einem Website-Design. Wenn Sie auf eine Schaltfläche klicken, führt die Benutzeroberfläche die entsprechenden Befehle im Hintergrund aus und zeigt Ihnen das Ergebnis auf dem Bildschirm an.

## Wo es eingesetzt wird
Es findet sich in Tools für künstliche Intelligenz wie ChatGPT, cloudbasierten Verwaltungspanels und Online-Tools.

## Häufig verwechselt mit
Die Software selbst und ihre Schnittstelle sind nicht dasselbe; Die Schnittstelle ist nur ein Tor.

## Häufige Fragen
**Verfügt jede Software über ein Webinterface?**
Nein, einige funktionieren nur über die Befehlszeile (CLI).

**Benötigt die Weboberfläche Internet?**
Normalerweise ja, da die Verbindung zum Server über den Browser hergestellt wird.
