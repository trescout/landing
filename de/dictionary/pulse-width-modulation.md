# Was ist Pulse-Width Modulation?

*Entwicklung · Zuletzt aktualisiert: 16. November 2026*

> Pulse-Width Modulation

Es handelt sich um eine Signalaufbereitungsmethode, die Leistung und Bildschirmhelligkeit steuert, indem die Spannungsschwankungsdauer digitaler Signale verändert wird.

## Definition

Die Pulsweitenmodulation (PWM) ist eine Technik zur Anpassung der Durchschnittsspannung, indem die Ein- und Ausschaltzeiten eines elektrischen Signals schnell verändert werden. Anstatt den Spannungspegel direkt zu senken, steuern Sie die Leistung, indem Sie sie innerhalb von Millisekunden ein- und ausschalten. Sie wird in vielen Hardwaresystemen häufig eingesetzt, von Bildschirmhelligkeitseinstellungen bis hin zur Motordrehzahlregelung.

***Analogie:** Sie können sich das so vorstellen, als würden Sie Ihren Schalter tausendmal pro Sekunde ein- und ausschalten, um die Lichtstärke einer Lampe zu verringern. Je länger der Schalter eingeschaltet bleibt, desto heller nimmt Ihr Auge das Licht wahr.*

## So funktioniert es

Das Tastverhältnis, das das Verhältnis der Zeit, in der das Signal hoch ist, zur Gesamtperiode darstellt, wird verändert. Wenn das Tastverhältnis 50 % beträgt, wird die Leistung zur Hälfte übertragen. Dank dieses Hochgeschwindigkeitsschaltens wird eine präzise Energieverwaltung ohne Energieverlust erreicht.

## Wo es eingesetzt wird

Sie wird häufig bei der Helligkeitsregelung von OLED- und LCD-Bildschirmen, bei Geschwindigkeitsanpassungen von Kühlgebläsen und bei der Steuerung von Elektromotoren bevorzugt.

## Häufig verwechselt mit

Sie kann mit einer direkten analogen Spannungseinstellung verwechselt werden. PWM senkt den Spannungspegel nicht selbst, sondern steuert die durchschnittliche Leistung, indem es die aktive Dauer der Spannung verändert.

## Fragen und Antworten

**Warum führt PWM bei Bildschirmen zu Augenermüdung?**

PWM-Bildschirme mit einer niedrigen Bildwiederholfrequenz erzeugen ein unauffälliges, schnelles Flackern. Dies kann bei einigen Benutzern zu Augenermüdung und Kopfschmerzen führen.

**Wie wird ein PWM-Signal erzeugt?**

Es wird mithilfe von Mikrocontrollern und speziellen Hardware-Timern über digitale Ausgangspins erzeugt.
