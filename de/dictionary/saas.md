# Was ist SaaS?

> Software as a Service

Es handelt sich um ein Modell, bei dem die Software über das Internet gemietet wird, anstatt sie auf Ihrem Computer zu installieren.

## Definition
Um ein Programm nutzen zu können, musste man früher eine CD kaufen und installieren. Beim SaaS-Modell öffnen Sie einfach Ihren Browser und stellen über das Internet eine Verbindung zur Software her. Alle Wartungs- und Aktualisierungsarbeiten werden von dem Unternehmen durchgeführt, das die Software anbietet.

## So funktioniert es
Die Mitgliedschaft wird erstellt und das System wird über den Internetbrowser angemeldet.

## Wo es eingesetzt wird
Beliebte Plattformen wie Google Workspace, Netflix oder Salesforce folgen diesem Modell.

## Häufig verwechselt mit
Kann mit PaaS verwechselt werden; SaaS ist für den Endbenutzer, PaaS ist für Entwickler.

## Häufige Fragen
**Wo werden meine Daten bei der Nutzung von SaaS gespeichert?**
Ihre Daten werden auf den sicheren Servern des Unternehmens gespeichert, das die Software bereitstellt.
