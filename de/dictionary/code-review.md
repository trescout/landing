# Was ist Code Review?

Dabei untersuchen Softwareentwickler gegenseitig ihre Codes, um Fehler zu finden und die Qualität zu verbessern.

## Definition
Unter Code Review versteht man die Überprüfung des Codes in einem Softwareprojekt durch ein anderes Auge, bevor er in die Hauptstruktur aufgenommen wird. Dieser Prozess ist nicht nur für das Debuggen von entscheidender Bedeutung, sondern auch dafür, dass das Team vom Codierungsstil des anderen lernt und Standards einhält. In der Welt von TreScout ist dies ein Qualitätskontrollfilter, der die Qualität des Codes sicherstellt.

## So funktioniert es
Der Entwickler sendet seinen Code, andere Teammitglieder überprüfen den Code, kommentieren und bitten gegebenenfalls um Korrekturen. Sobald der Code genehmigt ist, wird er dem Hauptprojekt hinzugefügt.

## Wo es eingesetzt wird
Dies ist eine gängige Praxis auf Plattformen wie GitHub, GitLab und in Entwicklungsprozessen für Unternehmenssoftware.

## Häufig verwechselt mit
Im Gegensatz zu automatisierten Tests, die nur testen, ob der Code funktioniert, kommen hier menschliche Logik und Ästhetik ins Spiel.

## Häufige Fragen
**Warum ist es nicht automatisiert?**
Automatisierte Tools können Fehler finden, aber nur Menschen können die Ausrichtung der Codelogik auf die Geschäftsziele vollständig bewerten.

**Ist das nicht Zeitverschwendung?**
Auch wenn es zunächst zeitaufwändig ist, spart es auf lange Sicht erheblich Zeit, da es größere Fehler verhindert, die später auftreten können.
