# Was ist Terminal File Manager?

Ein Tool, mit dem Sie Ihre Dateien nur über die Befehlszeile statt über visuelle Fenster verwalten können.

## Definition
Mit diesen Tools können Sie Dateien mit Tastaturkürzeln kopieren, verschieben oder löschen, ohne Ihre Maus zu verwenden. Es ermöglicht Ihnen eine sehr schnelle Bedienung ohne den Aufwand einer grafischen Benutzeroberfläche.

## So funktioniert es
Sie öffnen das Terminal und führen das Programm aus. Auf dem Bildschirm werden zwei Bedienfelder angezeigt, und Sie können mit den Pfeiltasten der Tastatur zwischen den Dateien navigieren.

## Wo es eingesetzt wird
Es wird bei der Verwaltung von Servern oder in Softwareentwicklungsprozessen verwendet, bei denen Sie Dateien sehr schnell bearbeiten müssen.

## Häufig verwechselt mit
Es sollte nicht mit „Shell“ verwechselt werden, das lediglich Befehle enthält. Dieses Tool bietet eine visuelle Bearbeitungsoberfläche.

## Häufige Fragen
**Ist es schwer zu lernen?**
Anfangs kann es einige Zeit dauern, sich die Tastenkombinationen zu merken, aber sobald man sich daran gewöhnt hat, geht es sehr schnell.

**Funktioniert es auf jedem Betriebssystem?**
Es kommt im Allgemeinen unter Linux und macOS sehr häufig vor.
