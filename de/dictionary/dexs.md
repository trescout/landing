# Was ist DEXs?

> Decentralized Exchanges

Dies sind dezentrale Plattformen, auf denen Benutzer ihre digitalen Vermögenswerte direkt miteinander austauschen können, ohne dass ein Vermittler oder eine Bank erforderlich ist.

## Definition
Bei traditionellen Börsen führen Sie Ihre Transaktionen über die Server eines Unternehmens durch. DEXs hingegen eliminieren dieses Unternehmen und führen die Transaktionen direkt über Smart Contracts auf der Blockchain aus. Auf diese Weise behalten Sie jederzeit die Kontrolle über Ihre Vermögenswerte.

## So funktioniert es
Sie verbinden Ihre digitale Wallet mit der Plattform, wählen den Vermögenswert aus, den Sie tauschen möchten, und sobald die Transaktion bestätigt ist, erfolgt der Tausch automatisch.

## Wo es eingesetzt wird
Sie werden auf Kryptowährungsmärkten, in Projekten des dezentralen Finanzwesens (DeFi) und bei Transaktionen verwendet, bei denen Benutzer Wert auf Privatsphäre legen.

## Häufig verwechselt mit
Sie können mit zentralen Börsen (CEX) verwechselt werden.

## Häufige Fragen
**Muss ich jemandem vertrauen, wenn ich DEXs nutze?**
Nein, Sie müssen nicht einer Person vertrauen, sondern dem Code selbst (Smart Contracts).

**Zahle ich Transaktionsgebühren?**
Ja, es fallen Transaktionsgebühren (Gas Fees) an, die an die Miner oder Validatoren im Netzwerk gezahlt werden.
