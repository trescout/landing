# Was ist DOM?

*Entwicklung · Zuletzt aktualisiert: 19. November 2026*

> Document Object Model

Eine hierarchische Struktur, die es dem Browser ermöglicht, Inhalte auf Webseiten zu verarbeiten und zu verwalten.

## Definition

Das DOM ist das System, das es Websites ermöglicht, im Hintergrund als Baumstruktur im Speicher abgelegt zu werden. Es wandelt HTML-Tags in Objekte um, die von Sprachen wie JavaScript leicht verändert werden können. So können dynamische Ereignisse wie das Ändern der Seite ohne Neuladen beim Drücken einer Schaltfläche stattfinden.

***Analogie:** Es ist wie der architektonische Plan eines Gebäudes. Wenn Sie Änderungen am Strom- oder Wassernetz vornehmen möchten, müssen Sie nicht die Originalwände einreißen, sondern schauen stattdessen auf den Plan, um das entsprechende Ventil oder Kabel zu finden und einzugreifen.*

## So funktioniert es

Sobald der Browser den Code der Website herunterlädt und liest, baut er diese hierarchische Struktur im Speicher auf. Programmierer können beim Schreiben von Code diese Struktur als Ziel verwenden, um Text oder Bilder auf der Seite in Echtzeit zu aktualisieren. Jedes HTML-Tag ist wie ein Zweig oder ein Blatt dieses Baumes positioniert.

## Wo es eingesetzt wird

Es arbeitet kontinuierlich im Hintergrund auf allen modernen Websites und Webanwendungen, die in Webbrowsern ausgeführt werden.

## Häufig verwechselt mit

Es kann mit dem rohen HTML-Code verwechselt werden, der vom Server kommt. Während HTML nur ein Textdokument ist, ist das DOM die vom Browser in ein lebendiges Objekt umgewandelte Version dieses Dokuments.

## Fragen und Antworten

**Gibt es das DOM auf jeder Website?**

Ja, hinter jeder visuellen Seite, die im Browser geöffnet wird, arbeitet diese Struktur definitiv.

**Kann das DOM direkt verändert werden?**

Es ist möglich, diese Struktur mithilfe von JavaScript in Echtzeit zu verändern und die Seite dynamischer zu gestalten.
