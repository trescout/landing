# Was ist Sun Code Conventions?

Eine Reihe von Standards, deren Einhaltung beim Schreiben von Code empfohlen wird und die von dem Unternehmen erstellt wurden, das die Java-Sprache entwickelt hat.

## Definition
Eine Reihe von Standards, deren Einhaltung beim Schreiben von Code empfohlen wird und die von dem Unternehmen erstellt wurden, das die Java-Sprache entwickelt hat.
