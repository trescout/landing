# Was ist Security Scanner?

*Glossar · Dev · Zuletzt aktualisiert: 15. Juni 2026*

Dabei handelt es sich um ein Tool, das automatisch Schwachstellen in Software oder Netzwerksystemen erkennt.

## Definition

Ein Sicherheitsscanner untersucht Ihre digitalen Systeme wie ein Detektiv. Es prüft, ob Sie die Türen oder Fenster Ihres Systems offen gelassen haben und meldet Ihre Schwachstellen gegenüber möglichen Cyber-Angriffen. Diese Tools scannen komplexen Softwarecode oder Netzwerkverkehr, um Fehler zu finden, die das menschliche Auge möglicherweise übersieht.

***Analogie:** Es ist, als ob ein professioneller Sicherheitsexperte alle Türschlösser und Fenster überprüft, bevor er Ihr Zuhause betritt.*

## So funktioniert es

Sie schließen den Scanner an Ihr System an und starten einen Scan. Das Tool vergleicht Dateien oder Netzwerkpakete auf Ihrem System mit bekannten Bedrohungsdatenbanken. Es präsentiert Ihnen eine Liste aller gefundenen verdächtigen Situationen und gibt Ihnen in der Regel Vorschläge, wie Sie die Lücke schließen können.

## Wo es eingesetzt wird

Es wird in Softwareentwicklungsprozessen, Servermanagement und Cybersicherheitsaudits von Unternehmen eingesetzt.

## Häufig verwechselt mit

Es wird für den gleichen Zweck wie das Vulnerability Scanning verwendet, dieser Begriff konzentriert sich jedoch direkt auf das Fahrzeug.

## Häufige Fragen

**Findet der Sicherheitsscanner jede Schwachstelle?**

Nein, es können nur Schwachstellen gefunden werden, die in der Datenbank definiert sind oder bestimmten Mustern entsprechen.

**Verlangsamen diese Tools das System?**

Sie können bei eingehenden Scans Systemressourcen beanspruchen, weshalb sie normalerweise außerhalb der Hauptverkehrszeiten ausgeführt werden.
