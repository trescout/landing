# Was ist Working Memory?

Es handelt sich um den Bereich des Kurzzeitgedächtnisses, in dem künstliche Intelligenz Informationen während der Verarbeitung vorübergehend speichert.

## Definition
Im Arbeitsgedächtnis hält die KI den aktuellen Kontext und die notwendigen Daten aktiv, während sie eine Aufgabe ausführt. Diese Informationen werden normalerweise gelöscht, wenn die Aufgabe abgeschlossen ist oder sich der Kontext ändert.

## So funktioniert es
Dies geschieht, wenn das Modell Eingabedaten und Zwischenergebnisse für einen schnellen Zugriff innerhalb des aktuellen Verarbeitungszyklus in seinem Speicher behält.

## Wo es eingesetzt wird
Es wird zur Aufbewahrung des Chatverlaufs und komplexer Argumentationsprozesse verwendet.

## Häufig verwechselt mit
Der Unterschied zum Langzeitgedächtnis besteht darin, dass es nur auf die aktuelle Aufgabe beschränkt ist.

## Häufige Fragen
**Was passiert, wenn der Arbeitsspeicher voll ist?**
Das Modell beginnt, alte Informationen zu vergessen oder verliert möglicherweise den Kontext.
