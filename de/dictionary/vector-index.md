# Was ist Vector Index?

Dabei handelt es sich um eine Zuordnungsmethode zum schnellen Suchen und Finden numerischer Äquivalente (Vektoren) von Daten.

## Definition
Modelle der künstlichen Intelligenz übersetzen Wörter oder Bilder in Zahlen. Anstatt Millionen von Daten einzeln zu durchsuchen und nach etwas zu suchen, organisieren wir diese Daten in einer speziellen Karte namens „Vektorindex“. Das ist so, als würde man die Bücher in der Bibliothek alphabetisch und kategorisch nach Themen ordnen und nicht in zufälligen Stapeln.

## So funktioniert es
Vektoren, die in einem mehrdimensionalen Raum nahe beieinander liegen (in ihrer Bedeutung ähnlich sind), werden in derselben Region platziert. Wenn eine Suche durchgeführt wird, gibt das System das Ergebnis zurück, indem es nur diese Region betrachtet.

## Wo es eingesetzt wird
Es wird in RAG-Systemen, Empfehlungs-Engines und großen Datenbanken verwendet.

## Häufig verwechselt mit
Kann mit Vector Database verwechselt werden; Vector Database ist ein Repository und Vector Index ist das Suchsystem innerhalb dieses Repositorys.

## Häufige Fragen
**Warum ist der Index wichtig?**
Ohne Index müssen Sie bei jeder Suche alle Daten durchsuchen, was sehr langsam ist.

**Was bedeuten Vektoren?**
Vektoren sind mathematische Koordinaten von Daten, die vom Computer verstanden werden.
