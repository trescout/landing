# Was ist Workflows?

Workflow (auf Deutsch Arbeitsablauf) ist eine geordnete Abfolge von Arbeitsschritten.

## Definition und Wortherkunft
Flow bedeutet Fluss. Die Schritte zum Ziel werden in eine Reihenfolge gebracht, komplexe Aufgaben werden in kleine Teile zerlegt. Der richtige Fluss reduziert Fehler und erhöht die Geschwindigkeit.

## Wie kann man es kennen und im täglichen Leben anwenden?

## Häufig gemischte Dinge
Es wird für eine Pipeline gehalten. Eine Pipeline ist ein technischer Datenfluss, ein Workflow ist eine allgemeinere Arbeitsabfolge. Jede Pipeline gilt als Workflow, das Umgekehrte ist nicht zwingend der Fall.

## Einsatz in verschiedenen Disziplinen
Rezept: Vorbereitung, Kochen und Servieren.Montage: Reihenfolge der Teile.Theke: Registrierung und Weiterleitung.

## Häufig gestellte Fragen
**Warum automatisieren?**
Wiederholung erzeugt Fehler und Zeitverlust. Automatisierung reduziert beides.

**Können sich Arbeitsabläufe ändern?**
Ja. Es wird aktualisiert, wenn sich die Anforderungen ändern, und versioniert.

**Wo soll ich anfangen?**
Mit der am häufigsten wiederholten Aufgabe. Die Schritte werden notiert, einer davon wird automatisiert.

**Ist ein Tool zwingend erforderlich?**
Nein. Eine Papierliste ist auch ein Ablauf. Wenn das Volumen wächst, wird ein Tool benötigt.
