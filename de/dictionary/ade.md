# Was ist ADE?

> Application Development Environment

Dabei handelt es sich um digitale Arbeitsumgebungen zur Beschleunigung und Steuerung von Softwareentwicklungsprozessen.

## Definition
Ziel von ADE ist es, alle Phasen vom Entwurf einer Software bis zur Veröffentlichung unter einem Dach zu vereinen. Es bietet vorgefertigte Tools, Bibliotheken und Testumgebungen, die Entwickler beim Schreiben von Code benötigen. Auf diese Weise können sich Entwickler nur auf ihre Produkte konzentrieren und müssen sich nicht mit Infrastrukturdetails befassen.

## So funktioniert es
Auf diesen Plattformen, deren Zugriff meist über eine cloudbasierte oder lokale Installation erfolgt, verwalten Sie Ihre Projektdateien und integrieren die notwendigen Tools.

## Wo es eingesetzt wird
Es wird bei großen Softwareprojekten, Teamarbeit und schneller Prototypenentwicklung bevorzugt.

## Häufig verwechselt mit
Kann mit IDE gemischt werden; Während sich IDE mehr auf das Schreiben von Code konzentriert, deckt ADE den gesamten Entwicklungsprozess ab.

## Häufige Fragen
**Ist die Verwendung von ADE obligatorisch?**
Es ist nicht zwingend erforderlich, spart aber Zeit bei komplexen Projekten.
