# Was ist User Interface?

*Glossar · Dev · Zuletzt aktualisiert: 25. Juni 2026*

> UI

Es handelt sich um den visuellen Anzeige- und Steuerbereich, der es dem Benutzer ermöglicht, mit einem Gerät oder einer Software zu interagieren.

## Definition

Es ist die Brücke zwischen Ihnen und einer Software in der digitalen Welt. Alles, was Sie sehen, wie Schaltflächen, Menüs, Symbole und Textfelder, ist Teil dieser Benutzeroberfläche. Eine gute Schnittstelle ermöglicht Ihnen die einfache Durchführung selbst komplexer Vorgänge.

***Analogie:** Es ist wie das Lenkrad, die Pedale und das Armaturenbrett eines Autos; Damit können Sie das Fahrzeug verwalten, ohne wissen zu müssen, wie der Motor funktioniert.*

## So funktioniert es

Designer entwerfen diese Bildschirme, indem sie analysieren, was Benutzer benötigen. Anschließend wandeln Softwareentwickler diese Zeichnungen in eine Struktur um, die mit Codes funktioniert. Das resultierende visuelle Layout übersetzt Ihre Befehle in eine Sprache, die der Computer verstehen kann.

## Wo es eingesetzt wird

Es erscheint in Anwendungen auf Ihrem Smartphone, auf Websites oder auf den Touchscreens Ihrer Smart-Home-Geräte.

## Häufig verwechselt mit

Es wird oft mit dem Backend der Software verwechselt, aber die Schnittstelle ist nur der Teil, den Sie sehen.

## Häufige Fragen

**Sind UI und UX dasselbe?**

Nein, die Benutzeroberfläche umfasst die visuellen Teile (Farbe, Schaltfläche), während es bei der Benutzeroberfläche darum geht, wie sich der Benutzer fühlt und wie wohl er sich bei der Verwendung dieser Benutzeroberfläche fühlt.
