# Was ist VPN?

*Glossar · Dev · Zuletzt aktualisiert: 11. Juni 2026*

> Virtual Private Network

Es handelt sich um ein Tool, das Ihre Identität verbirgt und durch die Verschlüsselung Ihrer Daten im Internet eine sichere Verbindung herstellt.

## Definition

Es leitet Ihre Daten durch einen Tunnel, während Sie eine Verbindung zum Internet herstellen. Dank dieses Tunnels können Außenstehende nicht sehen, was Sie tun oder von wo aus Sie eine Verbindung herstellen. Selbst Ihr Internetdienstanbieter kann Ihren Datenverkehr nicht lesen.

***Analogie:** Anstatt nackt auf der Straße herumzulaufen, ist es wie eine Fahrt in einem speziellen gepanzerten Fahrzeug, bei dem man von außen nicht erkennen kann, wer man ist.*

## So funktioniert es

Laden Sie eine VPN-App herunter, wählen Sie den Server aus, mit dem Sie eine Verbindung herstellen möchten, und aktivieren Sie die Verbindung. Ihr gesamter Datenverkehr wird jetzt verschlüsselt.

## Wo es eingesetzt wird

Es wird in öffentlichen WLAN-Netzwerken eingesetzt, für Arbeiten, die Vertraulichkeit erfordern oder um Zugangsbarrieren zu überwinden.

## Häufig verwechselt mit

Es kann mit einem Proxy verwechselt werden, aber ein VPN verschlüsselt den gesamten Geräteverkehr, während ein Proxy normalerweise nur bestimmte Anwendungen weiterleitet.

## Häufige Fragen

**Verlangsamt VPN meine Geschwindigkeit?**

Da die Daten verschlüsselt sind, kann es manchmal zu leichten Geschwindigkeitseinbußen kommen.

**Sind kostenlose VPNs sicher?**

Im Allgemeinen nein, sie können mit Ihren Daten Einnahmen generieren.
