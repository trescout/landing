# Was ist Source Control?

Es ist ein Nachverfolgungssystem, das alle Codeänderungen in Softwareprojekten aufzeichnet und eine Rückkehr zu früheren Versionen ermöglicht.

## Definition
Bei der Softwareentwicklung wird der Code ständig geändert. Die Quellcodeverwaltung speichert jede in diesem Prozess vorgenommene Änderung mit Datum und Autoreninformationen. Auf diese Weise kann bei einem Fehler problemlos zum vorherigen funktionierenden Zustand des Projekts zurückgekehrt werden.

## So funktioniert es
Entwickler laden ihren Code in das System hoch (Commit). Wenn ein Problem auftritt, wird einer der alten Datensätze im System ausgewählt und das Projekt auf diesen Zeitpunkt zurückgesetzt.

## Wo es eingesetzt wird
In allen modernen Softwareentwicklungsprozessen, insbesondere bei der Teamarbeit, ist es unerlässlich.

## Häufig verwechselt mit
Es ist nicht dasselbe wie ein Backup, da es nicht nur Dateien, sondern auch die Historie der Änderungen verwaltet.

## Häufige Fragen
**Warum sollte ich es verwenden?**
Es ist lebensrettend, um Ihren Code wiederherzustellen, falls Sie ihn versehentlich beschädigen sollten.

**Welches ist das beliebteste?**
Git ist heute das am weitesten verbreitete System.
