# Was ist Debugger?

*Glossar · Dev · Zuletzt aktualisiert: 7. Oktober 2026*

Ein Debugger ist ein Fehlerbehebungstool, mit dem Fehler in Software Schritt für Schritt verfolgt, gefunden und behoben werden können.

## Definition

Es ist ein spezielles Hilfsprogramm im Softwareentwicklungsprozess, mit dem Sie sich in den Code einklinken und live miterleben können, wie jede einzelne Zeile funktioniert. Der von Programmierern geschriebene Code funktioniert nicht immer beim ersten Mal fehlerfrei und kann zu unerwarteten Abstürzen oder falschen Ergebnissen führen. Mit einem Debugger können Sie die Ausführung des Codes an einer gewünschten Stelle anhalten, die Werte der Variablen zu diesem Zeitpunkt untersuchen und die Ursache des Fehlers punktgenau lokalisieren.

***Analogie:** Man kann sich das wie einen Detektiv vorstellen, der das Geschehen am Tatort in Zeitlupe noch einmal abspielt und jeden Hinweis mit einer Lupe untersucht.*

## So funktioniert es

Sie setzen einen Haltepunkt in einer bestimmten Zeile Ihres Codes. Wenn Sie das Programm ausführen, stoppt es genau an dieser Zeile, und Sie können Schritt für Schritt vorgehen, um live zu beobachten, welche Variable wann beschädigt wird.

## Wo es eingesetzt wird

Es wird häufig in Softwareentwicklungsumgebungen, den Entwicklertools von Webbrowsern und bei der Hintergrundfehleranalyse komplexer Systeme verwendet.

## Häufig verwechselt mit

Es kann mit einem Compiler verwechselt werden. Während ein Compiler den gesamten Code in Maschinensprache übersetzt, konzentriert sich ein debugger darauf, logische Fehler im laufenden Code zu finden.

## Häufige Fragen

**Kann ich keine Fehler beheben, ohne einen Debugger zu verwenden?**

Sie können auch nach Fehlern suchen, indem Sie fortlaufend Befehle zum Schreiben von Text auf dem Bildschirm in den Code einfügen, aber diese Methode ist bei großen Projekten sehr langsam und bietet nicht so tiefgehende Informationen wie ein Debugger.

**Was ist ein Haltepunkt (Breakpoint)?**

Es ist eine Markierung, die Sie an der Zeile platzieren, an der der Code während der Ausführung anhalten soll; wenn der Debugger diesen Punkt erreicht, friert er das Programm ein.
