# Was ist Server Hardening?

Dabei handelt es sich um den Prozess, das Angriffsrisiko zu verringern, indem unnötige Funktionen auf einem Server deaktiviert und die Sicherheitseinstellungen verschärft werden.

## Definition
Dabei handelt es sich um den Versuch, die Oberfläche des Servers so weit wie möglich zu reduzieren. Es umfasst Schritte wie das Deaktivieren ungenutzter Dienste, das Ändern von Standardkennwörtern und das Konfigurieren von Firewalls. Ziel ist es, Türen zu schließen, durch die ein Angreifer eindringen könnte.

## So funktioniert es
Schließen Sie unnötige Ports auf dem Server, aktualisieren Sie die Software auf die neueste Version, schränken Sie Benutzerberechtigungen ein, um unbefugten Zugriff zu verhindern, und führen Sie regelmäßige Sicherheitsscans durch.

## Wo es eingesetzt wird
Es wird in Cloud-Servern, lokalen Rechenzentren und Cybersicherheitsbetrieben eingesetzt.

## Häufig verwechselt mit
Es ist nicht dasselbe wie nur die Installation einer Firewall; Beim Härten handelt es sich um einen wesentlich umfassenderen Sicherheitsprozess.

## Häufige Fragen
**Wie oft sollte ich meinen Server härten?**
Es sollte ständig überprüft werden, wenn Systemaktualisierungen und neue Dienstinstallationen vorgenommen werden.
