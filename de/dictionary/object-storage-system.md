# Was ist Object Storage System?

*Glossar · Data · Zuletzt aktualisiert: 19. September 2026*

Eine groß angelegte Speichermethode, die Daten anstelle von Dateiordnern mit eindeutigen Identifikatoren speichert.

## Definition

Das Dateisystem auf Ihrem herkömmlichen Computer ist wie eine Baumstruktur; es verläuft in Form von Ordnern in Ordnern. Die Objektspeicherung hingegen behandelt Daten als Objekt und weist ihnen eine spezielle Kennung zu. Auf diese Weise können Sie schnell auf die Daten zugreifen, indem Sie direkt diese Kennung verwenden, anstatt Ordnerpfaden zu folgen.

***Analogie:** Es ist, als würde man in einer Bibliothek nicht nach Büchern in Regalen und mit Nummern suchen, sondern einen magischen Barcode auf dem Buch scannen und das Buch sofort in die Hand teleportiert bekommen.*

## So funktioniert es

Wenn Daten in das System hochgeladen werden, werden sie zu einem Objekt und einige Beschreibungen (Metadaten) werden hinzugefügt. Wenn Sie dieses Objekt benötigen, rufen Sie es über seine Kennung ab.

## Wo es eingesetzt wird

Es wird bei Cloud-Speicherdiensten, großen Datensicherungen und der Bereitstellung von Medieninhalten verwendet.

## Häufig verwechselt mit

Es kann mit normalen Festplatten-Dateisystemen verwechselt werden; dieses System ist jedoch für wesentlich größere Datenmengen konzipiert.

## Häufige Fragen

**Warum werden keine Ordner verwendet?**

Weil die Verwaltung von Milliarden von Daten in einer Ordnerstruktur sehr langsam ist, während das Objektsystem viel schneller ist.
