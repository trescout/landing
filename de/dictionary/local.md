# Was ist Local?

Das bedeutet, dass Programme oder Daten vollständig auf Ihrem Gerät ausgeführt werden, ohne dass eine Internetverbindung erforderlich ist.

## Definition
Die meisten Anwendungen senden heutzutage Daten in die Cloud. Beim lokalen Arbeitsprinzip endet alles im Prozessor Ihres Computers oder Telefons. Das bedeutet, dass Ihre Daten nicht verloren gehen.

## So funktioniert es
Anstatt die Software über die Cloud zu verwenden, laden Sie die Installationsdateien auf Ihr Gerät herunter. Auch wenn Sie das Internet ausschalten, funktioniert das Programm weiterhin mit allen Funktionen.

## Wo es eingesetzt wird
Es wird in datenschutzorientierten Tools für künstliche Intelligenz, persönlichen Dateiverwaltungssystemen und sicheren Softwareentwicklungsumgebungen verwendet.

## Häufig verwechselt mit
Es ähnelt dem Selbsthosting, bezieht sich jedoch lokal im Allgemeinen auf ein einzelnes Gerät, während sich Selbsthosting auf einen Server bezieht.

## Häufige Fragen
**Was ist der größte Vorteil der Arbeit vor Ort?**
Sein größter Vorteil ist die Privatsphäre; Ihre Daten verlassen niemals Ihr Gerät.
