# Was ist Virtual Machines?

Dabei handelt es sich um virtuelle Betriebssysteme, die in einem Computer ausgeführt werden, als wäre dieser ein separates Gerät.

## Definition
Mit virtuellen Maschinen können Sie mehrere Betriebssysteme gleichzeitig auf einem einzigen Computer ausführen, indem Sie Ihre physische Hardware partitionieren. Jede virtuelle Maschine verhält sich so, als wäre sie ein eigener unabhängiger Computer und nutzt ihre eigenen Ressourcen. Auf diese Weise können Sie sicher verschiedene Software oder Einstellungen ausprobieren, ohne Ihr Hauptsystem zu beschädigen.

## So funktioniert es
Sie trennen einen Teil Ihrer Hardware mithilfe von Software. In diesem reservierten Bereich installieren Sie ein Betriebssystem. Dieses von Ihnen installierte System beginnt in seiner eigenen Welt zu arbeiten, ohne dass Ihr Hauptcomputer davon Kenntnis erhält.

## Wo es eingesetzt wird
Es wird in der Serververwaltung, beim Softwaretesten und bei Aufgaben eingesetzt, die unterschiedliche Betriebssysteme erfordern.

## Häufig verwechselt mit
Häufig mit Behältern vermischt; Während virtuelle Maschinen ein vollständiges Betriebssystem enthalten, enthalten Container nur die Anwendung.

## Häufige Fragen
**Verlangsamt eine virtuelle Maschine den Computer?**
Ja, denn es funktioniert durch die gemeinsame Nutzung der Prozessor- und Speicherressourcen Ihres Host-Computers.

**Wenn ein Virus in der virtuellen Maschine auftritt, wird er dann auf den Host-Computer übertragen?**
Normalerweise nicht, da sich die virtuelle Maschine in einer vom Hostsystem isolierten Umgebung befindet.
