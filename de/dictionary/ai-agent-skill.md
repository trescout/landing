# Was ist AI Agent Skill?

*Glossar · AI · Zuletzt aktualisiert: 6. Juni 2026*

Hierbei handelt es sich um spezifische Fähigkeiten, die ein KI-Agent zur Erledigung einer Aufgabe einsetzen kann, beispielsweise zum Durchsuchen des Internets oder zum Organisieren einer Datei.

## Definition

KI-Agentenfähigkeiten sind Fähigkeiten, die es einer künstlichen Intelligenz ermöglichen, nicht nur Texte zu produzieren, sondern auch mit der Außenwelt zu interagieren. Wenn ein Agent lernt, eine Datei zu lesen, eine E-Mail zu senden oder eine Software auszuführen, spricht man von einer neuen Fähigkeit. Diese Fähigkeiten ermöglichen es dem Agenten, Aufgaben autonom zu erledigen.

***Analogie:** Dabei handelt es sich um Fähigkeiten, bei denen ein Mitarbeiter nicht nur sprechen, sondern auch Excel verwenden oder ein Meeting organisieren kann.*

## So funktioniert es

Entwickler erteilen dem Agenten die Erlaubnis, bestimmte APIs oder Tools zu verwenden. Wenn der Agent die Aufgabe erhält, wählt er die Fähigkeit aus, die er verwenden muss, und führt die Aktion mit diesem Werkzeug aus. Je umfassender die Kompetenz, desto mehr unterschiedliche Aufgaben wird der Agent erfolgreich bewältigen.

## Wo es eingesetzt wird

Es wird häufig in KI-Agentenplattformen und Automatisierungstools verwendet.

## Häufig verwechselt mit

Es kann mit allgemeiner Intelligenz verwechselt werden; Eine Fertigkeit ist das Mittel des Agenten, eine bestimmte Aufgabe zu erledigen.

## Häufige Fragen

**Wie erlernen Agenten neue Fähigkeiten?**

Sie werden von Entwicklern oft als vordefinierte Tools hinzugefügt oder in manchen Systemen entwickeln sie neue Funktionen, indem sie selbst Code schreiben.

**Sind die Fähigkeiten aller Agenten gleich?**

Nein, je nach Zweck des Agenten (z. B. Codierungsagent vs. Forschungsagent) unterscheiden sich seine Fähigkeiten völlig.
