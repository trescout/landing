# Was ist Japanese Input Method System?

> IME

Dabei handelt es sich um eine Schnittstellensoftware, die das Schreiben japanischer Zeichen mit einer Standardtastatur ermöglicht.

## Definition
Da Japanisch aus Tausenden von Zeichen besteht, passt es nicht auf eine Standardtastatur. Dieses System fungiert als Brücke, die vom Benutzer im lateinischen Alphabet geschriebene phonetische Laute in japanische Schriftzeichen umwandelt. Die Software verarbeitet das Geschriebene sofort und bringt die richtigen Zeichen auf den Bildschirm.

## So funktioniert es
Der Benutzer drückt Buchstaben auf der Tastatur, die Software sammelt diese Buchstaben und zeigt mithilfe einer „Konvertierungs-Engine“ japanische Zeichen auf dem Bildschirm an.

## Wo es eingesetzt wird
Es wird in Computer- und Telefonbetriebssystemen sowie Texteditoren verwendet.

## Häufig verwechselt mit
Kann mit der Neural Kana-Kanji Conversion Engine gemischt werden; IME ist das Gesamtsystem, während die Konvertierungs-Engine der intelligente Konverter darin ist.

## Häufige Fragen
**Kann ich Japanisch ohne IME eingeben?**
Nein, diese Software wird benötigt, da es unmöglich ist, Tausende von Zeichen auf der Tastatur unterzubringen.
