# Was ist Fine-tuned Ruleset?

Eine Reihe von Regeln, die durch Training mit speziellen Daten verfeinert werden, um eine bestimmte Aufgabe besser zu erledigen.

## Definition
Dabei handelt es sich um eine Reihe von Regeln, die dazu dienen, eine allgemeine künstliche Intelligenz in einen Experten für eine bestimmte Branche oder einen bestimmten Beruf zu verwandeln. Dieser Prozess ermöglicht es dem Modell, es an Ihre spezifischen Bedürfnisse anzupassen und gleichzeitig seine allgemeinen Informationen beizubehalten. Ziel ist eine geringere Fehlerquote und eine höhere Konzentration.

## So funktioniert es
Den allgemeinen Fähigkeiten des Modells werden nur Beispiele und Regeln hinzugefügt, die sich auf den Zieljob beziehen. Auf diese Weise spezialisiert sich das Modell auf die von Ihnen angegebenen Grenzen und nicht auf allgemeine Informationen.

## Wo es eingesetzt wird
Analyse von Rechtsdokumenten, medizinische Diagnoseunterstützungssysteme und spezielle Kundenservice-Bots.

## Häufig verwechselt mit
Es ähnelt der Feinabstimmung, aber hier liegt der Schwerpunkt auf den genauen Regeln, denen das Modell folgen muss, und nicht auf seinen Gesamtgewichten.

## Häufige Fragen
**Warum machen wir das?**
Um zu verhindern, dass das Modell abschweift, und um sicherzustellen, dass es immer den von Ihnen festgelegten Standards entspricht.
