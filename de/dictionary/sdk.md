# Was ist SDK?

> Software Development Kit

Dabei handelt es sich um eine Reihe von Tools und Bibliotheken, die es Softwareentwicklern erleichtern, Anwendungen für eine bestimmte Plattform zu entwickeln.

## Definition
SDK ist eine Art Entwicklungskit. Es enthält vorgefertigte Tools, Dokumente und Beispielcodes, die Ihnen das Schreiben von Code erleichtern. Anstatt alles von Grund auf neu zu schreiben, um die Funktionen einer Plattform zu nutzen, kombinieren Sie die vorgefertigten Teile, die dieses Kit bietet.

## So funktioniert es
Der Entwickler lädt das entsprechende SDK auf seinen Computer herunter und referenziert diese Tools beim Codieren. Somit kann es komplexe Vorgänge mit einzeiligen Befehlen bewältigen.

## Wo es eingesetzt wird
Es wird bei der Entwicklung mobiler Anwendungen, der Integration eines Modells der künstlichen Intelligenz in Ihre eigene Anwendung oder in Game-Engines verwendet.

## Häufig verwechselt mit
Gemischt mit API; Die API ist eine Tür, das SDK ist die gesamte Toolbox, die es Ihnen ermöglicht, durch diese Tür zu gelangen und das Haus einzurichten.

## Häufige Fragen
**Sind alle SDKs kostenlos?**
Die meisten sind kostenlos, aber einige bestimmte Plattformen erheben möglicherweise Lizenzgebühren für die SDK-Nutzung.

**Kann eine Anwendung nicht ohne SDK geschrieben werden?**
Es kann geschrieben werden, aber man muss alles von Grund auf programmieren, was zu lange dauert.
