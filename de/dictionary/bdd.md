# Was ist BDD?

*Glossar · Dev · Zuletzt aktualisiert: 12. Juli 2026*

> Behavior-Driven Development

Der Entwicklungsprozess, bei dem in einfachen Sätzen definiert wird, wie sich Software verhalten soll, die jeder verstehen kann.

## Definition

BDD ermöglicht die Einbindung technisch nicht versierter Personen in den Softwareentwicklungsprozess. Der Schwerpunkt liegt auf dem, was der Benutzer tun wird und wie das System reagieren wird, und nicht auf den technischen Details der Software. Dank dieser Methode sprechen Entwickler und Geschäftsbereiche dieselbe Sprache.

***Analogie:** Überlegen Sie sich ein Rezept; Es ist, als würde man in einer Sprache erklären, die jeder verstehen kann, wie das Essen beim Kochen riechen und schmecken soll, anstatt nur die Zutaten aufzuschreiben.*

## So funktioniert es

Zunächst wird das erwartete Verhalten des Systems wie folgt geschrieben: „Wenn der Benutzer X ausführt, sollte Ergebnis Y eintreten.“ Diese Sätze werden dann kodiert und getestet. Wenn der Code dieses Verhalten aufweist, funktioniert die Software ordnungsgemäß.

## Wo es eingesetzt wird

Es wird in Softwareprojekten verwendet, insbesondere bei der Entwicklung komplexer Funktionen und zur Reduzierung der Fehlerquote.

## Häufig verwechselt mit

Kann mit TDD verwechselt werden; Während sich TDD auf die Robustheit des Codes konzentriert, konzentriert sich BDD auf das Verhalten der Funktion in den Augen des Benutzers.

## Häufige Fragen

**Warum ist BDD wichtig?**

Es beseitigt die Kommunikationslücke zwischen dem technischen Team und dem Geschäftsteam.

**Benötigt BDD eine spezielle Sprache?**

Meist wird eine einfache Syntax verwendet, etwa Gherkin, die dem Englischen sehr nahe kommt und von jedem gelesen werden kann.
