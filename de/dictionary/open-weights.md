# Was ist Open Weights?

Dabei handelt es sich um die Weitergabe der trainierten internen Parameter des Modells der künstlichen Intelligenz an alle.

## Definition
Open Weights macht die internen Einstellungen und mathematischen Gewichte, die während des Trainingsprozesses eines Modells der künstlichen Intelligenz erstellt wurden, öffentlich zugänglich. Auf diese Weise können Entwickler das Modell auf ihren eigenen Computern ausführen oder neue Funktionen hinzufügen.

## So funktioniert es
Das Unternehmen, das das Modell trainiert, stellt riesige Dateigrößen an Gewichtsdaten über das Internet zur Verfügung. Sie können das Modell auch anpassen, indem Sie diese Dateien herunterladen und auf Ihrem eigenen System ausführen.

## Wo es eingesetzt wird
Es wird von Unternehmen und Forschern genutzt, die künstliche Intelligenz auf ihren eigenen Servern betreiben möchten, um das Modell vollständig unter Kontrolle zu halten.

## Häufig verwechselt mit
Es wird mit Open-Source-Software gemischt; Open Weights stellt die interne Struktur des Modells bereit, aber manchmal können die zum Trainieren des Modells selbst verwendeten Daten privat bleiben.

## Häufige Fragen
**Kann ich mit Open Weights alles am Modell ändern?**
Sie können die Grundstruktur des Modells nicht ändern, aber Sie können es durch das Hinzufügen neuer Daten auf bestimmte Themen spezialisieren.

**Was ist nötig, um diese Modelle zu betreiben?**
Normalerweise ist eine leistungsstarke Grafikkarte oder Serverhardware mit hoher Kapazität erforderlich.
