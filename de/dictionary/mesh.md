# Was ist Mesh?

Mehrere miteinander verbundene Geräte oder Dienste tauschen Daten aus, ohne dass ein zentraler Punkt erforderlich ist.

## Definition
In der Mesh-Struktur kann jeder Knoten direkt miteinander kommunizieren. Das System ist langlebiger, da es nicht auf einen zentralen Server angewiesen ist. Selbst wenn ein Knoten ausfällt, werden die Daten weiterhin über andere Routen übertragen.

## So funktioniert es
Geräte oder Dienste erkennen einander und bauen ein Netzwerk zwischen ihnen auf.

## Wo es eingesetzt wird
Es wird in drahtlosen Netzwerken, Smart-Home-Systemen und Microservice-Architekturen eingesetzt.

## Häufige Fragen
**Was ist der Vorteil von Mesh-Netzwerken?**
Da sie nicht mit einem einzigen Punkt verbunden sind, ist die Gefahr eines Systemzusammenbruchs viel geringer.
