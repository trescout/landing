# Was ist Array Operations?

Hierbei handelt es sich um kollektive mathematische Operationen, die an Gruppen von Daten ausgeführt werden, die nebeneinander im Computerspeicher aufgereiht sind.

## Definition
Wenn Computer Daten verarbeiten, speichern sie diese als Array, normalerweise nebeneinander. Mit Array-Operationen können Sie die gesamte Liste mit einem einzigen Befehl bearbeiten. Wenn Sie beispielsweise den Noten aller Schüler einer Klasse gleichzeitig 5 Punkte hinzufügen möchten, verwenden Sie diese Methode, anstatt es einzeln zu versuchen.

## So funktioniert es
Beim Schreiben von Code platzieren Programmierer Daten in einer Liste (Array). Dann definieren sie eine mathematische Operation für diese Sequenz. Der Computer wendet diese Operation nacheinander oder gleichzeitig auf jedes Element im Array an.

## Wo es eingesetzt wird
Es wird häufig in der Datenanalyse, Bildverarbeitung und Trainingsprozessen von Modellen der künstlichen Intelligenz eingesetzt.

## Häufig verwechselt mit
Kann mit Schleifen verwechselt werden; Während Schleifen jedoch Elemente einzeln verarbeiten, verarbeiten Array-Operationen sie stapelweise, um den Prozess zu beschleunigen.

## Häufige Fragen
**Warum verwenden wir dies, anstatt eine Transaktion nach der anderen durchzuführen?**
Weil die Stapelverarbeitung den Prozessor des Computers viel effizienter nutzt und die Arbeit viel schneller erledigt.
