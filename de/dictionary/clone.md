# Was ist Clone?

Dabei handelt es sich um den Vorgang, bei dem alle Dateien und der Verlauf eines Softwareprojekts aus dem Internet auf Ihren eigenen Computer kopiert werden.

## Definition
Das bedeutet, dass Sie ein Open-Source-Projekt, das normalerweise auf Plattformen wie GitHub verfügbar ist, in Ihre lokale Umgebung herunterladen, damit Sie daran arbeiten oder es überprüfen können. Dies geht über das bloße Herunterladen von Dateien hinaus und zeigt den gesamten Entwicklungsverlauf des Projekts an.

## So funktioniert es
Dies erfolgt über die Befehlszeile mit dem Befehl „git clone“ und der Adresse des Projekts.

## Wo es eingesetzt wird
Es ist der erste Prozess, den Softwareentwickler durchführen, bevor sie mit dem Projekt beginnen.

## Häufige Fragen
**Kann ich das Projekt nach dem Klonen ändern?**
Ja, Sie können auf Ihrem eigenen Computer alle gewünschten Änderungen an der Kopie vornehmen, dies hat jedoch keine Auswirkungen auf das Originalprojekt.
