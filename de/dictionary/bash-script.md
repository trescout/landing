# Was ist Bash Script?

*Glossar · Dev · Zuletzt aktualisiert: 12. August 2026*

Es handelt sich um eine Befehlssequenz, die mehrstufige Vorgänge, die auf dem Computer ausgeführt werden müssen, automatisiert, indem sie sie in einer einzigen Datei sammelt.

## Definition

Mit dem Bash-Skript können Sie die Befehle, die Sie einzeln in der Befehlszeile des Computers eingeben, kombinieren und in einer einzigen Datei speichern. Wenn Sie diese Datei ausführen, werden alle darin enthaltenen Befehle nacheinander und ohne Fehler ausgeführt. Es ist einer der größten Helfer für Softwareentwickler, insbesondere um sich wiederholende Aufgaben zu beschleunigen.

***Analogie:** Es ist, als würde man ein Rezept Schritt für Schritt auf Papier schreiben; Anstatt jedes Mal über die Zutaten nachzudenken, lesen Sie die Zeitung und bereiten das Essen schnell zu.*

## So funktioniert es

Sie öffnen eine Textdatei und schreiben die Befehle, die Sie ausführen möchten, untereinander. Sobald Sie die Datei gespeichert und ausführbar gemacht haben, starten Sie den gesamten Vorgang mit einem einzigen Klick oder Befehl.

## Wo es eingesetzt wird

Es wird häufig bei der Serververwaltung, bei Sicherungsvorgängen oder bei Softwareinstallationsprozessen verwendet.

## Häufige Fragen

**Warum sollte ich ein Skript verwenden, anstatt es von Hand zu schreiben?**

Es reduziert die Fehlerquote und ermöglicht es Ihnen, jedes Mal den gleichen Vorgang mit der gleichen Geschwindigkeit auszuführen.
