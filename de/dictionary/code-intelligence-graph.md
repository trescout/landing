# Was ist Code Intelligence Graph?

Dabei handelt es sich um eine detaillierte Karte, die die Beziehungen aller Dateien, Funktionen und Variablen in einem Softwareprojekt zeigt.

## Definition
In großen Softwareprojekten sind Codes über Tausende von Dateien verteilt. Code Intelligence Graph verbindet diese komplexe Struktur wie ein Netzwerk. Somit kann künstliche Intelligenz leicht verstehen, auf welche anderen Teile sich eine Änderung an einem Teil des Codes auswirkt.

## So funktioniert es
Softwareentwicklungstools scannen Ihr Projekt, markieren jeden Teil als Knoten und zeichnen die Verbindungen zwischen ihnen auf. Diese Datenbank wird verwendet, um Ihnen beim Schreiben von Code Vorschläge zu machen oder Fehler zu finden.

## Wo es eingesetzt wird
Es wird in modernen Code-Editoren, KI-gestützten Softwareentwicklungstools und bei der Verwaltung großer Projekte eingesetzt.

## Häufig verwechselt mit
Es handelt sich nicht nur um eine Liste von Dateien oder eine einfache Ordnerstruktur; Es umfasst auch die logischen Beziehungen des Codes.

## Häufige Fragen
**Warum ist das nötig?**
Denn bei sehr großen Projekten lässt sich manuell nicht nachvollziehen, wo eine Änderung zu Fehlern führt.
