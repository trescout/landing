# Was ist Extensibility?

Die Eignung eines Systems, durch das Hinzufügen neuer Funktionen entwickelt zu werden, ohne seine Grundstruktur zu zerstören.

## Definition
Erweiterbarkeit bedeutet, dass eine Software flexibel ist. Sie können neue Funktionen über Plug-ins oder Module hinzufügen, ohne den Hauptcode der Software zu berühren. Dies gewährleistet die Langlebigkeit des Systems.

## So funktioniert es
Das System ist mit einer „Schnittstelle“ ausgestattet, die externe Module akzeptiert.

## Wo es eingesetzt wird
Es wird in Browser-Add-ons, Content-Management-Systemen (wie WordPress) und großer Unternehmenssoftware verwendet.

## Häufige Fragen
**Ist jede Software erweiterbar?**
Nein, wenn die Software nicht von Anfang an mit dieser Flexibilität ausgestattet ist, kann es sehr schwierig sein, sie später hinzuzufügen.
