# Was ist Cloud Native?

Es handelt sich um einen Ansatz zum Entwerfen und Verwalten von Anwendungen, die mit höchster Effizienz in der Cloud-Umgebung ausgeführt werden sollen.

## Definition
Bei diesem Ansatz wird eine Software nicht nur in die Cloud hochgeladen, sondern sie mithilfe der Flexibilität, Skalierbarkeit und Haltbarkeit erstellt, die die Cloud bietet. Die Anwendung ist in Teile unterteilt, um sich an die dynamische Struktur der Cloud anzupassen.

## So funktioniert es
Anwendungen werden in Containern abgelegt und mit automatischen Verwaltungstools verwaltet. Wenn also der Datenverkehr zunimmt, kann die Anwendung ihre Kapazität selbstständig erhöhen.

## Wo es eingesetzt wird
Es wird in modernen Webdiensten, Großanwendungen und Microservice-Architekturen eingesetzt.

## Häufige Fragen
**Warum ist es wichtig?**
Dadurch wird sichergestellt, dass die Anwendung immer überlebt und schnell wächst.
