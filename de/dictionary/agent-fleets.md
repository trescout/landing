# Was ist Agent Fleets?

*Glossar · AI · Zuletzt aktualisiert: 27. August 2026*

Eine Gruppe mehrerer Softwareprogramme für künstliche Intelligenz, die harmonisch miteinander arbeiten, um komplexe Aufgaben zu erledigen.

## Definition

Anstelle einer einzelnen künstlichen Intelligenz kommen viele kleine Vertreter der künstlichen Intelligenz mit jeweils unterschiedlichen Fachkenntnissen zusammen und arbeiten zusammen. Während ein Agent recherchiert, schreibt ein anderer Code und ein anderer prüft die Ergebnisse.

***Analogie:** Es ist wie ein Orchester; Jeder Musiker spielt sein eigenes Instrument, aber alle bilden unter der Leitung des Dirigenten eine einzige Symphonie.*

## So funktioniert es

Ein zentrales System unterteilt die Aufgabe in Teile und weist jeden Teil dem entsprechenden Vertreter zu.

## Wo es eingesetzt wird

Es wird in komplexen Softwareentwicklungsprojekten und groß angelegter Geschäftsautomatisierung eingesetzt.

## Häufig verwechselt mit

Es ist fast dasselbe wie bei Multiagentensystemen. Der Schwerpunkt liegt hier eher auf einem groß angelegten „Flotten“-Management.

## Häufige Fragen

**Wie verstehen sich Vertreter untereinander?**

Sie kommunizieren über ein gemeinsames Protokoll oder eine gemeinsame Nachrichtensprache.
