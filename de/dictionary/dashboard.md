# Was ist Dashboard?

Panel, mit dem Sie komplexe Daten und Statistiken visuell auf einem einzigen Bildschirm verfolgen können.

## Definition
Das Dashboard ist wie ein digitales Bedienfeld. Es fasst den aktuellen Status, die Leistung und wichtige Daten eines Systems oder einer Anwendung in Grafiken oder Tabellen zusammen. Es vereinfacht komplexe Informationen und ermöglicht Ihnen, sie schnell zu verstehen.

## So funktioniert es
Es wird normalerweise von einer Quelle gespeist, aus der Daten gesammelt werden. Softwareentwickler stellen diese Daten dem Benutzer mithilfe von Visualisierungsbibliotheken zur Verfügung. Sie schauen einfach auf den Bildschirm und analysieren, was passiert und wie.

## Wo es eingesetzt wird
Es wird in der Geschäftswelt verwendet, um Verkaufscharts zu verfolgen, die Serverleistung zu überwachen oder für persönliche Budgetanwendungen.

## Häufig verwechselt mit
Es kann mit Berichten verwechselt werden, aber das Dashboard bietet Live- und interaktive Daten.

## Häufige Fragen
**Zeigt das Dashboard Live-Daten an?**
Ja, es spiegelt normalerweise sofort den aktuellen Status des Systems wider.

**Kann jemand ein Dashboard erstellen?**
Ja, Sie können Ihre eigenen Daten mit einfachen Tools visualisieren.
