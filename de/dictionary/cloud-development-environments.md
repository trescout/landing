# Was ist Cloud Development Environments?

> CDE

Es handelt sich um das Hosten aller für die Softwareentwicklung erforderlichen Tools auf Servern im Internet anstelle eines lokalen Computers.

## Definition
Früher musste ein Softwareentwickler Dutzende von Programmen auf seinem Computer installieren. Dank CDE verbinden Sie sich in dem Moment, in dem Sie Ihren Browser öffnen, mit einer fertigen Softwareentwicklungsumgebung. Alle Codes, Tools und Servereinstellungen befinden sich im Internet, sodass Sie von jedem Gerät aus genau dort weitermachen können, wo Sie aufgehört haben.

## So funktioniert es
Sie rufen die entsprechende Plattform im Browser auf, Ihre Projektdateien werden automatisch geladen und Sie beginnen mit dem Programmieren. Die Prozesse finden nicht auf Ihrem Computer statt, sondern auf leistungsstarken Remote-Servern.

## Wo es eingesetzt wird
Es wird in großen Softwareteams und in Unternehmen eingesetzt, die schnell Prototypen entwickeln.

## Häufig verwechselt mit
Es könnte lediglich mit einem Remote-Desktop verwechselt werden; dieses System ist jedoch speziell für das Programmieren optimiert.

## Häufige Fragen
**Was passiert mit meinem Code, wenn mein Computer kaputt geht?**
Es passiert gar nichts, da Ihre Codes bereits sicher auf den Servern im Internet gespeichert sind.
