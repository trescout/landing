# Was ist Open-Source Clones?

*Glossar · Dev · Zuletzt aktualisiert: 15. Juni 2026*

Dabei handelt es sich um ähnliche Versionen beliebter Software, die durch öffentliches Kopieren ihrer Quellcodes erstellt wurden.

## Definition

Open-Source-Kopien übernehmen die Logik oder das Aussehen einer erfolgreichen Software und verwandeln sie in etwas, das jeder frei entwickeln kann. Dadurch können Communities ihre eigenen Alternativen erstellen, bei denen die Originalsoftware kostenpflichtig oder geschlossen ist. Somit können in der Softwarewelt Tools mit ähnlichen Features genutzt werden, ohne dass man von einem einzelnen Unternehmen abhängig ist.

***Analogie:** Es ist, als würde ein Koch sein geliebtes Geheimrezept der Öffentlichkeit zugänglich machen und jeder kann es nehmen und nachkochen, indem er Gewürze nach seinem eigenen Geschmack hinzufügt.*

## So funktioniert es

Entwickler nehmen den Quellcode des Originalprojekts und nutzen ihn als Grundlage für ihre eigenen Projekte. Anschließend nehmen sie eigene Verbesserungen oder Änderungen an diesem Code vor. Das resultierende Produkt ist eine neue Version, die dem Original sehr ähnlich ist, aber von der Community unterstützt wird.

## Wo es eingesetzt wird

Es wird in der Softwarewelt verwendet, wenn alternative Tools entwickelt oder leichter zugängliche Versionen einer bestimmten Software erstellt werden.

## Häufig verwechselt mit

Es kann sein, dass es einfach mit dem Begriff „Klonen“ verwechselt wird, aber dieser Begriff deckt speziell diejenigen ab, die Open Source sind und von der Community betrieben werden.

## Häufige Fragen

**Sind Open-Source-Kopien legal?**

Wenn die Lizenz der Originalsoftware dies zulässt, dann ist es völlig legal.

**Warum sollte ich eine Kopie und nicht das Original verwenden?**

Sie werden im Allgemeinen bevorzugt, weil sie kostengünstiger sind, Sie sie je nach Bedarf ändern können oder eine freiere Struktur bieten.
