# Was ist Executables?

*Glossar · Dev · Zuletzt aktualisiert: 5. Oktober 2026*

Programme, die der Computer direkt ausführen kann und die meistens als Installations- oder Anwendungsdateien bekannt sind.

## Definition

Executables, also ausführbare Dateien, enthalten in Maschinensprache übersetzte Befehle, die der Prozessor des Computers direkt lesen und ausführen kann. Unter Windows enden sie meist auf .exe, während sie auf anderen Betriebssystemen andere Erweiterungen haben können. Dies sind die finalen Dateien, die beim Anklicken im Hintergrund große Prozesse starten.

***Analogie:** Ähnlich wie Kuchenteig, der direkt in den Ofen geschoben werden kann, anstatt nur die Rezepte in einem Kochbuch zu lesen; der Prozessor beginnt sofort zu backen, sobald er den Teig sieht.*

## So funktioniert es

Entwickler schreiben Code, der menschlicher Sprache ähnelt, ein Compiler übersetzt diesen Code in die vom Computer verstandenen Binärzahlen, und das Ergebnis sind diese ausführbaren Dateien.

## Wo es eingesetzt wird

Wenn Sie ein neues Spiel auf Ihrem Computer installieren, einen Browser öffnen oder eine Desktop-Anwendung starten, sind diese Dateien immer im Einsatz.

## Häufig verwechselt mit

Wird oft mit Quellcode verwechselt; Quellcode ist lesbarer Rohtext, während eine ausführbare Datei das vom Computer direkt ausgeführte Ergebnis ist.

## Häufige Fragen

**Ist jede Datei ausführbar?**

Nein, eine Musikdatei oder ein Textdokument kann nicht von sich aus ausgeführt werden, sondern muss über ein Programm geöffnet werden.

**Ist es aus Sicherheitsgründen riskant?**

Ja, ausführbare Dateien aus unbekannten Quellen können Schadsoftware enthalten, die Ihrem Computer schaden kann.
