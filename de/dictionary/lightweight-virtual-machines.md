# Was ist Lightweight Virtual Machines?

*Glossar · Dev · Zuletzt aktualisiert: 14. Juni 2026*

Kleine virtuelle Computer, die schnell laufen, nur die notwendigen Ressourcen verbrauchen und sehr wenig Platz beanspruchen.

## Definition

Herkömmliche virtuelle Computer können schwer und langsam sein. Leichte virtuelle Maschinen hingegen sind kleine Softwareumgebungen, die nur die grundlegendsten Aufgaben ausführen und keine unnötigen Belastungen verursachen.

***Analogie:** Anstatt ein Paket mit einem riesigen LKW zu transportieren, können Sie es sich auch so vorstellen, als würden Sie ein schnelles und wendiges Motorrad fahren.*

## So funktioniert es

Das System nutzt die Ressourcen des Host-Computers sehr sorgfältig und wandelt nur den geringen benötigten Speicherplatz in eine virtuelle Maschine um.

## Wo es eingesetzt wird

Es wird im Cloud Computing verwendet, um Anwendungen schnell auszuführen oder eine Sicherheitsisolation bereitzustellen.

## Häufig verwechselt mit

Es kann mit vollwertigen virtuellen Maschinen (Virtual Machines) verwechselt werden, sie booten jedoch viel schneller.

## Häufige Fragen

**Warum sollte ich mich für das Leichtgewicht entscheiden?**

Da weniger Ressourcen verbraucht werden, können Sie mehr Vorgänge gleichzeitig ausführen.

**Sind leichtgewichtige virtuelle Maschinen sicher?**

Ja, es isoliert Anwendungen voneinander, da jede in ihrem eigenen kleinen Bereich ausgeführt wird.
