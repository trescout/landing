# Was ist Code Coverage?

Eine Metrik, die misst, wie viel der geschriebenen Code-Softwaretests tatsächlich ausgeführt und überprüft werden.

## Definition
Wir schreiben Tests, um zu verstehen, ob jede Codezeile, die Sie in einem Softwareprojekt schreiben, fehlerfrei funktioniert. Die Codeabdeckung berechnet, wie viel Prozent Ihres Codes diese Tests berühren. Ein hohes Verhältnis bedeutet, dass Ihr Code sicherer und getesteter ist.

## So funktioniert es
Während des Softwareentwicklungsprozesses werden automatisierte Testtools ausgeführt. Diese Tools überwachen jede Zeile Ihres Codes und markieren die Zeilen, die der Test durchläuft. Schließlich erhalten Sie einen Bericht wie „85 % des Codes getestet“.

## Wo es eingesetzt wird
Es wird in Softwareentwicklungsprozessen, CI/CD-Linien und Qualitätskontrollberichten verwendet.

## Häufige Fragen
**Ist eine 100-prozentige Codeabdeckung immer gut?**
Nein, es zeigt nur, dass der Code funktioniert; garantiert nicht, dass logische Fehler oder jedes Szenario abgedeckt werden.

**Wie messe ich das?**
Es kann automatisch mit Testbibliotheken gemessen werden, die für die von Ihnen verwendete Programmiersprache geeignet sind (z. B. cover.py für Python).
