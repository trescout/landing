# Was ist Static Typing?

Es gilt als Regel, dass die Datentypen im Programm beim Schreiben genau festgelegt werden, bevor der Code ausgeführt wird.

## Definition
In statisch typisierten Sprachen müssen Sie beim Erstellen einer Variablen zunächst angeben, ob es sich um eine Zahl oder einen Text handelt. Der Computer überprüft diese Definitionen, bevor er den Code ausführt. Wenn Sie versuchen, Text dort einzugeben, wo eine Zahl erwartet wird, gibt das Programm eine Fehlermeldung aus, bevor es überhaupt ausgeführt wird.

## So funktioniert es
Beim Schreiben von Code werden Variablen Typen zugewiesen. Der Compiler prüft diese Zuweisungen. Diese Methode reduziert das Fehlerrisiko bei großen Projekten erheblich.

## Wo es eingesetzt wird
Es wird in Sprachen wie Java, C++, Rust und TypeScript verwendet.

## Häufig verwechselt mit
Es wird mit dynamisch typisierten Sprachen (wie Python) verwechselt; In dynamischen Sprachen werden Typen bestimmt, während der Code ausgeführt wird.

## Häufige Fragen
**Sind statisch typisierte Sprachen schwieriger?**
Am Anfang müssen Sie etwas mehr Code schreiben, aber auf lange Sicht ist es sicherer, da Fehler in großen Projekten viel früher erkannt werden.
