# Was ist Web-based Solutions?

Dabei handelt es sich um Softwaredienste, auf die Sie nur über einen Internetbrowser zugreifen und diese nutzen können, ohne dass eine Installation auf Ihrem Computer erforderlich ist.

## Definition
Webbasierte Lösungen sind Software, bei der alle Daten und Verarbeitung auf einem Remote-Server stattfinden. Der Benutzer verbindet sich über den Browser mit diesem System und verhält sich so, als ob es auf seinem Computer installiert wäre. Auf diese Weise nimmt es keinen Platz im Speicher Ihres Geräts ein und Sie können von überall aus darauf zugreifen.

## So funktioniert es
Sie gehen zu einer Website-Adresse, melden sich an und die App wird in Ihrem Browser ausgeführt. Da alle Updates serverseitig erfolgen, müssen Sie nichts extra installieren.

## Wo es eingesetzt wird
Es wird häufig in E-Mail-Diensten, Online-Dokumenteditoren und cloudbasierten Geschäftstools verwendet.

## Häufig verwechselt mit
Kann mit Desktop-Anwendungen verwechselt werden; Desktop-Anwendungen beanspruchen physischen Speicherplatz auf dem Gerät, während webbasierte Anwendungen im Browser ausgeführt werden.

## Häufige Fragen
**Kann ich die Anwendung verwenden, wenn mein Internet unterbrochen ist?**
Normalerweise nein, da die Anwendung und die Daten auf dem Server liegen. Einige moderne Anwendungen bieten jedoch möglicherweise die Möglichkeit, offline zu arbeiten.

**Ist es sicher?**
Da sich Ihre Daten auf dem Server befinden, ist dies von den Sicherheitsmaßnahmen des Anbieters des Dienstes abhängig.
