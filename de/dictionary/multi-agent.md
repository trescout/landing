# Was ist Multi-agent?

*Glossar · AI · Zuletzt aktualisiert: 26. Juni 2026*

Dabei handelt es sich um die Zusammenarbeit von mehr als einer KI-Software für ein gemeinsames Ziel durch Aufteilung einer komplexen Aufgabe.

## Definition

In Multiagentensystemen agiert jeder Künstliche-Intelligenz-Agent als Mitarbeiter mit eigenem Fachgebiet. Während ein Agent plant, schreibt ein anderer Code und ein anderer prüft die Ergebnisse. Auf diese Weise werden Aufgaben, die ein einzelnes Modell alleine nur schwer bewältigen könnte, viel schneller und fehlerfrei in der Zusammenarbeit erledigt.

***Analogie:** Anstatt dass eine einzelne Person versucht, das gesamte Unternehmen zu leiten, ist es so, als ob ein auf verschiedene Abteilungen spezialisiertes Team zusammenkommt und an dem Projekt arbeitet.*

## So funktioniert es

Definieren Sie eine Hauptaufgabe und unterteilen Sie diese in Unterabschnitte. Weisen Sie jedem Teil einen Agenten mit besonderen Fähigkeiten zu. Verwalten Sie den Prozess, indem Sie sicherstellen, dass diese Agenten miteinander kommunizieren.

## Wo es eingesetzt wird

Es wird häufig in der Softwareentwicklung, komplexen Datenanalysen und automatisierten Arbeitsabläufen eingesetzt.

## Häufig verwechselt mit

Es unterscheidet sich von einem einzelnen KI-Modell. Wichtig hierbei ist die Interaktion der Agenten untereinander.

## Häufige Fragen

**Wie verstehen sich Agenten?**

Normalerweise erfolgt die Nachrichtenübermittlung über einen „Conductor“-Agenten oder ein vorgegebenes Kommunikationsprotokoll.

**Warum verwenden wir nicht ein einziges leistungsstarkes Modell?**

Wenn Aufgaben sehr komplex werden, werden kleinere Spezialmodelle kombiniert, um weniger Fehler zu machen und bessere Ergebnisse zu erzielen.
