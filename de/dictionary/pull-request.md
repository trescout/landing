# Was ist Pull Request?

*Entwicklung · Zuletzt aktualisiert: 5. November 2026*

> PR

Eine Anfrage, bei der ein Entwickler die Änderungen, die er in ein Code-Repository einfügen möchte, zur Überprüfung und Genehmigung vorlegt.

## Definition

Ein Pull Request stellt sicher, dass Änderungen am Code von anderen Teammitgliedern überprüft werden, bevor sie in das Hauptprojekt aufgenommen werden. Durch diesen Prozess werden Fehler frühzeitig erkannt und die Codequalität gewahrt. Er ist einer der Grundpfeiler kollaborativer Softwareentwicklungsprozesse.

***Analogie:** Es ist vergleichbar damit, wenn ein Autor ein neues Kapitel, das er einem Buch hinzufügen möchte, dem Verleger oder Chefredakteur zur Genehmigung vorlegt.*

## So funktioniert es

Der Entwickler schließt seine Entwicklung in seinem eigenen Arbeitszweig ab und sendet sie an das Repository. Anschließend eröffnet er einen Pull Request, um seine Teamkollegen zur Überprüfung des Codes einzuladen. Nach der Überprüfung wird das Feedback eingearbeitet, und sobald die Genehmigung erteilt wurde, wird der Code in den Hauptzweig zusammengeführt.

## Wo es eingesetzt wird

Wird bei der Verwaltung von Softwareprojekten auf Versionskontrollplattformen wie GitHub, GitLab und Bitbucket verwendet.

## Häufig verwechselt mit

Kann mit dem Konzept von Git Push verwechselt werden. Während Git Push Code-Änderungen auf den Server hochlädt, initiiert ein Pull Request einen Überprüfungs- und Diskussionsprozess, um diese Änderungen in den Hauptcode zu integrieren.

## Fragen und Antworten

**Warum ist ein Pull Request wichtig?**

Er verbessert die Codequalität, ermöglicht den Wissensaustausch innerhalb des Teams und verhindert, dass fehlerhafter Code in das Live-System gelangt.

**Kann ein Pull Request abgelehnt werden?**

Ja, wenn der Code nicht den Standards entspricht oder Mängel aufweist, kann er abgelehnt oder eine Überarbeitung angefordert werden.
