# Was ist Local-first Memory?

Ein Ansatz zur Informationsspeicherung, bei dem Daten direkt auf Ihrem Gerät gespeichert werden und jederzeit abgerufen werden können, ohne dass das Internet erforderlich ist.

## Definition
Ihre Informationen werden direkt auf Ihrem Computer oder Telefon statt auf Cloud-Servern gespeichert. Auf diese Weise können Sie auch dann auf Ihre Daten zugreifen und diese bearbeiten, wenn Ihre Internetverbindung unterbrochen ist. Es ist eine sehr sichere Methode in Bezug auf Datenschutz und Geschwindigkeit.

## So funktioniert es
Die Daten werden in einer lokalen Datenbank gespeichert und Apps auf Ihrem Gerät kommunizieren direkt mit diesen lokalen Dateien.

## Wo es eingesetzt wird
Es wird in datenschutzorientierten Notizanwendungen und lokalen Systemen der künstlichen Intelligenz eingesetzt.

## Häufig verwechselt mit
Man könnte es mit reinem Offline-Arbeiten verwechseln, aber bei diesem Ansatz haben Sie das vollständige Eigentum an den Daten.

## Häufige Fragen
**Gehen meine Daten verloren, wenn mein Gerät ausfällt?**
Da es lokal gespeichert ist, müssen Sie das Gerät sichern; Wie in Cloud-Systemen können für die automatische Sicherung zusätzliche Einstellungen erforderlich sein.
