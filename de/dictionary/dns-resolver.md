# Was ist DNS Resolver?

*Entwicklung · Zuletzt aktualisiert: 19. November 2026*

Ein System, das die Namen von Websites in numerische Adressen übersetzt, die von Computern verstanden werden.

## Definition

Wenn Sie eine Internetadresse in Ihren Browser eingeben, weiß Ihr Computer nicht direkt, auf welchem Server dieser Name läuft. An dieser Stelle kommt der DNS-Resolver ins Spiel und sucht in dem im Hintergrund laufenden riesigen Telefonbuch. Er wandelt die für Menschen lesbare Webadresse in eine IP-Adresse um, mit der sich Maschinen gegenseitig finden können.

***Analogie:** Das ist vergleichbar damit, den Namen eines Freundes in einem Telefonbuch nachzuschlagen, um dessen tatsächliche Telefonnummer herauszufinden.*

## So funktioniert es

Wenn Sie eine Adresse in Ihren Browser eingeben und die Eingabetaste drücken, geht die Anfrage zunächst an das Resolver-System Ihres Internetanbieters oder eines externen Dienstes. Der Resolver fragt so lange andere Server, bis er die entsprechende Adresse findet, und sendet die gefundene IP-Adresse an Ihren Computer zurück.

## Wo es eingesetzt wird

Er arbeitet im Hintergrund bei der gesamten Netzwerkkommunikation, in Webbrowsern und Serverkonfigurationen kontinuierlich.

## Häufig verwechselt mit

Er kann mit dem allgemeinen Begriff DNS verwechselt werden, aber dieser Begriff bezeichnet direkt den Server oder Software-Mechanismus, der den Adressauflösungsprozess durchführt.

## Fragen und Antworten

**Läuft dieses System immer, wenn ich ins Internet gehe?**

Ja, für jede Website-Adresse, die Sie in Ihren Browser eingeben, wird dieser Übersetzungsprozess im Hintergrund durchgeführt.

**Beeinflusst die Verwendung eines anderen Resolvers die Geschwindigkeit?**

Schnell arbeitende externe Resolver-Systeme können die Ladezeit von Websites im Millisekundenbereich verbessern.
