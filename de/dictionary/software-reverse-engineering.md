# Was ist Software Reverse Engineering?

Dabei handelt es sich um den Prozess der Rückwärtsanalyse des Codes oder der Struktur einer fertigen Software, um zu verstehen, wie sie funktioniert.

## Definition
Es handelt sich um eine Detektivarbeit, wenn Sie nur über ein funktionierendes Programm verfügen, aber keinen Zugriff auf dessen Quellcode haben. Durch die Analyse der Binärdateien des Programms decken Sie dessen Logik, Schwachstellen oder Funktionsprinzipien auf.

## So funktioniert es
Die Maschinencodes der Software werden durch den Einsatz spezieller Analysetools (Disassembler/Decompiler) lesbar gemacht. Anschließend werden Argumentationsprozesse für diese Codes ausgeführt.

## Wo es eingesetzt wird
Es wird in der Sicherheitsforschung, bei der Analyse von Wettbewerbssoftware oder bei der Modernisierung von Altsystemen eingesetzt.

## Häufig verwechselt mit
Es kann nicht mit dem Schreiben von Code verwechselt werden; Dabei geht es nicht darum, das Bestehende zu produzieren, sondern zu lösen.

## Häufige Fragen
**Ist es legal?**
Wird allgemein für die Sicherheitsforschung akzeptiert, es ist jedoch Vorsicht bei Urheberrechten und Lizenzvereinbarungen geboten.
