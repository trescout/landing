# Was ist Stealth Headless Browser?

Ein unsichtbarer Browser, der Firewalls auf Websites umgeht und verhindert, dass er als Bot erkannt wird.

## Definition
Dies sind Softwareprogramme, die keinen Bildschirm wie Standardbrowser haben, aber das Verhalten eines menschlichen Benutzers imitieren, um Websites zu besuchen. Dank der Stealth-Funktion können sie die von Websites verwendeten Bot-Abwehrsysteme umgehen. Auf diese Weise können Datenerfassungsprozesse unterbrechungsfrei fortgesetzt werden, indem sie wie ein normaler Benutzer erscheinen.

## So funktioniert es
Der Browser wird so konfiguriert, dass Details wie Bildschirmauflösung, Mausbewegungen und Software-Signatur menschliches Verhalten vortäuschen.

## Wo es eingesetzt wird
Wird für Aufgaben wie Web Scraping, automatisierte Tests und Preisüberwachung verwendet.

## Häufig verwechselt mit
Headless Browser

## Häufige Fragen
**Warum verwenden wir keinen normalen Browser?**
Normale Browser verbrauchen zu viele Ressourcen und können nicht Tausende von Prozessen gleichzeitig im Hintergrund ausführen.
