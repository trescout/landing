# Was ist Toolchain Bootstrapping?

*Glossar · Dev · Zuletzt aktualisiert: 1. August 2026*

Dabei handelt es sich um den Prozess der schrittweisen Verbesserung eines Softwaretools, bis es die Fähigkeit erreicht, sich selbst zu kompilieren oder zu erstellen.

## Definition

In der Softwarewelt benötigt man zum Erstellen eines Tools von Grund auf oft ein anderes Tool. Bootstrapping ist eine Methode, diesen Kreislauf zu durchbrechen, indem zunächst eine kleine und einfache Version erstellt und diese Version dann verwendet wird, um komplexere und fortgeschrittenere Versionen zu erstellen. Es ist eine Art autodidaktische Werkzeugbaukunst.

***Analogie:** Es ist, als würde man einen Roboter bauen, um in einer Fabrik Roboter herzustellen, indem man zunächst einen einfachen Schraubenzieher verwendet und dann mit diesem Roboter fortschrittlichere Roboter herstellt.*

## So funktioniert es

Zunächst wird ein grundlegender Code geschrieben und dieser Code eigenständig ausführbar gemacht. Anschließend wird durch Ergänzungen dieser Grundstruktur eine vollwertige Entwicklungsumgebung aufgebaut.

## Wo es eingesetzt wird

Es wird häufig bei der Entwicklung von Programmiersprachen-Compilern und Betriebssystem-Tools verwendet.

## Häufige Fragen

**Warum ist es so kompliziert?**

Wenn man etwas von Grund auf neu baut, ist es notwendig, die Abhängigkeit von außen vollständig zu eliminieren.
