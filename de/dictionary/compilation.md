# Was ist Compilation?

*Glossar · Dev · Zuletzt aktualisiert: 14. Juni 2026*

Dabei handelt es sich um den Prozess der Umwandlung von Codes, die der menschlichen Sprache ähneln, in Maschinensprache, die der Prozessor des Computers verstehen kann.

## Definition

Computer verstehen nur Befehle, die aus Nullen und Einsen bestehen. Programmierer hingegen verwenden gut lesbare Sprachen. Der Kompilierungsprozess verbindet diese beiden Welten und wandelt den Code in eine ausführbare Datei um.

***Analogie:** Es ähnelt einem Buch, das in einer Fremdsprache geschrieben wurde und vollständig in die Sprache des Lesers übersetzt und veröffentlicht wird.*

## So funktioniert es

Eine spezielle Software namens Compiler scannt Ihren Quellcode, prüft ihn auf Fehler und wandelt ihn in ein Binärformat um, das der Prozessor direkt ausführen kann.

## Wo es eingesetzt wird

Dies ist ein unbedingter Schritt, bevor das Programm in Sprachen wie C++, Rust und Java ausgeführt wird.

## Häufig verwechselt mit

Der Unterschied zu interpretierten Sprachen besteht darin, dass der Code vor der Ausführung vollständig transformiert wird, nicht zur Laufzeit.

## Häufige Fragen

**Müssen alle Sprachen kompiliert werden?**

Nein, einige Sprachen wie Python führen den Code sofort Zeile für Zeile aus, ohne dass ein Kompilierungsprozess erforderlich ist.
