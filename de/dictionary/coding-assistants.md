# Was ist Coding Assistants?

Dabei handelt es sich um auf künstlicher Intelligenz basierende Assistenten, die das Schreiben von Code beschleunigen, Fehler beheben und während des Softwareentwicklungsprozesses Vorschläge machen.

## Definition
Diese Tools funktionieren genauso wie ein erfahrener Entwickler, der neben Ihnen sitzt. Sie können die nächste Zeile vorhersagen, während Sie Code schreiben, komplexe Funktionen, die Sie schreiben, in einfacher Sprache erklären oder logische Fehler in Ihrem Code sofort erkennen. Ihr Ziel ist es, Entwicklern die routinemäßige Belastung zu nehmen, indem sie den Codierungsprozess effizienter gestalten.

## So funktioniert es
Sie werden normalerweise als Plug-in für einen Code-Editor (IDE) installiert. Wenn Sie mit dem Schreiben von Code beginnen, arbeiten diese Tools im Hintergrund und analysieren den Kontext, in dem Sie schreiben. Anschließend empfehlen sie Ihnen passende Codeblöcke oder beantworten Ihre Fragen entsprechend der Struktur Ihres Projekts.

## Wo es eingesetzt wird
Sie werden in gängigen Softwareentwicklungsumgebungen wie VS Code, IntelliJ oder Plattformen verwendet, auf die direkt über einen Webbrowser zugegriffen werden kann.

## Häufig verwechselt mit
Es wird oft mit „AI Coding Agent“ verwechselt; Während Assistenten eher auf Vorschläge und Anleitungen ausgerichtet sind, handelt es sich bei Agenten um autonomere Strukturen, die bestimmte Aufgaben durchgängig für Sie erledigen können.

## Häufige Fragen
**Können diese Tools den gesamten Code selbst schreiben?**
Normalerweise können sie kleine Stücke schreiben, aber bei großen Projekten ist die Führung und Kontrolle eines Menschen immer noch unerlässlich.

**Ist es sicher?**
Da Ihr Code an die Cloud gesendet wird, sollten Sie darauf achten, Ihre privaten Schlüssel oder sensiblen Daten nicht weiterzugeben.
