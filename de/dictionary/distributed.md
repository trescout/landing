# Was ist Distributed?

Dabei handelt es sich um die Aufteilung eines Jobs auf mehrere mit dem Netzwerk verbundene Geräte statt auf ein einzelnes Zentrum.

## Definition
Verteilte Systeme unterteilen große und komplexe Aufgaben in Teile und verteilen sie auf verschiedene Geräte, anstatt sie einem einzelnen Computer zu überlassen. Auf diese Weise arbeitet das System schneller und selbst wenn ein Gerät ausfällt, kann der Rest der Arbeit weitergeführt werden. Es ist das grundlegende Arbeitsprinzip groß angelegter Anwendungen.

## So funktioniert es
Das System unterteilt die zu erledigende Hauptarbeit in kleine Teile. Anschließend werden diese Teile über das Netzwerk an andere Computer gesendet. Jeder Computer beendet seinen Anteil und sendet das Ergebnis zurück an die Zentrale, die sie zusammenführt.

## Wo es eingesetzt wird
Es wird in Cloud-Computing-Systemen, bei Big-Data-Analysen und im Hintergrund moderner Webanwendungen eingesetzt.

## Häufig verwechselt mit
Mischbar mit Zentralsystemen; In zentralisierten Systemen liegt die gesamte Last auf einem einzigen leistungsstarken Computer.

## Häufige Fragen
**Warum machen wir nicht alles auf einem Computer?**
Die Rechenleistung und Speicherkapazität eines einzelnen Computers ist begrenzt; Verteilte Systeme ermöglichen es uns, diese Grenzen zu überwinden.

**Sind verteilte Systeme fehleranfälliger?**
Ja, es gibt zusätzliche Herausforderungen wie Netzwerkkonnektivität oder Gerätekompatibilität, aber bei korrekter Einrichtung ist es viel zuverlässiger.
