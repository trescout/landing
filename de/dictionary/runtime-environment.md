# Was ist Runtime Environment?

Die grundlegende unterstützende Umgebung, die eine Software benötigt, um auf einem Computer ausgeführt zu werden.

## Definition
Wenn Sie sich Softwarecode als Rezept vorstellen, ist diese Umgebung die Küche, in der dieses Rezept gekocht wird. Es stellt die Bibliotheken und Systemressourcen bereit, die für die Ausführung des Codes erforderlich sind.

## So funktioniert es
Wenn Sie ein Programm installieren, wird die von diesem Programm benötigte Umgebung normalerweise im Hintergrund installiert. Sie sehen es nicht, aber das Programm erhält bei jeder Ausführung Unterstützung von dieser Umgebung.

## Wo es eingesetzt wird
Es ist in Webbrowsern, Anwendungsservern und sämtlicher Software auf Betriebssystemebene zu finden.

## Häufig verwechselt mit
Nicht zu verwechseln mit der Software selbst; Diese Umgebung ist das Haus, in dem die Software lebt.

## Häufige Fragen
**Warum gibt es einen Fehler?**
Normalerweise wird eine Fehlermeldung ausgegeben, weil die erforderlichen Mediendateien fehlen oder die falsche Version haben.
