# Was ist Free Tier?

Free Tier ist die eingeschränkte kostenlose Version eines Dienstes.

## Definition und Wortherkunft
Tier bedeutet Ebene. Zur Einführung wird ein Paket mit begrenzten Kontingenten oder Funktionen angeboten. Wenn der Bedarf wächst, wird auf ein kostenpflichtiges Modell umgestiegen. Dies ist bei SaaS, KI-APIs und in der Cloud der Standard.

## Wie kann man es kennen und im täglichen Leben anwenden?
Test: Erstes Projekt mit API-Schlüssel.Hobby: Hosting für kleine Websites.Lernen: Ausprobieren neuer Tools.

## Häufig gestellte Fragen
**Unbegrenzt?**
Nein. Es gibt Mengen- oder Funktionsbeschränkungen, die in der Tabelle aufgeführt sind.

**Wann wird bezahlt?**
Wenn das Limit überschritten wird oder erweiterte Funktionen benötigt werden. Zuerst erfolgt eine Warnung.

**Wird eine Karte benötigt?**
Das hängt vom Dienst ab. Bei Diensten, die eine Karte verlangen, wird eine Limitüberschreitung automatisch berechnet.

**Wann erfolgt ein Upgrade?**
Wenn das Kontingent nicht ausreicht oder Support benötigt wird. Die Entscheidung wird vor Ablauf der Testphase getroffen.
