# Was ist Nameservers?

*Glossar · Dev · Zuletzt aktualisiert: 17. August 2026*

Es handelt sich um ein Telefonbuch, das von Menschen verwendete Website-Namen in numerische Adressen umwandelt, die Computer verstehen.

## Definition

Jede Website im Internet hat tatsächlich ein numerisches Äquivalent, eine sogenannte IP-Adresse. Wenn Sie einen Namen in Ihren Browser eingeben, leitet der Nameserver diesen Namen an die entsprechende IP-Adresse weiter, sodass Sie den richtigen Server erreichen können. Dies ist das Adressbuchsystem des Internets.

***Analogie:** Es ist, als würde man den Namen eines Freundes im Telefonbuch nachschlagen und seine tatsächliche Nummer herausfinden; Sie kennen den Namen, das System findet die Nummer.*

## So funktioniert es

Wenn Sie eine Webadresse eingeben, fragt Ihr Computer die Nameserver: Wie lautet die numerische Adresse dieses Namens? Der Nameserver gibt die Antwort zurück und Ihr Browser stellt eine Verbindung zu dieser Adresse her.

## Wo es eingesetzt wird

Es befindet sich zentral in den Domänennameneinstellungen und den Infrastrukturen von Internetdienstanbietern.

## Häufig verwechselt mit

Es kann mit Hosting verwechselt werden; Beim Hosting werden die Dateien Ihrer Site gespeichert, und der Nameserver ist der Pfad dorthin.

## Häufige Fragen

**Was bewirkt das Ändern der Nameserver-Einstellungen?**

Wenn Sie Ihre Website auf einen anderen Server verschieben, aktualisieren Sie normalerweise diese Einstellungen, sodass der Datenverkehr an den neuen Standort geleitet wird.

**Was passiert, wenn der Nameserver abstürzt?**

Sie können Websites nicht namentlich aufrufen, da Ihr Internetbrowser nicht finden kann, wo sich die Website befindet.
