# Was ist Type-safe?

Dabei handelt es sich um eine Disziplin, die den sicheren Betrieb von Software gewährleistet, indem sie eine falsche Verwendung von Datentypen verhindert.

## Definition
Es erfordert, dass nur Daten des dafür angegebenen Typs in eine Variable eingegeben werden. Wenn Sie beispielsweise versuchen, Text dort einzugeben, wo eine Zahl erwartet wird, bemerkt das System dies, bevor Sie es überhaupt ausführen. Dies verhindert die häufigsten Fehler im Softwareentwicklungsprozess.

## So funktioniert es
Wenn Sie Code schreiben, definieren Sie die Variablentypen (z. B. Zahl, Text, Datum). Wenn Sie die Software ausführen oder kompilieren, warnt Sie das System, wenn es etwas erkennt, das diesen Definitionen nicht entspricht.

## Wo es eingesetzt wird
Es wird verwendet, um die Fehlerquote in modernen Programmiersprachen und großen Softwareprojekten zu verringern.

## Häufige Fragen
**Was ist der Vorteil der Typsicherheit?**
Es ist weniger wahrscheinlich, dass der Code zur Laufzeit abstürzt, und er wird sicherer.

**Ist es in jeder Sprache verfügbar?**
Nein, einige Sprachen sind flexibler, andere haben strenge Regeln.
