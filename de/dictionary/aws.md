# Was ist Amazon Web Services?

> Amazon Web Services

Eine riesige Cloud-Plattform, auf der Sie IT-Dienste wie Server, Speicher und Datenbanken über das Internet mieten können.

## Definition
Anstatt Ihre eigenen physischen Server zu installieren, können Sie die riesigen Rechenzentren von Amazon auf der ganzen Welt nutzen, indem Sie diese über das Internet mieten. Sie können die Kapazität bei Bedarf erhöhen und sie reduzieren, wenn Sie fertig sind.

## So funktioniert es
Sie nutzen es, indem Sie über die Weboberfläche oder Softwaretools virtuelle Maschinen und Datenbanken erstellen.

## Wo es eingesetzt wird
Es wird im Hintergrund fast aller modernen Websites und Anwendungen verwendet.

## Häufig verwechselt mit
Es handelt sich nicht nur um einen Website-Hosting-Dienst; Es handelt sich um einen viel umfassenderen Infrastrukturdienst.

## Häufige Fragen
**Warum sollte ich AWS verwenden?**
Um sofort über eine Infrastruktur auf professionellem Niveau zu verfügen, ohne sich um Hardwarekosten kümmern zu müssen.
