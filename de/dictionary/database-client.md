# Was ist Database Client?

Ein Zwischenprogramm, mit dem Sie auf Informationen in der Datenbank zugreifen und diese verwalten können.

## Definition
Mit dem Datenbank-Client können Sie über eine visuelle Schnittstelle eine Verbindung zu auf Servern gespeicherten Daten herstellen. Sie können damit Tabellen untersuchen, Abfragen schreiben und Daten organisieren. Es ist eines der grundlegendsten Softwaretools zum Verwalten der Datenbank, ohne Code schreiben zu müssen.

## So funktioniert es
In die Benutzeroberfläche eingegebene Befehle oder Klicks werden vom Client an den Datenbankserver übermittelt. Die Antworten des Servers werden in Form von lesbaren Tabellen oder Listen auf dem Bildschirm angezeigt.

## Wo es eingesetzt wird
Es wird häufig in Softwareentwicklungsprozessen, Datenanalysestudien und Servermanagement eingesetzt.

## Häufig verwechselt mit
Nicht zu verwechseln mit dem Datenbankserver, der die Daten selbst speichert; Der Client ist lediglich die Schnittstelle und das Verwaltungstool.

## Häufige Fragen
**Welche Programme werden als Datenbank-Clients bezeichnet?**
In diese Kategorie fallen Software wie DBeaver, pgAdmin oder MySQL Workbench.
