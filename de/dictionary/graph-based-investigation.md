# Was ist Graph-based Investigation?

Dabei handelt es sich um eine Methode zur Entdeckung versteckter Verbindungen durch die Visualisierung der Beziehungen zwischen Daten auf einer Netzwerkkarte.

## Definition
Es ist schwierig zu verstehen, was in komplexen Datensätzen mit was zusammenhängt. Bei einer diagrammbasierten Untersuchung werden Daten als Punkte und Linien angezeigt, die diese Punkte verbinden. So können Sie beispielsweise in einem Betrugsfall auf einen Blick erkennen, welche Konten miteinander in Zusammenhang stehen.

## So funktioniert es
Daten werden als „Knoten“ und „Link“ in das System eingegeben. Die Software navigiert durch dieses Netzwerk und analysiert Gemeinsamkeiten oder ungewöhnliche Muster.

## Wo es eingesetzt wird
Es wird in der Finanzkriminalitätsanalyse, der Cybersicherheitsforschung und der Analyse sozialer Netzwerke eingesetzt.

## Häufig verwechselt mit
Nicht zu verwechseln mit einer gewöhnlichen Excel-Tabelle; Dabei kommt es nicht auf die Daten selbst an, sondern auf die Beziehung zwischen den Daten.

## Häufige Fragen
**Läuft es bei Big Data langsam?**
Wenn die richtigen Tools verwendet werden, können Millionen von Links in Sekunden analysiert werden.

**Können nur Experten es nutzen?**
Dank Visualisierungstools kann jeder, der Logik versteht, Zusammenhänge verfolgen.
