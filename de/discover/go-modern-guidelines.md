## Was es bringt
- Ermöglicht KI-Modellen die Nutzung aktueller Go-Funktionen
- Bevorzugt moderne und effiziente Methoden gegenüber alten Codemustern
- Erkennt automatisch die Go-Version des Projekts und passt die Sprachfunktionen entsprechend an

## Installation
**Marktplatz für Junie hinzugefügt**

```
/extensions marketplace add JetBrains/go-modern-guidelines
```

**Plugin-Installation für Junie**

```
/extensions install modern-go-guidelines
```


## Ausführung
**Führen Sie die Anleitung zu Claude Code aus**

```
/modern-go-guidelines:use-modern-go
```


## Wenn Sie nicht programmieren
Nutzen Sie ab sofort beim Schreiben von Code moderne Go-Standards. Berücksichtigen Sie die Version von Go in der Datei go.mod des Projekts und entscheiden Sie sich für die neuesten Sprachfunktionen und Standardbibliothekserweiterungen von Version 1.0 bis 1.27. Verwenden Sie Funktionen wie „max(a, b)“ anstelle von „if-else“-Blöcken, moderne Methoden wie „slices.Contains“ anstelle manueller Schleifen und aktuelle Muster wie „cmp.Or“ anstelle von Nullprüfungen.
