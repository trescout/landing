# Mehrsprachiges Sounddesign ohne Token

VoxCPM; Es handelt sich um ein tokenizerfreies Open-Source-TTS-Modell, das für mehrsprachige Sprachproduktion, kreatives Sounddesign und realistisches Stimmenklonen entwickelt wurde.

## Installation

**Mit PyPI installieren**

```
pip install voxcpm
```

## Ausführung

**Text in Sprache umwandeln**

```
voxcpm design --text "VoxCPM2 brings studio-quality multilingual speech synthesis." --output out.wav
```

## Was bietet es?

- Mehrsprachige und natürliche Sprachproduktion.
- Kreatives und originelles Sounddesign.
- Hochpräzises Stimmenklonen.

## Haftungshinweis

Beinhaltet das Klonen von Stimmen. Die Nachahmung der Stimme einer Person ohne Erlaubnis führt zu rechtlichen und ethischen Problemen. Die Verantwortung liegt beim Benutzer.

## Wie installiere ich, wie verwende ich?

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Führen Sie „pip install voxcpm“ aus, um das Text-to-Speech-Tool VoxCPM zu installieren, und generieren Sie dann eine Audiodatei mit dem Befehl „voxcpm design --text „Hello world“ --output out.wav“; Wenn ich möchte, klone ich diesen Sound mit „voxcpm clone“ mit einer Referenz-Sounddatei.
