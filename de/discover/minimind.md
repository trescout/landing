# Minimind

MiniMind ist ein Python-Projekt, das es ermöglicht, in der kurzen Zeit von zwei Stunden ein großes Sprachmodell mit 64 Millionen Parametern von Grund auf zu trainieren. Es bietet eine praktische Lernumgebung für Benutzer mit begrenzten Hardwareressourcen, um die Funktionsprinzipien von Modellen der künstlichen Intelligenz zu verstehen.
