# Leichter KI-Sprachsynthesizer, der auf der CPU läuft

Pocket-TTS wurde von Kyutai Labs entwickelt und ist ein leichtes Text-to-Speech-Modell, das nur auf der Zentraleinheit (CPU) läuft, ohne dass eine Grafikverarbeitungseinheit erforderlich ist. Dank seines geringen Ressourcenverbrauchs bietet es eine schnelle und effiziente Klangsynthese auf Geräten mit Hardware-Einschränkungen.

- ★ 9.348
- Python
- GitHub Trending · 2026-07-08

## Was es bringt
- Funktioniert nur mit dem Prozessor, ohne dass eine Grafikkarte erforderlich ist
- Bietet eine schnelle Tonwiedergabe bei geringem Ressourcenverbrauch
- Bietet Sprachklonen und Unterstützung für mehrere Sprachen

## Installation
**Paketinstallation**

```
pip install pocket-tts
# or
uv add pocket-tts
```


## Ausführung
**Erstellen Sie eine Audiodatei**

```
uvx pocket-tts generate
# or if you installed it manually with pip:
pocket-tts generate
```

**Start des lokalen Servers**

```
uvx pocket-tts serve
# or if you installed it manually with pip:
pocket-tts serve
```
