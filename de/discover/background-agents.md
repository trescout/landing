# Künstliche Intelligenz-Agenten, die autonome Software entwickeln

Background-Agents wurde von ColeMurray entwickelt und ist ein Open-Source-Codierungssystem für Hintergrundagenten, das auf TypeScript basiert. Es ermöglicht Entwicklern, Agenten der künstlichen Intelligenz (KI-Agenten) zu erstellen, die autonome Prozesse innerhalb von Anwendungen ausführen.

- ★ 2.329
- TypeScript
- GitHub Trending · 2026-07-13

## Was es bringt
- Ausführen autonomer Aufgaben im Hintergrund
- Zugriff auf vollständige Entwicklungsumgebungen
- Integriertes Arbeiten über Slack und GitHub

## Installation
**Abhängigkeiten installieren**

```
# .openinspect/setup.sh (provisioning)
#!/bin/bash
npm install
pip install -r requirements.txt
```


## Ausführung
**Starten der Arbeitsumgebung**

```
# .openinspect/start.sh (runtime startup)
#!/bin/bash
docker compose up -d postgres redis
```


## Wenn Sie nicht programmieren
Du bist ein Dämon. Ich möchte, dass Sie die von mir festgelegten Aufgaben mithilfe von Node.js, Python und Git-Tools autonom ausführen. Erstellen Sie während der Arbeit Commits, die zu dem von mir entwickelten Projekt passen, starten Sie bei Bedarf parallele Unteraufgaben und machen Sie Ihre Aktionen auf GitHub nachverfolgbar.
