# Überwachen Sie Ihre Tesla-Daten auf Ihrem eigenen Server

Teslamate wurde für Besitzer von Tesla-Fahrzeugen entwickelt und ist eine Datenlogger-Anwendung, mit der Sie Daten auf Ihrem eigenen Server hosten können. Dieses in der Elixir-Sprache geschriebene Open-Source-Tool visualisiert und präsentiert dem Benutzer detaillierte Statistiken wie den Fahrverlauf und Ladedaten.

## Was es bringt
- Analysieren Sie Fahr- und Ladedaten im Detail
- Überwachen Sie den Zustand und die Effizienz der Batterie
- Erhalten Sie die volle Datenkontrolle auf Ihrem persönlichen Server

## Installation
**Erstellen Sie die Datei docker-compose.yml aus dem offiziellen Handbuch (Datenbankkennwort und Verschlüsselungsschlüssel gehören Ihnen).**

```
docker compose pull
```


## Ausführung
**Start (http://localhost:4000)**

```
docker compose up -d
```
