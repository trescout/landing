# Suchen Sie auf Mobilgeräten nach Spuren von Cyberangriffen

Das Mobile Verification Toolkit ist ein forensisches Tool zur Erkennung von Sicherheitsverletzungen auf Mobilgeräten. Diese in Python entwickelte Software analysiert Gerätedaten und deckt mögliche Spuren von Cyberangriffen auf.

## Was es bringt

- Sammelt forensische Spuren auf Android- und iOS-Geräten
- Durchsucht nach Spuren bekannter Spyware-Kampagnen
- Führt Sicherheitsanalysen mit Befehlszeilentools durch

## Installation

**Mit pip installieren**

```
pip3 install mvt
```

**Mit uv installieren**

```
uv tool install mvt
```

## Ausführung

**Vervollständigungsskript erstellen**

```
mvt completion bash
```
