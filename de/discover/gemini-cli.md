# KI-Zugriff über die Befehlszeile

Das von Google entwickelte gemini-cli ist ein Open-Source-Tool, das direkten Zugriff auf das KI-Modell Gemini über das Terminal ermöglicht. Die Software erlaubt es Benutzern, schnell und leichtgewichtige KI-Prompts in einer Befehlszeilenumgebung zu erstellen.

## Was es bringt

- Sie können Ihre Codebasen direkt über die Befehlszeile untersuchen und bearbeiten.
- Sie können neue Anwendungen aus Bildern oder Textdokumenten erstellen.
- Sie können sich wiederholende Aufgaben mit Skripten automatisieren.

## Installation

**Globale Installation mit dem Paketmanager npm**

```
npm install -g @google/gemini-cli
```

**Installation mit dem Paketmanager Homebrew**

```
brew install gemini-cli
```

## Ausführung

**Direktes Ausführen ohne Installation**

```
# Using npx (no installation required)
npx @google/gemini-cli
```
