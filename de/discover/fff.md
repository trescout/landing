# Geschwindigkeit durch künstliche Intelligenz bei der Dateisuche

fff wurde mit Rust entwickelt und ist ein Toolkit für Agenten der künstlichen Intelligenz und Texteditoren, das Dateisuchen mit hoher Geschwindigkeit und Genauigkeit durchführt. Mit C- und NodeJS-Unterstützung bietet es eine Struktur, die in verschiedene Entwicklungsumgebungen integriert werden kann.

## Was es bringt

- Es bietet eine hohe Geschwindigkeit bei der Dateisuche und dem Durchsuchen von Inhalten.
- Es bietet eine frequenzbasierte Sortierung, die häufig verwendete Dateien priorisiert.
- Es bietet eine für Agenten und Redakteure der künstlichen Intelligenz optimierte Indizierung.

## Installation

**MCP-Server-Installation (Linux / macOS)**

```
curl -L https://dmtrkovalenko.dev/install-fff-mcp.sh | bash
```

**Installation des Pi Agent Plugins**

```
pi install npm:@ff-labs/pi-fff
```

## Ausführung

**Konfiguration für Agent**

```
For any file search or grep in the current git-indexed directory, use fff tools.
```
