# Intelligente Verträge, die mit Internetdaten arbeiten

GenLayer ist eine dezentrale Ausführungsschicht, die es Smart Contracts ermöglicht, direkt mit Daten im Internet zu interagieren. Mit dieser Vorlage (Boilerplate) können Entwickler mit TypeScript Anwendungen erstellen, die auf der Blockchain laufen und externe Daten verarbeiten können.

## Was es bringt
- Entwickeln Sie intelligente Verträge, die direkt auf Internetdaten zugreifen
- Integrieren Sie KI-gestützte Vorhersage- und Verifizierungsprozesse
- Beschleunigen Sie die Entwicklung mit Schnelltesttools

## Installation
**Vorbereiten der Python-Umgebung**

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Starten der Schnittstelle**

```
cd frontend
npm install
npm run dev
```


## Wenn Sie nicht programmieren
Entwickeln Sie für mich einen GenLayer-Smart-Vertrag. Dieser Vertrag sollte in der Lage sein, aktuelle Daten aus dem Internet abzurufen und logische Entscheidungen zu treffen, indem er diese Daten mit Modellen der künstlichen Intelligenz verarbeitet. Stellen Sie sicher, dass der Code den Linter-Regeln entspricht, um fehlerfrei zu sein, und erstellen Sie Testfälle, die direkt im Speicher ausgeführt werden, um während des Entwicklungsprozesses schnelles Feedback zu erhalten.
