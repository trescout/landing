# Verwalten Sie KI-Agenten in einem einzigen System

Openrig ist eine Multi-Agenten-Infrastruktur, die Anthropics Programmierwerkzeug Claude Code und OpenAIs Programmiermodell Codex in einem einzigen System zusammenführt. Sie ermöglicht Entwicklern, verschiedene KI-Modelle gleichzeitig im selben Arbeitsablauf zu nutzen.

## Was es bringt

- Kombiniert verschiedene KI-Programmiertool-Modelle in einer einzigen Infrastruktur.
- Definiert Agenteams mit YAML und startet sie mit einem einzigen Befehl.
- Bietet Ergebnisse durch die Gewährleistung der Koordination zwischen Agenten.

## Installation

**CLI-Tool installieren**

```
npm install -g @openrig/cli
rig setup --dry-run
```
