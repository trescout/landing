# Browser-Debugging für KI

Dieser für Chrome DevTools entwickelte Server ermöglicht es Codierungs-Agenten für künstliche Intelligenz, browserbasierte Debugging-Prozesse zu verwalten. Mithilfe des Model Context Protocol ermöglicht dieses Tool Agenten die direkte Inspektion von Webanwendungen und die Automatisierung von Debugging-Prozessen.

- ★ 49.801
- TypeScript
- GitHub Trending · 2026-07-03

## Was es bringt
- Steuern Sie den Live-Browser direkt
- Automatisierung der Leistungsanalyse
- Überprüfen Sie Netzwerkanfragen und Konsolenfehler

## Installation
**npm: global**

```
npm install -g chrome-devtools-mcp
```


## Wenn Sie nicht programmieren
Stellen Sie über den Chrome DevTools MCP-Server eine Verbindung zu meiner aktiven Browsersitzung her und analysieren Sie Leistungsdaten meiner Webanwendung. Überprüfen Sie Netzwerkanfragen, untersuchen Sie Konsolenfehler und führen Sie die erforderlichen Debugging-Schritte durch, um etwaige Probleme zu beheben.
