# Erkunden Sie die chinesische Geschichte auf der Karte

DeanChensj/jiangshan-map ist eine interaktive historische Atlas- und Zeitleistenanwendung, die die chinesische Geschichte anhand von 18 Dynastien untersucht. Dieses mit JavaScript entwickelte Projekt präsentiert die Entwicklung von Siedlungen von der Antike bis zur Gegenwart sowie klassische Gedichtrouten auf einer Karte mit 198 verschiedenen Regionalbildern.

## Was es bringt

- Bietet einen historischen Atlas und eine Zeitleiste von der Antike bis zur Gegenwart.
- Zeigt die Entwicklung von Siedlungen anhand von 198 verschiedenen Regionalbildern.
- Ermöglicht es Ihnen, klassische Gedichtrouten auf der Karte zu verfolgen.

## Installation

**Projekt herunterladen und lokalen Server starten**

```
git clone https://github.com/DeanChensj/jiangshan-map.git
cd jiangshan-map
python3 -m http.server 8000
```

**Mit Docker ausführen**

```
docker compose up -d --build
```

## Ausführung

**Einzelbildschirmfoto aufnehmen**

```
python3 skills/jiangshan-atlas/scripts/jiangshan.py --year 819 --place 蓝关 --out /tmp/languan_819.png
```
