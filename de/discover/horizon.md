# Persönliches KI-Nachrichten-Tracking-Radar

Thysrael/Horizon ist ein Nachrichten-Tracking-Tool, das Nachrichten aus verschiedenen Quellen mithilfe von künstlicher Intelligenz sammelt, filtert und zusammenfasst. Die Software erstellt tägliche Newsletter in Englisch und Chinesisch und hilft Benutzern, ihren Informationsfluss zu verwalten, indem sie Inhalte zusammen mit Kontext und Community-Diskussionen präsentiert.

## Was es bringt

- Sammelt und filtert Nachrichten aus verschiedenen Quellen automatisch.
- Erstellt tägliche Zusammenfassungs-Newsletter in Englisch und Chinesisch.
- Präsentiert Nachrichten zusammen mit Kontext und Community-Diskussionen.

## Installation

**Projekt klonen und Installation**

```
git clone https://github.com/Thysrael/Horizon.git
cd Horizon

# Install with uv (recommended)
uv sync

# Install test/development extras when needed
uv sync --extra dev

# Or with pip
pip install -e .
```

## Ausführung

**Assistenten starten**

```
uv run horizon-wizard
```
