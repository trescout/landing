# Künstliche Intelligenz, die Code auf Ihrem Computer ausführt

Open Interpreter bietet einen Codierungsagenten, der Softwareentwicklungsprozesse automatisiert, indem er Code in der lokalen Computerumgebung ausführt. Dieses Tool wurde für die Arbeit mit kostengünstigen Sprachmodellen entwickelt und ermöglicht die Ausführung komplexer Aufgaben direkt vom Terminal aus.

## Was es bringt
- Es automatisiert Softwareprozesse über das lokale Terminal.
- Es ist mit kostengünstigen Sprachmodellen kompatibel.
- Bietet die Möglichkeit, Web- und native Anwendungen zu testen.

## Installation
**Installation für macOS und Linux**

```
curl -fsSL https://www.openinterpreter.com/install | sh
```


## Ausführung
**Sitzung starten**

```
i
```


## Wenn Sie nicht programmieren
Ich möchte, dass Sie als Programmieragent auf meinem Computer fungieren. Ich erwarte von Ihnen, dass Sie komplexe Aufgaben automatisieren, indem Sie Code in meiner lokalen Umgebung ausführen und bei Bedarf Web- oder lokale Anwendungen testen. Verwenden Sie Strukturen, die kostengünstige Modelle bei der Durchführung von Transaktionen optimieren und führen Sie meine Befehle sicher über das Terminal aus.
