# Vorkonfiguriertes Set für Claude Code

Claude Code ist ein Toolkit mit Agenten, Befehlen und Hooks, das entwickelt wurde, um KI-gestützte Entwicklungsprozesse zu beschleunigen. Es vereint alle notwendigen Komponenten zur Automatisierung von Softwareentwicklungs-Workflows unter einem Dach.

## Was es bringt

- Bietet vorgefertigte Agenten und Befehle zur Automatisierung von Softwareentwicklungsprozessen.
- Verhindert Kontextverlust durch Speicherverwaltung zwischen Sitzungen.
- Automatisiert Standards wie TDD (Test-Driven Development) und Sicherheitsüberprüfungen.

## So fangen Sie an

Es wird empfohlen, zunächst die „Shorthand Guide“- und „Longform Guide“-Anleitungen auf der GitHub-Seite des Projekts zu lesen, um die grundlegende Philosophie zu verstehen. Für die Installation können Sie das Plugin direkt innerhalb von Claude Code als Marketplace-Erweiterung installieren oder die erforderlichen Dateien mit den oben genannten Befehlen in Ihr eigenes Verzeichnis verschieben, um mit der Nutzung zu beginnen.
