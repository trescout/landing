# Schnittstellenkenntnisse für Konstrukteure

UI-Skills wurde für Designingenieure entwickelt und vereint die technischen Fähigkeiten und Kompetenzen, die in Entwicklungsprozessen für Benutzeroberflächen (UI) erforderlich sind. Diese TypeScript-basierte Ressource bietet eine Kompetenzkarte für Fachleute, die vom Interface-Design zur Programmierung übergehen.

## Was es bringt

- Technische Kompetenzkarte in Schnittstellenentwicklungsprozessen
- Überbrückung der Lücke zwischen Design und Codierung
- Greifen Sie über die Befehlszeile auf Fertigkeiten zu

## Installation

**Starten des Tools**

```
npx ui-skills start
```

**Kategorien auflisten**

```
npx ui-skills categories
```

## Ausführung

**Sehen Sie sich eine bestimmte Kategorie an**

```
npx ui-skills list --category motion
```

**Erwerben Sie die Fähigkeit**

```
npx ui-skills get baseline-ui
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Als Designingenieur möchte ich meine Fähigkeiten in der Schnittstellenentwicklung verbessern. Listen Sie mit dem UI-Fähigkeiten-Tool die technischen Kompetenzen in der Bewegungskategorie auf und erläutern Sie die Schritte, die zum Erwerb der grundlegenden UI-Fähigkeiten erforderlich sind.
