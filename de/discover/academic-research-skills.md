# KI-Assistent für akademische Forschung

Academic Research Skills ist eine für Claude Code entwickelte Python-Bibliothek, die akademische Prozesse in den Phasen Recherche, Schreiben, Überprüfung, Bearbeitung und Finalisierung automatisiert. Dieses Tool zielt darauf ab, akademische Arbeitsabläufe auf dem KI-gestützten Codierungstool Claude Code zu standardisieren.

- ★ 46.471
- Python
- GitHub Trending · 2026-09-02

## Was es bringt
- Verwaltet den Prozess des Schreibens akademischer Artikel von Anfang bis Ende
- Automatisiert die Referenzsuche und Verifizierungsprozesse
- Verbessert die Schreibqualität durch Überprüfung der Texte

## Installation
**Erweiterung aus dem Store hinzufügen**

```
/plugin marketplace add Imbad0202/academic-research-skills
```

**Erweiterung installieren**

```
/plugin install academic-research-skills
```


## Ausführung
**Artikelplanung**

```
/ars-plan
```


## Wenn Sie nicht programmieren
Ich möchte das Academic Research Skills-Plugin verwenden, um meinen akademischen Forschungsprozess zu verwalten. Starte einen sokratischen Dialog, um die strukturelle Gliederung meines Artikels zu erstellen, und hilf mir bei der Steuerung des Prozesses, indem du bestimmst, in welcher Phase meiner Forschung ich mich befinde.
