# KI-gestütztes Sicherheitsoperationszentrum

AiSOC ist ein Open-Source-KI-Sicherheitszentrum zur Automatisierung von Sicherheitsoperationen. Das Tool, das Warnungen mithilfe großer Sprachmodelle (LLMs) klassifiziert und Untersuchungen im Rahmen des MITRE ATT&CK-Frameworks durchführt, kann ohne API-Schlüssel auf Ihrem eigenen Server ausgeführt werden.

## Was es bringt

- Erkennt Bedrohungen durch automatisches Klassifizieren von Daten aus Sicherheitstools
- Untersucht Vorfälle mit KI-Agenten und bietet konkrete Handlungsempfehlungen zur Freigabe
- Führt alle Prozesse sicher auf Ihrem eigenen Server aus, ohne externe Abhängigkeiten
