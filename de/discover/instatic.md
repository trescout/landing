# Modernes visuelles CMS auf Ihrem eigenen Server

Instatic ist ein modernes, selbst gehostetes visuelles Content-Management-System (CMS) auf Basis von TypeScript. Es ermöglicht Benutzern, die Content-Management-Schnittstelle mit einem schnellen Installationsprozess auf ihren eigenen Servern auszuführen.

## Was es bringt

- Konsolidieren Sie das gesamte Content-Management auf einem einzigen Server
- Bearbeiten Sie Seiten direkt mit KI
- Erstellen Sie eine saubere und schnelle HTML-Ausgabe

## Installation

**Schnelle Installation mit Docker**

```
INSTATIC_IMAGE=ghcr.io/corebunch/instatic:latest docker compose -f compose.prod.yml -f compose.sqlite.yml up -d
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Erstellen Sie mithilfe des Agenten für künstliche Intelligenz in der Seitenbearbeitungsoberfläche bearbeitbare Knoten, die den festgelegten Designkriterien entsprechen, eine semantische HTML-Struktur aufweisen und mit CSS formatiert sind. Ermöglichen Sie dem Agenten die Integration mit Modellen wie Claude, OpenAI oder OpenRouter, um die Seitenstruktur und Inhaltskomponenten automatisch zu erstellen.
