# Ein KI-Team, das auf Ihrem Desktop läuft

Orkas ist ein Open-Source-KI-Team, das auf Desktop-Computern läuft und Ziele in Aufgabenlisten umwandelt. Durch die Koordination von sechzehn integrierten Experten-Agenten und verschiedenen Codierungsmodellen bietet diese Anwendung einen lokal ausgerichteten Arbeitsbereich (local-first) unter macOS und Windows.

## Was es bringt

- Führt Forschungs-, Inhalts-, Design- und Codierungsaufgaben mit sechzehn integrierten Experten-Agenten aus.
- Speichert Ihre Projekte, Regeln und Dateien im Gedächtnis, um zu verhindern, dass Sie jedes Mal von vorne beginnen müssen.
- Bringt Ihre Arbeitsabläufe durch geplante Automatisierungen und Aufgabenlisten regelmäßig voran.

## Installation

**Projekt-Repository klonen und ausführen**

```
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```
