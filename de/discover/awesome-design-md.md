# Fertige Designdokumente für künstliche Intelligenz

Awesome-design-md ist eine Sammlung von Designdokumenten (DESIGN.md) aus beliebten Markendesignsystemen. Mithilfe dieser Dokumente können Software-Agenten für Projekte geeignete Benutzeroberflächen (UIs) erstellen.

## Was es bringt
- Bringen Sie die Designsprachen beliebter Marken in Ihre Projekte ein
- Sorgen Sie mit KI-Agenten für visuelle Konsistenz
- Integrieren Sie Designsysteme in Ihr Projekt, ohne Code schreiben zu müssen

## So fangen Sie an
- Offizielle Quelle →
Wählen Sie aus der Sammlung im awesome-design-md-Repository eine DESIGN.md-Datei aus, die zu Ihrem Projekt passt. Kopieren Sie den Inhalt der entsprechenden Datei und speichern Sie ihn als Textdatei im Hauptverzeichnis Ihres Projekts. Verweisen Sie dann einfach auf diese Datei auf das von Ihnen verwendete Codierungstool für künstliche Intelligenz und geben Sie den Befehl „Erstellen Sie mir eine Seite, die so aussieht“.
