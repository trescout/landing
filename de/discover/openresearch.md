# KI-Arbeitsbereich zur Beschleunigung von Forschungsprozessen

AlphaXiv ist ein Framework, mit dem Sie parallele Forschungsagenten unter Verwendung verschiedener KI-Modelle ausführen können. Dieses in Rust entwickelte Open-Source-Tool zielt darauf ab, Datenerfassungsprozesse in der akademischen und technischen Forschung zu beschleunigen.

## Was es bringt

- Erstellt unabhängige und parallele Agentensitzungen für verschiedene Forschungsideen.
- Sorgt für Nachvollziehbarkeit, indem Experimentergebnisse, Protokolle und Codeänderungen an einem Ort zusammengehalten werden.
- Verwaltet Forschungszyklen autonom auf Ihrem lokalen Computer oder auf Remote-Servern.

## Wenn Sie nicht programmieren

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich möchte ein Forschungsprojekt auf OpenResearch starten. Ich möchte, dass du einen KI-Agenten wie Claude Code oder OpenCode verwendest, um eine Literaturrecherche durchzuführen, Hypothesen zu entwickeln und Experimente zum Testen dieser Hypothesen zu entwerfen. Verwalte den Prozess autonom, indem du alle während der Arbeit gewonnenen Erkenntnisse, Experimentergebnisse und Codeänderungen im lokalen Arbeitsbereich von OpenResearch protokollierst.

Repository: https://github.com/alphaXiv/OpenResearch. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.
