# Anleitung zum Austauschen von Gesichtern in Bildern

Faceswap auf Python-Basis ist eine Open-Source-Software, die das Ersetzen von Gesichtern in Bildern mithilfe der Deepfake-Technologie ermöglicht. Es ermöglicht Benutzern, Gesichtsaustauschvorgänge an Videos und Bildern durchzuführen.

## Was es bringt

- Gesichtsveränderung in Bildern und Videos
- Training mit Deep-Learning-Modellen
- Gesichtsextraktion in visuellen Inhalten

## Installation

**Klon-Repository**

```
git clone --depth 1 https://github.com/deepfakes/faceswap.git && cd faceswap
```

## Ausführung

**Einrichtungsassistent**

```
python setup.py
```
