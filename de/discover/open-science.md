# KI-Arbeitsumgebung für wissenschaftliche Forschung

Open Science, entwickelt von AIPOCH, bietet eine Local-First- und modellunabhängige KI-Arbeitsumgebung für wissenschaftliche Forschung. Die Software kombiniert Python- und R-Notebooks mit Datenverbindungen, um die Durchführung wissenschaftlicher Prozesse auf reproduzierbare Weise zu ermöglichen.

- ★ 4.013
- TypeScript
- GitHub Trending · 2026-09-07

## Was es bringt
- Führen Sie reproduzierbare wissenschaftliche Analysen durch, indem Sie Python- und R-Code ausführen
- Erstellen Sie automatisierte Berichte, Tabellen und Grafiken durch Anbindung an wissenschaftliche Datenquellen
- Verwalten Sie den gesamten Prozess von der Literaturrecherche bis zur Simulation mit lokalen KI-Agenten

## Installation
**Lokale Installation aus dem Quellcode**

```
git clone https://github.com/aipoch/open-science.git
cd open-science
npm install
npm run dev
```

**Web-Interface-Entwicklungsmodus**

```
npm run build:web
npm run dev:web
```


## Wenn Sie nicht programmieren
Unterstütze mich bei meinem wissenschaftlichen Forschungsprozess. Hilf mir bei der Literaturrecherche, der Hypothesenentwicklung und bei Datenanalyseprozessen, indem du Python- oder R-Code schreibst. Verstehe meine Forschungsziele, lies Dateien, durchsuche das Web und frage wissenschaftliche Daten ab, um nachvollziehbare Ergebnisse, Tabellen und Grafiken zu erstellen.
