# Docling

Docling ist eine Python-Bibliothek, die komplexe Dokumentenformate in sauberen Text oder strukturierte Daten umwandelt, die von generativen KI-Modellen verarbeitet werden können. Sie analysiert verschiedene Dateitypen wie PDF, Word und HTML und erleichtert so die Nutzung der Daten in KI-Anwendungen.
