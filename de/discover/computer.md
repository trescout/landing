# Computersteuerung von Agenten der künstlichen Intelligenz

Computer wurde von Cloudflare entwickelt und ist eine TypeScript-Bibliothek, die Agenten künstlicher Intelligenz die Möglichkeit gibt, einen lokalen oder Remote-Computer zu steuern. Mit diesem Tool können Agenten Befehle auf dem Betriebssystem ausführen und komplexe Aufgaben automatisieren, indem sie auf das Dateisystem zugreifen.

## Was es bringt

- Ermöglicht Agenten, Befehle auf dem Betriebssystem auszuführen
- Automatisiert komplexe Aufgaben durch Zugriff auf das Dateisystem
- Bietet containerisierte oder isolierte Arbeitsumgebungen

## So fangen Sie an

Um dieses Tool verwenden zu können, müssen Sie zunächst das Cloudflare-Computerpaket in Ihr Projekt einbinden. Informationen zu Installationsschritten, einer Einstiegspunktkarte und Beispielen für die Dateisystemnutzung finden Sie in der README-Datei im Verzeichnis „packages/computer“ im GitHub-Repository.
