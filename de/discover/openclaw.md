# Der persönliche KI-Assistent, der auf Ihrem Gerät läuft

Openclaw ist ein KI-basiertes Automatisierungstool, das Aufgaben auf verschiedenen Betriebssystemen und Plattformen ausführen kann. Diese mit TypeScript entwickelte Software ermöglicht es Benutzern, Prozesse auf dem Computer zu standardisieren und zu automatisieren.

## Was es bringt

- Sie bewahren Ihre Daten, Ihren Speicher und Ihre Kontoinformationen vollständig und sicher auf Ihrem eigenen Computer auf.
- Sie können über die Messaging-Apps WhatsApp, Telegram, Discord und das Geschäftskommunikationstool Slack mit Ihrem Assistenten chatten.
- Sie können verschiedene KI-Modelle und lokale Systemtools ganz einfach über ein einziges Zentrum verwalten.

## Installation

**Automatisches Installationsskript ausführen (ma**

```
# macOS / Linux / WSL2
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Global mit dem Node.js-Paketmanager npm**

```
npm install -g openclaw@latest --allow-scripts=openclaw
```
