# Designexperten für Claude Code

Mithilfe des Agententeamsystems von Claude Code unterteilt Harness komplexe Missionen in koordinierte Teams spezialisierter Agenten. Mit dem Befehl „Geschirr einrichten für“ stellt es das erforderliche Team und die erforderlichen Fähigkeiten für Sie zusammen.

## Was es bringt

- Teilt komplexe Missionen in Teams spezialisierter Agenten auf.
- Es entwickelt die Fähigkeiten, die Teams benötigen.
- Automatisiert Arbeitsabläufe.

## So fangen Sie an

Als Fertigkeit zu Claude Code hinzugefügt; Anschließend können Sie sie bitten, ein Agententeam für den gewünschten Bereich zusammenzustellen.

## Wie installiere ich, wie verwende ich?

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Installieren Sie das Harness-Plugin, indem Sie die Befehle „/plugin marketplace add revfactory/harness“ und dann „/plugin install harness@harness-marketplace“ in Claude Code ausführen. Bitten Sie es dann, ein für mein Projekt geeignetes Agententeam für künstliche Intelligenz einzurichten, indem Sie sagen: „Erstellen Sie ein Harness für dieses Projekt“.

**Claude Code · Marktplatz + Installation**

```
/plugin marketplace add revfactory/harness
/plugin install harness@harness-marketplace
```
