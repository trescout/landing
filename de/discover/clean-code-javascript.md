## Was macht dieses Werkzeug?
Clean Code JavaScript ist ein Open-Source-Leitfaden, der die berühmten 'Clean Code'-Prinzipien von Robert C. Martin auf das JavaScript-Ökosystem anwendet. Er veranschaulicht Standards für das Schreiben von lesbarem, wiederverwendbarem und wartbarem Code mit modernem JavaScript.

## Für wen ist es?
Für diejenigen, die die Qualität ihres JavaScript-Codes verbessern und nachhaltige Software nach professionellen Standards entwickeln möchten.

## Was Sie nicht erwarten sollten
Absolute Anfänger, die die Sprache JavaScript noch nicht einmal auf einem grundlegenden Niveau beherrschen.

## Höhepunkte
- Adaptiert traditionelle Software-Engineering-Prinzipien auf JavaScript.
- Präsentiert schlechte und gute Codepraktiken im direkten Vergleich.
- Bietet einen breiten Umfang von der Variablenbenennung bis hin zum Fehlermanagement.

## Ablauf für die erste Nutzung
- Besuchen Sie das offizielle GitHub-Repository, um das Inhaltsverzeichnis zu prüfen.
- Lesen Sie die 'Bad'- und 'Good'-Codebeispiele für Konzepte, bei denen Sie besonders Schwierigkeiten haben.
- Wenden Sie die gelernten Prinzipien in Ihren eigenen Projekten an, um sie in die Praxis umzusetzen.
