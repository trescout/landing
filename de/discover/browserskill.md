# Verleihen Sie KI-Agenten Browser-Fähigkeiten

BrowserSkill, entwickelt von Tencent, ist ein Browser-Automatisierungstool, das es KI-Agenten ermöglicht, aktive Browsersitzungen zu verwalten, ohne die Arbeit des Benutzers zu unterbrechen. Über eine Befehlszeilenschnittstelle und eine Browser-Erweiterung ermöglicht es jedem KI-Agenten den Zugriff auf die Daten bereits angemeldeter Browsersitzungen.

## Was es bringt

- Nutzt vorhandene Browsersitzungen und Anmeldedaten direkt.
- Läuft im Hintergrund in einem separaten Fenster, ohne Ihren Arbeitsablauf zu unterbrechen.
- Ermöglicht menschliches Eingreifen bei Verifizierungs- oder Anmeldebildschirmen.

## Installation

**Installation für macOS und Linux**

```
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
export PATH="${BSK_INSTALL_DIR:-$HOME/.local/bin}:$PATH"
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Du hast eine Verbindung zu BrowserSkill, einem Browser-Automatisierungstool. Ab jetzt kannst du meine vorhandenen Browsersitzungen nutzen, um Aufgaben im Internet für mich zu erledigen. Wenn du eine Aktion ausführst, leihe dir meine offenen Tabs im Browser, gib sie nach Abschluss der Arbeit wieder frei und berühre meine anderen Tabs nicht. Wenn du auf einen Bestätigungscode, einen Anmeldebildschirm oder ein Bestätigungsfenster stößt, halte den Vorgang an und bitte mich um Hilfe.
