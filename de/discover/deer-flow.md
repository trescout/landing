# KI-Agent für komplexe Aufgaben

Deer-Flow wurde von ByteDance entwickelt und ist ein Open-Source-Superagenten-Framework, das für die Ausführung lang andauernder Aufgaben entwickelt wurde. System; Mithilfe von Sandbox, Speicherverwaltung und Subagenten kann es komplexe Arbeitsabläufe autonom recherchieren und programmieren.

## Was es bringt
- Autonome Recherche- und Programmierfähigkeit
- Arbeiten in einer sicheren Sandbox-Umgebung
- Langzeitgedächtnis und Subagentenverwaltung

## Installation
**Klonen des Repositorys**

```
git clone https://github.com/bytedance/deer-flow.git
   cd deer-flow
```

**Starten des Setup-Assistenten**

```
make setup
```


## Ausführung
**Starten mit Docker**

```
make docker-init    # Pull sandbox image (only once or when image updates)
make docker-start   # Start services (auto-detects sandbox mode from config.yaml)
```


## Wenn Sie nicht programmieren
Klonen Sie das DeerFlow-Repository auf meinen Computer und führen Sie dann den Befehl „make setup“ aus, um die erforderliche Konfiguration für die lokale Entwicklungsumgebung abzuschließen. Helfen Sie mir, während des Einrichtungsassistenten Optionen wie LLM-Anbieter, Websucheinstellungen und Sicherheitseinstellungen zu konfigurieren.
