# Beispielserver für KI-Agenten

Model Context Protocol (MCP)-Server ermöglichen es generativen KI-Modellen, über eine standardisierte Schnittstelle auf externe Datenquellen und Tools zuzugreifen. Dieses Protokoll erlaubt es verschiedenen KI-Anwendungen, sich sicher und konsistent mit Datenbanken oder Software-Tools zu verbinden.

- TypeScript

- **1. Oktober 2026:** Sterne 90,906 → 90,905, neueste Version 2026.8.31 (31. August 2026).

## Was es bringt

- Sie ermöglichen Ihren großen Sprachmodellen (LLM) den sicheren Zugriff auf lokale Dateien, Datenspeicher und persistente Speicher.
- Indem Sie Referenzserver-Beispiele prüfen, können Sie Ihre KI-Anwendungen mit externen Datenquellen zusammenbringen.
- Sie erhalten Zugriff auf vorgefertigte Vorlagen, um mit verschiedenen Software Development Kits (SDK) Ihre eigenen Server zu entwickeln.

## Installation

**Git-Server installieren und starten**

```
# With uvx
uvx mcp-server-git

# With pip
pip install mcp-server-git
python -m mcp_server_git
```

## Ausführung

**Speicher-Server ausführen**

```
npx -y @modelcontextprotocol/server-memory
```
