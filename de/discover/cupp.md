# Erstellen Sie eine gezielte Passwortliste

Common User Passwords Profiler ist ein Python-Tool zum Erstellen gezielter Passwortlisten. Durch die Analyse bestimmter Benutzerdaten werden maßgeschneiderte Wörterbuchdateien (Wortlisten) erstellt.

- ★ 6.161
- Python
- GitHub Trending · 2026-07-01

## Was es bringt
- Es erstellt maßgeschneiderte Wörterbücher durch die Analyse von Benutzerdaten.
- Es bietet die Möglichkeit, mit interaktiven Fragen ein zielgerichtetes Profil zu erstellen.
- Analysiert Standard-Benutzernamen- und Passwort-Übereinstimmungen mit der Alecto-Datenbank.

## Installation
**Klon-Repository**

```
git clone --depth 1 https://github.com/Mebus/cupp.git && cd cupp
```


## Ausführung
**Im interaktiven Modus ausführen**

```
python3 cupp.py -i
```
