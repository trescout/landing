# AWS-Toolset für KI-Agenten

AWS hat ein Toolset veröffentlicht, das Model Context Protocol-Server, Fähigkeiten und Plug-Ins umfasst, um die Interaktion von KI-Agenten mit der Cloud-Infrastruktur zu erleichtern. Diese Entwicklung bietet eine standardisierte Struktur, die es Agenten ermöglicht, direkt auf AWS-Diensten zu arbeiten.

## Wenn Sie nicht programmieren
Helfen Sie mir, Anwendungen auf AWS zu entwickeln, bereitzustellen und zu verwalten. Interagieren Sie mit AWS-Services mithilfe der Agent Toolkit for AWS-Funktionen, nehmen Sie die erforderlichen Konfigurationen vor und führen Sie Vorgänge in der Cloud-Infrastruktur gemäß Standards durch.
