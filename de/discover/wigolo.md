# Native Webfunktionen für Ihren KI-Agenten

Wigolo ist ein Tool, das lokale Such-, Datenextraktions- und Crawling-Funktionen für Codierungsagenten für künstliche Intelligenz bereitstellt. Dieses System, das über das Model Context Protocol (MCP) arbeitet, ermöglicht kostenlose Recherche ohne Cloud-Abhängigkeit und ohne die Notwendigkeit eines API-Schlüssels.

## Was es bringt
- Kostenlose Suche und Scan, kein API-Schlüssel erforderlich
- Cloud-agnostische lokale Datenverarbeitung und Zwischenspeicherung
- Direkte Integration mit gängigen KI-Tools

## Installation
**Agenteninstallation wird gestartet**

```
npx wigolo init --agents=<your-agent>
```

**Überprüfen des Systemzustands**

```
npx wigolo doctor
```


## Wenn Sie nicht programmieren
Verwenden Sie Wigolo, um im Internet zu recherchieren, Daten abzurufen und Ihre Ergebnisse unter Angabe von Quellen zusammenzufassen. Halten Sie sich bei der Durchführung von Transaktionen an das Local-First-Arbeitsprinzip, verwenden Sie einfache Tools, die keinen API-Schlüssel erfordern, und melden Sie Ihre Ergebnisse strukturiert.
