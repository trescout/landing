# Engine zum schnellen Ausführen und Bereitstellen von KI-Modellen

vllm-project/vllm ist eine Inferenz- und Bereitstellungsengine für große Sprachmodelle (LLMs), die einen hohen Durchsatz und Speichereffizienz bietet. Dieses in Python entwickelte Tool zielt darauf ab, die Ausführungsprozesse von KI-Modellen zu beschleunigen.

## Was es bringt

- bietet ein speichereffizientes PagedAttention-Management
- arbeitet kompatibel mit beliebten Hugging Face-Modellen
- enthält Unterstützung für einen OpenAI-kompatiblen API-Server

## Installation

**vLLM-Installation**

```
uv pip install vllm
vllm download-kernels  # precompiled kernels for faster startup
```
