# Zentraler Speicher für Agenten der künstlichen Intelligenz

Hivemind wurde von Activeloop entwickelt und bietet eine zentralisierte Speicherschicht für alle Agenten der künstlichen Intelligenz. Diese auf TypeScript basierende Struktur ermöglicht es verschiedenen Agenten, Daten auszutauschen und über einen gemeinsamen Informationspool zu kommunizieren.

## Was es bringt

- Es erstellt eine gemeinsame Speicher- und Koordinationsebene für alle Ihre KI-Agenten.
- Es wandelt erfolgreiche Lösungsmuster aus vergangenen Sitzungen automatisch in wiederverwendbare Fähigkeiten um.
- Es reduziert die Kosten, da Agenten das Ziel mit weniger Token und weniger Schritten erreichen können.

## Installation

**Allgemeine Einrichtung**

```
npm install -g @deeplake/hivemind && hivemind install
```

## Ausführung

**Statusprüfung**

```
hivemind status
```
