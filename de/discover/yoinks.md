# Schneller Video-Download über das Terminal

Yoinks ist ein Tool zum Herunterladen beliebiger Videos über das Terminal (Befehlszeile) ohne Werbung oder Weiterleitungen. Diese mit TypeScript entwickelte Software bietet eine praktische Methode, Videodateien direkt auf den lokalen Speicher zu übertragen.

- ★ 3.165
- TypeScript
- GitHub Trending · 2026-10-02

## Was es bringt
- Lädt Videos von über 1800 Websites wie YouTube, Instagram und TikTok herunter
- Speichert direkt auf dem lokalen Speicher ohne Werbung oder gefälschte Download-Buttons
- Bietet die Möglichkeit, die Videoauflösung zu wählen oder nur die Audiodatei zu extrahieren

## Installation
**Global installieren**

```
npm install -g yoinks
```

**Betrieb ohne Installation**

```
npx yoinks
```


## Ausführung
**Starten mit Videolink**

```
yoinks https://youtu.be/dQw4w9WgXcQ
```

**Starten mit interaktivem Menü**

```
yoinks
```


## Wenn Sie nicht programmieren
Ich möchte Videos von Plattformen wie YouTube, X, Instagram oder TikTok herunterladen. Konfiguriere dieses Terminal-Tool so, dass es den von mir bereitgestellten Videolink direkt in meinem lokalen Download-Ordner speichert und mir Auflösungsoptionen anbietet. Stelle sicher, dass der Download-Prozess sauber abläuft und keine Werbung oder Weiterleitungen enthält.
