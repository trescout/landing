# Umgehen Sie die Internetzensur mit Kotlin

Das Fanqiang-Projekt ist ein in Kotlin geschriebenes Gateway-Tool, das entwickelt wurde, um die Internet-Zensur zu umgehen. Es handelt sich um Open-Source-Software, die Benutzern den Zugriff auf begrenzte Netzwerkressourcen ermöglichen soll.

## Was es bringt

- Bietet Zugriff auf umfassende Netzwerkzugriffshandbücher für verschiedene Betriebssysteme und Geräte.
- Bietet Konfigurations- und Nutzungshandbücher für verschiedene Netzwerkprotokolle und -tools.
- Es umfasst Methoden zur Umgehung von Netzwerkbeschränkungen auf verschiedenen Plattformen wie Spielekonsolen und Browsern.

## So fangen Sie an

Das Fanqiang-Projekt ist keine direkte Softwareinstallation, sondern eine umfassende Bibliothek mit Anleitungen und Tools. Navigieren Sie je nach benötigtem Gerätetyp (Windows, macOS, Android, iOS oder Spielekonsole) zum entsprechenden Ordner oder zur entsprechenden Wiki-Seite auf GitHub. Laden Sie die empfohlenen Tools herunter, indem Sie den Links im entsprechenden Handbuch folgen, und schließen Sie Ihre Konfiguration ab, indem Sie die mitgelieferten Benutzerhandbücher sorgfältig lesen.
