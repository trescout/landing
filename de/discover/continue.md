# Künstliche Intelligenz unterstützt Codierungsprozesse

Continue ist ein Open-Source-Coding-Agent zur Automatisierung von Softwareentwicklungsprozessen. Es ermöglicht Entwicklern, Code innerhalb der IDE unter Verwendung ihrer nativen Sprachmodelle (LLM) zu schreiben, zu debuggen und umzugestalten.

- ★ 35.282
- GitHub Trending · 2026-06-18

## Was es bringt
- Beschleunigt Codierungs- und Debugging-Prozesse
- Bietet einen sicheren Arbeitsplatz mit lokalen Sprachmodellen
- Lässt sich in Softwareentwicklungsumgebungen wie VS Code und JetBrains integrieren

## Installation
**npm: CLI (global) installieren**

```
npm i -g @continuedev/cli
```

**Als VS Code-Erweiterung installieren**

```
code --install-extension Continue.continue
```

**npm: global**

```
npm install -g continue
```


## Ausführung
**Continue-Agent per CLI starten**

```
cn
```


## Wenn Sie nicht programmieren
Führen Sie mich als Software-Entwicklungsassistent durch den Prozess des Schreibens von Code unter Verwendung muttersprachlicher Modelle, der Umstrukturierung bestehender Codeblöcke und des Debuggens. Analysieren Sie die Dateien in meiner Arbeitsumgebung, machen Sie Vorschläge zur Verbesserung der Codequalität und helfen Sie mir, komplexe logische Fehler zu erkennen.
