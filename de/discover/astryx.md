# Mit künstlicher Intelligenz kompatibles Designsystem

Astryx wurde von Meta entwickelt und bietet ein Designsystem, das vollständig anpassbar und mit Agenten der künstlichen Intelligenz kompatibel ist. Diese TypeScript-basierte Open-Source-Bibliothek konfiguriert Schnittstellenkomponenten für den Einsatz autonomer Systeme.

- ★ 11.769
- TypeScript
- GitHub Trending · 2026-07-01

## Was es bringt
- Mehr als 150 zugängliche Komponenten
- API kompatibel mit KI-Assistenten
- Flexible Struktur ohne stilistische Einschränkungen

## Installation
**Pakete installieren**

```
# npm
npm install @astryxdesign/core @astryxdesign/theme-neutral
npm install -D @astryxdesign/cli

# pnpm
pnpm add @astryxdesign/core @astryxdesign/theme-neutral
pnpm add -D @astryxdesign/cli

# yarn
yarn add @astryxdesign/core @astryxdesign/theme-neutral
yarn add -D @astryxdesign/cli
```
