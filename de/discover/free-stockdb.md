# Lokale Börsendaten- und Analyse-Engine

Free-stockdb ist eine native quantitative Analyse-Engine, die Tages- und Minutendaten für A-Aktien und Exchange Traded Funds (ETFs) verarbeitet. Das System vereint Funktionen wie inkrementelle Synchronisierung von Daten, lokales Caching, Preiskorrektur, Backtesting und Berechnung technischer Indikatoren.

## Was es bringt
- Speichern Sie alle Börsendaten auf Ihrem Computer
- Berechnen Sie 39 verschiedene technische Indikatoren in Sekunden
- Direkte Integration mit Python-, Excel- und KI-Tools

## So fangen Sie an
- Offizielle Quelle →
Wenn Sie ein Windows-Benutzer sind, laden Sie die aktuelle Version aus dem Abschnitt „Releases“ auf der GitHub-Seite herunter. Nachdem Sie die heruntergeladene Datei geöffnet haben, führen Sie das Datenaktualisierungstool aus und warten Sie, bis die Daten mit Ihrem lokalen Ordner synchronisiert wurden. Starten Sie dann die Stockdb-Anwendung.
