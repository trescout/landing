# Entwickeln Sie Unternehmensanwendungen, ohne Code schreiben zu müssen

ToolJet ist eine Open-Source-Plattform zur Anwendungserstellung für die Entwicklung interner Tools, Dashboards und Agenten für künstliche Intelligenz. Diese JavaScript-basierte Infrastruktur ermöglicht es Unternehmen, komplexe Arbeitsabläufe zu digitalisieren, indem sie die Notwendigkeit reduziert, Code zu schreiben.

## Was es bringt
- Schnelles visuelles Interface-Design mit Drag-and-Drop-Methode
- Einfache Integration mit Datenbank-, API- und Cloud-Diensten
- Flexible Workflows mit JavaScript- und Python-Unterstützung

## Installation
**Lokale Installation mit Docker**

```
docker run \
  --name tooljet \
  --restart unless-stopped \
  -p 80:80 \
  --platform linux/amd64 \
  -v tooljet_data:/var/lib/postgresql/13/main \
  tooljet/try:ee-lts-latest
```


## Wenn Sie nicht programmieren
Helfen Sie mir, mit über 60 vorgefertigten Komponenten auf ToolJet ein mit der Datenbank verbundenes internes Bedienfeld per Drag-and-Drop zu erstellen. Entwerfen Sie eine Anwendungsarchitektur, die Daten visualisiert und teaminterne Arbeitsabläufe automatisiert, die ich mithilfe von JavaScript und Python anpassen kann.
