Verwalten Sie KI-Modelle in einer einzigen Oberfläche

Aisuite wurde von Andrew Ng entwickelt und ist eine Python-Bibliothek, die die Verwaltung verschiedener generativer KI-Anbieter über eine einzige Schnittstelle ermöglicht. Es ermöglicht Entwicklern, zwischen verschiedenen Modelldiensten zu wechseln, ohne Codeänderungen vorzunehmen.

Aktualisierungen

  • 2. August 2026: Sterne 14,220 → 15,888, neueste Version v0.1.3 (20. Juli 2026).

Was es bringt

  • Verwalten Sie verschiedene KI-Anbieter über eine einzige Schnittstelle
  • Möglichkeit, zwischen Modellen zu wechseln, ohne den Code zu ändern
  • Definition von Python-Funktionen als Werkzeuge für künstliche Intelligenz

Installation

Grundlegende Bibliotheksinstallation
pip install aisuite               # base package, no provider SDKs
Einrichtung bei allen Anbietern
pip install 'aisuite[all]'        # with all provider SDKs

Wie kann ich mithilfe der Aisuite-Bibliothek verschiedene Modelle der künstlichen Intelligenz über eine einzige Schnittstelle verwalten?
