# SwiftUI-Expertise für Ihren KI-Assistenten

SwiftUI-Agent-Skill bietet KI-Modellen spezielle Fähigkeitspakete (Skills) für das UI-Entwicklungstool SwiftUI. Diese Ressource hilft KI-Codierungsassistenten wie Claude Code und Codex dabei, SwiftUI-Komponenten konsistenter und schneller zu erstellen.

## Was es bringt

- Lässt die KI Performance- und Barrierefreiheitsfehler in Code überprüfen, der mit der Apple-UI-Bibliothek SwiftUI geschrieben wurde.
- Verhindert, dass große Sprachmodelle veraltete Anwendungsschnittstellen (APIs) verwenden, und beugt Bildschirmleseproblemen vor.
- Lässt sich leicht in die Codierungsassistenten Claude Code und Codex integrieren und vermittelt moderne Codestandards.

## Installation

**Node-Umgebung mit dem Paketmanager Homebrew**

```
brew install node
```

**SwiftUI Pro-Fähigkeit für KI-Assiste**

```
npx skills add https://github.com/twostraws/swiftui-agent-skill --skill swiftui-pro
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Falls die Laufzeitumgebung Node nicht auf meinem Computer installiert ist, installiere sie mit dem Befehl 'brew install node'. Führe danach den Befehl 'npx skills add https://github.com/twostraws/swiftui-agent-skill --skill swiftui-pro' aus, um meinem Codierungsassistenten SwiftUI-Expertise zu verleihen und diese Fähigkeit für meine Projekte einsatzbereit zu machen.
