# Führen Sie alle KI-Modelle in einer einzigen Oberfläche zusammen

LibreChat ist eine Open-Source-Chat-Plattform, die verschiedene KI-Modelle und Tools in einer einzigen Oberfläche vereint. Diese Software, die Benutzer auf ihren eigenen Servern hosten können, bietet ein personalisiertes KI-Erlebnis mit Funktionen wie Modellwechsel und Multi-User-Authentifizierung.

- TypeScript

## Was es bringt

- Verwalten Sie verschiedene KI-Modelle über ein einziges Dashboard
- Richten Sie eine sichere und private Chat-Umgebung auf Ihrem eigenen Server ein
- Nutzen Sie fortschrittliche Tools wie Dateiverarbeitung und Websuche
