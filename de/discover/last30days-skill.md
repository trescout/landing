# KI-unterstützte Zusammenfassung der letzten 30 Tage

Last30days-skill bietet einen Skill für künstliche Intelligenz (AI-Agent-Skill), der aktuelle Daten durch Recherchen auf Plattformen wie Reddit, X, YouTube, Hacker News und Polymarket synthetisiert. Dieses Python-basierte Tool kombiniert Informationen aus verschiedenen Quellen, um überprüfbare Zusammenfassungen für Benutzer zu erstellen.

## Was es bringt

- Es synthetisiert aktuelle Daten von Plattformen wie Reddit, X, YouTube und Polymarket.
- Es liefert überprüfbare Zusammenfassungen basierend auf sozialen Interaktionen und Echtzeitdaten.
- Es ermöglicht Benutzern, mit einer einzigen Suche auf aktuelle Entwicklungen auf mehreren Plattformen zuzugreifen.
