# Schneller Python-Linter und -Formatter

Ruff ist ein extrem schneller Python-Linter und -Formatter, der mit der Programmiersprache Rust entwickelt wurde. Er wird verwendet, um die Codequalität bei der Softwareentwicklung zu verbessern und Formatierungsprozesse zu beschleunigen.

## Aktualisierungen

- **7. November 2026:** Sterne 50,736 → 50,736, neueste Version 0.17.4 (5. November 2026).

## Was es bringt

- Arbeitet im Vergleich zu bestehenden Tools Dutzende Male schneller
- Kombiniert Linting- und Formatierungsaufgaben in einem einzigen Tool
- Bietet Unterstützung für die automatische Fehlerbehebung in Python-Projekten

## Installation

**mit pip installieren**

```
pip install ruff
```

**Installation mit UV**

```
uv tool install ruff@latest
```

## Ausführung

**Code-Linting ausführen**

```
ruff check
```

**Code-Formatierung ausführen**

```
ruff format
```
