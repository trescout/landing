# Einheitlicher Arbeitsbereich für KI-Agenten

holaOS ist ein Open-Source-Arbeitsbereich, der verschiedene Agenten der künstlichen Intelligenz (Claude Code, Codex) mit Ihren Tools, Anwendungen und Dateien über einen gemeinsamen Speicher kombiniert. Mit über 100 Integrationen und Model Link Protocol (MCP)-Unterstützung ermöglicht es Benutzern, ihre eigenen Modelle (BYOK) oder integrierten Modelle in einer einzigen Schnittstelle zu verwalten.

## Was es bringt
- Es führt verschiedene Agenten wie Claude Code und Codex in einer einzigen Schnittstelle mit gemeinsam genutztem Speicher aus.
- Mit einem Klick können Sie eine Verbindung zu mehr als 50 beliebten Geschäftstools wie Gmail, Notion und Slack herstellen.
- Sie können integrierte KI-Modelle verwenden oder Ihre eigenen API-Schlüssel hinzufügen.

## Installation
**Schnellinstallationsbefehl**

```
curl -fsSL https://raw.githubusercontent.com/holaboss-ai/holaOS/refs/heads/main/scripts/install.sh | bash -s -- --launch
```


## Ausführung
**Starten der Entwicklungsumgebung**

```
npm run desktop:dev
```


## Wenn Sie nicht programmieren
Du bist mein KI-Assistent. Ich möchte, dass Sie in meinem holaOS-Arbeitsbereich an meinen Dateien, Tools und Apps arbeiten. Erinnern Sie sich mithilfe des Shared Memory an den Kontext meiner vergangenen Projekte und führen Sie meine Aufgaben durch die Integration von Agenten wie Claude Code oder Codex aus. Verwalten Sie meine Arbeitsabläufe, erstellen Sie Berichte und speichern Sie sie als tatsächliche Dateien (.xlsx, .pptx, .docx), indem Sie Daten aus meinen verbundenen Konten wie Notion, Gmail und Slack verwenden.
