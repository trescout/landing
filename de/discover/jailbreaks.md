# Sammlung von Befehlen für KI-Modelle

togg53192-cmd/jailbreaks bietet eine Sammlung von System-Prompts, Persönlichkeits-Locks und Arbeitsbereichsrichtlinien, die darauf abzielen, die Sicherheitsbeschränkungen von KI-Modellen zu umgehen. Diese Arbeit stellt eine technische Zusammenstellung dar, die darauf abzielt, die Funktionsweise verschiedener Open-Weight- und Closed-Source-Modelle zu verändern.

- GitHub Trending · 2026-10-27

## Was es bringt

- Bietet spezifische System-Prompts für verschiedene KI-Modelle
- Enthält Persönlichkeits-Locks und Arbeitsbereichsrichtlinien
- Ermöglicht Forschern die Untersuchung von Modellverhalten

## So fangen Sie an

Klicken Sie in der Liste auf GitHub auf die Datei des Modells, an dem Sie interessiert sind, um den Inhalt anzuzeigen. Kopieren Sie anschließend den gesamten Text und fügen Sie ihn in das Feld für System-Prompts oder benutzerdefinierte Anweisungen Ihres KI-Tools ein. Wenn Sie lokale Tools wie Ollama verwenden, können Sie den Inhalt der entsprechenden Datei direkt in die Konfigurationsbereiche einfügen.
