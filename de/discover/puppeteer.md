# Verwalten Sie Browser automatisch mit Code

Puppeteer ist eine Browser-Automatisierungsbibliothek zur Steuerung von Chrome- und Firefox-Browsern. Dieses mit TypeScript entwickelte Tool bietet eine Standardschnittstelle für Testautomatisierung und Web-Scraping-Vorgänge auf Webseiten.

- ★ 95.731
- GitHub Trending · 2026-06-15

**Hinweis von TreScout:** Damit können Sie den Browser nicht manuell, sondern mit Code nutzen: Öffnet die Seite, klickt, füllt ein Formular aus, erstellt einen Screenshot oder ein PDF. Playwright, das die gleiche Aufgabe erfüllt, ist umfassender. Wenn Sie mehr als einen Browser benötigen, schauen Sie dort nach. Die Installation lädt auch eine Kopie des Browsers herunter, die Speicherplatz beansprucht.

## Was es bringt

- Die Software steuert Chrome- und Firefox-Browser
- Erstellt automatische Testprozesse auf Webseiten
- Entfernt Daten von Websites

## Installation

**Mit npm (Node.js)**

```
npm i puppeteer
```

**npm: hinzufügen**

```
npm install puppeteer
```

## Wenn Sie nicht programmieren

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Sie sind Experte für Webautomatisierung. Erstellen Sie mithilfe der Puppeteer-Bibliothek ein einfaches JavaScript-Skript, das eine Webseite öffnet, Text in ein bestimmtes Feld schreibt und die Ergebnisse auf dem Bildschirm ausgibt. Stellen Sie ein Codebeispiel bereit, das Schritte zum Starten des Browsers, zum Erstellen einer neuen Seite, zum Navigieren zu einer URL und zum Drucken des Seitentitels in der Konsole enthält.

Repository: https://github.com/puppeteer/puppeteer. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.
