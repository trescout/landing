# Kopieren Sie Repositorys in GitHub-Workflows

Actions/Checkout wurde von GitHub entwickelt und ist ein Tool, das Repository-Checkout-Prozesse in Softwareentwicklungsprozessen automatisiert. Durch die kontinuierliche Integration kann der Quellcode in Workflows in die Arbeitsumgebung übertragen werden.

## Was es bringt

- Automatische Lagerkopiervorgänge
- Sicheres Anmeldeinformationsmanagement
