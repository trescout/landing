# Gleichzeitiger Browser für KI-Agenten

Ego-lite ist ein Browser, der es Benutzern und Agenten der künstlichen Intelligenz ermöglicht, gleichzeitig zu arbeiten. Dieses JavaScript-basierte Tool zielt darauf ab, die Interaktion von Mensch und Maschine parallel in derselben Browserumgebung durchzuführen.

## Was es bringt

- Agenten und Benutzer werden ohne Konflikte im selben Browser ausgeführt
- Schützt Sitzungen durch den Import von Chrome-Daten
- Schnellere Aufgabenerledigung mit JavaScript-basierter Struktur

## Installation

**Fähigkeiten hinzufügen**

```
npx skills add citrolabs/ego-lite
```

## Ausführung

**Starten Sie eine Aufgabe**

```
ego-browser follow @ego_agent on x.com for me
```
