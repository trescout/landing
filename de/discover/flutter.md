# Multiplattform-Anwendung mit einem einzigen Code

Flutter wurde von Google entwickelt und ermöglicht Ihnen die schnelle Erstellung von Benutzeroberflächen für Mobil-, Web- und Desktop-Plattformen mit einer einzigen Codebasis. Dieses Open-Source-Framework, das auf der Programmiersprache Dart basiert, wird weithin für die Entwicklung leistungsstarker und visuell ansprechender Anwendungen bevorzugt.

## Was es bringt
- Mobil-, Web- und Desktop-Unterstützung mit einer einzigen Codebasis
- Hot-Reload-Funktion, mit der Sie Änderungen sofort sehen können
- Hardwarebeschleunigte Hochleistungsgrafik

## Installation
**macOS (Homebrew)**

```
brew install --cask flutter
```


## Ausführung
**Überprüfen Sie die Umgebungskontrollen**

```
flutter doctor
```

**Neues Projekt erstellen und ausführen**

```
flutter create my_app
cd my_app
flutter run
```
