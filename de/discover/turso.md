# SQLite-kompatible In-Process-Datenbank

Turso bietet eine In-Process-SQL-Datenbank, die mit SQLite kompatibel ist. Dieses in der Rust-Sprache entwickelte System vereinfacht Datenverwaltungsprozesse durch die Integration in Anwendungsprozesse.

- ★ 23.620
- Rust
- GitHub Trending · 2026-06-21

## Was es bringt
- Volle SQL-Kompatibilität mit SQLite
- Unterstützung mehrerer Sprachen und Plattformen
- Erweiterte Parallelität und Datenverwaltung

## Installation
**Installation des Befehlszeilentools**

```
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/tursodatabase/turso/releases/latest/download/turso_cli-installer.sh | sh
```

**Installation des JavaScript-Pakets**

```
npm i @tursodatabase/database
```


## Ausführung
**Starten der interaktiven Shell**

```
tursodb
```
