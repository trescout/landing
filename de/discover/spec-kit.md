# Spezifikationsgetriebene Entwicklung mit künstlicher Intelligenz

Das von GitHub veröffentlichte spec-kit bietet die notwendigen Tools, um spezifikationsgesteuerte Entwicklungsprozesse zu starten. Diese Python-basierte Bibliothek erleichtert die Integration technischer Spezifikationen, die während der Softwareentwicklungsphase definiert wurden, in Codeprozesse.

## Was es bringt

- Es wandelt technische Spezifikationen in ausführbare Codeprozesse um.
- Es liefert konsistente und vorhersehbare Ergebnisse während der Softwareentwicklungsphase.
- Es erhöht die Entwicklungsgeschwindigkeit durch die Integration mit KI-Codierungsagenten.

## Installation

**Installieren des CLI-Tools**

```
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@vX.Y.Z
```

## Ausführung

**Starten des Projekts**

```
specify init my-project --integration copilot
cd my-project
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Wenn Sie einen KI-Codierungsagenten verwenden, definieren Sie Qualitäts- und Leistungsstandards mithilfe des Befehls /speckit.constitution, um die Grundlinien des Projekts zu bestimmen. Erklären Sie dann die Ziele der Anwendung, die Sie mit /speckit.specify erstellen möchten, geben Sie Ihre technische Architektur mit /speckit.plan an und erstellen Sie schließlich die Aufgabenliste mit /speckit.tasks und entwickeln Sie die Anwendung mit dem Befehl /speckit.implement.
