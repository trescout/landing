# Leistungsstarke Vektorindizierung mit Rust

Turbovec basiert auf der TurboQuant-Infrastruktur und ist ein leistungsstarkes Vektorindextool, das mit der Rust-Sprache entwickelt wurde. Dank Python-Bindungen können Entwickler vektorbasierte Suchvorgänge schnell und effizient durchführen.

## Was es bringt

- Es reduziert den Speicherverbrauch durch starke Komprimierung von Vektordaten.
- Es ermöglicht die sofortige Datenergänzung und schnelle Suche, ohne dass eine Schulungsphase erforderlich ist.
- Es erhält die Leistung aufrecht, indem es während der Suche Filtervorgänge durchführt.

## Installation

**Installation für Python**

```
pip install turbovec
```

**Installation für Rust**

```
cargo add turbovec
```
