# Plugins für den Codierungsassistenten Claude

Anthropic bietet ein offizielles Verzeichnis, das hochwertige, für Claude Code entwickelte Plugins in einem einzigen Zentrum sammelt. Diese Python-basierte Struktur ermöglicht es Entwicklern, für Codierungsassistenten vorbereitete Tools in einem Standardformat zu teilen und zu entdecken.

## Was es bringt
- Entdecken Sie die für Claude Code vorbereiteten Add-ons in einem einzigen Zentrum
- Fügen Sie Ihrem Codierungsassistenten neue Funktionen und Tools hinzu
- Greifen Sie auf offizielle und von der Community entwickelte Add-ons zu

## So fangen Sie an
- Offizielle Quelle →
Sie können verfügbare Plugins über das Menü „/plugin > Discover“ in der Claude Code-Benutzeroberfläche durchsuchen. Um Plugins zu installieren, verwenden Sie einfach den Befehl „/plugin install {plugin-name}@claude-plugins-official“ in der Claude Code-Befehlszeile.
