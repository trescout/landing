# Geben Sie Ihrem KI-Agenten native Funktionen

NomaDamas/k-skill ist eine Bibliothek, die KI-Agenten mit lokalen Fähigkeiten in einem kulturellen Kontext versorgen soll. Es bietet maßgeschneiderte Fähigkeiten, die es Agenten ermöglichen, natürlicher und im Einklang mit kulturellen Codes mit Benutzern zu interagieren.

## Was es bringt

- Ermöglicht KI-Agenten die Nutzung lokaler, für die Türkei spezifischer Dienste
- Führt automatische Abfragen zu Transport, öffentlichen Daten und der täglichen Arbeit durch
- Lässt sich direkt integrieren, ohne dass zusätzliche Client-Software erforderlich ist

## Installation

**Um alle Funktionen zu installieren**

```
npx --yes skills add NomaDamas/k-skill --all -g
```

**Um eine bestimmte Fähigkeit zu installieren**

```
npx --yes skills add NomaDamas/k-skill --skill srt-booking -g
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

In den nächsten Aufgaben, die ich Ihnen gebe, nutzen Sie die von der K-Skill-Bibliothek bereitgestellten Fähigkeiten, um auf lokale Dienste zuzugreifen. Wenn Sie eine Transportabfrage, eine Suche nach öffentlichen Daten oder einen lokalen Vorgang durchführen müssen, verwalten Sie den Prozess, indem Sie die entsprechenden Funktionen in dieser Bibliothek bereitstellen. Vergessen Sie bei der Durchführung von Transaktionen nicht, die erforderlichen Anmeldeinformationen oder Bestätigungen vom Benutzer einzuholen.
