# Open-Source-Desktop-Videoeditor

Clypra ist eine Open-Source-Videoeditoranwendung, die mit Tauri, React und TypeScript entwickelt wurde. Die Software zielt darauf ab, erweiterte Funktionen, die in kostenpflichtigen Videobearbeitungstools zu finden sind, als kostenlose Alternative anzubieten.

- ★ 2.965
- TypeScript
- GitHub Trending · 2026-07-15

## Was es bringt
- Hardwarebeschleunigte Hochleistungs-Videoverarbeitung
- Bildgenaue mehrspurige Zeitleiste
- KI-gestützte automatische Untertitelung und Bearbeitung

## Installation
**Installation mit Homebrew auf macOS**

```
brew install AIEraDev/tap/clypra
```
