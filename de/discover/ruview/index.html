Gewinnen Sie räumliche Intelligenz mit WLAN-Signalen

RuView bietet räumliche Echtzeit-Intelligenz, Vitalzeichenverfolgung und Anwesenheitserkennung ohne Kamera unter Verwendung gewöhnlicher WLAN-Signale. Es handelt sich um ein Open-Source-Projekt, das mit Rust entwickelt wurde.

Was bietet es?

  • Präsenz- und Bewegungserkennung ohne Verwendung einer Kamera.
  • Überwachung der Vitalfunktionen (Atmung und Puls).
  • Räumliche Intelligenz in Echtzeit.

Haftungshinweis

Es handelt sich um eine Technologie, die die Anwesenheit/Bewegung von Personen erkennt. Die sorgfältige und rechtmäßige Nutzung im Hinblick auf Datenschutz und Einwilligung liegt in Ihrer Verantwortung.

Wie installiere ich, wie verwende ich?

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Um es ohne Hardware auszuprobieren, führen Sie „docker pull ruvnet/wifi-densepose:latest“ im Terminal aus, beginnen Sie dann mit „docker run -p 3000:3000 ruvnet/wifi-densepose:latest“ und öffnen Sie http://localhost:3000 im Browser; Dies zeigt die Bewegungs-/Anwesenheitserkennungsschnittstelle von RuView mit WiFi-Signalen und simulierten Daten.

Ziehen Sie das Docker-Image
docker pull ruvnet/wifi-densepose:latest
Mit Docker ausführen (Simulation, keine Hardware erforderlich)
docker run -p 3000:3000 ruvnet/wifi-densepose:latest
Python-Paket (PyPI)
pip install ruview
