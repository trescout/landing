# Büroumgebung für Agenten der künstlichen Intelligenz

Munder-Difflin ist ein Mechanismus, der es mehreren Agenten der künstlichen Intelligenz ermöglicht, in lokalen Systemen zusammenzuarbeiten. Dieses mit TypeScript entwickelte Tool erleichtert die Verwaltung autonomer Agentensysteme, die komplexe Aufgaben in einer lokalen Umgebung teilen.

- ★ 4.946
- TypeScript
- GitHub Trending · 2026-08-18

## Was es bringt
- Es koordiniert terminalbasierte KI-Tools als autonomes Team.
- Es ermöglicht Agenten, ein Langzeitgedächtnis zu entwickeln und sich gegenseitig Nachrichten zu senden.
- Es bietet die Möglichkeit, die Arbeitsprozesse von Agenten über eine visuelle Office-Oberfläche zu verfolgen.

## Installation
**Laden Sie die App herunter und starten Sie sie**

```
git clone https://github.com/chaitanyagiri/munder-difflin.git
cd munder-difflin
npm install        # postinstall rebuilds node-pty against Electron's ABI
npm run dev        # launches the Electron app with hot reload
```


## Ausführung
**Erstellung und Vorschau der Produktionsfreigabe**

```
npm run build      # production build via electron-vite
npm run preview    # preview the production build
```


## Wenn Sie nicht programmieren
Geben Sie meinen Agenten, die an Munder Difflin arbeiten, die folgende Aufgabe: Erstellen Sie ein Team mithilfe vorhandener terminalbasierter Tools für künstliche Intelligenz, verteilen Sie Aufgaben über einen Manager-Agenten namens Michael und führen Sie alle Prozesse autonom durch, indem Sie sie in einer gemeinsamen Speicherschicht speichern.
