# Automatischer Penetrationstest mit künstlicher Intelligenz

VulnClaw automatisiert Penetrationstestprozesse mithilfe von KI-Agenten und der Model Context Protocol-Toolchain. Das Tool verarbeitet Befehle in natürlicher Sprache und führt eine umfassende Informationserfassung, Schwachstellenprüfung, Ausnutzung und Berichtsschritte durch.

## Installation
**Installation über PyPI**

```
pip install vulnclaw
```

**Installation aus dem Quellcode**

```
git clone https://github.com/Unclecheng-li/VulnClaw.git
cd VulnClaw
pip install -e .
```


## Ausführung
**Schnellstart**

```
vulnclaw
```

**Gezieltes Scannen**

```
vulnclaw run <target>
```


## Wenn Sie nicht programmieren
Sie sind Penetrationstester. Sammeln Sie mit dem VulnClaw-Tool Informationen über das Zielsystem, führen Sie Schwachstellenscans und Ausnutzungsschritte durch. Nutzen Sie die zielgerichtete Lösungs-Engine bei der Durchführung der Operationen, verifizieren Sie Ihre Erkenntnisse und erstellen Sie am Ende des Prozesses einen strukturierten Bericht und Python-basierten PoC-Code. Gehen Sie in jeder Phase auf der Grundlage der realen Daten vor, die Sie erhalten, und vermeiden Sie Annahmen.
