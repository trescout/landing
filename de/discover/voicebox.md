# Tonstudio mit künstlicher Intelligenz, das in einer lokalen Umgebung arbeitet

Voicebox ist ein Open-Source-Sprachstudio mit künstlicher Intelligenz, das es Benutzern ermöglicht, Stimmen zu klonen, zu diktieren und Inhalte zu erstellen. Diese mit der TypeScript-Sprache entwickelte Plattform bietet umfassende Tools zur Verwaltung von Audioverarbeitungsprozessen in der nativen Umgebung.

- ★ 50.505
- TypeScript
- GitHub Trending · 2026-06-21

## Was es bringt
- Transkribieren Sie Ihre eigene Stimme oder die Stimme einer anderen Person in Sekundenschnelle.
- Bieten Sie natürliches Voice-Over und Diktat in 23 verschiedenen Sprachen.
- Schützen Sie Ihre Privatsphäre, indem Sie alle Audiodaten auf Ihrem lokalen Computer speichern.

## Installation
**Installation aus dem Quellcode**

```
git clone https://github.com/jamiepine/voicebox.git
cd voicebox

just setup   # creates Python venv, installs all deps
just dev     # starts backend + desktop app
```
