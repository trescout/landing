# Benutzernamen in verschiedenen Netzwerken suchen

Das in Python entwickelte Projekt sherlock-project/sherlock ist ein Tool, das Benutzernamen verwendet, um Social-Media-Konten in verschiedenen Netzwerken zu durchsuchen. Das Projekt bietet von der Community gepflegte Paketunterstützung für verschiedene Plattformen wie Debian, Ubuntu, Homebrew, Kali und BlackArch.

## Was es bringt

- Durchsuchen Sie von Ihnen festgelegte Benutzernamen auf über vierhundert sozialen Netzwerken auf einmal.
- Fragen Sie mehrere Benutzernamen gleichzeitig ab und speichern Sie die Ergebnisse als Textdatei.
- Erhalten Sie Zugriff über verschiedene Betriebssysteme und Systempakete hinweg.

## So fangen Sie an
