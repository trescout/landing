# Eine Deployment-Plattform, die auf Ihrem eigenen Server läuft

Coolify ist ein Open-Source-Deployment-Tool als Alternative zu Cloud-Plattformen (PaaS) wie Vercel, Heroku und Netlify. Es ermöglicht Ihnen, über 360 Dienste, einschließlich statischer Websites, Datenbanken und komplexer Anwendungen, ganz einfach auf Ihren eigenen Servern zu hosten.

## Was es bringt

- Hosten Sie Anwendungen und Datenbanken auf Ihrem eigenen Server.
- Führen Sie automatische Deployments mit Git-Integration durch.
- Verwalten Sie automatische HTTPS-Zertifikate und Netzwerkeinstellungen.

## Installation

**Auf dem Server installieren**

```
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```
