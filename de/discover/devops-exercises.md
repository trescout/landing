# Umfassende DevOps-Interviewfragen

devops-exercises ist ein Repository mit Ressourcen, das DevOps-Interviewfragen in einem breiten Spektrum von Linux über Cloud-Plattformen bis hin zu Container-Technologien enthält. Ziel ist es, den Vorbereitungsprozess von Kandidaten mit technischen Fragen zu branchenüblichen Tools (wie Jenkins, Docker, Kubernetes, Terraform) zu unterstützen.
