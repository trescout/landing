# Verwandeln Sie Ihr Tablet in einen Android Auto-Bildschirm

Das von der Headunit wiederbelebte Projekt stellt eine Anwendung bereit, mit der die Android Auto-Benutzeroberfläche auf verschiedenen Bildschirmen angezeigt werden kann. Diese in der Kotlin-Sprache entwickelte Software bietet eine alternative Anzeigelösung für Infotainmentsysteme im Auto.

- ★ 1.484
- Kotlin
- GitHub Trending · 2026-06-25

## Was es bringt
- Nutzen Sie Ihr Android-Tablet oder -Telefon als Display im Auto
- Unterstützung für kabelgebundene Verbindungen über USB
- Zuverlässige drahtlose Verbindung mit Wireless Helper

## So fangen Sie an
- Offizielle Quelle →
Laden Sie die App über den Google Play Store oder Amazon Appstore auf Ihr Gerät herunter. Für eine drahtlose Verbindung wird empfohlen, auch die Anwendung „Wireless Helper“ auf Ihrem Telefon zu installieren. Detaillierte Installationsschritte und Verbindungseinstellungen finden Sie im Wiki-Abschnitt auf der GitHub-Seite.
