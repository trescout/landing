Patentanmeldungen und Offenlegungstexte mit KI automatisieren

Patent Disclosure Skill in Python analysiert Erfindungsbeschreibungen zur automatisierten Erstellung konformer Patentschriften, Patentansprüche und Neuheitsprüfungen.

  • ★ 6.058
  • Python
  • GitHub Trending · 2026-08-31

Aktualisierungen

  • 31. August 2026: 6.058 Sterne, mit automatisierter Patentanspruchs-Strukturierung und Neuheitsanalyse.

Was es bringt

  • Strukturierte Patentschriften-Erstellung: Formuliert technisches Gebiet, Stand der Technik, Zusammenfassung und Ausführungsbeispiele normgerecht.
  • Hierarchische Patentanspruchs-Struktur: Konstruiert voneinander abhängige und unabhängige Ansprüche für maximalen rechtlichen Schutzumfang.
  • Differenzierung gegenüber dem Stand der Technik: Arbeitet erfinderische Schritte und technische Vorteile präzise heraus.
  • Effiziente Zusammenarbeit mit Patentanwälten: Überführt Entwickler-Notizen in strukturierte Offenlegungsunterlagen zur Prüfung durch Patentanwälte.
  • Terminologische Harmonisierung: Erfüllt die formalen Richtlinien von DPMA, EPA (EPO) und WIPO.

Installation

Repository klonen und Abhängigkeiten installieren
git clone https://github.com/handsomestWei/patent-disclosure-skill.git
cd patent-disclosure-skill
pip install -r requirements.txt

Ausführung

Offenlegungsanalyse und Texterstellung ausführen
python run_skill.py --input bulus_taslagi.txt --output patent_disclosure.md

Technische Architektur und Funktionsweise

Patent Disclosure Skill führt einen mehrstufigen Agenten-Workflow zur Übersetzung technischer Notizen in Patentspezifikationen aus:

  • Extraktions-Engine für Erfindungsmerkmale: Identifiziert Schlüsselkomponenten, Verfahrensabläufe und technische Neuerungen aus Entwürfen.
  • Syntax- und Klarheitsprüfung für Patentansprüche: Prüft Ansprüche auf sprachliche Eindeutigkeit, formale Bezüge und Vermeidung unklarer Begriffe.
  • Modularer Markdown-Spezifikationsgenerator: Exportiert normgerechte Offenlegungsdokumente für die weitere juristische Ausarbeitung.

Patentanalyse-Workflows und Anspruchserstellung

F&E-Abteilungen und Patentexperten nutzen dieses Tool, um den Schutz geistigen Eigentums zu beschleunigen:

  • Überführung von Software-Algorithmen in Patentschriften: Erstellt aus Softwarearchitekturen patentfähige Verfahrens- und Systembeschreibungen.
  • Unterstützung bei Bescheidserwiderungen: Formuliert fundierte technische Gegenargumente bei Beanstandungen durch Patentprüfer.
  • Patentfähigkeits-Audits in der F&E: Identifiziert schutzfähige technische Neuerungen frühzeitig im Entwicklungsprozess.

Häufig gestellte Fragen

  • Ersetzt das Tool einen zugelassenen Patentanwalt? Nein. Es fungiert als Produktivitätstool, das technische Beschreibungen für die anwaltliche Prüfung und Einreichung strukturiert vorbereitet.
  • Welche Sprachmodelle werden unterstützt? Kann mit Claude 3.5 Sonnet, GPT-4o oder lokalen Modellen über Ollama und vLLM betrieben werden.
  • Bleiben Betriebs- und Geschäftsgeheimnisse geschützt? Bei Verwendung lokaler Modelle erfolgt die gesamte Textverarbeitung offline auf Ihrem Rechner ohne externe Datenübertragung.
  • Können Ablaufdiagramme und Zeichnungen ausgewertet werden? Mit multimodalen Modellen können auch schematische Blockdiagramme analysiert und in Textbeschreibungen überführt werden.
