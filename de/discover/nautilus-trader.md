# Leistungsstarke algorithmische Handelsplattform

Nautilus Trader ist eine Handelsmaschine mit einer deterministischen ereignisgesteuerten Architektur, die in der Rust-Sprache entwickelt wurde. Es bietet produktionstaugliche Infrastrukturlösungen für leistungsstarke Finanzsysteme.

## Was es bringt
- Rustbasierte schnelle und sichere Handelsinfrastruktur
- Übergang von der Forschung zum Leben ohne Codeänderungen
- Unterstützung mehrerer Börsen und Anlageklassen

## Installation
**Standardinstallation**

```
pip install -U nautilus_trader
```

**Installation aus privatem Paket-Repository**

```
pip install -U nautilus_trader --index-url=https://packages.nautechsystems.io/simple
```
