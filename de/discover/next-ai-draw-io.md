# Automatische Diagrammerstellung mit künstlicher Intelligenz

Diese Next.js-basierte Anwendung kombiniert das Diagrammtool draw.io mit generativen KI-Funktionen. Benutzer können visuelle Diagramme durch Befehle in natürlicher Sprache erstellen und ihre vorhandenen Diagramme mit Unterstützung künstlicher Intelligenz bearbeiten.

## Was es bringt

- Zeichnen Sie professionelle Diagramme mit Befehlen in natürlicher Sprache
- Konvertieren Sie vorhandene Bilder und PDF-Dateien in Diagramme
- Visualisieren Sie schnell Cloud-Architektur und Flussdiagramme

## Installation

**lokale Installation**

```
git clone https://github.com/DayuanJiang/next-ai-draw-io
cd next-ai-draw-io
npm install
cp env.example .env.local
```

## Ausführung

**Starten des Entwicklungsservers**

```
npm run dev
```
