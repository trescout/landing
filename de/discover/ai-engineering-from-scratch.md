# Künstliche Intelligenz-Ingenieurausbildung von Grund auf

Einführung in die Technik der künstlichen Intelligenz von Grund auf: 485 Lektionen, 20 Phasen und ca. 320 Stunden Inhalt. Er lehrt jeden Algorithmus, von der linearen Algebra bis hin zu autonomen Agenten, zunächst mit Mathematik und dann durch manuelles Schreiben von Code. Dieser Kurs, der die Sprachen Python, TypeScript, Rust und Julia abdeckt, ist völlig kostenlos und Open Source.

## Was lernt man?
- Sie richten die Grundlagen wie Backprop, Tokenizer und Attention manuell ein und beginnen mit der Mathematik.
- Sie entwickeln End-to-End, von der Agentenschleife bis zum MCP-Server.
- Jede Lektion hinterlässt eine wiederverwendbare Ausgabe: eine Eingabeaufforderung, eine Fertigkeit oder einen Agenten.
- Wenn Sie PyTorch verwenden, wissen Sie bereits, was sich hinter den Kulissen abspielt.

## So funktioniert es
Jede Lektion folgt demselben Zyklus: Problem analysieren, rechnen, Code schreiben, Test ausführen und Ausgabe speichern. Es gibt keine fünfminütigen Videos oder Bereitstellungsprozesse zum Kopieren und Einfügen. Alles läuft auf Ihrem eigenen Computer.
