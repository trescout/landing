# Moderner und umfassender Download-Manager

Motrix ist ein umfassender, mit TypeScript entwickelter Download-Manager, der alle Datei-Download-Anforderungen erfüllt. Es bietet Benutzern die Möglichkeit, verschiedene Protokolle wie HTTP, FTP und BitTorrent über eine einzige Schnittstelle zu verwalten.

## Was es bringt

- Verwaltet HTTP-, FTP- und BitTorrent-Protokolle über eine einzige Schnittstelle
- Begrenzt die Download-Geschwindigkeit und bietet erweiterte Sitzungsverwaltung
- Initiiert Ein-Klick-Downloads mit Browser-Add-ons

## Installation

**Installieren der Befehlszeilenschnittstelle**

```
npm install -g @motrix/cli
```

## Ausführung

**Starten des Dateidownloads**

```
motrix add https://example.com/file.iso --save-dir ~/Downloads
```
