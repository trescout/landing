# Automatisieren Sie Ihre End-to-End-Tests

Ein auf TypeScript basierendes Framework der nächsten Generation, das End-to-End-Testprozesse für Web- und mobile Anwendungen automatisiert. Es ermöglicht Entwicklern, Benutzeroberflächen von Anwendungen auf verschiedenen Plattformen schnell zu verifizieren.

- ★ 5.716
- TypeScript
- GitHub Trending · 2026-10-05

## Was es bringt
- Schreiben Sie Tests, indem Sie Ziele in natürlicher Sprache definieren
- Aktionen aufnehmen und bei späteren Ausführungen wiederverwenden
- Benutzeroberfläche in Web- und mobilen Anwendungen verifizieren

## Installation
**Konfiguration starten**

```
npx e2e init
```


## Wenn Sie nicht programmieren
Richten Sie mit dem Testtool automatisierte Tests mit in natürlicher Sprache geschriebenen Schritten für meine Web- oder mobile Anwendung ein und erstellen Sie die Konfigurationsdatei.
