# Sparen Sie Geld, indem Sie KI-Antworten verkürzen

Caveman ist ein für Claude Code entwickeltes Funktionspaket, das den Token-Verbrauch um 65 Prozent reduziert, indem es die Sprachverwendung des Modells der künstlichen Intelligenz vereinfacht. Ziel dieses Tools ist es, die Verarbeitungskosten zu senken, indem komplexe Befehle auf eine primitive Sprachstruktur reduziert werden.

## Was es bringt
- Spart bis zu 65 % Token bei KI-Antworten.
- Eliminiert unnötige Wörter, ohne die technische Genauigkeit zu beeinträchtigen.
- Es reduziert die Transaktionskosten und erhöht die Reaktionsgeschwindigkeit.

## Installation
**Setup für macOS, Linux und WSL**

```
curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.sh | bash
```

**Installation für Windows**

```
irm https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.ps1 | iex
```


## Ausführung
**Aktivieren Sie den Modus**

```
/caveman
```


## Wenn Sie nicht programmieren
Geben Sie von nun an Ihre Antworten im Höhlenmensch-Modus. Entfernen Sie unnötige Füllwörter und behalten Sie nur die prägnanten Informationen und technischen Details bei. Verfassen Sie Ihre Antworten in kurzen, prägnanten und fragmentierten Sätzen; aber weiterhin vollständige und präzise Codeblöcke, Befehle und Fehlermeldungen übermitteln.
