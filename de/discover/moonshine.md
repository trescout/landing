# Echtzeit-KI-Sprachtools

Moonshine bietet Sprach-zu-Text-, Absichtserkennungs- und Text-zu-Sprache-Funktionen mit geringer Latenz für Sprachschnittstellen und Agenten der künstlichen Intelligenz. Diese in der Sprache C++ entwickelte Bibliothek zielt darauf ab, Echtzeit-Audioverarbeitungsprozesse zu optimieren.

## Was es bringt
- Schnelle und diskrete Audioverarbeitung auf dem Gerät
- Geringe Latenz, optimiert für Live-Übertragungen
- Möglichkeit, Sprache in Text und Text in Audio umzuwandeln

## Installation
**Installation mit Python**

```
pip install moonshine-voice
moonshine-voice mic --language en
```

**Raspberry Pi-Installation**

```
sudo pip install --break-system-packages moonshine-voice
 moonshine-voice mic --language en
```


## Ausführung
**Live-Transkription über Mikrofon**

```
moonshine-voice mic --language en
```
