# Unterschreiben Sie ganz einfach digitale Dokumente

DocuSeal bietet eine Open-Source-Alternative zum Erstellen, Ausfüllen und Signieren digitaler Dokumente. Diese mit der Ruby-Sprache entwickelte Plattform bietet eine Lösung für Benutzer, die elektronische Signaturprozesse (E-Signatur) in ihrer eigenen Infrastruktur verwalten möchten.

- ★ 18.280
- Ruby
- GitHub Trending · 2026-07-18

## Was es bringt
- Erstellen und unterschreiben Sie PDF-Formulare online
- Mobilkompatible Benutzeroberfläche
- Sicheres Datenmanagement in Ihrer eigenen Infrastruktur

## Installation
**Schnelle Installation mit Docker**

```
docker run --name docuseal -p 3000:3000 -v.:/data docuseal/docuseal
```

**Docker Compose-Konfiguration**

```
curl https://raw.githubusercontent.com/docusealco/docuseal/master/docker-compose.yml > docker-compose.yml
```


## Ausführung
**Starten der App**

```
sudo HOST=your-domain-name.com docker compose up
```
