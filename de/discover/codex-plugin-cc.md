# KI-gestützte Codeüberprüfung für Claude Code

Das von OpenAI entwickelte Codex-Plugin wird auf Claude Code verwendet, um Codeüberprüfungsprozesse zu automatisieren und die Aufgabendelegierung bereitzustellen. Dieses Tool ermöglicht die Integration verschiedener Modelle der künstlichen Intelligenz (große Sprachmodelle) in Softwareentwicklungsworkflows.

## Was es bringt

- Automatisiert Codeüberprüfungsprozesse
- Delegiert Aufgaben an das Codex-Modell
- Verwaltet lang laufende Jobs im Hintergrund

## Installation

**Installieren Sie das Codex-Paket**

```
npm install -g @openai/codex
```

## Ausführung

**Beginnen Sie mit der ersten Überprüfung**

```
/codex:review
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Starten Sie eine Überprüfung meines vorhandenen Codes mithilfe des Codex-Plugins in Claude Code und berichten Sie über die Ergebnisse. Wenn es sich um eine komplexe Aufgabe handelt, delegieren Sie sie mit dem Befehl /codex:rescue an Codex und führen Sie sie im Hintergrund aus, damit ich den Fortschritt mit /codex:status verfolgen kann.
