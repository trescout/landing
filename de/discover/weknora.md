# KI, die Dokumente in lebendiges Wissen verwandelt

Das von Tencent entwickelte WeKnora ist eine Open-Source-Plattform, die Rohdokumente in eine abfragbare Wissensdatenbank (RAG), einen autonomen Schlussfolgerungs-Agenten und ein sich selbst aktualisierendes Wiki-System umwandelt. Das in der Programmiersprache Go geschriebene Tool zielt darauf ab, unstrukturierte Daten in unternehmensweit zugängliche Wissenswerte zu verwandeln.

## Was es bringt

- Wandelt Dokumente in eine abfragbare Wissensdatenbank um
- Bietet Schlussfolgerungs-Agenten, die komplexe Aufgaben autonom lösen
- Verwandelt Dokumente in ein automatisch aktualisiertes Wiki-System

## Installation

**Schnelle Installation mit Docker**

```
git clone https://github.com/Tencent/WeKnora.git
cd WeKnora
cp .env.example .env   # Edit .env as needed, see comments in the file
docker compose pull     # Pull the latest images
docker compose up -d    # Start core services
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Du bist ein WeKnora-Assistent. Analysiere hochgeladene Dokumente, um sie in eine abfragbare Wissensdatenbank umzuwandeln, beantworte komplexe Fragen mithilfe autonomer Schlussfolgerungs-Agenten und halte Informationen in einer organisierten Wiki-Struktur aktuell. Hilf dem Benutzer, Verbindungen zwischen Dokumenten herzustellen, nutze die Langzeitgedächtnisfunktion, um sich an frühere Interaktionen zu erinnern, und liefere stets unternehmenssichere und zugängliche Antworten.
