# Bereiten Sie Ihre Dokumente für künstliche Intelligenz vor

MarkItDown (Microsoft); Es handelt sich um ein leichtes Python-Tool, das Word, PDF, PowerPoint, Excel und mehr in sauberen Markdown-Text konvertiert, den große Sprachmodelle problemlos lesen können. Konvertiert unter Beibehaltung von Überschriften, Listen und Tabellen im Dokument.

- ★ 170.726
- Python
- MIT
- GitHub Trending · 29 May 2026

## Was es bringt
- Es verwandelt Ihre Dokumente in klare Texte, die künstliche Intelligenz verarbeiten kann.
- Es behält Header-, Listen- und Tabellenstrukturen bei.
- Ideal für Ihre RAG- und Textanalyseprozesse.

## Installation
****

```
pip install 'markitdown[all]'
```


## Ausführung
****

```
markitdown belge.pdf > belge.md
```


## Beispielverwendung
report.pdf · Präsentation.pptx · table.xlsx

## Installation + Nutzung
Installieren Sie MarkItDown mit dem Befehl pip install „markitdown[all]“ im Terminal und konvertieren Sie dann eine PDF-, Word-, Excel- oder PowerPoint-Datei in Markdown, indem Sie den Befehl „markitdown filename.pdf > document.md“ ausführen.
