# Leitfaden zum Entwurf großer Systeme

System Design Primer bietet eine umfassende Lernressource für diejenigen, die umfangreiche Softwaresysteme entwerfen möchten. Es vereint Systemdesignprinzipien und praktische Lernkarten für Softwareentwickler, die sich auf technische Interviews vorbereiten.

**Hinweis von TreScout:** Die erste Anlaufstelle für Mitarbeiter für den Systemdesign-Abschnitt des technischen Interviews. Es fasst die Konzepte gut zusammen, die Beispiele basieren jedoch auf klassischen Skalensystemen: Kopieren Sie die Architektur in Ihrer eigenen Arbeit nicht von hier, sondern verwenden Sie sie als Denkrahmen.

## Was es bringt

- Lernen Sie die Prinzipien der Großsystemarchitektur kennen
- Lösen Sie Übungsfragen für technische Interviews
- Verwenden Sie Anki-Lernkarten, um Informationen zu behalten

## So fangen Sie an

Dieses Handbuch ist ein Dokumentations-Repository auf GitHub. Um zu beginnen, können Sie direkt die GitHub-Seite des Projekts besuchen, die Inhaltstitel überprüfen und mit dem Lesen der zu Systemdesignfragen erstellten Arbeitsnotizen beginnen. Wenn Sie die Informationen vertiefen möchten, können Sie Anki-Dateien (Software, die das Auswendiglernen mit Karteikarten ermöglicht) über die entsprechenden Links herunterladen und verwenden.
