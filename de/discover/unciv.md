# Leichtes und Open-Source-Strategiespiel

Unciv ist eine Open-Source-Desktop- und Android-Adaption des Spiels Civilization V. Das in der Kotlin-Sprache entwickelte Projekt bietet Benutzern originelle Spielmechaniken auf einer einfacheren Infrastruktur.

## Was es bringt
- Reibungsloses Spielerlebnis auf Low-End-Geräten
- Modifizierbare und anpassbare Spielstruktur
- Cross-Unterstützung für Desktop- und Android-Plattformen

## So fangen Sie an
- Offizielle Quelle →
Um mit der Wiedergabe des Unciv-Projekts zu beginnen, müssen Sie die entsprechende Version für Ihr Gerät herunterladen. Android-Benutzer können über Google Play oder F-Droid installieren, während Windows-Benutzer die Installation über die aktualisierte MSI-Datei auf GitHub durchführen können. Für Linux- und macOS-Benutzer stehen verschiedene Installationsmöglichkeiten über itch.io, Flatpak oder Paketmanager zur Verfügung.
