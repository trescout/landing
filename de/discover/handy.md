# Transkribieren Sie Ihre Stimme lokal

cjpais/Handy ist eine kostenlose und Open-Source-Anwendung zur Spracherkennung (Speech-to-Text), die vollständig offline läuft. Dieses in Rust entwickelte Tool bietet eine erweiterbare Struktur, die es Benutzern ermöglicht, Audiodaten lokal zu verarbeiten.

## Was es bringt

- Wandelt Ihre Sprache sofort in Text um, ohne eine Internetverbindung zu benötigen
- Schützt Ihre Privatsphäre, indem Audiodaten nicht an Cloud-Server gesendet werden
- Schreibt direkt in das aktive Textfeld, indem Sie eine von Ihnen definierte Tastenkombination drücken

## Installation

**Debian- oder Ubuntu-basierte Linux-Systeme**

```
sudo apt install ./Handy_*.deb
```
