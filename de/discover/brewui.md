# Grafische Benutzeroberfläche für die macOS-Paketverwaltung

Homebrew ist ein Befehlszeilen-Tool zur Verwaltung von Softwarepaketen auf dem macOS-Betriebssystem. BrewUI ist eine offizielle Desktop-Anwendung, mit der Sie die komplexen Befehle dieses Tools über eine grafische Benutzeroberfläche (GUI) verwalten können.

## Was es bringt

- Verwalten Sie Softwarepakete ohne die Befehlszeile zu verwenden
- Verfolgen Sie Homebrew-Vorgänge über eine transparente Benutzeroberfläche
- Einfache Installation mit einer nativen macOS-Anwendung auf SwiftUI-Basis

## Installation

**Anwendung installieren**

```
brew install --cask homebrew-app
```
