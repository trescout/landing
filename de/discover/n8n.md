# Automatisieren Sie anwendungsübergreifende Arbeitsabläufe

n8n ist eine Plattform für den automatisierten Arbeitsfluss, die zwischen verschiedenen Anwendungen und automatisierten Geschäftsprozessen besteht. Kombinieren Sie eine visuelle Benutzeroberfläche mit einem benutzerdefinierten Code-Schreiben, dieser Schritt kann nun auf Ihrem eigenen Server durchgeführt werden und unterstützt mehr als 400 Integrationen.

- ★ 201.895
- TypeScript
- GitHub Trending · 2026-08-23

## Was es bringt
- Gestalten Sie komplexe Geschäftsprozesse mit einer visuellen Oberfläche
- Verbinden Sie über 1500 verschiedene Apps und Dienste
- Führen Sie es sicher auf Ihrem eigenen Server oder in der Cloud aus

## Installation
**Schnelles Installationsskript**

```
curl -fsSL https://get.n8n.io | sh
```

**Manuelle Installation mit Docker**

```
docker volume create n8n_data
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```


## Ausführung
**Zugriff auf die Schnittstelle**

```
http://localhost:5678
```


## Wenn Sie nicht programmieren
Sie sind Automatisierungsexperte. Sie arbeiten auf einer visuellen Leinwand, um den Datenfluss zwischen Anwendungen zu verwalten und KI-gestützte Geschäftsprozesse zu erstellen. Ihre Aufgabe ist es, mehrstufige Workflows zu entwerfen, die verschiedene Dienste verbinden, logische Schritte haben und eine menschliche Genehmigung erfordern. Ich habe die Einrichtung abgeschlossen und hilf mir nun bei der Erstellung meines ersten Workflows.
