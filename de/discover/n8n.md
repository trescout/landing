# Visuelle Workflows und KI-Automatisierung

n8n verbindet eine visuelle Arbeitsfläche, eigenen Code, KI-Agenten und Workflows in einer Fair-Code-Automatisierungsplattform. Die Plattform unterstützt selbst betriebene oder Cloud-Bereitstellungen und kann verschiedene Modellanbieter in Workflows einbinden.

## Installation

**Daten-Volume erstellen**

```
docker volume create n8n_data
```

## Ausführung

**n8n-Docker-Container starten**

```
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```

## Was macht dieses Werkzeug?

Mit n8n können Sie Workflows auf einer visuellen Arbeitsfläche erstellen und sie mit JavaScript, Python und npm-Paketen erweitern. Offizielle Quellen nennen Modellflexibilität über OpenAI, Anthropic, Google und Open-Source-Modelle sowie menschliche Freigaben, Beobachtbarkeit, rollenbasierten Zugriff und Audit-Trails. Die Plattform kann selbst betrieben oder in der Cloud eingesetzt werden.

## Für wen ist es?

Teams, die visuelles Workflow-Design mit eigenem Code und KI-Agenten verbinden möchten.

## Was Sie nicht erwarten sollten

Menschen, die ausschließlich Produkte mit proprietärer Lizenz suchen oder Workflows nicht mit Code oder Konfiguration erweitern möchten.

## Höhepunkte

- Verbindet visuelle Arbeitsfläche, eigenen Code und KI-Agenten in Workflows.
- Kann mit JavaScript, Python und npm-Paketen erweitert werden.
- Bietet selbst betriebene und Cloud-Bereitstellungen.
- Nennt menschliche Freigaben, Beobachtbarkeit, rollenbasierten Zugriff und Audit-Trails.

## Ablauf für die erste Nutzung

1. Folgen Sie dem offiziellen Schnellstart mit Docker, um n8n auszuführen.
2. Öffnen Sie den Editor in Ihrem Browser über Port 5678.
3. Erstellen Sie Ihren ersten Workflow auf der visuellen Arbeitsfläche.
4. Fügen Sie nach Bedarf eigenen Code oder einen unterstützten Modellanbieter hinzu.

## Sicherer Start

n8n ist unter der Sustainable Use License mit einsehbarem Quellcode verfügbar. Prüfen Sie die offiziellen Lizenzbedingungen und konfigurieren Sie Zugriff und Betrieb Ihrer selbst betriebenen Installation.
