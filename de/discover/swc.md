SWC wurde mit der Rust-Sprache entwickelt und bietet eine schnelle Kompilierungs- und Bündelungsplattform für Webprojekte. Es beschleunigt moderne Webentwicklungsprozesse durch die Verarbeitung von JavaScript- und TypeScript-Dateien mit hoher Leistung.

## Installation

**Projektabhängigkeit (npm)**

```
npm i -D @swc/core
```

**npm: global**

```
npm install -g @swc/cli @swc/core
```

## Ausführung

**TypeScript-Datei kompilieren**

```
swc index.ts -o index.js
```

## Wenn Sie nicht programmieren

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich habe ein Webentwicklungsprojekt und möchte meine Kompilierungsprozesse beschleunigen. Wie kann ich meine JavaScript- und TypeScript-Dateien mit dem in Rust geschriebenen SWC-Tool (Speedy Web Compiler) effizienter verarbeiten? Wie kann ich dieses Tool entsprechend den Anforderungen meines Projekts konfigurieren und was sollte ich beim Umstieg von anderen Tools wie Babel beachten?

Repository: https://github.com/swc-project/swc. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.
