## Installation

**Projektabhängigkeit (npm)**

```
npm i -D @swc/core
```

**npm: global**

```
npm install -g @swc/cli @swc/core
```

## Ausführung

**TypeScript-Datei kompilieren**

```
swc index.ts -o index.js
```
