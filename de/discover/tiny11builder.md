# Erstellen Sie ein leichtes und angepasstes Windows-11-Image

ntdevlabs/tiny11builder ist eine WinUI-Anwendung, mit der kleinere und angepasste Versionen des Betriebssystems Windows 11 erstellt werden können. Dieses in C# entwickelte Tool ermöglicht es Benutzern, System-images an ihre eigenen Bedürfnisse anzupassen.

## Was es bringt

- Sie können vorinstallierte Apps und unnötige Systemfunktionen aus dem Betriebssystem-Image entfernen.
- Je nach Bedarf können Sie voreingestellte Tiny11-Modi auswählen oder die zu entfernenden Komponenten einzeln festlegen.
- Mit der Option zur Prozessbeschleunigung können Sie den Image-Erstellungsprozess verkürzen und unterbrochene Vorgänge an der Stelle fortsetzen, an der sie gespeichert wurden.

## So fangen Sie an

Laden Sie die für Ihr Computersystem passende Archivdatei von der offiziellen GitHub-Release-Seite herunter. Entpacken Sie die gesamte komprimierte Archivdatei in einen Ordner, öffnen Sie die Ausführungsdatei mit Administratorrechten und folgen Sie den Schritten.

- [Offizielle Quelle →](https://github.com/ntdevlabs/tiny11builder/releases/latest)

- **Für wen es gedacht ist:** Es ist für Benutzer gedacht, die das Betriebssystem Windows 11 von unnötigen Komponenten befreien und es leichter machen möchten.
