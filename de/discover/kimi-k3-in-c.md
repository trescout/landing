# Kimi K3 in C

Das Projekt FareedKhan-dev/kimi-k3-in-c ermöglicht die Ausführung des Kimi K3-Modells mit 2,78 Billionen Parametern auf einem einzigen Prozessor bei einer Speicherauslastung von 8,24 GB. Diese auf C99 basierende Anwendung, die kein Framework oder eine Grafikverarbeitungseinheit (GPU) erfordert, konzentriert sich auf die Ausführung von KI-Modellen mit hoher Parameteranzahl auf Hardware mit begrenzten Ressourcen.
