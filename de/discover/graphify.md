# Verwandeln Sie Ihre Projekte in Wissensgraphen für künstliche Intelligenz

Graphify wandelt verschiedene Arten von Daten wie Codedateien, Datenbankschemata und Dokumentation in eine abfragbare Knowledge-Graph-Struktur um. Dieses Python-basierte Tool zielt darauf ab, eine zentrale Datenschicht für verschiedene KI-Codierungsassistenten zu schaffen.

## Was es bringt

- Der Code verwandelt Ihre Dateien und Dokumente in ein abfragbares Informationsnetzwerk.
- Es nutzt native und schnelle Tree-Sitter-Technologie zur Code-Analyse.
- Es erleichtert den Übergang zwischen Konzepten, indem es Verbindungen zwischen Dateien herstellt.

## Installation

**CLI-Installation**

```
uv tool install graphifyy      # install the CLI (or: pipx install graphifyy)
graphify install               # register the skill with your AI assistant
```

## Ausführung

**Projektanalyse**

```
/graphify .
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich habe dieses Projektverzeichnis mit Graphify in einen Wissensgraphen umgewandelt. Anhand dieser Struktur möchte ich nun, dass Sie die Beziehungen zwischen Konzepten im Projekt analysieren, erklären, wie komplexe Codeblöcke miteinander verbunden sind, und die Rolle von Masterknoten wie „APIRouter“ im System detailliert beschreiben. Bitte unterscheiden Sie zwischen Informationen, die direkt aus dem Quellcode stammen, und abgeleiteten Verbindungen, indem Sie bei Ihrer Analyse die Tags „EXTRACTED“ und „INFERRED“ berücksichtigen.
