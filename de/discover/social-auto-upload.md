# Laden Sie Ihre Videos automatisch auf alle Plattformen hoch

social-auto-upload ist ein Python-Tool, das Ihre Videos automatisch auf Social-Media-Plattformen wie TikTok, YouTube, Bilibili, Douyin und Xiaohongshu hochlädt. Es vereinfacht Ihre plattformübergreifenden Content-Verteilungsprozesse.

## Was es bringt

- Möglichkeit zum gleichzeitigen Hochladen auf mehrere Plattformen.
- Automatisierung von Inhaltsverteilungsprozessen.
- Effizienter Workflow, der Zeit spart.

## Installation

**Mit pip (PyPI)**

```
pip install social-auto-upload
```

## Haftungshinweis

Der automatische Upload kann den Nutzungsbedingungen der Plattformen (Spam-/Automatisierungsregeln) unterliegen. Sie sind für die Sicherheit Ihres Kontos und die Einhaltung der Nutzungsbedingungen verantwortlich.

## Wie installiere ich, wie verwende ich?

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Installieren Sie das Social-Auto-Upload-Repository (github.com/dreammis/social-auto-upload) und melden Sie sich mit dem Befehlszeilentool „sau“ zunächst mit „sau douyin login“ bei meinem Konto an und laden Sie dann mit dem Befehl „sau douyin upload-video“ automatisch ein Video mit Titel und Beschreibung hoch.
