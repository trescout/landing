# Automatisierte Business Intelligence mit künstlicher Intelligenz

WrenAI wurde von Canner entwickelt und ist ein Open-Source-Tool für generative Business Intelligence (generative BI), das Daten automatisch in Panels und Diagramme exportiert, indem es natürliche Sprache in Datenbankabfragen (Text-to-SQL) umwandelt. Die Plattform bietet zuverlässige Datenanalyseprozesse für KI-Agenten über eine verwaltbare Kontextschicht, die mehr als zwanzig Datenquellen unterstützt.

## Was es bringt
- Erzeugt zuverlässige SQL-Abfragen aus natürlicher Sprache
- Konvertiert Daten automatisch in Panels
- Unterstützt mehr als 22 Datenquellen

## Installation
**CLI-Installation**

```
pip install wrenai                      # core (DuckDB included)
pip install "wrenai[postgres,memory]"   # add per-datasource and memory extras as needed
```

**Stub-Setup für AI-Client**

```
npx skills add Canner/WrenAI            # auto-detects Claude Code, Cursor, Cline, Codex, …
```


## Wenn Sie nicht programmieren
Konfigurieren Sie meine Datenbankverbindung mit WrenAI, erstellen Sie das Projektgerüst und führen Sie meine erste Abfrage aus. Bereichern Sie dann den Kontext, indem Sie die Geschäftslogikdaten im Rohordner in mein Projekt einbinden.
