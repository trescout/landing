# Perfektionieren Sie Ihre KI-Designs

Impeccable ist eine Designsprachenbibliothek, die entwickelt wurde, um die Designergebnisse von Modellen der künstlichen Intelligenz zu verbessern. Die Software stellt standardisierte Regeln zur Verbesserung der visuellen Konsistenz und ästhetischen Qualität generativer KI-Tools bereit.

## Was es bringt

- Bietet standardisierte Designsprache und visuelle Konsistenz für KI-Modelle.
- Es beschleunigt Designkontroll-, Verbesserungs- und Benutzererfahrungsprozesse mit 23 verschiedenen Befehlen.
- Es verhindert automatisch häufige Designfehler mit 27 deterministischen Anti-Pattern-Regeln.

## Installation

**Installation über CLI**

```
npx impeccable skills install
```

## Ausführung

**Designprüfung**

```

```

## Wenn Sie nicht programmieren

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich möchte die Designqualität und visuelle Konsistenz meines Projekts verbessern. Ich möchte, dass Sie meine aktuelle Benutzeroberfläche mit dem Impeccable-Tool überprüfen und gemäß den Standards der Designsprache verbessern. Bitte verwenden Sie /impeccable-Befehle, um visuelle Fehler in meinem Projekt zu überprüfen, Mängel zu identifizieren und Anpassungen vorzunehmen, um die Benutzererfahrung zu verbessern.

Repository: https://github.com/pbakaus/impeccable. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.
