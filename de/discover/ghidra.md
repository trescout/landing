# Analyse-Framework für Software-Reverse-Engineering

Ghidra wurde von der National Security Agency (NSA) entwickelt und ist ein umfassendes Analyse-Framework für Software-Reverse-Engineering-Prozesse. Dieses in Java geschriebene Tool bietet Sicherheitsforschern die Möglichkeit, die Codestruktur von Binärdateien detailliert zu analysieren.

- ★ 74.145
- Java
- GitHub Trending · 2026-08-28

## Was es bringt
- Analyse kompilierter Codes auf verschiedenen Plattformen
- Binärdateien disassemblieren und dekompilieren
- Automatisierung von Prozessen mit anpassbaren Skripten
