# 12-wöchiger Lehrplan für künstliche Intelligenz

AI for Beginners wurde von Microsoft vorbereitet und vermittelt anhand von Jupyter Notebooks Einführungsthemen in die künstliche Intelligenz mit einem 12-wöchigen Lehrplan. Dieser Inhalt von 24 Lektionen bietet eine strukturierte Bildungsressource für diejenigen, die grundlegende Konzepte anhand angewandter Beispiele erlernen möchten.

## So fangen Sie an

Wenn Sie die Installationsbefehle nicht verwenden möchten, können Sie die Lektionen direkt über den Browser starten, indem Sie auf der GitHub-Seite des Projekts auf den Binder-Link klicken. Sie können den gesamten Lehrplan und die Kursnotizen auch über die Startseite auf GitHub abrufen.
