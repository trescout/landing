# Verwalten Sie Ihr eigenes Medienarchiv

LunaTV ist ein Projekt, das mit der Sprache TypeScript entwickelt wurde und eine Open-Source-Oberfläche zur Medienwiedergabe bietet. Diese Software ist nicht für die kommerzielle Nutzung bestimmt und ermöglicht es Benutzern, ihre eigenen Medieninhalte in einer strukturierten Form anzusehen.

- ★ 10.021
- TypeScript
- GitHub Trending · 2026-09-08

## Was es bringt
- Möglichkeit, persönliche Medieninhalte über eine strukturierte Oberfläche anzusehen
- Synchronisierung von Wiedergabeverlauf und Favoriten über verschiedene Geräte hinweg
- Portables Wiedergabeerlebnis über den Browser ohne Installationsaufwand

## So fangen Sie an
Dieses Tool arbeitet mit der Software-Containerisierungstechnologie namens Docker. Für die Installation können Sie den Abschnitt '部署' (Bereitstellung) auf der GitHub-Seite des Projekts besuchen, um die Docker-Compose-Dateien zu verwenden, oder eine Ein-Klick-Installation über Cloud-Plattformen wie Zeabur durchführen. Beachten Sie, dass das Projekt mit einer leeren Oberfläche geliefert wird und Sie Ihre eigenen Medienquellen hinzufügen müssen.
