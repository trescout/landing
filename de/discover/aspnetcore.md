# Plattform für Unternehmens-Webanwendungen

ASP.NET Core ist ein plattformübergreifendes .NET-Framework zur Entwicklung moderner cloudbasierter Webanwendungen unter Windows, macOS und Linux. Diese in der Sprache C# entwickelte Struktur ermöglicht die Erstellung leistungsstarker und skalierbarer Webdienste.

## Was es bringt
- Plattformübergreifender Betrieb unter Windows, macOS und Linux
- Cloudbasierte und skalierbare Anwendungsentwicklung
- Modularer Komponentenaufbau mit geringem Ressourcenverbrauch

## Installation
**macOS (Homebrew)**

```
brew install --cask dotnet-sdk
```

**Windows (Winget)**

```
winget install Microsoft.DotNet.SDK.10
```


## Ausführung
**Erstellen Sie ein neues ASP.NET Core-Projekt und führen Sie es aus**

```
dotnet new webapi -n MyWebApp
cd MyWebApp
dotnet run
```
