# Intelligentes Terminal und Automatisierung für macOS

cmux, ein Ghostty-basiertes macOS-Terminal, bietet Unterstützung für vertikale Tabs und Benachrichtigungen für KI-Codierungs-Agenten. Dieses auf Multitasking und Programmierbarkeit ausgerichtete Tool hilft Entwicklern, ihre Arbeitsumgebung zu organisieren.

## Was es bringt

- Bietet Benachrichtigungsunterstützung für KI-Codierungs-Agenten
- Organisiert den Arbeitsbereich mit vertikalen und horizontalen Tabs
- Enthält einen integrierten Browser mit einer skriptfähigen API

## Installation

**Installation mit Homebrew**

```
brew tap manaflow-ai/cmux
brew install --cask cmux
```

## Ausführung

**Anwendung aktualisieren**

```
brew upgrade --cask cmux
```
