# NASA-Entwicklungsrahmen für Flugsoftware

F´ wurde von der NASA entwickelt und ist ein Open-Source-Framework für Flugsoftware und eingebettete Systeme. Diese in C++ geschriebene Struktur bietet eine modulare Entwicklungsumgebung für Raumfahrzeuge und komplexe Systeme.

## Was es bringt

- Modularer Aufbau für Raumfahrzeuge und eingebettete Systeme
- Komponentenbasierte schnelle Softwareentwicklungsumgebung
- Automatische Codegenerierung und integrierte Testtools

## Installation

**Installieren des Bootstrap-Tools**

```
pip install fprime-bootstrap
```

## Ausführung

**Erstellen Sie ein neues Projekt**

```
fprime-bootstrap project
```
