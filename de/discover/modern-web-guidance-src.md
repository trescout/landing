# Kalibrierung von Leitfäden für die moderne Webentwicklung

GoogleChrome/modern-web-guidance-src ist ein Ressourcen-Repository, das den Code und die Dokumentation enthält, die für die Erstellung, Kalibrierung und Bewertung von Leitfäden für die moderne Webentwicklung erforderlich sind. Dieses in TypeScript entwickelte Projekt ermöglicht die Verwaltung von Leitfadeninhalten für Webstandards.

- ★ 1.570
- TypeScript
- GitHub Trending · 2026-11-11

## Was es bringt

- Ersetzt veraltete Codierungsgewohnheiten von KI-Coding-Agenten durch aktuelle Webstandards.
- Überträgt fertige Entwicklungsleitfäden mit Fokus auf Browserkompatibilität und Leistung direkt in den Kontext des Agenten.
- Stellt die integrierten Browserfunktionen und leichtgewichtige Lösungen anstelle von unnötigen Bibliotheken in den Vordergrund.

## Installation

**Installation mit interaktivem Assistenten**

```
npx modern-web-guidance@latest install
```

**Alternative Installation mit Optionen**

```
npx modern-web-guidance@latest install --choose
```

## Ausführung

**Suche nach Leitfäden und veralteten Strukturen im Code**

```
# Search for relevant guides
npx modern-web-guidance@latest search "animate a dialog modal backdrop"

# Retrieve a guide by ID
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"

# Scan a codebase for legacy patterns to modernize
npx modern-web-guidance@latest legacy-scan .
```
