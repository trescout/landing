# Erstellen Sie Ihren eigenen Medienserver

Jellyfin ist ein kostenloser Medienserver, mit dem Sie Ihre eigene Film-, Fernsehserien- und Musiksammlung verwalten und auf alle Ihre Geräte streamen können. Diese Plattform ist eine Alternative zu Plex und Emby und verfügt über keine Premium-Sperren, Werbung oder versteckte Gebühren.

## Was es bringt

- Alle Ihre Medien an einem Ort und von jedem Gerät aus zugänglich.
- Sie müssen sich nicht mit Abonnementgebühren oder Werbung herumschlagen.
- Ihre Daten bleiben bei Ihnen und werden nicht an Dritte weitergegeben.
- Eine Alternative zu Plex und Emby, die völlige Freiheit bietet.

## Installation

**Mit Docker**

```
docker run -d --name jellyfin -p 8096:8096 jellyfin/jellyfin
```

## Ausführung

**Im Browser öffnen**

```
http://localhost:8096
```

## Wie installiere ich?

Docker wird auf einem Server oder NAS installiert. Die Installationsanleitung finden Sie unter jellyfin.org. Nach der Installation stellen Sie Ihre Medienordner vor.
