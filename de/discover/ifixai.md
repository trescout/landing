# KI-Agenten überprüfen

iFixAi ist ein unabhängiges Prüftool, das kontrolliert, ob KI-Agenten die ihnen zugewiesenen Aufgaben ordnungsgemäß ausführen. Dieses in Python entwickelte System kann von Menschen oder dem Agenten selbst ausgeführt werden und analysiert die Korrektheit der Prozesse in weniger als zwei Minuten.

## Was es bringt

- Testet, ob Ihre KI-Agenten ihre Aufgaben korrekt ausführen.
- Liefert in weniger als zwei Minuten einen detaillierten Analysebericht.
- Erkennt Systemlücken und übersehene Fehler im Voraus.

## Installation

**Paket installieren**

```
pip install "ifixai[openai]"   # or anthropic, gemini, etc.: install the provider extra you'll test
```

**Öffnen Sie den Installationsassistenten**

```
ifixai setup                    # arrow-key wizard: pick provider, model, judge, suite → writes ifixai.yaml
```

## Ausführung

**Starten Sie das Tool**

```
ifixai run                      # no flags needed; reports land in ./ifixai-results/
```
