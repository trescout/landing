# Open-Source-Finanzverwaltung für Privatpersonen

Sure, entwickelt mit der Sprache Ruby, ist eine Open-Source-Anwendung für die persönliche Finanz- und Vermögensverwaltung, die für jeden zugänglich ist. Dieses Projekt wurde als Open-Source-Plattform konzipiert und bietet Funktionen, die es Benutzern ermöglichen, direkt mit Finanzberatern (CFP/CFA) in Kontakt zu treten.

## Was es bringt

- Verfolgt Cashflow und Nettovermögen
- Stellt direkte Verbindungen zu Finanzberatern her
- Kann auf dem eigenen Server gehostet werden

## So fangen Sie an

Um die Anwendung auf Ihrem eigenen Server auszuführen, können Sie den Docker-Hosting-Leitfaden lesen oder sie mithilfe des Entwicklerhandbuchs in einer lokalen Umgebung installieren. Detaillierte Anleitungen finden Sie in der Dokumentation im Projekt-Repository.
