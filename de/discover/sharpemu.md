# Experimentelles PlayStation 5-Emulatorprojekt

Sharpemu ist ein experimentelles PlayStation 5-Emulatorprojekt, das in der Sprache C# entwickelt wurde. Bei dieser Studie, die darauf abzielt, die Konsolenarchitektur auf Softwarebasis zu imitieren, handelt es sich um ein technisches Experiment, das zu Emulationstechnologien für Spielekonsolen durchgeführt wird.

- ★ 1.379
- C#
- GitHub Trending · 2026-07-13

## Was es bringt
- Gelegenheit, die Architektur von Spielekonsolen zu untersuchen
- Unterstützung für die Ausführung nativer CPU-Anweisungen
- Metadaten aus Spieledateien lesen

## So fangen Sie an
Um das Projekt zu verwenden, können Sie vorgefertigte Dateien von der Registerkarte „Releases“ auf der GitHub-Seite herunterladen oder die Quellcodes auf Ihrem Computer mit installiertem .NET SDK kompilieren. Zum Kompilieren kopieren Sie einfach das Projekt auf Ihren Computer, öffnen die Lösungsdatei über VSCode und führen den Befehl „dotnet build“ im Terminal aus.
