# Aktivieren Sie Hermès-Zifferblätter für die Apple Watch

pookjw/HermesEnabler ist eine Software, die Hermès-Zifferblätter (watch faces) auf allen Apple Watch-Geräten mit unterstützten watchOS-Versionen verfügbar macht. Dieses Tool, das auf macOS mit Xcode kompiliert oder mit App-Installationstools wie Sideloadly installiert werden kann, erfordert eine mit einem iPhone gekoppelte Apple Watch.

## Was es bringt

- Verwendung spezieller Zifferblätter auf unterstützten Uhren
- Unterstützung der Betriebssysteme macOS und Windows
- Schritt-für-Schritt-Installation über die Watch-App bereitstellen

## So fangen Sie an

Sie können die Installation auf macOS mit dem App-Installationstool Sideloadly oder der Entwicklersoftware Xcode durchführen. Auf der Windows-Seite können Sie das Community-Tool WatchBridge verwenden. Sie können die Installationsdateien von der offiziellen GitHub-Seite herunterladen und der Anleitung folgen.
