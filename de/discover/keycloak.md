# Zentrales Identitätsmanagement für Ihre Anwendungen

Keycloak bietet Open-Source-Identitäts- und Zugriffsmanagementlösungen für moderne Anwendungen und Dienste. Diese Java-basierte Plattform dient der Standardisierung zentraler Authentifizierungs- und Autorisierungsprozesse.

- ★ 36.517
- Java
- GitHub Trending · 2026-06-28

## Was es bringt
- Standardisiert Benutzerauthentifizierungsprozesse.
- Bietet starkes Identitätsmanagement und Autorisierung.
- Erhöht mühelos die Anwendungssicherheit.

## Installation
**Lokalen Dev-Container starten**

```
docker run --name keycloak -p 127.0.0.1:8080:8080 -e KC_BOOTSTRAP_ADMIN_USERNAME=admin -e KC_BOOTSTRAP_ADMIN_PASSWORD=change_me quay.io/keycloak/keycloak:latest start-dev
```


## Ausführung
**Lokale Oberfläche öffnen**

```
http://localhost:8080
```
