# Zentrales Identitätsmanagement für Ihre Anwendungen

Keycloak bietet Open-Source-Identitäts- und Zugriffsmanagementlösungen für moderne Anwendungen und Dienste. Diese Java-basierte Plattform dient der Standardisierung zentraler Authentifizierungs- und Autorisierungsprozesse.

- Erhöht mühelos die Anwendungssicherheit.

## Installation
**Nehmen Sie das offizielle Bild**

```
docker pull quay.io/keycloak/keycloak
```


## Ausführung
**Beginnen Sie im Entwicklungsmodus**

```
docker run -p 8080:8080 -e KC_BOOTSTRAP_ADMIN_USERNAME=admin -e KC_BOOTSTRAP_ADMIN_PASSWORD=admin quay.io/keycloak/keycloak start-dev
```
