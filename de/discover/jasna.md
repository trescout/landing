# Reparieren und verbessern Sie Ihre Videos

Kruk2/jasna ist ein Videoreparatur-Tool (Video Restoration Tool), das zur Verbesserung von Videos entwickelt wurde. Dieses in Python geschriebene Projekt automatisiert technische Prozesse zur Steigerung der Bildqualität.

## Aktualisierungen

## Was es bringt

- Erkennt automatisch verpixelte Bereiche in Videos und bereinigt diese, ohne den Rest des Bildes zu beeinträchtigen
- Repariert nur die von Ihnen festgelegten Abschnitte, anstatt das gesamte Video mit dem Bearbeitungstool zu verarbeiten
- Ermöglicht durch den integrierten Videoplayer die sofortige Vorschau des korrigierten Bildes, ohne eine neue Datei speichern zu müssen

## So fangen Sie an

Laden Sie das für Ihr Betriebssystem und Ihren Grafikprozessor geeignete Paket aus dem Release-Bereich der GitHub-Seite herunter. Entpacken Sie das heruntergeladene Archiv in einen lokalen Ordner, dessen Pfad keine türkischen oder Sonderzeichen enthält. Wenn Sie Windows verwenden, können Sie die grafische Benutzeroberfläche durch Ausführen der Datei jasna.exe im Ordner aufrufen.
