# Wifit3

Wifit3 ist ein in Python entwickeltes Tool zum Testen der WLAN-Sicherheit, das ausschließlich mit USB-Geräten funktioniert und verschiedene Betriebssysteme unterstützt. Es ist eine plattformübergreifende Alternative zu Wifite, einer beliebten Sicherheitssoftware, die Netzwerküberprüfungsprozesse automatisiert.
