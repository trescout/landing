# Open-Source-Kodierungsagent für künstliche Intelligenz

OpenCode ist ein Open-Source-Coding-Agent zur Automatisierung von Softwareentwicklungsprozessen. Dieses mit der TypeScript-Sprache entwickelte Tool bietet Funktionen zur autonomen Aufgabenausführung in Softwareprojekten.

- TypeScript

**Hinweis von TreScout:** Open-Source-Coding-Agent, der im Terminal ausgeführt wird. Sie wählen das Modell, Ihr Code geht dorthin, wo Sie wollen. Im Gegenzug liegen die Installations- und Modellkosten in Ihrer Verantwortung, fertige Produkte haben keinen Glanz.

## Was es bringt

- Verwaltet Softwareentwicklungsprozesse selbstständig
- Bietet spezielle Modi für die Codeüberprüfung und -planung
- Bietet globale Suchfunktion für mehrstufige Aufgaben

## Installation

**npm: global**

```
npm install -g opencode
```

## Wenn Sie nicht programmieren

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich möchte, dass Sie die Codes in meinem aktuellen Softwareprojekt mit dem OpenCode-Tool analysieren und dabei helfen, die Entwicklungsprozesse zu automatisieren. Mit dem Build-Agent können Sie während der Laufzeit mit vollem Zugriff entwickeln oder mit dem Plan-Agent die Codes überprüfen und Änderungen planen. Für komplexe Suchen oder mehrstufige Aufgaben erwarte ich, dass Sie @general verwenden.

Repository: https://github.com/anomalyco/opencode. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.
