# Hochgeschwindigkeits-Verwaltungstool für Python-Projekte

Entwickelt in der Programmiersprache Rust, ist uv ein auf hohe Geschwindigkeit ausgelegtes Tool zur Verwaltung von Python-Paketen und -Projekten. Es bietet eine leistungsorientierte Alternative zu herkömmlichen Paketmanagern (pip, pip-tools).

## Was es bringt

- Schließt Paketwarten-Operationen 10- bis 100-mal schneller ab als herkömmliche Tools.
- Die Programmiersprache lädt Python-Versionen auf Ihren Computer herunter und organisiert sie entsprechend Ihren Projekten.
- Führt die Funktionen von Tools wie dem Paketmanager pip, der Bibliotheksabhängigkeiten verwaltet, eigenständig aus.

## Installation

**Installation für macOS und Linux**

```
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Installation für Windows**

```
# On Windows.
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Ausführung

**Tool aktualisieren**

```
uv self update
```
