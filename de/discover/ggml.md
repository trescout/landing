# Tensor-Bibliothek für KI-Modelle

ggml-org/ggml ist eine in C++ entwickelte Tensor-Bibliothek für Modelle des maschinellen Lernens. Die Software erleichtert die Ausführung von KI-Modellen, indem sie einfache und anschauliche Beispiele für grundlegende Operationen wie die Matrizenmultiplikation bietet.

## Was es bringt

- Bietet Hochleistungs-Tensor-Operationen in C und C++ ohne externe Abhängigkeiten.
- Kann auf CPUs (Central Processing Units), GPUs (Graphics Processing Units) und in Browser-Umgebungen ausgeführt werden.
- Reduziert den Speicherbedarf durch Quantisierungsformate, die die Datengröße verringern.

## Installation

**Kompilieren aus Quellcode**

```
git clone https://github.com/ggml-org/ggml
cd ggml

mkdir build && cd build
cmake ..
cmake --build . --config Release -j 8
```
