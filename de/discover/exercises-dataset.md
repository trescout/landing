# Mehrsprachiger Fitnessübungsdatensatz

Der von Hasaneyldrm geteilte Übungsdatensatz (exercises-dataset) bietet 433 verschiedene Fitnessbewegungen mit Namen, Zielmuskelgruppen, Ausrüstung und visuellen Anweisungen. Diese umfassende Ressource bietet eine strukturierte Dateninfrastruktur für diejenigen, die Sporttechnologieanwendungen entwickeln.

## Was es bringt

- Strukturierte Daten für 1.324 verschiedene Fitnessübungen
- Schritt-für-Schritt-Anleitung zur Bewerbung in 6 Sprachen, darunter Türkisch
- Bereiter Leitfaden für die Datenbank- und API-Integration

## So fangen Sie an

Für dieses Tool ist keine Installation erforderlich. Nachdem Sie die Dateien auf der GitHub-Seite auf Ihren Computer heruntergeladen haben, können Sie die Übungen überprüfen, indem Sie die Datei „index.html“ mit einem beliebigen Internetbrowser öffnen, und auf die Datenbank und die API-Installationsanleitung zugreifen, indem Sie die Datei „setup.html“ öffnen.
