# KI-Knoten für Windows

OpenClaw bietet über den Windows-Knoten, die Taskleistenanwendung, die gemeinsam genutzte Bibliothek und die PowerToys-Befehlspalettenerweiterung eine integrierte Verwaltungssuite für das Windows-Betriebssystem. Dieses in der Sprache C# entwickelte Tool zielt darauf ab, den Zugriff auf Systemressourcen und Benutzerworkflows zu standardisieren.

## Was es bringt

- Bietet schnellen Zugriff auf den OpenClaw-Assistenten für künstliche Intelligenz über die Taskleiste.
- Es bietet lokales Gateway- und Verbindungsmanagement unter Windows.
- Es ermöglicht Live-Sitzungen, Nutzung und Knotenverfolgung mit der Kommandozentrale.

## Ausführung

**Nativer App-Start**

```
.\run-app-local.ps1
```

**Die WebSocket-Verbindung über CLI ist korrekt**

```
dotnet run --project src/OpenClaw.Cli -- --help
```
