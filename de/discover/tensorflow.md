# Open-Source-Plattform für KI-Modelle

TensorFlow, entwickelt von Google, ist eine Open-Source-Bibliothek zum Erstellen und Trainieren von Modellen für maschinelles Lernen (Machine Learning). Sie ermöglicht Entwicklern, komplexe neuronale Netze (Neural Networks) zu entwerfen und diese Modelle skalierbar bereitstellen.

## Was es bringt

- Ermöglicht das Erstellen und Bereitstellen von Anwendungen für maschinelles Lernen
- Bietet stabile Schnittstellen für die Programmiersprachen Python und C++
- Enthält ein flexibles Ökosystem mit GPU- und CPU-Unterstützung

## Installation

**Um die Bibliothek zu installieren**

```
pip install tensorflow
```

**Um nur die Version mit CPU-Unterstützung zu installieren**

```
pip install tensorflow-cpu
```

## Ausführung

**Um die Python-Umgebung zu starten**

```
python
```
