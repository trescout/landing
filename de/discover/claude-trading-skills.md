# KI-gestützte Investitionsentscheidungstools

tradermonty/claude-trading-skills bietet Claude Code-Fähigkeiten (Skills), die Prozesse wie Marktanalyse, technische Charts und Strategieentwicklung für Aktieninvestoren und Trader automatisieren. Dieses in Python entwickelte Projekt zielt darauf ab, Finanzdatenverarbeitungsprozesse mit Wirtschafts- und Browser-Tools zu unterstützen.

- Python

## Was es bringt

- Optimiert Marktanalyseprozesse für zeitkritische Investoren
- Bietet strukturierte Arbeitsabläufe für Risikomanagement und Handelsplanung
- Beinhaltet einen Einstiegspfad, der keine kostenpflichtigen Daten-Tool-Abos erfordert

## Ausführung

**Befehl zum Paketieren der Fähigkeiten**

```
python3 scripts/package_skills.py --skill <skill-name>
```
