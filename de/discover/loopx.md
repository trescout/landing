# Persistenter Speicher für Agenten der künstlichen Intelligenz

Loopx ist ein leichtgewichtiger Zustandskernel, der für Langzeitagententeams mit künstlicher Intelligenz entwickelt wurde. Es arbeitet kompatibel mit Coding-Agenten (Codex, Claude Code) und standardisiert Prozesse wie Aufgabenverfolgung, Quotenverwaltung und nachweisbare Arbeitsübertragung.

## Was es bringt

- Standardisiert die Zielverfolgung und Quotenverwaltung bei Langzeitmissionen.
- Es ermöglicht eine nachweisbare Arbeitsübergabe zwischen verschiedenen KI-Agenten.
- Speichert den Aufgabenverlauf und Beweise in einer organisierten Struktur.

## Installation

**Direkte Installation**

```
curl -fsSL https://raw.githubusercontent.com/huangruiteng/loopx/main/scripts/install-from-github.sh | bash
export PATH="$HOME/.local/bin:$PATH"
loopx doctor
```

## Ausführung

**Starten des Projekts**

```
cd /path/to/your-project
loopx connect
loopx status
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Wir arbeiten mit Ihnen an einem langfristigen Projekt. Ich möchte unsere Aufgaben, Ziele und Fortschrittsprotokolle mit der LoopX-Status-Bean verwalten. Überprüfen Sie während der Arbeit den aktuellen Status bei jedem Schritt, erfassen Sie Nachweise über abgeschlossene Arbeiten und halten Sie die Kontingentgrenzen ein, indem Sie die nächste Aufgabe (todo) festlegen. Hinterlassen Sie eine überprüfbare Spur durch LoopX, wenn Sie Aufgaben delegieren oder in eine neue Phase wechseln.
