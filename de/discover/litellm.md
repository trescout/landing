# KI-Modelle zentral an einem Ort verwalten

LiteLLM ist ein KI-Gateway (AI Gateway), das Schnittstellen von über 100 großen Sprachmodellen (LLMs) in einem einheitlichen Standardformat zusammenführt. Es bietet Softwareentwicklern Funktionen wie Kostenverfolgung, Lastverteilung und Guardrails, wodurch der Wechsel zwischen verschiedenen Modellanbietern erleichtert wird.

## Was es bringt

- Vereint mehr als hundert LLM-Anbieter (Large Language Model) in einem einzigen Standardformat und verhindert so Code-Chaos.
- Macht das Umschreiben Ihrer Codebasis beim Wechsel zwischen KI-Modellen überflüssig.
- Bietet mit Tools wie virtuellen Schlüsseln, Budgetverfolgung und Lastverteilung eine Verwaltungsinfrastruktur auf Unternehmensebene.

## Installation

**Python-Bibliothek für die Programmiersprache in**

```
uv add litellm
```

## Ausführung

**Starten des Gateway-Servers**

```
uv tool install 'litellm[proxy]'
litellm --model gpt-4o
```
