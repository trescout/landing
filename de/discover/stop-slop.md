# KI-Texte naturalisieren

Mit künstlicher Intelligenz erstellte Texte enthalten oft vorhersehbare Ausdrücke, Rhythmen und Strukturen. Stop Slop ist eine Fertigkeitsdatei, die Claude oder jedem LLM beibringt, diese Muster zu erkennen und zu beseitigen. Auf diese Weise erhalten Ihre Texte einen viel natürlicheren und menschlicheren Ton.

## Was es bringt
- Texte werden natürlicher gelesen, klischeehafte Ausdrücke und Wiederholungen werden reduziert.
- Es kann jedem LLM beigebracht werden (nicht nur Claude).
- Es verringert das Gefühl, bei der Content-Produktion von künstlicher Intelligenz geschrieben zu werden.

## Wie benutzt man?
- Korrigieren Sie diesen Text gemäß den Stop Slop-Regeln und löschen Sie KI-Muster.

## Wie installiere ich, wie verwende ich?
Laden Sie dieses Repository herunter (https://github.com/hardikpandya/stop-slop) und fügen Sie den Stop-Slop-Skill als Skill zu Claude Code hinzu; Dann nutzen Sie diese Fähigkeit, um KI-spezifische Klischees aus den von mir verfassten Texten zu entfernen.
