# KI-Training im Unternehmensmaßstab

Miles ist ein unternehmensorientiertes Framework, das Reinforcement-Learning-Prozesse für große Sprachmodelle (LLMs) und visuelle Sprachmodelle (VLMs) verwaltet. Dieses Python-basierte Tool wurde zur Optimierung von Post-Training-Prozessen entwickelt und entwickelt sich parallel zum Slime-Projekt weiter.

- ★ 2.603
- Python
- GitHub Trending · 2026-09-05

## Was es bringt
- Bietet leistungsstarke Reinforcement-Learning-Prozesse für Modelle mit Billionen von Parametern.
- Bietet Integration mit SGLang (Hochgeschwindigkeits-Modellbereitstellungssoftware) und Megatron-LM (skalierbare Trainingsbibliothek).
- Dank Fehlertoleranz erfolgt bei Systemabstürzen eine automatische Wiederherstellung, ohne das Training zu unterbrechen.
