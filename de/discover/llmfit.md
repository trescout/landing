# Finden Sie KI-Modelle, die zu Ihrer Hardware passen

Llmfit wurde mit der Rust-Sprache entwickelt und scannt Hunderte großer Sprachmodelle und Anbieter und ermöglicht es Ihnen, mit einem einzigen Befehl diejenigen zu identifizieren, die mit Ihrer Hardware kompatibel sind. Das Tool automatisiert den Prozess der Suche nach Modellen, die am besten zu den lokalen Systemressourcen passen.

## Was es bringt

- Erkennt automatisch mit Ihrem System kompatible Modelle
- Sortiert nach Speicher, Geschwindigkeit und Qualität
- Bietet eine einfache Verwaltung mit interaktiver Schnittstelle

## Installation

**Installation für macOS oder Linux**

```
brew install AlexsJones/llmfit/llmfit
```

**Schnelle Installation**

```
curl -fsSL https://llmfit.axjns.dev/install.sh | sh
```

## Ausführung

**Starten der interaktiven Oberfläche**

```
llmfit
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Analysieren Sie die Hardwarespezifikationen meines Systems und empfehlen Sie basierend auf meiner verfügbaren RAM-, CPU- und GPU-Kapazität die besten KI-Modelle für die Ausführung. Sortieren Sie die Modelle nach Leistung, Speicherverbrauch und Qualitätskriterien und listen Sie diejenigen auf, die am besten zu mir passen.
