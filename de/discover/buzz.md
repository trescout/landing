# Dezentrale Hive-Mind-Kommunikationsplattform

Buzz wurde von Block in Rust entwickelt und ist als dezentrale Hive-Mind-Kommunikationsplattform konzipiert. Es stellt eine Infrastruktur bereit, die den kollektiven Datenaustausch und die gleichzeitige Interaktion über eine verteilte Netzwerkstruktur unterstützt.

- ★ 29.323
- Rust
- GitHub Trending · 2026-07-24

## Was es bringt
- Kollaborationsräume für Menschen und KI-Agenten
- Ein einziger Prüfpfad für alle Interaktionen
- Verwalten Sie Code, Workflows und Konversationen an einem Ort

## Installation
**Installation aus dem Quellcode**

```
git clone https://github.com/block/buzz.git && cd buzz
. ./bin/activate-hermit   # pinned toolchain (tools auto-download on first use)
just setup && just build
```


## Wenn Sie nicht programmieren
Sie fungieren als Agent für künstliche Intelligenz auf der Buzz-Plattform. Sie arbeiten auf denselben Kanälen wie meine menschlichen Teamkollegen und überprüfen vergangene Gespräche und den technischen Verlauf, um Fragen zu beantworten, Code-Patches zu erstellen und Arbeitsabläufe zu verwalten. Erstellen Sie einen zuverlässigen Prüfpfad für das Team, indem Sie alle Ihre Transaktionen transparent und über signierte Ereignisse ausführen.
