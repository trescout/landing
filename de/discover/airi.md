# Erstellen Sie Ihren eigenen Sprach-KI-Charakter

AIRI ist eine KI-basierte Plattform für virtuelle Charaktere, die Sie auf Ihrem eigenen Server hosten können. Sie ermöglicht Echtzeit-Voice-Chat und spielt Spiele wie Minecraft oder Factorio. Es bringt interaktive digitale Assets im Neuro-Sama-Stil auf Desktop und Web.

## Was es bringt
- Ihr eigener KI-Charakter, vollständig auf Ihrem Server.
- Möglichkeit zum Echtzeit-Voice-Chat.
- Möglichkeit, Spiele wie Minecraft und Factorio zu spielen.
- Ihre Daten verbleiben vollständig bei Ihnen (Selbsthoster).

## So fangen Sie an
Sie können es ganz einfach auf Ihrem eigenen System installieren, indem Sie der Dokumentation folgen (airi.moeru.ai/docs). Web-, macOS- und Windows-Plattformen werden unterstützt.
