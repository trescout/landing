# Texturmalerei für 3D-Modelle

ArmorPaint ist ein Grafikdesign-Tool für die Echtzeit-Texturmalerei auf 3D-Modellen. Die Software bietet digitale Künstlern Flexibilität bei komplexen Texturerstellungsprozessen durch Unterstützung für physikalisch basiertes Rendering (PBR).

## Was es bringt

- Echtzeit-Texturmalerei auf Modellen durchführen
- Professionelle Ergebnisse mit Unterstützung für physikalisch basiertes Rendering erzielen
- Komplexe Texturerstellungsprozesse beschleunigen

## Installation

**Dateien auf Ihren Computer herunterladen**

```
git clone https://github.com/armory3d/armorpaint
cd armorpaint/paint
```

## Ausführung

**Ausführung unter Linux**

```
../base/make --run
```
