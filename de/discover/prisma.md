# Datenbankverwaltung für Node.js-Projekte

Prisma ist ein Object Relational Mapper (ORM)-Tool, das Datenbankinteraktionen für Node.js- und TypeScript-Projekte vereinfacht. Seine Struktur, die verschiedene Datenbanksysteme unterstützt, ermöglicht es Entwicklern, typsichere Datenbankabfragen zu erstellen.

## Was es bringt

- Erstellen typsicherer Datenbankabfragen
- Deklarative Datenmodellierung und -migration
- Grafische Oberfläche zur Datenvisualisierung

## Installation

**Erforderliche Pakete installieren**

```
npm install prisma --save-dev
npm install @prisma/client
```

## Ausführung

**Starten eines lokalen Datenbankservers**

```
npx prisma dev
```

**Erstellen einer cloudbasierten Datenbank**

```
npx create-db --interactive
```
