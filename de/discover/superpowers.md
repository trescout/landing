# Erweiterte Methodik für Codierungsagenten

Superpowers ist eine umfassende Softwareentwicklungsmethodik mit zusammengesetzten Fähigkeiten für Ihre Programmieragenten. Standardisiert agentenbasierte Arbeitsabläufe. Funktioniert mit Claude Code, Codex CLI, Gemini CLI und mehr.

## Was es bringt

- Ein vorgefertigtes, zusammengesetztes Kompetenzset für Ihren Agenten.
- Eine strukturierte Entwicklungsmethodik.
- Standardisieren Sie Agenten-Workflows.
- Volle Kompatibilität mit mehreren Plattformen.

## Installation

**Claude Code-Plugin installieren**

```
/plugin install superpowers@claude-plugins-official
```

## So fangen Sie an

Verleihen Sie Ihrem Agenten mit TreScout Superkräfte. Im Repository warten Schnellstartschritte für Claude Code, Codex und Gemini auf Sie.

## Wie installiere ich, wie verwende ich?

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Installieren Sie das Superpowers-Plugin, indem Sie den Befehl „/plugin install superpowers@claude-plugins-official“ in Claude Code ausführen. Wenn ich von nun an etwas verbessern möchte, kommen die Fähigkeiten automatisch ins Spiel.
