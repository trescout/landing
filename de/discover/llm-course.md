# Lernpfad für große Sprachmodelle

mlabonne/llm-course ist eine umfassende Bildungsressource mit Lernpfaden und Colab-Notizbüchern für alle, die in den Bereich der großen Sprachmodelle (LLM) einsteigen möchten. Dieses Projekt bietet einen Lehrplan, der Interessierte von den Grundlagen bis hin zu fortgeschrittenen KI-Modellen führt.

- ★ 84.301
- GitHub Trending · 2026-10-19

## Was es bringt

- Verständnis der Architektur von Sprachmodellen, beginnend mit grundlegender Mathematik und neuronalen Netzen
- Optimierung von Open-Source-Modellen durch Fine-Tuning und Quantisierung
- Direktes Ausführen von Experimenten ohne Installation über fertige Google Colab-Cloud-Notizbücher

## So fangen Sie an

Um dieses Projekt zu nutzen, müssen Sie keine Software auf Ihrem Computer installieren. Sie können die Themen im GitHub-Repository oder auf der DeepWiki-Dokumentationsseite durchgehen und auf den Google Colab-Link des gewünschten Abschnitts klicken, um die Arbeiten direkt in Ihrem Browser auszuführen.
