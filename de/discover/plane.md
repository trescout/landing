# Open-Source-Projektmanagementplattform

Plane ist eine Open-Source-Projektmanagementplattform, die Aufgabenverwaltung, Sprintplanung und Dokumentationsprozesse kombiniert. Diese Plattform wurde als Alternative zu Unternehmenstools wie Jira und Linear entwickelt und ermöglicht es Teams, Arbeitsabläufe über eine zentrale Schnittstelle zu organisieren.

- ★ 57.579
- TypeScript
- GitHub Trending · 2026-06-18

## Was es bringt
- Verfolgen Sie Aufgaben und Produkt-Roadmaps in einer zentralen Oberfläche
- Aufteilung komplexer Projekte in überschaubare Module und Zyklen
- KI-gestützte Dokumentations- und Analysetools

## Installation
**Laden Sie das Installationsskript herunter**

```
curl -fsSL -o setup.sh https://github.com/makeplane/plane/releases/latest/download/setup.sh
```

**Machen Sie es ausführbar**

```
chmod +x setup.sh
```


## Ausführung
**Installation starten (2 aus dem Menü)**

```
./setup.sh
```
