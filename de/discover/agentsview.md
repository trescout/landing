# Überwachen Sie Ihre Coding Agents mit künstlicher Intelligenz

Agentsview ist ein Überwachungstool, das lokale Sitzungsinformationen und Analysedaten für Codierungsagenten bereitstellt. Diese Software, die mehr als zwanzig Agenten unterstützt, darunter Claude Code und Codex, verspricht eine schnellere Leistung im Vergleich zum Ccusage-Tool.

## Was es bringt

- Überwachen Sie die Sitzungen aller Ihrer künstlichen Intelligenz-Coding-Agenten von einem einzigen Zentrum aus.
- Berechnen Sie schnell die Beträge und Kosten der verwendeten Token.
- Schützen Sie Ihre Privatsphäre, indem Sie Ihre Daten auf Ihrem lokalen Computer speichern.

## Installation

**macOS/Linux**

```
curl -fsSL https://agentsview.io/install.sh | bash
```

**Windows**

```
powershell -ExecutionPolicy ByPass -c "irm https://agentsview.io/install.ps1 | iex"
```

## Ausführung

**Server starten und auf die Schnittstelle zugreifen**

```
agentsview serve
```

**Sehen Sie sich die Zusammenfassung der täglichen Kosten an**

```
agentsview usage daily
```
