# Diagrammbasierte Visualisierung von Cyber-Bedrohungen

Flowsint bietet eine visuelle, flexible und erweiterbare graphbasierte Untersuchungsplattform für Cybersicherheitsanalysten und -forscher. Dieses mit TypeScript entwickelte Tool erleichtert die Visualisierung und Analyse komplexer Datensätze.

## Was es bringt

- Analysieren Sie Beziehungen zwischen Entitäten in einer visuellen Diagrammoberfläche
- Verarbeiten Sie IP-, Domain- und Social-Media-Daten mit automatischen Anreicherern
- Gewährleistung hoher Vertraulichkeit durch Speicherung aller Daten auf dem lokalen Computer

## Installation

**Setup-Befehle**

```
git clone https://github.com/reconurge/flowsint.git
cd flowsint
make prod
```

## Ausführung

**Starten der Entwicklungsumgebung**

```
make dev
```
