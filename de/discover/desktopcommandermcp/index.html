Verwalten Sie Ihren Computer mit künstlicher Intelligenz

DesktopCommanderMCP ist ein für Claude entwickelter Model Context Protocol-Server, der dem Modell der künstlichen Intelligenz Terminalsteuerung, Dateisystemsuche und differenzbasierte Dateibearbeitungsfunktionen bietet. Dieses in TypeScript geschriebene Tool ermöglicht es künstlicher Intelligenz, direkte Operationen auf lokalen Dateisystemen durchzuführen.

Aktualisierungen

  • 2. August 2026: Sterne 6,436 → 9,072, neueste Version v0.2.44 (9. Juli 2026).

Was es bringt

  • Führen Sie Terminalbefehle direkt aus
  • Durchsuchen und bearbeiten Sie das Dateisystem
  • Verwalten Sie Excel-, PDF- und DOCX-Dateien

Installation

schnelle Installation mit Npx
npx @wonderwhy-er/desktop-commander@latest setup
Bash-Skript für macOS
curl -fsSL https://raw.githubusercontent.com/wonderwhy-er/DesktopCommanderMCP/refs/heads/main/install.sh | bash

Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich möchte, dass Sie die Desktop Commander MCP-Tools verwenden, um Dateiverwaltung, Terminalbefehle und Dokumentbearbeitung auf meinem Computer durchzuführen. Bitte helfen Sie mir, indem Sie die Funktionen aktivieren, um das Dateisystem zu durchsuchen, Prozesse über das Terminal zu verwalten und bei Bedarf notwendige Änderungen an Dokumenten wie Excel oder PDF vorzunehmen.
