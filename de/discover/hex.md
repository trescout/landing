# Lokale Diktierfunktion, die Sprache sofort in Text umwandelt

Hex, entwickelt in der Programmiersprache Rust, ist ein lokales Sprache-zu-Text-Diktierwerkzeug, das unter den Betriebssystemen Mac, Windows und Linux läuft. Es ermöglicht Benutzern, durch Gedrückthalten einer Taste zu sprechen und das Gesprochene in Text umzuwandeln.

## Was es bringt

- Wenn Sie die Tastenkombination gedrückt halten und sprechen, wird Ihre Stimme sofort als Text in die geöffnete Anwendung übertragen.
- Lädt das Sprachmodell beim ersten Start auf Ihr Gerät herunter und verhindert, dass Ihre Daten Ihren Computer verlassen.
- Läuft lokal auf Mac-, Windows- und Linux-Systemen.

## So fangen Sie an

Um mit der Nutzung von Hex zu beginnen, können Sie die für Ihr Betriebssystem passende Installationsdatei oder das DMG-Paket aus der offiziellen Download-Tabelle herunterladen. Nachdem Sie die Datei installiert und ausgeführt haben, können Sie durch Gedrückthalten der Tastenkombination anfangen zu sprechen.
