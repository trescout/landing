# Sicherheitsbibliothek zur Verschlüsselung von Netzwerkverkehr

OpenSSL ist eine universelle Sicherheitsbibliothek, die zur Verschlüsselung von Netzwerkverkehr verwendet wird. Es ist ein Open-Source-Softwaretool, das die Protokolle Transport Layer Security (TLS), Datagram TLS (DTLS) und QUIC unterstützt.

## Was es bringt

- unterstützt TLS- und QUIC-Protokolle
- führt Verschlüsselungs- und Signierungsoperationen durch
- bietet Open-Source-Sicherheitstools
