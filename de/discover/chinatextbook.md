# Chinesische Lehrpläne und Lehrbücher

Das ChinaTextbook-Repository bietet ein digitales Archiv von Lehrbüchern, die im chinesischen Lehrplan von der Grundschule bis zur Universität verwendet werden, im tragbaren Dokumentformat (PDF). Diese Ressource bietet einen zentralen Zugangspunkt zu einer breiten Palette akademischer Materialien.

## Was es bringt
- Bietet Zugriff auf ein großes Archiv chinesischer Lehrbücher von der Grundschule bis zur Universität.
- Es erleichtert den Zugang zu kostenlosen Ressourcen, indem es Lehrmaterialien an einer zentralen Stelle sammelt.
- Es bietet spezielle Tool-Unterstützung zum Zusammenführen großer Dateien.

## So fangen Sie an
- Offizielle Quelle →
Sie können Lehrbücher der Primar-, Sekundar-, Oberschul- und Universitätsebene direkt im PDF-Format ansehen oder herunterladen, indem Sie die GitHub-Seite des ChinaTextbook-Repositorys besuchen. Wenn die heruntergeladene Datei in Teile geteilt ist, können Sie das Zusammenführungstool auf Ihren Computer herunterladen, indem Sie auf der Projektseite auf den Link „下载文件合并程序“ klicken und es zusammenführen, indem Sie es im selben Ordner mit den relevanten Dateien ausführen.
