# Künstliche Intelligenz entwickelt sich durch Benutzerinteraktionen

Hermes Agent wurde von NousResearch entwickelt und bietet eine autonome Agenteninfrastruktur, die aus Benutzerinteraktionen lernt und sich im Laufe der Zeit weiterentwickelt. Dieses Python-basierte System nutzt kontinuierliches Lernen, um personalisierte Arbeitsabläufe zu erstellen.

## Was es bringt

- Autonome Fähigkeiten, die sich im Laufe der Zeit weiterentwickeln, indem sie aus Benutzerinteraktionen lernen.
- Möglichkeit, integriert mit Plattformen wie Telegram, Discord und Slack zu arbeiten.
- Möglichkeit, zwischen verschiedenen Modellen der künstlichen Intelligenz zu wechseln, ohne den Code zu ändern.

## Installation

**Installation für Linux, macOS und WSL2**
