# Sprach-KI-Agenten in Echtzeit

LiveKit Agents ist ein Python-Framework, das zur Entwicklung von Audio- und Video-Agenten für künstliche Intelligenz in Echtzeit verwendet wird. Es ermöglicht Entwicklern, Sprachinteraktionen mit geringer Latenz zu erstellen, wodurch es einfacher wird, KI-Systeme zu erstellen, die wie ein Mensch reagieren.

## Was es bringt

- Erzeugt Stimminteraktionen, die menschenähnliche Reaktionen hervorrufen.
- Der WebRTC-Medienserver ist vollständig mit LiveKit kompatibel.
- Unterstützt Telefonanrufe und Multimode-Datenaustausch.

## Installation

**Installieren der Basisbibliothek**

```
pip install "livekit-agents[openai,deepgram,cartesia]"
```

**Fügen Sie Fähigkeiten für den KI-Assistenten hinzu**

```
npx skills add livekit/agent-skills --skill livekit-agents
```
