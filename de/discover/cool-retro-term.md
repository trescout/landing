# Terminal-Erlebnis mit Retro-Bildschirm-Optik

Cool-retro-term ist ein Terminal-Emulator, der das Aussehen alter Kathodenstrahlröhren-Bildschirme imitiert. Diese mit QML entwickelte Software verleiht dem modernen Befehlszeilenerlebnis eine nostalgische visuelle Ästhetik.

## Was es bringt

- Bietet die nostalgische Optik alter Kathodenstrahlröhren-Bildschirme
- Ermöglicht Anpassungen bei Farben, Schriftarten und visuellen Effekten
- Funktioniert als leichter und eleganter Terminal-Emulator auf modernen Betriebssystemen

## So fangen Sie an

Um die aktuellste Version auf Ihrem Linux- oder macOS-Betriebssystem zu nutzen, können Sie die Releases-Seite auf GitHub besuchen und die AppImage- oder dmg-Datei herunterladen. Alternativ können Sie die Installation über die offiziellen Paketquellen vieler Distributionen wie Ubuntu, Fedora oder Arch vornehmen.
