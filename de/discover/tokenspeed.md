# Schnelle Inferenz-Engine für KI-Modelle

lightseekorg/tokenspeed ist eine hochleistungsfähige Inferenz-Engine, die für große Sprachmodelle (LLMs) entwickelt wurde. Das in Python geschriebene Projekt zielt darauf ab, die Inferenzprozesse von KI-Modellen zu beschleunigen.

## Was es bringt

- bietet C++- und Python-basierte Steuerungs- und Ausführungsebenen
- hochleistungsfähig für große Sprachmodelle
- enthält einen Plugin-Mechanismus für Hardware-Beschleuniger
