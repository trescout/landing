# Mehrfaches Management künstlicher Intelligenz im Terminal

Herdr wurde mit der Rust-Sprache entwickelt und fungiert als Agent-Multiplexer, der auf dem Terminal ausgeführt wird. Mit diesem Tool können Benutzer mehrere Agenten für künstliche Intelligenz gleichzeitig in der Terminalumgebung verwalten.

- ★ 9.203
- Rust
- GitHub Trending · 2026-07-01

## Was es bringt

- Verwalten Sie mehrere Agenten der künstlichen Intelligenz gleichzeitig auf einem einzigen Terminal.
- Überwachen Sie den Arbeitsstatus von Agenten sofort mit farbigen Indikatoren.
- Lassen Sie Sitzungen im Hintergrund laufen, auch wenn die Verbindung unterbrochen wird.

## Installation

**Installation für Linux und macOS**

```
curl -fsSL https://herdr.dev/install.sh | sh
```

## Ausführung

**Starten des Tools**

```
herdr
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich möchte alle meine Agenten für künstliche Intelligenz, die auf dem Terminal laufen, von einem einzigen Zentrum aus verwalten und sofort den Arbeitsstatus (wartend, ausgeführt, abgeschlossen) jedes einzelnen von ihnen sehen. Mithilfe von Herdr kann ich diese Agenten so konfigurieren, dass sie in verschiedene Arbeitsbereiche und Registerkarten unterteilt werden, sodass die Prozesse im Hintergrund weiterlaufen, auch wenn ich das Terminal schließe.
