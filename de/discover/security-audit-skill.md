# Automatisierte Sicherheitsüberprüfung mit künstlicher Intelligenz

Das von Cloudflare entwickelte security-audit-skill ist ein Skill-Paket, das es Coding-Agenten ermöglicht, mehrstufige Sicherheitsüberprüfungen durchzuführen. Es automatisiert Sicherheitsstandards in Softwareentwicklungsprozessen, indem es maschinenlesbare und unabhängig verifizierte Ergebnisse generiert.

## Was es bringt

- Führt mehrstufige Sicherheitsscans in der Codebasis durch
- Bestätigt Ergebnisse durch unabhängige Verifizierung
- Erstellt standardisierte Sicherheitsberichte

## Installation

**lokale Installation**

```
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit
```

**Allgemeine Installation**

```
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit \
  --global
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Starte eine umfassende Sicherheitsüberprüfung für diese Codebasis. Erstelle eine Architekturkarte, um Einstiegspunkte zu identifizieren, und führe anschließend einen mehrstufigen Scan durch, um Sicherheitslücken zu erkennen. Unterziehe jeden potenziellen Schwachstellenfund einem unabhängigen Verifizierungsprozess und klassifiziere ihn als verifiziert, zu verifizieren oder abgelehnt. Berichte die Ergebnisse in einem strukturierten Format und dokumentiere alle Funde gemäß den Sicherheitsstandards des Projekts.
