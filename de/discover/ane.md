# KI-Training in Apple Neural Engine

ANE wurde von Maderix entwickelt und ermöglicht die Durchführung eines neuronalen Netzwerktrainings auf der Apple Neural Engine über private Anwendungsprogrammierschnittstellen (private APIs), die durch Reverse Engineering erhalten werden. Diese Studie ermöglicht den direkten Einsatz von Apple-Hardware in Modelltrainingsprozessen für künstliche Intelligenz.

## Was es bringt
- Direktes neuronales Netzwerktraining auf Apple-Hardware
- Umgehen von Hardwareeinschränkungen mit benutzerdefinierten APIs
- Dynamischer Workflow mit geringer Latenz

## So fangen Sie an
Bei diesem Projekt handelt es sich um eine Forschungsstudie, die darauf abzielt, neuronale Netze direkt auf Apple-Hardware zu trainieren. Indem Sie die Projektdateien aus dem offiziellen Repository auf GitHub auf Ihren Computer herunterladen, können Sie untersuchen, wie die durch Reverse Engineering erhaltenen speziellen APIs verwendet werden, und Ihre eigenen Experimente durchführen.
