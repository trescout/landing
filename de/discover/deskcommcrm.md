# Open-Source-KI-CRM für WhatsApp

DeskcommCRM ist eine Open-Source-Plattform für das Kundenbeziehungsmanagement (CRM), die für Unternehmen entwickelt wurde, die ihre Verkäufe über Chats abwickeln. Mit WhatsApp-Integration und integrierten KI-Agenten bietet es eine selbst gehostete Alternative zu kommerzieller Software mit ähnlichen Funktionen (Kommo, Octadesk, Intercom).

## Was es bringt

- Ermöglicht automatisierten Verkauf und Kundenmanagement über WhatsApp.
- Bietet volle Kontrolle über Ihre Daten durch Selbsthosting auf Ihrem eigenen Server.
- Ermöglicht den Zugriff auf alle Funktionen ohne monatliche Gebühren.

## Installation

**Server-Installation starten**

```
curl -fsSL https://raw.githubusercontent.com/melgarafael/DeskcommCRM/main/hostgator-setup-kit/comecar.sh | bash
```

**Installation auf VPS abschließen**

```
git clone https://github.com/melgarafael/DeskcommCRM.git
cd DeskcommCRM
bash hostgator-setup-kit/install.sh
```
