# Schwanzkatze

Tailcat wurde von Tailscale entwickelt und ist eine Version von Netcat, einem Befehlszeilentool zur sicheren Übertragung von Netzwerkverkehr, das auf der Netzwerkebene von Tailscale ausgeführt wird. Es ermöglicht eine direkte Datenübertragung zwischen Geräten, ohne dass eine Steuerungsebene erforderlich ist.
