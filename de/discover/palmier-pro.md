# KI-Videoeditor für macOS

Palmier Pro wurde als Videoeditor entwickelt, der auf dem Betriebssystem macOS läuft und durch künstliche Intelligenz unterstützte Bearbeitungswerkzeuge bietet. Diese in Swift-Sprache geschriebene Anwendung zielt darauf ab, auf künstlicher Intelligenz basierende Arbeitsabläufe mit lokaler Systemleistung zu kombinieren.

## Was es bringt
- Video- und visuelle Produktion mit künstlicher Intelligenz auf der Timeline
- Integration mit Claude, Codex und Cursor über MCP
- Native Swift-Leistung für Apple Silicon-Geräte

## So fangen Sie an
- Offizielle Quelle →
Laden Sie die Palmier Pro-App über den Download-Link auf der offiziellen GitHub-Seite herunter und installieren Sie sie auf Ihrem macOS-Gerät. Nachdem Sie die Anwendung ausgeführt haben, können Sie sich über das Hilfemenü in der Anwendung anmelden, um Tools für künstliche Intelligenz zu verwenden oder MCP-Integrationen zu konfigurieren.
