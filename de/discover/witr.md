# Entdecken Sie den Ursprung von Systemprozessen

Witr ist ein Befehlszeilentool, das Prozesse, Ports, Container oder Dateien im System überwacht und ermittelt, von welcher Quelle sie gestartet wurden. Diese Software, mit der Benutzer Aktivitäten auf dem System verfolgen können, bietet sowohl Unterstützung für die Befehlszeile (CLI) als auch für die textbasierte Benutzeroberfläche (TUI).

## Was es bringt
- Zeigt Schritt für Schritt, warum Prozesse funktionieren
- Überwacht die Container- und Hafenaktivitäten im Detail
- Erleichtert die Systemüberwachung durch eine interaktive Schnittstelle

## Installation
**Schnelle Installation für Unix-Systeme**

```
curl -fsSL https://raw.githubusercontent.com/pranshuparmar/witr/main/install.sh | bash
```

**Installation mit dem Homebrew-Paketmanager**

```
brew install witr
```


## Wenn Sie nicht programmieren
Ich möchte verstehen, von welcher Quelle ein in meinem System laufender Prozess, Port oder Container gestartet wurde und welche Ausführungskette er auf dem System hat. Wie kann ich mit dem Tool witr diesen Prozess überwachen und erkennen, warum er ausgeführt wird?
