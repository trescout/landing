Videos ohne Werbung und Tracking ansehen

Invidious ist eine Open-Source-Schnittstelle, die als Alternative zur YouTube-Plattform entwickelt wurde. Es bietet Benutzern ein Videoerlebnis, das keine Werbung enthält und keine Daten erfasst.

Was es bringt

  • Sehen Sie sich YouTube-Videos ohne Werbung und Datenverfolgung an
  • Abonnieren Sie Kanäle, ohne ein Google-Konto zu benötigen
  • Spielen Sie die Audiowiedergabe im Hintergrund mit geringem Datenverbrauch ab

Installation

Holen Sie sich das Repository und erstellen Sie die Datei
git clone --depth 1 https://github.com/iv-org/invidious.git && cd invidious

Ausführung

beginnen
docker compose up -d
