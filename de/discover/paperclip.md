# Managementzentrum für KI-Agenten

Paperclip ist eine Open-Source-Plattform, mit der Sie KI-Agenten am Arbeitsplatz über eine einzige Schnittstelle verwalten können. Dieses mit TypeScript entwickelte Tool ermöglicht es Ihnen, die Arbeitsabläufe von Agenten, die für verschiedene Aufgaben eingesetzt werden, von einem zentralen Punkt aus zu steuern.

## Was es bringt

- Verwalten Sie mehrere KI-Agenten über eine einzige Schnittstelle.
- Steuern Sie das Budget und die Aufgaben der Agenten zentral.
- Machen Sie Arbeitsabläufe wie einen Task-Manager nachverfolgbar.

## Installation

**Schnelle Installation**

```
curl -fsSL https://paperclip.ing/install.sh | bash -s -- --no-prompt --no-onboard
paperclipai onboard --yes
```

**Entwicklerinstallation**

```
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev
```

## Wenn Sie nicht programmieren

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Als KI-Manager definiere ich die Teilaufgaben, die zum Erreichen des von mir gesetzten Hauptgeschäftsziels notwendig sind, weise diese Aufgaben den entsprechenden Agenten zu, lege Budgetgrenzen fest und kontrolliere den Prozessfortschritt durch regelmäßige Berichte über die geleistete Arbeit.

Repository: https://github.com/paperclipai/paperclip. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.
