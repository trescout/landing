# Spirula Studio

Spirula Studio ist ein plattformübergreifendes Trainingstool, das Videos in dreidimensionale Szenendarstellungen (3D Gaussian Splatting) und diese wiederum in Polygone-Netze (Mesh) umwandelt. Die Software nutzt Vulkan- oder CUDA-Grafikschnittstellen und bietet so eine kompatible Arbeitsumgebung für verschiedene Hardwarehersteller.
