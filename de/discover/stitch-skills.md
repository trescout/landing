# Designfunktionen für KI-Agenten

Stitch Skills wurde von Google Labs entwickelt und ist eine Agentenkompetenzbibliothek, die für die Zusammenarbeit mit dem Stitch MCP-Server entwickelt wurde. Diese Bibliothek folgt offenen Standards und zielt darauf ab, Arbeitsabläufe für Codierungsagenten wie Gemini CLI und Cursor zu standardisieren.

## Was es bringt
- Standardisierter Workflow zwischen Code und Design
- Automatische Generierung von React- und React-Native-Komponenten
- Extrahieren und verwalten Sie Designsysteme aus Code

## Installation
**Installation für Claude Code**

```
npx plugins add google-labs-code/stitch-skills --scope project --target claude-code
```

**Setup für Cursor**

```
npx plugins add google-labs-code/stitch-skills --scope workspace --target cursor
```


## Ausführung
**Hilfebefehle anzeigen**

```
npx plugins --help

npx skills --help
```


## Wenn Sie nicht programmieren
Analysieren Sie meinen vorhandenen Schnittstellencode mithilfe der Stitch Skills-Bibliothek und importieren Sie ihn in ein Stitch-Projekt. Erstellen Sie dann React-Komponenten mit diesem Designsystem und überprüfen Sie, ob das Projekt den Designstandards entspricht.
