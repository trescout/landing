# Konvertieren Sie HTML-Codes in Videos

Hyperframes wurde von Heygen entwickelt und bietet ein Framework, das HTML-Codes direkt in Videos umwandelt. Dieses Tool wurde entwickelt, um Agenten der künstlichen Intelligenz die Erstellung visueller Inhalte zu erleichtern, und konvertiert webbasierte Schnittstellen in ein Videoformat.

- ★ 44.046
- TypeScript
- GitHub Trending · 2026-06-23

## Was es bringt
- Videoproduktion mit HTML und CSS
- Kompatibel mit Agenten der künstlichen Intelligenz
- Bringen Sie Ihr eigenes Designsystem ins Video

## Installation
**Einrichtung für KI-Agent**

```
npx skills add heygen-com/hyperframes
```

**Manuelle CLI-Installation**

```
npx hyperframes init my-video
cd my-video
npx hyperframes preview      # preview in browser with live reload
npx hyperframes render       # render to MP4
```


## Ausführung
**Vorschau und Rendern**
