## Was es bringt

- Zeigt Twitter-Inhalte an, ohne JavaScript auszuführen
- Versteckt die IP-Adresse des Benutzers und den Fingerabdruck des Browsers
- Es ist viel schneller und einfacher als die Standard-Twitter-Oberfläche

## Installation

**Installation mit Docker**

```
docker run -v $(pwd)/nitter.conf:/src/nitter.conf -d --network host zedeus/nitter:latest
```

**Starten mit Docker Compose**

```
docker-compose up -d
```
