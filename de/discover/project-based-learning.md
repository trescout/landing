# Leitfaden zur Softwareentwicklung mit angewandten Projekten

Projektbasiertes Lernen ist eine Liste, die Ressourcen zusammenfasst, die Softwareentwicklungsprozesse durch angewandte Projekte vermitteln. Es bietet einen umfassenden Leitfaden für diejenigen, die reale Anwendungen mit verschiedenen Programmiersprachen entwickeln möchten.

## Was es bringt
- Es bietet projektorientierte Lernressourcen für verschiedene Programmiersprachen.
- Es lehrt Schritt für Schritt Anwendungsentwicklungsprozesse von Grund auf.
- Zeigt, wie man komplexe Systeme wie Betriebssysteme und Datenbanken einrichtet.

## So fangen Sie an
- Offizielle Quelle →
Da es sich um eine Softwareliste handelt, ist keine Installation erforderlich. Sie können die Programmiersprache, die Sie interessiert, aus der Liste auswählen, auf die untenstehenden Links klicken und mit der Untersuchung der Projekte beginnen.
