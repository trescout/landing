# Visualisieren Sie Ihre Softwarearchitektur mit Live-Diagrammen

Likec4 ist ein Tool, das Softwarearchitektur direkt aus dem Quellcode visualisiert und die Erstellung von Live-Diagrammen ermöglicht. Ziel ist die Kontinuität der technischen Dokumentation durch Architekturdiagramme, die gleichzeitig mit der Codebasis aktualisiert werden.

- ★ 5.618
- TypeScript
- GitHub Trending · 2026-07-23

## Was es bringt
- Es erstellt Architekturschemata, die gleichzeitig mit Ihrer Codebasis aktualisiert werden.
- Es bietet eine flexible und anpassbare Modellierungssprache basierend auf dem C4-Modell.
- Es stellt die Kontinuität der Dokumentation sicher, indem es Visualisierungsprozesse über Code verwaltet.

## Ausführung
**Starten Sie das Projekt im Vorschaumodus**

```
npx likec4 start
```
