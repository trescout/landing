# KI-freundliche, schnelle Benutzeroberflächen

Solid ist eine deklarative JavaScript-Bibliothek zum Erstellen von Benutzeroberflächen. Anstatt ein Virtual Document Object Model (Virtual DOM) zu verwenden, kompiliert sie Templates direkt in echte Document Object Model (DOM)-Knoten und führt Aktualisierungen mit feingranularer Reaktivität (fine-grained reactivity) durch.

## Was es bringt

- Die Benutzeroberflächen-Verwaltungsstruktur gewinnt an Geschwindigkeit, indem sie statt eines Virtual DOM direkt echte Browser-Knoten aktualisiert.
- Minimiert die Last auf der CPU, indem Komponenten nur einmal ausgeführt werden.
- Aktualisiert dank ihrer Struktur zur automatischen Verfolgung von Datenänderungen nur die betroffenen kleinen Teile.

## Installation

**Neues Projekt mit einer vorgefertigten Vorlage erstellen**

```
npx degit solidjs/templates/solid-v2/basic my-app
cd my-app
npm install
npm run dev
```

## Ausführung

**In das Entwicklungstool-Vite-Projekt einbinden**

```
npm i solid-js @solidjs/web
npm i -D vite @solidjs/vite-plugin
```
