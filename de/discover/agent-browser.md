# Browser-Automatisierungstool für KI-Agenten

Das von Vercel Labs entwickelte agent-browser ist eine Befehlszeilenschnittstelle (CLI), die Browser-Automatisierung für KI-Agenten bereitstellt. Das in Rust geschriebene Tool liest Seiten als Barrierefreiheitsbaum (Accessibility Tree) und ermöglicht die Interaktion mit Web-Elementen über die Befehlszeile.

## Was es bringt

- Liest Seiten als Text im Format eines Barrierefreiheitsbaums
- Interagiert mit Web-Elementen über die Befehlszeile
- Steuert den Browser Befehl für Befehl über einen Hintergrundserver

## Installation

**Allgemeine Einrichtung**

```
npm install -g agent-browser
agent-browser install           # download Chrome for Testing (first time only)
```

## Ausführung

**Schnellstart**

```
agent-browser open example.com
```
