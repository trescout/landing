# Greifen Sie mit künstlicher Intelligenz auf aktuelle Daten zu

OpenAI-Plugins ermöglichen Sprachmodellen den Zugriff auf aktuelle Daten und die Interaktion mit Drittanwendungen. Diese Struktur ermöglicht es künstlicher Intelligenz, komplexe Aufgaben mithilfe externer Tools auszuführen.

## Was es bringt
- Es ermöglicht Sprachmodellen den Zugriff auf aktuelle Daten.
- Ermöglicht die Interaktion mit Anwendungen von Drittanbietern.
- Es ermöglicht künstlicher Intelligenz, mithilfe externer Tools komplexe Aufgaben zu erledigen.

## So fangen Sie an
Bei diesem Tool handelt es sich um ein Repository, das eine Beispielsammlung von OpenAI-Plugins bereitstellt. Um mit der Verwendung zu beginnen, können Sie das entsprechende Plugins-Repository auf GitHub besuchen und verschiedene Beispiele wie Figma, Notion oder Webanwendungen im Verzeichnis „Plugins“ untersuchen, um zu sehen, wie sie für Ihre eigenen Projekte konfiguriert sind.
