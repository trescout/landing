# Open-Source-Spieleentwicklungs-Engine

Godot Engine (Godot Engine) ist eine Open-Source-Game-Engine, die für zwei- und dreidimensionale Spieleentwicklungsprozesse verwendet wird. Diese in der Sprache C++ entwickelte Plattform ermöglicht es Entwicklern, Spiele zu erstellen, die auf verschiedenen Betriebssystemen ausgeführt werden können.

- ★ 115.850
- GitHub Trending · 2026-06-02

## Was es bringt
- Bietet umfassende Tools für zwei- und dreidimensionale Spiele
- Ermöglicht die Ausgabe von Spielen auf verschiedenen Plattformen mit einem Klick
- Es ist völlig kostenlos und wird von der Community verwaltet.

## Installation
**macOS (Homebrew)**

```
brew install --cask godot
```

**Windows (winget)**

```
winget install GodotEngine.GodotEngine
```
