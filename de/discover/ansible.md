## Was macht dieses Werkzeug?
Ansible ist ein agentloses Tool, das Systemkonfiguration, Softwarebereitstellung und IT-Automatisierung über einfache, lesbare YAML-Dateien durchführt. Es ermöglicht Ihnen, Ihre Infrastruktur als Code zu verwalten und komplexe Aufgaben zu standardisieren.

## Für wen ist es?
Für diejenigen, die mehrere Server gleichzeitig konfigurieren und Verwaltungsprozesse zuverlässig automatisieren möchten.

## Was Sie nicht erwarten sollten
Für diejenigen, die nur einfache Aufgaben auf einer einzigen lokalen Maschine ausführen möchten und keine Automatisierungsinfrastruktur benötigen.

## Höhepunkte
- Erfordert keine Installation von Agenten auf den Zielservern.
- Speichert Konfigurationen im einfach zu lesenden und zu schreibenden YAML-Format.
- Bietet eine breite Integrationsunterstützung mit Tausenden von fertigen Modulen.

## Ablauf für die erste Nutzung
- Installieren Sie das Ansible-Paket auf Ihrem Kontrollknoten.
- Fügen Sie die IP-Adressen der zu verwaltenden Server zur Konfigurationsdatei (Inventory) hinzu.
- Richten Sie eine schlüsselbasierte Authentifizierung ein, um den SSH-Zugriff auf die Zielserver zu gewährleisten.
- Führen Sie einen Ping-Test auf allen Servern durch, um die Verbindung zu überprüfen.

## Installation
**Mit pip (PyPI)**

```
pip install ansible
```

**macOS (Homebrew)**

```
brew install ansible
```


## Ausführung
**Führen Sie das Ansible-Playbook-Skript aus**

```
ansible-playbook site.yml
```
