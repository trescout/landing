# Plattform, die Modelle der künstlichen Intelligenz beschleunigt

ONNX Runtime ist ein plattformübergreifender Hochleistungsbeschleuniger für Inferenz und Training beim maschinellen Lernen.

- C++
- GitHub Trending · 2026-08-22

## Was es bringt
- Erhöht die Ausführungsgeschwindigkeit von Modellen für maschinelles Lernen
- Funktioniert kompatibel mit verschiedenen Hardware- und Betriebssystemen
- Unterstützt beliebte Bibliotheken wie PyTorch und TensorFlow
