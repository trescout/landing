# Schnittstellenframework, das zur Kompilierungszeit ausgeführt wird

Im Gegensatz zu herkömmlichen Frameworks verwendet Svelte einen Ansatz zur Kompilierungszeit, der den Laufzeitaufwand für den Browser reduziert. Diese JavaScript-Bibliothek vereinfacht Webentwicklungsprozesse, indem sie Anwendungscode in kleine und schnell laufende reine JavaScript-Module umwandelt.

- ★ 87.981
- GitHub Trending · 2026-06-07

## Was es bringt
- Reduziert die Laufzeitbelastung des Browsers
- Konvertiert Codes in schnell laufende JavaScript-Module
- Aktualisiert die DOM-Struktur chirurgisch, um Webseiten auf dem neuesten Stand zu halten

## Installation
**Neues Projekt (offizielle CLI)**

```
npx sv create
```
