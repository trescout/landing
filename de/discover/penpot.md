# Plattform, die Design und Software vereint

Penpot ist ein Open-Source-Designtool, das die Zusammenarbeit zwischen Designern und Entwicklern stärkt. Dank seiner vektorbasierten Schnittstelle ermöglicht es Ihnen, Designprozesse integriert mit der Codierungsphase zu verwalten.

- GitHub Trending · 2026-06-18

## Was es bringt
- Integriert Designprozesse mit Code
- Bietet offene Standards und Design-Tokens
- Bietet Teamzusammenarbeit in Echtzeit

## Installation
**Laden Sie die offizielle Compose-Datei herunter**

```
curl -o docker-compose.yaml https://raw.githubusercontent.com/penpot/penpot/main/docker/images/docker-compose.yaml
```


## Ausführung
**Start (http://localhost:9001)**

```
docker compose -p penpot -f docker-compose.yaml up -d
```
