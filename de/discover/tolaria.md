# Markdown-Wissensdatenbank-Desktopanwendung

Tolaria ist eine Desktop-Anwendung, die für die Verwaltung von Markdown-basierten Wissensdatenbanken entwickelt wurde. Dieses in TypeScript geschriebene Tool erleichtert die Organisation persönlicher Dokumentationen und Notizsysteme.

- ★ 19.513
- TypeScript
- GitHub Trending · 2026-06-08

## Was es bringt
- Bietet tragbare Notizverwaltung mit Markdown-Dateien.
- Bietet vollständige Versionskontrolle mit Git-Integration.
- Schützt den Dateneigentum durch Offline-Arbeitsunterstützung.

## Installation
**Abhängigkeiten für Arch/Manjaro**

```
sudo pacman -S --needed webkit2gtk-4.1 base-devel curl wget file openssl \
    appmenu-gtk-module libappindicator-gtk3 librsvg
```

**Abhängigkeiten für Debian/Ubuntu**

```
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
    libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev \
    libsoup-3.0-dev patchelf
```


## Ausführung
**Starten der Entwicklungsumgebung**

```
pnpm install
pnpm dev
```

**Führen Sie die Desktop-App aus**

```
pnpm tauri dev
```
