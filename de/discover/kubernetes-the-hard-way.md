# Kubernetes the Hard Way

Kubernetes the Hard Way, erstellt von Kelsey Hightower, ist ein Leitfaden, der beibringt, wie man die Container-Management-Plattform Kubernetes von Grund auf ohne Automatisierungsskripte einrichtet. Diese Arbeit bietet eine technische Bildungsressource für Benutzer, die die Kernkomponenten und Funktionsprinzipien des Systems durch manuelle Konfigurationsprozesse verstehen möchten.
