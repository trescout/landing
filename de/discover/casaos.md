# Verwalten Sie Ihren persönlichen Cloud-Server

CasaOS bietet ein persönliches Open-Source-Cloud-System, das die Verwaltung von Docker-basierten Anwendungen vereinfacht. Diese mit der Go-Sprache entwickelte Schnittstelle ermöglicht es Benutzern, ihre Server einfach über ein visuelles Panel zu verwalten.

- ★ 36.953
- Go
- GitHub Trending · 2026-06-26

## Was es bringt
- Installieren Sie Docker-Anwendungen mit einem Klick
- Verwalten Sie Dateien mit einer visuellen Oberfläche
- Überwachen Sie Serverressourcen mit dem Widget

## Installation
**Installationsbefehl**

```
curl -fsSL https://get.casaos.io | sudo bash
```


## Ausführung
**Update-Befehl**

```
curl -fsSL https://get.casaos.io/update | sudo bash
```
