# Code mit Vim im Terminal überprüfen

tuicr wurde mit der Rust-Sprache entwickelt und ist ein auf der Terminal-Benutzeroberfläche basierendes Codeüberprüfungstool, das Vim-Tastaturkürzel unterstützt. Es ermöglicht Entwicklern, ihren Codeüberprüfungsprozess direkt vom Terminal aus zu verwalten.

## Was es bringt

- Schnelle Codeüberprüfung im Terminal mit Vim-Verknüpfungen
- Veröffentlichen Sie Kommentare direkt auf GitHub und GitLab
- Strukturierte Ausgabeunterstützung für KI-Tools

## Installation

**Standardinstallation**

```
curl -fsSL tuicr.dev/install.sh | sh
# or
brew install agavra/tap/tuicr
```

**Alternative Paketmanager**

```
# Cargo
cargo install tuicr

# Mise
mise use github:agavra/tuicr

# Nix
nix run github:agavra/tuicr
```

## Ausführung

**Überprüfen Sie lokale Änderungen**

```
tuicr -w
```

**Überprüfen Sie eine bestimmte PR**

```
tuicr pr 125
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Sehen Sie sich diese Codeüberprüfung an und erstellen Sie eine strukturierte Liste aller gefundenen Fehler oder Verbesserungsvorschläge, wobei jeder Kommentar durch Dateipfad und Zeilennummer gekennzeichnet ist. Machen Sie bei der Überprüfung konkrete Vorschläge, die die Lesbarkeit und Leistung des Codes verbessern, basierend auf den Daten im Markdown-Format, die ich von tuicr kopiert habe.
