# KI-gestützte Codierung im Terminal

Claude Code; Es handelt sich um ein agentenbasiertes Codierungstool, das in Ihrem Terminal läuft und über ein tiefes Verständnis Ihrer Codebasis verfügt. Es beschleunigt Ihren Entwicklungsprozess, indem es Dateien liest, Änderungen vornimmt und Tests mit Befehlen in natürlicher Sprache durchführt. (Sie können damit viele der Tools auf dieser Seite verwenden.)

## Was es bringt
- Es versteht Ihre Codebasis und führt Vorgänge zwischen Dateien aus.
- Sagen Sie einfach „Hinzufügen oder korrigieren“ in natürlicher Sprache.
- Dabei werden viele Skills und Plugins aus diesem Katalog verwendet.

## Installation
**npm: global installieren**

```
npm install -g @anthropic-ai/claude-code
```


## Ausführung
**Claude Code im Terminal starten**

```
claude
```


## Wie installiere ich, wie verwende ich?
Ich habe in mein Terminal „curl -fsSL https://claude.ai/install.sh |“ eingegeben Installieren Sie Anthropics offizielles Claude Code-Tool mit dem Befehl „bash“, gehen Sie dann zu meinem Projektordner und geben Sie „claude“ ein, um es zu starten und mir beim Schreiben von Code zu helfen.
