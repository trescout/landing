## Was macht es?

- Forschung reproduzierbar machen.
- Bereitstellung einer Standard-Bewertungsumgebung.
- Kein Endbenutzer-Tool, sondern eine direkte Lösung für die Forschung.

## Wie installiere ich, wie verwende ich?

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Installieren Sie Stable-Worldmodel in meiner Python-Umgebung mit dem Befehl „pip install Stable-Worldmodel[all]“ und helfen Sie mir bei der Vorbereitung eines kleinen Skripts, das Daten in einer Beispiel-PushT-Umgebung sammelt und ein Weltmodell trainiert und auswertet.

**Von PyPI installieren (alle Plugins)**

```
pip install 'stable-worldmodel[all]'
```

**Zwischengespeicherte Datensätze auflisten**

```
swm datasets
```
