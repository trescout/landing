# Moderne Windows-Befehlszeilenerfahrung

Microsoft vereint Windows Terminal und den traditionellen Windows-Konsolenhost unter einem Dach. Dieses in der Sprache C++ entwickelte Open-Source-Projekt strukturiert die Befehlszeilenerfahrung mit einer modernen Benutzeroberfläche und anpassbaren Registerkarten neu.

## Aktualisieren
- 2. August 2026: Star 104.241 → 104.442, neueste Version v1.24.11911.0 (16. Juli 2026).

## Was es bringt
- Moderne und anpassbare Benutzeroberfläche
- Unterstützung mehrerer Registerkarten
- Verbesserte Befehlszeilenleistung

## Installation
**Windows (Winget)**

```
winget install Microsoft.WindowsTerminal
```


## Ausführung
**Von der Befehlszeile ausführen**

```
wt
```


## So fangen Sie an
