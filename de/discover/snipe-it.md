# Enterprise Asset- und Lizenzmanagement

Snipe-IT ist ein Open-Source-Managementsystem zur Verfolgung von IT-Assets und Softwarelizenzen. Diese mit der PHP-Sprache entwickelte Plattform ermöglicht es Institutionen, Bestandsaufzeichnungen und Nutzungszyklen in einer digitalen Umgebung zu organisieren.

## Was es bringt
- Überwachung des Lebenszyklus von IT-Assets
- Softwarelizenzen zentral verfolgen
- Digitalisierung von Hardware-Lastschriften

## Installation
**Nehmen Sie das offizielle Bild**

```
docker pull grokability/snipe-it
```


## Ausführung
**beginnen**

```
docker compose up -d
```
