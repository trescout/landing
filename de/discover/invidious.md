## Was macht dieses Werkzeug?

Invidious bietet eine alternative Oberfläche für YouTube und verwendet nicht die offiziellen YouTube-APIs. Sie können eine öffentliche Instanz auswählen oder anhand der Installationsdokumentation eine eigene Instanz betreiben. Das Projekt steht unter der AGPL-3.0-Lizenz und stellt eine dokumentierte Entwickler-API bereit.

## Für wen ist es?

Menschen, die eine alternative YouTube-Oberfläche, von Google unabhängige Abonnements oder eine selbst betriebene Instanz möchten.

## Was Sie nicht erwarten sollten

Menschen, die ausdrücklich eine Lösung auf Basis der offiziellen YouTube-APIs benötigen.

## Höhepunkte

- Nennt die Nutzung ohne Werbung oder Tracking und ohne JavaScript-Pflicht.
- Unterstützt von Google unabhängige Abonnements.
- Bietet Optionen für den Import und Export von Daten.
- Enthält eine dokumentierte Entwickler-API.

## Ablauf für die erste Nutzung

1. Wählen Sie eine öffentliche Invidious-Instanz, wenn Sie den Dienst nur nutzen möchten.
2. Wenn Sie den Dienst selbst betreiben möchten, lesen Sie zuerst die offizielle Installationsdokumentation.
3. Bereiten Sie für den aktuellen Docker-Weg PostgreSQL und Invidious Companion vor.
4. Planen Sie für eine eigene Installation mindestens 20 GB Speicherplatz und 2 GB freien RAM ein.

## Sicherer Start

Nutzen Sie das Projekt im Einklang mit den geltenden Vorschriften. Der offizielle Haftungstext erklärt, dass das Projekt für unangemessene Nutzung wie illegale Downloads nicht verantwortlich ist.
