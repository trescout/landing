YAML-Management für C++-Projekte

yaml-cpp ist eine Bibliothek für die Programmiersprache C++, die Daten im YAML-Format analysiert und ausgibt. Es ermöglicht Softwareentwicklern, Konfigurationsdateien zu verwalten und Datenserialisierungsvorgänge durchzuführen.

Aktualisierungen

  • 2. August 2026: Sterne 6,101 → 6,113, neueste Version yaml-cpp-0.9.0 (4. Februar 2026).

Was es bringt

  • Vollständige Einhaltung der YAML 1.2-Standards
  • Unterstützung für das Parsen und Rendern von Daten
  • Plattformübergreifende Kompilierung mit CMake

Installation

macOS (Homebrew)
brew install yaml-cpp
