# Disziplinieren Sie Ihren KI-Codierungsassistenten

Basierend auf den Beobachtungen von Andrej Karpathy, die bei der Kodifizierung mit großen Sprachmodellen (LLM) Fehler gefunden haben, hat CLAUDE.md die Möglichkeit, Claude Code zu lesen, um eine durch künstliche Intelligenz unterstützte Kodifizierungsstufe zu erreichen. Diese Konfigurationsdatei dient als Leitfaden für die beteiligten Personen, die mehr Informationen über den Code erhalten, als auch über Fehler in der künstlichen Intelligenz.

- ★ 205.391
- GitHub Trending · 2026-08-23

## Was es bringt
- Verhindert, dass KI falsche Annahmen trifft
- Verhindert unnötige Komplexität des Codes
- Bietet nur gezielte, saubere Änderungen

## Installation
**Zu neuem Projekt hinzufügen**

```
curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md
```


## Wenn Sie nicht programmieren
Wenden Sie von nun an beim Codieren die vier von Andrej Karpathy vorgeschlagenen Grundprinzipien an: Denken Sie vor dem Codieren nach, erläutern Sie Ihre Annahmen und fragen Sie nach Unsicherheiten, vermeiden Sie unnötige Komplexität, indem Sie immer die einfachste Lösung wählen, nehmen Sie Änderungen nur an den angeforderten Teilen vor und fahren Sie fort, indem Sie überprüfbare Erfolgskriterien festlegen, anstatt zu sagen, dass der Job ausgeführt werden soll.
