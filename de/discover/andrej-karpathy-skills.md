## Was macht dieses Werkzeug?

Andrej Karpathy Skills ist weder ein eigenständiges Modell noch eine Coding-Agent-Runtime. Es stellt eine CLAUDE.md und Plugin-artige Richtlinien bereit, um vorhandene Coding-Agenten zu steuern. Die vier Grundsätze sind: vor dem Programmieren denken, Einfachheit zuerst, chirurgische Änderungen und zielorientierte Ausführung.

## Für wen ist es?

Entwickler, die Claude Code oder Cursor verwenden und Coding-Agenten zusätzliche Richtlinien auf Projekt- oder Werkzeugebene geben möchten.

## Was Sie nicht erwarten sollten

Menschen, die ein eigenständiges LLM, einen Code-Editor, eine Coding-Agent-Runtime oder eine fertige Anwendung suchen.

## Höhepunkte

- Verwendet eine CLAUDE.md und einen Plugin-Ansatz zur Steuerung von Coding-Agenten.
- Definiert vier Grundsätze für bewusstes und überprüfbares Arbeiten.
- Enthält Einrichtungsoptionen für Claude Code und Cursor.
- Die README nennt die MIT-Lizenz.

## Ablauf für die erste Nutzung

1. Lesen Sie die Repository-README und wählen Sie die Option für Ihr Werkzeug: Claude-Code-Plugin, projektbezogene CLAUDE.md oder Cursor-Regel.
2. Für die Verwendung auf Projektebene fügen Sie die Richtlinien wie im Repository beschrieben in die CLAUDE.md Ihres Projekts ein.
3. Prüfen Sie die Richtlinien vor der Nutzung anhand der Anforderungen Ihres Projekts.

## Sicherer Start

Dieses Paket gibt Agenten Richtlinien; generierten Code, Änderungsumfang und Testergebnisse müssen Sie weiterhin selbst prüfen.

## Erster Prompt

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Nennen Sie zuerst den Plan, Unsicherheiten und betroffene Dateien für diese Aufgabe. Schlagen Sie danach den einfachsten Ansatz vor und nehmen Sie nur die für das Ziel erforderlichen Änderungen vor.
