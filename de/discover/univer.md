# Open-Source-Office-Suite

Univer ist eine Open-Source-Plattform, die Office-Werkzeuge wie Tabellenkalkulationen, Dokumente und Präsentationen in einer einzigen Laufzeitumgebung (Runtime) vereint. Sie bietet eine modulare Struktur, die entwickelt wurde, um die Interaktion von KI-Agenten (AI Agents) mit Office-Software zu erleichtern.

## Was es bringt

- Integrieren Sie Tabellenkalkulations-, Dokumenten- und Präsentationserlebnisse in Ihre eigene Anwendung.
- Führen Sie Datenverarbeitungsvorgänge im Browser oder auf der Server-Seite mit derselben Architektur aus.
- Kombinieren Sie mit einer modularen Plugin-Architektur nur die Funktionen, die Sie benötigen.

## Installation

**Repository klonen und Entwicklungsumgebung e**

```
git clone https://github.com/dream-num/univer.git
cd univer
pnpm install
pnpm dev
```
