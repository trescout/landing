# Verfolgen Sie die Börsendaten kostenlos

OpenStock ist eine Open-Source-Alternative zu teuren Börsenplattformen. Es bietet Preisverfolgung in Echtzeit, personalisierte Benachrichtigungen und Unternehmensanalysen. Es ist für jedermann zugänglich und für immer kostenlos.

- ★ 14.018
- TypeScript
- AGPL-3.0
- GitHub Trending · 26 May 2026

## Was es bringt
- Es verfolgt Echtzeitpreise.
- Sendet personalisierte Benachrichtigungen.
- Es bietet detaillierte Analysen für Unternehmen.
- Es macht teure Plattformen überflüssig.

## Wie benutzt man?
Sie können die vorgefertigte Seite (openstock-ods.vercel.app) direkt nutzen oder auf Ihrem eigenen Server installieren.

## Wie installiere ich, wie verwende ich?
**Klon-Repository**

```
git clone https://github.com/Open-Dev-Society/OpenStock.git
cd OpenStock
```

**Abhängigkeiten installieren**

```
pnpm install
```

**Starten Sie den Entwicklungsserver**

```
pnpm dev
```
