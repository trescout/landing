# Künstliche Intelligenz-Agenten für Anlagestrategien

Der KI-Hedgefonds nutzt autonome Agenten, um Finanzmarktanalyse- und Vermögensverwaltungsprozesse zu automatisieren. Dieses Python-basierte Projekt bietet ein Teammodell für künstliche Intelligenz, das Anlagestrategien durch die Verarbeitung von Marktdaten entwickelt.

- ★ 62.721
- Python
- GitHub Trending · 2026-07-13

## Was es bringt
- Autonome Agenten analysieren Finanzmarktdaten
- Modellierung verschiedener Investmentschulen
- Möglichkeit, Strategien mit historischen Daten zu testen

## Installation
**Klonen des Repositorys**

```
git clone https://github.com/virattt/ai-hedge-fund.git
cd ai-hedge-fund
```

**Abhängigkeiten installieren**

```
poetry install
```


## Ausführung
**Starten Sie die Investitionsanalyse**

```
poetry run python src/main.py --ticker AAPL,MSFT,NVDA
```


## Wenn Sie nicht programmieren
Dieses Tool verwendet autonome Agenten, die die Strategien berühmter Investoren wie Warren Buffett, Peter Lynch und Michael Burry nachahmen, um Finanzmärkte zu analysieren. Indem Sie KI-Agenten bestimmte Aktiensymbole (z. B. AAPL, MSFT) zuweisen, können Sie untersuchen, wie diese Agenten Marktdaten, Fundamentalindikatoren und technische Analysen auswerten und Entscheidungen mit der Logik eines Investmentfonds treffen.
