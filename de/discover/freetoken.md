# Große KI-Modelle auf dem Personal Computer

FlashML-org/FreeToken ist eine Bibliothek, mit der sich große KI-Modelle im Rechenzentrumsmaßstab schnell und effizient auf Personal Computern ausführen lassen. Sie ermöglicht es Benutzern, Mixture-of-Experts-Modelle (MoE) mit über 290 Milliarden Parametern auf Standard-Hardware mit interaktiven Geschwindigkeiten zu nutzen.

## Was es bringt

- Fasst die genutzten Hardware-Ressourcen zu einer einzigen KI-Infrastruktur zusammen.
- Bietet ein dynamisches Ressourcenmanagement zwischen Grafikspeicher (VRAM) und Hauptspeicher.
- Führt große Mixture-of-Experts-Architektur-Modelle (MoE) auf lokalen Geräten mit interaktiven Geschwindigkeiten aus.

## Installation

**Installation mit dem Paketmanager uv**

```
uv pip install "freetoken[accel]"
```

**Installation durch Kompilieren aus dem Quellcode**

```
git clone https://github.com/FlashML-org/FreeToken.git && cd FreeToken
uv venv && source .venv/bin/activate
uv pip install -e ".[accel]"
```
