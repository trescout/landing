# Erstellen Sie eine Online-Plattform zum Suchen und Ansehen von Videos

LibreSpark/LibreTV ist ein TypeScript-basiertes Softwareprojekt, mit dem Sie innerhalb einer Minute eine Film- und Serien-Website mittels Methoden wie Docker einrichten können. Es bietet eine Infrastruktur, die es Benutzern ermöglicht, schnell ihre eigenen Inhaltsplattformen zu erstellen.

## Was es bringt

- Suchen Sie Filme und Serien aus verschiedenen Quellen an einem Ort
- Sehen Sie Internet-Fernsehübertragungen im m3u- und m3u8-Format
- Speichern Sie Ihren Wiedergabeverlauf und die letzte Position in Ihrem Browser

## Installation

**Schnelle Installation mit Docker**

```
docker compose pull && docker compose up -d
```

## Ausführung

**Ausführen durch Kompilieren aus der Quelle**

```
npm install
PASSWORD=your-password npm run build
PASSWORD=your-password npm start   # 监听 8080
```
