# Benutzerscanner

User-Scanner wurde mit Python entwickelt und ist ein Open-Source-Intelligence-Tool (OSINT), das Daten aus mehr als 465 verschiedenen Quellen über eine einzige E-Mail-Adresse oder einen einzigen Benutzernamen sammelt. Die Software wurde für Sicherheitsforscher und digitale Tracker entwickelt und bietet eine detaillierte Datenanalyse mit einer breiten Palette von Scan-Vektoren.
