# Desktop-Steuerungswerkzeug für KI-Agenten

Das von Vercel Labs entwickelte agent-desktop ist eine Befehlszeilenschnittstelle (CLI), die es KI-Agenten ermöglicht, Desktop-Anwendungen über den Barrierefreiheitsbaum des Betriebssystems zu lesen und zu steuern. Das in Rust geschriebene Tool zielt darauf ab, die Computernutzungsfähigkeiten (computer use) von Agenten zu verbessern.

## Was es bringt

- Liest Desktop-Anwendungen über den Barrierefreiheitsbaum des Betriebssystems
- Führt Aktionen an Elementen aus, ohne dass Pixel-Matching erforderlich ist
- Generiert schnelle und strukturierte Antworten im JSON-Format

## Installation

**Über Paketmanager installieren**

```
npm install -g agent-desktop
agent-desktop version
```

**Fähigkeit hinzufügen**

```
npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop
```
