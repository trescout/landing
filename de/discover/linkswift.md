# Direkte Download-Links von Cloud-Diensten

LinkSwift ist ein Tool, das eine JavaScript-basierte Infrastruktur verwendet, um direkte Datei-Download-Links von verschiedenen Cloud-Speicherdiensten zu erhalten. Die Software unterstützt acht verschiedene populäre Cloud-Plattformen wie Baidu Netdisk, Alibaba Cloud Drive, China Mobile Cloud und Quark Drive.

## Was es bringt

- Erzeugt direkte Datei-Download-Links von neun verschiedenen Cloud-Speicherdiensten, einschließlich Baidu, Alibaba Cloud und Quark.
- Bietet die Möglichkeit, die erhaltenen Links an Software wie den Download-Manager IDM oder das Download-Tool Aria2 zu übertragen.
- Vereinfacht die Weboberfläche der unterstützten Cloud-Dienste und macht die Installation der offiziellen Desktop-Anwendungen überflüssig.

## So fangen Sie an

Zur Nutzung müssen Sie zunächst die Browser-Erweiterung Tampermonkey für Benutzerskripte installieren. Anschließend können Sie das Skript Ihrem Browser hinzufügen, indem Sie auf den Installationslink mit der Endung ".user.js" klicken, der auf der GitHub- oder ScriptCat-Seite des Projekts bereitgestellt wird. Sobald das Skript installiert ist, erscheint das Menü für direkte Downloads automatisch in der Benutzeroberfläche, wenn Sie eine unterstützte Cloud-Speicherseite aufrufen.
