# Erweiterter Download-Manager

XiaoYouChR/Ghost-Downloader-3 ist ein umfassendes Tool zum Herunterladen von Dateien, das auf vier verschiedenen Plattformen läuft und fast alle Download-Protokolle unterstützt. Dieses in Python entwickelte Projekt bietet eine Struktur, die ihre Funktionalität durch plugin-basierte Feature-Packs erweitern kann.

## Was es bringt

- Lädt Dateien über HTTP- und Torrent-Protokolle herunter
- zeichnet Videostreams und Live-Übertragungen auf
- läuft nativ auf mehreren Plattformen

## So fangen Sie an

Sie können es auf Ihrem Gerät installieren, indem Sie die offizielle Dokumentationsseite besuchen oder die Anwendungspakete aus dem Projekt-Repository herunterladen. Über das Einstellungsmenü können Sie das Befehlszeilentool ghd aktivieren.
