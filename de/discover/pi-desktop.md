# Arbeitsbereich für KI-Coding-Agenten

PI-Desktop ist ein KI-Coding-Agent, der nach dem Local-First-Prinzip entwickelt wurde. Mit seiner Architektur auf Basis von Electron (Framework für Desktop-Anwendungsentwicklung) und Rust (Systemprogrammiersprache) bietet es eine anpassbare Softwareentwicklungsumgebung, in der Benutzer ihre eigenen Plugins installieren können.

- ★ 1.990
- TypeScript
- GitHub Trending · 2026-09-10

## Was es bringt
- Verwalten Sie verschiedene KI-Modelle über eine einzige Schnittstelle.
- Kontrollieren Sie die Berechtigungen des Agenten zum Bearbeiten von Dateien und Ausführen von Befehlen.
- Passen Sie die Entwicklungsumgebung mit Plugins und Funktionen an.

## Installation
**Kompilieren aus Quellcode**

```
git clone https://github.com/vastsa/PI-Desktop.git
cd PI-Desktop

pnpm install

cargo build -p host-core
pnpm build:js

pnpm dev
```


## Ausführung
**Start im Entwicklungsmodus**

```
pnpm dev
```


## Wenn Sie nicht programmieren
Ich arbeite an PI-Desktop. Ich erteile dir die Berechtigung, den Code in meinen lokalen Projekten zu analysieren, Dateien zu bearbeiten und Terminalbefehle auszuführen. Ich möchte, dass du bei der Durchführung der Aufgaben zuerst einen Implementierungsplan erstellst, bei kritischen Änderungen meine Zustimmung einholst und den gesamten Prozess transparent berichtest. Bleibe beim Schreiben von Code der bestehenden Projektstruktur treu und führe bei Fehlern die notwendigen Tests durch, bevor du fortfährst.
