# Assistent für künstliche Intelligenz mit Ihren eigenen Daten

Open-Notebook bietet eine Open-Source-Alternative zu Google NotebookLM und ermöglicht es Benutzern, eine anpassbare KI-gestützte Notizenanalyse für ihre eigenen Daten durchzuführen. Dieses mit TypeScript entwickelte Projekt bietet im Vergleich zur ursprünglichen Plattform eine größere Flexibilität und einen erweiterten Funktionsumfang.

- ★ 38.082
- TypeScript
- GitHub Trending · 2026-06-05

## Was es bringt
- Analysieren Sie Ihre Daten in einer vollständig lokalen Umgebung und bewahren Sie sie vertraulich auf.
- Erhalten Sie eine flexible Modellauswahl von über 18 KI-Anbietern.
- Erstellen Sie professionelle Podcasts aus Ihren PDF-, Video- und Audiodateien.

## Installation
**Laden Sie die Konfigurationsdatei herunter**

```
curl -o docker-compose.yml https://raw.githubusercontent.com/lfnovo/open-notebook/main/docker-compose.yml
```


## Ausführung
**Startdienste**

```
docker compose up -d
```


## Wenn Sie nicht programmieren
Ich möchte das Open Notebook-Tool installieren. Docker Desktop ist installiert. Zuerst muss ich die Datei docker-compose.yml mit dem Befehl „curl“ herunterladen und dann den Abschnitt OPEN_NOTEBOOK_ENCRYPTION_KEY in der Datei durch ein eindeutiges Passwort ändern. Im letzten Schritt muss ich die Installation abschließen, indem ich den Befehl docker compose up -d ausführe.
