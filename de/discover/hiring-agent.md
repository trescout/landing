# Lebenslaufbewertung mit künstlicher Intelligenz

Hiring-Agent ist ein Agent mit künstlicher Intelligenz (KI-Agent), der zur Bewertung und Bewertung von Lebensläufen entwickelt wurde. Dieses mit der Python-Sprache entwickelte Tool zielt darauf ab, Kandidaten-Screening-Prozesse in Rekrutierungsprozessen zu automatisieren.

## Was es bringt
- Es analysiert automatisch Lebensläufe im PDF-Format.
- Es bereichert Kandidaten mit GitHub-Daten.
- Bietet einen fairen und erklärbaren Bewertungsbericht.

## Installation
**Herunterladen und Installieren der erforderlichen Dateien**

```
git clone https://github.com/interviewstreet/hiring-agent
cd hiring-agent

python -m venv .venv
# Linux or macOS
source .venv/bin/activate
# Windows
# .venv\Scripts\activate

pip install -r requirements.txt
```


## Ausführung
**Beginnen Sie mit der Überprüfung des Lebenslaufs**

```
python score.py /path/to/resume.pdf
```


## Wenn Sie nicht programmieren
Handeln Sie als Personalvermittler und analysieren Sie bereitgestellte Lebenslaufdaten und technische Beiträge auf GitHub. Bewerten Sie die Projekte, technischen Fähigkeiten und Berufserfahrung des Kandidaten nach objektiven Kriterien. Berücksichtigen Sie bei der Bewertung die Codequalität des Kandidaten auf GitHub, die Häufigkeit der Beiträge und die Relevanz seiner Projekte für reale Anwendungen. Erstellen Sie abschließend einen transparenten und fairen Bewertungsbericht, der die Stärken und Schwächen des Kandidaten hervorhebt.
