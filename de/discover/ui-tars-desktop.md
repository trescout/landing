# Schnittstelle für künstliche Intelligenz, die Ihren Computer verwaltet

UI-TARS wurde von ByteDance entwickelt und ist eine Open-Source-Agenteninfrastruktur, die multimodale KI-Modelle mit Desktop-Schnittstellen integriert. Dieses System ermöglicht die Erstellung von Agenten (KI-Agenten), die durch die Verarbeitung visueller Daten autonom Aufgaben am Computer ausführen.

## Was es bringt
- Führen Sie Desktop- und Browseraufgaben selbstständig aus
- Menschenähnlicher Arbeitsablauf durch Verarbeitung visueller Daten
- Vollständige Integration mit multimodalen KI-Modellen

## Installation
**Globale Installation**

```
npm install @agent-tars/cli@latest -g
```

**Direktbedienung**

```
npx @agent-tars/cli@latest
```


## Ausführung
**Mit Modellanbieter initialisieren**

```
agent-tars --provider volcengine --model doubao-1-5-thinking-vision-pro-250428 --apiKey your-api-key
```


## Wenn Sie nicht programmieren
Beschreiben Sie eine komplexe Aufgabe, die ich auf meinem Computer oder Browser ausführen soll. Beispielsweise kann es sein, dass ich Sie auffordere, eine bestimmte Website aufzurufen und Daten einzugeben oder einen Flugbuchungsprozess zu verwalten. Bitte analysieren Sie die visuelle Schnittstelle und führen Sie die Schritte selbstständig aus.
