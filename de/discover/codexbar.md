# Überwachen Sie die KI-Nutzungsgrenzen

CodexBar ist ein Tool, das die Anzeige von OpenAI Codex- und Claude Code-Nutzungsdaten ermöglicht, ohne dass eine Anmeldung erforderlich ist. Diese mit der Swift-Sprache entwickelte Anwendung erleichtert Entwicklern die Verfolgung von Verbrauchsstatistiken in KI-gestützten Codierungstools.

## Was es bringt

- Sehen Sie in der Menüleiste sofort die Nutzungsgrenzen aller Dienste der künstlichen Intelligenz
- Verfolgen Sie die Service-Reset-Zeiten mit einem Countdown
- Es speichert keine Passwörter, da es bestehende Sitzungen nutzt, es ist datenschutzorientiert

## Installation

**Installation mit Homebrew**

