jQuery ist eine JavaScript-Bibliothek, die das Erstellen interaktiver Elemente auf Webseiten erleichtert. Sie bietet Tools, die die Bearbeitung des Document Object Model (DOM) und die Ereignisverwaltung für Entwickler vereinfachen.

## Was es bringt

- Kompilieren Sie Ihre eigene benutzerdefinierte jQuery-Bibliothek.
- Reduzieren Sie die Größe, indem Sie Module entfernen, die Sie nicht benötigen.
- Generieren Sie alle Release-Dateien stapelweise.

## Installation

**Installieren Sie die Abhängigkeiten und erstellen Sie das Projekt**

```
cd jquery
npm install
npm run build
```

**Generieren Sie alle Release-Dateien**

```
npm run build:all
```
