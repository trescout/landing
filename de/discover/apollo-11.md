# Quellcodes des Apollo 11-Leitcomputers

Der ursprüngliche Quellcode des in der Apollo-11-Mission verwendeten Befehls- und Mondlandemodul-Leitcomputers (Guidance Computer) wurde auf GitHub in Assemblersprache verfügbar gemacht. Die Software dokumentiert die technischen Details der Berechnungsalgorithmen, die bei der ersten bemannten Mondlandung zum Einsatz kamen.

## Was es bringt

- Zugriff auf Originalcodes der Mondlandesoftware
- Überprüfung der Führungsalgorithmen für Kommando- und Mondlandemodule
- Erkundung der historischen Assembler-Softwarearchitektur

## So fangen Sie an

Dieses Repository wurde erstellt, um die ursprünglichen Quellcodes des bei der Apollo-11-Mission verwendeten Leitcomputers zu archivieren. Sie können die Ordner Comanche055 oder Luminary099 auf GitHub durchsuchen, um die Codes zu überprüfen, und die offizielle Website des Virtual AGC-Projekts besuchen, um detaillierte Informationen über die Kompilierungsprozesse zu erhalten.
