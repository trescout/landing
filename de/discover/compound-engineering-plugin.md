# Künstliche Intelligenz unterstützte Engineering-Prozesse

Verbundtechnik; Claude Code ist ein offizielles Add-on für Codex und Cursor. Die Grundphilosophie ist klar: Jede technische Aufgabe sollte die nächste einfacher und nicht schwieriger machen. Zu diesem Zweck bietet es KI-Fähigkeiten und Agenten, die den Entwicklungsprozess verbessern.

## Was es bringt

- Jede Aufgabe erleichtert die nächste, sodass Ihre Produktivität kumulativ steigt.
- Bietet vorgefertigte Fähigkeiten und Agenten.
- Passt sich problemlos an mehrere KI-Umgebungen an.

## Installation

**Claude Code Marketplace hinzufügen**

```
/plugin marketplace add EveryInc/compound-engineering-plugin
/plugin install compound-engineering
```

## Ausführung

**Installationsassistent starten**

```
/ce-setup
```

## So fangen Sie an

Sie können es als Add-on zu Ihrem KI-Assistenten installieren und die Fähigkeiten und Agenten dann in Ihren Workflow integrieren.

## Wie installiere ich, wie verwende ich?

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Wenn Sie an Claude Code arbeiten, installieren Sie das Compound Engineering-Plugin, indem Sie diese beiden Befehle nacheinander ausführen: „/plugin marketplace add EveryInc/compound-engineering-plugin“ gefolgt von „/plugin install Compound-engineering“; Wenn die Installation abgeschlossen ist, bereiten Sie die Umgebung vor, indem Sie den Befehl „/ce-setup“ in einem beliebigen Projekt ausführen.

Repository: https://github.com/EveryInc/compound-engineering-plugin. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.
