Befehlsschutz für KI-Agenten

Destructive Command Guard ist eine Sicherheitsschicht, die entwickelt wurde, um gefährliche Git- und Shell-Befehle zu verhindern, die von Agenten der künstlichen Intelligenz ausgeführt werden. Dieses in Rust geschriebene Tool reduziert das Risiko unerwünschter Datenverluste oder Systemschäden, indem es Befehlsausführungsprozesse auf Systemebene prüft.

Was es bringt

  • Blockiert gefährliche Befehle, bevor sie ausgeführt werden
  • Reduziert das Risiko von Datenverlust und Systemschäden
  • Bietet umfassenden Schutz mit mehr als 50 Sicherheitspaketen

Installation

Installation für Linux und macOS
curl -fsSL "https://raw.githubusercontent.com/Dicklesworthstone/destructive_command_guard/main/install.sh?$(date +%s)" | bash -s -- --easy-mode

Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich verwende Destructive Command Guard, um die Befehle zu steuern, die mein KI-Agent auf meinem System ausführt. Bitte beachten Sie die Sicherheitsregeln, bevor Sie gefährliche Git-, Dateisystem- oder Datenbank-Löschbefehle ausführen. Wenn Sie eine riskante Aktion durchführen müssen, informieren Sie mich zuerst und holen Sie meine Zustimmung ein.
