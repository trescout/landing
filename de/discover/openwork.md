# Teilen Sie KI-Workflows

Openwork ist ein Softwareprojekt, das als Open-Source-Alternative zur Claude-Cowork-Plattform entwickelt wurde und die Opencode-Infrastruktur nutzt. Dieses in der TypeScript-Sprache geschriebene Tool bietet eine von künstlicher Intelligenz unterstützte Arbeitsumgebung mit dem Ziel, Softwareentwicklungsprozesse zu automatisieren.

## Was es bringt
- Gemeinsame Nutzung von Funktionen zwischen KI-Tools
- Google Workspace- und Microsoft 365-Integration
- Zentralisiertes Talentmanagement innerhalb des Teams

## Ausführung
**Starten der lokalen Entwicklungsumgebung**

```
pnpm dev:worktree
```


## Wenn Sie nicht programmieren
Installieren Sie OpenWork auf meinem Computer, richten Sie meinen ersten Arbeitsbereich ein und öffnen Sie ihn gebrauchsfertig. Befolgen Sie die Schritte unter https://openworklabs.com/start.md?v=hero
