# Multiplattform-Anwendungen mit Rust

Dioxus ist ein Rust-Framework, das die Entwicklung von End-to-End-Anwendungen (Fullstack) mit einer einzigen Codebasis für Web-, Desktop- und mobile Plattformen ermöglicht. Es standardisiert die Anwendungsentwicklungserfahrung im Rust-Ökosystem, indem es den Erstellungsprozess der Benutzeroberfläche mit seiner React-ähnlichen komponentenbasierten Struktur beschleunigt.

## Was es bringt

- Entwicklung von Web-, Desktop- und mobilen Anwendungen mit einer einzigen Codebasis
- Schneller Entwicklungsprozess mit sofortiger Codeaktualisierung
- Reaktionsähnliche Komponentenstruktur und typsichere Fullstack-Unterstützung

## Installation

**Installieren Sie das CLI-Tool**

```
curl -fsSL https://dioxuslabs.com/install.sh | bash
```

**Alternative Installationsmethode**

```
cargo install --git https://github.com/DioxusLabs/dioxus dioxus-cli --locked
```

## Ausführung

**Starten der App**

```
dx serve
```

**Verpacken der App**

```
dx bundle
```
