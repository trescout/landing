# Tool zum Gravieren von Bildern auf optische Datenträger

Disc Image Studio ist ein plattformübergreifendes Tool zum Erstellen und Brennen von Disk-Images, mit dem Sie mit bloßem Auge sichtbare Bilder auf DVD-, CD- und Single-Layer-Blu-ray-Discs gravieren können. Diese in C# entwickelte Software ermöglicht es Ihnen, benutzerdefinierte Grafiken mithilfe eines beliebigen beschreibbaren optischen Laufwerks auf die Diskoberfläche zu brennen.

## Was es bringt

- Graviert mit bloßem Auge sichtbare benutzerdefinierte Grafiken auf die Oberfläche von DVD-, CD- und Blu-ray-Discs.
- Bietet fortschrittliche Bildverarbeitungs- und Shading-Tools zur Erstellung von Mustern auf der Diskoberfläche.
- Verfügt über eine plattformübergreifende Architektur, die unter Windows, Linux und macOS läuft.
