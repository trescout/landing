# Verwalten Sie problemlos Node.js-Versionen

Node Version Manager ist ein Befehlszeilentool, mit dem Entwickler mehrere Versionen von Node.js auf ihren Systemen verwalten können. Mit seiner POSIX-kompatiblen Shell-Skript-Struktur (Bash-Skript) erleichtert es schnelle Versionsübergänge zwischen verschiedenen Projekten.

## Was es bringt
- Wechseln Sie schnell zwischen verschiedenen Node.js-Versionen
- Arbeiten Sie nahtlos in POSIX-kompatiblen Shells
- Installieren Sie ganz einfach projektspezifische Node.js-Versionen

## Installation
**Installation mit cURL**

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
```

**Installation mit wget**

```
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
```


## Ausführung
**Installieren und Verwenden der Node.js-Version**

```
nvm install 24
```
