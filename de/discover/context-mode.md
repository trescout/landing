# Permanenter Speicher für Ihren KI-Agenten

Context-mode ist eine TypeScript-Bibliothek, die eine Optimierung des Kontextfensters (context window optimization) für KI-Codierungs-Agenten bietet. Sie reduziert die Datengröße durch die Isolierung von Tool-Ausgaben um 98 Prozent, bewahrt das Sitzungsgedächtnis und leitet Anfragen über das Model Context Protocol an 17 verschiedene Plattformen weiter.

- ★ 21.116
- TypeScript
- GitHub Trending · 2026-09-08

## Was es bringt
- Entlastet das Kontextfenster durch Reduzierung der Datengröße um 98 Prozent
- Gewährleistet Sitzungskontinuität durch die Nachverfolgung von Dateiänderungen und Aufgaben in einer SQLite-Datenbank
- Erhöht die Verarbeitungskapazität des Modells durch eine Struktur, die Code schreiben lässt, anstatt Daten zu verarbeiten

## Installation
**Installation über Claude Code**

```
/plugin marketplace add mksglu/context-mode
```

**Abschluss der Plugin-Installation**

```
/plugin install context-mode@context-mode
```


## Ausführung
**Überprüfung der Installation**

```
/context-mode:ctx-doctor
```


## Wenn Sie nicht programmieren
Mein KI-Agent, ich möchte, dass du ab jetzt Datenverarbeitungsaufgaben nicht mehr direkt ausführst, sondern den Code schreibst und ausführst, der diese Daten analysiert. Nutze die Context-mode-Tools, um die Datengröße zu minimieren, speichere meinen Sitzungsverlauf in SQLite und berichte mir nur die notwendigen Ergebnisse. Vermeide unnötige Erklärungen und konzentriere dich ausschließlich auf die Code-Generierung und ein effizientes Kontextmanagement.
