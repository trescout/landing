# Künstliche Intelligenz, die Dokumente in bearbeitbare Präsentationen umwandelt

PPT-Master ist ein KI-gestütztes Tool, das Dokumente direkt in bearbeitbare Präsentationsdateien (PPTX) umwandelt. Das System übersetzt Texte in anpassbare Präsentationen mit nativen Figuren, Animationen und Audionotizen des Sprechers.

## Was es bringt
- Konvertiert Text in PPTX-Dateien mit nativen Formen und Animationen.
- Fügt den Präsentationsfolien automatische gesprochene Sprechernotizen hinzu.
- Dank seiner editierbaren Struktur können Sie später Änderungen an der Präsentation vornehmen.

## Installation
**Laden Sie das Projekt auf Ihren Computer herunter**

```
git clone https://github.com/hugohe3/ppt-master.git
cd ppt-master
```

**Installieren der erforderlichen Bibliotheken**

```
pip install -r requirements.txt
```


## Wenn Sie nicht programmieren
Ich möchte das vorliegende Dokument mit PPT-Master in eine bearbeitbare Präsentationsdatei umwandeln. Analysieren Sie den Inhalt des Dokuments, erstellen Sie die Folienstruktur, fügen Sie die erforderlichen Animationen und Sprechernotizen hinzu, um eine professionelle PPTX-Datei vorzubereiten. Seien Sie versichert, dass ich in PowerPoint Änderungen an der resultierenden Präsentation vornehmen kann.
