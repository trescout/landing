# Geben Sie Agenten der künstlichen Intelligenz technisches Talent

Diese Bibliothek wurde für Codieragenten für künstliche Intelligenz entwickelt und bietet technische Fähigkeiten auf Produktionsebene. Es stellt standardisierte Tools zur Verfügung, um die technische Kapazität von Agenten zu erhöhen, die Softwareentwicklungsprozesse automatisieren.

## Was es bringt
- Es bietet professionellen Engineering-Workflows für Agenten der künstlichen Intelligenz.
- Es automatisiert Softwareentwicklungsprozesse mit standardisierten Schritten.
- Diszipliniert Test- und Überprüfungsprozesse, um die Codequalität zu verbessern.

## Installation
**Lokale Installation für Claude Code**

```
git clone https://github.com/addyosmani/agent-skills.git
claude --plugin-dir /path/to/agent-skills
```


## Wenn Sie nicht programmieren
Ich möchte, dass Sie wie ein Softwareentwickler arbeiten. Mithilfe der Agent Skills-Bibliothek wende ich in jeder Phase meines Softwareentwicklungsprozesses die Befehle /spec, /plan, /build, /test, /review, /code-simplify und /ship gemäß den Standards an. Erstellen Sie Code, indem Sie Arbeitsabläufe, Qualitätskontrollpunkte und bewährte technische Vorgehensweisen befolgen.
