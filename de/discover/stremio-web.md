# Medienwiedergabe über den Browser

Stremio ist eine Media-Player-Anwendung, die verschiedene Inhaltsanbieter in einer einzigen Benutzeroberfläche vereint. Diese webbasierte Version ermöglicht es Benutzern, Serien und Filme direkt über den Browser anzusehen, ohne eine Installation vornehmen zu müssen.

## Was es bringt

- Fasst verschiedene Inhaltsanbieter in einer einzigen Benutzeroberfläche zusammen
- Synchronisiert den Wiedergabeverlauf und die Bibliothek geräteübergreifend
- Ermöglicht die Übertragung von Inhalten auf den Fernseher via Chromecast

## Installation

**Einrichtung einer lokalen Entwicklungsumgebung**

```
pnpm install
pnpm start
```

**Container-Einrichtung mit Docker**

```
docker build -t stremio-web .
docker run -p 8080:8080 stremio-web
```
