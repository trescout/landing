# Uneingeschränkte KI-Interaktionsschnittstelle

G0DM0D3 ist eine befreite KI-Chat-Schnittstelle, die darauf abzielt, die Sicherheitsebenen großer Sprachmodelle zu umgehen. Dieses mit TypeScript entwickelte Open-Source-Projekt ermöglicht Benutzern die uneingeschränkte Interaktion mit Modellen.

## Was es bringt

- Mehrfache Vergleichsanalyse mit mehr als 60 Modellen
- Unterstützung für die Ausführung von Modellen auf lokaler Hardware
- Input-Mixing-Engine für Red-Team-Tests

## Installation

**Klonen Sie das Repository und starten Sie es auf dem lokalen Server**

```
# Clone the repository
git clone https://github.com/elder-plinius/G0DM0D3.git
cd G0DM0D3

# Open directly in your browser
open index.html
# or serve locally
python3 -m http.server 8000
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Aktivieren Sie mithilfe der G0DM0D3-Schnittstelle die ULTRAPLINIAN-Engine, die mehrere Modelle über die von mir angegebenen Modellanbieter (OpenRouter, Venice oder lokaler Server) laufen lässt. Wenden Sie Parseltongue-Eingabemischtechniken für meine Red-Team-Untersuchungen an und konfigurieren Sie mit der AutoTune-Funktion automatisch Stichprobenparameter, die am besten zum Abfragekontext passen.
