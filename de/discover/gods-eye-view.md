# Globaler räumlicher Echtzeitsimulator

Gods-eye-view ist ein Spatial-Intelligence-Simulator, der Echtzeit-Satellitendaten auf einem browserbasierten 3D-Globus visualisiert. Dieses mit JavaScript entwickelte Open-Source-Projekt ermöglicht es Benutzern, Live-Daten aus der ganzen Welt über eine fotorealistische Schnittstelle zu untersuchen.

## Was es bringt

- Sehen Sie sich Live-Flug-, Schiffs- und Satellitendaten von der Erde auf einem 3D-Globus an.
- Markieren Sie die Karte und wechseln Sie per Sprachbefehl in verschiedene Sensormodi.
- Entdecken Sie die Welt aus der Cockpit-Perspektive, indem Sie in lebende Flugzeuge einsteigen.

## Installation

**Abhängigkeiten installieren und starten**

```
npm install
npm run dev -- --host localhost --port 4173
```
