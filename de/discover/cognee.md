# Permanenter Speicher für Ihren KI-Agenten

Cognee ist eine Open-Source-Plattform, die künstliche Intelligenz-Agenten ein Langzeitgedächtnis zwischen Sitzungen bereitstellt. Es ermöglicht Agenten, Daten mithilfe einer selbstgehosteten Knowledge-Graph-Engine strukturiert zu speichern und abzurufen.

## Was es bringt

- Persistentes sitzungsübergreifendes Langzeitgedächtnis für Agenten.
- Selbstgehostete Wissensgraph-Engine
- Kontextuelles Lernen durch Kombination von Datenquellen

## Installation

**Paketinstallation**

```

## Ausführung

**Grundlegende Verwendung**

```

```

**Starten der Schnittstelle**

```
cognee-cli -ui
