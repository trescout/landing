# Permanenter Speicher für Ihren KI-Agenten

Cognee ist eine Open-Source-Plattform, die künstliche Intelligenz-Agenten ein Langzeitgedächtnis zwischen Sitzungen bereitstellt. Es ermöglicht Agenten, Daten mithilfe einer selbstgehosteten Knowledge-Graph-Engine strukturiert zu speichern und abzurufen.

## Was es bringt
- Persistentes sitzungsübergreifendes Langzeitgedächtnis für Agenten.
- Selbstgehostete Wissensgraph-Engine
- Kontextuelles Lernen durch Kombination von Datenquellen

## Installation
**Paketinstallation**

```
uv pip install cognee
```


## Ausführung
**Grundlegende Verwendung**

```
cognee-cli remember "Cognee turns documents into AI memory."
```

**Starten der Schnittstelle**

```
cognee-cli -ui
```


## Wenn Sie nicht programmieren
Mit Cognee möchte ich meine Daten in einer Knowledge-Graph-Struktur speichern und meinem Agenten ermöglichen, diese Daten abzurufen, indem er sie in seinem Langzeitgedächtnis speichert. Bitte erstellen Sie einen Workflow, der es mir ermöglicht, mir Daten mit der Funktion cognee.remember() zu merken und auf der Grundlage dieser Daten mit cognee.recall() aussagekräftige Antworten zu generieren.
