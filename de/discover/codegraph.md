# Mappen Sie Ihre Codebasis für KI

Codegraph ist ein lokales Knowledge-Graph-Tool (Wissensgraph), das Codebasen vorab indiziert und für KI-Modelle bereitstellt. Durch die automatische Synchronisierung von Codeänderungen sorgt es dafür, dass Codierungsassistenten wie Claude Code oder Cursor weniger Token und Tool-Aufrufe verbrauchen.

## Was es bringt
- Erstellt einen lokalen Wissensgraphen, der dafür sorgt, dass KI-Modelle beim Codieren weniger Token verbrauchen.
- Hält den Index stets aktuell, indem Codeänderungen im Hintergrund automatisch synchronisiert werden.
- Verbindet Tools wie den Codierungsassistenten Cursor direkt mit der Architektur Ihres Projekts.

## Installation
**Globale Installation mit dem Paketmanager npm**

```
npm i -g @colbymchenry/codegraph
```


## Ausführung
**Ausführen und Verknüpfen des Tools direkt mit npx**

```
npx @colbymchenry/codegraph
```


## Wenn Sie nicht programmieren
Installieren Sie das Codegraph-Tool in Ihrem Projekt über den Paketmanager npm, indem Sie den Befehl `npm i -g @colbymchenry/codegraph` ausführen. Führen Sie anschließend den Befehl `npx @colbymchenry/codegraph` aus, um die KI-Assistenten zu konfigurieren und den Vorgang abzuschließen.
