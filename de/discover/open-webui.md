# Eine einzige Benutzeroberfläche für Ihre KI-Modelle

open-webui ist eine benutzerfreundliche Oberfläche zur Interaktion mit KI-Modellen wie Ollama und der OpenAI-API. Es bietet eine webbasierte Benutzeroberfläche (Interface), die für die Verwaltung lokaler oder cloudbasierter Sprachmodelle entwickelt wurde.

## Was es bringt

- Sie können alle lokalen und cloudbasierten KI-Modelle über eine einzige Weboberfläche verwalten.
- Sie können Ihre eigenen Dokumente in das System hochladen, um Frage-Antwort-Interaktionen anhand Ihrer Texte durchzuführen und im Internet suchen zu lassen.
- Sie können Tools zur Bilderstellung, Sprachsuche, Kalenderverwaltung und Notizerfassung direkt im Chatbereich nutzen, ohne diesen zu verlassen.

## Installation

**Installation mit dem Python-Paketmanager pip**

```
pip install open-webui
```

## Ausführung

**Starten mit dem Software-Containerisierungstool Docker**

```
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```
