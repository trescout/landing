# Bereiten Sie Webdaten für KI vor

Crawl4AI; ist ein Open-Source-Webcrawler und -Scraper, der für große Sprachmodelle optimiert ist. Es konvertiert Webseiten in saubere und strukturierte Formate (Markdown usw.), die Modelle der künstlichen Intelligenz problemlos verarbeiten können.

## Was es bringt

- Es konvertiert Webinhalte in ein sauberes und KI-freundliches Format.
- Speziell optimiert für LLM-Prozesse.
- Es ist schnell und Open Source.

## Installation

**Mit pip (PyPI)**

```
pip install crawl4ai
```

## Ausführung

**Webseite scannen und für KI vorbereiten**

```
crawl4ai-download
```

## Installation (einzelner Befehl)

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Helfen Sie mir, den Open-Source-Webcrawler Crawl4AI zu installieren; Versuchen wir es, indem wir es mit „pip install -U crawl4ai“ installieren, dann „crawl4ai-setup“ ausführen und eine Webseite mit dem Befehl „crwl https://www.nbcnews.com/business -o markdown“ in LLM-freundliches Markdown konvertieren.
