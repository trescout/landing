# Übertragen Sie Spotify Portal-Daten an Ihren Coding-Assistenten

Die von Spotify entwickelten portal-ai-plugins ermöglichen die Integration des Spotify Portal-Systems in KI-gestützte Coding-Tools wie Claude Code, Codex, Cursor und pi. Diese in TypeScript geschriebenen Plugins erleichtern Entwicklern den Zugriff auf Spotify-Daten in ihren Arbeitsumgebungen.

- TypeScript
- GitHub Trending · 2026-11-04

## Was es bringt

- Durchsuchen Sie den Softwarekatalog mit natürlicher Sprache
- Erstellen Sie Service-Zusammenfassungen und Statusberichte
- Führen Sie Portal-Vorgänge sicher aus

## So fangen Sie an

Um das Spotify Portal-System in Claude Code, Codex, Cursor oder pi zu integrieren, können Sie den Installationsschritten auf der offiziellen Repository-Seite folgen.
