# Stil-Framework für schnelles Interface-Design

Tailwind CSS ist ein Utility-First-Stylesheet-Framework (CSS-Framework), das sich auf die schnelle Entwicklung von Benutzeroberflächen konzentriert. Es ermöglicht die schnelle Erstellung origineller Schnittstellen, indem es Low-Level-Klassen anstelle vorgefertigter Designkomponenten anbietet.

## Was es bringt
- Erstellen Sie einzigartige Designs mit Low-Level-Klassen
- Entwickeln Sie Schnittstellen, ohne sich mit vorgefertigten Komponenten auseinanderzusetzen
- Bieten Sie eine schnelle Stilverwaltung in modernen Webprojekten

## Installation
**mit npm**

```
npm install tailwindcss @tailwindcss/cli
```


## Ausführung
**CSS generieren**

```
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```
