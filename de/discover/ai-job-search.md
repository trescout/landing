# Automatische Bewerbung mit Claude Code

Mithilfe der Claude-Code-Infrastruktur bietet ai-job-search ein Framework, das den Jobsuchprozess automatisiert. Das Tool analysiert das Nutzerprofil und übernimmt mit Unterstützung künstlicher Intelligenz Aufgaben wie die Bearbeitung von Lebensläufen, das Verfassen von Anschreiben und die Vorbereitung von Vorstellungsgesprächen.

## Was es bringt
- Bereitet Lebenslauf und Anschreiben entsprechend Ihrem persönlichen Profil vor
- Analysiert Stellenausschreibungen und vergibt Eignungsbewertungen
- Bietet Anleitung zur Vorbereitung auf Vorstellungsgespräche

## Installation
**Laden Sie Tools zur Jobsuche herunter**

```
cd .agents/skills/jobbank-search/cli && bun install && cd ../../../..
cd .agents/skills/jobdanmark-search/cli && bun install && cd ../../../..
cd .agents/skills/jobindex-search/cli && bun install && cd ../../../..
cd .agents/skills/jobnet-search/cli && bun install && cd ../../../..
cd .agents/skills/linkedin-search/cli && bun install && cd ../../../..
```


## Ausführung
**Starten Sie die Profileinrichtung**

```
/setup
```

**Durchsuchen Sie Stellenausschreibungen**

```
/scrape
```


## Wenn Sie nicht programmieren
Erstellen Sie Ihr Profil mit dem Befehl /setup in Claude Code. Listen Sie dann mit dem Befehl /scrape die passenden Stellenausschreibungen auf und erstellen Sie mit dem Befehl /apply einen Entwurf Ihres Lebenslaufs und Anschreibens für die von Ihnen ausgewählte Stellenausschreibung. Bitten Sie während des Prozesses die künstliche Intelligenz, ihre Kompatibilität mit der Anzeige zu bewerten und Feedback für die Interviewvorbereitung zu geben.
