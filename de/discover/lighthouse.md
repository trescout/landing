# Spielen Sie Banjo Kazooie auf modernen Systemen

Lighthouse ist ein in C-Sprache entwickeltes Code-Coverage-Tool, das für Low-Level-Systeme konzipiert ist. Es stellt Entwicklern Daten zum Debuggen und zur Leistungsoptimierung zur Verfügung, indem es analysiert, welche Codeblöcke während der Testprozesse der Software ausgeführt werden.

## Was es bringt
- Bietet moderne Plattformunterstützung mit Originalspieldateien
- Bietet Unterstützung für mehrsprachige Pakete und Mods
- Enthält anpassbare Controller- und Grafikeinstellungen

## So fangen Sie an
Laden Sie die Lighthouse-Version von der offiziellen GitHub-Release-Seite herunter und extrahieren Sie die Dateien in einen Ordner. Nachdem Sie Ihre eigene Spieledatei (ROM) überprüft haben, wählen Sie Ihre Spieledatei aus, indem Sie „lighthouse.exe“ unter Windows, „lighthouse.appimage“ unter Linux oder „lighthouse“ unter macOS ausführen.
