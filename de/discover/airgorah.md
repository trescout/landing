# Sicherheitsüberprüfung für kabellose Netzwerke

Airgorah, entwickelt in der Programmiersprache Rust, ist eine Software zur Überprüfung der WLAN-Sicherheit. Sie bietet die Möglichkeit, Sicherheitstests wie das Überwachen des nahen Netzwerkverkehrs, das Erkennen von mit Access Points verbundenen Geräten und das Knacken von Passwörtern durchzuführen.

## Was es bringt

- Sie können den WLAN-Verkehr in der Nähe überwachen und verbundene Geräte erkennen.
- Sie können Netzwerk-Handshake-Daten und Sicherheitsschlüssel erfassen.
- Sie können die Passwortfestigkeit von Access Points testen.

## So fangen Sie an

Um die Software zu installieren und zu verwenden, können Sie den Anleitungen auf den offiziellen Wiki-Seiten des Projekts folgen. Damit die Anwendung funktioniert, benötigen Sie eine WLAN-Karte, die den Monitor-Modus unter dem Betriebssystem Linux unterstützt.
