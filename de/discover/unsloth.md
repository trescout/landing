# Trainieren und betreiben Sie lokale KI-Modelle

Unsloth ist eine Bibliothek, die das Training und die Ausführung großer Sprachmodelle (LLM) und Diffusionsmodelle in einer nativen Umgebung beschleunigt. Es macht die Feinabstimmung von Prozessen beliebter Modelle durch die Optimierung der Speichernutzung leichter zugänglich.

## Was es bringt

- Führen Sie große Sprachmodelle und Rendering-Tools auf Ihrem lokalen Computer aus.
- Führen Sie Feinabstimmungsprozesse doppelt so schnell und mit 70 % weniger Speicherverbrauch durch.
- Integrieren Sie Softwareentwicklungsagenten wie Claude Code in Ihre nativen Modelle.

## Installation

**Setup für macOS, Linux und WSL**

```
curl -fsSL https://unsloth.ai/install.sh | sh
```

## Ausführung

**Starten des Softwareentwicklungsagenten**

```
unsloth start claude
```

## Wenn Sie nicht programmieren

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich möchte mit Unsloth ein KI-Modell auf meinem lokalen Computer trainieren. Können Sie mir Schritt für Schritt die optimalen Konfigurationseinstellungen erläutern, die es mir ermöglichen, meine Hardwareressourcen optimal zu nutzen, die Speichernutzung zu optimieren und den Feinabstimmungsprozess zu beschleunigen?
