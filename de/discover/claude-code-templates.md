# Vorgefertigte Konfigurationen für Claude Code

Claude Code-Vorlagen bieten eine Befehlszeilenschnittstelle (CLI) für das Claude Code-Tool, die die Konfiguration und Überwachung vereinfacht. Dieses Python-basierte Tool standardisiert die Kontrolle der Entwickler über den Codierungsassistenten und das Workflow-Management.

## Was es bringt
- Mehr als hundert vorgefertigte KI-Agenten und Befehlszugriff
- Schnelle Integration und Hook-Verwaltung für externe Dienste
- Echtzeitanalyse und Überwachung für Entwicklungssitzungen

## Installation
**Starten Sie die interaktive Einrichtung**

```
npx claude-code-templates@latest
```

**Benutzerdefinierte Komponenteninstallation**

```
npx claude-code-templates@latest --agent development-tools/code-reviewer --yes
```


## Ausführung
**Sitzungsanalysen anzeigen**

```
npx claude-code-templates@latest --analytics
```

**Öffnen Sie das Chat-Überwachungsfenster**

```
npx claude-code-templates@latest --chats
```
