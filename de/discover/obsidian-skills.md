# Fügen Sie Ihren Obsidian-Notizen KI-Funktionen hinzu

Mit Obsidian-Skills können Agenten der künstlichen Intelligenz Operationen an der Notizanwendung Obsidian über die Befehlszeilenschnittstelle (CLI) und offene Dateiformate ausführen. Dieses Tool automatisiert die Verwaltung persönlicher Informationen, indem es Agenten ermöglicht, Formate wie Markdown und JSON Canvas zu lesen und zu bearbeiten.

## Was es bringt

- Es ermöglicht Agenten der künstlichen Intelligenz, Ihre Notizen zu lesen und zu organisieren.
- Es unterstützt Dateiformate wie Markdown und JSON Canvas.
- Es etabliert Automatisierungsprozesse auf der Notizanwendung Obsidian.

## Installation

**Installation mit npx**

```
npx skills add git@github.com:kepano/obsidian-skills.git
```

**Installation für OpenCode**

```
git clone https://github.com/kepano/obsidian-skills.git ~/.opencode/skills/obsidian-skills
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich verwende das Obsidian-Skills-Tool, um meine Obsidian-Notizen zu verwalten. Bitte nutzen Sie diese Fähigkeiten, um Markdown-Dateien in meinen Notizen zu bearbeiten, JSON Canvas-Inhalte zu aktualisieren oder notwendige Aktionen über die Obsidian CLI-Befehlszeilenschnittstelle auszuführen. Ich möchte, dass Sie einen effizienten Informationsmanagementfluss schaffen, insbesondere durch die Beibehaltung der komplexen Strukturen, Zusammenhänge und Merkmale in meinen Notizen.
