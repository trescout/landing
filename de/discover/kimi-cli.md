# KI-gestützte Entwicklung im Terminal

Kimi CLI wurde von Moonshot AI entwickelt und ist ein Agent für künstliche Intelligenz, der über eine Befehlszeilenschnittstelle (CLI) funktioniert. Dieses Python-basierte Tool wurde entwickelt, um Befehlszeileninteraktionen in Softwareentwicklungsprozessen zu automatisieren.

- ★ 11.306
- Python
- GitHub Trending · 2026-07-19

## Was es bringt
- Fähigkeit, Code zu lesen und zu bearbeiten
- Befehle über Terminal ausführen
- Websuche und autonome Planung

## Installation
**Einrichtung der Entwicklungsumgebung**

```
git clone https://github.com/MoonshotAI/kimi-cli.git
cd kimi-cli

make prepare  # prepare the development environment
```


## Wenn Sie nicht programmieren
Ich möchte, dass Sie als Entwicklungsagent im Terminal arbeiten. Während ich meine Softwareentwicklungsaufgaben erledige, lese und bearbeite ich meine Codedateien, führe die erforderlichen Shell-Befehle aus und plane Prozesse autonom, indem ich bei Bedarf im Internet suche.
