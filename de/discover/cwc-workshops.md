# Praxisorientierter Workshop für Agenten der künstlichen Intelligenz

Diese von Anthropic geteilten Workshops zeigen Entwicklern in der Praxis die Prozesse zur Entwicklung computertauglicher Agenten künstlicher Intelligenz. Zu den TypeScript-basierten Beispielen gehören technische Frameworks, die es Modellen ermöglichen, komplexe Aufgaben durch Interaktion mit Bildschirmschnittstellen zu verwalten.

- TypeScript

## Was es bringt
- Aufbau von Multiagentensystemen mit Fähigkeiten und MCP
- Verleiht Agenten dauerhafte Gedächtnis- und Lernfähigkeiten
- Evaluationsgesteuerte Agentenentwicklungsprozesse

## So fangen Sie an
Dieses Tool enthält Material aus den Code with Claude-Workshops, die von Anthropic veranstaltet werden. Besuchen Sie zunächst das offizielle cwc-workshops-Repository auf GitHub, navigieren Sie zu dem Ordner, der Sie interessiert, und befolgen Sie die dortigen Anweisungen.
