# Kubernetes-Verwaltung für Nvidia-Grafikkarten

NVIDIA Kubernetes Engine (NVKE) bietet eine Steuerungsebene (Management Plane) zur Verwaltung von GPU-beschleunigten Kubernetes-Clustern auf Bare-Metal-Servern. Das in Go entwickelte Tool läuft auf einer Docker-Infrastruktur mit Unterstützung für virtuelle TPMs und vereinfacht die Prozesse der Cluster-Bereitstellung und Workload-Erstellung.

## Was es bringt

- Richten Sie verwaltete Cluster auf Ihrer eigenen Hardware ein.

## Installation

**Kompilieren aus Quellcode**

```
git clone https://github.com/dsx-ai-factory/nvke.git
cd nvke
make build
```
