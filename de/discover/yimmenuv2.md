# Experimenteller Modus-Menü für Grand Theft Auto 5

YimMenuV2 ist eine experimentelle Menümodifikation, die für Grand Theft Auto 5: Enhanced Edition entwickelt wurde. Dieses in C++ geschriebene Tool bietet verschiedene Anpassungen und erweiterte Funktionen innerhalb des Spiels.

## So fangen Sie an
- Offizielle Quelle →
Laden Sie zunächst die YimMenuV2-Datei von der GitHub-Release-Seite herunter und holen Sie sich ein Injektor-Tool. Deaktivieren Sie BattlEye in den Rockstar Launcher-Einstellungen, starten Sie dann das Spiel und fügen Sie die heruntergeladene DLL-Datei mithilfe des Injektors zum Spiel hinzu.
