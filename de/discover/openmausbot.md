# Chat-orientiertes KI-Bot-Team

OpenMausBot ist eine Open-Source-Alternative zu Grok Bot, mit der Sie Ihr eigenes KI-Bot-Team innerhalb von Chat-Anwendungen erstellen können. Die Software wird mit Unterstützung für eine virtuelle Maschine geliefert, die von den Bots verwendet werden kann.

- ★ 7.628
- TypeScript
- GitHub Trending · 2026-10-30

## Aktualisierungen

- **30. Oktober 2026:** Sterne 7,621 → 7,628, neueste Version v0.1.134 (30. Oktober 2026).

## Was es bringt

- Sie können Ihr eigenes KI-Bot-Team über die Desktop-Anwendungsarchitektur Electron verwalten.
- Sie können Ihren Chat-Verlauf und Ihre Daten lokal auf Ihrem Computer statt in der Cloud speichern.
- Mit der Befehlszeilentool-CLI-Integration können Sie Ihren Bots verschiedene KI-Modelle zuweisen.

## Installation

**Installation und Ausführung des OpenMausBot-Pakets**

```
npm install -g openmausbot
openmausbot
```
