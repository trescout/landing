# Schnelle und zuverlässige Programmiersprache

Die von Google entwickelte Programmiersprache Go ist eine Open-Source-Systemprogrammiersprache zur Erstellung leistungsstarker und skalierbarer Software. Aufgrund seines Parallelitätsmanagements und seiner schnellen Kompilierungszeiten wird es in modernen Cloud-Computing-Infrastrukturen weithin bevorzugt.

## Was es bringt

- Einfache und verständliche Codestruktur
- Hohe Arbeitsleistung
- Effizienz für moderne Cloud-Systeme

## Installation

**macOS (Homebrew)**

```
brew install go
```

**Windows (winget)**

```
winget install GoLang.Go
```

## Ausführung

**Version prüfen**

```
go version
```
