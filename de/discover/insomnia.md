# Einfache Verwaltung moderner API-Anfragen

Insomnia ist ein Open-Source-API-Client (Application Programming Interface), der die Protokolle GraphQL, REST, WebSockets, SSE und gRPC unterstützt. Die Software bietet plattformübergreifende Unterstützung mit Cloud-basierten, lokalen und Git-Speicheroptionen.

## Was es bringt

- Unterstützung für das Debuggen gängiger Protokolle wie GraphQL, REST und gRPC
- Flexible lokale, Git- oder cloudbasierte Speicheroptionen
- Visuelles API-Design mit integriertem OpenAPI-Editor

## Installation

**macOS (Homebrew)**

```
brew install --cask insomnia
```

**Linux · Snap-Paket (Insomnia-Publisher)**

```
sudo snap install insomnia
```

## So fangen Sie an

Um mit der Nutzung von Insomnia zu beginnen, können Sie auf die offizielle Website https://insomnia.rest gehen und die für Ihr Betriebssystem geeignete Installationsdatei herunterladen und ausführen. Sie können die App mit ihrer nativen Scratch Pad-Funktion nutzen, ohne ein Konto zu erstellen, oder ein kostenloses Konto für weitere Funktionen erstellen.
