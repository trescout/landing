# Permanente URL für die lokale Entwicklungsumgebung

Das von Vercel Labs entwickelte Portless wandelt Portnummern, die in lokalen Entwicklungsumgebungen verwendet werden, in permanente und benannte URLs um. Dieses Tool ermöglicht es sowohl Entwicklern als auch autonomen KI-Agenten, einfacher mit lokalen Diensten zu interagieren.

## Was es bringt

- Wandelt variable Portnummern in einprägsame Adressen um
- Bietet automatisch HTTPS- und HTTP/2-Unterstützung
- Erstellt separate URLs für jedes Paket in Monorepo-Strukturen

## Installation

**Allgemeine Installation**

```
npm install -g portless
```

**Projektbasierte Einrichtung**

```
npm install -D portless
```

## Ausführung

**Anwendung mit benannter URL starten**

```
portless myapp next dev
```
