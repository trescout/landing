Reinforcement-Learning-Simulationsumgebung für Microduck-Robotik

Entwickelt von Pollen Robotics, bietet microduck_rl physikbasierte Reinforcement-Learning-Umgebungen auf MuJoCo und mjlab für den zweibeinigen Microduck-Roboter.

  • ★ 1.001
  • Python
  • GitHub Trending · 2026-08-31

Aktualisierungen

  • 31. August 2026: 1.001 Sterne, mit MuJoCo mjlab-Physikengine und Fortbewegungsaufgaben.

Was es bringt

  • Präzise MuJoCo-Physiksimulation: Hochfrequente Berechnung von Gelenkmomenten, Bodenkontaktkräften und Gravitationseffekten.
  • Vorkonfigurierte Fortbewegungsaufgaben: Fertig abgestimmte Belohnungsfunktionen für Gehen, Balancieren und Hindernisbewältigung.
  • Optimierter Sim-to-Real-Transfer: Durch Domain Randomization gehärtete Kontrollrichtlinien für reale Microduck-Hardware.
  • Moderner Reinforcement-Learning-Stack: Unterstützung etablierter Algorithmen wie PPO (Proximal Policy Optimization) und SAC.
  • Interaktive 3D-Echtzeitvisualisierung: Überprüfen Sie Gangmuster und Stabilität des Roboters direkt im interaktiven 3D-Viewport.

Installation

Repository klonen und Simulationsumgebung installieren
git clone https://github.com/pollen-robotics/microduck_rl.git
cd microduck_rl
pip install -e .

Ausführung

Training oder Richtlinien-Evaluierung ausführen
python -m microduck_rl.train --task walk
# Eğitilen politikayı simülatörde izleme:
python -m microduck_rl.enjoy --checkpoint checkpoint.pt

Technische Architektur und Funktionsweise

microduck_rl verbindet die MuJoCo-Physikengine über mjlab mit der standardisierten Gymnasium-API:

  • MuJoCo- & mjlab-Kinematikschicht: Deklarative MJCF/XML-Modelle für Gelenkkinematik, Aktordynamik und Trägheitseigenschaften.
  • Gymnasium-Beobachtungs- und Aktionsräume: Standardisierte kontinuierliche Aktionsvektoren für Drehmomente und IMU-Sensordaten.
  • Domain-Randomization-Pipeline: Variiert Reibung, Massen und Latenzen dynamisch für robuste Übertragbarkeit auf physische Roboter.

Physiksimulation und Robotik-Steuerungsrichtlinien

Robotik-Forscher nutzen microduck_rl zur risikofreien Entwicklung stabiler Bewegungsmuster:

  • Kein Hardware-Risiko während der Explorationsphase: Vermeiden Sie Motorschäden und Stürze, indem Sie riskante Manöver zunächst rein virtuell trainieren.
  • Massiv beschleunigtes paralleles Training: Simulieren Sie physikalische Prozesse mit 100-facher Echtzeitgeschwindigkeit für Trainingsergebnisse in wenigen Stunden.
  • Individuelle Terrains und Hindernisse: Erstellen Sie Rampen, Stufen und rutschige Untergründe, um adaptive Gangmuster auf die Probe zu stellen.

Häufig gestellte Fragen

  • Wird die physische Microduck-Hardware zwingend benötigt? Nein. Das gesamte Repository läuft vollständig virtuell im MuJoCo-Simulator auf Ihrem Computer.
  • Ist eine dedizierte GPU erforderlich? MuJoCo läuft bereits auf der CPU sehr schnell, eine CUDA-kompatible GPU beschleunigt das parallele Training jedoch maßgeblich.
  • Wie wird die trainierte Policy auf den echten Roboter übertragen? Die erzeugten PyTorch- oder ONNX-Dateien werden auf den Onboard-Computer des Roboters kopiert und steuern die Gelenkmotoren direkt an.
  • Können andere Robotertypen simuliert werden? microduck_rl ist auf Microduck zugeschnitten, die modulare Struktur lässt sich jedoch auf andere zwei- oder vierbeinige Roboter übertragen.
