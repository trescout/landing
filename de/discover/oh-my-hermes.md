# Professionelle Betriebsebene für Hermes Agent

Das für Hermes Agent entwickelte oh-my-hermes bietet Pakete für Programmierintelligenz, ein Langzeitgedächtnissystem und modellorientierte Arbeitsabläufe in einem einzigen Plugin. Dieses Tool, das Softwareentwicklungsprozesse optimiert, bietet Entwicklern mit seiner Python-basierten Struktur eine umfassende Arbeitsumgebung.

- ★ 2.299
- Python
- GitHub Trending · 2026-09-15

## Was es bringt
- Bietet eine Arbeitsumgebung, die Softwareentwicklungsprozesse optimiert.
- Hält die Projekthistorie mit einem Langzeitgedächtnissystem organisiert.
- Fügt Programmierintelligenz und modellorientierte Arbeitsabläufe hinzu.

## Installation
**Installation für macOS und Linux**

```
curl -fsSL https://raw.githubusercontent.com/rlaope/oh-my-hermes/main/install.sh | sh
```

**Installation mit dem Homebrew-Paketmanager**

```
brew install rlaope/tap/omh
```


## Ausführung
**Konfiguration nach der Installation**

```
omh setup
```


## Wenn Sie nicht programmieren
Installieren und konfigurieren Sie das Oh My Hermes-Plugin auf dem Hermes Agent. Verwenden Sie während des Installationsprozesses den für das Betriebssystem geeigneten Installer, schließen Sie die interaktive Modellinstallation ab, führen Sie das Modellketten-Gespräch durch und führen Sie die Doctor-Schritte aus. Behalten Sie die bestehende Hermes-Konfiguration bei, wenden Sie nur die dokumentierten Installationsänderungen an und berichten Sie über das Ergebnis des Vorgangs.
