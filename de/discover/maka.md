# Lokaler Arbeitsbereich für KI-Agenten

Apache Maka ist ein lokaler Arbeitsraum, der für künstliche Intelligenzagenten entwickelt wurde. Sie müssen die Prozesse stabilisieren, indem die Agenten schwere Verkehrskontrollen durchführen, Fahrzeuge abholen und über die Erlaubnis entscheiden, sich an einem anexos orientierten Protokoll zu beteiligen.

- ★ 2.064
- TypeScript
- GitHub Trending · 2026-08-22

## Was es bringt
- Speichert Daten sicher auf Ihrem lokalen Computer
- Zeichnet den Transaktionsverlauf und Fahrzeuganrufe auf
- Bietet native Tools wie Dateibearbeitung und Befehlsausführung

## Installation
**Starten der Entwicklungsumgebung**

```
git clone https://github.com/apache/maka.git
cd maka
npm ci
npm run dev
```

**Erstellen Sie alle Arbeitsbereiche**

```
npm run dev:full
```


## Ausführung
**Starten der Terminalschnittstelle**

```
npm run cli:dev
```


## Wenn Sie nicht programmieren
Im Maka-Arbeitsbereich müssen Sie ein Projekt analysieren, die Dateien mit den erforderlichen Tools organisieren und alle Ihre Aktionen in einem nachvollziehbaren Protokoll festhalten. Kontrollieren Sie Berechtigungen im gesamten Workflow, bewahren Sie Modellmeldungen auf und verwalten Sie den Prozess im Fehlerfall auf wiederherstellbare Weise.
