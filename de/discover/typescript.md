# Fehlerprüfung für JavaScript-Projekte

TypeScript, eine Obermenge der JavaScript-Sprache, ermöglicht die Fehlerprüfung während der Kompilierungsphase des Codes. Mit seiner statischen Typisierungsfunktion unterstützt es zuverlässigere und skalierbarere Softwareentwicklungsprozesse.

- ★ 110.286
- TypeScript
- GitHub Trending · 2026-07-11

## Was es bringt
- Beim Schreiben von Code auf Fehler prüfen
- Zuverlässigkeit durch statische Typidentifikation
- Skalierbare Softwareentwicklungsprozesse

## Installation
**npm: global installieren**

```
npm install -g typescript
```

**Als Projektabhängigkeit hinzufügen**

```
npm install --save-dev typescript
```


## Ausführung
**TypeScript-Datei kompilieren**

```
tsc index.ts
```
