# System, das Agenten der künstlichen Intelligenz koordiniert

Swarm Forge ist in der Sprache Clojure geschrieben und ein Tool zur Koordinierung mehrerer KI-Agenten von einem einzigen Zentrum aus. Die Software bietet eine einfache Struktur zur Verwaltung komplexer Prozesse, bei denen verschiedene Agenten zusammenarbeiten müssen.

## Was es bringt

- Verwaltet mehrere Agenten für künstliche Intelligenz von einem einzigen Zentrum aus
- Überwachen Sie Agenten gleichzeitig mit dem Tmux-Terminal-Multiplexer
- Bietet projektspezifische anpassbare Arbeitsabläufe

## Installation

**Laden Sie den Arbeitszweig herunter und bereiten Sie ihn vor**

```
BRANCH=four-pack
curl -L "https://github.com/unclebob/swarm-forge/archive/refs/heads/${BRANCH}.tar.gz" | tar -xz --strip-components=1
```

## Ausführung

**Systeminitialisierung**

```
./swarm
```
