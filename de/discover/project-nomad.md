# Überlebenscomputer ohne Internet

Projekt N.O.M.A.D; Es handelt sich um ein autarkes Offline-Computerbauprojekt, das keine Internetverbindung benötigt und mit wichtigen Werkzeugen, Informationsressourcen und künstlicher Intelligenz ausgestattet ist. Es ist speziell für Notfälle und Szenarien konzipiert, in denen kein Internet verfügbar ist.

## Was es bringt

- Es bietet wichtige Tools und Informationen, die kein Internet erfordern.
- Bietet lokale (Offline-)Unterstützung für künstliche Intelligenz.
- Es ermöglicht die Vorbereitung auf Notfall- und Offline-Szenarien.

## Wie installiere ich, wie verwende ich?

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Auf einem Debian-basierten System (Ubuntu empfohlen) fügen Sie den folgenden Installationsbefehl in das Terminal ein und führen ihn aus. Öffnen Sie dann http://localhost:8080 im Browser, um mir bei der Verwendung des Offline-Informationsservers zu helfen.

**Schnelle Installation (Debian/Ubuntu)**

```
curl -fsSL https://raw.githubusercontent.com/Crosstalk-Solutions/project-nomad/refs/heads/main/install/install_nomad.sh -o install_nomad.sh
sudo bash install_nomad.sh
```

**beginnen**

```
sudo bash /opt/project-nomad/start_nomad.sh
```
