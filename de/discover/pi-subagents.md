# Asynchrones Aufgabenmanagement mit künstlicher Intelligenz

pi-subagents ist eine TypeScript-Bibliothek, die zur Verwaltung asynchroner Subagenten-Delegierungsprozesse auf der Pi-Plattform entwickelt wurde. Es erleichtert die Verteilung komplexer Arbeitslasten auf Subagenten.

## Was es bringt

- Es verteilt die Arbeitslast auf Subagenten.
- Bietet asynchrone und parallele Ausführung.
- Es funktioniert vollständig integriert mit der Pi-Plattform.

## Wie installiere ich, wie verwende ich?

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Installieren Sie dieses Paket mit dem Befehl „pi install npm:pi-subagents“, führen Sie dann eine Codeüberprüfung mit „/run reviewer“ durch oder führen Sie mehrere Experten-Subagenten (z. B. Reviewer, Scheduler) gleichzeitig mit „/parallel“ aus und verteilen Sie die Arbeit an sie.

Repository: https://github.com/nicobailon/pi-subagents. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.

**mit pi installieren**

```
pi install npm:pi-subagents
```

**Führen Sie einen Subagenten aus**

```
/run <ajan> [görev]
```

**Führen Sie Agenten parallel aus**

```
/parallel ajan1 "görev1" -> ajan2 "görev2"
```
