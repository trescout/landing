# Ein maßgeschneiderter KI-Arbeitsbereich für Ihr Unternehmen

Cloudflare hat einen Agent-Arbeitsbereich (Agent Workspace) eingeführt, der die Erstellung von Dokumenten mit internen Daten, die Anwendungsentwicklung und das Ausführen von KI-Agenten unterstützt. Diese Plattform läuft auf Cloudflare Workers und bietet eine in Unternehmenssysteme integrierte Entwicklungsumgebung.

- ★ 10.697
- TypeScript
- GitHub Trending · 2026-10-04

## Was es bringt
- Sie können Präsentationen oder kleine persönliche Anwendungen erstellen, indem Sie KI-Agenten Befehle erteilen.
- Sie können Sicherheitslecks verhindern, indem Sie die erstellten Anwendungen in isolierten Umgebungen ausführen.
- Dank der Sicherheitsebene können Sie die von den Agenten ausgeführten Aktionen überwachen und genehmigen.
