# Generieren Sie hochwertige 3D-Modelle aus Bildern

TRELLIS wurde von Microsoft entwickelt und ist eine strukturierte latente Darstellungsarchitektur, die Text oder visuelle Eingaben in dreidimensionale (3D) Modelle umwandelt. Diese Technologie nutzt generative KI-Methoden, um schnell und kompakt hochwertige 3D-Assets zu erstellen.

- ★ 11.002
- Python
- GitHub Trending · 2026-08-02

## Was es bringt
- Erstellt detaillierte und strukturierte 3D-Assets aus einem einzigen Bild.
- Es bearbeitet erfolgreich komplexe Strukturen und offene Flächen.
- Es liefert realistische Ergebnisse mit PBR, physikbasierten Visualisierungsmaterialien.

## Installation
**Klonen Sie das Repository**

```
git clone -b main https://github.com/microsoft/TRELLIS.2.git --recursive
    cd TRELLIS.2
```

**Abhängigkeiten installieren**

```
. ./setup.sh --new-env --basic --flash-attn --nvdiffrast --nvdiffrec --cumesh --o-voxel --flexgemm
```
