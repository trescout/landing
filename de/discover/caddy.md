# Richten Sie einen automatischen HTTPS-Server ein

Caddy ist ein in Go geschriebener, erweiterbarer Webserver, der eine automatische HTTPS-Zertifikatsverwaltung bietet. Er vereinfacht die Einrichtung und Sicherheit von Websites durch die Unterstützung der Protokolle HTTP/1, HTTP/2 und HTTP/3.

## Was es bringt

- Bietet standardmäßig automatische HTTPS-Zertifikatsverwaltung
- Unterstützt die Protokolle HTTP/1, HTTP/2 und HTTP/3
- Läuft überall ohne externe Abhängigkeiten

## Ausführung

**Zusammenstellung**

```
git clone "https://github.com/caddyserver/caddy.git"
cd caddy/cmd/caddy/
go build
```
