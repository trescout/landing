# OpenMAIC

OpenMAIC ist eine immersive Lernplattform, die mehrere KI-Agenteninteraktionen mit einem einzigen Klick simuliert. Dieses mit TypeScript entwickelte Open-Source-Tool ermöglicht Benutzern das Erleben einer interaktiven Unterrichtsumgebung mit verschiedenen Agentenmodellen.
