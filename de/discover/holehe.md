# Finden Sie registrierte Konten per E-Mail

Holehe ist ein Python-Tool, das abfragt, ob eine eingegebene E-Mail-Adresse auf beliebten Plattformen wie Twitter und Instagram verwendet wird. Es erkennt die mit der entsprechenden E-Mail verknüpften Kontoinformationen mithilfe von Funktionen zum Zurücksetzen des Passworts.

## Was es bringt

- E-Mail-Abfrage auf mehr als 120 Plattformen
- Es werden keine Benachrichtigungen an die Ziel-E-Mail-Adresse gesendet
- Mit Passwort-Reset-Funktionen erkannt

## Installation

**Installation mit PyPI**

```
pip3 install holehe
```

**Installation über GitHub**

```
git clone https://github.com/megadose/holehe.git
cd holehe/
python3 setup.py install
```

## Ausführung

**E-Mail-Anfrage**

```
holehe test@gmail.com
```
