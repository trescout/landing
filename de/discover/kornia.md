# Computer Vision für Künstliche Intelligenz

Kornia ist eine differenzierbare Computer-Vision-Bibliothek, die für räumliche KI-Anwendungen (Spatial AI) entwickelt wurde. Dieses Tool, das auf dem Deep-Learning-Framework PyTorch läuft, ermöglicht die Integration von Bildverarbeitungs- und geometrischen Vision-Algorithmen in KI-Workflows.

## Was es bringt

- Beschleunigt Prozesse, indem Bildverarbeitung und geometrische Berechnungen auf der Grafikkarte (GPU) ausgeführt werden.
- Dank seiner differenzierbaren Struktur lässt es sich direkt in das Modeltraining einbinden, das mit dem Deep-Learning-Framework PyTorch erstellt wurde.
- Bietet Datenaugmentierung, Kantenerkennung und vorgefertigte visuelle Analysemodelle unter einem Dach.
