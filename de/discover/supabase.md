# Open-Source-Datenbank und Backend

Supabase ist eine Open-Source-Alternative zu Firebase, die auf PostgreSQL basiert. Es bietet Echtzeit-Dienste.

- ★ 107.669
- GitHub Trending · 2026-07-04

## Was macht dieses Werkzeug?
Supabase ist ein Open-Source-Backend-Dienst, der auf PostgreSQL basiert. Er bietet Funktionen wie Echtzeit-Datenbank-Abonnements, Authentifizierung, Speicher und Edge-Funktionen direkt einsatzbereit an.

## Für wen ist es?
Für diejenigen, die den Backend-Entwicklungsprozess beschleunigen und sich direkt auf ihre Produkte konzentrieren möchten, ohne auf die Leistungsfähigkeit einer relationalen Datenbank zu verzichten.

## Was Sie nicht erwarten sollten
Entwickler, die ausschließlich dokumentenbasierte Datenbanken benötigen oder die Verwendung von SQL vollständig vermeiden möchten.

## Höhepunkte
- Stellt für jedes Projekt eine vollwertige, standardmäßige PostgreSQL-Datenbank bereit.
- Unterstützt Echtzeit-Datensynchronisation direkt nach dem Auspacken.
- Kann auf dem eigenen Server oder als verwalteter Cloud-Dienst genutzt werden.

## Ablauf für die erste Nutzung
- Erstellen Sie ein neues Projekt über das Supabase-Dashboard oder in Ihrer lokalen Umgebung.
- Erstellen Sie Ihre Tabellen und konfigurieren Sie die Sicherheitsrichtlinien.
- Installieren Sie die offizielle Client-Bibliothek für die Sprache, die Sie in Ihrem Projekt verwenden werden.
- Fügen Sie Ihre API-Schlüssel zu Ihrer Anwendung hinzu und führen Sie Ihre erste Datenbankabfrage aus.

## Installation
**macOS (Homebrew)**

```
brew install supabase/tap/supabase
```

**Als Entwicklungsabhängigkeit mit npm hinzufügen**

```
npm install -D supabase
```


## Ausführung
**Starten Sie die lokale Supabase-Entwicklungsumgebung**

```
supabase init
supabase start
```
