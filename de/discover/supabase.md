# Open-Source-Postgres-Entwicklungsplattform

Supabase ist eine Entwicklungsplattform, die eine Postgres-Datenbankinfrastruktur zur Entwicklung von Web-, Mobil- und künstlichen Intelligenzanwendungen bietet. Mit seiner Open-Source-Struktur bietet es Datenbankverwaltungs- und Backend-Dienste, die zur Beschleunigung von Anwendungsentwicklungsprozessen erforderlich sind.

## Was es bringt

- Bietet eine vorgefertigte Postgres-Datenbankinfrastruktur
- Bietet automatische API und Authentifizierung
- Beinhaltet künstliche Intelligenz und Vektorunterstützung

## Installation

**macOS (Homebrew)**

```
brew install supabase/tap/supabase
```

**Als Entwicklungsabhängigkeit mit npm hinzufügen**

```
npm install -D supabase
```

## Ausführung

**Starten Sie die lokale Supabase-Entwicklungsumgebung**

```
supabase init
supabase start
```
