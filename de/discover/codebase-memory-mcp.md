# Schnelle Indizierung für KI-Codierungsagenten

Codebase-memory-mcp bietet leistungsstarke Code-Intelligenz, indem es Codebasen in einen permanenten Wissensgraphen umwandelt. Das in C-Sprache entwickelte Tool unterstützt 158 ​​Programmiersprachen, reduziert die Abfragezeiten auf unter Millisekunden und reduziert die Token-Nutzung.

## Was es bringt
- Konvertiert die Codebasis in Millisekunden in einen Wissensgraphen
- Unterstützt nativ 158 Programmiersprachen
- Reduziert den Münzverbrauch um das bis zu 120-fache

## Installation
**macOS- und Linux-Installation**

```
curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | bash
```

**Installation über visuelle Schnittstelle**

```
curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | bash -s -- --ui
```


## Ausführung
**Starten der visuellen Schnittstelle**

```
codebase-memory-mcp --ui=true --port=9749
```
