# Hochleistungs-Webserver und Reverse-Proxy

Das Open-Source-Repository NGINX wird in C als leistungsstarker Webserver und Reverse-Proxy weiterentwickelt. Die Software bietet eine Standardlösung in großen Infrastrukturen zur Verwaltung des Netzwerkverkehrs und zur Optimierung der Inhaltsverteilung.

## Was es bringt
- Hochleistungs-Webserver- und Reverse-Proxy-Verwaltung.
- Erweiterte Lastausgleichs- und Inhalts-Caching-Funktionen.
- Flexible und skalierbare Infrastrukturinstallation dank modularem Aufbau.

## Installation
**Abhängigkeiten installieren**

```
sudo apt install gcc make
```

**Installation der erforderlichen Bibliotheken**

```
sudo apt install libpcre3-dev zlib1g-dev
```


## Ausführung
**Statische Modulsteuerung**

```
nginx -V
```
