# Mobilgeräte-Automatisierung mit künstlicher Intelligenz

Mobile-mcp ist ein Model Context Protocol (Modell-Kontext-Protokoll)-Server, der Automatisierung und Datenextraktion auf Mobilgeräten und Simulatoren durchführt. Dieses Tool ermöglicht es KI-Modellen, direkt mit iOS- und Android-Plattformen zu interagieren, um Aufgaben auszuführen.

- ★ 8.549
- TypeScript
- GitHub Trending · 2026-09-27

## Was es bringt
- App-Tests auf iOS- und Android-Geräten durchführen
- Bildschirmelemente automatisch scannen und strukturierte Daten extrahieren
- Emulatoren und Simulatoren über eine einzige Benutzeroberfläche verwalten

## Installation
**Installation mit Claude**

```
claude mcp add mobile-mcp -- npx -y @mobilenext/mobile-mcp@latest
```

**Direkte Ausführung**

```
npx @mobilenext/mobile-mcp@latest
```


## Ausführung
**Server starten**

```
npx @mobilenext/mobile-mcp@latest
```


## Wenn Sie nicht programmieren
Verwende den Model-Kontext-Protokoll-Server (Model Context Protocol), der mit den mobilen Entwicklungstools auf meinem Computer kommuniziert, um die Apps auf den verbundenen Mobilgeräten aufzulisten und die Elemente auf dem Bildschirm zu scannen.
