# Erstellen Sie Ihre eigenen Technologien von Grund auf

„Build Your Own“ ist eine Sammlung von Schritt-für-Schritt-Anleitungen, mit denen Sie Ihre bevorzugten Technologien wie Datenbank, Betriebssystem, Git, Docker und Programmiersprache von Grund auf neu schreiben können. Es bietet eine Lernerfahrung durch praktisches Handeln im Einklang mit Feynmans Philosophie „Ich kann nicht verstehen, was ich nicht erschaffen kann“.

**Hinweis von TreScout:** Das Lern-Repository ist kein zu installierendes Tool: Es sammelt Tutorials zum Schreiben Ihrer eigenen Datenbank, Shell oder Git von Grund auf. Dies ist der effizienteste Weg, wenn Sie eine Technologie wirklich verstehen möchten, aber es ist kein zweistündiger Job am Abend – jede Anleitung dauert Tage.
