# Sicherer Dateiaustausch zwischen Geräten

LocalSend ist eine Open-Source-Anwendung, die die gemeinsame Nutzung von Dateien zwischen verschiedenen Betriebssystemen ermöglicht. Es schafft eine plattformunabhängige Alternative zur AirDrop-Funktion von Apple-Geräten.

- ★ 88.401
- Dart
- GitHub Trending · 2026-08-13

## Was es bringt
- Schnelle Dateiübertragung ohne Internetverbindung
- Nahtlose Kommunikation zwischen verschiedenen Betriebssystemen
- Sichere Datenübertragung mit HTTPS-Verschlüsselung
