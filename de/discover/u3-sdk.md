# Passen Sie das Unturned-Spiel an

SmartlyDressedGames hat das U3-SDK-Softwareentwicklungskit, das für das Open-World-Zombie-Überlebensspiel Unturned entwickelt wurde, als Open Source bereitgestellt. Diese in C#-Sprache erstellten Quellcodes ermöglichen es Community-Mitgliedern, das Spiel anzupassen und weiterzuentwickeln.

## Was es bringt
- Bietet Zugriff auf die Quellcodes des Spiels
- Ermöglicht Ihnen, Ihre eigenen Inhalte und Mods zu entwickeln
- Sie können gemeinschaftsorientierte Spielgestaltungen treffen

## So fangen Sie an
- Offizielle Quelle →
Laden Sie das Projekt herunter oder kopieren Sie es auf Ihren Computer. Installieren Sie dann die angegebene Unity 2022.3.62f3-Version über Unity Hub und stellen Sie sicher, dass das Unturned-Spiel auf Steam installiert ist. Abschließend können Sie das Projekt starten, indem Sie es mit dem Unity-Editor öffnen und zur Szene „Assets/GameStartup.unity“ wechseln.
