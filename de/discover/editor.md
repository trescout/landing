# Webbasierter 3D-Architektureditor

Der auf TypeScript basierende Pascalorg/Editor ermöglicht Benutzern das Erstellen und Teilen dreidimensionaler Architekturprojekte über den Browser. Ziel der Software ist es, architektonische Entwurfsprozesse über eine webbasierte Schnittstelle zugänglich zu machen.

## Was es bringt

- 3D-Architekturmodellierung mit React Three Fiber
- Hochleistungsvisualisierung mit WebGPU-Unterstützung
- Zustandsbasiertes zentrales Phasen- und Statusmanagement

## Installation

**Installieren Sie die erforderlichen Pakete**

```
npm install @pascal-app/core @pascal-app/viewer @pascal-app/editor @pascal-app/nodes
```

## Ausführung

**Starten Sie den Entwicklungsserver**

```
bun dev
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich möchte mit dem Pascal Editor eine Architekturszene erstellen. Helfen Sie mir, eine grundlegende 3D-Struktur mit den in der Projektarchitektur enthaltenen Paketen @pascal-app/core und @pascal-app/viewer zu erstellen. Führen Sie mich Schritt für Schritt durch die Konfiguration der useScene- und useViewer-Hooks, um den Szenenstatus zu verwalten, die Knotenhierarchie (Standort, Gebäude, Ebene) zu definieren und eine NodeRenderer-Komponente in die Szene zu integrieren.
