# Analysieren Sie Ihre Dokumente schnell mit Rust

Liteparse (run-lama); ist ein in Rust geschriebener Open-Source-Dokumentparser zum schnellen und effizienten Parsen von Dokumenten. Es erleichtert KI- und RAG-Prozesse, indem es komplexe Dokumentenstrukturen verarbeitbar macht.

- ★ 12.210
- Rust
- Apache-2.0
- GitHub Trending · 30 May 2026

## Was es bringt
- Bietet schnelles und effizientes Parsen von Dokumenten.
- Es macht komplexe Strukturen bearbeitbar.
- Vollständig kompatibel mit AI- und RAG-Pipelines.

## Installation
**Mit pip (PyPI)**

```
pip install liteparse
```


## Wie installiere ich, wie verwende ich?
Installieren Sie das PDF-Parsing-Tool LiteParse mit „pip install liteparse“, extrahieren Sie dann den Text einer PDF-Datei mit dem Befehl „lit parse document.pdf“ oder speichern Sie ihn als strukturiertes JSON mit Begrenzungsrahmen mit „lit parse document.pdf --format json -o output.json“.
