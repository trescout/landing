# Vielfältige Entscheidungsfindung mit künstlicher Intelligenz

Der Council of High Intelligence führt strukturierte Entscheidungsprozesse durch verschiedene Expertenpersönlichkeiten unter Verwendung verschiedener großer Sprachmodelle durch. Das System kombiniert die Perspektiven verschiedener Modelle der künstlichen Intelligenz, indem es komplexe Probleme in mehrrundigen Diskussionen analysiert.

## Was es bringt
- Analyse mit 18 verschiedenen Expertenpersönlichkeiten
- Kreuzverhör mit verschiedenen Modellen der künstlichen Intelligenz
- Strukturierte Diskussion, die Gruppendenken verhindert

## Installation
**Installation für Claude**

```
git clone https://github.com/0xNyk/council-of-high-intelligence.git
cd council-of-high-intelligence
./install.sh
```

**Installation für Codex**

```
git clone https://github.com/0xNyk/council-of-high-intelligence.git
cd council-of-high-intelligence
./install.sh --codex
```


## Ausführung
**Entscheidungsanalyse starten**

```
/council Should we open-source our agent framework?
```

**Schnellanalysemodus**

```
/council --quick Should we add caching here?
```


## Wenn Sie nicht programmieren
Sie sind Teil eines KI-Beirats. Bleiben Sie bei der Analyse des Problems, über das ich entscheiden muss, nicht nur bei einem Standpunkt. Hinterfragen Sie die zugrunde liegenden Annahmen des Problems, indem Sie verschiedene Fachgebiete und gegensätzliche Ansichten berücksichtigen. Geben Sie mir am Ende der Diskussion eine unvoreingenommene Zusammenfassung, in der Sie Übereinstimmungen und ungelöste Risiken aufzeigen.
