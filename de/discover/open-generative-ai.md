# Unbeschränktes Bild- und Videostudio mit künstlicher Intelligenz

Open-Generative-AI ist eine Open-Source-Studioplattform ohne Inhaltsfilterung und mit mehr als 200 visuellen und Videoerstellungsmodellen. Benutzer können ihre visuellen Produktionsprozesse frei verwalten, indem sie diese unter der MIT-Lizenz angebotene Software auf ihren eigenen Servern (selbst gehostet) ausführen.

## Was es bringt
- Mehr als 200 fortschrittliche KI-Modelle
- Keine Inhaltsfilter oder Abonnementgebühren
- Möglichkeit, am eigenen Computer zu arbeiten

## Ausführung
**Starten Sie die Desktop-App**

```
npm run electron:dev
```


## Wenn Sie nicht programmieren
Mit der Open-Generative-AI-Plattform möchte ich qualitativ hochwertige Bilder und Videos erstellen, ohne in Inhaltsfiltern hängen zu bleiben. Wie kann ich aus den über 200 auf der Plattform angebotenen Modellen die für meine kreativen Projekte am besten geeigneten auswählen und mit den kostenlosen Produktionsmöglichkeiten dieser Modelle einen professionellen Workflow in meinem eigenen lokalen System aufbauen?
