# Videoanalyse mit künstlicher Intelligenz

Claude-video ist ein Python-Tool, das dem Claude-Modell die Möglichkeit gibt, Videoinhalte zu analysieren. Indem die Software Videos herunterlädt, in Frames unterteilt und in Text umwandelt (Transkription), bringt die Software die visuellen Daten in ein Format, das das Modell der künstlichen Intelligenz verarbeiten kann.

## Was es bringt
- Analysiert Videos Bild für Bild
- Erstellt automatisch Untertitel und Transkripte
- Verarbeitet lokale oder Online-Videos

## Installation
**Allgemeine Installation**

```
npx skills add bradautomates/claude-video -g
```


## Ausführung
**Videoanalyse starten**

```
/watch https://youtu.be/dQw4w9WgXcQ what happens at the 30 second mark?
```


## Wenn Sie nicht programmieren
Ich möchte, dass Sie das von mir geteilte Video mit dem Claude Video-Tool analysieren. Beantworten Sie den Inhalt des Videos, seine wichtigen Momente und die Fragen, die ich stelle, basierend auf den visuellen Frames im Video und dem Audiotranskript. Wenn das Video keinen Untertitel enthält, konvertieren Sie den Ton mithilfe der Whisper-API in Text und analysieren Sie ihn, indem Sie die visuellen Details (Frames) untersuchen.
