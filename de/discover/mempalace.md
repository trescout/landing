# Fügen Sie Speicher zu KI-Modellen hinzu

MemPalace bietet ein Open-Source-Speichersystem für Modelle der künstlichen Intelligenz. Das System umfasst optimierte Tools zur Messung und Verbesserung der kontextuellen Speicherleistung großer Sprachmodelle.

- ★ 58.311
- Python
- GitHub Trending · 2026-06-06

## Was es bringt
- Es bietet eine semantische Suche, indem der Gesprächsverlauf unverändert bleibt.
- Durch die Kategorisierung von Personen, Projekten und Themen entsteht eine organisierte Gedächtnisstruktur.
- Durch sein lokales Wirkprinzip ermöglicht es die Verarbeitung von Daten, ohne Ihre Maschine zu verlassen.

## Installation
**Installation mit UV**

```
uv tool install mempalace
mempalace init ~/projects/myapp
```

**Installation mit virtueller Umgebung**

```
python -m venv .venv && source .venv/bin/activate
pip install mempalace
```
