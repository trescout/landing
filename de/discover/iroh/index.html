Entdecken · GitHub · Iroh

Switchbasierte flexible Netzwerkverbindungen

Iroh ist ein modularer Netzwerk-Stack, der Netzwerkverbindungen flexibler macht, indem er schlüsselbasierte Adressierung anstelle von IP-Adressen verwendet. Dieses mit der Rust-Sprache entwickelte Tool bietet eine Infrastruktur, die gegen Netzwerkunterbrechungen resistent ist und eine direkte Datenübertragung ermöglicht.

Was es bringt

  • Verbindung über öffentlichen Schlüssel statt über IP-Adressen
  • Automatische Lochung zur direkten Datenübertragung
  • QUIC-basierte sichere und verschlüsselte Kommunikation

Installation

Mit Cargo (zum Rust-Projekt hinzufügen)
cargo add iroh
Installieren Sie das iroh CLI-Tool
cargo install iroh

Ausführung

Knoten-ID anzeigen (CLI)
iroh node id

Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ich möchte mithilfe der Iroh-Bibliothek eine Switch-basierte Netzwerkverbindung einrichten. Können Sie eine einfache Beispielcodestruktur erstellen, die zeigt, wie ich einen Endpunkt in Rust erstellen, über einen öffentlichen Schlüssel eine Verbindung zu einem anderen Endpunkt herstellen und einen sicheren Datenfluss mit dem QUIC-Protokoll initiieren kann?
