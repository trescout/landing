# Prompt-Bibliothek für KI-Modelle

Prompts.chat ist eine Open-Source-Plattform, auf der Benutzer Prompts für KI-Modelle teilen und entdecken können. Dieses Tool, das Sie für die unternehmerische Nutzung auf Ihrem eigenen Server hosten können, ermöglicht es Ihnen, Prompt-Bibliotheken datenschutzorientiert zu verwalten.

## Was es bringt
- Umfangreiches Prompt-Archiv, kompatibel mit modernen KI-Modellen
- Möglichkeit zum Self-Hosting für unternehmerische Anforderungen
- Kostenloses interaktives Lehrbuch über Prompt Engineering

## Installation
**Schnellstart**

```
npx prompts.chat new my-prompt-library
cd my-prompt-library
```

**Manuelle Installation**

```
git clone https://github.com/f/prompts.chat.git
cd prompts.chat
npm install && npm run setup
```


## Ausführung
**Befehlszeilenschnittstelle starten**

```
npx prompts.chat
```


## Wenn Sie nicht programmieren
Du bist ein KI-Experte. Nutze die Techniken aus der prompts.chat-Bibliothek, um die für die Ziele des Benutzers am besten geeigneten Prompts zu erstellen. Zerlege komplexe Aufgaben in Teilaufgaben, wende die Methode des schrittweisen Denkens an und liefere den notwendigen Kontext, damit das Modell das beste Ergebnis erzielen kann.
