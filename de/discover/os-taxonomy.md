# Verbindungskarte der Grundschul-L Lerninhalte

withmarbleapp/os-taxonomy ist eine in JavaScript entwickelte Bibliothek zur Organisation von Betriebssystem-Klassifikationen. Sie ermöglicht es Softwareentwicklern, verschiedene Betriebssystemdaten in einer Standardstruktur zu definieren.

- ★ 6.389
- JavaScript
- GitHub Trending · 2026-10-20

## Was es bringt

- Untersuchen Sie über 1.500 Mikrothemen auf Grundschulniveau anhand von Altersgruppen und Leistungskriterien.
- Erstellen Sie schrittweise Lernpfade, indem Sie über 3.200 Vorkenntnisbeziehungen zwischen den Themen verfolgen.
- Erhalten Sie direkten Zugriff auf pädagogische Ansätze in den Bereichen Naturwissenschaften und Mathematik sowie auf beispielhafte Aktivitäten im Klassenzimmer.

## Ausführung

**Datenvalidierung und Ausführung von Tests**

```
node scripts/validate.mjs
node --test scripts/teaching-research.test.mjs
```
