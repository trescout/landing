# Orchestrierungswerkzeug für KI-Agenten

Ax, entwickelt von Google, ist eine Open-Source-Orchestrierungs-Runtime für KI-Agenten. Diese in Go geschriebene Infrastruktur erleichtert die Verwaltung und Ausführung komplexer agentenbasierter Workflows.

## Was es bringt

- Ermöglicht Ihnen die Verwaltung von Milliarden autonomer KI-Arbeitslasten.
- Ermöglicht die Ausführung von Agenten in einer sicheren und isolierten Sandbox-Umgebung.
- Bietet eine schnelle und deklarative Konfiguration mit YAML-Dateien.

## Installation

**CLI-Tool installieren**

```
go install github.com/google/ax/cmd/ax@latest
```

**Steuerungsebene bereitstellen**

```
make deploy AX_IMAGE_REPO=<your-registry>
```
