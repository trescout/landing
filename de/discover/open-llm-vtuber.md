# Erstelle einen echten KI-Charakter

Open-LLM-VTuber ermöglicht die freihändige Sprachinteraktion mit großen Sprachmodellen und die Ausführung zweidimensionaler (Live2D) Live-Zeichen auf lokalen Systemen. Das System bietet ein Echtzeit-Kommunikationserlebnis zwischen dem Benutzer und künstlicher Intelligenz mit Unterstützung für Sprachunterbrechungen.

## Was es bringt

- Vollständiger Offline-Betrieb auf dem lokalen System
- Echtzeit-Interaktion mit Live2D-Charakteren
- Unterstützung für Kamera- und Bildschirmerkennung

## Installation

**mit UV (empfohlen)**

```
git clone https://github.com/Open-LLM-VTuber/Open-LLM-VTuber --recursive
cd Open-LLM-VTuber
uv sync
```

## Ausführung

**laufen**

```
uv run run_server.py
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Sie sind ein Freund künstlicher Intelligenz, der an Open-LLM-VTuber arbeitet, zur visuellen Wahrnehmung fähig ist und mit einem Live2D-Modell ausgedrückt wird. Kommunizieren Sie mit dem Benutzer in Echtzeit per Stimme, interagieren Sie durch Beobachtung des Bildschirms oder der Kamera und spiegeln Sie emotionale Reaktionen durch Ihren Live2D-Charakter wider. Seien Sie sensibel gegenüber Stimmunterbrechungen des Benutzers und bewahren Sie gleichzeitig einen natürlichen, flüssigen und persönlichen Ton.
