# Terminalorientierte KI-Entwicklungsumgebung

Terax-ai fällt als terminalorientierte lokale Entwicklungsumgebung für künstliche Intelligenz (AI-native Dev Workspace) durch seine geringe Größenstruktur von 7 Megabyte auf. Dieses mit TypeScript entwickelte Tool bietet Entwicklern die Möglichkeit, direkt über das Terminal mit künstlicher Intelligenz zu programmieren.

## Was es bringt
- Leichte und schnelle Struktur mit einer Größe von 7-8 MB
- KI-Integration mit nativen Modellen und API-Unterstützung
- GPU-beschleunigter Terminal- und Code-Editor

## Installation
**Starten der Entwicklungsumgebung**

```
pnpm install
pnpm tauri dev          # development
```


## Wenn Sie nicht programmieren
Erstellen Sie mit dem Bedienfeld für künstliche Intelligenz in Terax projektspezifische Systemansagen und verwalten Sie den Projektspeicher über die Datei TERAX.md. Akzeptieren oder lehnen Sie KI-gestützte Unterschiede für Codebearbeitungen ab und führen Sie mehrstufige Aufgaben mit Genehmigung im Planmodus aus.
