# Stable Diffusion.cpp

Stable-diffusion.cpp ist eine Inferenzbibliothek, die Bildgenerierungsmodelle (wie Stable Diffusion, Flux, Wan) in reinem C/C++ ausführt. Dieses Tool ermöglicht die Ausführung von Hochleistungsmodellen auf Systemen mit geringer Hardwareausstattung oder in speziellen Umgebungen ohne zusätzliche Abhängigkeiten.
