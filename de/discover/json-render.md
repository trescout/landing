# JSON Render

Das von Vercel Labs entwickelte json-render ist ein Framework zur Umwandlung von Datenstrukturen in visuelle Komponenten für generative UI-Szenarien (generative UI). Es ermöglicht Entwicklern, strukturierte Daten von KI-Modellen als dynamische und interaktive Elemente in Web-Oberflächen bereitzustellen.
