Sicherheits-Experten-Fähigkeiten für Claude

Claude-Red ist eine Bibliothek für offensive Sicherheitsfähigkeiten, die in das Fähigkeitssystem des KI-Modells Claude integriert ist. Sie zielt darauf ab, Sicherheitstests zu automatisieren, indem sie Expertenmethoden für Themen wie SQL-Injection und das Umgehen von Endpunktschutzsystemen bereitstellt.

Was es bringt

  • Ermöglicht den Zugriff auf offensive Sicherheitsmethoden
  • Verwandelt das KI-Modell in einen Penetrationstester
  • Lädt benötigte Fähigkeiten automatisch herunter

Installation

Alle Fähigkeiten herunterladen
git clone https://github.com/SnailSploit/claude-red ~/.claude/skills/claude-red
Interaktive Installation
./install.sh                           # interactive
./install.sh --target ~/.claude/skills # explicit target
./install.sh --category web            # single category

Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Ab sofort möchte ich, dass du dich wie ein Penetration-Testing-Experte verhältst. Analysiere Sicherheitslücken unter Verwendung der Methoden aus den von mir geteilten Kompetenzdateien, bewerte Angriffsflächen und leite mich bei meinen Cybersicherheitsrecherchen an.
