# Datenschutzorientierter Offline-Grammatikprüfer

Harper bietet einen Offline- und datenschutzorientierten Grammatikprüfer, der mit der Rust-Sprache entwickelt wurde. Ziel dieses Open-Source-Tools ist es, eine leistungsstarke und sichere Alternative für Textanalyseprozesse zu schaffen.

- ★ 14.110
- Rust
- GitHub Trending · 2026-07-24

## Was es bringt
- Überprüft Text schnell und in Millisekunden
- Schützt die Privatsphäre durch lokale Verarbeitung Ihrer Daten
- Bietet hohe Leistung bei geringem Speicherverbrauch

## Installation
**macOS (Homebrew)**

```
brew install harper
```
