# Stimmklonung und Synchronisation lokal durchführen

VoiceStudio ist eine Open-Source-Plattform zur Audioverarbeitung, die Aufgaben wie Stimmklonung, Synchronisation und Transkription ohne Internetverbindung ausführt. Sie bietet eine lokal ausführbare Alternative zum Sprachsynthesedienst ElevenLabs und unterstützt 646 Sprachen.

- ★ 15.411
- Python
- GitHub Trending · 2026-09-03

## Was es bringt
- Stimmklonung und Synchronisation ohne Internetverbindung durchführen
- Unterstützung für Sprachsynthese und Transkription in 646 verschiedenen Sprachen erhalten
- Volle Privatsphäre durch Speicherung Ihrer Daten auf Ihrem eigenen Computer

## Installation
**Ausführung aus dem Quellcode**

```
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun install
bun run desktop
```
