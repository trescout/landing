# Verwalten Sie Cloud-native Infrastrukturen

Meshery ist eine Service-Mesh-Managementplattform, die für die Verwaltung cloudnativer Infrastrukturen entwickelt wurde. Die Plattform ermöglicht die Durchführung von Konfigurations-, Lifecycle-Management- und Performance-Analyseprozessen in komplexen Cloud-Umgebungen aus einer Hand.

## Was es bringt

- Zentrale Verwaltung der Kubernetes-basierten Infrastruktur und Anwendungen
- Möglichkeit zur visuellen Gestaltung, ohne sich mit komplexen YAML-Dateien befassen zu müssen
- Konsistenter Betrieb über mehrere Cloud-Anbieter und Cluster hinweg

## Installation

**Bash-Skript**

```
curl -L https://meshery.io/install | bash -
```

## Ausführung

**CLI**

```
mesheryctl system start
```
