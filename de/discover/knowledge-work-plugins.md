# Expert Assistant-Erfahrung mit Claude

Dieser Open-Source-Plugin-Satz von Anthropic vereint Fähigkeiten, Konnektoren, Slash-Befehle und Subagenten für jede Geschäftsfunktion. Diese Lösung, die es Claude ermöglicht, wie ein Experte auf seinem Gebiet zu agieren, umfasst 11 vorgefertigte Plugins, die für Claude Cowork entwickelt wurden.

## Was es bringt
- Spezialisiert Claude basierend auf Ihrer Rolle (z. B. Marketing, Finanzen, Recht).
- Jedes Plugin besteht aus einer Reihe von Fähigkeiten, Konnektoren und Befehlen und ermöglicht so einen schnellen Einstieg.
- Bringen Sie Claude bei, wie Sie die Arbeit lieben und steigern Sie Ihre Produktivität.
- Sie müssen keinen Code schreiben, es läuft direkt auf Cowork.

## So fangen Sie an
Sie können es über den Plugin-Markt von Claude Cowork installieren. Die Liste der 11 Plugins und ihrer Funktionen ist in einer Tabelle im Repo enthalten. Nach der Installation beginnt Claude, sich wie ein Experte für die jeweilige Geschäftsfunktion zu verhalten.
