# Entwickeln Sie dynamische Fähigkeiten für Claude

Anthropische Fähigkeiten; Es handelt sich um die offizielle Sammlung von Fertigkeitspaketen, die Claude dynamisch lädt, um bei bestimmten Missionen bessere Leistungen zu erbringen. Diese Ordner mit Anweisungen, Skripten und Ressourcen zeigen Claude, wie man bestimmte Aufgaben erledigt.

## Was es bringt
- Bereite und formale Fähigkeiten für Claude.
- Dynamische Belastung: kommt nur bei Bedarf ins Spiel.
- Vollständig konform mit dem Agentskills-Standard.

## Installation
****

```
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
```


## Wie benutzt man?
Sie definieren den relevanten Skill als Skill für Claude (z. B. Claude Code oder Cowork); Dadurch steigert sich Ihre Leistungsfähigkeit bei Spezialaufgaben.

## Wie installiere ich, wie verwende ich?
Fügen Sie in Claude Code das Skills-Repository von Anthropic als Marktplatz mit dem Befehl „/plugin marketplace add anthropics/skills“ hinzu und installieren Sie dann Document Skills mit „/plugin install document-skills@anthropic-agent-skills“; Bitten Sie ihn dann, die entsprechende Fähigkeit einzusetzen, um beispielsweise Formularfelder aus einem PDF zu extrahieren.
