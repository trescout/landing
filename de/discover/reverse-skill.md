# Künstliche Intelligenz-Anleitung für Penetrationstests

Reverse-Skill bietet ein durch künstliche Intelligenz unterstütztes Routing-Paket für Reverse-Engineering- und Penetrationstest-Prozesse. Mit seinem Toolchain-Bootstrapping und sich selbst entwickelnden Wissensdatenbankfunktionen lässt sich Claude Code in Codierungstools wie Cursor und Cline integrieren.

## Was es bringt
- Standardisierte Arbeitsabläufe für KI-Agenten
- Automatische Werkzeugauswahl basierend auf verschiedenen Dateitypen
- Wiederholbare und nachvollziehbare Sicherheitsvorgänge

## Installation
**Laden Sie das Repository auf Ihren Computer herunter**

```
git clone https://github.com/zhaoxuya520/reverse-skill.git
```


## Wenn Sie nicht programmieren
Verwenden Sie dieses Projekt als Leitfaden für eine Penetrationstest- oder Reverse-Engineering-Aufgabe. Bevor Sie Ihre Aufgabe ausführen, lesen Sie die Anweisungen in der Datei README_AI.md, befolgen Sie die Routing-Regeln in der Datei RULES.md und starten Sie den Workflow, indem Sie über MASTER-ROUTING.md die richtige Methodik bestimmen.
