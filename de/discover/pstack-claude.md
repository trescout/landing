# Verbessern Sie die Ergebnisse von KI-Agenten

Pstack-claude ist eine Automatisierungsbibliothek, die die Kernfunktionen des Softwareentwicklungstools Cursor für verschiedene KI-Modelle und -Plattformen anpasst. Sie ermöglicht Entwicklern, komplexe KI-Agenten-Arbeitsabläufe (agentic workflows) standardisiert in verschiedenen Arbeitsumgebungen auszuführen.

## Was es bringt

- hält Ihren Code kurz, einfach und verifiziert
- angepasst für verschiedene KI-Modelle und -Plattformen
- läuft lokal und hat keinen Server oder Telemetrie

## So fangen Sie an

Sie können beginnen, indem Sie die entsprechenden Plugin-Befehle über Ihre Plattform Claude Code, Codex oder Pi ausführen. Detaillierte Schritte zur gemeinsamen Einrichtung finden Sie in der Dokumentation.
