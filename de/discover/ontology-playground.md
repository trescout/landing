# Entwerfen Sie KI-Ontologien mit Ontology-Playground

Ontology-Playground wurde von Microsoft entwickelt und ist eine Open-Source-Webanwendung zum Erlernen von Ontologien und zum Erstellen visueller Designs auf Microsoft Fabric IQ. Mit diesem vollständig statischen Tool können Benutzer Ontologiemodelle entwerfen, sie im RDF/XML-Format exportieren und interaktive Diagramme teilen.

- ★ 1.806
- TypeScript
- GitHub Trending · 2026-07-21

## Was es bringt
- Erstellen Sie Ontologiemodelle mit visueller Schnittstelle
- Export in das RDF/XML-Format
- Erkunden Sie Daten mit interaktiven Diagrammen

## Installation
**Installieren des Projekts in einer lokalen Umgebung**

```
cd Ontology-Playground
npm install
```

**Starten des Entwicklungsservers**

```
npm run dev
```


## Wenn Sie nicht programmieren
Ich möchte eine Ontologie mit Ontology-Playground entwerfen. Laden Sie die Startervorlage, indem Sie ein Feld wie Einzelhandel, Gesundheitswesen oder Finanzen auswählen. Fügen Sie dieser Vorlage dann neue Entitätstypen hinzu, definieren Sie die Beziehungen zwischen ihnen und zeigen Sie mir die Schritte, die ich zum Exportieren dieses von mir erstellten Modells im RDF/XML-Format benötige.
