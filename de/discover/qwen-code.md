# KI-Codierungsagent

QwenLM/qwen-code ist ein Open-Source-KI-Codierungsagent, der im Terminal, in Editoren, auf dem Desktop und im Browser läuft. Dieses in TypeScript entwickelte Tool zielt darauf ab, Softwareentwicklungsprozesse auf verschiedenen Plattformen zu unterstützen.

## Was es bringt

- Ermöglicht das Programmieren im Terminal, auf dem Desktop, im Browser und in Editoren
- Bietet dynamische Arbeitsabläufe mit automatischem Speicher, Fähigkeiten und Unteragenten
- Nutzt verschiedene KI-Dienste und lokale Modelle durch Multi-Protokoll-Unterstützung

## Installation

**Installation mit NPM**

```
npm install -g @qwen-code/qwen-code@latest
```

**Installation mit Homebrew**

```
brew install qwen-code
```

## Ausführung

**Starten**

```
qwen
```
