# Führen Sie lokale KI-Modelle auf Ihrem Computer aus

Magnitude ist ein Open-Source-Inferenzserver, der mit bestehenden KI-Agenten integriert wird und es Ihnen ermöglicht, lokale Modelle auszuführen, die für Ihre Hardware optimiert sind. Er lässt sich nahtlos mit Coding-Assistenten wie Cline und verschiedenen Open-Source-Modellen kombinieren, um die Nutzung lokaler Rechenleistung zu erleichtern.

- ★ 3.348
- TypeScript
- GitHub Trending · 2026-09-04

## Was es bringt
- Ermittelt automatisch die am besten geeigneten lokalen Modelle für Ihre Hardware
- Funktioniert vollständig offline ohne Internetverbindung
- Eliminiert Token-Kosten durch Integration mit KI-Assistenten

## Installation
**Installieren Sie das CLI-Tool und starten Sie die Einrichtung**

```
npm i -g @magnitudedev/cli
magnitude setup
```


## Wenn Sie nicht programmieren
Richten Sie lokale Modelle für mich mit dem Magnitude CLI ein. Installieren Sie es mit `npm i -g @magnitudedev/cli` (oder meinem Paketmanager), führen Sie dann `magnitude docs onboarding` aus und folgen Sie den Anweisungen.
