# Schnelle Laufzeit für JavaScript-Projekte

Bun ist ein Hochleistungstool, das JavaScript-Laufzeit, Paketmanager, Testläufer und Packager unter einem Dach vereint. Diese mit der Rust-Sprache entwickelte Plattform bietet eine integrierte Infrastruktur zur Beschleunigung von Softwareentwicklungsprozessen.

## Was es bringt

- Schnelle Laufzeit, kompatibel mit Node.js
- Paketmanager und Testtool unter einem Dach
- Geringe Speichernutzung und schneller Start

## Installation

**Installation per Installationsskript**

```
curl -fsSL https://bun.com/install | bash
```

**Installation unter Windows**

```
powershell -c "irm bun.sh/install.ps1 | iex"
```

## Ausführung

**Paketinstallation**

```
bun install <pkg>
```

**Dateiausführung**

```
bun run index.tsx
```
