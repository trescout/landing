# Erweiterter YouTube-Client für Android TV

SmartTube ist ein für Android TV-Geräte entwickelter YouTube-Client, der erweiterte Funktionen wie Werbeblockierung und eine anpassbare Benutzeroberfläche bietet. Er ermöglicht es Benutzern, ihr Videoerlebnis nach ihren eigenen Regeln zu gestalten.

## Was es bringt

- Werbefreies und anpassbares Videoerlebnis
- Überspringen von gesponserten Inhalten in Videos mit SponsorBlock
- Unabhängige Arbeitsweise, die keine Google-Dienste erfordert

## So fangen Sie an

Installieren Sie die Downloader-App auf Ihrem Android TV-Gerät. Öffnen Sie die App, geben Sie kutt.to/stn_beta für die Beta-Version oder kutt.to/stn_stable für die stabile Version ein und schließen Sie die Installation ab, indem Sie die Sicherheitsbestätigungen auf dem Bildschirm befolgen.
