# Skalierbare Datenbank für verteilte Systeme

Apache Cassandra ist eine verteilte Open-Source-Transaktionsdatenbank, die lineare Skalierbarkeit und Fehlertoleranz bietet, ohne dass es zu Leistungseinbußen auf Standardhardware oder Cloud-Infrastrukturen kommt. Dieses in der Java-Sprache entwickelte System ist für umfangreiche Datenverwaltungsprozesse konzipiert, die eine hohe Verfügbarkeit erfordern.

- ★ 10.004
- Java
- GitHub Trending · 2026-07-28

## Was es bringt

- Verteilt Daten automatisch auf mehrere Maschinen.
- Einfache Datenverwaltung mit SQL-ähnlicher CQL-Abfragesprache.
- Bietet hohe Verfügbarkeit und Fehlertoleranz.

## Installation

**macOS (Homebrew)**

```
brew install cassandra
```

**Docker-Image**

```
docker pull cassandra
```

## Ausführung

**Mit Docker starten**

```
docker run -p 9042:9042 cassandra
```
