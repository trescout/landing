# KI-Integration für TradingView

TradingView-mcp verbindet Claude Code mit der TradingView-Desktopanwendung und ermöglicht Ihnen so die Automatisierung von Diagrammanalyseprozessen. Diese Integration ermöglicht es Benutzern, technische Analyse-Workflows durch KI-gestützten Modellkontext (Model Context Protocol) zu personalisieren.

- ★ 5.932
- JavaScript
- GitHub Trending · 2026-07-22

## Was es bringt
- Pine Script-Codierung und Debugging mit künstlicher Intelligenz
- Automatische Zeichnungs- und Analyseverwaltung im Diagramm
- Steuern Sie Preisalarme und Symbole per Befehl

## Installation
**Herunterladen von Dateien und Installation**

```
git clone https://github.com/tradesdontlie/tradingview-mcp.git
cd tradingview-mcp
npm install
```

**Start unter macOS**

```
./scripts/launch_tv_debug_mac.sh
```


## Ausführung
**Direkte Nutzung über CLI**

```
# Install globally (optional)
npm link

# Or run directly
node src/cli/index.js <command>
```


## Wenn Sie nicht programmieren
Sie haben sich mit meiner TradingView-Desktopanwendung verbunden. Wenn ich nun möchte, dass Sie eine technische Analyse des Diagramms durchführen, Pine-Script-Codes überprüfen oder Diagrammeinstellungen ändern, möchte ich, dass Sie mit diesem Tool in die TradingView-Oberfläche eingreifen. Bitte führen Sie die erforderlichen Befehle aus, um Diagrammdaten zu lesen, Indikatorwerte zu analysieren oder neue Diagramme hinzuzufügen.
