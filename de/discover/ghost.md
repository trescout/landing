## Installation

**Installieren Sie das Befehlszeilentool**

```
npm install ghost-cli -g
```

## Ausführung

**Starten Sie die lokale Installation**

```
ghost install local
```

**Starten Sie die Installation auf dem Server**

```
ghost install
```
