# Digitale E-Book-Bibliothek in verschiedenen Kategorien

jbiaojerry/ebook-treasure-chest ist ein digitales Bibliotheksprojekt, das E-Book-Download-Links aus verschiedenen Kategorien zusammenführt. Das Projekt zielt darauf ab, den Zugriff auf Inhalte in beliebten Lese-Apps (帆书, 微信读书, 京东读书, 喜马拉雅) zu ermöglichen.

## Was es bringt

- Sie erhalten einen zentralen Zugriff auf Download-Links für Tausende von E-Books.
- Sie können Bücher in drei verschiedenen Formatoptionen wie epub, mobi und azw3 herunterladen.
- Dank der Suchoberfläche können Sie Werke sofort nach Titel, Autor oder Kategorie finden.

## So fangen Sie an

Sie benötigen keine Befehlszeile, um das Projekt zu nutzen. Sie können die offizielle Webseite auf der Code-Hosting-Plattform GitHub besuchen und den Buchtitel oder Autor in das Suchfeld eingeben. Wenn Sie möchten, können Sie die Kategoriedateien durchsuchen, um auf den Download-Link des gewünschten E-Books zuzugreifen.
