# KI-Management über das Terminal

OpenClaude ist eine flexible KI-Schnittstelle, die auf jeder Hardware läuft und verschiedene Datenquellen nutzen kann. Dieses in TypeScript entwickelte Open-Source-Projekt ermöglicht es Benutzern, maßgeschneiderte KI-Modelle auf ihrer eigenen Infrastruktur auszuführen.

## Was es bringt

- Vereint cloudbasierte und lokale KI-Modelle in einer einzigen Schnittstelle.
- Führt Aufgaben wie Dateiverwaltung, Suche und Programmierung direkt über das Terminal aus.
- Ermöglicht die einfache Konfiguration verschiedener Anbieter durch eine benutzerfreundliche geführte Installation.

## Installation

**Allgemeine Installation**

```
npm install -g @gitlawb/openclaude@latest
```

## Ausführung

**Starten des Tools**

```
openclaude
```
