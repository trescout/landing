# Geheime Nachrichten ohne Benutzerkennung

SimpleX bietet eine datenschutzorientierte Kommunikationsinfrastruktur als erstes Messaging-Netzwerk, das ohne die Verwendung von Benutzerkennungen auskommt. Die in Haskell-Sprache entwickelte Plattform zielt darauf ab, Benutzerdaten dank ihrer dezentralen Struktur vollständig anonym zu halten.

## Was es bringt
- Anonyme Kommunikation ohne Benutzerkennung
- End-to-End-Dual-Layer-Verschlüsselung
- Dezentrale und datenschutzorientierte Architektur

## Installation
**Installation der Terminal-App**

```
curl -o- https://raw.githubusercontent.com/simplex-chat/simplex-chat/stable/install.sh | bash
```


## Wenn Sie nicht programmieren
Erstellen Sie auf der Grundlage der benutzerkennungsfreien Struktur und der Ende-zu-Ende-Verschlüsselungsmethoden von SimpleX Chat einen kurzen Leitfaden, der erklärt, wie diese Plattform ein datenschutzorientiertes Messaging-Erlebnis bietet.
