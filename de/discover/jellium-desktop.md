# Desktop-Zugriff auf Ihre Jellyfin-Medienbibliothek

Jellium-desktop ist ein inoffizieller Desktop-Client, der in Rust für den Medienserver Jellyfin entwickelt wurde. Die Software bietet eine native Schnittstelle, die es Benutzern ermöglicht, direkt über das Betriebssystem auf Medienbibliotheken zuzugreifen.

- ★ 1.342
- Rust
- GitHub Trending · 2026-07-20

## Was es bringt

- Greifen Sie über die native App auf Ihren Jellyfin-Medienserver zu
- Optimierte Medienwiedergabe mit CEF- und MPV-Infrastruktur
- Native Schnittstellenunterstützung unter Windows, macOS und Linux
