# Angular für umfassende Webanwendungen

Angular wurde von Google entwickelt und ist ein umfassendes Framework zur Erstellung skalierbarer Webanwendungen. Mit seiner TypeScript-basierten Struktur bietet es Werkzeuge, die den Entwicklungsprozess in komplexen Projekten standardisieren und strukturieren.

## Was es bringt

- Bietet die Möglichkeit, mobile und Desktop-Webanwendungen zu entwickeln
- Standardisiert komplexe Projekte mit seiner TypeScript-basierten Struktur
- Erleichtert die Erstellung skalierbarer Projekte mit umfassender Tool-Unterstützung

## Installation

**Einrichten der Befehlszeilenschnittstelle**

```
npm install -g @angular/cli
```

## Ausführung

**Erstellen Sie einen neuen Arbeitsbereich**

```
ng new [PROJECT NAME]
```

**Starten Sie die App lokal**

```
cd [PROJECT NAME]
ng serve
```
