# Erstellen Sie dreidimensionale Modelle aus Bildern

Modly ist eine Desktop-Anwendung, die 3D-Modelle aus Bildern erstellt und alle Vorgänge auf der lokalen Grafikkarte (GPU) ausführt. Dieses Tool, das ohne Internetverbindung funktioniert, bringt den durch künstliche Intelligenz unterstützten Modellierungsprozess auf Personalcomputer.

- ★ 5.550
- TypeScript
- GitHub Trending · 2026-08-14

## Was es bringt
- Konvertiert Fotos in 3D-Modelle auf dem lokalen Computer
- Funktioniert vollständig offline, ohne dass eine Internetverbindung erforderlich ist
- Bietet eine flexible Struktur, die mit externen Modellen erweitert werden kann

## Installation
**Abhängigkeiten installieren**

```
npm install
```

**Vorbereiten der Python-Infrastruktur**

```
cd api
python -m venv .venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate  # Linux / macOS
pip install -r requirements.txt
```


## Ausführung
**Starten der App**

```
# Windows
launch.bat

# Linux / macOS
./launch.sh
```
