# Verwalten Sie Webschnittstellen mit natürlicher Sprache

Der von Alibaba entwickelte Page-Agent ist ein In-Page-Agent für grafische Benutzeroberflächen, der die Steuerung von Webschnittstellen mit Befehlen in natürlicher Sprache ermöglicht. Dieses in TypeScript geschriebene Tool bietet einen browserbasierten Steuerungsmechanismus zur Automatisierung von Webinteraktionen.

## Was es bringt
- Keine Browsererweiterungen oder Python erforderlich
- Textbasiertes DOM-Rendering statt Screenshot
- Integration mit Ihren eigenen KI-Modellen

## Installation
**Installation über NPM**

```
npm install page-agent
```


## Wenn Sie nicht programmieren
Ich möchte Interaktionen auf der Webseite mit Befehlen in natürlicher Sprache mithilfe von PageAgent verwalten. Ich möchte, dass es Vorgänge wie das Klicken auf Schaltflächen auf der Seite, das Ausfüllen von Formularen oder die Eingabe von Daten mithilfe des von mir ermittelten Modells der künstlichen Intelligenz ausführt.
