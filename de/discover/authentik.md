# Zentrales Identitätsmanagement für Ihre Anwendungen

Authentik ist eine Open-Source-Sicherheitsplattform, die eine zentralisierte Authentifizierung und Zugriffsverwaltung für Anwendungen bietet. Durch die Kombination komplexer Authentifizierungsprozesse an einem einzigen Punkt bietet es einen sicheren Übergang zwischen verschiedenen Diensten.

## Was es bringt

- Bietet einen sicheren Übergang zwischen verschiedenen Diensten von einem einzigen Punkt aus
- Unterstützt Standardprotokolle wie SAML und OAuth2
- Skalierbar von kleinen Projekten bis hin zu Großsystemen

## So fangen Sie an

Besuchen Sie zur Installation die Dokumentationsseite auf der offiziellen Website. Sie können Docker Compose für kleine oder Testinstallationen und Kubernetes für große Strukturen wählen. Eine Installation über AWS oder die Nutzung des DigitalOcean App Stores ist ebenfalls möglich.
