# FxEmbed

FxEmbed ist ein Tool zum Einbetten von Inhalten, mit dem Beiträge auf X- und Bluesky-Plattformen in Anwendungen wie Discord oder Telegram ordnungsgemäß angezeigt werden. Es ermöglicht die vollständige Darstellung von Medienelementen wie mehreren Bildern, Videos und Umfragen auf Messaging-Plattformen.
