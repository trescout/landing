# Unabhängiges Browser- und Engine-Projekt

Ladybird ist ein unabhängiges Webbrowser- und Browser-Engine-Projekt auf Grundlage von Webstandards. Die offizielle README beschreibt es als Pre-Alpha und ausschließlich für Entwickler geeignet; die Multiprozess-Architektur trennt unter anderem Netzwerkverbindungen und Bilddekodierung.

## Installation

**Quellcode klonen**

```
git clone https://github.com/LadybirdBrowser/ladybird.git
```

**In das Projektverzeichnis wechseln**

```
cd ladybird
```

## Ausführung

**Bauen und ausführen**

```
./Meta/ladybird.py run
```

## Was macht dieses Werkzeug?

Ladybird ist ein Open-Source-Projekt für einen Browser und eine Browser-Engine. Es läuft unter Linux, macOS, Windows mit WSL2 und anderen Unix-ähnlichen Systemen. Die Projektwebsite nennt eine erste Alpha-Version für 2026 unter Linux und macOS als Ziel, während die Bauanleitung Qt 6.9+, einen C++23-fähigen Compiler, Rust und CMake 3.30+ voraussetzt.

## Für wen ist es?

Entwickler, die Browsertechnologien untersuchen, zum Projekt beitragen oder den Quellcode in einer Entwicklungsumgebung bauen möchten.

## Was Sie nicht erwarten sollten

Menschen, die einen stabilen Browser für den täglichen Endanwenderbetrieb suchen.

## Höhepunkte

- Unabhängiges Browser- und Engine-Projekt auf Grundlage von Webstandards.
