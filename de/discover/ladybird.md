# Eigenständiger Webbrowser Ladybird

Ladybird ist ein neuer Webbrowser, der unabhängig von den bestehenden großen Browser-Engines entwickelt wurde. Dieses in C++ geschriebene Projekt zielt darauf ab, eine Open-Source-Alternative basierend auf Internetstandards bereitzustellen.

- ★ 65.040

- GitHub Trending · 2026-08-09

## Was es bringt
- Bietet eine neue Struktur unabhängig von vorhandenen Browser-Engines
- Bietet eine Open-Source-Alternative basierend auf Internetstandards
- Zielt mit seiner Multi-Processing-Architektur auf ein sicheres und dauerhaftes Surferlebnis ab
