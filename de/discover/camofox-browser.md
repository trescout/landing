# Stealth-Browser für KI-Agenten

Camofox ist ein Stealth-Headless-Browser, der es KI-Agenten ermöglicht, Bot-Erkennungssysteme und Web-Scraping-Blockaden zu umgehen. Er arbeitet direkt mit den Browser-Automatisierungstools Puppeteer und Playwright zusammen und bietet eine Alternative zu diesen Bibliotheken.

- ★ 10.915
- JavaScript
- GitHub Trending · 2026-09-08

## Was es bringt
- Umgeht Bot-Erkennungssysteme und Web-Scraping-Blockaden auf C++-Ebene.
- Verbraucht 90 % weniger Daten als Standard-HTML durch Accessibility-Snapshots.
- Ermöglicht benutzerbasiertes Cookie- und Speichermanagement durch Sitzungsisolierung.

## Installation
**Direktbedienung**

```
npx @askjo/camofox-browser
```

**Installation aus dem Quellcode**

```
git clone https://github.com/jo-inc/camofox-browser
cd camofox-browser
npm install
npm start  # downloads Camoufox on first run (~300MB)
```


## Ausführung
**Starten des lokalen Servers**

```
git clone https://github.com/jo-inc/camofox-browser && cd camofox-browser
npm install && npm start
# -> http://localhost:9377
```


## Wenn Sie nicht programmieren
Du bist ein Webbrowser-Manager. Nutze den Camofox-Browser, um auf Ziel-Websites zuzugreifen. Verwende diesen auf C++-Ebene getarnten Browser, um nicht von der Bot-Erkennung erfasst zu werden. Bevorzuge beim Extrahieren von Daten von Webseiten die leichteren Accessibility-Snapshots anstelle von rohem HTML. Verwende stabile Identifikatoren für Elemente, mit denen du interagieren musst, und verwalte Sitzungen durch benutzerbasierte Isolierung.
