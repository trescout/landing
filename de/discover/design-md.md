# Führen Sie Designsysteme in die KI ein

DESIGN.md wurde von Google Labs entwickelt und bietet eine strukturierte Formatspezifikation für die Weitergabe visueller Anmeldeinformationen an Codierungsagenten. Dieser Standard stellt sicher, dass Designsysteme von Agenten der künstlichen Intelligenz konsistent und dauerhaft verstanden werden.

## Was es bringt

- Speichert Designentscheidungen in strukturiertem Format
- Bietet konsistente visuelle Anleitung für Codierungsagenten
- Prüft automatisch auf Designfehler und Inkonsistenzen

## Installation

**Installieren Sie das Paket**

```
npm install @google/design.md
```

**Für Windows installieren**

```
npm install "@google/design.md"
```

## Ausführung

**Validieren Sie die Designdatei**

```
npx @google/design.md lint DESIGN.md
```

**Vergleich zweier Designdateien**

```
npx @google/design.md diff DESIGN.md DESIGN-v2.md
```

## Wenn Sie nicht programmieren

🤖 Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Sehen Sie sich die Datei DESIGN.md an, die die visuelle Identität und das Designsystem meines Projekts definiert. Halten Sie sich bei allen von Ihnen erstellten Codes an diese Struktur, indem Sie sich auf die Farbpalette, Typografieregeln, Leerzeichenwerte und Komponentendefinitionen in dieser Datei beziehen. Nutzen Sie Werte direkt aus dem Designsystem und vermeiden Sie visuelle Inkonsistenzen.
