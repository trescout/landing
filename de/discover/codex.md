## Was macht dieses Werkzeug?
Codex CLI ist ein Programmieragent, der im Terminal auf Ihrem lokalen Computer ausgeführt wird. Er kann Code in einem Projektverzeichnis überprüfen, Dateien ändern, Befehle ausführen und dabei helfen, wiederkehrende Aufgaben zu automatisieren.

## Für wen ist es?
Entwickler, die im Terminal arbeiten, die Codebasis überprüfen, Dateien bearbeiten und wiederkehrende Entwicklungsaufgaben automatisieren möchten.

## Was Sie nicht erwarten sollten
Es ist möglicherweise nicht für Personen geeignet, die das Terminal nicht verwenden möchten.

## Höhepunkte
- Er kann Code überprüfen und Dateien ändern.
- Er kann Befehle ausführen und wiederkehrende Aufgaben automatisieren.
- Modell, reasoning effort, Berechtigungen und Befehlsfreigaben können vom Benutzer verwaltet werden.
- Das GitHub-Repository ist unter Apache-2.0 lizenziert.

## Ablauf für die erste Nutzung
- Wählen Sie die für Ihr Betriebssystem geeignete offizielle Installationsmethode.
- Starten Sie Codex CLI nach der Installation.
- Melden Sie sich mit ChatGPT oder einer anderen verfügbaren Anmeldemethode an.
- Beginnen Sie im Projektverzeichnis. Erstellen Sie vor und nach Änderungen einen Git checkpoint.
