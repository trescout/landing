# Vielseitiger KI-Coding-Agent

Kilo ist eine All-in-One-Agenten-basierte Engineering-Plattform zur Beschleunigung von Softwareentwicklungsprozessen. Es standardisiert die Anwendungserstellungs-, Verteilungs- und Iterationsprozesse durch einen Open-Source-Softwareentwicklungsagenten (Codierungsagenten).

## Was es bringt

- Möglichkeit, zwischen mehr als 500 Modellen zu wechseln
- VS-Code, JetBrains und CLI-Unterstützung
- Generierung und Debugging von Code in natürlicher Sprache

## Installation

**mit npm installieren**

```
npm install -g @kilocode/cli
```

**Installation mit Homebrew**

```
brew install Kilo-Org/tap/kilo
```

## Ausführung

**Starten des Tools**

```
kilo
```

**Autonomer Betriebsmodus**

```
kilo run --auto "run tests and fix any failures"
```

## Wenn Sie nicht programmieren

Fügen Sie dies in Ihren Agenten ein (Claude Code · Codex · Antigravity)

Als Softwareentwicklungsagent benötige ich Sie, um meine Prozesse zur Codegenerierung in natürlicher Sprache, zum Debuggen oder zur Architekturplanung in meinem aktuellen Projektverzeichnis zu verwalten. Ich möchte, dass Sie aus den mehr als 500 von Kilo angebotenen Modellen dasjenige auswählen, das am besten zu meiner Aufgabe passt, die von Ihnen geschriebenen Codes mit Ihrem eigenen Selbstprüfungsmechanismus überprüfen und sie gemäß den Leistungs- und Sicherheitsstandards liefern.

Repository: https://github.com/Kilo-Org/kilocode. Richte dich bei der Installation und Ausführung nach den offiziellen Anweisungen in der README-Datei dieses Repositorys.

Prüfe vor dem Start, unter welchem Betriebssystem wir arbeiten und ob die notwendigen Tools (z. B. Python, Node.js, Git, Docker) installiert sind. Installiere fehlende Tools schrittweise entsprechend diesem System.

Erstelle einen neuen, leeren Ordner für die Arbeit. Rühre keine Dateien außerhalb dieses Ordners an und lösche nichts. Sag mir vor jedem Befehl in einem Satz, was du tun wirst.

Sag mir, was ich am Ende jedes Schrittes auf dem Bildschirm sehen sollte. Wenn ein Fehler auftritt, füge ich die Fehlermeldung exakt so ein, wie sie ist, und wir beheben sie gemeinsam.
