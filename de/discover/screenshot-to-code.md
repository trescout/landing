# Wandeln Sie Screenshots in funktionierenden Code um

Screenshot-to-Code ist ein Softwaretool, das Screenshot-Dateien analysiert und sie in sauberen HTML-, Tailwind-, React- oder Vue-Code umwandelt. Es ermöglicht Entwicklern, Schnittstellendesigns schnell in funktionierende Codeausschnitte zu übersetzen.

- Python

## Was es bringt
- Übersetzt Screenshots und Designdateien in sauberen HTML- oder React-Code
- Verwandelt Website-Aufzeichnungen in funktionale Prototypen
- Tailwind unterstützt CSS und verschiedene gängige Schnittstellenbibliotheken

## Installation
**Schnelle Installation mit Docker**

```
echo "OPENAI_API_KEY=sk-your-key" > .env
docker-compose up -d --build
```

**Starten der Schnittstelle**

```
cd frontend
pnpm install
pnpm dev
```


## Wenn Sie nicht programmieren
Analysieren Sie den Screenshot und erstellen Sie eine saubere und funktionale Codestruktur, die das Design im Bild genau widerspiegelt. Bereiten Sie die Ausgabe im HTML- oder React-Format mit Tailwind CSS vor. Extrahieren Sie die echten Logos und Assets im Bild und fügen Sie sie in den Code ein, um alle Elemente des Designs responsiv zu codieren.
