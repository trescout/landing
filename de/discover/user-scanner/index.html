OSINT-Benutzeraufklärung über mehr als 465 Plattformen

Das Python-basierte User-Scanner führt automatisierte Open-Source-Intelligence-Recherchen (OSINT) über 465+ soziale Netzwerke und Foren durch.

  • ★ 3.910
  • Python
  • GitHub Trending · 2026-08-31

Aktualisierungen

  • 31. August 2026: 3.910 Sterne, erweitert auf 465+ Plattformen mit asynchroner HTTP-Scan-Engine.

Was es bringt

  • Enorme Plattformabdeckung: Überprüfen Sie Konten auf GitHub, Reddit, Steam, Telegram und über 465 Diensten in einem Durchlauf.
  • Asynchrone Hochgeschwindigkeitsabfragen: Hunderte Endpunkte dank Python asyncio und aiohttp innerhalb von Sekunden parallel abfragen.
  • Intelligente Falsch-Positiv-Filterung: Validiert sowohl HTTP-Statuscodes als auch spezifische Fehlermuster im Antworttext.
  • Strukturierte JSON- und CSV-Exporte: Speichern Sie Untersuchungsergebnisse in Standardformaten für Cyber-Security-Berichte.
  • Lokale Ausführung und Privatsphäre: Führen Sie Recherchen direkt im Terminal aus, ohne Daten an externe Server zu übermitteln.

Installation

Repository klonen und Abhängigkeiten installieren
git clone https://github.com/kaifcodec/user-scanner.git
cd user-scanner
pip install -r requirements.txt

Ausführung

Zielbenutzernamen und E-Mail-Adresse scannen
python3 user_scanner.py -u hedef_kullanici
# veya e-posta ile:
python3 user_scanner.py -e hedef@ornek.com

Technische Architektur und Funktionsweise

User-Scanner basiert auf einer asynchronen Aufklärungs-Pipeline mit modularen Plattformprofilen:

  • JSON-basiertes Plattform-Manifest: Modulare Spezifikationen mit URL-Mustern, Statuscodes und Regex-Signaturen für 465+ Plattformen.
  • Verbindungspooling für hohe Durchsätze: Optimiert Netzwerkressourcen durch persistente TCP-Sitzungen und lokales DNS-Caching.
  • Header- und User-Agent-Rotation: Simuliert echte Browser-Anfragen, um WAF-Blockaden und Rate-Limits zuverlässig zu vermeiden.

OSINT-Rechercheszenarien und Datenanalyse

Sicherheitsforscher und Forensiker setzen User-Scanner in entscheidenden Szenarien ein:

  • Digitale Spurenanalyse: Kartieren Sie aktive Konten nach Datenlecks, um das Ausmaß digitaler Exposition präzise einzuschätzen.
  • Unternehmenssicherheitsaudits: Überprüfen Sie, ob geschäftliche E-Mail-Adressen auf nicht autorisierten Plattformen verwendet werden.
  • Schutz vor Social Engineering: Erkennen Sie gefälschte Profile und exponierte Entwickler-Accounts vor zielgerichteten Angriffen frühzeitig.

Häufig gestellte Fragen

  • Ist der Einsatz von User-Scanner legal? Ja. User-Scanner fragt ausschließlich öffentlich zugängliche Webseiten ab; es umgeht keine Zugriffssperren und knackt keine Passwörter.
  • Wird Tor oder Proxy-Routing unterstützt? Ja. Anfragen können über SOCKS5- oder HTTP-Proxys geleitet werden, um die eigene IP-Adresse zu verschleiern und Rate-Limits zu umgehen.
  • Wie lange dauert ein vollständiger Suchlauf? Dank asynchroner Abfragen ist der Scan über mehr als 465 Plattformen je nach Verbindung meist in 20 bis 45 Sekunden abgeschlossen.
  • Wie funktioniert die E-Mail-Aufklärung? Im E-Mail-Modus werden öffentlich sichtbare Bestätigungssignale bei Registrierungs- oder Passwort-Reset-Prüfungen analysiert.
