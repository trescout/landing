# Moderne JavaScript- und TypeScript-Laufzeitumgebung

Deno ist eine moderne Laufzeitumgebung, die für die Sprachen JavaScript und TypeScript entwickelt wurde. Dieses in der Rust-Sprache entwickelte Tool bietet mit seiner sicherheits- und leistungsorientierten Struktur eine alternative Infrastruktur zur traditionellen Node.js-Plattform.

## Was es bringt

- Es führt sicher die Sprachen JavaScript, TypeScript und WebAssembly aus.
- Mit seinem V8-Motor und der Rust-Sprache bietet es hohe Leistung.
- Es bietet eine moderne und praktische Infrastruktur für die Entwicklung von Webservern.

## Installation

**Installation auf Mac- oder Linux-Systemen**

```
curl -fsSL https://deno.land/install.sh | sh
```

**Installation mit Homebrew auf Mac**

```
brew install deno
```

## Ausführung

**Starten der vorbereiteten Serverdatei**

```
deno run --allow-net server.ts
```
