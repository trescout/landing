# Virtuelle-Maschinen-Images für GitHub Actions

GitHub Actions Runner Images enthalten die Umgebungen für virtuelle Maschinen, die von der GitHub Actions-Plattform zur Automatisierung von Softwareentwicklungsprozessen verwendet werden. Diese Images stellen die vorkonfigurierten Betriebssysteme und Toolsets bereit, die für Softwaretest- und -bereitstellungsprozesse erforderlich sind.

- ★ 13.393
- PowerShell
- GitHub Trending · 2026-09-27

## Was es bringt
- Bietet vorbereitete Umgebungen für verschiedene Ubuntu-, macOS- und Windows-Versionen.
- Stellt vorkonfigurierte Toolsets für Softwaretest- und -bereitstellungsprozesse bereit.
- Enthält den Quellcode zum Erstellen von benutzerdefiniertem Quellcode für virtuelle Maschinen.

## So fangen Sie an
Um eine virtuelle Maschine für dieses Tool zu erstellen, können Sie die Anweisungen in der Datei create-image-and-azure-resources.md im Ordner docs des Repositorys einsehen.
