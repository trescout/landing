# Modul-Bundler für Webprojekte

Webpack ist ein Bundler, der JavaScript und andere Web-Assets für die Ausführung im Browser bündelt. Dank der Code-Splitting-Funktion, die Module in verwaltbare Teile unterteilt, können Anwendungen bei Bedarf geladen werden.

- ★ 65.962
- JavaScript
- GitHub Trending · 2026-08-05

## Was es bringt
- Es kombiniert JavaScript-Dateien zur Ausführung im Browser.
- Es verkürzt die Ladezeit der Anwendung mit seiner Code-Splitting-Funktion.
- Es kann verschiedene Dateitypen wie TypeScript vorverarbeiten.

## Installation
**mit npm installieren**

```
npm install --save-dev webpack
```

**Installation mit Garn**

```
yarn add webpack --dev
```
