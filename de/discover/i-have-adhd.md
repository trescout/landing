# Konzentrieren Sie sich auf KI-Antworten

i-have-adhd wurde entwickelt, um die Ausgabe von Codierungsagenten fokussierter und organisierter zu gestalten und verbessert die Benutzererfahrung, indem komplexe Antworten in Teile zerlegt werden. Diese auf Python basierende Fähigkeit standardisiert die Darstellung von Informationen durch KI in einem für Aufmerksamkeitsdefizit-Hyperaktivitätsstörungen (ADHS) geeigneten Format.

## Was es bringt

- Entfernt unnötige Einleitungssätze in KI-Antworten.
- Unterteilt komplexe Aufgaben in nummerierte Schritte.
- Es bietet ein klares Ausgabeformat, das sich direkt auf die Aktion konzentriert.

## So fangen Sie an

Die Installationsschritte variieren je nach verwendetem Codierungstool (Claude Code oder Codex). Bitte lesen Sie den Abschnitt „Installieren“ auf der GitHub-Seite des Projekts oder folgen Sie der Datei INSTALL.md für detaillierte Anweisungen.
