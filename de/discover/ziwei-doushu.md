# Open-Source-Ziwei-Doushu-Astrologie-Engine

Renhuai123/ziwei-doushu ist eine Open-Source-TypeScript-Engine, die auf Ni Haixias Tianji-System basiert und Ziwei-Doushu-Astrologiekarten berechnet. Das Projekt stellt einen umfangreichen 13-dimensionalen Datensatz für astrologische Interpretationen (v4.0) zur Verfügung, der Daten für den Zeitraum von 1950 bis 2026 abdeckt.

## Was es bringt

- Bietet 675.000命盘 (Horoskope) und einen 13-dimensionalen, umfangreichen Datensatz für astrologische Interpretationen.
- Führt Echtzeit-Kartenberechnungen und Korrekturen der Sonnenzeit durch.
- Enthält eine vollständige Astrologie-Engine, die auf Ni Haixias Tianji-System basiert.

## Installation

**Das Projekt klonen und vorbereiten**

```
git clone https://github.com/Renhuai123/ziwei-doushu.git
cd ziwei-doushu

# 安装依赖
npm install

# 配置环境变量（只看排盘可以跳过；AI 配置仅在你自己实现了 /api/* 接口时才用得上）
cp .env.example .env.local

# 启动开发服务器
npm run dev
```
