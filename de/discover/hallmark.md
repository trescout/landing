# Verleihen Sie KI-Designs Originalität

Hallmark ist eine Stildatei, die entwickelt wurde, um den Einfluss von Standardinhalten, die durch künstliche Intelligenz (KI-Slop) erzeugt werden, auf das Design zu reduzieren. Claude Code sorgt dafür, dass die in Tools wie Cursor und Codex verwendeten Schnittstellen eine einzigartige und menschliche Ästhetik erhalten.

## Was es bringt
- Vermeidet die Standard-KI-Ästhetik
- Erstellt einzigartige Schnittstellen mit zwanzig verschiedenen Themen
- Prüft und überarbeitet vorhandene Codes

## Installation
**Fahrzeug hinzufügen**

```
npx skills add nutlope/hallmark
```


## Wenn Sie nicht programmieren
Erstellen Sie mithilfe der Hallmark-Stildatei ein einzigartiges Interface-Design, das nicht so aussieht, als wäre es von KI erstellt worden. Vermeiden Sie beim Design Standardvorlagen, wählen Sie aus zwanzig verschiedenen Themen das Passende aus und schaffen Sie eine einzigartige Struktur, die 57 Qualitätstests besteht.
