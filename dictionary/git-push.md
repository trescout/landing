# Git Push nedir?

**Kategori:** Geliştirme  
**Son güncelleme:** 2026-06-27

Yerel bilgisayarınızda yaptığınız yazılım değişikliklerini internet üzerindeki ortak bir sunucuya yükleme işlemidir.

## Tanım
Yazılım geliştirirken kodlarınızı kendi bilgisayarınızda yazar ve düzenlersiniz. Bu değişikliklerin ekibin geri kalanıyla paylaşılması için 'push' komutu kullanılır. Bu sayede yaptığınız tüm güncellemeler merkezi bir depoya (repository) gönderilir.

## Bir benzetmeyle
Bilgisayarınızda yazdığınız bir raporu, bulut üzerindeki ortak bir klasöre 'kaydet ve gönder' tuşuna basarak yüklemek gibidir.

## Nasıl çalışır?
Terminal veya kod editörü üzerinden 'git push' komutu yazılarak gerçekleştirilir.

## Nerede kullanılır?
Yazılım geliştirme süreçlerinde, özellikle GitHub veya GitLab gibi platformlarda kullanılır.

## Sık karıştırılanlar
Git pull ile karıştırılır; pull internetten kodu alırken, push internete gönderir.

## Sıkça sorulanlar

**Push yapmazsam ne olur?**  
Yaptığınız değişiklikler sadece sizin bilgisayarınızda kalır ve ekibiniz bunları göremez.
