# Memory Engine nedir?

**Son güncelleme:** 2026-06-03

## Tanım
Yapay zekânın geçmiş etkileşimleri hatırlamasını ve bu bilgileri kullanarak daha tutarlı yanıtlar vermesini sağlayan sistem. Kullanıcı deneyimini kişiselleştirerek uzun vadeli bir bağlam oluşturur.

## Nasıl çalışır?
Geçmiş verileri vektör veritabanlarında depolar ve yeni sorgular sırasında ilgili geçmiş bilgileri geri çağırarak yanıtları zenginleştirir.

## Örnek
Memory engine sayesinde yapay zekâ, önceki konuşmalarda bahsettiğiniz tercihlerinizi unutmadan size özel öneriler sunabilir.
