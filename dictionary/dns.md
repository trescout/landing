# DNS nedir?

*Geliştirme · Son güncelleme: 23 Ekim 2026*

> Domain Name System

İnternet alan adlarını bilgisayarların birbirini bulmasını sağlayan sayısal IP adreslerine çeviren küresel rehber sistemidir.

## Tanım

Alan Adı Sistemi (DNS), insanların hatırlamakta zorlanacağı karmaşık IP adresleri yerine anlamlı web sitesi isimlerinin kullanılmasını mümkün kılan ağ protokolüdür. Siz tarayıcınıza bir adres yazdığınızda DNS sunucuları devreye girerek bu ismi doğru sunucunun IP adresine eşler. İnternetin temel altyapı taşlarından biri olarak kesintisiz iletişim sağlar.

*Telefon rehberinde bir kişinin ismini aratıp numarasına ulaşmaya ve aramayı bu numara üzerinden yapmaya benzer.*

## Nasıl çalışır?

Kullanıcı tarayıcıya bir alan adı girdiğinde istek önce yerel DNS önbelleğine, ardından kademeli olarak yetkili DNS sunucularına iletilir. Doğru IP adresi bulunduğunda tarayıcıya geri döndürülür ve bağlantı kurulur. Bu sorgulama işlemi genellikle milisaniyeler içinde tamamlanır.

## Nerede kullanılır?

Web sitelerine erişirken, e-posta iletim altyapılarında ve bulut sunucuları arasındaki yönlendirmelerde kullanılır.

## Sık karıştırılanlar

IP adresi kavramıyla karıştırılır. IP adresi cihazın gerçek sayısal kimliğidir, DNS ise bu kimliği insanların okuyabileceği isimlerle eşleştiren sistemdir.

## Sorular ve yanıtlar

**DNS çökerse internete girilebilir mi?**

Alan adları çözümlenemez fakat sitelerin doğrudan IP adresleri biliniyorsa tarayıcı üzerinden erişim sağlanabilir.

**DNS önbelleği nedir?**

Sık ziyaret edilen sitelerin IP adreslerinin cihazda geçici olarak saklanmasıdır; böylece her defasında sunucuya sorma ihtiyacı ortadan kalkar.
