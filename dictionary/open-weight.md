# Open Weight nedir, ne demek?

**Kategori:** Yapay Zekâ  
**Son güncelleme:** 2026-09-22

Open weight (Türkçe karşılığıyla **açık ağırlık**), model dosyaları herkese açık yapay zekâ modelidir.

## Tanım ve Kelime Kökeni
Modelin beyni sayılan sayısal değerler paylaşılır. İndiren kendi bilgisayarında kurar ve çalıştırır. Eğitim verisinin açık olması şart değildir, bu ayrım kritiktir.

## Gündelik Hayatta Nasıl Bilinir ve Kullanılır?
- **Yerel:** İnternetsiz asistan.
- **Özel proje:** Kurum içi uyarlama.
- **Araştırma:** Taban model deneyi.

## Teknik Derinlik ve Mimari
Üçgen:
- **Ağırlık:** Eğitilmiş dosyalar.
- **Kod:** Çalıştırma yazılımı.
- **Veri:** Eğitim kümesi, genelde kapalı.

İndirme örneği:

```
git lfs install
git clone https://huggingface.co/ornek/model
```

Lisans notu: Apache ve MIT serbesttir, topluluk lisansları sınır koyabilir. Metin okunmadan ticari işe girilmez.

## Sık Karıştırılanlar
Open Source AI sanılır. O kod ve süreç şeffaflığını da kapsar, bu yalnızca son halin paylaşımıdır. Kapsam farkı lisansı belirler.

## Farklı Disiplinlerde Kullanımı
- **Tarif:** Malzemesiyle paylaşılan yemek.
- **Ders kitabı:** Herkesin okuduğu kaynak.
- **Tohum:** Paylaşılan ata tohumu.

## Bir benzetmeyle
Yemeğin tarifini ve malzemelerini paylaşıp herkesin kendi mutfağında pişirmesine benzer.

## Sıkça sorulanlar

**Open Source farkı ne?**  
Open Source veri ve süreci de kapsar, open weight son hali paylaşır. Kapsam farklıdır.

**Veri de açık mı?**  
Genellikle hayır. Ağırlık açıktır, eğitim kümesi kapalı kalır.

**Ticari kullanılır mı?**  
Lisansa göre değişir. Apache ve MIT serbesttir, topluluk metni okunur.

**Donanım gerekir mi?**  
Modele göre değişir. Küçükler dizüstünde, büyükler sunucuda koşar.
