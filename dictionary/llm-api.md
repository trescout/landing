# LLM API nedir?

*Sözlük · Yapay Zekâ · Son güncelleme: 2 Ekim 2026*

> Large Language Model Application Programming Interface

Yazılımcıların kendi uygulamalarına yapay zekâ modellerinin yeteneklerini eklemelerini sağlayan bir köprüdür.

## Tanım

Bir yapay zekâ modelini doğrudan kendi bilgisayarınızda çalıştırmak yerine, internet üzerinden bu modele soru sorup cevap almanızı sağlayan bir bağlantı noktasıdır. Yazılımcılar bu arayüzü kullanarak kendi programlarını yapay zekâ ile konuşturabilirler. Yani siz bir uygulama geliştirirken, modelin karmaşık hesaplamalarını kendi sunucunuzda yapmak zorunda kalmaz, hazır bir hizmeti kullanırsınız.

*Bir restoranda mutfağa girip yemeği kendiniz pişirmek yerine, garsona siparişinizi verip hazır yemeğin masanıza gelmesini beklemek gibidir.*

## Nasıl çalışır?

Geliştirici, modele bir 'istek' (request) gönderir. Model bu isteği işler ve sonucu bir 'cevap' (response) olarak geri döner. Bu süreç standart bir internet protokolü üzerinden gerçekleşir.

## Nerede kullanılır?

Sohbet botları, otomatik içerik üreticileri ve yapay zekâ destekli tüm web uygulamalarında kullanılır.

## Sık karıştırılanlar

LLM'in kendisi değil, ona ulaşmayı sağlayan kapıdır.

## Sıkça sorulanlar

**Herkes LLM API kullanabilir mi?**

Evet, ancak genellikle bir ücret ödemeniz veya bir anahtar (API key) almanız gerekir.

**Kendi bilgisayarımda çalışan bir modelden farkı nedir?**

Kendi bilgisayarınızda donanım gücüne ihtiyaç duyarsınız, API kullanımında ise tüm yük karşı taraftaki sunucudadır.
