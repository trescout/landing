# Memory API nedir?

**Kategori:** Geliştirme  
**Son güncelleme:** 2026-06-03

Yazılımların yapay zekâ hafızasına veri eklemesini veya mevcut bilgileri sorgulamasını sağlayan bağlantı noktası.

## Tanım
Yazılımların yapay zekâ hafızasına veri eklemesini veya mevcut bilgileri sorgulamasını sağlayan bağlantı noktası. Geliştiricilerin yapay zekâ uygulamalarına kalıcı bellek kazandırmasını kolaylaştırır.

## Nasıl çalışır?
Standart HTTP istekleri aracılığıyla hafıza veritabanına veri yazma veya okuma işlemlerini gerçekleştirir.

## Örnek
Uygulamanız, Memory API kullanarak kullanıcının geçmiş tercihlerini yapay zekâ modeline anlık olarak aktarabilir.
