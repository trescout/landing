# Pull Request nedir?

*Geliştirme · Son güncelleme: 5 Kasım 2026*

> PR

Bir geliştiricinin kod deposuna eklemek istediği değişiklikleri incelemeye ve onaylatmaya sunduğu talep.

## Tanım

Pull Request, kod üzerinde yapılan değişikliklerin ana projeye dahil edilmeden önce diğer ekip üyeleri tarafından gözden geçirilmesini sağlar. Bu işlem sayesinde hatalar erken tespit edilir ve kod kalitesi koruma altına alınır. İşbirliğine dayalı yazılım geliştirme süreçlerinin temel taşlarından biridir.

*Bir yazarın kitaba eklemek istediği yeni bir bölümü yayıncıya veya başeditöre onay için sunması gibidir.*

## Nasıl çalışır?

Geliştirici kendi çalışma dalında geliştirmesini tamamlar ve depoya gönderir. Ardından bir Pull Request açarak ekip arkadaşlarını kodu incelemeye davet eder. İnceleme sonrası yapılan geri bildirimler düzeltilir ve onay alındığında kod ana dala birleştirilir.

## Nerede kullanılır?

GitHub, GitLab ve Bitbucket gibi sürüm kontrol platformlarında yazılım projelerinin yönetilmesinde kullanılır.

## Sık karıştırılanlar

Git Push kavramı ile karıştırılabilir. Git Push kod değişikliklerini sunucuya yüklerken Pull Request bu değişikliklerin ana koda birleştirilmesi için bir inceleme ve tartışma süreci başlatır.

## Sorular ve yanıtlar

**Pull Request neden önemlidir?**

Kod kalitesini artırır, ekip içi bilgi paylaşımını sağlar ve hatalı kodların canlı sisteme geçmesini engeller.

**Pull Request reddedilebilir mi?**

Evet, kod standartlara uymuyorsa veya eksikler varsa düzeltilmesi için reddedilebilir veya revizyon istenebilir.
