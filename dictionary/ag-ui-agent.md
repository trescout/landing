# AG-UI Agent nedir?

*Yapay Zekâ · Son güncelleme: 30 Ekim 2026*

> Agent-GUI Agent

Grafik kullanıcı arayüzünü ekran görüntüleri ve arayüz ögeleri üzerinden analiz edip insan gibi tıklama ve yazma eylemleri gerçekleştiren yapay zekâ ajanıdır.

## Tanım

AG-UI agent, bir bilgisayar veya mobil cihaz ekranındaki düğmeleri, metin kutularını ve menüleri görsel olarak algılayan yazılımsal bir yapay zekâ asistanıdır. Klasik arka plan entegrasyonlarına veya API bağlantılarına ihtiyaç duymadan doğrudan kullanıcı arayüzünü kullanarak görevleri yerine getirir. Fare hareketleri, tıklamalar ve klavye girdilerini tıpkı bir insan gibi simüle ederek yazılımlarla etkileşime girer.

*Bilgisayarın başına oturup ekrandaki simgelere bakarak sizin adınıza fareyi hareket ettiren ve tuşlara basan görünmez bir stajyere benzer.*

## Nasıl çalışır?

Gelişmiş çok modlu yapay zekâ modelleri ekran görüntüsünü sürekli yakalar ve piksel düzeyinde görsel analizi metin hiyerarşisiyle birleştirir. Model, hedef ögenin ekrandaki koordinatlarını belirledikten sonra işletim sistemi seviyesindeki kontrol komutlarını tetikleyerek tıklama veya metin girme işlemini yürütür. Her eylemden sonra ekranın yeni durumunu kontrol ederek görevin başarıyla tamamlanıp tamamlanmadığını doğrular.

## Nerede kullanılır?

API desteği sunmayan eski kurumsal yazılımların otomatikleştirilmesinde, web sitelerinde karmaşık form doldurma işlemlerinde ve yazılım test süreçlerinin otomatik yürütülmesinde kullanılır.

## Sık karıştırılanlar

Standart yapay zekâ ajanları sadece metin veya veri tabanı seviyesinde işlem yapabilirken AG-UI agent doğrudan görsel ekran piksellerini ve grafik arayüz elemanlarını hedef alarak çalışır.

## Sorular ve yanıtlar

**AG-UI agent kullanmak için yazılımların API sunması gerekir mi?**

Hayır. Bu ajanlar ekrandaki görsel pikselleri ve düğmeleri analiz ettiği için sistemde hiçbir API bulunmasa bile doğrudan arayüzü kullanarak çalışabilir.

**Web tarayıcısı dışındaki masaüstü programlarında da çalışır mı?**

Evet. Doğrudan işletim sisteminin grafik çıktısını okuyabildiği için hem masaüstü hem de mobil ve web uygulamalarında görev alabilir.
