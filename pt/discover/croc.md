# Transferência de arquivos fácil e segura

Croc é uma ferramenta que fornece transferência segura de arquivos e dados entre dois computadores usando criptografia ponta a ponta. Este software, desenvolvido com a linguagem de programação Go, utiliza um mecanismo de retransmissão temporária para facilitar o processo de transferência.

## O que você ganha
- Transmissão de dados criptografados de ponta a ponta
- Compatibilidade entre diferentes sistemas operacionais
- Retomando transferências interrompidas de onde pararam

## Instalação
**Instalação geral**

```
curl https://getcroc.schollz.com | bash
```

**Instalação no macOS**

```
brew install croc
```


## Execução
**enviar arquivo**

```
croc send [file(s)-or-folder]
```

**receber arquivos**

```
croc code-phrase
```
