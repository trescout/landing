Retomar avaliação com inteligência artificial

Agente de contratação é um agente de inteligência artificial (agente de IA) projetado para avaliar e pontuar currículos. Esta ferramenta, desenvolvida em linguagem Python, tem como objetivo automatizar processos de seleção de candidatos em processos de recrutamento.

O que você ganha

  • Ele analisa automaticamente currículos em formato PDF.
  • Enriquece os candidatos com dados do GitHub.
  • Fornece um relatório de pontuação justo e explicável.

Instalação

Baixando e instalando os arquivos necessários
git clone https://github.com/interviewstreet/hiring-agent
cd hiring-agent

python -m venv .venv
# Linux or macOS
source .venv/bin/activate
# Windows
# .venv\Scripts\activate

pip install -r requirements.txt

Execução

Iniciar revisão de currículo
python score.py /path/to/resume.pdf

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Atuar como recrutador e analisar dados de currículo fornecidos e contribuições técnicas no GitHub. Pontue os projetos, habilidades técnicas e experiência profissional do candidato de acordo com critérios objetivos. Ao pontuar, considere a qualidade do código do candidato no GitHub, a frequência das contribuições e a relevância de seus projetos para aplicações do mundo real. Em última análise, crie um relatório de avaliação transparente e justo que destaque os pontos fortes e fracos do candidato.
