# Aperfeiçoe seus designs de IA

Impeccable é uma biblioteca de linguagem de design desenvolvida para melhorar os resultados de design de modelos de inteligência artificial. O software fornece regras padronizadas para melhorar a consistência visual e a qualidade estética das ferramentas generativas de IA.

## O que você ganha

- Fornece linguagem de design padronizada e consistência visual para modelos de IA.
- Ele acelera os processos de controle de design, melhoria e experiência do usuário com 23 comandos diferentes.
- Ele evita automaticamente erros comuns de design com 27 regras antipadrão determinísticas.

## Instalação

**Instalação via CLI**

```
npx impeccable skills install
```

## Execução

**Inspeção de projeto**

```
/impeccable audit
```
