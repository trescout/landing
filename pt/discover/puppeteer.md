# Gerencie navegadores automaticamente com código

Puppeteer é uma biblioteca de automação de navegador usada para controlar os navegadores Chrome e Firefox. Desenvolvido com TypeScript, esta ferramenta oferece uma interface padrão para automação de testes e operações de web scraping em páginas web.

## O que você ganha
- O software controla os navegadores Chrome e Firefox
- Cria processos de teste automáticos em páginas da web
- Extrai dados de sites

## Instalação
**via npm (Node.js)**

```
npm i puppeteer
```


## Se você não programa
Você é um especialista em automação web. Usando a biblioteca Puppeteer, crie um script JavaScript simples que abre uma página da web, escreve texto em um campo especificado e imprime os resultados na tela. Forneça um exemplo de código que inclua etapas que iniciam o navegador, criam uma nova página, navegam até um URL e imprimem o título da página no console.
