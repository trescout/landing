# IA leve para dispositivos de ponta

Desenvolvido pela Cactus Compute, o Needle oferece um modelo básico de 14 MB que pode ser executado em pequenos hardwares, como telefones, dispositivos vestíveis e robôs. Essa estrutura leve visa executar aplicativos de inteligência artificial localmente em dispositivos de ponta com poder de processamento limitado.

- ★ 6.022
- Python
- GitHub Trending · 2026-08-13

## O que você ganha
- Modelo de arquivo único com tamanho de apenas 14 MB
- Trabalhando com 28 MB de RAM com baixo uso de memória
- Capacidade de convocar veículos e extrair dados estruturados

## Instalação
**Configuração básica**

```
pip install cactus-needle
```

**Instalação com suporte GPU**

```
pip install "cactus-needle[gpu]"
```


## Se você não programa
Você é um assistente de inteligência artificial. Analise o texto vindo do usuário e faça as chamadas de ferramentas necessárias utilizando as funções Python que defini ou extraia os dados desejados do texto em formato JSON estruturado. Sempre considere a pontuação de confiança fornecida pelo modelo em suas respostas e confirme a transação com níveis de confiança baixos.
