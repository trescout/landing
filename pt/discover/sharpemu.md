# Projeto experimental de emulador de PlayStation 5

Sharpemu é um projeto experimental de emulador de PlayStation 5 desenvolvido em linguagem C#. Este estudo, que visa imitar a arquitetura do console com base em software, é um experimento técnico realizado em tecnologias de emulação de consoles de jogos.

- ★ 1.379
- C#

## O que você ganha
- Oportunidade de examinar a arquitetura do console de jogos
- Suporte para execução de instruções nativas da CPU
- Lendo metadados de arquivos de jogo

## Como começar
Para utilizar o projeto, você pode baixar arquivos prontos na aba ‘Releases’ da página do GitHub ou compilar os códigos-fonte em seu computador com o .NET SDK instalado. Para compilar, basta copiar o projeto para o seu computador, abrir o arquivo da solução via VSCode e executar o comando dotnet build no terminal.
