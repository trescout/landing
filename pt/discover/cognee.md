# Memória permanente para seu agente de IA

Cognee é uma plataforma de código aberto que fornece memória de longo prazo entre sessões para agentes de inteligência artificial. Ele permite que os agentes armazenem e recuperem dados de forma estruturada, usando um mecanismo de gráfico de conhecimento auto-hospedado.

## Instalação
**Instalação do pacote**

```
uv pip install cognee
```


## Execução
**Uso básico**

```
cognee-cli remember "Cognee turns documents into AI memory."
```

**Iniciando a interface**

```
cognee-cli -ui
```


## Se você não programa
Usando o Cognee, quero armazenar meus dados em uma estrutura de gráfico de conhecimento e permitir que meu agente recupere esses dados, mantendo-os em sua memória de longo prazo. Crie um fluxo de trabalho que me permita memorizar dados com a função cognee.remember() e gerar respostas significativas com base nesses dados com cognee.recall().
