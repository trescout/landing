Agregue 34 provedores LLM gratuitos em uma API OpenAI unificada

O FreeLLMAPI unifica 34 provedores gratuitos de grandes modelos de linguagem sob uma interface compatível com OpenAI com roteamento inteligente e failover.

  • ★ 21.410
  • TypeScript
  • GitHub Trending · 2026-08-28

Atualizações

  • 28 de agosto de 2026: 21.410 estrelas, integrando 34 provedores gratuitos de IA com suporte a streaming.

O que você ganha

  • 34 provedores de modelos gratuitos: Gateway unificado integrado a Google Gemini, Groq, Cloudflare Workers AI e HuggingFace sem custos de assinatura.
  • Compatibilidade direta com a API OpenAI: Endpoint /v1/chat/completions pronto para uso com LangChain, LlamaIndex e SDKs oficiais.
  • Roteamento inteligente e failover automático: Redireciona solicitações para provedores alternativos quando limites de uso ou falhas ocorrem.
  • Streaming via Server-Sent Events (SSE): Transmissão de tokens em tempo real para interfaces de usuário com baixa latência.
  • Implantação leve e prática: Inicie instâncias locais ou de produção em segundos via Docker ou ambiente Node.js.

Instalação

Clonar o repositório e instalar dependências
git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
npm install

Execução

Iniciar servidor e enviar requisição
npm start
# OpenAI uyumlu istek:
curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Merhaba!"}]}'

Arquitetura técnica e princípio de funcionamento

O FreeLLMAPI atua como um proxy reverso convertendo payloads no padrão OpenAI em esquemas de cada provedor:

  • Camada de adaptadores de provedores: Normaliza diferentes protocolos REST e WebSocket em respostas JSON padrão OpenAI.
  • Balanceamento de carga e rastreamento de cotas: Monitora limites de taxa para direcionar o tráfego aos endpoints mais responsivos.
  • Cache em memória e lógica de retentativas: Armazena em cache prompts frequentes e repete requisições temporariamente indisponíveis.

Roteamento de modelos e resiliência de failover

Desenvolvedores utilizam o FreeLLMAPI para realizar testes de nível de produção sem custos de API:

  • Benchmarking de múltiplos modelos: Envie prompts idênticos para diferentes modelos e compare a precisão e o tempo de resposta.
  • Prototipagem e MVPs a custo zero: Crie e teste produtos orientados a inteligência artificial sem cadastrar cartões de crédito ou chaves pagas.
  • Resiliência com pipelines de fallback: Evite indisponibilidade alternando automaticamente para modelos secundários se o provedor principal cair.

Perguntas frequentes

  • Preciso comprar chaves de API para usar o FreeLLMAPI? Não. O proxy consolida 34 provedores que oferecem camadas gratuitas ou inferência pública sem planos pagos.
  • Quais grandes modelos de linguagem são suportados? Suporta famílias como Llama 3, Mistral, Gemma e endpoints gratuitos do Google Gemini.
  • É adequado para privacidade de dados corporativos? O FreeLLMAPI executa localmente, mas os provedores gratuitos de backend possuem suas próprias políticas de retenção de dados.
  • Ele é compatível com LangChain ou CrewAI? Sim. Por emular a especificação da OpenAI, basta definir a baseURL como localhost:3000/v1 em frameworks como LangChain ou CrewAI.
