# Padrão de código aberto de processamento de imagem

OpenCV, uma biblioteca de visão computacional de código aberto, oferece uma ampla gama de ferramentas para processamento de imagens e aplicativos de aprendizado de máquina. Esta biblioteca, desenvolvida em linguagem C++, serve como infraestrutura padrão em processos de análise visual de dados em tempo real.

## O que você ganha
- Analise dados visuais em tempo real
- Gerencie processos de processamento de imagens com infraestrutura padrão
- Acesse ferramentas abrangentes para aplicativos de aprendizado de máquina

**Python (pip)**

```
pip install opencv-python
```
