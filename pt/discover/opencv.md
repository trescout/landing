# Padrão de código aberto de processamento de imagem

OpenCV, uma biblioteca de visão computacional de código aberto, oferece uma ampla gama de ferramentas para processamento de imagens e aplicativos de aprendizado de máquina. Esta biblioteca, desenvolvida em linguagem C++, serve como infraestrutura padrão em processos de análise visual de dados em tempo real.

**Nota da TreScout:** Não para treinar o modelo de IA, mas para lidar com a imagem em si: corte, correção de cores, detecção de bordas, leitura da imagem da câmera. Quando é necessário treinar um modelo, são utilizadas bibliotecas separadas para esse fim, isso não as substitui. Sua instalação é um comando único, podendo exigir pacotes adicionais para formatos de vídeo.
