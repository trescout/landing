# Processos de engenharia apoiados por inteligência artificial

Engenharia de Compostos; Claude Code é um complemento oficial para Codex e Cursor. A sua filosofia básica é clara: cada tarefa de engenharia deve tornar a próxima mais fácil, e não mais difícil. Para isso, oferece capacidades e agentes de IA que melhoram o processo de desenvolvimento.

- TypeScript
- MIT
- GitHub Trending · 29 May 2026

## O que você ganha
- Cada tarefa torna a próxima mais fácil, fazendo com que sua produtividade aumente cumulativamente.
- Fornece habilidades e agentes prontos.
- Adapta-se facilmente a vários ambientes de IA.

## Instalação
**Adicionar marketplace do Claude Code**

```
/plugin marketplace add EveryInc/compound-engineering-plugin
/plugin install compound-engineering
```


## Execução
**Iniciar assistente de instalação**

```
/ce-setup
```


## Como começar
Você pode instalá-lo como um complemento ao seu assistente de IA e, em seguida, incorporar as habilidades e os agentes ao seu fluxo de trabalho.

## Como instalar, como usar?
Se você estiver trabalhando no Claude Code, instale o plugin Compound Engineering executando estes dois comandos em sequência: '/plugin marketplace add EveryInc/compound-engineering-plugin' seguido por '/plugin install compound-engineering'; Terminada a instalação, prepare o ambiente executando o comando '/ce-setup' em qualquer projeto.
