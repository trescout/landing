# Gerencie seus serviços em tempo real

iii é um método para criar, estender e monitorar todos os serviços em sua pilha de back-end (fila, cron, HTTP, estado, observabilidade, agentes, sandbox) em tempo real. Faz com que peças que normalmente apresentam dificuldades de integração separadas possam ser gerenciadas a partir de um único ponto.

## O que você ganha
- Fila, cron, HTTP e gerenciamento de estado em um só lugar.
- Oportunidade de rastreabilidade em tempo real.
- Suporte a agente e sandbox.
- Reduz a complexidade nos processos de integração.

## Como começar
Para começar e acessar a documentação, você pode visitar iii.dev.

## Como instalar, como usar?
**Criar projeto**

```
iii project init myapp
```

**ligar o motor**

```
cd myapp
iii
```

**Adicionar trabalhador (habilidade)**

```
iii worker add queue
```

**Instale o SDK do Node.js.**

```
npm install iii-sdk
```
