# Servidor web de alto desempenho e proxy reverso

O repositório de código aberto NGINX continua a ser desenvolvido em C como um servidor web de alto desempenho e proxy reverso. O software oferece uma solução padrão em infraestruturas de grande escala para gerenciar o tráfego de rede e otimizar a distribuição de conteúdo.

## O que você ganha
- Servidor web de alto desempenho e gerenciamento de proxy reverso.
- Recursos avançados de balanceamento de carga e cache de conteúdo.
- Instalação de infraestrutura flexível e escalável graças à sua estrutura modular.

## Instalação
**Instalando Dependências**

```
sudo apt install gcc make
```

**Instalação das bibliotecas necessárias**

```
sudo apt install libpcre3-dev zlib1g-dev
```


## Execução
**Controle de módulo estático**

```
nginx -V
```
