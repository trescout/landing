## Instalação

**Clonar repositório oficial**

```
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
```

## Execução

**Iniciar com Docker Compose**

```
docker-compose up
```

**Iniciar interface web**

```
uv run streamlit run ./webui/Main.py --browser.gatherUsageStats=False
```

## nota honesta

Requer uma chave API do modelo AI + instalação para funcionar; O uso da API pode ser cobrado. É responsabilidade do usuário garantir que os vídeos produzidos cumpram as regras de direitos autorais e da plataforma.
