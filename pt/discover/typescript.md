# Erro ao verificar projetos JavaScript

TypeScript, um superconjunto da linguagem JavaScript, permite a verificação de erros durante a fase de compilação do código. Ele suporta processos de desenvolvimento de software mais confiáveis ​​e escaláveis ​​com seu recurso de digitação estática.

- ★ 110.042
- TypeScript
- GitHub Trending · 2026-07-11

## O que você ganha
- Verificando erros ao escrever código
- Confiabilidade com identificação de tipo estático
- Processos escaláveis de desenvolvimento de software

## Instalação
**instalação global com npm**

```
npm install -g typescript
```

**Adicionar como dependência do projeto**

```
npm install --save-dev typescript
```


## Execução
**Compilar arquivo TypeScript**

```
tsc index.ts
```
