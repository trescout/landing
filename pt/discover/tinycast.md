# Lançador de aplicativos leve para macOS

Tinycast é um lançador de aplicativos leve, gerenciador de atalhos e ferramenta de histórico da área de transferência desenvolvido para o sistema operacional macOS. Escrito em Swift, este software nativo visa acelerar os fluxos de trabalho na área de trabalho usando os recursos do sistema de forma eficiente.

## Instalação

**Adicionando o repositório ao sistema**

```
brew trust --tap abue-ammar/tinycast   # required for third-party taps
brew tap abue-ammar/tinycast
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Para ativar os recursos de inteligência artificial no Tinycast, defina sua própria chave de API ou as informações de uma conta de IA configurada no menu Configurações. Após esse processo, você pode iniciar chats diretamente pela paleta e realizar operações rápidas em textos selecionados, como correção gramatical, resumo ou tradução.
