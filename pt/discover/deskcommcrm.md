# CRM de código aberto com IA para WhatsApp

DeskcommCRM é uma plataforma de gestão de relacionamento com o cliente (CRM) de código aberto desenvolvida para empresas que realizam vendas via chat. Com integração ao WhatsApp e agentes de IA integrados, oferece uma alternativa auto-hospedável a softwares comerciais com funcionalidades semelhantes (Kommo, Octadesk, Intercom).

- ★ 1.491
- TypeScript
- GitHub Trending · 2026-09-12

## O que você ganha
- Permite vendas automáticas e gestão de clientes via WhatsApp.
- Oferece controle total sobre seus dados ao hospedar em seu próprio servidor.
- Permite acesso a todos os recursos sem pagar mensalidades.

## Instalação
**Iniciar a instalação do servidor**

```
curl -fsSL https://raw.githubusercontent.com/melgarafael/DeskcommCRM/main/hostgator-setup-kit/comecar.sh | bash
```

**Concluir a instalação em um VPS**

```
git clone https://github.com/melgarafael/DeskcommCRM.git
cd DeskcommCRM
bash hostgator-setup-kit/install.sh
```
