# Gerenciamento de tarefas assíncronas com inteligência artificial

pi-subagents é uma biblioteca TypeScript desenvolvida para gerenciar processos assíncronos de delegação de subagentes na plataforma Pi. Facilita a distribuição de cargas de trabalho complexas para subagentes.

- ★ 3.200
- TypeScript
- Lisans: yok
- GitHub Trending · 1 Haziran 2026

## O que você ganha
- Distribui a carga de trabalho aos subagentes.
- Fornece execução assíncrona e paralela.
- Funciona totalmente integrado à plataforma Pi.

## Como instalar, como usar?
**instalar com pi**

```
pi install npm:pi-subagents
```

**Execute um subagente**

```
/run <ajan> [görev]
```

**Execute agentes em paralelo**

```
/parallel ajan1 "görev1" -> ajan2 "görev2"
```
