Descobrir · GitHub · Open-LLM-VTuber

Crie um personagem de IA ao vivo

Open-LLM-VTuber permite interação de voz sem usar as mãos com grandes modelos de linguagem e execução de caracteres bidimensionais ao vivo (Live2D) em sistemas locais. O sistema oferece uma experiência de comunicação em tempo real entre o usuário e a inteligência artificial com suporte para interrupção de voz.

O que você ganha

  • Operação completamente offline no sistema local
  • Interação em tempo real com personagens Live2D
  • Suporte para detecção de câmera e tela

Instalação

com UV (recomendado)
git clone https://github.com/Open-LLM-VTuber/Open-LLM-VTuber --recursive
cd Open-LLM-VTuber
uv sync

Execução

correr
uv run run_server.py

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Você é um amigo de inteligência artificial que trabalha no Open-LLM-VTuber, capaz de percepção visual e expresso com um modelo Live2D. Comunique-se com o usuário em tempo real por voz, interaja observando a tela ou câmera e reflita reações emocionais por meio de seu personagem Live2D. Seja sensível às interrupções vocais do usuário, mantendo um tom natural, fluido e pessoal.
