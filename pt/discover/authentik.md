# Gerenciamento central de identidade para seus aplicativos

Authentik é uma plataforma de segurança de código aberto que fornece autenticação centralizada e gerenciamento de acesso para aplicativos. Ao combinar processos complexos de autenticação em um único ponto, oferece transição segura entre diferentes serviços.

## O que você ganha
- Fornece transição segura entre diferentes serviços a partir de um único ponto
- Suporta protocolos padrão como SAML e OAuth2
- Escalável desde pequenos projetos até sistemas de grande escala

## Como começar
- Fonte oficial →
Para instalação, acesse a página de documentação no site oficial. Você pode escolher Docker Compose para instalações pequenas ou de teste e Kubernetes para estruturas de grande escala. Também é possível instalar via AWS ou usar a app store DigitalOcean.
