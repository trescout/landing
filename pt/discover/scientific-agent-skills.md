# Dê capacidades de pesquisa científica ao seu agente de IA

Scientific-agent-skills é uma biblioteca que contém 163 habilidades (skills) verificadas e mais de 100 bancos de dados científicos, especializada em agentes de inteligência artificial em processos de pesquisa científica. Ela permite que agentes que trabalham nas áreas de biologia, química e medicina realizem análises de dados de forma compatível com plataformas como o editor de código Cursor ou o assistente de inteligência artificial Claude Code.

## O que você ganha
- Oferece 163 habilidades científicas diferentes nas áreas de biologia, química e medicina.
- Ele fornece interação direta com mais de 100 bases de dados científicas.
- Funciona de forma compatível com ferramentas de inteligência artificial, como editor de código Cursor e Claude Code.

## Instalação
**Instalação em nível de usuário**

```
git clone https://github.com/K-Dense-AI/scientific-agent-skills.git ~/.agents/skills/scientific-agent-skills   # user-level
```

**Configuração no nível do projeto**

```
git clone https://github.com/K-Dense-AI/scientific-agent-skills.git .agents/skills/scientific-agent-skills      # project-level
```


## Se você não programa
Você agora é um assistente especializado em pesquisa científica. Execute análises complexas de dados, pesquisas bibliográficas e processos de modelagem em biologia, química e medicina usando 163 habilidades na biblioteca Scientific Agent Skills. Baseie seu trabalho em bancos de dados científicos atuais e apresente seus resultados com evidências verificáveis.
