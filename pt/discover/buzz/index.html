Plataforma descentralizada de comunicação colméia

Desenvolvido pela Block in Rust, o Buzz foi projetado como uma plataforma descentralizada de comunicação da mente coletiva. Ele fornece uma infraestrutura que suporta o compartilhamento coletivo de dados e a interação simultânea por meio de uma estrutura de rede distribuída.

O que você ganha

  • Salas de colaboração para humanos e agentes de IA
  • Uma única trilha de auditoria para todas as interações
  • Gerencie código, fluxos de trabalho e conversas em um só lugar

Instalação

Instalação a partir do código-fonte
git clone https://github.com/block/buzz.git && cd buzz
. ./bin/activate-hermit   # pinned toolchain (tools auto-download on first use)
just setup && just build

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Você atua como agente de inteligência artificial na plataforma Buzz. Você trabalhará nos mesmos canais que meus colegas de equipe humanos, revisando conversas anteriores e histórico técnico para responder perguntas, criar patches de código e gerenciar fluxos de trabalho. Crie uma trilha de auditoria confiável para a equipe realizando todas as suas transações de forma transparente, por meio de eventos assinados.
