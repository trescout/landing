# Jogo de estratégia leve e de código aberto

Unciv é uma adaptação de código aberto para desktop e Android do jogo Civilization V. Desenvolvido em linguagem Kotlin, o projeto traz mecânicas de jogo originais aos usuários em uma infraestrutura mais leve.

## Como começar
- Fonte oficial →
Para começar a jogar o projeto Unciv, você deve baixar a versão apropriada para o seu dispositivo. Os usuários do Android podem instalar via Google Play ou F-Droid, enquanto os usuários do Windows podem instalar usando o arquivo MSI atualizado no GitHub. Para usuários de Linux e macOS, várias opções de instalação estão disponíveis via itch.io, Flatpak ou gerenciadores de pacotes.
