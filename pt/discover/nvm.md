# Gerencie facilmente versões do Node.js.

Node Version Manager é uma ferramenta de linha de comando que permite aos desenvolvedores gerenciar várias versões do Node.js em seus sistemas. Com sua estrutura de script shell compatível com POSIX (script bash), torna mais fácil fazer transições rápidas de versão entre diferentes projetos.

- ★ 94.519
- Shell
- GitHub Trending · 2026-08-12

## O que você ganha
- Alterne rapidamente entre diferentes versões do Node.js.
- Trabalhe perfeitamente em shells compatíveis com POSIX
- Instale facilmente versões Node.js específicas do projeto

## Instalação
**Instalação usando cURL**

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
```

**Instalação usando wget**

```
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
```


## Execução
**Instalando e usando a versão Node.js**

```
nvm install 24
```
