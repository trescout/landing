# Especialização em SwiftUI para o seu assistente de inteligência artificial

O SwiftUI-Agent-Skill oferece pacotes de habilidades (skills) especiais para modelos de inteligência artificial para a ferramenta de desenvolvimento de interface SwiftUI. Este recurso ajuda assistentes de codificação de IA, como o Claude Code e o Codex, a criar componentes SwiftUI de forma mais consistente e rápida.

## O que você ganha

- Permite que a inteligência artificial inspecione erros de desempenho e acessibilidade em códigos escritos com a biblioteca de interface da Apple, SwiftUI.
- Evita que grandes modelos de linguagem usem interfaces de programação de aplicativos (APIs) antigas e previne problemas de leitura de tela.
- Integra-se facilmente aos assistentes de codificação Claude Code e Codex, proporcionando padrões de código modernos.

## Instalação

**Ambiente Node com o gerenciador de pacotes Homebrew**

```
brew install node
```

**Habilidade SwiftUI Pro para o assistente de IA**

```
npx skills add https://github.com/twostraws/swiftui-agent-skill --skill swiftui-pro
```
