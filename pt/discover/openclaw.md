# O assistente de inteligência artificial pessoal executado no seu dispositivo

O Openclaw é uma ferramenta de automação baseada em inteligência artificial capaz de executar tarefas em diferentes sistemas operacionais e plataformas. Desenvolvido com TypeScript, este software permite que os usuários padronizem e automatizem operações no computador.

- ★ 391.115
- TypeScript
- GitHub Trending · 2026-10-01

## O que você ganha
- Você mantém seus dados, memória e informações de conta com total segurança diretamente no seu próprio computador.
- Você pode conversar com o seu assistente por meio dos aplicativos de mensagens WhatsApp, Telegram, Discord e da ferramenta de comunicação corporativa Slack.
- Você pode gerenciar facilmente diferentes modelos de inteligência artificial e ferramentas de sistema locais a partir de um único local.

## Instalação
**Executando o script de instalação automática (ma**

```
# macOS / Linux / WSL2
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Globalmente com o gerenciador de pacotes do Node.js, o npm**

```
npm install -g openclaw@latest --allow-scripts=openclaw
```
