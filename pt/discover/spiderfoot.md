# Ferramenta de coleta de inteligência de código aberto

SpiderFoot é uma ferramenta Python que automatiza a coleta de inteligência de código aberto (OSINT) para inteligência de ameaças e processos de mapeamento de superfície de ataque. Permite detectar vulnerabilidades de segurança em ativos digitais, integrando várias fontes de dados.

- ★ 20.026
- Python
- GitHub Trending · 2026-06-22

## O que você ganha
- Coleta automática de dados com mais de 200 módulos
- Interface baseada na Web ou suporte de linha de comando
- Mapeamento abrangente da superfície de ataque para ativos digitais

## Instalação
**Instalação de versão estável**

```
wget https://github.com/smicallef/spiderfoot/archive/v4.0.tar.gz
 tar zxvf v4.0.tar.gz
 cd spiderfoot-4.0
 pip3 install -r requirements.txt
 python3 ./sf.py -l 127.0.0.1:5001
```

**Instalação da versão de desenvolvimento**

```
git clone https://github.com/smicallef/spiderfoot.git
 cd spiderfoot
 pip3 install -r requirements.txt
 python3 ./sf.py -l 127.0.0.1:5001
```


## Execução
**Iniciando a interface**

```
python3 ./sf.py -l 127.0.0.1:5001
```
