# Transfira os dados do portal do Spotify para o assistente de codificação

O portal-ai-plugins, desenvolvido pelo Spotify, permite integrar o sistema Spotify Portal a ferramentas de codificação baseadas em inteligência artificial, como Claude Code, Codex, Cursor e pi. Escritos em TypeScript, esses plugins facilitam o acesso dos desenvolvedores a dados provenientes do Spotify em seus ambientes de trabalho.
