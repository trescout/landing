# Escrevendo código limpo com JavaScript

Este guia, que adapta princípios de código limpo à linguagem JavaScript, oferece padrões para escrever código legível e de fácil manutenção em processos de desenvolvimento de software. Combina programação orientada a objetos e princípios de programação funcional com exemplos práticos.

## O que você ganha
- Padrões de código legíveis e fáceis de manter
- Práticas funcionais e orientadas a objetos
- Configuração que facilita a depuração

## Como começar
- Fonte oficial →
Esta ferramenta é um guia, não uma biblioteca de software. Ao visitar o repositório clean-code-javascript no GitHub, você pode examinar seções como nomenclatura de variáveis, design de funções e princípios SOLID, e melhorar a qualidade do seu código aplicando esses padrões em seus próprios projetos.
