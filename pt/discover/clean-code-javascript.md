## O que esta ferramenta faz?
Clean Code JavaScript é um guia de código aberto que adapta os famosos princípios de 'Clean Code' de Robert C. Martin ao ecossistema JavaScript. Ele exemplifica padrões para escrever código legível, reutilizável e sustentável com JavaScript moderno.

## Para quem é?
Para aqueles que desejam melhorar a qualidade do seu código JavaScript e desenvolver softwares sustentáveis com padrões profissionais.

## O que não esperar
Iniciantes absolutos que ainda não conhecem a linguagem JavaScript nem mesmo em um nível básico.

## Destaques
- Adapta os princípios tradicionais de engenharia de software para o JavaScript.
- Apresenta práticas de código ruim e bom lado a lado para comparação.
- Fornece um escopo amplo, desde a nomeação de variáveis até o tratamento de erros.

## Primeiro fluxo de uso
- Acesse o repositório oficial do GitHub para conferir o sumário.
- Leia os exemplos de código Ruim (Bad) e Bom (Good) para os conceitos com os quais você tem mais dificuldade.
- Coloque em prática os princípios aprendidos aplicando-os em seus próprios projetos.
