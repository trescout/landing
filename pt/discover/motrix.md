# Gerenciador de download moderno e abrangente

Motrix é um gerenciador de download abrangente desenvolvido em TypeScript que atende a todas as necessidades de download de arquivos. Oferece aos usuários a oportunidade de gerenciar diferentes protocolos como HTTP, FTP e BitTorrent através de uma única interface.

- ★ 53.422
- TypeScript
- GitHub Trending · 2026-08-18

## O que você ganha
- Gerencia protocolos HTTP, FTP e BitTorrent a partir de uma única interface
- Limita as velocidades de download e oferece gerenciamento avançado de sessões
- Inicia downloads com um clique com complementos do navegador

## Instalação
**Instalando a interface da linha de comandos**

```
npm install -g @motrix/cli
```


## Execução
**Iniciando o download do arquivo**

```
motrix add https://example.com/file.iso --save-dir ~/Downloads
```


## Se você não programa
Ajude-me a gerenciar tarefas de download usando a interface de linha de comando do Motrix. Use 'motrix list' para visualizar a lista de downloads, 'motrix add [URL] --save-dir [DIRECTORY]' para adicionar um novo arquivo e 'motrix watch --stats' para rastrear o progresso do download ao vivo. Se eu precisar me conectar a um servidor remoto, ative o comando 'motrix pair'.
