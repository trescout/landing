# Gestão de receitas com inteligência artificial

AiToEarn é uma plataforma baseada em TypeScript que permite aos usuários gerenciar seus processos de monetização por meio de automações baseadas em IA. O projeto oferece uma infraestrutura aberta aos desenvolvedores, combinando execução autônoma de tarefas e modelos de ganhos baseados em inteligência artificial.

- ★ 24.551
- TypeScript
- GitHub Trending · 2026-06-08

## O que você ganha
- Ele gerencia a criação de conteúdo com suporte de inteligência artificial e processos de publicação automática.
- Permite gerar receita com conteúdo com modelos CPS, CPE e CPM.
- Oferece interação simultânea e gerenciamento de seguidores em múltiplas plataformas de mídia social.

## Instalação
**Configuração rápida com Docker**

```
git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn
docker compose up -d
```

**Instalação do plug-in OpenClaw**

```
npx -y @aitoearn/openclaw-plugin-cli
```


## Execução
**Lançando com Docker**

```
docker compose up -d
```
