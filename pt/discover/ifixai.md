# Audite agentes de inteligência artificial

O iFixAi é uma ferramenta de auditoria independente que verifica se os agentes de inteligência artificial realizam corretamente as tarefas atribuídas a eles. Desenvolvido em Python, este sistema pode ser executado por humanos ou pelo próprio agente para analisar a precisão dos processos em menos de dois minutos.

## Instalação

**Instale o pacote**

```
pip install "ifixai[openai]"   # or anthropic, gemini, etc.: install the provider extra you'll test
```

**Abra o assistente de instalação**

```
ifixai setup                    # arrow-key wizard: pick provider, model, judge, suite → writes ifixai.yaml
```

## Execução

**Execute a ferramenta**

```
ifixai run                      # no flags needed; reports land in ./ifixai-results/
```
