# Cliente YouTube avançado para Android TV

O SmartTube é um cliente YouTube desenvolvido para dispositivos Android TV, oferecendo recursos avançados como bloqueio de anúncios e uma interface personalizável. Ele permite que os usuários gerenciem suas experiências de visualização de vídeos de acordo com suas próprias regras.

## O que você ganha

- Experiência de visualização de vídeo sem anúncios e personalizável
- Pular conteúdo patrocinado dentro dos vídeos com o SponsorBlock
- Estrutura de operação independente que não requer Serviços do Google

## Como começar

Instale o aplicativo Downloader no seu dispositivo Android TV. Abra o aplicativo, insira kutt.to/stn_beta para a versão beta ou kutt.to/stn_stable para a versão estável e conclua a instalação seguindo as confirmações de segurança na tela.
