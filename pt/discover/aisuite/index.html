Gerencie modelos de IA em uma única interface

Desenvolvido por Andrew Ng, aisuite é uma biblioteca Python que permite gerenciar diferentes provedores de IA generativa por meio de uma única interface. Ele permite que os desenvolvedores alternem entre vários serviços de modelo sem fazer alterações no código.

O que você ganha

  • Gerencie diferentes provedores de IA com uma única interface
  • Capacidade de alternar entre modelos sem alterar o código
  • Definindo funções Python como ferramentas para inteligência artificial

Instalação

Instalação básica da biblioteca
pip install aisuite               # base package, no provider SDKs
Configuração com todos os provedores
pip install 'aisuite[all]'        # with all provider SDKs
