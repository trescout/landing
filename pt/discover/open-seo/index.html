Plataforma de dados e análise de SEO de código aberto

Open SEO oferece uma alternativa de código aberto para ferramentas pagas como Semrush e Ahrefs. Este software, desenvolvido para analisar dados de otimização de mecanismos de busca (SEO), tem como objetivo tornar os processos transparentes com sua infraestrutura baseada em TypeScript.

Instalação

Adicionando recursos a um agente de IA
npx skills add every-app/open-seo --skill '*'
Instalação local com Docker
docker compose pull
docker compose up -d

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Conduza pesquisas detalhadas de palavras-chave para meu site usando recursos OpenSEO e analise meus dados de classificação atuais para fornecer sugestões de melhorias.
