# Encontre contas registradas por e-mail

Holehe é uma ferramenta Python que consulta se um endereço de e-mail inserido é usado em plataformas populares como Twitter e Instagram. Ele detecta as informações da conta associadas ao e-mail relevante usando funções de redefinição de senha.

- ★ 14.563
- Python
- GitHub Trending · 2026-08-14

## O que você ganha
- Consulta de e-mail em mais de 120 plataformas
- Não enviar notificações para o endereço de e-mail de destino
- Detectado usando funções de redefinição de senha

## Instalação
**Instalação com PyPI**

```
pip3 install holehe
```

**Instalação via GitHub**

```
git clone https://github.com/megadose/holehe.git
cd holehe/
python3 setup.py install
```


## Execução
**Consulta por e-mail**

```
holehe test@gmail.com
```


## Se você não programa
Utilizando a ferramenta Holehe, verifique em quais plataformas o endereço [E-MAIL_ADRESI] está cadastrado e apresente os resultados em uma lista.
