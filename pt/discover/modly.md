# Crie modelos tridimensionais a partir de imagens

Modly é um aplicativo de desktop que cria modelos 3D a partir de imagens e executa todas as operações na placa gráfica local (GPU). Essa ferramenta, que funciona sem a necessidade de conexão com a internet, leva o processo de modelagem apoiado por inteligência artificial para os computadores pessoais.

- ★ 7.347
- TypeScript
- GitHub Trending · 2026-08-14

## O que você ganha
- Converte fotos em modelos 3D no computador local
- Funciona completamente offline, sem necessidade de conexão com a Internet
- Oferece uma estrutura flexível que pode ser ampliada com modelos externos

## Instalação
**Instalando dependências**

```
npm install
```

**Preparando a infraestrutura Python**

```
cd api
python -m venv .venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate  # Linux / macOS
pip install -r requirements.txt
```


## Execução
**Iniciando o aplicativo**

```
# Windows
launch.bat

# Linux / macOS
./launch.sh
```


## Se você não programa
Quero converter uma imagem em um modelo 3D usando o aplicativo Modly. Ajude-me a configurar o fluxo 'Imagem -> Gerar malha -> Adicionar à cena' acessando a guia 'Fluxos de trabalho' no aplicativo. Então, deixe-me iniciar a geração do modelo 3D selecionando o fluxo de trabalho relevante na guia “Gerar”. Se eu receber um erro, como posso analisar o problema na seção 'Configurações/Registros/Erros'?
