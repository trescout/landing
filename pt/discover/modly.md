# Crie modelos tridimensionais a partir de imagens

Modly é um aplicativo de desktop que cria modelos 3D a partir de imagens e executa todas as operações na placa gráfica local (GPU). Essa ferramenta, que funciona sem a necessidade de conexão com a internet, leva o processo de modelagem apoiado por inteligência artificial para os computadores pessoais.

## O que você ganha

- Converte fotos em modelos 3D no computador local
- Funciona completamente offline, sem necessidade de conexão com a Internet
- Oferece uma estrutura flexível que pode ser ampliada com modelos externos

## Instalação

**Instalando dependências**

```
npm install
```

**Preparando a infraestrutura Python**

```
cd api
python -m venv .venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate  # Linux / macOS
pip install -r requirements.txt
```

## Execução

**Iniciando o aplicativo**

```
# Windows
launch.bat

# Linux / macOS
./launch.sh
```
