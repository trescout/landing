# Integração de IA para TradingView

TradingView-mcp conecta Claude Code com o aplicativo de desktop TradingView, permitindo automatizar processos de análise de gráficos. Essa integração permite que os usuários personalizem fluxos de trabalho de análise técnica por meio de contexto de modelo baseado em IA (Model Context Protocol).

- ★ 5.932
- JavaScript
- GitHub Trending · 2026-07-22

## O que você ganha
- Codificação e depuração do Pine Script com inteligência artificial
- Gerenciamento automático de desenho e análise no gráfico
- Controle alertas de preços e símbolos por comando

## Instalação
**Baixando arquivos e instalação**

```
git clone https://github.com/tradesdontlie/tradingview-mcp.git
cd tradingview-mcp
npm install
```

**Iniciando no macOS**

```
./scripts/launch_tv_debug_mac.sh
```


## Execução
**Uso direto via CLI**

```
# Install globally (optional)
npm link

# Or run directly
node src/cli/index.js <command>
```


## Se você não programa
Você se conectou ao meu aplicativo de desktop TradingView. Agora, quando eu quiser que você realize análises técnicas no gráfico, revise os códigos do Pine Script ou altere as configurações do gráfico, quero que você intervenha na interface do TradingView usando esta ferramenta. Execute os comandos necessários para ler os dados do gráfico, analisar os valores dos indicadores ou adicionar novos gráficos.
