# Experiência de terminal com visual de tela antiga

Cool-retro-term é um emulador de terminal que imita a aparência de telas antigas de tubo de raios catódicos. Desenvolvido com a linguagem QML, este software adiciona uma estética visual nostálgica à experiência moderna de linha de comando.

## O que você ganha
- Oferece a aparência nostálgica de telas antigas de tubo de raios catódicos
- Permite personalização de cores, fontes e efeitos visuais
- Funciona como um emulador de terminal leve e elegante em sistemas operacionais modernos

## Como começar
Para usar a versão mais recente no seu sistema operacional Linux ou macOS, você pode acessar a página de Releases no GitHub e baixar o arquivo AppImage ou dmg. Alternativamente, você pode instalar através dos repositórios oficiais de pacotes de várias distribuições, como Ubuntu, Fedora ou Arch.
