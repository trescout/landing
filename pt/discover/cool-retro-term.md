# Experiência de terminal com visual de tela antiga

Cool-retro-term é um emulador de terminal que imita a aparência de telas antigas de tubo de raios catódicos. Desenvolvido com a linguagem QML, este software adiciona uma estética visual nostálgica à experiência moderna de linha de comando.
