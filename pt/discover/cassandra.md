# Banco de dados escalável para sistemas distribuídos

Apache Cassandra é um banco de dados transacional distribuído de código aberto que fornece escalabilidade linear e tolerância a falhas sem causar perda de desempenho em hardware padrão ou infraestruturas de nuvem. Este sistema, desenvolvido em linguagem Java, é projetado para processos de gerenciamento de dados em grande escala que exigem alta disponibilidade.

- ★ 10.004
- Java
- GitHub Trending · 2026-07-28

## O que você ganha

- Distribui dados automaticamente em várias máquinas.
- Fácil gerenciamento de dados com linguagem de consulta CQL semelhante a SQL.
- Fornece alta disponibilidade e tolerância a falhas.

## Instalação

**macOS (Homebrew)**

```
brew install cassandra
```

**Imagem do Docker**

```
docker pull cassandra
```

## Execução

**Lançar com Docker**

```
docker run -p 9042:9042 cassandra
```
