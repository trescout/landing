Computador de sobrevivência sem Internet

Projeto N.O.M.A.D; É um projeto de construção de computadores off-line, autossuficiente, que não requer conexão com a internet e está equipado com ferramentas críticas, recursos de informação e inteligência artificial. Foi especialmente desenvolvido para emergências e cenários onde não há internet.

O que você ganha

  • Oferece ferramentas e informações críticas que não requerem internet.
  • Fornece suporte de inteligência artificial local (offline).
  • Permite a preparação para cenários de emergência e offline.

Como instalar, como usar?

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Em um sistema baseado em Debian (recomendado Ubuntu), cole e execute o comando de instalação abaixo no terminal e abra http://localhost:8080 no navegador para me ajudar a usar o servidor de informações offline.

Instalação rápida (Debian/Ubuntu)
curl -fsSL https://raw.githubusercontent.com/Crosstalk-Solutions/project-nomad/refs/heads/main/install/install_nomad.sh -o install_nomad.sh
sudo bash install_nomad.sh
começar
sudo bash /opt/project-nomad/start_nomad.sh
