# Plataforma moderna de conteúdo e newsletter

Ghost é um sistema de gerenciamento de conteúdo (CMS) de código aberto desenvolvido para publicação moderna, gerenciamento de membros e envio de boletins informativos. Esta é uma plataforma baseada em JavaScript que fornece aos criadores de conteúdo a infraestrutura necessária para criar modelos de receita baseados em assinatura.

## O que você ganha
- Criação de modelos de receita baseados em assinatura
- Publicação de conteúdo moderno e profissional
- Boletim informativo rápido e gerenciamento de membros

## Instalação
**Instale a ferramenta de linha de comando**

```
npm install ghost-cli -g
```


## Execução
**Iniciar instalação local**

```
ghost install local
```

**Inicie a instalação no servidor**

```
ghost install
```
