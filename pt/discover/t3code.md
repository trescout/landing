# Interface web para agentes de codificação

T3Code é um conjunto de ferramentas desenvolvido para melhorar e padronizar a qualidade do código em projetos baseados em TypeScript. Ele fornece suporte de automação para desenvolvedores em processos de segurança de tipo e edição de código.

## Se você não programa

Cole isto no seu agente (Claude Code · Codex · Antigravity)

Usando a ferramenta T3 Code, configure um dos provedores Codex, Claude, Cursor ou OpenCode e inicie a interface do agente de codificação. Após concluir o processo de autenticação do provedor escolhido, execute a ferramenta e comece a receber suporte de codificação em seus projetos.

Repositório: https://github.com/pingdotgg/t3code. Baseie-se nas instruções oficiais no arquivo README deste repositório para a instalação e execução.

Antes de começar, verifique em qual sistema operacional estamos e se as ferramentas necessárias (ex: Python, Node.js, Git, Docker) estão instaladas. Instale as que faltarem passo a passo de acordo com este sistema.

Crie uma pasta nova e vazia para trabalhar. Não toque em arquivos fora desta pasta e não exclua nada. Antes de executar cada comando, diga o que você vai fazer em uma frase.

Diga-me o que devo ver na tela ao final de cada etapa. Se ocorrer um erro, colarei a mensagem de erro para você exatamente como ela é, e vamos corrigi-la juntos.
