# Kubernetes the Hard Way

Kubernetes the Hard Way, criado por Kelsey Hightower, é um guia que ensina a configurar a plataforma de gerenciamento de contêineres Kubernetes do zero, sem usar nenhum script de automação. Este trabalho oferece um recurso de treinamento técnico para usuários que desejam entender os componentes fundamentais e os princípios de funcionamento do sistema por meio de processos de configuração manual.
