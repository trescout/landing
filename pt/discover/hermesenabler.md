# Ative os mostradores Hermès para Apple Watch

pookjw/HermesEnabler é um software que disponibiliza os mostradores de relógio Hermès em todos os dispositivos Apple Watch que possuem versões do watchOS compatíveis. Esta ferramenta, que pode ser compilada no macOS com o Xcode ou instalada através de ferramentas de sideload como o Sideloadly, requer um Apple Watch emparelhado com um iPhone.

## Como começar

Pode efetuar a instalação no macOS utilizando a ferramenta de sideload Sideloadly ou o software de desenvolvimento Xcode. No Windows, pode utilizar a ferramenta da comunidade chamada WatchBridge. Pode descarregar os ficheiros de instalação a partir da página oficial do GitHub e seguir o guia.
