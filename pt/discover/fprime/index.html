Estrutura de desenvolvimento de software de voo da NASA

Desenvolvido pela NASA, F´ é uma estrutura de código aberto projetada para software de voo e sistemas embarcados. Escrita em C++, esta estrutura oferece um ambiente de desenvolvimento modular para naves espaciais e sistemas complexos.

Atualizações

O que você ganha

  • Estrutura modular para naves espaciais e sistemas embarcados
  • Ambiente de desenvolvimento rápido de software baseado em componentes
  • Geração automática de código e ferramentas de teste integradas

Instalação

Instalando a ferramenta Bootstrap
pip install fprime-bootstrap

Execução

Crie um novo projeto
fprime-bootstrap project
