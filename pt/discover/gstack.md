# Fábrica de desenvolvimento de software com inteligência artificial

Gstack é um sistema baseado na configuração Claude Code de Garry Tan e consiste em 23 ferramentas especializadas que desempenham diferentes funções, como CEO, designer, gerente de engenharia. Esta estrutura baseada em TypeScript oferece fluxos de trabalho definidos para automatizar processos de desenvolvimento de software.

## O que você ganha
- Fluxo de trabalho com 23 funções especializadas diferentes
- Revisão automatizada de código e controle de qualidade
- Alto aumento na velocidade de desenvolvimento de software

## Instalação
**Baixe e instale a ferramenta em seu computador**

```
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/gstack
cd ~/gstack && ./setup
```


## Se você não programa
Você agora é minha equipe de engenharia virtual. Analise meu projeto usando ferramentas Gstack, determine minha estratégia com /office-hours, crie meu plano de trabalho com /autoplan e verifique a qualidade do código com /review. Automatize todas as etapas do processo de desenvolvimento de software atuando como CEO, designer e gerente de engenharia.
