# Uma interface única para os seus modelos de inteligência artificial

O open-webui é uma interface amigável que permite interagir com modelos de inteligência artificial, como Ollama e OpenAI API. Ele oferece uma interface web (interface) desenvolvida para gerenciar modelos de linguagem locais ou baseados em nuvem.

## O que você ganha

- Você pode gerenciar todos os modelos de inteligência artificial locais e baseados em nuvem em uma única tela web.
- Você pode carregar seus próprios documentos no sistema para fazer perguntas e respostas com base nos seus textos e realizar pesquisas na internet.
- Você pode usar ferramentas de geração de imagens, pesquisa por voz, gerenciamento de calendário e anotações sem sair da área de bate-papo.

## Instalação

**Instalação com o gerenciador de pacotes do Python pip**

```
pip install open-webui
```

## Execução

**Iniciar com a ferramenta de conteinerização de software Docker**

```
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```
