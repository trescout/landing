# Orientação de inteligência artificial para testes de penetração

Reverse-skill oferece um pacote de roteamento apoiado por inteligência artificial para processos de engenharia reversa e testes de penetração. Com sua inicialização do conjunto de ferramentas e recursos de base de conhecimento de autodesenvolvimento, Claude Code se integra a ferramentas de codificação como Cursor e Cline.

## Instalação
**Baixe o repositório para o seu computador**

```
git clone https://github.com/zhaoxuya520/reverse-skill.git
```


## Se você não programa
Use este projeto como um guia em um teste de penetração ou tarefa de engenharia reversa. Antes de executar sua tarefa, revise as instruções no arquivo README_AI.md, cumpra as regras de roteamento no arquivo RULES.md e inicie o fluxo de trabalho determinando a metodologia correta por meio de MASTER-ROUTING.md.
