# Teste de penetração automático com inteligência artificial

VulnClaw automatiza processos de teste de penetração usando agentes de IA e o conjunto de ferramentas Model Context Protocol. A ferramenta processa comandos de linguagem natural e executa etapas completas de coleta de informações, verificação de vulnerabilidades, exploração e relatórios.

- ★ 2.646
- Python
- GitHub Trending · 2026-06-30

## O que você ganha
- Teste de penetração ponta a ponta com comandos de linguagem natural
- Verificação de segurança autônoma direcionada
- Relatórios automáticos e geração de PoC em Python

## Instalação
**Instalação via PyPI**

```
pip install vulnclaw
```

**Instalação a partir do código-fonte**

```
git clone https://github.com/Unclecheng-li/VulnClaw.git
cd VulnClaw
pip install -e .
```


## Execução
**Início rápido**

```
vulnclaw
```

**Verificação direcionada**

```
vulnclaw run <target>
```


## Se você não programa
Você é um testador de penetração. Usando a ferramenta VulnClaw, colete informações sobre o sistema de destino, execute etapas de verificação de vulnerabilidades e exploração. Use o mecanismo de resolução orientado a objetivos enquanto executa as operações, verifique suas descobertas e crie um relatório estruturado e código PoC baseado em Python no final do processo. Em cada etapa, proceda com base nos dados reais obtidos e evite suposições.
