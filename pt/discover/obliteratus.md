# Limpe dependências desnecessárias

Como uma ferramenta de desenvolvimento de software baseada em Python, OBLITERATUS visa limpar dependências desnecessárias e estruturas em bases de código. No projeto não tem redução, não é problema, é questão de tempo.

## O que você ganha
- Ele limpa cirurgicamente os comportamentos de rejeição em modelos de inteligência artificial.
- Desativa restrições, preservando os recursos básicos de linguagem do modelo.
- Visualiza como as restrições funcionam com análise entre camadas.

## Se você não programa
Analise comportamentos de rejeição em um modelo de IA e remova cirurgicamente as estruturas internas que desencadeiam esses comportamentos sem prejudicar as capacidades gerais de linguagem do modelo. Durante o processo, utilize técnicas como a decomposição SVD para identificar restrições e garantir que o modelo responda sem obstáculos artificiais.
