# Transforme seus projetos em gráficos de conhecimento para inteligência artificial

Graphify transforma diferentes tipos de dados, como arquivos de código, esquemas de banco de dados e documentação, em uma estrutura de gráfico de conhecimento consultável. Esta ferramenta baseada em Python visa criar uma camada central de dados para vários assistentes de codificação de IA.

## O que você ganha

- O código transforma seus arquivos e documentos em uma rede de informações consultáveis.
- Ele usa tecnologia nativa e rápida de tree-sitter para análise de código.
- Facilita a transição entre conceitos estabelecendo conexões entre arquivos.

## Instalação

**Instalação CLI**

```
uv tool install graphifyy      # install the CLI (or: pipx install graphifyy)
graphify install               # register the skill with your AI assistant
```

## Execução

**Análise de projeto**

```
/graphify .
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Converti este diretório de projeto em um gráfico de conhecimento usando Graphify. Agora, usando essa estrutura, quero que você analise as relações entre os conceitos no projeto, explique como os blocos de código complexos estão conectados entre si e detalhe a função dos nós mestres como 'APIRouter' no sistema. Distinga entre informações provenientes diretamente do código-fonte e conexões inferidas, levando em consideração as tags 'EXTRACTED' e 'INFERRED' ao realizar sua análise.
