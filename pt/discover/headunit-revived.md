# Transforme seu tablet na tela do Android Auto

O projeto revivido da unidade principal fornece um aplicativo que permite visualizar a interface do Android Auto em diferentes telas. Este software, desenvolvido em linguagem Kotlin, fornece uma solução alternativa de exibição para sistemas de infoentretenimento em veículos.

- ★ 1.484
- Kotlin
- GitHub Trending · 2026-06-25

## O que você ganha

- Use seu tablet ou telefone Android como display no carro
- Suporte para conexão com fio via USB
- Conexão sem fio confiável com Wireless Helper
