# Jogue Banjo Kazooie em sistemas modernos

Lighthouse é uma ferramenta de cobertura de código desenvolvida em linguagem C e projetada para sistemas de baixo nível. Ele fornece dados aos desenvolvedores para depuração e otimização de desempenho, analisando quais blocos de código são executados durante os processos de teste do software.

## O que você ganha
- Fornece suporte de plataforma moderna com arquivos originais do jogo
- Oferece pacote multilíngue e suporte para mod
- Inclui controlador personalizável e configurações gráficas

## Como começar
Baixe a versão do Lighthouse na página oficial de lançamentos do GitHub e extraia os arquivos em uma pasta. Depois de verificar seu próprio arquivo de jogo (ROM), selecione-o executando lighthouse.exe no Windows, lighthouse.appimage no Linux ou lighthouse no macOS.
