## Instalação

**Instalando dependências**

```
pnpm install
```

## Execução

**Iniciando o ambiente de desenvolvimento**

```
pnpm dev
```

**Compilando o aplicativo de desktop**

```
pnpm --dir apps/desktop tauri build
```
