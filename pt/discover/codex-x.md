# Gerencie as configurações do modelo de inteligência artificial a partir de uma única tela

Codex-X é uma ferramenta de interface visual de desktop e linha de comando escrita em Rust, desenvolvida para gerenciar modelos OpenAI Codex. O software centraliza a experiência do desenvolvedor com recursos como gerenciamento de API, sincronização de sessão, injeção de prompt e gerenciamento de habilidades (skills).

## O que você ganha

- Gerencie facilmente modelos de prompt e plugins através da interface
- Alterne rapidamente entre diferentes provedores de inteligência artificial
- Acompanhe o histórico de sessões e as tendências de uso de tokens

## Instalação

**Instalando dependências**

```
pnpm install
```

## Execução

**Iniciando o ambiente de desenvolvimento**

```
pnpm dev
```

**Compilando o aplicativo de desktop**

```
pnpm --dir apps/desktop tauri build
```
