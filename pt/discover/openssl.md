# Biblioteca de segurança que criptografa o tráfego de rede

O OpenSSL é uma biblioteca de segurança de uso geral usada para criptografar o tráfego de rede. É uma ferramenta de software de código aberto que suporta os protocolos Transport Layer Security (TLS), Datagram TLS (DTLS) e QUIC.
