# Modelo que analisa os mercados financeiros

Kronos é um modelo básico projetado para analisar os padrões únicos dos mercados financeiros. Ele se concentra na análise da estrutura complexa dos dados de mercado e é usado em estudos quantitativos de finanças e aprendizado de máquina.

## Instalação

**Clonar repositório oficial**

```

cd Kronos
pip install -r requirements.txt
```

## Execução

**Executar predição de exemplo**

```
python examples/prediction_example.py
```

## O que isso faz?

- Ele fornece a base para modelar padrões de mercado.
- Ele pode ser ajustado como modelo básico.
- Ele fornece uma base sólida para PNL financeira e pesquisa.
