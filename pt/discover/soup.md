# Treinamento de inteligência artificial com pouca memória

Soup é uma biblioteca Python que permite o ajuste fino de grandes modelos de linguagem por meio de um único arquivo YAML. Ele pode treinar modelos com 8 bilhões de parâmetros usando o método de streaming de camada em processadores gráficos de laptop com 4 GB de memória.

- ★ 3.235
- Python
- GitHub Trending · 2026-08-16

## O que você ganha
- Você pode treinar modelos com 8 bilhões de parâmetros em laptops com 4 GB de memória gráfica.
- Com o método de fluxo de camadas, você não precisa lidar com instalações complexas superando restrições de hardware.
- Você pode gerenciar todo o processo de treinamento através de um único arquivo de configuração.

## Instalação
**Configuração básica**

```
pip install "soup-cli[train]"
```

**Configuração com todos os recursos**

```
pip install "soup-cli[all]"
```


## Execução
**Comece a treinar**

```
soup init --template chat
soup train
```
