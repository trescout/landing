## O que você ganha

- Você pode treinar modelos com 8 bilhões de parâmetros em laptops com 4 GB de memória gráfica.
- Com o método de fluxo de camadas, você não precisa lidar com instalações complexas superando restrições de hardware.
- Você pode gerenciar todo o processo de treinamento através de um único arquivo de configuração.

## Instalação

**Configuração básica**

```
pip install "soup-cli[train]"
```

**Configuração com todos os recursos**

```
pip install "soup-cli[all]"
```

## Execução

**Comece a treinar**

```
soup init --template chat
soup train
```
