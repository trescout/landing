# Interfaces rápidas compatíveis com inteligência artificial

Solid é uma biblioteca JavaScript declarativa para construir interfaces de usuário. Em vez de usar um modelo de objeto de documento virtual (Virtual DOM), ela compila modelos diretamente em nós reais do modelo de objeto de documento (DOM), realizando atualizações com reatividade de granulação fina (fine-grained reactivity).

## O que você ganha

- A estrutura de gerenciamento de interface ganha velocidade atualizando diretamente os nós reais do navegador em vez de usar o Virtual DOM.
- Minimiza a carga no processador executando os componentes apenas uma vez.
- Atualiza apenas as pequenas partes afetadas com sua estrutura que rastreia automaticamente as alterações de dados.

## Instalação

**Criar um novo projeto com modelo pronto**

```
npx degit solidjs/templates/solid-v2/basic my-app
cd my-app
npm install
npm run dev
```

## Execução

**Incluir no projeto Vite da ferramenta de desenvolvimento**

```
npm i solid-js @solidjs/web
npm i -D vite @solidjs/vite-plugin
```
