# Ambiente de desenvolvimento de IA orientado a terminal

Terax-ai, como um ambiente de desenvolvimento local de inteligência artificial orientado a terminal (espaço de trabalho de desenvolvimento nativo de IA), atrai a atenção por sua estrutura de tamanho reduzido de 7 megabytes. Desenvolvida em TypeScript, esta ferramenta oferece aos desenvolvedores a oportunidade de codificar com inteligência artificial diretamente pelo terminal.

- ★ 8.790
- TypeScript
- GitHub Trending · 2026-07-05

## O que você ganha
- Estrutura leve e rápida com tamanho de 7 a 8 MB
- Integração de IA com modelos nativos e suporte de API
- Terminal acelerado por GPU e editor de código

## Instalação
**Iniciando o ambiente de desenvolvimento**

```
pnpm install
pnpm tauri dev          # development
```


## Se você não programa
Crie prompts de sistema específicos para meu projeto usando o painel de inteligência artificial do Terax e gerencie a memória do projeto através do arquivo TERAX.md. Aceite ou rejeite diferenças baseadas em IA para edições de código e execute tarefas de várias etapas com aprovação usando o modo de plano.
