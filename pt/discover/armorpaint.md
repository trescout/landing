# Pintura de texturas para modelos 3D

O ArmorPaint é uma ferramenta de design gráfico que realiza pintura de texturas em tempo real em modelos 3D. O software oferece flexibilidade aos artistas digitais em processos complexos de criação de texturas com suporte a renderização baseada em física (PBR).

- ★ 4.546
- C
- GitHub Trending · 2026-09-11

## O que você ganha
- Realize pintura de texturas em tempo real em modelos
- Obtenha resultados profissionais com suporte a renderização baseada em física
- Acelere processos complexos de criação de texturas

## Instalação
**Baixe os arquivos para o seu computador**

```
git clone https://github.com/armory3d/armorpaint
cd armorpaint/paint
```


## Execução
**Executando no Linux**

```
../base/make --run
```
