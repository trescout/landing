# Sintetizador de voz AI leve rodando na CPU

Desenvolvido pela Kyutai Labs, o Pocket-TTS é um modelo leve de conversão de texto em fala que roda apenas na unidade central de processamento (CPU), sem a necessidade de uma unidade de processamento gráfico. Graças ao seu baixo consumo de recursos, oferece síntese sonora rápida e eficiente em dispositivos com restrições de hardware.

## O que você ganha
- Funciona apenas com o processador, sem necessidade de placa gráfica
- Fornece reprodução de som rápida com baixo consumo de recursos
- Oferece clonagem de voz e suporte multilíngue

## Instalação
**Instalação do pacote**

```
pip install pocket-tts
# or
uv add pocket-tts
```


## Execução
**Crie um arquivo de áudio**

```
uvx pocket-tts generate
# or if you installed it manually with pip:
pocket-tts generate
```

**Inicialização do servidor local**

```
uvx pocket-tts serve
# or if you installed it manually with pip:
pocket-tts serve
```
