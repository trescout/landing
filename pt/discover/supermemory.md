# Memória inteligente para inteligência artificial

Supermemory oferece um mecanismo de memória altamente escalável e uma API projetada para a era da inteligência artificial. Ele permite adicionar uma camada de memória persistente e consultável aos seus aplicativos.

- ★ 28.742
- TypeScript
- MIT
- GitHub Trending · 1 Haziran 2026

## O que você ganha
- Ele adiciona uma camada de memória persistente ao seu aplicativo.
- Suporte de arquitetura escalável.
- Fácil integração via API.

## Como instalar, como usar?
**Instale o SDK (Nó ou Python)**

```
npm install supermemory    # ya da: pip install supermemory
```

**Conecte o servidor MCP ao cliente AI**

```
npx -y install-mcp@latest https://mcp.supermemory.ai/mcp --client claude --oauth=yes
```
