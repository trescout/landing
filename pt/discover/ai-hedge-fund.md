# Agentes de inteligência artificial para estratégias de investimento

O fundo de hedge de IA utiliza agentes autônomos para automatizar a análise do mercado financeiro e os processos de gestão de ativos. Este projeto baseado em Python oferece um modelo de equipe de inteligência artificial que desenvolve estratégias de investimento por meio do processamento de dados de mercado.

## O que você ganha
- Agentes autônomos analisando dados do mercado financeiro
- Modelagem representando diferentes escolas de investimento
- Possibilidade de testar estratégias com dados históricos

## Instalação
**Clonando o repositório**

```
git clone https://github.com/virattt/ai-hedge-fund.git
cd ai-hedge-fund
```

**Instalando dependências**

```
poetry install
```


## Execução
**Iniciar análise de investimento**

```
poetry run python src/main.py --ticker AAPL,MSFT,NVDA
```


## Se você não programa
Esta ferramenta utiliza agentes autônomos que imitam as estratégias de investidores famosos como Warren Buffett, Peter Lynch e Michael Burry para analisar os mercados financeiros. Ao fornecer determinados símbolos de ações (por exemplo, AAPL, MSFT) aos agentes de IA, você pode examinar como esses agentes avaliam dados de mercado, indicadores fundamentais e análises técnicas e tomam decisões com a lógica de um fundo mútuo.
