# Wifit3

Wifit3 é uma ferramenta em Python desenvolvida para testar a segurança de redes sem fio, operando exclusivamente com dispositivos USB e oferecendo suporte a diferentes sistemas operacionais. Trata-se de uma alternativa multiplataforma ao Wifite, um software de segurança popular que automatiza processos de auditoria de rede.
