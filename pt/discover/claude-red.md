# Habilidades de especialista em segurança para Claude

Claude-Red é uma biblioteca de habilidades de segurança ofensivas integradas ao sistema de habilidades do modelo de inteligência artificial Claude. Seu objetivo é automatizar os testes de segurança, fornecendo metodologias de nível especializado em tópicos como injeção de SQL e como contornar sistemas de proteção de endpoint.

- ★ 6.081

## O que você ganha
- Fornece acesso a metodologias de segurança orientadas a ataques
- Transforma um modelo de IA em um testador de penetração
- Instala automaticamente as habilidades necessárias

## Instalação
**Baixe todas as habilidades**

```
git clone https://github.com/SnailSploit/claude-red ~/.claude/skills/claude-red
```

**Configuração interativa**

```
./install.sh                           # interactive
./install.sh --target ~/.claude/skills # explicit target
./install.sh --category web            # single category
```

De agora em diante, quero que você aja como um testador de penetração. Analise vulnerabilidades, avalie superfícies de ataque e oriente-me em minha pesquisa de segurança cibernética usando as metodologias contidas nos arquivos de habilidades que compartilho.
