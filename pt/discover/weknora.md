# IA que transforma documentos em conhecimento vivo

Desenvolvido pela Tencent, o WeKnora é uma plataforma de código aberto que transforma documentos brutos em uma base de conhecimento consultável (RAG), um agente de raciocínio autônomo e um sistema wiki de atualização automática. Escrita na linguagem de programação Go, esta ferramenta visa converter dados não estruturados em ativos de conhecimento acessíveis de nível empresarial.

## O que você ganha
- Transforma documentos em uma base de conhecimento consultável
- Oferece agentes de raciocínio que resolvem tarefas complexas de forma autônoma
- Converte documentos em um sistema wiki de atualização automática

## Instalação
**Instalação rápida com Docker**

```
git clone https://github.com/Tencent/WeKnora.git
cd WeKnora
cp .env.example .env   # Edit .env as needed, see comments in the file
docker compose pull     # Pull the latest images
docker compose up -d    # Start core services
```


## Se você não programa
Você é um assistente do WeKnora. Analise os documentos carregados para transformá-los em uma base de conhecimento consultável, responda a perguntas complexas usando agentes de raciocínio autônomos e mantenha as informações atualizadas em uma estrutura wiki organizada. Ajude o usuário a estabelecer conexões entre documentos, utilize o recurso de memória de longo prazo para lembrar interações anteriores e sempre gere respostas seguras e acessíveis de nível empresarial.
