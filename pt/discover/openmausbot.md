# Equipe de bots de IA focada em chat

O OpenMausBot é uma alternativa de código aberto ao Grok Bot que permite criar sua própria equipe de bots de IA dentro de aplicativos de chat. O software vem com suporte a uma máquina virtual para que os bots possam usar.

- ★ 7.628
- TypeScript

## Atualizações

## O que você ganha

- Você pode gerenciar sua própria equipe de bots de IA através do Electron, a infraestrutura de aplicativos de desktop.
- Você pode armazenar seu histórico de chat e dados no seu computador local em vez da nuvem.
- Com a integração da ferramenta de linha de comando CLI, você pode definir diferentes modelos de IA para seus bots.

## Instalação

**Instalação e execução do pacote OpenMausBot**

```
npm install -g openmausbot
openmausbot
```
