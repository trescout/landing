# Transcreva sua voz localmente

cjpais/Handy é um aplicativo de conversão de fala em texto (speech-to-text) gratuito e de código aberto que roda totalmente offline. Desenvolvido em Rust, esta ferramenta oferece uma estrutura extensível que permite aos usuários processar dados de voz localmente.

## O que você ganha

- Converta suas conversas em texto instantaneamente sem precisar de conexão com a internet
- Protege sua privacidade pessoal ao não enviar dados de voz para servidores em nuvem
- Permite digitar diretamente no campo de texto ativo pressionando um atalho definido no teclado

## Instalação

**Sistemas Linux baseados em Debian ou Ubuntu**

```
sudo apt install ./Handy_*.deb
```
