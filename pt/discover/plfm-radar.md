# Radar phased array de código aberto

PLFM RADAR é um sistema de radar phased array de baixo custo e código aberto operando na frequência de 10,5 GHz. Este projeto baseado em hardware utiliza software de controle desenvolvido em linguagem PLSQL para tornar acessíveis tecnologias de detecção de radiofrequência.

## O que você ganha
- Opções de autonomia de 3 km e 20 km
- Capacidade de direção eletrônica do feixe
- Processamento de sinal avançado baseado em FPGA

## Como começar
Este projeto é um sistema abrangente que consiste em componentes de hardware e software. Para começar, você pode acessar os esquemas de hardware, os arquivos de software FPGA e a interface de usuário baseada em Python revisando a documentação na página do GitHub. Recomenda-se que você siga os relatórios técnicos e resultados de simulação nas pastas relevantes para a instalação e utilização do projeto.
