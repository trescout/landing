# Agentes especialistas em design para Claude Code

Usando o sistema de equipe de agentes de Claude Code, Harness divide missões complexas em equipes coordenadas de agentes especializados. Com o comando 'Configurar um arnês para', ele projeta a equipe e as habilidades necessárias para você.

## O que você ganha

- Divide missões complexas em equipes de agentes especializados.
- Desenvolve as habilidades que as equipes precisam.
- Automatiza fluxos de trabalho.

## Como começar

Adicionado como habilidade ao Claude Code; Depois, você pode pedir que eles estabeleçam uma equipe de agentes para a área desejada.

## Como instalar, como usar?

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Instale o plugin Harness executando os comandos '/plugin marketplace add revfactory/harness' e depois '/plugin install chicote@harness-marketplace' no Claude Code, depois peça para configurar uma equipe de agentes de inteligência artificial adequada para o meu projeto dizendo "Criar um chicote para este projeto".

**Código Claude · marketplace + instalação**

```
/plugin marketplace add revfactory/harness
/plugin install harness@harness-marketplace
```
