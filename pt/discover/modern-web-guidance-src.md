# Calibre os guias de desenvolvimento web moderno

O GoogleChrome/modern-web-guidance-src é um repositório de recursos que contém o código e a documentação necessários para a criação, calibração e avaliação de guias de desenvolvimento web moderno. Desenvolvido com a linguagem TypeScript, este projeto permite o gerenciamento de conteúdos de orientação voltados para padrões web.

## O que você ganha

- Substitui hábitos antigos de escrita de código de agentes de codificação de inteligência artificial por padrões web atuais.
- Importa guias de desenvolvimento prontos, focados em compatibilidade com navegadores e desempenho, diretamente para o contexto do agente.
- Prioriza recursos nativos do navegador e soluções leves em vez de bibliotecas desnecessárias.

## Instalação

**Instalação com assistente interativo**

```
npx modern-web-guidance@latest install
```

**Instalação alternativa com opções**

```
npx modern-web-guidance@latest install --choose
```

## Execução

**Busca de guias e estruturas obsoletas no código**

```
# Search for relevant guides
npx modern-web-guidance@latest search "animate a dialog modal backdrop"

# Retrieve a guide by ID
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"

# Scan a codebase for legacy patterns to modernize
npx modern-web-guidance@latest legacy-scan .
```
