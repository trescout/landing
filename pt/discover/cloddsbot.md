# Terminal de negociação autônomo com inteligência artificial

O CloddsBot é um agente de negociação de inteligência artificial de código aberto que opera autonomamente em mais de 1000 mercados. Baseado em Claude, este software executa processos de compra e venda automatizados em várias bolsas de criptomoedas e plataformas de previsão (Polymarket, Binance) com gestão de risco e protocolos de pagamento máquina a máquina.

- ★ 1.873
- TypeScript
- GitHub Trending · 2026-09-11

## O que você ganha
- Negociação automatizada em mais de 1000 mercados
- Portfólio e estratégias gerenciáveis por linguagem natural
- Integração total com 21 plataformas de mensagens diferentes

## Instalação
**Instalação rápida**

```
npm install -g clodds --loglevel=error
clodds onboard
```

**Instalação a partir do código-fonte**

```
git clone https://github.com/alsk1992/CloddsBot.git && cd CloddsBot
npm install && cp .env.example .env
# Add ANTHROPIC_API_KEY to .env
npm run build && npm start
```


## Execução
**Iniciando a interface**

```
clodds start
```


## Se você não programa
Você é um assistente de negociação. Quero que você analise os mercados de criptomoedas e plataformas de previsão usando o CloddsBot com mais de 118 estratégias. Aplicando regras de gestão de risco, gerencie as operações de compra e venda automatizadas dentro do orçamento que defini e apresente-me relatórios monitorando os dados do mercado.
