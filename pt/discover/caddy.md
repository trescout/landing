# Configure um servidor https automático

O Caddy é um servidor web extensível escrito em Go que oferece gerenciamento automático de certificados HTTPS. Ele simplifica a configuração e a segurança de sites ao suportar os protocolos HTTP/1, HTTP/2 e HTTP/3.

- ★ 76.784
- Go
- GitHub Trending · 2026-10-05

## O que você ganha
- Oferece gerenciamento automático de certificados HTTPS por padrão
- Suporta os protocolos HTTP/1, HTTP/2 e HTTP/3
- Funciona em qualquer lugar sem dependências externas

## Execução
**compilação**

```
git clone "https://github.com/caddyserver/caddy.git"
cd caddy/cmd/caddy/
go build
```
