# Linguagem de programação rápida e confiável

Desenvolvida pelo Google, a linguagem de programação Go é uma linguagem de programação de sistema de código aberto projetada para criar software escalonável e de alto desempenho. É amplamente preferido em infraestruturas modernas de computação em nuvem com seu gerenciamento de simultaneidade e tempos de compilação rápidos.

- ★ 134.555
- GitHub Trending · 2026-06-07

## O que você ganha
- Estrutura de código simples e compreensível
- Capacidade de trabalho de alto desempenho
- Eficiência para sistemas de nuvem modernos

## Instalação
**macOS (homebrew)**

```
brew install go
```

**Janelas (winget)**

```
winget install GoLang.Go
```


## Execução
**Verifique a versão**

```
go version
```
