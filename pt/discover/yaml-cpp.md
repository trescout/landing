# Gerenciamento YAML para projetos C++

yaml-cpp é uma biblioteca para a linguagem de programação C++ que analisa e emite dados no formato YAML. Ele permite que desenvolvedores de software gerenciem arquivos de configuração e executem operações de serialização de dados.

## O que você ganha

- Conformidade total com os padrões YAML 1.2
- Análise de dados e suporte à renderização
- Compilação multiplataforma com CMake

## Instalação

**macOS (Homebrew)**

```
brew install yaml-cpp
```
