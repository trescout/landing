# Gerenciamento YAML para projetos C++

yaml-cpp é uma biblioteca para a linguagem de programação C++ que analisa e emite dados no formato YAML. Ele permite que desenvolvedores de software gerenciem arquivos de configuração e executem operações de serialização de dados.

## O que você ganha
- Conformidade total com os padrões YAML 1.2
- Análise de dados e suporte à renderização
- Compilação multiplataforma com CMake

## Instalação
**macOS (homebrew)**

```
brew install yaml-cpp
```


## Como começar
- Fonte oficial →
Para começar a usar a ferramenta, primeiro você deve baixar e instalar o software CMake de seu site oficial. Você pode então executar comandos de configuração do CMake criando uma pasta 'build' no diretório de código-fonte do seu projeto ou integrá-la ao seu projeto usando o recurso FetchContent do CMake. Para exemplos de uso detalhados e documentação da API, você pode conferir a seção Wiki na página do GitHub.
