# Mapeamento de código aberto baseado em nuvem

GeoLibre é uma plataforma leve de sistema de informações geográficas (GIS) baseada em nuvem, projetada para visualizar, explorar e analisar dados geográficos. Desenvolvido com TypeScript, esta ferramenta pode ser executada em navegadores da web, desktops, dispositivos móveis e notebooks Jupyter.

- Análise de geodados sem instalação no navegador

## Instalação
**via pip (PyPI)**

```
pip install GeoLibre
```


## Como começar
- Fonte oficial →
Você não precisa de nenhuma instalação para começar a usar o GeoLibre. Você pode acessar a versão web através do seu navegador ou visitar a página de download no site oficial para baixar o instalador do sistema operacional do seu desktop.
