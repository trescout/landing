# Encontre modelos de IA adequados ao seu hardware

Desenvolvido com a linguagem Rust, o llmfit verifica centenas de grandes modelos e provedores de linguagem e permite identificar aqueles compatíveis com o seu hardware com um único comando. A ferramenta automatiza o processo de localização de modelos que melhor se adequam aos recursos do sistema local.

## O que você ganha
- Detecta automaticamente modelos compatíveis com o seu sistema
- Classifica por memória, velocidade e qualidade
- Fornece fácil gerenciamento com interface interativa

## Instalação
**Instalação para macOS ou Linux**

```
brew install AlexsJones/llmfit/llmfit
```

**Instalação rápida**

```
curl -fsSL https://llmfit.axjns.dev/install.sh | sh
```


## Execução
**Iniciando a interface interativa**

```
llmfit
```
