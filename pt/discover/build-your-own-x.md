# Crie suas próprias tecnologias do zero

Build Your Own é uma coleção de guias passo a passo que permitem reescrever suas tecnologias favoritas, como banco de dados, sistema operacional, Git, Docker e linguagem de programação do zero. Oferece uma experiência de aprendizagem fazendo, em linha com a filosofia de Feynman de “Não consigo compreender o que não posso criar”.

## O que você ganha
- Você aprende a lógica interna dos sistemas fazendo.
- Uma ampla variedade de tópicos, desde banco de dados até sistema operacional.
- Projetos práticos em vez de explicação teórica.

## Como usar?
Você pode escolher a tecnologia de seu interesse na página do GitHub e seguir os guias passo a passo.
