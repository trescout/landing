# Interface alternativa de código aberto para o YouTube

Invidious é uma interface alternativa de código aberto para o YouTube. O README oficial lista uso sem anúncios ou rastreamento, sem exigir JavaScript, com inscrições independentes do Google e opções de importação e exportação de dados.

- GitHub Trending · 2026-08-02

## Instalação
**Clone o repositório**

```
git clone https://github.com/iv-org/invidious.git
```

**Entre no diretório do projeto**

```
cd invidious
```


## Execução
**Inicie o Docker Compose**

```
docker compose up -d
```


## O que esta ferramenta faz?
Invidious oferece uma interface alternativa ao YouTube e não usa as APIs oficiais do YouTube. Você pode escolher uma instância pública ou hospedar a sua própria seguindo a documentação de instalação. O projeto usa a licença AGPL-3.0 e fornece uma API documentada para desenvolvedores.

## Para quem é?
Pessoas que querem uma interface alternativa ao YouTube, inscrições independentes do Google ou uma instância auto-hospedada.

## O que não esperar
Pessoas que precisam especificamente de uma solução baseada nas APIs oficiais do YouTube.

## Destaques
- Lista uso sem anúncios ou rastreamento e sem exigir JavaScript.
- Oferece inscrições independentes do Google.
- Fornece opções de importação e exportação de dados.
- Inclui uma API documentada para desenvolvedores.

## Primeiro fluxo de uso
- Escolha uma instância pública do Invidious se quiser apenas usar o serviço.
- Se pretende hospedar o serviço, leia primeiro a documentação oficial de instalação.
- Para o caminho atual com Docker, prepare o PostgreSQL e o Invidious Companion.
- Considere pelo menos 20 GB de espaço em disco e 2 GB de RAM livre para sua instalação.
