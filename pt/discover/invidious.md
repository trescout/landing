# Assistir vídeos sem anúncios e rastreamento

Invidious é uma interface de código aberto desenvolvida como alternativa à plataforma YouTube. Ele oferece aos usuários uma experiência de visualização de vídeos que não contém anúncios e não rastreia dados.

- ★ 22.400
- Crystal
- GitHub Trending · 2026-08-02

## O que você ganha
- Assista a vídeos do YouTube sem anúncios e rastreamento de dados
- Assine canais sem precisar de uma conta do Google
- Reproduza áudio em segundo plano com baixo uso de dados

## Instalação
**Obtenha o repositório e componha o arquivo**

```
git clone --depth 1 https://github.com/iv-org/invidious.git && cd invidious
```


## Execução
**começar**

```
docker compose up -d
```
