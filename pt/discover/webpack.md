# Empacotador de módulos para projetos da web

Webpack é um empacotador que agrupa JavaScript e outros ativos da web para serem executados no navegador. Ele permite que aplicativos sejam carregados quando necessário, graças ao recurso de divisão de código que divide os módulos em partes gerenciáveis.

## O que você ganha

- Ele combina arquivos JavaScript para serem executados no navegador.
- Ele reduz o tempo de carregamento do aplicativo com seu recurso de divisão de código.
- Ele pode pré-processar diferentes tipos de arquivos, como TypeScript.

## Instalação

**instalar com npm**

```
npm install --save-dev webpack
```

**instalação com fio**

```
yarn add webpack --dev
```
