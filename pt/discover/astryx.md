# Sistema de design compatível com inteligência artificial

Desenvolvido pela Meta, o Astryx oferece um sistema de design totalmente customizável e compatível com agentes de inteligência artificial. Esta biblioteca de código aberto baseada em TypeScript configura componentes de interface para uso de sistemas autônomos.

- ★ 11.769
- TypeScript
- GitHub Trending · 2026-07-01

## O que você ganha
- Mais de 150 componentes acessíveis
- API compatível com assistentes de IA
- Estrutura flexível sem restrições de estilo

## Instalação
**Instalar pacotes**

```
# npm
npm install @astryxdesign/core @astryxdesign/theme-neutral
npm install -D @astryxdesign/cli

# pnpm
pnpm add @astryxdesign/core @astryxdesign/theme-neutral
pnpm add -D @astryxdesign/cli

# yarn
yarn add @astryxdesign/core @astryxdesign/theme-neutral
yarn add -D @astryxdesign/cli
```
