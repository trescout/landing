Produza vídeos de IA com um clique

MoneyPrinterTurbo produz automaticamente vídeos curtos usando modelos de linguagem grandes a partir de um tópico ou palavra-chave que você fornece. Combina texto, legendas, música de fundo e recursos visuais. (O nome é para fins de marketing, é uma ferramenta de produção de conteúdo, não uma máquina de ‘impressão de dinheiro’.)

O que você ganha

  • Ele cria edição automática usando texto, legendas, música e recursos visuais.
  • É fácil de usar graças à sua interface web.
  • Ele permite a produção de vídeos em lote e múltiplos.

Instalação

Clonar repositório oficial
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo

Execução

Iniciar com Docker Compose
docker-compose up
Iniciar interface web
uv run streamlit run ./webui/Main.py --browser.gatherUsageStats=False

nota honesta

Requer uma chave API do modelo AI + instalação para funcionar; O uso da API pode ser cobrado. É responsabilidade do usuário garantir que os vídeos produzidos cumpram as regras de direitos autorais e da plataforma.
