# Gere modelos 3D de alta qualidade a partir de imagens

Desenvolvido pela Microsoft, TRELLIS é uma arquitetura estruturada de representação latente que transforma texto ou entradas visuais em modelos tridimensionais (3D). Esta tecnologia usa métodos generativos de IA para criar ativos 3D de alta qualidade de forma rápida e compacta.

- ★ 9.992
- Python
- GitHub Trending · 2026-08-02

## O que você ganha
- Cria ativos 3D detalhados e texturizados a partir de uma única imagem.
- Processa com sucesso estruturas complexas e superfícies abertas.
- Ele fornece resultados realistas com PBR, materiais de visualização baseados em física.

## Instalação
**Clonar o repositório**

```
git clone -b main https://github.com/microsoft/TRELLIS.2.git --recursive
    cd TRELLIS.2
```

**Instalar dependências**

```
. ./setup.sh --new-env --basic --flash-attn --nvdiffrast --nvdiffrec --cumesh --o-voxel --flexgemm
```
