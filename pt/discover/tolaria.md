# Aplicativo de desktop da base de conhecimento Markdown

Tolaria é um aplicativo desktop desenvolvido para gerenciar bases de conhecimento baseadas em Markdown. Escrita em TypeScript, esta ferramenta facilita a organização da documentação pessoal e dos sistemas de notas.

## O que você ganha
- Fornece gerenciamento portátil de notas com arquivos markdown.

- Protege a propriedade dos dados com suporte de trabalho offline.

## Instalação
**Dependências para Arch/Manjaro**

```
sudo pacman -S --needed webkit2gtk-4.1 base-devel curl wget file openssl \
    appmenu-gtk-module libappindicator-gtk3 librsvg
```

**Dependências para Debian/Ubuntu**

```
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
    libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev \
    libsoup-3.0-dev patchelf
```


## Execução
**Iniciando o ambiente de desenvolvimento**

```
pnpm install
pnpm dev
```

**Execute o aplicativo de desktop**

```
pnpm tauri dev
```
