# Tick Stock Panel

Tick-stock-panel é uma plataforma personalizável de seleção, monitoramento e backtesting de ações que opera com dados da bolsa de valores chinesa (A-share). É uma ferramenta Python de código aberto que automatiza os processos de desenvolvimento de estratégias e análise de ações com o suporte de grandes modelos de linguagem (large language models).
