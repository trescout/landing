# Acesso a inteligência artificial a partir da linha de comando

Desenvolvido pelo Google, o gemini-cli é uma ferramenta de código aberto que fornece acesso direto ao modelo de inteligência artificial Gemini através do terminal. O software permite que os usuários criem prompts de IA de forma rápida e leve no ambiente de linha de comando.

## O que você ganha

- Você pode inspecionar e editar suas bases de código diretamente através da linha de comando.
- Você pode gerar novos aplicativos a partir de imagens ou documentos de texto.
- Você pode automatizar suas tarefas repetitivas com scripts de comandos.

## Instalação

**Instalação global com o gerenciador de pacotes npm**

```
npm install -g @google/gemini-cli
```

**Instalação com o gerenciador de pacotes Homebrew**

```
brew install gemini-cli
```

## Execução

**Execução direta sem instalação**

```
# Using npx (no installation required)
npx @google/gemini-cli
```
