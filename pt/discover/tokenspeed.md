# Motor de inferência rápida para modelos de inteligência artificial

lightseekorg/tokenspeed é um motor de inferência de alto desempenho desenvolvido para grandes modelos de linguagem (LLM). Escrito em Python, este projeto visa acelerar os processos de previsão de modelos de inteligência artificial.
