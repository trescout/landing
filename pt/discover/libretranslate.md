# Serviço de tradução gratuito em seu próprio servidor

LibreTranslate oferece uma interface de tradução automática (API) gratuita e de código aberto. Esta ferramenta baseada em Python, que você pode hospedar em seu próprio servidor, permite trabalhar offline sem conexão com a Internet.

- ★ 15.834
- GitHub Trending · 2026-06-19

## O que você ganha
- Livre-se de serviços dependentes como Google ou Azure
- Traduza offline sem conexão com a internet
- Use um mecanismo de tradução totalmente aberto e gratuito

## Instalação
**via pip (PyPI)**

```
pip install libretranslate
```

**com Docker**

```
docker run -p 5000:5000 libretranslate/libretranslate
```


## Execução
**Iniciar servidor de tradução**

```
libretranslate
```

**Iniciar servidor de tradução**

```
libretranslate --port 5000
```
