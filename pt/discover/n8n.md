# Automatize fluxos de trabalho entre aplicativos

n8n é uma plataforma de automação de fluxo de trabalho que flui dados entre diferentes aplicativos e automatiza processos de negócios. Combinando uma interface visual com escrita de código customizada, esta ferramenta pode rodar tanto na nuvem quanto em seu próprio servidor, com suporte para mais de 400 integrações.

- ★ 201.895
- TypeScript
- GitHub Trending · 2026-08-23

## O que você ganha
- Projete processos de negócios complexos com uma interface visual
- Conecte mais de 1.500 aplicativos e serviços diferentes
- Execute com segurança em seu próprio servidor ou na nuvem

## Instalação
**Script de instalação rápida**

```
curl -fsSL https://get.n8n.io | sh
```

**Instalação manual com Docker**

```
docker volume create n8n_data
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```


## Execução
**Acesso à interface**

```
http://localhost:5678
```
