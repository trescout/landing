# Estúdio de som com inteligência artificial trabalhando em ambiente local

Voicebox é um estúdio de voz de inteligência artificial de código aberto que permite aos usuários realizar clonagem de voz, ditado e criação de conteúdo. Desenvolvido em linguagem TypeScript, esta plataforma oferece ferramentas completas para gerenciar processos de processamento de áudio no ambiente nativo.

- ★ 50.505
- TypeScript
- GitHub Trending · 2026-06-21

## O que você ganha
- Transcreva sua própria voz ou a voz de outra pessoa em segundos.
- Forneça narração e ditado naturais em 23 idiomas diferentes.
- Proteja a privacidade mantendo todos os dados de áudio no seu computador local.

## Instalação
**Instalação a partir do código-fonte**

```
git clone https://github.com/jamiepine/voicebox.git
cd voicebox

just setup   # creates Python venv, installs all deps
just dev     # starts backend + desktop app
```
