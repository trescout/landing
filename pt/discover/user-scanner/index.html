Scanner de usuário

Desenvolvido em Python, o User-Scanner é uma ferramenta de inteligência de código aberto (OSINT) que coleta dados de mais de 465 fontes diferentes por meio de um único endereço de e-mail ou nome de usuário. Projetado para pesquisadores de segurança e rastreadores digitais, o software oferece análise aprofundada de dados com uma ampla variedade de vetores de varredura.
