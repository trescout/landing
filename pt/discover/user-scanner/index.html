Reconhecimento OSINT de usuários em mais de 465 plataformas

O User-Scanner em Python executa varreduras automatizadas de inteligência de fontes abertas (OSINT) em mais de 465 redes e fóruns a partir de um único identificador.

  • ★ 3.910
  • Python
  • GitHub Trending · 2026-08-31

Atualizações

  • 31 de agosto de 2026: 3.910 estrelas, ampliação para mais de 465 plataformas com motor assíncrono de requisições.

O que você ganha

  • Ampla cobertura de plataformas: Confirme a existência de perfis no GitHub, Reddit, Steam, Telegram e em mais de 465 serviços.
  • Consultas assíncronas de alta velocidade: Dispare centenas de requisições simultâneas em segundos usando Python asyncio e aiohttp.
  • Filtragem de falsos positivos: Algoritmo que valida tanto os códigos HTTP quanto mensagens de erro no corpo da resposta.
  • Exportação em JSON e CSV: Gere arquivos estruturados prontos para documentação de perícia digital e segurança.
  • Privacidade e execução local: Execute investigações diretamente do seu terminal sem enviar dados para servidores de terceiros.

Instalação

Clonar o repositório e instalar dependências
git clone https://github.com/kaifcodec/user-scanner.git
cd user-scanner
pip install -r requirements.txt

Execução

Escanear nome de usuário e endereço de e-mail alvo
python3 user_scanner.py -u hedef_kullanici
# veya e-posta ile:
python3 user_scanner.py -e hedef@ornek.com

Arquitetura técnica e princípio de funcionamento

O User-Scanner opera um fluxo de reconhecimento assíncrono estruturado por perfis modulares:

  • Manifesto de plataformas em JSON: Especificações modulares com padrões de URL, códigos esperados e regex para mais de 465 sites.
  • Pool de conexões simultâneas: Otimiza a largura de banda da rede com sessões TCP persistentes e cache DNS local.
  • Rotação de cabeçalhos e User-Agents: Emula navegadores legítimos para contornar bloqueios de WAF e limites de requisição.

Cenários de pesquisa OSINT e análise de dados

Especialistas em segurança e peritos forenses aplicam o User-Scanner em cenários críticos:

  • Mapeamento de pegada digital: Descubra a extensão de perfis ativos após vazamentos de credenciais correlacionando contas.
  • Auditoria de segurança corporativa: Identifique se e-mails institucionais estão registrados em serviços externos não homologados.
  • Defesa contra engenharia social: Localize perfis fraudulentos de personificação e contas vulneráveis a spear phishing.

Perguntas frequentes

  • O uso do User-Scanner é legal? Sim. O User-Scanner apenas consulta páginas e endpoints públicos; não realiza invasões, quebra de senhas ou acessos não autorizados.
  • Ele suporta Tor ou servidores proxy? Sim. É possível encaminhar requisições por meio de proxies SOCKS5 ou HTTP para mascarar o IP e evitar restrições de frequência.
  • Quanto tempo demora uma varredura completa? Graças ao motor assíncrono, a varredura em mais de 465 plataformas costuma levar entre 20 e 45 segundos.
  • Como funciona a busca por e-mail? No modo e-mail, a ferramenta avalia respostas públicas emitidas por fluxos de registro e recuperação de contas suportados.
