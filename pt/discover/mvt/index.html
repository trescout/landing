Descobrir · GitHub · MVT

Procure vestígios de ataques cibernéticos em dispositivos móveis

Mobile Verification Toolkit é uma ferramenta de computação forense utilizada para detectar violações de segurança em dispositivos móveis. Desenvolvida em Python, este software analisa os dados do dispositivo para revelar possíveis vestígios de ataques cibernéticos.

O que você ganha

  • Coleta vestígios forenses em dispositivos Android e iOS

  • Realiza análises de segurança com ferramentas de linha de comando

Instalação

instalar com pip
pip3 install mvt
instalar com uv
uv tool install mvt

Execução

Criar script de preenchimento
mvt completion bash
