# Analise rapidamente seus documentos com Rust

Liteparse (run-lhama); é um analisador de documentos de código aberto escrito em Rust para analisar documentos de forma rápida e eficiente. Ele facilita os processos de IA e RAG, tornando processáveis ​​estruturas complexas de documentos.

- ★ 12.210
- Rust
- Apache-2.0
- GitHub Trending · 30 May 2026

## O que você ganha
- Fornece análise de documentos rápida e eficiente.
- Torna estruturas complexas usináveis.
- Totalmente compatível com pipelines AI e RAG.

## Instalação
**com pip (PyPI)**

```
pip install liteparse
```


## Como instalar, como usar?
Instale a ferramenta de análise de PDF LiteParse com 'pip install liteparse' e extraia o texto de um PDF com o comando 'lit parse document.pdf' ou salve como JSON estruturado com caixas delimitadoras com 'lit parse document.pdf --format json -o output.json'.
