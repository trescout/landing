# Plugins para assistente de codificação Claude

A Anthropic oferece um diretório oficial que coleta plugins de alta qualidade desenvolvidos para Claude Code em um único centro. Essa estrutura baseada em Python permite que os desenvolvedores compartilhem e descubram ferramentas preparadas para assistentes de codificação em um formato padrão.

## Como começar
- Fonte oficial →
Você pode navegar pelos plug-ins disponíveis usando o menu '/plugin > Descobrir' na interface do Claude Code. Para instalar plugins, basta usar o comando '/plugin install {plugin-name}@claude-plugins-official' na linha de comando do Claude Code.
