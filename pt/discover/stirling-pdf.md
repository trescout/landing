# Edição abrangente de PDF em seu próprio servidor

Stirling-PDF é uma ferramenta de processamento de documentos de código aberto que permite aos usuários editar arquivos PDF em qualquer dispositivo. Desenvolvido em TypeScript, este aplicativo centraliza os processos de gerenciamento de documentos, executando em servidores locais.

## Instalação

**Iniciar contêiner Docker persistente**

```
docker run -d --name stirling-pdf -p 127.0.0.1:8080:8080 -v ./stirling-data:/configs --restart unless-stopped docker.stirlingpdf.com/stirlingtools/stirling-pdf:latest
```

## Execução

**Acessar interface local**

```
http://localhost:8080
```
