# Edição abrangente de PDF em seu próprio servidor

Stirling-PDF é uma ferramenta de processamento de documentos de código aberto que permite aos usuários editar arquivos PDF em qualquer dispositivo. Desenvolvido em TypeScript, este aplicativo centraliza os processos de gerenciamento de documentos, executando em servidores locais.

## O que você ganha
- Mais de 50 ferramentas diferentes de edição de PDF
- Processamento local dos seus dados sem enviá-los para serviços externos
- Fácil acesso via navegador ou desktop

## Instalação
**Instalação rápida com Docker**

```
docker run -p 8080:8080 docker.stirlingpdf.com/stirlingtools/stirling-pdf
```


## Execução
**Acesso à interface**

```
http://localhost:8080
```
