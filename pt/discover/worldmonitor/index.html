Painel de inteligência global em tempo real

Worldmonitor oferece um painel de inteligência global em tempo real que combina compilação de notícias com tecnologia de IA e recursos de monitoramento geopolítico em uma única interface. Essa ferramenta, que fornece monitoramento da infraestrutura e consciência situacional, facilita os processos de análise ao visualizar fluxos de dados complexos.

O que você ganha

  • Resumindo mais de 500 fontes de notícias com inteligência artificial
  • Análise visual com globo 3D e suporte a mapas WebGL
  • Combinação de dados económicos, militares e geopolíticos numa única interface

Instalação

Configuração básica
git clone https://github.com/koala73/worldmonitor.git
cd worldmonitor
npm install
npm run dev

Execução

Operação baseada em variante
npm run dev:tech       # tech.worldmonitor.app
npm run dev:finance    # finance.worldmonitor.app
npm run dev:commodity  # commodity.worldmonitor.app
npm run dev:happy      # happy.worldmonitor.app
npm run dev:energy     # energy.worldmonitor.app
