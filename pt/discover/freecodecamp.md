# Entre no mundo do software gratuitamente

freeCodeCamp é uma plataforma de aprendizagem de código aberto que oferece materiais educacionais gratuitos sobre matemática, programação e ciência da computação. Desenvolvido com a linguagem TypeScript, este projeto permite aos usuários adquirir habilidades de desenvolvimento de software por meio de um currículo aplicado.

**Nota da TreScout:** Um currículo completo para iniciantes, com exercícios que funcionam no navegador. Os certificados têm peso limitado nas candidaturas a empregos, seu principal valor está na ordem estruturada: É isso que você procura se não sabe por onde começar.

- Aquisição de competências de desenvolvimento de software através de currículo aplicado.
- Certificados gratuitos válidos no setor.
