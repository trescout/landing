# JSON Render

Desenvolvido pelos Vercel Labs, o json-render é um framework para cenários de interface generativa (generative UI) que converte estruturas de dados em componentes visuais. Ele permite que os desenvolvedores apresentem dados estruturados provenientes de modelos de inteligência artificial como elementos dinâmicos e interativos em interfaces web.
