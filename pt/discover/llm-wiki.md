# Crie automaticamente uma wiki de IA a partir dos seus documentos

O LLM Wiki é um aplicativo de desktop multiplataforma que organiza documentos automaticamente e os transforma em uma base de conhecimento interconectada. Ao contrário do método tradicional de recuperação e resposta (RAG), ele cria uma wiki persistente a partir de suas fontes, mantendo os dados atualizados de forma progressiva.

- ★ 18.359
- TypeScript
- GitHub Trending · 2026-09-11

## O que você ganha
- Analisa documentos e os transforma em páginas wiki interconectadas
- Mantém os dados continuamente atualizados com uma estrutura de memória persistente
- Funciona em total compatibilidade com o software de anotações Obsidian

## Como começar
Baixe o projeto para o seu computador seguindo as etapas de instalação na página do GitHub. Certifique-se de que os ambientes de desenvolvimento Node.js e Rust estejam instalados, então você pode instalar as dependências necessárias e iniciar o aplicativo via linha de comando.
