# Cópia de sites com inteligência artificial

O clonador de sites de inteligência artificial (AI website cloner), desenvolvido pela JCodesMore, permite copiar sites existentes com um único comando usando agentes de codificação baseados em TypeScript. Esta ferramenta usa geração de código com tecnologia de IA para automatizar processos de design e desenvolvimento de web.

- ★ 33.227
- TypeScript
- GitHub Trending · 2026-06-23

## O que você ganha
- Converte sites existentes em base de código Next.js
- Extrai automaticamente elementos e ativos de design
- Reconstrói componentes em paralelo

## Instalação
**Clonar o repositório**

```
git clone https://github.com/YOUR-USERNAME/YOUR-NEW-REPOSITORY.git
   cd YOUR-NEW-REPOSITORY
```

**Instalar dependências**

```
npm install
```


## Se você não programa
Usando este projeto, analise o site de destino, extraia elementos e ativos de design, escreva propriedades do componente e execute renderizadores paralelos para reconstruí-lo na estrutura Next.js.
