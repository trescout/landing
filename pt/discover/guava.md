# Conjunto básico de bibliotecas para projetos Java

Desenvolvido pelo Google, Guava é um kit de ferramentas que contém bibliotecas básicas frequentemente necessárias em projetos Java. As coleções aceleram o desenvolvimento de software simplificando tarefas comuns, como armazenamento em cache e manipulação de strings.

## O que você ganha
- Possibilidade de usar tipos de coleção e biblioteca gráfica

- Ferramentas essenciais confiáveis desenvolvidas pelo Google

Você pode começar escolhendo uma das versões JRE ou Android de acordo com as necessidades do seu projeto e adicionando os códigos de dependência relevantes ao arquivo de configuração do seu projeto.
