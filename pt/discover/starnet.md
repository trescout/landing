# Starnet

Starnet é uma ferramenta de gerenciamento de desktop que permite que agentes de inteligência artificial executem tarefas reais no computador usando um princípio de funcionamento com prioridade local (local-first). Ela permite que os usuários definam suas próprias chaves e monitorem os fluxos de trabalho de equipes de agentes através de uma interface de arte em pixel.
