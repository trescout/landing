# Agente de IA para tarefas complexas

Desenvolvido pela ByteDance, Deer-Flow é uma estrutura de superagente de código aberto projetada para executar tarefas de longa duração. Sistema; Ele pode pesquisar e codificar de forma autônoma fluxos de trabalho complexos usando sandbox, gerenciamento de memória e subagentes.

## O que você ganha
- Pesquisa autônoma e capacidade de codificação
- Trabalhando em um ambiente sandbox seguro
- Memória de longo prazo e gerenciamento de subagentes

## Instalação
**Clonando o repositório**

```
git clone https://github.com/bytedance/deer-flow.git
   cd deer-flow
```

**Iniciando o assistente de configuração**

```
make setup
```


## Execução
**Lançando com Docker**

```
make docker-init    # Pull sandbox image (only once or when image updates)
make docker-start   # Start services (auto-detects sandbox mode from config.yaml)
```


## Se você não programa
Clone o repositório DeerFlow em meu computador e execute o comando make setup para concluir a configuração necessária para o ambiente de desenvolvimento local. Ajude-me a configurar opções como provedor LLM, preferências de pesquisa na web e configurações de segurança durante o assistente de configuração.
