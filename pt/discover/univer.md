# Conjunto de ferramentas de escritório de código aberto

O Univer é uma plataforma de código aberto que combina ferramentas de escritório como planilhas, documentos e apresentações em um único tempo de execução (runtime). Ele oferece uma estrutura modular projetada para facilitar a interação de agentes de inteligência artificial (AI agents) com softwares de escritório.

## O que você ganha

- Incorpore experiências de planilha, documento e apresentação em seu próprio aplicativo.
- Execute operações de processamento de dados com a mesma arquitetura no navegador ou no lado do servidor.
- Reúna apenas os recursos de que você precisa com a arquitetura de plugins modulares.

## Instalação

**Clonando o Repositório e Ambiente de Desenvolvimento B**

```
git clone https://github.com/dream-num/univer.git
cd univer
pnpm install
pnpm dev
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Para executar o projeto Univer no ambiente local, clone o repositório no terminal com o comando git clone https://github.com/dream-num/univer.git, depois navegue até a pasta com cd univer, instale as dependências usando pnpm install e, em seguida, execute o comando pnpm dev.
