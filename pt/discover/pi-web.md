# Interface da Web para agente de codificação Pi

Pi-web oferece uma interface de usuário baseada na web aprimorada (UI da web) para o agente de codificação Pi. Esta ferramenta, escrita em linguagem TypeScript, permite gerenciar processos de codificação por meio de uma interface visual.

- ★ 3.714
- TypeScript
- GitHub Trending · 2026-07-22

## O que você ganha
- Digitalize visualmente sessões de codificação anteriores
- Visualizar arquivos via navegador
- Gerenciar configurações de modelo e capacidade na interface

## Instalação
**Inicialização rápida sem instalação**

```
npx @agegr/pi-web@latest
```

**Carregar globalmente**

```
npm install -g @agegr/pi-web
pi-web
```


## Se você não programa
Quero visualizar meu trabalho com o agente de codificação Pi e gerenciar minhas sessões com mais eficiência. Como posso visualizar meus arquivos de sessão local por meio do navegador, editar meu histórico de bate-papo e visualizar meus arquivos de projeto por meio da interface usando a ferramenta Pi Web? Explique passo a passo como posso facilitar a configuração do modelo e o gerenciamento de talentos usando o espaço de trabalho aberto no navegador após a instalação.
