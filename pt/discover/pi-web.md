# Interface da Web para agente de codificação Pi

Pi-web oferece uma interface de usuário baseada na web aprimorada (UI da web) para o agente de codificação Pi. Esta ferramenta, escrita em linguagem TypeScript, permite gerenciar processos de codificação por meio de uma interface visual.

## O que você ganha

- Digitalize visualmente sessões de codificação anteriores
- Visualizar arquivos via navegador
- Gerenciar configurações de modelo e capacidade na interface

## Instalação

**Inicialização rápida sem instalação**

```
npx @agegr/pi-web@latest
```

**Carregar globalmente**

```
npm install -g @agegr/pi-web
pi-web
```
