# Radar de acompanhamento de notícias com IA pessoal

Thysrael/Horizon é uma ferramenta de acompanhamento de notícias que coleta, filtra e resume notícias de diferentes fontes usando inteligência artificial. Este software, que prepara boletins diários em inglês e chinês, ajuda os usuários a gerenciar seu fluxo de informações apresentando conteúdos junto com o contexto e discussões da comunidade.

## O que você ganha

- Coleta e filtra automaticamente notícias de diferentes fontes.
- Prepara boletins de resumo diários em inglês e chinês.
- Apresenta as notícias junto com o contexto e as discussões da comunidade.

## Instalação

**Clonagem e instalação do projeto**

```
git clone https://github.com/Thysrael/Horizon.git
cd Horizon

# Install with uv (recommended)
uv sync

# Install test/development extras when needed
uv sync --extra dev

# Or with pip
pip install -e .
```

## Execução

**Iniciar o assistente**

```
uv run horizon-wizard
```
