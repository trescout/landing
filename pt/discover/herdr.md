# Gerenciamento múltiplo de inteligência artificial no terminal

Desenvolvido com a linguagem Rust, o herdr funciona como um multiplexador de agente rodando no terminal. Esta ferramenta permite aos usuários gerenciar vários agentes de inteligência artificial simultaneamente no ambiente do terminal.

- ★ 9.203
- Rust
- GitHub Trending · 2026-07-01

## O que você ganha
- Gerencie vários agentes de inteligência artificial simultaneamente em um único terminal.
- Monitore instantaneamente o status de trabalho dos agentes com indicadores coloridos.
- Mantenha as sessões em execução em segundo plano mesmo se a conexão for perdida.

## Instalação
**Instalação para Linux e macOS**

```
curl -fsSL https://herdr.dev/install.sh | sh
```


## Execução
**Iniciando a ferramenta**

```
herdr
```


## Se você não programa
Quero gerenciar todos os meus agentes de inteligência artificial em execução no terminal a partir de um único centro e ver instantaneamente o status de funcionamento (em espera, em execução, concluído) de cada um deles. Use o Herdr para me ajudar a configurar esses agentes para separá-los em diferentes espaços de trabalho e guias para que os processos continuem em segundo plano mesmo se eu fechar o terminal.
