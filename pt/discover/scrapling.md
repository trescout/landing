# Extraia seus dados com web scraping flexível

Scrapling é uma estrutura de web scraping adaptável que pode lidar com escala desde uma única solicitação até trabalhos de rastreamento em grande escala. Tem como objetivo fornecer alta adaptabilidade mesmo que a estrutura da página mude. É baseado em Python.

## O que você ganha
- Ferramenta abrangente que pode realizar varreduras em grande escala com uma única solicitação.
- Adaptação automática às mudanças de página.
- Estrutura rápida e de código aberto.

## Instalação (comando único)
**Python (pip)**

```
pip install scrapling
```
