# Mensagens seguras via Bluetooth sem internet

Bitchat-android oferece uma experiência de mensagens descentralizada que não requer conexão com a internet, usando tecnologia mesh Bluetooth. O aplicativo, desenvolvido em linguagem Kotlin, permite aos usuários estabelecer comunicação semelhante a IRC na rede local.

- ★ 7.424
- Kotlin
- GitHub Trending · 2026-07-27

## O que você ganha
- Comunicação sem internet com tecnologia mesh Bluetooth
- Mensagens criptografadas e descentralizadas de ponta a ponta
- Privacidade sem necessidade de conta ou número de telefone

## Instalação
**Copie o repositório para o seu computador**

git clone https://github.com/permissionlesstech/bitchat-android.git
   cd bitchat-android
