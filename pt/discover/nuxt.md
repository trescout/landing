# Desenvolvimento web full-stack com Vue

Nuxt é uma estrutura full-stack usada para desenvolver aplicativos baseados em Vue. Oferecida com suporte TypeScript, esta ferramenta otimiza a renderização do lado do servidor e os processos de criação de sites estáticos.

- ★ 60.726
- TypeScript
- GitHub Trending · 2026-07-12

## O que você ganha
- Renderização do lado do servidor e geração de site estático
- Roteamento automático e divisão de código
- Ambiente de desenvolvimento configurado com TypeScript

## Instalação
**Crie um novo projeto**

```
npm create nuxt@latest <my-project>
```
