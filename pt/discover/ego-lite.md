# Navegador simultâneo para agentes de IA

Ego-lite é um navegador que permite que usuários e agentes de inteligência artificial trabalhem simultaneamente. Esta ferramenta baseada em JavaScript tem como objetivo realizar a interação humana e máquina em paralelo no mesmo ambiente de navegador.

- ★ 14.478
- JavaScript
- GitHub Trending · 2026-07-24

## O que você ganha
- Agentes e usuários são executados no mesmo navegador sem conflito
- Protege sessões importando dados do Chrome
- Conclusão de tarefas mais rápida com estrutura baseada em JavaScript

## Instalação
**Adicionando habilidades**

```
npx skills add citrolabs/ego-lite
```


## Execução
**Iniciar uma tarefa**

```
ego-browser follow @ego_agent on x.com for me
```


## Se você não programa
Configure o ego lite para mim: https://github.com/citrolabs/ego-lite. Leia `skills/ego-browser/references/install.md` e siga as etapas para instalar o ego lite.
