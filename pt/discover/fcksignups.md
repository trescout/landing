# Ferramentas de código aberto que não exigem registro

FckSignups é uma lista que reúne ferramentas baseadas em navegador de código aberto que não exigem registro ou associação do usuário. Ela centraliza serviços digitais que desenvolvedores de software e usuários finais podem acessar rapidamente sem criar contas.

## O que você ganha

- Fornece acesso a ferramentas sem a necessidade de registro ou e-mail
- Oferece uma lista segura, sem rastreamento de dados ou monitoramento
- Inclui ferramentas em diferentes categorias, como design, desenvolvimento e produtividade

## Instalação

**Execução em ambiente local**

```
git clone https://github.com/BraveOPotato/FckSignups.git && \
cd FckSignups && \
npm install && \
npm run dev
```
