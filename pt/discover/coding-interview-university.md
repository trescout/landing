# Guia de preparação para entrevistas de software

A Universidade de Entrevista de Codificação oferece um plano de estudo abrangente que cobre os fundamentos da ciência da computação para aqueles que desejam se tornar engenheiros de software. Este recurso combina o conhecimento teórico e prático necessário na preparação para entrevistas técnicas com um currículo estruturado.

## O que você ganha
- Currículo estruturado de ciência da computação para entrevistas técnicas
- Conhecimento teórico aprofundado de estruturas de dados e algoritmos
- Preparação abrangente para processos de entrevista de engenharia de software

## Se você não programa
Estou me preparando para uma entrevista de engenharia de software usando o currículo da Coding Interview University. Crie um plano de estudo diário para que eu aprenda as estruturas de dados, algoritmos e tópicos de ciência da computação abordados neste recurso. Você pode preparar um roteiro do nível iniciante ao avançado que inclua os assuntos básicos que preciso aprender, a ordem em que devo estudá-los e os recursos com os quais posso praticar?
