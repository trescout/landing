Descobrir · GitHub · Maka

Espaço de trabalho local para agentes de IA

Apache Maka é um espaço de trabalho local desenvolvido para agentes de inteligência artificial. Ele fornece rastreabilidade dos processos do agente gravando mensagens, chamadas de veículos e decisões de permissão em um registro orientado a anexos.

  • ★ 2.064
  • TypeScript
  • GitHub Trending · 2026-08-22

Atualizações

  • 22 de agosto de 2026: Estrelas 2,062 → 2,064, versão mais recente v0.1.11 (18 de agosto de 2026).

O que você ganha

  • Armazena dados com segurança em seu computador local
  • Registra histórico de transações e chamadas de veículos
  • Oferece ferramentas nativas como edição de arquivos e execução de comandos

Instalação

Iniciando o ambiente de desenvolvimento
git clone https://github.com/apache/maka.git
cd maka
npm ci
npm run dev
Crie todos os espaços de trabalho
npm run dev:full

Execução

Iniciando a interface do terminal
npm run cli:dev

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

No espaço de trabalho Maka, você precisa analisar um projeto, organizar os arquivos usando as ferramentas necessárias e manter todas as suas ações em um registro rastreável. Controle as permissões em todo o seu fluxo de trabalho, preserve as mensagens do modelo e gerencie o processo de forma recuperável em caso de erros.
