# Acelere os processos de compra de ingressos Bilibili

Esta ferramenta baseada em Python que automatiza os processos de compra de membros do Bilibili é um assistente de compra de ingressos projetado para agilizar os processos de compra de ingressos. Ele permite que os usuários obtenham produtos de estoque limitado na plataforma com mais rapidez.

## O que você ganha
- Automatiza a compra de ingressos via Bilibili
- Aumenta a velocidade de captura de produtos de estoque limitado
- Uma ferramenta utilitária prática para uso pessoal

## Instalação
**Instalação automática para Linux macOS**

```
curl -fsSL https://raw.githubusercontent.com/mikumifa/biliTickerBuy/main/install.sh | sh
```

**via pip (PyPI)**

```
pip install biliTickerBuy
```


## Execução
**Executar a partir da linha de comando**

```
btb
```
