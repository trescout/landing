# Programe animações matemáticas explicativas

Manim é um mecanismo de animação para criar vídeos matemáticos explicativos precisos por meio de programação. Você pode definir as animações em Python e começar com as cenas de exemplo do repositório 3b1b selecionado.

- ★ 90.309
- GitHub Trending · 2026-08-12

## O que esta ferramenta faz?
Esta página trata do ManimGL do repositório 3b1b. Ele é usado para criar em código animações que explicam conceitos matemáticos. O Manim Community Edition é um fork e projeto separado, portanto suas instruções de instalação não devem ser misturadas com as do ManimGL.

## Para quem é?
Educadores, estudantes e criadores de conteúdo que querem explicar conceitos matemáticos com animações programadas.

## O que não esperar
Pessoas que procuram uma ferramenta de animação com interface de arrastar e soltar ou que querem instalar especificamente o Manim Community Edition.

## Destaques
- Animação programática para vídeos matemáticos explicativos.
- Funciona com Python 3.10 ou mais recente.
- OpenGL faz parte dos requisitos do sistema.
- Licença MIT.

## Primeiro fluxo de uso
- Prepare Python 3.10 ou mais recente, FFmpeg e os requisitos de OpenGL.
- Instale LaTeX se for usá-lo; no Linux, instale também os headers de desenvolvimento do Pango.
- Execute `pip install manimgl` no terminal.
- Teste a instalação com `manimgl example_scenes.py OpeningManimExample`.

## Instalação
**Instale o ManimGL**

```
pip install manimgl
```


## Execução
**Execute a cena de exemplo**

```
manimgl example_scenes.py OpeningManimExample
```
