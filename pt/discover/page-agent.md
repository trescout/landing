# Gerencie interfaces web com linguagem natural

Desenvolvido pela Alibaba, o page-agent é um agente de interface gráfica de usuário in-page que permite controlar interfaces da web com comandos de linguagem natural. Escrita em TypeScript, esta ferramenta oferece um mecanismo de controle baseado em navegador para automatizar as interações na web.

## O que você ganha
- Não são necessárias extensões de navegador ou Python
- Renderização DOM baseada em texto em vez de capturas de tela
- Integração com seus próprios modelos de IA

## Instalação
**Instalação via NPM**

```
npm install page-agent
```


## Se você não programa
Quero gerenciar interações na página da web com comandos de linguagem natural usando PageAgent. Quero que ele execute operações como clicar em botões da página, preencher formulários ou inserir dados usando o modelo de inteligência artificial que determinei.
