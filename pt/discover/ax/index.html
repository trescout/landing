Descobrir · GitHub · AX

Ferramenta de orquestração para agentes de inteligência artificial

Desenvolvido pelo Google, o Ax é um tempo de execução (runtime) de orquestração de código aberto para agentes de inteligência artificial. Escrito em Go, essa infraestrutura facilita o gerenciamento e a execução de fluxos de trabalho agênticos complexos.

O que você ganha

  • Permite gerenciar bilhões de cargas de trabalho de IA autônomas.
  • Permite executar agentes em um ambiente sandbox seguro e isolado.
  • Oferece configuração rápida e declarativa com arquivos YAML.

Instalação

Instalando a ferramenta CLI
go install github.com/google/ax/cmd/ax@latest
Implantando o plano de controle
make deploy AX_IMAGE_REPO=<your-registry>

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Quero instalar a ferramenta AX, desenvolvida pelo Google e que fornece orquestração para agentes de inteligência artificial. Primeiro, instale a ferramenta de linha de comando executando o comando `go install github.com/google/ax/cmd/ax@latest`. Em seguida, implante o plano de controle usando o comando `make deploy AX_IMAGE_REPO=<your-registry>`.
