# Virtualização rápida do Linux no Mac

Desenvolvido pela Apple, o container permite criar e executar containers Linux usando máquinas virtuais leves no Mac. Escrita em linguagem Swift, a ferramenta oferece desempenho otimizado para a arquitetura de silício da Apple.

- ★ 49.541
- Swift
- GitHub Trending · 2026-06-11

## O que você ganha
- Ele executa contêineres Linux como máquinas virtuais leves em dispositivos Mac com processadores Apple Silicon.
- Ele permite extrair e usar imagens de contêiner compatíveis com OCI de registros padrão.
- Ele é escrito em linguagem Swift e oferece alto desempenho usando recursos de virtualização do macOS.
