# Registro rápido para projetos C++

spdlog é uma biblioteca de registro muito rápida desenvolvida para a linguagem de programação C++. Oferece gerenciamento de saída de alto desempenho para acelerar processos de depuração e monitoramento em projetos de software.

- ★ 29.437
- C++
- GitHub Trending · 2026-08-05

## O que você ganha
- Gerenciamento de registros de alto desempenho
- Saída para diferentes destinos, como arquivo, console e depurador
- Alteração dinâmica do nível de log em tempo de execução

## Instalação
**macOS (homebrew)**

```
brew install spdlog
```


## Como começar
Para incluí-lo em seu projeto, basta copiar a pasta include da página GitHub para seu diretório de trabalho. Alternativamente, você pode instalar a biblioteca usando o comando apropriado ao seu sistema através de gerenciadores de pacotes como Debian, Homebrew ou vcpkg.
