Ferramenta de depuração visual e nativa

Desenvolvido pela Epic Games, o raddebugger é um depurador nativo e visual escrito na linguagem C. Oferecendo suporte a múltiplos processos (multi-process), esta ferramenta opera no modo de usuário para ajudar os desenvolvedores de software a detectar erros em aplicações.

Atualizações

  • 7 de outubro de 2026: Estrelas 7,693 → 7,702, versão mais recente v0.9.29-alpha (30 de setembro de 2026).

O que você ganha

  • Com o Raddebugger, um depurador com interface visual, você pode detectar facilmente bugs em suas aplicações.
  • Com a ferramenta de vinculação de código RAD Linker, você pode reduzir os tempos de compilação em grandes projetos de software.
  • Com o formato de dados personalizado RDI, você pode converter rapidamente informações de depuração e obter melhorias de desempenho.

Como começar

Você pode baixar os arquivos pré-compilados adequados para o seu sistema na seção de lançamentos (releases) na página do GitHub do projeto. Você pode começar a usar a ferramenta imediatamente seguindo o manual de instruções dentro da pasta baixada.
