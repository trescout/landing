# Ferramenta de download de mídia tudo-em-um

O Omniget é um aplicativo de desktop de código aberto que permite baixar vídeos, músicas e livros de mais de 1.800 plataformas. Com um reprodutor de cursos, leitor de e-books e biblioteca de música integrados, esta ferramenta realiza downloads através de uma interface gráfica, sem a necessidade de usar o terminal.

- ★ 12.132
- Rust
- GitHub Trending · 2026-09-14

## O que você ganha
- Baixa vídeos, músicas e e-books de mais de 1.800 plataformas
- Oferece ferramentas integradas para reproduzir e gerenciar o conteúdo baixado
- Gerenciado facilmente através de uma interface gráfica sem usar o terminal

## Instalação
**instalação para janelas**

```
winget install -e --id tonhowtf.OmniGet
```

**configuração para macOS**

```
brew install --cask tonhowtf/tap/omniget
```
