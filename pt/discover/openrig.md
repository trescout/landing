# Gerencie agentes de inteligência artificial em um único sistema

O Openrig é uma infraestrutura multi-agente que combina a ferramenta de programação Claude Code, da Anthropic, e o modelo de programação Codex, da OpenAI, em um único sistema. Ele permite que os desenvolvedores usem diferentes modelos de IA simultaneamente no mesmo fluxo de trabalho.

## O que você ganha

- Combina diferentes modelos de ferramentas de programação de IA em uma única infraestrutura.
- Define equipes de agentes com YAML e os inicia com um único comando.
- Fornece resultados garantindo a coordenação entre os agentes.

## Instalação

**Instale a ferramenta CLI**

```
npm install -g @openrig/cli
rig setup --dry-run
```
