# Melhore os resultados dos agentes de inteligência artificial

O Pstack-claude é uma biblioteca de automação que adapta as funcionalidades principais da ferramenta de desenvolvimento de software Cursor para diferentes modelos e plataformas de inteligência artificial. Ele permite que os desenvolvedores executem fluxos de trabalho de agentes de IA complexos de maneira padronizada em vários ambientes de trabalho.

- ★ 1.292
- JavaScript

## O que você ganha
- mantém o seu código curto, simples e verificado
- adaptado para diferentes modelos e plataformas de inteligência artificial
- executa localmente e não possui servidores ou telemetria

## Como começar
Você pode começar executando os comandos de plugin correspondentes através da sua plataforma Claude Code, Codex ou Pi. Você pode consultar a documentação para obter etapas detalhadas de instalação compartilhada.
