# Gerencie seu próprio arquivo de mídia

LunaTV é um projeto desenvolvido na linguagem TypeScript que oferece uma interface de visualização de mídia de código aberto. Este software, que não é destinado ao uso comercial, permite que os usuários assistam aos seus próprios conteúdos de mídia em uma estrutura organizada.

- ★ 10.021
- TypeScript
- GitHub Trending · 2026-09-08

## O que você ganha
- Possibilidade de assistir a conteúdos de mídia pessoais em uma interface organizada
- Sincronização do histórico de visualização e favoritos entre dispositivos
- Experiência de visualização portátil via navegador, sem necessidade de instalação

## Como começar
Esta ferramenta funciona com a tecnologia de conteinerização de software chamada Docker. Para a instalação, você pode acessar a seção '部署' (Implantação) na página do GitHub do projeto para usar os arquivos Docker Compose ou realizar uma instalação com um clique através de plataformas em nuvem como o Zeabur. Lembre-se de que o projeto vem com uma interface vazia e você precisa adicionar suas próprias fontes de mídia.
