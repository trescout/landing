# rabo de gato

Desenvolvido pela Tailscale, Tailcat é uma versão do Netcat, uma ferramenta de linha de comando usada para transferir tráfego de rede com segurança, rodando na camada de rede Tailscale. Ele fornece transmissão direta de dados entre dispositivos sem a necessidade de um plano de controle.
