Editor de arquitetura 3D baseado na Web

Pascalorg/editor baseado em TypeScript permite aos usuários criar e compartilhar projetos arquitetônicos tridimensionais por meio do navegador. O software tem como objetivo tornar os processos de projeto arquitetônico acessíveis por meio de uma interface baseada na web.

O que você ganha

  • Modelagem arquitetônica 3D com React Three Fiber
  • Visualização de alto desempenho com suporte WebGPU
  • Estágio central baseado em Zustand e gerenciamento de status

Instalação

Instale os pacotes necessários
npm install @pascal-app/core @pascal-app/viewer @pascal-app/editor @pascal-app/nodes

Execução

Inicie o servidor de desenvolvimento
bun dev

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Quero criar uma cena arquitetônica usando o Pascal Editor. Ajude-me a construir uma estrutura 3D básica usando os pacotes @pascal-app/core e @pascal-app/viewer incluídos na arquitetura do projeto. Explique passo a passo como configurar os ganchos useScene e useViewer para gerenciar o estado da cena, definir a hierarquia do nó (Site, Building, Level) e integrar um componente NodeRenderer na cena.
