Descobrir · GitHub · FFF

Velocidade da inteligência artificial na busca de arquivos

Desenvolvido com Rust, fff é um kit de ferramentas para agentes de inteligência artificial e editores de texto que realiza buscas em arquivos com alta velocidade e precisão. Com suporte a C e NodeJS, oferece uma estrutura que pode ser integrada a diversos ambientes de desenvolvimento.

O que você ganha

  • Ele fornece alta velocidade na pesquisa de arquivos e navegação de conteúdo.
  • Ele oferece classificação baseada em frequência que prioriza arquivos usados ​​com frequência.
  • Ele fornece indexação otimizada para agentes e editores de inteligência artificial.

Instalação

Instalação do servidor MCP (Linux/macOS)
curl -L https://dmtrkovalenko.dev/install-fff-mcp.sh | bash
Instalação do plug-in do agente Pi
pi install npm:@ff-labs/pi-fff

Execução

Configuração para Agente
For any file search or grep in the current git-indexed directory, use fff tools.

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Use ferramentas fff para todas as operações de pesquisa de arquivos e rastreamento de conteúdo (grep) em meu projeto. Essas ferramentas retornarão resultados mais eficientes graças à classificação baseada em frequência e aos recursos de indexação rápida.
