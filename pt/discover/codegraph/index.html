Mapeie sua base de código para a inteligência artificial

O Codegraph é uma ferramenta local de gráfico de conhecimento (knowledge graph) que pré-indexa bases de código e as apresenta a modelos de inteligência artificial. Ao sincronizar automaticamente as alterações de código, ele permite que assistentes de codificação como o Claude Code ou o Cursor usem menos tokens e chamadas de ferramentas.

O que você ganha

  • Cria um gráfico de conhecimento local que permite que os modelos de inteligência artificial consumam menos tokens durante a codificação.
  • Sincroniza automaticamente as alterações de código em segundo plano, mantendo o índice sempre atualizado.
  • Conecta ferramentas como o assistente de codificação Cursor diretamente à arquitetura do seu projeto.

Instalação

Instalação global com o gerenciador de pacotes npm
npm i -g @colbymchenry/codegraph

Execução

Execução direta da ferramenta com npx e vinculação
npx @colbymchenry/codegraph

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Instale a ferramenta Codegraph executando o comando `npm i -g @colbymchenry/codegraph` através do gerenciador de pacotes npm no seu projeto. Em seguida, execute o comando `npx @colbymchenry/codegraph` para configurar os assistentes de inteligência artificial e concluir o processo.
