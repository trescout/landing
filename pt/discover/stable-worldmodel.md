# Acelere a pesquisa do modelo mundial

modelo de mundo estável; É uma plataforma que garante que a investigação sobre “modelos mundiais” seja repetível e comparável. Centra-se particularmente nos processos de investigação e avaliação.

- ★ 2.080
- Python
- Lisans: kontrol et
- GitHub Trending · 30 May 2026

## O que isso faz?
- Tornando a pesquisa reproduzível.
- Fornecer um ambiente de avaliação padrão.
- Não é uma ferramenta para o usuário final, mas uma solução direta para pesquisa.

## Como instalar, como usar?
**Instalar do PyPI (todos os plug-ins)**

```
pip install 'stable-worldmodel[all]'
```

**Listar conjuntos de dados armazenados em cache**

```
swm datasets
```
