Assistente de inteligência artificial com seus próprios dados

Open-notebook oferece uma alternativa de código aberto ao Google NotebookLM, permitindo que os usuários realizem análises de notas personalizáveis com tecnologia de IA em seus próprios dados. Desenvolvido com TypeScript, este projeto oferece maior flexibilidade e conjunto expandido de recursos em comparação com a plataforma original.

O que você ganha

  • Analise seus dados em um ambiente totalmente local, mantendo-os confidenciais.
  • Obtenha seleção flexível de modelos de mais de 18 fornecedores de IA.
  • Crie podcasts profissionais a partir de seus arquivos PDF, vídeo e áudio.

Instalação

Baixe o arquivo de configuração
curl -o docker-compose.yml https://raw.githubusercontent.com/lfnovo/open-notebook/main/docker-compose.yml

Execução

Iniciando serviços
docker compose up -d

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Quero instalar a ferramenta Open Notebook. O Docker Desktop está instalado. Primeiro, preciso baixar o arquivo docker-compose.yml com o comando curl e, em seguida, alterar a seção OPEN_NOTEBOOK_ENCRYPTION_KEY no arquivo com uma senha exclusiva. No último estágio, preciso concluir a instalação executando o comando docker compose up -d. Há alguma outra configuração ou etapa que devo prestar atenção neste processo?
