# Mecanismo para execução e entrega rápida de modelos de inteligência artificial

vllm-project/vllm é um motor de inferência e atendimento que fornece alta vazão e eficiência de memória para grandes modelos de linguagem (LLMs). Desenvolvido em Python, esta ferramenta visa acelerar os processos de execução de modelos de inteligência artificial.

## O que você ganha

- oferece gerenciamento PagedAttention que garante eficiência de memória
- funciona de forma compatível com os modelos populares do Hugging Face
- inclui suporte a servidor de API compatível com OpenAI

## Instalação

**instalação do vLLM**

```
uv pip install vllm
vllm download-kernels  # precompiled kernels for faster startup
```
