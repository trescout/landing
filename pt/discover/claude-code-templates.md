# Configurações prontas para Claude Code

Os modelos do Claude Code fornecem uma interface de linha de comando (CLI) para a ferramenta Claude Code que simplifica a configuração e o monitoramento. Esta ferramenta baseada em Python padroniza o controle dos desenvolvedores sobre o assistente de codificação e o gerenciamento do fluxo de trabalho.

- ★ 30.058
- Python
- GitHub Trending · 2026-07-11

## O que você ganha
- Mais de cem agentes de IA prontos e acesso de comando
- Integração rápida e gerenciamento de ganchos para serviços externos
- Análise e monitoramento em tempo real para sessões de desenvolvimento

## Instalação
**Iniciar configuração interativa**

```
npx claude-code-templates@latest
```

**Instalação de componentes personalizados**

```
npx claude-code-templates@latest --agent development-tools/code-reviewer --yes
```


## Execução
**Ver análises da sessão**

```
npx claude-code-templates@latest --analytics
```

**Abra o painel de monitoramento de chat**

```
npx claude-code-templates@latest --chats
```
