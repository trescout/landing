# Traga originalidade aos designs de IA

Hallmark é um arquivo de estilo desenvolvido para reduzir o impacto do conteúdo padrão produzido pela inteligência artificial (resíduos de IA) no design. Claude Code garante que as interfaces utilizadas em ferramentas como Cursor e Codex ganhem uma estética única e humana.

## O que você ganha
- Evita a estética padrão da IA
- Cria interfaces exclusivas com vinte temas diferentes
- Audita e redesenha códigos existentes

## Instalação
**Adicionar veículo**

```
npx skills add nutlope/hallmark
```


## Se você não programa
Crie um design de interface exclusivo que não pareça ter sido criado por IA usando o arquivo de estilo Hallmark. Evite modelos padrão no design, escolha o apropriado entre vinte temas diferentes e crie uma estrutura única que passará em cinquenta e sete testes de qualidade.
