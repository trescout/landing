## Instalação
**macOS ou Linux**

```
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

**Windows PowerShell**

```
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```


## Execução
**Iniciar o Codex CLI**

```
codex
```


## O que esta ferramenta faz?
O Codex CLI é um agente de programação executado no terminal do seu computador local. Ele pode revisar o código em um diretório de projeto, fazer alterações em arquivos, executar comandos e ajudar a automatizar tarefas repetitivas.

## Para quem é?
Desenvolvedores que desejam trabalhar no terminal, revisar a base de código, editar arquivos e automatizar tarefas repetitivas de desenvolvimento.

## O que não esperar
Pode não ser adequado para quem não deseja usar o terminal.

## Destaques
- Ele pode revisar código e fazer alterações em arquivos.
- Ele pode executar comandos e automatizar tarefas repetitivas.
- O modelo, o reasoning effort, as permissões e as aprovações de comandos podem ser gerenciados pelo usuário.
- O repositório do GitHub é licenciado sob Apache-2.0.

## Primeiro fluxo de uso
- Escolha o método de instalação oficial adequado ao seu sistema operacional.
- Inicie o Codex CLI após a instalação.
- Faça login com o ChatGPT ou com outro método de login disponível.
- Comece no diretório do projeto. Crie um checkpoint do Git antes e depois das alterações.
