# Guia para trocar rostos em imagens

Faceswap baseado em Python é um software de código aberto que permite substituir rostos em imagens usando tecnologia deepfake. Ele permite aos usuários realizar operações de troca de rosto em vídeos e imagens.

## O que você ganha
- Mudança de rosto em imagens e vídeos
- Treinamento com modelos de aprendizagem profunda
- Extração de rosto em conteúdo visual

## Instalação
**Clonar repositório**

```
git clone --depth 1 https://github.com/deepfakes/faceswap.git && cd faceswap
```


## Execução
**Assistente de configuração**

```
python setup.py
```
