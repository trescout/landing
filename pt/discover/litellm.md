# Gerencie modelos de inteligência artificial de forma centralizada

O LiteLLM é um gateway de IA (AI gateway) que unifica mais de 100 interfaces de grandes modelos de linguagem (LLM) em um único formato padrão. Ele facilita a alternância entre diferentes provedores de modelos, oferecendo aos desenvolvedores recursos como monitoramento de custos, balanceamento de carga e barreiras de proteção (guardrails).

## O que você ganha

- Evita a desorganização no código ao unificar mais de cem provedores de LLM (Grande Modelo de Linguagem) em um único formato padrão.
- Elimina a necessidade de reescrever sua base de código ao alternar entre modelos de inteligência artificial.
- Oferece uma infraestrutura de gerenciamento de nível corporativo com ferramentas como chaves virtuais, controle de orçamento e balanceamento de carga.

## Instalação

**Instalar a biblioteca Python da linguagem de programação**

```
uv add litellm
```

## Execução

**Iniciar o servidor gateway**

```
uv tool install 'litellm[proxy]'
litellm --model gpt-4o
```
