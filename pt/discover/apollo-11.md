# Códigos-fonte do computador de orientação da Apollo 11

O código-fonte original do computador de comando e orientação do módulo lunar (Guidance Computer) utilizado na missão Apollo 11 foi disponibilizado no GitHub em linguagem assembly. O software documenta os detalhes técnicos dos algoritmos de cálculo utilizados na primeira missão tripulada a pousar na Lua.

## Como começar

Este repositório foi criado para arquivar os códigos-fonte originais do computador de orientação usado na missão Apollo 11. Você pode navegar nas pastas Comanche055 ou Luminary099 no GitHub para revisar os códigos e visitar o site oficial do projeto Virtual AGC para obter informações detalhadas sobre os processos de compilação.
