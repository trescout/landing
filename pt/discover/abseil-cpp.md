# Ferramentas que aproveitam a biblioteca padrão C++

Desenvolvido pelo Google, o Abseil oferece trechos de código-fonte aberto que complementam a biblioteca padrão C++. Esta biblioteca fornece estruturas de dados e algoritmos básicos para melhorar a capacidade de manutenção e o desempenho do código em projetos de software complexos.

- ★ 18.083
- C++
- GitHub Trending · 2026-07-11

## O que você ganha
- Fornece estruturas de dados e algoritmos subjacentes compatíveis com C++17
- Fornece trechos de código confiáveis ​​testados em projetos do Google
- Completa a funcionalidade ausente na biblioteca padrão

## Instalação
**macOS (homebrew)**

```
brew install abseil
```
