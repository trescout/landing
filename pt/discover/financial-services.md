# Modelos de IA para serviços financeiros

Esta biblioteca Python publicada pela Anthropic oferece modelos prontos e exemplos de código para o desenvolvimento de aplicações de inteligência artificial para o setor de serviços financeiros. Seu objetivo é orientar os desenvolvedores que desejam automatizar os processos de análise e geração de relatórios de dados financeiros.

- ★ 37.453
- GitHub Trending · 2026-09-21

## O que você ganha
- Automatiza processos bancários de investimento e gerenciamento de ativos
- Oferece plug-ins prontos e modelos de API
- Permite que você conduza pesquisas de mercado e modelagem financeira

## Instalação
**Implantar agente gerenciado**

```
export ANTHROPIC_API_KEY=sk-ant-...
scripts/deploy-managed-agent.sh gl-reconciler
```


## Se você não programa
Instale o plugin Claude Cowork para criar análises financeiras e modelos de avaliação e iniciar processos de pesquisa de mercado e avaliação de receitas.
