# Download rápido de vídeos via terminal

Yoinks é uma ferramenta para baixar qualquer vídeo via terminal (linha de comando) sem anúncios ou redirecionamentos. Desenvolvido com TypeScript, este software oferece um método prático para transferir arquivos de vídeo diretamente para o armazenamento local.

## O que você ganha

- Baixa vídeos de mais de 1800 sites, como YouTube, Instagram e TikTok
- Salva diretamente no armazenamento local sem anúncios ou botões de download falsos
- Oferece a possibilidade de selecionar a resolução do vídeo ou baixar apenas o arquivo de áudio

## Instalação

**Instalação global**

```
npm install -g yoinks
```

**Operação sem instalação**

```
npx yoinks
```

## Execução

**Iniciar com link de vídeo**

```
yoinks https://youtu.be/dQw4w9WgXcQ
```

**Iniciar com menu interativo**

```
yoinks
```
