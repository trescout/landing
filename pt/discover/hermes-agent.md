# Desenvolvimento de Inteligência Artificial por meio de Interações do Usuário

Desenvolvido pela NousResearch, o Hermes Agent oferece uma infraestrutura de agente autônomo que aprende com as interações do usuário e se desenvolve ao longo do tempo. Este sistema baseado em Python usa aprendizado contínuo para criar fluxos de trabalho personalizados.

## O que você ganha

- Capacidades autônomas que evoluem ao longo do tempo aprendendo com as interações do usuário.
- Oportunidade de trabalhar integrado com plataformas como Telegram, Discord e Slack.
- Capacidade de alternar entre diferentes modelos de inteligência artificial sem alterar o código.

## Instalação

**Instalação para Linux, macOS e WSL2**
