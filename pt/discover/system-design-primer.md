# Guia de design de sistema em grande escala

System Design Primer oferece um recurso de aprendizagem abrangente para quem deseja projetar sistemas de software em larga escala. Ele reúne princípios de design de sistemas e cartões de estudo práticos para desenvolvedores de software que se preparam para entrevistas técnicas.

## O que você ganha
- Aprenda princípios de arquitetura de sistema em larga escala
- Resolva questões práticas para entrevistas técnicas
- Use flashcards Anki para reter informações

## Como começar

Se quiser reforçar as informações, você pode baixar e usar os arquivos Anki (software que permite a memorização com flashcards) nos links relevantes.
