# Converta capturas de tela em código funcional

Screenshot-to-code é uma ferramenta de software que analisa arquivos de captura de tela e os converte em código HTML, Tailwind, React ou Vue limpo. Ele permite que os desenvolvedores traduzam rapidamente designs de interface em trechos de código funcionais.

## O que você ganha

- Traduz capturas de tela e arquivos de design em HTML limpo ou código React
- Transforma gravações de sites em protótipos funcionais
- Tailwind oferece suporte a CSS e várias bibliotecas de interface populares

## Instalação

**Instalação rápida com Docker**

```
echo "OPENAI_API_KEY=sk-your-key" > .env
docker-compose up -d --build
```

**Iniciando a interface**

```
cd frontend
pnpm install
pnpm dev
```
