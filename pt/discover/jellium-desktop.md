# Acesso desktop à sua biblioteca de mídia Jellyfin

Jellium-desktop é um cliente de desktop não oficial desenvolvido em Rust para o servidor de mídia Jellyfin. O software oferece uma interface nativa que permite aos usuários acessar bibliotecas de mídia diretamente através do sistema operacional.

- ★ 1.342
- Rust
- GitHub Trending · 2026-07-20

## O que você ganha
- Acesse seu servidor de mídia Jellyfin via aplicativo nativo
- Reprodução de mídia otimizada com infraestrutura CEF e MPV
- Suporte de interface nativa em Windows, macOS e Linux
