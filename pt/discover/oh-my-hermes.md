# Camada operacional profissional para o Hermes Agent

O oh-my-hermes, desenvolvido para o Hermes Agent, oferece pacotes de inteligência de codificação, sistema de memória de longo prazo e fluxo de trabalho orientado a modelos em um único plugin. Esta ferramenta, que otimiza os processos de desenvolvimento de software, proporciona aos desenvolvedores um ambiente de trabalho abrangente com sua estrutura baseada em Python.

## O que você ganha
- Oferece um ambiente de trabalho que otimiza os processos de desenvolvimento de software.
- Mantém o histórico do projeto organizado com um sistema de memória de longo prazo.
- Adiciona inteligência de codificação e fluxos de trabalho orientados a modelos.

## Instalação
**Instalação para macOS e Linux**

```
curl -fsSL https://raw.githubusercontent.com/rlaope/oh-my-hermes/main/install.sh | sh
```

**Instalação com gerenciador de pacotes Homebrew**

```
brew install rlaope/tap/omh
```


## Execução
**Configuração pós-instalação**

```
omh setup
```


## Se você não programa
Instale e configure o plugin Oh My Hermes no Hermes Agent. Durante o processo de instalação, utilize o instalador apropriado para o sistema operacional, conclua a configuração interativa do modelo, realize a conversa da cadeia de modelos e execute as etapas do 'doctor'. Mantendo a configuração atual do Hermes, aplique apenas as alterações de instalação documentadas e relate o resultado da operação.
