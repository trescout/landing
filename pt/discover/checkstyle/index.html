Checkstyle

Checkstyle é uma ferramenta de análise que ajuda os programadores Java a desenvolver software de acordo com padrões de codificação estabelecidos. Ela verifica a qualidade do código suportando padrões como o Google Java Style Guide e as Sun Code Conventions.
