# Roteiro de treinamento de grandes modelos de linguagem

mlabonne/llm-course é um recurso educacional abrangente que contém roteiros e notebooks Colab para aqueles que desejam ingressar na área de grandes modelos de linguagem (LLM). Este projeto oferece um currículo que orienta quem deseja aprender modelos de inteligência artificial, do nível básico ao avançado.

- ★ 84.301
- GitHub Trending · 2026-10-19

## O que você ganha

- Começando pela matemática básica e redes neurais artificiais até a compreensão da arquitetura de modelos de linguagem
- Otimização de modelos de código aberto através de ajuste fino (fine-tuning) e quantização (quantization)
- Execução de testes diretamente através de notebooks de código em nuvem prontos do Google Colab, sem necessidade de instalação

## Como começar

Para usar este projeto, você não precisa instalar nenhum software em seu computador. Você pode examinar os tópicos no repositório do GitHub ou na página de documentação do DeepWiki e clicar no link do Google Colab da seção de seu interesse para executar os trabalhos diretamente pelo seu navegador.
