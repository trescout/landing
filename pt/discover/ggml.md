# Biblioteca de tensores para modelos de inteligência artificial

ggml-org/ggml é uma biblioteca de tensores desenvolvida em C++ para modelos de aprendizado de máquina. O software facilita a execução de modelos de inteligência artificial ao fornecer exemplos simples e claros para operações básicas, como multiplicação de matrizes.

## O que você ganha

- Oferece operações de tensores de alto desempenho em C e C++ sem dependências externas.
- Pode ser executado em unidades de processamento central (CPU), unidades de processamento gráfico (GPU) e ambientes de navegador.
- Reduz o uso de memória com formatos de quantização que diminuem o tamanho dos dados.

## Instalação

**Compilando a partir do código-fonte**

```
git clone https://github.com/ggml-org/ggml
cd ggml

mkdir build && cd build
cmake ..
cmake --build . --config Release -j 8
```
