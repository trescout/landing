# Adicione memória aos modelos de IA

MemPalace oferece um sistema de memória de código aberto para modelos de inteligência artificial. O sistema inclui ferramentas otimizadas para medir e melhorar o desempenho da memória contextual de grandes modelos de linguagem.

- ★ 58.584
- Python
- GitHub Trending · 2026-06-06

## O que você ganha
- Oferece pesquisa semântica, mantendo o histórico da conversa como está.
- Cria uma estrutura de memória organizada categorizando pessoas, projetos e tópicos.
- Com seu princípio de funcionamento local, permite que os dados sejam processados ​​sem sair da sua máquina.

## Instalação
**instalação com uv**

```
uv tool install mempalace
mempalace init ~/projects/myapp
```

**Instalação com ambiente virtual**

```
python -m venv .venv && source .venv/bin/activate
pip install mempalace
```
