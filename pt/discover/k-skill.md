# Dê ao seu agente de IA recursos nativos

NomaDamas/k-skill é uma biblioteca projetada para fornecer aos agentes de IA habilidades locais em um contexto cultural. Oferece conjuntos de habilidades customizados que permitem aos agentes interagir com os usuários de forma mais natural e de acordo com códigos culturais.

## O que você ganha

- Permite que agentes de IA usem serviços locais específicos da Turquia
- Realiza consultas automáticas sobre transporte, dados públicos e trabalho diário
- Integra-se diretamente sem a necessidade de software cliente extra

## Instalação

**Para instalar todos os recursos**

```
npx --yes skills add NomaDamas/k-skill --all -g
```

**Para instalar uma habilidade específica**

```
npx --yes skills add NomaDamas/k-skill --skill srt-booking -g
```
