# Tempo de execução rápido para projetos JavaScript

Bun é uma ferramenta de alto desempenho que combina tempo de execução JavaScript, gerenciador de pacotes, executor de testes e empacotador sob o mesmo teto. Desenvolvida com a linguagem Rust, esta plataforma oferece uma infraestrutura integrada para acelerar os processos de desenvolvimento de software.

## O que você ganha
- Tempo de execução rápido compatível com Node.js
- Gerenciador de pacotes e ferramenta de teste sob o mesmo teto
- Baixo uso de memória e inicialização rápida

## Instalação
**Instalação via script de instalação**

```
curl -fsSL https://bun.com/install | bash
```

**Instalando no Windows**

```
powershell -c "irm bun.sh/install.ps1 | iex"
```


## Execução
**Instalação do pacote**

```
bun install <pkg>
```

**Execução de arquivo**

```
bun run index.tsx
```
