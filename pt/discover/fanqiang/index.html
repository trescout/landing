Ignore a censura na Internet com Kotlin

O projeto Fanqiang é uma ferramenta de gateway escrita em Kotlin, desenvolvida para contornar a censura na Internet. É um software de código aberto projetado para fornecer aos usuários acesso a recursos de rede limitados.

O que você ganha

  • Fornece acesso a guias abrangentes de acesso à rede para diferentes sistemas operacionais e dispositivos.
  • Fornece guias de configuração e uso para vários protocolos e ferramentas de rede.
  • Inclui métodos para contornar restrições de rede em diferentes plataformas, como consoles de jogos e navegadores.
