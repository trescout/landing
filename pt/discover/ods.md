# ODS

Osmantic/ODS é uma plataforma de código aberto que transforma computadores pessoais em um servidor de IA com recursos como inferência de modelo de linguagem grande (inferência LLM), processamento de áudio e renderização visual. O software permite a criação de manufatura assistida por pesquisa (RAG) e fluxos de trabalho de agentes inteligentes executados em hardware local.
