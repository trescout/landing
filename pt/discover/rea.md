# Engenharia reversa com inteligência artificial

O Rea é uma ferramenta de engenharia reversa baseada em agentes de IA que analisa tudo, desde o comportamento de aplicativos até binários nativos. Desenvolvido em TypeScript, este software tem como objetivo decodificar a lógica de funcionamento de sistemas complexos por meio de processos automatizados.

## O que você ganha

- Você pode decodificar a lógica interna de aplicativos de desktop ou web, aos quais você não tem acesso ao código-fonte, com o suporte de inteligência artificial.
- Você pode inspecionar arquivos de sistema binários com segurança em seu computador local, integrando-se aos softwares de engenharia reversa Hopper e Ghidra.
- Você pode aprender passo a passo, com evidências, como funciona um recurso de software de que gosta e adaptá-lo ao seu próprio projeto.

## Instalação

**Iniciando o assistente de instalação**

```
npx rea-agents setup
```

**Instalação global com o gerenciador de pacotes npm**

```
npm install --global rea-agents
rea setup
```

## Execução

**Verificação do sistema e análise de aplicativo de exemplo**

```
npx -y rea-agents@latest doctor
npx -y rea-agents@latest analyze /Applications/Notes.app
```
