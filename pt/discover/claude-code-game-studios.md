# Estúdio de jogos completo impulsionado por IA

Claude-Code-Game-Studios é um projeto que visa transformar a ferramenta de desenvolvimento de software Claude Code em um estúdio de jogos abrangente. Ele oferece um sistema de coordenação que imita a hierarquia de um estúdio real, utilizando 49 agentes de inteligência artificial e 72 habilidades de fluxo de trabalho (workflow skills).

## O que você ganha

- Oferece a oportunidade de gerenciar todos os processos, desde o design de jogos até a fase de testes, com equipes de inteligência artificial.
- Estabelece uma hierarquia de estúdio disciplinada graças a agentes de IA especializados.
- Fornece padrões de codificação prontos e mecanismos de controle para motores de jogos populares.
