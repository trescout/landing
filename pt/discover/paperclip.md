# Centro de gerenciamento para agentes de IA

Paperclip é uma plataforma de código aberto que permite gerenciar agentes de IA no local de trabalho por meio de uma única interface. Desenvolvido em TypeScript, esta ferramenta permite controlar os fluxos de trabalho dos agentes utilizados para diferentes tarefas a partir de um ponto central.

## O que você ganha

- Gerencie vários agentes de IA em uma única interface.
- Controle centralmente o orçamento e as tarefas dos agentes.
- Torne os fluxos de trabalho rastreáveis ​​como um gerenciador de tarefas.

## Instalação

**Instalação rápida**

```
curl -fsSL https://paperclip.ing/install.sh | bash -s -- --no-prompt --no-onboard
paperclipai onboard --yes
```

**Instalação do desenvolvedor**

```
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev
```
