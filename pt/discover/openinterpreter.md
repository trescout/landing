# Inteligência artificial que executa código no seu computador

Open Interpreter oferece um agente de codificação que automatiza processos de desenvolvimento de software executando código no ambiente de computador local. Projetada para trabalhar com modelos de linguagem de baixo custo, esta ferramenta permite executar tarefas complexas diretamente do terminal.

- ★ 67.509
- Rust
- GitHub Trending · 2026-07-16

## O que você ganha
- Automatiza processos de software através do terminal local.
- É compatível com modelos de linguagem de baixo custo.
- Oferece a capacidade de testar aplicativos web e nativos.

## Instalação
**Instalação para macOS e Linux**

```
curl -fsSL https://www.openinterpreter.com/install | sh
```


## Execução
**Iniciar sessão**

```
i
```

Quero que você atue como agente de codificação no meu computador. Utilizar estruturas que otimizem modelos de baixo custo na realização de transações e executar meus comandos com segurança através do terminal.
