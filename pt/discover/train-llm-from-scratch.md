# Treine seu próprio modelo LLM do zero

train-llm-from-scratch oferece um método simples e passo a passo de treinar um grande modelo de linguagem do zero, desde o download do conjunto de dados até a geração de texto. É um recurso prático para o seu processo de aprendizagem.

- ★ 8.864
- Jupyter Notebook
- MIT
- GitHub Trending · 30 May 2026

## O que você aprende?
- Fluxo ponta a ponta cobrindo download de dados, treinamento e produção de texto.
- Método de aplicação baseado no funcionamento interno do LLM.
- Uso prático com notebooks diretamente operáveis.

## Como instalar, como usar?
**Clonar repositório**

```
git clone https://github.com/FareedKhan-dev/train-llm-from-scratch.git
cd train-llm-from-scratch
```

**Instalar dependências**

```
pip install -r requirements.txt
```
