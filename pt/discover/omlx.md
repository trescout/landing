# Servidor AI para computadores Mac

Omlx é um servidor de inferência de modelo de linguagem grande (LLM) que oferece suporte a lote contínuo e cache SSD para processadores Apple Silicon. Esta ferramenta, gerenciada pela barra de menu do macOS, oferece a oportunidade de executar modelos de alto desempenho em hardware local.

## O que você ganha
- Executando modelos de alto desempenho em processadores Apple Silicon
- Gerenciamento eficiente de memória com cache SSD
- Fácil controle do servidor na barra de menu

## Instalação
**Instalação com Homebrew**

```
brew tap jundot/omlx https://github.com/jundot/omlx
brew install jundot/omlx/omlx
```


## Execução
**Iniciando o serviço em segundo plano**

```
omlx start
```
