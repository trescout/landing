# Suporte de inteligência artificial para processos de codificação

Continue é um agente de codificação de código aberto projetado para automatizar processos de desenvolvimento de software. Ele permite que os desenvolvedores escrevam, depurem e refatorem código dentro do IDE usando seus modelos de linguagem nativa (LLM).

- ★ 35.282
- GitHub Trending · 2026-06-18

**Nota da TreScout:** Assistente de inteligência artificial que ajuda você a escrever código. A diferença dos assistentes prontos é que você decide qual modelo usar: você conecta sua própria chave ou um modelo rodando no seu computador, seu código não vazará. Em troca, a instalação e a seleção do modelo passam a ser seu trabalho, a experiência não é tão refinada quanto a dos produtos prontos para uso.

- Acelera os processos de codificação e depuração

- Integra-se com ambientes de desenvolvimento de software, como VS Code e JetBrains

## Instalação

**Instalar CLI com npm (global)**

```
npm i -g @continuedev/cli
```

**Instalar como extensão do VS Code**

```
code --install-extension Continue.continue
```

**Global com npm**

```
npm install -g continue
```

## Execução

**Executar agente Continue via CLI**

```
cn
```
