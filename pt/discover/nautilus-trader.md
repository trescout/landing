# Plataforma de negociação algorítmica de alto desempenho

Nautilus Trader é um mecanismo de negociação com arquitetura determinística orientada a eventos, desenvolvido em linguagem Rust. Oferece soluções de infraestrutura de nível de produção para sistemas financeiros de alto desempenho.

- ★ 26.536
- Rust
- GitHub Trending · 2026-06-18

## O que você ganha
- Infraestrutura de negociação rápida e segura baseada em ferrugem
- Transição da pesquisa para a vida real sem alterações de código
- Suporte a múltiplas exchanges e classes de ativos

## Instalação
**Instalação padrão**

```
pip install -U nautilus_trader
```

**Instalação do repositório de pacotes privados**

```
pip install -U nautilus_trader --index-url=https://packages.nautechsystems.io/simple
```
