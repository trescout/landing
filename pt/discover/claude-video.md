# Análise de vídeo com inteligência artificial

Claude-video é uma ferramenta Python que dá ao modelo Claude a capacidade de analisar conteúdo de vídeo. Ao baixar vídeos, dividi-los em frames e convertê-los em texto (transcrição), o software traz os dados visuais para um formato que o modelo de inteligência artificial pode processar.

- ★ 15.503
- Python
- GitHub Trending · 2026-07-07

## O que você ganha
- Analisa vídeos quadro a quadro
- Produz legendas e transcrições automaticamente
- Processa vídeos locais ou online

## Instalação
**Instalação geral**

```
npx skills add bradautomates/claude-video -g
```


## Execução
**Iniciar análise de vídeo**

```
/watch https://youtu.be/dQw4w9WgXcQ what happens at the 30 second mark?
```


## Se você não programa
Quero que você analise o vídeo que compartilhei usando a ferramenta Claude Video. Responda o conteúdo do vídeo, seus momentos importantes e as perguntas que faço, com base nos enquadramentos visuais do vídeo e na transcrição do áudio. Caso não haja legenda no vídeo, converta o áudio em texto usando Whisper API e analise examinando os detalhes visuais (frames).
