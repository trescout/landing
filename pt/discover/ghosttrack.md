# Rastreamento de localização por meio de números de celular e nomes de usuário

GhostTrack baseado em Python é uma ferramenta que permite rastreamento de localização por meio de números de celular. Este software de código aberto foi desenvolvido para detectar os dados geográficos do número alvo.

- ★ 13.874
- GitHub Trending · 2026-06-08

## O que você ganha
- Detecta dados de geolocalização de números de celular
- Coleta informações por meio de nomes de usuário de mídia social
- Funciona integrado com ferramentas auxiliares para rastreamento de endereços IP

## Instalação
**Clonar + dependências (Linux · Python 3)**

```
git clone https://github.com/HunxByts/GhostTrack.git && cd GhostTrack && pip3 install -r requirements.txt
```


## Execução
**correr**

```
python3 GhostTR.py
```
