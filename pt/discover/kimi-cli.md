# Desenvolvimento assistido por IA no terminal

Desenvolvido pela Moonshot AI, Kimi CLI é um agente de inteligência artificial que funciona através de uma interface de linha de comando (CLI). Esta ferramenta baseada em Python foi projetada para automatizar interações de linha de comando em processos de desenvolvimento de software.

- ★ 11.306
- Python
- GitHub Trending · 2026-07-19

## O que você ganha
- Capacidade de ler e editar código
- Executando comandos via terminal
- Pesquisa na web e planejamento autônomo

## Instalação
**Configuração do ambiente de desenvolvimento**

```
git clone https://github.com/MoonshotAI/kimi-cli.git
cd kimi-cli

make prepare  # prepare the development environment
```


## Se você não programa
Quero que você trabalhe como agente de desenvolvimento dentro do terminal. Ao executar minhas tarefas de desenvolvimento de software, leio e edito meus arquivos de código, executo os comandos shell necessários e planejo processos de forma autônoma, pesquisando na Internet quando preciso deles.
