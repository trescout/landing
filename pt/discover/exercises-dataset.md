# Conjunto de dados de exercícios físicos multilíngue

O conjunto de dados de exercícios (conjunto de dados de exercícios) compartilhado por Hasaneyldrm oferece 433 movimentos de condicionamento físico diferentes com nomes, grupos musculares alvo, equipamentos e instruções visuais. Este recurso abrangente fornece uma infraestrutura de dados estruturada para quem desenvolve aplicações de tecnologia esportiva.

## O que você ganha
- Dados estruturados para 1.324 exercícios físicos diferentes
- Instruções de aplicação passo a passo em 6 idiomas, incluindo turco
- Guia pronto para integração de banco de dados e API

## Como começar
Esta ferramenta não requer nenhuma instalação. Após baixar os arquivos da página do GitHub para o seu computador, você pode revisar os exercícios abrindo o arquivo 'index.html' com qualquer navegador de internet, e acessar o banco de dados e o guia de instalação da API abrindo o arquivo 'setup.html'.
