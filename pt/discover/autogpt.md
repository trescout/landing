# Crie agentes de IA autônomos

AutoGPT é um projeto Python de código aberto que permite a criação de agentes autônomos de IA que podem planejar e executar tarefas complexas por conta própria. Facilita o acesso à inteligência artificial ao automatizar processos como busca na internet e gerenciamento de arquivos para atingir os objetivos traçados pelos usuários.

- ★ 186.620
- Python
- GitHub Trending · 2026-08-07

## O que você ganha
- Ele economiza tempo semanal ao automatizar fluxos de trabalho complexos.
- Ele transforma comandos dados em linguagem natural em um agente funcional de inteligência artificial.
- Oferece a oportunidade de personalizar e gerenciar as etapas do agente por meio da interface visual.

## Instalação
**Instalação para macOS e Linux**

```
curl -fsSL https://setup.agpt.co/install.sh -o install.sh && bash install.sh
```


## Se você não programa
Crie um agente autônomo usando recursos de pesquisa na Internet, gerenciamento de arquivos e planejamento de fluxo de trabalho para atingir o objetivo que estabeleci. Espere que eu defina claramente o resultado do trabalho e execute automaticamente todas as etapas necessárias do processo.
