Testes unitários e mocks em C++ no padrão da indústria

GoogleTest e GoogleMock oferecem testes unitários de padrão industrial, objetos simulados (mocks) e testes parametrizados para C++ moderno.

  • ★ 38.987
  • C++
  • GitHub Trending · 2026-08-27

Atualizações

  • 27 de agosto de 2026: 38.987 estrelas, versão v1.15.2 com suporte a conceitos de C++20 e validação avançada de mocks.

O que você ganha

  • Macros de asserção abrangentes: Diagnósticos claros com macros ASSERT_* (fatal, interrompe o teste) e EXPECT_* (não fatal, continua a execução).
  • Conjunto avançado de mocks (GoogleMock): Isole dependências usando MOCK_METHOD para simular interfaces e definir expectativas de chamadas.
  • Testes parametrizados por valores: Execute a mesma lógica de teste em dezenas de conjuntos de dados usando padrões de teste parametrizados.
  • Segurança de threads multiplataforma: Execução thread-safe em Linux, macOS e Windows com testes de falha fatal (death tests).
  • Integração CI/CD e relatórios: Integração nativa com GitHub Actions e GitLab CI através de relatórios XML e JSON compatíveis com JUnit.

Instalação

Integração via CMake FetchContent
include(FetchContent)
FetchContent_Declare(
  googletest
  URL https://github.com/google/googletest/archive/refs/tags/v1.15.2.tar.gz
)
FetchContent_MakeAvailable(googletest)

Execução

Compilar e executar testes via CTest
cmake -B build -S .
cmake --build build
ctest --test-dir build --output-on-failure

Arquitetura técnica e princípio de funcionamento

O GoogleTest é construído sobre uma arquitetura C++ modular otimizada para compiladores modernos:

  • Gerenciamento de fixtures e ciclo de vida: Os métodos SetUp e TearDown garantem alocação e liberação previsíveis de recursos em cada teste.
  • Isolamento de processos para death tests: Cria processos filhos isolados para verificar com segurança travamentos e encerramentos anormais.
  • Modelos de testes parametrizados por tipo: Valida classes genéricas com templates C++ em múltiplos tipos de dados sem duplicar código.

Cenários de teste e integração com GoogleMock

Isolar dependências usando objetos simulados (mocks) em C++ moderno oferece vantagens práticas imediatas:

  • Abstração de chamadas de rede e banco de dados: Simule respostas de API e latências sem sockets reais utilizando MOCK_METHOD.
  • Validação de contagem de chamadas e argumentos: Verifique quantas vezes, com quais parâmetros e em que ordem os métodos foram executados com EXPECT_CALL.
  • Testes de resiliência com exceções: Garanta o tratamento correto de erros em trechos de código que lançam exceções usando EXPECT_THROW.

Perguntas frequentes

  • Qual é a forma moderna de incluir o GoogleTest em um projeto? Em projetos CMake modernos, o módulo FetchContent é o método recomendado, baixando e compilando o GoogleTest sem gerenciadores externos.
  • Qual é a diferença entre EXPECT_* e ASSERT_*? As macros EXPECT_* registram falhas e permitem a continuidade do teste. As macros ASSERT_* interrompem imediatamente a execução da função de teste atual.
  • O GoogleMock é uma biblioteca separada? O GoogleMock era originalmente separado, mas foi incorporado ao repositório unificado do GoogleTest há muito tempo; ambos funcionam juntos.
  • O GoogleTest é seguro para threads? Sim. Em plataformas com suporte a pthreads e no Windows, o GoogleTest é thread-safe e sincroniza asserções de threads concorrentes.
