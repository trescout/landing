# Ambiente de trabalho de IA para pesquisas científicas

O Open Science, desenvolvido pela AIPOCH, oferece um ambiente de trabalho de IA local-first e independente de modelo para pesquisas científicas. O software combina notebooks Python e R com conexões de dados, permitindo que os processos científicos sejam conduzidos de forma reprodutível.

## O que você ganha

- Realize análises científicas reprodutíveis executando códigos Python e R
- Crie relatórios, tabelas e gráficos automáticos conectando-se a fontes de dados científicos
- Gerencie todo o processo, desde a revisão de literatura até a simulação, com agentes de IA locais

## Instalação

**Instalação local a partir do código-fonte**

```
git clone https://github.com/aipoch/open-science.git
cd open-science
npm install
npm run dev
```

**Modo de desenvolvimento de interface web**

```
npm run build:web
npm run dev:web
```
