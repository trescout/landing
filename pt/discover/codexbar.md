# Monitore os limites de uso de IA

CodexBar é uma ferramenta que permite visualizar dados de uso do OpenAI Codex e Claude Code sem a necessidade de login. Desenvolvido em linguagem Swift, este aplicativo facilita aos desenvolvedores o rastreamento de estatísticas de consumo em ferramentas de codificação suportadas por IA.

## O que você ganha

- Veja instantaneamente os limites de uso de todos os serviços de inteligência artificial na barra de menu
- Acompanhe os tempos de reinicialização do serviço com uma contagem regressiva
- Não armazena senhas porque usa sessões existentes, é orientado para a privacidade
