Workshop prático para agentes de inteligência artificial

Esses workshops compartilhados pela Anthropic mostram aos desenvolvedores na prática os processos de criação de agentes de inteligência artificial capazes de uso computacional. Os exemplos baseados em TypeScript incluem estruturas técnicas que permitem que os modelos gerenciem tarefas complexas interagindo com interfaces na tela.

  • ★ 1.632
  • TypeScript
  • GitHub Trending · 2026-07-18

O que você ganha

  • Construindo sistemas multiagentes com capacidades e MCP
  • Dando aos agentes memória permanente e habilidades de aprendizagem
  • Processos de desenvolvimento de agentes orientados por avaliação

Como começar

Esta ferramenta inclui material dos workshops Code with Claude organizados pela Anthropic. Para começar, visite o repositório oficial cwc-workshops no GitHub e navegue até a pasta de seu interesse e siga as instruções lá.
