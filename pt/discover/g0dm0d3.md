# Interface de interação de IA irrestrita

G0DM0D3 é uma interface de chat de IA liberada que visa contornar as camadas de segurança de grandes modelos de linguagem. Desenvolvido em TypeScript, este projeto de código aberto permite aos usuários interagir com modelos sem restrições.

## O que você ganha

- Suporte para execução de modelos em hardware local

## Instalação

**Clone o repositório e inicie-o no servidor local**

```
# Clone the repository
git clone https://github.com/elder-plinius/G0DM0D3.git
cd G0DM0D3

# Open directly in your browser
open index.html
# or serve locally
python3 -m http.server 8000
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Usando a interface G0DM0D3, ative o mecanismo ULTRAPLINIAN, que executa vários modelos por meio dos provedores de modelos que eu especifico (OpenRouter, Venice ou servidor local). Aplique técnicas de mixagem de entrada de língua de cobra para minhas investigações da equipe vermelha e configure automaticamente os parâmetros de amostragem mais adequados ao contexto de consulta com o recurso AutoTune.
