# Torne a interface do GIMP semelhante ao Photoshop

PhotoGIMP oferece um patch que faz com que a interface do GIMP pareça familiar para os usuários do Photoshop. Esta ferramenta adapta atalhos e layouts de menu aos padrões do Photoshop para facilitar a transição para um software de edição de imagens.

- ★ 17.197
- CSS
- GitHub Trending · 2026-07-09

## O que você ganha
- Mesmas teclas de atalho do Photoshop
- Layout do veículo com o qual você está acostumado
- Layout de espaço de trabalho estendido

## Instalação
**backup para linux**

```
cp -r ~/.config/GIMP/3.0 ~/GIMP-3.0-backup
```

**Instalação com Chocolatey**

```
choco install photogimp
```
