# Metodologia Avançada para Agentes de Codificação

Superpowers é uma metodologia abrangente de desenvolvimento de software de habilidades compostas para seus agentes de codificação. Padroniza fluxos de trabalho baseados em agentes. Funciona com Claude Code, Codex CLI, Gemini CLI e muito mais.

## O que você ganha
- Um conjunto de habilidades composto e pronto para o seu agente.
- Uma metodologia de desenvolvimento estruturada.
- Padronize os fluxos de trabalho dos agentes.
- Compatibilidade total com múltiplas plataformas.

## Instalação
**Instalar plugin Claude Code**

```
/plugin install superpowers@claude-plugins-official
```


## Como começar
Dê superpoderes ao seu agente com TreScout; As etapas de início rápido para Claude Code, Codex e Gemini estão esperando por você no repositório.

## Como instalar, como usar?
Instale o plugin Superpowers executando o comando '/plugin install superpowers@claude-plugins-official' no Claude Code; A partir de agora, quando quero melhorar alguma coisa, as habilidades entram em ação automaticamente.
