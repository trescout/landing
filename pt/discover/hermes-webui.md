# Gerencie seus agentes de IA pela web

Hermes WebUI é uma interface que permite gerenciar agentes Hermes AI via navegador da web ou dispositivos móveis. Ele permite rastrear e controlar as interações dos agentes a partir de um único centro.

- ★ 17.366
- Python
- MIT
- GitHub Trending · 1 Haziran 2026

## O que você ganha
- Gerencie seus agentes via navegador ou celular.
- Monitore todas as interações a partir de um ponto central.
- Aproveite a interface simples e amigável.

## Como instalar, como usar?
**Clone e execute o bootstrap**

```
git clone https://github.com/nesquena/hermes-webui.git hermes-webui
cd hermes-webui
python3 bootstrap.py
```

**Execute com script de inicialização**

```
./start.sh
```
