# Documentos de design prontos para inteligência artificial

Awesome-design-md é uma coleção de documentos de design (DESIGN.md) de sistemas de design de marcas populares. Usando esses documentos, os agentes de software podem criar interfaces de usuário (UIs) adequadas para projetos.

## O que você ganha
- Traga as linguagens de design de marcas populares para seus projetos
- Mantenha a consistência visual com agentes de IA
- Integre sistemas de design ao seu projeto sem escrever código

## Como começar
- Fonte oficial →
Selecione um arquivo DESIGN.md adequado ao seu projeto na coleção do repositório awesome-design-md. Copie o conteúdo do arquivo relevante e salve-o como um arquivo de texto no diretório principal do seu projeto. Em seguida, basta referenciar este arquivo à ferramenta de codificação de inteligência artificial que você está usando e dar o comando ‘Crie-me uma página parecida com esta’.
