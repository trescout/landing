# Lista de recursos de ferramentas gratuitas para desenvolvedores

Free-for-dev é uma lista de recursos que reúne os níveis gratuitos de soluções de software como serviço (SaaS), plataforma como serviço (PaaS) e infraestrutura como serviço (IaaS) usadas em processos de desenvolvimento de software. O objetivo é facilitar o acesso de desenvolvedores e engenheiros de infraestrutura a ferramentas gratuitas.

## Como começar
- Fonte oficial →
Esta ferramenta não é um software, mas sim um recurso que lista serviços gratuitos. Ao visitar a página oficial gratuita para desenvolvedores no GitHub, você pode escolher o serviço que precisa na lista categorizada e registrar-se diretamente no nível gratuito dessa plataforma clicando no link relevante.
