# Aplicativos multiplataforma com Rust

Dioxus é um framework Rust que permite desenvolver aplicações ponta a ponta (fullstack) com uma única base de código para plataformas web, desktop e mobile. Ele padroniza a experiência de desenvolvimento de aplicativos no ecossistema Rust, acelerando o processo de criação da interface do usuário com sua estrutura baseada em componentes semelhante ao React.

## O que você ganha
- Desenvolvimento de aplicativos Web, desktop e móveis com uma única base de código
- Processo de desenvolvimento rápido com atualização instantânea de código
- Estrutura de componentes semelhante a React e suporte fullstack com segurança de tipo

## Instalação
**Instale a ferramenta CLI**

```
curl -fsSL https://dioxuslabs.com/install.sh | bash
```

**Método de instalação alternativo**

```
cargo install --git https://github.com/DioxusLabs/dioxus dioxus-cli --locked
```


## Execução
**Iniciando o aplicativo**

```
dx serve
```

**Empacotando o aplicativo**

```
dx bundle
```


## Se você não programa
Como posso desenvolver uma aplicação para plataformas web, desktop ou mobile em Rust usando Dioxus? Explique passo a passo o processo de criação de uma interface de usuário simples usando estrutura baseada em componentes, gerenciamento de estado e recurso de atualização instantânea de código com o comando 'dx serve'.
