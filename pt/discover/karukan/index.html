Sistema de login japonês com suporte de inteligência artificial

Desenvolvido com a linguagem Rust, Karukan é um sistema de método de entrada japonês (Japanese Input Method System) que usa um mecanismo de conversão neural kana-kanji para sistemas operacionais Linux e macOS. O software vai além dos métodos tradicionais e oferece uma abordagem baseada em inteligência artificial para processos de conversão de texto.

O que você ganha

  • Conversão neural kana-kanji baseada em GPT-2
  • Conversão de texto ao vivo em tempo real enquanto você digita
  • mecanismo de previsão inteligente que aprende as escolhas do usuário

Como começar

Para usá-lo com fcitx5 no Linux, você deve seguir as etapas de instalação nos arquivos README na pasta karukan-fcitx5 e para macOS na pasta karukan-macos. Como os arquivos do modelo serão baixados automaticamente do Hugging Face na primeira utilização, o processo de conversão inicial pode levar algum tempo.
