# Ferramenta de automação de navegador para agentes de IA

Desenvolvido pela Vercel Labs, o agent-browser é uma interface de linha de comando (CLI) que fornece automação de navegador para agentes de inteligência artificial. Escrito em Rust, esta ferramenta permite ler páginas como uma árvore de acessibilidade (accessibility tree) e interagir com elementos da web através da linha de comando.

## O que você ganha

- Lê as páginas em formato de texto como uma árvore de acessibilidade
- Interage com elementos da web através da linha de comando
- Gerencia o navegador comando por comando com o servidor em segundo plano

## Instalação

**Configuração geral**

```
npm install -g agent-browser
agent-browser install           # download Chrome for Testing (first time only)
```

## Execução

**Início Rápido**

```
agent-browser open example.com
```
