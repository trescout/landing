# Ferramenta multiprotocolo para análise de hardware

ESP32-Bit-Pirate é uma ferramenta de hacking de hardware que suporta vários protocolos de comunicação por meio de uma interface de linha de comando (CLI) baseada na web. Este sistema, desenvolvido em linguagem C++, facilita os processos de análise de hardware gerenciando diferentes protocolos em uma única plataforma.

## O que você ganha

- Gerenciar protocolos como I2C, SPI, UART e 1-Wire
- Interação com radiofrequências, Bluetooth e Wi-Fi
- Depuração de hardware via interface baseada na web

## Como começar

Instale o software apropriado para o seu dispositivo através do navegador usando a ferramenta Web Flasher no site oficial. Em seguida, acesse a interface de linha de comando conectando-se ao seu dispositivo com um aplicativo de terminal serial ou terminal Web Serial baseado em navegador.
