# Copiar repositórios em fluxos de trabalho do GitHub

Desenvolvido pelo GitHub, actions/checkout é uma ferramenta que automatiza processos de checkout de repositórios em processos de desenvolvimento de software. A integração contínua permite que o código-fonte seja transferido para o ambiente de trabalho em fluxos de trabalho.
