# Copiar repositórios em fluxos de trabalho do GitHub

Desenvolvido pelo GitHub, actions/checkout é uma ferramenta que automatiza processos de checkout de repositórios em processos de desenvolvimento de software. A integração contínua permite que o código-fonte seja transferido para o ambiente de trabalho em fluxos de trabalho.

## O que você ganha
- Transferindo o código-fonte para o ambiente de trabalho
- Operações automáticas de cópia de armazém
- Gerenciamento seguro de credenciais

## Como começar
- Fonte oficial →
Você pode ativar a ferramenta para baixar seu repositório para o espaço de trabalho adicionando a linha -uses: actions/checkout@v7 à seção de etapas do seu arquivo de fluxo de trabalho do GitHub Actions. Você pode personalizar o comportamento da cópia definindo parâmetros como profundidade de busca ou submódulos no bloco with de acordo com sua necessidade.
