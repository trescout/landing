# Compartilhe arquivos e mensagens na rede local

Compartilhe arquivos e mensagens entre dispositivos próximos em uma rede local. O LocalSend funciona sem conexão com a internet ou servidor de terceiros e usa criptografia HTTPS.

- ★ 88.882
- GitHub Trending · 2026-08-13

## O que esta ferramenta faz?
LocalSend é um aplicativo gratuito e de código aberto para compartilhar arquivos e mensagens entre dispositivos Windows, macOS, Linux, Android e iOS na mesma rede local. Ele usa uma API REST e criptografia HTTPS, sem exigir conta ou login.

## Para quem é?
Pessoas que querem compartilhar arquivos ou mensagens entre dispositivos na mesma rede local, inclusive com sistemas operacionais diferentes.

## O que não esperar
Pessoas que precisam transferir arquivos entre redes diferentes pela internet ou esperam atualizações automáticas no aplicativo.

## Destaques
- Funciona sem conexão com a internet ou servidor de terceiros.
- Oferece suporte a Windows, macOS, Linux, Android e iOS.
- Não exige criação de conta ou login.
- Usa uma API REST e criptografia HTTPS para a comunicação local.

## Primeiro fluxo de uso
- Instale a versão adequada ao seu dispositivo pelo site oficial, por uma loja de aplicativos ou por um gerenciador de pacotes.
- Conecte os dispositivos que você quer usar à mesma rede local.
- Se houver falha de conexão, verifique no firewall o tráfego de entrada TCP e UDP na porta 53317.
- Escolha um arquivo ou uma mensagem no aplicativo e inicie a transferência.
