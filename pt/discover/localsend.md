# Compartilhamento seguro de arquivos entre dispositivos

LocalSend é um aplicativo de código aberto que permite o compartilhamento de arquivos entre diferentes sistemas operacionais. Ele cria uma alternativa independente de plataforma ao recurso AirDrop oferecido pelos dispositivos Apple.

- ★ 88.882
- Dart

## O que você ganha
- Transferência rápida de arquivos sem necessidade de conexão com a Internet
- Comunicação perfeita entre diferentes sistemas operacionais
- Transferência segura de dados com criptografia HTTPS
