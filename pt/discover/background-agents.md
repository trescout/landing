# Agentes de inteligência artificial que desenvolvem software autônomo

Desenvolvido por ColeMurray, background-agents é um sistema de codificação de agentes em segundo plano de código aberto baseado em TypeScript. Ele permite que os desenvolvedores criem agentes de inteligência artificial (agentes de IA) que executam processos autônomos dentro dos aplicativos.

- ★ 2.329
- TypeScript
- GitHub Trending · 2026-07-13

## O que você ganha
- Executando tarefas autônomas em segundo plano
- Acesso a ambientes de desenvolvimento completos
- Trabalho integrado via Slack e GitHub

## Instalação
**Instalando dependências**

```
# .openinspect/setup.sh (provisioning)
#!/bin/bash
npm install
pip install -r requirements.txt
```


## Execução
**Iniciando o ambiente de trabalho**

```
# .openinspect/start.sh (runtime startup)
#!/bin/bash
docker compose up -d postgres redis
```


## Se você não programa
Você é um demônio. Quero que você execute as tarefas que defini de forma autônoma usando Node.js, Python e ferramentas git. Enquanto trabalho, crie commits apropriados ao projeto que estou desenvolvendo, inicie subtarefas paralelas quando necessário e torne suas ações rastreáveis ​​no GitHub.
