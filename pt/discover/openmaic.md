# OpenMAIC

OpenMAIC é uma plataforma de aprendizagem imersiva que simula múltiplas interações de agentes de IA com um único clique. Esta ferramenta de código aberto, desenvolvida com TypeScript, permite aos usuários experimentar um ambiente de sala de aula interativo com diferentes modelos de agentes.
