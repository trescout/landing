Mecanismo de inteligência artificial baseado em dados

RAGFlow é um mecanismo de geração baseada em busca (RAG) de código aberto que cria uma camada de contexto para grandes modelos de linguagem (LLM). O objetivo é melhorar o processamento de dados e a precisão das respostas, combinando técnicas avançadas de RAG com capacidades de agente.

O que você ganha

  • Extrai informações de documentos complexos com alta precisão.
  • Ele segmenta dados de forma inteligente usando métodos baseados em modelos.
  • Reduz a alucinação graças às respostas apoiadas por aspas.

Instalação

Baixe o repositório para o seu computador
git clone https://github.com/infiniflow/ragflow.git
Inicie o serviço com Docker
docker compose -f docker/docker-compose.yml up -d
