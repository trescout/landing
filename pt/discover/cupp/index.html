Crie uma lista de senhas direcionadas

Common User Passwords Profiler é uma ferramenta Python para criar listas de senhas direcionadas. Ele prepara arquivos de dicionário personalizados (listas de palavras) analisando determinados dados do usuário.

  • ★ 6.161
  • Python
  • GitHub Trending · 2026-07-01

O que você ganha

  • Prepara dicionários personalizados analisando os dados do usuário.
  • Oferece a oportunidade de criar um perfil orientado ao alvo com perguntas interativas.
  • Analisa as correspondências de nome de usuário e senha padrão com o banco de dados Alecto.

Instalação

Clonar repositório
git clone --depth 1 https://github.com/Mebus/cupp.git && cd cupp

Execução

Execute em modo interativo
python3 cupp.py -i
