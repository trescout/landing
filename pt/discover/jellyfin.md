# Construa seu próprio servidor de mídia

Jellyfin é um servidor de mídia gratuito que permite gerenciar e transmitir seus próprios filmes, séries de TV e coleção de músicas para todos os seus dispositivos. Uma alternativa ao Plex e Emby, esta plataforma não possui bloqueios premium, anúncios ou taxas ocultas.

## Instalação

**Com Docker**

```
docker run -d --name jellyfin -p 8096:8096 jellyfin/jellyfin
```

## Execução

**Acessar pelo navegador**

```
http://localhost:8096
```

## Como instalar?

Docker é instalado em um servidor ou NAS. O guia de instalação está em jellyfin.org; Depois de instalá-lo, você apresenta suas pastas de mídia.
