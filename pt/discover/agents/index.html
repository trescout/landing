Agentes de IA de voz em tempo real

LiveKit Agents é uma estrutura Python usada para desenvolver agentes de inteligência artificial de áudio e vídeo em tempo real. Ele permite que os desenvolvedores criem interações de voz de baixa latência, facilitando a criação de sistemas de IA que respondem como os humanos.

O que você ganha

  • Cria interações vocais que produzem respostas semelhantes às humanas.
  • O servidor de mídia WebRTC é totalmente compatível com LiveKit.
  • Suporta chamadas telefônicas e troca de dados multimodo.

Instalação

Instalando a biblioteca base
pip install "livekit-agents[openai,deepgram,cartesia]"
Adicione habilidades para assistente de IA
npx skills add livekit/agent-skills --skill livekit-agents
