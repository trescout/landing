# Inteligência artificial para testes de penetração autônomos

Desenvolvido com a linguagem Go, o Pentagi oferece um sistema de agentes de inteligência artificial (agentes de IA) totalmente autônomos que podem realizar testes de penetração complexos. O sistema visa padronizar fluxos de trabalho autônomos para detectar e explorar vulnerabilidades.

- ★ 21.475
- Go
- GitHub Trending · 2026-07-10

## O que você ganha
- Testes de segurança totalmente autônomos em ambiente Sandboxed Docker
- Suporte para mais de 20 ferramentas profissionais como Nmap e SQLmap
- Monitoramento detalhado do sistema com Grafana e Prometheus

## Execução
**Inicie o serviço**

```
curl -O https://raw.githubusercontent.com/vxcontrol/pentagi/master/docker-compose.yml
docker compose up -d
```
