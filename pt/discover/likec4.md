# Visualize sua arquitetura de software com diagramas em tempo real

Likec4 é uma ferramenta que visualiza a arquitetura de software diretamente do código-fonte e permite a criação de diagramas ao vivo. Visa a continuidade da documentação técnica através de diagramas de arquitetura que são atualizados simultaneamente com a base de código.

## O que você ganha
- Ele cria esquemas arquitetônicos que são atualizados simultaneamente com sua base de código.
- Oferece uma linguagem de modelagem flexível e personalizável baseada no modelo C4.
- Garante a continuidade da documentação gerenciando processos de visualização por meio de código.

## Execução
**Iniciando o projeto no modo de visualização**

```
npx likec4 start
```
