# Procure vestígios de ataques cibernéticos em dispositivos móveis

Mobile Verification Toolkit é uma ferramenta de computação forense utilizada para detectar violações de segurança em dispositivos móveis. Desenvolvida em Python, este software analisa os dados do dispositivo para revelar possíveis vestígios de ataques cibernéticos.

- ★ 14.955
- GitHub Trending · 2026-09-22

## O que você ganha
- Coleta vestígios forenses em dispositivos Android e iOS
- Verifica vestígios de campanhas conhecidas de spyware
- Realiza análises de segurança com ferramentas de linha de comando

## Instalação
**instalar com pip**

```
pip3 install mvt
```

**instalar com uv**

```
uv tool install mvt
```


## Execução
**Criar script de preenchimento**

```
mvt completion bash
```


## Se você não programa
Oriente-me nas etapas de instalação e execução de comandos no Mobile Verification Toolkit, uma ferramenta de forense digital móvel. Vamos instalar a ferramenta usando o comando uv tool install mvt e, em seguida, gerar o script de preenchimento de shell executando o comando mvt completion bash.
