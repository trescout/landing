# Contratos inteligentes trabalhando com dados da Internet

GenLayer é uma camada de execução descentralizada que permite que contratos inteligentes interajam diretamente com dados na Internet. Este modelo (boilerplate) permite que os desenvolvedores usem TypeScript para criar aplicativos que rodam em blockchain e podem processar dados externos.

- ★ 15.748
- TypeScript
- GitHub Trending · 2026-08-18

## O que você ganha
- Desenvolva contratos inteligentes que acessem diretamente dados da Internet
- Integre processos de previsão e verificação baseados em IA
- Acelere o desenvolvimento com ferramentas de teste rápido

## Instalação
**Preparando o ambiente Python**

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Iniciando a interface**

```
cd frontend
npm install
npm run dev
```


## Se você não programa
Desenvolva um contrato inteligente GenLayer para mim. Este contrato deverá ser capaz de extrair dados atualizados da Internet e tomar decisões lógicas, processando esses dados com modelos de inteligência artificial. Certifique-se de que o código esteja em conformidade com as regras do linter para estar livre de erros e crie casos de teste que sejam executados diretamente na memória para obter feedback rápido durante o processo de desenvolvimento.
