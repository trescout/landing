# Agente de IA para aplicativos de mensagens

AstrBot é uma estrutura de desenvolvimento de agentes de inteligência artificial que se integra a diversas plataformas de mensagens instantâneas, grandes modelos de linguagem e plug-ins. Esta ferramenta baseada em Python permite a criação de assistentes de IA personalizáveis ​​como uma alternativa de código aberto.

## O que você ganha
- Integração com plataformas de mensagens populares
- Estrutura extensível com milhares de plugins
- Área de trabalho segura e isolada do agente

## Instalação
**instalação com uv**

```
uv tool install astrbot --python 3.12
```


## Execução
**Primeira instalação e operação**

```
astrbot init # Only execute this command for the first time to initialize the environment
astrbot run
```


## Se você não programa
Quero criar um assistente de inteligência artificial personalizável em minhas plataformas de mensagens usando AstrBot. Ajude-me a criar um agente de IA configurado de acordo com minhas necessidades e integrado aos meus fluxos de trabalho pessoais e profissionais, usando o suporte de plug-in da plataforma, recursos multimodais e recursos de espaço de trabalho do agente.
