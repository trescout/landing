# Kit de desenvolvimento para agentes de inteligência artificial

O Harness SDK é um kit de desenvolvimento de código aberto que fornece controle e gerenciamento de ponta a ponta para agentes de inteligência artificial. Compatível com as linguagens Python e TypeScript, essa ferramenta permite a padronização de agentes de nível de produção que operam em diferentes modelos e infraestruturas de nuvem.

## O que você ganha
- Funciona em total compatibilidade com as linguagens Python e TypeScript
- Suporta diferentes modelos de inteligência artificial e infraestruturas de nuvem
- Oferece memória, gerenciamento de sessões e integração de ferramentas

## Instalação
**Instalação com Python**

```
pip install strands-harness
```

**Instalação com TypeScript**

```
npm install @strands-agents/harness
```
