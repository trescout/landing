Desenvolva aplicativos corporativos sem escrever código

ToolJet é uma plataforma de criação de aplicativos de código aberto para o desenvolvimento de ferramentas internas, painéis e agentes de inteligência artificial. Essa infraestrutura baseada em JavaScript permite que as empresas digitalizem fluxos de trabalho complexos, reduzindo a necessidade de escrever código.

O que você ganha

  • Design de interface visual rápido com método de arrastar e soltar
  • Fácil integração com banco de dados, API e serviços em nuvem
  • Fluxos de trabalho flexíveis com suporte a JavaScript e Python

Instalação

Instalação local com Docker
docker run \
  --name tooljet \
  --restart unless-stopped \
  -p 80:80 \
  --platform linux/amd64 \
  -v tooljet_data:/var/lib/postgresql/13/main \
  tooljet/try:ee-lts-latest
