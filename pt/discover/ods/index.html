Transforme seu computador em um servidor local de inferência de IA

O Osmantic/ODS capacita computadores pessoais com inferência local de LLMs, pipelines de RAG com busca vetorial e orquestração de agentes sem nuvem.

  • Python

Atualizações

  • 31 de agosto de 2026: 5.181 estrelas, trazendo pipelines locais de RAG e suporte a modelos multimodais.

O que você ganha

  • Privacidade total e execução local: Execute modelos de IA no seu próprio hardware sem envio de dados para provedores em nuvem.
  • RAG integrado de busca vetorial: Indexe documentos pessoais e bases de código para consultas semânticas instantâneas.
  • Conjunto de recursos multimodais: Integra geração de texto, transcrição de áudio com Whisper, síntese de voz e imagens.
  • API local compatível com OpenAI: Conecte seus aplicativos existentes alterando apenas a URL base para o servidor ODS local.
  • Orquestração de agentes autônomos: Crie fluxos de trabalho com agentes inteligentes capazes de executar comandos locais.

Instalação

Clonar o repositório e instalar pacote
git clone https://github.com/Osmantic/ODS.git
cd ODS
pip install -e .

Execução

Iniciar o servidor local de IA
python -m ods.server --port 8000
# Web paneline http://localhost:8000 adresinden erişin

Arquitetura técnica e princípio de funcionamento

O Osmantic/ODS opera uma arquitetura modular que coordena a inferência local e indexação vetorial:

  • Motor de inferência local (llama.cpp & vLLM): Carrega formatos quantizados GGUF com uso eficiente de memória VRAM e CPU.
  • Banco de dados vetorial embutido: Armazenamento vetorial leve com ChromaDB e SQLite para busca semântica em arquivos.
  • Fila de tarefas assíncrona e máquina de estados: Coordena loops de raciocínio de múltiplas etapas e chamada de ferramentas locais.

Fluxos de trabalho RAG locais e pipelines de agentes privados

O ODS permite implantar soluções avançadas de IA garantindo soberania total dos dados corporativos:

  • Inteligência sobre documentos confidenciais: Consulte contratos e relatórios financeiros com segurança via RAG local sem risco de vazamento.
  • Assistente de programação privado: Indexe repositórios proprietários para obter autocompletar de código no VS Code ou Cursor.
  • Processamento autônomo em segundo plano: Agende tarefas automáticas para ler, resumir e converter dados locais do sistema de arquivos.

Perguntas frequentes

  • Funciona completamente offline em ambientes isolados? Sim. Após o download dos modelos, o ODS roda perfeitamente sem conexão com a internet.
  • Quais formatos de modelo são suportados? Suporta modelos quantizados em GGUF (Llama 3, Mistral, Qwen, DeepSeek) e pesos nativos do HuggingFace.
  • O ODS possui interface gráfica web? Sim. Inclui um painel web intuitivo para gerenciar modelos, carregar documentos e conversar com agentes locais.
  • Ele roda apenas com CPU sem placa de vídeo? Sim. O motor llama.cpp utiliza instruções vetoriais AVX2/AVX-512 para processamento eficiente apenas em CPU.
