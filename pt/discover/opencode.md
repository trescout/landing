# Agente de codificação de inteligência artificial de código aberto

OpenCode é um agente de codificação de código aberto projetado para automatizar processos de desenvolvimento de software. Desenvolvida em linguagem TypeScript, esta ferramenta oferece capacidade de execução autônoma de tarefas em projetos de software.

- Gerencia processos de desenvolvimento de software de forma autônoma

- Fornece capacidade de pesquisa global para tarefas de várias etapas

## Instalação

**Global com npm**

```
npm install -g opencode
```

## Se você não programa

Cole isto no seu agente (Claude Code · Codex · Antigravity)

Gostaria que você analisasse os códigos do meu projeto de software atual usando a ferramenta OpenCode e ajudasse a automatizar os processos de desenvolvimento. Você pode desenvolver com acesso total durante o tempo de execução usando o agente de construção ou pode revisar os códigos e planejar alterações usando o agente de planejamento. Para pesquisas complexas ou tarefas de várias etapas, espero que você use @general.

Repositório: https://github.com/anomalyco/opencode. Baseie-se nas instruções oficiais no arquivo README deste repositório para a instalação e execução.

Antes de começar, verifique em qual sistema operacional estamos e se as ferramentas necessárias (ex: Python, Node.js, Git, Docker) estão instaladas. Instale as que faltarem passo a passo de acordo com este sistema.

Crie uma pasta nova e vazia para trabalhar. Não toque em arquivos fora desta pasta e não exclua nada. Antes de executar cada comando, diga o que você vai fazer em uma frase.

Diga-me o que devo ver na tela ao final de cada etapa. Se ocorrer um erro, colarei a mensagem de erro para você exatamente como ela é, e vamos corrigi-la juntos.
