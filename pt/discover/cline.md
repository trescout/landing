# Agente de IA que automatiza processos de desenvolvimento de software

Cline é um agente de codificação autônomo que automatiza processos de desenvolvimento de software. Ele se integra aos projetos dos desenvolvedores operando através de uma extensão de IDE, kit de desenvolvimento de software (SDK) ou interface de linha de comando (CLI).

## O que você ganha

- Realiza edições de código coordenadas em todo o projeto
- Executa comandos via terminal e monitora as saídas em tempo real
- Mantém o processo de desenvolvimento sob controle com modos de planejamento e execução

## Instalação

**Instalação da interface de linha de comando**

```
npm i -g cline
```

**Instalação do kit de desenvolvimento de software**

```
npm install @cline/sdk
```

## Execução

**Início de tarefa com equipe de múltiplos agentes**

```
cline --team-name auth-sprint "Plan and implement user authentication with tests"
```
