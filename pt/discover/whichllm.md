# Encontre o modelo de IA mais adequado para o seu hardware

Whichllm é uma ferramenta que permite identificar os modelos nativos de linguagem grande com melhor desempenho em seu hardware. Concentrando-se nos benchmarks atuais e não no número de parâmetros, este software baseado em Python permite escolher o modelo mais adequado com um único comando.

## O que você ganha

- Ele determina o modelo de idioma nativo mais adequado ao seu hardware com dados de benchmark atualizados.
- Ele prevê o desempenho detectando automaticamente a GPU e os recursos do sistema.
- Oferece a oportunidade de baixar modelos, iniciar chats e criar exemplos de código Python com um único comando.
