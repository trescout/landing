# Diretrizes de Karpathy para agentes de código

Este pacote de diretrizes é descrito como derivado das observações de Andrej Karpathy sobre falhas de codificação de LLMs. Ele oferece opções de plugin para Claude Code, CLAUDE.md por projeto e regra para Cursor.

## O que esta ferramenta faz?

Andrej Karpathy Skills não é um modelo independente nem um runtime de agente de código. Ele fornece um CLAUDE.md e diretrizes no estilo de plugin para orientar agentes de código existentes, organizadas em quatro princípios: pensar antes de codificar, priorizar a simplicidade, fazer mudanças cirúrgicas e executar orientado pelo objetivo.

## Para quem é?

Desenvolvedores que usam Claude Code ou Cursor e querem adicionar diretrizes no nível do projeto ou da ferramenta.

## O que não esperar

Pessoas que procuram um LLM independente, editor de código, runtime de agente ou aplicativo pronto para execução.

## Destaques

- Usa um CLAUDE.md e uma abordagem de plugin para orientar agentes de código.
- Define quatro princípios para um trabalho deliberado e verificável.
- Inclui opções de configuração para Claude Code e Cursor.
- O README informa a licença MIT.

## Primeiro fluxo de uso

1. Leia o README do repositório e escolha a opção adequada à sua ferramenta: plugin do Claude Code, CLAUDE.md do projeto ou regra do Cursor.
2. Para uso no nível do projeto, adicione as diretrizes ao CLAUDE.md do seu projeto conforme descrito no repositório.
3. Revise as diretrizes de acordo com as necessidades do projeto antes de usá-las.

## Início seguro

Este pacote orienta agentes; ainda é necessário verificar o código gerado, o escopo das alterações e os resultados dos testes.

## Primeiro prompt

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Primeiro apresente o plano, as incertezas e os arquivos afetados por esta tarefa. Depois sugira a abordagem mais simples e faça apenas as alterações necessárias para o objetivo.
