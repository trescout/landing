# Dê talentos de engenharia a agentes de inteligência artificial

Esta biblioteca, desenvolvida para agentes de codificação de inteligência artificial, oferece habilidades de engenharia em nível de produção. Fornece ferramentas padronizadas para aumentar a capacidade técnica dos agentes que automatizam processos de desenvolvimento de software.

- ★ 91.114
- Shell
- GitHub Trending · 2026-06-10

## O que você ganha
- Fornece fluxos de trabalho de engenharia profissionais para agentes de inteligência artificial.
- Ele automatiza processos de desenvolvimento de software com etapas padronizadas.
- Disciplina processos de teste e revisão para melhorar a qualidade do código.

## Instalação
**Instalação local para Claude Code**

```
git clone https://github.com/addyosmani/agent-skills.git
claude --plugin-dir /path/to/agent-skills
```


## Se você não programa
Quero que você trabalhe como um engenheiro de software. Usando a biblioteca Agent Skills, aplique os comandos /spec, /plan, /build, /test, /review, /code-simplify e /ship de acordo com os padrões em cada estágio do meu processo de desenvolvimento de software. Produza código seguindo fluxos de trabalho, pontos de controle de qualidade e práticas recomendadas de engenharia.
