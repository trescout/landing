# Navegador furtivo para agentes de inteligência artificial

Camofox é um navegador furtivo (stealth headless browser) que permite que agentes de inteligência artificial superem sistemas de detecção de bots e bloqueios de web scraping. Ele funciona de forma diretamente compatível com as ferramentas de automação de navegador Puppeteer e Playwright, oferecendo uma solução alternativa a essas bibliotecas.

## O que você ganha

- Supera sistemas de detecção de bots e bloqueios de web scraping em nível de C++.
- Consome 90% menos dados do que o HTML padrão com snapshots de acessibilidade.
- Fornece gerenciamento de cookies e armazenamento baseado no usuário por meio de isolamento de sessão.

## Instalação

**Operação direta**

```
npx @askjo/camofox-browser
```

**Instalação a partir do código-fonte**

```
git clone https://github.com/jo-inc/camofox-browser
cd camofox-browser
npm install
npm start  # downloads Camoufox on first run (~300MB)
```

## Execução

**Iniciando o servidor local**

```
git clone https://github.com/jo-inc/camofox-browser && cd camofox-browser
npm install && npm start
# -> http://localhost:9377
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Você é um administrador de navegador web. Use o Camofox-browser para acessar sites de destino. Utilize este navegador, que é ocultado em nível de C++, para evitar ser detectado por sistemas de detecção de bots. Ao extrair dados de páginas da web, prefira snapshots de acessibilidade, que são mais leves do que o HTML bruto. Use identificadores estáveis para elementos com os quais precisa interagir e gerencie as sessões isolando-as por usuário.
