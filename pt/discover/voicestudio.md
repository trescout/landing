# Faça clonagem de voz e dublagem localmente

VoiceStudio é uma plataforma de processamento de áudio de código aberto que realiza tarefas como clonagem de voz, dublagem e transcrição sem a necessidade de internet. Oferece uma alternativa que pode ser executada localmente ao serviço de síntese de voz ElevenLabs e suporta 646 idiomas.

## O que você ganha
- Faça clonagem de voz e dublagem sem precisar de conexão com a internet
- Obtenha suporte para síntese de voz e conversão de fala em texto em 646 idiomas diferentes
- Garanta total privacidade mantendo seus dados em seu próprio computador

## Instalação
**Executar a partir do código-fonte**

```
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun install
bun run desktop
```
