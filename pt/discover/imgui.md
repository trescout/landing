# Interface leve para projetos C++

Dear ImGui é uma biblioteca leve de interface gráfica de usuário para projetos C++ que funciona com dependências mínimas. Ele permite que os desenvolvedores de software criem uma interface simples em processos rápidos de prototipagem e desenvolvimento de ferramentas.

## O que você ganha
- Estrutura simples que não requer dependências externas
- Prototipagem rápida e desenvolvimento de ferramentas
- Baixo consumo de memória e processador

## Como começar
- Fonte oficial →
Para iniciar seu projeto, basta adicionar todos os arquivos .cpp e .h começando com imgui no repositório GitHub ao seu projeto existente. Em seguida, você pode começar a criar sua própria interface gráfica examinando os aplicativos de exemplo na pasta backends.
