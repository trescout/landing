URL persistente para o ambiente de desenvolvimento local

Desenvolvido pelo Vercel Labs, o Portless converte números de porta usados em ambientes de desenvolvimento local em endereços URL persistentes e nomeados. Esta ferramenta permite que tanto desenvolvedores quanto agentes de IA autônomos interajam mais facilmente com serviços locais.

Atualizações

O que você ganha

  • Converte números de porta variáveis em endereços com nomes memoráveis
  • Fornece suporte automático para HTTPS e HTTP/2
  • Cria URLs separadas para cada pacote em estruturas monorepo

Instalação

Instalação geral
npm install -g portless
Configuração baseada em projeto
npm install -D portless

Execução

Inicie a aplicação com uma URL nomeada
portless myapp next dev

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Quero que os serviços que rodam no meu ambiente de desenvolvimento local usem endereços persistentes com a extensão .localhost em vez de números de porta. Use a ferramenta Portless para executar meu projeto e permitir que eu acesse meus serviços por meio de endereços identificáveis como https://myapp.localhost.
