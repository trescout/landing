# Banco de dados em processo compatível com SQLite

Turso oferece um banco de dados SQL em processo compatível com SQLite. Este sistema, desenvolvido em linguagem Rust, simplifica os processos de gerenciamento de dados integrando-se aos processos da aplicação.

- ★ 23.620
- Rust
- GitHub Trending · 2026-06-21

## O que você ganha
- Compatibilidade total de SQL com SQLite
- Suporte multilíngue e de plataforma
- Simultaneidade avançada e gerenciamento de dados

## Instalação
**Instalação da ferramenta de linha de comando**

```
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/tursodatabase/turso/releases/latest/download/turso_cli-installer.sh | sh
```

**Instalação do pacote JavaScript**

```
npm i @tursodatabase/database
```


## Execução
**Iniciando o Shell Interativo**

```
tursodb
```
