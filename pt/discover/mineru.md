# Converta seus documentos para IA

MinerU converte formatos de documentos complexos, como PDF e Office, em formato markdown ou JSON adequado para modelos de linguagem grandes. Esta ferramenta tem como objetivo disponibilizar dados não estruturados em fluxos de trabalho baseados em agentes.

- ★ 76.547
- Python
- GitHub Trending · 2026-06-26

## O que você ganha
- Converte arquivos PDF e Office em linguagem de marcação
- Prepara dados não estruturados para fluxos de trabalho de agentes
- Converte formatos de documentos complexos em saída JSON

## Instalação
**Instalação padrão**

```
pip install --upgrade pip
pip install uv
uv pip install -U "mineru[all]"
```

**Instalação do desenvolvedor**

```
git clone https://github.com/opendatalab/MinerU.git
cd MinerU
uv pip install -e .[all]
```


## Se você não programa
Quero converter os complexos documentos PDF e Office que possuo em um formato que meu agente de inteligência artificial possa entender. Preciso converter esses arquivos para o formato markdown ou JSON usando a ferramenta MinerU.
