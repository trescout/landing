# Revisão de código com tecnologia de IA para Claude Code

Desenvolvido pela OpenAI, o plugin Codex é usado no Claude Code para automatizar processos de revisão de código e fornecer delegação de tarefas. Esta ferramenta permite a integração de diferentes modelos de inteligência artificial (modelos de grandes linguagens) em fluxos de trabalho de desenvolvimento de software.

## O que você ganha
- Automatiza processos de revisão de código
- Delega tarefas ao modelo Codex
- Gerencia trabalhos de longa duração em segundo plano

## Instalação
**Instale o pacote Codex**

```
npm install -g @openai/codex
```


## Execução
**Iniciar a primeira revisão**

```
/codex:review
```


## Se você não programa
Inicie uma revisão do meu código existente usando o plugin Codex dentro do Claude Code e relate as descobertas. Se houver uma tarefa complexa, delegue-a ao Codex com o comando /codex:rescue e execute-a em segundo plano, permitindo-me acompanhar o progresso com /codex:status.
