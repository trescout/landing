# Integre modelos DeepSeek em suas ferramentas

compartilhado no GitHub, awesome-deepseek-agent é uma coleção de recursos que lista agentes de inteligência artificial (agentes de IA) desenvolvidos com modelos e ferramentas DeepSeek neste campo. Reúne projetos e integrações que ajudam desenvolvedores a construir sistemas autônomos utilizando a infraestrutura DeepSeek.

- ★ 5.755
- GitHub Trending · 2026-08-15

## O que você ganha
- Acesse guias de instalação para agentes de IA populares
- Possibilidade de usar modelos DeepSeek em assistentes de codificação
- Suporte de configuração para sistemas autônomos e veículos baseados em terminais

## Como começar
Primeiro você precisa obter uma chave API por meio da plataforma DeepSeek. Em seguida, revise a tabela na página do GitHub e clique no link do guia ao lado da ferramenta que deseja usar. Cada guia detalha as etapas necessárias para instalar a ferramenta escolhida e configurá-la com os modelos DeepSeek.
