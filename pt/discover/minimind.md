# minimente

MiniMind é um projeto Python que permite treinar um grande modelo de linguagem com 64 milhões de parâmetros do zero em um curto espaço de duas horas. Ele oferece um ambiente de aprendizagem prático para usuários com recursos de hardware limitados para compreender os princípios de funcionamento dos modelos de inteligência artificial.
