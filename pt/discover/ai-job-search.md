# Candidatura automática de emprego com Claude Code

Usando a infraestrutura do Claude Code, ai-job-search oferece uma estrutura que automatiza o processo de procura de emprego. A ferramenta analisa o perfil do usuário e realiza tarefas como edição de currículo, redação de cartas de apresentação e preparação de entrevistas com apoio de inteligência artificial.

## Instalação

**Baixe ferramentas de busca de emprego**

```
cd .agents/skills/jobbank-search/cli && bun install && cd ../../../..
cd .agents/skills/jobdanmark-search/cli && bun install && cd ../../../..
cd .agents/skills/jobindex-search/cli && bun install && cd ../../../..
cd .agents/skills/jobnet-search/cli && bun install && cd ../../../..
cd .agents/skills/linkedin-search/cli && bun install && cd ../../../..
```

## Execução

**Iniciar configuração do perfil**

```
/setup
```

**Procure ofertas de emprego**

```
/scrape
```

## Se você não programa

Cole isto no seu agente (Claude Code · Codex · Antigravity)

Crie seu perfil usando o comando /setup enquanto estiver no Claude Code. Em seguida, liste as ofertas de emprego adequadas com o comando /scrape e use o comando /apply para criar um rascunho do seu currículo e carta de apresentação para a oferta de emprego que você selecionou. Durante o processo, peça à inteligência artificial que avalie sua compatibilidade com o anúncio e dê feedback para preparação da entrevista.
