# Baixe sites para o disco local

O downloader de sites, desenvolvido por AhmadIbrahiim, permite baixar todos os códigos-fonte e ativos de um site para o computador local usando Node.js. A ferramenta é usada para arquivar todo o site, incluindo arquivos JavaScript, folhas de estilo e imagens.

- ★ 4.223
- HTML
- GitHub Trending · 2026-07-08

## O que você ganha
- Arquiva todos os recursos do site
- Organiza links para visualização offline
- Salva imagens e arquivos de estilo

## Como começar
- Fonte oficial →
Para começar a usar a ferramenta, baixe os códigos da página do GitHub para o seu computador. Em seguida, acesse a pasta do projeto através do terminal, instale as dependências necessárias e inicie a aplicação. Após a execução do aplicativo, você pode iniciar o download acessando seu endereço local por meio do navegador.
