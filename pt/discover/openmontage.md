# Produção de vídeo profissional com inteligência artificial

OpenMontage é um sistema baseado em agente de código aberto que transforma assistentes de codificação de IA em um estúdio de produção de vídeo completo. Esta plataforma baseada em Python automatiza processos de produção de vídeo com 12 pipelines diferentes e mais de 500 habilidades de agente.

## O que você ganha
- Cenário automático, edição visual e sonora
- Compilação de vídeos a partir de filmagens e arquivos abertos
- Planejamento de produção aprovado passo a passo

## Instalação
**Configuração básica**

```
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup
```


## Se você não programa
Quero iniciar uma produção de vídeo utilizando o sistema OpenMontage. Quero que você gerencie todo o processo, desde a pesquisa até a edição, determinando o assunto, o tempo alvo e o estilo visual. Primeiro crie um plano de produção, faça uma estimativa de custos e prossiga para a produção de ativos com minha aprovação.
