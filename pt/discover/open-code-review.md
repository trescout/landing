# Revisão de código baseada em IA de precisão

A ferramenta de revisão de código-fonte aberta desenvolvida pela Alibaba combina pipelines determinísticos e agentes de modelo de linguagem grande (LLM) em uma estrutura híbrida. Equipada com regras de segurança de software e recursos de interpretação baseados em linhas, a ferramenta é escrita em linguagem Go e oferece infraestrutura compatível com OpenAI e Anthropic.

**Instale a ferramenta CLI globalmente**

```
npm install -g @alibaba-group/open-code-review
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Revise minhas alterações atuais no Git usando a ferramenta Open Code Review. Analise arquivos na base de código, detecte erros linha por linha e crie feedback estruturado. Minimize os falsos positivos seguindo regras determinísticas durante o processo de revisão e concentre-se apenas em erros críticos de segurança ou lógicos.
