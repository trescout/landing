# Desenvolva inteligência artificial com Claude Code

Este guia visual do Claude Code oferece uma ampla variedade de exemplos, desde conceitos básicos até configurações avançadas de agentes. O objetivo é acelerar os processos de codificação dos usuários e padronizar as práticas de desenvolvimento de aplicativos por meio de modelos copiáveis.

## O que você ganha
- Integrando recursos do Claude Code em fluxos de trabalho.
- Acelerando os processos de desenvolvimento de código com modelos prontos.
- Configurando automação com configurações de agente e servidores MCP.

## Instalação
**Clonando o diretório e copiando o primeiro comando**

```
# 1. Clone the guide
git clone https://github.com/luongnv89/claude-howto.git
cd claude-howto

# 2. Copy your first slash command
mkdir -p /path/to/your-project/.claude/commands
cp 01-slash-commands/optimize.md /path/to/your-project/.claude/commands/
```

**Instalação de gancho**

```
mkdir -p ~/.claude/hooks
cp 06-hooks/*.sh ~/.claude/hooks/
chmod +x ~/.claude/hooks/*.sh
```


## Execução
**Primeira tentativa de comando**

```
# 3. Try it — in Claude Code, type:
# /optimize
```
