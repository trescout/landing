# Estrutura de estilo para design de interface rápido

Tailwind CSS é uma estrutura de folha de estilo utilitária (estrutura CSS) focada no desenvolvimento rápido de interface de usuário. Ele permite a criação rápida de interfaces originais, oferecendo classes de baixo nível em vez de componentes de design prontos.

- ★ 96.949
- TypeScript
- GitHub Trending · 2026-08-05

## O que você ganha
- Crie designs originais com classes de baixo nível
- Desenvolva interfaces sem lidar com componentes prontos
- Fornece gerenciamento rápido de estilo em projetos web modernos

## Instalação
**com npm**

```
npm install tailwindcss @tailwindcss/cli
```


## Execução
**Gerar CSS**

```
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```
