# Auto Ontology

Desenvolvido pela NVIDIA, o auto-ontology é um framework Python que permite criar camadas de raciocínio semântico e baseadas em grafos sobre dados. Esta ferramenta oferece resultados mais explicáveis e geração de consultas determinísticas para grandes modelos de linguagem (LLM) e fluxos de trabalho de agentes de inteligência artificial.
