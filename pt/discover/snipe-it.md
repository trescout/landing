# Gerenciamento de licenças e ativos corporativos

Snipe-IT é um sistema de gerenciamento de código aberto para rastrear ativos de tecnologia da informação e licenças de software. Esta plataforma, desenvolvida em linguagem PHP, permite que as instituições organizem registros de inventário e ciclos de utilização em ambiente digital.

- ★ 14.798
- PHP
- GitHub Trending · 2026-07-30

## O que você ganha
- Monitorando o ciclo de vida dos ativos de TI
- Rastreamento centralizado de licenças de software
- digitalização de registros de débito de hardware

## Instalação
**Pegue a imagem oficial**

```
docker pull grokability/snipe-it
```


## Execução
**começar**

```
docker compose up -d
```
