# Memória permanente para agentes de codificação de inteligência artificial

Escrito em Rust, o ai-memory oferece uma solução de memória de longo prazo para agentes de inteligência artificial. Ele suporta a continuidade de interfaces de linha de comando (CLI) usadas em processos de desenvolvimento de software, facilitando a transferência de dados entre diferentes provedores de agentes.

## O que você ganha
- Mantém o contexto entre diferentes agentes de IA
- Fornece continuidade nos processos de desenvolvimento
- Funciona com muitas ferramentas de codificação

Para começar a usar a ferramenta, acesse a página oficial no GitHub e baixe a versão adequada ao seu sistema operacional. Você pode aprender como integrar a ferramenta aos agentes de codificação suportados revisando os arquivos de documentação relevantes para obter detalhes de instalação e configuração.
