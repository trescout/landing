# Ferramentas de voz de IA em tempo real

Moonshine oferece recursos de fala para texto de baixa latência, reconhecimento de intenção e texto para fala para interfaces de voz e agentes de inteligência artificial. Esta biblioteca, desenvolvida em linguagem C++, tem como objetivo otimizar processos de processamento de áudio em tempo real.

## O que você ganha

- Processamento de áudio rápido e discreto executado no dispositivo
- Baixa latência otimizada para transmissões ao vivo
- Capacidade de converter fala em texto e texto em áudio

## Instalação

**Instalação com Python**

```
pip install moonshine-voice
moonshine-voice mic --language en
```

**Instalação do Raspberry Pi**

```
sudo pip install --break-system-packages moonshine-voice
 moonshine-voice mic --language en
```

## Execução

**Transcrição ao vivo via microfone**

```
moonshine-voice mic --language en
```
