# Gerencie seu servidor em nuvem pessoal

CasaOS oferece um sistema de nuvem pessoal de código aberto que facilita o gerenciamento de aplicativos baseados em Docker. Essa interface, desenvolvida na linguagem Go, permite ao usuário gerenciar de forma simples seus servidores por meio de um painel visual.

## O que você ganha
- Instale aplicativos Docker com um clique
- Gerencie arquivos com uma interface visual
- Monitore os recursos do servidor com widget

## Instalação
**comando de instalação**

```
curl -fsSL https://get.casaos.io | sudo bash
```


## Execução
**comando de atualização**

```
curl -fsSL https://get.casaos.io/update | sudo bash
```
