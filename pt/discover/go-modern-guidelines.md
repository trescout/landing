## O que você ganha
- Permite que modelos de IA usem os recursos atuais do Go
- Prefere métodos modernos e eficientes a padrões de código antigos
- Detecta automaticamente a versão Go do projeto e adapta os recursos de linguagem de acordo

## Instalação
**Adicionando mercado para Junie**

```
/extensions marketplace add JetBrains/go-modern-guidelines
```

**Instalação do plugin para Junie**

```
/extensions install modern-go-guidelines
```


## Execução
**Execute orientações sobre o Código Claude**

```
/modern-go-guidelines:use-modern-go
```


## Se você não programa
De agora em diante, use padrões Go modernos ao escrever código. Considere a versão do Go no arquivo go.mod do projeto, optando pelos recursos de linguagem mais recentes e adições de biblioteca padrão da versão 1.0 a 1.27. Use funções como `max(a, b)` em vez de blocos `if-else`, métodos modernos como `slices.Contains` em vez de loops manuais e padrões atualizados como `cmp.Or` em vez de verificações nulas.
