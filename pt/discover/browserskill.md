# Dê aos agentes de IA a capacidade de navegar

Desenvolvido pela Tencent, o BrowserSkill é uma ferramenta de automação de navegador que permite que agentes de IA gerenciem sessões de navegador ativas sem interromper o trabalho do usuário. Por meio de uma interface de linha de comando e uma extensão de navegador, ele permite que qualquer agente de IA acesse os dados do navegador onde o usuário já está logado.

## O que você ganha

- Utiliza sessões de navegador e credenciais de login existentes diretamente.
- Executa em segundo plano em uma janela separada sem interromper seu fluxo de trabalho.
- Permite intervenção humana em telas de verificação ou login.

## Instalação

**Instalação para macOS e Linux**

```
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
export PATH="${BSK_INSTALL_DIR:-$HOME/.local/bin}:$PATH"
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Você tem uma conexão com o BrowserSkill, uma ferramenta de automação de navegador. Agora você pode realizar tarefas na internet em meu nome usando minhas sessões de navegador existentes. Ao realizar uma ação, pegue emprestadas minhas abas abertas no navegador, devolva-as quando terminar e não toque nas minhas outras abas. Se você encontrar um código de verificação, tela de login ou janela de confirmação, interrompa a operação e peça minha ajuda.
