# Envie automaticamente seus vídeos para todas as plataformas

social-auto-upload é uma ferramenta Python que envia automaticamente seus vídeos para plataformas de mídia social como TikTok, YouTube, Bilibili, Douyin e Xiaohongshu. Simplifica seus processos de distribuição de conteúdo multiplataforma.

## O que você ganha
- Capacidade de fazer upload para várias plataformas ao mesmo tempo.
- Automatizando processos de distribuição de conteúdo.
- Fluxo de trabalho eficiente que economiza tempo.

## Nota de responsabilidade

## Como instalar, como usar?
**Faça login em uma plataforma**

```
sau douyin login --account <hesap_adi>
```

**Enviar vídeo**

```
sau douyin upload-video --account <hesap_adi> --file videos/demo.mp4 --title "Başlık" --desc "Açıklama"
```
