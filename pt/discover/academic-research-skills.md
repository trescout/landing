# Assistente de IA para pesquisas acadêmicas

Academic Research Skills é uma biblioteca Python desenvolvida para o Claude Code que automatiza processos acadêmicos nas etapas de pesquisa, escrita, revisão, edição e finalização. Esta ferramenta visa padronizar fluxos de trabalho acadêmicos no Claude Code, uma ferramenta de codificação assistida por IA.

- ★ 45.232
- Python
- GitHub Trending · 2026-09-02

## O que você ganha
- Gerencia o processo de redação de artigos acadêmicos de ponta a ponta
- Automatiza processos de busca e verificação de referências
- Revisa textos melhorando a qualidade da escrita

## Instalação
**Adicionar a extensão a partir da loja**

```
/plugin marketplace add Imbad0202/academic-research-skills
```

**Instalar a extensão**

```
/plugin install academic-research-skills
```


## Execução
**Planejamento de artigo**

```
/ars-plan
```


## Se você não programa
Quero usar o plugin Academic Research Skills para gerenciar meu processo de pesquisa acadêmica. Inicie um diálogo socrático para criar a estrutura do meu artigo e ajude-me a gerenciar o processo determinando em qual estágio da minha pesquisa estou.
