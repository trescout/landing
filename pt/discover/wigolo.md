# Recursos nativos da web para seu agente de IA

Wigolo é uma ferramenta que fornece recursos de pesquisa local, extração de dados e rastreamento para agentes de codificação de inteligência artificial. Esse sistema, que funciona sobre o protocolo de contexto do modelo (MCP), oferece pesquisas gratuitas, sem dependência da nuvem e sem a necessidade de chave API.

- ★ 4.069
- TypeScript
- GitHub Trending · 2026-07-19

## O que você ganha
- Pesquisa e verificação gratuitas sem necessidade de chave API
- Processamento e cache de dados locais independentes da nuvem
- Integração direta com ferramentas populares de IA

## Instalação
**Iniciando a instalação do agente**

```
npx wigolo init --agents=<your-agent>
```

**Verificando a integridade do sistema**

```
npx wigolo doctor
```


## Se você não programa
Use o Wigolo para pesquisar na web, extrair dados e sintetizar suas descobertas citando fontes. Ao realizar transações, siga o princípio de funcionamento local, use ferramentas básicas que não exigem uma chave de API e relate seus resultados de forma estruturada.
