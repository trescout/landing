# Gerencie seus agentes de IA sem erros

Babysitter fornece um mecanismo de controle determinístico para que uma força de trabalho de agentes de inteligência artificial possa realizar tarefas complexas sem erros e alucinações.

## Como instalar, como usar?

Cole isto no seu agente (Claude Code · Codex · Antigravity)

Instale o plugin Babysitter no Claude Code usando os comandos 'claude plugin marketplace add a5c-ai/babysitter' seguido de 'claude plugin install --scope user babysitter@a5c.ai' e, em seguida, inicie um fluxo de trabalho controlado passo a passo com o comando '/babysitter:call'.

Repositório: https://github.com/a5c-ai/babysitter. Baseie-se nas instruções oficiais no arquivo README deste repositório para a instalação e execução.

Antes de começar, verifique em qual sistema operacional estamos e se as ferramentas necessárias (ex: Python, Node.js, Git, Docker) estão instaladas. Instale as que faltarem passo a passo de acordo com este sistema.

Crie uma pasta nova e vazia para trabalhar. Não toque em arquivos fora desta pasta e não exclua nada. Antes de executar cada comando, diga o que você vai fazer em uma frase.

Diga-me o que devo ver na tela ao final de cada etapa. Se ocorrer um erro, colarei a mensagem de erro para você exatamente como ela é, e vamos corrigi-la juntos.

**Código Claude · marketplace + instalação**

```
claude plugin marketplace add a5c-ai/babysitter
claude plugin install --scope user babysitter@a5c.ai
```

**Executar tarefa com TDD**

```
claude "/babysitter:call implement user authentication with TDD"
```
