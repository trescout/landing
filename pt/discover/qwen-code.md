# Agente de codificação de inteligência artificial

QwenLM/qwen-code é um agente de codificação de inteligência artificial de código aberto (open-source) que funciona no terminal, editor, desktop e navegador. Desenvolvida com a linguagem TypeScript, esta ferramenta visa apoiar os processos de desenvolvimento de software em diferentes plataformas.

## O que você ganha

- Permite codificar no terminal, desktop, navegador e editor
- Oferece fluxos de trabalho dinâmicos com memória automática, habilidades e subagentes
- Utiliza diferentes serviços de inteligência artificial e modelos locais com suporte a múltiplos protocolos

## Instalação

**Instalação via NPM**

```
npm install -g @qwen-code/qwen-code@latest
```

**Instalação via Homebrew**

```
brew install qwen-code
```

## Execução

**Inicialização**

```
qwen
```
