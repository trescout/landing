## Instalação

**Instalação em sistemas Mac ou Linux**

```
curl -fsSL https://deno.land/install.sh | sh
```

**Instalação com Homebrew no Mac**

```
brew install deno
```

## Execução

**Iniciando o arquivo do servidor preparado**

```
deno run --allow-net server.ts
```
