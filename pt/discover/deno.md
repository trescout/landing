# Tempo de execução moderno de JavaScript e TypeScript

Deno é um ambiente de execução moderno projetado para linguagens JavaScript e TypeScript. Desenvolvida na linguagem Rust, esta ferramenta oferece uma infraestrutura alternativa à tradicional plataforma Node.js com sua estrutura voltada para segurança e desempenho.

- ★ 108.181
- Rust
- GitHub Trending · 2026-08-05

## O que você ganha
- Ele executa com segurança as linguagens JavaScript, TypeScript e WebAssembly.
- Ele oferece alto desempenho com seu motor V8 e linguagem Rust.
- Oferece uma infraestrutura moderna e prática para desenvolvimento de servidores web.

## Instalação
**Instalação em sistemas Mac ou Linux**

```
curl -fsSL https://deno.land/install.sh | sh
```

**Instalação com Homebrew no Mac**

```
brew install deno
```


## Execução
**Iniciando o arquivo do servidor preparado**

```
deno run --allow-net server.ts
```


## Se você não programa
