# Projete ontologias de IA com Ontology-Playground

Desenvolvido pela Microsoft, Ontology-Playground é um aplicativo web de código aberto usado para aprender ontologias e criar designs visuais no Microsoft Fabric IQ. Esta ferramenta completamente estática permite aos usuários projetar modelos de ontologias, exportá-los em formato RDF/XML e compartilhar diagramas interativos.

## Instalação

**Instalando o projeto em um ambiente local**

```
cd Ontology-Playground
npm install
```

**Iniciando o servidor de desenvolvimento**

```
npm run dev
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Quero projetar uma ontologia usando Ontology-Playground. Carregue o modelo inicial selecionando um campo como Varejo, Saúde ou Finanças. Em seguida, adicione novos tipos de entidade a este modelo, defina os relacionamentos entre eles e mostre as etapas necessárias para exportar este modelo que criei no formato RDF/XML.
