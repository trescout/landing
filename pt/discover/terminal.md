# Experiência moderna de linha de comando do Windows

A Microsoft está combinando o Windows Terminal e o host de console tradicional do Windows sob o mesmo teto. Este projeto de código aberto, desenvolvido em linguagem C++, reestrutura a experiência de linha de comando com uma interface moderna e abas personalizáveis.

## O que você ganha
- Interface moderna e personalizável
- Suporte a múltiplas guias
- Melhor desempenho da linha de comando

## Instalação
**Janelas (winget)**

```
winget install Microsoft.WindowsTerminal
```


## Execução
**Executar a partir da linha de comando**

```
wt
```


## Como começar
- Fonte oficial →
Você pode baixar facilmente o aplicativo Windows Terminal na Microsoft Store. Alternativamente, você pode baixar manualmente a versão atual na página Releases no GitHub ou instalá-la em seu computador usando gerenciadores de pacotes como Winget, Chocolatey ou Scoop.
