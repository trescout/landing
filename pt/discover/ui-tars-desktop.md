# Interface de inteligência artificial que gerencia seu computador

Desenvolvido pela ByteDance, UI-TARS é uma infraestrutura de agente de código aberto que integra modelos de IA multimodais com interfaces de desktop. Este sistema permite a criação de agentes (agentes de IA) que executam tarefas no computador de forma autônoma, processando dados visuais.

## O que você ganha

- Execute tarefas de desktop e navegador de forma autônoma
- Fluxo de trabalho semelhante ao humano, processando dados visuais
- Integração total com modelos de IA multimodais

## Instalação

**Instalação global**

```
npm install @agent-tars/cli@latest -g
```

**Operação direta**

```
npx @agent-tars/cli@latest
```

## Execução

**Inicializar com provedor de modelo**

```
agent-tars --provider volcengine --model doubao-1-5-thinking-vision-pro-250428 --apiKey your-api-key
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Descreva uma tarefa complexa que você deseja que eu execute em meu computador ou navegador. Por exemplo, posso pedir que você acesse um site específico e insira dados ou gerencie um processo de reserva de voo. Analise a interface visual e conclua as etapas de forma autônoma.
