# Interface visual para gerenciamento de pacotes no macOS

O Homebrew é uma ferramenta de linha de comando usada para gerenciar pacotes de software no sistema operacional macOS. O BrewUI é um aplicativo de desktop oficial que permite gerenciar os comandos complexos dessa ferramenta através de uma interface gráfica (GUI).

- ★ 2.014
- Swift
- GitHub Trending · 2026-09-16

## O que você ganha
- Gerencie pacotes de software sem usar a linha de comando
- Acompanhe as operações do Homebrew com uma interface transparente
- Instalação fácil com um aplicativo nativo para macOS baseado em SwiftUI

## Instalação
**Instalar o aplicativo**

```
brew install --cask homebrew-app
```
