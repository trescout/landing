Inteligência de negócios automatizada com inteligência artificial

Desenvolvido por Canner, WrenAI é uma ferramenta de business intelligence generativa (BI generativo) de código aberto que exporta automaticamente dados para painéis e gráficos, convertendo linguagem natural em consultas de banco de dados (texto para SQL). A plataforma fornece processos confiáveis ​​de análise de dados para agentes de IA por meio de uma camada de contexto gerenciável que suporta mais de vinte fontes de dados.

O que você ganha

  • Gera consultas SQL confiáveis a partir de linguagem natural
  • Converte dados automaticamente em painéis
  • Suporta mais de 22 fontes de dados

Instalação

Instalação CLI
pip install wrenai                      # core (DuckDB included)
pip install "wrenai[postgres,memory]"   # add per-datasource and memory extras as needed
Configuração de stub para cliente AI
npx skills add Canner/WrenAI            # auto-detects Claude Code, Cursor, Cline, Codex, …

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Configure minha conexão com o banco de dados usando WrenAI, crie o esqueleto do projeto e execute minha primeira consulta. Em seguida, enriqueça o contexto incluindo os dados da lógica de negócios na pasta bruta em meu projeto.
