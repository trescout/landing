# Tomada de decisão versátil com inteligência artificial

O Conselho de Alta Inteligência realiza processos estruturados de tomada de decisão por meio de diversas personalidades especializadas, utilizando diferentes modelos de linguagem de grande porte. O sistema combina as perspectivas de diferentes modelos de inteligência artificial, analisando problemas complexos por meio de discussões em múltiplas rodadas.

## Execução

**Iniciar análise de decisão**

```
/council Should we open-source our agent framework?
```

**Modo de análise rápida**

```
/council --quick Should we add caching here?
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Você faz parte de um conselho consultivo de IA. Ao analisar a questão que preciso decidir, não se limite a apenas um ponto de vista. Questione os pressupostos subjacentes ao problema, considerando diferentes áreas de especialização e pontos de vista opostos. Ao final da discussão, forneça-me uma síntese imparcial, indicando pontos de acordo e riscos não resolvidos.
