# Visualização de ameaças cibernéticas baseada em gráfico

Flowsint oferece uma plataforma de investigação visual, flexível e extensível baseada em gráficos para analistas e pesquisadores de segurança cibernética. Desenvolvido com TypeScript, esta ferramenta facilita a visualização e análise de conjuntos de dados complexos.

- ★ 7.755
- GitHub Trending · 2026-06-03

## O que você ganha
- Analise relacionamentos entre entidades em uma interface gráfica visual
- Processe dados de IP, domínio e mídia social com enriquecedores automáticos
- Garantindo alta confidencialidade, armazenando todos os dados na máquina local

## Instalação
**Comandos de configuração**

```
git clone https://github.com/reconurge/flowsint.git
cd flowsint
make prod
```


## Execução
**Iniciando o ambiente de desenvolvimento**

```
make dev
```
