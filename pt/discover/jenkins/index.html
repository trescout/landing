Servidor que automatiza processos de software

Jenkins é um servidor de integração contínua e entrega contínua de código aberto que automatiza os processos de desenvolvimento de software. Esta plataforma baseada em Java oferece um amplo ecossistema de plugins para gerenciar as fases de compilação, teste e implantação de projetos de software.

O que você ganha

  • Automatiza os processos de compilação e teste de projetos de software
  • Oferece a oportunidade de personalizar processos com amplo suporte a plug-ins
  • Acelera a detecção de erros e as fases de implantação

Instalação

macOS (homebrew)
brew install jenkins
Imagem do Docker
docker pull jenkins/jenkins:lts

Execução

Comece com Docker (http://localhost:8080)
docker run -p 8080:8080 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts
