# Gerenciamento de projetos para projetos Java

Apache Maven é uma ferramenta de gerenciamento e compreensão de projetos (ferramenta de automação de construção) que gerencia processos de criação de software em projetos baseados em Java. Ele usa a estrutura do modelo de objeto do projeto para padronizar o ciclo de vida de desenvolvimento de software.

## O que você ganha
- Padroniza processos de criação de software
- Fornece gerenciamento centralizado com modelo de objeto de projeto
- Gerencia processos de relatórios e documentação

## Instalação
**macOS (homebrew)**

```
brew install maven
```

**Imagem do Docker**

```
docker pull maven
```


## Execução
**Compilar o projeto**

```
mvn package
```
