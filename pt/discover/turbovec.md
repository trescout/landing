# Indexação vetorial de alto desempenho com Rust

Construído na infraestrutura TurboQuant, turbovec é uma ferramenta de índice vetorial de alto desempenho desenvolvida com a linguagem Rust. Graças às ligações Python, permite aos desenvolvedores realizar operações de pesquisa baseadas em vetores de forma rápida e eficiente.

## O que você ganha

- Ele reduz o uso de memória ao compactar altamente dados vetoriais.
- Ele fornece adição instantânea de dados e pesquisa rápida sem exigir uma fase de treinamento.
- Ele mantém o desempenho realizando operações de filtragem durante a pesquisa.

## Instalação

**Instalação para Python**

```
pip install turbovec
```

**Instalação para ferrugem**

```
cargo add turbovec
```
