# Spirula Studio

Spirula Studio é uma ferramenta de treinamento multiplataforma que converte vídeos em representações de cenas tridimensionais (3D Gaussian Splatting) e os transforma em malhas (mesh). O software oferece um ambiente de trabalho compatível com diferentes fabricantes de hardware, utilizando as interfaces gráficas Vulkan ou CUDA.
