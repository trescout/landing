# Mecanismo de desenvolvimento de jogos de código aberto

Godot Engine (Godot Engine) é um mecanismo de jogo de código aberto usado para processos de desenvolvimento de jogos bidimensionais e tridimensionais. Esta plataforma, desenvolvida em linguagem C++, permite aos desenvolvedores produzir jogos que podem rodar em diferentes sistemas operacionais.

## O que você ganha
- Oferece ferramentas abrangentes para jogos bidimensionais e tridimensionais
- Permite enviar jogos para diferentes plataformas com um clique
- É totalmente gratuito e gerenciado pela comunidade.

## Instalação
**macOS (homebrew)**

```
brew install --cask godot
```

**Janelas (winget)**

```
winget install GodotEngine.GodotEngine
```
