# Angular para aplicações web abrangentes

Desenvolvido pelo Google, Angular é uma estrutura abrangente usada para criar aplicativos web escalonáveis. Com sua estrutura baseada em TypeScript, oferece ferramentas que padronizam e estruturam o processo de desenvolvimento em projetos complexos.

- TypeScript

## O que você ganha
- Oferece a oportunidade de desenvolver aplicativos da web para dispositivos móveis e desktop
- Padroniza projetos complexos com sua estrutura baseada em TypeScript
- Facilita a criação de projetos escalonáveis ​​com amplo suporte de ferramentas

## Instalação
**Configurando a interface de linha de comando**

```
npm install -g @angular/cli
```


## Execução
**Crie um novo espaço de trabalho**

```
ng new [PROJECT NAME]
```

**Iniciando o aplicativo localmente**

```
cd [PROJECT NAME]
ng serve
```
