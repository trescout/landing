## O que esta ferramenta faz?
O CS249r Book é um livro didático abrangente e de código aberto focado em executar modelos de aprendizado de máquina em dispositivos com recursos limitados. Ele explora profundamente os tópicos de TinyML e computação de aprendizado profundo eficiente (efficient deep learning computing).

## Para quem é?
Estudantes e pesquisadores que desejam integrar modelos de aprendizado profundo em dispositivos de borda (edge devices).

## O que não esperar
Apenas aqueles interessados em desenvolvimento web ou que ainda não possuem os fundamentos de aprendizado de máquina.

## Destaques
- Oferece um recurso fundamental sobre TinyML e tópicos de aprendizado profundo eficiente.
- Explica técnicas de otimização de modelos para dispositivos com restrições de hardware.
- É um livro didático de código aberto com qualidade acadêmica.

## Primeiro fluxo de uso
- Visite o repositório oficial do GitHub para acessar a versão atualizada do livro.
- Baixe o PDF ou a versão web correspondente para o seu dispositivo.
- Configure os ambientes Python e PyTorch recomendados para testar os exemplos de código do livro.
