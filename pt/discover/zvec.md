# Banco de dados de vetores rápido no aplicativo

Desenvolvido pela Alibaba, zvec é uma solução de banco de dados vetorial em processo leve e de alta velocidade escrita em C++. Seu objetivo é aumentar o desempenho do sistema, permitindo que os aplicativos processem dados vetoriais diretamente na memória.

- ★ 15.504
- C++
- GitHub Trending · 2026-06-17

## O que você ganha
- Arquitetura operacional local que não requer servidor
- Velocidade de pesquisa em milissegundos em bilhões de vetores
- Suporte para pesquisa vetorial, de texto e híbrida

## Instalação
**Instalação para Python**

```
pip install zvec
```

**Instalação para Node.js**

```
npm install @zvec/zvec
```


## Se você não programa
Preciso criar uma coleção usando a biblioteca Zvec. Você pode criar um código de exemplo em Python que me permita definir um esquema, adicionar dados vetoriais apropriados a esse esquema e, em seguida, pesquisar com uma consulta vetorial específica? Use uma estrutura que especifique o caminho do arquivo para que os dados sejam persistentes.
