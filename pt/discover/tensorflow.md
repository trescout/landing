# Plataforma de código aberto para modelos de inteligência artificial

Desenvolvido pelo Google, o TensorFlow é uma biblioteca de código aberto usada para criar e treinar modelos de aprendizado de máquina (machine learning). Ele permite que desenvolvedores projetem redes neurais complexas e implantem esses modelos de forma escalável.

## O que você ganha

- Permite criar e implantar aplicações de aprendizado de máquina
- Oferece interfaces estáveis para as linguagens de programação Python e C++
- Possui um ecossistema flexível com suporte a GPU e CPU

## Instalação

**Para instalar a biblioteca**

```
pip install tensorflow
```

**Para instalar apenas a versão com suporte a CPU**

```
pip install tensorflow-cpu
```

## Execução

**Para iniciar o ambiente Python**

```
python
```
