# Links de download direto de serviços de nuvem

LinkSwift é uma ferramenta que utiliza uma infraestrutura baseada em JavaScript para obter links de download direto de arquivos de vários serviços de armazenamento em nuvem. O software suporta oito plataformas de nuvem populares, como Baidu Netdisk, Alibaba Cloud Drive, China Mobile Cloud e Quark Drive.

## O que você ganha

- Gera links de download direto de nove serviços de armazenamento em nuvem diferentes, incluindo Baidu, Alibaba Cloud e Quark.
- Oferece a possibilidade de transferir os links obtidos para softwares como o gerenciador de downloads IDM ou a ferramenta de download Aria2.
- Simplifica a interface web dos serviços de nuvem suportados, eliminando a necessidade de instalar aplicativos de desktop oficiais.

## Como começar

Para usar, primeiro você precisa instalar a extensão gerenciadora de scripts de usuário Tampermonkey no seu navegador. Em seguida, você pode adicionar o script ao seu navegador clicando no link de instalação com a extensão ".user.js" compartilhado na página do GitHub ou ScriptCat do projeto. Após a instalação do script, ao acessar um site de armazenamento em nuvem suportado, o menu de download direto aparecerá automaticamente na interface.
