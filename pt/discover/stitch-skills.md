# Capacidades de design para agentes de IA

Desenvolvido pelo Google Labs, Stitch Skills é uma biblioteca de habilidades de agente projetada para funcionar com o servidor Stitch MCP. Seguindo padrões abertos, esta biblioteca visa padronizar fluxos de trabalho para agentes de codificação como Gemini CLI e Cursor.

## O que você ganha
- Fluxo de trabalho padronizado entre código e design
- Geração automática de componentes React e React Native
- Extraia e gerencie sistemas de design a partir do código

## Instalação
**Instalação para Código Claude**

```
npx plugins add google-labs-code/stitch-skills --scope project --target claude-code
```

**Configuração do cursor**

```
npx plugins add google-labs-code/stitch-skills --scope workspace --target cursor
```


## Execução
**Ver comandos de ajuda**

```
npx plugins --help

npx skills --help
```


## Se você não programa
Analise meu código de interface existente usando a biblioteca Stitch Skills e importe-o para um projeto Stitch. Em seguida, crie componentes React usando este sistema de design e verifique se o projeto está em conformidade com os padrões de design.
