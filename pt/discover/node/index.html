Desenvolvimento do lado do servidor com JavaScript

Node.js oferece um ambiente de execução que permite que o código JavaScript seja executado fora do navegador. Baseada no motor V8, esta plataforma é usada para desenvolver aplicações de rede escaláveis ​​no lado do servidor.

Nota da TreScout: A maneira padrão de executar JavaScript no lado do servidor. Usar a mesma linguagem dos dois lados é uma grande comodidade para a equipe; O preço é que a árvore de dependências aumenta rapidamente e o gerenciamento de versões se torna seu trabalho.
