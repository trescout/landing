# Estruturas de dados e algoritmos com animações

Hello 算法 é uma plataforma educacional de código aberto que ensina estruturas de dados e algoritmos com visualizações animadas. O projeto padroniza o processo de aprendizagem, oferecendo suporte para diversas linguagens de programação e exemplos de códigos executáveis ​​com um clique.
