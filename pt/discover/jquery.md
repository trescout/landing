# Crie versões personalizadas do jquery

O jQuery é uma biblioteca JavaScript que facilita a criação de elementos interativos em páginas da web. Ela oferece ferramentas que simplificam a manipulação do Modelo de Objeto de Documento (DOM) e o gerenciamento de eventos para os desenvolvedores.

## O que você ganha

- Compile sua própria biblioteca jquery personalizada.

## Instalação

**Instale as dependências e compile o projeto**

```
cd jquery
npm install
npm run build
```

**Gere todos os arquivos de versão**

```
npm run build:all
```
