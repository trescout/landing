# Gerenciamento de banco de dados para projetos Node.js

Prisma é uma ferramenta de mapeador relacional de objetos (ORM) que simplifica as interações de banco de dados para projetos Node.js e TypeScript. Sua estrutura, que suporta diferentes sistemas de banco de dados, permite aos desenvolvedores criar consultas de banco de dados com segurança de tipo.

## Instalação
**Instalando pacotes necessários**

```
npm install prisma --save-dev
npm install @prisma/client
```


## Execução
**Iniciando um servidor de banco de dados local**

```
npx prisma dev
```

**Criando um banco de dados baseado em nuvem**

```
npx create-db --interactive
```
