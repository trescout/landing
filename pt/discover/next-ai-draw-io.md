# Criação automática de diagramas com inteligência artificial

Este aplicativo baseado em Next.js combina a ferramenta de diagramação draw.io com recursos generativos de IA. Os usuários podem criar diagramas visuais por meio de comandos de linguagem natural e editar seus diagramas existentes com suporte de inteligência artificial.

## O que você ganha
- Desenhe diagramas profissionais com comandos de linguagem natural
- Converta imagens e arquivos PDF existentes em diagramas
- Visualize rapidamente a arquitetura e os fluxogramas da nuvem

## Instalação
**instalação local**

```
git clone https://github.com/DayuanJiang/next-ai-draw-io
cd next-ai-draw-io
npm install
cp env.example .env.local
```


## Execução
**Iniciando o servidor de desenvolvimento**

```
npm run dev
```
