# Gerencie agentes de inteligência artificial com padrões de equipe

Desenvolvido pela Tencent, o teamai-cli é uma ferramenta de desenvolvimento de software que permite que as equipes interajam com ferramentas de inteligência artificial por meio de uma interface de linha de comando (CLI). Esta ferramenta visa digitalizar os processos de trabalho das equipes integrando recursos de inteligência artificial generativa (generative AI) aos fluxos de trabalho.

## O que você ganha

- Define regras de colaboração e habilidades comuns para todos os membros da equipe.
- Funciona de forma compatível com ferramentas de inteligência artificial como Claude Code e Cursor.
- Sincroniza automaticamente as atualizações feitas com todos os membros da equipe.

## Instalação

**Instale a ferramenta no seu computador**

```
npm install -g teamai-cli
```

## Execução

**Conecte o repositório da equipe ao seu projeto**

```
teamai init https://github.com/yourorg/yourrepo
```
