# Adicione recursos de IA às suas notas Obsidian

Obsidian-skills permite que agentes de inteligência artificial executem operações no aplicativo de anotações Obsidian usando a interface de linha de comando (CLI) e formatos de arquivo abertos. Esta ferramenta automatiza o gerenciamento de informações pessoais, permitindo que os agentes leiam e editem formatos como Markdown e JSON Canvas.

## O que você ganha
- Permite que agentes de inteligência artificial leiam e organizem suas anotações.
- Suporta formatos de arquivo como Markdown e JSON Canvas.
- Estabelece processos de automação no aplicativo de anotações Obsidian.

## Instalação
**instalação com npx**

```
npx skills add git@github.com:kepano/obsidian-skills.git
```

**Instalação para OpenCode**

```
git clone https://github.com/kepano/obsidian-skills.git ~/.opencode/skills/obsidian-skills
```


## Se você não programa
Eu uso a ferramenta Obsidian-skills para gerenciar minhas notas Obsidian. Use este conjunto de habilidades para editar arquivos Markdown em minhas notas, atualizar o conteúdo do JSON Canvas ou executar as ações necessárias por meio da interface de linha de comando Obsidian CLI. Quero que você crie um fluxo eficiente de gerenciamento de informações, principalmente preservando as estruturas, conexões e recursos complexos de minhas anotações.
