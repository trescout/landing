# Formatação rápida para projetos C++

fmt é uma biblioteca moderna de formatação de texto desenvolvida para a linguagem de programação C++. Oferece uma alternativa mais rápida e segura aos métodos printf e iostream da biblioteca padrão C++.

## O que você ganha
- Oferece um desempenho superior em comparação aos métodos padrão.
- Proporciona uma estrutura segura que reduz a margem de erro.
- Utiliza uma sintaxe fácil, semelhante à do Python.
