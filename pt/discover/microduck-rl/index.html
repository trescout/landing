Ambiente de aprendizado por reforço para a robótica Microduck

Criado pela Pollen Robotics, o microduck_rl oferece ambientes de aprendizado por reforço em MuJoCo e mjlab para o robô bípede Microduck.

  • ★ 1.001
  • Python
  • GitHub Trending · 2026-08-31

Atualizações

  • 31 de agosto de 2026: 1.001 estrelas, com motor físico MuJoCo mjlab e ambientes de locomoção.

O que você ganha

  • Simulação física realista em MuJoCo: Cálculo de alto desempenho de torques articulares, atrito e dinâmica gravitacional.
  • Ambientes de locomoção prontos para uso: Funções de recompensa pré-configuradas para caminhada, equilíbrio e desvio de obstáculos.
  • Facilidade de transferência Sim-to-Real: Políticas robustas projetadas para implantação no hardware robótico real do Microduck.
  • Algoritmos modernos de aprendizado por reforço: Integração nativa com PPO (Proximal Policy Optimization) e SAC.
  • Visualização 3D interativa: Acompanhe a marcha e estabilidade do robô em tempo real na interface gráfica da simulação.

Instalação

Clonar o repositório e instalar pacote de simulação
git clone https://github.com/pollen-robotics/microduck_rl.git
cd microduck_rl
pip install -e .

Execução

Executar treinamento ou visualização de políticas
python -m microduck_rl.train --task walk
# Eğitilen politikayı simülatörde izleme:
python -m microduck_rl.enjoy --checkpoint checkpoint.pt

Arquitetura técnica e princípio de funcionamento

O microduck_rl conecta o motor de física MuJoCo à API Gymnasium por meio do mjlab:

  • Camada cinemática MuJoCo e mjlab: Arquivos XML/MJCF que modelam a estrutura mecânica, atuadores e limites articulares do robô.
  • Espaços de ação e observação Gymnasium: Vetores padronizados para envio de torques de motores e leitura de sensores IMU.
  • Randomização de domínio (Domain Randomization): Altera atritos, massas e ruídos para garantir robustez na transição para o robô real.

Simulação física e políticas de controle robótico

Pesquisadores de robótica usam o microduck_rl para desenvolver controladores robustos sem danificar o hardware físico:

  • Proteção contra danos ao hardware: Elimine riscos de quebra de atuadores e quedas treinando primeiro no ambiente virtual.
  • Treinamento acelerado em paralelo: Simule a física a velocidades até 100 vezes maiores que o tempo real para concluir o treino em horas.
  • Criação de terrenos e desafios personalizados: Adicione rampas, escadas e solos irregulares para testar a adaptabilidade da marcha.

Perguntas frequentes

  • É obrigatório ter o robô físico Microduck? Não. Todo o repositório executa de forma 100% virtual no simulador MuJoCo sem exigir o robô físico.
  • É necessário ter uma GPU? O MuJoCo roda com eficiência na CPU, mas uma placa com suporte a CUDA acelera substancialmente o treinamento em paralelo.
  • Como transferir o modelo treinado para o robô real? O arquivo de checkpoint PyTorch ou ONNX gerado é copiado para o computador de bordo do robô para acionar os motores.
  • Ele suporta outros tipos de robôs? Embora focado no Microduck, a arquitetura modular permite adaptar modelos cinemáticos de outros robôs bípedes.
