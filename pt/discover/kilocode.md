# Agente versátil de codificação de IA

Kilo é uma plataforma completa de engenharia baseada em agentes, projetada para acelerar os processos de desenvolvimento de software. Ele padroniza os processos de criação, distribuição e iteração de aplicativos por meio de um agente de desenvolvimento de software de código aberto (agente de codificação).

## O que você ganha

- Capacidade de alternar entre mais de 500 modelos
- Suporte VS Code, JetBrains e CLI
- Geração e depuração de código em linguagem natural

## Instalação

**instalar com npm**

```
npm install -g @kilocode/cli
```

**Instalação com Homebrew**

```
brew install Kilo-Org/tap/kilo
```

## Execução

**Iniciando a ferramenta**

```
kilo
```

**Modo de operação autônomo**

```
kilo run --auto "run tests and fix any failures"
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Como agente de desenvolvimento de software, preciso que você gerencie meus processos de geração de código em linguagem natural, depuração ou planejamento de arquitetura em meu diretório de projeto atual. Quero que você escolha o que melhor se adapta à minha tarefa entre os mais de 500 modelos oferecidos pela Kilo, revise os códigos que escreveu com seu próprio mecanismo de autoauditoria e os entregue de acordo com os padrões de desempenho e segurança.
