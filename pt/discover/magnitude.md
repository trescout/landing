# Execute modelos de IA locais no seu computador

Magnitude é um servidor de inferência de código aberto que se integra com agentes de IA existentes e permite executar modelos locais adequados ao seu hardware. Ele funciona de forma compatível com assistentes de codificação como o Cline e vários modelos de código aberto, facilitando o aproveitamento do poder de processamento local.

- ★ 3.348
- TypeScript
- GitHub Trending · 2026-09-04

## O que você ganha
- Identifica automaticamente os modelos locais mais adequados ao seu hardware
- Funciona totalmente offline, sem necessidade de conexão com a internet
- Integra-se com assistentes de IA, eliminando custos de tokens

## Instalação
**Instale a ferramenta CLI e inicie a configuração**

```
npm i -g @magnitudedev/cli
magnitude setup
```


## Se você não programa
Configure modelos locais para mim com o Magnitude CLI. Instale-o com `npm i -g @magnitudedev/cli` (ou meu gerenciador de pacotes), depois execute `magnitude docs onboarding` e siga as instruções.
