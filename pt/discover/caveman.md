# Economize dinheiro encurtando as respostas da IA

Caveman é um pacote de recursos desenvolvido para Claude Code que reduz o consumo de tokens em 65%, simplificando o uso da linguagem do modelo de inteligência artificial. Esta ferramenta visa reduzir custos de processamento, reduzindo comandos complexos a uma estrutura de linguagem primitiva.

- ★ 102.818
- JavaScript
- GitHub Trending · 2026-07-03

## O que você ganha
- Economiza até 65% de tokens em respostas de IA.
- Elimina palavras desnecessárias sem sacrificar a precisão técnica.
- Reduz os custos de transação e aumenta a velocidade de resposta.

## Instalação
**Configuração para macOS, Linux e WSL**

```
curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.sh | bash
```

**instalação para janelas**

```
irm https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.ps1 | iex
```


## Execução
**Ative o modo**

```
/caveman
```


## Se você não programa
A partir de agora, dê suas respostas no modo Caveman. Remova palavras de preenchimento desnecessárias, mantenha apenas informações concisas e detalhes técnicos. Redija suas respostas em frases curtas, concisas e fragmentadas; mas continue a transmitir blocos de código, comandos e mensagens de erro completos e precisos.
