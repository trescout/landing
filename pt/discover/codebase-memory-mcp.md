# Indexação rápida para agentes de codificação de IA

Codebase-memory-mcp oferece inteligência de código de alto desempenho, transformando bases de código em um gráfico de conhecimento permanente. Desenvolvida em linguagem C, a ferramenta suporta 158 linguagens de programação, reduz o tempo de consulta para menos de milissegundos e reduz o uso de tokens.

- ★ 39.459
- C
- GitHub Trending · 2026-06-18

## O que você ganha
- Converte a base de código em gráfico de conhecimento em milissegundos
- Suporta nativamente 158 linguagens de programação
- Reduz o uso de moedas em até 120x

## Instalação
**Global com npm**

```
npm install -g codebase-memory-mcp
```


## Se você não programa
Indexe este projeto para ajudá-lo a analisar minha base de código e responder a consultas estruturadas com mais eficiência. Depois de indexar o projeto, quero que você forneça informações detalhadas sobre minha base de código usando relacionamentos entre funções, classes e cadeias de chamadas.
