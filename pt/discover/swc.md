# Crie seus projetos web na velocidade Rust

Desenvolvido com a linguagem Rust, SWC oferece uma plataforma rápida de compilação e agrupamento para projetos web. Ele acelera processos modernos de desenvolvimento web processando arquivos JavaScript e TypeScript com alto desempenho.

- ★ 34.160
- GitHub Trending · 2026-06-14

## O que você ganha
- Processa arquivos JavaScript e TypeScript em alta velocidade
- Fornece infraestrutura de alto desempenho desenvolvida com linguagem Rust
- Acelera os processos modernos de desenvolvimento web

## Instalação
**Dependência do projeto (npm)**

```
npm i -D @swc/core
```
