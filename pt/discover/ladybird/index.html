Navegador independente Ladybird

Ladybird é um novo navegador desenvolvido independentemente dos principais mecanismos de navegador existentes. Escrito em C++, este projeto visa fornecer uma alternativa de código aberto baseada em padrões da Internet.

  • ★ 65.040
  • C++
  • GitHub Trending · 2026-08-09

O que você ganha

  • Oferece uma nova estrutura independente dos mecanismos de navegador existentes
  • Fornece uma alternativa de código aberto baseada em padrões da Internet
  • Visa uma experiência de navegação segura e durável com sua arquitetura de multiprocessamento

Como começar

Ladybird é um navegador ainda em desenvolvimento. Para as etapas de instalação e operação, você pode revisar as instruções de compilação na seção de documentação do site oficial.
