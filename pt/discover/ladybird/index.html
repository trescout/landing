Projeto de navegador e mecanismo independente

Ladybird é um projeto independente de navegador e mecanismo web baseado nos padrões da web. O README oficial o descreve como pré-alpha e destinado apenas a desenvolvedores; sua arquitetura multiprocessos separa as conexões de rede e a decodificação de imagens.

O que esta ferramenta faz?

Ladybird é um projeto de código aberto de navegador e mecanismo de navegador. Ele funciona em Linux, macOS, Windows com WSL2 e outros sistemas semelhantes ao Unix. O site do projeto indica como meta uma primeira versão Alpha em 2026 para Linux e macOS, enquanto o guia de build exige Qt 6.9+, um compilador compatível com C++23, Rust e CMake 3.30+.

Para quem é?

Desenvolvedores que querem estudar tecnologias de navegadores, contribuir com o projeto ou compilar o código-fonte em um ambiente de desenvolvimento.

O que não esperar

Pessoas que procuram um navegador estável para uso diário.

Destaques

  • Projeto independente de navegador e mecanismo baseado nos padrões da web.
  • Arquitetura multiprocessos com processos separados para conexões de rede e decodificação de imagens.
  • Processos renderer de abas executados em sandbox.
  • Licença BSD-2-Clause.

Primeiro fluxo de uso

  1. Abra as instruções oficiais de build e verifique se sua plataforma é compatível.
  2. Prepare Qt 6.9+, um compilador compatível com C++23, Rust e CMake 3.30+.
  3. Clone o repositório oficial e siga as instruções de build do projeto.

Início seguro
