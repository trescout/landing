# Servidores de exemplo para agentes de inteligência artificial

Os servidores do Model Context Protocol (MCP) permitem que modelos de inteligência artificial generativa acedam a fontes de dados externas e ferramentas através de uma interface padrão. Este protocolo permite que diferentes aplicações de inteligência artificial se conectem de forma segura e consistente a bases de dados ou ferramentas de software.

- ★ 90.905
- TypeScript
- GitHub Trending · 2026-10-01

## O que você ganha
- Permite que os seus grandes modelos de linguagem (LLM) acedam com segurança a ficheiros locais, repositórios de dados e memória persistente.
- Pode conectar as suas aplicações de inteligência artificial a fontes de dados externas examinando os exemplos de servidores de referência.
- Obtém modelos prontos para desenvolver os seus próprios servidores utilizando diferentes kits de desenvolvimento de software (SDK).

## Instalação
**Instalar e iniciar o servidor Git**

```
# With uvx
uvx mcp-server-git

# With pip
pip install mcp-server-git
python -m mcp_server_git
```


## Execução
**Executar o servidor de memória**

```
npx -y @modelcontextprotocol/server-memory
```
