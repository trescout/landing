Biblioteca de programação de rede assíncrona

Asio é uma biblioteca C++ desenvolvida para operações de E/S assíncronas. Ele fornece um gateway portátil (abstração de rede) para programação de rede e tarefas de sistema de baixo nível.

  • ★ 6.090
  • C++
  • GitHub Trending · 2026-07-11

O que você ganha

  • Execute operações assíncronas de entrada e saída
  • Estabelecendo uma infraestrutura de programação de rede portátil
  • Gerenciando tarefas do sistema de baixo nível

Instalação

macOS (homebrew)
brew install asio

Como começar

Asio é uma biblioteca C++. Para começar a usá-lo, você pode visitar https://think-async.com/ ou seguir o caminho doc/index.html no arquivo que você baixou para acessar a documentação e os tutoriais da API.
