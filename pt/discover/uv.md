# Ferramenta de gerenciamento de alta velocidade para projetos Python

Desenvolvido com a linguagem de programação Rust, o uv é uma ferramenta de alta velocidade projetada para gerenciar pacotes e projetos Python. Ele oferece uma alternativa voltada para o desempenho aos gerenciadores de pacotes tradicionais (pip, pip-tools).

## O que você ganha

- Conclui as operações de gerenciamento de pacotes de 10 a 100 vezes mais rápido do que as ferramentas tradicionais.
- Linguagem de programação Baixa versões do Python para o seu computador e as organiza de acordo com os seus projetos.
- Executa sozinho as funções de ferramentas como o pip, o gerenciador de pacotes que gerencia as dependências de bibliotecas.

## Instalação

**Instalação para macOS e Linux**

```
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**instalação para janelas**

```
# On Windows.
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Execução

**Atualizando a ferramenta**

```
uv self update
```
