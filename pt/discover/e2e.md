# Automatize seus testes de ponta a ponta

Um framework de nova geração baseado em TypeScript que automatiza processos de teste de ponta a ponta (end-to-end testing) para aplicativos web e móveis. Permite que os desenvolvedores validem rapidamente as interfaces de aplicativos em diferentes plataformas.

- ★ 5.508
- TypeScript
- GitHub Trending · 2026-10-05

## O que você ganha
- Escreva testes definindo alvos em linguagem natural
- Grave ações e reutilize-as em execuções subsequentes
- Valide a interface em aplicativos web e móveis

## Instalação
**Iniciar Configuração**

```
npx e2e init
```


## Se você não programa
Configure testes automatizados com etapas escritas em linguagem natural para meu aplicativo web ou móvel usando a ferramenta de teste e crie o arquivo de configuração.
