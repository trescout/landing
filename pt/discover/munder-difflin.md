# Ambiente de escritório para agentes de inteligência artificial

Munder-Difflin é um mecanismo que permite que vários agentes de inteligência artificial trabalhem juntos em sistemas locais. Desenvolvido com TypeScript, esta ferramenta facilita o gerenciamento de sistemas de agentes autônomos que compartilham tarefas complexas em um ambiente local.

## O que você ganha

- Coordena ferramentas de IA baseadas em terminais como uma equipe autônoma.
- Ele permite que os agentes ganhem memória de longo prazo e a capacidade de enviar mensagens uns aos outros.
- Oferece a oportunidade de acompanhar os processos de trabalho dos agentes através de uma interface visual de escritório.

## Instalação

**Baixe e inicie o aplicativo**

```
git clone https://github.com/chaitanyagiri/munder-difflin.git
cd munder-difflin
npm install        # postinstall rebuilds node-pty against Electron's ABI
npm run dev        # launches the Electron app with hot reload
```

## Execução

**Criação e visualização da versão de produção**

```
npm run build      # production build via electron-vite
npm run preview    # preview the production build
```

## Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Dê aos meus agentes que trabalham no Munder Difflin a seguinte tarefa: criar uma equipe usando ferramentas existentes de inteligência artificial baseadas em terminal, distribuir tarefas por meio de um agente gerente chamado Michael e concluir todos os processos de forma autônoma, armazenando-os em uma camada de memória comum.
