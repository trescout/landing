# Ferramenta de teste de carga para servidores web

Desenvolvido em Go, o hey é uma ferramenta de teste de carga usada para medir o desempenho de servidores web. Oferece uma alternativa moderna e rápida à clássica ferramenta de benchmark ApacheBench (ab).

## O que você ganha

- Envia facilmente carga de requisições para aplicações web.
- Define o número de workers simultâneos e a quantidade total de requisições.
- Suporta endpoints HTTP/2 e relata os resultados.
