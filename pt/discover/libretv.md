# Crie uma plataforma de busca e visualização de vídeos online

LibreSpark/LibreTV é um projeto de software baseado em TypeScript que permite configurar um site de filmes e séries em um minuto usando métodos como Docker. Ele oferece uma infraestrutura que permite aos usuários criar rapidamente suas próprias plataformas de conteúdo.

- ★ 18.500
- TypeScript
- GitHub Trending · 2026-10-16

## O que você ganha

- pesquise filmes e séries de diferentes fontes em um só lugar
- assista a transmissões de televisão pela internet nos formatos m3u e m3u8
- salve seu histórico de visualização e onde parou no seu navegador

## Instalação

**instalação rápida com docker**

```
docker compose pull && docker compose up -d
```

## Execução

**execução compilando a partir da fonte**

```
npm install
PASSWORD=your-password npm run build
PASSWORD=your-password npm start   # 监听 8080
```
