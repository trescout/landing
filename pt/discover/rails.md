# Framework de desenvolvimento de aplicações web orientadas a banco de dados

Ruby on Rails é um framework de aplicação web baseado na arquitetura Model-View-Controller (Modelo-Visão-Controlador), utilizado para desenvolver aplicações web orientadas a banco de dados. O seu objetivo é padronizar os processos, fornecendo aos desenvolvedores todas as ferramentas necessárias em um só lugar.
