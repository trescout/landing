# Espaço de trabalho para agentes de codificação de inteligência artificial

O PI-Desktop é um agente de codificação de inteligência artificial desenvolvido com o princípio de trabalho local-first. Com uma arquitetura baseada em Electron (framework de desenvolvimento de aplicações desktop) e Rust (linguagem de programação de sistemas), oferece um ambiente de desenvolvimento de software personalizável onde os usuários podem instalar seus próprios plugins.

- ★ 1.990
- TypeScript
- GitHub Trending · 2026-09-10

## O que você ganha
- Gerencie diferentes modelos de inteligência artificial a partir de uma única interface.
- Controle as permissões de edição de arquivos e execução de comandos do agente.
- Personalize o ambiente de desenvolvimento com plugins e capacidades.

## Instalação
**Compilando a partir do código-fonte**

```
git clone https://github.com/vastsa/PI-Desktop.git
cd PI-Desktop

pnpm install

cargo build -p host-core
pnpm build:js

pnpm dev
```


## Execução
**Iniciar em modo de desenvolvimento**

```
pnpm dev
```


## Se você não programa
Estou trabalhando no PI-Desktop. Dou-lhe permissão para analisar o código em meus projetos locais, editar arquivos e executar comandos no terminal. Ao realizar as operações, quero que você crie um plano de execução primeiro, obtenha minha aprovação para alterações críticas e relate todo o processo de forma transparente. Ao escrever código, mantenha-se fiel à estrutura atual do projeto e, em caso de erro, prossiga realizando os testes necessários.
