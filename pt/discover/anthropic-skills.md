# Desenvolva habilidades dinâmicas para Claude

Habilidades Antrópicas; É o repositório oficial de pacotes de habilidades que Claude carrega dinamicamente para ter um melhor desempenho em missões específicas. Essas pastas de instruções, scripts e recursos ensinam Claude como realizar determinadas tarefas.

## O que você ganha
- Habilidades prontas e formais para Claude.
- Carregamento dinâmico: entra em ação somente quando necessário.
- Totalmente compatível com o padrão Agentskills.

## Como usar?
Você define a habilidade relevante como uma habilidade para Claude (por exemplo, Claude Code ou Cowork); Desta forma, aumenta o seu desempenho em tarefas especiais.

## Como instalar, como usar?
**Adicionar Marketplace (Código Claude)**

```
/plugin marketplace add anthropics/skills
```

**Desenvolva suas habilidades documentais**

```
/plugin install document-skills@anthropic-agent-skills
```
