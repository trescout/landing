Previsão de IA para séries temporais

O modelo Time Series Foundation, desenvolvido pelo Google Research, oferece uma estrutura pré-treinada para previsão de séries temporais. O modelo foi projetado para fornecer recursos preditivos gerais em diferentes conjuntos de dados.

O que você ganha

  • Previsão rápida com modelo base pré-treinado
  • Suporte para comprimento de contexto de 16k
  • Adaptação a diferentes conjuntos de dados com estrutura flexível

Instalação

Instalação via PyPI
pip install timesfm[torch]
# Or with Flax
pip install timesfm[flax]
# And when XReg is needed
pip install timesfm[xreg]
instalação local
git clone https://github.com/google-research/timesfm.git
    cd timesfm
