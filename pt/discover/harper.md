# Verificador gramatical off-line com foco na privacidade

Harper oferece um verificador gramatical offline e voltado para a privacidade, desenvolvido com a linguagem Rust. Esta ferramenta de código aberto visa criar uma alternativa segura e de alto desempenho em processos de análise de texto.

- ★ 14.110
- Rust
- GitHub Trending · 2026-07-24

## Atualizar
- 2 de agosto de 2026: Star 12.510 → 14.110, versão mais recente v2.7.0 (28 de julho de 2026).

## O que você ganha
- Verifica rapidamente o texto em milissegundos
- Protege a privacidade processando seus dados localmente
- Oferece alto desempenho com baixo uso de memória

## Instalação
**macOS (homebrew)**

```
brew install harper
```


## Como começar
- Fonte oficial →
Para começar a usar a ferramenta Harper, você pode visitar o site oficial writewithharper.com. Você pode concluir a instalação revisando os guias de integração adequados para o editor de texto que você usa, como Visual Studio Code, Neovim, Helix, Emacs ou Zed, na seção de documentação do site.
