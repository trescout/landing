# Gerencie processos de dados com Python

Prefect é uma estrutura de orquestração de fluxo de trabalho usada para criar pipelines de dados baseados em Python. Projetada para desenvolver processos de dados resilientes, esta ferramenta permite o gerenciamento e o monitoramento de fluxos de trabalho de dados complexos.

- ★ 23.774
- Python
- GitHub Trending · 2026-07-13

## O que você ganha
- Movendo pipelines de dados para o nível de produção
- Tratamento de erros e nova tentativa automática
- Monitore visualmente os fluxos de trabalho

## Instalação
**Instalação via pip**

```
pip install -U prefect
```

**Instalação com UV**

```
uv add prefect
```


## Execução
**Iniciando o servidor**

```
prefect server start
```
