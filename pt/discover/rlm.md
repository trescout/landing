# Infraestrutura para modelos recursivos de inteligência artificial

Desenvolvido para modelos de linguagem recursiva, rlm é uma biblioteca de inferência plug-and-play que oferece suporte a diferentes sandboxes. Esta ferramenta baseada em Python padroniza processos complexos de modelos de linguagem, tornando-os mais fáceis de integrar em diferentes sistemas.

- ★ 5.343
- Python
- GitHub Trending · 2026-06-18

## O que você ganha
- Gerenciamento de contexto de comprimento infinito
- Arquitetura plug-and-play executada em um ambiente de código
- Integração segura com diferentes ambientes sandbox

## Instalação
**Instalação rápida**

```
pip install rlms
```

**Instalação manual**

```
curl -LsSf https://astral.sh/uv/install.sh | sh
uv init && uv venv --python 3.12  # change version as needed
uv pip install -e .
```


## Execução
**Teste rápido**

```
make quickstart
```


## Se você não programa
Usando a biblioteca RLM, construa uma estrutura que permita ao modelo de linguagem decompor a entrada, analisá-la e fazer chamadas recursivas dentro de si mesmo. Ao instanciar a classe RLM, defina a configuração do modelo que você usa como backend e permita que o modelo interaja com o ambiente de código para resolver tarefas complexas.
