# Infraestrutura para modelos recursivos de inteligência artificial

Desenvolvido para modelos de linguagem recursiva, rlm é uma biblioteca de inferência plug-and-play que oferece suporte a diferentes sandboxes. Esta ferramenta baseada em Python padroniza processos complexos de modelos de linguagem, tornando-os mais fáceis de integrar em diferentes sistemas.

## Instalação

**Instalação rápida**

```

```

**Instalação manual**

```

```
