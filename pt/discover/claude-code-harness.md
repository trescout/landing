# Desenvolvimento Disciplinado com Claude Code

Claude Code Harness introduz a disciplina de planejar, fazer, revisar e entregar, reduzindo a tendência de desmoronamento do trabalho bruto do agente. Ele evita que os planos se percam no chat, limita os testes e garante uma produção de código mais consistente. Embora Claude seja centrado em código, ele também oferece caminhos de integração para Codex e OpenCode.

## O que você ganha
- O agente não se dispersa; O plano é mantido em registro.
- A qualidade é aumentada limitando os testes.
- Resultados mais previsíveis e consistentes são obtidos.

## Como começar
Integrado ao Claude Code com instalação no repositório; em seguida, implementa o ciclo planejar, fazer e revisar.

## Como instalar, como usar?
**Código Claude · marketplace + instalação**

```
/plugin marketplace add Chachamaru127/claude-code-harness
/plugin install claude-code-harness@claude-code-harness-marketplace
```

**Iniciar a instalação**

```
/harness-setup
```

**Fluxo: planejar → trabalhar → revisar → publicar**

```
/harness-plan
/harness-work
/harness-review
/harness-release
```
