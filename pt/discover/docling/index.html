Docagem

Docling é uma biblioteca Python que converte formatos de documentos complexos em texto limpo ou dados estruturados que modelos generativos de IA podem processar. Facilita o uso de dados em aplicações de inteligência artificial, analisando diferentes tipos de arquivos, como PDF, Word e HTML.
