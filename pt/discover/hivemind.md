# Memória central para agentes de inteligência artificial

Desenvolvido pela Activeloop, o Hivemind oferece uma camada de memória centralizada para todos os agentes de inteligência artificial. Essa estrutura baseada em TypeScript permite que diferentes agentes compartilhem dados e se comuniquem por meio de um pool de inteligência comum.

- ★ 1.526
- TypeScript
- GitHub Trending · 2026-06-11

## O que você ganha
- Ele cria uma camada comum de memória e coordenação para todos os seus agentes de IA.
- Ele transforma automaticamente padrões de solução bem-sucedidos de sessões anteriores em habilidades reutilizáveis.
- Reduz custos ao permitir que os agentes atinjam a meta usando menos tokens e menos etapas.

## Instalação
**Configuração geral**

```
npm install -g @deeplake/hivemind && hivemind install
```


## Execução
**Verificação de status**

```
hivemind status
```


## Se você não programa
Quero criar uma camada de memória comum entre meus agentes de IA usando a ferramenta Hivemind. Depois de concluir a instalação com o comando npm install -g @deeplake/hivemind && hivemind install, explique passo a passo como meus agentes podem compartilhar dados históricos da sessão com mais eficiência e como converter automaticamente esses dados em arquivos de habilidades.
