Keycloak oferece soluções de gerenciamento de identidade e acesso de código aberto para aplicativos e serviços modernos. Esta plataforma baseada em Java é usada para padronizar processos centralizados de autenticação e autorização.

## Instalação

**Iniciar container de desenvolvimento local**

```
docker run --name keycloak -p 127.0.0.1:8080:8080 -e KC_BOOTSTRAP_ADMIN_USERNAME=admin -e KC_BOOTSTRAP_ADMIN_PASSWORD=change_me quay.io/keycloak/keycloak:latest start-dev
```

## Execução

**Acessar interface local**

```
http://localhost:8080
```
