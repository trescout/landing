# Gerenciamento central de identidade para seus aplicativos

Keycloak oferece soluções de gerenciamento de identidade e acesso de código aberto para aplicativos e serviços modernos. Esta plataforma baseada em Java é usada para padronizar processos centralizados de autenticação e autorização.

## O que você ganha
- Padroniza os processos de autenticação do usuário.

- Aumenta sem esforço a segurança do aplicativo.

## Instalação
**Pegue a imagem oficial**

```
docker pull quay.io/keycloak/keycloak
```


## Execução
**Comece no modo de desenvolvimento**

```
docker run -p 8080:8080 -e KC_BOOTSTRAP_ADMIN_USERNAME=admin -e KC_BOOTSTRAP_ADMIN_PASSWORD=admin quay.io/keycloak/keycloak start-dev
```
