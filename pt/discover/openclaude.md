# Gerenciamento de inteligência artificial via terminal

O OpenClaude é uma interface de IA flexível que pode rodar em qualquer hardware e utilizar diferentes fontes de dados. Desenvolvido na linguagem TypeScript, este projeto de código aberto permite que os usuários executem modelos de IA personalizados em sua própria infraestrutura.

## O que você ganha

- Combina modelos de IA baseados em nuvem e locais em uma única interface.
- Executa tarefas como gerenciamento de arquivos, busca e codificação a partir do terminal.
- Configura facilmente diferentes provedores com uma instalação guiada amigável.

## Instalação

**Instalação geral**

```
npm install -g @gitlawb/openclaude@latest
```

## Execução

**Iniciando a ferramenta**

