Editor de vídeo AI para macOS

Palmier Pro foi desenvolvido como um editor de vídeo que roda no sistema operacional macOS e oferece ferramentas de edição com suporte de inteligência artificial. Esta aplicação, escrita em linguagem Swift, tem como objetivo combinar fluxos de trabalho baseados em inteligência artificial com desempenho de sistema local.

O que você ganha

  • Produção de vídeo e visual com inteligência artificial na timeline
  • Integração com Claude, Codex e Cursor via MCP
  • Desempenho nativo do Swift para dispositivos Apple Silicon

Como começar

Baixe e instale o aplicativo Palmier Pro em seu dispositivo macOS usando o link de download na página oficial do GitHub. Depois de executar o aplicativo, você pode fazer login para usar ferramentas de inteligência artificial ou configurar integrações MCP no menu Ajuda do aplicativo.
