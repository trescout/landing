- Exibe conteúdo do Twitter sem executar JavaScript

- É muito mais rápido e leve que a interface padrão do Twitter

## Instalação

**Instalação com Docker**

```
docker run -v $(pwd)/nitter.conf:/src/nitter.conf -d --network host zedeus/nitter:latest
```

**Lançando com Docker Compose**

```
docker-compose up -d
```
