# Transforme repositórios do GitHub em diagramas interativos

O Gitdiagram é uma ferramenta que visualiza estruturas de arquivos complexas e relações de código em repositórios do GitHub. Ele cria diagramas interativos que facilitam a compreensão da arquitetura de projetos de software.

- ★ 16.568
- TypeScript
- GitHub Trending · 2026-09-19

## O que você ganha
- Compreenda rapidamente a arquitetura visualizando estruturas de código complexas.
- Navegue até o arquivo de código-fonte correspondente clicando nos componentes do diagrama.
- Exporte os diagramas gerados em formato de imagem ou texto.

## Instalação
**Preparação e inicialização do ambiente local**

```
git clone https://github.com/ahmedkhaleel2004/gitdiagram.git
cd gitdiagram
bun install
cp .env.example .env
bun run dev
```

**Validação e compilação do projeto**

```
bun run lint
bun run typecheck
bun run test
bun run build
```


## Se você não programa
Usando a ferramenta GitDiagram, crie a arquitetura do repositório GitHub que estou analisando como um gráfico em nível de sistema. Prepare um diagrama interativo que mostre claramente os componentes na estrutura do código, as relações entre eles e a lógica de funcionamento. Ao criar o diagrama, resuma o funcionamento geral do sistema com base nos caminhos dos arquivos e nos módulos importantes.
