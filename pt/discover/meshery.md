# Gerencie infraestruturas nativas da nuvem

Meshery é uma plataforma de gerenciamento de malha de serviço projetada para o gerenciamento de infraestruturas nativas em nuvem. A plataforma permite que processos de configuração, gerenciamento do ciclo de vida e análise de desempenho em ambientes de nuvem complexos sejam realizados a partir de um único centro.

- ★ 11.669
- TypeScript
- GitHub Trending · 2026-06-15

## O que você ganha
- Gerenciamento centralizado de infraestrutura e aplicativos baseados em Kubernetes
- Oportunidade de design visual sem lidar com arquivos YAML complexos
- Operação consistente em vários provedores de nuvem e clusters

## Instalação
**Script Bash**

```
curl -L https://meshery.io/install | bash -
```


## Execução
**CLI**

```
mesheryctl system start
```
