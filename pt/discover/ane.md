# Treinamento de IA no Apple Neural Engine

Desenvolvido pela Maderix, o ANE permite que o treinamento de redes neurais seja realizado no Apple Neural Engine por meio de interfaces de programação de aplicações privadas (APIs privadas) obtidas por engenharia reversa. Este estudo possibilita a utilização direta de hardware Apple em processos de treinamento de modelos de inteligência artificial.

## Como começar
Este projeto é uma pesquisa que visa treinar redes neurais diretamente em hardware Apple. Ao baixar os arquivos do projeto do repositório oficial no GitHub para o seu computador, você pode examinar como as APIs especiais obtidas por engenharia reversa são usadas e conduzir seus próprios experimentos.
