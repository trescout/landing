# Automação de dispositivos móveis com inteligência artificial

O Mobile-mcp é um servidor de Protocolo de Contexto de Modelo (Model Context Protocol) que realiza automação e raspagem de dados em dispositivos móveis e simuladores. Esta ferramenta permite que modelos de inteligência artificial interajam diretamente com as plataformas iOS e Android para executar tarefas.

- ★ 8.439
- TypeScript
- GitHub Trending · 2026-09-27

## O que você ganha
- Realizar testes de aplicativos em dispositivos iOS e Android
- escanear automaticamente elementos da tela e extrair dados estruturados
- gerenciar emuladores e simuladores através de uma única interface

## Se você não programa
Usando o servidor do Protocolo de Contexto do Modelo (Model Context Protocol) que se comunica com as ferramentas de desenvolvimento móvel no meu computador, liste os aplicativos nos dispositivos móveis conectados e escaneie os elementos na tela.
