# Aplicativo multiplataforma com um único código

Desenvolvido pelo Google, o Flutter permite criar rapidamente interfaces de usuário para plataformas móveis, web e desktop usando uma única base de código. Esta estrutura de código aberto, baseada na linguagem de programação Dart, é amplamente preferida para o desenvolvimento de aplicativos visualmente ricos e de alto desempenho.

- Suporte móvel, web e desktop com uma única base de código

- Gráficos de alto desempenho acelerados por hardware

## Instalação
**macOS (homebrew)**

```
brew install --cask flutter
```


## Execução
**Verifique os controles ambientais**

```
flutter doctor
```

**Criar e executar novo projeto**

```
flutter create my_app
cd my_app
flutter run
```
