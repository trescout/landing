# Coleção de comandos para modelos de inteligência artificial

togg53192-cmd/jailbreaks oferece uma coleção de prompts de sistema, bloqueios de personalidade e políticas de espaço de trabalho destinados a contornar as restrições de segurança de modelos de inteligência artificial. Este trabalho é uma compilação técnica que visa alterar os princípios operacionais de vários modelos de pesos abertos (open-weight) e fechados.

## O que você ganha

- Oferece prompts de sistema específicos para diferentes modelos de IA
- Contém bloqueios de personalidade e políticas de espaço de trabalho
- Permite que pesquisadores examinem os comportamentos dos modelos

## Como começar

Clique no arquivo do modelo de seu interesse na lista no GitHub para visualizar seu conteúdo. Em seguida, copie todo o texto e cole-o no campo de prompts de sistema ou instruções personalizadas da ferramenta de IA que você está usando. Se estiver usando ferramentas locais como o Ollama, você pode adicionar o conteúdo do arquivo diretamente aos campos de configuração.
