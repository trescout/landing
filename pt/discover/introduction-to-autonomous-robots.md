# Entre no mundo da robótica autônoma

O projeto Introdução aos Robôs Autônomos apresenta os princípios básicos e estruturas algorítmicas de sistemas robóticos com uma abordagem acadêmica. Este recurso, preparado em linguagem TeX, fornece orientação técnica sobre movimentação autônoma e projeto de sistemas.
