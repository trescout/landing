# Sistema que coordena agentes de inteligência artificial

Swarm Forge, escrito na linguagem Clojure, é uma ferramenta para coordenar vários agentes de IA a partir de um único centro. O software oferece uma estrutura simples para gerenciar processos complexos onde diferentes agentes devem trabalhar de forma colaborativa.

- ★ 2.897
- Clojure
- GitHub Trending · 2026-08-08

## O que você ganha
- Gerencia vários agentes de inteligência artificial em um único centro
- Monitore agentes simultaneamente com o multiplexador de terminal Tmux
- Oferece fluxos de trabalho personalizáveis específicos do projeto

## Instalação
**Baixe e prepare o branch de trabalho**

```
BRANCH=four-pack
curl -L "https://github.com/unclebob/swarm-forge/archive/refs/heads/${BRANCH}.tar.gz" | tar -xz --strip-components=1
```


## Execução
**Inicialização do sistema**

```
./swarm
```


## Se você não programa
Você faz parte de uma equipe de desenvolvimento de software. Conclua a tarefa dada a você seguindo as regras do sistema Swarm Forge e os arquivos de configuração no diretório do projeto. Trabalhe em colaboração com outros agentes enquanto executa suas tarefas, use árvores de trabalho Git e mantenha a qualidade do código, a testabilidade e os padrões de arquitetura aderindo às definições de função estabelecidas.
