# Auditoria de segurança automatizada com inteligência artificial

O security-audit-skill, desenvolvido pela Cloudflare, é um pacote de habilidades (skill) que permite que agentes de codificação realizem auditorias de segurança em várias etapas. Ele automatiza os padrões de segurança nos processos de desenvolvimento de software, gerando descobertas legíveis por máquina e verificadas de forma independente.

- ★ 11.472
- JavaScript
- GitHub Trending · 2026-09-18

## O que você ganha
- Realiza varredura de segurança em várias etapas na base de código
- Confirma as descobertas com verificação independente
- Gera relatórios de segurança padronizados

## Instalação
**instalação local**

```
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit
```

**Instalação geral**

```
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit \
  --global
```


## Se você não programa
Inicie uma auditoria de segurança abrangente para esta base de código. Mapeie a arquitetura para identificar pontos de entrada e, em seguida, execute uma varredura em várias etapas para detectar vulnerabilidades de segurança. Submeta cada candidato a vulnerabilidade encontrado a um processo de verificação independente, classificando-o como verificado, a ser verificado ou rejeitado. Relate os resultados em um formato estruturado e documente todas as descobertas de acordo com os padrões de segurança do projeto.
