# Memória persistente para agentes de inteligência artificial

Loopx é um kernel de estado leve desenvolvido para equipes de agentes de inteligência artificial de longo prazo. Funciona de forma compatível com agentes de codificação (Codex, Claude Code) e padroniza processos como rastreamento de tarefas, gerenciamento de cotas e transferência de trabalho verificável.

## O que você ganha
- Padroniza o rastreamento de alvos e o gerenciamento de cotas em missões de longo prazo.
- Ele permite a transferência verificável de trabalho entre diferentes agentes de IA.
- Armazena histórico de tarefas e evidências em uma estrutura organizada.

## Instalação
**Instalação direta**

```
curl -fsSL https://raw.githubusercontent.com/huangruiteng/loopx/main/scripts/install-from-github.sh | bash
export PATH="$HOME/.local/bin:$PATH"
loopx doctor
```


## Execução
**Iniciando o projeto**

```
cd /path/to/your-project
loopx connect
loopx status
```


## Se você não programa
Trabalharemos em um projeto de longo prazo com você. Quero gerenciar nossas tarefas, metas e logs de progresso com o bean de estado LoopX. À medida que você trabalha, verifique o status atual em cada etapa, registre evidências do trabalho concluído e permaneça dentro dos limites da cota determinando a próxima tarefa (fazer). Deixe um rastro verificável por meio do LoopX ao delegar tarefas ou passar para uma nova fase.
