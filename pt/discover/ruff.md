# Linter e formatador rápido para Python

O Ruff é um linter e formatador de código Python extremamente rápido, desenvolvido na linguagem de programação Rust. Ele é usado em processos de desenvolvimento de software para melhorar a qualidade do código e acelerar as operações de formatação.

## O que você ganha

- Funciona dezenas de vezes mais rápido em comparação com as ferramentas existentes
- Combina operações de linting e formatação em uma única ferramenta
- Oferece suporte a correção automática de erros em projetos Python

## Instalação

**instalar com pip**

```
pip install ruff
```

**instalação com uv**

```
uv tool install ruff@latest
```

## Execução

**executar linting de código**

```
ruff check
```

**executar formatação de código**

```
ruff format
```
