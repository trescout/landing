# Editor de vídeo para desktop de código aberto

Clypra é um aplicativo editor de vídeo de código aberto desenvolvido usando Tauri, React e TypeScript. O software tem como objetivo oferecer recursos avançados encontrados em ferramentas pagas de edição de vídeo como alternativa gratuita.

- ★ 2.965
- TypeScript
- GitHub Trending · 2026-07-15

## O que você ganha
- Processamento de vídeo de alto desempenho acelerado por hardware
- Linha do tempo multipista com precisão de quadro
- Legendagem e edição automáticas com tecnologia de IA

## Instalação
**Instalação com Homebrew no macOS**

```
brew install AIEraDev/tap/clypra
```
