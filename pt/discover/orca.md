# Gerencie vários agentes de IA

Desenvolvido pela Stablyai, o Orca oferece um ambiente de desenvolvimento de agentes que permite gerenciar vários agentes de inteligência artificial simultaneamente. Usando sua assinatura, os usuários podem executar vários agentes de codificação em plataformas desktop e móveis.

## O que você ganha

- Execute vários agentes de IA em diferentes espaços de trabalho simultaneamente.
- Monitore e direcione seus agentes remotamente através do aplicativo móvel.
- Gerencie projetos de dentro do aplicativo com GitHub e integração linear.

## Instalação

**configuração para macOS**

```
brew install --cask stablyai/orca/orca
```

**Instalação para Arch Linux**

```
yay -S stably-orca-bin
```
