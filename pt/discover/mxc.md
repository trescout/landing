# Isolamento de sistema em camadas baseado em políticas com Rust

Desenvolvido pela Microsoft, MXC é uma solução de isolamento e contenção em camadas baseada em políticas, escrita em linguagem Rust. Ele foi projetado para limitar com segurança os recursos do sistema e aumentar a segurança dos aplicativos.

## O que você ganha

- Executa código não confiável com segurança em ambientes isolados.
- Controla o acesso a arquivos, redes e interfaces com políticas baseadas em JSON.
- Ele oferece vários back-ends de isolamento em Windows, Linux e macOS.

## Instalação

**Compilando no Linux**

```
./build.sh
```

**Crie no macOS**

```
./build-mac.sh
```

## Execução

**Executando com binário nativo**

```
wxc-exec.exe config.json
```
