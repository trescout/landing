# Biblioteca de prompts para modelos de inteligência artificial

O Prompts.chat é uma plataforma de código aberto onde os usuários compartilham e descobrem prompts criados para modelos de inteligência artificial. Esta ferramenta, que você pode hospedar em seu próprio servidor para uso corporativo, permite gerenciar bibliotecas de prompts com foco em privacidade.

## O que você ganha
- Amplo arquivo de prompts compatível com modelos modernos de inteligência artificial
- Possibilidade de hospedagem em servidor próprio para necessidades corporativas
- Livro didático interativo gratuito sobre engenharia de prompts

## Instalação
**Início rápido**

```
npx prompts.chat new my-prompt-library
cd my-prompt-library
```

**Instalação manual**

```
git clone https://github.com/f/prompts.chat.git
cd prompts.chat
npm install && npm run setup
```


## Execução
**Iniciar a interface de linha de comando**

```
npx prompts.chat
```


## Se você não programa
Você é um especialista em inteligência artificial. Use as técnicas da biblioteca prompts.chat para criar os prompts mais adequados aos objetivos do usuário. Divida tarefas complexas em partes, aplique o método de pensamento passo a passo e forneça o contexto necessário para que o modelo obtenha o melhor resultado.
