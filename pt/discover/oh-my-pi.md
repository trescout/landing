# Codificação suportada por inteligência artificial no terminal

Oh-my-pi é um agente de codificação de inteligência artificial que roda em um ambiente de terminal e automatiza processos de edição de código. A ferramenta visa otimizar fluxos de trabalho de desenvolvimento de software com recursos como protocolo de servidor de linguagem (LSP), integração de navegador e gerenciamento de subagentes.

## O que você ganha

- Ele automatiza os processos de edição de código trazendo recursos IDE para o terminal.
- Com integração LSP, ele realiza operações como renomeação e rastreamento de referência sem erros.
- Ele resolve problemas no local interagindo diretamente com ferramentas de depuração.

## Instalação

**Instalação para macOS e Linux**

```
curl -fsSL https://omp.sh/install | sh
```

**Instalação através deste**

```
bun install -g @oh-my-pi/pi-coding-agent
```

## Execução

**Configurando complementos de shell**

```
# zsh — add to ~/.zshrc (or write the output into a file on your $fpath)
eval "$(omp completions zsh)"

# bash — add to ~/.bashrc
eval "$(omp completions bash)"

# fish
omp completions fish > ~/.config/fish/completions/omp.fish
```
