# Ferramenta de controle de desktop para agentes de inteligência artificial

Desenvolvido pelo Vercel Labs, o agent-desktop é uma interface de linha de comando (CLI) que permite que agentes de inteligência artificial leiam e gerenciem aplicativos de desktop através da árvore de acessibilidade do sistema operacional. Escrita em Rust, esta ferramenta visa aprimorar as capacidades de uso de computador (computer use) dos agentes.

## O que você ganha

- Lê aplicativos de desktop através da árvore de acessibilidade do sistema operacional
- Realiza ações em elementos sem a necessidade de correspondência de pixels
- Gera respostas rápidas e estruturadas em formato JSON

## Instalação

**Instalar com o gerenciador de pacotes**

```
npm install -g agent-desktop
agent-desktop version
```

**Adicionar habilidade**

```
npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop
```
