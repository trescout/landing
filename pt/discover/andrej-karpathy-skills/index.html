Descobrir · GitHub · Andrej Karpathy Skills

Discipline seu assistente de codificação de IA

Com base nas observações de Andrej Karpathy sobre erros encontrados ao codificar com grandes modelos de linguagem (LLM), CLAUDE.md visa melhorar o desempenho do Claude Code, uma ferramenta de programação suportada por inteligência artificial. Este arquivo de configuração serve como um guia para os desenvolvedores obterem saída de código mais consistente e livre de erros de inteligência artificial.

  • ★ 205.391
  • GitHub Trending · 2026-08-23

O que você ganha

  • Impede que a IA faça suposições incorretas
  • Evita complexidade desnecessária do código
  • Fornece apenas alterações direcionadas e limpas

Instalação

Adicionar ao novo projeto
curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md

Se você não programa

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

A partir de agora, aplique os quatro princípios básicos sugeridos por Andrej Karpathy ao codificar: Pense antes de codificar, explique suas suposições e questione as incertezas, evite complexidades desnecessárias escolhendo sempre a solução mais simples, faça alterações apenas nas partes solicitadas e prossiga definindo critérios de sucesso testáveis em vez de dizer 'executar' o trabalho.
