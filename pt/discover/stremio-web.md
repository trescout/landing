# Reprodução de mídia via navegador

O Stremio é um aplicativo de media player que reúne diferentes provedores de conteúdo em uma única interface. Esta versão baseada na web permite que os usuários assistam a séries e filmes pelo navegador sem a necessidade de qualquer instalação.

- JavaScript
- GitHub Trending · 2026-09-07

## O que você ganha
- Reúne diferentes provedores de conteúdo em uma única interface
- Sincroniza o histórico de visualização e a biblioteca entre dispositivos
- Permite a transmissão de imagem para a televisão via Chromecast

## Instalação
**Configuração do ambiente de desenvolvimento local**

```
pnpm install
pnpm start
```

**Configuração de contêiner com Docker**

```
docker build -t stremio-web .
docker run -p 8080:8080 stremio-web
```
