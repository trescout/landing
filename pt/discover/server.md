# Servidor de música digital de código aberto

Music Assistant é um gerenciador de biblioteca de mídia de código aberto que combina diferentes serviços de streaming digital e alto-falantes conectados em uma única interface. Este software de servidor baseado em Python permite a criação de um sistema central de gerenciamento de música em dispositivos em operação constante.

## O que você ganha
- Combina diferentes serviços de transmissão digital em uma interface
- Permite controlar centralmente todos os alto-falantes conectados
- Ele fornece suporte de automação trabalhando totalmente integrado ao Home Assistant

## Instalação
**janela de encaixe**

```
docker run --network host --privileged -v ma-data:/data ghcr.io/music-assistant/server
```
