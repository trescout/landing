# Espaço de trabalho unificado para agentes de IA

holaOS é um espaço de trabalho de código aberto que combina diferentes agentes de inteligência artificial (Claude Code, Codex) com suas ferramentas, aplicativos e arquivos em uma memória comum. Com mais de 100 integrações e suporte ao Model Link Protocol (MCP), ele permite que os usuários gerenciem seus próprios modelos (BYOK) ou modelos integrados em uma única interface.

- ★ 9.653
- TypeScript
- GitHub Trending · 2026-08-14

## O que você ganha
- Ele executa diferentes agentes como Claude Code e Codex em uma única interface com memória compartilhada.
- Um clique conecta-se a mais de 50 ferramentas de negócios populares, como Gmail, Notion e Slack.
- Você pode usar modelos de IA integrados ou adicionar suas próprias chaves de API.

## Instalação
**Comando de instalação rápida**

```
curl -fsSL https://raw.githubusercontent.com/holaboss-ai/holaOS/refs/heads/main/scripts/install.sh | bash -s -- --launch
```


## Execução
**Iniciando o ambiente de desenvolvimento**

```
npm run desktop:dev
```
