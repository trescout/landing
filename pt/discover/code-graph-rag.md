# Consulte seu repositório de código com inteligência artificial

Code-graph-rag combina gráficos de conhecimento e geração assistida por busca (RAG) para compreender e consultar estruturas complexas em grandes repositórios de código. Ele permite que os desenvolvedores analisem e editem bases de código em diferentes linguagens com a ajuda da inteligência artificial.

## O que você ganha

- Veja relacionamentos complexos transformando a base de código em um gráfico de conhecimento
- Obtenha respostas sobre a estrutura do código fazendo perguntas em linguagem natural
- Faça alterações precisas no código com ferramentas estruturadas de pesquisa e edição

## Instalação

**Instalação com gerenciador de pacotes**

```
uv tool install "code-graph-rag[treesitter-full,semantic]"
```

**Método de instalação alternativo**

```
pipx install "code-graph-rag[treesitter-full,semantic]"
```

## Execução

**Iniciando o banco de dados**

```
cgr daemon up
```

**Analisar e consultar o armazém**

```
cgr start --repo-path /path/to/repo --update-graph
```
