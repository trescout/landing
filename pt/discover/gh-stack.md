# Gerenciar solicitações pull em massa

Desenvolvido pelo GitHub, gh-stack é uma ferramenta de linha de comando que facilita a criação e o gerenciamento de solicitações pull empilhadas durante o processo de desenvolvimento de software. O objetivo é acelerar o processo de revisão, dividindo alterações complexas de código em partes pequenas e independentes.

## O que você ganha

- Quebra grandes alterações de código em partes pequenas e gerenciáveis
- Organiza automaticamente dependências entre pull requests
- Facilita as operações de rebase para manter as ramificações da pilha atualizadas

## Instalação

**Instalando a ferramenta**

```
gh extension install github/gh-stack
```

**Ativar suporte de IA**

```
gh skill install github/gh-stack
```

## Execução

**Iniciando uma nova pilha**

```
gh stack init
```

**Adicionando uma nova camada à pilha**

```
gh stack add api-endpoints
```
