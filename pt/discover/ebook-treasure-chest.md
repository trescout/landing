# Biblioteca de e-books digitais em várias categorias

jbiaojerry/ebook-treasure-chest é um projeto de biblioteca digital que reúne links de download de e-books em várias categorias. O projeto tem como objetivo fornecer acesso a conteúdos de aplicativos de leitura populares (帆书, 微信读书, 京东读书, 喜马拉雅).

## O que você ganha

- Obtenha acesso centralizado a links de download de milhares de e-books.
- Você pode baixar os livros em três opções de formato diferentes: epub, mobi e azw3.
- Graças à interface de busca, você pode encontrar obras instantaneamente por título, autor ou categoria.

## Como começar

Você não precisa de uma linha de comando para aproveitar o projeto. Visite a página da web oficial hospedada na plataforma de hospedagem de código GitHub e digite o nome do livro ou o autor na caixa de pesquisa. Se preferir, você pode navegar pelos arquivos de categoria para acessar o link de download do e-book desejado.
