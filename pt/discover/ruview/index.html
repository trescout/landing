Obtenha inteligência espacial com sinais WiFi

RuView fornece inteligência espacial em tempo real, rastreamento de sinais vitais e detecção de presença sem câmera, usando sinais WiFi comuns. É um projeto de código aberto desenvolvido com Rust.

O que isso oferece?

  • Detecção de presença e movimento sem usar câmera.
  • Monitoramento de sinais vitais (respiração e pulso).
  • Inteligência espacial em tempo real.

Nota de responsabilidade

É uma tecnologia que detecta a presença/movimento de pessoas. O uso cuidadoso e legal em termos de privacidade e consentimento é de sua responsabilidade.

Como instalar, como usar?

🤖 Cole isto no seu agente (Claude Code · Codex · Antigravity)

Para experimentá-lo sem hardware, execute 'docker pull ruvnet/wifi-densepose:latest' no terminal, comece com 'docker run -p 3000:3000 ruvnet/wifi-densepose:latest' e abra http://localhost:3000 no navegador; Isso mostra a interface de detecção de movimento/presença do RuView com sinais WiFi com dados simulados.

Extraia a imagem do Docker
docker pull ruvnet/wifi-densepose:latest
Execute com Docker (simulação, sem necessidade de hardware)
docker run -p 3000:3000 ruvnet/wifi-densepose:latest
Pacote Python (PyPI)
pip install ruview
