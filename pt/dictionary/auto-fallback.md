# O que é Auto-fallback?

Quando ocorre um erro em um sistema ou o método principal falha, o sistema muda automaticamente para um método mais seguro ou alternativo.

## Definição
O fallback automático garante que o sistema não 'desista'. Por exemplo, quando o seu modelo de IA mais avançado não responde, o sistema muda automaticamente para um modelo mais rápido, porém mais simples, para concluir o processo. Esta é uma medida de segurança crítica para garantir que a experiência do usuário continue ininterrupta.

## Como funciona
Uma regra 'se não funcionar, faça isto' está incorporada no software. O sistema verifica constantemente o status e ativa o método de backup sempre que o método principal retorna um código de erro.

## Onde é usado
É utilizado em serviços de inteligência artificial, conexões de rede e gerenciamento de servidores.

## Costuma ser confundido com
É semelhante ao tratamento de erros; No entanto, o fallback automático refere-se diretamente a uma solução alternativa.

## Perguntas frequentes
**Esse recurso causa lentidão?**
Às vezes, o processo de transição pode causar um atraso de milissegundos, mas é melhor do que uma parada completa do sistema.

**Sempre funciona?**
Se o método de backup também falhar, o sistema continuará a falhar, portanto os backups também devem ser confiáveis.
