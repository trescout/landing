# O que é Utilities?

Pequeno software útil que facilita a manutenção, gerenciamento ou funções básicas do computador.

## Definição
Não se trata de aplicativos enormes, mas de pequenas ferramentas que facilitam o seu trabalho. Eles executam tarefas como compactar arquivos, limpar o sistema ou ajustar configurações de rede.

## Como funciona
Eles geralmente se concentram em um único propósito e trabalham silenciosamente em segundo plano para manter o sistema em ordem.

## Onde é usado
Eles estão localizados em sistemas operacionais ou em pequenos pacotes de utilitários.

## Costuma ser confundido com
Não deve ser confundido com software principal; São ferramentas que dão suporte ao funcionamento do software principal.

## Perguntas frequentes
**Todo utilitário é necessário?**
Depende das suas necessidades, mas o básico (limpeza, segurança) é importante para a saúde do sistema.

**O software utilitário é um aplicativo?**
Sim, mas é uma aplicação mais específica e de pequena escala.
