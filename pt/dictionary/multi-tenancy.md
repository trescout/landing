# O que é Multi-tenancy?

*Glossário · Dev · Última atualização: 30 de junho de 2026*

É a capacidade de um único software fornecer serviços independentes para muitos usuários ou empresas diferentes ao mesmo tempo.

## Definição

Pense em um prédio de apartamentos; Todo mundo usa o mesmo prédio, mas cada um tem seu próprio apartamento. No mundo do software, multilocação significa que diferentes clientes que compartilham o mesmo servidor e o mesmo programa trabalham em suas próprias áreas sem ver os dados uns dos outros.

***Analogia:** É como um hotel onde todos usam o mesmo prédio e a mesma piscina, mas cada um tem seu próprio quarto privado.*

## Como funciona

O software atribui a cada usuário uma 'tag' exclusiva no banco de dados. O sistema corresponde a uma solicitação de um usuário apenas com os dados dessa tag, portanto não há confusão.

## Onde é usado

É usado em plataformas SaaS (software como serviço), aplicativos baseados em nuvem e software de gerenciamento empresarial.

## Costuma ser confundido com

Pode ser confundido com um servidor compartilhado; Porém, o que é compartilhado aqui não é apenas o hardware, mas a estrutura lógica do software.

## Perguntas frequentes

**Por que usar um único programa?**

Porque instalar um programa separado para cada usuário é muito caro e difícil de gerenciar; É muito mais fácil atualizar a partir de um único centro.
