# O que é Patch?

É um pequeno patch de atualização aplicado para corrigir erros ou eliminar deficiências de software.

## Definição
Em vez de reinstalar o programa inteiro, ele simplesmente substitui ou melhora a pequena parte problemática. É usado para eliminar vulnerabilidades de segurança ou melhorar o desempenho.

## Como funciona
Os desenvolvedores de software encontram o bug, corrigem-no e lançam um pequeno arquivo contendo essa correção. Você pode atualizar seu programa executando este arquivo.

## Onde é usado
É usado em sistemas operacionais, jogos e todas as atualizações de aplicativos.

## Costuma ser confundido com
Pode ser confundido com uma atualização de versão completa; patch é apenas uma pequena correção, enquanto a atualização de versão traz grandes inovações.

## Perguntas frequentes
**Por que o patch é importante?**
Ele mantém o sistema seguro e corrige peças com defeito.

**Devo sempre instalá-lo?**
Sim, especialmente os patches voltados para a segurança protegem seu sistema contra ataques.
