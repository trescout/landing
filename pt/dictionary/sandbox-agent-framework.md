# O que é Sandbox Agent Framework?

*Glossário · AI · Última atualização: 19 de junho de 2026*

É a infraestrutura que permite que os agentes de inteligência artificial trabalhem em uma área segura sem danificar o sistema principal.

## Definição

É um ambiente de trabalho isolado que evita que agentes de IA danifiquem seu computador host enquanto realizam tentativa e erro ou aprendem novas tarefas. Esta estrutura garante que o agente acesse apenas os recursos permitidos. Se o agente cometer um erro, esse erro permanecerá naquela caixinha e o sistema host não será afetado.

***Analogia:** É como uma criança brincando em um playground macio especialmente preparado, em vez de brincar com brinquedos perigosos em casa.*

## Como funciona

O desenvolvedor coloca o agente nesta área restrita. Aqui o agente escreve código, conecta-se à Internet ou modifica arquivos. No entanto, nenhuma destas operações pode causar danos permanentes ao sistema operacional principal.

## Onde é usado

É usado em ambientes de desenvolvimento onde os agentes de inteligência artificial são testados com segurança.

## Costuma ser confundido com

É a mesma lógica do Sandbox, mas é especificamente especializado para agentes.

## Perguntas frequentes

**Existe alguma chance de o agente sair?**

As estruturas são projetadas para impedir a saída do agente, restringindo-o com regras estritas.

**Por que isso é tão importante?**

Porque agentes autônomos podem cometer erros e você não quer que esses erros travem seu sistema.
