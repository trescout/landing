# O que é Tech Stack?

É a coleção de todas as linguagens, bancos de dados e ferramentas utilizadas para construir um projeto de software.

## Definição
É a 'pilha de tecnologia' usada na construção de um aplicativo. Por exemplo, uma linguagem para o lado visível do site, outra ferramenta para o banco de dados em execução em segundo plano e os servidores que os conectam fazem parte dessa pilha.

## Como funciona
No planejamento do projeto é decidido qual linguagem, qual banco de dados e qual servidor será utilizado. Essas escolhas determinam o ritmo e a capacidade do projeto.

## Onde é usado
É definido durante a fase de arquitetura dos projetos de desenvolvimento de software.

## Perguntas frequentes
**Por que a seleção da pilha é importante?**
Porque afeta diretamente a rapidez com que o projeto crescerá e a facilidade com que será desenvolvido.
