# O que é Multivariate Testing?

> Multivariate Testing

Método de teste que altera diferentes partes de uma página web ao mesmo tempo e mede qual delas dá melhores resultados.

## Definição
O teste multivariado é usado para encontrar a versão que fornece a maior interação do usuário, testando diferentes combinações de vários elementos (por exemplo, título, imagem e botão) em páginas da web ao mesmo tempo. Este método permite analisar muito mais variáveis ​​simultaneamente do que os testes A/B tradicionais. Assim, você consegue perceber claramente qual componente atrai mais o usuário.

## Como funciona
O software mostra aleatoriamente diferentes variações da página para as pessoas que visitam seu site. Dados como em qual botão os visitantes clicaram ou quanto tempo permaneceram são coletados e a combinação estatisticamente mais bem-sucedida é determinada.

## Onde é usado
É utilizado em campanhas de marketing, home pages de sites de comércio eletrônico e processos de otimização da experiência do usuário.

## Costuma ser confundido com
Muitas vezes é confundido com testes A/B, que comparam duas versões diferentes de um único item, mas o MVT testa vários itens simultaneamente.

## Perguntas frequentes
**O que é necessário para fazer MVT?**
São necessários alto tráfego na web e software de análise especial que possa gerenciar esses testes.

**Como é diferente do teste A/B?**
Enquanto o teste A/B se concentra em uma única mudança, o MVT examina a interação de vários componentes simultaneamente.
