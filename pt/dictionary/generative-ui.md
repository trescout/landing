# O que é Generative UI?

É um design de tela criado instantaneamente por inteligência artificial de acordo com as necessidades atuais do usuário.

## Definição
UI generativa são telas dinâmicas moldadas de acordo com a intenção e o contexto atuais do usuário, em vez de uma interface fixa. Em um site padrão todos os botões e menus são óbvios, mas nesta tecnologia o sistema pode criar um novo botão ou gráfico de acordo com sua necessidade. Dessa forma, você vê apenas as ferramentas necessárias, em vez de se perder em menus complexos.

## Como funciona
O modelo de inteligência artificial analisa a solicitação do usuário e combina instantaneamente as peças de código que compõem a interface. O sistema redesenha a interface decidindo quais informações devem estar em primeiro plano. Este processo é constantemente atualizado com base na interação do usuário.

## Onde é usado
É usado em chatbots modernos, painéis personalizados e ferramentas complexas de análise de dados.

## Costuma ser confundido com
Pode ser confundido com web design estático, mas o design aqui é produzido inteiramente por inteligência artificial naquele momento.

## Perguntas frequentes
**Por que a UI generativa é importante?**
Evita que o usuário se perca em aplicações complexas e fornece apenas as ferramentas necessárias para o trabalho atual.

**Parece sempre o mesmo?**
Não, a interface pode mudar completamente para cada usuário e cada tarefa diferente.
