# O que é Local-first Code Intelligence?

As ferramentas de desenvolvimento de software fornecem sugestões de código processando dados diretamente no seu dispositivo local, sem enviá-los para a nuvem.

## Definição
Essa abordagem foi projetada para proteger a confidencialidade do seu código e ser executada rapidamente, mesmo sem conexão com a Internet. Em vez de enviar dados para servidores remotos, seu ambiente de desenvolvimento analisa seu código usando o poder do seu próprio computador. Assim, a segurança é aumentada e o tempo de atraso é eliminado.

## Como funciona
Este sistema executa modelos de inteligência artificial que escaneiam seu código no processador ou placa gráfica do seu computador. Seu IDE ou editor fica em constante comunicação com esses modelos locais, gerando sugestões instantâneas. Os recursos de conclusão de código ou depuração continuam funcionando mesmo se sua conexão com a Internet for perdida.

## Onde é usado
Ele é usado em editores de código modernos, plug-ins nativos com tecnologia de IA e ambientes de desenvolvimento com foco na privacidade.

## Costuma ser confundido com
Pode ser confundido com assistentes de código baseados em nuvem, mas aqui todo o processo termina no seu dispositivo.

## Perguntas frequentes
**Por que devo escolher local em vez de nuvem?**
Manter seus dados em seu dispositivo é uma enorme vantagem de segurança, especialmente se você estiver trabalhando com códigos confidenciais ou comerciais secretos.
