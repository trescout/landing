# O que é Frontend?

*Desenvolvimento · Última atualização: 25 de outubro de 2026*

É a camada de interface frontal de um site ou aplicativo que é diretamente vista, clicada e com a qual os usuários interagem.

## Definição

O frontend é o lado do cliente que inclui todos os elementos visuais, botões, formulários e animações onde o software encontra o usuário. Os códigos executados no navegador ou dispositivo móvel transformam os dados provenientes do servidor em uma interface elegante que o usuário pode entender facilmente. A velocidade, a acessibilidade e o sucesso estético da experiência do usuário dependem diretamente da qualidade desta camada.

***Analogia:** É semelhante à iluminação, às mesas, ao menu e ao elegante salão de jantar onde os garçons prestam serviço em um restaurante; enquanto o fogão e o depósito na cozinha ficam nos bastidores.*

## Como funciona

O HTML forma o esqueleto da página, o CSS veste o design visual e o JavaScript dá vida à página com base nos cliques do usuário. Esses componentes são interpretados pelo navegador e renderizados na tela. Quando o usuário realiza uma ação, o frontend encaminha essa solicitação para os bastidores e atualiza instantaneamente a resposta recebida na interface.

## Onde é usado

Ele está presente em todas as páginas web que você visita, nos aplicativos móveis que você instala no seu telefone e nos menus de tela sensível ao toque de dispositivos inteligentes.

## Costuma ser confundido com

É o oposto do conceito de backend. Enquanto o frontend lida com tudo o que você vê na tela, o backend gerencia o banco de dados, os cálculos do servidor e a segurança em segundo plano.

## Perguntas e respostas

**Quais linguagens são necessárias para o desenvolvimento frontend?**

No mundo web, o trio padrão fundamental é HTML, CSS e JavaScript. Hoje em dia, essa estrutura é usada em conjunto com bibliotecas modernas como React e Vue.

**O design frontend e o design UI/UX são a mesma coisa?**

Não. Enquanto o design UI/UX é o planejamento visual e a pesquisa de usuários, o frontend consiste na conversão desses designs em código de software funcional.
