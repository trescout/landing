# O que é Vector Indexing?

É o processo de conversão de grandes conjuntos de dados em um mapa digital a partir do qual um computador pode encontrar semelhanças significativas em segundos.

## Definição
A indexação vetorial consiste em converter dados em vetores matemáticos e, em seguida, colocar esses vetores em uma estrutura rapidamente consultável. Este processo permite que você encontre aquele que mais se aproxima do assunto que procura entre milhares de documentos. Depois que os dados são indexados, ele funciona como um mecanismo de busca, retornando rapidamente conteúdo com significado semelhante.

## Como funciona
Primeiro, os dados são convertidos em coordenadas numéricas com modelos incorporados. Essas coordenadas são então salvas em um banco de dados vetorial, com as próximas umas das outras parando na mesma região.

## Onde é usado
É usado em sistemas RAG, mecanismos de busca em larga escala e sistemas de recomendação.

## Costuma ser confundido com
Pode ser confundido com Banco de Dados Vetorial; A indexação vetorial é o método de organização e mapeamento deste banco de dados.

## Perguntas frequentes
**Por que usamos isso em vez da pesquisa clássica?**
A pesquisa clássica corresponde às palavras, a indexação vetorial corresponde ao significado.

**Existe uma diferença de velocidade?**
Sim, como os dados são indexados, os resultados podem ser obtidos em milissegundos a partir de milhões de registros.
