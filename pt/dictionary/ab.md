# O que é ab?

*Glossário · Dev · Última atualização: 1 de outubro de 2026*

> ApacheBench

Uma ferramenta de teste de desempenho simples usada para medir quantas pessoas um servidor web pode suportar simultaneamente.

## Definição

ab é uma ferramenta de linha de comando clássica usada para testar a resiliência dos seus servidores web. Ela permite que você envie milhares de solicitações virtuais simultâneas para o seu servidor para ver quando ele ficará lento ou travará. É de vital importância, especialmente para entender a capacidade antes de colocar um novo site no ar.

***Analogia:** É como colocar uma simulação de uma multidão de pessoas na porta de um café recém-inaugurado para entender como o caixa e os garçons reagirão quando centenas de clientes chegarem ao mesmo tempo.*

## Como funciona

Você abre a tela do terminal e executa digitando o endereço web que deseja testar e o número de solicitações que deseja enviar. Quando o teste termina, a ferramenta gera um relatório informando quantas solicitações por segundo foram atendidas.

## Onde é usado

É frequentemente usada em configurações de servidores web, testes de desempenho e processos de otimização de sistemas.

## Costuma ser confundido com

Não deve ser confundida com ferramentas avançadas de teste de carga ou automações de navegador real; ela mede puramente a velocidade bruta do servidor.

## Perguntas frequentes

**Reflete exatamente o tráfego real do usuário?**

Não, ela envia apenas solicitações HTTP básicas e não simula operações de JavaScript no navegador.
