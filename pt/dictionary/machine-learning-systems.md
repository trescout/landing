# O que é Machine Learning Systems?

São sistemas de computador que aprendem por conta própria analisando dados e podem fazer previsões mais precisas ao longo do tempo.

## Definição
Esses sistemas aprendem regras automaticamente extraindo exemplos de dados, em vez de serem explicitamente programados. Uma vez treinado, ele usa experiências passadas para fazer previsões quando se depara com dados novos e nunca vistos. Eles melhoram seu desempenho ao longo do tempo com um fluxo constante de dados.

## Como funciona
Grandes conjuntos de dados são fornecidos ao modelo, o modelo encontra padrões nesses dados e cria um modelo matemático para produzir um resultado.

## Onde é usado
É utilizado em sistemas de recomendação, detecção de fraudes, análise de saúde e veículos autônomos.

## Perguntas frequentes
**Como é diferente da inteligência artificial?**
O aprendizado de máquina é um subramo da inteligência artificial focado no aprendizado a partir de dados; Nem toda inteligência artificial usa aprendizado de máquina.
