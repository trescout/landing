# O que é Shell Script?

*Glossário · Dev · Última atualização: 17 de agosto de 2026*

Esses são pequenos scripts que instruem o sistema operacional do computador a fazer o trabalho que precisa ser feito em ordem.

## Definição

Um script de shell é uma lista de comandos que você pode salvar em um arquivo e executar coletivamente, em vez de digitá-los um por um no computador. Esses arquivos se comunicam com a interface de linha de comando do sistema operacional, automatizando tarefas como copiar arquivos, iniciar programas ou alterar configurações do sistema. Eles são como uma lista digital de instruções que permitem realizar tarefas complexas com um único clique.

***Analogia:** Pense em uma receita; Em vez de preparar os ingredientes um por um, você entrega ao processador de alimentos um pedaço de papel com todos os passos escritos e ele seguirá sozinho a receita do início ao fim.*

## Como funciona

Geralmente é escrito como um arquivo de texto e contém comandos que você pode executar no terminal. Depois que o arquivo recebe permissão de execução, todas as operações nele são realizadas sequencialmente com um único comando por meio do terminal.

## Onde é usado

É frequentemente usado para automatizar tarefas de gerenciamento de servidores, operações de backup e processos de desenvolvimento de software.

## Costuma ser confundido com

É a mesma coisa que script bash, apenas um termo mais geral.

## Perguntas frequentes

**Preciso saber o código?**

Você só precisa conhecer comandos básicos, não precisa conhecer linguagens de programação complexas.

**Funciona em todos os computadores?**

Geralmente é executado em ambientes de terminal em sistemas como Linux ou macOS; configurações especiais podem ser necessárias para Windows.
