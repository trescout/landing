# O que é Resolver Load Balancing?

É o processo de prevenção da sobrecarga do sistema, distribuindo consultas de endereços da Internet para vários servidores.

## Definição
Quando o tráfego da Internet é muito intenso, um único servidor não consegue acompanhar todas as consultas. Este método evita que o sistema trave, redirecionando as consultas para servidores diferentes, como um guarda de trânsito. Isso garante uma conexão rápida e ininterrupta em todos os momentos.

## Como funciona
Instale um software balanceador de carga e distribua as consultas DNS recebidas igualmente entre os servidores que você definir.

## Onde é usado
É usado em grandes sites e infraestruturas de rede de alto tráfego.

## Costuma ser confundido com
Pode ser confundido apenas com clustering de servidores, mas esse método se concentra especificamente no gerenciamento do tráfego de consultas.

## Perguntas frequentes
**O site ficará mais rápido graças a este sistema?**
Sim, os tempos de resposta são mais curtos à medida que a carga no servidor é reduzida.

**O que acontece se um único servidor cair?**
O balanceador de carga mantém o site funcionando redirecionando para outros servidores.
