# O que é Single Source of Truth?

*Glossário · Data · Última atualização: 17 de julho de 2026*

> SSOT

O princípio é que todos os dados sejam gerenciados a partir de um único centro confiável e todos tenham acesso às mesmas informações.

## Definição

Se existirem ficheiros ou números diferentes para a mesma informação numa instituição, surge confusão. Uma única fonte de verdade garante que os dados sejam atualizados em apenas um lugar e que todos possam usar esses dados atualizados. Isso elimina a inconsistência de dados.

***Analogia:** É como se todos os funcionários de uma empresa olhassem para uma torre de relógio principal para acertar seus relógios; todo mundo vê ao mesmo tempo.*

## Como funciona

Um banco de dados central ou sistema em nuvem é estabelecido. Todos os departamentos escrevem dados aqui e os leem daqui. Então, 'qual arquivo estava atualizado?' A questão se torna história.

## Onde é usado

É obrigatório em software empresarial, sistemas financeiros e projetos onde trabalham grandes equipes.

## Costuma ser confundido com

Pode ser confundido com o banco de dados central; Este é um princípio de gestão e não uma técnica.

## Perguntas frequentes

**Por que esse princípio é difícil?**

Porque todos os departamentos devem se adaptar ao mesmo sistema e ser disciplinados.

**O que acontece se falhar?**

Isso leva a decisões erradas e perda de tempo dentro da organização.
