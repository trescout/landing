# O que é User Identifiers?

*Glossário · Dev · Última atualização: 27 de junho de 2026*

São marcadores de identidade únicos usados para distinguir cada usuário em sistemas digitais.

## Definição

Estes são códigos especiais ou nomes de usuário atribuídos ao sistema para reconhecê-lo quando você entra em um aplicativo. Graças a esses identificadores, o sistema pode apresentar suas transações, configurações e dados anteriores especificamente para você, sem misturá-los. Você pode pensar nisso como se fosse seu número de membro de uma biblioteca.

***Analogia:** É como um passe que você usa para entrar em um prédio; Ao digitalizar o cartão, o segurança sabe instantaneamente quem você é e em quais andares pode entrar.*

## Como funciona

Quando você se registra ou faz login no sistema, ele é criado automaticamente em segundo plano e comparado com você no banco de dados.

## Onde é usado

Ele é usado para rastreamento de usuários em sites, aplicativos móveis e software corporativo.

## Costuma ser confundido com

Pode ser confundido com um nome de usuário, mas é uma estrutura mais técnica e geral que permite ao sistema reconhecê-lo.

## Perguntas frequentes

**Por que obtenho um ID diferente para cada sistema?**

Para sua segurança; Não usar sua identidade em um sistema em outro sistema mantém seus dados mais seguros.
