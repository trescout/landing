# O que é Continuous Integration?

> CI

É o processo que garante que os erros sejam detectados precocemente, combinando e testando automaticamente os códigos escritos pelos desenvolvedores de software.

## Definição
A Integração Contínua (CI) garante que os códigos sejam frequentemente enviados para um sistema central durante o processo de desenvolvimento de software e aí submetidos a testes automáticos. Desta forma, se o código escrito por um desenvolvedor de software entrar em conflito com o código de outros, isso será imediatamente percebido. Os bugs são resolvidos antes de se tornarem maiores, enquanto ainda estão em desenvolvimento.

## Como funciona
Assim que o desenvolvedor carrega seu código no sistema, robôs executados em segundo plano compilam automaticamente o código e executam testes pré-determinados.

## Onde é usado
É uma prática padrão em grandes equipes de software e em ciclos modernos de desenvolvimento de software (DevOps).

## Perguntas frequentes
**Por que não fazemos testes manuais?**
O teste manual é lento e sujeito a erros humanos; A CI, por outro lado, trabalha com a mesma meticulosidade em cada mudança.
