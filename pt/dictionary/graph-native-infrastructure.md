# O que é Graph-native Infrastructure?

*Glossário · Data · Última atualização: 8 de agosto de 2026*

É uma estrutura especial de armazenamento de dados projetada com base em conexões diretas entre dados.

## Definição

Ao contrário das tabelas tradicionais, este sistema mantém os dados na forma de nós e linhas interconectadas. As relações entre as informações são tão importantes quanto os próprios dados. Desta forma, análises complexas de redes podem ser realizadas muito rapidamente.

***Analogia:** É como criar um mapa construindo hiperlinks diretos de um assunto para outro, em vez de organizar os arquivos em uma biblioteca em ordem alfabética.*

## Como funciona

Os dados são vinculados por ponteiros, portanto você não precisa examinar a lista inteira para passar de um dado para outro.

## Onde é usado

É usado em análises de redes sociais, sistemas de detecção de fraudes e gráficos de conhecimento complexos.

## Costuma ser confundido com

Não deve ser confundido com bancos de dados relacionais clássicos (SQL); porque aqui o relacionamento não faz parte do quadro, mas é a base da estrutura.

## Perguntas frequentes

**Por que devo escolher esta estrutura?**

Essa estrutura é muito mais rápida se você precisar consultar relacionamentos profundos e complexos entre dados em segundos.
