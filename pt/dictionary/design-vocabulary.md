# O que é Design Vocabulary?

*Desenvolvimento · Última atualização: 29 de outubro de 2026*

É um conjunto de termos visuais e regras que os agentes de inteligência artificial utilizam para garantir consistência ao projetar interfaces.

## Definição

O vocabulário de design (design vocabulary) é um conjunto de termos padrão aos quais um agente de inteligência artificial recorre ao gerar interfaces visuais e componentes. Códigos de cores, regras de tipografia, estilos de botões e padrões de layout são definidos neste vocabulário. Assim, em vez de criar um design do zero a cada vez, o sistema permanece fiel a uma linguagem de design comum.

***Analogia:** É como o manual de símbolos padrão e paleta de cores que um escritório de arquitetura usa em todos os desenhos.*

## Como funciona

Os desenvolvedores adicionam regras de componentes predefinidas ao prompt do sistema ou aos arquivos de configuração do agente. Ao gerar código, o agente consulta essas regras para corresponder corretamente aos nomes e estilos dos componentes.

## Onde é usado

É utilizado em sistemas de interface generativa, ferramentas automatizadas de codificação de front-end e sistemas de design corporativo.

## Costuma ser confundido com

É diferente de um sistema de design (design system); enquanto o sistema de design abrange bibliotecas de código, o vocabulário de design é o mapa conceitual de termos que permite que os agentes compreendam esses componentes.

## Perguntas e respostas

**Por que o vocabulário de design é necessário?**

É necessário para evitar que os agentes de inteligência artificial usem estilos diferentes em cada geração de código, o que quebraria a integridade da interface.

**Como o vocabulário de design é criado?**

Os nomes dos componentes e as regras visuais do sistema de design existente são convertidos em modelos baseados em texto e definidos para o agente.
