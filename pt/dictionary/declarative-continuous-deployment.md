# O que é Declarative Continuous Deployment?

É o método que define o estado final do sistema e garante que as atualizações atinjam automaticamente esse objetivo.

## Definição
Você não está interessado em como atualizar o sistema, mas em qual deve ser o resultado. Basta dizer 'deixe o sistema estar neste estado' e as ferramentas tomarão todas as medidas necessárias para capturar este estado. Isso evita atualizações manuais erradas.

## Como funciona
Você prepara um arquivo de configuração. O sistema automático lê esse arquivo, compara-o com a situação atual e faz os ajustes necessários para fechar a lacuna.

## Onde é usado
Ele é usado em aplicativos baseados em nuvem e gerenciamento de servidores em grande escala.

## Costuma ser confundido com
Pode ser confundido com métodos imperativos (orientados a comandos); Nesse método, você conta cada passo, um por um.

## Perguntas frequentes
**Por que devemos escolher este método?**
Minimiza o erro humano e garante que o sistema permaneça sempre no estado desejado.

**O que acontece se eu cometer um erro?**
O sistema percebe que você definiu o estado errado e geralmente volta ao antigo estado de funcionamento.
