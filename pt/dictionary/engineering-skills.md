# O que é Engineering Skills?

É a capacidade de projetar e construir sistemas utilizando lógica e matemática para resolver problemas complexos.

## Definição
Não se trata apenas de escrever código, é o processo de planejar como resolver um problema de forma mais eficiente. Esta habilidade visa criar um todo funcional, reunindo as partes. A perspectiva da engenharia permite fazer o melhor uso dos recursos limitados disponíveis.

## Como funciona
Primeiro divida o problema em partes menores, depois escolha a solução lógica mais apropriada para cada parte e combine essas partes para que funcionem juntas.

## Onde é usado
É usado em todo o desenvolvimento de software, projeto de arquitetura e processos gerais de resolução de problemas.

## Costuma ser confundido com
Pode ser confundido apenas com habilidades de codificação, enquanto a codificação é apenas a parte de aplicação desse processo.

## Perguntas frequentes
**Qualquer pessoa pode adquirir habilidades de engenharia?**
Sim, é uma habilidade que se desenvolve ao longo do tempo através da prática do pensamento sistemático.

**Será útil para mim mesmo que eu não seja um desenvolvedor de software?**
Definitivamente torna mais fácil resolver problemas complexos em todas as áreas da vida.
