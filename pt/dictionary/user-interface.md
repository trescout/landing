# O que é User Interface?

*Glossário · Dev · Última atualização: 25 de junho de 2026*

> UI

É a área de exibição visual e controle que permite ao usuário interagir com um dispositivo ou software.

## Definição

É a ponte entre você e um software no mundo digital. Tudo o que você vê, como botões, menus, ícones e caixas de texto, faz parte desta interface. Uma boa interface permite executar facilmente até mesmo operações complexas.

***Analogia:** É como o volante, os pedais e o painel de um carro; Permite-lhe gerir o veículo sem precisar de saber como funciona o motor.*

## Como funciona

Os designers desenham essas telas analisando o que os usuários precisam. Em seguida, os desenvolvedores de software transformam esses desenhos em uma estrutura que funciona com códigos. O layout visual resultante traduz seus comandos em uma linguagem que o computador possa entender.

## Onde é usado

Ele aparece em aplicativos do seu smartphone, em sites ou nas telas sensíveis ao toque dos seus dispositivos domésticos inteligentes.

## Costuma ser confundido com

Muitas vezes é confundido com o back-end do software, mas a interface é apenas a parte que você vê.

## Perguntas frequentes

**UI e UX são a mesma coisa?**

Não, a UI cobre as partes visuais (cor, botão), enquanto a UX trata de como o usuário se sente e quão confortável ele se sente ao usar essa interface.
