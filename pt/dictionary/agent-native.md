# O que é Agent-native?

*Glossário · AI · Última atualização: 16 de agosto de 2026*

Os sistemas são projetados para tomar decisões autônomas sem esperar por comandos humanos.

## Definição

Essa abordagem visa fazer com que o software se comporte como um funcionário com objetivos próprios, e não apenas como uma ferramenta. Os próprios sistemas determinam e implementam as etapas necessárias para resolver os problemas que encontram.

***Analogia:** Em vez de um carrinho de brinquedo que só funciona quando você aperta um botão, é como um veículo sem motorista que segue seu próprio caminho e obedece às regras de trânsito.*

## Como funciona

Os modelos de IA são definidos com objetivos específicos e as ferramentas que podem utilizar para atingir esses objetivos; O modelo gerencia o processo usando essas ferramentas.

## Onde é usado

É usado em ferramentas autônomas de desenvolvimento de software e sistemas de gerenciamento de tarefas complexas.

## Costuma ser confundido com

A diferença deles em relação aos chatbots comuns é que eles não apenas respondem, mas também agem.

## Perguntas frequentes

**O que acontece se esses sistemas cometerem erros?**

Por serem autônomos, possuem uma margem de erro, por isso muitas vezes operam sob supervisão humana.
