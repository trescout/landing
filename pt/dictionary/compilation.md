# O que é Compilation?

É o processo de conversão de códigos escritos próximos à linguagem humana em linguagem de máquina que o processador do computador possa compreender.

## Definição
Os computadores entendem apenas comandos que consistem em 0s e 1s. Os programadores, por outro lado, usam linguagens altamente legíveis. O processo de compilação une esses dois mundos, transformando o código em um arquivo executável.

## Como funciona
Um software especial chamado compilador verifica seu código-fonte, verifica se há erros e o converte em um formato binário que o processador pode executar diretamente.

## Onde é usado
É uma etapa obrigatória antes de executar o programa em linguagens como C++, Rust e Java.

## Costuma ser confundido com
A diferença das linguagens interpretadas é que o código é completamente transformado antes da execução, e não em tempo de execução.

## Perguntas frequentes
**Todas as linguagens precisam ser compiladas?**
Não, algumas linguagens, como Python, executam o código instantaneamente, linha por linha, sem exigir um processo de compilação.
