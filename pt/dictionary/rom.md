# O que é ROM?

*Glossário · Dev · Última atualização: 4 de julho de 2026*

> Read-Only Memory

É um tipo de memória permanente somente leitura que preserva as informações contidas mesmo quando o computador está desligado.

## Definição

ROM contém as instruções básicas necessárias para ligar o computador ou dispositivo. Este tipo de memória foi projetada para armazenar dados permanentemente e não pode ser facilmente alterada pelo usuário durante o uso normal. É onde o “cérebro” do dispositivo sabe o que fazer quando ele acorda.

***Analogia:** É como a versão impressa de um livro; Você pode ler o texto interno, mas não pode excluir ou reescrever as páginas.*

## Como funciona

Quando você pressiona o botão liga/desliga do dispositivo, o processador primeiro lê as instruções na ROM. Estas instruções informam como o sistema operacional deve ser instalado.

## Onde é usado

É encontrado nas telas iniciais de smartphones, placas-mãe de computadores e sistemas embarcados.

## Costuma ser confundido com

Está misturado com RAM; A RAM é temporária e é excluída quando o computador é desligado, enquanto a ROM é permanente.

## Perguntas frequentes

**Por que as informações na ROM não podem ser alteradas?**

Porque as regras básicas de operação do dispositivo são protegidas para evitar exclusão acidental ou corrupção.
