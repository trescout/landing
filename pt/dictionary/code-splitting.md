# O que é Code Splitting?

*Glossário · Dev · Última atualização: 6 de agosto de 2026*

Para aumentar a velocidade de carregamento do site, é um método de dividir grandes arquivos de código em pequenos pedaços e carregá-los somente quando necessário.

## Definição

Quando o usuário entra no seu site, ao invés de baixar todos os códigos, ele baixa apenas os códigos necessários para a página que está visualizando no momento. Os códigos de outras páginas são carregados em segundo plano quando o usuário clica nessas páginas.

***Analogia:** É como estar em um restaurante onde os pratos vão um por um conforme você pede, em vez de todos os pratos do cardápio serem trazidos à mesa ao mesmo tempo.*

## Como funciona

O desenvolvedor faz marcas no código como 'carregar esta parte agora, carregar o resto mais tarde'.

## Onde é usado

Ele é usado em aplicativos da web e sites de grande escala que se preocupam com a experiência do usuário.

## Costuma ser confundido com

Pode ser confundido com agrupamento; Embora o agrupamento combine arquivos, a divisão de código os separa de forma inteligente em pedaços.

## Perguntas frequentes

**Haverá um atraso quando o usuário clicar na página?**

Pode demorar muito pouco, mas a experiência geral é melhor, pois a velocidade de carregamento inicial é muito mais rápida.
