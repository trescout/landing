# O que é Identity Provider?

Serviço central que verifica as informações de login do usuário e fornece acesso seguro às aplicações.

## Definição
Ele permite que você comprove sua identidade por meio de um sistema central, em vez de criar uma nova senha toda vez para um aplicativo. O aplicativo pergunta a este serviço quem você é e recebe a confirmação.

## Como funciona
O usuário faz login, o serviço autentica e envia uma chave de ‘login’ para o aplicativo.

## Onde é usado
É usado em sistemas locais, estruturas SSO (Single Sign-On) e aplicações web modernas.

## Costuma ser confundido com
Não é apenas um gerenciador de senhas, é uma autoridade de autenticação.

## Perguntas frequentes
**É seguro?**
Sim, é mais seguro porque você não fornece sua senha para todos os aplicativos.

**O que acontece se o sistema travar?**
Por se tratar de um serviço central, o acesso a todas as aplicações conectadas pode ser interrompido.
