# O que é Open-Source Clones?

*Glossário · Dev · Última atualização: 15 de junho de 2026*

São versões semelhantes de softwares populares criados pela cópia pública de seus códigos-fonte.

## Definição

As cópias de código aberto pegam a lógica ou a aparência de um software de sucesso e o transformam em algo que qualquer pessoa pode desenvolver livremente. Isso permite que as comunidades criem suas próprias alternativas onde o software original é pago ou fechado. Assim, ferramentas com características semelhantes podem ser utilizadas no mundo do software sem depender de uma única empresa.

***Analogia:** É como se um chef disponibilizasse ao público sua querida receita secreta e todos pudessem pegá-la e cozinhá-la adicionando temperos ao seu gosto.*

## Como funciona

Os desenvolvedores pegam o código-fonte do projeto original e o utilizam como base para seus próprios projetos. Eles então fazem suas próprias melhorias ou alterações neste código. O produto resultante é uma nova versão muito semelhante à original, mas apoiada pela comunidade.

## Onde é usado

É usado no mundo do software no desenvolvimento de ferramentas alternativas ou na criação de versões mais acessíveis de um determinado software.

## Costuma ser confundido com

Pode ser confundido com o termo simplesmente 'Clone', mas este termo abrange especificamente aqueles que são de código aberto e orientados pela comunidade.

## Perguntas frequentes

**As cópias de código aberto são legais?**

Se a licença do software original permitir, então sim, é totalmente legal.

**Por que devo usar uma cópia e não o original?**

Geralmente são preferidos porque são mais econômicos, você pode alterá-los de acordo com sua necessidade ou oferecem uma estrutura mais gratuita.
