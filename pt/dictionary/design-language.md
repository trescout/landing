# O que é Design Language?

É um conjunto de regras que mantém consistentes o mundo visual e a experiência do usuário de um produto.

## Definição
Linguagens de design são padrões estabelecidos sobre a aparência e comportamento de um software ou produto. Ele garante que elementos como paletas de cores, fontes, formatos de botões e uso de espaçamento sejam compatíveis entre si. Desta forma, o usuário encontra uma interface familiar e regular sempre que abre o aplicativo.

## Como funciona
Os designers criam um guia e os desenvolvedores colocam essas regras no código. Isso evita que o design se deteriore sempre que um novo recurso é adicionado. Graças a essa consistência, os usuários aprendem a aplicação com mais facilidade.

## Onde é usado
É utilizado em sites, aplicativos móveis e todas as plataformas digitais onde a identidade da marca é criada.

## Costuma ser confundido com
Não é apenas um tema visual, é um sistema que abrange toda a lógica de interação de um produto.

## Perguntas frequentes
**Por que isso é importante?**
Evita que o usuário se confunda ao usar o aplicativo e proporciona uma experiência profissional.

**O que isso significa para desenvolvedores de software?**
Elimina a necessidade de criar sempre um novo design e permite um progresso rápido através da combinação de peças predefinidas.
