# O que é Extensibility?

A adequação de um sistema a ser desenvolvido adicionando novas funcionalidades sem perturbar sua estrutura básica.

## Definição
Extensibilidade significa que um software é flexível. Você pode adicionar novos recursos por meio de plug-ins ou módulos sem mexer no código principal do software. Isso garante a longevidade do sistema.

## Como funciona
O sistema foi projetado com uma 'interface' que aceitará módulos externos.

## Onde é usado
Ele é usado em complementos de navegador, sistemas de gerenciamento de conteúdo (como WordPress) e software de grandes empresas.

## Perguntas frequentes
**Todo software é extensível?**
Não, se o software não for projetado com essa flexibilidade desde o início, adicioná-lo posteriormente pode ser muito difícil.
