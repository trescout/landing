# O que é API?

> Application Programming Interface

É uma ponte digital que permite que dois softwares diferentes se comuniquem.

## Definição
API é uma linguagem padrão que permite que os softwares se comuniquem entre si. Ele permite que um aplicativo disponibilize seus recursos para outros aplicativos.

## Como funciona
Um software envia uma solicitação para um endereço específico. Outro software recebe esta solicitação, processa-a e retorna o resultado. Este processo é totalmente baseado em regras e automático.

## Onde é usado
É usado em aplicações meteorológicas para recuperar dados do centro meteorológico ou para acessar modelos de inteligência artificial pela internet.

## Costuma ser confundido com
É confundido com o próprio site, mas a API foi projetada para que máquinas conversem com máquinas, não com humanos.

## Perguntas frequentes
**Qualquer pessoa pode usar a API?**
Geralmente o acesso é feito mediante autorização com chave, portanto é um processo controlado.

**Por que a API é segura?**
Uma vez que só permite a partilha de dados permitidos, abre apenas a parte relevante do sistema, não o sistema inteiro.
