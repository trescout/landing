# O que é AI Coding Assistants?

São ferramentas de inteligência artificial que oferecem sugestões aos desenvolvedores de software na hora de escrever códigos, encontram erros e agilizam o processo de desenvolvimento.

## Definição
Os assistentes de codificação de IA agem como colegas de um desenvolvedor. Ao escrever o código, ele prevê a próxima linha, explica funções complexas ou verifica erros no código que você escreveu. Essas ferramentas permitem que os desenvolvedores cometam menos erros e produzam códigos mais rápidos.

## Como funciona
Ele é instalado como um plugin no seu editor de código. Quando você começa a escrever o código, ele é executado em segundo plano e mostra sugestões na tela.

## Onde é usado
É usado em ambientes de desenvolvimento de software (IDE), como VS Code e IntelliJ.

## Costuma ser confundido com
Pode ser confundido com 'AI Coding Agent', que escreve código inteiramente por conta própria; Os assistentes geralmente trabalham sob seu controle.

## Perguntas frequentes
**Essas ferramentas substituirão os desenvolvedores de software?**
Não, é uma ferramenta auxiliar que torna o trabalho do desenvolvedor de software mais fácil e produtivo.
