# O que é Fine-tuning?

*Glossário · AI · Última atualização: 3 de junho de 2026*

É o processo de treinar especificamente um modelo de inteligência artificial pronto para uma tarefa ou área de especialização específica.

## Definição

O ajuste fino é o retreinamento de uma inteligência artificial treinada de uso geral com um pequeno conjunto de dados para executar melhor um determinado estilo, área de especialização ou tarefa. Este processo preserva as capacidades gerais do modelo ao mesmo tempo que o especializa em um assunto específico.

***Analogia:** É como um médico que recebeu formação em medicina geral e se torna cirurgião ou cardiologista após receber formação especializada por um determinado período de tempo.*

## Como funciona

Primeiro, um modelo básico é selecionado e um conjunto de dados específico para este modelo é exibido. O modelo passa por um leve treinamento com esses dados e ajusta suas conexões internas de acordo com seu novo alvo.

## Onde é usado

Ele é usado em áreas muito específicas, como redação jurídica, suporte de diagnóstico médico ou imitação da linguagem de correspondência privada da sua empresa.

## Costuma ser confundido com

É frequentemente confundido com RAG; O RAG traz informações de fora, enquanto o ajuste fino altera permanentemente o comportamento ou a experiência do modelo.

## Perguntas frequentes

**O ajuste fino é muito caro?**

Tornou-se muito mais acessível do que antes, mas ainda requer grande poder de processamento e um conjunto de dados de qualidade.

**Devo ajustar o modelo todos os dias?**

Não, o ajuste fino é um processo permanente; Faz muito mais sentido usar o RAG para obter informações atualizadas.
