# O que é Pipeline?

É uma série de etapas automáticas pelas quais os dados passam do estado bruto até chegarem a um resultado processado.

## Definição
Um pipeline é uma linha de produção onde os dados entram por uma extremidade e saem como um resultado significativo na outra extremidade. Em cada etapa, os dados são limpos, transformados ou analisados. Essa estrutura elimina o trabalho manual, garantindo que o processo seja repetível e livre de erros.

## Como funciona
A fonte de dados é determinada e, em seguida, as etapas de processamento (como limpeza, transformação) são definidas. O sistema executa automaticamente essas etapas em ordem.

## Onde é usado
É utilizado em processos de processamento de dados, distribuição de software e treinamento de modelos de inteligência artificial.

## Costuma ser confundido com
Não deve ser confundido apenas com um banco de dados; Um pipeline é um processo que processa dados, não um local para armazená-los.

## Perguntas frequentes
**O que acontece se o pipeline quebrar?**
O processo pode parar ou produzir dados incorretos, por isso o monitoramento (observabilidade) é muito importante.

**Deveria ser sempre automático?**
Sim, a automação está no centro do conceito de pipeline.
