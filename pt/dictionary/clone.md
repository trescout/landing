# O que é Clone?

É o processo de copiar todos os arquivos e histórico de um projeto de software da Internet para o seu próprio computador.

## Definição
Significa baixar um projeto de código aberto, geralmente disponível em plataformas como GitHub, para seu ambiente local para que você possa trabalhar nele ou revisá-lo. Mais do que baixar arquivos, traz todo o histórico de desenvolvimento do projeto.

## Como funciona
Isso é feito através da linha de comando usando o comando ‘git clone’ e o endereço do projeto.

## Onde é usado
É o primeiro processo que os desenvolvedores de software realizam antes de iniciar o projeto.

## Perguntas frequentes
**Posso alterar o projeto após a clonagem?**
Sim, você pode fazer as alterações que desejar na cópia em seu próprio computador, mas isso não afetará o projeto original.
