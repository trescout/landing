# O que é Code Intelligence Graph?

*Glossário · Dev · Última atualização: 18 de julho de 2026*

É um mapa detalhado que mostra os relacionamentos de todos os arquivos, funções e variáveis em um projeto de software.

## Definição

Em grandes projetos de software, os códigos estão espalhados por milhares de arquivos. Code Intelligence Graph conecta essa estrutura complexa como uma rede. Assim, a inteligência artificial consegue entender facilmente quais outras partes uma alteração feita em uma parte do código afetará.

***Analogia:** É como um mapa de trânsito muito detalhado que mostra como todas as estradas, cruzamentos e edifícios de uma cidade estão conectados entre si.*

## Como funciona

As ferramentas de desenvolvimento de software examinam seu projeto, marcam cada parte como um nó e registram as conexões entre elas. Este banco de dados é usado para fornecer sugestões ou encontrar erros enquanto você escreve o código.

## Onde é usado

Ele é usado em editores de código modernos, ferramentas de desenvolvimento de software baseadas em IA e gerenciamento de projetos de grande escala.

## Costuma ser confundido com

Não é apenas uma lista de arquivos ou uma simples estrutura de pastas; Também inclui os relacionamentos lógicos do código.

## Perguntas frequentes

**Por que isso é necessário?**

Porque em projetos muito grandes, é impossível rastrear manualmente onde uma alteração causará erros.
