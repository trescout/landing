# O que é AI Skills?

*Glossário · AI · Última atualização: 3 de junho de 2026*

> Skills

Capacidades ou ferramentas especiais que os modelos de IA usam para executar uma tarefa específica.

## Definição

São habilidades ou ferramentas especiais que os modelos de inteligência artificial usam para realizar uma tarefa específica. Esses recursos permitem que o modelo execute tarefas concretas, como pesquisar na internet ou executar código, em vez de apenas produzir texto.

***Analogia:** Embora um processador de alimentos tenha apenas um recurso de mistura, é como adicionar um acessório para fatiar ou ralar para que ele funcione mais.*

## Como funciona

O modelo aprende a usar conjuntos de comandos especiais ou ferramentas definidas para ele. Ele aciona essas ferramentas quando necessário, processa os dados e apresenta o resultado ao usuário.

## Onde é usado

É usado em assistentes inteligentes, ferramentas de análise de dados e software que automatiza tarefas complexas.

## Costuma ser confundido com

Muitas vezes é confundido com recursos gerais de IA, mas são ferramentas especializadas adicionadas para realizar um trabalho específico.

## Perguntas frequentes

**Todo modelo de IA possui habilidades de IA?**

Não, apenas os modelos equipados com essas capacidades ou autorizados a dirigir possuem essas capacidades.

**Essas habilidades podem ser adicionadas posteriormente?**

Sim, novos recursos podem ser adicionados a um modelo com infraestrutura apropriada e conexões de API.
