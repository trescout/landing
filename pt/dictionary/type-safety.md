# O que é Type Safety?

*Glossário · Dev · Última atualização: 13 de julho de 2026*

É uma regra de segurança que evita que tipos errados de dados sejam usados no software e detecta erros durante a escrita do código.

## Definição

Nas linguagens de programação, os dados possuem um 'tipo'; Por exemplo, você não pode adicionar um número e um texto. A segurança de tipo impõe tais regras de tipo. Se você cometer um erro, o computador avisa antes de executar o código. Esta é uma das maiores proteções que evitam falhas de software.

***Analogia:** É como a moldura de um quebra-cabeça que não permite que a peça se encaixe quando você tenta forçar a peça errada no lugar.*

## Como funciona

O sistema verifica constantemente seu código enquanto você o escreve. Se você inserir acidentalmente um número em uma caixa de texto, o programa notará isso imediatamente e apresentará um erro dizendo 'você só pode escrever texto aqui'.

## Onde é usado

É usado em linguagens como Rust, TypeScript, Java e em projetos de software de grande escala.

## Costuma ser confundido com

Não é apenas uma “mensagem de erro”; Este é o princípio básico de funcionamento da própria linguagem de programação.

## Perguntas frequentes

**Por que nem todo mundo usa?**

Algumas linguagens não exigem isso para flexibilidade, mas é definitivamente preferível evitar cometer erros em grandes projetos.
