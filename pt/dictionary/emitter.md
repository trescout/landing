# O que é Emitter?

É o mecanismo que converte dados ou códigos processados em um formato de saída que outro sistema ou ferramenta pode usar.

## Definição
O emissor geralmente está envolvido no estágio final de um analisador ou compilador. Depois que o analisador analisa e compreende os dados, o emissor grava essas informações em uma linguagem ou arquivo que a plataforma de destino entende. Isso pode ser na forma de conversão para código de máquina ou geração de uma saída JSON que uma API aceitará.

## Como funciona
Ele pega a estrutura de dados abstrata e a exporta de acordo com modelos ou regras predefinidas. A saída pode ser um arquivo, um pacote de rede ou diretamente a entrada de outra função.

## Onde é usado
Você encontra isso com frequência em compiladores, ferramentas de transformação de dados e sistemas orientados a eventos.

## Perguntas frequentes
**Qual é a diferença entre Emissor e Analisador?**
O Parser importa e analisa os dados, enquanto o Emitter apresenta os dados processados ​​ao exterior em um formato adequado.
