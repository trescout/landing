# O que é Agent-native Applications?

São aplicativos desenvolvidos especificamente para que agentes de inteligência artificial tomem decisões e realizem transações.

## Definição
Ao contrário dos aplicativos tradicionais, os aplicativos nativos do agente aguardam comandos de um agente de inteligência artificial em vez de interação humana. Esses aplicativos são estruturados de forma que os agentes possam utilizar facilmente as ferramentas. Isso significa que o aplicativo contém todos os recursos de que um agente precisa para concluir uma tarefa por conta própria.

## Como funciona
Esses aplicativos possuem portas especiais que permitem que um agente se comunique com o sistema em vez de uma interface padrão. O agente acessa dados e executa operações usando essas portas.

## Onde é usado
É usado em plataformas de automação, fluxos de trabalho inteligentes e ecossistemas de software autônomos.

## Costuma ser confundido com
Não deve ser confundido com recursos de inteligência artificial adicionados posteriormente a um aplicativo comum; estes são construídos desde o início para os agentes.

## Perguntas frequentes
**Por que eles precisam ser especialmente projetados?**
Porque os agentes preferem estruturas onde possam processar comandos diretos, em vez de menus complexos que as pessoas usam.

**As pessoas podem usar esses aplicativos?**
Sim, mas o foco do design está na eficiência dos agentes.
