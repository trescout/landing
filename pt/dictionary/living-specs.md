# O que é Living Specs?

*Desenvolvimento · Última atualização: 27 de outubro de 2026*

São requisitos técnicos que são atualizados automaticamente com o código durante o processo de desenvolvimento do software e refletem o status atual do projeto.

## Definição

A documentação tradicional se torna obsoleta à medida que o projeto avança, mas esse método torna a documentação parte do código. Esses requisitos são atualizados sempre que uma alteração é feita no software. Dessa forma, os desenvolvedores sempre têm um roteiro atualizado.

***Analogia:** É como ter o mapa de uma cidade como um display digital que é atualizado automaticamente à medida que as estradas são construídas.*

## Como funciona

Graças aos comentários no código ou às ferramentas automatizadas, os documentos técnicos são mantidos sincronizados com a versão atual do código.

## Onde é usado

É usado para gerenciar a complexidade em grandes projetos de software e trabalho em equipe.

## Costuma ser confundido com

Difere dos documentos técnicos tradicionais que são estáticos e se tornam obsoletos com o tempo.

## Perguntas e respostas

**Por que não usamos documentos estáticos?**

Porque os documentos estáticos ficam desatualizados muito rapidamente e podem enganar os desenvolvedores.

**Isso é difícil de instalar?**

Requer ferramentas de automação, mas economiza muito tempo no longo prazo.
