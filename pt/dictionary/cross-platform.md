# O que é Cross-platform?

*Glossário · Dev · Última atualização: 14 de outubro de 2026*

Tipo de software que pode funcionar perfeitamente em diferentes sistemas operacionais ou dispositivos.

## Definição

Às vezes, os desenvolvedores de software preferem usar uma única base de código para criar aplicativos que funcionam tanto em computadores quanto em celulares, em vez de escrever códigos separados para cada dispositivo. Essa abordagem economiza tempo e facilita a manutenção.

***Analogia:** É como uma mala inteligente que pode viajar de bicicleta, de carro e a pé.*

## Como funciona

Os códigos escritos em uma infraestrutura comum são executados sendo traduzidos para a linguagem do dispositivo de destino.

## Onde é usado

É amplamente utilizado em projetos de desenvolvimento de aplicativos móveis e de desktop.

## Costuma ser confundido com

Diferencia-se nesse aspecto dos aplicativos nativos presos a um único dispositivo.

## Perguntas frequentes

**Por que é preferido?**

Reduz os custos e acelera o processo de desenvolvimento.
