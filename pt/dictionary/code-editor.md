# O que é Code Editor?

Um editor de texto especial onde os desenvolvedores de software se beneficiam de recursos como coloração e verificação de erros ao escrever códigos de computador.

## Definição
Um editor de código é uma ferramenta de software inteligente que, ao contrário dos editores de texto simples normais, entende as regras da linguagem de programação em que você escreve. Ele torna seus códigos mais fáceis de ler, exibindo-os em cores, completa automaticamente as palavras que você digita e informa sobre seus erros antes de executá-los. Pode ser considerada a versão digital mais avançada de lápis e borracha no mundo do software.

## Como funciona
À medida que você insere linhas de código no teclado, ele analisa a linguagem em segundo plano. Ele verifica instantaneamente se os comandos digitados são válidos ou não e acelera o processo de desenvolvimento.

## Onde é usado
Ele aparece em todas as principais telas de programação que você utiliza ao desenvolver software no seu computador ou na nuvem.

## Costuma ser confundido com
Não confundir com ferramentas IDE, que são grandes ambientes de desenvolvimento que compilam todo o sistema do início ao fim e o transformam em software funcional; O editor é mais focado e leve.

## Perguntas frequentes
**Qual é a diferença entre editor de código e bloco de notas normal?**
Cadernos normais exibem texto em preto e branco. Os editores de código oferecem coloração, preenchimento automático e suporte a plug-ins.
