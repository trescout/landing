# O que é Bash Script?

É uma sequência de comandos que automatiza operações de várias etapas que precisam ser realizadas no computador, reunindo-as em um único arquivo.

## Definição
O script Bash permite combinar os comandos digitados um por um na linha de comando do computador e armazená-los em um único arquivo. Quando você executa este arquivo, todos os comandos nele contidos são executados sequencialmente e sem erros. É um dos maiores ajudantes dos desenvolvedores de software, principalmente para agilizar tarefas repetitivas.

## Como funciona
Você abre um arquivo de texto e escreve os comandos que deseja executar, um abaixo do outro. Depois de salvar o arquivo e torná-lo executável, você inicia todo o processo com um único clique ou comando.

## Onde é usado
É frequentemente usado em gerenciamento de servidores, operações de backup ou processos de instalação de software.

## Perguntas frequentes
**Por que devo usar script em vez de escrevê-lo à mão?**
Reduz a margem de erro e permite que você execute sempre a mesma operação na mesma velocidade.
