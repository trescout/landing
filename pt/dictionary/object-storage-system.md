# O que é Object Storage System?

*Glossário · Data · Última atualização: 19 de setembro de 2026*

É um método de armazenamento em larga escala que guarda dados com identificadores únicos em vez de pastas de arquivos.

## Definição

O sistema de arquivos do seu computador tradicional é como uma estrutura de árvore; ele progride na forma de pastas dentro de pastas. O armazenamento de objetos trata o dado como um objeto e lhe atribui uma identidade específica. Dessa forma, em vez de seguir caminhos de pastas para acessar o dado, você pode acessá-lo rapidamente usando diretamente essa identidade.

***Analogia:** É como se, em uma biblioteca, em vez de procurar um livro por prateleiras e números, você escaneasse um código de barras mágico colado no livro e ele fosse instantaneamente teletransportado para suas mãos.*

## Como funciona

Quando o dado é carregado no sistema, ele se torna um objeto e algumas descrições (metadados) são adicionadas a ele. Quando você precisa, você chama esse objeto através de sua identidade.

## Onde é usado

É utilizado em serviços de armazenamento em nuvem, backups de grandes volumes de dados e na entrega de conteúdos de mídia.

## Costuma ser confundido com

Pode ser confundido com sistemas de arquivos de discos rígidos comuns; no entanto, este sistema foi projetado para dados muito maiores.

## Perguntas frequentes

**Por que não usa pastas?**

Porque gerenciar bilhões de dados em uma estrutura de pastas é muito lento, enquanto o sistema de objetos é muito mais rápido.
