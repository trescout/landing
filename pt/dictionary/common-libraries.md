# O que é Common Libraries?

Pacotes de código pré-preparados para que os desenvolvedores de software possam executar facilmente operações usadas com frequência.

## Definição
São soluções prontas usadas para evitar reinventar a roda a cada vez durante o desenvolvimento de software. Essas bibliotecas permitem realizar muitas tarefas complexas, desde operações matemáticas até gerenciamento de arquivos, com um único comando. Adicioná-lo ao seu projeto economiza tempo e reduz o risco de erros.

## Como funciona
Você inclui a biblioteca necessária em seu projeto e chama as funções prontas em seu próprio código.

## Onde é usado
É usado em quase todos os projetos de software, como processamento de dados, conexões de rede ou criação de interface visual.

## Costuma ser confundido com
Pode ser confundido com Framework; O framework desenha o esqueleto do projeto e a biblioteca oferece apenas a ferramenta que você precisa.

## Perguntas frequentes
**Todas as bibliotecas são seguras?**
Não, como qualquer código externo, as bibliotecas devem ser verificadas quanto à atualização e confiabilidade.

**Posso fazer minha própria biblioteca?**
Sim, você pode empacotar os códigos que usa com frequência e reutilizá-los em outros projetos.
