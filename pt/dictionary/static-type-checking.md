# O que é Static Type Checking?

*Glossário · Dev · Última atualização: 22 de agosto de 2026*

É um mecanismo de segurança que encontra automaticamente erros de dados antes mesmo de o código ser executado.

## Definição

No processo de desenvolvimento de software, é uma verificação feita antes que as linhas de código sejam processadas pelo computador. Este sistema verifica se as variáveis ​​carregam o tipo correto de dados. Por exemplo, se um texto for inserido acidentalmente onde um número é esperado, o sistema notará isso imediatamente.

***Analogia:** É como um especialista em controle de qualidade separando as peças defeituosas antes que os produtos passem pela esteira de uma fábrica; Assim, o produto danificado fica impedido de chegar ao usuário final.*

## Como funciona

Ao escrever o código, a linguagem de programação segue essas regras e avisa se houver erros. Dessa forma, a possibilidade de seu aplicativo travar inesperadamente durante a execução é reduzida.

## Onde é usado

É amplamente utilizado em ferramentas modernas de desenvolvimento de software e bases de código de projetos de grande escala.

## Costuma ser confundido com

Pode ser confundido com erros de tempo de execução, mas esse método detecta erros enquanto você escreve o código.

## Perguntas frequentes

**Por que devo usar o controle estático?**

Encontrar bugs antes que eles ocorram economiza tempo e torna o software mais seguro.

**Está disponível em todos os idiomas?**

Não, algumas linguagens exigem isso internamente, enquanto outras podem exigir ferramentas adicionais.
