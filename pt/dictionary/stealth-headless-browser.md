# O que é Stealth Headless Browser?

Um navegador invisível que contorna firewalls em sites, impedindo que seja detectado como um robô.

## Definição
São softwares que não possuem uma interface visual como os navegadores padrão, mas que visitam sites imitando o comportamento de um usuário humano. Graças ao recurso 'stealth' (furtivo), eles podem contornar os sistemas de bloqueio de robôs usados pelos sites. Dessa forma, as operações de coleta de dados continuam ininterruptas, parecendo um usuário normal.

## Como funciona
O navegador é configurado para exibir detalhes como resolução de tela, movimentos do mouse e assinatura de software de forma a simular o comportamento humano.

## Onde é usado
Utilizado em processos como web scraping, testes automatizados e monitoramento de preços.

## Costuma ser confundido com
Navegador Headless

## Perguntas frequentes
**Por que não usamos navegadores normais?**
Navegadores normais consomem muitos recursos e não conseguem realizar milhares de operações simultaneamente em segundo plano.
