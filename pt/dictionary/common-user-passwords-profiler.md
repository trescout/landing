# O que é Common User Passwords Profiler?

*Glossário · Dev · Última atualização: 1 de julho de 2026*

> CUPS

É uma ferramenta que identifica vulnerabilidades de segurança analisando senhas fracas que as pessoas usam com frequência.

## Definição

Esta ferramenta coleta os erros que as pessoas cometem ao criar senhas (por exemplo, usando '123456' ou 'senha') em um banco de dados. Os especialistas em segurança cibernética usam essas listas para testar a facilidade com que um sistema pode ser hackeado. Seu objetivo é comprovar o perigo de senhas fracas.

***Analogia:** É como ter um especialista em segurança verificando sua casa, sabendo em quais janelas os ladrões têm mais dificuldade.*

## Como funciona

Ele compara as senhas do sistema com esta lista comum. Se houver uma correspondência, o sistema será relatado como fraco.

## Onde é usado

É usado em auditorias de segurança cibernética e processos de criação de políticas de senha.

## Costuma ser confundido com

Pode ser confundido com listas de palavras; Esta ferramenta é um mecanismo de análise que utiliza essas listas.

## Perguntas frequentes

**Posso testar minha própria senha?**

Sim, mas você deve fazer isso com ferramentas confiáveis ​​e em seus próprios sistemas.
