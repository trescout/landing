# O que é Exponential Time Hypothesis?

*Desenvolvimento · Última atualização: 27 de outubro de 2026*

É uma abordagem teórica que sugere que o tempo de solução de alguns problemas difíceis aumenta exponencialmente à medida que a quantidade de insumos aumenta.

## Definição

Embora algumas operações na ciência da computação pareçam simples, à medida que a quantidade de dados aumenta, elas colocam muita pressão no processador. Esta hipótese argumenta que certos problemas não podem ser resolvidos mais rapidamente e levarão inerentemente muito tempo. É um critério para os desenvolvedores de software entenderem o quão eficiente um algoritmo deve ser.

***Analogia:** É como tentar todas as combinações de uma fechadura, com o tempo de processamento aumentando cada vez que o comprimento da senha aumenta.*

## Como funciona

Métodos mais eficientes são buscados levando essa hipótese em consideração durante o projeto do algoritmo.

## Onde é usado

A criptografia aparece na análise de dados e em problemas complexos de otimização.

## Costuma ser confundido com

Fala não apenas sobre códigos de execução lenta, mas também sobre a dificuldade de resolver o problema matematicamente.

## Perguntas e respostas

**Como essa hipótese afeta o software?**

Permite-nos compreender quais os problemas que não têm solução e utilizar corretamente os nossos recursos.

**Todos os problemas são assim?**

Não, só se aplica a problemas de certa complexidade.
