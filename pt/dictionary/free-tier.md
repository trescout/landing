# O que é Free Tier?

É o nível de entrada de um serviço oferecido gratuitamente com recursos limitados.

## Definição
É um modelo de teste que as empresas oferecem para acostumar os usuários ao sistema. Geralmente é um pacote no qual uma determinada cota de uso ou alguns recursos avançados são restritos. Quando a necessidade aumenta, os usuários mudam para planos pagos.

## Como funciona
O usuário cria uma conta e o sistema define automaticamente os limites gratuitos. Quando o limite é atingido, o sistema avisa e pede uma atualização.

## Onde é usado
É comum em serviços de software (SaaS), APIs de IA e plataformas em nuvem.

## Costuma ser confundido com
Não deve ser confundido com software totalmente gratuito; faz parte de um modelo de negócios.

## Perguntas frequentes
**Ilimitado?**
Não, geralmente há restrições com base na quantidade de uso ou nos recursos.

**Quando devo pagar uma taxa?**
Você paga quando excede seus limites ou precisa de recursos mais avançados.
