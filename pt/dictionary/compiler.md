# O que é Compiler?

É um programa que traduz os códigos escritos por humanos em linguagem de máquina que o computador pode compreender e executar diretamente.

## Definição
Os computadores só entendem 0s e 1s. Os programadores, por outro lado, escrevem código em uma linguagem mais compreensível. O compilador atua como um tradutor, pegando essa linguagem do desenvolvedor e convertendo-a em uma linguagem que o processador do computador entenda.

## Como funciona
Você escreve e salva seu código e, em seguida, executa o comando do compilador. O compilador verifica seu código, se não houver erros, ele o transforma em um arquivo executável.

## Onde é usado
Está no centro de todos os processos de desenvolvimento de software.

## Perguntas frequentes
**O compilador de cada linguagem é diferente?**
Sim, toda linguagem de programação precisa de um compilador ou interpretador que atenda às suas próprias regras.
