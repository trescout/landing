# O que é CLI Agent?

*Glossário · Dev · Última atualização: 21 de julho de 2026*

> Command Line Interface Agent

É um software que gerencia automaticamente operações e executa tarefas em nome do usuário por meio da linha de comando do computador.

## Definição

Os agentes CLI escrevem comandos e leem a saída para você no mundo da linha de comando com tela preta. Eles podem realizar tarefas técnicas como gerenciamento de arquivos, instalações de sistemas ou configurações de servidores sem esperar por seus comandos. Eles gerenciam tarefas complexas do sistema usando o terminal como um ser humano.

***Analogia:** É como um mecânico digital que entra no computador e conserta o motor apenas com as instruções que você dá.*

## Como funciona

Você concede acesso ao seu terminal; Ele também lista arquivos, atualiza pacotes ou resolve problemas verificando logs.

## Onde é usado

É usado no gerenciamento de servidores, processos de distribuição de software e automação de sistemas complexos.

## Costuma ser confundido com

Pode ser confundido com um simples script 'script' ou 'shell'; os agentes têm a capacidade de tomar decisões com base nos resultados.

## Perguntas frequentes

**É seguro?**

O Terminal é uma ferramenta altamente autorizada, portanto, você só deve executar agentes em quem confia.

**Quais comandos ele usa?**

Ele usa comandos de terminal padrão suportados pelo seu sistema operacional.
