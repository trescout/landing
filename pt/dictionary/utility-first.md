# O que é Utility-first?

*Glossário · Dev · Última atualização: 6 de agosto de 2026*

É uma abordagem para criar estilos rapidamente usando comandos (classes) pequenos e funcionais predefinidos ao projetar.

## Definição

Em vez de escrever códigos CSS longos para cada elemento, você cria o design combinando pequenos comandos prontos, como 'cor azul', 'margem-10'. Este método garante um desenvolvimento consistente e rápido do projeto.

***Analogia:** É como construir uma casa com peças de Lego; Em vez de produzir cada peça do zero, você pode construir rapidamente o design desejado combinando peças prontas.*

## Como funciona

Você adiciona tags curtas em seus códigos HTML que especificam a aparência do design.

## Onde é usado

É frequentemente usado em web design moderno e especialmente em bibliotecas como Tailwind CSS.

## Costuma ser confundido com

Pode ser confundido com a estrutura CSS; utility-first é um método, enquanto o framework CSS é a ferramenta que implementa esse método.

## Perguntas frequentes

**O código não parece muito lotado?**

Pode parecer à primeira vista, mas é uma grande vantagem poder ver todo o design em um só lugar, sem alternar entre arquivos.
