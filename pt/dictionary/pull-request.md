# O que é Pull Request?

*Desenvolvimento · Última atualização: 5 de novembro de 2026*

> PR

Uma solicitação na qual um desenvolvedor submete as alterações que deseja adicionar a um repositório de código para revisão e aprovação.

## Definição

Um Pull Request permite que as alterações feitas no código sejam revisadas por outros membros da equipe antes de serem incorporadas ao projeto principal. Graças a esse processo, erros são detectados precocemente e a qualidade do código é preservada. É uma das pedras angulares dos processos de desenvolvimento de software colaborativo.

***Analogia:** É como um autor submetendo um novo capítulo que deseja adicionar ao livro para a aprovação do editor ou editor-chefe.*

## Como funciona

O desenvolvedor conclui seu desenvolvimento em sua própria ramificação de trabalho e envia para o repositório. Em seguida, abre um Pull Request para convidar seus colegas de equipe a revisar o código. Após a revisão, os feedbacks fornecidos são corrigidos e, uma vez obtida a aprovação, o código é mesclado à ramificação principal.

## Onde é usado

É utilizado no gerenciamento de projetos de software em plataformas de controle de versão como GitHub, GitLab e Bitbucket.

## Costuma ser confundido com

Pode ser confundido com o conceito de Git Push. Enquanto o Git Push envia alterações de código para o servidor, o Pull Request inicia um processo de revisão e discussão para que essas alterações sejam mescladas ao código principal.

## Perguntas e respostas

**Por que o Pull Request é importante?**

Aumenta a qualidade do código, permite o compartilhamento de conhecimento dentro da equipe e evita que códigos com erros sejam levados para o sistema de produção.

**Um Pull Request pode ser rejeitado?**

Sim, se o código não estiver em conformidade com os padrões ou se houver lacunas, ele pode ser rejeitado ou pode ser solicitada uma revisão para que seja corrigido.
