# O que é Agents Directory?

*Glossário · AI · Última atualização: 11 de outubro de 2026*

É uma estrutura de pastas dedicada em projetos de software que mantém reunidos os comportamentos, ferramentas e regras de agentes de inteligência artificial.

## Definição

O diretório de agentes (agents directory) é o diretório em uma base de código que abriga as instruções e as conexões de ferramentas de agentes de inteligência artificial projetados para diferentes tarefas. Ele permite que você organize os limites de tarefas e os padrões de comportamento de vários assistentes autônomos que trabalham no seu projeto em um único local padrão. Ferramentas de desenvolvimento e motores de orquestração examinam este diretório para reconhecer automaticamente os agentes específicos do seu projeto.

***Analogia:** É semelhante à pasta de recursos humanos de uma empresa, onde a descrição de cargo, as autorizações e os manuais de orientação de cada funcionário especialista são mantidos organizados.*

## Como funciona

Os desenvolvedores geralmente criam uma pasta chamada .agents ou agents no diretório raiz do projeto. Dentro dessa pasta, são adicionados arquivos de configuração para cada agente que escreve testes, revisa códigos ou prepara documentações. As ferramentas de desenvolvimento com suporte a agentes leem esses arquivos para determinar quais funções o agente assumirá e quais funções ele poderá chamar.

## Onde é usado

É frequentemente utilizado em ambientes de desenvolvimento de software baseados em agentes, plataformas de orquestração de inteligência artificial e editores de código modernos.

## Costuma ser confundido com

Pode ser confundido com o conceito geral de "espaço de trabalho de agentes" (agent workspace): enquanto o espaço de trabalho se refere à memória temporária e aos arquivos temporários que o agente utiliza ao realizar o trabalho, o diretório de agentes é o diretório de arquivos permanente onde o código-fonte e as definições de regras dos agentes são armazenados.

## Perguntas frequentes

**Os agentes de inteligência artificial não conseguem funcionar sem esta pasta?**

Eles conseguem funcionar, mas você precisaria especificar manualmente as instruções de sistema e as ferramentas que cada agente pode usar, um por um; a estrutura de diretório automatiza e padroniza esse processo.

**Os agentes na pasta conseguem se comunicar uns com os outros automaticamente?**

Conseguem: sistemas com arquitetura multi-agente listam os agentes neste diretório e os utilizam como um guia para delegar uma tarefa a outro agente.
