# O que é Trading Strategies?

Um conjunto de regras lógicas que determinam em que condições comprar ou vender ao investir.

## Definição
Uma estratégia consiste em instruções claras como “compre se o preço cair para o nível X, venda se o preço subir para o nível Y”. Essas estratégias são utilizadas para prevenir decisões emocionais e garantir uma disciplina de investimento consistente. No mundo da inteligência artificial, estas estratégias formam os padrões comportamentais básicos dos agentes.

## Como funciona
Os investidores testam suas estratégias em dados históricos (backtesting) e começam a usar as regras mais lucrativas do mercado real.

## Onde é usado
É usado em software de mercado de ações, plataformas de investimento e ferramentas financeiras baseadas em inteligência artificial.

## Costuma ser confundido com
Está misturado com agente comercial; A estratégia é a regra, o agente é o software que implementa esta regra.

## Perguntas frequentes
**A estratégia sempre funciona?**
Não, as estratégias antigas podem tornar-se ineficazes quando as condições do mercado mudam.

**Quem determina a estratégia?**
Normalmente, os analistas de dados ou modelos de inteligência artificial criam a estratégia mais eficiente examinando dados históricos.
