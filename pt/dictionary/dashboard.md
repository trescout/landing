# O que é Dashboard?

Painel que permite rastrear visualmente dados e estatísticas complexas em uma única tela.

## Definição
O Dashboard é como um painel de controle digital. Ele resume o status atual, o desempenho e os dados importantes de um sistema ou aplicativo com gráficos ou tabelas. Ele simplifica informações complexas e permite entendê-las rapidamente.

## Como funciona
Geralmente é alimentado por uma fonte da qual os dados são coletados. Os desenvolvedores de software apresentam esses dados ao usuário por meio de bibliotecas de visualização. Basta olhar para a tela e analisar o que está acontecendo e como.

## Onde é usado
Ele é usado no mundo dos negócios para rastrear gráficos de vendas, monitorar o desempenho do servidor ou para aplicativos de orçamento pessoal.

## Costuma ser confundido com
Pode ser confundido com relatórios, mas o painel fornece dados interativos e ao vivo.

## Perguntas frequentes
**O painel mostra dados ao vivo?**
Sim, geralmente reflete o status atual do sistema instantaneamente.

**Alguém pode fazer um painel?**
Sim, você pode visualizar seus próprios dados com ferramentas simples.
