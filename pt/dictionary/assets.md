# O que é Assets?

É o conjunto de todas as partes digitais que compõem um projeto.

## Definição
Quaisquer recursos externos que você usa ao desenvolver software ou jogos são chamados de “ativos”. Estes não são o código em si, mas os materiais auxiliares de que o código necessita. São as matérias-primas visuais, sonoras ou estruturais de um projeto.

## Como funciona
Eles são mantidos em pastas separadas nos arquivos do projeto e você os chama referenciando esses arquivos enquanto escreve o código.

## Onde é usado
Ele é usado em todos os projetos de desenvolvimento de jogos, web design e aplicativos móveis.

## Perguntas frequentes
**Os arquivos de código são considerados ativos?**
Geralmente não, embora o código seja considerado a estrutura principal; Visuais, sons e modelos 3D são classificados como ativos.
