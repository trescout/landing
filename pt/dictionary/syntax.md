# O que é Syntax?

São as regras de escrita que devem ser seguidas para que o código funcione sem erros em uma linguagem de programação.

## Definição
É o equivalente às regras gramaticais no mundo do código. Ao contrário dos humanos, os computadores não são flexíveis; por isso, a falta de um ponto e vírgula ou um parêntese no lugar errado impede que o código funcione. Esse conjunto de regras que determina a estrutura do código é chamado de sintaxe.

## Como funciona
Os editores de código geralmente o alertam durante a escrita. Quando você recebe um erro, você vai até a linha marcada pelo editor e faz a correção verificando os parênteses ou comandos.

## Onde é usado
É utilizado em todas as linguagens de programação e linguagens de script.

## Costuma ser confundido com
É confundido com erros lógicos; enquanto um erro de sintaxe impede que o código funcione, um erro lógico faz com que o código forneça um resultado incorreto.

## Perguntas frequentes
**O que devo fazer se receber um erro de sintaxe?**
Verifique o número da linha na mensagem de erro e revise as regras de escrita.
