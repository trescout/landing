# O que é Assembly?

É o processo de reunir vários componentes ou peças para formar um sistema complexo.

## Definição
Montagem é a combinação de diferentes bibliotecas, módulos ou peças de hardware no mundo do software em um único todo funcional. Você pode pensar nisso como colocar os tijolos de um prédio; Embora cada peça faça sentido por si só, uma estrutura funcional só surge após o processo de montagem. Em projetos de software, esse processo geralmente está interligado com etapas de “construção” ou “compilação”.

## Como funciona
Os desenvolvedores reúnem os pedaços de código, bibliotecas e arquivos de configuração que escrevem para criar um ‘pacote’.

## Onde é usado
É utilizado em processos de desenvolvimento de software, automação de fábrica e instalação de grandes sistemas.

## Costuma ser confundido com
Não deve ser confundido com linguagem assembly; O termo é usado aqui para significar “processo de unificação”.

## Perguntas frequentes
**Por que o dividimos em pedaços?**
Para facilitar o gerenciamento, encontrando erros e reaproveitando peças em outros projetos.
