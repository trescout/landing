# O que é Bindings?

São pontes que permitem que diferentes linguagens de programação utilizem as bibliotecas umas das outras.

## Definição
Uma biblioteca geralmente é escrita em uma única linguagem (por exemplo, C++). No entanto, se estiver usando Python, você não poderá usar essa biblioteca diretamente. Binding é uma interface que traduz essa biblioteca em uma linguagem que o Python entende. Dessa forma, você pode ultrapassar as fronteiras do idioma e usar as melhores ferramentas no idioma desejado.

## Como funciona
Os desenvolvedores criam uma pequena camada de código que transporta as funções da biblioteca principal para a linguagem de destino. Portanto, operações complexas na biblioteca principal funcionam como um comando simples em sua própria linguagem.

## Onde é usado
A maioria dos modelos de IA são escritos em C++, mas graças às ligações do Python podemos usá-los facilmente com o Python.

## Costuma ser confundido com
Pode ser confundido com API, mas enquanto a API se comunica pela rede, a ligação é uma conexão no nível da memória dentro do mesmo computador.

## Perguntas frequentes
**Por que nem todas as bibliotecas são escritas em todos os idiomas?**
Linguagens de baixo nível (C++) são preferidas para desempenho, linguagens de alto nível (Python) são preferidas para facilidade de uso.

**A ligação fica mais lenta?**
Embora geralmente haja uma ligeira perda de desempenho, a conveniência que ela oferece vale a pena.
