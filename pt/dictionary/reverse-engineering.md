# O que é Reverse Engineering?

É o processo de desmontar um produto, sistema ou software concluído para entender como ele funciona e decifrar seus princípios de funcionamento.

## Definição
A engenharia reversa é a arte de compreender a estrutura interna de uma construção que não possui documentos de design ou código-fonte. Nesse processo, observa-se como o produto reage às entradas e todos os componentes são examinados um por um. Como enfatizamos frequentemente na plataforma TreScout, este método não é usado para copiar tecnologias existentes, mas sim para melhorá-las e torná-las mais seguras.

## Como funciona
Primeiramente, o sistema-alvo é observado e testado detalhadamente. Em seguida, o sistema é desmontado passo a passo, seja de forma física ou lógica. Na fase final, você reúne os dados obtidos para criar um novo esquema que mostre a lógica de funcionamento do sistema.

## Onde é usado
Você pode recorrer frequentemente a isso na segurança cibernética para decifrar a lógica de funcionamento de softwares maliciosos. Além disso, você pode usar este método na modernização de sistemas antigos que não possuem documentação.

## Costuma ser confundido com
É confundido com o termo "engenharia reversa de software" (software reverse engineering), que é específico do mundo do software. A engenharia reversa é um conceito guarda-chuva muito mais amplo que também abrange máquinas físicas e hardwares.

## Perguntas frequentes
**Fazer engenharia reversa é legal?**
Depende do seu propósito de uso. Embora seja geralmente considerada legal quando feita para fins de análise de segurança ou para garantir a compatibilidade do sistema, realizá-la com a intenção de violar direitos autorais pode gerar problemas jurídicos.

**É obrigatório saber programar para realizar esse processo?**
Se você estiver examinando uma máquina física, conhecimentos de mecânica são suficientes. No entanto, se quiser decifrar softwares no mundo digital, você precisará de conhecimentos avançados de codificação e arquitetura de sistemas.
