# O que é Caching?

Os dados usados com frequência são armazenados temporariamente na memória para acesso rápido.

## Definição
Cache é um método de aceleração usado para evitar que um sistema calcule repetidamente os mesmos dados ou extraia-os de uma fonte remota. Os dados são copiados para uma área de acesso rápido (cache) e servidos a partir daí quando necessário. Isto reduz significativamente o tempo de resposta geral do sistema.

## Como funciona
Quando o sistema solicita dados, ele primeiro analisa o cache; Se os dados estiverem lá, ele os recupera imediatamente; caso contrário, ele os extrai da fonte principal e deixa uma cópia no cache.

## Onde é usado
É amplamente utilizado para melhorar o desempenho em navegadores da web, aplicativos e data centers de grande escala.

## Costuma ser confundido com
Pode ser confundido com um banco de dados, mas o cache é temporário e rápido, enquanto o banco de dados é permanente e maior.

## Perguntas frequentes
**O que acontece se o cache ficar cheio?**
Dados antigos ou raramente usados ​​são excluídos e substituídos por novos dados.
