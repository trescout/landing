# O que é Emulator?

É uma ferramenta que permite executar programas em outros dispositivos por meio de software que emula o hardware de um computador ou console de jogo.

## Definição
O emulador simula o processador e a lógica operacional de um dispositivo em um ambiente virtual. Dessa forma, você pode usar o software executado no dispositivo original em uma plataforma diferente sem precisar da presença física desse dispositivo. É frequentemente usado especialmente para jogar jogos antigos em computadores atuais.

## Como funciona
Você instala o software emulador e, em seguida, carrega os arquivos de software (geralmente chamados de ROM) do sistema que deseja executar no sistema. O emulador lê esses arquivos e os exibe na tela como se você estivesse no dispositivo original.

## Onde é usado
No mundo dos jogos, ele é usado para reviver consoles antigos, para desenvolvedores de software testarem em diferentes dispositivos ou para executar sistemas operacionais antigos.

## Costuma ser confundido com
Pode ser confundido com simulador; Enquanto o simulador apenas imita o comportamento, o emulador tenta copiar exatamente a lógica de funcionamento do hardware.

## Perguntas frequentes
**É legal usar um emulador?**
O software emulador em si é legal, mas usar arquivos de jogos protegidos por direitos autorais sem permissão pode criar problemas legais.

**Ele pode executar qualquer coisa no meu computador?**
Normalmente a potência do seu hardware precisa ser maior que a do dispositivo emulado.
