# O que é Interface?

*Dev · Última atualização: 12 de outubro de 2026*

É o limite de comunicação comum que permite a um usuário gerenciar um sistema ou a dois componentes de software conversarem entre si.

## Definição

Interface refere-se ao ponto de encontro onde dois sistemas independentes ou um humano e um computador interagem. No mundo do software, é um conceito abrangente que define todos os tipos de superfícies de contato, desde telas gráficas (UI) até pontes de dados entre sistemas (API). Na programação orientada a objetos, atua como um contrato técnico vinculativo que declara quais funções um componente oferecerá ao mundo exterior.

***Analogia:** O volante e os pedais de um automóvel são a interface que permite ao motorista controlar o motor; as tomadas padrão onde os cabos do motor sob o capô são conectados são as interfaces das próprias peças.*

## Como funciona

O mecanismo complexo em segundo plano do sistema é ocultado e caminhos de controle padrão acessíveis ao mundo exterior são definidos. Enquanto para humanos essa interação é apresentada por meio de botões e formulários, para softwares ela é executada por meio de funções de código vinculadas a regras específicas. Mesmo que a estrutura interna ou os códigos sejam completamente renovados, desde que as regras da interface sejam mantidas, a conexão continua funcionando sem interrupções.

## Onde é usado

É utilizada em menus de navegação de sites, telas de aplicativos móveis, linhas de comando de sistemas operacionais e serviços de segundo plano onde servidores compartilham dados entre si.

## Costuma ser confundido com

É confundida apenas com a interface do usuário (UI), que é o design da tela. No entanto, a UI é apenas a parte da interface voltada para o ser humano; as APIs, onde as máquinas conversam entre si, também são interfaces.

## Perguntas frequentes

**Interface e UI são a mesma coisa?**

Não: A UI abrange diretamente as telas que o ser humano vê e toca, enquanto a interface geral (Interface) é um termo mais amplo que inclui também os pontos de contato invisíveis onde os softwares se comunicam em nível de código.

**Por que a interface é importante no desenvolvimento de software?**

Permite que códigos escritos por equipes diferentes sejam integrados perfeitamente, sem que precisem conhecer os detalhes um do outro, apenas seguindo as regras estabelecidas.
