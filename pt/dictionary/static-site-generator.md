# O que é Static Site Generator?

Uma ferramenta que pega conteúdos e templates prontos e os transforma em páginas fixas prontas para serem apresentadas ao usuário.

## Definição
Os sites tradicionais extraem informações do banco de dados para cada visitante. Já o gerador de sites estáticos faz esse processo uma única vez, cria as páginas antecipadamente e envia apenas os arquivos prontos para o visitante. Isso garante que seu site carregue muito rapidamente e seja mais seguro.

## Como funciona
Você escreve seu conteúdo em Markdown ou arquivos semelhantes. A ferramenta combina esses conteúdos com modelos de design e produz arquivos HTML. Você também carrega esses arquivos na Internet.

## Onde é usado
É frequentemente preferido em blogs, sites de documentação e portfólios pessoais.

## Costuma ser confundido com
É misturado com CMS (Sistema de Gerenciamento de Conteúdo); O CMS usa um banco de dados, enquanto esta ferramenta produz apenas arquivos.

## Perguntas frequentes
**Como faço para atualizar meu site?**
Ao alterar o conteúdo e executar a ferramenta novamente, você gera e carrega novos arquivos.

**Nenhum banco de dados é necessário?**
Não, não requer banco de dados, o que o torna muito rápido.
