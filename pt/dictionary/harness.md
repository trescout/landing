# O que é Harness?

É um mecanismo de controle que verifica se um software ou sistema opera de acordo com os padrões esperados.

## Definição
No mundo do software, o aproveitamento é geralmente uma estrutura que automatiza os processos de teste. Depois que um trecho de código é escrito, ele verifica constantemente se esse código reage corretamente em diferentes cenários. É como uma rede de segurança que realiza uma “verificação de saúde” do sistema.

## Como funciona
Os desenvolvedores escrevem cenários de teste para seus códigos e colocam esses cenários em uma estrutura. O sistema executa esses testes automaticamente sempre que o código é atualizado e avisa se houver erros.

## Onde é usado
É utilizado em processos de desenvolvimento de software, linhas de integração contínua (CI) e etapas de controle de qualidade.

## Costuma ser confundido com
Não é apenas o software em si, é o “ambiente” ou “infraestrutura” que testa o software.

## Perguntas frequentes
**Por que um equipamento de teste é necessário?**
Para reduzir o erro humano e garantir que o código não seja quebrado a cada alteração.

**É necessário um chicote para cada software?**
É prática padrão garantir confiabilidade em projetos profissionais.
