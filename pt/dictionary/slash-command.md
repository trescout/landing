# O que é Slash Command?

*Desenvolvimento · Última atualização: 17 de novembro de 2026*

São comandos curtos iniciados por uma barra inclinada que os usuários utilizam em um chat ou interface de linha de comando.

## Definição

São atalhos iniciados por uma barra inclinada usados para realizar ações rápidas no mundo do software. Por exemplo, em vez de digitar ajuda ou configurações em uma janela de chat, permite que você execute esses comandos de uma só vez. Permite que você os acione rapidamente sem precisar se lembrar dos recursos prontos oferecidos pela interface.

***Analogia:** É como pedir diretamente ao garçom pelo nome do código em vez de ler o menu demoradamente em um restaurante.*

## Como funciona

Quando você digita o caractere de barra inclinada na interface, o sistema traz automaticamente a lista de comandos disponíveis. Quando você continua digitando e pressiona enter, o programa em segundo plano executa um longo processo de uma só vez. Geralmente aparece com frequência em janelas de chat e ferramentas de desenvolvimento.

## Onde é usado

É frequentemente utilizado em bots de chat, janelas de terminal e editores de código com inteligência artificial.

## Costuma ser confundido com

É frequentemente confundido com mensagens de chat normais, mas, graças ao caractere especial no início, é percebido diretamente como um comando e não como um texto comum.

## Perguntas e respostas

**Por que a barra inclinada é usada?**

Este caractere foi escolhido como padrão para que o sistema possa distinguir facilmente entre textos normais e comandos.

**Podemos escrever nosso próprio comando?**

Sim, muitas plataformas de software permitem que você defina seus próprios comandos de atalho personalizados.
