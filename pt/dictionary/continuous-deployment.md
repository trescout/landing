# O que é Continuous Deployment?

*Glossário · Dev · Última atualização: 28 de julho de 2026*

> CD

Os códigos que passam no teste são ativados automaticamente, sem qualquer intervenção humana.

## Definição

É um método que acelera o processo de desenvolvimento de software. Assim que você escreve seu código, ele passa por testes automáticos e, caso não haja obstáculos, é carregado diretamente no sistema utilizado pelos usuários. Garante que o software seja constantemente atualizado, eliminando processos manuais de aprovação.

***Analogia:** É como se o chef de um restaurante servisse a comida diretamente na mesa do cliente assim que a cozinhasse, sem perguntar ao garçom ou ao chef; É claro que cada refeição passa primeiro por testes de controle de qualidade.*

## Como funciona

O desenvolvedor envia o código ao sistema, o sistema executa testes automatizados e, se for bem-sucedido, o código é transferido para o servidor ativo.

## Onde é usado

Aplicativos web modernos, plataformas SaaS e produtos digitais que exigem atualizações rápidas.

## Costuma ser confundido com

Pode ser confundido com Entrega Contínua; No Delivery, a fase de go-live pode exigir uma aprovação manual, enquanto no Deployment é totalmente automática.

## Perguntas frequentes

**O que acontece se cometermos um erro?**

O sistema tenta detectar o erro antes de entrar no ar, graças a testes automáticos, mas ainda traz riscos; portanto, os testes devem ser muito robustos.
