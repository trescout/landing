# O que é Jupyter Notebooks?

É um ambiente de trabalho interativo onde você pode fazer anotações enquanto escreve o código e ver os resultados instantaneamente.

## Definição
Jupyter Notebooks coleta linhas de código, gráficos e comentários em uma única página. É como um laboratório para cientistas de dados; Você escreve um código e o executa, você vê o resultado logo abaixo. Isso torna muito mais fácil fazer tentativa e erro e compartilhar descobertas com outras pessoas.

## Como funciona
Funciona no navegador. Você cria blocos de código, pressiona ‘run’ e o resultado aparece logo abaixo.

## Onde é usado
A análise de dados é padrão na educação em inteligência artificial e em estudos acadêmicos.

## Costuma ser confundido com
Não é apenas um editor de código, é um sistema de documentos que visualiza e reporta dados.

## Perguntas frequentes
**É necessário saber codificação?**
Sim, você precisa usar linguagens como Python, mas elas são ótimas para visualizar dados mesmo em um nível muito básico.

**Quem usa?**
Cientistas de dados, pesquisadores e desenvolvedores de IA.
