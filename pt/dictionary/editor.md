# O que é Editor?

É um programa de escrita especial usado por desenvolvedores de software para escrever, editar e depurar código.

## Definição
Um editor ajuda você não apenas a escrever texto, mas também a compreender a estrutura do código que você escreve. Ele mostra instantaneamente erros em seu código e permite gerenciar estruturas complexas com mais facilidade. No mundo do software, essas ferramentas geralmente formam a base de pacotes mais abrangentes, também chamados de IDEs.

## Como funciona
Você abre seus arquivos de código com este programa. O editor reconhece a linguagem do código que você escreve e destaca os comandos com cores diferentes. Dessa forma, você pode entender rapidamente qual parte faz o quê.

## Onde é usado
É usado em todos os processos de desenvolvimento de software. É a primeira ferramenta aberta na hora de escrever sites, aplicativos móveis ou modelos de inteligência artificial.

## Costuma ser confundido com
Pode ser confundido com editores de texto comuns (como o Bloco de Notas); mas os editores de código possuem habilidades especiais para compreender a lógica do software.

## Perguntas frequentes
**Qualquer editor de texto pode ser usado para escrever código?**
Sim, mas os editores de código ajudam você a realizar seu trabalho com muito mais rapidez, com recursos como detecção de erros e preenchimento automático.
