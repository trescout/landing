# O que é Dynamic Tiling?

*Desenvolvimento · Última atualização: 3 de novembro de 2026*

É a organização automática e ordenada das janelas abertas na tela do computador, sem que elas se sobreponham.

## Definição

Em vez de redimensionar as janelas uma a uma com o mouse, permite que elas se posicionem automaticamente dividindo o espaço da tela matematicamente. É uma das maneiras mais práticas para desenvolvedores e usuários avançados usarem a tela de forma eficiente e trabalharem com foco no teclado. Quando uma nova janela çá aberta ou fechada, as janelas são redimensionadas instantaneamente e alinhadas para que não sobre espaço vago.

***Analogia:** É como separar compartimentos especiais do tamanho exato para cada documento na mesa, em vez de empilhá-los uns sobre os outros.*

## Como funciona

Softwares especiais chamados gerenciadores de janelas dividem a tela usando a lógica de linhas e colunas para posicionar automaticamente as novas janelas de acordo com regras.

## Onde é usado

Você se depara com isso frequentemente em ambientes de desktop Linux, gerenciadores de janelas dedicados e extensões de sistemas operacionais com recursos de tiling.

## Costuma ser confundido com

Muitas vezes é confundido com a lógica de arrastar e soltar livre das interfaces de janelas clássicas, mas aqui tudo é automático.

## Perguntas e respostas

**É difícil trabalhar sem usar o mouse?**

No início exige um pouco de hábito, mas logo permite que você trabalhe muito mais rápido com atalhos de teclado.

**Em quais sistemas operacionais está disponível?**

É especialmente comum no mundo Linux, mas também pode ser usado no macOS e no Windows com ferramentas de terceiros.
