# O que é SaaS?

*Glossário · Dev · Última atualização: 22 de setembro de 2026*

> Software as a Service

SaaS (Software as a Service, software como serviço) é um modelo de uso de aplicativos por assinatura via navegador, sem a necessidade de instalá-los em seu computador.

## Definição e origem da palavra

Antigamente, para usar um programa, era necessário comprar um CD e instalá-lo. No modelo SaaS, você abre seu navegador e se conecta ao software pela internet. A empresa que oferece o software realiza manutenção, backup e atualizações. Geralmente você paga com uma assinatura mensal ou anual. Google Workspace, Salesforce e Netflix são exemplos bem conhecidos deste modelo.

***Analogia:** É como utilizar a água municipal fornecida pelo município mediante pagamento de uma mensalidade em vez de perfurar um poço de água na sua própria casa; Você não precisa lidar com infraestrutura.*

## Como conhecer e usar no dia a dia?

**Escritório:** Edição de e-mail, calendário e documentos.
**Entretenimento:** Plataformas de streaming de séries e música.
**Trabalhar:** Gestão de relacionamento com o cliente (CRM), contabilidade, recursos humanos.
**Educação:** Plataformas de tarefas e exames.

## Profundidade Técnica e Arquitetura

Nos bastidores dos produtos SaaS, funciona o seguinte:

**Arquitetura multi-tenant:** Uma única instalação atende a milhares de clientes. Os dados são mantidos logicamente separados.
**Assinatura e autorização:** Recursos e cotas de usuário liberados de acordo com seu plano.
**Atualização contínua:** A nova versão é disponibilizada para todos ao mesmo tempo. Você não precisa se preocupar em acompanhar versões.
**Escalabilidade:** Os recursos são aumentados automaticamente durante os horários de pico.
**Backup e SLA:** Os dados são copiados regularmente e o nível de serviço é garantido por contrato.

## Coisas frequentemente misturadas

Pode ser confundido com PaaS. SaaS é uma aplicação pronta, destinada ao usuário final. Já o PaaS é uma plataforma onde os desenvolvedores executam suas próprias aplicações. IaaS está em um nível ainda mais baixo: você aluga servidor, disco e rede, e constrói o restante.

## Use em diferentes disciplinas

**Água encanada:** Assinar a rede pública em vez de abrir um poço.
**Apartamento alugado:** A manutenção é do proprietário, o uso é seu.
**Transporte público:** Obter serviço de transporte sem ser proprietário de um veículo.

## Perguntas Frequentes

**Onde meus dados são armazenados ao usar SaaS?**

Armazenado nos centros de dados do provedor. Certifique-se de verificar as condições de backup, criptografia e acesso no contrato.

**O que acontece se a internet cair?**

Os recursos online param. Alguns produtos oferecem funcionalidade offline limitada, mas o uso completo requer internet.

**O que acontece com meus dados se eu cancelar a assinatura?**

Geralmente é concedido um período de transição. Você deve exportar seus dados antes que o prazo termine. Informe-se sobre o formato de exportação antes do cancelamento.

**Qual é a diferença para PaaS?**

SaaS é um aplicativo pronto, você faz login e usa. PaaS é uma plataforma vazia, você instala seu próprio software nela.
