# O que é SaaS?

> Software as a Service

É um modelo de utilização do software alugando-o pela internet em vez de instalá-lo no computador.

## Definição
Antigamente, para usar um programa, era necessário comprar um CD e instalá-lo. No modelo SaaS, basta abrir o navegador e conectar-se ao software pela internet. Todas as manutenções e atualizações são feitas pela empresa fornecedora do software.

## Como funciona
A adesão é criada e o sistema é conectado através do navegador da Internet.

## Onde é usado
Plataformas populares como Google Workspace, Netflix ou Salesforce seguem este modelo.

## Costuma ser confundido com
Pode ser confundido com PaaS; SaaS é para o usuário final, PaaS é para desenvolvedores.

## Perguntas frequentes
**Onde meus dados são armazenados ao usar SaaS?**
Seus dados são armazenados nos servidores seguros da empresa fornecedora do software.
