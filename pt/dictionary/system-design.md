# O que é System Design?

*Glossário · Dev · Última atualização: 29 de junho de 2026*

O processo de planejamento da arquitetura, comunicação de peças e fluxo de dados de sistemas de software grandes e complexos.

## Definição

Um aplicativo não consiste apenas em escrever código; Como esse aplicativo irá lidar com milhões de usuários, onde os dados serão armazenados e como o sistema sobreviverá se uma parte falhar requer um projeto. O design do sistema está desenhando a planta azul desta enorme estrutura.

***Analogia:** É como o plano detalhado desenhado por um arquiteto antes de construir uma casa; É calculado antecipadamente por onde passará a instalação elétrica e quanta carga as paredes suportarão.*

## Como funciona

Engenheiros; Eles tomam decisões como seleção de banco de dados, posicionamento de servidores, medidas de segurança e otimização de velocidade nesta fase.

## Onde é usado

É utilizado nas etapas iniciais de projetos de desenvolvimento de software e no estabelecimento de sistemas escaláveis.

## Costuma ser confundido com

É confundido com codificação; Codificação é obra de construção, design de sistema é projeto arquitetônico.

## Perguntas frequentes

**É necessário para todos os projetos?**

Pode ser simples para pequenos projetos, mas é vital em grandes sistemas.

**Isso pode ser alterado?**

Sim, mas é muito caro e difícil alterar a arquitetura à medida que o sistema cresce.
