# O que é User Experience?

> UX

É a sensação geral de facilidade, rapidez e satisfação que você experimenta ao usar um produto.

## Definição
A experiência do usuário se preocupa com a sensação de um aplicativo, não apenas com sua aparência. Detalhes como a localização dos menus, o tamanho dos botões e a rapidez com que o processo é concluído fazem parte deste conceito. Uma boa experiência permite ao usuário atingir seu objetivo sem pensar duas vezes.

## Como funciona
Os designers observam os usuários, descobrem onde eles têm dificuldades e reorganizam a interface para resolver essas dificuldades.

## Onde é usado
É fundamental nos processos de design de sites, aplicativos móveis, ferramentas de software e produtos físicos.

## Costuma ser confundido com
É confundido com Interface do Usuário (IU); UI é visual, UX é como esse visual interage.

## Perguntas frequentes
**Por que a UX é importante?**
Os usuários param de usar aplicativos que consideram difíceis, portanto, uma boa experiência do usuário é essencial para o sucesso.
