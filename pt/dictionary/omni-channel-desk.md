# O que é Omni-channel Desk?

É um sistema de suporte que reúne em uma única tela todos os diferentes canais de comunicação como e-mails, mensagens e ligações de clientes.

## Definição
No atendimento ao cliente, é difícil rastrear as mensagens provenientes de cada canal separadamente. Este sistema unifica todos os canais, permitindo ao agente visualizar o histórico do cliente em um só lugar. Dessa forma, não importa para qual canal o cliente escreva, o representante sabe tudo.

## Como funciona
Diferentes plataformas (WhatsApp, e-mail, chat ao vivo) se conectam a este sistema. Cada mensagem recebida é automaticamente transformada em um ‘ticket’.

## Onde é usado
É utilizado em sites de comércio eletrônico, unidades de atendimento de grandes empresas e no setor de serviços.

## Costuma ser confundido com
Pode ser mixado com multicanal; Omni-channel é uma estrutura onde todos os canais conversam entre si.

## Perguntas frequentes
**O que a inteligência artificial faz aqui?**
Pode analisar as mensagens recebidas e sugerir respostas automáticas ou direcioná-las para a unidade relevante.

**Qual é a vantagem para o cliente?**
Ele não precisa se explicar do zero todas as vezes para resolver seu problema.
