# O que é Coding Assistant?

É um assistente apoiado por inteligência artificial que oferece sugestões durante o processo de desenvolvimento de software, agiliza a escrita do código e detecta erros.

## Definição
O assistente de codificação é uma ferramenta inteligente que entende o contexto do código que você escreve e prevê o que você deseja escrever na próxima linha. Ele pode completar blocos de código complexos para você, encontrar erros lógicos no código que você escreve ou fornecer exemplos para uma biblioteca que você não conhece.

## Como funciona
Geralmente é instalado como um plugin no editor de código que você está usando. Quando você começa a escrever o código, ele é executado em segundo plano e mostra sugestões em cinza; Se você confirmar, ele completará o código para você.

## Onde é usado
É usado em projetos diários de software, no aprendizado de um novo idioma ou na criação de prototipagem rápida para grandes projetos.

## Costuma ser confundido com
Pode ser confundido com o ‘Agente IA’ que faz todo o projeto de forma totalmente autônoma; O assistente geralmente atua sob sua direção.

## Perguntas frequentes
**Ele escreve todo o código?**
Não, um assistente é apenas um ajudante; Você está sempre no controle.

**É seguro?**
Depende da política de privacidade da ferramenta com a qual você está compartilhando seu código. Você deve ter cuidado ao compartilhar dados confidenciais.
