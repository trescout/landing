# O que é Agentic System?

Estruturas autônomas que tomam decisões e agem por conta própria para atingir metas sem intervenção humana.

## Definição
O sistema agentico é um sistema que não apenas executa o comando que lhe é dado, mas também planeja quais passos ele precisa tomar para executar esse comando. Estas estruturas podem mudar as suas estratégias para superar os obstáculos que encontram e gerir o processo até atingirem o objetivo. Ele usa sua própria iniciativa, como se fosse um funcionário digital.

## Como funciona
Você simplesmente define o objetivo final do sistema. O sistema identifica as subtarefas necessárias para atingir esse objetivo, seleciona as ferramentas e executa cada etapa sequencialmente. Ele corrige erros verificando seu próprio desempenho ao longo do processo.

## Onde é usado
É utilizado na automação de fluxos de trabalho complexos, processos de desenvolvimento de software e projetos de pesquisa autônomos.

## Costuma ser confundido com
Pode ser confundido com ferramentas comuns de automação; Enquanto a automação segue apenas o caminho predefinido, o próprio sistema agente traça o caminho.

## Perguntas frequentes
**Os sistemas agentes sempre tomam a decisão certa?**
Não, por vezes podem seguir estratégias erradas, razão pela qual a supervisão humana ainda é importante em processos críticos.

**Esses sistemas aprendem por conta própria?**
Sim, a maioria dos sistemas agentes são projetados para aprender com a experiência e trabalhar com mais eficiência na próxima tarefa.
