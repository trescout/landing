# O que é Session Intelligence?

Um sistema que entende o comportamento dos usuários analisando suas interações e tem como objetivo proporcionar uma melhor experiência.

## Definição
Ele busca uma resposta para a pergunta “o que essa pessoa quer fazer” rastreando o clique, o tempo de espera ou o caminho de cada usuário dentro do aplicativo. Desta forma, o sistema pode antecipar as necessidades do usuário.

## Como funciona
Os dados gerados ao longo da sessão do usuário são processados ​​por inteligência artificial e a intenção atual do usuário é prevista.

## Onde é usado
É utilizado em sites de comércio eletrônico ou assistentes personalizados de inteligência artificial.

## Costuma ser confundido com
Não é apenas um simples rastreamento do usuário, é um processo de compreensão dos dados.

## Perguntas frequentes
**Isso viola a privacidade?**
Muitas vezes funciona com dados anônimos, concentrando-se em padrões comportamentais e não na identidade pessoal.

**Qual é o seu propósito?**
É permitir que o usuário consiga o que deseja com menos esforço na aplicação.
