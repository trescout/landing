# O que é Code Review?

*Glossário · Dev · Última atualização: 6 de julho de 2026*

É o processo em que os desenvolvedores de software examinam os códigos uns dos outros para encontrar erros e melhorar a qualidade.

## Definição

A revisão de código é a verificação do código em um projeto de software por outro olho antes de ser incluído na estrutura principal. Esse processo é fundamental não apenas para a depuração, mas também para que a equipe aprenda com o estilo de codificação uma da outra e mantenha os padrões. No mundo TreScout, este é um filtro de controle de qualidade que garante a qualidade do código.

***Analogia:** É como se um autor fizesse o editor ler seu livro e corrigir seus erros antes de publicá-lo.*

## Como funciona

O desenvolvedor envia seu código, outros membros da equipe revisam o código, comentam e pedem correções se necessário. Assim que o código for aprovado, ele será adicionado ao projeto principal.

## Onde é usado

É uma prática padrão em plataformas como GitHub, GitLab e em processos de desenvolvimento de software empresarial.

## Costuma ser confundido com

Ao contrário dos testes automatizados que testam apenas se o código funciona, a lógica e a estética humanas entram em jogo aqui.

## Perguntas frequentes

**Por que não é automatizado?**

Ferramentas automatizadas podem encontrar bugs, mas somente humanos podem avaliar completamente o alinhamento da lógica do código com os objetivos de negócios.

**Não é uma perda de tempo?**

Embora leve tempo no início, economiza muito tempo no longo prazo, pois evita erros graves que podem ocorrer posteriormente.
