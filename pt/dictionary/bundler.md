# O que é Bundler?

É uma ferramenta que combina e otimiza vários arquivos em um projeto de software e os transforma em uma única estrutura que os navegadores podem executar.

## Definição
Os projetos web modernos consistem em centenas de pequenos arquivos. Os navegadores têm dificuldade em baixar tantos arquivos, um por um. O Bundler pega esses arquivos, os vincula e melhora o desempenho limpando partes desnecessárias.

## Como funciona
Durante a fase de desenvolvimento, você trabalha com arquivos individualmente. Quando você publica o projeto, o bundler entra em ação e empacota todos os arquivos de uma forma que o navegador possa entender.

## Onde é usado
É indispensável em projetos de desenvolvimento web baseados em JavaScript.

## Costuma ser confundido com
Pode ser misturado com compilador; O compilador traduz o código para outra linguagem, o bundler reúne os arquivos.

## Perguntas frequentes
**Por que não colocamos tudo em um arquivo?**
Arquivos muito grandes podem deixar o navegador lento; então o bundler às vezes divide os arquivos em partes inteligentes.
