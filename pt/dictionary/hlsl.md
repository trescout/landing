# O que é HLSL?

> High-Level Shader Language

É uma linguagem de programação usada para calcular efeitos visuais, como iluminação e sombras, em jogos.

## Definição
É uma linguagem que contém comandos que determinam a cor e a luz de cada pixel na tela. Utilizando especialmente o poder da placa de vídeo, ela calcula reflexos, sombras e efeitos de textura no mundo do jogo em tempo real.

## Como funciona
Os desenvolvedores enviam o código escrito nesta linguagem para a placa de vídeo; a placa de vídeo usa esses códigos para calcular as cenas dezenas de vezes por segundo e desenhá-las na tela.

## Onde é usado
É usada em motores de jogo (baseados em DirectX) e aplicações gráficas.

## Costuma ser confundido com
É confundida com linguagens de programação de propósito geral; o HLSL é especializado apenas para cálculos gráficos (shaders).

## Perguntas frequentes
**Aprender HLSL é difícil?**
Se você estiver familiarizado com a matemática gráfica e a arquitetura de placas de vídeo, a lógica básica é semelhante às linguagens C.
