# O que é ADB?

> Android Debug Bridge

É uma ponte que permite enviar comandos para dispositivos Android através do seu computador e realizar operações como instalação de software ou gerenciamento de arquivos do sistema.

## Definição
Ele cria uma linguagem de comunicação entre o seu dispositivo Android e o seu computador. Os desenvolvedores usam esta ferramenta para depurar o dispositivo, instalar aplicativos ou alterar configurações do sistema.

## Como funciona
Você instala o software ADB em seu computador, conecta o dispositivo via USB e gerencia o dispositivo digitando determinados códigos na linha de comando.

## Onde é usado
É usado em processos de desenvolvimento de software e personalizações avançadas do Android.

## Costuma ser confundido com
Não é apenas uma ferramenta de transferência de arquivos; É uma ferramenta muito mais poderosa que pode intervir no sistema.

## Perguntas frequentes
**Todos podem usar?**
Requer conhecimento técnico, comandos incorretos podem afetar o funcionamento do aparelho.
