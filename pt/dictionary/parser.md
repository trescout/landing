# O que é Parser?

É um analisador que divide dados ou códigos complexos em partes significativas que o computador pode processar passo a passo.

## Definição
Um analisador pega um pedaço de texto ou dados e o transforma em uma estrutura que o programa pode compreender logicamente. Por exemplo, funciona como um interpretador que permite ao computador compreender uma linha simples de código que você escreve como 'há uma variável aqui, uma operação está sendo executada aqui'. Ele cria uma estrutura em árvore dividindo os dados em partes.

## Como funciona
Ele recebe dados brutos como entrada, verifica esses dados de acordo com as regras da linguagem ou formato e, por fim, produz um modelo de dados ou estrutura em árvore. Se houver um erro de digitação nos dados, o analisador notará isso imediatamente.

## Onde é usado
É utilizado em compiladores para leitura de HTML em navegadores web e em qualquer software que processe formatos de dados (JSON, XML).

## Costuma ser confundido com
Pode ser confundido com Análise de Documento; No entanto, analisador é um conceito mais geral e é usado para todos os tipos de estruturas de dados.

## Perguntas frequentes
**O que acontece se o analisador apresentar um erro?**
Se o analisador encontrar os dados em um formato que não consegue entender, ocorrerá um 'erro de sintaxe' e impedirá que o processo continue.
