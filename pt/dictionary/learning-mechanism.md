# O que é Learning Mechanism?

Um conjunto de métodos que permitem que um sistema produza melhores resultados ao longo do tempo, extraindo padrões de dados.

## Definição
É a infraestrutura que permite aos modelos de inteligência artificial aprender com os seus erros, internalizar novas informações e aumentar o seu desempenho. Desta forma, o sistema se desenvolve através da experiência, em vez de trabalhar com regras fixas.

## Como funciona
O fluxo de dados é fornecido, o modelo faz uma previsão, o erro é medido e os pesos são atualizados para reduzir esse erro.

## Onde é usado
Participa dos processos de treinamento de modelos de aprendizado de máquina e dos ciclos de feedback de assistentes inteligentes.

## Costuma ser confundido com
Não é diretamente o modelo em si, mas o conjunto de regras e métodos subjacentes que permitem o desenvolvimento desse modelo.

## Perguntas frequentes
**Ele aprende constantemente?**
Sim, se o sistema for concebido em conformidade, caso contrário só funciona durante a fase de formação.
