# O que é DOM?

*Desenvolvimento · Última atualização: 19 de novembro de 2026*

> Document Object Model

Estrutura hierárquica que permite que o conteúdo das páginas da web seja processado e gerenciado pelo navegador.

## Definição

O DOM é o sistema que permite que os sites sejam armazenados na memória em segundo plano na forma de uma estrutura de árvore. Ele transforma as tags HTML em objetos que linguagens como JavaScript podem modificar facilmente. Assim, eventos dinâmicos podem ocorrer, como a alteração da página sem precisar ser atualizada quando você clica em um botão.

***Analogia:** É como a planta arquitetônica de um edifício. Quando você deseja fazer alterações no encanamento elétrico ou hidráulico, em vez de quebrar as paredes reais, você olha para a planta para encontrar a válvula ou o cabo correspondente e intervir.*

## Como funciona

Assim que o navegador baixa e lê o código do site, ele estabelece essa estrutura hierárquica na memória. Ao escrever código, os desenvolvedores podem ter como alvo essa estrutura para atualizar instantaneamente o texto ou as imagens na página. Cada tag HTML é posicionada como um galho ou folha desta árvore.

## Onde é usado

Ele opera continuamente em segundo plano em todos os sites modernos e aplicativos da web executados em navegadores da web.

## Costuma ser confundido com

Pode ser confundido com o código HTML bruto proveniente do servidor. Enquanto o HTML é apenas um documento de texto, o DOM é a versão em que o navegador transformou esse documento em um objeto ativo.

## Perguntas e respostas

**O DOM existe em todos os sites?**

Sim, esta estrutura certamente opera por trás de cada página visual aberta no navegador.

**O DOM pode ser modificado diretamente?**

É possível alterar esta estrutura instantaneamente usando JavaScript e dar vida à página.
