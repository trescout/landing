# O que é Web Compiler?

*Glossário · Dev · Última atualização: 17 de junho de 2026*

É uma ferramenta que torna seus códigos executáveis diretamente pelo navegador de internet, sem instalar nada no computador.

## Definição

Tradicionalmente, o desenvolvimento de software exigia instalações complexas no seu computador. O compilador web carrega esse processo para o navegador. Ele permite que você obtenha resultados instantâneos processando os códigos que você escreve em servidores em nuvem.

***Analogia:** Em vez de levar todos os ingredientes e fogões para sua casa para cozinhar na cozinha, é como se conectar a uma cozinha profissional pela internet e cozinhar e servir sua comida lá.*

## Como funciona

Você abre seu navegador, acessa o site relevante, digita seu código e pressiona 'executar'. O sistema compila seu código em segundo plano e mostra o resultado na tela.

## Onde é usado

É preferido em plataformas de aprendizagem de código, ao fazer prototipagem rápida ou quando o hardware do seu computador é insuficiente.

## Costuma ser confundido com

Pode ser misturado com compiladores nativos; O compilador web usa a internet enquanto os locais usam a energia do seu computador.

## Perguntas frequentes

**Preciso manter um arquivo de código no meu computador?**

Normalmente não, seus projetos são armazenados em sua conta na nuvem.

**O que acontece se minha internet cair?**

Seu código interrompe o processamento porque o processamento ocorre no servidor remoto, não no navegador.
