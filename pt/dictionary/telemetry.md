# O que é Telemetry?

Dados técnicos coletados automaticamente pelo sistema sobre o uso e os erros de um software.

## Definição
São relatórios que os aplicativos enviam aos desenvolvedores sobre como o software está funcionando. Graças a esses dados, os desenvolvedores podem entender qual recurso é muito utilizado ou onde o aplicativo trava. Para os usuários, é geralmente um fluxo de dados que ocorre silenciosamente em segundo plano.

## Como funciona
Pequenos trechos de código inseridos no software transmitem essas informações para um servidor seguro quando eventos específicos ocorrem.

## Onde é usado
É usado na depuração de software, melhoria da experiência do usuário e monitoramento de desempenho.

## Costuma ser confundido com
registro

## Perguntas frequentes
**Afeta a minha privacidade?**
Geralmente, dados anônimos são coletados, mas você pode verificar quais dados estão sendo enviados na seção de configurações.
