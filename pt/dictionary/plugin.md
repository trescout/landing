# O que é Plugin?

Pequenos softwares que são instalados posteriormente para fornecer recursos adicionais ao programa principal.

## Definição
Essas estruturas, também conhecidas como plug-ins, permitem adicionar novos recursos a um software sem alterar seu código principal. Por exemplo, se você tiver um navegador, poderá instalar um plug-in que bloqueie anúncios e faça com que ele faça algo que o navegador não pode fazer. É o método mais prático utilizado para expandir os limites do programa principal.

## Como funciona
O software principal fornece portas especiais às quais os plug-ins podem ser conectados. Ao instalar o plugin, ele começa a se comunicar com o programa principal através dessas portas e novos botões ou recursos são adicionados ao menu.

## Onde é usado
É usado em navegadores web, programas de design gráfico e interfaces que permitem que modelos de inteligência artificial se conectem à internet.

## Costuma ser confundido com
Não deve ser confundido com o programa em si, mas apenas com as partes auxiliares que o suportam.

## Perguntas frequentes
**Os complementos tornam o computador lento?**
A instalação de muitos plug-ins pode diminuir um pouco a velocidade de inicialização ou execução do programa principal.

**Existem complementos para cada programa?**
Não, apenas softwares que permitem sistema plug-in (arquitetura aberta) suportam esse recurso.
