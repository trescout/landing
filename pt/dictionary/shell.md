# O que é Shell?

É uma interface que permite controlar o computador digitando comandos de texto diretamente em vez de uma interface gráfica.

## Definição
Ele atua como uma ponte entre você e o núcleo do sistema operacional. Você pode gerenciar arquivos, executar programas e alterar configurações do sistema digitando comandos no teclado em vez de usar o mouse. É o espaço de trabalho mais básico e poderoso para desenvolvedores de software.

## Como funciona
Você abre uma tela preta e digita certos comandos lá. Por exemplo, quando você digita 'ls' e pressiona enter, será apresentada uma lista de todos os arquivos na pasta em que você está atualmente.

## Onde é usado
Está integrado em todos os sistemas Linux, macOS e Windows; É indispensável para processos de desenvolvimento de software.

## Costuma ser confundido com
É confundido com o terminal; terminal é a janela que exibe esta interface e shell é o interpretador de comandos executado dentro dessa janela.

## Perguntas frequentes
**É difícil aprender Shell?**
Pode parecer um pouco estranho no início, mas depois que você aprende alguns comandos básicos, gerenciar o computador fica muito mais rápido.
