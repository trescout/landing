# O que é Desktop Client?

*Glossário · Dev · Última atualização: 20 de julho de 2026*

É um aplicativo de software que você instala no seu computador e executa diretamente no ambiente de trabalho.

## Definição

Ao contrário dos aplicativos da web executados no navegador, ele interage diretamente com o sistema operacional. Ele fornece acesso mais profundo aos recursos de hardware e geralmente proporciona uma experiência mais estável. Ele pode executar suas funções básicas mesmo sem conexão com a internet.

***Analogia:** Visitar um site é como entrar em uma loja; mas o aplicativo de desktop é como instalar aquela loja em sua própria casa.*

## Como funciona

Você baixa o arquivo de instalação do aplicativo e o instala em seu computador. O aplicativo executa suas tarefas acessando seu sistema de arquivos e hardware tanto quanto seu sistema operacional permitir.

## Onde é usado

É usado em sistemas operacionais, programas de escritório e ferramentas profissionais de desenvolvimento de software.

## Costuma ser confundido com

Pode ser confundido com aplicações web; Embora os aplicativos da web dependam do navegador, o cliente de desktop funciona de forma independente.

## Perguntas frequentes

**Um aplicativo de desktop é sempre melhor?**

Para tarefas que exigem maior desempenho e acesso a hardware, sim, mas em termos de portabilidade, as aplicações web são mais práticas.
