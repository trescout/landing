# O que é Context Database?

É um armazenamento de dados privado que armazena as informações necessárias à inteligência artificial para produzir respostas mais consistentes e personalizadas.

## Definição
Ao responder a uma pergunta, os modelos de IA podem usar não apenas suas próprias informações gerais, mas também suas interações anteriores com você ou documentos privados. O banco de dados de contexto é uma área onde esses dados são armazenados regularmente e recuperados rapidamente quando necessário. Dessa forma, a inteligência artificial pode exibir memória significativa e de longo prazo sem esquecer o contexto.

## Como funciona
O sistema divide os dados ou documentos provenientes do usuário em pedaços e os salva neste banco de dados. Quando a inteligência artificial recebe uma pergunta, ela primeiro olha para esse banco de dados, encontra as informações relevantes, enriquece sua resposta com essas informações e as apresenta a você.

## Onde é usado
É usado em assistentes pessoais de inteligência artificial, sistemas internos de gerenciamento de documentos e todos os aplicativos de inteligência artificial que requerem memória de longo prazo.

## Costuma ser confundido com
Muitas vezes é confundido com bancos de dados vetoriais; Entretanto, o banco de dados de contexto representa uma estratégia mais ampla de gerenciamento e acesso a esses dados.

## Perguntas frequentes
**Por que isso é necessário?**
É necessário que a inteligência artificial te reconheça e não se esqueça das conversas anteriores.

**Meus dados estão seguros?**
A estrutura do banco de dados de contexto é protegida por protocolos de segurança locais ou baseados em nuvem, dependendo de onde e como os dados são armazenados.
