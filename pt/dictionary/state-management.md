# O que é State Management?

*Glossário · Dev · Última atualização: 3 de junho de 2026*

É um método de rastrear o status atual e os dados de um software.

## Definição

Gerenciamento de estado é o processo de manter em ordem o estado atual de uma aplicação, ou seja, os dados em sua interação com o usuário. Ele gerencia a memória do aplicativo e permite ao usuário continuar de onde parou.

***Analogia:** Usar marcadores ao ler um livro é um método de gerenciamento de estado que permite lembrar a página e a linha em que você parou.*

## Como funciona

A aplicação guarda num repositório central as escolhas que o utilizador faz ou as informações que introduz. Sempre que há uma mudança, este hub é atualizado e outras partes do aplicativo aprendem essas novas informações imediatamente.

## Onde é usado

É usado em sites para manter o conteúdo de um carrinho de compras ou para lembrar mensagens anteriores em um chat de IA.

## Costuma ser confundido com

É confundido com banco de dados, mas o banco de dados mantém registros permanentes enquanto o gerenciamento de estado gerencia o estado temporário e instantâneo.

## Perguntas frequentes

**O que acontece se a administração estadual for corrompida?**

O aplicativo se comporta de maneira inconsistente, por exemplo, o item que você adicionou ao carrinho pode desaparecer ou pode esquecer o início da conversa.

**Por que usar uma estrutura central?**

É preferível garantir que os dados permanecem atualizados em todos os lugares ao mesmo tempo e evitar confusões.
