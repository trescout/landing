# O que é Control Plane?

É a camada de gerenciamento central que controla como um sistema deve funcionar, gerenciando o tráfego e as configurações.

## Definição
Em grandes sistemas, o local onde o trabalho é realizado (plano de dados) é separado do local onde se decide como esse trabalho deve ser feito (plano de controle). O plano de controle é como o cérebro do sistema; ele gerencia para onde os dados vão, quem tem autorização e o estado geral do sistema.

## Como funciona
As regras são estabelecidas por meio de um software ou interface central. Essas regras são transmitidas para as outras partes do sistema para garantir a continuidade operacional.

## Onde é usado
Encontra-se em arquiteturas de computação em nuvem, sistemas de gerenciamento de rede e data centers de grande escala.

## Costuma ser confundido com
Pode ser confundido com o plano de dados; um gerencia, o outro executa o trabalho.

## Perguntas frequentes
**O que acontece se ele falhar?**
O sistema torna-se incapaz de receber novos comandos ou gerenciar o tráfego, por isso geralmente é protegido com altíssima disponibilidade.
