# O que é Interoperability?

É a capacidade de diferentes sistemas ou softwares de trocar dados entre si de maneira integrada.

## Definição
Interoperabilidade é a capacidade de dois sistemas escritos em idiomas diferentes ou com tecnologias diferentes se comunicarem falando um idioma comum. Por exemplo, é graças a esta capacidade que um programa de contabilidade pode comunicar automaticamente com os sistemas bancários. Esse recurso permite que as tecnologias formem um ecossistema sem dependerem umas das outras.

## Como funciona
Normalmente, as APIs são entregues usando formatos de dados padrão (como JSON) e protocolos comuns.

## Onde é usado
É de importância crítica em software empresarial, dispositivos IoT e grandes projetos onde diferentes serviços se combinam.

## Perguntas frequentes
**Por que nem todo sistema possui esse recurso?**
Às vezes, as empresas desejam manter seus sistemas fechados ou diferentes tecnologias não são tecnicamente compatíveis entre si.
