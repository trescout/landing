# O que é OIDC?

> OpenID Connect

É um protocolo padrão que verifica sua identidade com segurança ao fazer login em diferentes sites.

## Definição
É uma tecnologia que permite fazer login com sua conta Google ou Apple em vez de criar uma senha separada para cada site da internet. O OIDC garante que o site entenda quem você é com segurança, mas não fornece sua senha para esse site.

## Como funciona
Quando você pressiona o botão de login, o aplicativo redireciona você para um provedor de identidade confiável (como o Google). Depois de confirmar lá, o provedor envia um documento digital para o aplicativo dizendo ‘essa é mesmo a pessoa’.

## Onde é usado
É usado em aplicativos da web, telas de login móveis e sistemas de software corporativos.

## Costuma ser confundido com
É confundido com SSO (Single Sign-On); SSO é um conceito geral, enquanto OIDC é o protocolo técnico que faz esse trabalho.

## Perguntas frequentes
**Compartilho minha senha com outros sites?**
Não, apenas é compartilhada uma confirmação digital de que sua identidade foi verificada.
