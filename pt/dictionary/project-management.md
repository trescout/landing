# O que é Project Management?

É o planejamento e gerenciamento de tempo, recursos e tarefas para atingir um objetivo específico.

## Definição
Faz você entender que um projeto de software não envolve apenas escrever código. Esta disciplina controla qual trabalho será feito primeiro, quem é responsável por quê e quando o projeto será concluído. É traçar um roteiro ordenado para um resultado bem-sucedido.

## Como funciona
O processo é seguido passo a passo usando listas de tarefas, calendários e ferramentas de acompanhamento de trabalho.

## Onde é usado
É utilizado em quase todos os setores, desde equipes de software até projetos de construção.

## Perguntas frequentes
**Por que os desenvolvedores de software usam isso?**
Para evitar que projetos complexos desmoronem e manter todos focados no mesmo objetivo.
