# O que é Markdown?

*Glossário · Dev · Última atualização: 3 de junho de 2026*

Uma linguagem de formatação leve usada para formatar texto, permitindo escrever com caracteres simples.

## Definição

Markdown é uma linguagem de marcação leve e simples para formatar textos sem escrever códigos complexos. Ele permite que você faça edições como títulos, listas ou negrito enquanto escreve com alguns caracteres simples.

***Analogia:** É como formatar rapidamente, como fazer anotações com uma caneta no papel, em vez de mexer nos menus de um editor de texto.*

## Como funciona

Caracteres como asteriscos ou cerquilhas são adicionados ao texto. Por exemplo, quando você coloca um asterisco no início e no final de uma palavra, o sistema converte automaticamente para texto em itálico.

## Onde é usado

É o método preferido pelos desenvolvedores de software ao escrever documentação, criar conteúdo em aplicativos de anotações ou sites.

## Costuma ser confundido com

É confundido com HTML, mas embora o HTML seja muito mais complexo e detalhado, o Markdown foi projetado exclusivamente para melhorar a legibilidade.

## Perguntas frequentes

**Por que devo usar Markdown em vez de Word?**

Markdown é muito mais rápido, menos perturbador e facilmente visualizável em qualquer plataforma.

**Como abro arquivos Markdown?**

Você pode abri-lo com qualquer editor de texto, mas pode lê-lo formatado mais facilmente com visualizadores especiais.
