# O que é Database Client?

Programa utilitário que permite acessar e gerenciar as informações em um banco de dados.

## Definição
Um cliente de banco de dados permite que você se conecte aos dados armazenados em servidores por meio de uma interface visual. Ele permite examinar tabelas, escrever consultas e editar dados. É uma das ferramentas de software mais fundamentais usadas para gerenciar bancos de dados sem precisar escrever código.

## Como funciona
Comandos ou cliques feitos na interface do usuário são transmitidos pelo cliente ao servidor de banco de dados. As respostas do servidor são exibidas na tela na forma de tabelas ou listas legíveis.

## Onde é usado
É amplamente utilizado em processos de desenvolvimento de software, trabalhos de análise de dados e gerenciamento de servidores.

## Costuma ser confundido com
Não deve ser confundido com o servidor de banco de dados que armazena os dados em si; o cliente é apenas a interface e a ferramenta de gerenciamento.

## Perguntas frequentes
**Quais programas são conhecidos como clientes de banco de dados?**
Softwares como DBeaver, pgAdmin ou MySQL Workbench se enquadram nesta categoria.
