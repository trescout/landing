# O que é Data Logger?

*Glossário · Data · Última atualização: 16 de junho de 2026*

É um dispositivo eletrônico que registra e armazena dados de sensores em intervalos regulares.

## Definição

Um registrador de dados monitora constantemente as mudanças físicas em seu ambiente e armazena essas informações junto com carimbos de data/hora. Esses dispositivos são frequentemente usados ​​para rastrear dados como temperatura, umidade ou movimento. Esses dados coletados são então analisados ​​para entender como o sistema funciona.

***Analogia:** Pense em um registrador de dados como um diário que registra o que você come e quantos passos você dá ao longo do dia.*

## Como funciona

Você coloca o dispositivo onde deseja monitorá-lo e ele grava os dados em sua memória interna ou em um computador. Você pode então abrir esses registros e examinar o que aconteceu no passado.

## Onde é usado

Ele é usado para monitorar a integridade de máquinas em fábricas, rastrear resultados de experimentos em laboratórios ou medir o consumo de energia em sistemas domésticos inteligentes.

## Costuma ser confundido com

Pode ser confundido com um banco de dados, mas este dispositivo é antes o hardware físico na fase de coleta de dados brutos.

## Perguntas frequentes

**Como um registrador de dados armazena dados?**

Geralmente salva em um cartão de memória interno ou diretamente no banco de dados de um computador ao qual está conectado.

**Todo sensor é um registrador de dados?**

Não, o sensor apenas detecta os dados; O registrador de dados é uma unidade superior que associa esses dados ao tempo e os registra.
