# O que é ORM?

> Object-Relational Mapping

É uma ponte que converte tabelas de banco de dados em objetos em código.

## Definição
Ele permite que você use esses dados como objetos em uma linguagem de programação, em vez de lidar com tabelas complexas no banco de dados ao desenvolver software. Dessa forma, você pode gerenciar dados sem escrever consultas complexas como SQL. Isso torna seu código mais legível e gerenciável.

## Como funciona
Funciona como uma camada entre o banco de dados e o código da aplicação. Quando você salva dados em seu código, essa operação é traduzida na consulta SQL apropriada em segundo plano. Dessa forma, mesmo que a estrutura do banco de dados mude, você só precisará alterar ligeiramente o seu código.

## Onde é usado
É frequentemente usado em aplicações web, software empresarial e projetos com uso intensivo de banco de dados.

## Costuma ser confundido com
Pode ser confundido com o driver do banco de dados; O driver fornece a conexão bruta, enquanto o ORM facilita essa conexão.

## Perguntas frequentes
**Por que devo usar o ORM?**
Acelera as operações do banco de dados e reduz erros de código.

**Isso reduz o desempenho?**
Para consultas muito complexas, o SQL manual às vezes pode ser mais rápido, mas na maioria dos casos a conveniência vale a pena.
