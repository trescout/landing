# O que é Native Binaries?

*Glossário · Dev · Última atualização: 6 de outubro de 2026*

São arquivos de programa compilados diretamente para serem executáveis em um sistema operacional e arquitetura de processador específicos.

## Definição

Binários nativos são arquivos que permitem que o código escrito seja compreendido diretamente pelo hardware do computador, sem a necessidade de nenhum software intermediário. Como esses arquivos são preparados especificamente para o sistema operacional e o tipo de processador de destino, eles oferecem o máximo de desempenho. Ao contrário de linguagens como Java ou Python, eles não exigem uma máquina virtual ou interpretador instalado no computador para funcionar.

***Analogia:** Você pode comparar isso a conversar diretamente com uma pessoa que fala o mesmo idioma nativo que você, sem precisar de um tradutor. Você não perde tempo intermediário e se comunica diretamente.*

## Como funciona

Os desenvolvedores convertem o código que escrevem diretamente em linguagem de máquina com a ajuda de ferramentas chamadas compiladores. Durante esse processo, o hardware de destino é especificado e o compilador produz um arquivo composto por zeros e ums que apenas aquele hardware entenderá. O arquivo resultante pode ser executado diretamente pelo usuário com um clique duplo.

## Onde é usado

São frequentemente usados em programação de sistemas, motores de jogos e sistemas embarcados, onde a velocidade e a eficiência são cruciais. Além disso, as ferramentas de linha de comando modernas e os aplicativos de desktop de alto desempenho que você analisa no TreScout geralmente são distribuídos com essa estrutura.

## Costuma ser confundido com

Eles são confundidos com arquivos de código intermediário executados em uma máquina virtual. Enquanto os arquivos de código intermediário precisam de um intermediário para funcionar em qualquer computador, os binários nativos são executados diretamente apenas no sistema específico para o qual foram gerados.

## Perguntas frequentes

**Os binários nativos funcionam em qualquer computador?**

Não. Eles funcionam apenas no sistema operacional e na arquitetura de processador para os quais foram compilados. Por exemplo, um arquivo compilado para Windows não pode ser executado diretamente em um computador Mac.

**Quais linguagens produzem binários nativos?**

Linguagens de programação de sistemas como Rust, C++, Go e Zig foram projetadas para produzir diretamente binários nativos.
