# O que é Text Extraction?

É o processo de conversão de dados escritos em documentos digitais ou imagens em formato de texto que o computador pode processar.

## Definição
Este processo transfere texto em um pedaço de papel ou texto em um arquivo de imagem para um documento de texto digital. Para computadores, uma imagem consiste apenas em pixels coloridos; Graças a esta tecnologia, esses pixels são transformados em palavras significativas.

## Como funciona
O documento entra no sistema, algoritmos de IA ou de reconhecimento de caracteres combinam pixels com letras e fornecem texto editável.

## Onde é usado
É utilizado no processamento de faturas, sistemas de autenticação e digitalização de arquivos legados.

## Costuma ser confundido com
É quase igual ao OCR; Embora extração de texto seja o nome geral para esse processo, OCR é o nome da tecnologia utilizada.

## Perguntas frequentes
**Ele consegue ler caligrafia?**
Com modelos modernos sim, mas a legibilidade do texto afeta diretamente a qualidade do resultado.
