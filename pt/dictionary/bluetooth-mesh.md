# O que é Bluetooth Mesh?

Tecnologia de comunicação sem fio que permite que vários dispositivos se conectem entre si e estabeleçam uma rede em uma área ampla.

## Definição
Bluetooth Mesh é uma estrutura que permite aos dispositivos transferir dados não apenas entre si, mas também para todos os outros dispositivos da rede. Desta forma, a comunicação pode ser estabelecida numa vasta área sem a necessidade de um ponto central. É especialmente usado para acionar uns aos outros em sistemas domésticos inteligentes.

## Como funciona
Quando os dispositivos ingressam na rede, eles se reconhecem automaticamente. O comando vindo de um dispositivo chega ao destino saltando sobre os demais. Essa estrutura garante que a rede continue a operar mesmo se um único dispositivo falhar.

## Onde é usado
É usado em sistemas de iluminação inteligentes, redes de sensores industriais e automação de grandes escritórios.

## Costuma ser confundido com
A conexão Bluetooth padrão é apenas entre dois dispositivos, enquanto o Mesh conecta todos os dispositivos juntos.

## Perguntas frequentes
**O Bluetooth Mesh requer internet?**
Não, os dispositivos estabelecem uma rede local entre si.

**Seu alcance é limitado?**
À medida que o número de dispositivos aumenta, a área de cobertura da rede também se expande.
