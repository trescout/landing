# O que é Terminal?

É uma interface de tela preta que permite a comunicação direta com o computador sem o uso do mouse, apenas digitando comandos de texto.

## Definição
O terminal é a porta para o 'capô' do computador. É útil para fazer configurações profundas do sistema, desenvolvimento de software e gerenciamento de arquivos que as interfaces gráficas (GUI) não podem fazer. É a área de trabalho mais básica dos desenvolvedores de software.

## Como funciona
Você digita comandos no teclado e pressiona ‘Enter’. O computador processa esse comando instantaneamente e retorna o resultado como texto.

## Onde é usado
É utilizado em processos de desenvolvimento de software, gerenciamento de servidores e trabalhos de automação.

## Costuma ser confundido com
É misturado com GUI; O terminal é inteiramente de texto, enquanto a GUI é totalmente visual.

## Perguntas frequentes
**É necessário aprender o terminal?**
Se você quer entrar no mundo do software, sim, porque muitas ferramentas só funcionam através do terminal.
