# O que é Terminal?

Terminal é a interface onde você conversa com o computador com comandos de texto.

## Definição e origem da palavra
Vem de terminais de máquinas de escrever antigas. Você digita um comando, pressiona Enter e o resultado retorna como texto. Configurações profundas, operações em lote e gerenciamento de servidor que a interface gráfica não pode fazer são feitas aqui. É a área de trabalho diário do desenvolvedor de software.

## Como conhecer e usar no dia a dia?
Desenvolvimento: Instalação de pacotes, compilação, testes.Apresentador: Gerenciamento remoto de máquinas.Automação: Trabalho repetitivo com scripts.

## Coisas frequentemente misturadas
Pensa-se que é uma GUI. A GUI é visual, o terminal é textual. Também se confunde com o shell: o terminal é a janela, o shell é o interpretador.

## Use em diferentes disciplinas
Cozinha de restaurante: Ingredientes diretos em vez de um menu.Cabine de pilotagem: Controle direto com o botão.Casa de máquinas: Girar as válvulas manualmente.

## Perguntas Frequentes
**É necessário aprender o terminal?**
Se você está no caminho do software, sim. Muitas ferramentas funcionam apenas a partir do terminal, os fundamentos são aprendidos em poucos dias.

**Qual é a diferença para o Shell?**
O terminal é a janela, o shell é o interpretador. Você pode alterar o shell sem alterar a janela.

**Por qual se deve começar?**
Com comandos de arquivo: Onde estou, listar, entrar, sair. O resto vem conforme a necessidade.

**Um comando errado causa danos?**
Comandos de leitura não causam. Nos comandos que excluem e escrevem, o caminho e os caracteres curinga são verificados duas vezes.
