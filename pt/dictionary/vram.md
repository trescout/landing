# O que é VRAM?

> Video Random Access Memory

É uma unidade de memória especial na placa gráfica que acelera gráficos intensivos e operações de inteligência artificial.

## Definição
VRAM é uma área de armazenamento rápida na própria placa gráfica, independente da memória principal do processador. Enquanto os modelos de inteligência artificial estão em execução, os parâmetros do modelo e os dados de cálculo atuais são carregados nesta área. Quanto maior a quantidade de memória, mais rápido seu computador poderá processar modelos maiores e mais complexos.

## Como funciona
Quando o modelo AI é executado, o software recupera dados da RAM do sistema e os copia para VRAM; A placa gráfica também processa esses dados muito rapidamente e retorna o resultado.

## Onde é usado
É usado em jogos, programas de edição de vídeo e sistemas que executam modelos nativos de inteligência artificial.

## Costuma ser confundido com
Muitas vezes é confundido com RAM do sistema; A RAM é usada para tarefas gerais, enquanto a VRAM é usada para gráficos intensivos e tarefas de cálculo da placa gráfica.

## Perguntas frequentes
**O que acontece se a VRAM não for suficiente?**
O modelo de IA fica muito lento ou para de funcionar com um erro de ‘falta de memória’.
