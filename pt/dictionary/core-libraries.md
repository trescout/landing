# O que é Core Libraries?

Eles são pacotes de código padrão que um software precisa para executar suas funções básicas.

## Definição
Bibliotecas principais são bibliotecas de código prontas que contêm os blocos de construção mais básicos de uma linguagem ou plataforma de programação. Essas bibliotecas permitem que os desenvolvedores executem operações padrão rapidamente, em vez de escrever código do zero todas as vezes. Assim como as colunas de fundação de um edifício, são peças indispensáveis ​​para garantir que o software sobreviva e funcione corretamente.

## Como funciona
Ao incluir essas bibliotecas em seus projetos, os desenvolvedores podem lidar com operações matemáticas complexas, gerenciamento de dados ou operações de arquivos com comandos de uma linha.

## Onde é usado
É usado em quase todas as linguagens de programação e desenvolvimento de sistemas operacionais.

## Costuma ser confundido com
Pode ser confundido com Framework ou SDK, mas as bibliotecas principais referem-se à funcionalidade básica e as estruturas referem-se a um esqueleto de aplicativo mais amplo.

## Perguntas frequentes
**Por que as bibliotecas principais são importantes?**
Acelera o processo de desenvolvimento de software, reduz erros e garante uma operação de código mais estável.
