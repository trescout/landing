# O que é Digital Twin?

É uma cópia digital de um objeto ou sistema físico.

## Definição
Um gêmeo digital é uma cópia exata de um objeto físico ou sistema no mundo digital. Esta réplica é constantemente atualizada com dados do objeto do mundo real, simulando seu comportamento.

## Como funciona
Os dados são coletados do mundo real por meio de sensores. Esses dados são transferidos para o modelo digital, e o modelo calcula quando o objeto real pode falhar ou qual será seu desempenho.

## Onde é usado
É utilizado para estimar o tempo de manutenção de máquinas em fábricas ou para simular o fluxo de tráfego no planejamento urbano.

## Costuma ser confundido com
Não confundir com um modelo 3D simples; O gêmeo digital é uma estrutura dinâmica que é constantemente alimentada com dados ao vivo.

## Perguntas frequentes
**Os gêmeos digitais e as simulações são iguais?**
Uma simulação pode ser executada uma vez, enquanto um gêmeo digital é um sistema constantemente ativo com dados em tempo real.

**Tudo pode ter um gêmeo digital?**
Teoricamente sim, mas os custos e as possibilidades de recolha de dados são decisivos.
