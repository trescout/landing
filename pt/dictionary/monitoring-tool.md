# O que é Monitoring Tool?

São softwares que monitoram continuamente se os sistemas estão funcionando corretamente e emitem alertas em caso de erro.

## Definição
Quando uma aplicação é colocada em produção, você precisa ter certeza de que tudo está correndo bem. Essas ferramentas acompanham a velocidade do servidor, as taxas de erro e o tráfego de usuários segundo a segundo. Quando ocorre um problema (por exemplo, quando o site fica lento), elas avisam você imediatamente.

## Como funciona
Você adiciona um pequeno código de rastreamento ao seu sistema, essa ferramenta coleta dados continuamente e apresenta um painel (dashboard) para você.

## Onde é usado
É utilizado em servidores, aplicações web e infraestruturas de grande escala.

## Costuma ser confundido com
Pode ser confundido com ferramentas de depuração (debugging); a depuração encontra o erro dentro do código, enquanto a ferramenta de monitoramento acompanha a saúde geral do sistema.

## Perguntas frequentes
**Por que preciso disso?**
Para que você perceba e corrija antes que seus usuários notem que o site está com problemas.
