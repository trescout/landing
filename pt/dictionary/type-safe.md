# O que é Type-safe?

É uma disciplina que garante a operação segura do software, evitando o uso incorreto de tipos de dados.

## Definição
Requer que apenas dados do tipo especificado sejam inseridos em uma variável. Por exemplo, se você tentar inserir um texto onde se espera um número, o sistema perceberá isso antes mesmo de você executá-lo. Isso evita os erros mais comuns no processo de desenvolvimento de software.

## Como funciona
Ao escrever código, você define os tipos de variáveis ​​(como número, texto, data). Quando você executa ou compila o software, o sistema avisa se encontrar algo que não atenda a essas definições.

## Onde é usado
É usado para reduzir a margem de erro em linguagens de programação modernas e projetos de software de grande escala.

## Perguntas frequentes
**Qual é a vantagem de ter segurança de tipo?**
O código tem menos probabilidade de travar em tempo de execução e se torna mais seguro.

**Está disponível em todos os idiomas?**
Não, alguns idiomas são mais flexíveis, alguns têm regras rígidas.
