# O que é Local-first Code Intelligence Graph?

*Glossário · Dev · Última atualização: 21 de julho de 2026*

É um sistema que mapeia as relações entre partes de código em projetos de software em seu computador local sem a necessidade de Internet.

## Definição

Este sistema conecta todos os arquivos e funções da sua base de código como uma rede. Seus dados permanecem privados porque são executados diretamente no seu dispositivo, em vez de se conectar à Internet. Ajuda você a entender a estrutura do seu código e navegar rapidamente em projetos complexos.

***Analogia:** É como um mapa mágico que mostra como todos os livros de uma enorme biblioteca fazem referência uns aos outros, apenas na sua mesa.*

## Como funciona

Ele está integrado ao seu ambiente de desenvolvimento de software e cria uma rede de relacionamentos ao digitalizar seu código. Quando você altera uma função, ela mostra instantaneamente quais arquivos essa alteração afetará.

## Onde é usado

É usado em projetos de software complexos, desenvolvimento de software corporativo onde a privacidade está em primeiro lugar e em situações que exigem trabalho offline.

## Costuma ser confundido com

Pode ser confundido com ferramentas gerais de análise de código ou serviços de indexação de código baseados na Internet.

## Perguntas frequentes

**Por que é chamado de 'local primeiro'?**

Porque todo o processo de análise ocorre diretamente no seu próprio computador e não em servidores em nuvem.

**Funcionará quando eu não tiver internet?**

Sim, o sistema não necessita de conexão com a internet porque funciona totalmente localmente.
