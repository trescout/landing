# O que é End-to-End Privacy?

*Glossário · Dev · Última atualização: 28 de junho de 2026*

É um método de segurança no qual os dados só podem ser lidos pelo remetente e pelo destinatário, e ninguém entre eles pode acessá-los.

## Definição

A privacidade de ponta a ponta garante que suas mensagens ou arquivos não sejam roubados por ninguém em trânsito no mundo digital. Os dados são criptografados assim que saem do seu dispositivo e só podem ser descriptografados pelo destinatário que possui a chave correta. Desta forma, mesmo os prestadores de serviços não conseguem ver o conteúdo dos seus dados.

***Analogia:** É como colocar uma carta num envelope lacrado e selá-lo; O mensageiro que carrega a carta nunca consegue ler o que está dentro do envelope.*

## Como funciona

O sistema bloqueia os dados com algoritmos matemáticos complexos antes de enviá-los. A parte receptora possui a chave especial para abrir esta fechadura. Os servidores intermediários transmitem os dados apenas como um pacote e não podem intervir no conteúdo.

## Onde é usado

Ele é usado em aplicativos de mensagens, serviços de armazenamento em nuvem e transferências seguras de arquivos.

## Costuma ser confundido com

Pode ser confundido com mera criptografia, mas aqui os usuários têm controle total da chave.

## Perguntas frequentes

**O provedor de serviços pode ver o rendimento?**

Não, com privacidade de ponta a ponta, os provedores não podem acessar o conteúdo porque os dados são criptografados.

**O que acontece se eu perder minha chave?**

Você pode perder completamente o acesso aos seus dados porque não há outra cópia disponível para decodificá-los.
