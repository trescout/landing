# O que é Server Hardening?

*Glossário · Dev · Última atualização: 10 de julho de 2026*

É o processo de reduzir o risco de ataque, desativando recursos desnecessários em um servidor e reforçando as configurações de segurança.

## Definição

É uma tentativa de reduzir ao máximo a área de superfície do servidor. Inclui etapas como desligar serviços não utilizados, alterar senhas padrão e configurar firewalls. O objetivo é fechar portas pelas quais um invasor possa entrar furtivamente.

***Analogia:** Não basta trancar as portas de uma casa; é como transformar a casa num castelo tomando todas as medidas de segurança como passar as janelas e instalar o sistema de alarme.*

## Como funciona

Feche portas desnecessárias no servidor, atualize o software para a versão mais recente, restrinja as permissões do usuário para evitar acesso não autorizado e execute verificações de segurança regulares.

## Onde é usado

É usado em servidores em nuvem, data centers locais e operações de segurança cibernética.

## Costuma ser confundido com

Não é a mesma coisa que instalar um firewall; o endurecimento é um processo de segurança muito mais abrangente.
