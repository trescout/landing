# O que é Linear Scalability?

À medida que a quantidade de recursos adicionados ao sistema aumenta, o desempenho aumenta na mesma proporção.

## Definição
Refere-se à capacidade de crescimento de um sistema. Se o seu sistema puder realizar o dobro do trabalho quando você adicionar o dobro de servidores, o sistema será linearmente escalável. Esta é a maior prova de que o sistema pode crescer mantendo a sua eficiência.

## Como funciona
A arquitetura do sistema é projetada para dividir a carga de trabalho em partes e distribuí-la para diferentes recursos.

## Onde é usado
Sistemas de computação em nuvem, bancos de dados e serviços web de alto tráfego.

## Costuma ser confundido com
Não se trata apenas de ‘ser rápido’, é que o aumento de desempenho é proporcional ao aumento de recursos.

## Perguntas frequentes
**Por que nem todo sistema pode ser dimensionado linearmente?**
Porque à medida que o sistema cresce, a carga de comunicação entre as partes aumenta, o que pode desperdiçar alguns dos recursos adicionados.
