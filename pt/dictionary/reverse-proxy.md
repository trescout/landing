# O que é Reverse Proxy?

*Glossário · Dev · Última atualização: 7 de junho de 2026*

É um roteador de tráfego que recebe solicitações da Internet, distribui-as aos servidores apropriados e garante a segurança.

## Definição

Ao entrar em um site, você não vai diretamente para o servidor principal. Primeiro você encontra um proxy reverso, que é um gatekeeper. Ele recebe sua solicitação, verifica sua segurança e redireciona você para o servidor correto.

***Analogia:** Ela é como a recepcionista de uma grande empresa; Cumprimenta os visitantes que chegam, entende quem são e os direciona ao departamento relevante.*

## Como funciona

O tráfego de entrada chega a esse servidor intermediário. A ferramenta analisa o tráfego, equilibra a carga e encaminha-a para os servidores traseiros onde os dados reais estão localizados.

## Onde é usado

É utilizado em servidores web, firewalls e sites com alto tráfego.

## Costuma ser confundido com

Pode ser confundido com um proxy normal; O proxy normal oculta o usuário, o proxy reverso oculta e protege o servidor.

## Perguntas frequentes

**Por que não nos conectamos diretamente ao servidor?**

Uma camada intermediária é sempre mais eficiente para segurança, velocidade e distribuição de carga.

**Este é um software?**

É uma camada de software e de servidor na qual este software é executado.
