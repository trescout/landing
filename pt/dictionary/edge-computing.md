# O que é Edge Computing?

É o processamento de dados no próprio dispositivo ou muito próximo dele onde os dados são produzidos, sem serem enviados para um servidor central.

## Definição
Nos sistemas tradicionais, os dados eram enviados para um centro remoto e ali processados. A edge computing move esse processo para a ‘edge’, ou seja, para o dispositivo ou rede local do usuário. Essa abordagem reduz a latência e permite que o sistema funcione mesmo se a conexão com a Internet for ruim.

## Como funciona
Capacidades de processamento local são adicionadas ao dispositivo. Em vez de ir para o centro, o fluxo de dados é analisado instantaneamente pelo processador do próprio aparelho.

## Onde é usado
É usado em dispositivos domésticos inteligentes, veículos autônomos e sensores industriais que exigem resposta instantânea.

## Costuma ser confundido com
É confundido com computação em nuvem; a nuvem é central, a borda é local.

## Perguntas frequentes
**Por que não enviamos tudo para a nuvem?**
Porque demora para enviar os dados para a central e se a internet for cortada o sistema para.

**A computação de ponta é segura?**
Geralmente é considerado mais seguro em termos de privacidade porque os dados não saem do dispositivo.
