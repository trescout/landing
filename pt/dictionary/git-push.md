# O que é Git Push?

É o processo de upload das alterações de software feitas em seu computador local para um servidor compartilhado na Internet.

## Definição
Ao desenvolver software, você escreve e edita seus códigos em seu próprio computador. O comando ‘push’ é usado para compartilhar essas mudanças com o resto da equipe. Desta forma, todas as atualizações feitas são enviadas para um repositório central.

## Como funciona
Isso é feito digitando o comando ‘git push’ via terminal ou editor de código.

## Onde é usado
É utilizado em processos de desenvolvimento de software, principalmente em plataformas como GitHub ou GitLab.

## Costuma ser confundido com
É confundido com git pull; Enquanto o pull recupera o código da internet, o push o envia para a internet.

## Perguntas frequentes
**O que acontece se eu não empurrar?**
As alterações feitas permanecem apenas no seu computador e sua equipe não pode vê-las.
