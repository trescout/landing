# O que é Cloning?

É o processo de duplicar um projeto de software ou dados inteiros, copiando-os para outro local.

## Definição
A clonagem é usada especialmente no mundo do software para baixar a versão atual de um projeto para o seu próprio computador. Desta forma você tem uma cópia do projeto com todo seu histórico e arquivos. Dessa forma, você pode fazer alterações no projeto original sem danificá-lo.

## Como funciona
Normalmente você copia o link para o projeto usando o comando 'clone' através de um sistema de controle de versão (como o git). O sistema baixa todos os arquivos para o seu dispositivo.

## Onde é usado
É usado ao importar projetos de código aberto de plataformas como GitHub para o seu próprio computador.

## Costuma ser confundido com
Pode ser confundido com backup; A clonagem é mais uma cópia feita com o propósito de trabalhar nela.

## Perguntas frequentes
**Isso altera o projeto original?**
Não, as alterações feitas na sua cópia não afetarão o projeto original.

**É necessária uma conexão com a Internet?**
Somente cópia é necessária no momento; Você pode então trabalhar offline.
