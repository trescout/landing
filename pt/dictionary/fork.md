# O que é Fork?

O processo de fazer uma cópia de um projeto de software existente e começar a fazer novas alterações nele de forma independente.

## Definição
No mundo do código aberto, um fork permite copiar uma cópia exata de um projeto escrito por outra pessoa para sua própria conta ou domínio. Depois de ter esta cópia, você pode modificá-la como desejar, adicionar novos recursos ou seguir sua própria direção sem estar vinculado ao projeto original.

## Como funciona
Ao pressionar o botão relevante nas plataformas de hospedagem de código, você copia todo o histórico e arquivos do projeto para seu próprio espaço.

## Onde é usado
É usado ao contribuir para projetos de código aberto ou quando você deseja personalizar um software existente para uma finalidade diferente.

## Costuma ser confundido com
Não deve ser confundido com o processo de clonagem, que simplesmente baixa o projeto para o computador e o examina; O processo de bifurcação cria uma propriedade nova e independente no lado do servidor.

## Perguntas frequentes
**Receberei atualizações do projeto original após a bifurcação?**
Ele não vem automaticamente, mas você também pode transferir o que há de novo no projeto original para sua própria cópia.
