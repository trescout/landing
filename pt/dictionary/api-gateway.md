# O que é API Gateway?

*Glossário · Dev · Última atualização: 17 de junho de 2026*

É um portão de entrada central que atende todas as solicitações do mundo exterior, direciona-as para os locais certos e realiza verificações de segurança.

## Definição

As aplicações modernas consistem em muitas partes diferentes. O API Gateway é como um guarda de trânsito diante de todas essas peças. Ele recebe a solicitação recebida, verifica quem a enviou e a encaminha para o serviço relevante.

***Analogia:** É como a recepção de uma grande empresa; Todos os visitantes vêm aqui primeiro, seu cadastro é feito e é determinado para qual departamento irão.*

## Como funciona

Ele monitora o tráfego de entrada, garante a segurança, restringe as solicitações se necessário e retorna os resultados ao usuário.

## Onde é usado

É usado em grandes sistemas de software com arquitetura de microsserviços.

## Costuma ser confundido com

Não é apenas um roteador; Também assume funções de segurança e gestão.

## Perguntas frequentes

**Por que isso é necessário?**

Em vez de abrir cada serviço individualmente para o mundo exterior, gerenciá-lo a partir de um único ponto proporciona segurança e ordem.
