# O que é Sandbox?

É uma área de trabalho isolada onde novos softwares ou códigos podem ser testados com segurança sem danificar o sistema principal.

## Definição
Uma sandbox é um playground em seu computador ou servidor que funciona como se estivesse em um ambiente real, mas está desconectado do mundo exterior. Erros cometidos aqui ou códigos perigosos executados nunca podem prejudicar seu sistema real. Você pode redefinir facilmente esse campo quando o experimento for concluído.

## Como funciona
Quando os desenvolvedores de software desenvolvem um novo recurso ou abrem um arquivo suspeito, eles o executam em uma sandbox. Se o sistema travar, apenas a pequena área da sandbox será afetada, deixando o computador intacto.

## Onde é usado
Ele é usado em testes de segurança cibernética, estágios de desenvolvimento de software e para que navegadores executem sites com segurança.

## Costuma ser confundido com
Pode ser misturado com máquinas virtuais; Uma caixa de areia é um espaço de isolamento geralmente mais leve e especializado para uma aplicação específica.

## Perguntas frequentes
**Por que uma sandbox é necessária?**
É necessário entender se um software desconhecido está infectado ou se um novo código irá quebrar o sistema.

**Os dados podem vazar da sandbox?**
Uma sandbox bem estruturada restringe completamente a comunicação com o mundo exterior e evita vazamentos.
