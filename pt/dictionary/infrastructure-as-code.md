# O que é Infrastructure as Code?

> IaC

Um método de automatizar instalações de sistema, como servidor e rede, escrevendo arquivos de código em vez de fazê-los manualmente.

## Definição
No passado, demorava dias para instalar e configurar servidores manualmente. Com o IaC, você grava essas configurações em arquivos de texto e as executa como software. Desta forma, seu sistema fica sempre configurado da mesma forma e os erros são minimizados.

## Como funciona
Arquivos de código especificando os requisitos do sistema são criados e esses arquivos são aplicados aos servidores por ferramentas IaC.

## Onde é usado
É usado em computação em nuvem, gerenciamento de sistemas de grande escala e lançamento contínuo de software.

## Perguntas frequentes
**Por que escrevemos código em vez de instalá-lo manualmente?**
Porque em operações manuais, uma pequena configuração esquecida pode causar grandes problemas, enquanto o código dá sempre o mesmo resultado.
