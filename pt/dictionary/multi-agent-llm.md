# O que é Multi-agent LLM?

É um sistema funcional no qual vários modelos de inteligência artificial cooperam para resolver tarefas complexas.

## Definição
Na estrutura LLM multiagente, cada unidade de IA possui uma expertise específica. Essas unidades se comunicam entre si e completam diferentes partes de um projeto. Tarefas complexas que seriam difíceis para um único modelo são resolvidas com muito mais rapidez e sem erros pela combinação de modelos especializados.

## Como funciona
Um modelo mestre distribui tarefas. Outros modelos trabalham em suas próprias áreas de especialização, como escrever código, realizar pesquisas ou controle de qualidade, e transmitir os resultados ao modelo principal.

## Onde é usado
É utilizado em processos de desenvolvimento de software, análise de dados complexos e fluxos de trabalho autônomos.

## Costuma ser confundido com
Ao contrário de um modelo único de inteligência artificial, aqui há trabalho em equipe e divisão de trabalho.

## Perguntas frequentes
**Por que um modelo não é suficiente?**
Algumas obras têm várias camadas; Ter um modelo que escreve código e verifica toda a segurança aumenta a margem de erro.

**Como os modelos se dão bem?**
Eles se comunicam enviando mensagens entre si usando comandos predefinidos e formatos de troca de dados.
