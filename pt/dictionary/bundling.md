# O que é Bundling?

*Glossário · Dev · Última atualização: 14 de junho de 2026*

É a combinação de muitos pequenos arquivos de código necessários para o funcionamento dos sites e transformados em um único pacote.

## Definição

Os projetos web modernos consistem em centenas de pequenos arquivos. Os navegadores demoram para baixar esses arquivos um por um. O processo de empacotamento otimiza e combina esses arquivos, fazendo com que o carregamento do site seja muito mais rápido.

***Analogia:** É como comprar um kit de refeição pronta que inclui tudo, em vez de comprar no mercado as dezenas de ingredientes necessários para fazer uma refeição, um por um.*

## Como funciona

Os desenvolvedores da Web montam arquivos e limpam peças desnecessárias usando ferramentas como Webpack ou Vite.

## Onde é usado

Frontend é utilizado em processos de desenvolvimento web, especialmente em aplicações de grande escala.

## Costuma ser confundido com

Não se trata apenas de copiar arquivos, mas também do processo de compactação e otimização deles.

## Perguntas frequentes

**Por que combinamos arquivos?**

Aumentar a velocidade de carregamento do site fazendo com que o navegador envie menos solicitações ao servidor.
