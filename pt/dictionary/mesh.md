# O que é Mesh?

Vários dispositivos ou serviços interconectados trocam dados sem a necessidade de um ponto central.

## Definição
Na estrutura mesh, cada nó pode se comunicar diretamente entre si. O sistema é mais durável porque não depende de um servidor central. Mesmo que um nó fique inativo, os dados continuam a ser transmitidos por outras rotas.

## Como funciona
Dispositivos ou serviços descobrem uns aos outros e estabelecem uma rede entre eles.

## Onde é usado
É usado em redes sem fio, sistemas domésticos inteligentes e arquiteturas de microsserviços.

## Perguntas frequentes
**Qual é a vantagem das redes mesh?**
Como não estão conectados a um único ponto, o risco de colapso do sistema é muito menor.
