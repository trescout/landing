# O que é Headless Browser?

Headless browser (traduzido para o português como navegador sem interface gráfica), é um navegador completo que roda sem tela.

## Definição e origem da palavra
"Headless" significa sem cabeça: nenhuma janela é renderizada, apenas o código é executado. Quando a carga visual é removida, a velocidade aumenta e o uso de recursos diminui. É o trabalhador silencioso de testes e processamento de dados.

## Como conhecer e usar no dia a dia?
Teste: Controle de regressão de páginas.Dados: Rastreamento de sites.Relatório: Geração de capturas de tela.

## Use em diferentes disciplinas
Impressão em papel: Olhar para os dados, não para a imagem.Voo cego: Navegar por instrumentos.Cozinha dos fundos: Produção sem clientes.

## Perguntas Frequentes
**Por que não há interface?**
Os dados são processados, não é necessária exibição. Economiza velocidade e recursos.

**É detectado?**
Pode ser. O modo stealth reduz os rastros, a política do site é determinante.

**Quando a GUI é necessária?**
Em inspeção visual e testes manuais. Na automação, o modo sem cabeça (headless) é suficiente.

**Qual é a diferença de recursos?**
O uso de memória e CPU diminui, a execução paralela aumenta. A escalabilidade vem daqui.
