# O que é Headless Browser?

Um navegador que não possui interface visual, carregando páginas da internet e processando dados inteiramente através de códigos.

## Definição
É um tipo de navegador onde a interface visual que você vê normalmente ao acessar a internet (botões, imagens) não é executada em segundo plano, sendo processada apenas a estrutura do código. Como não renderiza a interface visual, ele funciona muito rapidamente e consome menos recursos do computador.

## Como funciona
Os desenvolvedores usam ferramentas de automação para dar a este navegador o comando 'vá para este site e obtenha estes dados'.

## Onde é usado
É utilizado em testes automatizados de sites e em processos de extração de dados.

## Costuma ser confundido com
Navegador Headless Stealth

## Perguntas frequentes
**Por que não tem interface visual?**
Porque só precisamos dos dados, não precisamos ver a página.
