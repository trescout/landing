# O que é Open Source?

*Glossário · Dev · Última atualização: 3 de junho de 2026*

São softwares cujos códigos-fonte estão abertos ao acesso e desenvolvimento de todos.

## Definição

Código aberto é o compartilhamento dos códigos-fonte de um software de forma que qualquer pessoa possa examiná-lo, modificá-lo e distribuí-lo. Essa abordagem garante que o software seja desenvolvido e desenvolvido de forma transparente pela comunidade.

***Analogia:** É como publicar a receita de um prato num livro de receitas público, em vez de mantê-lo em segredo e permitir que todos melhorem essa receita e a tornem mais deliciosa.*

## Como funciona

Os desenvolvedores compartilham seus códigos em plataformas como GitHub. Desenvolvedores voluntários de todo o mundo trabalham neste código, corrigindo bugs e adicionando novos recursos.

## Onde é usado

Está no centro da tecnologia moderna, desde sistemas operacionais (como Linux) até modelos de inteligência artificial. Muitas vezes as empresas o escolhem para reduzir custos e garantir confiança.

## Costuma ser confundido com

É confundido com software livre, mas o código-fonte aberto é gratuito, ser gratuito é um efeito colateral.

## Perguntas frequentes

**O código aberto é seguro?**

Sim, porque milhares de olhos examinam o código, as vulnerabilidades são frequentemente encontradas e fechadas mais rapidamente do que em software de código fechado.

**Alguém pode alterar o código?**

Sim, mas a inclusão de alterações no projeto principal geralmente depende da aprovação dos diretores do projeto.
