# O que é Memory API?

Porta que permite ao software adicionar dados à memória de inteligência artificial ou consultar informações existentes.

## Definição
É o ponto de conexão que permite ao software adicionar dados à memória da inteligência artificial ou consultar informações existentes. Essa interface permite que os desenvolvedores forneçam facilmente memória de longo prazo à IA.

## Como funciona
O desenvolvedor envia comandos para o mecanismo de memória por meio da API. Com estes comandos, as informações são salvas, atualizadas ou recuperadas quando necessário.

## Onde é usado
Ele é usado por desenvolvedores de software que desenvolvem aplicativos de inteligência artificial para tornar o aplicativo mais inteligente.

## Costuma ser confundido com
É confundido com operações de banco de dados, mas trata-se especificamente de gerenciamento de memória em um formato que os modelos de inteligência artificial entendem.

## Perguntas frequentes
**Qualquer pessoa pode usar a API de memória?**
Se você tiver conhecimento em desenvolvimento de software, poderá seguir a documentação fornecida e integrá-la aos seus aplicativos.

**O que pode ser armazenado com esta API?**
Qualquer informação que a inteligência artificial precise lembrar, como preferências do usuário, conversas anteriores, detalhes do projeto.
