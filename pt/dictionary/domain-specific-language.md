# O que é Domain-Specific Language?

> DSL

São linguagens de programação especializadas projetadas para serem utilizadas apenas em uma área de negócio ou tipo de problema específico.

## Definição
Ao contrário das linguagens de uso geral (como Python ou Java), uma DSL é otimizada para uma tarefa específica. Por exemplo, CSS usado para organizar a aparência de uma página web ou SQL usado para consultas de banco de dados são linguagens especializadas em suas áreas. Essas linguagens simplificam as complexidades específicas desse domínio, permitindo ao desenvolvedor trabalhar mais com menos código.

## Como funciona
Ao usar uma DSL, é difícil ir além da área onde o idioma está definido porque o dicionário e as regras do idioma atendem apenas a essa área. Os desenvolvedores podem criar DSLs pequenas e personalizadas em seus próprios projetos para tornar sistemas complexos mais legíveis e gerenciáveis.

## Onde é usado
Você o encontra frequentemente em áreas como desenvolvimento web (CSS, HTML), gerenciamento de banco de dados (SQL), arquivos de configuração (YAML) e modelagem financeira.

## Costuma ser confundido com
Pode ser confundido com linguagens de programação de uso geral; A diferença é que um tenta fazer tudo, enquanto o outro se concentra em fazer algo com perfeição.

## Perguntas frequentes
**Por que não usamos uma DSL para cada trabalho?**
Porque aprender e manter cada novo idioma é um custo separado. Linguagens de uso geral ainda são indispensáveis ​​em grandes projetos que exigem flexibilidade.

**SQL é uma DSL?**
Sim, SQL é uma linguagem específica de domínio otimizada para consultas de banco de dados.
