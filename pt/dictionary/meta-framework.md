# O que é Meta-framework?

É uma plataforma de desenvolvimento abrangente baseada em ferramentas básicas de software.

## Definição
Metaframework é uma estrutura de alto nível que combina os recursos oferecidos por bibliotecas básicas para acelerar o processo de desenvolvimento de software. Geralmente em processos de desenvolvimento web, facilita o trabalho do desenvolvedor ao automatizar configurações complexas.

## Como funciona
Combina os recursos oferecidos pelas ferramentas básicas e oferece uma estrutura direcionada, permitindo ao desenvolvedor fazer mais trabalho com menos código.

## Onde é usado
Ele é usado para lançar rapidamente sites modernos e projetos de software complexos.

## Costuma ser confundido com
Sua diferença em relação às bibliotecas padrão é que ela serve como uma estrutura que gerencia todo o processo.

## Perguntas frequentes
**Por que devo usar metaestrutura?**
Ele aumenta a velocidade de desenvolvimento automatizando tarefas demoradas, como instalação e configuração de projetos.
