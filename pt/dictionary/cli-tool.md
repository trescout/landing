# O que é CLI Tool?

> Command Line Interface Tool

É um pequeno utilitário que permite ao computador realizar uma tarefa específica dando comandos escritos.

## Definição
A ferramenta CLI é um software que permite a comunicação com o computador digitando comandos no teclado em vez de clicar com o mouse. Graças a essas ferramentas, os desenvolvedores podem gerenciar arquivos, atualizar programas ou testar códigos. Não possui interface visual, funciona com texto em tela preta.

## Como funciona
Você abre o terminal ou aplicativo de linha de comando, digita o nome do programa e os comandos que especificam a ação que deseja executar e pressiona Enter.

## Onde é usado
É amplamente utilizado em processos de desenvolvimento de software, gerenciamento de servidores e scripts de automação.

## Costuma ser confundido com
É diferente dos programas normais com interface gráfica, é totalmente baseado em texto.

## Perguntas frequentes
**É difícil aprender ferramentas CLI?**
Depois de memorizar os comandos básicos, você perceberá que é bastante rápido e prático.
