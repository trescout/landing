# O que é CLI?

> Command Line Interface

É um método de dar comandos ao computador por meio de textos escritos.

## Definição
CLI é um método de gerenciamento do computador digitando comandos baseados em texto em vez de clicar com o mouse. É uma ferramenta de controle rápida e muito poderosa, especialmente para desenvolvedores de software.

## Como funciona
Uma tela preta é aberta e alguns comandos são digitados lá. O computador lê esses comandos e os executa instantaneamente.

## Onde é usado
É utilizado em processos de desenvolvimento de software, gerenciamento de servidores e para execução de modelos de inteligência artificial no computador local.

## Costuma ser confundido com
É confundido com uma interface gráfica (GUI), mas a CLI é totalmente baseada em texto e oferece muito mais customização.

## Perguntas frequentes
**É necessário aprender CLI?**
Embora não seja essencial para a maioria das ferramentas modernas, proporciona grande velocidade para trabalhar a nível profissional.

**O que acontece se eu digitar o comando errado?**
O sistema geralmente apresenta erros, mas também existem comandos críticos que exigem cautela.
