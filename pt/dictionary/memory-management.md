# O que é Memory Management?

É a colocação e limpeza regular de dados para utilizar a memória temporária do computador de forma eficiente.

## Definição
A RAM, que é a memória temporária dos computadores, tem espaço limitado. O gerenciamento de memória é um gerenciamento de sistema que decide quais dados permanecerão na memória por quanto tempo e como serão excluídos quando terminar.

## Como funciona
Enquanto os programas estão em execução, eles gravam os dados necessários na memória. O sistema monitora esses dados e elimina o que não é mais necessário, abrindo espaço para novos dados.

## Onde é usado
Ele é executado em segundo plano em sistemas operacionais, mecanismos de jogos e todos os softwares que exigem alto desempenho.

## Costuma ser confundido com
Não confundir com armazenamento (disco rígido); Este processo diz respeito apenas à memória temporária (RAM).

## Perguntas frequentes
**O que acontece se o gerenciamento de memória for ruim?**
O computador pode ficar lento, congelar ou os programas podem travar e fechar.

**Devo fazer isso?**
A maioria das linguagens modernas faz isso automaticamente, mas a verificação manual pode ser necessária se você estiver desenvolvendo software em nível de sistema.
