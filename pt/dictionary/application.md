# O que é Application?

É um programa de software desenvolvido para realizar uma tarefa específica em dispositivos como computadores, telefones ou tablets.

## Definição
Os aplicativos são ferramentas digitais que facilitam o trabalho diário dos usuários. Desde digitar um texto até editar uma foto ou navegar na web, tudo acontece através de um aplicativo. Esses softwares são executados no sistema operacional e fornecem uma interface visual ao usuário.

## Como funciona
O usuário executa o arquivo baixado em lojas de aplicativos ou na internet. O aplicativo processa os comandos do usuário utilizando os recursos do dispositivo e exibe os resultados na tela.

## Onde é usado
Ele aparece o tempo todo em smartphones, computadores desktop e navegadores da web.

## Costuma ser confundido com
Pode ser confundido com o sistema operacional; Embora o sistema operacional gerencie todo o dispositivo, o aplicativo realiza apenas um trabalho específico.

## Perguntas frequentes
**Aplicativos e software são a mesma coisa?**
Um aplicativo é um subconjunto de software. Todo aplicativo é software, mas nem todo software é um aplicativo (por exemplo, drivers são software, mas não aplicativos).

**Como atualizar aplicativos?**
Os desenvolvedores atualizam os arquivos do aplicativo para corrigir bugs ou adicionar novos recursos, que são baixados para o seu dispositivo automática ou manualmente.
