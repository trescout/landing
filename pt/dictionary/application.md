# O que é Application?

Aplicativo é um software de usuário que executa um trabalho específico.

## Definição e origem da palavra
Tudo, desde a escrita de texto até a edição de fotos, é feito por meio de um aplicativo. Ele roda no sistema operacional e oferece uma interface visual. A analogia da casa é adequada: o sistema é a casa, as aplicações são os seus móveis.

## Como conhecer e usar no dia a dia?
Telefone: Mensagens e serviços bancários.Área de trabalho: Escritório e design.Web: Aqueles que abrem no navegador.

## Coisas frequentemente misturadas
É considerado um sistema operacional. O sistema gerencia o dispositivo, o aplicativo faz um trabalho. Os drivers são software, mas não aplicativos.

## Use em diferentes disciplinas
Mobília: Itens dentro de casa.Utensílio de cozinha: Dispositivos de tarefa única.Acessório para carro: Peça instalada posteriormente.

## Perguntas Frequentes
**O aplicativo e o software são iguais?**
Aplicativo é um subconjunto de software. Todo aplicativo é um software, nem todo software é um aplicativo.

**Como atualizar aplicativos?**
Automático ou manual da loja. Os da Web são atualizados na inicialização.

**Qual é a diferença entre web e nativo?**
Native é rápido e totalmente autorizado, não requer instalação web. PWA alcança.

**A loja é necessária?**
Prático para distribuição, não obrigatório. A distribuição na Web e empresarial são alternativas.
