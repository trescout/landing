# O que é Toolchain Bootstrapping?

*Glossário · Dev · Última atualização: 1 de agosto de 2026*

É o processo de melhoria gradual de uma ferramenta de software até que ela atinja a capacidade de compilar ou construir-se.

## Definição

No mundo do software, para construir uma ferramenta do zero, muitas vezes você precisa de outra ferramenta. Bootstrapping é um método para quebrar esse ciclo, primeiro criando uma versão pequena e simples e depois usando essa versão para produzir versões mais complexas e avançadas. É uma espécie de arte autodidata de fabricação de ferramentas.

***Analogia:** É como construir um robô para produzir robôs em uma fábrica, primeiro usando uma simples chave de fenda e depois produzindo robôs mais avançados com esse robô.*

## Como funciona

Primeiro, um trecho básico de código é escrito e esse código se torna executável por si só. Em seguida, um ambiente de desenvolvimento completo é estabelecido fazendo acréscimos a essa estrutura básica.

## Onde é usado

É frequentemente usado no desenvolvimento de compiladores de linguagens de programação e ferramentas de sistema operacional.

## Perguntas frequentes

**Por que é tão complicado?**

É necessário eliminar completamente a dependência externa ao construir algo do zero.
