# O que é FP8?

*Glossário · AI · Última atualização: 15 de agosto de 2026*

> 8-bit Floating Point

É um formato de dados que representa números em um espaço menor para acelerar os cálculos de inteligência artificial.

## Definição

O FP8 simplifica a forma como os computadores processam números, permitindo-lhes consumir menos memória e executar operações mais rapidamente. Como os modelos de IA realizam cálculos massivos, esse formato pequeno aumenta significativamente a eficiência.

***Analogia:** Em vez de escrever uma carta detalhadamente, é como apenas resumi-la com palavras-chave e enviá-la com mais rapidez.*

## Como funciona

Os valores numéricos são convertidos para o formato FP8 enquanto o modelo é treinado ou executado.

## Onde é usado

É usado no treinamento e execução (inferência) de modelos de inteligência artificial.

## Costuma ser confundido com

Pode ser confundido com Quantização; FP8 é na verdade um tipo de quantização.

## Perguntas frequentes

**Isso reduz a qualidade do modelo?**

Quando aplicado corretamente quase não é perceptível, mas com uso excessivo a qualidade pode diminuir.

**Por que não foi usado antes?**

O hardware antigo não suportava esse formato, ele se difundiu com os chips de nova geração.
