# O que é Nameservers?

*Glossário · Dev · Última atualização: 17 de agosto de 2026*

É uma lista telefônica que converte nomes de sites usados por pessoas em endereços numéricos que os computadores entendem.

## Definição

Na verdade, todo site na Internet possui um equivalente numérico chamado endereço IP. Nameserver, quando você digita um nome em seu navegador, direciona esse nome para o endereço IP relevante, permitindo que você acesse o servidor correto. Este é o sistema de catálogo de endereços da Internet.

***Analogia:** É como procurar o nome de um amigo na lista telefônica e encontrar seu número real; Você sabe o nome, o sistema encontra o número.*

## Como funciona

Quando você digita um endereço web, seu computador pergunta aos servidores de nomes: Qual é o endereço numérico deste nome? O servidor de nomes retorna a resposta e seu navegador se conecta a esse endereço.

## Onde é usado

Ele está localizado centralmente nas configurações de nomes de domínio e nas infraestruturas dos provedores de serviços de Internet.

## Costuma ser confundido com

Pode ser confundido com hospedagem; hospedagem é onde os arquivos do seu site são armazenados e o servidor de nomes é o caminho para chegar lá.

## Perguntas frequentes

**O que a alteração das configurações do servidor de nomes faz?**

Normalmente, quando você move seu site para um servidor diferente, você atualiza essas configurações para que o tráfego vá para o novo local.

**O que acontece se o servidor de nomes falhar?**

Você não pode acessar sites pelo nome porque seu navegador da Internet não consegue encontrar onde o site está localizado.
