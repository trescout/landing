# O que é Source Control?

É um sistema de rastreamento que registra todas as alterações de código em projetos de software e permite retornar ao histórico.

## Definição
Ao desenvolver software, alterações constantes são feitas no código. O controle de versão armazena cada alteração feita nesse processo com informações de data e autor. Assim, quando um erro é cometido, é possível retornar facilmente ao estado funcional anterior do projeto.

## Como funciona
Os desenvolvedores enviam (commit) seus códigos para o sistema. Se surgir um problema, um dos registros antigos no sistema é selecionado e o projeto é revertido para aquele momento.

## Onde é usado
É obrigatório em todos os processos modernos de desenvolvimento de software, especialmente em trabalhos em equipe.

## Costuma ser confundido com
Não é o mesmo que backup, pois gerencia não apenas os arquivos, mas também o histórico das alterações.

## Perguntas frequentes
**Por que devo usar?**
É vital para restaurar seu código ao estado anterior caso você o corrompa acidentalmente.

**Qual é o mais popular?**
O Git é o sistema mais utilizado atualmente.
