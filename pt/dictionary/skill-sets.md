# O que é Skill Sets?

É o conjunto de habilidades que uma pessoa ou inteligência artificial possui para realizar um trabalho ou tarefa específica.

## Definição
Muitas vezes, uma habilidade não é suficiente para realizar um trabalho. Um conjunto de habilidades é uma coleção de habilidades interconectadas e usadas em conjunto para atingir um objetivo. No mundo da IA, isso se refere ao conjunto de ferramentas e capacidades que um agente precisa para concluir uma tarefa específica.

## Como funciona
'Ferramentas' e 'habilidades' são definidas para agentes de inteligência artificial para permitir-lhes desempenhar as suas tarefas. Essas definições se unem para formar a capacidade do agente para realizar esse trabalho.

## Onde é usado
O AI Agent é usado em processos de desenvolvimento, descrições de cargos e gerenciamento de projetos.

## Costuma ser confundido com
Pode ser confundido com uma única ‘habilidade’, mas é um conjunto de habilidades.

## Perguntas frequentes
**Podemos adicionar novos recursos à inteligência artificial?**
Sim, novas ferramentas e capacidades podem ser definidas para os agentes de acordo com as suas necessidades.

**Por que o conjunto de habilidades é importante?**
É necessário determinar quais tarefas o agente pode ou não realizar.
