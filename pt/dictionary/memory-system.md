# O que é Memory System?

É a arquitetura de armazenamento que permite à inteligência artificial lembrar interações passadas, preferências do usuário e dados.

## Definição
O sistema de memória permite que a inteligência artificial acesse não apenas a conversa atual, mas também informações passadas. Graças a este sistema, a inteligência artificial não esquece quem você é ou o que disse antes. Isso é fundamental para uma experiência de usuário personalizada e consistente.

## Como funciona
O sistema salva as conversas em bancos de dados vetoriais ou arquivos de memória especiais. Quando uma nova pergunta é feita, o sistema primeiro verifica sua memória e encontra e utiliza informações relevantes.

## Onde é usado
Ele é usado em assistentes pessoais, ferramentas de inteligência artificial que rastreiam projetos de longo prazo e bots de atendimento ao cliente.

## Costuma ser confundido com
Pode ser confundido com janela de contexto; a janela de contexto é a memória de curto prazo, enquanto o sistema de memória é a memória permanente ou de longo prazo.

## Perguntas frequentes
**A memória pode ser apagada?**
Sim, a maioria dos sistemas tem a opção de limpar os dados do usuário ou redefinir a memória.

**A inteligência artificial lembra de tudo?**
Somente as informações que o sistema tem permissão para salvar ou que são consideradas importantes são lembradas.
