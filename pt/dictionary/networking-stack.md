# O que é Networking Stack?

É a estrutura em camadas de software e protocolos que permite que os computadores se comuniquem entre si.

## Definição
A pilha de rede é um conjunto de camadas de software que gerenciam o processo desde a conexão de um dispositivo à Internet até que os pacotes de dados cheguem ao endereço correto. Cada camada segue certas regras (protocolos) sobre como os dados são empacotados, transmitidos e descompactados na extremidade oposta. Graças a esta estrutura, dispositivos de diferentes marcas e modelos podem falar uma linguagem comum.

## Como funciona
À medida que os dados descem da camada superior para a camada inferior, eles são empacotados, passam pela linha de transmissão e se transformam em informações significativas, subindo novamente no receptor.

## Onde é usado
É encontrado na estrutura central dos sistemas operacionais, infraestruturas de servidores e hardware de rede.

## Costuma ser confundido com
Não deve ser confundido apenas com cabos físicos ou modem; é um conjunto de protocolos de software.

## Perguntas frequentes
**Por que tem uma estrutura em camadas?**
Porque dividir um processo complexo em partes torna muito mais fácil encontrar bugs e atualizar a tecnologia.
