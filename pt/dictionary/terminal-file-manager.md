# O que é Terminal File Manager?

*Glossário · Dev · Última atualização: 27 de julho de 2026*

Uma ferramenta que permite gerenciar seus arquivos apenas através da linha de comando em vez de janelas visuais.

## Definição

Essas ferramentas permitem copiar, mover ou excluir arquivos com atalhos de teclado sem usar o mouse. Ele permite que você opere muito rapidamente sem o peso de uma interface gráfica.

***Analogia:** É um sistema que permite ter o livro que deseja à sua frente apenas pressionando um botão, em vez de subir nas prateleiras com uma escada de uma biblioteca.*

## Como funciona

Você abre o terminal e executa o programa. Dois painéis aparecem na tela e você pode navegar entre os arquivos com as teclas de seta do teclado.

## Onde é usado

É utilizado no gerenciamento de servidores ou em processos de desenvolvimento de software onde é necessário editar arquivos muito rapidamente.

## Costuma ser confundido com

Não deve ser confundido com 'shell', que apenas diz comandos; Esta ferramenta oferece uma interface de edição visual.

## Perguntas frequentes

**É difícil aprender?**

Pode levar algum tempo para memorizar os atalhos no início, mas depois que você se acostuma com eles, fica muito rápido.

**Funciona em todos os sistemas operacionais?**

Geralmente é muito comum no Linux e no macOS.
