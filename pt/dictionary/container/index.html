O que é Container?

É uma caixa portátil que contém tudo o que é necessário para o funcionamento de um software e garante que funcione da mesma forma em todos os computadores.

Definição

Os contêineres agrupam o código, as bibliotecas e as configurações de um aplicativo em um único pacote. Dessa forma, seu software funciona no servidor ou no computador de outra pessoa da mesma maneira que no seu computador. Assim, elimina completamente o problema de ‘estava funcionando no meu computador’.

Analogia: Pense em uma cozinha; Você coloca todos os ingredientes, temperos e utensílios necessários para cada refeição em uma única caixa e leva para onde quiser. Não importa onde você o abra, você poderá cozinhar a mesma comida com o mesmo sabor.

Como funciona

Usando ferramentas como o Docker, os desenvolvedores empacotam tudo o que o aplicativo precisa em uma ‘imagem de contêiner’. Este pacote é executado em uma área isolada, independente do sistema operacional. Dessa forma, não haverá conflito com outros aplicativos do sistema.

Onde é usado

É usado em computação em nuvem, distribuição de software e gerenciamento de aplicativos complexos. É especialmente padrão em projetos onde grandes equipes precisam trabalhar em harmonia umas com as outras.

Costuma ser confundido com

Muitas vezes é confundido com máquinas virtuais; mas os contêineres são muito mais leves e rápidos porque compartilham o sistema operacional.

Perguntas frequentes

Por que o contêiner é tão popular?

Porque garante que o software funcione com a mesma estabilidade em todos os ambientes e reduz o processo de instalação de minutos para segundos.

Qual é a diferença entre um contêiner e uma máquina virtual?

As máquinas virtuais carregam seus próprios sistemas operacionais, enquanto os contêineres compartilham o kernel do sistema operacional host; então os contêineres são muito mais rápidos.
