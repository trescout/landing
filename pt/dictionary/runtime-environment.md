# O que é Runtime Environment?

O ambiente de suporte básico que um software precisa para ser executado em um computador.

## Definição
Se você pensar no código de software como uma receita, esse ambiente é a cozinha onde a receita é preparada. Ele fornece as bibliotecas e os recursos do sistema necessários para a execução do código.

## Como funciona
Quando você instala um programa, o ambiente necessário para esse programa geralmente é instalado em segundo plano. Você não vê, mas o programa recebe suporte desse ambiente toda vez que é executado.

## Onde é usado
Ele é encontrado em navegadores da web, servidores de aplicativos e todos os softwares de nível de sistema operacional.

## Costuma ser confundido com
Não deve ser confundido com o software em si; Este ambiente é a casa onde o software reside.

## Perguntas frequentes
**Por que dá erro?**
Geralmente ocorre um erro porque os arquivos de mídia necessários estão faltando ou são da versão errada.
