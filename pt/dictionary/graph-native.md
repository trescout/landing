# O que é Graph-native?

É um projeto de sistema baseado em uma estrutura na qual os dados são conectados entre si por meio de nós.

## Definição
Embora os bancos de dados tradicionais armazenem informações em tabelas, essa abordagem conecta os dados como um mapa de rede. Coloca as relações entre as informações no centro do sistema desde o início. Dessa forma, consultar conexões complexas torna-se muito mais rápido e natural.

## Como funciona
Ao criar seu modelo de dados, você define objetos e suas interações como pontos e linhas. Seguindo essas linhas, o sistema encontra links ocultos entre os dados em segundos.

## Onde é usado
É usado em análises complexas de redes sociais, sistemas de recomendação e aplicativos que gerenciam grandes massas de informações interconectadas.

## Costuma ser confundido com
É frequentemente confundido com bancos de dados relacionais tradicionais; No entanto, este sistema estabelece relações na fase de concepção, e não posteriormente.

## Perguntas frequentes
**Por que devo escolher este método?**
Este método é a forma mais eficiente se as relações entre os seus dados forem tão importantes quanto os próprios dados.
