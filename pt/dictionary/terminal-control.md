# O que é Terminal Control?

*Glossário · Dev · Última atualização: 10 de julho de 2026*

É o processo de dar instruções ao computador diretamente pela linha de comando, sem utilizar interface gráfica (mouse e windows).

## Definição

É o gerenciamento do sistema operacional ou aplicativos por meio de comandos baseados em texto digitados pelo usuário por meio do teclado. Permite operações mais rápidas e precisas, superando as limitações visuais oferecidas pela interface gráfica. É um método indispensável para desenvolvedores de software profissionais.

***Analogia:** É como ditar uma receita especial diretamente ao chef de um restaurante, em vez de escolher no cardápio olhando as fotos.*

## Como funciona

Abra o aplicativo de terminal em seu computador. Digite os comandos que executam a ação desejada (por exemplo, listar um arquivo ou executar um programa) e pressione Enter.

## Onde é usado

É amplamente utilizado em processos de desenvolvimento de software, gerenciamento de servidores e automação.

## Costuma ser confundido com

É igual ao conceito de CLI (Command Line Interface); o controle do terminal refere-se ao processo de uso ativo desta interface.

## Perguntas frequentes

**Por que nem todo mundo usa terminal?**

As interfaces gráficas são mais fáceis de aprender porque são visuais, mas o terminal é muito mais poderoso e rápido.
