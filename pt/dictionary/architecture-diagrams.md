# O que é Architecture Diagrams?

São diagramas visuais que mostram os componentes de um sistema de software complexo e suas relações entre si.

## Definição
Os diagramas de arquitetura de software fornecem uma visão geral de como um projeto funciona. É usado para entender qual parte está onde, como os dados fluem e a estrutura geral do sistema. Também é uma ótima ferramenta para explicar o sistema para pessoas não técnicas.

## Como funciona
Caixas, setas e linhas são frequentemente utilizadas. As caixas representam partes do software e as setas representam o tráfego de dados ou a interação entre essas partes.

## Onde é usado
É utilizado em processos de desenvolvimento de software, reuniões de equipe e documentação técnica.

## Costuma ser confundido com
Pode ser confundido com fluxogramas; No entanto, os diagramas arquitetônicos mostram mais a estrutura do sistema e os fluxogramas mostram as etapas de um processo.

## Perguntas frequentes
**Preciso saber código para desenhar esses diagramas?**
Não, existem muitas ferramentas de visualização que funcionam com arrastar e soltar.

**Por que isso é tão importante?**
Reduz a complexidade do sistema e permite que todos da equipe sonhem a mesma coisa.
