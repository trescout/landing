# O que é Workspace?

*Desenvolvimento · Última atualização: 29 de outubro de 2026*

É um espaço de trabalho digital onde os usuários gerenciam projetos, modelos de inteligência artificial e ferramentas de desenvolvimento sob o mesmo teto.

## Definição

Um espaço de trabalho (workspace) é um ambiente digital que reúne todos os arquivos, configurações e ferramentas necessários nos processos de desenvolvimento de software ou criação de conteúdo. Em sistemas de inteligência artificial, o espaço de trabalho limita os diretórios locais e o contexto de memória que os modelos podem acessar. Assim, os usuários não enfrentam confusão de dados ao alternar entre projetos.

***Analogia:** É semelhante a uma escrivaninha organizada que contém apenas os documentos e ferramentas do projeto em que você está focado no momento.*

## Como funciona

O usuário ou agente define a pasta de projeto relevante como o diretório principal. O sistema indexa automaticamente os códigos, as configurações e as fontes de dados dentro desta pasta, incluindo-os no espaço de trabalho.

## Onde é usado

É utilizado em editores de código, plataformas de agentes de inteligência artificial e ambientes de desenvolvimento baseados em nuvem.

## Costuma ser confundido com

É diferente de um espaço de trabalho de agente (agent workspace); enquanto o espaço de trabalho do agente é uma zona de isolamento onde apenas um agente executa tarefas, o espaço de trabalho geral abrange todo o projeto do usuário.

## Perguntas e respostas

**O que o isolamento do espaço de trabalho proporciona?**

Evita que códigos, variáveis de ambiente e contextos de diferentes projetos se misturem.

**Como os agentes de inteligência artificial utilizam o espaço de trabalho?**

Eles leem e editam os arquivos dentro do espaço de trabalho para gerar código com uma compreensão abrangente de todo o projeto.
