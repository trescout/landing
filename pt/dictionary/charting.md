# O que é Charting?

*Desenvolvimento · Última atualização: 2 de novembro de 2026*

É o processo de transformar conjuntos de dados complexos ou resultados de cálculos em gráficos e mapas visuais.

## Definição

O charting é o processo de criação de gráficos, tabelas e diagramas para facilitar a análise e a apresentação de dados brutos. Possui uma ampla gama de aplicações, desde a análise de dados financeiros até indicadores técnicos e cálculos de mapas astrológicos. É frequentemente preferido em sistemas de software para fornecer feedback visual instantâneo ao usuário.

***Analogia:** É como transformar uma planilha confusa de milhares de linhas em um gráfico de linhas colorido que se torna compreensível em um único relance.*

## Como funciona

Números brutos ou objetos extraídos de fontes de dados são processados com uma lógica de dimensionamento específica. Com a ajuda de bibliotecas de desenho e motores gráficos, eles são transferidos para um sistema de coordenadas, convertidos em elementos visuais e renderizados na tela.

## Onde é usado

É utilizado em plataformas de análise do mercado de ações, painéis de inteligência de negócios, aplicativos de monitoramento de saúde e softwares de astrologia.

## Costuma ser confundido com

O conceito de Data Visualization refere-se à disciplina geral de visualização de dados, enquanto o charting foca especificamente na ação e no mecanismo de desenho de gráficos ou mapas.

## Perguntas e respostas

**As operações de charting devem ser realizadas no navegador ou no servidor?**

Para interação do usuário e gráficos dinâmicos, geralmente são preferidas as bibliotecas do lado do cliente no navegador, mas o desenho no lado do servidor também pode ser feito para relatórios estatísticos pesados.

**Quais são os tipos de gráficos mais populares para charting?**

Gráficos de linhas, gráficos de colunas, gráficos de velas e gráficos de pizza são amplamente utilizados.
