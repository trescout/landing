# O que é LSP?

> Language Server Protocol

É um protocolo de comunicação padrão que fornece recursos inteligentes ao seu editor enquanto escreve código.

## Definição
LSP é uma ponte entre ferramentas de escrita de código (editores) e servidores que entendem a lógica do código. Graças a este protocolo, o editor que você usa; Ele pode oferecer recursos como detecção de erros, preenchimento automático e acesso às definições de forma padrão em todos os idiomas. Ele permite que seu editor atue de forma inteligente, sem precisar saber qual idioma você está usando.

## Como funciona
Seu editor envia o código que você escreve para um 'servidor de linguagem' executado em segundo plano. O servidor analisa o código e dá sugestões. Você escreve seu código com mais rapidez e sem erros, sem sentir nada.

## Onde é usado
Ele é executado constantemente em segundo plano em editores de código modernos, como o VS Code.

## Costuma ser confundido com
Não é apenas um recurso do editor, é uma linguagem de conversação universal entre o editor e a linguagem.

## Perguntas frequentes
**Por que isso é tão importante?**
Em vez de desenvolver recursos separadamente para cada editor, ele permite que o suporte à linguagem de gravação única funcione em qualquer lugar.

**Isso afeta minha velocidade?**
Não, pelo contrário, acelera o seu processo de codificação evitando que cometa erros.
