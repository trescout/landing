# O que é Code Coverage?

Uma métrica que mede quanto dos testes de software de código escrito realmente são executados e verificados.

## Definição
Escrevemos testes para entender se cada linha de código que você escreve em um projeto de software funciona sem erros. A cobertura de código calcula qual porcentagem do seu código esses testes tocam. Uma proporção alta significa que seu código é mais seguro e testado.

## Como funciona
Ferramentas de teste automatizadas são executadas durante o processo de desenvolvimento de software. Essas ferramentas monitoram cada linha do seu código e marcam as linhas que o teste passa. Finalmente, ele fornece um relatório como '85% do código testado'.

## Onde é usado
É utilizado em processos de desenvolvimento de software, linhas CI/CD e relatórios de controle de qualidade.

## Perguntas frequentes
**100% de cobertura de código é sempre bom?**
Não, apenas mostra que o código funciona; não garante a cobertura de erros lógicos ou de todos os cenários.

**Como faço para medir isso?**
Ele pode ser medido automaticamente com bibliotecas de teste adequadas à linguagem de programação usada (por exemplo, cobertura.py para Python).
