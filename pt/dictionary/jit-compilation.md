# O que é Just-in-Time Compilation?

*Desenvolvimento · Última atualização: 27 de outubro de 2026*

> Just-in-Time Compilation

É um método de acelerar o código do programa, traduzindo-o para linguagem de máquina no momento em que será executado, e não antes.

## Definição

Normalmente, o código é traduzido uma vez após ser escrito, mas este método analisa o código enquanto ele está em execução e otimiza as partes usadas com mais frequência naquele momento. Dessa forma, os programas permanecem flexíveis e apresentam alto desempenho. Os navegadores modernos e muitas linguagens de programação usam essa tecnologia.

***Analogia:** É como cozinhar a comida fresca logo quando você se senta à mesa, em vez de prepará-la com antecedência e deixá-la esperando.*

## Como funciona

Em tempo de execução, o desempenho do código é monitorado e as partes críticas são transformadas para serem executadas mais rapidamente.

## Onde é usado

É encontrado em mecanismos JavaScript, máquinas virtuais Java e ambientes de tempo de execução modernos.

## Costuma ser confundido com

Difere do método de compilação tradicional, onde o código é totalmente traduzido no início, com seu dinamismo em tempo de execução.

## Perguntas e respostas

**Por que nem tudo é JIT?**

Como pode introduzir alguma sobrecarga na inicialização, às vezes é mais vantajoso compilá-lo antecipadamente.

**Aumenta o desempenho?**

Sim, aumenta significativamente a velocidade, especialmente em blocos de código repetidos com frequência.
