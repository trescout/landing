# O que é Plugin Specification?

*Glossário · Dev · Última atualização: 15 de agosto de 2026*

É um conjunto de regras técnicas que devem ser seguidas para desenvolver complementos externos para um software.

## Definição

A especificação do plug-in é um guia que determina como o software principal se comunicará com os plug-ins, quais dados ele trocará e como funcionará. Graças a estas regras, a estabilidade do software é mantida.

***Analogia:** É como o formato e a voltagem de uma tomada; Para que o seu dispositivo funcione, você deve inserir um plugue que esteja em conformidade com esses padrões.*

## Como funciona

Os desenvolvedores leem a documentação especificada e introduzem o plugin no sistema escrevendo seus códigos de acordo com estas regras.

## Onde é usado

Ele é usado em complementos de navegador, integrações de ferramentas de IA e nas principais plataformas de software.

## Costuma ser confundido com

Pode ser confundido com SDK, mas é mais um conjunto de regras, enquanto SDK é um conjunto mais amplo de ferramentas.

## Perguntas frequentes

**Por que devo seguir essas regras?**

Se você não cumprir, seu plugin não funcionará no software principal ou apresentará um erro.

**As regras são as mesmas para todos os softwares?**

Não, cada software possui seus próprios padrões específicos.
