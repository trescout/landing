# O que é Microservices?

É uma arquitetura que divide softwares grandes em pequenas partes, cada uma operando de forma independente.

## Definição
Antigamente, os softwares eram construídos como um único bloco gigantesco. Os microsserviços, por outro lado, dividem essa estrutura em partes. Por exemplo, em um site de compras, o pagamento, o carrinho e o login do usuário funcionam como pequenos softwares separados.

## Como funciona
Cada parte pode ser atualizada ou reparada por conta própria. Se uma parte falha, em vez de todo o aplicativo travar, apenas aquele recurso fica desativado.

## Onde é usado
É utilizado em aplicações web de grande escala e sistemas de alto tráfego.

## Costuma ser confundido com
Não se trata apenas da fragmentação do código, mas do método pelo qual essas partes se comunicam entre si.

## Perguntas frequentes
**Por que é tão complicado?**
Em grandes projetos, é impossível alterar todo o sistema ao mesmo tempo, por isso a divisão em partes facilita a gestão.

**É adequado para todos os projetos?**
Não, para projetos pequenos pode criar uma complexidade desnecessária.
