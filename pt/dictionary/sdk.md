# O que é SDK?

*Glossário · Dev · Última atualização: 16 de junho de 2026*

> Software Development Kit

É um conjunto de ferramentas e bibliotecas que facilitam aos desenvolvedores de software o desenvolvimento de aplicativos para uma plataforma específica.

## Definição

SDK é uma espécie de kit de desenvolvimento. Ele contém ferramentas prontas, documentos e códigos de amostra que facilitam a escrita de código. Em vez de escrever tudo do zero para utilizar os recursos de uma plataforma, você combina as peças prontas que este kit oferece.

***Analogia:** É um armário que você compra de uma marca de móveis; Contém não apenas placas, mas também parafusos, chave Allen e guia de montagem. O SDK é aquela caixa que contém tudo que você precisa para fazer um software.*

## Como funciona

O desenvolvedor baixa o SDK relevante em seu computador e faz referência a essas ferramentas durante a codificação. Assim, ele pode lidar com operações complexas com comandos de linha única.

## Onde é usado

É utilizado no desenvolvimento de aplicações móveis, integrando um modelo de inteligência artificial em sua própria aplicação ou em motores de jogos.

## Costuma ser confundido com

Misturado com API; A API é uma porta, o SDK é toda a caixa de ferramentas que permite passar por aquela porta e montar a casa.

## Perguntas frequentes

**Todos os SDKs são gratuitos?**

A maioria é gratuita, mas algumas plataformas específicas podem cobrar taxas de licenciamento pelo uso do SDK.

**Um aplicativo não pode ser escrito sem SDK?**

Pode ser escrito, mas é preciso codificar tudo do zero, o que leva muito tempo.
