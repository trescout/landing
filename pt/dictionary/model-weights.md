# O que é Model Weights?

Valores numéricos que armazenam as informações que a inteligência artificial aprendeu durante o treinamento e que determinam suas decisões.

## Definição
São números que indicam a força das conexões neurais no cérebro de um modelo de inteligência artificial. Durante o processo de treinamento, o modelo trabalha com bilhões de dados e atualiza esses números continuamente. Esse enorme conjunto de números resultante é onde todas as capacidades e conhecimentos do modelo são armazenados.

## Como funciona
Os dados fornecidos como entrada passam por camadas compostas por esses números e, a cada etapa, são multiplicados e somados para produzir um resultado. À medida que erros são cometidos, esses números são reduzidos ou aumentados.

## Onde é usado
Você os encontrará ao compartilhar modelos de código aberto, ao dimensionar arquivos de modelo e em processos de ajuste fino (fine-tuning).

## Costuma ser confundido com
Podem ser confundidos com dados brutos ou código de programação, mas são apenas os coeficientes de experiência que o modelo aprendeu.

## Perguntas frequentes
**Os pesos do modelo podem ser alterados?**
Sim, esses números podem ser atualizados por meio de processos de ajuste fino ou treinamento adicional.
