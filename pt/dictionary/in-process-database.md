# O que é In-process Database?

*Glossário · Data · Última atualização: 23 de junho de 2026*

É um sistema leve de armazenamento de dados que é executado diretamente no aplicativo, sem a necessidade de um servidor separado.

## Definição

Esses tipos de bancos de dados funcionam como parte do seu aplicativo. Em vez de enviar dados para outro lugar ou conectar-se pela internet, ele mantém os dados diretamente na memória do programa que você está utilizando. Desta forma, é muito rápido e a instalação bastante simples.

***Analogia:** É como ter todos os livros em uma gaveta da mesa em vez de ir à biblioteca; Você não precisa sair do seu lugar para encontrar a informação que procura.*

## Como funciona

Você o adiciona ao seu aplicativo como uma biblioteca ou arquivo. Você usa comandos padrão para ler ou gravar dados e, quando o aplicativo é fechado, os dados geralmente são armazenados em um arquivo local.

## Onde é usado

É preferido em aplicativos móveis, pequenos softwares de desktop ou processos de prototipagem rápida.

## Costuma ser confundido com

É misturado com bancos de dados baseados em cliente-servidor; Este sistema é local, embora exija conexão remota.

## Perguntas frequentes

**Esses bancos de dados são adequados para big data?**

Geralmente projetados para dados de pequeno e médio porte, os baseados em servidor são melhores para sistemas grandes.

**É difícil de instalar?**

Não, normalmente você pode começar a usá-lo imediatamente, apenas adicionando um arquivo de biblioteca.
