# O que é Kernels?

*Glossário · Dev · Última atualização: 30 de julho de 2026*

A parte mais básica do sistema operacional que gerencia a comunicação entre o hardware e o software do computador.

## Definição

Kernel é o coração de um sistema operacional. É a primeira peça carregada na memória quando o computador é ligado e controla qual software pode acessar o processador, a memória e outros hardwares e quando. Quando um usuário abre um aplicativo, esse aplicativo se comunica com o hardware por meio do kernel, e não diretamente.

***Analogia:** É como a recepção de um hotel; Gerencia o acesso e o layout das salas (hardware) para todos os hóspedes (software).*

## Como funciona

Ele traduz as operações solicitadas pelo software em comandos que o hardware pode compreender e transmite os resultados do hardware de volta para o software.

## Onde é usado

Ele está localizado no centro de todos os sistemas operacionais, como Windows, Linux e macOS.

## Costuma ser confundido com

Não deve ser confundido com o sistema operacional como um todo; O kernel é apenas a camada de gerenciamento mais básica.

## Perguntas frequentes

**O que acontece se o kernel travar?**

Todo o sistema para e o computador desliga, muitas vezes apresentando erros como uma “tela azul”.

**O kernel de cada sistema operacional é diferente?**

Sim, por exemplo, o kernel do Linux e o kernel do Windows possuem arquiteturas diferentes.
