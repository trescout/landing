# O que é Superset?

*Glossário · Dev · Última atualização: 11 de julho de 2026*

É uma estrutura mais abrangente que inclui todos os recursos de um sistema existente e adiciona novos recursos.

## Definição

Quando algo é um superconjunto, significa que inclui tudo o que está subjacente a ele. Por exemplo, outra linguagem, que é um superconjunto de uma linguagem de programação, pode executar todo o código da primeira linguagem, mas oferece novos recursos adicionais. Isso é usado para melhorar o sistema enquanto mantém a compatibilidade com versões anteriores.

***Analogia:** É como um smartphone contendo todos os recursos de um aparelho antigo que só possuía recursos de fabricação de telefone e agregava novos recursos como internet e câmera.*

## Como funciona

Ao projetar uma nova linguagem ou ferramenta, as regras existentes são preservadas e novas camadas são construídas sobre elas para não atrapalhar os hábitos dos usuários antigos.

## Onde é usado

É frequentemente usado em linguagens de programação (por exemplo, TypeScript é um superconjunto de JavaScript) e arquiteturas de software.

## Perguntas frequentes

**É vantajoso usar superconjunto?**

Sim, porque permite mudar para novas tecnologias sem jogar fora os códigos escritos no sistema antigo.
