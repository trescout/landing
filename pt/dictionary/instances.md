# O que é Instances?

É cada cópia independente de um software ou sistema em execução simultânea.

## Definição
No mundo da computação, quando você inicia um programa, uma 'instância' desse programa é criada na memória. Se você abrir três janelas diferentes do mesmo programa, estará executando três cópias (instâncias) distintas dele. Cada uma é independente da outra e mantém seus próprios dados.

## Como funciona
Os recursos do sistema reservam um espaço separado para cada cópia. Assim, se ocorrer um erro em uma cópia ou se o programa travar, as outras cópias podem continuar funcionando sem serem afetadas.

## Onde é usado
É muito utilizado em computação em nuvem, gerenciamento de servidores e servidores de jogos.

## Costuma ser confundido com
Não deve ser confundido com o programa em si (código-fonte); o código-fonte é único, enquanto as cópias em execução podem ser ilimitadas.

## Perguntas frequentes
**Por que executamos mais de uma cópia?**
É utilizado para distribuir a carga, aumentar a segurança ou gerenciar as tarefas de diferentes usuários simultaneamente.
