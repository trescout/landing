# O que é Production Pipeline?

É a cadeia de processos automatizados pela qual o software passa depois de desenvolvido e testado até chegar aos usuários.

## Definição
Pipeline de produção é uma linha de produção que garante que o código saia do seu computador e chegue ao servidor ativo com segurança. Nesse processo, o código é automaticamente testado, verificado quanto a erros e enviado ao servidor. Garante que o software permaneça sempre atualizado e estável, minimizando a intervenção humana.

## Como funciona
Quando os desenvolvedores carregam o código no sistema, o pipeline entra em ação; Ele executa os testes primeiro e atualiza o software se for bem-sucedido.

## Onde é usado
É uma prática padrão em empresas de software modernas e em aplicativos constantemente atualizados.

## Costuma ser confundido com
Pode ser misturado com pipeline de dados; O pipeline de dados movimenta os dados, enquanto o pipeline de produção prepara o próprio software para publicação.

## Perguntas frequentes
**Por que estamos automatizando esse processo?**
Ganhar velocidade e aumentar a segurança eliminando erros manuais.
