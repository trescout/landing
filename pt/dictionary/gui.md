# O que é GUI?

*Glossário · Dev · Última atualização: 5 de julho de 2026*

> Graphical User Interface

É uma interface que permite gerenciar programas de computador visualmente com ícones, menus e janelas em vez de digitar texto.

## Definição

GUI é a camada visual que torna a tecnologia acessível a todos. Permite que alguém que não sabe codificar controle o computador clicando com o mouse. É a base dos sistemas operacionais modernos.

***Analogia:** Em vez de um chef (código) cozinhando pratos complexos na cozinha de um restaurante, ele é como um garçom e um cardápio que permite escolher o cardápio e fazer o pedido.*

## Como funciona

Cada botão, janela e ícone que você vê na tela é um elemento GUI. Ao clicar em um botão, os códigos executados em segundo plano recebem este comando visual e iniciam o processo relevante.

## Onde é usado

Ele é encontrado em smartphones, sistemas operacionais de computador e em todos os aplicativos móveis que você usa.

## Costuma ser confundido com

Contrasta com CLI (Interface de Linha de Comando); Na CLI, apenas o texto é escrito, enquanto na GUI a visualidade está em primeiro plano.

## Perguntas frequentes

**Todo software possui uma GUI?**

Não, algumas ferramentas profissionais funcionam apenas com base em texto (CLI).

**A GUI afeta o desempenho?**

Desenhar elementos visuais requer poder de processamento; portanto, interfaces baseadas em texto às vezes são preferidas em sistemas muito simples.
