# O que é Backend?

*Glossário · Dev · Última atualização: 19 de setembro de 2026*

É a parte de trás de uma aplicação que não é vista pelo usuário, onde os dados são processados e executados no servidor.

## Definição

Os botões ou menus que você vê ao entrar em um site são o front-end. Nos bastidores, a parte que realiza todo o trabalho pesado, como a verificação de suas senhas, a extração de informações do banco de dados ou o processamento de pagamentos, é o back-end. O usuário vê apenas o resultado, enquanto o back-end é a cozinha que prepara esse resultado.

***Analogia:** É como a cozinha de um restaurante; você come sua refeição na mesa (front-end), mas o preparo da comida, a seleção dos ingredientes e o cozimento acontecem inteiramente na cozinha (back-end).*

## Como funciona

Os códigos executados no servidor recebem as solicitações recebidas, comunicam-se com o banco de dados e, após realizar as operações lógicas necessárias, enviam o resultado de volta ao usuário.

## Onde é usado

Está presente em todas as aplicações web modernas, no plano de fundo de aplicações móveis e em sistemas de API.

## Costuma ser confundido com

Pode ser confundido com o front-end; o front-end interage com você, enquanto o back-end faz o trabalho.

## Perguntas frequentes

**Por que executamos código no back-end?**

Porque é necessário garantir a segurança dos dados e realizar cálculos complexos sem sobrecarregar o dispositivo do usuário.
