# O que é Local?

Isso significa que programas ou dados rodam inteiramente no seu dispositivo, sem a necessidade de Internet.

## Definição
A maioria dos aplicativos hoje envia dados para a nuvem. No princípio de funcionamento local, tudo termina no processador do seu computador ou telefone. Isso significa que seus dados não serão divulgados.

## Como funciona
Em vez de usar o software na nuvem, você baixa os arquivos de instalação para o seu dispositivo. Mesmo desligando a internet, o programa continua funcionando com todas as suas funcionalidades.

## Onde é usado
Ele é usado em ferramentas de inteligência artificial com foco na privacidade, sistemas de gerenciamento de arquivos pessoais e ambientes seguros de desenvolvimento de software.

## Costuma ser confundido com
É semelhante à auto-hospedagem, mas local geralmente se refere a um único dispositivo, enquanto a auto-hospedagem se refere a um servidor.

## Perguntas frequentes
**Qual é a maior vantagem de trabalhar localmente?**
A sua maior vantagem é a privacidade; Seus dados nunca saem do seu dispositivo.
