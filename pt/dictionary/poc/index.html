O que é PoC?

Proof of Concept

É um teste preliminar de pequena escala realizado para provar se uma ideia funciona na prática.

Definição

Antes de iniciar um grande projeto, é um estudo de curta duração realizado para entender se a tecnologia base apresenta o desempenho esperado. Nesta fase, não se espera um design perfeito ou um produto em escala total; apenas a funcionalidade básica é testada.

Analogia: É como fazer uma maquete antes de construir um prédio ou cozinhar um prato em casa para testar antes de adicioná-lo ao menu de um restaurante.

Como funciona

Com recursos limitados, dados são coletados tornando funcional apenas a característica mais crítica. Se o resultado for bem-sucedido, investe-se no projeto; caso contrário, ele é descartado.

Onde é usado

É utilizado em processos de desenvolvimento de software e em investimentos em novas tecnologias.

Costuma ser confundido com

É confundido com protótipo; o protótipo é um exemplo do produto, enquanto o PoC é um experimento que prova a viabilidade da ideia.

Perguntas frequentes

O que acontece se o PoC for bem-sucedido?

Como a viabilidade da ideia foi comprovada, passa-se para a fase de desenvolvimento em escala total.
