# O que é Scripting Language?

*Desenvolvimento · Última atualização: 23 de outubro de 2026*

É um tipo de linguagem de programação usada para automatizar processos de software e executar tarefas rapidamente, geralmente sem a necessidade de compilação.

## Definição

Uma linguagem de script (scripting language) é executada linha por linha por um interpretador, em vez de ser previamente compilada em código de máquina como as linguagens tradicionais. Geralmente é preferida para conectar sistemas existentes, automatizar tarefas rotineiras ou adicionar dinamismo a páginas da web. Python, JavaScript e Bash estão entre as linguagens de script mais populares.

***Analogia:** Em vez de ser a cópia final montada de ponta a ponta de um filme, assemelha-se a um texto teatral prático que os atores seguem passo a passo no palco.*

## Como funciona

O desenvolvedor escreve o código e dá diretamente o comando de execução. Um software intermediário (interpretador) lê esses códigos instantaneamente e os encaminha como comandos para o sistema operacional ou navegador. Como não há etapa de compilação, o ciclo de desenvolvimento e teste avança de forma extremamente rápida.

## Onde é usado

É frequentemente utilizada na automação de tarefas rotineiras em administração de sistemas, na criação de interfaces interativas em navegadores web e em fluxos de trabalho de análise de dados.

## Costuma ser confundido com

É confundida com linguagens de programação de sistemas. Enquanto linguagens de sistema como C ou Rust são compiladas diretamente para alto desempenho a nível de hardware, as linguagens de script são focadas na praticidade e na velocidade de desenvolvimento.

## Perguntas e respostas

**As linguagens de script são lentas?**

Em termos de poder de processamento puro, geralmente são mais lentas em comparação com linguagens diretamente compiladas, mas graças às otimizações modernas, são mais do que suficientes para a maioria das tarefas diárias e aplicações web.

**Python é uma linguagem de script?**

Sim, Python é tanto uma linguagem de programação de propósito geral quanto uma linguagem de script poderosa e amplamente utilizada.
