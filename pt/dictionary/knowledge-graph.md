# O que é Knowledge Graph?

*Glossário · Data · Última atualização: 3 de junho de 2026*

É uma rede estruturada de informações que conecta relações entre dados e conceitos.

## Definição

Um gráfico de conhecimento é um modelo de dados estruturado que conecta os relacionamentos dos dados como um mapa. Dessa forma, a inteligência artificial pode descobrir facilmente conexões ocultas entre informações aparentemente independentes.

***Analogia:** É como desvendar uma teia de crimes conectando fotos e nomes com fios vermelhos em um quadro de detetives.*

## Como funciona

As informações são registradas na forma de pontos nodais e linhas que conectam esses pontos. Por exemplo, um relacionamento de funcionário é estabelecido entre um nó pessoal e um nó empresa.

## Onde é usado

Ele é usado para fornecer resultados mais precisos em mecanismos de busca e para analisar dados corporativos complexos.

## Costuma ser confundido com

Não é uma tabela ou lista comum do Excel porque o relacionamento entre os dados é importante aqui, e não os dados em si.

## Perguntas frequentes

**Qual é a diferença entre gráfico de conhecimento e RAG?**

Ao pesquisar documentos RAG, o gráfico de conhecimento mapeia as relações lógicas de conceitos nesses documentos.

**Por que é chamado de gráficos?**

É chamado assim porque é matematicamente uma estrutura de rede que consiste em pontos e linhas.
