# O que é LLM API?

*Glossário · AI · Última atualização: 2 de outubro de 2026*

> Large Language Model Application Programming Interface

É uma ponte que permite aos desenvolvedores adicionar as capacidades de modelos de inteligência artificial às suas próprias aplicações.

## Definição

Em vez de executar um modelo de inteligência artificial diretamente no seu próprio computador, é um ponto de conexão que permite fazer perguntas a esse modelo e obter respostas através da internet. Os desenvolvedores podem usar esta interface para fazer com que os seus programas comuniquem com a inteligência artificial. Ou seja, ao desenvolver uma aplicação, não precisa de realizar os cálculos complexos do modelo no seu próprio servidor, utiliza um serviço pronto.

***Analogia:** É como ir a um restaurante e, em vez de entrar na cozinha para cozinhar a comida você mesmo, fazer o pedido ao empregado de mesa e esperar que a comida pronta chegue à sua mesa.*

## Como funciona

O desenvolvedor envia um 'pedido' (request) ao modelo. O modelo processa este pedido e devolve o resultado como uma 'resposta' (response). Este processo ocorre através de um protocolo de internet padrão.

## Onde é usado

É utilizado em chatbots, geradores de conteúdo automático e em todas as aplicações web baseadas em inteligência artificial.

## Costuma ser confundido com

Não é o LLM em si, mas a porta que permite aceder a ele.

## Perguntas frequentes

**Qualquer pessoa pode usar uma API de LLM?**

Sim, mas geralmente é necessário pagar uma taxa ou obter uma chave (API key).

**Qual é a diferença em relação a um modelo que corre no meu próprio computador?**

Você precisa de energia de hardware em seu próprio computador, mas ao usar API, toda a carga fica no outro servidor.
