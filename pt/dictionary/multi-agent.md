# O que é Multi-agent?

*Glossário · AI · Última atualização: 26 de junho de 2026*

É a colaboração de mais de um software de inteligência artificial para um objetivo comum, dividindo uma tarefa complexa.

## Definição

Em sistemas multiagentes, cada agente de inteligência artificial atua como um funcionário com sua própria área de atuação. Enquanto um agente planeja, outro escreve o código e outro verifica os resultados. Dessa forma, tarefas que um único modelo teria dificuldade em realizar sozinho são concluídas com muito mais rapidez e sem erros de cooperação.

***Analogia:** Em vez de uma única pessoa tentar gerir toda a empresa, é como se uma equipe especializada em diferentes departamentos se reunisse e trabalhasse no projeto.*

## Como funciona

Defina uma tarefa principal e divida-a em subpartes. Atribua um agente com habilidades especiais para cada peça. Gerencie o processo garantindo que esses agentes se comuniquem entre si.

## Onde é usado

É frequentemente usado no desenvolvimento de software, análise de dados complexos e fluxos de trabalho automatizados.

## Costuma ser confundido com

É diferente de um único modelo de IA; O que é importante aqui é a interação dos agentes entre si.

## Perguntas frequentes

**Como os agentes se dão bem?**

Eles geralmente enviam mensagens por meio de um agente 'condutor' ou de um protocolo de comunicação predeterminado.

**Por que não usamos um único modelo poderoso?**

Quando as tarefas se tornam muito complexas, modelos especializados menores se combinam para cometer menos erros e produzir melhores resultados.
