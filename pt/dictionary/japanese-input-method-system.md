# O que é Japanese Input Method System?

*Glossário · Dev · Última atualização: 2 de julho de 2026*

> IME

É um software de interface que permite escrever caracteres japoneses com um teclado padrão.

## Definição

Como o japonês consiste em milhares de caracteres, ele não cabe em um teclado padrão. Este sistema funciona como uma ponte que converte sons fonéticos escritos pelo usuário no alfabeto latino em caracteres japoneses. O software processa instantaneamente o que está escrito e traz os caracteres corretos para a tela.

***Analogia:** É como se um tradutor transcrevesse instantaneamente o que você diz em outro idioma.*

## Como funciona

O usuário pressiona letras no teclado, o software acumula essas letras e exibe os caracteres japoneses na tela com a ajuda de um ‘mecanismo de conversão’.

## Onde é usado

É usado em sistemas operacionais de computadores e telefones e em editores de texto.

## Costuma ser confundido com

Pode ser misturado com o mecanismo de conversão Neural Kana-Kanji; IME é o sistema geral, enquanto o mecanismo de conversão é a parte do conversor inteligente dentro dele.

## Perguntas frequentes

**Posso digitar em japonês sem IME?**

Não, este software é necessário porque é impossível inserir milhares de caracteres no teclado.
