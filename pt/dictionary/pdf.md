# O que é PDF?

*Glossário · Data · Última atualização: 8 de junho de 2026*

> Portable Document Format

É um formato de documento digital que é exibido sem perder seu formato independentemente do dispositivo em que é aberto.

## Definição

PDF é uma versão fixa do texto, imagens e layout do documento. A fonte pode mudar quando você abre um arquivo do Word em outro computador, mas o PDF elimina esse risco. Hoje, é uma das fontes de dados mais utilizadas para sistemas de inteligência artificial.

***Analogia:** É como colocar um pedaço de papel no freezer e congelar; Onde quer que você leve o papel, seu formato nunca muda.*

## Como funciona

O documento é convertido em um único arquivo com todos os dados da imagem por meio de uma impressora PDF. Os sistemas de IA usam analisadores de PDF para “ler” esses arquivos.

## Onde é usado

É utilizado em correspondências oficiais, e-books, faturas e artigos acadêmicos.

## Costuma ser confundido com

Pode ser confundido com arquivos do Word, mas o Word é editável, enquanto o PDF geralmente é fixado.

## Perguntas frequentes

**Posso editar o PDF?**

Pode ser editado com ferramentas especiais, mas seu principal objetivo é visualizar e compartilhar.

**Como a IA lê PDF?**

Ele lê o PDF convertendo-o em texto com ferramentas especiais (analisadores) que analisam o texto e as imagens nele contidas.
