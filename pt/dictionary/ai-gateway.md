# O que é AI Gateway?

*Glossário · AI · Última atualização: 2 de julho de 2026*

É um software de gateway que gerencia e controla o tráfego para modelos de inteligência artificial.

## Definição

É uma camada que coleta e organiza as solicitações feitas a diferentes modelos de inteligência artificial em um único ponto. Este software decide para qual modelo as solicitações serão direcionadas, realiza verificações de segurança e rastreia os custos de uso. É uma espécie de polícia de trânsito do mundo da inteligência artificial.

***Analogia:** É como a recepção de um hotel; Cumprimenta os hóspedes que chegam, encaminha-os para o quarto adequado e verifica se cumprem as regras do hotel.*

## Como funciona

Em vez de enviar os dados da sua aplicação diretamente para o modelo de inteligência artificial, primeiro você os envia para este gateway. O gateway verifica os dados, anonimiza-os se necessário e encaminha-os para o modelo mais adequado. Ele também organiza a resposta para você e a apresenta de volta.

## Onde é usado

Ele é usado para segurança e gerenciamento de custos em aplicativos empresariais de inteligência artificial.

## Costuma ser confundido com

Só pode ser confundido com uma API; no entanto, essa estrutura fornece uma camada adicional de controle e gerenciamento além da API.

## Perguntas frequentes

**O uso do AI Gateway fica lento?**

Pode haver um atraso muito pequeno, mas os benefícios de segurança e gerenciamento compensam essa diferença.

**Em que casos é necessário?**

Obrigatório se você usa vários modelos ou deseja controlar o uso de IA dentro da empresa.
