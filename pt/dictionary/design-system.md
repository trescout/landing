# O que é Design System?

É o conjunto de padrões de design e componentes usados no desenvolvimento de aplicações.

## Definição
São bibliotecas de regras, paletas de cores, fontes e componentes prontos criados para manter a consistência visual e funcional de um produto digital. Usando este sistema, os desenvolvedores e designers não projetam do zero sempre. Desta forma, todos os botões ou menus do aplicativo funcionam e aparecem da mesma forma.

## Como funciona
Os designers primeiro determinam os elementos básicos (cor, tipografia). Em seguida, são criados componentes combinados (botões, formulários) a partir desses elementos. Os desenvolvedores adicionam esses componentes aos seus projetos como bibliotecas de código e os utilizam quando precisam deles.

## Onde é usado
É usado em sites, aplicativos móveis e projetos de software empresariais de grande porte.

## Costuma ser confundido com
Pode ser confundido com o ‘Guia de Estilo’, que é apenas um guia visual; O sistema de design é uma versão muito mais ampla e funcional disso.

## Perguntas frequentes
**Por que precisamos de um sistema de design?**
É preciso ganhar velocidade e entregar a mesma experiência de usuário em toda a aplicação.

**Quem é responsável pelo sistema de design?**
É um documento vivo que normalmente é gerenciado em conjunto por designers e desenvolvedores front-end.
