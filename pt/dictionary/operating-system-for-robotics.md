# O que é Operating System for Robotics?

*Glossário · Dev · Última atualização: 30 de junho de 2026*

> ROS

É uma infraestrutura de software especial que gerencia movimentos, sensores e partes complexas de robôs.

## Definição

Os robôs não tratam apenas de hardware; Eles precisam de um cérebro que os controle. Este sistema operacional coordena tudo, desde o movimento dos braços do robô até a capacidade de ver o ambiente ao redor com o olho (câmera).

***Analogia:** Ele é como o maestro de uma orquestra; Garante uma música harmoniosa, dizendo ao violinista, baterista e pianista o que fazer e quando.*

## Como funciona

Diferentes peças de hardware enviam mensagens entre si através deste sistema. Por exemplo, a câmera envia a mensagem ‘há um obstáculo na minha frente’, e o sistema dá o comando ‘parar’ aos motores.

## Onde é usado

É utilizado em robôs industriais, veículos autônomos e projetos robóticos em laboratórios de pesquisa.

## Costuma ser confundido com

Não deve ser confundido com sistemas operacionais normais (Windows/macOS); Esses sistemas são otimizados apenas para gerenciar hardware robótico.

## Perguntas frequentes

**É necessário ser engenheiro para utilizar este sistema?**

Não é necessário ser engenheiro para aprender os conceitos básicos, mas é recomendável aprendê-lo, pois é uma linguagem padrão no mundo da robótica.
