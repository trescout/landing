# O que é Adversarial Analysis?

*Glossário · Dev · Última atualização: 28 de junho de 2026*

São testes de segurança realizados imitando ataques maliciosos para encontrar os pontos fracos de um sistema.

## Definição

Este método é usado para entender a durabilidade de um software ou inteligência artificial. Os especialistas em segurança enviam deliberadamente informações incorretas ou enganosas para fazer o sistema cometer erros ou contornar suas defesas. O objetivo é prever como o sistema reagirá em caso de ataque real.

***Analogia:** É como fingir ser um guarda de castelo e tentar entrar furtivamente para testar as paredes de um castelo.*

## Como funciona

Dados inesperados, comandos incorretos ou perguntas manipulativas são enviados ao sistema. São analisadas as respostas dadas pelo sistema e onde são mapeadas as vulnerabilidades de segurança.

## Onde é usado

É utilizado para garantir a segurança de modelos de inteligência artificial, auditorias de segurança cibernética e processos de desenvolvimento de software.

## Costuma ser confundido com

Não deve ser confundido apenas com depuração; Aqui, o foco está na presença de um ator malicioso.

## Perguntas frequentes

**Por que estamos fazendo esse teste?**

Isso é feito para testar o sistema diante de invasores reais e eliminar suas vulnerabilidades.

**Como isso funciona na inteligência artificial?**

A resistência é medida fazendo perguntas ao modelo que o enganarão ou o forçarão a responder de forma antiética.
