# O que é Vector Index?

*Glossário · Data · Última atualização: 8 de junho de 2026*

É um método de mapeamento usado para pesquisar e encontrar rapidamente os equivalentes numéricos (vetores) dos dados.

## Definição

Os modelos de inteligência artificial traduzem palavras ou imagens em números. Em vez de examinar milhões de dados um por um enquanto procuramos algo, organizamos esses dados em um mapa especial chamado “índice vetorial”. É como organizar os livros da biblioteca em ordem alfabética e categórica por assunto, em vez de em pilhas aleatórias.

***Analogia:** Embora existam milhares de livros em uma biblioteca, é como um sistema de catálogo especial que permite encontrar apenas aqueles com “capa vermelha e gênero de aventura” em segundos.*

## Como funciona

Vetores próximos uns dos outros (semelhantes em significado) em um espaço multidimensional são colocados na mesma região. Quando é feita uma busca, o sistema retorna o resultado olhando apenas para aquela região.

## Onde é usado

É usado em sistemas RAG, mecanismos de recomendação e grandes bancos de dados.

## Costuma ser confundido com

Pode ser confundido com Banco de Dados Vetorial; Vector Database é um repositório e Vector Index é o sistema de pesquisa dentro desse repositório.

## Perguntas frequentes

**Por que o índice é importante?**

Sem um índice, você precisa examinar todos os dados a cada pesquisa, o que é muito lento.

**Qual é o significado dos vetores?**

Vetores são coordenadas matemáticas de dados compreendidos pelo computador.
