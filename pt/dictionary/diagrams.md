# O que é Diagrams?

São diagramas visualmente simplificados de sistemas, processos ou estruturas complexas.

## Definição
Diagramas são mapas visuais que nos permitem compreender muitas estruturas complexas, desde arquitetura de software até processos de negócios. Em vez de se perder entre as linhas de código, ele ajuda você a ver rapidamente como as partes se conectam e como os dados fluem. Um bom diagrama pode ser mais descritivo do que milhares de páginas de documentos.

## Como funciona
Usando caixas, setas e linhas, você desenha os componentes do sistema e as interações entre eles. Hoje em dia também existem ferramentas que criam isso automaticamente escrevendo código.

## Onde é usado
É usado durante o projeto do sistema, reuniões de equipe e documentação técnica.

## Costuma ser confundido com
Não é apenas uma imagem, é um modelo que representa o funcionamento lógico do sistema.

## Perguntas frequentes
**Alguém pode desenhar um diagrama?**
Sim, o importante não é que seja artístico, mas que reflita com precisão o funcionamento do sistema.
