# O que é Network Stack?

É o conjunto de camadas de software necessárias para que um computador se conecte à internet e troque dados.

## Definição
Quando você envia dados pela internet, eles não vão em uma única etapa. A pilha de rede (network stack) é o conjunto de regras de software que gerencia todo o processo, desde o empacotamento dos dados até a sua passagem pelo cabo e a remontagem no destino. Essas camadas formam a ponte entre o hardware e os aplicativos que você utiliza.

## Como funciona
Seu sistema operacional executa essas camadas automaticamente em segundo plano assim que você se conecta à internet; você apenas abre o navegador.

## Onde é usado
Está presente como um componente fundamental em servidores, computadores pessoais e roteadores de rede.

## Costuma ser confundido com
É o mesmo conceito que networking stack.

## Perguntas frequentes
**Sou eu quem gerencia essas camadas?**
Não, seu sistema operacional e os drivers de rede gerenciam esse processo para você.

**Por que isso é importante?**
Se uma dessas camadas funcionar incorretamente, sua conexão com a internet será interrompida ou você sofrerá perda de dados.
