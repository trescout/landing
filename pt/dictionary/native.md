# O que é Native?

Significa que um software foi criado especificamente para o sistema operacional do dispositivo em que é executado e projetado para oferecer o mais alto desempenho.

## Definição
Aplicativos nativos podem acessar diretamente o hardware e o sistema operacional do dispositivo. Como falam a língua do dispositivo sem precisar de outra camada, eles funcionam de forma mais rápida e fluida. Geralmente, utilizam os recursos exclusivos daquele dispositivo em sua capacidade total.

## Como funciona
Os desenvolvedores escrevem código usando as ferramentas de desenvolvimento de software do próprio dispositivo. Dessa forma, o aplicativo pode usar diretamente todos os recursos oferecidos pelo sistema operacional. Como não há uma camada de tradução intermediária, não há atrasos.

## Onde é usado
Eles aparecem nas lojas de aplicativos de smartphones, em softwares de nível de sistema operacional e em jogos que exigem alto desempenho.

## Costuma ser confundido com
Aplicativos baseados na web ou aplicativos híbridos usam uma camada intermediária, como um navegador, para se comunicar com o dispositivo.

## Perguntas frequentes
**Um aplicativo nativo é sempre melhor?**
Em termos de desempenho, geralmente sim, mas o desenvolvimento leva mais tempo e é necessário escrever um código separado para cada dispositivo.

**Como funcionam os aplicativos não nativos?**
Eles geralmente funcionam dentro de um navegador ou através de uma camada de tradução, o que às vezes pode causar lentidão.
