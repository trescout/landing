# O que é Compile-time?

*Glossário · Dev · Última atualização: 7 de junho de 2026*

É a fase de preparação onde o código escrito é traduzido para uma linguagem que o computador possa entender e os erros são verificados.

## Definição

Os códigos escritos por desenvolvedores de software são geralmente legíveis por humanos. Para que o computador o entenda, ele deve ser traduzido para linguagem de máquina. O tempo de compilação é a fase crítica em que o código é inspecionado e transformado pouco antes de ser executado.

***Analogia:** É como o processo de verificação de um livro pelo editor antes de ser impresso e de prepará-lo para impressão na gráfica.*

## Como funciona

O desenvolvedor emite o comando 'compile'. O sistema verifica os códigos, verifica erros de digitação e, se for bem-sucedido, cria um arquivo executável.

## Onde é usado

É parte integrante do processo de desenvolvimento de software em linguagens como C++, Rust e Go.

## Costuma ser confundido com

Está misturado com tempo de execução; O tempo de compilação é a fase de detecção de erros, o tempo de execução pode ser a fase de detecção de erros.

## Perguntas frequentes

**Por que os erros em tempo de compilação são importantes?**

Ele fornece uma experiência de software mais segura porque detecta erros antes da execução do programa.

**Toda linguagem compila?**

Não, algumas linguagens (como Python) podem ser executadas diretamente sem compilar.
