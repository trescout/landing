# O que é Specification?

É um documento técnico detalhado que especifica o que um projeto, software ou produto deve fazer e quais regras deve seguir.

## Definição
Especificação ('spec' para abreviar) é como o projeto arquitetônico de um edifício. Os desenvolvedores de software entendem o que construirão examinando este documento antes de começarem a escrever código. É utilizado para reduzir erros e esclarecer expectativas.

## Como funciona
É escrito por proprietários de projetos ou engenheiros. Inclui recursos, regras de segurança e expectativas de desempenho.

## Onde é usado
É utilizado em processos de desenvolvimento de software, arquivos de licitações e etapas de design de produtos.

## Costuma ser confundido com
Semelhante ao requisito; o requisito centra-se em “o que queremos”, enquanto a especificação centra-se em “como o faremos”.

## Perguntas frequentes
**As especificações podem mudar?**
Sim, pode ser atualizado de acordo com as necessidades à medida que o projeto avança, mas isso muitas vezes afeta o custo.
