# O que é ab (ApacheBench)?

> ApacheBench

Uma ferramenta de teste de desempenho simples usada para medir quantas pessoas um servidor web pode suportar simultaneamente.

## Definição
Quando você cria um site, você se pergunta quantos visitantes ele consegue suportar ao mesmo tempo. O ApacheBench, ou simplesmente ab, roda a partir da linha de comando e envia centenas de solicitações falsas para o seu servidor simultaneamente. Assim, você vê com antecedência quando seu servidor vai travar ou ficar lento.

## Como funciona
Você abre a tela do terminal e digita os comandos especificando o endereço web que deseja testar e quantas solicitações deseja enviar. A ferramenta fornece um relatório numérico sobre quantas transações você consegue realizar por segundo.

## Onde é usado
É usado ao medir o desempenho do servidor, logo antes de se esperar uma grande onda de tráfego ou para realizar um teste de velocidade após a otimização do sistema.

## Perguntas frequentes
**Ele simula um usuário real?**
Exatamente não, ele apenas bombardeia o destino com solicitações muito rapidamente, uma após a outra.

**Funciona apenas em servidores Apache?**
Não, embora o nome seja ApacheBench, ele pode testar qualquer endereço web acessível na internet.
