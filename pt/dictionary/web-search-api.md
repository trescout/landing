# O que é Web Search API?

É uma ponte que permite que softwares e agentes de inteligência artificial realizem pesquisas na internet e recebam resultados atualizados como dados organizados.

## Definição
A API de Pesquisa na Web permite que o programa que você desenvolve utilize motores de busca exatamente como um ser humano. Graças a esta ferramenta, seus softwares podem encontrar a informação que procuram entre bilhões de páginas na internet em segundos e transferi-la para seus próprios sistemas. É uma fonte de informação indispensável, especialmente para sistemas de inteligência artificial que necessitam de dados atualizados.

## Como funciona
Seu software envia uma solicitação contendo palavras-chave específicas para o endereço da API. Os servidores do motor de busca processam essa solicitação e devolvem os resultados ao seu software em um formato organizado, composto por títulos, links e textos de resumo.

## Onde é usado
Você pode usar esta ferramenta em sistemas RAG, que permitem que modelos de inteligência artificial aprendam notícias recentes, e em softwares de monitoramento automático de conteúdo.

## Costuma ser confundido com
É frequentemente confundido com o método de web scraping. Enquanto o web scraping examina o design dos sites e extrai dados brutos, a API de Pesquisa na Web traz diretamente os resultados de pesquisa prontos e filtrados fornecidos pelo motor de busca.

## Perguntas frequentes
**Por que os modelos de inteligência artificial usam a API de Pesquisa na Web?**
Os dados de treinamento dos modelos de inteligência artificial pertencem ao passado. Para aprender eventos atuais, a previsão do tempo em tempo real ou as últimas notícias, eles realizam pesquisas na internet por meio dessas APIs.

**O uso da API de Pesquisa na Web é pago?**
Geralmente, é oferecida uma certa cota de uso gratuito. No entanto, para pesquisas de alto volume e projetos comerciais, você precisa pagar aos provedores de motores de busca.
