# O que é DNS?

*Desenvolvimento · Última atualização: 23 de outubro de 2026*

> Domain Name System

É um sistema de diretório global que traduz nomes de domínio da internet em endereços IP numéricos que permitem que os computadores encontrem uns aos outros.

## Definição

O Sistema de Nomes de Domínio (DNS) é um protocolo de rede que torna possível o uso de nomes de sites significativos em vez de endereços IP complexos que seriam difíceis de lembrar para as pessoas. Quando você digita um endereço no seu navegador, os servidores DNS entram em ação, mapeando esse nome para o endereço IP do servidor correto. Como um dos blocos de construção fundamentais da infraestrutura da internet, ele garante uma comunicação ininterrupta.

***Analogia:** É semelhante a procurar o nome de uma pessoa na agenda telefônica para obter o seu número e fazer a chamada através desse número.*

## Como funciona

Quando um usuário insere um nome de domínio no navegador, a solicitação vai primeiro para o cache DNS local e, em seguida, gradualmente para os servidores DNS autoritativos. Quando o endereço IP correto é encontrado, ele é retornado ao navegador e a conexão é estabelecida. Esse processo de consulta geralmente é concluído em milissegundos.

## Onde é usado

É utilizado ao acessar sites, em infraestruturas de entrega de e-mail e em roteamentos entre servidores em nuvem.

## Costuma ser confundido com

É confundido com o conceito de endereço IP. O endereço IP é a identidade numérica real do dispositivo, enquanto o DNS é o sistema que mapeia essa identidade para nomes legíveis por humanos.

## Perguntas e respostas

**É possível acessar a internet se o DNS cair?**

Os nomes de domínio não podem ser resolvidos, mas se os endereços IP diretos dos sites forem conhecidos, o acesso pode ser feito através do navegador.

**O que é o cache DNS?**

É o armazenamento temporário de endereços IP de sites visitados com frequência no dispositivo; assim, elimina-se a necessidade de consultar o servidor todas as vezes.
