# O que é Clean Code?

É uma estrutura de código clara, simples e livre de erros que pode ser facilmente lida por outros desenvolvedores de software.

## Definição
Código limpo é um código escrito de uma forma que não apenas os computadores, mas também os humanos possam entendê-lo. Em vez de estruturas complexas e entrelaçadas, são preferidos códigos com nomes significativos e tarefas divididas em partes claras e regulares. Essa abordagem torna o projeto mais fácil de manter a longo prazo e reduz erros.

## Como funciona
Ele é escrito dando nomes significativos às variáveis, minimizando funções para realizar um único trabalho e evitando complexidade desnecessária.

## Onde é usado
É um princípio fundamental para todas as equipes profissionais de desenvolvimento de software manter a qualidade do código.

## Perguntas frequentes
**Não é suficiente para o código funcionar?**
Fazer o código funcionar é apenas o primeiro passo; O código limpo garante que o código possa ser alterado por outra pessoa no futuro.
