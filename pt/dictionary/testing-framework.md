# O que é Testing Framework?

É um conjunto de ferramentas prontas que permitem escrever e executar testes de software regularmente, de forma rápida e fácil.

## Definição
É uma biblioteca que oferece regras e estruturas prontas, em vez de escrever constantemente os mesmos códigos enquanto escreve testes. Reporta resultados de testes, indica erros e padroniza o processo. É um conjunto de ferramentas auxiliares que facilita o trabalho dos desenvolvedores de software.

## Como funciona
Você inclui esta ferramenta em seu projeto e escreve seus testes com os comandos que ela oferece. A ferramenta executa automaticamente seus testes e lista quais foram aprovados ou reprovados.

## Onde é usado
É utilizado em projetos de desenvolvimento de software, principalmente em sistemas que são constantemente atualizados.

## Perguntas frequentes
**Qual estrutura devo escolher?**
Geralmente é melhor escolher o mais popular com base na linguagem de programação que você está usando e nas necessidades do projeto.
