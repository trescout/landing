# Qu'est-ce que Decompiler ?

C'est un outil de traduction qui convertit le code machine en un langage de programmation lisible.

## Définition
Lorsqu'un programme informatique est compilé, le code compréhensible par les humains est transformé en langage machine, c'est-à-dire en nombres que seul le processeur peut comprendre. Le décompilateur inverse ce processus pour tenter de ramener ces nombres, qui semblent complexes et dénués de sens, au format de code source sur lequel les développeurs peuvent travailler. Cette opération est généralement utilisée lorsque le code source original est perdu ou pour comprendre le fonctionnement d'un programme.

## Comment ça marche
Il prend le fichier exécutable du programme et analyse les séquences d'instructions qu'il contient. Ensuite, il fait correspondre ces instructions à des structures de langage de programmation ayant une fonction similaire. Le texte résultant, bien qu'il ne soit pas identique au code original, offre un brouillon permettant d'en comprendre la logique.

## Où est-ce utilisé
Il est utilisé dans la recherche en sécurité logicielle, pour comprendre le fonctionnement d'une application ou pour mettre à jour d'anciens logiciels dont le code source a été perdu.

## Souvent confondu avec
Il est souvent confondu avec le compilateur ; le compilateur traduit le code pour la machine, tandis que le décompilateur traduit le code machine pour l'humain.

## Questions fréquentes
**Puis-je obtenir exactement le même code original avec un décompilateur ?**
Généralement non ; car lors de la compilation, certains noms de variables et commentaires sont supprimés, ce qui rend le résultat obtenu un peu plus complexe et anonyme.

**Tout programme peut-il être décompilé ?**
Techniquement, la plupart peuvent l'être, mais certains logiciels sont protégés par des méthodes d'« obfuscation » (brouillage de code) qui rendent cette opération difficile.
