# Qu'est-ce que OpenStreetMap ?

Il s'agit d'un projet de carte gratuit et open source auquel n'importe qui dans le monde peut contribuer.

## Définition
Contrairement aux cartes commerciales comme Google Maps, OpenStreetMap (OSM) est entièrement créée par des bénévoles. N'importe qui peut ajouter de nouvelles routes, bâtiments ou points de repère à la carte. Ces données sont accessibles au public.

## Comment ça marche
Vous pouvez télécharger des données cartographiques sur Internet et les utiliser gratuitement dans vos propres applications ou analyses.

## Où est-ce utilisé
Il est utilisé dans les applications logistiques, les outils de navigation et les projets d’urbanisme.

## Questions fréquentes
**Pourquoi devrais-je utiliser OSM ?**
Idéal lorsque vous souhaitez un contrôle total sur les données et que vous souhaitez éviter les frais des services de cartographie commerciaux.
