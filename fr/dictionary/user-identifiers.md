# Qu'est-ce que User Identifiers ?

Ce sont des marqueurs d’identité uniques utilisés pour distinguer chaque utilisateur dans les systèmes numériques.

## Définition
Il s'agit de codes spéciaux ou de noms d'utilisateur attribués au système pour vous reconnaître lorsque vous entrez dans une candidature. Grâce à ces identifiants, le système peut vous présenter spécifiquement vos transactions passées, vos paramètres et vos données sans les mélanger. Vous pouvez y penser comme à votre numéro de membre dans une bibliothèque.

## Comment ça marche
Lorsque vous vous inscrivez ou vous connectez au système, celui-ci est automatiquement créé en arrière-plan et mis en correspondance avec vous dans la base de données.

## Où est-ce utilisé
Il est utilisé pour le suivi des utilisateurs sur les sites Web, les applications mobiles et les logiciels d'entreprise.

## Souvent confondu avec
Il peut être confondu avec un nom d'utilisateur, mais il s'agit d'une structure plus technique et générale qui permet au système de vous reconnaître.

## Questions fréquentes
**Pourquoi est-ce que je reçois un identifiant différent pour chaque système ?**
Pour votre sécurité ; Ne pas utiliser votre identité dans un système dans un autre système garantit la sécurité de vos données.
