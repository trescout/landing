Qu'est-ce que API Gateway ?

Il s'agit d'un portail d'entrée central qui répond à toutes les demandes du monde extérieur, les oriente vers les bons endroits et effectue les contrôles de sécurité.

Définition

Les applications modernes se composent de nombreuses parties différentes. API Gateway est comme un agent de la circulation se tenant devant toutes ces pièces. Il reçoit la demande entrante, vérifie qui l'a envoyée et la transmet au service concerné.

Analogie : C'est comme l'accueil d'une grande entreprise ; Tous les visiteurs viennent ici en premier, leur inscription est effectuée et il est déterminé dans quel département ils se rendront.

Comment ça marche

Il surveille le trafic entrant, assure la sécurité, restreint les demandes si nécessaire et renvoie les résultats à l'utilisateur.

Où est-ce utilisé

Il est utilisé dans les grands systèmes logiciels dotés d’une architecture de microservices.

Souvent confondu avec

Ce n'est pas seulement un routeur ; Il assure également des tâches de sécurité et de gestion.

Questions fréquentes

Pourquoi est-ce nécessaire ?

Au lieu d’ouvrir chaque service individuellement au monde extérieur, sa gestion à partir d’un point unique assure sécurité et ordre.
