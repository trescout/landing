# Qu'est-ce que Edge Computing ?

*Glossaire · Dev · Dernière mise à jour : 23 juin 2026*

Il s'agit du traitement des données sur ou à proximité immédiate de l'appareil lui-même où les données sont produites, sans être envoyées à un serveur central.

## Définition

Dans les systèmes traditionnels, les données étaient envoyées vers un centre distant et y étaient traitées. L'Edge Computing déplace ce processus vers la « périphérie », c'est-à-dire vers l'appareil ou le réseau local de l'utilisateur. Cette approche réduit la latence et permet au système de fonctionner même si la connexion Internet est mauvaise.

***Analogie :** Lorsque vous posez une question, c'est comme demander la réponse à votre ami à côté de vous, au lieu d'appeler une autre ville pour obtenir la réponse ; C'est beaucoup plus rapide.*

## Comment ça marche

Des capacités de traitement locales sont ajoutées au-dessus de l'appareil. Au lieu d'être acheminé vers le centre, le flux de données est analysé instantanément par le propre processeur de l'appareil.

## Où est-ce utilisé

Il est utilisé dans les appareils domestiques intelligents, les véhicules autonomes et les capteurs industriels qui nécessitent une réponse instantanée.

## Souvent confondu avec

On le confond avec le cloud computing ; le cloud est central, la périphérie est locale.

## Questions fréquentes

**Pourquoi ne pas tout envoyer dans le cloud ?**

Car l’envoi des données au centre prend du temps et si internet est coupé, le système s’arrête.

**L’informatique de pointe est-elle sûre ?**

Il est généralement considéré comme plus sûr en termes de confidentialité car les données ne quittent pas l'appareil.
