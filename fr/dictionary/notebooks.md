# Qu'est-ce que Notebooks ?

*Glossaire · Dev · Dernière mise à jour : 20 juin 2026*

Ce sont des environnements de travail interactifs dans lesquels vous pouvez prendre des notes tout en écrivant du code et voir les résultats instantanément.

## Définition

Les notebooks sont des espaces de travail où le code et le texte sont entrelacés, utilisés notamment dans les processus de science des données et de développement de logiciels. Lorsque vous exécutez un bloc de code, vous voyez le résultat juste en dessous, vous pouvez donc suivre le processus étape par étape au fur et à mesure de vos expériences. Cette structure est également très utile pour expliquer des analyses complexes à d’autres.

***Analogie :** C'est comme le cahier de laboratoire qu'un scientifique utilise pour mener ses expériences ; Vous conservez à la fois l’action et le résultat de l’expérience sur la même page.*

## Comment ça marche

Dans cet environnement qui s'exécute sur le navigateur, vous écrivez votre code dans des zones divisées en cellules. Lorsque vous appuyez sur le bouton Exécuter, le code est traité et la sortie est affichée juste en dessous.

## Où est-ce utilisé

Il est utilisé dans l’analyse des données, la formation de modèles d’intelligence artificielle et les processus de prototypage rapide de code.

## Souvent confondu avec

Sa différence avec les éditeurs de code standards est qu'il permet d'exécuter le code morceau par morceau et de voir le résultat immédiatement.

## Questions fréquentes

**Les personnes qui ne savent pas coder peuvent-elles l’utiliser ?**

Il s'agit généralement d'un codage, mais des modèles prêts à l'emploi peuvent être utilisés pour une analyse simple.

**Quel est le plus populaire ?**

Les notebooks Jupyter sont les plus largement utilisés.
