# Qu'est-ce que RAG Chunks ?

Il s’agit d’une version de documents longs divisés en petits morceaux afin que l’intelligence artificielle puisse les comprendre plus facilement.

## Définition
La quantité d’informations que les modèles d’IA peuvent lire simultanément est limitée. RAG Chunks divise les documents volumineux en petits morceaux significatifs, permettant à l'intelligence artificielle de trouver exactement les informations dont elle a besoin. De cette façon, le modèle donne des réponses correctes en se concentrant uniquement sur la page pertinente au lieu de lire un énorme livre.

## Comment ça marche
Lorsque les documents sont téléchargés dans le système, ils sont automatiquement divisés en petits morceaux et chaque morceau est numéroté. Lorsque vous posez une question, le système trouve l’élément le plus pertinent et le présente à l’intelligence artificielle.

## Où est-ce utilisé
Il est utilisé dans la phase de préparation des données, qui constitue la base des systèmes RAG.

## Souvent confondu avec
Il est important non seulement de diviser les données, mais aussi de les diviser tout en préservant une intégrité significative.

## Questions fréquentes
**Que se passe-t-il si les morceaux sont trop petits ?**
L'IA peut perdre son contexte, la taille des fragments doit donc être équilibrée.

**Pourquoi ne donnons-nous pas le texte intégral ?**
Non seulement le coût augmente, mais le modèle risque de se perdre dans trop d’informations et de donner une mauvaise réponse.
