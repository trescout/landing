# Qu'est-ce que Runtime Environment ?

L'environnement de support de base dont un logiciel a besoin pour s'exécuter sur un ordinateur.

## Définition
Si vous considérez le code logiciel comme une recette, cet environnement est la cuisine où cette recette est préparée. Il fournit les bibliothèques et les ressources système nécessaires à l'exécution du code.

## Comment ça marche
Lorsque vous installez un programme, l'environnement nécessaire à ce programme est généralement installé en arrière-plan. Vous ne le voyez pas, mais le programme reçoit le support de cet environnement à chaque fois qu'il s'exécute.

## Où est-ce utilisé
On le trouve dans les navigateurs Web, les serveurs d'applications et tous les logiciels au niveau du système d'exploitation.

## Souvent confondu avec
À ne pas confondre avec le logiciel lui-même ; Cet environnement est la maison dans laquelle vit le logiciel.

## Questions fréquentes
**Pourquoi ça donne une erreur ?**
Cela donne généralement une erreur car les fichiers multimédias requis sont manquants ou sont de mauvaise version.
