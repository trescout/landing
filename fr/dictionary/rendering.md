# Qu'est-ce que Rendering ?

Le processus par lequel un ordinateur traite des données brutes et les transforme en un visuel ou un graphique que nous voyons à l'écran.

## Définition
Les ordinateurs conservent les données sous forme de chiffres. Le rendu calcule les propriétés de ces données numériques telles que la lumière, la couleur et la forme et les transforme en une image visible. Ce processus nécessite des calculs mathématiques complexes.

## Comment ça marche
Le processeur ou la carte vidéo reçoit les données, les traite selon des règles et colore les pixels de l'écran.

## Où est-ce utilisé
Il est utilisé dans les jeux, les programmes de montage vidéo et la visualisation de pages Web dans le navigateur.

## Questions fréquentes
**Pourquoi le rendu peut-il être lent ?**
Si la quantité de données à traiter est trop importante ou si le matériel informatique ne peut pas suivre ces calculs, le processus ralentit.
