# Qu'est-ce que Operating System for Robotics ?

> ROS

Il s'agit d'une infrastructure logicielle spéciale qui gère les mouvements, les capteurs et les pièces complexes des robots.

## Définition
Les robots ne sont pas seulement une question de matériel ; Ils ont besoin d'un cerveau qui les contrôle. Ce système d'exploitation coordonne tout, depuis le mouvement des bras du robot jusqu'à sa capacité à voir l'environnement avec son œil (caméra).

## Comment ça marche
Différents éléments matériels s’envoient des messages via ce système. Par exemple, la caméra envoie le message « il y a un obstacle devant moi » et le système donne l'ordre « stop » aux moteurs.

## Où est-ce utilisé
Il est utilisé dans les robots industriels, les véhicules autonomes et les projets robotiques des laboratoires de recherche.

## Souvent confondu avec
À ne pas confondre avec les systèmes d'exploitation classiques (Windows/macOS) ; Ces systèmes sont optimisés uniquement pour la gestion du matériel robotique.

## Questions fréquentes
**Faut-il être ingénieur pour utiliser ce système ?**
Il n'est pas nécessaire d'être ingénieur pour apprendre les concepts de base, mais il est recommandé de l'apprendre car c'est un langage standard dans le monde de la robotique.
