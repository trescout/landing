# Qu'est-ce que Foundation Model ?

*Glossaire · AI · Dernière mise à jour : 3 juin 2026*

Il s’agit de modèles d’IA grand public largement formés qui constituent la base de nombreuses applications différentes.

## Définition

Les modèles de base sont des modèles d'intelligence artificielle de base complets et polyvalents sur lesquels d'autres applications sont construites. Ces modèles sont formés une seule fois puis utilisés en les personnalisant en fonction des différents besoins.

***Analogie :** C'est comme poser les fondations d'une maison ; Vous pouvez construire une villa, un bureau ou un gratte-ciel sur ces fondations.*

## Comment ça marche

Ils suivent une formation générale sur d’énormes ensembles de données. Dans ce processus, ils apprennent les règles de base du langage, de la logique ou du visuel.

## Où est-ce utilisé

Un modèle de base sous-tend la plupart des applications modernes d’intelligence artificielle. Par exemple, des modèles comme la série GPT ou Llama sont des modèles de base.

## Souvent confondu avec

On les prend pour de simples chatbots ; Pourtant, ils sont à la base de beaucoup de choses, de l’écriture de code au traitement d’images.

## Questions fréquentes

**Le modèle Foundation à lui seul est-il suffisant ?**

C'est suffisant pour des travaux généraux, mais des améliorations supplémentaires sont souvent apportées pour des besoins professionnels.

**Tout le monde peut-il créer son propre modèle de fondation ?**

Il est généralement réalisé par de grandes entreprises technologiques car il nécessite une énorme quantité de puissance de calcul et de données.
