# Qu'est-ce que Extensibility ?

L'aptitude d'un système à être développé en ajoutant de nouvelles fonctionnalités sans perturber sa structure de base.

## Définition
L'extensibilité signifie qu'un logiciel est flexible. Vous pouvez ajouter de nouvelles fonctionnalités via des plug-ins ou des modules sans toucher au code principal du logiciel. Cela garantit la longévité du système.

## Comment ça marche
Le système est conçu avec une « interface » qui acceptera des modules externes.

## Où est-ce utilisé
Il est utilisé dans les modules complémentaires de navigateur, les systèmes de gestion de contenu (comme WordPress) et les logiciels des grandes entreprises.

## Questions fréquentes
**Tous les logiciels sont-ils extensibles ?**
Non, si le logiciel n’est pas conçu avec cette flexibilité dès le départ, son ajout ultérieur peut s’avérer très difficile.
