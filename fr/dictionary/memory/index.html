Qu'est-ce que Memory ?

C’est la capacité de l’intelligence artificielle à stocker les interactions passées et à personnaliser ses réponses futures en fonction de ces informations.

Définition

Les modèles d’intelligence artificielle sont en fait intrinsèquement oublieux ; Ils recommencent chaque nouvelle conversation à partir de zéro. La fonction Mémoire est comme le modèle qui enregistre vos préférences, les informations que vous avez fournies dans le passé ou un résumé des conversations précédentes dans un « bloc-notes ». De cette façon, vous n'êtes pas obligé de vous présenter à partir de zéro à chaque fois.

Analogie : C'est comme écrire le nom d'une personne que vous venez de rencontrer dans un cahier et l'appeler par son nom la prochaine fois que vous vous rencontrerez.

Comment ça marche

Le système enregistre les informations qu'il juge importantes au cours de la conversation dans une base de données et met à jour sa réponse en consultant cette base de données à chaque nouvelle question.

Où est-ce utilisé

Il est utilisé dans les assistants personnels, les outils de suivi des projets à long terme et les robots du service client.

Souvent confondu avec

Il ne faut pas les confondre avec les propres données d'entraînement du modèle ; Cette fonctionnalité couvre votre historique privé avec vous.

Questions fréquentes

Ces informations sont-elles partagées avec d’autres ?

Il est généralement associé uniquement à votre compte, mais il est important de vérifier vos paramètres de confidentialité.

Comment puis-je effacer la mémoire ?

Sur la plupart des systèmes, vous pouvez supprimer ces données avec la commande « effacer la mémoire » ou « oublier ».
