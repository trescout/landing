# Qu'est-ce que Executables ?

Programmes que l'ordinateur peut exécuter directement, généralement connus sous le nom de fichiers d'installation ou d'application.

## Définition
Les exécutables, c'est-à-dire les fichiers exécutables, contiennent des instructions traduites en langage machine que le processeur de l'ordinateur peut lire et exécuter directement. Sur les systèmes Windows, leur extension se termine généralement par .exe, tandis qu'ils peuvent avoir des extensions différentes sur d'autres systèmes d'exploitation. Ce sont les fichiers finaux qui lancent de grands processus en arrière-plan lorsque vous cliquez dessus.

## Comment ça marche
Les développeurs écrivent du code proche du langage humain, un compilateur traduit ce code en nombres binaires compréhensibles par l'ordinateur, et ces fichiers exécutables en résultent.

## Où est-ce utilisé
Lorsque vous installez un nouveau jeu sur votre ordinateur, ouvrez un navigateur ou lancez n'importe quelle application de bureau, ces fichiers sont toujours à l'œuvre.

## Souvent confondu avec
Il est confondu avec le code source ; le code source est un texte brut lisible, tandis que le fichier exécutable est le résultat directement exécuté par l'ordinateur.

## Questions fréquentes
**Tous les fichiers sont-ils exécutables ?**
Non, un fichier musical ou un document texte ne peut pas être exécuté de lui-même, mais il peut être ouvert via un programme.

**Est-ce risqué du point de vue de la sécurité ?**
Oui, les fichiers exécutables provenant de sources inconnues peuvent contenir des logiciels malveillants susceptibles d'endommager votre ordinateur.
