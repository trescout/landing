# Qu'est-ce que Syntax ?

Ce sont les règles d'écriture à respecter dans un langage de programmation pour que le code s'exécute sans erreur.

## Définition
C'est l'équivalent des règles de grammaire dans le monde du code. Contrairement aux humains, les ordinateurs ne sont pas flexibles ; c'est pourquoi un point-virgule manquant ou une parenthèse mal placée empêche le code de fonctionner. Cet ensemble de règles qui définit la structure du code est appelé syntaxe.

## Comment ça marche
Les éditeurs de code vous avertissent généralement lors de la saisie. Lorsque vous recevez une erreur, vous allez à la ligne indiquée par l'éditeur et vous effectuez une correction en vérifiant les parenthèses ou les commandes.

## Où est-ce utilisé
Utilisé dans tous les langages de programmation et les langages de script.

## Souvent confondu avec
Souvent confondu avec les erreurs logiques ; alors qu'une erreur de syntaxe empêche le code de s'exécuter, une erreur logique entraîne un résultat incorrect.

## Questions fréquentes
**Que dois-je faire si je reçois une erreur de syntaxe ?**
Vérifiez le numéro de ligne dans le message d'erreur et passez à nouveau en revue les règles d'écriture.
