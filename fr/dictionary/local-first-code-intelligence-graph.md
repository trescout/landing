# Qu'est-ce que Local-first Code Intelligence Graph ?

*Glossaire · Dev · Dernière mise à jour : 21 juillet 2026*

Il s'agit d'un système qui cartographie les relations entre les éléments de code dans les projets logiciels sur votre ordinateur local sans avoir besoin d'Internet.

## Définition

Ce système connecte tous les fichiers et fonctions de votre base de code comme un réseau. Vos données restent privées car elles s'exécutent directement sur votre appareil plutôt que de vous connecter à Internet. Il vous aide à comprendre la structure de votre code et à naviguer rapidement dans des projets complexes.

***Analogie :** C'est comme une carte magique qui montre comment tous les livres d'une immense bibliothèque se référencent les uns les autres, simplement posés sur votre bureau.*

## Comment ça marche

Il s'intègre à votre environnement de développement logiciel et crée un réseau de relations en scannant votre code. Lorsque vous modifiez une fonction, il vous montre instantanément quels fichiers cette modification affectera.

## Où est-ce utilisé

Il est utilisé dans des projets logiciels complexes, dans le développement de logiciels d'entreprise où la confidentialité est au premier plan et dans des situations nécessitant un travail hors ligne.

## Souvent confondu avec

Il peut être confondu avec des outils généraux d'analyse de code ou des services d'indexation de code sur Internet.

## Questions fréquentes

**Pourquoi parle-t-on de « local d’abord » ?**

Parce que l'ensemble du processus d'analyse se déroule directement sur votre propre ordinateur, et non sur des serveurs cloud.

**Est-ce que ça fonctionnera si je n'ai pas Internet ?**

Oui, le système n’a pas besoin d’une connexion Internet car il fonctionne entièrement en local.
