# Qu'est-ce que HLSL ?

> High-Level Shader Language

Il s'agit d'un langage de programmation utilisé pour calculer des effets visuels tels que l'éclairage et les ombres dans les jeux.

## Définition
C'est un langage contenant des commandes qui déterminent la couleur et la lumière de chaque pixel à l'écran. Il utilise particulièrement la puissance de la carte graphique pour calculer en temps réel les reflets, les ombres et les effets de texture dans l'univers du jeu.

## Comment ça marche
Les développeurs envoient le code écrit dans ce langage à la carte graphique ; la carte graphique utilise ensuite ces codes pour calculer les scènes des dizaines de fois par seconde et les afficher à l'écran.

## Où est-ce utilisé
Il est utilisé dans les moteurs de jeu (basés sur DirectX) et les applications graphiques.

## Souvent confondu avec
Il est confondu avec les langages de programmation à usage général ; HLSL est spécialisé uniquement pour les calculs graphiques (shaders).

## Questions fréquentes
**Est-il difficile d'apprendre le HLSL ?**
Si vous êtes familier avec les mathématiques graphiques et l'architecture des cartes graphiques, sa logique fondamentale est similaire aux langages de type C.
