# Qu'est-ce que Cross-platform ?

*Développement · Dernière mise à jour : 14 octobre 2026*

Type de logiciel capable de fonctionner de manière fluide sur différents systèmes d'exploitation ou appareils.

## Définition

Les développeurs de logiciels préfèrent parfois utiliser une base de code unique au lieu d'écrire du code séparé pour chaque appareil afin de créer des applications qui fonctionnent à la fois sur ordinateur et sur téléphone. Cette approche permet de gagner du temps et facilite la maintenance.

***Analogie :** C'est comme une valise intelligente qui peut voyager à vélo, en voiture et à pied.*

## Comment ça marche

Le code écrit sur une infrastructure commune est exécuté après avoir été traduit dans la langue de l'appareil cible.

## Où est-ce utilisé

Il est largement utilisé dans les projets de développement d'applications mobiles et de bureau.

## Souvent confondu avec

Il se distingue ainsi des applications natives enfermées sur un seul appareil.

## Questions et réponses

**Pourquoi est-il privilégié ?**

Il réduit les coûts et accélère le processus de développement.
