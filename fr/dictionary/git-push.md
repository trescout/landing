# Qu'est-ce que Git Push ?

Il s'agit du processus de téléchargement des modifications logicielles que vous apportez sur votre ordinateur local vers un serveur partagé sur Internet.

## Définition
Lorsque vous développez un logiciel, vous écrivez et modifiez vos codes sur votre propre ordinateur. La commande « push » est utilisée pour partager ces modifications avec le reste de l'équipe. De cette façon, toutes les mises à jour que vous effectuez sont envoyées vers un référentiel central.

## Comment ça marche
Cela se fait en tapant la commande 'git push' via un terminal ou un éditeur de code.

## Où est-ce utilisé
Il est utilisé dans les processus de développement de logiciels, notamment sur des plateformes telles que GitHub ou GitLab.

## Souvent confondu avec
Il est confondu avec git pull ; Pendant que pull récupère le code sur Internet, push l’envoie sur Internet.

## Questions fréquentes
**Que se passe-t-il si je ne pousse pas ?**
Les modifications que vous apportez restent uniquement sur votre ordinateur et votre équipe ne peut pas les voir.
