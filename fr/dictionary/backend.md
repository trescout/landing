# Qu'est-ce que Backend ?

*Glossaire · Dev · Dernière mise à jour : 19 septembre 2026*

Il s'agit de la partie d'une application qui n'est pas visible par l'utilisateur, où les données sont traitées et qui s'exécute sur le serveur.

## Définition

Lorsque vous visitez un site web, les boutons ou les menus que vous voyez constituent le front-end. En arrière-plan, la partie qui effectue tout le travail lourd, comme la vérification de vos mots de passe, l'extraction d'informations de la base de données ou le traitement des paiements, est le back-end. L'utilisateur ne voit que le résultat, tandis que le back-end est la cuisine qui prépare ce résultat.

***Analogie :** C'est comme la cuisine d'un restaurant ; vous mangez votre repas à table (front-end), mais la préparation du repas, le choix des ingrédients et la cuisson se déroulent entièrement en cuisine (back-end).*

## Comment ça marche

Les codes s'exécutant sur le serveur reçoivent les requêtes entrantes, communiquent avec la base de données et, après avoir effectué les opérations logiques nécessaires, renvoient le résultat à l'utilisateur.

## Où est-ce utilisé

Il est présent dans toutes les applications web modernes, en arrière-plan des applications mobiles et dans les systèmes d'API.

## Souvent confondu avec

Il peut être confondu avec le front-end ; le front-end interagit avec vous, tandis que le back-end effectue le travail.

## Questions fréquentes

**Pourquoi exécutons-nous du code sur le back-end ?**

Parce qu'il est nécessaire d'assurer la sécurité des données et d'effectuer des calculs complexes sans surcharger l'appareil de l'utilisateur.
