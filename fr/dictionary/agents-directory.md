# Qu'est-ce que Agents Directory ?

*Intelligence artificielle · Dernière mise à jour : 11 octobre 2026*

Il s'agit d'une structure de dossier spéciale qui regroupe les comportements, les outils et les règles des agents d'intelligence artificielle dans les projets logiciels.

## Définition

L'agents directory est un répertoire d'une base de code qui héberge les instructions et les connexions d'outils des agents d'intelligence artificielle conçus pour différentes tâches. Il vous permet d'organiser les limites des tâches et les modèles de comportement de plusieurs assistants autonomes travaillant sur votre projet en un seul endroit standard. Les outils de développement et les moteurs d'orchestration analysent ce répertoire pour reconnaître automatiquement les agents spécifiques à votre projet.

***Analogie :** C'est comparable au dossier des ressources humaines d'une entreprise où la description de poste, les autorisations et les manuels de référence de chaque employé spécialisé sont tenus à jour.*

## Comment ça marche

Les développeurs créent généralement un dossier nommé .agents ou agents dans le répertoire racine du projet. Des fichiers de configuration pour chaque agent qui écrit des tests, examine du code ou prépare de la documentation sont ajoutés à ce dossier. Les outils de développement assistés par agent lisent ces fichiers pour déterminer les rôles que l'agent assumera et les fonctions qu'il pourra appeler.

## Où est-ce utilisé

Il est fréquemment utilisé dans les environnements de développement logiciel basés sur des agents, les plates-formes d'orchestration d'intelligence artificielle et les éditeurs de code modernes.

## Souvent confondu avec

Il peut être confondu avec le concept général d'« espace de travail d'agent » (agent workspace) : alors que l'espace de travail fait référence à la mémoire temporaire et aux fichiers temporaires utilisés par l'agent lors de son travail, l'agents directory est le répertoire de fichiers permanent où sont stockés le code source et les définitions de règles des agents.

## Questions fréquentes

**Les agents d'intelligence artificielle ne peuvent-ils pas fonctionner sans ce dossier ?**

Ils le peuvent, mais vous devez spécifier manuellement les instructions système et les outils utilisables pour chaque agent un par un ; la structure du répertoire automatise et standardise ce processus.

**Les agents du dossier peuvent-ils communiquer automatiquement entre eux ?**

Ils le peuvent : les systèmes dotés d'une architecture multi-agents répertorient les agents de ce répertoire et les utilisent comme guide pour déléguer une tâche à un autre agent.
