# Qu'est-ce que LLM API ?

> Large Language Model Application Programming Interface

C'est un pont qui permet aux développeurs d'intégrer les capacités des modèles d'intelligence artificielle dans leurs propres applications.

## Définition
Au lieu d'exécuter un modèle d'intelligence artificielle directement sur votre propre ordinateur, il s'agit d'un point de connexion qui vous permet de poser des questions au modèle via Internet et d'obtenir des réponses. Les développeurs peuvent utiliser cette interface pour faire communiquer leurs programmes avec l'intelligence artificielle. En d'autres termes, lorsque vous développez une application, vous n'avez pas besoin d'effectuer les calculs complexes du modèle sur votre propre serveur, vous utilisez un service prêt à l'emploi.

## Comment ça marche
Le développeur envoie une « requête » (request) au modèle. Le modèle traite cette requête et renvoie le résultat sous forme de « réponse » (response). Ce processus se déroule via un protocole Internet standard.

## Où est-ce utilisé
Il est utilisé dans les chatbots, les générateurs de contenu automatisés et toutes les applications Web assistées par l'intelligence artificielle.

## Souvent confondu avec
Ce n'est pas le LLM lui-même, mais la porte qui permet d'y accéder.

## Questions fréquentes
**Tout le monde peut-il utiliser une API LLM ?**
Oui, mais vous devez généralement payer des frais ou obtenir une clé (API key).

**Quelle est la différence avec un modèle fonctionnant sur mon propre ordinateur ?**
Vous avez besoin de puissance matérielle sur votre propre ordinateur, tandis qu'avec l'utilisation de l'API, toute la charge repose sur le serveur distant.
