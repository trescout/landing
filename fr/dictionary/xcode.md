# Qu'est-ce que Xcode ?

Il s'agit de l'environnement de développement logiciel officiel utilisé pour développer des applications pour les appareils Apple (iPhone, Mac, iPad).

## Définition
Xcode est un ensemble d'outils complet qu'Apple propose aux développeurs. Il comprend un éditeur pour écrire du code, des outils visuels pour concevoir à quoi ressemblera l'application et des mécanismes de test pour trouver des bogues. C'est le seul moyen officiel de développer des applications dans le monde Apple.

## Comment ça marche
Il est installé sur votre ordinateur Mac. Vous écrivez ici vos codes d'application en utilisant les langages Swift ou Objective-C, testez votre application et la téléchargez sur le magasin.

## Où est-ce utilisé
Cela ne fonctionne que sur le système d'exploitation macOS.

## Souvent confondu avec
Il se distingue des autres éditeurs de code généralistes en étant spécifique à l'écosystème Apple.

## Questions fréquentes
**Puis-je utiliser Xcode sur un ordinateur Windows ?**
Non, Xcode ne fonctionne que sur le système d'exploitation macOS d'Apple.
