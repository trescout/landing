# Qu'est-ce que Unit Testing ?

Il s'agit d'une méthode de test qui vérifie si les plus petites parties du logiciel fonctionnent correctement d'elles-mêmes.

## Définition
Il s'agit des tests de base effectués pour garantir que chaque fonction ou méthode fonctionne sans erreur lors du développement de logiciels. Vous pouvez imaginer cela comme vérifier les pièces d’un grand puzzle une par une. Si les petites pièces sont intactes, la fiabilité de l'ensemble du système augmente.

## Comment ça marche
Les développeurs écrivent des scénarios de test spécifiques pour chaque morceau de code. Ces scénarios vérifient automatiquement si le code donne le résultat attendu à l'entrée attendue. Si le test échoue, il est immédiatement clair quelle petite pièce est en cause.

## Où est-ce utilisé
Il est utilisé au tout début du processus de développement logiciel, lors de l’écriture du code ou immédiatement après son écriture.

## Souvent confondu avec
Cela peut être confondu avec les tests de bout en bout ; Alors qu’ils testent l’ensemble du système, les tests unitaires se concentrent sur une seule partie.

## Questions fréquentes
**Pourquoi devrais-je tester chaque pièce ?**
Pour détecter les erreurs très tôt et éviter les problèmes majeurs qui surviendront ultérieurement dans tout le système.

**Est-ce que cela se fait automatiquement ?**
Oui, il est généralement automatisé par le développeur à l'aide d'outils de test.
