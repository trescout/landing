# Qu'est-ce que Inference Server ?

Il s'agit d'un système de serveur spécialisé où les modèles d'intelligence artificielle sont exécutés pour générer des réponses aux questions reçues.

## Définition
Une fois qu'un modèle d'intelligence artificielle est entraîné, il doit rester opérationnel en permanence pour que les utilisateurs puissent lui poser des questions et obtenir des réponses. Le serveur d'inférence est un centre informatique puissant qui héberge ce modèle, traite rapidement les données entrantes et renvoie des résultats. Ces systèmes optimisent les performances du modèle et peuvent servir de nombreuses personnes simultanément.

## Comment ça marche
Le modèle requis est chargé sur ce serveur et configuré pour répondre aux questions arrivant via une porte d'entrée (API). Le serveur traduit la question reçue dans le langage compris par le modèle, exécute le modèle et renvoie la réponse générée à l'utilisateur.

## Où est-ce utilisé
Il est utilisé en arrière-plan des applications basées sur l'intelligence artificielle, sur les plateformes de cloud computing ou dans les centres de données des grandes entreprises.

## Souvent confondu avec
Ce n'est pas seulement un ordinateur, mais une infrastructure spécialisée optimisée pour le fonctionnement du modèle.

## Questions fréquentes
**Pourquoi un ordinateur normal ne suffit-il pas ?**
Les modèles d'intelligence artificielle nécessitent énormément de puissance de calcul et de mémoire, c'est pourquoi des serveurs équipés de matériel spécialisé sont nécessaires.

**Est-ce la même chose que l'entraînement du modèle ?**
Non, l'entraînement est le processus d'apprentissage du modèle, tandis que l'inférence est le processus d'utilisation de ce qui a été appris.
