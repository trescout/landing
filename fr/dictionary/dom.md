# Qu'est-ce que DOM ?

*Développement · Dernière mise à jour : 19 novembre 2026*

> Document Object Model

Structure hiérarchique permettant au navigateur de traiter et de gérer le contenu des pages Web.

## Définition

Le DOM est le système qui permet de mémoriser les sites Web en arrière-plan sous forme de structure arborescente. Il convertit les balises HTML en objets que des langages tels que JavaScript peuvent facilement modifier. Ainsi, des événements dynamiques peuvent se produire, comme le changement de la page sans rechargement lorsque vous appuyez sur un bouton.

***Analogie :** C'est comme le plan architectural d'un bâtiment. Si vous souhaitez modifier l'installation électrique ou plomberie, au lieu de casser les murs porteurs, vous regardez le plan pour trouver la vanne ou le câble concerné et intervenir.*

## Comment ça marche

Dès que le navigateur télécharge et lit le code du site Web, il crée cette structure hiérarchique en mémoire. Lors de l'écriture du code, les développeurs peuvent cibler cette structure pour mettre à jour instantanément le texte ou les images de la page. Chaque balise HTML est positionnée comme une branche ou une feuille de cet arbre.

## Où est-ce utilisé

Il fonctionne en permanence en arrière-plan sur tous les sites Web et applications Web modernes exécutés dans les navigateurs.

## Souvent confondu avec

Il peut être confondu avec le code HTML brut provenant du serveur. Alors que le HTML n'est qu'un document texte, le DOM est la version où le navigateur a transformé ce document en un objet vivant.

## Questions et réponses

**Le DOM existe-t-il sur tous les sites Web ?**

Oui, cette structure fonctionne obligatoirement derrière chaque page visuelle ouverte dans le navigateur.

**Le DOM peut-il être modifié directement ?**

Il est possible de modifier cette structure en temps réel à l'aide de JavaScript et d'animer la page.
