# Qu'est-ce que Multi-agent ?

Il s'agit de la collaboration de plusieurs logiciels d'intelligence artificielle pour un objectif commun en divisant une tâche complexe.

## Définition
Dans les systèmes multi-agents, chaque agent d’intelligence artificielle agit comme un employé avec son propre domaine d’expertise. Pendant qu'un agent planifie, un autre écrit du code et un autre vérifie les résultats. De cette manière, les tâches qu’un modèle unique aurait du mal à réaliser seul sont réalisées beaucoup plus rapidement et sans erreurs de coopération.

## Comment ça marche
Définissez une tâche principale et divisez-la en sous-parties. Attribuez un agent doté de capacités spéciales à chaque pièce. Gérez le processus en vous assurant que ces agents communiquent entre eux.

## Où est-ce utilisé
Il est fréquemment utilisé dans le développement de logiciels, l’analyse de données complexes et les flux de travail automatisés.

## Souvent confondu avec
C’est différent d’un modèle d’IA unique ; Ce qui est important ici, c'est l'interaction des agents entre eux.

## Questions fréquentes
**Comment les agents s’entendent-ils ?**
Ils envoient généralement des messages via un agent « conducteur » ou un protocole de communication prédéterminé.

**Pourquoi n'utilisons-nous pas un seul modèle puissant ?**
Lorsque les tâches deviennent très complexes, des modèles spécialisés plus petits se combinent pour commettre moins d’erreurs et produire de meilleurs résultats.
