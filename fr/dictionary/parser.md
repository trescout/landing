# Qu'est-ce que Parser ?

Il s'agit d'un analyseur qui décompose des données ou du code complexes en éléments significatifs que l'ordinateur peut traiter étape par étape.

## Définition
Un analyseur prend un morceau de texte ou de données et le transforme en une structure que le programme peut logiquement comprendre. Par exemple, il fonctionne comme un interpréteur qui permet à l'ordinateur de comprendre une simple ligne de code que vous écrivez comme « il y a une variable ici, une opération est en cours d'exécution ici ». Il crée une structure arborescente en divisant les données en morceaux.

## Comment ça marche
Il prend des données brutes en entrée, analyse ces données selon les règles du langage ou du format et produit finalement un modèle de données ou une arborescence. S'il y a une faute de frappe dans les données, l'analyseur le remarquera immédiatement.

## Où est-ce utilisé
Il est utilisé dans les compilateurs pour lire le HTML dans les navigateurs Web et dans tout logiciel traitant des formats de données (JSON, XML).

## Souvent confondu avec
Il peut être confondu avec l'analyse de documents ; Cependant, l’analyseur est un concept plus général et est utilisé pour toutes sortes de structures de données.

## Questions fréquentes
**Que se passe-t-il si l'analyseur donne une erreur ?**
Si l'analyseur trouve les données dans un format qu'il ne peut pas comprendre, il génère une « erreur de syntaxe » et empêche la poursuite du processus.
