# Qu'est-ce que Agent-native Applications ?

Il s'agit d'applications spécialement conçues pour permettre aux agents d'intelligence artificielle de prendre des décisions et d'effectuer des transactions.

## Définition
Contrairement aux applications traditionnelles, les applications natives d'agent attendent les commandes d'un agent d'intelligence artificielle plutôt que l'interaction humaine. Ces applications sont structurées de manière à ce que les agents puissent facilement utiliser les outils. Cela signifie que l'application contient toutes les fonctionnalités dont un agent a besoin pour accomplir une tâche par lui-même.

## Comment ça marche
Ces applications disposent de ports spéciaux qui permettent à un agent de communiquer avec le système plutôt qu'une interface standard. L'agent accède aux données et effectue des opérations à l'aide de ces ports.

## Où est-ce utilisé
Il est utilisé dans les plateformes d'automatisation, les flux de travail intelligents et les écosystèmes logiciels autonomes.

## Souvent confondu avec
Il ne faut pas la confondre avec les fonctionnalités d’intelligence artificielle ajoutées ultérieurement à une application ordinaire ; ceux-ci sont construits à partir de zéro pour les agents.

## Questions fréquentes
**Pourquoi doivent-ils être spécialement conçus ?**
Parce que les agents préfèrent les structures dans lesquelles ils peuvent traiter des commandes directes plutôt que les menus complexes que les gens utilisent.

**Les gens peuvent-ils utiliser ces applications ?**
Oui, mais la conception met l’accent sur l’efficacité des agents.
