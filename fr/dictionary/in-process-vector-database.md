# Qu'est-ce que In-process Vector Database ?

*Glossaire · Data · Dernière mise à jour : 17 juin 2026*

Il s'agit d'un système de stockage de données rapide qui conserve les données de l'intelligence artificielle directement dans la mémoire de l'application sans passer par un serveur séparé.

## Définition

Les modèles d’IA ont besoin de beaucoup de données. Extraire ces données d’une base de données externe prend du temps. Une base de données en cours de processus intègre les données dans l'application, augmentant ainsi considérablement la vitesse.

***Analogie :** C'est comme conserver l'information que vous recherchez dans une bibliothèque dans un cahier de poche, au lieu de la récupérer dans les archives d'un autre bâtiment.*

## Comment ça marche

Lorsque l'application démarre, la base de données s'exécute avec elle. Lorsque l'application se ferme, les données sont généralement supprimées de la mémoire ou enregistrées dans un fichier local.

## Où est-ce utilisé

Il est utilisé dans les applications mobiles ou les assistants personnels d’intelligence artificielle qui doivent réagir rapidement.

## Souvent confondu avec

Mélangé avec des bases de données externes ; les externes sont destinés aux données volumineuses, celui-ci est axé sur la vitesse.

## Questions fréquentes

**Est-il adapté au Big Data ?**

Non, il est généralement conçu pour les données de petite et moyenne taille nécessitant un accès rapide.
