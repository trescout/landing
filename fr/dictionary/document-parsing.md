# Qu'est-ce que Document Parsing ?

Il s'agit de la conversion de données contenues dans des documents complexes dans un format compréhensible par l'ordinateur.

## Définition
L'analyse de documents est le processus de conversion des informations contenues dans des documents complexes (PDF, tableau, image) dans un format structuré que l'ordinateur peut comprendre. Il lit l'ordre dans les informations.

## Comment ça marche
Le logiciel numérise le document et sépare les titres, les paragraphes et les tableaux. Ces données sont ensuite converties au format texte ou code et enregistrées.

## Où est-ce utilisé
Il est utilisé dans le traitement automatique des factures, l’analyse des contrats ou la synthèse de longs rapports à l’intelligence artificielle.

## Souvent confondu avec
On le confond avec la simple copie de texte, mais l'analyse transfère les données tout en préservant leur structure (tableau ou en-tête).

## Questions fréquentes
**Peut-il lire tous les documents ?**
Le taux de réussite est très élevé avec les documents numériques, mais l'écriture manuscrite ou les images très déformées peuvent s'avérer difficiles.

**Pourquoi est-ce important ?**
Les ordinateurs ne comprennent pas les fichiers PDF bruts, les convertir en données significatives permet au système d'agir intelligemment.
