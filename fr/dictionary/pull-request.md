# Qu'est-ce que Pull Request ?

*Développement · Dernière mise à jour : 5 novembre 2026*

> PR

Une demande par laquelle un développeur soumet les modifications qu'il souhaite ajouter à un dépôt de code pour examen et approbation.

## Définition

Une Pull Request permet aux autres membres de l'équipe de passer en revue les modifications apportées au code avant qu'elles ne soient intégrées au projet principal. Grâce à ce processus, les erreurs sont détectées précocement et la qualité du code est préservée. C'est l'un des piliers des processus de développement logiciel collaboratif.

***Analogie :** C'est comme si un auteur soumettait un nouveau chapitre qu'il souhaite ajouter à un livre à son éditeur ou à son rédacteur en chef pour approbation.*

## Comment ça marche

Le développeur termine son développement sur sa propre branche de travail et l'envoie vers le dépôt. Ensuite, il ouvre une Pull Request pour inviter ses collègues à examiner le code. Après l'examen, les retours sont pris en compte et, une fois l'approbation obtenue, le code est fusionné dans la branche principale.

## Où est-ce utilisé

Il est utilisé dans la gestion de projets logiciels sur des plateformes de contrôle de version telles que GitHub, GitLab et Bitbucket.

## Souvent confondu avec

Il peut être confondu avec le concept de Git Push. Alors que Git Push téléverse les modifications de code sur le serveur, une Pull Request initie un processus d'examen et de discussion pour que ces modifications soient fusionnées dans le code principal.

## Questions et réponses

**Pourquoi une Pull Request est-elle importante ?**

Elle améliore la qualité du code, favorise le partage des connaissances au sein de l'équipe et empêche le code défectueux d'être déployé en production.

**Une Pull Request peut-elle être rejetée ?**

Oui, si le code ne respecte pas les normes ou s'il présente des lacunes, elle peut être rejetée ou des révisions peuvent être demandées pour correction.
