# Qu'est-ce que Bundler ?

Il s'agit d'un outil qui combine et optimise plusieurs fichiers dans un projet logiciel et les transforme en une structure unique que les navigateurs peuvent exécuter.

## Définition
Les projets Web modernes sont constitués de centaines de petits fichiers. Les navigateurs ont du mal à télécharger autant de fichiers un par un. Bundler prend ces fichiers, les relie entre eux et améliore les performances en nettoyant les parties inutiles.

## Comment ça marche
Pendant la phase de développement, vous travaillez avec des fichiers individuellement. Lorsque vous publiez le projet, le bundler entre en jeu et regroupe tous les fichiers d'une manière que le navigateur peut comprendre.

## Où est-ce utilisé
Il est indispensable dans les projets de développement Web basés sur JavaScript.

## Souvent confondu avec
Peut être mélangé avec le compilateur ; Le compilateur traduit le code dans une autre langue, le bundler rassemble les fichiers.

## Questions fréquentes
**Pourquoi ne pas tout mettre dans un seul fichier ?**
Les fichiers très volumineux peuvent ralentir le navigateur ; donc le bundler divise parfois les fichiers en parties intelligentes.
