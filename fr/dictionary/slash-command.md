# Qu'est-ce que Slash Command ?

*Développement · Dernière mise à jour : 17 novembre 2026*

Ce sont des commandes courtes que les utilisateurs initient avec une barre oblique dans une interface de chat ou de ligne de commande.

## Définition

Ce sont des raccourcis commençant par une barre oblique, utilisés pour effectuer des actions rapides dans le monde logiciel. Par exemple, au lieu de taper aide ou paramètres dans une fenêtre de chat, ils vous permettent d'exécuter ces commandes en un seul geste. Ils vous permettent de déclencher rapidement les fonctionnalités prêtes à l'emploi proposées par l'interface sans avoir à vous en souvenir.

***Analogie :** C'est comme commander directement auprès du serveur en utilisant un nom de code au lieu de lire tout le menu dans un restaurant.*

## Comment ça marche

Lorsque vous tapez le caractère de la barre oblique dans l'interface, le système affiche automatiquement la liste des commandes disponibles. Lorsque vous tapez la suite et appuyez sur la touche Entrée, le programme en arrière-plan exécute un long processus en un seul geste. On les rencontre souvent dans les fenêtres de chat et les outils de développement.

## Où est-ce utilisé

Ils sont fréquemment utilisés dans les robots de chat, les fenêtres de terminal et les éditeurs de code alimentés par l'intelligence artificielle.

## Souvent confondu avec

Ils sont souvent confondus avec les messages de chat normaux, mais grâce au caractère spécial au début, ils sont perçus non pas comme du texte ordinaire, mais comme une commande directe.

## Questions et réponses

**Pourquoi utilise-t-on une barre oblique ?**

Ce caractère a été choisi comme norme afin que le système puisse facilement distinguer le texte normal des commandes.

**Pouvons-nous écrire notre propre commande ?**

Oui, de nombreuses plateformes logicielles vous permettent de définir vos propres commandes de raccourci personnalisées.
