# Qu'est-ce que Continuous Integration ?

> CI

C'est le processus qui garantit que les erreurs sont détectées rapidement en combinant et en testant automatiquement les codes écrits par les développeurs de logiciels.

## Définition
L'intégration continue (CI) garantit que les codes sont fréquemment envoyés à un système central pendant le processus de développement logiciel et y sont soumis à des tests automatiques. De cette façon, si le code écrit par un développeur de logiciels entre en conflit avec le code d’autres personnes, cela est immédiatement remarqué. Les bugs sont résolus avant qu’ils ne deviennent plus gros, alors qu’ils sont encore en développement.

## Comment ça marche
Dès que le développeur télécharge son code sur le système, les robots exécutés en arrière-plan compilent automatiquement le code et exécutent des tests prédéterminés.

## Où est-ce utilisé
Il s'agit d'une pratique courante dans les grandes équipes logicielles et les cycles de développement logiciel modernes (DevOps).

## Questions fréquentes
**Pourquoi ne faisons-nous pas de tests manuels ?**
Les tests manuels sont lents et sujets aux erreurs humaines ; CI, quant à lui, travaille avec la même minutie à chaque changement.
