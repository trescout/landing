# Qu'est-ce que Vector Index ?

*Glossaire · Data · Dernière mise à jour : 8 juin 2026*

Il s'agit d'une méthode de cartographie utilisée pour rechercher et trouver rapidement les équivalents numériques (vecteurs) des données.

## Définition

Les modèles d'intelligence artificielle traduisent des mots ou des images en chiffres. Au lieu d'examiner des millions de données une par une tout en recherchant quelque chose, nous organisons ces données dans une carte spéciale appelée « index vectoriel ». Cela revient à classer les livres de la bibliothèque par ordre alphabétique et catégorique par sujet, plutôt que par piles aléatoires.

***Analogie :** Bien qu'il y ait des milliers de livres dans une bibliothèque, celle-ci s'apparente à un système de catalogue spécial qui vous permet de trouver uniquement ceux avec « des couvertures rouges et un genre d'aventure » en quelques secondes.*

## Comment ça marche

Les vecteurs proches les uns des autres (de signification similaire) dans un espace multidimensionnel sont placés dans la même région. Lorsqu'une recherche est effectuée, le système renvoie le résultat en regardant uniquement cette région.

## Où est-ce utilisé

Il est utilisé dans les systèmes RAG, les moteurs de recommandation et les grandes bases de données.

## Souvent confondu avec

Peut être confondu avec la base de données vectorielles ; Vector Database est un référentiel et Vector Index est le système de recherche au sein de ce référentiel.

## Questions fréquentes

**Pourquoi l'index est-il important ?**

Sans index, vous devez parcourir toutes les données à chaque recherche, ce qui est très lent.

**Quelle est la signification des vecteurs ?**

Les vecteurs sont des coordonnées mathématiques de données comprises par l'ordinateur.
