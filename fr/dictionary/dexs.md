# Qu'est-ce que DEXs ?

*Glossaire · Data · Dernière mise à jour : 12 septembre 2026*

> Decentralized Exchanges

Ce sont des plateformes décentralisées où les utilisateurs échangent leurs actifs numériques directement entre eux, sans intermédiaire ni banque.

## Définition

Sur les bourses traditionnelles, vous effectuez vos transactions via les serveurs d'une entreprise. Les DEX suppriment cet intermédiaire et effectuent les transactions directement via des contrats intelligents sur la blockchain. Ainsi, vous gardez toujours le contrôle de vos actifs.

***Analogie :** Alors qu'une bourse traditionnelle ressemble à un échange de devises en faisant la queue dans une agence bancaire, les DEX ressemblent à deux personnes qui se serrent la main dans la rue pour effectuer un échange direct.*

## Comment ça marche

Vous connectez votre portefeuille numérique à la plateforme, sélectionnez l'actif que vous souhaitez échanger, et une fois la transaction confirmée, l'échange s'effectue automatiquement.

## Où est-ce utilisé

Ils sont utilisés sur les marchés des cryptomonnaies, dans les projets de finance décentralisée (DeFi) et pour les transactions où les utilisateurs accordent de l'importance à la confidentialité.

## Souvent confondu avec

Ils peuvent être confondus avec les bourses centralisées (CEX).

## Questions fréquentes

**Dois-je faire confiance à quelqu'un lorsque j'utilise des DEX ?**

Non, ce n'est pas une personne à qui vous devez faire confiance, mais le code lui-même (les contrats intelligents).

**Dois-je payer des frais de transaction ?**

Oui, il existe des frais de transaction (frais de gaz) payés aux mineurs ou aux validateurs du réseau.
