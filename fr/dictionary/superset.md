# Qu'est-ce que Superset ?

Il s'agit d'une structure plus complète qui inclut toutes les fonctionnalités d'un système existant et ajoute de nouvelles fonctionnalités.

## Définition
Quand quelque chose est un sur-ensemble, cela signifie qu’il inclut tout ce qui le sous-tend. Par exemple, un autre langage, qui est un surensemble d’un langage de programmation, peut exécuter tout le code du premier langage mais offre de nouvelles fonctionnalités supplémentaires. Ceci est utilisé pour améliorer le système tout en maintenant la compatibilité ascendante.

## Comment ça marche
Lors de la conception d'un nouveau langage ou d'un nouveau outil, les règles existantes sont préservées et de nouvelles couches sont construites par-dessus afin de ne pas perturber les habitudes des anciens utilisateurs.

## Où est-ce utilisé
Il est fréquemment utilisé dans les langages de programmation (par exemple TypeScript est un surensemble de JavaScript) et les architectures logicielles.

## Questions fréquentes
**Est-il avantageux d’utiliser un superset ?**
Oui, car cela permet de passer aux nouvelles technologies sans jeter les codes écrits avec l’ancien système.
