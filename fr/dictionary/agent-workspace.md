# Qu'est-ce que Agent Workspace ?

Il s'agit d'un espace de travail numérique sécurisé où les agents d'intelligence artificielle peuvent créer et modifier des fichiers et exécuter des outils afin d'accomplir les tâches qui leur sont confiées.

## Définition
Un espace de travail pour agent (agent workspace) est un environnement isolé conçu pour permettre aux assistants IA autonomes d'agir librement sans intervention humaine. Dans cet espace, l'agent IA peut écrire du code, lire et mettre à jour des fichiers, et récupérer des données sur Internet. Pour des raisons de sécurité, cet espace est généralement complètement isolé du système informatique hôte.

## Comment ça marche
Lorsqu'un agent IA commence une tâche, le système crée pour lui un dossier et un espace de traitement temporaires ou permanents. L'agent accomplit ses tâches en utilisant la boîte à outils de cet espace (API, navigateurs, compilateurs de code). Une fois la tâche terminée, les résultats obtenus sont présentés à l'utilisateur et l'espace de travail est nettoyé.

## Où est-ce utilisé
Il est utilisé dans les outils de rédaction de code assistés par IA, les systèmes d'analyse de données automatisés et les tâches complexes d'édition de fichiers. Ces espaces sont indispensables, notamment pour empêcher les agents de test de logiciels autonomes d'endommager le système principal.

## Souvent confondu avec
À ne pas confondre avec un environnement de développement (development environment) : alors que l'environnement de développement est conçu pour que les humains écrivent du code, l'espace de travail pour agent est entièrement optimisé pour que les logiciels d'IA effectuent des opérations de manière autonome.

## Questions fréquentes
**L'agent IA peut-il sortir de cet espace de travail et endommager mon ordinateur ?**
Non, les espaces de travail pour agents sont généralement configurés dans des bacs à sable (sandboxes) protégés et leur connexion avec le monde extérieur est limitée.

**Puis-je voir moi-même les fichiers se trouvant dans l'espace de travail ?**
Oui, grâce aux intégrations de TreScout, vous pouvez suivre en temps réel tous les mouvements de fichiers et les modifications dans l'espace de travail de l'agent.
