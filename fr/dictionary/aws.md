# Qu'est-ce que Amazon Web Services ?

> Amazon Web Services

Une immense plateforme cloud où vous pouvez louer des services informatiques tels que des serveurs, du stockage et des bases de données sur Internet.

## Définition
Au lieu d'installer vos propres serveurs physiques, il vous permet d'utiliser les énormes centres de données d'Amazon dans le monde entier en les louant sur Internet. Vous pouvez augmenter la capacité lorsque vous en avez besoin et la réduire lorsque vous avez terminé.

## Comment ça marche
Vous l'utilisez en créant des machines virtuelles et des bases de données via l'interface web ou des outils logiciels.

## Où est-ce utilisé
Il est utilisé en arrière-plan de presque tous les sites Web et applications modernes.

## Souvent confondu avec
Il ne s'agit pas simplement d'un service d'hébergement de sites Web ; Il s'agit d'un service d'infrastructure beaucoup plus complet.

## Questions fréquentes
**Pourquoi devrais-je utiliser AWS ?**
Pour disposer instantanément d’une infrastructure de niveau professionnel sans avoir à gérer les coûts matériels.
