# Qu'est-ce que Type Safety ?

Il s'agit d'une règle de sécurité qui empêche l'utilisation d'un mauvais type de données dans le logiciel et détecte les erreurs lors de l'écriture du code.

## Définition
Dans les langages de programmation, les données ont un « type » ; Par exemple, vous ne pouvez pas ajouter un numéro et un texte. La sécurité des types applique de telles règles de type. Si vous faites une erreur, l'ordinateur vous prévient avant d'exécuter le code. Il s’agit de l’une des plus grandes protections qui empêchent les logiciels de planter.

## Comment ça marche
Le système vérifie constamment votre code au fur et à mesure que vous l'écrivez. Si vous entrez accidentellement un nombre dans une zone de texte, le programme le remarquera immédiatement et vous donnera une erreur indiquant « vous ne pouvez écrire que du texte ici ».

## Où est-ce utilisé
Il est utilisé dans des langages tels que Rust, TypeScript, Java et dans des projets logiciels à grande échelle.

## Souvent confondu avec
Il ne s'agit pas simplement d'un « message d'erreur » ; C'est le principe de fonctionnement de base du langage de programmation lui-même.

## Questions fréquentes
**Pourquoi tout le monde ne l'utilise-t-il pas ?**
Certains langages ne l'exigent pas pour des raisons de flexibilité, mais il est définitivement préférable d'éviter de commettre des erreurs dans les grands projets.
