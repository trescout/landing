# Qu'est-ce que Headless Browser ?

Un navigateur sans tête (headless browser en anglais) est un navigateur complet qui fonctionne sans interface graphique.

## Définition et origine du mot
"Headless" signifie sans tête : aucune fenêtre n'est tracée, le code s'exécute. Lorsque la charge visuelle est supprimée, la vitesse augmente et les ressources diminuent. C'est le travailleur silencieux des tests et du traitement des données.

## Comment connaître et utiliser dans la vie quotidienne ?
Test : Contrôle de régression de page.Données : Exploration de sites.Rapport : Génération de captures d'écran.

## Choses fréquemment mélangées
Considéré comme furtif. Stealth est le mode du mode sans tête qui échappe à la protection anti-bot. L'un est le moteur, l'autre le camouflage.

## Utilisation dans différentes disciplines
Impression papier : Regarder les données et non l'image.Vol sans visibilité : S'orienter aux instruments.Cuisine arrière : Production sans client.

## Foire aux questions
**Pourquoi n'y a-t-il pas d'interface ?**
Les données sont traitées, aucune image n'est nécessaire. Cela permet d'économiser de la vitesse et des ressources.

**Est-ce détecté ?**
C'est possible. Le mode furtif réduit les traces, la politique du site est déterminante.

**Quand a-t-on besoin d'une interface graphique (GUI) ?**
Pour le contrôle visuel et les tests manuels. En automatisation, le mode sans tête (headless) suffit.

**Quelle est la différence au niveau des ressources ?**
La mémoire et le processeur diminuent, l'exécution parallèle augmente. C'est de là que vient la mise à l'échelle.
