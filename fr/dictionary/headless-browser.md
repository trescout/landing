# Qu'est-ce que Headless Browser ?

Un navigateur sans interface visuelle qui charge les pages web et traite les données entièrement via du code.

## Définition
Il s'agit d'un type de navigateur où l'interface visuelle que vous voyez normalement lorsque vous naviguez sur Internet (boutons, images) n'est pas exécutée en arrière-plan, et seule la structure du code est traitée. Comme il ne dessine pas l'interface visuelle, il fonctionne très rapidement et consomme moins de ressources informatiques.

## Comment ça marche
Les développeurs utilisent des outils d'automatisation pour donner à ce navigateur la commande : 'va sur ce site et récupère ces données'.

## Où est-ce utilisé
Il est utilisé pour les tests automatisés de sites web et les opérations de récupération de données (web scraping).

## Souvent confondu avec
Navigateur sans tête furtif

## Questions fréquentes
**Pourquoi n'a-t-il pas d'interface visuelle ?**
Parce que nous avons seulement besoin des données, nous n'avons pas besoin de voir la page.
