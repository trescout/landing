# Qu'est-ce que Native ?

Il s'agit d'un logiciel spécifiquement conçu pour le système d'exploitation de l'appareil sur lequel il fonctionne, afin d'offrir les meilleures performances possibles.

## Définition
Les applications natives peuvent accéder directement au matériel et au système d'exploitation de l'appareil. Comme elles parlent la langue de l'appareil sans avoir besoin d'une couche intermédiaire, elles fonctionnent de manière plus rapide et plus fluide. Elles utilisent généralement les fonctionnalités uniques de l'appareil à pleine capacité.

## Comment ça marche
Les développeurs écrivent du code en utilisant les outils de développement logiciel propres à l'appareil. Ainsi, l'application peut utiliser directement toutes les possibilités offertes par le système d'exploitation. Comme aucune couche de traduction intermédiaire n'est présente, il n'y a pas de latence.

## Où est-ce utilisé
On les retrouve dans les boutiques d'applications des smartphones, dans les logiciels au niveau du système d'exploitation et dans les jeux nécessitant des performances élevées.

## Souvent confondu avec
Les applications basées sur le web ou les applications hybrides utilisent une couche intermédiaire, telle qu'un navigateur, pour communiquer avec l'appareil.

## Questions fréquentes
**Une application native est-elle toujours meilleure ?**
En termes de performances, généralement oui, mais son développement prend plus de temps et il est nécessaire d'écrire un code distinct pour chaque appareil.

**Comment fonctionnent les applications non natives ?**
Elles fonctionnent généralement à l'intérieur d'un navigateur ou via une couche de traduction, ce qui peut parfois entraîner des ralentissements.
