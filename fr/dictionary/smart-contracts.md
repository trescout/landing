# Qu'est-ce que Smart Contracts ?

*Glossaire · Dev · Dernière mise à jour : 18 août 2026*

Ce sont des contrats numériques qui fonctionnent automatiquement lorsque certaines conditions sont remplies et ne nécessitent pas d'intermédiaire.

## Définition

Les contrats traditionnels nécessitent qu’un intermédiaire, tel qu’un avocat ou une banque, vérifie si quelqu’un respecte les règles. Les contrats intelligents, quant à eux, sont écrits en code et la transaction se termine automatiquement lorsque les conditions sont remplies (par exemple, un paiement est effectué). Ces codes sont immuables et transparents.

***Analogie :** C'est comme un distributeur automatique : lorsque vous insérez la pièce et choisissez le produit, la machine reconnaît que la condition est remplie et vous donne le produit ; Il n'est pas nécessaire qu'un vendeur intervienne.*

## Comment ça marche

Ce sont des morceaux de code qui s'exécutent sur des réseaux blockchain. Les règles spécifiées sont codées et vérifiées par le réseau et exécutées automatiquement.

## Où est-ce utilisé

Il est utilisé dans les transactions financières, les transferts de propriété et la gestion des actifs numériques.

## Souvent confondu avec

Il peut être confondu avec une simple signature numérique, mais les contrats intelligents contiennent une logique de transaction.

## Questions fréquentes

**Peut-on le changer ?**

Non, une fois téléchargés sur la blockchain, ils ne peuvent pas être modifiés.

**Est-ce sécuritaire?**

Le code doit être écrit sans erreurs ; Des codes incorrects peuvent créer des vulnérabilités.
