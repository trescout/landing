# Qu'est-ce que PDF ?

*Glossaire · Data · Dernière mise à jour : 8 juin 2026*

> Portable Document Format

Il s'agit d'un format de document numérique qui s'affiche sans perdre son format quel que soit l'appareil sur lequel il est ouvert.

## Définition

Le PDF est une version fixe du texte, des images et de la mise en page du document. La police peut changer lorsque vous ouvrez un fichier Word sur un autre ordinateur, mais le format PDF élimine ce risque. Aujourd’hui, c’est l’une des sources de données les plus utilisées pour les systèmes d’intelligence artificielle.

***Analogie :** C'est comme mettre un morceau de papier au congélateur et le congeler ; Peu importe où vous prenez le papier, sa forme ne change jamais.*

## Comment ça marche

Le document est converti en un seul fichier avec toutes les données d'image via une imprimante PDF. Les systèmes d'IA utilisent des analyseurs PDF pour « lire » ces fichiers.

## Où est-ce utilisé

Il est utilisé dans la correspondance officielle, les livres électroniques, les factures et les articles académiques.

## Souvent confondu avec

Il peut être confondu avec les fichiers Word, mais Word est modifiable alors que le PDF est généralement épinglé.

## Questions fréquentes

**Puis-je modifier le PDF ?**

Il peut être modifié avec des outils spéciaux, mais son objectif principal est la visualisation et le partage.

**Comment l’IA lit-elle les PDF ?**

Il lit le PDF en le convertissant en texte avec des outils spéciaux (analyseurs) qui analysent le texte et les images qu'il contient.
