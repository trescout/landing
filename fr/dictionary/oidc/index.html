Qu'est-ce que OIDC ?

OpenID Connect

Il s'agit d'un protocole standard qui vérifie en toute sécurité votre identité lorsque vous vous connectez à différents sites.

Définition

Il s'agit d'une technologie qui vous permet de vous connecter avec votre compte Google ou Apple au lieu de créer un mot de passe distinct pour chaque site Internet. OIDC garantit que le site comprend en toute sécurité qui vous êtes, mais ne donne pas votre mot de passe à ce site.

Analogie : C'est comme montrer votre passeport à la réception lorsque vous allez dans un hôtel ; L'hôtel vérifie qui vous êtes mais vous rend votre passeport.

Comment ça marche

Lorsque vous appuyez sur le bouton de connexion, l'application vous redirige vers un fournisseur d'identité de confiance (comme Google). Une fois que vous confirmez, le fournisseur envoie un document numérique à l'application indiquant « c'est bien la personne ».

Où est-ce utilisé

Il est utilisé dans les applications Web, les écrans de connexion mobiles et les systèmes logiciels d'entreprise.

Souvent confondu avec

Il est confondu avec SSO (Single Sign-On) ; SSO est un concept général, tandis qu'OIDC est le protocole technique qui fait ce travail.

Questions fréquentes

Dois-je partager mon mot de passe avec d'autres sites ?

Non, seule une confirmation numérique indiquant que votre identité a été vérifiée est partagée.
