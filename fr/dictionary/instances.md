# Qu'est-ce que Instances ?

Il s'agit de chaque copie indépendante d'un logiciel ou d'un système fonctionnant simultanément.

## Définition
Dans le monde informatique, lorsque vous lancez un programme, une « instance » de ce programme est créée en mémoire. Si vous ouvrez trois fenêtres différentes du même programme, vous exécutez trois copies (instances) distinctes de ce programme. Chacune est indépendante et conserve ses propres données.

## Comment ça marche
Les ressources système allouent un espace distinct pour chaque copie. Ainsi, si une erreur survient dans une copie ou si le programme plante, les autres copies peuvent continuer à fonctionner sans être affectées.

## Où est-ce utilisé
Il est très fréquemment utilisé dans le cloud computing, la gestion de serveurs et les serveurs de jeux.

## Souvent confondu avec
Il ne doit pas être confondu avec le programme lui-même (le code source) ; le code source est unique, tandis que les copies en cours d'exécution peuvent être illimitées.

## Questions fréquentes
**Pourquoi exécutons-nous plusieurs copies ?**
Il est utilisé pour répartir la charge, augmenter la sécurité ou gérer les tâches de différents utilisateurs simultanément.
