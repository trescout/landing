# Qu'est-ce que CLI Tool ?

*Glossaire · Dev · Dernière mise à jour : 27 septembre 2026*

> Command Line Interface Tool

C'est un petit utilitaire qui permet à l'ordinateur d'effectuer une tâche spécifique en donnant des commandes écrites.

## Définition

L'outil CLI est un logiciel qui vous permet de communiquer avec l'ordinateur en tapant des commandes sur le clavier au lieu de cliquer avec la souris. Grâce à ces outils, les développeurs peuvent gérer des fichiers, mettre à jour des programmes ou tester des codes. Il n'a pas d'interface visuelle, il fonctionne avec du texte sur un écran noir.

***Analogie :** Au lieu d’une chaîne stéréo dotée de boutons compliqués, c’est comme un assistant intelligent qui fonctionne en tapant des commandes comme une machine à écrire.*

## Comment ça marche

Vous ouvrez le terminal ou l'application de ligne de commande, tapez le nom du programme et les commandes spécifiant l'action que vous souhaitez effectuer, puis appuyez sur Entrée.

## Où est-ce utilisé

Il est largement utilisé dans les processus de développement de logiciels, la gestion de serveurs et les scripts d'automatisation.

## Souvent confondu avec

Il est différent des programmes normaux dotés d'une interface graphique, il est entièrement basé sur du texte.

## Questions fréquentes

**Est-il difficile d'apprendre les outils CLI ?**

Une fois que vous aurez mémorisé les commandes de base, vous vous rendrez compte que c'est assez rapide et pratique.
