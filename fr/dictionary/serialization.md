# Qu'est-ce que Serialization ?

Il s'agit du processus de conversion de structures de données complexes en texte brut ou en tableau d'octets pouvant être stocké ou transmis.

## Définition
Vous devez traduire en ligne droite des objets conservés de manière complexe dans la mémoire de l'ordinateur (par exemple, un profil d'utilisateur) afin de les envoyer sur Internet ou de les enregistrer dans un fichier. Ce processus est appelé sérialisation. Lorsque l'autre partie reçoit ces données, elle effectue une « désérialisation » et les restaure dans son ancienne structure complexe.

## Comment ça marche
Les données sont généralement converties aux formats JSON, XML ou binaires plus rapides. De cette manière, la structure originale des données est préservée et devient portable entre différents systèmes.

## Où est-ce utilisé
Il est utilisé dans les communications API, les enregistrements de bases de données et la création de fichiers de sauvegarde dans les jeux.

## Questions fréquentes
**Pourquoi avons-nous besoin de sérialisation ?**
Les données contenues dans la mémoire de l'ordinateur n'ont de sens que pour le programme en cours. Pour envoyer des données vers un autre ordinateur ou disque, nous devons les convertir dans un format universel.
