# Qu'est-ce que Local-first Code Intelligence ?

Les outils de développement logiciel fournissent des suggestions de code en traitant les données directement sur votre appareil local sans les envoyer vers le cloud.

## Définition
Cette approche est conçue pour protéger la confidentialité de votre code et fonctionner rapidement même sans connexion Internet. Au lieu de télécharger des données sur des serveurs distants, votre environnement de développement analyse votre code en utilisant la puissance de votre propre ordinateur. Ainsi, la sécurité est augmentée et les délais sont éliminés.

## Comment ça marche
Ce système exécute des modèles d'intelligence artificielle qui scannent votre code sur le processeur ou la carte graphique de votre ordinateur. Votre IDE ou éditeur reste en communication constante avec ces modèles locaux, générant des suggestions instantanées. Les fonctionnalités de complétion de code ou de débogage continuent de fonctionner même si votre connexion Internet est perdue.

## Où est-ce utilisé
Il est utilisé dans les éditeurs de code modernes, les plugins natifs basés sur l'IA et les environnements de développement axés sur la confidentialité.

## Souvent confondu avec
Il peut être confondu avec les assistants de code basés sur le cloud, mais ici l'ensemble du processus se termine sur votre appareil.

## Questions fréquentes
**Pourquoi devrais-je choisir le local plutôt que le cloud ?**
Conserver vos données sur votre appareil constitue un énorme avantage en matière de sécurité, surtout si vous travaillez sur un code sensible ou secret commercial.
