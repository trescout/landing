# Qu'est-ce que Assets ?

C'est l'ensemble de toutes les parties numériques qui composent un projet.

## Définition
Toutes les ressources externes que vous utilisez lors du développement de logiciels ou de jeux sont appelées des « actifs ». Il ne s’agit pas du code lui-même, mais des matériaux auxiliaires dont le code a besoin. Ce sont les matières premières visuelles, sonores ou structurelles d’un projet.

## Comment ça marche
Ils sont conservés dans des dossiers séparés au sein de vos fichiers de projet et vous les appelez en référençant ces fichiers lors de l'écriture du code.

## Où est-ce utilisé
Il est utilisé dans tous les projets de développement de jeux, de conception Web et d’applications mobiles.

## Questions fréquentes
**Les fichiers de code sont-ils considérés comme des actifs ?**
Généralement non, alors que le code est considéré comme la structure principale ; Les visuels, sons et modèles 3D sont classés comme atouts.
