# Qu'est-ce que Security Scanner ?

*Glossaire · Dev · Dernière mise à jour : 15 juin 2026*

C'est un outil qui détecte automatiquement les vulnérabilités des logiciels ou des systèmes réseau.

## Définition

Un scanner de sécurité examine vos systèmes numériques comme un détective. Il vérifie si vous avez laissé les portes ou les fenêtres de votre système ouvertes et signale vos vulnérabilités face à d'éventuelles cyberattaques. Ces outils analysent le code logiciel complexe ou le trafic réseau pour détecter les erreurs que l'œil humain pourrait manquer.

***Analogie :** C'est comme si un expert en sécurité professionnel vérifiait toutes les serrures de portes et fenêtres avant d'entrer dans votre maison.*

## Comment ça marche

Vous connectez le scanner à votre système et démarrez une analyse. L'outil compare les fichiers ou les paquets réseau de votre système avec les bases de données de menaces connues. Il vous présente une liste de toutes les situations suspectes qu'il détecte et vous donne généralement des suggestions sur la façon de combler l'écart.

## Où est-ce utilisé

Il est utilisé dans les processus de développement de logiciels, la gestion des serveurs et les audits de cybersécurité des entreprises.

## Souvent confondu avec

Il est utilisé dans le même but que le Vulnerability Scanning, mais ce terme se concentre directement sur le véhicule.

## Questions fréquentes

**Le scanner de sécurité trouve-t-il toutes les vulnérabilités ?**

Non, il ne peut trouver que les vulnérabilités définies dans la base de données ou qui correspondent à certains modèles.

**Ces outils ralentissent-ils le système ?**

Ils peuvent utiliser les ressources du système lors d’analyses approfondies, c’est pourquoi ils sont généralement exécutés pendant les heures creuses.
