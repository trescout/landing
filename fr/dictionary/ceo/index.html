Qu'est-ce que CEO ?

Chief Executive Officer

Il est le plus haut fonctionnaire qui gère toutes les opérations et décisions stratégiques d’une entreprise.

Définition

Le PDG est comme le capitaine d’une organisation. Il détermine les objectifs de l'entreprise, assume la responsabilité des décisions importantes et s'assure que l'équipe avance conformément à la vision. Il se concentre sur l’avenir de l’institution plutôt que sur le fonctionnement quotidien.

Analogie : Il est comme un capitaine sur un navire ; Il décide où le navire ira et est responsable du travail coordonné de l'ensemble de l'équipage.

Comment ça marche

Le PDG est nommé par le conseil d'administration et élabore des stratégies pour le succès de l'entreprise. Il crée des ponts entre les investisseurs, les collaborateurs et les clients.

Où est-ce utilisé

On le retrouve dans les entreprises, les startups technologiques et les organisations à grande échelle.

Souvent confondu avec

Il peut être confondu avec le président du conseil d'administration (Chair) ; Le PDG exécute, le président gère le conseil d'administration.

Questions fréquentes

Le PDG se mêle-t-il de tout ?

Non, le PDG se concentre davantage sur les décisions stratégiques et délègue les tâches opérationnelles aux chefs de service.
