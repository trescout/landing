Qu'est-ce que Agent Skills ?

Les compétences d'agent (agent skills) sont des ensembles regroupant les instructions, les outils et les ressources nécessaires à un agent pour accomplir une tâche spécifique de manière cohérente.

Définition et origine du mot

Une compétence (skill) indique à l'agent quel travail effectuer, quand le faire et dans quelles limites. Elle peut fournir un accès à des outils tels que la recherche, la lecture de fichiers ou l'exécution de code ; cependant, chaque compétence n'est pas nécessairement un outil en soi. Une compétence bien conçue définit clairement le contexte nécessaire et les étapes de validation.

Analogie : Si vous comparez l'agent à un couteau suisse, les compétences sont les différentes fonctions comme le couteau, le tournevis et les ciseaux.

Comment connaître et utiliser dans la vie quotidienne ?

Plateforme : Bibliothèques de compétences prêtes à l'emploi.
Automatisation : Tâches planifiées.
Développement: Outils de dépôt et de test.

Profondeur technique et architecture

Le format varie selon la plateforme ; voici une définition simplifiée d'une compétence :

{
  "name": "dosya-ozetle",
  "description": "Belirtilen dosyadan kısa bir özet çıkarır",
  "instructions": ["Önce dosyayı oku.", "Hassas veriyi özet içinde maskele."]
}

Flux : La tâche arrive, l'agent sélectionne la compétence appropriée selon la description, appelle les outils nécessaires et valide le résultat. Pour les opérations ayant un impact comme l'écriture, le réseau ou le paiement, les limites d'autorisation de l'application et, si nécessaire, l'approbation humaine entrent en jeu. Règle : Peu de compétences claires valent mieux que beaucoup de compétences vagues.

Choses fréquemment mélangées

On croit à une intelligence générale. Pourtant, ce qui est visé, c'est la capacité à accomplir une tâche spécifique. Le modèle comprend, la compétence exécute.

Utilisation dans différentes disciplines

Couteau suisse : Ensemble de couteau, tournevis et ciseaux.
Boîte à outils : Clé choisie en fonction du travail.
Magasin d'applications : Programme téléchargé selon les besoins.

Foire aux questions

Est-ce que j'ajoute les compétences moi-même ?

Cela dépend de la plateforme. Dans certains environnements, des compétences prêtes à l'emploi sont sélectionnées, dans d'autres, l'équipe définit ses propres packs de compétences.

Les capacités de chaque agent sont-elles les mêmes ?

Non. Elles sont personnalisées selon l'objectif ; l'ensemble d'un agent analyste de données est différent de celui d'un agent codeur.

Est-ce sécuritaire?

La lecture présente un faible risque. Pour les opérations d'écriture et de paiement, une approbation et une limite de portée sont indispensables.

Existe-t-il une bibliothèque prête à l'emploi ?

Oui. Les plateformes regroupent les compétences courantes, et vous écrivez les vôtres pour des tâches spécifiques.
