# Qu'est-ce que LSP ?

> Language Server Protocol

Il s'agit d'un protocole de communication standard qui fournit des fonctionnalités intelligentes à votre éditeur lors de l'écriture du code.

## Définition
LSP est un pont entre les outils d'écriture de code (éditeurs) et les serveurs qui comprennent la logique du code. Grâce à ce protocole, l'éditeur que vous utilisez ; Il peut offrir des fonctionnalités telles que la détection d'erreurs, la saisie semi-automatique et l'accès aux définitions de manière standard dans toutes les langues. Il permet à votre éditeur d'agir intelligemment sans avoir besoin de savoir quelle langue vous utilisez.

## Comment ça marche
Votre éditeur envoie le code que vous écrivez à un « serveur de langage » exécuté en arrière-plan. Le serveur analyse le code et vous fait des suggestions. Vous écrivez votre code plus rapidement et sans erreur, sans rien ressentir.

## Où est-ce utilisé
Il s'exécute constamment en arrière-plan des éditeurs de code modernes comme VS Code.

## Souvent confondu avec
Ce n'est pas seulement une fonctionnalité d'éditeur, c'est un langage conversationnel universel entre l'éditeur et le langage.

## Questions fréquentes
**Pourquoi est-ce si important ?**
Au lieu de développer des fonctionnalités séparément pour chaque éditeur, il permet à la prise en charge des langages à écriture unique de fonctionner partout.

**Est-ce que cela affecte ma vitesse ?**
Non, au contraire, cela accélère votre processus de codage en vous évitant de commettre des erreurs.
