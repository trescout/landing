# Qu'est-ce que Data Logger ?

Il s'agit d'un appareil électronique qui enregistre et stocke les données des capteurs à intervalles réguliers.

## Définition
Un enregistreur de données surveille en permanence les changements physiques dans son environnement et stocke ces informations ainsi que des horodatages. Ces appareils sont souvent utilisés pour suivre des données telles que la température, l'humidité ou les mouvements. Ces données collectées sont ensuite analysées pour comprendre le fonctionnement du système.

## Comment ça marche
Vous placez l'appareil là où vous souhaitez le surveiller et il écrit les données dans sa mémoire interne ou sur un ordinateur. Vous pouvez ensuite ouvrir ces enregistrements et examiner ce qui s'est passé dans le passé.

## Où est-ce utilisé
Il est utilisé pour surveiller l’état des machines dans les usines, suivre les résultats des expériences dans les laboratoires ou mesurer la consommation d’énergie dans les systèmes de maison intelligente.

## Souvent confondu avec
Il peut être confondu avec une base de données, mais ce dispositif est plutôt du matériel physique au stade de la collecte des données brutes.

## Questions fréquentes
**Comment un enregistreur de données stocke-t-il les données ?**
Il enregistre généralement sur une carte mémoire interne ou directement dans la base de données d'un ordinateur auquel il est connecté.

**Chaque capteur est-il un enregistreur de données ?**
Non, le capteur détecte simplement les données ; L'enregistreur de données est une unité supérieure qui associe ces données au temps et les enregistre.
