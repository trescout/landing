# Qu'est-ce que Code Knowledge Graph ?

Structure qui cartographie les éléments de code des projets logiciels et leurs relations sous la forme d'un réseau d'information.

## Définition
Le Graphe de Connaissance du Code (Code Knowledge Graph) est une carte d'information spéciale qui organise les éléments d'un projet logiciel tels que les fonctions, les classes, les variables et les dépendances sous forme de nœuds et d'arêtes. Il permet aux systèmes d'intelligence artificielle de comprendre de manière globale non seulement la structure textuelle du code, mais aussi l'architecture logique qui se cache derrière. Il est fréquemment utilisé sur la plateforme TreScout pour expliquer des bases de code complexes aux agents d'intelligence artificielle et leur fournir le contexte adéquat.

## Comment ça marche
Tout d'abord, la base de code est analysée à l'aide d'outils d'analyse statique pour extraire tous les composants. Ensuite, les relations d'appel, d'héritage ou de transfert de données entre ces composants sont enregistrées dans une base de données de graphes. Lorsqu'elle reçoit une requête de code, l'intelligence artificielle accède directement au nœud de code concerné ainsi qu'aux composants environnants qui y sont liés afin de générer la réponse correcte.

## Où est-ce utilisé
Il est utilisé lors de l'analyse de code dans de grands projets logiciels, dans les outils d'examen de code automatisés et dans les assistants de codage propulsés par l'intelligence artificielle. Il est également privilégié pour comprendre les dépendances architecturales lors de la modernisation de systèmes existants.

## Souvent confondu avec
Il est différent des systèmes de recherche textuelle classiques ; au lieu d'une simple correspondance de texte, il révèle les liens sémantiques et architecturaux du code.

## Questions fréquentes
**Pourquoi utiliser un Graphe de Connaissance du Code plutôt qu'une simple recherche textuelle ?**
La recherche textuelle trouve l'endroit où un mot apparaît, mais ne peut pas montrer quelles classes cette fonction affecte ; le graphe de connaissance présente l'ensemble du réseau de relations.

**Comment la création de cette structure affecte-t-elle les performances de l'intelligence artificielle ?**
Elle empêche l'intelligence artificielle de faire des déductions incomplètes ou erronées sur le code, et lui permet de générer du code plus cohérent en lui fournissant le contexte correct.
