# Qu'est-ce que GUI ?

> Graphical User Interface

C'est une interface qui permet de gérer visuellement les programmes informatiques avec des icônes, des menus et des fenêtres au lieu de taper du texte.

## Définition
L'interface graphique est la couche visuelle qui rend la technologie accessible à tous. Il permet à quelqu'un qui ne sait pas coder de contrôler l'ordinateur en cliquant sur la souris. C'est la pierre angulaire des systèmes d'exploitation modernes.

## Comment ça marche
Chaque bouton, fenêtre et icône que vous voyez sur votre écran est un élément de l'interface graphique. Lorsque vous cliquez sur un bouton, les codes exécutés en arrière-plan reçoivent cette commande visuelle et démarrent le processus correspondant.

## Où est-ce utilisé
On le trouve dans les smartphones, les systèmes d'exploitation informatiques et toutes les applications mobiles que vous utilisez.

## Souvent confondu avec
Contrastes avec CLI (Command Line Interface); En CLI, seul le texte est écrit, tandis qu’en GUI, la visualisation est au premier plan.

## Questions fréquentes
**Tous les logiciels ont-ils une interface graphique ?**
Non, certains outils professionnels fonctionnent uniquement en mode texte (CLI).

**L’interface graphique affecte-t-elle les performances ?**
Dessiner des éléments visuels nécessite une puissance de traitement, c'est pourquoi les interfaces textuelles sont parfois préférées sur des systèmes très simples.
