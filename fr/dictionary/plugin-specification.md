# Qu'est-ce que Plugin Specification ?

Il s'agit d'un ensemble de règles techniques qui doivent être suivies pour développer des modules complémentaires externes pour un logiciel.

## Définition
La spécification du plugin est un guide qui détermine comment le logiciel principal communiquera avec les plug-ins, quelles données il échangera et comment il fonctionnera. Grâce à ces règles, la stabilité du logiciel est maintenue.

## Comment ça marche
Les développeurs lisent la documentation spécifiée et introduisent le plugin dans le système en écrivant leurs codes selon ces règles.

## Où est-ce utilisé
Il est utilisé dans les modules complémentaires de navigateur, les intégrations d'outils d'IA et les principales plates-formes logicielles.

## Souvent confondu avec
Il peut être confondu avec le SDK, mais il s'agit plutôt d'un ensemble de règles tandis que le SDK est un ensemble d'outils plus large.

## Questions fréquentes
**Pourquoi devrais-je suivre ces règles ?**
Si vous ne vous conformez pas, votre plugin ne fonctionnera pas dans le logiciel principal ou générera une erreur.

**Les règles sont-elles les mêmes pour tous les logiciels ?**
Non, chaque logiciel a ses propres standards spécifiques.
