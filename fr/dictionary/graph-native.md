# Qu'est-ce que Graph-native ?

*Glossaire · Data · Dernière mise à jour : 11 août 2026*

Il s'agit d'une conception de système basée sur une structure dans laquelle les données sont connectées les unes aux autres via des nœuds.

## Définition

Alors que les bases de données traditionnelles stockent les informations dans des tableaux, cette approche connecte les données comme une carte réseau. Elle place dès le départ les relations entre les informations au centre du système. De cette manière, l’interrogation de connexions complexes devient beaucoup plus rapide et naturelle.

***Analogie :** C'est comme mettre une carte des autres livres sur ce sujet dans chaque livre, au lieu de classer les livres dans une bibliothèque par ordre alphabétique.*

## Comment ça marche

Lorsque vous créez votre modèle de données, vous définissez les objets et leurs interactions sous forme de points et de lignes. En suivant ces lignes, le système trouve des liens cachés entre les données en quelques secondes.

## Où est-ce utilisé

Il est utilisé dans l’analyse complexe des réseaux sociaux, les systèmes de recommandation et les applications qui gèrent de grandes masses d’informations interconnectées.

## Souvent confondu avec

Elle est fréquemment confondue avec les bases de données relationnelles traditionnelles ; Cependant, ce système établit des relations dès la phase de conception, pas plus tard.

## Questions fréquentes

**Pourquoi devrais-je choisir cette méthode ?**

Cette méthode est la plus efficace si les relations entre vos données sont aussi importantes que les données elles-mêmes.
