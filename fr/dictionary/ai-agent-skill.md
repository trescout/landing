# Qu'est-ce que AI Agent Skill ?

Il s’agit de compétences spécifiques qu’un agent IA peut utiliser pour accomplir une tâche, comme effectuer une recherche sur Internet ou organiser un fichier.

## Définition
Les compétences des agents IA sont des capacités qui permettent à une intelligence artificielle non seulement de produire du texte, mais également d'interagir avec le monde extérieur. Lorsqu’un agent apprend à lire un fichier, à envoyer un email ou à exécuter un logiciel, on dit qu’il a acquis une nouvelle compétence. Ces capacités permettent à l'agent d'effectuer des tâches de manière autonome.

## Comment ça marche
Les développeurs accordent à l'agent l'autorisation d'utiliser certaines API ou outils. Lorsque l'agent reçoit la tâche, il choisit la compétence qu'il doit utiliser et exécute l'action à l'aide de cet outil. Plus la compétence est large, plus l'agent réussira à accomplir des tâches différentes.

## Où est-ce utilisé
Il est fréquemment utilisé dans les plateformes d’agents d’IA et les outils d’automatisation.

## Souvent confondu avec
Elle peut être confondue avec l'intelligence générale ; Une compétence est le moyen dont dispose l'agent pour effectuer un travail spécifique.

## Questions fréquentes
**Comment les agents acquièrent-ils de nouvelles compétences ?**
Ils sont souvent ajoutés par les développeurs en tant qu'outils prédéfinis ou, dans certains systèmes, ils développent de nouvelles fonctionnalités en écrivant eux-mêmes du code.

**Les compétences de chaque agent sont-elles les mêmes ?**
Non, selon la finalité de l'agent (par exemple agent de codage ou agent de recherche), leurs compétences diffèrent complètement.
