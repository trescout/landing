# Qu'est-ce que Service Mesh ?

Il s'agit d'une couche d'infrastructure qui permet à différents services de communiquer entre eux de manière sécurisée et régulière dans des systèmes logiciels complexes.

## Définition
Dans un système composé de centaines de petites pièces, il est difficile pour ces pièces de se retrouver et de communiquer en toute sécurité. Le Service Mesh est un réseau invisible qui gère cette communication, régule le trafic et fonctionne comme un pare-feu.

## Comment ça marche
Un petit utilitaire est placé à côté de votre application. Toutes les communications passent par cet outil, vous pouvez donc gérer le trafic sans changer votre code principal.

## Où est-ce utilisé
Il est utilisé dans les applications cloud à grande échelle avec une architecture de microservices.

## Questions fréquentes
**Est-ce nécessaire pour chaque projet ?**
Non, cela n’est nécessaire que pour gérer la complexité de grands systèmes comportant de nombreuses parties.
