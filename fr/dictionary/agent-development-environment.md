# Qu'est-ce que Agent Development Environment ?

Il s'agit d'un environnement de développement logiciel spécialisé utilisé pour créer, tester et gérer des assistants d'intelligence artificielle.

## Définition
Développer des agents IA est un peu plus compliqué que développer des logiciels classiques, car vous devez surveiller les processus décisionnels des agents. Ces environnements vous permettent de voir comment les agents pensent et corrigent leurs erreurs.

## Comment ça marche
Dans cet environnement, les développeurs définissent à quelles informations l'agent peut accéder et quels outils il peut utiliser. Ensuite, ils suivent pas à pas les décisions prises par l’agent, détectent les erreurs logiques ou les erreurs d’orientation et apportent des améliorations.

## Où est-ce utilisé
Il est utilisé dans des projets logiciels axés sur l’intelligence artificielle et sur les ordinateurs des équipes développant des systèmes basés sur des agents.

## Souvent confondu avec
À ne pas confondre avec les éditeurs de texte standard qui écrivent simplement du code ; Il existe également des outils ici pour surveiller le processus de « pensée » de l'agent.

## Questions fréquentes
**Pourquoi un environnement spécial est-il nécessaire ?**
Parce que les agents d’intelligence artificielle peuvent parfois prendre des décisions inattendues ; Ces environnements nous permettent de comprendre la raison de ces décisions.
