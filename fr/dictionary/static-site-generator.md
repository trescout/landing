# Qu'est-ce que Static Site Generator ?

Un outil qui prend du contenu et des modèles prêts à l'emploi et les transforme en pages Web fixes prêtes à être présentées à l'utilisateur.

## Définition
Les sites Web traditionnels extraient des informations de la base de données pour chaque visiteur. Le générateur de site statique, en revanche, effectue ce processus une seule fois, crée les pages à l'avance et envoie uniquement les fichiers prêts au visiteur. Cela garantit que votre site se charge très rapidement et est plus sécurisé.

## Comment ça marche
Vous écrivez votre contenu dans Markdown ou dans des fichiers similaires. L'outil combine ces contenus avec des modèles de conception et produit des fichiers HTML. Vous téléchargez également ces fichiers sur Internet.

## Où est-ce utilisé
Il est fréquemment préféré dans les blogs, les sites de documentation et les portfolios personnels.

## Souvent confondu avec
Il est mixé avec un CMS (Content Management System) ; CMS utilise une base de données, alors que cet outil ne produit que des fichiers.

## Questions fréquentes
**Comment mettre à jour mon site ?**
En modifiant le contenu et en exécutant à nouveau l'outil, vous générez et téléchargez de nouveaux fichiers.

**Aucune base de données requise ?**
Non, cela ne nécessite pas de base de données, ce qui le rend très rapide.
