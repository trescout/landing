# Qu'est-ce que Cloning ?

*Glossaire · Dev · Dernière mise à jour : 26 juin 2026*

Il s'agit du processus de duplication d'un projet logiciel ou de données entières en le copiant vers un autre emplacement.

## Définition

Le clonage est notamment utilisé dans le monde du logiciel pour télécharger la version actuelle d'un projet sur votre propre ordinateur. De cette façon, vous disposez d'une copie du projet avec tout son historique et ses fichiers. De cette façon, vous pouvez apporter des modifications au projet d'origine sans l'endommager.

***Analogie :** C'est comme photocopier un livre ; L'original reste en place et vous disposez d'une copie avec laquelle travailler.*

## Comment ça marche

Vous copiez généralement le lien vers le projet à l'aide de la commande « clone » via un système de contrôle de version (comme git). Le système télécharge tous les fichiers sur votre appareil.

## Où est-ce utilisé

Il est utilisé lors de l'importation de projets open source depuis des plateformes telles que GitHub vers votre propre ordinateur.

## Souvent confondu avec

Cela peut être confondu avec la sauvegarde ; Le clonage est plutôt une copie effectuée dans le but de travailler dessus.

## Questions fréquentes

**Est-ce que cela change le projet initial ?**

Non, les modifications que vous apportez à votre copie n'affecteront pas le projet original.

**Une connexion Internet est-elle requise ?**

Seule la copie est requise à ce moment-là ; Vous pouvez alors travailler hors ligne.
