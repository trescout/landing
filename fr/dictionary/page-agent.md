# Qu'est-ce que Page Agent ?

*Glossaire · AI · Dernière mise à jour : 5 juillet 2026*

Il s'agit d'un assistant spécial d'intelligence artificielle qui analyse les pages Web et effectue des actions telles que cliquer ou saisir des données au nom de l'utilisateur.

## Définition

Page Agent est un assistant numérique qui s'exécute sur le navigateur. Non seulement il peut lire du texte, mais il peut également appuyer sur des boutons, remplir des formulaires et naviguer entre les pages. Il est conçu pour naviguer sur des sites Web complexes comme un humain.

***Analogie :** C'est comme un assistant numérique qui guide une personne perdue sur un site Web et remplit des formulaires à la place.*

## Comment ça marche

Il fonctionne comme un module complémentaire ou une application en arrière-plan installée dans votre navigateur. Vous lui dites quoi faire, il analyse les éléments de la page Web et exécute les étapes une par une.

## Où est-ce utilisé

Il est utilisé pour suivre les prix sur les sites de commerce électronique, remplir des formulaires ou collecter des données sur le Web.

## Souvent confondu avec

Il peut être confondu avec les modèles d'agents d'IA à usage général, mais il s'agit uniquement d'un navigateur Web.

## Questions fréquentes

**L'agent de page est-il sûr ?**

Il ne peut pas agir en dehors des zones que vous avez autorisées, mais vous devez néanmoins être prudent lorsque vous travaillez avec vos données sensibles.

**Est-ce que ça marche sur tous les sites Web ?**

Il fonctionne généralement sur des structures Web standards, mais peut rencontrer des difficultés sur des sites dotés de mesures de sécurité très complexes.
