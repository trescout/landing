Qu'est-ce que Bindings ?

Ce sont des ponts qui permettent à différents langages de programmation d'utiliser les bibliothèques des uns et des autres.

Définition

Une bibliothèque est généralement écrite dans un seul langage (par exemple C++). Cependant, si vous utilisez Python, vous ne pouvez pas utiliser directement cette bibliothèque. La liaison est une interface qui traduit cette bibliothèque dans un langage compris par Python. De cette façon, vous pouvez dépasser les frontières linguistiques et utiliser les meilleurs outils dans la langue de votre choix.

Analogie : C'est comme un interprète traduisant entre deux personnes parlant des langues différentes ; l’un aide l’autre à comprendre ce que l’autre dit.

Comment ça marche

Les développeurs créent une petite couche de code qui transfère les fonctions de la bibliothèque principale vers le langage cible. Les opérations complexes dans la bibliothèque principale fonctionnent donc comme une simple commande dans votre propre langage.

Où est-ce utilisé

La plupart des modèles d'IA sont écrits en C++, mais grâce aux liaisons Python, nous pouvons facilement les utiliser avec Python.

Souvent confondu avec

Elle peut être confondue avec l'API, mais même si l'API communique sur le réseau, la liaison est une connexion au niveau de la mémoire au sein du même ordinateur.

Questions fréquentes

Pourquoi toutes les bibliothèques ne sont-elles pas écrites dans toutes les langues ?

Les langages de bas niveau (C++) sont privilégiés pour les performances, les langages de haut niveau (Python) sont privilégiés pour la facilité d'utilisation.

La liaison ralentit-elle ?

Bien qu’il y ait généralement une légère perte de performances, la commodité qu’elle offre en vaut la peine.
