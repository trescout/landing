Qu'est-ce que VPN ?

Virtual Private Network

C'est un outil qui cache votre identité et fournit une connexion sécurisée en cryptant vos données sur Internet.

Définition

Il transmet vos données via un tunnel lorsque vous vous connectez à Internet. Grâce à ce tunnel, les étrangers ne peuvent pas voir ce que vous faites ni d'où vous vous connectez. Même votre fournisseur d'accès Internet ne peut pas lire votre trafic.

Analogie : Au lieu de marcher nu dans la rue, c'est comme voyager dans un véhicule blindé spécial où l'on ne sait pas clairement qui vous êtes de l'extérieur.

Comment ça marche

Téléchargez une application VPN, sélectionnez le serveur auquel vous souhaitez vous connecter et activez la connexion ; Tout votre trafic sera désormais crypté.

Où est-ce utilisé

Il est utilisé dans les réseaux WiFi publics, pour des travaux nécessitant de la confidentialité ou pour surmonter les barrières d'accès.

Souvent confondu avec

Il peut être confondu avec un proxy, mais un VPN crypte tout le trafic des appareils, alors qu'un proxy n'achemine généralement que certaines applications.

Questions fréquentes

Le VPN va-t-il ralentir ma vitesse ?

Les données étant cryptées, il peut parfois y avoir une légère perte de vitesse.

Les VPN gratuits sont-ils sûrs ?

Généralement non, ils peuvent générer des revenus à partir de vos données.
