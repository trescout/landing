# Qu'est-ce que Playlist ?

Il s'agit d'une liste où le contenu numérique est rassemblé pour être joué dans un certain ordre ou selon un thème.

## Définition
Il s'agit de la présentation de fichiers de musique, de vidéo ou de données dans un ordre personnalisé par l'utilisateur. Il est également utilisé dans le monde du logiciel, notamment pour organiser des ensembles de données ou des séquences de tâches confiées à des modèles d'intelligence artificielle.

## Comment ça marche
Le contenu est sélectionné, trié dans un fichier de liste ou une base de données, et le joueur suit cette liste.

## Où est-ce utilisé
Il est utilisé dans les plateformes musicales, les sites vidéo et les processus de traitement de données.

## Questions fréquentes
**A quoi sert la playlist en intelligence artificielle ?**
Il est utilisé pour gérer l'ordre des fichiers de données dans lesquels le modèle doit être formé ou testé.
