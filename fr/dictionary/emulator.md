# Qu'est-ce que Emulator ?

C'est un outil qui vous permet d'exécuter des programmes sur d'autres appareils grâce à un logiciel émulant le matériel d'un ordinateur ou d'une console de jeux.

## Définition
L'émulateur simule le processeur et la logique de fonctionnement d'un appareil dans un environnement virtuel. De cette façon, vous pouvez utiliser un logiciel exécuté sur l'appareil d'origine sur une plate-forme différente sans avoir besoin de la présence physique de cet appareil. Il est souvent utilisé notamment pour jouer à d’anciens jeux sur des ordinateurs actuels.

## Comment ça marche
Vous installez le logiciel d'émulation, puis chargez les fichiers logiciels (généralement appelés ROM) du système que vous souhaitez exécuter dans le système. L'émulateur lit ces fichiers et les affiche à l'écran comme si vous étiez sur l'appareil d'origine.

## Où est-ce utilisé
Dans le monde du jeu, il est utilisé pour faire revivre d’anciennes consoles, pour que les développeurs de logiciels testent sur différents appareils ou pour exécuter d’anciens systèmes d’exploitation.

## Souvent confondu avec
Peut être confondu avec simulateur ; Alors que le simulateur imite uniquement le comportement, l'émulateur essaie de copier exactement la logique de fonctionnement du matériel.

## Questions fréquentes
**Est-il légal d'utiliser un émulateur ?**
Le logiciel d'émulation lui-même est légal, mais l'utilisation de fichiers de jeu protégés par le droit d'auteur sans autorisation peut créer des problèmes juridiques.

**Peut-il exécuter n'importe quoi sur mon ordinateur ?**
Habituellement, la puissance de votre matériel doit être supérieure à celle du périphérique émulé.
