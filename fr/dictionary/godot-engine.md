# Qu'est-ce que Godot Engine ?

Il s'agit d'une plate-forme logicielle entièrement gratuite et open source utilisée pour le développement de jeux.

## Définition
Godot Engine est un moteur de jeu puissant qui vous permet de créer des jeux 2D et 3D. Avec son interface conviviale et son propre langage de codage propriétaire, il est très populaire auprès des nouveaux venus dans le monde du développement de jeux. Grâce à sa nature open source, il offre un environnement de développement gratuit où chacun peut contribuer.

## Comment ça marche
Les utilisateurs placent des objets dans la scène, codent les mouvements des personnages et déterminent les règles du jeu. Le moteur transforme toutes ces conceptions en logiciels auxquels le joueur peut jouer.

## Où est-ce utilisé
Il est utilisé par les développeurs de jeux indépendants dans des projets de jeux sur PC, consoles et mobiles.

## Souvent confondu avec
Contrairement aux autres moteurs de jeux commerciaux, il est entièrement gratuit et ne facture aucun frais de licence.

## Questions fréquentes
**Dois-je connaître le code ?**
L'apprentissage de la logique de base du code rend votre travail beaucoup plus facile, mais grâce aux outils visuels, vous pouvez également faire beaucoup de choses sans code.

**Quels types de jeux peut-on créer ?**
Vous pouvez tout développer, des simples jeux de réflexion aux jeux d'aventure 3D complexes.
