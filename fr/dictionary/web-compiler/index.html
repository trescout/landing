Qu'est-ce que Web Compiler ?

C'est un outil qui rend vos codes exécutables directement via votre navigateur Internet, sans rien installer sur votre ordinateur.

Définition

Traditionnellement, le développement de logiciels nécessitait des installations complexes sur votre ordinateur. Le compilateur Web transmet ce processus au navigateur. Il vous permet d'obtenir des résultats instantanés en traitant les codes que vous écrivez sur les serveurs cloud.

Analogie : Au lieu d'apporter tous les ingrédients et les fourneaux chez vous pour cuisiner dans la cuisine, c'est comme se connecter à une cuisine professionnelle via Internet et y cuisiner et y servir votre nourriture.

Comment ça marche

Vous ouvrez votre navigateur, accédez au site Web concerné, saisissez votre code et appuyez sur « exécuter ». Le système compile votre code en arrière-plan et vous montre le résultat sur votre écran.

Où est-ce utilisé

Il est privilégié sur les plateformes d'apprentissage de code, lors de la réalisation de prototypage rapide ou lorsque le matériel de votre ordinateur est insuffisant.

Souvent confondu avec

Peut être mélangé avec des compilateurs natifs ; Le compilateur Web utilise Internet tandis que les compilateurs locaux utilisent la puissance de votre ordinateur.

Questions fréquentes

Dois-je conserver un fichier de code sur mon ordinateur ?

Généralement non, vos projets sont stockés dans votre compte cloud.

Que se passe-t-il si ma connexion Internet est coupée ?

Votre code arrête le traitement car le traitement a lieu sur le serveur distant et non dans le navigateur.
