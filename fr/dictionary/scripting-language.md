# Qu'est-ce que Scripting Language ?

*Développement · Dernière mise à jour : 23 octobre 2026*

Type de langage de programmation généralement sans compilation, utilisé pour automatiser les processus logiciels et exécuter rapidement des tâches.

## Définition

Un langage de script est un langage exécuté ligne par ligne par un interpréteur, plutôt que d'être préalablement compilé en code machine comme les langages traditionnels. Il est généralement privilégié pour relier des systèmes existants, automatiser des tâches routinières ou ajouter du dynamisme à des pages Web. Python, JavaScript et Bash comptent parmi les langages de script les plus populaires.

***Analogie :** Plutôt que d'être la copie finale montée d'un film de bout en bout, il ressemble à un texte de théâtre pratique que les acteurs suivent pas à pas sur scène.*

## Comment ça marche

Le développeur écrit le code et donne directement la commande d'exécution. Un logiciel intermédiaire (l'interpréteur) lit instantanément ce code et transmet les instructions au système d'exploitation ou au navigateur. En l'absence d'étape de compilation, le cycle de développement et de test est extrêmement rapide.

## Où est-ce utilisé

Il est fréquemment utilisé pour automatiser des tâches de routine en administration système, créer des interfaces interactives dans les navigateurs Web et dans les flux de travail d'analyse de données.

## Souvent confondu avec

Il est confondu avec les langages de programmation système. Alors que les langages système tels que C ou Rust sont compilés directement au niveau du matériel pour des performances élevées, les langages de script sont axés sur la praticité et la vitesse de développement.

## Questions et réponses

**Les langages de script sont-ils lents ?**

Ils sont généralement plus lents en termes de puissance de calcul pure par rapport aux langages directement compilés, mais grâce aux optimisations modernes, ils sont largement suffisants pour la plupart des tâches quotidiennes et des applications Web.

**Python est-il un langage de script ?**

Oui, Python est à la fois un langage de programmation à usage général et un langage de script puissant largement utilisé.
