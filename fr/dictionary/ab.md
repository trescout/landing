# Qu'est-ce que ab ?

> ApacheBench

Un outil de test de performance simple permettant de mesurer combien d'utilisateurs un serveur Web peut gérer simultanément.

## Définition
ab est un outil de ligne de commande classique utilisé pour tester la résilience de vos serveurs web. Il vous permet d'envoyer des milliers de requêtes virtuelles simultanées à votre serveur pour voir quand il ralentira ou tombera en panne. Il est particulièrement vital pour comprendre la capacité avant de mettre en ligne un nouveau site.

## Comment ça marche
Vous l'exécutez en ouvrant l'écran du terminal et en saisissant l'adresse web que vous souhaitez tester ainsi que le nombre de requêtes que vous souhaitez envoyer. Une fois le test terminé, l'outil vous indique combien de requêtes par seconde ont été traitées.

## Où est-ce utilisé
Il est fréquemment utilisé dans les configurations de serveurs web, les tests de performance et les processus d'optimisation système.

## Souvent confondu avec
À ne pas confondre avec des outils de test de charge avancés ou des automatisations de navigateur réelles, il mesure purement la vitesse brute du serveur.

## Questions fréquentes
**Reflète-t-il exactement le trafic utilisateur réel ?**
Non, il envoie uniquement des requêtes HTTP de base et ne simule pas les opérations JavaScript sur le navigateur.
