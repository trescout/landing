# Qu'est-ce que Core Libraries ?

Il s'agit de packages de codes standard dont un logiciel a besoin pour exécuter ses fonctions de base.

## Définition
Les bibliothèques principales sont des bibliothèques de codes prêtes à l'emploi qui contiennent les éléments constitutifs les plus élémentaires d'un langage ou d'une plate-forme de programmation. Ces bibliothèques permettent aux développeurs d'effectuer rapidement des opérations standard au lieu d'écrire du code à partir de zéro à chaque fois. Comme les colonnes de fondation d’un bâtiment, ce sont des éléments indispensables qui assurent la survie et le bon fonctionnement du logiciel.

## Comment ça marche
En incluant ces bibliothèques dans leurs projets, les développeurs peuvent gérer des opérations mathématiques complexes, la gestion des données ou des opérations sur les fichiers avec des commandes sur une seule ligne.

## Où est-ce utilisé
Il est utilisé dans presque tous les langages de programmation et développements de systèmes d’exploitation.

## Souvent confondu avec
Il peut être confondu avec Framework ou SDK, mais les bibliothèques principales font référence aux fonctionnalités de base et les frameworks font référence à un squelette d'application plus large.

## Questions fréquentes
**Pourquoi les bibliothèques principales sont-elles importantes ?**
Il accélère le processus de développement logiciel, réduit les erreurs et garantit un fonctionnement du code plus stable.
