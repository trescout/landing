# Qu'est-ce que Text Extraction ?

Il s'agit du processus de conversion de données écrites dans des documents numériques ou des images au format texte que l'ordinateur peut traiter.

## Définition
Ce processus transfère le texte sur une feuille de papier ou le texte d'un fichier image vers un document texte numérique. Pour les ordinateurs, une image n’est constituée que de pixels colorés ; Grâce à cette technologie, ces pixels sont transformés en mots significatifs.

## Comment ça marche
Le document entre dans le système, l'IA ou les algorithmes de reconnaissance de caractères font correspondre les pixels aux lettres et vous donnent un texte modifiable.

## Où est-ce utilisé
Il est utilisé dans le traitement des factures, les systèmes d’authentification et la numérisation des archives existantes.

## Souvent confondu avec
C'est presque la même chose que l'OCR ; Alors que l’extraction de texte est le nom général de ce processus, l’OCR est le nom de la technologie utilisée.

## Questions fréquentes
**Peut-il lire l'écriture manuscrite ?**
Avec les modèles modernes, oui, mais la lisibilité du texte influe directement sur la qualité du résultat.
