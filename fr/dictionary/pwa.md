# Qu'est-ce que PWA ?

> Progressive Web App

Ce sont des pages Web qui fonctionnent via un navigateur Internet mais qui peuvent être installées sur votre téléphone ou votre ordinateur comme une application.

## Définition
La technologie PWA fournit des fonctionnalités de type application aux sites Web. Ils ont la possibilité de travailler hors ligne, d'envoyer des notifications et d'accéder au matériel de l'appareil. Il peut être installé directement depuis le navigateur sans avoir besoin d'une boutique d'applications supplémentaire.

## Comment ça marche
Développez un site Web et ajoutez-y un petit fichier d'arrière-plan appelé « service worker ». Lorsque l'utilisateur visite votre site, il peut installer l'application en cliquant sur « Ajouter à l'écran d'accueil » via le navigateur.

## Où est-ce utilisé
Il est fréquemment utilisé dans les sites d’actualités, les plateformes de commerce électronique et les applications de widgets simples.

## Souvent confondu avec
À ne pas confondre avec les applications natives ; PWA est en fait un site Web.

## Questions fréquentes
**Est-il téléchargé depuis l'App Store ?**
Non, il se charge directement via le navigateur.

**Est-ce que ça fonctionnera si je n'ai pas Internet ?**
Oui, grâce à la fonction de mise en cache, les fonctions de base peuvent fonctionner même s'il n'y a pas d'Internet.
