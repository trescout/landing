Qu'est-ce que RAM ?

Random Access Memory

La RAM (Random Access Memory) est la mémoire temporaire dans laquelle le processeur conserve les données actives.

Définition et origine du mot

Son contenu est supprimé lorsque l'ordinateur est éteint, mais comme il est proche du processeur, il fonctionne à une vitesse très élevée. Le processeur extrait les fichiers ici tout en travaillant. Lorsque les programmes sont ouverts, ils sont copiés du disque vers la RAM.

Analogie : C'est comme un bureau d'ordinateur ; À mesure que le tableau s'agrandit, le nombre de fichiers ouverts simultanément augmente.

Comment connaître et utiliser dans la vie quotidienne ?

Ordinateur: Onglets et applications.
Téléphone : Applications en arrière-plan.
Présentateur: Demandes simultanées.

Profondeur technique et architecture

Types :

DRAME: La mémoire principale est dense et bon marché.
SRAM : Le cache est rapide et coûteux.
Échanger: L'espace libre alloué à partir du disque le ralentit.

Vérification de l'état :

free -h

Règle : Lorsqu'il est plein, le système ralentit ou l'application se ferme. 8 Go c'est basique, 16 Go c'est confortable, 32 Go c'est station de travail. Une capacité excessive reste inutilisée.

Choses fréquemment mélangées

C’est considéré comme du stockage. La RAM est un espace de travail temporaire, le disque est une bibliothèque permanente. Lorsqu'il s'arrête, la RAM est vidée et le disque reste.

Utilisation dans différentes disciplines

Tableau: Le nombre de fichiers ouverts augmente à mesure que la largeur augmente.
Rester: Garder le matériel à portée de main.
Tableau blanc : Zone de notes temporaire.

Foire aux questions

Que se passe-t-il si la RAM est pleine ?

Le système ralentit ou les applications se ferment. Les onglets inutiles sont fermés et la capacité est augmentée si nécessaire.

Est-ce que trop l'accélère ?

Oui, il attend inactif aussi longtemps que nécessaire. Si le goulot d'étranglement est le disque, l'augmentation de la RAM n'a pas d'importance.

Quelle est la différence entre les SSD ?

Le SSD est un stockage permanent, la RAM est un espace temporaire. Les deux travaillent ensemble, l’un ne remplace pas l’autre.

Combien suffit-il ?

8 Go pour le travail quotidien, 16 Go pour le développement et 32 ​​Go pour les gros travaux sont des équivalents pratiques.
