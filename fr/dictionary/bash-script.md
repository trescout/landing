# Qu'est-ce que Bash Script ?

Il s'agit d'une séquence de commandes qui automatise les opérations en plusieurs étapes qui doivent être effectuées sur l'ordinateur en les rassemblant dans un seul fichier.

## Définition
Le script Bash vous permet de combiner les commandes que vous tapez une par une sur la ligne de commande de l'ordinateur et de les stocker dans un seul fichier. Lorsque vous exécutez ce fichier, toutes les commandes qu'il contient sont exécutées séquentiellement et sans erreur. C'est l'un des plus grands assistants des développeurs de logiciels, notamment pour accélérer les tâches répétitives.

## Comment ça marche
Vous ouvrez un fichier texte et écrivez les commandes que vous souhaitez exécuter les unes sous les autres. Une fois que vous avez enregistré le fichier et l'avez rendu exécutable, vous démarrez l'ensemble du processus avec un simple clic ou une simple commande.

## Où est-ce utilisé
Il est fréquemment utilisé dans la gestion de serveurs, les opérations de sauvegarde ou les processus d'installation de logiciels.
