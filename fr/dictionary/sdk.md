# Qu'est-ce que SDK ?

*Glossaire · Dev · Dernière mise à jour : 16 juin 2026*

> Software Development Kit

Il s'agit d'un ensemble d'outils et de bibliothèques qui permettent aux développeurs de logiciels de développer plus facilement des applications pour une plate-forme spécifique.

## Définition

Le SDK est une sorte de kit de développement. Il contient des outils, des documents et des exemples de codes prêts à l'emploi qui vous facilitent l'écriture de code. Au lieu de tout écrire à partir de zéro pour utiliser les fonctionnalités d’une plateforme, vous combinez les pièces toutes faites que propose ce kit.

***Analogie :** Il s'agit d'un coffret armoire que vous achetez chez une marque de meubles ; Il contient non seulement des planches, mais aussi des vis, une clé Allen et un guide de montage. Le SDK est cette boîte qui contient tout ce dont vous avez besoin pour créer un logiciel.*

## Comment ça marche

Le développeur télécharge le SDK correspondant sur son ordinateur et référence ces outils lors du codage. Ainsi, il peut gérer des opérations complexes avec des commandes sur une seule ligne.

## Où est-ce utilisé

Il est utilisé lors du développement d'applications mobiles, en intégrant un modèle d'intelligence artificielle dans votre propre application ou dans des moteurs de jeux.

## Souvent confondu avec

Mélangé avec API ; L'API est une porte, le SDK est la boîte à outils complète qui vous permet de franchir cette porte et d'installer la maison.

## Questions fréquentes

**Tous les SDK sont-ils gratuits ?**

La plupart sont gratuits, mais certaines plates-formes spécifiques peuvent facturer des frais de licence pour l'utilisation du SDK.

**Une application ne peut-elle pas être écrite sans SDK ?**

Cela peut être écrit, mais il faut tout coder à partir de zéro, ce qui prend trop de temps.
