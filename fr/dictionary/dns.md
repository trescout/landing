# Qu'est-ce que DNS ?

*Développement · Dernière mise à jour : 23 octobre 2026*

> Domain Name System

C'est un système d'annuaire mondial qui traduit les noms de domaine Internet en adresses IP numériques permettant aux ordinateurs de se trouver les uns les autres.

## Définition

Le système des noms de domaine (DNS) est un protocole réseau qui permet d'utiliser des noms de sites Web significatifs au lieu d'adresses IP complexes que les humains auraient du mal à mémoriser. Lorsque vous tapez une adresse dans votre navigateur, les serveurs DNS entrent en action pour faire correspondre ce nom à l'adresse IP du bon serveur. En tant que l'une des pierres angulaires de l'infrastructure d'Internet, il garantit une communication ininterrompue.

***Analogie :** Cela ressemble à la recherche du nom d'une personne dans un répertoire téléphonique pour obtenir son numéro et passer l'appel via ce numéro.*

## Comment ça marche

Lorsqu'un utilisateur saisit un nom de domaine dans le navigateur, la requête est d'abord transmise au cache DNS local, puis progressivement aux serveurs DNS faisant autorité. Lorsque la bonne adresse IP est trouvée, elle est renvoyée au navigateur et la connexion est établie. Ce processus de requête s'achève généralement en quelques millisecondes.

## Où est-ce utilisé

Il est utilisé lors de l'accès aux sites Web, dans les infrastructures de transmission d'e-mails et dans le routage entre les serveurs cloud.

## Souvent confondu avec

Il est confondu avec le concept d'adresse IP. L'adresse IP est l'identité numérique réelle de l'appareil, tandis que le DNS est le système qui associe cette identité à des noms lisibles par l'homme.

## Questions et réponses

**Peut-on accéder à Internet si le DNS tombe en panne ?**

Les noms de domaine ne peuvent pas être résolus, mais si les adresses IP directes des sites sont connues, l'accès est possible via le navigateur.

**Qu'est-ce que le cache DNS ?**

C'est le stockage temporaire sur l'appareil des adresses IP des sites fréquemment visités, éliminant ainsi le besoin d'interroger le serveur à chaque fois.
