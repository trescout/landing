# Qu'est-ce que Common Libraries ?

*Glossaire · Dev · Dernière mise à jour : 12 juillet 2026*

Packages de code pré-préparés afin que les développeurs de logiciels puissent facilement effectuer les opérations fréquemment utilisées.

## Définition

Ce sont des solutions toutes faites permettant d’éviter de réinventer la roue à chaque fois lors du développement d’un logiciel. Ces bibliothèques vous permettent d'effectuer de nombreuses tâches complexes, des opérations mathématiques à la gestion de fichiers, avec une seule commande. L’ajouter à votre projet permet de gagner du temps et réduit le risque d’erreurs.

***Analogie :** C'est comme utiliser des pots à épices prêts à l'emploi du marché au lieu de fabriquer des épices à partir de zéro à chaque fois dans la cuisine.*

## Comment ça marche

Vous incluez la bibliothèque dont vous avez besoin dans votre projet et appelez les fonctions prêtes à l'emploi dans votre propre code.

## Où est-ce utilisé

Il est utilisé dans presque tous les projets logiciels, tels que le traitement de données, les connexions réseau ou la création d'interfaces visuelles.

## Souvent confondu avec

Il peut être confondu avec Framework ; Le framework dessine le squelette du projet, et la bibliothèque vous propose uniquement l'outil dont vous avez besoin.

## Questions fréquentes

**Toutes les bibliothèques sont-elles sûres ?**

Non, comme tout code externe, la mise à jour et la fiabilité des bibliothèques doivent être vérifiées.

**Puis-je créer ma propre bibliothèque ?**

Oui, vous pouvez regrouper les codes que vous utilisez fréquemment et les réutiliser dans vos autres projets.
