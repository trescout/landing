# Qu'est-ce que Control Plane ?

*Glossaire · Dev · Dernière mise à jour : 31 août 2026*

Il s'agit de la couche de gestion centrale qui régit le fonctionnement d'un système et contrôle le trafic ainsi que les paramètres.

## Définition

Dans les grands systèmes, on distingue l'endroit où le travail est effectué (plan de données) de l'endroit où l'on décide de la manière dont ce travail doit être effectué (plan de contrôle). Le plan de contrôle est comme le cerveau du système ; il gère les données qui circulent, les autorisations et l'état général du système.

***Analogie :** Si, dans un aéroport, les pistes où les avions volent représentent le plan de données, la tour de contrôle qui définit les itinéraires de vol et gère le trafic de décollage et d'atterrissage est le plan de contrôle.*

## Comment ça marche

Les règles sont définies via un logiciel ou une interface centralisée. Ces règles sont transmises aux autres parties du système pour assurer la continuité opérationnelle.

## Où est-ce utilisé

On le trouve dans les architectures de cloud computing, les systèmes de gestion de réseau et les centres de données à grande échelle.

## Souvent confondu avec

Il peut être confondu avec le plan de données ; l'un gère, l'autre exécute le travail.

## Questions fréquentes

**Que se passe-t-il s'il tombe en panne ?**

Le système devient incapable de recevoir de nouvelles commandes ou de gérer le trafic, c'est pourquoi il est généralement protégé par une très haute disponibilité.
