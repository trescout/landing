# Qu'est-ce que ROM ?

*Glossaire · Dev · Dernière mise à jour : 4 juillet 2026*

> Read-Only Memory

Il s'agit d'un type de mémoire permanente en lecture seule qui préserve les informations qu'elle contient même lorsque l'ordinateur est éteint.

## Définition

La ROM contient les instructions de base nécessaires pour allumer l'ordinateur ou l'appareil. Ce type de mémoire est conçu pour stocker des données de manière permanente et ne peut pas être facilement modifié par l'utilisateur lors d'une utilisation normale. C'est là que le « cerveau » de l'appareil sait quoi faire lorsqu'il se réveille pour la première fois.

***Analogie :** C'est comme la version imprimée d'un livre ; Vous pouvez lire le texte à l’intérieur, mais vous ne pouvez pas supprimer ou réécrire les pages.*

## Comment ça marche

Lorsque vous appuyez sur le bouton d'alimentation de l'appareil, le processeur lit d'abord les instructions dans la ROM. Ces instructions vous indiquent comment le système d'exploitation doit être installé.

## Où est-ce utilisé

On le retrouve dans les écrans de démarrage des smartphones, des cartes mères d’ordinateurs et des systèmes embarqués.

## Souvent confondu avec

Il est mélangé à la RAM ; La RAM est temporaire et est supprimée lorsque l'ordinateur est éteint, tandis que la ROM est permanente.

## Questions fréquentes

**Pourquoi les informations dans la ROM ne peuvent-elles pas être modifiées ?**

Parce que les règles de fonctionnement de base de l’appareil sont protégées pour éviter toute suppression accidentelle ou corruption.
