# Qu'est-ce que Web-based Solutions ?

*Glossaire · Dev · Dernière mise à jour : 15 juillet 2026*

Il s'agit de services logiciels auxquels vous pouvez accéder et utiliser uniquement via un navigateur Internet, sans aucune installation sur votre ordinateur.

## Définition

Les solutions basées sur le Web sont des logiciels dans lesquels toutes les données et tous les traitements ont lieu sur un serveur distant. L'utilisateur se connecte à ce système via le navigateur et agit comme s'il était installé sur son ordinateur. De cette façon, il ne prend pas de place dans la mémoire de votre appareil et est accessible de n'importe où.

***Analogie :** C'est comme s'inscrire à une bibliothèque numérique et lire des livres en ligne, plutôt que de conserver un livre dans votre propre bibliothèque ; Vous n’avez pas besoin d’emporter le livre avec vous.*

## Comment ça marche

Vous accédez à une adresse de site Web, vous connectez et l'application commence à s'exécuter dans votre navigateur. Étant donné que toutes les mises à jour sont effectuées côté serveur, vous n’avez rien à installer de plus.

## Où est-ce utilisé

Il est largement utilisé dans les services de messagerie, les éditeurs de documents en ligne et les outils professionnels basés sur le cloud.

## Souvent confondu avec

Peut être confondu avec les applications de bureau ; Les applications de bureau occupent de l'espace physique sur l'appareil, tandis que les applications Web s'exécutent dans le navigateur.

## Questions fréquentes

**Puis-je utiliser l’application si mon internet est coupé ?**

Généralement non, car l'application et les données se trouvent sur le serveur. Cependant, certaines applications modernes peuvent offrir la possibilité de travailler hors ligne.

**Est-ce sécuritaire?**

Puisque vos données se trouvent sur le serveur, cela dépend des mesures de sécurité de l'entreprise fournissant le service.
