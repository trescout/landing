# Qu'est-ce que Graph-native Infrastructure ?

Il s'agit d'une structure spéciale de stockage de données conçue sur la base de connexions directes entre les données.

## Définition
Contrairement aux tables traditionnelles, ce système conserve les données sous forme de nœuds et de lignes interconnectés. Les relations entre les informations sont aussi importantes que les données elles-mêmes. De cette manière, des analyses de réseau complexes peuvent être réalisées très rapidement.

## Comment ça marche
Les données sont liées entre elles par des pointeurs, vous n'avez donc pas besoin de parcourir toute la liste pour passer d'une donnée à une autre.

## Où est-ce utilisé
Il est utilisé dans l'analyse des réseaux sociaux, les systèmes de détection de fraude et les graphiques de connaissances complexes.

## Souvent confondu avec
A ne pas confondre avec les bases de données relationnelles classiques (SQL) ; car ici, la relation ne fait pas partie du tableau, mais la base de la structure.

## Questions fréquentes
**Pourquoi devrais-je choisir cette structure ?**
Cette structure est beaucoup plus rapide si vous devez interroger des relations profondes et complexes entre des données en quelques secondes.
