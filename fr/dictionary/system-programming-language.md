# Qu'est-ce que System Programming Language ?

Il s'agit d'un langage puissant utilisé pour développer des logiciels de base tels qu'un système d'exploitation ou un pilote matériel.

## Définition
Ce sont des langages capables de communiquer directement avec le matériel de l'ordinateur et d'offrir un contrôle total sur la gestion de la mémoire. Ils sont très rapides mais moins tolérants aux erreurs.

## Comment ça marche
Ces langages permettent de gérer dans les moindres détails le fonctionnement du matériel.

## Où est-ce utilisé
Il est utilisé dans les systèmes d'exploitation (Windows, Linux), les moteurs de jeux et les serveurs hautes performances.

## Souvent confondu avec
À ne pas confondre avec les langages Web ; Alors que les langages Web traitent davantage de l’interface utilisateur, ceux-ci s’occupent du matériel.

## Questions fréquentes
**Quelles langues entrent dans cette catégorie ?**
C, C++ et Rust en sont les exemples les plus connus.

**Pourquoi tout le monde n’utilise-t-il pas ces langues ?**
C’est difficile à apprendre et nécessite un codage très minutieux.
