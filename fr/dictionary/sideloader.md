# Qu'est-ce que Sideloader ?

*Glossaire · Dev · Dernière mise à jour : 12 septembre 2026*

Il s'agit d'un outil ou d'une méthode permettant d'installer des applications sur votre appareil directement à partir d'un fichier, en dehors des magasins d'applications officiels.

## Définition

Normalement, vous utilisez des portails officiels comme l'Apple App Store ou Google Play pour installer des applications sur un téléphone ou un ordinateur. Le sideloader contourne ces portails, vous permettant d'installer manuellement un fichier d'application téléchargé sur Internet sur votre appareil. Cette méthode est utilisée pour accéder à des logiciels qui ne sont pas disponibles dans les magasins officiels ou qui n'ont pas encore été approuvés.

***Analogie :** Si les magasins officiels sont l'entrée principale d'un bâtiment, le sideloader revient à entrer dans le bâtiment par une fenêtre ou par la porte dérobée.*

## Comment ça marche

Vous devez activer l'option « autoriser l'installation à partir de sources inconnues » dans les paramètres de votre appareil. Ensuite, vous lancez le processus d'installation en ouvrant le fichier d'installation que vous avez téléchargé sur Internet (par exemple, .apk pour Android).

## Où est-ce utilisé

On le trouve fréquemment sur les téléphones Android, dans les applications en phase de test des développeurs de logiciels spécialisés, ou sur les appareils des utilisateurs souhaitant contourner les restrictions.

## Souvent confondu avec

Peut être confondu avec le sideloading (l'action d'installer).

## Questions fréquentes

**L'utilisation d'un sideloader est-elle sûre ?**

Comme il n'y a pas de contrôle de sécurité des magasins officiels, vous devez faire très attention à la source du fichier que vous téléchargez.

**Fonctionne-t-il sur tous les appareils ?**

Il fonctionne sur la plupart des systèmes ouverts, mais sur les systèmes fermés comme celui d'Apple, des autorisations spéciales ou un jailbreak peuvent parfois être nécessaires.
