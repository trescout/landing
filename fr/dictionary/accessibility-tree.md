# Qu'est-ce que Accessibility Tree ?

*Développement · Dernière mise à jour : 4 novembre 2026*

La structure hiérarchique créée par le système d'exploitation pour expliquer les éléments à l'écran aux technologies d'assistance.

## Définition

L'arbre d'accessibilité est une carte compréhensible par ordinateur des boutons, des textes et des images présents à l'écran. Les lecteurs d'écran utilisés par les malvoyants lisent cet arbre pour vocaliser ce qui se trouve à l'écran. Récemment, les agents d'intelligence artificielle utilisent également cet arbre directement pour comprendre l'écran.

***Analogie :** C'est similaire à une carte en relief tactile imprimée pour les aveugles dans un bâtiment. Alors qu'une personne voyante observe directement le bâtiment, cette carte résume la structure du bâtiment et l'emplacement des portes.*

## Comment ça marche

Le système d'exploitation et les navigateurs convertissent l'interface visuelle en arrière-plan en un format d'arbre textuel et structurel. Les logiciels ou les robots d'intelligence artificielle parcourent cet arbre pour détecter les zones cliquables à l'écran.

## Où est-ce utilisé

Il joue un rôle dans les logiciels de lecture d'écran, les outils d'automatisation et les agents d'intelligence artificielle qui contrôlent l'ordinateur en lisant les éléments à l'écran plutôt qu'avec une souris.

## Souvent confondu avec

Il est confondu avec le code source HTML. Le code source est la structure brute du site ; l'arbre d'accessibilité est l'état visible que le navigateur ou le système filtre et organise pour l'accessibilité.

## Questions et réponses

**Pourquoi l'intelligence artificielle utilise-t-elle l'arbre d'accessibilité ?**

Plutôt que d'analyser les pixels visuels un par un, lire directement les textes structurés est beaucoup plus rapide et sans erreur pour l'intelligence artificielle.

**Pourquoi est-ce important lors du développement d'un site Web ?**

Une structure correctement étiquetée garantit à la fois l'accès aux personnes handicapées et constitue une base pour que les outils d'intelligence artificielle comprennent correctement la page.
