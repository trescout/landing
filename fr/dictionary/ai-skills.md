# Qu'est-ce que AI Skills ?

> Skills

Capacités ou outils spéciaux que les modèles d'IA utilisent pour effectuer une tâche spécifique.

## Définition
Il s’agit de capacités ou d’outils spéciaux que les modèles d’intelligence artificielle utilisent pour effectuer une tâche spécifique. Ces capacités permettent au modèle d'effectuer des tâches concrètes, telles que rechercher sur Internet ou exécuter du code, plutôt que de simplement produire du texte.

## Comment ça marche
Le modèle apprend à utiliser des jeux de commandes spéciaux ou des outils définis pour lui. Il déclenche ces outils en cas de besoin, traite les données et présente le résultat à l'utilisateur.

## Où est-ce utilisé
Il est utilisé dans les assistants intelligents, les outils d’analyse de données et les logiciels qui automatisent des tâches complexes.

## Souvent confondu avec
Elle est souvent confondue avec les capacités générales de l’IA, mais il s’agit d’outils spécialisés ajoutés pour effectuer un travail spécifique.

## Questions fréquentes
**Chaque modèle d’IA possède-t-il des compétences en IA ?**
Non, seuls les modèles équipés de ces capacités ou autorisés à rouler disposent de ces capacités.

**Ces compétences peuvent-elles être ajoutées ultérieurement ?**
Oui, de nouvelles fonctionnalités peuvent être ajoutées à un modèle avec l’infrastructure et les connexions API appropriées.
