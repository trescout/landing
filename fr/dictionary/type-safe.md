# Qu'est-ce que Type-safe ?

*Glossaire · Dev · Dernière mise à jour : 9 juillet 2026*

C'est une discipline qui garantit le fonctionnement sûr des logiciels en empêchant une utilisation incorrecte des types de données.

## Définition

Il nécessite que seules les données du type spécifié soient saisies dans une variable. Par exemple, si vous essayez de saisir du texte là où un nombre est attendu, le système le remarquera avant même que vous ne l'exécutiez. Cela évite les erreurs les plus courantes dans le processus de développement logiciel.

***Analogie :** C'est comme une boîte aux lettres qui n'accepte que les lettres mais ne vous permet pas de déposer des colis ou des déchets ; Les règles sont claires dès le début et vous ne pouvez pas commettre d’erreurs.*

## Comment ça marche

Lorsque vous écrivez du code, vous définissez les types de variables (telles que le nombre, le texte, la date). Lorsque vous exécutez ou compilez le logiciel, le système vous avertit s'il détecte quelque chose qui ne répond pas à ces définitions.

## Où est-ce utilisé

Il est utilisé pour réduire la marge d'erreur dans les langages de programmation modernes et les projets logiciels à grande échelle.

## Questions fréquentes

**Quel est l’avantage d’être de type sécurisé ?**

Le code est moins susceptible de planter au moment de l'exécution et devient plus sécurisé.

**Est-il disponible dans toutes les langues ?**

Non, certaines langues sont plus flexibles, certaines ont des règles strictes.
