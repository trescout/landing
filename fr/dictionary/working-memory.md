# Qu'est-ce que Working Memory ?

Il s’agit de la zone de mémoire à court terme où l’intelligence artificielle conserve temporairement les informations pendant leur traitement.

## Définition
La mémoire de travail est l'endroit où l'IA maintient actifs le contexte actuel et les données nécessaires lors de l'exécution d'une tâche. Ces informations sont généralement effacées lorsque la tâche est terminée ou que le contexte change.

## Comment ça marche
Cela se produit lorsque le modèle conserve les données d'entrée et les résultats intermédiaires dans sa mémoire pour un accès rapide dans le cycle de traitement en cours.

## Où est-ce utilisé
Il est utilisé pour préserver l’historique des discussions et les processus de raisonnement complexes.

## Souvent confondu avec
Sa différence avec la mémoire à long terme est qu'elle est limitée uniquement à la tâche en cours.

## Questions fréquentes
**Que se passe-t-il si la mémoire de travail est pleine ?**
Le modèle commence à oublier les anciennes informations ou peut perdre son contexte.
