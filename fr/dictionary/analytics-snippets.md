# Qu'est-ce que Analytics Snippets ?

*Glossaire · Data · Dernière mise à jour : 17 août 2026*

Il s'agit de petits morceaux de code que les sites Web ajoutent à leurs pages pour suivre le comportement des visiteurs.

## Définition

Un extrait d'analyse est un morceau de code placé sur un site Web qui enregistre où les visiteurs sont arrivés sur le site et combien de temps ils ont passé sur quelles pages. Ces données aident les propriétaires de sites à améliorer leurs sites. Il s'exécute généralement silencieusement en arrière-plan de la page.

***Analogie :** C'est comme un compteur invisible placé à la porte d'un magasin qui note combien de personnes entrent et dans quelles allées elles s'arrêtent.*

## Comment ça marche

Le propriétaire du site ajoute ce shortcode reçu du service d'analyse aux fichiers sources du site Internet. Lorsque l'utilisateur ouvre la page, le code s'exécute et envoie les informations de visite au serveur d'analyse.

## Où est-ce utilisé

Il est produit sur des plateformes telles que Google Analytics et placé dans les codes HTML des sites Internet.

## Souvent confondu avec

Il est souvent confondu avec les cookies ; Alors que les cookies conservent les données dans votre navigateur, l'extrait est l'outil qui collecte les données et les envoie au serveur.

## Questions fréquentes

**Ces codes voleront-ils mes informations personnelles ?**

Ils collectent souvent des données anonymes ; cependant, les sites doivent être transparents sur la manière dont ils utilisent ces données.

**Pourquoi est-ce présent sur tous les sites ?**

Les propriétaires de sites souhaitent offrir une meilleure expérience en mesurant ce que les utilisateurs aiment et n'aiment pas.
