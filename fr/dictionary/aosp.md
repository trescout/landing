# Qu'est-ce que AOSP ?

> Android Open Source Project

Il s'agit de la version de base du système d'exploitation Android utilisé sur les smartphones, ouverte à l'accès et au développement par tous.

## Définition
Google a rendu le code source de base d'Android accessible à tous. Les fabricants de téléphones prennent ce code de base et y ajoutent leurs propres fonctionnalités, interfaces et applications avant de l'installer sur leurs appareils. En d'autres termes, l'AOSP est le cœur d'Android, mais il ne contient pas les applications propriétaires de Google (comme le Play Store).

## Comment ça marche
Les développeurs peuvent télécharger ces codes, les adapter à leurs propres appareils, corriger les erreurs ou créer un tout nouveau système d'exploitation.

## Où est-ce utilisé
Il est utilisé sur les smartphones, les tablettes et les appareils Android spécialisés.

## Souvent confondu avec
Il peut être confondu avec la version d'Android proposée par Google ; la version de Google inclut des services propriétaires ajoutés par-dessus l'AOSP.

## Questions fréquentes
**Si j'utilise l'AOSP, aurai-je le Play Store ?**
Non, les services Google sont soumis à une licence distincte, l'AOSP n'est que le système d'exploitation de base.
