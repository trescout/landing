# Qu'est-ce que Terminal File Manager ?

*Glossaire · Dev · Dernière mise à jour : 27 juillet 2026*

Un outil qui vous permet de gérer vos fichiers uniquement via la ligne de commande au lieu de fenêtres visuelles.

## Définition

Ces outils vous permettent de copier, déplacer ou supprimer des fichiers avec des raccourcis clavier sans utiliser votre souris. Il permet d'opérer très rapidement sans le poids d'une interface graphique.

***Analogie :** C'est un système qui permet d'avoir le livre que l'on veut devant soi en appuyant simplement sur un bouton, au lieu de grimper sur les étagères avec une échelle dans une bibliothèque.*

## Comment ça marche

Vous ouvrez le terminal et exécutez le programme. Deux panneaux apparaissent à l'écran et vous pouvez naviguer entre les fichiers avec les touches fléchées du clavier.

## Où est-ce utilisé

Il est utilisé lors de la gestion de serveurs ou dans les processus de développement de logiciels où vous devez modifier des fichiers très rapidement.

## Souvent confondu avec

Il ne faut pas le confondre avec « shell », qui indique simplement les commandes ; Cet outil propose une interface d'édition visuelle.

## Questions fréquentes

**Est-ce difficile à apprendre ?**

La mémorisation des raccourcis peut prendre un certain temps au début, mais une fois que vous vous y êtes habitué, cela devient très rapide.

**Est-ce que ça marche sur tous les systèmes d'exploitation ?**

C'est généralement très courant sous Linux et macOS.
