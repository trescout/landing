# Qu'est-ce que Data Plane ?

*Développement · Dernière mise à jour : 14 novembre 2026*

Il s'agit de la couche d'infrastructure de base sur laquelle les données d'un réseau sont réellement transmises et acheminées.

## Définition

C'est l'autoroute principale par laquelle circule le trafic dans les systèmes de réseau. Alors que le centre de contrôle donne les ordres, le plan de données achemine les paquets réels vers leur destination conformément à ces ordres.

***Analogie :** Les voies où circulent les voitures sur l'autoroute représentent le plan de données, tandis que les feux de circulation et les panneaux constituent la couche de contrôle.*

## Comment ça marche

Il examine les paquets de données entrants, vérifie leurs adresses de destination et les achemine vers le prochain arrêt de la manière la plus rapide possible.

## Où est-ce utilisé

Il joue un rôle critique dans les routeurs, les commutateurs et les architectures de réseau cloud.

## Souvent confondu avec

Il est confondu avec le plan de contrôle (control plane) ; alors que le plan de contrôle définit les règles qui gèrent le trafic, le plan de données accomplit le travail réel, c'est-à-dire le transport des données.

## Questions et réponses

**Pourquoi le plan de données est-il important ?**

C'est le composant principal qui détermine directement les performances et la vitesse du réseau.
