# Qu'est-ce que Continuous Deployment ?

> CD

Les codes qui réussissent le test sont automatiquement mis en ligne sans aucune intervention humaine.

## Définition
C'est une méthode qui accélère le processus de développement logiciel. Dès que vous écrivez votre code, il passe des tests automatiques et, s'il n'y a aucun obstacle, il est téléchargé directement sur le système utilisé par les utilisateurs. Il garantit que le logiciel est constamment mis à jour en éliminant les processus d'approbation manuels.

## Comment ça marche
Le développeur soumet le code au système, le système exécute des tests automatisés et en cas de succès, le code est transféré au serveur en direct.

## Où est-ce utilisé
Applications Web modernes, plateformes SaaS et produits numériques nécessitant des mises à jour rapides.

## Souvent confondu avec
Peut être confondu avec Livraison continue ; En Livraison, la phase de mise en service peut nécessiter une approbation manuelle, alors qu'en Déploiement, elle est entièrement automatique.

## Questions fréquentes
**Que se passe-t-il si nous faisons une erreur ?**
Le système essaie de détecter l'erreur avant sa mise en ligne, grâce à des tests automatiques, mais cela comporte toujours des risques ; les tests doivent donc être très robustes.
