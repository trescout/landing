# Qu'est-ce que Local-first ?

Il s'agit d'une approche logicielle basée sur la conservation et le traitement des données sur l'appareil sans dépendre d'une connexion Internet.

## Définition
L'approche locale d'abord vise à stocker les données de l'utilisateur sur son propre appareil plutôt que sur des serveurs cloud. Même si Internet tombe en panne, l'application continue de fonctionner et les données restent en sécurité sur l'appareil. Lorsque Internet est activé, les appareils se synchronisent entre eux et mettent à jour les données.

## Comment ça marche
L'application écrit les données dans une base de données locale et fait correspondre ces données avec le serveur ou d'autres appareils en arrière-plan lorsqu'il existe une connexion Internet.

## Où est-ce utilisé
Il est utilisé dans les applications de prise de notes, les outils d’intelligence artificielle personnelle et les logiciels axés sur la confidentialité.

## Souvent confondu avec
On ne peut que le confondre avec le travail hors ligne ; Cependant, cette approche vise à préserver la capacité de synchronisation hors ligne.

## Questions fréquentes
**Que se passe-t-il si mes données et mon appareil sont corrompus ?**
Les applications locales peuvent souvent être sauvegardées dans le cloud de manière chiffrée, mais la priorité va toujours à la copie locale.
