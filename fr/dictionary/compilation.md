# Qu'est-ce que Compilation ?

Il s'agit du processus de conversion de codes écrits proches du langage humain en langage machine que le processeur de l'ordinateur peut comprendre.

## Définition
Les ordinateurs ne comprennent que les commandes composées de 0 et de 1. Les programmeurs, quant à eux, utilisent des langages hautement lisibles. Le processus de compilation relie ces deux mondes, transformant le code en un fichier exécutable.

## Comment ça marche
Un logiciel spécial appelé compilateur analyse votre code source, recherche les erreurs et le convertit en un format binaire que le processeur peut exécuter directement.

## Où est-ce utilisé
C'est une étape incontournable avant d'exécuter le programme dans des langages tels que C++, Rust et Java.

## Souvent confondu avec
La différence avec les langages interprétés est que le code est complètement transformé avant l'exécution, et non au moment de l'exécution.

## Questions fréquentes
**Est-ce que tous les langages doivent être compilés ?**
Non, certains langages, comme Python, exécutent le code instantanément, ligne par ligne, sans nécessiter de processus de compilation.
