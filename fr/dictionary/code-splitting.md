# Qu'est-ce que Code Splitting ?

Afin d'augmenter la vitesse de chargement du site Web, il s'agit d'une méthode permettant de diviser les gros fichiers de code en petits morceaux et de les charger uniquement en cas de besoin.

## Définition
Lorsque l'utilisateur accède à votre site, au lieu de télécharger tous les codes, il télécharge uniquement les codes requis pour la page qu'il consulte actuellement. Les codes des autres pages sont chargés en arrière-plan lorsque l'utilisateur clique sur ces pages.

## Comment ça marche
Le développeur fait des marques dans le code telles que « charger cette partie maintenant, charger le reste plus tard ».

## Où est-ce utilisé
Il est utilisé dans des applications Web à grande échelle et des sites soucieux de l’expérience utilisateur.

## Souvent confondu avec
Peut être confondu avec le regroupement ; Alors que le regroupement combine les fichiers, le fractionnement du code les sépare intelligemment en morceaux.

## Questions fréquentes
**Y aura-t-il un délai lorsque l’utilisateur clique sur la page ?**
Cela peut prendre très peu de temps, mais l'expérience globale est meilleure car la vitesse de chargement initiale est beaucoup plus rapide.
