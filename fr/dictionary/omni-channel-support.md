# Qu'est-ce que Omni-channel Support ?

C'est la structure de support qui permet aux clients d'atteindre une marque de manière ininterrompue et connectée via tous les canaux.

## Définition
Cette approche vise à garantir que l'expérience du client ne soit pas perturbée lors du basculement entre différents canaux tels que les réseaux sociaux, l'e-mail ou le magasin. Étant donné que tous les canaux sont interconnectés, une demande d’assistance démarrée sur un canal peut continuer là où elle s’est arrêtée sur l’autre canal. Pour le client, la marque agit comme un tout.

## Comment ça marche
Les entreprises regroupent tous les canaux de communication en un seul système central. Ainsi, le représentant client peut voir instantanément ce que le client a précédemment écrit sur quel canal.

## Où est-ce utilisé
Il est utilisé sur les sites de commerce électronique, les applications bancaires et les grands centres de service client.

## Souvent confondu avec
Mixé avec un support multicanal ; Dans le support multicanal, les canaux sont indépendants les uns des autres, tandis que dans le support omnicanal, ils sont tous interconnectés.

## Questions fréquentes
**Pourquoi l’omnicanal est-il important ?**
Cela empêche le client d’expliquer encore et encore le même problème et augmente la confiance.

**Que faut-il pour mettre cela en place ?**
Une base de données centrale solide et une infrastructure logicielle intégrée qui alimente tous les canaux sont nécessaires.
