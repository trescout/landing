# Qu'est-ce que Agent Skills ?

Capacités ou outils spéciaux que les agents d'IA utilisent pour effectuer des tâches spécifiques.

## Définition
Les capacités des agents sont des fonctions spéciales qui permettent à une IA d'interagir avec le monde. Grâce à ces fonctionnalités, l'agent peut effectuer des recherches sur Internet, lire un fichier, exécuter du code ou envoyer un e-mail. Plus l’agent possède de capacités, plus il peut gérer seul des tâches complexes.

## Comment ça marche
L'agent analyse la tâche qui lui est assignée et décide quelle capacité est requise pour résoudre cette tâche. Ensuite, il déclenche cette capacité, effectue l’opération et évalue le résultat.

## Où est-ce utilisé
Il est utilisé dans les plates-formes d'agents d'IA, les outils d'automatisation et les processus de développement de logiciels.

## Souvent confondu avec
Il ne s’agit pas de l’intelligence générale de l’IA, mais uniquement de sa capacité à effectuer un travail spécifique.

## Questions fréquentes
**Est-ce que j'ajoute des capacités d'agent ?**
Oui, vous définissez généralement aux agents les outils qu'ils peuvent utiliser ou choisissez parmi des bibliothèques prêtes à l'emploi.

**Les capacités de chaque agent sont-elles les mêmes ?**
Non, ses fonctionnalités sont personnalisées en fonction de l'utilisation prévue de l'agent (par exemple, un agent qui analyse uniquement les données).
