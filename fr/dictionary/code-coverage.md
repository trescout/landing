# Qu'est-ce que Code Coverage ?

Une métrique qui mesure la quantité de tests logiciels de code écrit réellement exécutés et vérifiés.

## Définition
Nous écrivons des tests pour comprendre si chaque ligne de code que vous écrivez dans un projet logiciel fonctionne sans erreurs. La couverture du code calcule le pourcentage de votre code touché par ces tests. Un ratio élevé signifie que votre code est plus sécurisé et testé.

## Comment ça marche
Des outils de test automatisés sont exécutés pendant le processus de développement logiciel. Ces outils surveillent chaque ligne de votre code et marquent les lignes parcourues par le test. Enfin, il vous donne un rapport du type « 85 % du code testé ».

## Où est-ce utilisé
Il est utilisé dans les processus de développement de logiciels, les lignes CI/CD et les rapports de contrôle qualité.

## Questions fréquentes
**Une couverture de code à 100 % est-elle toujours bonne ?**
Non, cela montre simplement que le code fonctionne ; ne garantit pas la couverture des erreurs logiques ou de tous les scénarios.

**Comment puis-je mesurer cela ?**
Il peut être mesuré automatiquement avec des bibliothèques de tests adaptées au langage de programmation que vous utilisez (par exemple, cover.py pour Python).
