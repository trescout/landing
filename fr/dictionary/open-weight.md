# Qu'est-ce que Open Weight ?

Modèles d'intelligence artificielle dont la structure interne et les paramètres ont été rendus publics afin que les développeurs puissent les exécuter sur leurs propres appareils.

## Définition
Il s'agit du partage avec tout le monde des valeurs numériques (poids) considérées comme le « cerveau » d'un modèle d'intelligence artificielle. Cela vous permet de voir comment le modèle fonctionne et de l'installer et de l'utiliser sur votre propre ordinateur. Cependant, cela ne signifie pas que les données d'entraînement du modèle sont également ouvertes.

## Comment ça marche
Les développeurs téléchargent ces poids pour exécuter le modèle sur leurs propres serveurs ou ordinateurs locaux.

## Où est-ce utilisé
Utilisé dans les applications d'intelligence artificielle locales, les projets privés et les travaux de personnalisation de modèles.

## Souvent confondu avec
IA open source

## Questions fréquentes
**Quelle est la différence avec l'Open Source ?**
L'Open Source inclut généralement les données d'entraînement, tandis que l'Open Weight ne partage que la version finale du modèle.
