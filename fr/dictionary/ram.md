# Qu'est-ce que RAM ?

> Random Access Memory

Unité de mémoire temporaire dans laquelle l'ordinateur lit et écrit rapidement les données qu'il utilise activement.

## Définition
C'est un espace de travail où les données sont supprimées lorsque l'ordinateur est éteint, mais il fonctionne à une vitesse fulgurante car il est très proche du processeur. Le processeur extrait ici tous les fichiers dont il a besoin pour effectuer son travail.

## Comment ça marche
Lorsque les programmes sont ouverts, ils sont copiés du disque dur vers la RAM, le processeur reçoit et traite les données à partir de là.

## Où est-ce utilisé
Il s’agit d’un élément matériel essentiel de tous les ordinateurs, téléphones et serveurs.

## Souvent confondu avec
Mixé avec du stockage (HDD/SSD) ; La RAM est l'espace de travail temporaire tandis que le stockage est la bibliothèque permanente.

## Questions fréquentes
**Que se passe-t-il si la RAM est pleine ?**
L'ordinateur ralentit ou les applications se ferment.

**Est-ce que plus de RAM augmente toujours la vitesse ?**
Il l'augmente jusqu'au niveau requis et l'excédent reste inutilisé.
