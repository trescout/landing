# Qu'est-ce que Swift Package Manager ?

*Glossaire · Dev · Dernière mise à jour : 13 octobre 2026*

> Swift Package Manager

Outil permettant de gérer, de télécharger et de compiler des paquets de code écrits en langage Swift.

## Définition

SwiftPM est le gestionnaire de paquets officiel de l'écosystème Apple qui vous permet de garder organisées les bibliothèques et les projets ajoutés de l'extérieur lors du développement de logiciels. Il suit les codes externes dont dépend votre projet, télécharge ces codes sur Internet et les compile avec votre application. Ainsi, au lieu de tout écrire à partir de zéro, vous pouvez utiliser en toute sécurité des composants prêts à l'emploi écrits par d'autres.

***Analogie :** Il ressemble à un responsable d'entrepôt méthodique qui trie les pièces d'un grand ensemble Lego selon leurs boîtes et commande des pièces manquantes.*

## Comment ça marche

Vous commencez à travailler en ajoutant le fichier de définition de paquet dans le dossier de votre projet. Vous y écrivez les adresses des bibliothèques nécessaires. À l'aide de commandes de terminal ou via votre éditeur de code, vous assurez la mise à jour des paquets et leur intégration dans le projet.

## Où est-ce utilisé

Il sert d'outil fondamental dans les processus de développement d'applications macOS et iOS, ainsi que dans tous les projets logiciels utilisant le langage Swift.

## Souvent confondu avec

Il diffère des gestionnaires d'extensions généraux des éditeurs de code, se concentrant directement sur l'écosystème propre au langage et sur son processus de compilation.

## Questions fréquentes

**Comment SwiftPM accélère-t-il le projet ?**

Étant donné qu'il gère automatiquement les codes prêts à l'emploi, il élimine la corvée d'installation manuelle de bibliothèques de fichiers.

**Avec quels langages fonctionne-t-il ?**

Il est principalement utilisé dans les projets mixtes basés sur Swift et C/C++.
