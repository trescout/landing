# Qu'est-ce que Telemetry ?

Données techniques collectées automatiquement par le système concernant l'utilisation et les erreurs d'un logiciel.

## Définition
Il s'agit de rapports envoyés par les applications aux développeurs sur le fonctionnement du logiciel. Grâce à ces données, les développeurs peuvent comprendre quelles fonctionnalités sont les plus utilisées ou où l'application plante. Pour les utilisateurs, il s'agit généralement d'un flux de données qui s'exécute silencieusement en arrière-plan.

## Comment ça marche
De petits morceaux de code intégrés au logiciel transmettent ces informations à un serveur sécurisé lorsque certains événements se produisent.

## Où est-ce utilisé
Il est utilisé pour le débogage logiciel, l'amélioration de l'expérience utilisateur et le suivi des performances.

## Souvent confondu avec
journalisation

## Questions fréquentes
**Cela affecte-t-il ma vie privée ?**
En général, des données anonymes sont collectées, mais vous pouvez contrôler les données envoyées via les paramètres.
