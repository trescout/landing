# Qu'est-ce que Infrastructure as Code ?

*Glossaire · Dev · Dernière mise à jour : 12 juillet 2026*

> IaC

Une méthode d'automatisation des installations de systèmes tels que les serveurs et les réseaux en écrivant des fichiers de code au lieu de les faire manuellement.

## Définition

Dans le passé, il fallait plusieurs jours pour installer et configurer les serveurs manuellement. Avec IaC, vous écrivez ces paramètres dans des fichiers texte et vous les exécutez comme un logiciel. De cette façon, votre système est toujours configuré de la même manière et les erreurs sont minimisées.

***Analogie :** C'est comme si au lieu d'assembler un meuble à la main, un bras robotique assemble le meuble sans erreur selon les instructions que vous écrivez.*

## Comment ça marche

Des fichiers de code spécifiant la configuration système requise sont créés et ces fichiers sont appliqués aux serveurs par les outils IaC.

## Où est-ce utilisé

Il est utilisé dans le cloud computing, la gestion de systèmes à grande échelle et la publication continue de logiciels.

## Questions fréquentes

**Pourquoi écrivons-nous du code au lieu de l’installer manuellement ?**

Car dans les opérations manuelles, un petit réglage oublié peut causer de gros problèmes, alors que le code donne toujours le même résultat.
