# Qu'est-ce que Tools ?

Ce sont des fonctions ou des outils auxiliaires qui permettent à un logiciel d'interagir avec le monde extérieur pour effectuer certaines opérations.

## Définition
Dans le monde de l'IA, les « outils » permettent au modèle d'effectuer des tâches qu'il ne peut pas effectuer seul (comme effectuer une recherche sur Internet, utiliser une calculatrice ou lire un fichier). Lorsque le modèle doit utiliser un outil, il le fait sous la forme d'un appel de fonction. Cela permet à l'agent de passer d'un système qui produit simplement du texte à un assistant qui interagit avec le monde.

## Comment ça marche
Ajoutez des instructions (invites système) qui indiquent à votre agent quel outil utiliser et quand. Définissez clairement le format d'entrée et de sortie de l'outil afin que le modèle ne fasse pas d'erreurs.

## Où est-ce utilisé
Il est utilisé dans les systèmes basés sur des agents, les outils d'automatisation et les systèmes RAG.

## Souvent confondu avec
C'est similaire aux plugins ; Les outils sont des fonctions généralement intégrées au niveau du code, tandis que les plugins offrent des fonctionnalités plus complètes.

## Questions fréquentes
**L’intelligence artificielle peut-elle choisir elle-même les véhicules ?**
Oui, les agents avancés peuvent décider quel outil résoudra quel problème.

**Comment fabriquer mon propre véhicule ?**
Vous pouvez le faire en écrivant une fonction et en la définissant pour l'agent via une API ou une bibliothèque.
