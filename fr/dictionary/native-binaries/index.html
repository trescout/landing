Qu'est-ce que Native Binaries ?

Ce sont des fichiers de programme compilés pour être directement exécutables pour un système d'exploitation et une architecture de processeur spécifiques.

Définition

Les binaires natifs sont des fichiers qui permettent au matériel de l'ordinateur de comprendre directement le code écrit, sans nécessiter de logiciel intermédiaire. Étant préparés spécifiquement pour le système d'exploitation et le type de processeur cibles, ces fichiers offrants les meilleures performances. Contrairement aux langages tels que Java ou Python, ils ne nécessitent pas de machine virtuelle ou d'interpréteur installé sur l'ordinateur pour fonctionner.

Analogie : Vous pouvez comparer cela à une discussion directe avec une personne parlant votre langue maternelle, sans avoir besoin d'un traducteur. Vous ne perdez aucun temps et communiquez directement.

Comment ça marche

Les développeurs convertissent directement leur code en langage machine à l'aide d'outils appelés compilateurs. Pendant ce processus, le matériel cible est spécifié et le compilateur produit un fichier composé de zéros et de uns que seul ce matériel peut comprendre. Ce fichier généré peut être exécuté directement par l'utilisateur en double-cliquant dessus.

Où est-ce utilisé

Ils sont fréquemment utilisés dans la programmation système, les moteurs de jeux et les systèmes embarqués où la vitesse et l'efficacité sont critiques. De plus, les outils en ligne de commande modernes et les applications de bureau rapides que vous examinez sur TreScout sont généralement distribués selon cette structure.

Souvent confondu avec

Ils sont confondus avec les fichiers de code intermédiaire s'exécutant sur une machine virtuelle. Alors que les fichiers de code intermédiaire ont besoin d'un intermédiaire pour fonctionner sur n'importe quel ordinateur, les binaires natifs ne s'exécutent directement que sur le système spécifique pour lequel ils ont été produits.

Questions fréquentes

Les binaires natifs fonctionnent-ils sur tous les ordinateurs ?

Non. Ils ne fonctionnent que sur le système d'exploitation et l'architecture de processeur pour lesquels ils ont été compilés. Par exemple, un fichier compilé pour Windows ne peut pas être exécuté directement sur un ordinateur Mac.

Quels langages produisent des binaires natifs ?

Les langages de programmation système tels que Rust, C++, Go et Zig sont conçus pour produire directement des binaires natifs.
