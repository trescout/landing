# Qu'est-ce que Prompts ?

Il s’agit de commandes ou de questions écrites que vous donnez à l’intelligence artificielle pour en tirer un résultat.

## Définition
Ce sont les instructions que vous utilisez lorsque vous interagissez avec des modèles d’IA. Ces commandes peuvent être une simple question ou des instructions détaillées indiquant comment le modèle doit se comporter. Une bonne commande permet à l’IA de vous répondre avec plus de précision et dans le format que vous souhaitez.

## Comment ça marche
Vous commencez par saisir une tâche dans la zone de discussion AI. En fonction de vos besoins, vous pouvez renforcer votre maîtrise en ajoutant des expressions claires telles que « résumer ceci », « traduire dans cette langue » ou « agir dans ce rôle ».

## Où est-ce utilisé
ChatGPT est utilisé dans toutes les interfaces de chat IA telles que Claude ou Gemini.

## Souvent confondu avec
Il peut être confondu avec Prompt Engineering ; Bien que l'invite soit la commande elle-même, l'ingénierie est le processus permettant de rendre cette commande la plus efficace.

## Questions fréquentes
**Comment rédiger une bonne commande ?**
Vous devez écrire clairement en indiquant ce que vous voulez, dans quel format et toutes les restrictions que vous avez.

**Mes commandes entraîneront-elles l’intelligence artificielle ?**
Généralement non, mais vous pouvez contrôler si ces données seront utilisées pour la formation dans les paramètres de la plateforme que vous utilisez.
