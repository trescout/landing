Qu'est-ce que In-process Database ?

Il s'agit d'un système de stockage de données léger qui s'exécute directement dans l'application sans avoir besoin d'un serveur séparé.

Définition

Ces types de bases de données fonctionnent dans le cadre de votre application. Au lieu d'envoyer des données ailleurs ou de se connecter via Internet, il conserve les données directement dans la mémoire du programme que vous utilisez. De cette façon, c’est très rapide et l’installation est assez simple.

Analogie : C'est comme avoir tous les livres dans un tiroir de votre bureau au lieu d'aller dans une bibliothèque ; Vous n'avez pas besoin de quitter votre siège pour trouver l'information que vous recherchez.

Comment ça marche

Vous l'ajoutez à votre application sous forme de bibliothèque ou de fichier. Vous utilisez des commandes standard pour lire ou écrire des données, et lorsque l'application se ferme, les données sont généralement stockées dans un fichier local.

Où est-ce utilisé

Il est préféré dans les applications mobiles, les petits logiciels de bureau ou les processus de prototypage rapide.

Souvent confondu avec

Il est confondu avec les bases de données client-serveur ; Ce système est local alors qu'ils nécessitent une connexion à distance.

Questions fréquentes

Ces bases de données sont-elles adaptées au big data ?

Généralement conçus pour les données de petite et moyenne taille, les systèmes basés sur serveur conviennent mieux aux systèmes volumineux.

Est-ce difficile à installer ?

Non, vous pouvez généralement commencer à l'utiliser immédiatement en ajoutant simplement un fichier de bibliothèque.
