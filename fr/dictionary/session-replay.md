# Qu'est-ce que Session Replay ?

C'est une technologie qui permet d'enregistrer et de regarder tous les mouvements des utilisateurs sur votre site internet comme un film.

## Définition
Il vous permet de voir étape par étape où un utilisateur a déplacé la souris, sur quel bouton il a cliqué ou où il est resté bloqué. Il s’agit du moyen le plus efficace de comprendre les problèmes techniques ou la confusion rencontrés par l’utilisateur.

## Comment ça marche
Vous ajoutez un petit morceau de code à votre site Web. Ce code enregistre de manière anonyme tous les mouvements de l'utilisateur dans le navigateur et vous le présente comme un lecteur vidéo.

## Où est-ce utilisé
Il est utilisé dans les processus de test d’expérience utilisateur (UX) et de débogage technique.

## Souvent confondu avec
Il est confondu avec Analytics (statistiques) ; Analytics « Combien de personnes ont cliqué ? » dit, rediffusion de la session "Comment ça s'est passé?" répond à la question.

## Questions fréquentes
**Qu’en est-il de la confidentialité des utilisateurs ?**
Les bons systèmes masquent automatiquement les données sensibles (comme les mots de passe).

**Est-ce que ça prend beaucoup de place ?**
Les systèmes modernes sont assez légers car ils enregistrent uniquement les données de mouvement.
