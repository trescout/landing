# Qu'est-ce que Jupyter Notebook ?

Il s'agit d'un environnement de travail interactif dans lequel vous pouvez ajouter des notes, des graphiques et des visualisations tout en écrivant du code.

## Définition
Jupyter Notebook est un outil basé sur un navigateur utilisé notamment dans les projets de science des données et d'intelligence artificielle. Il vous permet d'écrire votre code en petits morceaux, de l'exécuter instantanément et de voir les résultats immédiatement. Il peut être organisé comme un agenda ou des notes de cours, car vous pouvez ajouter non seulement du code mais aussi des textes expliquant ce que fait ce code.

## Comment ça marche
Il est généralement utilisé avec le langage Python. Vous tapez votre code dans une cellule, appuyez sur « exécuter » et la sortie apparaît juste en dessous. Lorsque vous avez terminé, vous pouvez partager ce fichier avec d'autres et leur faire suivre les mêmes étapes.

## Où est-ce utilisé
Il est utilisé lors de l’analyse de données, de la formation de modèles d’intelligence artificielle ou du test d’un algorithme étape par étape.

## Souvent confondu avec
Il peut être confondu avec un éditeur de texte ou un programme de codage (IDE) classique ; mais la plus grande différence avec Jupyter est que le code et le résultat sont liés.

## Questions fréquentes
**Peut-il uniquement exécuter Python ?**
Non, bien qu’il soit basé sur Python, il dispose également de plugins pour différents langages.

**Quelle est l'extension du fichier ?**
Il est généralement enregistré avec l'extension .ipynb.
