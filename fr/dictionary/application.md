# Qu'est-ce que Application ?

Une application (dont l'équivalent turc est uygulama) est un logiciel utilisateur qui effectue une tâche spécifique.

## Définition et origine du mot
De la rédaction de texte à la retouche photo, chaque tâche est effectuée via une application. Elle fonctionne sur le système d'exploitation et offre une interface visuelle. L'analogie de la maison est appropriée : le système est la maison elle-même, les applications sont les meubles.

## Comment connaître et utiliser dans la vie quotidienne ?
Téléphone : Messagerie et banque.Bureau : Bureautique et design.Web : Ceux qui s'ouvrent dans le navigateur.

## Choses fréquemment mélangées
On le confond avec le système d'exploitation. Le système gère l'appareil, l'application effectue une seule tâche. Les pilotes sont des logiciels mais ne sont pas des applications.

## Utilisation dans différentes disciplines
Meubles : Les objets à l'intérieur de la maison.Appareil de cuisine : Appareils à tâche unique.Accessoire de voiture : Pièce installée ultérieurement.

## Foire aux questions
**L'application et le logiciel sont-ils la même chose ?**
L'application est un sous-ensemble du logiciel. Chaque application est un logiciel, tout logiciel n'est pas une application.

**Comment mettre à jour les applications ?**
Automatiquement ou manuellement depuis le store. Les versions web sont actualisées au démarrage.

**Quelle est la différence entre le web et le natif ?**
Le natif est rapide et dispose de toutes les autorisations, le web ne nécessite pas d'installation. La PWA comble l'écart.

**Le store est-il obligatoire ?**
C'est pratique pour la distribution, mais pas obligatoire. Le web et la distribution d'entreprise sont des alternatives.
