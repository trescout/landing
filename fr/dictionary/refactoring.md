# Qu'est-ce que Refactoring ?

Il s'agit du processus consistant à rendre la structure du code à l'intérieur du logiciel plus organisée et efficace sans modifier son comportement externe.

## Définition
La refactorisation, c'est comme renouveler la plomberie à l'intérieur d'un bâtiment ou changer l'emplacement des éléments pour les rendre plus utiles, sans endommager l'apparence extérieure. Il n'y a aucun changement dans le fonctionnement du logiciel, mais la lisibilité du code augmente et il devient plus facile d'ajouter de nouvelles fonctionnalités dans le futur. C’est un processus de nettoyage qui doit être effectué régulièrement pour réduire la dette technique.

## Comment ça marche
Les blocs de code inutiles sont supprimés, les fonctions complexes sont décomposées en parties plus simples et les noms de variables sont rendus plus compréhensibles.

## Où est-ce utilisé
Il est appliqué dans les étapes de révision du code des processus de développement logiciel.

## Souvent confondu avec
Il ne faut pas confondre cela avec l’ajout de nouvelles fonctionnalités ou la correction de bugs ; cela améliore simplement la qualité du code.

## Questions fréquentes
**Pourquoi le faisons-nous ?**
Si le code est plus propre, les erreurs futures seront évitées et le processus de développement sera plus rapide.
