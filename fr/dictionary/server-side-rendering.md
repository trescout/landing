# Qu'est-ce que Server-side Rendering ?

> SSR

C'est une méthode qui permet de préparer des pages Web sur le serveur et de les afficher rapidement avant d'être envoyées à l'utilisateur.

## Définition
Normalement, le navigateur prend la page comme une case vide et la remplit lui-même. Avec SSR, le serveur envoie la page au navigateur complètement prête. Cela permet au site de se charger beaucoup plus rapidement et d’être trouvé plus facilement par les moteurs de recherche.

## Comment ça marche
Lorsque la demande de l'utilisateur arrive, le serveur crée la page, y place les données et envoie la version terminée.

## Où est-ce utilisé
Il est utilisé sur les sites e-commerce et tous les projets web où le référencement est important.

## Souvent confondu avec
Peut être confondu avec le rendu côté client ; Côté client, la plupart du travail est effectué dans le navigateur, et en SSR, la plupart du travail est effectué sur le serveur.

## Questions fréquentes
**Pourquoi tous les sites n'utilisent-ils pas SSR ?**
Il augmente la charge du serveur et est plus complexe à installer ; Cela n’est peut-être pas nécessaire pour tous les projets.
