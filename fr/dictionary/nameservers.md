# Qu'est-ce que Nameservers ?

Il s'agit d'un annuaire téléphonique qui convertit les noms de sites Web utilisés par les internautes en adresses numériques compréhensibles par les ordinateurs.

## Définition
Chaque site Web sur Internet possède en fait un équivalent numérique appelé adresse IP. Le serveur de noms, lorsque vous tapez un nom dans votre navigateur, dirige ce nom vers l'adresse IP correspondante, vous permettant d'atteindre le bon serveur. Il s'agit du système de carnet d'adresses d'Internet.

## Comment ça marche
Lorsque vous saisissez une adresse Web, votre ordinateur demande aux serveurs de noms : Quelle est l'adresse numérique de ce nom ? Le serveur de noms renvoie la réponse et votre navigateur se connecte à cette adresse.

## Où est-ce utilisé
Il est situé au centre des paramètres de noms de domaine et des infrastructures des fournisseurs de services Internet.

## Souvent confondu avec
Cela peut être confondu avec l’hébergement ; l'hébergement est l'endroit où les fichiers de votre site sont stockés et le serveur de noms est le chemin pour y accéder.

## Questions fréquentes
**À quoi sert la modification des paramètres du serveur de noms ?**
Habituellement, lorsque vous déplacez votre site Web vers un autre serveur, vous mettez à jour ces paramètres afin que le trafic soit dirigé vers le nouvel emplacement.

**Que se passe-t-il si le serveur de noms plante ?**
Vous ne pouvez pas accéder aux sites Web par leur nom car votre navigateur Internet ne peut pas trouver où se trouve le site.
