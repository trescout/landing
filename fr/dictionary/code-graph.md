# Qu'est-ce que Code-Graph ?

Il s'agit d'une structure cartographique qui visualise les relations entre les blocs de code, les fonctions et les fichiers dans les projets logiciels.

## Définition
Dans les grands projets logiciels, il est difficile de comprendre quel code affecte lequel. Code-Graph crée le squelette du projet en connectant toutes ces connexions comme un réseau. De cette façon, vous pouvez voir à l’avance ce qui pourrait casser si vous effectuez un changement.

## Comment ça marche
Les outils logiciels analysent votre projet et analysent tous les appels de fonction et dépendances de variables. Il crée une carte visuelle en traitant ces données dans une base de données graphique.

## Où est-ce utilisé
Il est utilisé dans des projets logiciels complexes, des processus de refactorisation (amélioration) de code et pour aider les développeurs de logiciels qui rejoignent une nouvelle équipe à comprendre le projet.

## Souvent confondu avec
Elle peut être confondue avec la structure classique des répertoires de fichiers, mais elle montre les liens logiques fonctionnels du code, pas seulement les fichiers.

## Questions fréquentes
**Comment Code-Graph vous aide-t-il à écrire du code ?**
Lorsque vous souhaitez supprimer ou modifier une fonction, cela vous permet de voir instantanément où cette fonction est utilisée.

**Peut-il être créé automatiquement ?**
Oui, les outils de développement modernes et les systèmes basés sur l'IA peuvent automatiquement tracer cette carte en analysant votre code.
