# Qu'est-ce que Source Control ?

*Glossaire · Dev · Dernière mise à jour : 3 septembre 2026*

C'est un système de suivi qui enregistre toutes les modifications de code dans les projets logiciels et permet de revenir en arrière.

## Définition

Lors du développement de logiciels, le code est constamment modifié. Le contrôle de version stocke chaque modification effectuée au cours de ce processus avec la date et les informations sur l'auteur. Ainsi, en cas d'erreur, il est facile de revenir à une version précédente fonctionnelle du projet.

***Analogie :** C'est comme écrire un livre, faire une copie de chaque page, noter 'j'ai modifié cette page hier' et pouvoir revenir à la version d'hier si vous n'êtes pas satisfait.*

## Comment ça marche

Les développeurs téléchargent leur code dans le système (commit). Si un problème survient, l'un des anciens enregistrements du système est sélectionné et le projet est ramené à ce moment-là.

## Où est-ce utilisé

Il est indispensable dans tous les processus de développement logiciel modernes, en particulier dans le travail d'équipe.

## Souvent confondu avec

Ce n'est pas la même chose qu'une sauvegarde, car il gère non seulement les fichiers, mais aussi l'historique des modifications.

## Questions fréquentes

**Pourquoi devrais-je l'utiliser ?**

C'est salvateur pour restaurer votre code si vous le cassez accidentellement.

**Quel est le plus populaire ?**

Git est le système le plus utilisé aujourd'hui.
