# Qu'est-ce que Desktop Client ?

Il s'agit d'une application logicielle que vous installez sur votre ordinateur et exécutez directement dans l'environnement de bureau.

## Définition
Contrairement aux applications Web qui s'exécutent via le navigateur, elle interagit directement avec votre système d'exploitation. Il offre un accès plus approfondi aux ressources matérielles et offre généralement une expérience plus stable. Il peut remplir ses fonctions de base même sans connexion Internet.

## Comment ça marche
Vous téléchargez le fichier d'installation de l'application et l'installez sur votre ordinateur. L'application effectue ses tâches en accédant à votre système de fichiers et à votre matériel autant que votre système d'exploitation le permet.

## Où est-ce utilisé
Il est utilisé dans les systèmes d’exploitation, les programmes bureautiques et les outils de développement de logiciels professionnels.

## Souvent confondu avec
Peut être confondu avec les applications Web ; Alors que les applications Web dépendent du navigateur, le client de bureau s'exécute de manière indépendante.

## Questions fréquentes
**Une application de bureau est-elle toujours meilleure ?**
Pour les tâches qui nécessitent des performances et un accès matériel plus élevés, oui, mais en termes de portabilité, les applications Web sont plus pratiques.
