Qu'est-ce que Open Weights ?

Il s’agit du partage des paramètres internes entraînés du modèle d’intelligence artificielle avec tout le monde.

Définition

Open Weights rend publics les paramètres internes et les poids mathématiques créés au cours du processus de formation d’un modèle d’intelligence artificielle. De cette manière, les développeurs peuvent exécuter le modèle sur leurs propres ordinateurs ou y ajouter de nouvelles fonctionnalités.

Analogie : C'est comme si un chef non seulement écrivait sa recette secrète sur papier, mais permettait à chacun d'appliquer toutes les étapes de cuisson et les astuces de ce plat.

Comment ça marche

L’entreprise qui forme le modèle met à disposition sur Internet des fichiers de données de poids très volumineux. Vous pouvez également personnaliser le modèle en téléchargeant ces fichiers et en les exécutant sur votre propre système.

Où est-ce utilisé

Il est utilisé par les entreprises et les chercheurs qui souhaitent exécuter l’intelligence artificielle sur leurs propres serveurs, afin de garder le modèle totalement sous contrôle.

Souvent confondu avec

Il est mélangé à des logiciels open source ; Open Weights fournit la structure interne du modèle, mais parfois les données utilisées pour entraîner le modèle lui-même peuvent rester privées.

Questions fréquentes

Puis-je tout changer sur le modèle avec Open Weights ?

Vous ne pouvez pas modifier la structure de base du modèle, mais vous pouvez le spécialiser dans certains sujets en y ajoutant de nouvelles données.

Que faut-il pour faire fonctionner ces modèles ?

Cela nécessite généralement une carte graphique puissante ou un matériel serveur haute capacité.
