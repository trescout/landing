# Qu'est-ce que Japanese Input Method System ?

> IME

Il s'agit d'un logiciel d'interface qui permet d'écrire des caractères japonais avec un clavier standard.

## Définition
Le japonais étant composé de milliers de caractères, il ne peut pas tenir sur un clavier standard. Ce système agit comme un pont qui convertit les sons phonétiques écrits par l'utilisateur dans l'alphabet latin en caractères japonais. Le logiciel traite instantanément ce qui est écrit et affiche les caractères corrects à l'écran.

## Comment ça marche
L'utilisateur appuie sur les lettres du clavier, le logiciel accumule ces lettres et affiche les caractères japonais à l'écran à l'aide d'un « moteur de conversion ».

## Où est-ce utilisé
Il est utilisé dans les systèmes d’exploitation des ordinateurs et des téléphones ainsi que dans les éditeurs de texte.

## Souvent confondu avec
Peut être mélangé avec le moteur de conversion Neural Kana-Kanji ; IME est le système global, tandis que le moteur de conversion est la partie convertisseur intelligent qu'il contient.

## Questions fréquentes
**Puis-je taper en japonais sans IME ?**
Non, ce logiciel est nécessaire car il est impossible de faire rentrer des milliers de caractères sur le clavier.
