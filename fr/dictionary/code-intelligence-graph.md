# Qu'est-ce que Code Intelligence Graph ?

Il s'agit d'une carte détaillée qui montre les relations de tous les fichiers, fonctions et variables d'un projet logiciel.

## Définition
Dans les grands projets logiciels, les codes sont répartis sur des milliers de fichiers. Code Intelligence Graph connecte cette structure complexe comme un réseau. Ainsi, l’intelligence artificielle peut facilement comprendre quelles autres parties affecteront une modification apportée à une partie du code.

## Comment ça marche
Les outils de développement logiciel analysent votre projet, marquent chaque partie comme un nœud et enregistrent les connexions entre elles. Cette base de données est utilisée pour vous donner des suggestions ou trouver des erreurs pendant que vous écrivez du code.

## Où est-ce utilisé
Il est utilisé dans les éditeurs de code modernes, les outils de développement de logiciels basés sur l'IA et la gestion de projets à grande échelle.

## Souvent confondu avec
Il ne s'agit pas simplement d'une liste de fichiers ou d'une simple structure de dossiers ; Il inclut également les relations logiques du code.

## Questions fréquentes
**Pourquoi est-ce nécessaire ?**
Parce que dans les très grands projets, il est impossible de savoir manuellement où une modification provoquera des erreurs.
