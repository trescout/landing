# Gestion des revenus avec l'intelligence artificielle

AiToEarn est une plate-forme basée sur TypeScript qui permet aux utilisateurs de gérer leurs processus de monétisation grâce à des automatisations basées sur l'IA. Le projet offre une infrastructure ouverte aux développeurs en combinant l'exécution de tâches autonomes et des modèles de revenus basés sur l'intelligence artificielle.

## Ce que ça vous apporte

- Il gère la création de contenu basée sur l'intelligence artificielle et les processus de publication automatique.
- Il permet de générer des revenus à partir du contenu avec les modèles CPS, CPE et CPM.
- Il offre une interaction simultanée et une gestion des abonnés sur plusieurs plateformes de médias sociaux.

## Installation

**Configuration rapide avec Docker**

```
git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn
docker compose up -d
```

**Installation du plugin OpenClaw**

```
npx -y @aitoearn/openclaw-plugin-cli
```
