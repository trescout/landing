Reprendre l'évaluation avec l'intelligence artificielle

L'agent d'embauche est un agent d'intelligence artificielle (agent IA) conçu pour évaluer et noter les CV. Cet outil, développé avec le langage Python, vise à automatiser les processus de sélection des candidats dans les processus de recrutement.

Ce que ça vous apporte

  • Il analyse automatiquement les CV au format PDF.
  • Il enrichit les candidats avec les données GitHub.
  • Fournit un rapport de notation juste et explicable.

Installation

Téléchargement et installation des fichiers nécessaires
git clone https://github.com/interviewstreet/hiring-agent
cd hiring-agent

python -m venv .venv
# Linux or macOS
source .venv/bin/activate
# Windows
# .venv\Scripts\activate

pip install -r requirements.txt

Exécution

Commencer l'examen du CV
python score.py /path/to/resume.pdf

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Agir en tant que recruteur et analyser les données de CV fournies et les contributions techniques sur GitHub. Noter les projets, les compétences techniques et l'expérience professionnelle du candidat selon des critères objectifs. Lors de la notation, tenez compte de la qualité du code du candidat sur GitHub, de la fréquence des contributions et de la pertinence de ses projets par rapport aux applications du monde réel. En fin de compte, créez un rapport d'évaluation transparent et équitable qui met en évidence les forces et les faiblesses du candidat.
