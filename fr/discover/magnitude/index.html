Exécutez des modèles d'IA locaux sur votre ordinateur

Magnitude est un serveur d'inférence open source qui s'intègre aux agents d'IA existants et vous permet d'exécuter des modèles locaux adaptés à votre matériel. Il facilite l'exploitation de la puissance de calcul locale en étant compatible avec des assistants de codage comme Cline et divers modèles open source.

Ce que ça vous apporte

  • Identifie automatiquement les modèles locaux les mieux adaptés à votre matériel
  • Fonctionne entièrement hors ligne, sans connexion Internet
  • S'intègre aux assistants d'IA pour réduire les coûts de jetons à zéro

Installation

Installez l'outil CLI et lancez la configuration
npm i -g @magnitudedev/cli
magnitude setup

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Configurez des modèles locaux pour moi avec la CLI Magnitude. Installez-la avec `npm i -g @magnitudedev/cli` (ou mon gestionnaire de paquets), puis exécutez `magnitude docs onboarding` et suivez les instructions.
