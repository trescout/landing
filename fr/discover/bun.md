# Exécution rapide pour les projets JavaScript

Bun est un outil hautes performances qui combine le runtime JavaScript, le gestionnaire de packages, l'exécuteur de tests et le packager sous un même toit. Développée avec le langage Rust, cette plateforme offre une infrastructure intégrée pour accélérer les processus de développement logiciel.

- Rust

## Ce que ça vous apporte
- Exécution rapide compatible avec Node.js
- Gestionnaire de packages et outil de test sous un même toit
- Faible utilisation de la mémoire et démarrage rapide

## Installation
**Installation via un script d'installation**

```
curl -fsSL https://bun.com/install | bash
```

**Installation sous Windows**

```
powershell -c "irm bun.sh/install.ps1 | iex"
```


## Exécution
**Installation du paquet**

```
bun install <pkg>
```

**Exécution de fichiers**

```
bun run index.tsx
```
