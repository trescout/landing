# Gestion de projet simple et rapide

Kaneo est un outil de gestion de projet open source développé avec une interface orientée utilisateur. Écrite en TypeScript, la plateforme vise à créer des flux de travail sans complexité.

## Ce que ça vous apporte
- Interface propre, sans encombrement
- Hébergement sur votre propre serveur offrant un contrôle des données
- Expérience de travail rapide axée sur la performance

## Installation
**installation automatique**

```
curl -fsSL https://assets.kaneo.app/install.sh | sh
drim setup
```


## Exécution
**Démarrage de l'environnement de développement**

```
# Clone and install dependencies
git clone https://github.com/usekaneo/kaneo.git
cd kaneo
pnpm install

# Create a .env file in the root with required environment variables
# See ENVIRONMENT_SETUP.md for detailed instructions

# Start development servers
pnpm dev
```
