# Assistant d'intelligence artificielle avec vos propres données

Open-notebook offre une alternative open source à Google NotebookLM, permettant aux utilisateurs d'effectuer une analyse de notes personnalisable basée sur l'IA sur leurs propres données. Développé avec TypeScript, ce projet offre une plus grande flexibilité et un ensemble de fonctionnalités étendu par rapport à la plate-forme d'origine.

## Ce que ça vous apporte
- Analysez vos données dans un environnement entièrement local, en les gardant confidentielles.
- Bénéficiez d’une sélection flexible de modèles auprès de plus de 18 fournisseurs d’IA.
- Créez des podcasts professionnels à partir de vos fichiers PDF, vidéo et audio.

## Installation
**Téléchargez le fichier de configuration**

```
curl -o docker-compose.yml https://raw.githubusercontent.com/lfnovo/open-notebook/main/docker-compose.yml
```


## Exécution
**Services de démarrage**

```
docker compose up -d
```


## Si vous ne codez pas
Je souhaite installer l'outil Open Notebook. Docker Desktop est installé. Tout d'abord, je dois télécharger le fichier docker-compose.yml avec la commande curl, puis modifier la section OPEN_NOTEBOOK_ENCRYPTION_KEY dans le fichier avec un mot de passe unique. À la dernière étape, je dois terminer l'installation en exécutant la commande docker compose up -d. Y a-t-il d'autres paramètres ou étapes auxquels je devrais prêter attention dans ce processus ?
