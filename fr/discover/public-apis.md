# Sources de données gratuites pour vos projets

Public-apis est une liste complète d'interfaces de programmation d'applications (API) gratuites que les développeurs d'applications peuvent utiliser dans leurs projets. Il sert de point de référence central qui facilite l'accès aux sources de données externes nécessaires aux processus de développement de logiciels.

## Ce que ça vous apporte
- Il fournit un accès rapide aux données nécessaires aux processus de développement d'applications.
- Il rassemble des interfaces de programmation d'applications (API) gratuites de différents domaines dans un seul centre.
- Fournit une liste complète et organisée de références gérées par la communauté.
