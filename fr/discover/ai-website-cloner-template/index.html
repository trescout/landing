Copie de sites Web avec l'intelligence artificielle

Le cloneur de sites Web à intelligence artificielle (AI website cloner), développé par JCodesMore, permet de copier des sites Web existants avec une seule commande à l'aide d'agents de codage basés sur TypeScript. Cet outil utilise la génération de code basée sur l'IA pour automatiser les processus de conception et de développement Web.

Ce que ça vous apporte

  • Convertit les sites Web existants en base de code Next.js
  • Extrait automatiquement les éléments de conception et les actifs
  • Reconstruit les composants en parallèle

Installation

Cloner le référentiel
git clone https://github.com/YOUR-USERNAME/YOUR-NEW-REPOSITORY.git
   cd YOUR-NEW-REPOSITORY
Installer les dépendances
npm install

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

À l'aide de ce projet, analysez le site Web cible, extrayez les éléments de conception et les actifs, écrivez les propriétés des composants et exécutez des moteurs de rendu parallèles pour le reconstruire dans la structure Next.js.
