# Automatisation des appareils mobiles avec intelligence artificielle

Mobile-mcp est un serveur Model Context Protocol qui effectue le scraping de données avec automatisation sur les appareils mobiles et les simulateurs. Cet outil permet aux modèles d'IA d'exécuter des tâches en interagissant directement avec les plateformes iOS et Android.

- ★ 7 665
- TypeScript
- GitHub Trending · 2026-09-27

## Ce que ça vous apporte
- Test d'applications sur les appareils iOS et Android
- analyser automatiquement les éléments de l'écran et capturer des données structurées
- Gérez les émulateurs et les simulateurs via une interface unique

## Installation
**Installation avec Claude**

```
claude mcp add mobile-mcp -- npx -y @mobilenext/mobile-mcp@latest
```

**Fonctionnement direct**

```
npx @mobilenext/mobile-mcp@latest
```


## Exécution
**Démarrer le serveur**

```
npx @mobilenext/mobile-mcp@latest
```


## Si vous ne codez pas
Répertoriez les applications sur les appareils mobiles connectés et analysez les éléments à l'écran à l'aide du serveur Model Context Protocol qui communique avec les outils de développement mobile sur mon ordinateur.
