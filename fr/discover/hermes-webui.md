# Gérez vos agents IA depuis le Web

Hermes WebUI est une interface qui vous permet de gérer les agents Hermes AI via un navigateur Web ou des appareils mobiles. Il vous permet de suivre et de contrôler les interactions des agents à partir d'un seul centre.

- ★ 17 366
- Python
- MIT
- GitHub Trending · 1 Haziran 2026

## Ce que ça vous apporte
- Gérez vos agents via un navigateur ou un mobile.
- Surveillez toutes les interactions à partir d’un point central.
- Profitez de l'interface simple et conviviale.

## Installation
**Cloner et lancer le dépôt officiel**

```
git clone https://github.com/nesquena/hermes-webui.git hermes-webui
cd hermes-webui
python3 bootstrap.py
```


## Exécution
**Démarrer le serveur**

```
./start.sh
```


## Comment installer, comment utiliser ?
Installez Hermes WebUI : téléchargez avec 'git clone https://github.com/nesquena/hermes-webui.git hermes-webui', entrez dans le répertoire et exécutez 'python3 bootstrap.py' ; Utilisez ensuite l'agent Hermes depuis l'interface du navigateur ouvert.
