Donner des talents d’ingénieur aux agents d’intelligence artificielle

Cette bibliothèque, développée pour les agents de codage d'intelligence artificielle, offre des compétences d'ingénierie au niveau de la production. Il fournit des outils standardisés pour augmenter la capacité technique des agents qui automatisent les processus de développement de logiciels.

Ce que ça vous apporte

  • Il fournit des flux de travail d'ingénierie professionnels aux agents d'intelligence artificielle.
  • Il automatise les processus de développement logiciel avec des étapes standardisées.
  • Disciplines les processus de test et de révision pour améliorer la qualité du code.

Installation

Installation locale pour Claude Code
git clone https://github.com/addyosmani/agent-skills.git
claude --plugin-dir /path/to/agent-skills

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Je veux que tu travailles comme un ingénieur logiciel. À l'aide de la bibliothèque Agent Skills, appliquez les commandes /spec, /plan, /build, /test, /review, /code-simplify et /ship conformément aux normes à chaque étape de mon processus de développement logiciel. Produisez du code en suivant les flux de travail, les points de contrôle qualité et les meilleures pratiques d'ingénierie.
