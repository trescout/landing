# Créez votre propre serveur multimédia

Jellyfin est un serveur multimédia gratuit qui vous permet de gérer et de diffuser vos propres films, séries télévisées et collections musicales sur tous vos appareils. Alternative à Plex et Emby, cette plateforme n'a pas de verrous premium, de publicités ou de frais cachés.

## Ce que ça vous apporte
- Tous vos médias au même endroit et accessibles depuis n'importe quel appareil.
- Vous n'aurez pas à vous soucier des frais d'abonnement ou des publicités.
- Vos données restent avec vous et ne sont pas partagées avec des tiers.
- Une alternative à Plex et Emby qui offre une liberté totale.

## Installation
**avec Docker**

```
docker run -d --name jellyfin -p 8096:8096 jellyfin/jellyfin
```


## Exécution
****

```
http://localhost:8096
```


## Comment installer ?
Docker est installé sur un serveur ou un NAS. Le guide d'installation se trouve sur jellyfin.org ; Après l'avoir installé, vous présentez vos dossiers multimédias.

## Comment installer, comment utiliser ?
Je souhaite installer le serveur multimédia Jellyfin ; Téléchargez et installez la version adaptée à mon système d'exploitation à partir de la page officielle jellyfin.org/downloads, ou aidez-moi à l'exécuter avec l'image « jellyfin/jellyfin » si j'utilise Docker.
