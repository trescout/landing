Navigateur simultané pour les agents IA

Ego-lite est un navigateur qui permet aux utilisateurs et aux agents d'intelligence artificielle de travailler simultanément. Cet outil basé sur JavaScript vise à réaliser une interaction humaine et machine en parallèle dans le même environnement de navigateur.

Ce que ça vous apporte

  • Les agents et les utilisateurs s'exécutent dans le même navigateur sans conflit
  • Protège les sessions en important des données Chrome
  • Réalisation plus rapide des tâches grâce à une structure basée sur JavaScript

Installation

Ajout de compétences
npx skills add citrolabs/ego-lite

Exécution

Démarrer une tâche
ego-browser follow @ego_agent on x.com for me
