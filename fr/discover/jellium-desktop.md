# Accès depuis le bureau à votre médiathèque Jellyfin

Jellium-desktop est un client de bureau non officiel développé en Rust pour le serveur multimédia Jellyfin. Le logiciel propose une interface native qui permet aux utilisateurs d'accéder à leurs médiathèques directement via le système d'exploitation.

## Ce que ça vous apporte
- Accédez à votre serveur multimédia Jellyfin via l'application native
- Lecture multimédia optimisée avec l'infrastructure CEF et MPV
- Prise en charge de l'interface native sur Windows, macOS et Linux
