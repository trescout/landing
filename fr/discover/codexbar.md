# Surveiller les limites d'utilisation de l'IA

CodexBar est un outil qui permet de visualiser les données d'utilisation d'OpenAI Codex et Claude Code sans nécessiter de connexion. Développée avec le langage Swift, cette application permet aux développeurs de suivre facilement les statistiques de consommation dans les outils de codage pris en charge par l'IA.

## Ce que ça vous apporte

- Visualisez instantanément les limites d'utilisation de tous les services d'intelligence artificielle dans la barre de menu
- Suivez les temps de réinitialisation des services avec un compte à rebours
- Il ne stocke pas les mots de passe car il utilise les sessions existantes, il est axé sur la confidentialité
