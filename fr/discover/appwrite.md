# Appwrite

Appwrite est une plateforme cloud open source réunissant divers outils tels que l'authentification, la base de données, le stockage et l'hébergement pour les développeurs et les agents d'intelligence artificielle. Développé en TypeScript, ce service offre une infrastructure complète qui simplifie les processus de développement d'applications.
