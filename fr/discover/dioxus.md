# Applications multiplateformes avec Rust

Dioxus est un framework Rust qui permet de développer des applications de bout en bout (fullstack) avec une base de code unique pour les plateformes Web, de bureau et mobiles. Il standardise l'expérience de développement d'applications dans l'écosystème Rust en accélérant le processus de création d'interface utilisateur grâce à sa structure basée sur des composants de type React.

## Ce que ça vous apporte
- Développement d'applications Web, de bureau et mobiles avec une base de code unique
- Processus de développement rapide avec actualisation instantanée du code
- Structure de composants de type React et prise en charge fullstack sécurisée

## Installation
**Installez l'outil CLI**

```
curl -fsSL https://dioxuslabs.com/install.sh | bash
```

**Méthode d'installation alternative**

```
cargo install --git https://github.com/DioxusLabs/dioxus dioxus-cli --locked
```


## Exécution
**Démarrer l'application**

```
dx serve
```

**Emballage de l'application**

```
dx bundle
```
