# Donnez des fonctionnalités standard aux agents IA

Agent Skills est un projet de spécification technique et de documentation qui standardise les compétences utilisées par les agents d'intelligence artificielle dans l'exécution de leurs tâches. Cette structure basée sur Python vise à faciliter le partage de capacités et l'interopérabilité entre différents systèmes d'agents.

## Pour commencer
- Source officielle →
Agent Skills est une installation standard plutôt qu'une installation logicielle. Pour commencer, vous pouvez consulter la documentation officielle sur agentskills.io, parcourir le répertoire d'exemples sur GitHub pour voir des exemples de fonctionnalités et commencer à développer vos capacités dans cette structure de dossiers au format standard.
