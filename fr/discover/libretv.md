# Créez une plateforme de recherche et de visionnage de vidéos en ligne

LibreSpark/LibreTV est un projet logiciel basé sur TypeScript qui vous permet de configurer un site de films et de séries en moins d'une minute grâce à des méthodes telles que Docker. Il fournit une infrastructure permettant aux utilisateurs de créer rapidement leur propre plateforme de contenu.

- ★ 18 500
- TypeScript
- GitHub Trending · 2026-10-16

## Ce que ça vous apporte

- recherchez des films et des séries provenant de différentes sources en un seul endroit
- regardez des diffusions de télévision sur Internet aux formats m3u et m3u8
- conservez votre historique de visionnage et votre position de lecture dans votre navigateur

## Installation

**installation rapide avec docker**

```
docker compose pull && docker compose up -d
```

## Exécution

**exécution par compilation à partir de la source**

```
npm install
PASSWORD=your-password npm run build
PASSWORD=your-password npm start   # 监听 8080
```
