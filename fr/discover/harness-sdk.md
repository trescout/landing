# Kit de développement pour agents d'intelligence artificielle

Harness SDK est un kit de développement open source qui fournit un contrôle et une gestion de bout en bout pour les agents IA. Compatible avec les langages Python et TypeScript, cet outil permet la standardisation des agents de niveau production fonctionnant sur différents modèles et infrastructures cloud.

## Ce que ça vous apporte
- Entièrement compatible avec les langages Python et TypeScript
- Prend en charge différents modèles d'intelligence artificielle et infrastructures cloud
- Offre mémoire, gestion de session et intégration d'outils

## Installation
**Installation avec Python**

```
pip install strands-harness
```

**Installation avec TypeScript**

```
npm install @strands-agents/harness
```
