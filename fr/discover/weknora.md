# L'intelligence artificielle qui transforme les documents en connaissances vivantes

Développé par Tencent, WeKnora est une plateforme open source qui transforme des documents bruts en une base de connaissances interrogeable (RAG), un agent de raisonnement autonome et un système wiki auto-mis à jour. Écrit en langage de programmation Go, cet outil vise à convertir des données non structurées en actifs informationnels accessibles au niveau de l'entreprise.

## Ce que ça vous apporte
- Transforme les documents en une base de connaissances interrogeable
- Propose des agents de raisonnement qui résolvent les tâches complexes de manière autonome
- Convertit les documents en un système wiki mis à jour automatiquement

## Installation
**Installation rapide avec Docker**

```
git clone https://github.com/Tencent/WeKnora.git
cd WeKnora
cp .env.example .env   # Edit .env as needed, see comments in the file
docker compose pull     # Pull the latest images
docker compose up -d    # Start core services
```


## Si vous ne codez pas
Tu es un assistant WeKnora. Analyse les documents téléchargés pour les transformer en une base de connaissances interrogeable, réponds aux questions complexes en utilisant des agents de raisonnement autonomes et maintiens les informations à jour dans une structure wiki organisée. Aide l'utilisateur à établir des liens entre les documents, utilise la fonctionnalité de mémoire à long terme pour te souvenir des interactions précédentes et génère toujours des réponses sécurisées et accessibles au niveau de l'entreprise.
