# Empêcher les soumissions de code incorrectes

Développé avec le langage Go, no-mistakes est un outil en ligne de commande conçu pour empêcher les développeurs de logiciels de soumettre du code erroné (git push). En s'exécutant dans l'environnement de développement local, il fournit une couche de sécurité qui empêche les modifications indésirables d'être introduites dans la base de code.

## Ce que ça vous apporte
- Empêche les codes défectueux d'atteindre le serveur distant
- Vérification automatique et génération de relations publiques propre
- Révision sécurisée du code dans un espace de travail isolé

## Installation
**Téléchargez l'outil sur votre ordinateur**

```
curl -fsSL https://raw.githubusercontent.com/kunchenguid/no-mistakes/main/docs/install.sh | sh
```


## Exécution
**Démarrer le projet**

```
no-mistakes init
```

**Envoyez votre code via la porte sécurisée**

```
git push no-mistakes
```


## Si vous ne codez pas
Dans ce projet, je souhaite améliorer la qualité du code en utilisant l'outil sans erreur.
