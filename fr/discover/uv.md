# Outil de gestion ultra-rapide pour les projets Python

Développé avec le langage de programmation Rust, uv est un outil ultra-rapide conçu pour gérer les projets et paquets Python. Il offre une alternative axée sur les performances aux gestionnaires de paquets traditionnels (pip, pip-tools).

## Ce que ça vous apporte

- Effectue les opérations de gestion de paquets 10 à 100 fois plus rapidement que les outils traditionnels.
- Télécharge les versions du langage de programmation Python sur votre ordinateur et les organise selon vos projets.
- Remplit à lui seul les fonctions d'outils tels que pip, le gestionnaire de paquets qui gère les dépendances de bibliothèques.

## Installation

**Installation pour macOS et Linux**

```
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**installation pour fenêtres**

```
# On Windows.
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Exécution

**Mise à jour de l'outil**

```
uv self update
```
