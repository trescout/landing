# Jouez à Banjo Kazooie sur les systèmes modernes

Lighthouse est un outil de couverture de code développé en langage C et conçu pour les systèmes de bas niveau. Il fournit des données aux développeurs pour le débogage et l'optimisation des performances en analysant les blocs de code exécutés pendant les processus de test du logiciel.

## Ce que ça vous apporte

- Fournit un support de plate-forme moderne avec les fichiers de jeu originaux
- Offre un support de packs et de mods multilingues
- Comprend des paramètres de contrôleur et graphiques personnalisables

## Pour commencer

Téléchargez la version Lighthouse à partir de la page officielle des versions de GitHub et extrayez les fichiers dans un dossier. Après avoir vérifié votre propre fichier de jeu (ROM), sélectionnez votre fichier de jeu en exécutant lighthouse.exe sous Windows, lighthouse.appimage sous Linux ou lighthouse sous macOS.
