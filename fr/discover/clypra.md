# Éditeur vidéo de bureau open source

Clypra est une application d'édition vidéo open source développée à l'aide de Tauri, React et TypeScript. Le logiciel vise à offrir des fonctionnalités avancées trouvées dans les outils de montage vidéo payants comme alternative gratuite.

## Ce que ça vous apporte
- Traitement vidéo haute performance accéléré par le matériel
- Chronologie multipiste précise à l'image près
- Sous-titrage et édition automatiques basés sur l'IA

## Installation
**Installation avec Homebrew sur macOS**

```
brew install AIEraDev/tap/clypra
```
