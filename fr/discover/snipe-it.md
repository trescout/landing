# Gestion des actifs et des licences de l'entreprise

Snipe-IT est un système de gestion open source permettant de suivre les actifs informatiques et les licences logicielles. Cette plateforme, développée avec le langage PHP, permet aux institutions d'organiser les registres d'inventaire et les cycles d'utilisation dans un environnement numérique.

## Ce que ça vous apporte
- Surveillance du cycle de vie des actifs informatiques
- Suivi centralisé des licences logicielles
- numériser les enregistrements de débit matériel

## Installation
**Prenez l'image officielle**

```
docker pull grokability/snipe-it
```


## Exécution
**commencer**

```
docker compose up -d
```
