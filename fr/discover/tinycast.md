# Lanceur d'applications léger pour macOS

Tinycast est un lanceur d'applications léger, un gestionnaire de raccourcis et un outil d'historique du presse-papiers développé pour le système d'exploitation macOS. Écrit en Swift, ce logiciel natif vise à accélérer les flux de travail sur le bureau en utilisant efficacement les ressources système.

## Ce que ça vous apporte
- Logiciel natif utilisant efficacement les ressources système
- Prise en charge de l'exécution directe des extensions Raycast
- Gestion de l'historique du presse-papiers et des modèles de texte

## Installation
**Ajout du dépôt au système**

```
brew trust --tap abue-ammar/tinycast   # required for third-party taps
brew tap abue-ammar/tinycast
```


## Si vous ne codez pas
Pour activer les fonctionnalités d'intelligence artificielle sur Tinycast, définissez votre propre clé API ou les informations de votre compte IA configuré via le menu Paramètres. Une fois cette opération effectuée, vous pouvez lancer des discussions directement depuis la palette, effectuer des corrections grammaticales, des résumés ou des traductions rapides sur les textes sélectionnés.
