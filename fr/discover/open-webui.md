# Une interface unique pour vos modèles d'intelligence artificielle

open-webui est une interface conviviale permettant d'interagir avec des modèles d'intelligence artificielle tels qu'Ollama et l'API OpenAI. Elle propose une interface web développée pour gérer des modèles de langage locaux ou basés sur le cloud.

## Ce que ça vous apporte

- Vous pouvez gérer tous vos modèles d'intelligence artificielle locaux et basés sur le cloud depuis un écran web unique.
- Vous pouvez téléverser vos propres documents dans le système pour effectuer des questions-réponses sur vos textes et lancer des recherches sur Internet.
- Vous pouvez utiliser la génération d'images, la recherche vocale, la gestion d'agenda et les outils de prise de notes sans quitter la zone de discussion.

## Installation

**Installation avec le gestionnaire de paquets Python pip**

```
pip install open-webui
```

## Exécution

**Démarrer avec l'outil de conteneurisation logicielle Docker**

```
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```
