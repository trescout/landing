# Interfaces rapides adaptées à l'intelligence artificielle

Solid est une bibliothèque JavaScript déclarative utilisée pour créer des interfaces utilisateur. Au lieu d'utiliser un modèle d'objet de document virtuel (Virtual DOM), elle compile les modèles directement en nœuds de modèle d'objet de document (DOM) réels, effectuant des mises à jour avec une réactivité à grain fin (fine-grained reactivity).

## Ce que ça vous apporte

- La structure de gestion de l'interface gagne en vitesse en mettant à jour directement les nœuds du navigateur réel au lieu d'utiliser un Virtual DOM.
- Minimise la charge sur le processeur en n'exécutant les composants qu'une seule fois.
- Grâce à sa structure qui suit automatiquement les changements de données, elle ne actualise que les petites parties concernées.

## Installation

**Créer un nouveau projet avec un modèle prêt à l'emploi**

```
npx degit solidjs/templates/solid-v2/basic my-app
cd my-app
npm install
npm run dev
```

## Exécution

**Intégrer l'outil de développement au projet Vite**

```
npm i solid-js @solidjs/web
npm i -D vite @solidjs/vite-plugin
```
