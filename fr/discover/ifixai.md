# Auditez les agents d'intelligence artificielle

iFixAi est un outil d'audit indépendant qui vérifie si les agents d'intelligence artificielle exécutent correctement les tâches qui leur sont confiées. Développé en langage Python, ce système peut être exécuté par un humain ou par l'agent lui-même pour analyser la conformité des processus en moins de deux minutes.

## Ce que ça vous apporte

- Teste si vos agents d'intelligence artificielle accomplissent correctement leurs tâches.

- Détecte à l'avance les failles du système et les erreurs passées inaperçues.

## Installation

**Installez le package**

```
pip install "ifixai[openai]"   # or anthropic, gemini, etc.: install the provider extra you'll test
```

**Ouvrez l'assistant d'installation**

```
ifixai setup                    # arrow-key wizard: pick provider, model, judge, suite → writes ifixai.yaml
```

## Exécution

**Exécutez l'outil**

```
ifixai run                      # no flags needed; reports land in ./ifixai-results/
```
