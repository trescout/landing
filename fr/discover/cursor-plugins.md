# Personnaliser l'éditeur de curseur avec des plugins

Plugins de curseur ; Il comprend la spécification officielle du plugin et des plugins officiels prêts à l'emploi pour l'éditeur de code Cursor. Il permet aux développeurs de créer leurs propres plugins.

- ★ 6 355
- TypeScript
- Lisans: kontrol et
- GitHub Trending · 30 May 2026

## Ce que ça vous apporte
- Il vous permet d'étendre l'environnement du curseur en fonction de vos propres besoins.
- Fournit une compatibilité ascendante grâce à sa structure de spécifications officielle.
- Vous pouvez développer vos propres solutions en vous inspirant de plugins prêts à l’emploi.

## Installation
**Cloner les plugins avec Git**

```
git clone https://github.com/cursor-plugins/cursor-plugins.git
```


## Comment l'utiliser avec l'IA ?
Aidez-moi à installer les plugins Cursor officiels de ce référentiel (par exemple, les plugins qui effectuent des révisions de code ou des contrôles de sécurité) du marché des plugins Cursor pour le projet sur lequel je travaille dans l'éditeur Cursor, et expliquez étape par étape comment les utiliser.
