# Gestion des opérations avec des agents d'intelligence artificielle

LobeHub permet de créer une équipe d'IA qui travaille 24 heures sur 24, 7 jours sur 7, en gérant les agents d'intelligence artificielle via des processus de recrutement, de planification et de reporting. La plateforme propose une interface d'administration qui automatise les flux de travail en organisant différents agents à partir d'un seul centre.

## Ce que ça vous apporte
- Gérer tous les agents d’intelligence artificielle depuis un seul centre
- Coopération inter-agents et répartition des tâches
- Prise en charge de plus de 10 000 outils et plugins

## Installation
**Bureau macOS (Homebrew)**

```
brew install --cask lobehub
```

**Image Docker**

```
docker pull lobehub/lobehub
```


## Exécution
**Lancer avec Docker**

```
docker compose up -d
```
