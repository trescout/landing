# Nœud IA pour Windows

OpenClaw propose une suite de gestion intégrée sur le système d'exploitation Windows via le nœud Windows, l'application de la barre d'état système, la bibliothèque partagée et l'extension de palette de commandes PowerToys. Développé en langage C#, cet outil vise à standardiser l’accès aux ressources système et aux workflows des utilisateurs.

## Ce que ça vous apporte

- Fournit un accès rapide à l'assistant d'intelligence artificielle OpenClaw via la barre d'état système.
- Il offre une gestion de passerelle locale et de connexion sous Windows.
- Il permet les sessions en direct, l'utilisation et le suivi des nœuds avec le centre de commande.

## Exécution

**Lancement d'application native**

```
.\run-app-local.ps1
```

**La connexion WebSocket via CLI est correcte**

```
dotnet run --project src/OpenClaw.Cli -- --help
```
