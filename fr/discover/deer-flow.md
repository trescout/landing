# Agent IA pour tâches complexes

Développé par ByteDance, Deer-Flow est un framework de superagent open source conçu pour effectuer des tâches de longue durée. Système; Il peut rechercher et coder de manière autonome des flux de travail complexes à l'aide d'un bac à sable, d'une gestion de la mémoire et de sous-agents.

## Ce que ça vous apporte
- Capacité de recherche et de codage autonome
- Travailler dans un environnement sandbox sécurisé
- Mémoire à long terme et gestion des sous-agents

## Installation
**Clonage du référentiel**

```
git clone https://github.com/bytedance/deer-flow.git
   cd deer-flow
```

**Démarrage de l'assistant de configuration**

```
make setup
```


## Exécution
**Lancement avec Docker**

```
make docker-init    # Pull sandbox image (only once or when image updates)
make docker-start   # Start services (auto-detects sandbox mode from config.yaml)
```


## Si vous ne codez pas
Clonez le référentiel DeerFlow sur mon ordinateur, puis exécutez la commande make setup pour terminer la configuration nécessaire pour l'environnement de développement local. Aidez-moi à configurer des options telles que le fournisseur LLM, les préférences de recherche sur le Web et les paramètres de sécurité lors de l'assistant de configuration.
