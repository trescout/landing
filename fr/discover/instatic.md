# CMS visuel moderne sur votre propre serveur

Instatic est un système de gestion de contenu visuel (CMS) moderne auto-hébergé basé sur TypeScript. Il permet aux utilisateurs d'exécuter l'interface de gestion de contenu sur leurs propres serveurs avec un processus d'installation rapide.

- ★ 7 891
- TypeScript
- GitHub Trending · 2026-07-01

## Ce que ça vous apporte
- Consolidez toute la gestion de contenu sur un seul serveur
- Modifiez les pages directement avec l'IA
- Produire une sortie HTML propre et rapide

## Installation
**Installation rapide avec Docker**

```
INSTATIC_IMAGE=ghcr.io/corebunch/instatic:latest docker compose -f compose.prod.yml -f compose.sqlite.yml up -d
```


## Si vous ne codez pas
À l'aide de l'agent d'intelligence artificielle dans l'interface d'édition de page, créez des nœuds modifiables conformes aux critères de conception spécifiés, ayant une structure HTML sémantique et formatés avec CSS. Permettez à l'agent de s'intégrer à des modèles tels que Claude, OpenAI ou OpenRouter pour créer automatiquement la structure de la page et les composants de contenu.
