Découvrir · GitHub · Univer

Suite d'outils bureautiques open source

Univer est une plateforme open source qui réunit des outils bureautiques tels que des feuilles de calcul, des documents et des présentations dans un seul environnement d'exécution (runtime). Elle offre une structure modulaire conçue pour faciliter l'interaction des agents d'IA (AI agents) avec les logiciels bureautiques.

Ce que ça vous apporte

  • Intégrez des expériences de feuilles de calcul, de documents et de présentations dans votre propre application.
  • Exécutez des opérations de traitement de données dans le navigateur ou côté serveur avec la même architecture.
  • Rassemblez uniquement les fonctionnalités dont vous avez besoin grâce à une architecture de plugins modulaire.

Installation

Clonage du dépôt et environnement de développement B
git clone https://github.com/dream-num/univer.git
cd univer
pnpm install
pnpm dev

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Pour exécuter le projet Univer dans un environnement local, clonez le dépôt dans le terminal avec la commande git clone https://github.com/dream-num/univer.git, puis, après avoir installé les dépendances avec cd univer et pnpm install, exécutez la commande pnpm dev.
