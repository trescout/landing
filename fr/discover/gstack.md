# Usine de développement de logiciels avec intelligence artificielle

Gstack est un système basé sur la configuration Claude Code de Garry Tan et se compose de 23 outils spécialisés qui jouent différents rôles tels que PDG, concepteur, responsable de l'ingénierie. Cette structure basée sur TypeScript propose des flux de travail définis pour automatiser les processus de développement logiciel.

## Installation

**Téléchargez et installez l'outil sur votre ordinateur**

```
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/gstack
cd ~/gstack && ./setup
```

## Si vous ne codez pas

Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Vous êtes maintenant mon équipe d'ingénierie virtuelle. Analysez mon projet à l'aide des outils Gstack, déterminez ma stratégie avec /office-hours, créez mon plan de travail avec /autoplan et vérifiez la qualité du code avec /review. Automatisez toutes les étapes du processus de développement logiciel en agissant en tant que PDG, concepteur et responsable de l'ingénierie.

Dépôt : https://github.com/garrytan/gstack. Base-toi sur les instructions officielles du fichier README de ce dépôt pour l'installation et l'exécution.

Avant de commencer, vérifie quel système d'exploitation nous utilisons et si les outils nécessaires (ex: Python, Node.js, Git, Docker) sont installés. Installe ceux qui manquent étape par étape selon ce système.

Crée un nouveau dossier vide pour travailler. Ne touche pas aux fichiers en dehors de ce dossier et ne supprime rien. Avant chaque commande, décris ce que tu vas faire en une phrase.

Dis-moi ce que je devrais voir à l'écran à la fin de chaque étape. Si une erreur survient, je te copierai le message d'erreur tel quel et nous la corrigerons ensemble.
