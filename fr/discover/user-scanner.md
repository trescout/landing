# User Scanner

Développé en Python, User-Scanner est un outil de renseignement en sources ouvertes (OSINT) qui collecte des données à partir de plus de 465 sources différentes via une seule adresse e-mail ou un nom d'utilisateur. Conçu pour les chercheurs en sécurité et les enquêteurs numériques, le logiciel offre une analyse de données approfondie avec un large éventail de vecteurs de recherche.
