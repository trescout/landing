# Système de connexion japonais pris en charge par l'intelligence artificielle

Développé avec le langage Rust, Karukan est un système de méthode de saisie japonais (Japanese Input Method System) qui utilise un moteur de conversion neuronal kana-kanji pour les systèmes d'exploitation Linux et macOS. Le logiciel va au-delà des méthodes traditionnelles et propose une approche basée sur l'intelligence artificielle pour les processus de conversion de texte.

## Pour commencer

Pour l'utiliser avec fcitx5 sous Linux, vous devez suivre les étapes d'installation dans les fichiers README du dossier karukan-fcitx5, et pour macOS dans le dossier karukan-macos. Étant donné que les fichiers de modèles seront automatiquement téléchargés depuis Hugging Face lors de la première utilisation, le processus de conversion initial peut prendre un certain temps.
