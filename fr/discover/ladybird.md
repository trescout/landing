# Projet de navigateur et de moteur indépendant

Ladybird est un projet indépendant de navigateur web et de moteur de navigateur fondé sur les standards du Web. Le README officiel le décrit comme pré-alpha et destiné uniquement aux développeurs ; son architecture multiprocessus sépare notamment les connexions réseau et le décodage des images.

## Installation
**Cloner le code source**

```
git clone https://github.com/LadybirdBrowser/ladybird.git
```

**Entrer dans le répertoire du projet**

```
cd ladybird
```


## Exécution
**Compiler et exécuter**

```
./Meta/ladybird.py run
```


## Que fait cet outil ?
Ladybird est un projet open source de navigateur et de moteur de navigateur. Il fonctionne sous Linux, macOS, Windows avec WSL2 et d’autres systèmes de type Unix. Le site du projet vise une première version Alpha en 2026 pour Linux et macOS, tandis que le guide de compilation exige Qt 6.9+, un compilateur compatible C++23, Rust et CMake 3.30+.

## Pour qui ?
Les développeurs qui souhaitent étudier les technologies des navigateurs, contribuer au projet ou compiler le code source dans un environnement de développement.

## À quoi ne faut-il pas s’attendre ?
Les personnes qui recherchent un navigateur stable pour un usage quotidien.

## Points forts
- Projet indépendant de navigateur et de moteur fondé sur les standards du Web.
- Architecture multiprocessus avec des processus séparés pour les connexions réseau et le décodage des images.
- Processus renderer sandboxés pour les onglets.
