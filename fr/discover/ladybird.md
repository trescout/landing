# Navigateur Web autonome Ladybird

Ladybird est un nouveau navigateur Web développé indépendamment des principaux moteurs de navigation existants. Écrit en C++, ce projet vise à fournir une alternative open source basée sur les standards Internet.

## Ce que ça vous apporte
- Offre une nouvelle structure indépendante des moteurs de navigateur existants
- Fournit une alternative open source basée sur les normes Internet
- Vise une expérience de navigation sécurisée et durable avec son architecture multi-traitement
