# Intégrez les modèles DeepSeek dans vos outils

partagée sur GitHub, Awesome-deepseek-agent est une collection de ressources qui répertorie les agents d'intelligence artificielle (agents IA) développés avec les modèles et outils DeepSeek dans ce domaine. Il rassemble des projets et des intégrations qui aident les développeurs à créer des systèmes autonomes à l'aide de l'infrastructure DeepSeek.

- ★ 5 755
- GitHub Trending · 2026-08-15

## Ce que ça vous apporte
- Accédez aux guides d’installation des agents IA populaires
- Possibilité d'utiliser les modèles DeepSeek dans les assistants de codage
- Prise en charge de la configuration pour les systèmes autonomes et les véhicules basés sur des terminaux

## Pour commencer
Vous devez d’abord obtenir une clé API via la plateforme DeepSeek. Ensuite, consultez le tableau sur la page GitHub et cliquez sur le lien du guide à côté de l'outil que vous souhaitez utiliser. Chaque guide détaille les étapes dont vous avez besoin pour installer l'outil de votre choix et le configurer avec les modèles DeepSeek.
