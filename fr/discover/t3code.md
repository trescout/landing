# Interface Web pour les agents de codage

T3Code est un ensemble d'outils développé pour améliorer et standardiser la qualité du code dans les projets basés sur TypeScript. Il fournit une prise en charge d'automatisation aux développeurs dans les processus de sécurité des types et d'édition de code.

## Si vous ne codez pas

Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

A l'aide de l'outil T3 Code, configurez l'un des fournisseurs Codex, Claude, Cursor ou OpenCode et lancez l'interface de l'agent de codage. Après avoir terminé le processus d'authentification du fournisseur que vous avez choisi, exécutez l'outil et commencez à recevoir une assistance au codage sur vos projets.

Dépôt : https://github.com/pingdotgg/t3code. Base-toi sur les instructions officielles du fichier README de ce dépôt pour l'installation et l'exécution.

Avant de commencer, vérifie quel système d'exploitation nous utilisons et si les outils nécessaires (ex: Python, Node.js, Git, Docker) sont installés. Installe ceux qui manquent étape par étape selon ce système.

Crée un nouveau dossier vide pour travailler. Ne touche pas aux fichiers en dehors de ce dossier et ne supprime rien. Avant chaque commande, décris ce que tu vas faire en une phrase.

Dis-moi ce que je devrais voir à l'écran à la fin de chaque étape. Si une erreur survient, je te copierai le message d'erreur tel quel et nous la corrigerons ensemble.
