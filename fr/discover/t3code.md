# Interface Web pour les agents de codage

T3Code est un ensemble d'outils développé pour améliorer et standardiser la qualité du code dans les projets basés sur TypeScript. Il fournit une prise en charge d'automatisation aux développeurs dans les processus de sécurité des types et d'édition de code.

## Ce que ça vous apporte
- Prise en charge du Codex, Claude, Cursor et OpenCode
- Gestion du code visuel via navigateur
- Options d'installation et de fonctionnement rapides

## Installation
**Installation sur macOS**

```
brew install --cask t3-code
```


## Exécution
**Fonctionnement sans installation**

```
npx t3@latest
```


## Si vous ne codez pas
A l'aide de l'outil T3 Code, configurez l'un des fournisseurs Codex, Claude, Cursor ou OpenCode et lancez l'interface de l'agent de codage. Après avoir terminé le processus d'authentification du fournisseur que vous avez choisi, exécutez l'outil et commencez à recevoir une assistance au codage sur vos projets.
