# Outil de collecte de renseignements open source

SpiderFoot est un outil Python qui automatise la collecte de renseignements open source (OSINT) pour les processus de renseignement sur les menaces et de cartographie des surfaces d'attaque. Il permet de détecter les failles de sécurité sur les actifs numériques en intégrant diverses sources de données.

## Ce que ça vous apporte

- Collecte automatique de données avec plus de 200 modules
- Interface Web ou prise en charge de la ligne de commande
- Cartographie complète des surfaces d'attaque pour les actifs numériques

## Installation

**Installation de la version stable**

```
wget https://github.com/smicallef/spiderfoot/archive/v4.0.tar.gz
 tar zxvf v4.0.tar.gz
 cd spiderfoot-4.0
 pip3 install -r requirements.txt
```

**Installation de la version de développement**
