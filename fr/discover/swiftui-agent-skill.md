# Expertise SwiftUI pour votre assistant d'intelligence artificielle

SwiftUI-Agent-Skill propose des packs de compétences (skills) spécifiques aux modèles d'intelligence artificielle pour SwiftUI, l'outil de développement d'interfaces. Cette ressource aide les assistants de codage IA tels que Claude Code et Codex à créer des composants SwiftUI de manière plus cohérente et plus rapide.

## Ce que ça vous apporte

- Permet à l'intelligence artificielle de vérifier les erreurs de performance et d'accessibilité dans le code écrit avec SwiftUI, la bibliothèque d'interface d'Apple.
- Empêche les grands modèles de langage d'utiliser des interfaces de programmation d'application (API) obsolètes et évite les problèmes de lecture d'écran.
- S'intègre facilement dans les assistants de codage Claude Code et Codex pour leur apporter des standards de code modernes.

## Installation

**Environnement Node avec le gestionnaire de paquets Homebrew**

```
brew install node
```

**La compétence SwiftUI Pro à l'assistant d'i**

```
npx skills add https://github.com/twostraws/swiftui-agent-skill --skill swiftui-pro
```

## Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Si l'environnement d'exécution Node n'est pas installé sur mon ordinateur, installe-le en utilisant la commande 'brew install node'.
