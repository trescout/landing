# Développement assisté par l'IA dans le terminal

Développé par Moonshot AI, Kimi CLI est un agent d'intelligence artificielle qui fonctionne via une interface de ligne de commande (CLI). Cet outil basé sur Python est conçu pour automatiser les interactions en ligne de commande dans les processus de développement logiciel.

## Ce que ça vous apporte
- Capacité à lire et à modifier le code
- Exécuter des commandes via un terminal
- Recherche Web et planification autonome

## Installation
**Configuration de l'environnement de développement**

```
git clone https://github.com/MoonshotAI/kimi-cli.git
cd kimi-cli

make prepare  # prepare the development environment
```


## Si vous ne codez pas
Je veux que vous travailliez en tant qu'agent de développement au sein du terminal. Tout en effectuant mes tâches de développement logiciel, je lis et modifie mes fichiers de code, exécute les commandes shell nécessaires et planifie les processus de manière autonome en recherchant sur Internet lorsque j'en ai besoin.
