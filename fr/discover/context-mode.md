# Mémoire permanente pour votre agent IA

Context-mode est une bibliothèque TypeScript qui permet l'optimisation de la fenêtre de contexte pour les agents de codage par intelligence artificielle. Elle réduit la taille des données de 98 % en isolant les sorties des outils, préserve la mémoire de session et effectue des redirections vers 17 plateformes différentes via le protocole de contexte de modèle (Model Context Protocol).

## Ce que ça vous apporte
- Libère la fenêtre de contexte en réduisant la taille des données de 98 %
- Assure la continuité de la session en suivant les modifications de fichiers et les tâches dans une base de données SQLite
- Augmente la capacité de traitement du modèle grâce à une structure qui fait écrire du code au lieu de traiter les données

## Installation
**Installation via Claude Code**

```
/plugin marketplace add mksglu/context-mode
```

**Finalisation de l'installation de l'extension**

```
/plugin install context-mode@context-mode
```


## Exécution
**Vérification de l'installation**

```
/context-mode:ctx-doctor
```


## Si vous ne codez pas
Mon agent d'intelligence artificielle, à partir de maintenant, au lieu d'effectuer directement les tâches de traitement de données, je veux que tu écrives et exécutes le code qui analysera ces données. Utilise les outils de context-mode pour minimiser la taille des données, conserve mon historique de session sur SQLite et ne me rapporte que les résultats nécessaires. Évite les explications inutiles et concentre-toi uniquement sur la génération de code et la gestion efficace du contexte.
