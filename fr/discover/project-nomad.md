# Ordinateur de survie sans Internet

Projet N.O.M.A.D ; Il s'agit d'un projet de construction informatique autonome et hors ligne qui ne nécessite pas de connexion Internet et est équipé d'outils critiques, de ressources d'information et d'intelligence artificielle. Il est spécialement conçu pour les urgences et les scénarios où il n’y a pas d’Internet.

- ★ 36 474
- TypeScript
- Apache-2.0
- GitHub Trending · 30 May 2026

## Ce que ça vous apporte
- Il offre des outils et des informations critiques qui ne nécessitent pas Internet.
- Fournit un support d’intelligence artificielle local (hors ligne).
- Il permet de se préparer à des scénarios d’urgence et hors ligne.

## Comment installer, comment utiliser ?
**Installation rapide (Debian/Ubuntu)**

```
curl -fsSL https://raw.githubusercontent.com/Crosstalk-Solutions/project-nomad/refs/heads/main/install/install_nomad.sh -o install_nomad.sh
sudo bash install_nomad.sh
```

**commencer**

```
sudo bash /opt/project-nomad/start_nomad.sh
```
