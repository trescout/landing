# Exécutez des opérations d'IA dans votre base de code

Développé par Anthropics, Claude Code Action est un outil qui permet aux développeurs d'effectuer des opérations prises en charge par l'IA directement sur leurs bases de code. Cette solution basée sur TypeScript vise à accélérer les flux de développement de logiciels en automatisant les processus d'édition et d'analyse de code.
