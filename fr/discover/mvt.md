# Rechercher des signes de cyberattaques sur les appareils mobiles

Mobile Verification Toolkit est un outil d'investigation numérique utilisé pour détecter les failles de sécurité sur les appareils mobiles. Ce logiciel, développé avec le langage Python, analyse les données des appareils et révèle d'éventuelles traces de cyberattaques.

- ★ 14 955
- GitHub Trending · 2026-09-22

## Ce que ça vous apporte
- Collecte des traces médico-légales numériques sur les appareils Android et iOS
- Analyse les traces de campagnes de logiciels espions connues
- Effectue une analyse de sécurité avec des outils de ligne de commande

## Installation
**installer avec pip**

```
pip3 install mvt
```

**installer avec uv**

```
uv tool install mvt
```


## Exécution
**Créer un script d'achèvement**

```
mvt completion bash
```
