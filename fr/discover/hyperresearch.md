# Recherche approfondie avec l'intelligence artificielle

Hyperresearch est un outil de recherche basé sur des agents d'intelligence artificielle (AI agents) qui collecte des données sur Internet, les analyse et les transforme en une base de connaissances permanente. Développé en Python, ce système consolide les recherches Internet dispersées dans une structure wiki organisée et interrogeable.

## Ce que ça vous apporte
- Parcourt et vérifie plus de 250 sources avec une seule commande.
- Stocke les informations obtenues dans une base de connaissances permanente et interrogeable.
- Génère des rapports impartiaux en effectuant des recoupements entre des sources académiques et techniques.

## Installation
**Intégrer l'outil au projet**

```
cd your-project
pip install hyperresearch && hyperresearch install
```
