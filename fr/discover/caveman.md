# Économisez de l'argent en raccourcissant les réponses de l'IA

Caveman est un package de fonctionnalités développé pour Claude Code qui réduit la consommation de jetons de 65 % en simplifiant l'utilisation du langage du modèle d'intelligence artificielle. Cet outil vise à réduire les coûts de traitement en réduisant les commandes complexes à une structure de langage primitive.

## Ce que ça vous apporte
- Économise jusqu'à 65 % de jetons sur les réponses de l'IA.
- Élimine les mots inutiles sans sacrifier la précision technique.
- Cela réduit les coûts de transaction et augmente la vitesse de réponse.

## Installation
**Configuration pour macOS, Linux et WSL**

```
curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.sh | bash
```

**installation pour fenêtres**

```
irm https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.ps1 | iex
```


## Exécution
**Activer le mode**

```
/caveman
```


## Si vous ne codez pas
Désormais, donnez vos réponses en mode Caveman. Supprimez les mots de remplissage inutiles, ne conservez que les informations concises et les détails techniques. Composez vos réponses en phrases courtes, concises et fragmentées ; mais continuez à transmettre des blocs de code, des commandes et des messages d'erreur complets et précis.
