# Surveillez vos agents de codage avec l’intelligence artificielle

Agentsview est un outil de surveillance qui fournit des données d'analyse et d'intelligence de session locales pour les agents de codage. Ce logiciel, qui supporte plus d'une vingtaine d'agents, dont Claude Code et Codex, promet des performances plus rapides par rapport à l'outil ccusage.

## Ce que ça vous apporte
- Surveillez les sessions de tous vos agents de codage d’intelligence artificielle depuis un seul centre.
- Calculez rapidement les montants et les coûts des jetons utilisés.
- Protégez la confidentialité en conservant vos données sur votre ordinateur local.

## Installation
**macOS/Linux**

```
curl -fsSL https://agentsview.io/install.sh | bash
```

**Fenêtres**

```
powershell -ExecutionPolicy ByPass -c "irm https://agentsview.io/install.ps1 | iex"
```


## Exécution
**Démarrage du serveur et accès à l'interface**

```
agentsview serve
```

**Afficher le récapitulatif des coûts quotidiens**

```
agentsview usage daily
```
