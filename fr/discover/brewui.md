# Interface graphique pour la gestion de paquets macOS

Homebrew est un outil en ligne de commande permettant de gérer les paquets logiciels sur le système d'exploitation macOS. BrewUI est une application de bureau officielle qui vous permet de gérer les commandes complexes de cet outil via une interface graphique (GUI).

- ★ 1 658
- Swift
- GitHub Trending · 2026-09-16

## Ce que ça vous apporte
- Gérez vos paquets logiciels sans utiliser la ligne de commande
- Suivez les opérations Homebrew avec une interface transparente
- Installation facile avec une application macOS native basée sur SwiftUI

## Installation
**Installer l'application**

```
brew install --cask homebrew-app
```


## Si vous ne codez pas
J'utilise l'application BrewUI pour gérer mes paquets Homebrew. Je souhaite découvrir, installer, mettre à jour et gérer les paquets en toute sécurité au sein de l'application. En utilisant cette interface qui me permet de voir de manière transparente les opérations effectuées par Homebrew en arrière-plan, comment puis-je optimiser la configuration des paquets sur mon système et définir des variables personnalisées via le fichier brew.env ?
