# Agents d'IA intelligents sur Java

Embabel est un framework conçu pour développer des agents d'intelligence artificielle fonctionnant sur la machine virtuelle Java (JVM). Cette structure, écrite en Kotlin, facilite l'intégration des capacités d'IA générative dans les écosystèmes logiciels d'entreprise.

## Ce que ça vous apporte

- Il intègre des modèles d'intelligence artificielle aux systèmes d'entreprise basés sur Java et Kotlin.
- Il résout des tâches complexes de manière dynamique grâce à une capacité de planification automatique.
- Grâce à une vérification de type renforcée, il gère les interactions entre le code et l’intelligence artificielle sans erreurs.
