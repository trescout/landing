# Langage de programmation rapide et fiable

Développé par Google, le langage de programmation Go est un langage de programmation système open source conçu pour créer des logiciels performants et évolutifs. Il est largement préféré dans les infrastructures de cloud computing modernes avec sa gestion de la concurrence et ses temps de compilation rapides.

## Ce que ça vous apporte
- Structure de code simple et compréhensible
- Capacité de travail haute performance
- Efficacité pour les systèmes cloud modernes

## Installation
**macOS (Homebrew)**

```
brew install go
```

**Windows (winget)**

```
winget install GoLang.Go
```


## Exécution
**Vérifier la version**

```
go version
```
