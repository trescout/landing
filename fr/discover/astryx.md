# Système de conception compatible avec l’intelligence artificielle

Développé par Meta, Astryx propose un système de conception entièrement personnalisable et compatible avec les agents d'intelligence artificielle. Cette bibliothèque open source basée sur TypeScript configure les composants d'interface pour l'utilisation de systèmes autonomes.

- ★ 12 124
- TypeScript
- GitHub Trending · 2026-07-01

## Ce que ça vous apporte
- Plus de 150 composants accessibles
- API compatible avec les assistants IA
- Structure flexible sans restrictions de style

## Installation
**Installer des packages**

```
# npm
npm install @astryxdesign/core @astryxdesign/theme-neutral
npm install -D @astryxdesign/cli

# pnpm
pnpm add @astryxdesign/core @astryxdesign/theme-neutral
pnpm add -D @astryxdesign/cli

# yarn
yarn add @astryxdesign/core @astryxdesign/theme-neutral
yarn add -D @astryxdesign/cli
```
