# Docling

Docling est une bibliothèque Python qui convertit les formats de documents complexes en texte clair ou en données structurées que les modèles d'IA génératifs peuvent traiter. Il facilite l'utilisation des données dans les applications d'intelligence artificielle en analysant différents types de fichiers tels que PDF, Word et HTML.
