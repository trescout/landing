# Gestionnaire de téléchargement moderne et complet

Motrix est un gestionnaire de téléchargement complet développé avec TypeScript qui répond à tous les besoins de téléchargement de fichiers. Il offre aux utilisateurs la possibilité de gérer différents protocoles tels que HTTP, FTP et BitTorrent via une seule interface.

## Ce que ça vous apporte

- Gère les protocoles HTTP, FTP et BitTorrent à partir d'une seule interface
- Limite les vitesses de téléchargement et offre une gestion avancée des sessions
- Lance les téléchargements en un clic avec les modules complémentaires du navigateur

## Installation

**Installation de l'interface de ligne de commande**

```
npm install -g @motrix/cli
```

## Exécution

**Démarrer le téléchargement du fichier**

```
motrix add https://example.com/file.iso --save-dir ~/Downloads
```
