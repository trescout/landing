# Créez une liste de mots de passe ciblée

Common User Passwords Profiler est un outil Python permettant de créer des listes de mots de passe ciblées. Il prépare des fichiers de dictionnaire personnalisés (listes de mots) en analysant les données utilisateur spécifiques.

- ★ 6 161
- Python
- GitHub Trending · 2026-07-01

## Ce que ça vous apporte

- Il prépare des dictionnaires personnalisés en analysant les données des utilisateurs.
- Il offre la possibilité de créer un profil ciblé avec des questions interactives.
- Analyse les correspondances de nom d'utilisateur et de mot de passe par défaut avec la base de données Alecto.

## Installation

**Cloner le référentiel**

```
git clone --depth 1 https://github.com/Mebus/cupp.git && cd cupp
```

## Exécution

**Exécuter en mode interactif**

```
python3 cupp.py -i
```
