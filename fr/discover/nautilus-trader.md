# Plateforme de trading algorithmique haute performance

Nautilus Trader est un moteur de trading doté d'une architecture déterministe basée sur les événements, développé en langage Rust. Elle propose des solutions d'infrastructure de niveau production pour des systèmes financiers hautes performances.

## Ce que ça vous apporte
- Infrastructure de trading rapide et sécurisée basée sur Rust
- Transition de la recherche à la vie sans changements de code
- Prise en charge de plusieurs bourses et classes d'actifs

## Installation
**Installation standard**

```
pip install -U nautilus_trader
```

**Installation à partir d'un référentiel de packages privé**

```
pip install -U nautilus_trader --index-url=https://packages.nautechsystems.io/simple
```
