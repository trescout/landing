# Ensemble d'outils AWS pour les agents IA

AWS a publié un ensemble d'outils comprenant des serveurs, des compétences et des plug-ins Model Context Protocol pour faciliter l'interaction des agents d'IA avec l'infrastructure cloud. Ce développement fournit une structure standardisée qui permet aux agents d'opérer directement sur les services AWS.

## Ce que ça vous apporte
- Interaction directe et sécurisée avec les services AWS
- Capacités standardisées pour les agents IA
- Plugins prêts à l'emploi pour la gestion de l'infrastructure cloud

## Exécution
**Ajouter des fonctionnalités**

```
npx skills add aws/agent-toolkit-for-aws/skills
```


## Si vous ne codez pas
Aidez-moi à développer, déployer et gérer des applications sur AWS. Interagissez avec les services AWS à l'aide des fonctionnalités Agent Toolkit for AWS, effectuez les configurations nécessaires et effectuez les opérations sur l'infrastructure cloud conformément aux normes.
