# Gestion centralisée des identités pour vos applications

Keycloak propose des solutions open source de gestion des identités et des accès pour les applications et services modernes. Cette plate-forme basée sur Java est utilisée pour normaliser les processus centralisés d'authentification et d'autorisation.

- ★ 36 028
- Java
- GitHub Trending · 2026-06-28

## Ce que ça vous apporte
- Standardise les processus d’authentification des utilisateurs.
- Fournit une gestion et une autorisation solides des identités.
- Augmente sans effort la sécurité des applications.

## Installation
**Prenez l'image officielle**

```
docker pull quay.io/keycloak/keycloak
```


## Exécution
**Démarrer en mode développement**

```
docker run -p 8080:8080 -e KC_BOOTSTRAP_ADMIN_USERNAME=admin -e KC_BOOTSTRAP_ADMIN_PASSWORD=admin quay.io/keycloak/keycloak start-dev
```
