# Peinture de textures pour modèles 3D

ArmorPaint est un outil de conception graphique permettant de peindre des textures en temps réel sur des modèles 3D. Le logiciel offre aux artistes numériques une flexibilité dans les processus complexes de création de textures grâce à la prise en charge du rendu basé sur la physique (PBR).

## Ce que ça vous apporte
- Peignez des textures en temps réel sur des modèles
- Obtenez des résultats professionnels avec la prise en charge du rendu basé sur la physique
- Accélérez les processus complexes de création de textures

## Installation
**Téléchargez les fichiers sur votre ordinateur**

```
git clone https://github.com/armory3d/armorpaint
cd armorpaint/paint
```


## Exécution
**Exécution sous Linux**

```
../base/make --run
```


## Si vous ne codez pas
Aidez-moi dans mes processus de modélisation 3D et de texturage. Permettez-moi de préparer des revêtements réalistes pour mes modèles en utilisant des techniques de rendu basées sur la physique (PBR). Guidez-moi étape par étape lorsque je rencontre des problèmes techniques ou que je suis bloqué lors de la phase de création de textures.
