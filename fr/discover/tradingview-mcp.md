# Intégration de l'IA pour TradingView

TradingView-mcp connecte Claude Code à l'application de bureau TradingView, vous permettant d'automatiser les processus d'analyse graphique. Cette intégration permet aux utilisateurs de personnaliser les flux de travail d'analyse technique via un contexte de modèle alimenté par l'IA (Model Context Protocol).

## Ce que ça vous apporte

- Codage et débogage Pine Script avec intelligence artificielle
- Gestion automatique des tracés et analyses sur la carte
- Contrôlez les alertes de prix et les symboles par commande

## Installation

**Téléchargement de fichiers et installation**

```
git clone https://github.com/tradesdontlie/tradingview-mcp.git
cd tradingview-mcp
npm install
```

**Lancement sur macOS**

```
./scripts/launch_tv_debug_mac.sh
```

## Exécution

**Utilisation directe via CLI**

```
# Install globally (optional)
npm link

# Or run directly
node src/cli/index.js <command>
```
