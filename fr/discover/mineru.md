# Convertissez vos documents pour l'IA

MinerU convertit les formats de documents complexes tels que PDF et Office en format markdown ou JSON adapté aux grands modèles de langage. Cet outil vise à rendre les données non structurées disponibles dans des workflows basés sur des agents.

## Ce que ça vous apporte

- Convertit les fichiers PDF et Office en langage de balisage
- Prépare les données non structurées pour les flux de travail des agents
- Convertit les formats de documents complexes en sortie JSON

## Installation

**Installation standard**

```
pip install --upgrade pip
pip install uv
uv pip install -U "mineru[all]"
```

**Installation du développeur**

```
git clone https://github.com/opendatalab/MinerU.git
cd MinerU
uv pip install -e .[all]
```
