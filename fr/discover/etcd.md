# Magasin clé-valeur pour systèmes distribués

etcd est un magasin clé-valeur fiable conçu pour stocker les données critiques dans les systèmes distribués. Développé en Go, ce système se concentre sur la garantie de la cohérence des données au sein des architectures distribuées.

## Ce que ça vous apporte

- stocke en toute sécurité les données critiques dans les systèmes distribués
- atteint des dizaines de milliers d'écritures par seconde
- offre un chiffrement TLS automatique et une authentification par certificat client

## Installation

**Installer le client**

```
go get go.etcd.io/etcd/client/v3
```
