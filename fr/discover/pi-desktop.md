# Espace de travail pour les agents de codage par intelligence artificielle

PI-Desktop est un agent de codage par intelligence artificielle développé selon le principe du « local-first ». Grâce à son architecture basée sur Electron (framework de développement d'applications de bureau) et Rust (langage de programmation système), il offre un environnement de développement logiciel personnalisable où les utilisateurs peuvent installer leurs propres extensions.

- ★ 1 990
- TypeScript
- GitHub Trending · 2026-09-10

## Ce que ça vous apporte
- Gérez différents modèles d'intelligence artificielle à partir d'une interface unique.
- Contrôlez les autorisations de l'agent pour la modification de fichiers et l'exécution de commandes.
- Personnalisez l'environnement de développement avec des extensions et des fonctionnalités.

## Installation
**Compilation à partir du code source**

```
git clone https://github.com/vastsa/PI-Desktop.git
cd PI-Desktop

pnpm install

cargo build -p host-core
pnpm build:js

pnpm dev
```


## Exécution
**Lancement en mode développement**

```
pnpm dev
```
