# Gestion open source pour les appareils Logitech

OpenLogi est une alternative native et open source à Logitech Options+ écrite en Rust. Configure les boutons, le DPI et SmartShift sans nécessiter de comptabilité ou de télémétrie.

## Ce que ça vous apporte

- Fournit un contrôle local sans créer de compte
- Attribue des raccourcis personnalisés à toutes les touches
- Offre un support multiplateforme, y compris Linux

## Installation

**Installation standard avec Homebrew**

```
brew install --cask openlogi
```

**Suivez la dernière version**

```
brew tap aprilnea/tap
brew install --cask aprilnea/tap/openlogi@latest
```
