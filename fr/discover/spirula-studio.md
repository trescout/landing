# Studio Spirule

Spirula Studio est un outil pédagogique multiplateforme qui convertit les vidéos en représentations de scènes tridimensionnelles (3D Gaussian Splatting) et les convertit en maillages. Le logiciel fournit un environnement de travail compatible avec différents fabricants de matériel utilisant les interfaces graphiques Vulkan ou CUDA.
