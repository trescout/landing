# Documents de conception prêts pour l'intelligence artificielle

Awesome-design-md est une collection de documents de conception (DESIGN.md) issus de systèmes de conception de marques populaires. À l'aide de ces documents, les agents logiciels peuvent créer des interfaces utilisateur (UI) adaptées aux projets.

## Ce que ça vous apporte
- Apportez les langages de conception de marques populaires à vos projets
- Maintenir la cohérence visuelle avec les agents IA
- Intégrez des systèmes de conception dans votre projet sans écrire de code
