# Terminal de trading autonome assisté par intelligence artificielle

CloddsBot est un agent de trading IA open source qui effectue des transactions autonomes sur plus de 1000 marchés. Basé sur Claude, ce logiciel gère des processus d'achat et de vente automatisés sur diverses plateformes de cryptomonnaies et de prédiction (Polymarket, Binance) grâce à la gestion des risques et aux protocoles de paiement machine à machine.

- ★ 2 262
- TypeScript
- GitHub Trending · 2026-09-11

## Ce que ça vous apporte
- Trading automatisé sur plus de 1000 marchés
- Portefeuille et stratégies gérables en langage naturel
- Intégration complète avec 21 plateformes de messagerie différentes

## Installation
**Installation rapide**

```
npm install -g clodds --loglevel=error
clodds onboard
```

**Installation à partir du code source**

```
git clone https://github.com/alsk1992/CloddsBot.git && cd CloddsBot
npm install && cp .env.example .env
# Add ANTHROPIC_API_KEY to .env
npm run build && npm start
```


## Exécution
**Démarrage de l'interface**

```
clodds start
```


## Si vous ne codez pas
Tu es un assistant de trading. Je souhaite que tu analyses les marchés des cryptomonnaies et les plateformes de prédiction en utilisant CloddsBot avec plus de 118 stratégies. En appliquant les règles de gestion des risques, gère les transactions d'achat et de vente automatisées dans la limite du budget que j'ai défini et présente-moi des rapports en surveillant les données du marché.
