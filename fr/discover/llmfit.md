# Trouvez des modèles d'IA adaptés à votre matériel

Développé avec le langage Rust, llmfit analyse des centaines de grands modèles et fournisseurs de langages et vous permet d'identifier ceux compatibles avec votre matériel avec une seule commande. L'outil automatise le processus de recherche de modèles les mieux adaptés aux ressources du système local.

- ★ 32 610
- Rust
- GitHub Trending · 2026-07-22

## Ce que ça vous apporte
- Détecte automatiquement les modèles compatibles avec votre système
- Trie par mémoire, vitesse et qualité
- Fournit une gestion facile avec une interface interactive

## Installation
**Installation pour macOS ou Linux**

```
brew install AlexsJones/llmfit/llmfit
```

**Installation rapide**

```
curl -fsSL https://llmfit.axjns.dev/install.sh | sh
```


## Exécution
**Démarrage de l'interface interactive**

```
llmfit
```


## Si vous ne codez pas
Analysez les spécifications matérielles de mon système et recommandez les meilleurs modèles d'IA à exécuter en fonction de ma capacité RAM, CPU et GPU disponible. Trier les modèles selon des critères de performances, d'utilisation mémoire et de qualité et lister ceux qui me conviennent le mieux.
