# Indexation vectorielle hautes performances avec Rust

Construit sur l'infrastructure TurboQuant, turbovec est un outil d'indexation vectorielle hautes performances développé avec le langage Rust. Grâce aux liaisons Python, il permet aux développeurs d'effectuer des opérations de recherche vectorielles rapidement et efficacement.

## Ce que ça vous apporte
- Il réduit l'utilisation de la mémoire en compressant fortement les données vectorielles.
- Il permet un ajout instantané de données et une recherche rapide sans nécessiter de phase de formation.
- Il maintient les performances en effectuant des opérations de filtrage pendant la recherche.

## Installation
**Installation pour Python**

```
pip install turbovec
```

**Installation pour la rouille**

```
cargo add turbovec
```
