# Agent IA pour applications de messagerie

AstrBot est un framework de développement d'agents d'intelligence artificielle qui s'intègre à diverses plateformes de messagerie instantanée, de grands modèles de langage et des plug-ins. Cet outil basé sur Python permet de créer des assistants IA personnalisables comme alternative open source.

- ★ 39 919
- Python
- GitHub Trending · 2026-07-20

## Ce que ça vous apporte
- Intégration avec les plateformes de messagerie populaires
- Structure extensible avec des milliers de plugins
- Zone de travail des agents sécurisée et isolée

## Installation
**installation avec uv**

```
uv tool install astrbot --python 3.12
```


## Exécution
**Première installation et fonctionnement**

```
astrbot init # Only execute this command for the first time to initialize the environment
astrbot run
```


## Si vous ne codez pas
Je souhaite créer un assistant d'intelligence artificielle personnalisable sur mes plateformes de messagerie grâce à AstrBot. Aidez-moi à créer un agent IA configuré en fonction de mes besoins et qui s'intègre à mes flux de travail personnels et professionnels, en utilisant la prise en charge des plug-ins, les capacités multimodales et les fonctionnalités de l'espace de travail de l'agent de la plateforme.
