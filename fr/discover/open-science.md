# Environnement de travail IA pour la recherche scientifique

Open Science, développé par AIPOCH, propose un environnement de travail IA local et indépendant du modèle pour la recherche scientifique. Le logiciel combine des notebooks Python et R avec des connexions de données pour permettre la réalisation de processus scientifiques reproductibles.

## Ce que ça vous apporte

- Effectuez des analyses scientifiques reproductibles en exécutant du code Python et R
- Générez des rapports, des tableaux et des graphiques automatiques en vous connectant à des sources de données scientifiques
- Gérez l'ensemble du processus, de la revue de littérature à la simulation, avec des agents IA locaux

## Installation

**Installation locale à partir du code source**

```
git clone https://github.com/aipoch/open-science.git
cd open-science
npm install
npm run dev
```

**Mode de développement de l'interface web**

```
npm run build:web
npm run dev:web
```
