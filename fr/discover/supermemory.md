# Mémoire intelligente pour l'intelligence artificielle

Supermemory propose un moteur de mémoire et une API hautement évolutifs conçus pour l'ère de l'intelligence artificielle. Il vous permet d'ajouter une couche mémoire persistante et interrogeable à vos applications.

- ★ 28 742
- TypeScript
- MIT
- GitHub Trending · 1 Haziran 2026

## Ce que ça vous apporte
- Il ajoute une couche de mémoire persistante à votre application.
- Prise en charge de l'architecture évolutive.
- Intégration facile via API.

## Comment installer, comment utiliser ?
**Installer le SDK (Node ou Python)**

```
npm install supermemory    # ya da: pip install supermemory
```

**Connectez le serveur MCP au client AI**

```
npx -y install-mcp@latest https://mcp.supermemory.ai/mcp --client claude --oauth=yes
```
