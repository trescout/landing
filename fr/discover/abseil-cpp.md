# Outils qui exploitent la bibliothèque standard C++

Développé par Google, Abseil propose des extraits de code open source qui complètent la bibliothèque standard C++. Cette bibliothèque fournit des structures de données et des algorithmes de base pour améliorer la maintenabilité et les performances du code dans les projets logiciels complexes.

## Ce que ça vous apporte
- Fournit des structures de données et des algorithmes sous-jacents compatibles C++17
- Fournit des morceaux de code fiables testés dans les projets Google
- Complète les fonctionnalités manquantes dans la bibliothèque standard

## Installation
**macOS (Homebrew)**

```
brew install abseil
```
