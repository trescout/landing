# Formation en IA dans Apple Neural Engine

Développé par Maderix, ANE permet d'effectuer une formation aux réseaux de neurones sur Apple Neural Engine via des interfaces de programmation d'applications privées (API privées) obtenues par rétro-ingénierie. Cette étude permet d'utiliser directement le matériel Apple dans les processus de formation de modèles d'intelligence artificielle.

Ce projet est une étude de recherche qui vise à former des réseaux de neurones directement sur le matériel Apple. En téléchargeant les fichiers du projet depuis le référentiel officiel sur GitHub sur votre ordinateur, vous pouvez examiner comment les API spéciales obtenues par ingénierie inverse sont utilisées et mener vos propres expériences.
