# Framework de développement d'applications web pilotées par une base de données

Ruby on Rails est un framework d'application web utilisé pour développer des applications web pilotées par une base de données et basé sur l'architecture Modèle-Vue-Contrôleur (Model-View-Controller). Il vise à standardiser les processus en offrant aux développeurs tous les outils dont ils ont besoin en un seul endroit.
