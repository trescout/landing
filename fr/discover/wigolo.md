# Fonctionnalités Web natives pour votre agent IA

Wigolo est un outil qui fournit des capacités de recherche, d'extraction de données et d'exploration locales pour les agents de codage d'intelligence artificielle. Ce système, qui fonctionne sur le protocole de contexte de modèle (MCP), permet une recherche gratuite sans dépendance au cloud et sans nécessiter de clé API.

## Ce que ça vous apporte
- Recherche et analyse gratuites sans clé API requise
- Traitement et mise en cache des données locales indépendants du cloud
- Intégration directe avec les outils d'IA populaires

## Installation
**Installation de l'agent de démarrage**

```
npx wigolo init --agents=<your-agent>
```

**Vérification de l'état du système**

```
npx wigolo doctor
```


## Si vous ne codez pas
Utilisez Wigolo pour rechercher sur le Web, extraire des données et synthétiser vos résultats en citant des sources. Lorsque vous effectuez des transactions, respectez le principe de fonctionnement local d'abord, utilisez des outils de base qui ne nécessitent pas de clé API et rapportez vos résultats de manière structurée.
