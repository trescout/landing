# Gestion d'investissement avec l'IA autonome

AutoHedge est un framework qui utilise l'intelligence en essaim et des agents d'IA pour automatiser l'analyse de marché, la gestion des risques et les opérations de trading. Il permet aux utilisateurs de créer leurs propres fonds spéculatifs autonomes (autonomous hedge fund) en quelques minutes.

## Ce que ça vous apporte
- Automatise l'analyse de marché et la gestion des risques
- Fonctionne avec plusieurs agents d'IA spécialisés
- Capable d'effectuer des transactions entièrement autonomes sur Solana

## Installation
**Installez la bibliothèque sur votre ordinateur**

```
pip install -U autohedge
```


## Exécution
**Lancez le système de fonds d'investissement**

```
autohedge
```


## Si vous ne codez pas
Je souhaite créer une stratégie d'investissement en utilisant le système AutoHedge. Je veux que vous effectuiez une analyse de marché avec le Director Agent, que vous évaluiez les données techniques avec le Quant Agent et que vous déterminiez la taille des positions avec le Risk Management Agent. Avant d'exécuter les transactions, rapportez toutes les analyses de risques via ce framework basé sur l'IA.
