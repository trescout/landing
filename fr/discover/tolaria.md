# Application de bureau de base de connaissances Markdown

Tolaria est une application de bureau développée pour gérer les bases de connaissances basées sur Markdown. Écrit en TypeScript, cet outil facilite l'organisation des systèmes de documentation personnelle et de notes.

## Ce que ça vous apporte

- Fournit une gestion de notes portable avec des fichiers de démarque.
- Offre un contrôle complet des versions avec l'intégration de Git.
- Protège la propriété des données avec une prise en charge du travail hors ligne.

## Installation

**Dépendances pour Arch/Manjaro**

```
sudo pacman -S --needed webkit2gtk-4.1 base-devel curl wget file openssl \
    appmenu-gtk-module libappindicator-gtk3 librsvg
```

**Dépendances pour Debian/Ubuntu**

```
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
    libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev \
    libsoup-3.0-dev patchelf
```

## Exécution

**Démarrage de l'environnement de développement**

```
pnpm install
pnpm dev
```

**Exécutez l'application de bureau**

```
pnpm tauri dev
```
