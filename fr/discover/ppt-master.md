# L'intelligence artificielle qui transforme les documents en présentations modifiables

PPT-Master est un outil basé sur l'IA qui convertit les documents directement en fichiers de présentation modifiables (PPTX). Le système traduit le texte en présentations personnalisables avec des figures natives, des animations et des notes audio du présentateur.

## Ce que ça vous apporte

- Convertit le texte en fichiers PPTX avec des formes et des animations natives.
- Ajoute des notes vocales automatiques du locuteur aux diapositives de présentation.
- Grâce à sa structure modifiable, il vous permet d'apporter des modifications à la présentation ultérieurement.

## Installation

**Téléchargez le projet sur votre ordinateur**

```
git clone https://github.com/hugohe3/ppt-master.git
cd ppt-master
```

**Installation des bibliothèques requises**

```
pip install -r requirements.txt
```
