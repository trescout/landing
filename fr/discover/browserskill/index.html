Donnez des capacités de navigation aux agents d'IA

Développé par Tencent, BrowserSkill est un outil d'automatisation de navigateur qui permet aux agents d'IA de gérer des sessions de navigation actives sans interrompre le travail de l'utilisateur. Grâce à une interface de ligne de commande et une extension de navigateur, il permet à tout agent d'IA d'accéder aux données de session du navigateur déjà connecté.

Ce que ça vous apporte

  • Utilise directement les sessions de navigateur et les informations de connexion existantes.
  • Fonctionne en arrière-plan dans une fenêtre séparée sans interrompre votre flux de travail.
  • Permet l'intervention humaine sur les écrans de vérification ou de connexion.

Installation

Installation pour macOS et Linux
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
export PATH="${BSK_INSTALL_DIR:-$HOME/.local/bin}:$PATH"

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Tu es connecté à BrowserSkill, un outil d'automatisation de navigateur. Tu peux désormais effectuer des tâches sur Internet à ma place en utilisant mes sessions de navigateur existantes. Lorsque tu effectues une action, emprunte mes onglets ouverts dans le navigateur, rends-les une fois le travail terminé et ne touche pas à mes autres onglets. Si tu rencontres un code de vérification, un écran de connexion ou une fenêtre de confirmation, arrête l'opération et demande-moi de l'aide.
