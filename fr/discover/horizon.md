# Radar personnel de suivi de l'actualité par intelligence artificielle

Thysrael/Horizon est un outil de suivi de l'actualité qui collecte, filtre et résume les informations provenant de différentes sources à l'aide de l'intelligence artificielle. Ce logiciel, qui prépare des bulletins quotidiens en anglais et en chinois, aide les utilisateurs à gérer leur flux d'informations en présentant les contenus avec leur contexte et les discussions de la communauté.

## Ce que ça vous apporte

- Collecte et filtre automatiquement les actualités provenant de différentes sources.
- Prépare des bulletins de résumé quotidiens en anglais et en chinois.
- Présente les actualités avec leur contexte et les discussions de la communauté.

## Installation

**Clonage et installation du projet**

```
git clone https://github.com/Thysrael/Horizon.git
cd Horizon

# Install with uv (recommended)
uv sync

# Install test/development extras when needed
uv sync --extra dev

# Or with pip
pip install -e .
```

## Exécution

**Lancement de l'assistant**

```
uv run horizon-wizard
```
