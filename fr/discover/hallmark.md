# Apportez de l'originalité aux conceptions d'IA

Hallmark est un fichier de style développé pour réduire l'impact du contenu standard produit par l'intelligence artificielle (AI slop) sur la conception. Claude Code veille à ce que les interfaces utilisées dans des outils tels que Cursor et Codex acquièrent une esthétique unique et humaine.

## Ce que ça vous apporte
- Évite l’esthétique standard de l’IA
- Crée des interfaces uniques avec vingt thèmes différents
- Audite et repense les codes existants

## Installation
**Ajouter un véhicule**

```
npx skills add nutlope/hallmark
```


## Si vous ne codez pas
Créez une conception d'interface unique qui ne semble pas avoir été créée par l'IA à l'aide du fichier de style Hallmark. Évitez les modèles standard dans la conception, choisissez celui qui convient parmi vingt thèmes différents et créez une structure unique qui passera cinquante-sept tests de qualité.
