# Concevoir des ontologies d'IA avec Ontology-Playground

Développée par Microsoft, Ontology-Playground est une application Web open source utilisée pour apprendre des ontologies et créer des conceptions visuelles sur Microsoft Fabric IQ. Cet outil entièrement statique permet aux utilisateurs de concevoir des modèles d'ontologie, de les exporter au format RDF/XML et de partager des diagrammes interactifs.

- ★ 1 806
- TypeScript
- GitHub Trending · 2026-07-21

## Ce que ça vous apporte
- Créer des modèles d'ontologie avec une interface visuelle
- Exporter au format RDF/XML
- Explorez les données avec des diagrammes interactifs

## Installation
**Installer le projet dans un environnement local**

```
cd Ontology-Playground
npm install
```

**Démarrage du serveur de développement**

```
npm run dev
```


## Si vous ne codez pas
Je souhaite concevoir une ontologie en utilisant Ontology-Playground. Chargez le modèle de démarrage en sélectionnant un champ tel que Vente au détail, Santé ou Finance. Ensuite, ajoutez de nouveaux types d'entités à ce modèle, définissez les relations entre elles et montrez-moi les étapes dont j'ai besoin pour exporter ce modèle que j'ai créé au format RDF/XML.
