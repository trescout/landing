# Rechercher des comptes enregistrés par e-mail

Holehe est un outil Python qui demande si une adresse e-mail saisie est utilisée sur des plateformes populaires telles que Twitter et Instagram. Il détecte les informations de compte associées à l'e-mail concerné à l'aide des fonctions de réinitialisation du mot de passe.

- ★ 14 563
- Python
- GitHub Trending · 2026-08-14

## Ce que ça vous apporte
- Requête par email sur plus de 120 plateformes
- Ne pas envoyer de notifications à l'adresse e-mail cible
- Détecté à l'aide des fonctions de réinitialisation du mot de passe

## Installation
**Installation avec PyPI**

```
pip3 install holehe
```

**Installation via GitHub**

```
git clone https://github.com/megadose/holehe.git
cd holehe/
python3 setup.py install
```


## Exécution
**Demande par e-mail**

```
holehe test@gmail.com
```


## Si vous ne codez pas
À l'aide de l'outil Holehe, vérifiez sur quelles plateformes l'adresse [E-MAIL_ADRESI] est enregistrée et présentez les résultats dans une liste.
