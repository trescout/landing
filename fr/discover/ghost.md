# Plateforme moderne de contenu et de newsletter

Ghost est une plate-forme technologique indépendante pour la publication, les adhésions, les abonnements et les newsletters par courrier électronique.

- ★ 55 098
- JavaScript
- GitHub Trending · 2026-08-22

## Ce que ça vous apporte
- Créer des modèles de revenus basés sur les abonnements
- Publication de contenu moderne et professionnelle
- Newsletter rapide et gestion des membres

## Installation
**Installer l'outil de ligne de commande**

```
npm install ghost-cli -g
```


## Exécution
**Démarrer l'installation locale**

```
ghost install local
```

**Démarrer l'installation sur le serveur**

```
ghost install
```
