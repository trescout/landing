# Préparer les données Web pour l'IA

Firecrawl propose une interface (API) pour explorer les données des sites Web à grande échelle, les extraire et les convertir dans un format de texte clair que les modèles d'IA peuvent traiter. Cet outil simplifie les processus de collecte de données en automatisant l'interaction avec le contenu Web.

**Note TreScout :** Il convertit les sites Web en texte clair pouvant être transmis à l'intelligence artificielle. ## Installation

**Ajouter via npm**

```
npm install @mendable/firecrawl-js
```

## Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

À l'aide de Firecrawl, analysez les données sur le site Web que j'ai spécifié et convertissez-les dans un format Markdown propre que les modèles d'intelligence artificielle peuvent facilement traiter. Lors de la capture du contenu d'une page, nettoyez les structures complexes et extrayez uniquement le texte significatif, les données structurées ou les informations visuelles essentielles.
