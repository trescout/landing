Gérez facilement les versions de Node.js

Node Version Manager est un outil de ligne de commande qui permet aux développeurs de gérer plusieurs versions de Node.js sur leurs systèmes. Grâce à sa structure de script shell (script bash) compatible POSIX, il facilite les transitions rapides de version entre différents projets.

Ce que ça vous apporte

  • Basculez rapidement entre les différentes versions de Node.js
  • Travaillez de manière transparente dans des shells compatibles POSIX
  • Installez facilement les versions Node.js spécifiques au projet

Installation

Installation à l'aide de cURL
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
Installation à l'aide de wget
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash

Exécution

Installation et utilisation de la version Node.js
nvm install 24
