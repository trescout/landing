# Gérer les processus de données avec Python

Prefect est un framework d'orchestration de flux de travail utilisé pour créer des pipelines de données basés sur Python. Conçu pour développer des processus de données résilients, cet outil permet la gestion et la surveillance de flux de données complexes.

- ★ 23 774
- Python
- GitHub Trending · 2026-07-13

## Ce que ça vous apporte
- Déplacement des pipelines de données vers le niveau de production
- Gestion des erreurs et nouvelle tentative automatique
- Surveiller visuellement les flux de travail

## Installation
**Installation via pip**

```
pip install -U prefect
```

**Pose avec UV**

```
uv add prefect
```


## Exécution
**Démarrage du serveur**

```
prefect server start
```
