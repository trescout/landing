# Ajoutez des capacités d'IA à vos notes Obsidian

Obsidian-skills permet aux agents d'intelligence artificielle d'effectuer des opérations sur l'application de prise de notes Obsidian à l'aide de l'interface de ligne de commande (CLI) et de formats de fichiers ouverts. Cet outil automatise la gestion des informations personnelles en permettant aux agents de lire et de modifier des formats tels que Markdown et JSON Canvas.

## Ce que ça vous apporte
- Il permet aux agents d'intelligence artificielle de lire et d'organiser vos notes.
- Il prend en charge les formats de fichiers tels que Markdown et JSON Canvas.
- Il établit des processus d'automatisation sur l'application de prise de notes Obsidian.

## Installation
**installation avec npx**

```
npx skills add git@github.com:kepano/obsidian-skills.git
```

**Installation pour OpenCode**

```
git clone https://github.com/kepano/obsidian-skills.git ~/.opencode/skills/obsidian-skills
```


## Si vous ne codez pas
J'utilise l'outil Obsidian-skills pour gérer mes notes Obsidian. Veuillez utiliser cet ensemble de compétences pour modifier les fichiers Markdown dans mes notes, mettre à jour le contenu de JSON Canvas ou effectuer les actions nécessaires via l'interface de ligne de commande Obsidian CLI. Je souhaite que vous créiez un flux de gestion de l'information efficace, notamment en préservant les structures, connexions et fonctionnalités complexes de mes notes.
