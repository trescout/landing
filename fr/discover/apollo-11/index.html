Codes sources de l'ordinateur de guidage d'Apollo 11

Le code source original de l'ordinateur de commande et de guidage du module lunaire (Guidance Computer) utilisé dans la mission Apollo 11 a été mis à disposition sur GitHub avec le langage assembleur. Le logiciel documente les détails techniques des algorithmes de calcul utilisés lors de la première mission habitée à atterrir sur la Lune.

Pour commencer

Ce référentiel a été créé pour archiver les codes sources originaux de l'ordinateur de guidage utilisé dans la mission Apollo 11. Vous pouvez parcourir les dossiers Comanche055 ou Luminary099 sur GitHub pour consulter les codes et visiter le site officiel du projet Virtual AGC pour obtenir des informations détaillées sur les processus de compilation.
