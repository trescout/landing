Développement côté serveur avec JavaScript

Node.js offre un environnement d'exécution qui permet d'exécuter du code JavaScript en dehors du navigateur. Cette plateforme, basée sur le moteur V8, permet de développer des applications réseaux évolutives côté serveur.

  • ★ 118 797
  • JavaScript
  • GitHub Trending · 2026-07-27

Note TreScout : La manière standard d'exécuter JavaScript côté serveur. Utiliser le même langage des deux côtés est d’une grande commodité pour l’équipe ; Le prix à payer est que l'arborescence des dépendances grossit rapidement et que la gestion des versions devient votre travail.
