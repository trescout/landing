# Une équipe d'intelligence artificielle qui fonctionne sur votre bureau

Orkas est une équipe d'IA open-source fonctionnant sur les ordinateurs de bureau qui transforme les objectifs en listes de tâches. Coordonnant seize agents experts intégrés et divers modèles de codage, cette application offre un espace de travail orienté local (local-first) sur macOS et Windows.

## Ce que ça vous apporte

- Exécute des tâches de recherche, de contenu, de design et de codage grâce à seize agents experts intégrés.
- Mémorise vos projets, règles et fichiers pour vous éviter de recommencer à zéro à chaque fois.
- Fait progresser régulièrement vos processus de travail grâce à des automatisations planifiées et des listes de tâches.

## Installation

**Clonez le dépôt du projet et exécutez-le**

```
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```
