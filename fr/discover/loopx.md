# Mémoire persistante pour les agents d'intelligence artificielle

Loopx est un noyau d'état léger développé pour les équipes d'agents d'intelligence artificielle à long terme. Il fonctionne de manière compatible avec les agents de codage (Codex, Claude Code) et standardise les processus tels que le suivi des tâches, la gestion des quotas et le transfert de travail vérifiable.

## Ce que ça vous apporte
- Standardise le suivi des cibles et la gestion des quotas dans les missions à long terme.
- Il permet un transfert vérifiable du travail entre différents agents d’IA.
- Stocke l’historique des tâches et les preuves dans une structure organisée.

## Installation
**Installation directe**

```
curl -fsSL https://raw.githubusercontent.com/huangruiteng/loopx/main/scripts/install-from-github.sh | bash
export PATH="$HOME/.local/bin:$PATH"
loopx doctor
```


## Exécution
**Démarrage du projet**

```
cd /path/to/your-project
loopx connect
loopx status
```


## Si vous ne codez pas
Nous travaillerons avec vous sur un projet à long terme. Je souhaite gérer nos tâches, nos objectifs et nos journaux de progression avec le bean d'état LoopX. Pendant que vous travaillez, vérifiez l'état actuel à chaque étape, enregistrez les preuves du travail terminé et respectez les limites du quota en déterminant la prochaine tâche (à faire). Laissez une trace vérifiable via LoopX lorsque vous déléguez des tâches ou passez à une nouvelle phase.
