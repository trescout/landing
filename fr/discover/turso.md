# Base de données en cours compatible SQLite

Turso propose une base de données SQL en cours compatible avec SQLite. Ce système, développé en langage Rust, simplifie les processus de gestion des données en s'intégrant aux processus applicatifs.

- ★ 23 620
- Rust
- GitHub Trending · 2026-06-21

## Ce que ça vous apporte
- Compatibilité SQL totale avec SQLite
- Prise en charge multilingue et plateforme
- Gestion avancée des données et de la concurrence

## Installation
**Installation de l'outil de ligne de commande**

```
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/tursodatabase/turso/releases/latest/download/turso_cli-installer.sh | sh
```

**Installation du package JavaScript**

```
npm i @tursodatabase/database
```


## Exécution
**Démarrage du shell interactif**

```
tursodb
```
