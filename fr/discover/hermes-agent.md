# L'intelligence artificielle se développe grâce aux interactions des utilisateurs

Développé par NousResearch, Hermes Agent propose une infrastructure d'agent autonome qui apprend des interactions des utilisateurs et se développe au fil du temps. Ce système basé sur Python utilise l'apprentissage continu pour créer des flux de travail personnalisés.

- ★ 231 039
- Python
- GitHub Trending · 2026-06-04

## Ce que ça vous apporte
- Des capacités autonomes qui évoluent au fil du temps en apprenant des interactions des utilisateurs.
- Possibilité de travailler en intégration avec des plateformes telles que Telegram, Discord et Slack.
- Possibilité de basculer entre différents modèles d'intelligence artificielle sans changer le code.

## Installation
**Installation pour Linux, macOS et WSL2**

```
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```


## Exécution
**Démarrage de l'interface**

```
hermes
```
