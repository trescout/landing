Checkstyle

Checkstyle est un outil d'analyse qui aide les programmeurs Java à développer des logiciels conformes aux normes de codage établies. Il contrôle la qualité du code en prenant en charge des normes telles que le Google Java Style Guide et les Sun Code Conventions.
