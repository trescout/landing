# Gestion de l'intelligence artificielle multiple dans le terminal

Développé avec le langage Rust, herdr fonctionne comme un multiplexeur d'agents s'exécutant sur le terminal. Cet outil permet aux utilisateurs de gérer plusieurs agents d'intelligence artificielle simultanément dans l'environnement du terminal.

- ★ 9 203
- Rust
- GitHub Trending · 2026-07-01

## Ce que ça vous apporte
- Gérez plusieurs agents d’intelligence artificielle simultanément sur un seul terminal.
- Surveillez instantanément l’état de fonctionnement des agents avec des indicateurs colorés.
- Gardez les sessions en arrière-plan même si la connexion est perdue.

## Installation
**Installation pour Linux et macOS**

```
curl -fsSL https://herdr.dev/install.sh | sh
```


## Exécution
**Démarrage de l'outil**

```
herdr
```


## Si vous ne codez pas
Je souhaite gérer tous mes agents d'intelligence artificielle exécutés sur le terminal à partir d'un seul centre et voir instantanément l'état de fonctionnement (en attente, en cours d'exécution, terminé) de chacun d'eux. Utilisez Herdr pour m'aider à configurer ces agents afin de les séparer en différents espaces de travail et onglets afin que les processus se poursuivent en arrière-plan même si je ferme le terminal.
