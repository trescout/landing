# Transformez vos projets en graphiques de connaissances pour l'intelligence artificielle

Graphify transforme différents types de données tels que les fichiers de code, les schémas de base de données et la documentation en une structure de graphe de connaissances interrogeable. Cet outil basé sur Python vise à créer une couche de données centrale pour divers assistants de codage IA.

## Ce que ça vous apporte
- Le code transforme vos fichiers et documents en un réseau d'informations interrogeable.
- Il utilise une technologie native et rapide d'arborescence pour l'analyse du code.
- Il facilite la transition entre les concepts en établissant des connexions entre les fichiers.

## Installation
**Installation de la CLI**

```
uv tool install graphifyy      # install the CLI (or: pipx install graphifyy)
graphify install               # register the skill with your AI assistant
```


## Exécution
**Analyse du projet**

```
/graphify .
```


## Si vous ne codez pas
J'ai converti ce répertoire de projet en un graphe de connaissances à l'aide de Graphify. Maintenant, en utilisant cette structure, je souhaite que vous analysiez les relations entre les concepts du projet, que vous expliquiez comment les blocs de code complexes sont connectés les uns aux autres et que vous détailliez le rôle des nœuds maîtres tels que « APIRouter » dans le système. Veuillez faire la distinction entre les informations provenant directement du code source et les connexions déduites en prenant en compte les balises « EXTRAITE » et « INFÉRÉE » lors de l'exécution de votre analyse.
