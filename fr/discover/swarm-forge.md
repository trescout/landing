# Système qui coordonne les agents d’intelligence artificielle

Écrit en langage Clojure, Swarm Forge est un outil permettant de coordonner plusieurs agents d'IA à partir d'un seul centre. Le logiciel offre une structure simple pour gérer des processus complexes où différents agents doivent travailler en collaboration.

## Ce que ça vous apporte

- Gère plusieurs agents d’intelligence artificielle à partir d’un seul centre
- Surveiller les agents simultanément avec le multiplexeur de terminal Tmux
- Offre des flux de travail personnalisables spécifiques au projet

## Installation

**Téléchargez et préparez la branche de travail**

```
BRANCH=four-pack
curl -L "https://github.com/unclebob/swarm-forge/archive/refs/heads/${BRANCH}.tar.gz" | tar -xz --strip-components=1
```

## Exécution

**Initialisation du système**

```
./swarm
```
