# Accès à l'intelligence artificielle depuis la ligne de commande

Développé par Google, gemini-cli est un outil open source (dont le code source est accessible à tous) qui permet d'accéder au modèle d'intelligence artificielle Gemini directement via le terminal. Le logiciel permet aux utilisateurs de créer rapidement et facilement des requêtes d'intelligence artificielle dans l'environnement de la ligne de commande.

## Ce que ça vous apporte

- Vous pouvez inspecter et modifier vos bases de code directement depuis la ligne de commande.
- Vous pouvez créer de nouvelles applications à partir d'images ou de documents textuels.
- Vous pouvez automatiser vos tâches répétitives à l'aide de scripts.

## Installation

**Installation globale avec le gestionnaire de paquets npm**

```
npm install -g @google/gemini-cli
```

**Installation avec le gestionnaire de paquets Homebrew**

```
brew install gemini-cli
```

## Exécution

**Exécution directe sans installation**

```
# Using npx (no installation required)
npx @google/gemini-cli
```
