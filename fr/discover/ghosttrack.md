# Suivi de localisation via des numéros de mobile et des noms d'utilisateur

GhostTrack basé sur Python est un outil qui permet le suivi de localisation via des numéros de mobile. Ce logiciel open source a été développé pour détecter les données géographiques du numéro cible.

- ★ 14 877
- GitHub Trending · 2026-06-08

## Ce que ça vous apporte
- Détecte les données de géolocalisation des numéros de mobile
- Collecte des informations via les noms d'utilisateur des réseaux sociaux
- Fonctionne intégré avec des outils auxiliaires pour le suivi des adresses IP

## Installation
**Cloner + dépendances (Linux · Python 3)**

```
git clone https://github.com/HunxByts/GhostTrack.git && cd GhostTrack && pip3 install -r requirements.txt
```


## Exécution
**courir**

```
python3 GhostTR.py
```
