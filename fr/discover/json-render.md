# Rendu JSON

Développé par Vercel Labs, json-render est un framework qui transforme les structures de données en composants visuels pour les configurations d'interface utilisateur génératives. Il permet aux développeurs de présenter les données structurées des modèles d'IA sous forme d'éléments dynamiques et interactifs dans des interfaces Web.
