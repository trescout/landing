# Application multiplateforme avec un seul code

Développé par Google, Flutter permet la création rapide d'interfaces utilisateur pour les plateformes mobiles, Web et de bureau à l'aide d'une base de code unique. Ce framework open source, basé sur le langage de programmation Dart, est largement privilégié pour développer des applications performantes et visuellement riches.

## Ce que ça vous apporte
- Prise en charge mobile, Web et ordinateur avec une base de code unique
- Fonction de rechargement à chaud qui vous permet de voir les modifications instantanées
- Graphiques hautes performances accélérés par le matériel

## Installation
**macOS (Homebrew)**

```
brew install --cask flutter
```


## Exécution
**Vérifier les contrôles environnementaux**

```
flutter doctor
```

**Créer et exécuter un nouveau projet**

```
flutter create my_app
cd my_app
flutter run
```
