Que fait cet outil ?

Codex CLI est un agent de codage qui s’exécute dans le terminal de votre ordinateur local. Il peut examiner le code d’un répertoire de projet, modifier des fichiers, exécuter des commandes et aider à automatiser les tâches répétitives.

Pour qui ?

Les développeurs qui souhaitent travailler dans le terminal, examiner la base de code, modifier des fichiers et automatiser les tâches de développement répétitives.

À quoi ne faut-il pas s’attendre ?

Il peut ne pas convenir aux personnes qui ne souhaitent pas utiliser le terminal.

Points forts

  • Il peut examiner le code et modifier des fichiers.
  • Il peut exécuter des commandes et automatiser les tâches répétitives.
  • Le modèle, le reasoning effort, les autorisations et les approbations de commandes peuvent être gérés par l’utilisateur.
  • Le dépôt GitHub est sous licence Apache-2.0.

Premiers pas

  1. Choisissez la méthode d’installation officielle adaptée à votre système d’exploitation.
  2. Lancez Codex CLI après l’installation.
  3. Connectez-vous avec ChatGPT ou une autre méthode de connexion disponible.
  4. Commencez dans le répertoire du projet. Créez un checkpoint Git avant et après les modifications.

Démarrage prudent

Il est recommandé de créer un checkpoint Git avant et après les modifications. Vous pouvez consulter les autorisations avec /permissions et l’état actuel avec /status.

Premier prompt

Prompt prêt pour commencer

Lors de la première utilisation, vous pouvez commencer par une demande d’examen expliquant l’objectif du projet et la structure des fichiers.
