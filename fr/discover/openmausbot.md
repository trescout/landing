# Équipe de bots d'intelligence artificielle axée sur la discussion

OpenMausBot est une alternative open source à Grok Bot qui vous permet de créer votre propre équipe de bots d'intelligence artificielle au sein d'applications de messagerie. Le logiciel est fourni avec un support de machine virtuelle que les bots peuvent utiliser.

## Ce que ça vous apporte

- Vous pouvez gérer votre propre équipe de bots d'intelligence artificielle via Electron, l'infrastructure d'application de bureau.
- Vous pouvez stocker votre historique de chat et vos données sur votre ordinateur local au lieu du cloud.
- Vous pouvez définir différents modèles d'intelligence artificielle pour vos bots grâce à l'intégration de l'outil en ligne de commande CLI.

## Installation

**Installation et exécution du paquet OpenMausBot**

```
npm install -g openmausbot
openmausbot
```
