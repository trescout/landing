# Gestion Unity avec intelligence artificielle

Unity MCP fournit un pont entre les grands modèles de langage et l'éditeur Unity, permettant d'automatiser les processus de gestion des actifs, de contrôle de scène et d'édition de code. Cet outil, qui fonctionne via le Model Server Protocol (Model Context Protocol), permet aux assistants d'intelligence artificielle d'intervenir directement dans les workflows de développement de jeux.

- Flux de travail du jeu avec 47 outils différents

## Pour commencer
- Source officielle →
Ouvrez votre projet Unity et accédez à la fenêtre Package Manager. Cliquez sur « Ajouter un package à partir de l'URL git » et collez l'adresse https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main. Une fois l'installation terminée, accédez à l'onglet « MCP pour Unity » sous le menu Fenêtre et complétez les paramètres de configuration.
