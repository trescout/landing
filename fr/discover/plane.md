# Plateforme de gestion de projet open source

Plane est une plateforme de gestion de projet open source qui regroupe les processus de gestion des tâches, de planification de sprint et de documentation. Développée comme alternative aux outils d'entreprise tels que Jira et Linear, cette plateforme permet aux équipes d'organiser les flux de travail via une interface centrale.

## Ce que ça vous apporte
- Suivez les tâches et les feuilles de route des produits dans une interface centrale
- Diviser les projets complexes en modules et cycles gérables
- Outils de documentation et d'analyse basés sur l'IA

## Installation
**Télécharger le script d'installation**

```
curl -fsSL -o setup.sh https://github.com/makeplane/plane/releases/latest/download/setup.sh
```

**Rendre le exécutable**

```
chmod +x setup.sh
```


## Exécution
**Démarrer l'installation (2 à partir du menu)**

```
./setup.sh
```


## Pour commencer
- Source officielle →
Pour commencer rapidement, vous pouvez créer un compte gratuit via Plane Cloud. Si vous souhaitez l'héberger sur votre propre infrastructure, vous pouvez l'installer sur votre propre serveur en suivant les guides d'installation Docker ou Kubernetes sur la page de documentation officielle.
