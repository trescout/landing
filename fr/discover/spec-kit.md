# Développement basé sur les spécifications avec l'intelligence artificielle

Publié par GitHub, spec-kit offre les outils nécessaires pour démarrer des processus de développement basés sur les spécifications. Cette bibliothèque basée sur Python facilite l'intégration des spécifications techniques définies lors de la phase de développement logiciel dans les processus de code.

## Ce que ça vous apporte

- Il convertit les spécifications techniques en processus de code exécutable.
- Il fournit des résultats cohérents et prévisibles pendant la phase de développement logiciel.
- Il augmente la vitesse de développement en travaillant de manière intégrée avec les agents de codage IA.

## Installation

**Installation de l'outil CLI**

```
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@vX.Y.Z
```

## Exécution

**Démarrer le projet**

```
specify init my-project --integration copilot
cd my-project
```

## Si vous ne codez pas

Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Lorsque vous utilisez un agent de codage IA, définissez des normes de qualité et de performances à l'aide de la commande /speckit.constitution pour déterminer les lignes de base du projet. Ensuite, expliquez les objectifs de l'application que vous souhaitez construire avec /speckit.specify, spécifiez votre architecture technique avec /speckit.plan, et enfin créez la liste des tâches avec /speckit.tasks et développez l'application avec la commande /speckit.implement.

Dépôt : https://github.com/github/spec-kit. Base-toi sur les instructions officielles du fichier README de ce dépôt pour l'installation et l'exécution.

Avant de commencer, vérifie quel système d'exploitation nous utilisons et si les outils nécessaires (ex: Python, Node.js, Git, Docker) sont installés. Installe ceux qui manquent étape par étape selon ce système.

Crée un nouveau dossier vide pour travailler. Ne touche pas aux fichiers en dehors de ce dossier et ne supprime rien. Avant chaque commande, décris ce que tu vas faire en une phrase.

Dis-moi ce que je devrais voir à l'écran à la fin de chaque étape. Si une erreur survient, je te copierai le message d'erreur tel quel et nous la corrigerons ensemble.
