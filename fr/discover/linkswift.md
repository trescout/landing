# Liens de téléchargement direct depuis les services cloud

LinkSwift est un outil basé sur JavaScript permettant d'obtenir des liens de téléchargement direct de fichiers depuis divers services de stockage cloud. Le logiciel prend en charge huit plateformes cloud populaires différentes, dont Baidu Netdisk, Alibaba Cloud Drive, China Mobile Cloud et Quark Drive.

## Ce que ça vous apporte

- Génère des liens de téléchargement direct de fichiers à partir de neuf services de stockage cloud différents, notamment Baidu, Alibaba Cloud et Quark.
- Permet de transférer les liens obtenus vers des logiciels tels que le gestionnaire de téléchargement IDM ou l'outil de téléchargement de fichiers Aria2.
- Simplifie l'interface web des services cloud pris en charge, éliminant ainsi la nécessité d'installer les applications de bureau officielles.

## Pour commencer

Pour l'utiliser, vous devez d'abord installer l'extension de gestionnaire de scripts utilisateur Tampermonkey sur votre navigateur. Vous pouvez ensuite ajouter le script à votre navigateur en cliquant sur le lien d'installation portant l'extension « .user.js » partagé sur la page GitHub ou ScriptCat du projet. Une fois le script installé, le menu de téléchargement direct apparaît automatiquement sur l'interface lorsque vous accédez à un site de stockage cloud pris en charge.
