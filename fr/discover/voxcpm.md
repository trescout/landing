## Installation

**Installer via PyPI**

```
pip install voxcpm
```

## Exécution

**Synthèse vocale (TTS)**

```
voxcpm design --text "VoxCPM2 brings studio-quality multilingual speech synthesis." --output out.wav
```

## Que propose-t-il ?

- Production de parole multilingue et naturelle.
- Conception sonore créative et originale.
- Clonage vocal de haute précision.

## Note de responsabilité

Comprend le clonage vocal. Se faire passer pour la voix d'une personne sans autorisation crée des problèmes juridiques et éthiques ; La responsabilité appartient à l'utilisateur.
