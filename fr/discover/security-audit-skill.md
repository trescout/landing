# Audit de sécurité automatisé par intelligence artificielle

Développé par Cloudflare, security-audit-skill est un pack de compétences (skill) permettant aux agents de codage d'effectuer des audits de sécurité en plusieurs étapes. Il automatise les normes de sécurité dans les processus de développement logiciel en produisant des résultats lisibles par machine et vérifiés de manière indépendante.

## Ce que ça vous apporte

- Effectue une analyse de sécurité en plusieurs étapes sur la base de code
- Confirme les résultats par une vérification indépendante
- Génère des rapports de sécurité standardisés

## Installation

**installation locale**

```
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit
```

**Installation générale**

```
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit \
  --global
```

## Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Lance un audit de sécurité complet pour cette base de code. Cartographie l'architecture pour identifier les points d'entrée, puis effectue une analyse en plusieurs étapes pour détecter les vulnérabilités. Soumets chaque candidat à une vulnérabilité trouvé à un processus de vérification indépendant pour le classer comme vérifié, à vérifier ou rejeté. Rapporte les résultats dans un format structuré et documente toutes les conclusions selon les normes de sécurité du projet.
