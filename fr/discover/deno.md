# Runtime JavaScript et TypeScript moderne

Deno est un environnement d'exécution moderne conçu pour les langages JavaScript et TypeScript. Développé en langage Rust, cet outil propose une infrastructure alternative à la plateforme traditionnelle Node.js avec sa structure orientée sécurité et performance.

## Ce que ça vous apporte
- Il exécute en toute sécurité les langages JavaScript, TypeScript et WebAssembly.
- Il offre de hautes performances avec son moteur V8 et son langage Rust.
- Il offre une infrastructure moderne et pratique pour développer des serveurs Web.

## Installation
**Installation sur les systèmes Mac ou Linux**

```
curl -fsSL https://deno.land/install.sh | sh
```

**Installation avec Homebrew sur Mac**

```
brew install deno
```


## Exécution
**Démarrage du fichier serveur préparé**

```
deno run --allow-net server.ts
```
