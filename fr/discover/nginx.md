## Installation

**macOS (Homebrew)**

```
brew install nginx
```

**Ubuntu / Debian**

```
sudo apt update && sudo apt install -y nginx
```

## Exécution

**Démarrer le serveur web**

```
sudo systemctl start nginx
```
