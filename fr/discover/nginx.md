# Serveur Web hautes performances et proxy inverse

Le référentiel open source NGINX continue d'être développé en C en tant que serveur Web hautes performances et proxy inverse. Le logiciel offre une solution standard dans les infrastructures à grande échelle pour gérer le trafic réseau et optimiser la distribution de contenu.

## Ce que ça vous apporte
- Serveur Web haute performance et gestion de proxy inverse.
- Fonctionnalités avancées d’équilibrage de charge et de mise en cache de contenu.
- Installation d'infrastructure flexible et évolutive grâce à sa structure modulaire.

## Installation
**Installation des dépendances**

```
sudo apt install gcc make
```

**Installation des bibliothèques requises**

```
sudo apt install libpcre3-dev zlib1g-dev
```


## Exécution
**Contrôle du module statique**

```
nginx -V
```
