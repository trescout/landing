# Format rapide et structuré pour l'échange de données

Développés par Google, les tampons de protocole sont un format d'échange de données indépendant du langage utilisé pour sérialiser des données structurées. Ce mécanisme permet un transfert de données binaires efficace et rapide dans la communication inter-systèmes.

## Ce que ça vous apporte
- Transfert de données binaires efficace entre les systèmes
- Sérialisation des données indépendante de la langue
- Structure de données flexible et extensible

## Installation
**macOS (Homebrew)**

```
brew install protobuf
```


## Exécution
**compiler le schéma**

```
protoc --cpp_out=. dosya.proto
```
