Gagnez en intelligence spatiale avec les signaux WiFi

RuView fournit une intelligence spatiale en temps réel, un suivi des signes vitaux et une détection de présence sans caméra, en utilisant des signaux WiFi ordinaires. Il s'agit d'un projet open source développé avec Rust.

Que propose-t-il ?

  • Détection de présence et de mouvement sans utiliser de caméra.
  • Surveillance des signes vitaux (respiration et pouls).
  • Intelligence spatiale en temps réel.

Note de responsabilité

C'est une technologie qui détecte la présence/le mouvement des personnes. Une utilisation prudente et licite en termes de confidentialité et de consentement relève de votre responsabilité.

Comment installer, comment utiliser ?

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Pour l'essayer sans matériel, exécutez « docker pull ruvnet/wifi-densepose:latest » dans le terminal, puis commencez par « docker run -p 3000:3000 ruvnet/wifi-densepose:latest » et ouvrez http://localhost:3000 depuis le navigateur ; Ceci montre l'interface de détection de mouvement/présence de RuView avec des signaux WiFi avec des données simulées.

Extraire l'image Docker
docker pull ruvnet/wifi-densepose:latest
Exécuter avec Docker (simulation, aucun matériel requis)
docker run -p 3000:3000 ruvnet/wifi-densepose:latest
Paquet Python (PyPI)
pip install ruview
