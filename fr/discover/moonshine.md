# Outils vocaux d'IA en temps réel

Moonshine offre des capacités de synthèse vocale à faible latence, de reconnaissance d'intention et de synthèse vocale pour les interfaces vocales et les agents d'intelligence artificielle. Cette bibliothèque, développée en langage C++, a pour objectif d'optimiser les processus de traitement audio en temps réel.

## Ce que ça vous apporte

- Traitement audio rapide et discret exécuté sur l'appareil
- Faible latence optimisée pour les diffusions en direct
- Possibilité de convertir la parole en texte et le texte en audio

## Installation

**Installation avec Python**

```
pip install moonshine-voice
moonshine-voice mic --language en
```

**Installation du Raspberry Pi**

```
sudo pip install --break-system-packages moonshine-voice
 moonshine-voice mic --language en
```

## Exécution

**Transcription en direct via microphone**

```
moonshine-voice mic --language en
```
