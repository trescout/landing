# Explorez les projets de développeurs indépendants chinois

Cette base de données open source, qui recense les projets réalisés par des développeurs indépendants chinois, rassemble les applications et espaces de travail développés par les développeurs de logiciels. La plateforme vous permet de suivre les tendances actuelles et les études orientées produits dans l'écosystème du développement indépendant (indie hacking).
