# Connectez vos agents d'intelligence artificielle aux interfaces

AG-UI est un protocole de communication open source et événementiel qui connecte les agents d'intelligence artificielle aux interfaces utilisateur. Il simplifie les intégrations d'applications en permettant aux développeurs d'établir un flux de données standard entre les agents d'intelligence artificielle et les interfaces utilisateur.

## Ce que ça vous apporte

- Établit une synchronisation d'état en temps réel entre les agents et les interfaces utilisateur
- S'adapte à différentes méthodes de transport de données grâce à sa structure flexible basée sur les événements
- Prend en charge les interfaces génératives et les processus de collaboration avec intervention humaine
