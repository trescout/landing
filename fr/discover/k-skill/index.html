Donnez à votre agent IA des capacités natives

NomaDamas/k-skill est une bibliothèque conçue pour fournir aux agents IA des compétences locales dans un contexte culturel. Il propose des compétences personnalisées qui permettent aux agents d'interagir avec les utilisateurs de manière plus naturelle et dans le respect des codes culturels.

  • ★ 6 780
  • JavaScript
  • GitHub Trending · 2026-08-02

Ce que ça vous apporte

  • Permet aux agents IA d'utiliser les services locaux spécifiques à la Turquie
  • Effectue des requêtes automatiques sur les transports, les données publiques et le travail quotidien
  • S'intègre directement sans avoir besoin de logiciel client supplémentaire

Installation

Pour installer toutes les fonctionnalités
npx --yes skills add NomaDamas/k-skill --all -g
Pour installer une capacité spécifique
npx --yes skills add NomaDamas/k-skill --skill srt-booking -g

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Dans les prochaines tâches que je vous confie, utilisez les compétences fournies par la bibliothèque k-skill pour accéder aux services locaux. Si vous devez effectuer une requête de transport, une recherche de données publiques ou une opération locale, gérez le processus en déployant les fonctionnalités pertinentes dans cette bibliothèque. Lors de l'exécution de transactions, n'oubliez pas d'obtenir les informations de connexion ou les confirmations nécessaires de la part de l'utilisateur.
