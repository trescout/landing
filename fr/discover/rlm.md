# Infrastructure pour les modèles d'intelligence artificielle récursifs

Développé pour les modèles de langage récursifs, rlm est une bibliothèque d'inférence plug-and-play qui prend en charge différents bacs à sable. Cet outil basé sur Python standardise les processus de modèles de langage complexes, les rendant plus faciles à intégrer dans différents systèmes.

## Ce que ça vous apporte
- Gestion de contexte de longueur infinie
- Architecture plug-and-play fonctionnant dans un environnement de code
- Intégration sécurisée avec différents environnements sandbox

## Installation
**Installation rapide**

```
pip install rlms
```

**Installation manuelle**

```
curl -LsSf https://astral.sh/uv/install.sh | sh
uv init && uv venv --python 3.12  # change version as needed
uv pip install -e .
```


## Exécution
**Test rapide**

```
make quickstart
```


## Si vous ne codez pas
À l'aide de la bibliothèque RLM, créez une structure qui permet au modèle de langage de décomposer les entrées, de les analyser et d'effectuer des appels récursifs en lui-même. Lors de l'instanciation de la classe RLM, définissez la configuration du modèle que vous utilisez comme backend et autorisez le modèle à interagir avec l'environnement de code pour résoudre des tâches complexes.
