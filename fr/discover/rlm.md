# Infrastructure pour les modèles d'intelligence artificielle récursifs

Développé pour les modèles de langage récursifs, rlm est une bibliothèque d'inférence plug-and-play qui prend en charge différents bacs à sable. Cet outil basé sur Python standardise les processus de modèles de langage complexes, les rendant plus faciles à intégrer dans différents systèmes.
