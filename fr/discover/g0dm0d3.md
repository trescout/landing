# Interface d'interaction IA illimitée

G0DM0D3 est une interface de chat IA libérée qui vise à contourner les couches de sécurité des grands modèles de langage. Développé avec TypeScript, ce projet open source permet aux utilisateurs d'interagir avec des modèles sans restrictions.

## Ce que ça vous apporte
- Analyse comparative multiple avec plus de 60 modèles
- Prise en charge de l'exécution de modèles sur du matériel local
- Moteur de mixage d'entrée pour les tests de l'équipe rouge

## Installation
**Clonez le référentiel et démarrez-le sur le serveur local**

```
# Clone the repository
git clone https://github.com/elder-plinius/G0DM0D3.git
cd G0DM0D3

# Open directly in your browser
open index.html
# or serve locally
python3 -m http.server 8000
```


## Si vous ne codez pas
À l'aide de l'interface G0DM0D3, activez le moteur ULTRAPLINIAN, qui pilote plusieurs modèles via les fournisseurs de modèles que je spécifie (OpenRouter, Venice ou serveur local). Appliquez les techniques de mélange d'entrées en Fourchelang pour mes enquêtes d'équipe rouge et configurez automatiquement les paramètres d'échantillonnage les mieux adaptés au contexte de la requête avec la fonctionnalité AutoTune.
