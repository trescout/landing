# Contourner la censure sur Internet avec Kotlin

Le projet Fanqiang est un outil de passerelle écrit en Kotlin, développé pour contourner la censure sur Internet. Il s'agit d'un logiciel open source conçu pour fournir aux utilisateurs un accès à des ressources réseau limitées.

- ★ 49 405
- Kotlin
- GitHub Trending · 2026-06-12

## Ce que ça vous apporte
- Fournit un accès à des guides d’accès réseau complets pour différents systèmes d’exploitation et appareils.
- Fournit des guides de configuration et d’utilisation pour divers protocoles et outils réseau.
- Il comprend des méthodes pour contourner les restrictions réseau sur différentes plates-formes telles que les consoles de jeux et les navigateurs.
