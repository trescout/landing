# Espace de travail unifié pour les agents IA

holaOS est un espace de travail open source qui combine différents agents d'intelligence artificielle (Claude Code, Codex) avec vos outils, applications et fichiers sur une mémoire commune. Avec plus de 100 intégrations et la prise en charge du Model Link Protocol (MCP), il permet aux utilisateurs de gérer leurs propres modèles (BYOK) ou des modèles intégrés dans une seule interface.

## Ce que ça vous apporte

- Il exécute différents agents tels que Claude Code et Codex dans une seule interface à mémoire partagée.
- Connectez-vous en un clic à plus de 50 outils professionnels populaires tels que Gmail, Notion et Slack.
- Vous pouvez utiliser des modèles d'IA intégrés ou ajouter vos propres clés API.

## Installation

**Commande d'installation rapide**

```
curl -fsSL https://raw.githubusercontent.com/holaboss-ai/holaOS/refs/heads/main/scripts/install.sh | bash -s -- --launch
```

## Exécution

**Démarrage de l'environnement de développement**

```
npm run desktop:dev
```
