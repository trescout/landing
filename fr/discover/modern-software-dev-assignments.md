# Missions de développement de logiciels modernes

Les missions de développement de logiciels modernes préparées par l'Université de Stanford enseignent les pratiques d'ingénierie actuelles via le langage Python. Combinant les processus de développement de logiciels avec un programme académique, cette ressource propose des normes industrielles dans la pratique.
