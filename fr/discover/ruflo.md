# Couche d'orchestration pour les agents IA

Ruflo, akıllı ajan sürülerini devreye almak, otonom iş akışlarını koordine etmek ve diyalogsal yapay zekâ sistemleri oluşturmak için bir ajan orkestrasyon katmanıdır.

- ★ 68 873
- TypeScript
- GitHub Trending · 2026-08-22

## Ce que ça vous apporte
- Permet aux agents de collaborer entre eux
- Offre une mémoire permanente qui rappelle les sessions passées
- Système d'auto-apprentissage qui gère automatiquement les tâches

## Installation
**Démarrage de l'assistant de configuration interactif**

```
npx ruflo@latest init wizard
```

**Installer Ruflo à l'échelle mondiale**

```
npm install -g ruflo@latest
```


## Si vous ne codez pas
Vous êtes dans un environnement de travail intégré avec Ruflo. Optimisez votre flux de travail en utilisant les outils, les fonctionnalités de mémoire et les essaims d'agents de Ruflo pour effectuer des tâches. Améliorez vous-même les prochaines étapes en apprenant des modèles réussis et en vous coordonnant avec d'autres agents pour gérer des tâches complexes.
