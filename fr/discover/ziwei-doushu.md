# Moteur d'astrologie open source ziwei doushu

Renhuai123/ziwei-doushu est un moteur TypeScript open source qui calcule les cartes astrologiques Ziwei Doushu, basé sur le système Tianji de Ni Haixia. Le projet propose un vaste ensemble de données d'interprétation astrologique en 13 dimensions (v4.0) couvrant les dates entre 1950 et 2026.

## Ce que ça vous apporte

- Offre six cent soixante-quinze mille 命盘 (cartes de vie) et un vaste ensemble de données d'interprétation astrologique en treize dimensions.
- Effectue le calcul de carte en temps réel et la correction de l'heure solaire.
- Héberge un moteur d'astrologie complet basé sur le système Tianji de Ni Haixia.

## Installation

**Cloner et préparer le projet**

```
git clone https://github.com/Renhuai123/ziwei-doushu.git
cd ziwei-doushu

# 安装依赖
npm install

# 配置环境变量（只看排盘可以跳过；AI 配置仅在你自己实现了 /api/* 接口时才用得上）
cp .env.example .env.local

# 启动开发服务器
npm run dev
```
