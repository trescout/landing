# Gestion de base de données pour les projets Node.js

Prisma est un outil de mappage relationnel objet (ORM) qui simplifie les interactions de bases de données pour les projets Node.js et TypeScript. Sa structure, qui prend en charge différents systèmes de bases de données, permet aux développeurs de créer des requêtes de base de données de type sécurisé.

## Installation

**Installation des packages requis**

```
npm install prisma --save-dev
npm install @prisma/client
```

## Exécution

**Démarrage d'un serveur de base de données local**

```
npx prisma dev
```

**Création d'une base de données basée sur le cloud**

```
npx create-db --interactive
```
