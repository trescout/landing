# Guide de conception de systèmes à grande échelle

System Design Primer offre une ressource d’apprentissage complète pour ceux qui souhaitent concevoir des systèmes logiciels à grande échelle. Il rassemble les principes de conception de systèmes et des fiches d'études pratiques pour les développeurs de logiciels se préparant aux entretiens techniques.

## Ce que ça vous apporte
- Apprenez les principes de l'architecture système à grande échelle
- Résoudre des questions pratiques pour les entretiens techniques
- Utilisez les flashcards Anki pour conserver les informations

## Pour commencer
- Source officielle →

Si vous souhaitez renforcer l'information, vous pouvez télécharger et utiliser les fichiers Anki (logiciel qui permet la mémorisation avec des flashcards) à partir des liens correspondants.
