# Gérez vos agents d'intelligence artificielle dans un système unique

Openrig est une infrastructure multi-agents qui combine l'outil de codage Claude Code d'Anthropic et le modèle de codage Codex d'OpenAI au sein d'un système unique. Elle permet aux développeurs d'utiliser simultanément différents modèles d'intelligence artificielle dans le même flux de travail.

## Ce que ça vous apporte

- Combine différents modèles d'outils de codage par intelligence artificielle au sein d'une infrastructure unique.
- Définit des équipes d'agents avec YAML et les lance en une seule commande.
- Assure la coordination entre les agents et fournit des résultats.

## Installation

**Installer l'outil CLI**

```
npm install -g @openrig/cli
rig setup --dry-run
```
