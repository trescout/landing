# Synthétiseur vocal IA léger fonctionnant sur CPU

Développé par Kyutai Labs, Pocket-TTS est un modèle léger de synthèse vocale qui s'exécute uniquement sur l'unité centrale (CPU) sans avoir besoin d'une unité de traitement graphique. Grâce à sa faible consommation de ressources, il offre une synthèse sonore rapide et efficace sur les appareils soumis à des restrictions matérielles.

## Ce que ça vous apporte
- Fonctionne uniquement avec le processeur, sans nécessiter de carte graphique
- Fournit une reproduction sonore rapide avec une faible consommation de ressources
- Offre le clonage vocal et la prise en charge multilingue

## Installation
**Installation du paquet**

```
pip install pocket-tts
# or
uv add pocket-tts
```


## Exécution
**Créer un fichier audio**

```
uvx pocket-tts generate
# or if you installed it manually with pip:
pocket-tts generate
```

**Démarrage du serveur local**

```
uvx pocket-tts serve
# or if you installed it manually with pip:
pocket-tts serve
```
