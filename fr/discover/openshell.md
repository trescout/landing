# Environnement sécurisé pour les agents d'intelligence artificielle

Développé par NVIDIA, OpenShell propose un environnement d'exécution sécurisé et axé sur la confidentialité pour les agents d'IA autonomes. Écrite en Rust, cette infrastructure vise à isoler l'accès des agents aux ressources système afin de créer un espace d'exécution sécurisé.

- ★ 14 197
- Rust
- GitHub Trending · 2026-09-29

## Ce que ça vous apporte
- Exécute les agents d'intelligence artificielle dans un environnement bac à sable isolé
- Limite l'accès aux fichiers et au réseau à l'aide de règles
- Améliore la sécurité en masquant les informations d'identification

## Installation
**Installer l'outil et créer un environnement de démonstration**

```
curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh
openshell sandbox create --name demo
```


## Exécution
**Ajouter des fonctionnalités**

```
npx skills add NVIDIA/OpenShell
```


## Si vous ne codez pas
Pour installer et tester l'outil OpenShell, vous pouvez utiliser les commandes suivantes : curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh, puis créer un environnement de démonstration en exécutant la commande openshell sandbox create --name demo.
