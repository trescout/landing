# Édition complète de PDF sur votre propre serveur

Stirling-PDF est un outil de traitement de documents open source qui permet aux utilisateurs de modifier des fichiers PDF sur n'importe quel appareil. Développée avec TypeScript, cette application centralise les processus de gestion documentaire en s'exécutant sur des serveurs locaux.

## Installation

**Démarrer le conteneur Docker persistant**

```
docker run -d --name stirling-pdf -p 127.0.0.1:8080:8080 -v ./stirling-data:/configs --restart unless-stopped docker.stirlingpdf.com/stirlingtools/stirling-pdf:latest
```

## Exécution

**Accéder à l'interface locale**

```
http://localhost:8080
```
