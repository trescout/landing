# Contrôle des appareils électroménagers Samsung depuis le réseau local

mbillow/localthings vous permet de contrôler vos appareils électroménagers Samsung via votre réseau local à l'aide de la plateforme de gestion domotique Home Assistant, sans avoir besoin d'un compte cloud. Développé en Python, cet outil replace le contrôle de vos appareils directement sur votre réseau local.

## Ce que ça vous apporte

- Ne nécessite pas de compte cloud ni de connexion Internet
- communique directement avec les appareils via le réseau local
- Entièrement compatible avec la plateforme d'domotique Home Assistant

## Pour commencer

Vous pouvez le télécharger en utilisant le magasin d'extensions communautaire HACS en recherchant LocalThings dans la section Intégrations. Vous pouvez également copier le dossier custom_components dans le répertoire de configuration de Home Assistant, puis redémarrer le logiciel Home Assistant.
