# Tailcat

Tailcat, développé par Tailscale, est une version de l'outil en ligne de commande Netcat, utilisé pour transférer le trafic réseau de manière sécurisée, fonctionnant sur la couche réseau de Tailscale. Il permet une transmission de données directe entre appareils sans nécessiter de plan de contrôle (control plane).
