# Interface Web pour l'agent de codage Pi

Pi-web offre une interface utilisateur Web améliorée (interface utilisateur Web) pour l'agent de codage Pi. Cet outil, écrit en langage TypeScript, permet de gérer les processus de codage via une interface visuelle.

## Ce que ça vous apporte

- Scanner visuellement les sessions de codage passées
- Prévisualiser les fichiers via le navigateur
- Gérer les paramètres de modèle et de capacité depuis l'interface

## Installation

**Démarrage rapide sans installation**

```
npx @agegr/pi-web@latest
```

**Télécharger globalement**

```
npm install -g @agegr/pi-web
pi-web
```
