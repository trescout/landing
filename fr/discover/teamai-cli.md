# Gérez les agents d'intelligence artificielle avec des normes d'équipe

Développé par Tencent, teamai-cli est un outil de développement logiciel qui permet aux équipes d'interagir avec des outils d'intelligence artificielle via une interface de ligne de commande (CLI). Cet outil vise à numériser les processus de travail des équipes en intégrant des fonctionnalités d'intelligence artificielle générative (generative AI) dans leurs flux de travail.

## Ce que ça vous apporte

- Définit des règles de collaboration et des compétences communes pour tous les membres de l'équipe.
- Fonctionne en compatibilité avec des outils d'intelligence artificielle tels que Claude Code et Cursor.
- Synchronise automatiquement les mises à jour effectuées avec tous les membres de l'équipe.

## Installation

**Installez l'outil sur votre ordinateur**

```
npm install -g teamai-cli
```

## Exécution

**Connectez le dépôt d'équipe à votre projet**

```
teamai init https://github.com/yourorg/yourrepo
```
