# Rassemblez tous les modèles d'IA dans une seule interface

LibreChat est une plateforme de chat open source qui combine différents modèles et outils d'IA dans une interface unique. Ce logiciel, que les utilisateurs peuvent héberger sur leurs propres serveurs, offre une expérience d'IA personnalisée avec des fonctionnalités telles que le changement de modèle et l'authentification multi-utilisateurs.
