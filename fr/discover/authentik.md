# Gestion centralisée des identités pour vos applications

Authentik est une plateforme de sécurité open source qui fournit une authentification centralisée et une gestion des accès aux applications. En combinant des processus d'authentification complexes en un seul point, il offre une transition sécurisée entre différents services.

## Ce que ça vous apporte
- Fournit une transition sûre entre différents services à partir d’un seul point
- Prend en charge les protocoles standards tels que SAML et OAuth2
- Évolutif des petits projets aux systèmes à grande échelle

## Pour commencer
- Source officielle →
Pour l'installation, rendez-vous sur la page de documentation sur le site officiel. Vous pouvez choisir Docker Compose pour les petites installations ou les installations de test, et Kubernetes pour les structures à grande échelle. Il est également possible d'installer via AWS ou d'utiliser la boutique d'applications DigitalOcean.
