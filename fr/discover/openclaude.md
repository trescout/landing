# Gestion de l'intelligence artificielle via le terminal

OpenClaude est une interface d'intelligence artificielle flexible capable de fonctionner sur tout type de matériel et d'utiliser différentes sources de données. Développé en TypeScript, ce projet open source permet aux utilisateurs d'exécuter des modèles d'IA personnalisés sur leur propre infrastructure.

## Ce que ça vous apporte
- Combine des modèles d'IA basés sur le cloud et locaux dans une interface unique.
- Exécute des tâches telles que la gestion de fichiers, la recherche et le codage depuis le terminal.
- Configure facilement différents fournisseurs grâce à une installation guidée conviviale.

## Installation
**Installation générale**

```
npm install -g @gitlawb/openclaude@latest
```


## Exécution
**Démarrage de l'outil**

```
openclaude
```


## Si vous ne codez pas
Je souhaite optimiser mon flux de travail basé sur le terminal tout en travaillant sur OpenClaude. Créez un plan de travail pour augmenter ma productivité dans mes tâches de codage en utilisant les outils de fichiers, la fonction de recherche grep et l'intégration MCP (Model Context Protocol). Expliquez également étape par étape comment configurer mes paramètres de fournisseur avec la commande `/provider` et comment inclure les modèles GitHub.
