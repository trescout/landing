# Effectuez le clonage vocal et le doublage localement

VoiceStudio est une plateforme de traitement audio open source qui effectue des opérations telles que le clonage vocal, le doublage et la transcription sans avoir besoin d'Internet. Il offre une alternative fonctionnant localement au service de synthèse vocale ElevenLabs et prend en charge 646 langues.

## Ce que ça vous apporte
- Effectuez le clonage vocal et le doublage sans connexion Internet
- Bénéficiez de la prise en charge de la synthèse vocale et de la transcription dans 646 langues différentes
- Assurez une confidentialité totale en conservant vos données sur votre propre ordinateur

## Installation
**Exécution à partir du code source**

```
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun install
bun run desktop
```
