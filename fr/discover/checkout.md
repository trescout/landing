# Copier des référentiels dans les workflows GitHub

Développé par GitHub, actions/checkout est un outil qui automatise les processus d'extraction de référentiel dans les processus de développement logiciel. L'intégration continue permet de transférer le code source vers l'environnement de travail dans des workflows.

## Ce que ça vous apporte
- Transfert du code source vers l'environnement de travail
- Opérations de copie automatiques en entrepôt
- Gestion sécurisée des identifiants

## Pour commencer
- Source officielle →
Vous pouvez activer l'outil pour télécharger votre référentiel sur l'espace de travail en ajoutant la ligne -uses: actions/checkout@v7 à la section étapes de votre fichier de workflow GitHub Actions. Vous pouvez personnaliser le comportement de copie en définissant des paramètres tels que la profondeur de récupération ou les sous-modules sous le bloc with en fonction de vos besoins.
