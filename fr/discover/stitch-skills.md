# Capacités de conception pour les agents IA

Développée par Google Labs, Stitch Skills est une bibliothèque de compétences d'agent conçue pour fonctionner avec le serveur Stitch MCP. Suivant des normes ouvertes, cette bibliothèque vise à standardiser les flux de travail pour les agents de codage tels que Gemini CLI et Cursor.

## Ce que ça vous apporte

- Flux de travail standardisé entre le code et la conception
- Génération automatique de composants React et React Native
- Extraire et gérer les systèmes de conception à partir du code

## Installation

**Installation pour Claude Code**

```
npx plugins add google-labs-code/stitch-skills --scope project --target claude-code
```

**Configuration du curseur**

```
npx plugins add google-labs-code/stitch-skills --scope workspace --target cursor
```

## Exécution

**Afficher les commandes d'aide**

```
npx plugins --help

npx skills --help
```
