Exemples de serveurs pour agents d'intelligence artificielle

Les serveurs du Model Context Protocol (MCP) permettent aux modèles d'intelligence artificielle générative d'accéder à des sources de données externes et à des outils via une interface standard. Ce protocole permet à différentes applications d'IA de se connecter de manière sécurisée et cohérente à des bases de données ou à des outils logiciels.

Ce que ça vous apporte

  • Vous permet de garantir à vos grands modèles de langage (LLM) un accès sécurisé aux fichiers locaux, aux entrepôts de données et à la mémoire persistante.
  • Vous pouvez connecter vos applications d'intelligence artificielle à des sources de données externes en examinant les exemples de serveurs de référence.
  • Vous accédez à des modèles prêts à l'emploi pour développer vos propres serveurs en utilisant différents kits de développement logiciel (SDK).

Installation

Installation et démarrage du serveur Git
# With uvx
uvx mcp-server-git

# With pip
pip install mcp-server-git
python -m mcp_server_git

Exécution

Exécution du serveur de mémoire
npx -y @modelcontextprotocol/server-memory
