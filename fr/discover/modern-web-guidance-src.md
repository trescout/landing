# Calibrez les guides de développement web moderne

GoogleChrome/modern-web-guidance-src est un dépôt de ressources contenant le code et la documentation nécessaires à la création, à l'étalonnage et à l'évaluation de guides de développement web moderne. Développé en TypeScript, ce projet permet de gérer le contenu des guides orientés vers les standards du web.

## Ce que ça vous apporte

- Il remplace les anciennes habitudes de codage des agents de codage d'intelligence artificielle par des standards web actuels.
- Il importe directement dans le contexte de l'agent des guides de développement prêts à l'emploi axés sur la compatibilité des navigateurs et les performances.
- Il met en avant les fonctionnalités natives du navigateur et des solutions légères à la place des bibliothèques inutiles.

## Installation

**Installation avec l'assistant interactif**

```
npx modern-web-guidance@latest install
```

**Installation alternative avec options**

```
npx modern-web-guidance@latest install --choose
```

## Exécution

**Recherche de guides et identification des anciennes structures dans le code**

```
# Search for relevant guides
npx modern-web-guidance@latest search "animate a dialog modal backdrop"

# Retrieve a guide by ID
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"

# Scan a codebase for legacy patterns to modernize
npx modern-web-guidance@latest legacy-scan .
```
