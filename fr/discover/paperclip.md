# Centre de gestion pour les agents IA

Paperclip est une plateforme open source qui vous permet de gérer les agents IA sur le lieu de travail via une interface unique. Développé avec TypeScript, cet outil permet de contrôler les workflows des agents utilisés pour différentes tâches depuis un point central.

- TypeScript
- GitHub Trending · 2026-08-11

## Ce que ça vous apporte
- Gérez plusieurs agents IA à partir d’une seule interface.
- Contrôlez de manière centralisée le budget et les tâches des agents.
- Rendre les flux de travail traçables comme un gestionnaire de tâches.

## Installation
**Installation rapide**

```
curl -fsSL https://paperclip.ing/install.sh | bash -s -- --no-prompt --no-onboard
paperclipai onboard --yes
```

**Installation du développeur**

```
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev
```


## Si vous ne codez pas
Agissant en tant que responsable de l'IA, je définis les sous-tâches nécessaires pour atteindre l'objectif commercial principal que je me suis fixé, assigne ces tâches aux agents appropriés, fixe les limites budgétaires et contrôle l'avancement du processus en rendant régulièrement compte du travail effectué.
