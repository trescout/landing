# Norme sémantique commune pour les plateformes de données

Apache Ossie est une initiative industrielle qui vise à standardiser l'échange de métadonnées sémantiques entre les plateformes d'analyse, d'intelligence artificielle et de business intelligence (BI). Ce projet facilite l'intégration des données en créant une source de vérité unique et indépendante du fournisseur entre différentes plates-formes.

## Ce que ça vous apporte

- Fournit des définitions cohérentes dans différents outils de données
- Crée une source unique de vérité, indépendante du fournisseur
- Augmente la compatibilité entre les outils d'IA et de business intelligence

## Pour commencer

Apache Ossie est une spécification de normes plutôt qu'une installation logicielle. Vous pouvez obtenir des informations sur la façon dont les outils de données que vous utilisez peuvent être rendus compatibles avec cette norme en examinant les documents techniques et les fichiers de schéma dans le dossier core-spec sur la page GitHub du projet.
