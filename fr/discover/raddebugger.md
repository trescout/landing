# Outil de débogage visuel et natif

Développé par Epic Games, raddebugger est un débogueur natif et visuel écrit en langage C. Offrant un support multi-processus, cet outil fonctionne en mode utilisateur pour aider les développeurs de logiciels à identifier les bogues applicatifs.

## Ce que ça vous apporte

- Vous pouvez facilement identifier les bogues de vos applications grâce à Raddebugger, un débogueur doté d'une interface visuelle.
- Vous pouvez réduire les temps de compilation dans les grands projets logiciels grâce à l'outil d'édition de liens RAD Linker.
- Grâce au format de données personnalisé RDI, vous pouvez convertir rapidement les informations de débogage et gagner en performance.
