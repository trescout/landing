Agrégez 34 fournisseurs LLM gratuits sous une API OpenAI unifiée

FreeLLMAPI regroupe 34 fournisseurs gratuits de grands modèles de langage derrière une interface compatible OpenAI avec routage intelligent et basculement.

  • TypeScript
  • GitHub Trending · 2026-08-28

Mises à jour

  • 28 août 2026: 21 410 étoiles, intégrant 34 fournisseurs d'IA gratuits avec streaming en temps réel.

Ce que vous gagnez

  • 34 fournisseurs de modèles gratuits: Passerelle unifiée connectée à Google Gemini, Groq, Cloudflare Workers AI et HuggingFace sans abonnement.
  • Compatibilité totale avec l'API OpenAI: Point de terminaison /v1/chat/completions compatible sans modification avec LangChain et LlamaIndex.
  • Routage intelligent et basculement automatique: Bascule automatiquement vers un fournisseur disponible en cas de saturation ou de panne.
  • Streaming d'événements serveur (SSE): Diffusez les réponses mot par mot en temps réel vers vos interfaces avec une latence minimale.
  • Déploiement léger et rapide: Déployable via Docker ou Node.js en quelques secondes sur machine locale ou serveur distant.

Installation

Cloner le dépôt et installer les dépendances
git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
npm install

Exécution

Démarrer le serveur et envoyer une requête
npm start
# OpenAI uyumlu istek:
curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Merhaba!"}]}'

Architecture technique et principe de fonctionnement

FreeLLMAPI agit comme un proxy inverse transformant les requêtes OpenAI en schémas propres à chaque fournisseur:

  • Couche d'adaptateurs de fournisseurs: Normalise les API REST et WebSocket hétérogènes en réponses JSON compatibles OpenAI.
  • Équilibrage de charge et gestion des quotas: Suit les limites d'utilisation pour acheminer les requêtes vers les modèles les plus véloces.
  • Mise en cache et tolérance aux pannes: Met en cache les requêtes fréquentes et réessaie automatiquement les appels en cas de timeout.

Routage de modèles et résilience au basculement

Les développeurs utilisent FreeLLMAPI pour évaluer des modèles en conditions réelles sans frais d'API:

  • Bancs d'essai multi-modèles: Envoyez des invites identiques à plusieurs modèles pour comparer qualité de réponse et latence.
  • Prototypage et MVP à coût zéro: Développez des prototypes d'IA sans enregistrer de carte bancaire ni payer de clés d'API.
  • Stratégie de secours haute disponibilité: Garantissez la continuité de service en basculant automatiquement vers des modèles secondaires en cas de panne.

Foire aux questions

  • Dois-je acheter des clés d'API pour utiliser FreeLLMAPI? Non. Le proxy rassemble 34 fournisseurs proposant des accès gratuits ou des offres d'essai sans abonnement.
  • Quels modèles de langage sont supportés? Les architectures supportées incluent Llama 3, Mistral, Gemma et les accès gratuits à Google Gemini.
  • Est-ce adapté à la confidentialité des données d'entreprise? FreeLLMAPI fonctionne localement, mais les fournisseurs tiers sous-jacents appliquent leurs propres règles de confidentialité.
  • Fonctionne-t-il avec LangChain ou CrewAI? Oui. Grâce à la conformité rigoureuse avec l'API OpenAI, il suffit de configurer baseURL sur localhost:3000/v1 pour l'intégrer à tout framework.
