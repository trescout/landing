# Concentrer les réponses de l'IA

Développé pour rendre la sortie des agents de codage plus ciblée et organisée, i-have-adhd améliore l'expérience utilisateur en divisant les réponses complexes en plusieurs parties. Cette compétence basée sur Python standardise la présentation des informations par l'IA dans un format compatible avec le trouble déficitaire de l'attention avec hyperactivité (TDAH).

## Ce que ça vous apporte
- Supprime les phrases d'introduction inutiles dans les réponses de l'IA.
- Divise les tâches complexes en étapes numérotées.
- Il fournit un format de sortie clair qui se concentre directement sur l’action.

## Pour commencer
Les étapes d'installation varient en fonction de l'outil de codage que vous utilisez (Claude Code ou Codex). Veuillez consulter la section « Installer » sur la page GitHub du projet ou suivre le fichier INSTALL.md pour des instructions détaillées.
