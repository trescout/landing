# Plateforme de montage vidéo open source

OpenCut est un projet de développement d'applications basé sur TypeScript qui offre une alternative open source pour les processus de montage vidéo. Visant à offrir une expérience utilisateur de type CapCut, cette plateforme vise à rendre accessibles les outils de montage vidéo.

## Ce que ça vous apporte
- Prise en charge des plateformes Web, de bureau et mobiles
- Extensibilité avec une architecture orientée plugin
- Mode sans tête pour l'automatisation et le traitement par lots

## Si vous ne codez pas
En vous basant sur l'architecture du projet OpenCut en cours de réécriture, notamment sa structure de base basée sur Rust, son système de plug-ins et les fonctionnalités du serveur MCP proposées aux agents d'intelligence artificielle, expliquez en détail comment cet outil peut automatiser les flux de montage vidéo et l'impact du futur support des plug-ins sur les processus créatifs.
