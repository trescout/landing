# Outil d'automatisation de navigateur pour les agents d'intelligence artificielle

Développé par Vercel Labs, agent-browser est une interface en ligne de commande (CLI) offrant l'automatisation de navigateur pour les agents d'intelligence artificielle. Écrit en Rust, cet outil permet de lire les pages sous forme d'arbre d'accessibilité et d'interagir avec les éléments web via la ligne de commande.

## Ce que ça vous apporte

- Lit les pages sous forme de texte via l'arbre d'accessibilité
- Interagit avec les éléments web via la ligne de commande
- Gère le navigateur commande par commande avec le serveur en arrière-plan

## Installation

**Configuration générale**

```
npm install -g agent-browser
agent-browser install           # download Chrome for Testing (first time only)
```

## Exécution

**Démarrage rapide**

```
agent-browser open example.com
```
