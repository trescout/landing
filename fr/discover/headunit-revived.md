# Transformez votre tablette en écran Android Auto

Le projet relancé par l'unité principale fournit une application qui permet de visualiser l'interface Android Auto sur différents écrans. Ce logiciel, développé en langage Kotlin, offre une solution d'affichage alternative pour les systèmes d'infodivertissement embarqués.

- ★ 1 484
- Kotlin
- GitHub Trending · 2026-06-25

## Ce que ça vous apporte
- Utilisez votre tablette ou votre téléphone Android comme écran embarqué
- Prise en charge de la connexion filaire via USB
- Connexion sans fil fiable avec Wireless Helper

## Pour commencer
- Source officielle →
Téléchargez l'application sur votre appareil via Google Play Store ou Amazon Appstore. Pour une connexion sans fil, il est recommandé d'installer également l'application « Wireless Helper » sur votre téléphone. Pour connaître les étapes d'installation détaillées et les paramètres de connexion, vous pouvez consulter la section Wiki sur la page GitHub.
