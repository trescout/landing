# Gérez votre propre archive multimédia

LunaTV est un projet développé en TypeScript qui propose une interface de visualisation multimédia open source. Ce logiciel, qui n'est pas destiné à un usage commercial, permet aux utilisateurs de regarder leurs propres contenus multimédias dans une structure organisée.

## Ce que ça vous apporte
- Possibilité de regarder des contenus multimédias personnels dans une interface organisée
- Synchronisation de l'historique de visionnage et des favoris entre les appareils
- Expérience de visionnage portable sans installation via le navigateur

## Pour commencer
Cet outil fonctionne avec la technologie de conteneurisation logicielle appelée Docker. Pour l'installation, vous pouvez vous rendre dans la section '部署' (Déploiement) sur la page GitHub du projet pour utiliser les fichiers Docker Compose ou effectuer une installation en un clic via des plateformes cloud comme Zeabur. N'oubliez pas que le projet est livré avec une interface vide et que vous devez ajouter vos propres sources multimédias.
