# Analysez rapidement vos documents avec Rust

Liteparse (run-llama); est un analyseur de documents open source écrit en Rust pour analyser des documents rapidement et efficacement. Il facilite les processus IA et RAG en rendant les structures de documents complexes traitables.

Installez l'outil d'analyse PDF LiteParse avec « pip install liteparse », puis extrayez le texte d'un PDF avec la commande « lit parse document.pdf » ou enregistrez-le au format JSON structuré avec des cadres de délimitation avec « lit parse document.pdf --format json -o output.json ».

Dépôt : https://github.com/run-llama/liteparse. Base-toi sur les instructions officielles du fichier README de ce dépôt pour l'installation et l'exécution.

Avant de commencer, vérifie quel système d'exploitation nous utilisons et si les outils nécessaires (ex: Python, Node.js, Git, Docker) sont installés. Installe ceux qui manquent étape par étape selon ce système.

Crée un nouveau dossier vide pour travailler. Ne touche pas aux fichiers en dehors de ce dossier et ne supprime rien. Avant chaque commande, décris ce que tu vas faire en une phrase.
