# Gestion des tâches asynchrones avec intelligence artificielle

pi-subagents est une bibliothèque TypeScript développée pour gérer les processus de délégation de sous-agents asynchrones sur la plateforme Pi. Il facilite la distribution de charges de travail complexes aux sous-agents.

## Ce que ça vous apporte
- Il répartit la charge de travail entre les sous-agents.
- Fournit une exécution asynchrone et parallèle.
- Il fonctionne entièrement intégré à la plateforme Pi.

## Comment installer, comment utiliser ?
**installer avec pi**

```
pi install npm:pi-subagents
```

**Exécuter un sous-agent**

```
/run <ajan> [görev]
```

**Exécuter des agents en parallèle**

```
/parallel ajan1 "görev1" -> ajan2 "görev2"
```
