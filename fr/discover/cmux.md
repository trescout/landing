# Terminal intelligent et automatisation pour macOS

cmux, un terminal macOS basé sur Ghostty, propose des onglets verticaux et un support de notification pour les agents de codage IA. Axé sur la gestion du multitâche et la programmabilité, cet outil aide les développeurs à organiser leur espace de travail.

## Ce que ça vous apporte
- Offre un support de notification pour les agents de codage IA
- Organise l'espace de travail avec des onglets verticaux et horizontaux
- Comprend un navigateur intégré avec une API scriptable

## Installation
**Installation avec Homebrew**

```
brew tap manaflow-ai/cmux
brew install --cask cmux
```


## Exécution
**Mise à jour de l'application**

```
brew upgrade --cask cmux
```


## Si vous ne codez pas
cmux est un terminal macOS qui permet de suivre les notifications, de gérer les fenêtres avec des onglets verticaux et horizontaux et d'utiliser le navigateur intégré tout en travaillant avec des agents de codage d'intelligence artificielle.
