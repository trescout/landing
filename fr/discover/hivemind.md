# Mémoire centrale pour les agents d'intelligence artificielle

Développé par Activeloop, Hivemind propose une couche mémoire centralisée pour tous les agents d'intelligence artificielle. Cette structure basée sur TypeScript permet à différents agents de partager des données et de communiquer via un pool de renseignements commun.

- ★ 1 564
- TypeScript
- GitHub Trending · 2026-06-11

## Ce que ça vous apporte
- Il crée une couche de mémoire et de coordination commune pour tous vos agents IA.
- Il transforme automatiquement les modèles de solutions réussies des sessions précédentes en compétences réutilisables.
- Cela réduit les coûts en permettant aux agents d'atteindre l'objectif en utilisant moins de jetons et moins d'étapes.

## Installation
**Configuration générale**

```
npm install -g @deeplake/hivemind && hivemind install
```


## Exécution
**Vérification de l'état**

```
hivemind status
```
