# Configurez un serveur HTTPS automatique

Caddy est un serveur web extensible écrit en Go qui offre une gestion automatique des certificats HTTPS. Il simplifie la configuration et la sécurité des sites web en prenant en charge les protocoles HTTP/1, HTTP/2 et HTTP/3.

- ★ 76 784
- Go
- GitHub Trending · 2026-10-05

## Ce que ça vous apporte
- Offre une gestion automatique des certificats HTTPS par défaut
- Prend en charge les protocoles HTTP/1, HTTP/2 et HTTP/3
- Fonctionne partout sans dépendance externe

## Exécution
**Compilation**

```
git clone "https://github.com/caddyserver/caddy.git"
cd caddy/cmd/caddy/
go build
```
