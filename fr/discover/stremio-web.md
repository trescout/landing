# Lecture multimédia via navigateur

Stremio est une application de lecteur multimédia qui regroupe différents fournisseurs de contenu dans une interface unique. Cette version basée sur le web permet aux utilisateurs de regarder des séries et des films via leur navigateur sans aucune installation.

## Ce que ça vous apporte

- Regroupe différents fournisseurs de contenu dans une interface unique
- Synchronise l'historique de visionnage et la bibliothèque entre les appareils
- Permet la diffusion d'images vers la télévision avec Chromecast

## Installation

**Configuration de l'environnement de développement local**

```
pnpm install
pnpm start
```

**Installation de conteneur avec Docker**

```
docker build -t stremio-web .
docker run -p 8080:8080 stremio-web
```
