# Expérience de ligne de commande Windows moderne

Microsoft combine Windows Terminal et l'hôte de console Windows traditionnel sous un même toit. Ce projet open source, développé en langage C++, restructure l'expérience en ligne de commande avec une interface moderne et des onglets personnalisables.

- ★ 104 442
- C++
- GitHub Trending · 2026-07-20

## Ce que ça vous apporte
- Interface moderne et personnalisable
- Prise en charge de plusieurs onglets
- Performances de ligne de commande améliorées

## Installation
**Windows (winget)**

```
winget install Microsoft.WindowsTerminal
```


## Exécution
**Exécuter à partir de la ligne de commande**

```
wt
```
