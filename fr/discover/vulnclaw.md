# Tests d'intrusion automatiques avec intelligence artificielle

VulnClaw automatise les processus de tests d'intrusion à l'aide d'agents IA et de la chaîne d'outils Model Context Protocol. L'outil traite les commandes en langage naturel et effectue des étapes de collecte d'informations de bout en bout, d'analyse des vulnérabilités, d'exploitation et de reporting.

## Ce que ça vous apporte
- Tests d'intrusion de bout en bout avec des commandes en langage naturel
- Analyse de sécurité autonome ciblée
- Reporting automatique et génération de PoC Python

## Installation
**Installation via PyPI**

```
pip install vulnclaw
```

**Installation à partir du code source**

```
git clone https://github.com/Unclecheng-li/VulnClaw.git
cd VulnClaw
pip install -e .
```


## Exécution
**Démarrage rapide**

```
vulnclaw
```

**Analyse ciblée**

```
vulnclaw run <target>
```


## Si vous ne codez pas
Vous êtes un testeur d'intrusion. À l'aide de l'outil VulnClaw, collectez des informations sur le système cible, effectuez les étapes d'analyse et d'exploitation des vulnérabilités. Utilisez le moteur de résolution orienté cible lors de l'exécution des opérations, vérifiez vos résultats et créez un rapport structuré et un code PoC basé sur Python à la fin du processus. À chaque étape, procédez en fonction des données réelles que vous obtenez et évitez les hypothèses.
