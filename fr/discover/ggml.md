# Bibliothèque de tenseurs pour les modèles d'intelligence artificielle

ggml-org/ggml est une bibliothèque de tenseurs développée en C++ pour les modèles d'apprentissage automatique. Le logiciel facilite l'exécution des modèles d'intelligence artificielle en fournissant des exemples simples et explicites pour des opérations de base telles que la multiplication matricielle.

## Ce que ça vous apporte

- Offre des opérations tensorielles hautes performances en C et C++ sans dépendances externes.
- Peut s'exécuter sur les unités centrales (CPU), les unités de traitement graphique (GPU) et dans des environnements de navigateur.
- Réduit l'utilisation de la mémoire grâce à des formats de quantification qui diminuent la taille des données.

## Installation

**Compilation à partir du code source**

```
git clone https://github.com/ggml-org/ggml
cd ggml

mkdir build && cd build
cmake ..
cmake --build . --config Release -j 8
```
