# Créer des modèles tridimensionnels à partir d'images

Modly est une application de bureau qui crée des modèles 3D à partir d'images et effectue toutes les opérations sur la carte graphique locale (GPU). Cet outil, qui fonctionne sans connexion Internet, transpose le processus de modélisation basé sur l’intelligence artificielle sur les ordinateurs personnels.

- ★ 6 115
- TypeScript
- GitHub Trending · 2026-08-14

## Ce que ça vous apporte
- Convertit les photos en modèles 3D sur l'ordinateur local
- Fonctionne complètement hors ligne sans connexion Internet requise
- Offre une structure flexible qui peut être étendue avec des modèles externes

## Installation
**Installation des dépendances**

```
npm install
```

**Préparation de l'infrastructure Python**

```
cd api
python -m venv .venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate  # Linux / macOS
pip install -r requirements.txt
```


## Exécution
**Démarrer l'application**

```
# Windows
launch.bat

# Linux / macOS
./launch.sh
```


## Si vous ne codez pas
Je souhaite convertir une image en modèle 3D à l'aide de l'application Modly. Aidez-moi à configurer le flux « Image -> Générer un maillage -> Ajouter à la scène » en accédant à l'onglet « Workflows » de l'application. Laissez-moi ensuite démarrer la génération du modèle 3D en sélectionnant le flux de travail approprié dans l'onglet « Générer ». Si j'obtiens une erreur, comment puis-je analyser le problème dans la section « Paramètres/Journaux/Erreurs » ?
