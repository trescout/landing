# Prise en charge de l'intelligence artificielle pour les processus de codage

Continue est un agent de codage open source conçu pour automatiser les processus de développement de logiciels. Il permet aux développeurs d'écrire, de déboguer et de refactoriser du code dans l'EDI à l'aide de leurs modèles de langage natif (LLM).

**Note TreScout :** Assistant d'intelligence artificielle qui vous aide à écrire du code. La différence avec les assistants prêts à l'emploi est que vous décidez quel modèle vous utiliserez : vous connectez votre propre clé ou un modèle fonctionnant sur votre ordinateur, votre code ne sera pas divulgué. En retour, l'installation et la sélection du modèle deviennent votre travail, l'expérience n'est pas aussi raffinée que celle des produits disponibles dans le commerce.

## Ce que ça vous apporte

- Accélère les processus de codage et de débogage
- Fournit un espace de travail sécurisé avec des modèles linguistiques locaux
- S'intègre aux environnements de développement logiciel tels que VS Code et JetBrains

## Installation

**Installation du CLI avec npm (global)**

```
npm i -g @continuedev/cli
```

**Installer l'extension VS Code**

```
code --install-extension Continue.continue
```

**Global via npm**

```
npm install -g continue
```

## Exécution

**Exécuter l'agent Continue via CLI**

```
cn
```
