# Prise en charge de l'intelligence artificielle pour les processus de codage

Continue est un agent de codage open source conçu pour automatiser les processus de développement de logiciels. Il permet aux développeurs d'écrire, de déboguer et de refactoriser du code dans l'EDI à l'aide de leurs modèles de langage natif (LLM).

- ★ 35 282
- GitHub Trending · 2026-06-18

## Ce que ça vous apporte
- Accélère les processus de codage et de débogage
- Fournit un espace de travail sécurisé avec des modèles linguistiques locaux
- S'intègre aux environnements de développement logiciel tels que VS Code et JetBrains

## Installation
**Installation CLI avec npm (global)**

```
npm i -g @continuedev/cli
```

**Installation en tant que module complémentaire VS Code**

```
code --install-extension Continue.continue
```

****

```
npm install -g continue
```


## Exécution
**Exécuter l'agent Continuer via CLI**

```
cn
```


## Si vous ne codez pas
En tant qu'assistant de développement logiciel, guidez-moi tout au long du processus d'écriture de code à l'aide de modèles de langage natif, de restructuration des blocs de code existants et de débogage. Analysez les fichiers dans mon environnement de travail, fournissez des suggestions pour améliorer la qualité du code et aidez-moi à détecter des erreurs logiques complexes.
