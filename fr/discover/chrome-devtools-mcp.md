# Débogage du navigateur pour l'IA

Développé pour Chrome DevTools, ce serveur permet aux agents de codage d'intelligence artificielle de gérer les processus de débogage basés sur le navigateur. Fonctionnant via le Model Context Protocol, cet outil permet aux agents d'inspecter directement les applications Web et d'automatiser les processus de débogage.

## Ce que ça vous apporte

- Contrôlez directement le navigateur en direct

- Examiner les requêtes réseau et les erreurs de la console

## Installation

**Global via npm**

```
npm install -g chrome-devtools-mcp
```

## Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Connectez-vous à ma session de navigateur active à l'aide du serveur Chrome DevTools MCP et analysez les données de performances de mon application Web. Vérifiez les requêtes réseau, examinez les erreurs de la console et effectuez les étapes de débogage nécessaires pour résoudre les problèmes que je rencontre.
