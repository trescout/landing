# Introduire les systèmes de conception à l’IA

Développé par Google Labs, DESIGN.md fournit une spécification de format structuré pour transmettre les informations d'identification visuelles aux agents de codage. Cette norme garantit que les systèmes de conception sont compris de manière cohérente et permanente par les agents d’intelligence artificielle.

- ★ 26 873
- TypeScript
- GitHub Trending · 2026-06-25

## Ce que ça vous apporte
- Stocke les décisions de conception dans un format structuré
- Fournit un guidage visuel cohérent pour les agents de codage
- Vérifie automatiquement les erreurs de conception et les incohérences

## Installation
**Installer le paquet**

```
npm install @google/design.md
```

**Installer pour Windows**

```
npm install "@google/design.md"
```


## Exécution
**Valider le fichier de conception**

```
npx @google/design.md lint DESIGN.md
```

**Comparaison de deux fichiers de conception**

```
npx @google/design.md diff DESIGN.md DESIGN-v2.md
```


## Si vous ne codez pas
Consultez le fichier DESIGN.md qui définit l'identité visuelle et le système de conception de mon projet. Respectez cette structure dans tous les codes que vous créez en vous référant à la palette de couleurs, aux règles de typographie, aux valeurs d'espace et aux définitions de composants dans ce fichier. Utilisez les valeurs directement du système de conception et évitez de créer des incohérences visuelles.
