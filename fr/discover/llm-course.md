# Feuille de route d'apprentissage des grands modèles de langage

mlabonne/llm-course est une ressource pédagogique complète comprenant des feuilles de route et des carnets Colab pour ceux qui souhaitent se lancer dans le domaine des grands modèles de langage (LLM). Ce projet propose un programme guidant les personnes désireuses d'apprendre les modèles d'intelligence artificielle, des bases jusqu'au niveau avancé.

- ★ 84 301
- GitHub Trending · 2026-10-19

## Ce que ça vous apporte

- Comprendre l'architecture des modèles de langage en partant des mathématiques fondamentales et des réseaux de neurones artificiels
- Optimiser les modèles open source grâce au réglage fin (fine-tuning) et à la quantification (quantization)
- Exécuter directement des expérimentations sans aucune installation grâce à des carnets de code Google Colab prêts à l'emploi dans le cloud

## Pour commencer

Aucune installation logicielle sur votre ordinateur n'est requise pour utiliser ce projet. Vous pouvez explorer les sujets abordés sur le dépôt GitHub ou sur la page de documentation DeepWiki, puis cliquer sur le lien Google Colab de la section qui vous intéresse pour exécuter les travaux directement depuis votre navigateur.
