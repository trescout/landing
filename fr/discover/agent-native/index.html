Cadre d'application pour les agents IA

Développé par BuilderIO, agent-native est un framework TypeScript axé sur la création d'applications natives pour les agents d'intelligence artificielle. Il permet aux développeurs d'intégrer des flux de travail basés sur des agents directement dans l'architecture de l'application.

Ce que ça vous apporte

  • Synchronise l'agent et l'interface utilisateur dans une seule base de données
  • Entièrement compatible avec les bases de données SQL et l'hébergement propulsé par Nitro
  • Vous permet de définir votre code une fois et de l'utiliser en CLI, API et interface

Installation

Créer un projet
npx @agent-native/core@latest create my-platform
cd my-platform
pnpm install
pnpm dev
Ajoutez des talents prêts à l'emploi
npx @agent-native/core@latest skills add visual-plan

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Je souhaite définir une action pour mon application à l'aide du framework Agent-Native. À l'aide de la fonction définirAction, aidez-moi à créer une structure qui traitera les données entrantes dans la base de données et sera accessible à la fois à l'interface utilisateur et à l'agent d'intelligence artificielle.
