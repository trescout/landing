# Produisez des vidéos IA en un seul clic

MoneyPrinterTurbo produit automatiquement de courtes vidéos en utilisant de grands modèles linguistiques à partir d'un sujet ou d'un mot-clé que vous fournissez. Il combine texte, sous-titres, musique de fond et visuels. (Le nom est à des fins de marketing, il s'agit d'un outil de production de contenu, pas d'une machine à « imprimer de l'argent ».)

## Ce que ça vous apporte

- Il crée une édition automatique à l'aide de texte, de sous-titres, de musique et de visuels.
- Il est simple à utiliser grâce à son interface web.
- Il permet la production vidéo par lots et multiples.

## Installation

**Cloner le dépôt officiel**

```
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
```

## Exécution

**Démarrer avec Docker Compose**

```
docker-compose up
```

**Démarrer l'interface web**

```
uv run streamlit run ./webui/Main.py --browser.gatherUsageStats=False
```

## note honnête

Nécessite une clé API de modèle AI + une installation pour fonctionner ; L'utilisation de l'API peut être facturée. Il est de la responsabilité de l'utilisateur de s'assurer que les vidéos produites sont conformes aux règles du droit d'auteur et de la plateforme.
