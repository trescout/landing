# Cartographiez votre base de code pour l'intelligence artificielle

Codegraph est un outil de graphe de connaissances (knowledge graph) local qui pré-indexe les bases de code pour les fournir aux modèles d'intelligence artificielle. En synchronisant automatiquement les modifications de code, il permet aux assistants de codage comme Claude Code ou Cursor d'utiliser moins de jetons (tokens) et d'appels d'outils.

## Ce que ça vous apporte
- Génère un graphe de connaissances local qui permet aux modèles d'intelligence artificielle de consommer moins de jetons lors du codage.
- Maintient l'index toujours à jour en synchronisant automatiquement les modifications de code en arrière-plan.
- Connecte des outils comme l'assistant de codage Cursor directement à l'architecture de votre projet.

## Installation
**Installation globale avec le gestionnaire de paquets npm**

```
npm i -g @colbymchenry/codegraph
```


## Exécution
**Exécution et liaison de l'outil directement avec npx**

```
npx @colbymchenry/codegraph
```


## Si vous ne codez pas
Installez l'outil Codegraph dans mon projet en exécutant la commande `npm i -g @colbymchenry/codegraph` via le gestionnaire de paquets npm. Ensuite, exécutez la commande `npx @colbymchenry/codegraph` pour configurer les assistants d'intelligence artificielle et terminer le processus.
