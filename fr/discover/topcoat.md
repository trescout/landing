# Applications Web à part entière avec Rust

Développé par l'équipe Tokio, Topcoat propose un framework complet qui comprend tous les outils nécessaires pour créer des applications Web dans Rust. Il vise à standardiser le processus de développement d’applications en rassemblant les composants de base nécessaires aux développeurs dans une structure unique.

## Ce que ça vous apporte
- Rendu HTML rapide côté serveur
- Routage automatique avec structure modulaire
- Bibliothèque de composants prête à l'emploi avec intégration Tailwind

## Installation
**Rouille avec cargaison**

```
cargo install topcoat
```


## Pour commencer
- Source officielle →
Pour commencer à travailler avec Topcoat, vous devez suivre le guide « Mise en route » dans la documentation officielle sur GitHub. À l'aide de ce guide, vous pouvez créer un nouveau projet, installer l'outil CLI nécessaire et démarrer le serveur de développement.
