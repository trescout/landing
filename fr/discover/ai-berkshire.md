# Recherche d'investissement de valeur avec l'intelligence artificielle

AI-berkshire est un cadre de recherche sur l'investissement de valeur qui met en œuvre les méthodologies d'investisseurs tels que Warren Buffett et Charlie Munger, en utilisant l'infrastructure Claude Code. Le système analyse les données financières grâce à sa structure multi-agents et effectue des examens contradictoires.

## Ce que ça vous apporte
- Analyse structurée avec la méthodologie de quatre maîtres d'investissement
- Enquête oppositionnelle approfondie avec plusieurs agents IA
- Haute précision et contrôle des erreurs dans les données numériques

## Installation
**Installation de Claude Code**

```
npm install -g @anthropic-ai/claude-code
```

**Copiez le jeu d'outils**

```
git clone https://github.com/xbtlin/ai-berkshire.git

# 复制 skills 到 Claude Code 全局 commands 目录
cp ai-berkshire/skills/*.md ~/.claude/commands/
```


## Si vous ne codez pas
En tant qu'analyste en investissement, vous analysez la société que je choisis en utilisant les méthodologies de Warren Buffett, Charlie Munger, Duan Yongping et Li Lu. Dans votre analyse, évaluez non seulement les données financières, mais également la durabilité du modèle économique, les avantages concurrentiels (fossé), la qualité de la gestion et les risques possibles sous quatre perspectives différentes. Utiliser des sources indépendantes pour vérifier les informations, préférer dire « je ne sais pas » dans des situations ambiguës et fournir des conseils stratégiques avec une fourchette de prix claire pour la décision d'investissement.
