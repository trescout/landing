# Gérez votre serveur cloud personnel

CasaOS propose un système cloud personnel open source qui facilite la gestion des applications basées sur Docker. Cette interface, développée avec le langage Go, permet aux utilisateurs de gérer simplement leurs serveurs via un panneau visuel.

## Ce que ça vous apporte
- Installez les applications Docker en un clic
- Gérer les fichiers avec une interface visuelle
- Surveiller les ressources du serveur avec un widget

## Installation
**commande d'installation**

```
curl -fsSL https://get.casaos.io | sudo bash
```


## Exécution
**commande de mise à jour**

```
curl -fsSL https://get.casaos.io/update | sudo bash
```


## Si vous ne codez pas
J'utilise CasaOS pour gérer les applications basées sur Docker sur mon serveur personnel. Je souhaite surveiller les ressources de mon système, installer de nouvelles applications et gérer les fichiers via un panneau visuel. Expliquez étape par étape les défis techniques que j'ai rencontrés dans ce processus et comment je peux gérer plus efficacement les applications dans l'écosystème Docker.
