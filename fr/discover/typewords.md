# Mémorisez des mots anglais avec votre vitesse de frappe

TypeWords est un outil d'exercice de dactylographie basé sur une interface Vue qui permet aux utilisateurs d'améliorer leur vitesse de frappe tout en pratiquant l'anglais. Le logiciel transforme chaque frappe en une étape d'apprentissage, soutenant les compétences linguistiques par la gamification.

## Ce que ça vous apporte

- Effectue une répétition intelligente des mots selon les courbes de mémorisation
- Offre la possibilité d'une étude comparative bilingue avec des manuels et des articles
- Suit automatiquement les mots mal orthographiés et les ajoute à la liste de répétition

## Pour commencer

Aucune installation n'est nécessaire pour commencer à utiliser l'outil ; vous pouvez vous rendre sur https://typewords.cc depuis votre navigateur et commencer à pratiquer immédiatement. Si vous souhaitez l'exécuter sur votre propre ordinateur, après avoir installé l'environnement de développement Node.js, vous pouvez télécharger le code source du projet depuis GitHub et lancer le serveur local en installant les dépendances nécessaires via le terminal.
