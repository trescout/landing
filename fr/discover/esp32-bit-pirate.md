# Outil multiprotocole pour l'analyse du matériel

ESP32-Bit-Pirate est un outil de piratage matériel qui prend en charge plusieurs protocoles de communication via une interface de ligne de commande (CLI) basée sur le Web. Ce système, développé en langage C++, facilite les processus d'analyse matérielle en gérant différents protocoles sur une seule plateforme.

## Ce que ça vous apporte

- Gérer des protocoles tels que I2C, SPI, UART et 1-Wire
- Interaction avec les fréquences radio, Bluetooth et Wi-Fi
- Débogage du matériel via une interface Web

## Pour commencer

Installez le logiciel adapté à votre appareil via votre navigateur à l'aide de l'outil Web Flasher sur le site officiel. Ensuite, accédez à l'interface de ligne de commande en vous connectant à votre appareil avec une application de terminal série ou un terminal série Web basé sur un navigateur.
