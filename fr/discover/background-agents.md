# Agents d'intelligence artificielle qui développent des logiciels autonomes

Développé par ColeMurray, background-agents est un système de codage d'agents d'arrière-plan open source basé sur TypeScript. Il permet aux développeurs de créer des agents d'intelligence artificielle (agents IA) qui exécutent des processus autonomes au sein des applications.

- ★ 2 329
- TypeScript
- GitHub Trending · 2026-07-13

## Ce que ça vous apporte
- Exécuter des tâches autonomes en arrière-plan
- Accès à des environnements de développement complets
- Travail intégré via Slack et GitHub

## Installation
**Installation des dépendances**

```
# .openinspect/setup.sh (provisioning)
#!/bin/bash
npm install
pip install -r requirements.txt
```


## Exécution
**Démarrage de l'environnement de travail**

```
# .openinspect/start.sh (runtime startup)
#!/bin/bash
docker compose up -d postgres redis
```
