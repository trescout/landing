# Révision de code basée sur l'IA pour Claude Code

Développé par OpenAI, le plugin Codex est utilisé sur Claude Code pour automatiser les processus de révision de code et assurer la délégation de tâches. Cet outil permet l'intégration de différents modèles d'intelligence artificielle (grands modèles de langage) dans les workflows de développement logiciel.

- ★ 30 950
- JavaScript
- GitHub Trending · 2026-07-03

## Ce que ça vous apporte
- Automatise les processus de révision du code
- Délégue les tâches au modèle Codex
- Gère les tâches de longue durée en arrière-plan

## Installation
**Installez le pack Codex**

```
npm install -g @openai/codex
```


## Exécution
**Commencer le premier examen**

```
/codex:review
```


## Si vous ne codez pas
Commencez une révision de mon code existant à l'aide du plugin Codex dans Claude Code et rapportez les résultats. S'il y a une tâche complexe, déléguez-la au Codex avec la commande /codex:rescue et exécutez-la en arrière-plan, ce qui me permet de suivre la progression avec /codex:status.
