# Angulaire pour des applications Web complètes

Développé par Google, Angular est un framework complet utilisé pour créer des applications Web évolutives. Avec sa structure basée sur TypeScript, il propose des outils qui standardisent et structurent le processus de développement dans des projets complexes.

## Ce que ça vous apporte

- Offre la possibilité de développer des applications Web mobiles et de bureau
- Standardise les projets complexes grâce à sa structure basée sur TypeScript
- Facilite la création de projets évolutifs avec une prise en charge étendue des outils

## Installation

**Configuration de l'interface de ligne de commande**

```
npm install -g @angular/cli
```

## Exécution

**Créer un nouvel espace de travail**

```
ng new [PROJECT NAME]
```

**Démarrer l'application localement**

```
cd [PROJECT NAME]
ng serve
```
