Base de données évolutive pour les systèmes distribués

Apache Cassandra est une base de données transactionnelle distribuée open source qui offre une évolutivité linéaire et une tolérance aux pannes sans entraîner de perte de performances sur le matériel standard ou les infrastructures cloud. Ce système, développé en langage Java, est conçu pour les processus de gestion de données à grande échelle nécessitant une haute disponibilité.

  • ★ 10 004
  • Java
  • GitHub Trending · 2026-07-28

Ce que ça vous apporte

  • Distribue automatiquement les données sur plusieurs machines.
  • Gestion facile des données avec le langage de requête CQL de type SQL.
  • Offre une haute disponibilité et une tolérance aux pannes.

Installation

macOS (Homebrew)
brew install cassandra
Image Docker
docker pull cassandra

Exécution

Lancer avec Docker
docker run -p 9042:9042 cassandra
