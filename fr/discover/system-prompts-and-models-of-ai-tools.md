# Dans les coulisses des outils d’intelligence artificielle

Les invites système et les modèles de langage utilisés (modèles d'IA) des outils d'intelligence artificielle populaires sont rassemblés dans une source unique que les développeurs peuvent examiner. Cette archive révèle de manière transparente les stratégies de configuration derrière les assistants de codage et les plates-formes d'IA génératives actuelles.
