Créez vos propres technologies à partir de zéro

Build Your Own est une collection de guides étape par étape qui vous permettent de réécrire à partir de zéro vos technologies préférées telles que la base de données, le système d'exploitation, Git, Docker et le langage de programmation. Il propose une expérience d'apprentissage par la pratique, conformément à la philosophie de Feynman selon laquelle « je ne peux pas comprendre ce que je ne peux pas créer ».

Note TreScout : Le référentiel d'apprentissage n'est pas un outil à installer : il rassemble des didacticiels pour écrire votre propre base de données, shell ou Git à partir de zéro. C'est le moyen le plus efficace si l'on veut vraiment comprendre une technologie, mais ce n'est pas un travail de deux heures le soir · chaque guide prend des jours.

Ce que ça vous apporte

  • Vous apprenez la logique interne des systèmes par la pratique.
  • Un large éventail de sujets, de la base de données au système d'exploitation.
  • Des projets pratiques plutôt que des explications théoriques.

Comment utiliser ?

Vous pouvez choisir la technologie qui vous intéresse sur la page GitHub et suivre les guides étape par étape.
