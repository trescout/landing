# Créez automatiquement un wiki IA à partir de vos documents

LLM Wiki est une application de bureau multiplateforme qui organise automatiquement les documents en une base de connaissances interconnectée. Contrairement à la méthode traditionnelle de récupération et de réponse (RAG), elle crée un wiki permanent à partir de vos sources, maintenant les données à jour de manière progressive.

## Ce que ça vous apporte

- Analyse les documents et les transforme en pages wiki interconnectées
- Maintient les données constamment à jour grâce à une structure de mémoire permanente
- Entièrement compatible avec le logiciel de prise de notes Obsidian

## Pour commencer

Téléchargez-le sur votre ordinateur en suivant les étapes d'installation sur la page GitHub du projet. Assurez-vous que les environnements de développement Node.js et Rust sont installés, puis installez les dépendances nécessaires via la ligne de commande pour lancer l'application.
