# Protection des commandes pour les agents IA

Destructive Command Guard est une couche de sécurité développée pour empêcher les commandes git et shell dangereuses exécutées par des agents d'intelligence artificielle. Écrit en Rust, cet outil réduit les risques de perte de données indésirable ou de dommages au système en auditant les processus d'exécution de commandes au niveau du système.

## Ce que ça vous apporte
- Bloque les commandes dangereuses avant qu'elles ne soient exécutées
- Réduit le risque de perte de données et de dommages au système
- Fournit une protection complète avec plus de 50 packages de sécurité

## Installation
**Installation pour Linux et macOS**

```
curl -fsSL "https://raw.githubusercontent.com/Dicklesworthstone/destructive_command_guard/main/install.sh?$(date +%s)" | bash -s -- --easy-mode
```


## Si vous ne codez pas
J'utilise Destructive Command Guard pour contrôler les commandes que mon agent IA exécute sur mon système. Veuillez tenir compte des règles de sécurité avant d'exécuter des commandes dangereuses de suppression de git, de système de fichiers ou de base de données. Si vous devez prendre une action risquée, informez-moi d'abord et obtenez mon approbation.
