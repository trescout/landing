# Gérez facilement les requêtes API modernes

Insomnia est un client d'interface de programmation d'application (API) open source qui prend en charge les protocoles GraphQL, REST, WebSockets, SSE et gRPC. Le logiciel offre une prise en charge multiplateforme avec des options de stockage basées sur le cloud, local et Git.

## Ce que ça vous apporte
- Prise en charge du débogage de protocoles populaires tels que GraphQL, REST et gRPC
- Options de stockage flexibles locales, Git ou basées sur le cloud
- Conception d'API visuelle avec éditeur OpenAPI intégré

## Installation
**macOS (Homebrew)**

```
brew install --cask insomnia
```

**Package Linux Snap (éditeur Insomnia)**

```
sudo snap install insomnia
```


## Pour commencer
- Source officielle →
Pour commencer à utiliser Insomnia, vous pouvez vous rendre sur le site officiel https://insomnia.rest et télécharger et exécuter le fichier d'installation adapté à votre système d'exploitation. Vous pouvez commencer à utiliser l'application avec sa fonctionnalité native Scratch Pad sans créer de compte, ou créer un compte gratuit pour plus de fonctionnalités.
