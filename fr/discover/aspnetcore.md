# Plateforme pour applications Web d'entreprise

ASP.NET Core est un framework .NET multiplateforme utilisé pour développer des applications Web modernes basées sur le cloud sur Windows, macOS et Linux. Cette structure, développée en langage C#, permet de créer des services web performants et évolutifs.

- ★ 38 367
- GitHub Trending · 2026-06-19

## Ce que ça vous apporte
- Fonctionnement multiplateforme sur Windows, macOS et Linux
- Développement d'applications basées sur le cloud et évolutives
- Structure de composants modulaires avec une faible utilisation des ressources

## Installation
**macOS (Homebrew)**

```
brew install --cask dotnet-sdk
```

**Windows (winget)**

```
winget install Microsoft.DotNet.SDK.10
```


## Exécution
**Créer et exécuter un nouveau projet ASP.NET Core**

```
dotnet new webapi -n MyWebApp
cd MyWebApp
dotnet run
```
