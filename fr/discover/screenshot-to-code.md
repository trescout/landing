# Transformez des captures d'écran en code fonctionnel

Screenshot-to-code est un outil logiciel qui analyse des fichiers de capture d'écran pour les convertir en code HTML, Tailwind, React ou Vue propre. Il permet aux développeurs de transformer rapidement des conceptions d'interface en extraits de code fonctionnels.

## Ce que ça vous apporte

- Convertit les captures d'écran et les fichiers de conception en code HTML ou React propre
- Transforme les enregistrements de sites web en prototypes fonctionnels
- Prend en charge Tailwind CSS et diverses bibliothèques d'interface populaires

## Installation

**Installation rapide avec Docker**

```
echo "OPENAI_API_KEY=sk-your-key" > .env
docker-compose up -d --build
```

**Démarrage de l'interface**

```
cd frontend
pnpm install
pnpm dev
```
