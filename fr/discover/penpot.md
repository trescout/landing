# Plateforme alliant design et logiciel

Penpot est un outil de conception open source qui renforce la collaboration entre concepteurs et développeurs. Grâce à son interface vectorielle, il vous permet de gérer les processus de conception de manière intégrée avec la phase de codage.

- ★ 57 989
- Clojure
- GitHub Trending · 2026-06-18

## Ce que ça vous apporte
- Intègre les processus de conception avec le code
- Propose des normes ouvertes et des jetons de conception
- Fournit une collaboration d’équipe en temps réel

## Installation
**Téléchargez le fichier de composition officiel**

```
curl -o docker-compose.yaml https://raw.githubusercontent.com/penpot/penpot/main/docker/images/docker-compose.yaml
```


## Exécution
**Démarrer (http://localhost:9001)**

```
docker compose -p penpot -f docker-compose.yaml up -d
```
