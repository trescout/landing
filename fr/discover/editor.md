# Éditeur d'architecture 3D basé sur le Web

L'éditeur/pascalorg basé sur TypeScript permet aux utilisateurs de créer et de partager des projets architecturaux en trois dimensions via le navigateur. Le logiciel vise à rendre les processus de conception architecturale accessibles via une interface Web.

- ★ 21 794
- TypeScript
- GitHub Trending · 2026-07-29

## Ce que ça vous apporte
- Modélisation architecturale 3D avec React Three Fiber
- Visualisation hautes performances avec prise en charge WebGPU
- Gestion de la scène centrale et des statuts basée sur Zustand

## Installation
**Installer les packages requis**

```
npm install @pascal-app/core @pascal-app/viewer @pascal-app/editor @pascal-app/nodes
```


## Exécution
**Démarrer le serveur de développement**

```
bun dev
```


## Si vous ne codez pas
Je souhaite créer une scène architecturale à l'aide de Pascal Editor. Aidez-moi à construire une structure 3D de base en utilisant les packages @pascal-app/core et @pascal-app/viewer inclus dans l'architecture du projet. Expliquez-moi étape par étape comment configurer les hooks useScene et useViewer pour gérer l'état de la scène, définir la hiérarchie des nœuds (Site, Bâtiment, Niveau) et intégrer un composant NodeRenderer dans la scène.
