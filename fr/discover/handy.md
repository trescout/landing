# Transcrivez votre voix en local

cjpais/Handy est une application de reconnaissance vocale (speech-to-text) gratuite et open source qui fonctionne entièrement hors ligne. Développé en Rust, cet outil offre une structure extensible permettant aux utilisateurs de traiter des données vocales en local.

## Ce que ça vous apporte

- Convertit instantanément vos paroles en texte sans nécessiter de connexion Internet
- Protège votre vie privée en évitant d'envoyer des données vocales à des serveurs cloud
- Écrit directement dans le champ de texte actif en appuyant sur un raccourci clavier défini par l'utilisateur

## Installation

**Systèmes Linux basés sur Debian ou Ubuntu**

```
sudo apt install ./Handy_*.deb
```
