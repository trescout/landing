# Révision de code de précision basée sur l'IA

L'outil de révision de code open source développé par Alibaba combine des pipelines déterministes et des agents LLM (Large Language Model) dans une structure hybride. Doté de règles de sécurité logicielles et de capacités d'interprétation basées sur les lignes, l'outil est écrit en langage Go et propose une infrastructure compatible OpenAI et Anthropic.

## Ce que ça vous apporte
- Détection précise des erreurs basée sur les lignes
- Haute efficacité avec une faible consommation de jetons
- Résultats stables avec des pipelines déterministes

## Installation
**Installer l'outil CLI globalement**

```
npm install -g @alibaba-group/open-code-review
```


## Si vous ne codez pas
Passez en revue mes modifications Git actuelles à l’aide de l’outil Open Code Review. Analysez les fichiers dans la base de code, détectez les erreurs ligne par ligne et créez des commentaires structurés. Minimisez les faux positifs en suivant des règles déterministes pendant le processus d'examen et concentrez-vous uniquement sur les erreurs critiques de sécurité ou de logique.
