# Bibliothèque de programmation réseau asynchrone

Asio est une bibliothèque C++ développée pour les opérations d'E/S asynchrones. Il fournit une passerelle portable (abstraction réseau) pour la programmation réseau et les tâches système de bas niveau.

## Ce que ça vous apporte

- Effectuer des opérations d'entrée et de sortie asynchrones
- Établir une infrastructure de programmation réseau portable
- Gestion des tâches système de bas niveau

## Installation

**macOS (Homebrew)**

```
brew install asio
```
