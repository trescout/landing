# OpenMAIC

OpenMAIC est une plateforme d'apprentissage immersive qui simule les interactions entre plusieurs agents d'intelligence artificielle en un seul clic. Développé avec TypeScript, cet outil open source permet aux utilisateurs de faire l'expérience d'un environnement de classe interactif avec différents modèles d'agents.
