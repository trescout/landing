# Plateforme de données et d'analyses SEO open source

Open SEO offre une alternative open source aux outils payants comme Semrush et Ahrefs. Ce logiciel, développé pour analyser les données d'optimisation des moteurs de recherche (SEO), vise à rendre les processus transparents grâce à son infrastructure basée sur TypeScript.

## Ce que ça vous apporte
- Payez uniquement ce que vous utilisez, sans frais d'abonnement
- Analyse des données SEO directe avec des agents d'intelligence artificielle
- Suivi des mots clés et audit technique du site

## Installation
**Ajouter des fonctionnalités à un agent IA**

```
npx skills add every-app/open-seo --skill '*'
```

**Installation locale avec Docker**

```
docker compose pull
docker compose up -d
```


## Si vous ne codez pas
Effectuer une recherche détaillée de mots clés pour mon site Web à l'aide des fonctionnalités OpenSEO et analyser mes données de classement actuelles pour fournir des suggestions d'amélioration.
