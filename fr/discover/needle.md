# IA légère pour les appareils de pointe

Développé par Cactus Compute, Needle propose un modèle de base de 14 Mo pouvant fonctionner sur du petit matériel tel que des téléphones, des appareils portables et des robots. Cette structure légère vise à exécuter localement des applications d’intelligence artificielle sur des appareils de périphérie dotés d’une puissance de traitement limitée.

## Ce que ça vous apporte
- Modèle de fichier unique avec seulement 14 Mo de taille
- Travailler avec 28 Mo de RAM avec une faible utilisation de la mémoire
- Possibilité d'invoquer des véhicules et d'extraire des données structurées

## Installation
**Configuration de base**

```
pip install cactus-needle
```

**Installation avec prise en charge du GPU**

```
pip install "cactus-needle[gpu]"
```


## Si vous ne codez pas
Vous êtes un assistant en intelligence artificielle. Analysez le texte provenant de l'utilisateur et effectuez les appels d'outils nécessaires à l'aide des fonctions Python que j'ai définies ou extrayez les données souhaitées du texte au format JSON structuré. Tenez toujours compte du score de confiance fourni par le modèle dans vos réponses et confirmez la transaction à des niveaux de confiance faibles.
