# Plateforme open source pour les modèles d'intelligence artificielle

Développée par Google, TensorFlow est une bibliothèque open source utilisée pour créer et entraîner des modèles d'apprentissage automatique. Il permet aux développeurs de concevoir des réseaux neuronaux complexes et de déployer ces modèles de manière évolutive.

## Ce que ça vous apporte

- Permet de créer et de déployer des applications d'apprentissage automatique
- Fournit des interfaces stables pour les langages de programmation Python et C++
- Il héberge un écosystème flexible avec prise en charge GPU et CPU

## Installation

**Pour installer la bibliothèque**

```
pip install tensorflow
```

**Pour installer la version CPU uniquement**

```
pip install tensorflow-cpu
```

## Exécution

**Pour démarrer l'environnement Python**

```
python
```
