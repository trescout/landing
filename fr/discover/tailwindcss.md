# Cadre de style pour une conception d'interface rapide

Tailwind CSS est un framework de feuilles de style (framework CSS) axé sur le développement rapide d'interfaces utilisateur. Il permet la création rapide d'interfaces originales en proposant des classes de bas niveau au lieu de composants de conception prêts à l'emploi.

## Ce que ça vous apporte

- Créez des designs uniques avec des classes de bas niveau
- Développez des interfaces sans avoir à gérer des composants prêts à l'emploi
- Assurer une gestion rapide du style dans les projets Web modernes

## Installation

**avec npm**

```
npm install tailwindcss @tailwindcss/cli
```

## Exécution

**Générer du CSS**

```
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```
