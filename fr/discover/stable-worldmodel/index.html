Accélérer la recherche sur les modèles mondiaux

modèle de monde stable ; Il s'agit d'une plateforme qui garantit que la recherche sur les « modèles mondiaux » est reproductible et comparable. Il se concentre particulièrement sur les processus de recherche et d’évaluation.

Mises à jour

Qu'est-ce que ça fait ?

  • Rendre la recherche reproductible.
  • Fournir un environnement d’évaluation standard.
  • Il ne s'agit pas d'un outil pour l'utilisateur final, mais d'une solution directe pour la recherche.

Comment installer, comment utiliser ?

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Installez stable-worldmodel dans mon environnement Python avec la commande « pip install stable-worldmodel[all] » et aidez-moi à préparer un petit script qui collecte des données dans un exemple d'environnement PushT et entraîne et évalue un modèle mondial.

Installer depuis PyPI (tous les plugins)
pip install 'stable-worldmodel[all]'
Répertorier les ensembles de données mis en cache
swm datasets
