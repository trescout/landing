# Serveur qui automatise les processus logiciels

Jenkins est un serveur d'intégration continue et de livraison continue open source qui automatise les processus de développement de logiciels. Cette plateforme basée sur Java propose un large écosystème de plugins pour gérer les phases de compilation, de test et de déploiement des projets logiciels.

- Java
- GitHub Trending · 2026-07-27

## Ce que ça vous apporte
- Automatise les processus de compilation et de test des projets logiciels
- Offre la possibilité de personnaliser les processus grâce à une prise en charge étendue des plug-ins
- Accélère les phases de détection des erreurs et de déploiement

## Installation
**macOS (Homebrew)**

```
brew install jenkins
```

**Image Docker**

```
docker pull jenkins/jenkins:lts
```


## Exécution
**Commencez avec Docker (http://localhost:8080)**

```
docker run -p 8080:8080 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts
```
