# Gérez votre carrière avec l'intelligence artificielle

À l'aide de l'infrastructure Claude Code, Career-Ops automatise les processus de recherche d'emploi basés sur l'intelligence artificielle avec 14 modes de compétences différents. Le système centralise des fonctions telles que la gestion des lots et la création de CV via un panneau de contrôle basé sur Go.

## Ce que ça vous apporte
- Filtrez les offres d'emploi en les notant dans 10 dimensions différentes
- Création d'un CV compatible ATS spécifique à la description de poste
- Gestion du processus de candidature en masse via un terminal

## Installation
**Configuration de base**

```
git clone https://github.com/santifer/career-ops.git
cd career-ops && npm install
npx playwright install chromium
```

**Contrôle du système**

```
npm run doctor
```

## Si vous ne codez pas
Je souhaite personnaliser le système Career-Ops. Laissez le système évaluer les offres d'emploi en fonction des critères qui me conviennent le mieux, en fonction de mon CV et de mes objectifs de carrière. Aidez-moi à effectuer tous les réglages nécessaires pour compléter la configuration de mon profil et ajouter des entreprises spécifiques à ma liste de surveillance.
