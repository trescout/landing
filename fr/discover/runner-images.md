# Images de machines virtuelles pour GitHub Actions

Les images de runner GitHub Actions hébergent les environnements de machines virtuelles utilisés par la plateforme GitHub Actions, qui automatise les processus de développement logiciel. Ces images fournissent les systèmes d'exploitation et les ensembles d'outils préconfigurés nécessaires aux processus de test et de déploiement de logiciels.

## Ce que ça vous apporte
- Offre des environnements prêts à l'emploi pour différentes versions d'Ubuntu, macOS et Windows.
- Fournit des ensembles d'outils préconfigurés pour les processus de test et de déploiement de logiciels.
- Héberge le code source pour créer des ressources de machines virtuelles personnalisées.

## Pour commencer
Pour créer une machine virtuelle pour cet outil, vous pouvez consulter les instructions dans le fichier create-image-and-azure-resources.md situé dans le dossier docs du dépôt.
