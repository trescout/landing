# Ligneur et formateur de code Python rapide

Ruff est un ligneur (linter) et un formateur de code Python extrêmement rapide, développé en langage de programmation Rust. Il est utilisé pour améliorer la qualité du code et accélérer les processus de formatage lors du développement logiciel.

## Ce que ça vous apporte

- Fonctionne des dizaines de fois plus rapidement que les outils existants
- Combine le linting et le formatage du code en un seul outil
- Offre un support de correction automatique des erreurs dans les projets Python

## Installation

**installer avec pip**

```
pip install ruff
```

**installation avec uv**

```
uv tool install ruff@latest
```

## Exécution

**exécuter le linting du code**

```
ruff check
```

**exécuter le formatage du code**

```
ruff format
```
