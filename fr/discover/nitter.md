## Ce que ça vous apporte

- Affiche le contenu Twitter sans exécuter JavaScript
- Masque l'adresse IP de l'utilisateur et l'empreinte digitale du navigateur
- C'est beaucoup plus rapide et plus léger que l'interface Twitter standard

## Installation

**Installation avec Docker**

```
docker run -v $(pwd)/nitter.conf:/src/nitter.conf -d --network host zedeus/nitter:latest
```

**Lancement avec Docker Compose**

```
docker-compose up -d
```
