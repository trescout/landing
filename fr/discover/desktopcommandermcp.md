# Gérez votre ordinateur avec l'intelligence artificielle

DesktopCommanderMCP est un serveur Model Context Protocol développé pour Claude qui fournit des capacités de contrôle de terminal, de recherche de système de fichiers et d'édition de fichiers basées sur les différences au modèle d'intelligence artificielle. Écrit en TypeScript, cet outil permet à l'intelligence artificielle d'effectuer des opérations directes sur les systèmes de fichiers locaux.

- TypeScript

## Ce que ça vous apporte
- Exécuter directement les commandes du terminal
- Rechercher et modifier le système de fichiers
- Gérer les fichiers Excel, PDF et DOCX

## Installation
**installation rapide avec npx**

```
npx @wonderwhy-er/desktop-commander@latest setup
```

**script bash pour macOS**

```
curl -fsSL https://raw.githubusercontent.com/wonderwhy-er/DesktopCommanderMCP/refs/heads/main/install.sh | bash
```


## Si vous ne codez pas
Je souhaite que vous utilisiez les outils Desktop Commander MCP pour effectuer la gestion des fichiers, les commandes de terminal et l'édition de documents sur mon ordinateur. Aidez-moi en activant les fonctionnalités permettant de rechercher dans le système de fichiers, de gérer les processus via le terminal et d'apporter les modifications nécessaires aux documents tels qu'Excel ou PDF lorsque j'en ai besoin.
