# Plateforme domotique contrôlée localement

Home Assistant est une plateforme domotique open source qui donne la priorité au contrôle local et à la confidentialité. Ce système, développé avec le langage Python, permet aux utilisateurs de gérer leurs appareils intelligents via un réseau central.

## Ce que ça vous apporte

- Gérez vos appareils intelligents à partir d'un seul centre
- Protégez la confidentialité de vos données avec un contrôle local
- Ajoutez de nouveaux appareils avec une structure modulaire

## Installation

**avec pip (environnement virtuel Python)**

```
pip install homeassistant
```

**Avec Docker**

```
docker run -d --name homeassistant --privileged --restart=unless-stopped --network=host ghcr.io/home-assistant/home-assistant:stable
```

## Exécution

**Démarrer le serveur Home Assistant Core**

```
hass
```
