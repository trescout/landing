# Infrastructure évolutive pour les agents d'intelligence artificielle

Conçu avec le langage Go, l'agent Substrate offre un runtime de base pour les agents d'intelligence artificielle. Cette infrastructure, qui prend en charge différentes architectures d'agents, doit protéger les ressources du système et les flux de travail nécessaires aux agents.

- ★ 1 275
- Go

## Ce que ça vous apporte
- Lance les agents en quelques secondes avec une faible latence
- Assure la persistance en préservant la mémoire et l'état du système de fichiers
- Exécute plusieurs agents simultanément avec des ressources limitées

## Exécution
**Envoi d'une demande au compteur d'échantillons**

```
curl -X POST -H "Host: my-counter-1.demo.actors.resources.substrate.ate.dev" -i http://localhost:8000/
```


## Si vous ne codez pas
J'utilise l'infrastructure Substrate pour exécuter des agents IA à grande échelle. Dans ce système fonctionnant sur Kubernetes (système de gestion de conteneurs), je souhaite gérer le cycle de vie des acteurs, utiliser les ressources efficacement et effectuer des déploiements d'agents haute densité.
