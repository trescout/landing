# Bibliothèque de sécurité chiffrant le trafic réseau

OpenSSL est une bibliothèque de sécurité à usage général utilisée pour chiffrer le trafic réseau. C'est un outil logiciel open-source prenant en charge les protocoles Transport Layer Security (TLS), Datagram TLS (DTLS) et QUIC.
