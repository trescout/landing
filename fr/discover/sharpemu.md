# Projet d'émulateur expérimental PlayStation 5

Sharpemu est un projet expérimental d'émulateur PlayStation 5 développé en langage C#. Cette étude, qui vise à imiter l'architecture des consoles sur une base logicielle, est une expérimentation technique réalisée sur les technologies d'émulation des consoles de jeux.

## Ce que ça vous apporte

- Possibilité d'examiner l'architecture de la console de jeu
- Prise en charge de l'exécution d'instructions CPU natives
- Lire les métadonnées des fichiers de jeu

## Pour commencer

Pour utiliser le projet, vous pouvez télécharger des fichiers prêts à l'emploi à partir de l'onglet « Versions » de la page GitHub ou compiler les codes sources sur votre ordinateur avec le SDK .NET installé. Pour compiler, copiez simplement le projet sur votre ordinateur, ouvrez le fichier de solution via VSCode et exécutez la commande dotnet build dans le terminal.
