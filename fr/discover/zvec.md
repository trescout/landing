# Base de données vectorielles rapide dans l'application

Développée par Alibaba, zvec est une solution de base de données vectorielles en cours de processus légère et rapide écrite en C++. Il vise à augmenter les performances du système en permettant aux applications de traiter les données vectorielles directement en mémoire.

## Ce que ça vous apporte

- Architecture d'exploitation locale qui ne nécessite pas de serveur
- Vitesse de recherche en millisecondes sur des milliards de vecteurs
- Prise en charge de la recherche vectorielle, textuelle et hybride

## Installation

**Installation pour Python**

```
pip install zvec
```

**Installation pour Node.js**

```
npm install @zvec/zvec
```
