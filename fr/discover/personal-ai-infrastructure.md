# Construisez votre infrastructure d'IA personnelle

L'infrastructure d'IA personnelle fournit un cadre pour créer des systèmes d'intelligence artificielle basés sur des agents (IA agent) conçus pour augmenter les capacités humaines. Développée avec TypeScript, cette structure prend en charge une architecture modulaire qui permet aux utilisateurs de gérer leurs propres flux de travail autonomes.

- ★ 15 080
- TypeScript
- GitHub Trending · 2026-06-07

## Ce que ça vous apporte
- Il vous permet d'installer un système d'exploitation qui gère vos objectifs personnels et votre flux de vie.
- Crée des flux de travail autonomes et une gestion des tâches via votre assistant numérique.
- Il divise les tâches complexes en petits critères vérifiables selon le principe de l’état idéal.

## Installation
**Installation rapide en une seule ligne**

```
curl -sSL https://ourpai.ai/install.sh | bash
```


## Exécution
**Ouvrez le tableau de bord de la vie**

```
open http://localhost:31337
```
