# Interface d'intelligence artificielle qui gère votre ordinateur

Développé par ByteDance, UI-TARS est une infrastructure d'agent open source qui intègre des modèles d'IA multimodaux avec des interfaces de bureau. Ce système permet la création d'agents (agents IA) qui effectuent de manière autonome des tâches sur l'ordinateur en traitant des données visuelles.

## Ce que ça vous apporte
- Effectuez de manière autonome des tâches de bureau et de navigateur
- Flux de travail semblable à celui d'un humain grâce au traitement des données visuelles
- Intégration complète avec les modèles d'IA multimodaux

## Installation
**Installation globale**

```
npm install @agent-tars/cli@latest -g
```

**Fonctionnement direct**

```
npx @agent-tars/cli@latest
```


## Exécution
**Initialiser avec le fournisseur de modèle**

```
agent-tars --provider volcengine --model doubao-1-5-thinking-vision-pro-250428 --apiKey your-api-key
```


## Si vous ne codez pas
Décrivez une tâche complexe que vous souhaitez que j'effectue sur mon ordinateur ou mon navigateur. Par exemple, je pourrais vous demander d'accéder à un site Web spécifique et de saisir des données ou de gérer un processus de réservation de vol. Veuillez analyser l'interface visuelle et effectuer les étapes de manière autonome.
