# Ensemble de configuration prêt à l'emploi pour Claude Code

Claude Code est une boîte à outils contenant des agents, des commandes et des hooks conçus pour accélérer les processus de développement assistés par l'intelligence artificielle. Il rassemble sous un même toit tous les composants nécessaires à l'automatisation des flux de travail de développement logiciel.

## Ce que ça vous apporte
- Propose des agents et des commandes prêts à l'emploi qui automatisent les processus de développement logiciel.
- Évite la perte de contexte grâce à la gestion de la mémoire entre les sessions.
- Automatise les standards tels que le TDD (Test Driven Development) et les audits de sécurité.

## Pour commencer
Il est recommandé de lire d'abord le 'Shorthand Guide' et le 'Longform Guide' sur la page GitHub du projet pour comprendre la philosophie de base. Pour l'installation, vous pouvez installer l'extension directement depuis Claude Code en tant qu'extension de marketplace ou commencer à l'utiliser en déplaçant les fichiers nécessaires dans votre propre répertoire avec les commandes ci-dessus.
