# Outil d'orchestration pour les agents IA

Développé par Google, Axe est un runtime d'orchestration open source pour les agents d'intelligence artificielle. Cette infrastructure, écrite en langage Go, facilite la gestion et l'exécution de workflows agentiques complexes.

- ★ 12 083
- GitHub Trending · 2026-09-23

## Ce que ça vous apporte
- Il vous permet de gérer des milliards de charges de travail d'IA autonomes.
- Il vous permet d'exécuter des agents dans un environnement sandBox sécurisé et isolé.
- Il offre une configuration rapide et déclarative avec les fichiers YAML.

## Installation
**Installation de l'outil CLI**

```
go install github.com/google/ax/cmd/ax@latest
```

**Déployer le plan de contrôle**

```
make deploy AX_IMAGE_REPO=<your-registry>
```


## Si vous ne codez pas
Je souhaite installer l'outil AX développé par Google, qui assure l'orchestration des agents d'intelligence artificielle. Tout d'abord, installez l'outil de ligne de commande en exécutant « go install github.com/google/ax/cmd/ax@latest ». Déployez ensuite le plan de contrôle à l'aide de la commande `make déployer AX_IMAGE_REPO=<your-registry>`.
