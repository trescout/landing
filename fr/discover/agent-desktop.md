# Outil de contrôle de bureau pour les agents d'intelligence artificielle

Développé par Vercel Labs, agent-desktop est une interface de ligne de commande (CLI) qui permet aux agents d'intelligence artificielle de lire et de gérer des applications de bureau via l'arbre d'accessibilité du système d'exploitation. Écrit en Rust, cet outil vise à améliorer les capacités d'utilisation d'ordinateur (computer use) des agents.

## Ce que ça vous apporte

- Lit les applications de bureau via l'arbre d'accessibilité du système d'exploitation
- Interagit sur les éléments sans avoir besoin de correspondance de pixels
- Génère des réponses rapides et structurées au format JSON

## Installation

**Installer avec le gestionnaire de paquets**

```
npm install -g agent-desktop
agent-desktop version
```

**Ajouter une compétence**

```
npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop
```
