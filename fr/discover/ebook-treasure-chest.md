# Bibliothèque de livres électroniques numériques de diverses catégories

jbiaojerry/ebook-treasure-chest est un projet de bibliothèque numérique qui rassemble des liens de téléchargement de livres électroniques dans diverses catégories. Le projet vise à fournir un accès au contenu des applications de lecture populaires (帆书, 微信读书, 京东读书, 喜马拉雅).

## Ce que ça vous apporte

- Vous bénéficiez d'un accès unique aux liens de téléchargement de milliers de livres électroniques.
- Vous pouvez télécharger les livres sous trois options de formats différents tels que epub, mobi et azw3.
- Grâce à l'interface de recherche, vous pouvez trouver instantanément des œuvres par titre, auteur ou catégorie.

## Pour commencer

Vous n'avez pas besoin de ligne de commande pour profiter du projet. Vous pouvez visiter la page Web officielle hébergée sur la plateforme d'hébergement de code GitHub et taper le nom du livre ou l'auteur dans la boîte de recherche. Si vous le souhaitez, vous pouvez accéder au lien de téléchargement du livre électronique de votre choix en examinant les fichiers de catégories.
