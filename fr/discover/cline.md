# Agent d'intelligence artificielle automatisant les processus de développement logiciel

Cline est un agent de codage autonome qui automatise les processus de développement logiciel. Il s'intègre aux projets des développeurs via une extension IDE, un kit de développement logiciel (SDK) ou une interface de ligne de commande (CLI).

## Ce que ça vous apporte

- Effectue des modifications de code coordonnées à l'échelle du projet
- Exécute des commandes via le terminal et surveille les sorties en temps réel
- Maintient le processus de développement sous contrôle grâce aux modes plan et exécution

## Installation

**Installation de l'interface de ligne de commande**

```
npm i -g cline
```

**Installation du kit de développement logiciel**

```
npm install @cline/sdk
```

## Exécution

**Lancement de tâches avec une équipe multi-agents**

```
cline --team-name auth-sprint "Plan and implement user authentication with tests"
```

## Si vous ne codez pas

Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Analysez la structure de fichiers de mon projet et accomplissez la tâche que j'ai définie en tenant compte des normes de code existantes et des règles du fichier .clinerules. Effectuez des vérifications d'erreurs lors de l'apport de modifications au code, exécutez les commandes nécessaires dans le terminal et avancez en obtenant mon approbation à chaque étape.

Dépôt : https://github.com/cline/cline. Base-toi sur les instructions officielles du fichier README de ce dépôt pour l'installation et l'exécution.

Avant de commencer, vérifie quel système d'exploitation nous utilisons et si les outils nécessaires (ex: Python, Node.js, Git, Docker) sont installés. Installe ceux qui manquent étape par étape selon ce système.

Crée un nouveau dossier vide pour travailler. Ne touche pas aux fichiers en dehors de ce dossier et ne supprime rien. Avant chaque commande, décris ce que tu vas faire en une phrase.

Dis-moi ce que je devrais voir à l'écran à la fin de chaque étape. Si une erreur survient, je te copierai le message d'erreur tel quel et nous la corrigerons ensemble.
