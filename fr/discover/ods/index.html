Transformez votre PC en serveur d'inférence et d'agents IA local

Osmantic/ODS équipe vos ordinateurs personnels pour l'inférence LLM locale, les pipelines RAG vectoriels et l'orchestration d'agents autonomes sans cloud.

Ce que vous gagnez

  • Confidentialité totale et exécution locale: Faites tourner vos modèles sur votre matériel sans aucune fuite de données vers le cloud.
  • RAG intégré (Génération augmentée de recherche): Indexez vos documents personnels et dépôts de code pour des recherches sémantiques précises.
  • Suite de capacités multimodales: Combine génération textuelle, transcription Whisper, synthèse vocale et génération d'images.
  • API locale compatible OpenAI: Redirigez vos applications d'IA existantes vers votre machine via une simple modification d'URL.
  • Flux d'agents autonomes: Orchestrez des chaînes d'agents capables d'exécuter des outils locaux et de résoudre des tâches complexes.

Installation

Cloner le dépôt et installer le paquet
git clone https://github.com/Osmantic/ODS.git
cd ODS
pip install -e .

Exécution

Lancer le serveur d'IA local
python -m ods.server --port 8000
# Web paneline http://localhost:8000 adresinden erişin

Architecture technique et principe de fonctionnement

Osmantic/ODS s'appuie sur une architecture modulaire coordonnant inférence locale et indexation vectorielle:

  • Moteur d'inférence local (llama.cpp & vLLM): Charge les formats GGUF et poids GPU avec une empreinte mémoire optimisée.
  • Base de données vectorielle embarquée: Stockage vectoriel léger via ChromaDB et SQLite pour le découpage et la recherche documentaire.
  • File de tâches asynchrone et machine à états: Gère les boucles de raisonnement multi-étapes et l'exécution d'outils locaux.

Flux de travail RAG locaux et pipelines d'agents privés

ODS permet de déployer des solutions d'IA avancées en garantissant la souveraineté totale des données:

  • Analyse de documents confidentiels: Interrogez contrats et bilans financiers en toute sécurité via RAG sans risque d'exposition.
  • Assistant de code privé: Indexez vos dépôts pour bénéficier de complétions de code locales dans VS Code ou Cursor.
  • Agents de traitement automatisés: Planifiez des agents d'arrière-plan pour analyser, synthétiser et structurer vos fichiers locaux.

Foire aux questions

  • Fonctionne-t-il totalement hors ligne? Oui. Une fois les poids téléchargés, ODS s'exécute sans aucune connexion réseau dans des environnements isolés.
  • Quels formats de modèles sont supportés? Prend en charge les modèles quantifiés GGUF (Llama 3, Mistral, Qwen) et les formats bruts HuggingFace.
  • Dispose-t-il d'une interface web? Oui. ODS intègre un tableau de bord web pour gérer les modèles, indexer des fichiers et échanger avec les agents.
  • Peut-il fonctionner sur CPU sans carte graphique? Oui. Grâce à llama.cpp et aux instructions AVX2/AVX-512, il fonctionne avec de bonnes performances sur simple CPU.
