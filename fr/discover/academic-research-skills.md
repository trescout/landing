# Assistant IA pour la recherche universitaire

Academic Research Skills est une bibliothèque Python développée pour Claude Code qui automatise les processus universitaires à travers les étapes de recherche, de rédaction, de révision, d'édition et de finalisation. Cet outil vise à standardiser les flux de travail académiques sur l'outil de codage assisté par IA, Claude Code.

- ★ 45 232
- Python
- GitHub Trending · 2026-09-02

## Ce que ça vous apporte
- Gère le processus de rédaction d'articles universitaires de bout en bout
- Automatise les processus de recherche et de vérification des références
- Améliore la qualité de rédaction en révisant les textes

## Installation
**Ajouter l'extension depuis le marché**

```
/plugin marketplace add Imbad0202/academic-research-skills
```

**Installer l'extension**

```
/plugin install academic-research-skills
```


## Exécution
**Planification d'article**

```
/ars-plan
```


## Si vous ne codez pas
Je souhaite utiliser l'extension Academic Research Skills pour gérer mon processus de recherche académique. Engage un dialogue socratique pour créer le plan structurel de mon article et aide-moi à gérer le processus en déterminant à quelle étape de ma recherche je me trouve.
