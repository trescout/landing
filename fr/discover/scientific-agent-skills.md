# Donnez des capacités de recherche scientifique à votre agent IA

Les compétences d'agent scientifique sont une bibliothèque qui contient 163 compétences (compétences) vérifiées et plus de 100 bancs de données scientifiques, des agents d'intelligence artificielle spécialisés dans les processus de recherche scientifique. Cela permet aux agents qui travaillent dans les domaines de la biologie, de la chimique et de la médecine de réaliser des analyses de données de forme compatible avec des plates-formes telles que l'éditeur de code Cursor ou l'assistant d'intelligence artificielle Claude Code.

## Ce que ça vous apporte
- Il propose 163 compétences scientifiques différentes dans les domaines de la biologie, de la chimie et de la médecine.
- Il permet une interaction directe avec plus de 100 bases de données scientifiques.
- Il fonctionne de manière compatible avec les outils d'intelligence artificielle tels que l'éditeur de code Cursor et Claude Code.

## Installation
**Installation au niveau utilisateur**

```
git clone https://github.com/K-Dense-AI/scientific-agent-skills.git ~/.agents/skills/scientific-agent-skills   # user-level
```

**Configuration au niveau du projet**

```
git clone https://github.com/K-Dense-AI/scientific-agent-skills.git .agents/skills/scientific-agent-skills      # project-level
```


## Si vous ne codez pas
Vous êtes désormais assistant spécialisé en recherche scientifique. Effectuez des analyses de données complexes, des recherches documentaires et des processus de modélisation en biologie, chimie et médecine à l'aide des 163 compétences de la bibliothèque de compétences d'agent scientifique. Basez votre travail sur les bases de données scientifiques actuelles et présentez vos résultats avec des preuves vérifiables.
