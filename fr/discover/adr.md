# Sécurité pour les agents IA d'entreprise

Développé par Uber, ADR protège les agents d’IA d’entreprise grâce à des méthodes d’observabilité, d’analyse comparative de la sécurité et de détection des menaces. Le logiciel offre un cadre de sécurité développé pour augmenter la sécurité des systèmes d'intelligence artificielle.

## Ce que ça vous apporte
- Il surveille les actions entreprises par les agents IA, vous permettant de comprendre ce qu'ils font et pourquoi ils le font.
- Teste la sécurité des agents avec plus de 300 missions contre 17 techniques d'attaque différentes.
- Il utilise une architecture en deux étapes pour détecter les sessions suspectes.

## Installation
**Préparation du système de détection**

```
git clone https://github.com/uber/ADR
cd ADR/Detection
uv sync
export ANTHROPIC_API_KEY="..." OPENAI_API_KEY="..."
```
