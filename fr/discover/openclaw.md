# Un assistant personnel d'intelligence artificielle fonctionnant sur votre appareil

Openclaw est un outil d'automatisation basé sur l'intelligence artificielle capable d'exécuter des tâches sur différents systèmes d'exploitation et plateformes. Développé avec TypeScript, ce logiciel permet aux utilisateurs de standardiser et d'automatiser les opérations sur leur ordinateur.

## Ce que ça vous apporte
- Vous conservez vos données, votre mémoire et vos informations de compte en toute sécurité, entièrement sur votre propre ordinateur.
- Vous pouvez discuter avec votre assistant via les applications de messagerie WhatsApp, Telegram, Discord et l'outil de communication professionnelle Slack.
- Vous pouvez facilement gérer différents modèles d'intelligence artificielle et outils système locaux à partir d'un seul centre.

## Installation
**Exécuter le script d'installation automatique (ma**

```
# macOS / Linux / WSL2
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Globalement avec le gestionnaire de paquets Node.js npm**

```
npm install -g openclaw@latest --allow-scripts=openclaw
```
