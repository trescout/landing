# Visualisez votre architecture logicielle avec des diagrammes en direct

Likec4 est un outil qui visualise l'architecture logicielle directement à partir du code source et permet la création de diagrammes en direct. Il vise la continuité de la documentation technique à travers des schémas architecturaux mis à jour simultanément avec la base de code.

## Ce que ça vous apporte

- Il crée des schémas architecturaux qui sont mis à jour simultanément avec votre base de code.
- Il propose un langage de modélisation flexible et personnalisable basé sur le modèle C4.
- Il assure la continuité de la documentation en gérant les processus de visualisation via le code.

## Exécution

**Démarrer le projet en mode aperçu**

```
npx likec4 start
```
