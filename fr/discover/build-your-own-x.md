# Créez vos propres technologies à partir de zéro

Build Your Own est une collection de guides étape par étape qui vous permettent de réécrire à partir de zéro vos technologies préférées telles que la base de données, le système d'exploitation, Git, Docker et le langage de programmation. Il propose une expérience d'apprentissage par la pratique, conformément à la philosophie de Feynman selon laquelle « je ne peux pas comprendre ce que je ne peux pas créer ».

**Note TreScout :** Le référentiel d'apprentissage n'est pas un outil à installer : il rassemble des didacticiels pour écrire votre propre base de données, shell ou Git à partir de zéro.
