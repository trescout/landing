# Exécutez des modèles d’IA sur votre ordinateur

Llama.cpp est une bibliothèque d'inférence basée sur C et C++ qui permet d'exécuter efficacement de grands modèles de langage sur du matériel standard. Le logiciel facilite l'exécution de modèles d'intelligence artificielle sur des appareils locaux grâce à sa faible utilisation de mémoire et sa structure orientée hautes performances.

**Note TreScout :** Il exécute des modèles linguistiques sur votre propre ordinateur, sans louer de serveur. La configuration est désormais simple, mais définissez des attentes : les modèles plus petits sont rapides, les modèles plus grands solliciteront votre mémoire et n'attendent pas la réactivité des services cloud.

## Installation

**Cloner le code source**

```
git clone https://github.com/ggml-org/llama.cpp.git
cd llama.cpp
```

## Exécution

**Exécuter le modèle GGUF**

```
llama-cli -m my_model.gguf
```
