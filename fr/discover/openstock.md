# Suivez les données boursières gratuitement

OpenStock est une alternative open source aux plateformes d'échange coûteuses. Il offre un suivi des prix en temps réel, des alertes personnalisées et des analyses d'entreprise. Il est accessible à tous et gratuit pour toujours.

- ★ 14 018
- TypeScript
- AGPL-3.0
- GitHub Trending · 26 May 2026

## Ce que ça vous apporte
- Il suit les prix en temps réel.
- Envoie des notifications personnalisées.
- Il fournit une analyse détaillée aux entreprises.
- Cela élimine le besoin de plates-formes coûteuses.

## Comment utiliser ?
Vous pouvez utiliser le site prêt à l'emploi (openstock-ods.vercel.app) directement ou l'installer sur votre propre serveur.

## Comment installer, comment utiliser ?
**Cloner le référentiel**

```
git clone https://github.com/Open-Dev-Society/OpenStock.git
cd OpenStock
```

**Installer les dépendances**

```
pnpm install
```

**Démarrer le serveur de développement**

```
pnpm dev
```
