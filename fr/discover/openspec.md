# Développement de standards dans les projets d’intelligence artificielle

OpenSpec est une bibliothèque TypeScript qui prend en charge les processus de développement basés sur les spécifications pour les assistants de code d'intelligence artificielle. Il garantit la standardisation des exigences techniques lors des étapes de développement logiciel et une progression plus contrôlée des processus de production de code.

## Ce que ça vous apporte

- Standardise les exigences techniques avant d’écrire du code
- Contrôle le processus de développement avec l’intelligence artificielle
- Archive les modifications dans une structure de dossiers organisée

## Installation

**Installer l'outil globalement**

```
npm install -g @fission-ai/openspec@latest
```

## Exécution

**Lancer dans le répertoire du projet**

```
openspec init
```
