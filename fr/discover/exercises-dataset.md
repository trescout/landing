# Ensemble de données multilingues sur les exercices de fitness

L'ensemble de données d'exercices (ensemble de données d'exercices) partagé par Hasaneyldrm propose 433 mouvements de fitness différents avec des noms, des groupes musculaires cibles, des équipements et des instructions visuelles. Cette ressource complète fournit une infrastructure de données structurée pour ceux qui développent des applications technologiques sportives.

## Pour commencer

Cet outil ne nécessite aucune installation. Après avoir téléchargé les fichiers de la page GitHub sur votre ordinateur, vous pouvez revoir les exercices en ouvrant le fichier « index.html » avec n'importe quel navigateur Internet, et accéder à la base de données et au guide d'installation de l'API en ouvrant le fichier « setup.html ».
