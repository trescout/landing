# L'intelligence artificielle qui exécute du code sur votre ordinateur

Open Interpreter propose un agent de codage qui automatise les processus de développement logiciel en exécutant du code dans l'environnement informatique local. Conçu pour fonctionner avec des modèles de langage à faible coût, cet outil permet d'exécuter des tâches complexes directement depuis le terminal.

## Ce que ça vous apporte
- Il automatise les processus logiciels via le terminal local.
- Il est compatible avec les modèles linguistiques à faible coût.
- Offre la possibilité de tester des applications Web et natives.

## Installation
**Installation pour macOS et Linux**

```
curl -fsSL https://www.openinterpreter.com/install | sh
```


## Exécution
**Démarrer la session**

```
i
```


## Si vous ne codez pas
Je veux que vous agissez comme un agent de codage sur mon ordinateur. J'attends de vous que vous automatisiez des tâches complexes en exécutant du code dans mon environnement local, en testant des applications Web ou locales si nécessaire. Utiliser des structures qui optimisent les modèles à faible coût lors de l'exécution de transactions et exécuter mes commandes en toute sécurité via le terminal.
