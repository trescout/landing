# Agents d'intelligence artificielle pour les stratégies d'investissement

Le hedge fund AI utilise des agents autonomes pour automatiser les processus d'analyse des marchés financiers et de gestion d'actifs. Ce projet basé sur Python propose un modèle d'équipe d'intelligence artificielle qui développe des stratégies d'investissement en traitant les données de marché.

## Ce que ça vous apporte
- Agents autonomes analysant les données des marchés financiers
- Modélisation représentant différentes écoles d'investissement
- Possibilité de tester des stratégies avec des données historiques

## Installation
**Clonage du référentiel**

```
git clone https://github.com/virattt/ai-hedge-fund.git
cd ai-hedge-fund
```

**Installation des dépendances**

```
poetry install
```


## Exécution
**Commencer l'analyse des investissements**

```
poetry run python src/main.py --ticker AAPL,MSFT,NVDA
```


## Si vous ne codez pas
Cet outil utilise des agents autonomes qui imitent les stratégies d'investisseurs célèbres tels que Warren Buffett, Peter Lynch et Michael Burry pour analyser les marchés financiers. En donnant certains symboles boursiers (par exemple AAPL, MSFT) aux agents IA, vous pouvez examiner comment ces agents évaluent les données de marché, les indicateurs fondamentaux et l'analyse technique et prennent des décisions dans la logique d'un fonds commun de placement.
