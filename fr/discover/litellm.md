# Gérez vos modèles d'intelligence artificielle depuis un endroit unique

LiteLLM est une passerelle IA (AI gateway) qui unifie plus de 100 interfaces de grands modèles de langage (LLM) dans un format standard unique. Il facilite la transition entre différents fournisseurs de modèles pour les développeurs en offrant des fonctionnalités telles que le suivi des coûts, la répartition de charge et des garde-fous (guardrails).

## Ce que ça vous apporte

- Il évite la complexité du code en unifiant plus de cent fournisseurs de LLM (Grand Modèle de Langage) dans un format standard unique.
- Il élimine la nécessité de réécrire votre base de code lors du passage d'un modèle d'IA à un autre.
- Il offre une infrastructure de gestion de niveau entreprise avec des outils tels que des clés virtuelles, le suivi budgétaire et la répartition de charge.

## Installation

**charger la bibliothèque Python du langage de pro**

```
uv add litellm
```

## Exécution

**Démarrage du serveur passerelle**

```
uv tool install 'litellm[proxy]'
litellm --model gpt-4o
```
