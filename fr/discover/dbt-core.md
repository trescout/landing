# Processus de transformation standardisés dans l'entrepôt de données

L'outil de transformation des données (dbt-core) permet aux analystes de données et aux ingénieurs d'effectuer la transformation des données en utilisant des méthodes similaires aux processus de développement logiciel. Il standardise les flux de travail analytiques en intégrant les processus de contrôle de version et de test dans les entrepôts de données.
