# Compétences d'expert en sécurité pour Claude

Claude-Red est une bibliothèque de compétences de sécurité offensive intégrée au système de capacités du modèle d'intelligence artificielle Claude. Elle vise à automatiser les tests de sécurité en proposant des méthodologies de niveau expert sur des sujets tels que l'injection SQL et le contournement des systèmes de protection des points de terminaison.

## Ce que ça vous apporte
- Fournit un accès aux méthodologies de sécurité offensive
- Transforme le modèle d'intelligence artificielle en expert en tests d'intrusion
- Charge automatiquement les compétences nécessaires

## Installation
**Télécharger toutes les compétences**

```
git clone https://github.com/SnailSploit/claude-red ~/.claude/skills/claude-red
```

**Installation interactive**

```
./install.sh                           # interactive
./install.sh --target ~/.claude/skills # explicit target
./install.sh --category web            # single category
```
