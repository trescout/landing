# Activer les cadrans Hermès pour Apple Watch

pookjw/HermesEnabler est un logiciel qui permet d'utiliser les cadrans de montre Hermès sur toutes les Apple Watch disposant de versions watchOS compatibles. Cet outil, qui peut être compilé sur macOS avec Xcode ou installé à l'aide d'outils de chargement d'applications tels que Sideloadly, nécessite une Apple Watch jumelée à un iPhone.

## Ce que ça vous apporte

- utilisation de cadrans personnalisés sur les montres prises en charge
- prise en charge des systèmes d'exploitation macOS et Windows
- installation étape par étape via l'application de la montre

## Pour commencer

Vous pouvez l'installer sur macOS à l'aide de l'outil de chargement d'applications Sideloadly ou du logiciel de développement Xcode. Côté Windows, vous pouvez utiliser l'outil communautaire WatchBridge. Vous pouvez télécharger les fichiers d'installation depuis la page GitHub officielle et suivre le guide.
