# Radar multiéléments open source

PLFM RADAR est un système radar multiéléments à faible coût et open source fonctionnant à une fréquence de 10,5 GHz. Ce projet basé sur le matériel utilise un logiciel de contrôle développé avec le langage PLSQL pour rendre accessibles les technologies de détection par radiofréquence.

## Ce que ça vous apporte
- Options d'autonomie de 3 km et 20 km
- Capacité de direction de faisceau électronique
- Traitement avancé du signal basé sur FPGA

## Pour commencer
Ce projet est un système complet composé de composants matériels et logiciels. Pour commencer, vous pouvez accéder aux schémas matériels, aux fichiers logiciels FPGA et à l'interface utilisateur basée sur Python en consultant la documentation sur la page GitHub. Il est recommandé de suivre les rapports techniques et les résultats de simulation dans les dossiers pertinents pour l'installation et l'utilisation du projet.
