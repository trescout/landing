# Intelligence artificielle pour les tests d'intrusion autonomes

Développé avec le langage Go, Pentagi propose un système d'agents d'intelligence artificielle (agents IA) entièrement autonomes capables d'effectuer des tests d'intrusion complexes. Le système vise à normaliser les flux de travail autonomes pour détecter et exploiter les vulnérabilités.

## Ce que ça vous apporte

- Tests de sécurité entièrement autonomes dans un environnement Sandboxed Docker
- Prise en charge de plus de 20 outils professionnels tels que Nmap et SQLmap
- Surveillance détaillée du système avec Grafana et Prometheus

## Exécution

**Démarrer le service**

```
curl -O https://raw.githubusercontent.com/vxcontrol/pentagi/master/docker-compose.yml
docker compose up -d
```
