Développement discipliné avec Claude Code

Claude Code Harness introduit la discipline de planifier, réaliser, réviser et livrer, freinant ainsi la tendance du travail brut des agents à s'effondrer. Cela empêche les plans de se perdre dans le chat, limite les tests et garantit une production de code plus cohérente. Bien que Claude soit centré sur le Code, il propose également des chemins d'intégration pour Codex et OpenCode.

Ce que ça vous apporte

  • L'agent ne se disperse pas ; Le plan est conservé dans un dossier.
  • La qualité est augmentée en limitant les tests.
  • Des résultats plus prévisibles et cohérents sont obtenus.

Pour commencer

Intégré à Claude Code avec installation dans le référentiel; met ensuite en œuvre le cycle de planification, d'exécution et de révision.

Comment installer, comment utiliser ?

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Configurez ce flux de travail discipliné dans Claude Code en exécutant « /plugin marketplace add Chachamaru127/claude-code-harness », puis « /plugin install claude-code-harness@claude-code-harness-marketplace » et « /harness-setup », puis commencez avec « /harness-plan ».
