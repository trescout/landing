# Simulateur spatial mondial en temps réel

Gods-eye-view est un simulateur d'intelligence spatiale qui visualise des données satellites en temps réel sur un globe 3D basé sur le navigateur. Développé en JavaScript, ce projet open source permet aux utilisateurs d'examiner des données en direct sur la Terre via une interface photoréaliste.

## Ce que ça vous apporte

- Suivez les données en direct des vols, des navires et des satellites sur Terre via un globe 3D.
- Effectuez des marquages sur la carte par commandes vocales et basculez entre différents modes de capteurs.
- Explorez le monde depuis le point de vue du cockpit en entrant dans les aéronefs en direct.

## Installation

**Installation des dépendances et démarrage**

```
npm install
npm run dev -- --host localhost --port 4173
```
