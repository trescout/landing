Trouvez le modèle d'IA le mieux adapté à votre matériel

Whichllm est un outil qui vous permet d'identifier les grands modèles de langage natifs qui fonctionnent le mieux sur votre matériel. En se concentrant sur les benchmarks actuels plutôt que sur le nombre de paramètres, ce logiciel basé sur Python vous permet de choisir le modèle le plus adapté avec une seule commande.

Ce que ça vous apporte

  • Il détermine le modèle de langage natif le mieux adapté à votre matériel avec des données de référence à jour.
  • Il prédit les performances en détectant automatiquement les fonctionnalités du GPU et du système.
  • Il offre la possibilité de télécharger des modèles, de démarrer des discussions et de créer des exemples de code Python avec une seule commande.
