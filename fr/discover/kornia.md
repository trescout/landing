# Vision par ordinateur pour l'intelligence artificielle

Kornia est une bibliothèque de vision par ordinateur différentiable développée pour les applications d'intelligence artificielle spatiale (spatial AI). Fonctionnant sur le framework d'apprentissage profond PyTorch, cet outil permet d'intégrer des algorithmes de traitement d'image et de vision géométrique dans les flux de travail de l'intelligence artificielle.

## Ce que ça vous apporte

- Elle accélère les opérations en exécutant le traitement d'image et les calculs géométriques sur l'unité de traitement graphique (GPU).
- Grâce à sa structure différentiable, elle se connecte directement aux entraînements de modèles construits avec le framework d'apprentissage profond PyTorch.
- Elle offre l'augmentation de données, la détection de contours et des modèles d'analyse visuelle prêts à l'emploi sous un même toit.
