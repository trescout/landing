# Téléchargement rapide de vidéos via le terminal

Yoinks est un outil permettant de télécharger n'importe quelle vidéo via le terminal sans publicité ni redirection. Développé en TypeScript, ce logiciel offre une méthode pratique pour transférer directement des fichiers vidéo vers le stockage local.

## Ce que ça vous apporte

- Télécharge des vidéos depuis plus de 1800 sites tels que YouTube, Instagram et TikTok
- Enregistre directement sur le stockage local sans publicité ni faux boutons de téléchargement
- Offre la possibilité de choisir la résolution vidéo ou d'extraire uniquement le fichier audio

## Installation

**Installation globale**

```
npm install -g yoinks
```

**Fonctionnement sans installation**

```
npx yoinks
```

## Exécution

**Démarrage avec un lien vidéo**

```
yoinks https://youtu.be/dQw4w9WgXcQ
```

**Démarrage avec un menu interactif**

```
yoinks
```
