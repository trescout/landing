# Agents experts en conception pour Claude Code

Utilisant le système d'équipe d'agents de Claude Code, Harness divise les missions complexes en équipes coordonnées d'agents spécialisés. Avec la commande « Mettre en place un harnais pour », il conçoit pour vous l'équipe et les compétences requises.

## Ce que ça vous apporte
- Divise les missions complexes en équipes d'agents spécialisés.
- Il développe les compétences dont les équipes ont besoin.
- Automatise les flux de travail.

## Pour commencer
Ajouté comme compétence à Claude Code ; Ensuite, vous pouvez leur demander de constituer une équipe d’agents pour la zone souhaitée.
