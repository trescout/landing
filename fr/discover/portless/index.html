URL persistante pour l'environnement de développement local

Développé par Vercel Labs, Portless transforme les numéros de port utilisés dans les environnements de développement locaux en adresses URL persistantes et nommées. Cet outil permet aux développeurs ainsi qu'aux agents d'IA autonomes d'interagir plus facilement avec les services locaux.

Ce que ça vous apporte

  • Convertit les numéros de port variables en adresses nommées mémorisables
  • Fournit automatiquement la prise en charge de HTTPS et HTTP/2
  • Crée une URL distincte pour chaque paquet dans les structures monorepo

Installation

Installation générale
npm install -g portless
Installation basée sur le projet
npm install -D portless

Exécution

Démarrer l'application avec une URL nommée
portless myapp next dev

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Je souhaite que les services fonctionnant dans mon environnement de développement local utilisent des adresses persistantes avec l'extension .localhost au lieu de numéros de port. Exécute mon projet en utilisant l'outil Portless et permets-moi d'accéder à mes services via des adresses identifiables telles que https://myapp.localhost.
