# Journalisation rapide pour les projets C++

spdlog est une bibliothèque de journalisation très rapide développée pour le langage de programmation C++. Il offre une gestion de sortie haute performance pour accélérer les processus de débogage et de surveillance dans les projets logiciels.

- ★ 29 437
- C++
- GitHub Trending · 2026-08-05

## Ce que ça vous apporte
- Gestion de journalisation haute performance
- Sortie vers différentes destinations telles que fichier, console et débogueur
- Niveau de journalisation dynamique changeant au moment de l'exécution

## Installation
**macOS (Homebrew)**

```
brew install spdlog
```


## Pour commencer
Pour l'inclure dans votre projet, copiez simplement le dossier include de la page GitHub vers votre répertoire de travail. Alternativement, vous pouvez installer la bibliothèque à l'aide de la commande appropriée à votre système via des gestionnaires de packages tels que Debian, Homebrew ou vcpkg.
