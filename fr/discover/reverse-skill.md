# Conseils sur l’intelligence artificielle pour les tests d’intrusion

Reverse-skill propose un package de routage basé sur l'intelligence artificielle pour les processus de rétro-ingénierie et de tests d'intrusion. Grâce à ses fonctionnalités d'amorçage de chaîne d'outils et de base de connaissances auto-développées, Claude Code s'intègre aux outils de codage tels que Cursor et Cline.

## Ce que ça vous apporte
- Flux de travail standardisés pour les agents IA

## Installation
**Téléchargez le référentiel sur votre ordinateur**

```
git clone https://github.com/zhaoxuya520/reverse-skill.git
```


## Si vous ne codez pas
Utilisez ce projet comme guide dans une tâche de test d’intrusion ou d’ingénierie inverse. Avant d'effectuer votre tâche, consultez les instructions du fichier README_AI.md, respectez les règles de routage du fichier RULES.md et démarrez le flux de travail en déterminant la méthodologie correcte via MASTER-ROUTING.md.
