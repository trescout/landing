# Formez votre propre modèle LLM à partir de zéro

train-llm-from-scratch propose une méthode simple, étape par étape, pour entraîner un grand modèle de langage à partir de zéro, du téléchargement de l'ensemble de données à la génération de texte. C'est une ressource pratique pour votre processus d'apprentissage.

- ★ 8 864
- Jupyter Notebook
- MIT
- GitHub Trending · 30 May 2026

## Qu'est-ce qu'on apprend ?
- Flux de bout en bout couvrant le téléchargement des données, la formation et la production de textes.
- Méthode de candidature basée sur le fonctionnement interne du LLM.
- Utilisation pratique avec des ordinateurs portables directement utilisables.

## Comment installer, comment utiliser ?
**Cloner le référentiel**

```
git clone https://github.com/FareedKhan-dev/train-llm-from-scratch.git
cd train-llm-from-scratch
```

**Installer les dépendances**

```
pip install -r requirements.txt
```
