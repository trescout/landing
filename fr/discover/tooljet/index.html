Développer des applications d'entreprise sans écrire de code

ToolJet est une plateforme de création d'applications open source permettant de développer des outils internes, des tableaux de bord et des agents d'intelligence artificielle. Cette infrastructure basée sur JavaScript permet aux entreprises de numériser des flux de travail complexes en réduisant le besoin d'écrire du code.

Ce que ça vous apporte

  • Conception d'interface visuelle rapide avec méthode glisser-déposer
  • Intégration facile avec la base de données, l'API et les services cloud
  • Flux de travail flexibles avec prise en charge de JavaScript et Python

Installation

Installation locale avec Docker
docker run \
  --name tooljet \
  --restart unless-stopped \
  -p 80:80 \
  --platform linux/amd64 \
  -v tooljet_data:/var/lib/postgresql/13/main \
  tooljet/try:ee-lts-latest

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Aidez-moi à créer un panneau d'opérations internes connecté à une base de données, par glisser-déposer, à l'aide de plus de 60 composants prêts à l'emploi sur ToolJet. Concevoir une architecture d'application qui visualise les données et automatise les flux de travail intra-équipe que je peux personnaliser à l'aide de JavaScript et Python.
