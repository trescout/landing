# Minimind

MiniMind est un projet Python qui permet d'entraîner un grand modèle de langage (LLM) de 64 millions de paramètres à partir de zéro et en seulement deux heures. Il offre un environnement d'apprentissage pratique pour comprendre les principes de fonctionnement des modèles d'intelligence artificielle pour les utilisateurs disposant de ressources matérielles limitées.
