# Kimi K3 in C

Le projet FareedKhan-dev/kimi-k3-in-c permet d'exécuter le modèle Kimi K3 de 2,78 billions de paramètres sur un seul processeur avec une utilisation de mémoire de 8,24 Go. Ne nécessitant aucun framework ni unité de traitement graphique (GPU), cette application basée sur C99 se concentre sur l'exécution de modèles d'intelligence artificielle à haut nombre de paramètres sur du matériel limité.
