Simulation de classe interactive multi-agents avec IA

Développé par des chercheurs de Tsinghua, OpenMAIC réunit des agents IA endossant des rôles d'enseignants, d'élèves et d'observateurs dans une classe simulée.

Ce que vous gagnez

  • Architecture multi-agents basée sur les rôles: Interactions dynamiques entre agents LLM incarnant enseignants, élèves curieux et modérateurs.
  • Interface de classe visuelle et sonore: Environnement immersif avec tableau blanc virtuel, flux de questions-réponses et synthèse vocale.
  • Programme de cours personnalisable: Téléversez vos PDF ou notes de cours pour générer automatiquement des sessions interactives.
  • Lancement de simulation en un clic: Pilotez l'orchestration multi-agents via une interface web moderne sans coder.
  • Compatibilité avec les modèles ouverts: Connectez Ollama, vLLM ou des API cloud pour animer les agents avec le modèle de votre choix.

Installation

Cloner le dépôt et installer les dépendances
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install

Exécution

Démarrer le serveur de développement
pnpm run dev
# Tarayıcıda http://localhost:3000 adresini açın

Architecture technique et principe de fonctionnement

OpenMAIC fonctionne sur une boucle conversationnelle événementielle coordonnant les interactions multi-agents:

  • Moteur d'orchestration conversationnelle: Coordinateur central gérant les tours de parole, le rythme du débat et le contexte partagé.
  • Gestion de la mémoire et du contexte: Conserve l'état du tableau blanc virtuel, les questions des élèves et la progression pédagogique.
  • Streaming WebSocket à faible latence: Transmet en temps réel les répliques des agents, les métadonnées et animations à l'interface web.

Dynamiques de classe multi-agents et simulations de rôles

OpenMAIC ouvre des perspectives novatrices dans l'edtech et la recherche sur les agents d'IA:

  • Environnements de débat socratique: Stimulez la réflexion critique de l'utilisateur grâce à des débats animés entre agents.
  • Tutorat personnalisé adaptatif: Ajustez le niveau de difficulté en temps réel selon le rythme de compréhension de l'apprenant.
  • Recherche sur la dynamique sociale des agents: Analysez la collaboration et l'émergence de consensus au sein de groupes d'agents autonomes.

Foire aux questions

  • OpenMAIC nécessite-t-il un GPU local? Un GPU n'est nécessaire que si vous exécutez un modèle local avec Ollama; les API hébergées (OpenAI, Gemini) fonctionnent sur n'importe quel ordinateur.
  • L'utilisateur peut-il intervenir à la voix? Oui. Grâce au module WebRTC, vous pouvez prendre la parole au micro pour participer aux débats.
  • Combien d'agents peuvent interagir simultanément? La configuration standard gère idéalement 3 à 8 agents, extensible selon les quotas de vos modèles.
  • Quels formats de documents sont acceptés? Les fichiers texte brut, Markdown et documents PDF sont directement indexés dans la mémoire de cours.
