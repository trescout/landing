# Gestion de l'espace de travail pour les agents IA

Gas Town propose une infrastructure qui permet à différents agents d'intelligence artificielle de travailler ensemble en tant que gestionnaire d'espace de travail multi-agents. Développé avec le langage Go, cet outil centralise la coordination inter-agents et la gestion des ressources dans des workflows complexes.

## Ce que ça vous apporte

- Coordonnez plusieurs agents d’intelligence artificielle à partir d’un seul centre.
- Empêchez les agents de perdre le contexte lors des redémarrages.
- Conservez les processus métier avec le stockage basé sur Git.

## Installation

**Installation avec Homebrew**

```
brew install gastown
```

**Créer un espace de travail**

```
gt install ~/gt --git
```

## Exécution

**Séance de démarrage du maire**

```
gt mayor attach
```
