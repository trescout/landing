- Gérez facilement les modèles d'invite et les plugins via l'interface

## Installation

**Installation des dépendances**

```
pnpm install
```

## Exécution

**Démarrage de l'environnement de développement**

```
pnpm dev
```

**Créer l'application de bureau**

```
pnpm --dir apps/desktop tauri build
```
