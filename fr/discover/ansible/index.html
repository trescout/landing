Plateforme qui automatise les systèmes informatiques

Ansible est une plate-forme d'automatisation des technologies de l'information qui automatise les processus de déploiement d'applications et de gestion de système. Il effectue les opérations de configuration dans un langage simple via le protocole SSH, sans avoir besoin d'installer de middleware sur les systèmes distants.

Ce que ça vous apporte

  • Gérer les systèmes distants via SSH
  • Configurer sans installer de middleware
  • Effectuez facilement des mises à jour complexes

Installation

via pip (PyPI)
pip install ansible
macOS (Homebrew)
brew install ansible

Exécution

Exécuter le script du playbook Ansible
ansible-playbook site.yml

Pour commencer

Pour installer Ansible, vous devez visiter le guide d'installation sur le site officiel. Vous pouvez trouver les étapes détaillées pour différents systèmes d'exploitation dans le guide d'installation sur la page de documentation officielle d'Ansible.
