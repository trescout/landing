# Intelligence économique automatisée avec intelligence artificielle

Développé par Canner, WrenAI est un outil open source de business intelligence générative (BI générative) qui exporte automatiquement les données dans des panneaux et des graphiques en convertissant le langage naturel en requêtes de base de données (texte vers SQL). La plateforme fournit des processus d'analyse de données fiables pour les agents d'IA via une couche contextuelle gérable qui prend en charge plus de vingt sources de données.

## Ce que ça vous apporte
- Génère des requêtes SQL fiables à partir du langage naturel
- Convertit automatiquement les données en panneaux
- Prend en charge plus de 22 sources de données

## Installation
**Installation de la CLI**

```
pip install wrenai                      # core (DuckDB included)
pip install "wrenai[postgres,memory]"   # add per-datasource and memory extras as needed
```

**Configuration du stub pour le client AI**

```
npx skills add Canner/WrenAI            # auto-detects Claude Code, Cursor, Cline, Codex, …
```


## Si vous ne codez pas
Configurez ma connexion à la base de données à l'aide de WrenAI, créez le squelette du projet et exécutez ma première requête. Enrichissez ensuite le contexte en incluant les données de logique métier du dossier brut dans mon projet.
