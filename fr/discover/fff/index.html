Vitesse de l'intelligence artificielle dans la recherche de fichiers

Développé avec Rust, fff est une boîte à outils pour les agents d'intelligence artificielle et les éditeurs de texte qui effectue des recherches de fichiers avec une vitesse et une précision élevées. Avec le support C et NodeJS, il offre une structure qui peut être intégrée dans différents environnements de développement.

Ce que ça vous apporte

  • Il offre une vitesse élevée de recherche de fichiers et de navigation de contenu.
  • Il propose un tri basé sur la fréquence qui donne la priorité aux fichiers fréquemment utilisés.
  • Il fournit une indexation optimisée pour les agents et éditeurs d’intelligence artificielle.

Installation

Installation du serveur MCP (Linux / macOS)
curl -L https://dmtrkovalenko.dev/install-fff-mcp.sh | bash
Installation du plug-in de l'agent Pi
pi install npm:@ff-labs/pi-fff

Exécution

Configuration pour l'agent
For any file search or grep in the current git-indexed directory, use fff tools.

Si vous ne codez pas

🤖 Collez ceci dans votre agent (Claude Code · Codex · Antigravity)

Utilisez les outils fff pour toutes les opérations de recherche de fichiers et d'exploration de contenu (grep) dans mon projet. Ces outils renverront des résultats plus efficaces grâce à leurs fonctionnalités de tri basé sur la fréquence et d'indexation rapide.
