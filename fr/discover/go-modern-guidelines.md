## Ce que ça vous apporte
- Permet aux modèles d'IA d'utiliser les fonctionnalités Go actuelles
- Préfère les méthodes modernes et efficaces aux anciens modèles de code
- Détecte automatiquement la version Go du projet et adapte les fonctionnalités linguistiques en conséquence

## Installation
**Ajout d'un marché pour Junie**

```
/extensions marketplace add JetBrains/go-modern-guidelines
```

**Installation du plugin pour Junie**

```
/extensions install modern-go-guidelines
```


## Exécution
**Exécuter des conseils sur Claude Code**

```
/modern-go-guidelines:use-modern-go
```


## Si vous ne codez pas
À partir de maintenant, utilisez les normes Go modernes lors de l’écriture de code. Considérez la version de Go dans le fichier go.mod du projet, en optant pour les dernières fonctionnalités du langage et les ajouts de bibliothèques standard de la version 1.0 à 1.27. Utilisez des fonctions comme `max(a, b)` au lieu des blocs `if-else`, des méthodes modernes comme `slices.Contains` au lieu des boucles manuelles et des modèles à jour comme `cmp.Or` au lieu de vérifications nulles.
