## Que fait cet outil ?
Clean Code JavaScript est un guide open source qui adapte les célèbres principes de « Clean Code » de Robert C. Martin à l'écosystème JavaScript. Il illustre les normes d'écriture de code lisible, réutilisable et maintenable avec du JavaScript moderne.

## Pour qui ?
Pour ceux qui souhaitent améliorer la qualité de leur code JavaScript et développer des logiciels maintenables selon des normes professionnelles.

## À quoi ne faut-il pas s’attendre ?
Pour les débutants complets qui ne connaissent pas encore les bases du langage JavaScript.

## Points forts
- Adapte les principes traditionnels de l'ingénierie logicielle à JavaScript.
- Présente les mauvaises et les bonnes pratiques de code de manière comparative.
- Couvre un large éventail de sujets, du nommage des variables à la gestion des erreurs.

## Premiers pas
- Consultez la table des matières en vous rendant sur le dépôt GitHub officiel.
- Lisez les exemples de code « Mauvais » (Bad) et « Bon » (Good) pour les concepts avec lesquels vous avez particulièrement du mal.
- Mettez en pratique les principes appris en les appliquant à vos propres projets.
