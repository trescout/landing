# Formation à l'intelligence artificielle en mémoire faible

Soup est une bibliothèque Python qui permet d'affiner de grands modèles de langage via un seul fichier YAML. Il peut entraîner des modèles avec 8 milliards de paramètres à l'aide de la méthode de streaming de couches sur des processeurs graphiques d'ordinateurs portables dotés de 4 Go de mémoire.

## Ce que ça vous apporte

- Vous pouvez entraîner des modèles avec 8 milliards de paramètres sur des ordinateurs portables dotés de 4 Go de mémoire graphique.
- Avec la méthode du flux de couches, vous n'avez pas à gérer des installations complexes en surmontant les restrictions matérielles.
- Vous pouvez gérer l'ensemble du processus de formation via un seul fichier de configuration.

## Installation

**Configuration de base**

```
pip install "soup-cli[train]"
```

**Configuration avec toutes les fonctionnalités**

```
pip install "soup-cli[all]"
```

## Exécution

**Commencer la formation**

```
soup init --template chat
soup train
```
