# Visualisation graphique des cybermenaces

Flowsint propose une plateforme d'investigation visuelle, flexible et extensible basée sur des graphiques pour les analystes et les chercheurs en cybersécurité. Développé avec TypeScript, cet outil facilite la visualisation et l'analyse d'ensembles de données complexes.

## Ce que ça vous apporte
- Analyser les relations entre les entités dans une interface graphique visuelle
- Traitez les données IP, de domaine et de réseaux sociaux avec des enrichisseurs automatiques
- Assurer une haute confidentialité en stockant toutes les données sur la machine locale

## Installation
**Commandes de configuration**

```
git clone https://github.com/reconurge/flowsint.git
cd flowsint
make prod
```


## Exécution
**Démarrage de l'environnement de développement**

```
make dev
```
