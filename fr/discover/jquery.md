# Créer des versions personnalisées de jquery

jQuery est une bibliothèque JavaScript qui facilite la création d'éléments interactifs sur les pages Web. Elle fournit des outils qui simplifient la manipulation du modèle d'objet de document (DOM) et la gestion des événements pour les développeurs.

## Ce que ça vous apporte

- Compilez votre propre bibliothèque jquery personnalisée.
- Réduisez la taille en supprimant les modules dont vous n'avez pas besoin.
- Générez tous les fichiers de version en bloc.

## Installation

**Installez les dépendances et compilez le projet**

```
cd jquery
npm install
npm run build
```

**Générez tous les fichiers de version**

```
npm run build:all
```
