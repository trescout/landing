# Gérer les interfaces Web avec le langage naturel

Développé par Alibaba, page-agent est un agent d'interface utilisateur graphique sur la page qui permet de contrôler les interfaces Web avec des commandes en langage naturel. Écrit en TypeScript, cet outil offre un mécanisme de contrôle basé sur un navigateur pour automatiser les interactions Web.

## Ce que ça vous apporte
- Aucune extension de navigateur ou Python requis
- Rendu DOM basé sur du texte au lieu de captures d'écran
- Intégration avec vos propres modèles d'IA

## Installation
**Installation via NPM**

```
npm install page-agent
```


## Si vous ne codez pas
Je souhaite gérer les interactions sur la page Web avec des commandes en langage naturel à l'aide de PageAgent. Je souhaite qu'il effectue des opérations telles que cliquer sur des boutons sur la page, remplir des formulaires ou saisir des données en utilisant le modèle d'intelligence artificielle que j'ai déterminé.
