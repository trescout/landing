# Infrastructure logicielle sécurisée pour TypeScript

Effect-TS est un écosystème de bibliothèques permettant de développer des applications évolutives et tolérantes aux pannes avec TypeScript. Il standardise les processus de développement logiciel en utilisant les principes de la programmation fonctionnelle pour gérer des flux de travail complexes.

## Ce que ça vous apporte
- Centralise la gestion des erreurs et les processus de validation des données.
- Sécurise la planification et la gestion de la concurrence.
- Offre des extensions officielles pour différentes bases de données et environnements d'exécution.

## Installation
**Ajouter le package au projet**

```
npm install effect
```


## Si vous ne codez pas
Je souhaite inclure la bibliothèque Effect dans mon projet basé sur TypeScript. Effectue l'installation nécessaire en utilisant la commande 'npm install effect' et assure-toi que le paramètre de vérification de type 'strict' est activé dans le fichier 'tsconfig.json' du projet.
