Cadre de tests unitaires pour les projets C++

Catch2 est un framework de tests unitaires moderne qui prend en charge C++14 et versions ultérieures. Il est conçu pour prendre en charge les pratiques de développement piloté par les tests (TDD) et de développement piloté par le comportement (BDD) dans les processus de développement logiciel.

Ce que ça vous apporte

  • Prend en charge les processus de développement pilotés par les tests
  • Offre une rédaction de tests simple et naturelle
  • Comprend des fonctionnalités essentielles de micro-analyse comparative

Installation

macOS (Homebrew)
brew install catch2

Pour commencer

Catch2 est structuré comme une bibliothèque. Pour commencer, vous pouvez apprendre comment l'inclure dans votre projet en consultant le guide « Tutoriel » dans la section documentation de la page GitHub.
