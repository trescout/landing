Programmer des animations mathématiques explicatives

Manim est un moteur d’animation pour créer par programmation des vidéos mathématiques explicatives et précises. Vous pouvez définir les animations en Python et commencer avec les scènes d’exemple du dépôt 3b1b sélectionné.

Que fait cet outil ?

Cette fiche concerne ManimGL du dépôt 3b1b. Il sert à créer en code des animations qui expliquent des concepts mathématiques. Manim Community Edition est un fork et un projet distincts ; ses instructions d’installation ne doivent pas être mélangées avec celles de ManimGL.

Pour qui ?

Les enseignants, étudiants et créateurs de contenu qui souhaitent expliquer des concepts mathématiques avec des animations programmées.

À quoi ne faut-il pas s’attendre ?

Les personnes qui recherchent un outil d’animation par glisser-déposer ou qui souhaitent installer spécifiquement Manim Community Edition.

Points forts

  • Animation programmatique pour des vidéos mathématiques explicatives.
  • Fonctionne avec Python 3.10 ou une version ultérieure.
  • OpenGL fait partie des exigences système.
  • Licence MIT.

Premiers pas

  1. Préparez Python 3.10 ou une version ultérieure, FFmpeg et les exigences OpenGL.
  2. Installez LaTeX si vous comptez l’utiliser ; sous Linux, installez également les en-têtes de développement Pango.
  3. Exécutez `pip install manimgl` dans votre terminal.
  4. Testez l’installation avec `manimgl example_scenes.py OpeningManimExample`.

Démarrage prudent

Cette fiche concerne ManimGL. Le nom du paquet est `manimgl` ; n’utilisez pas les instructions d’installation du projet distinct Manim Community Edition.
