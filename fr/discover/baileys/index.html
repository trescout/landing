Intégration avec le protocole Web WhatsApp

Baileys propose une interface basée sur socket (API) basée sur le protocole Web WhatsApp et permettant de développer des applications basées sur TypeScript et JavaScript. Grâce à cette bibliothèque, les développeurs peuvent intégrer directement les fonctions de messagerie WhatsApp dans leurs propres projets.

Ce que ça vous apporte

  • Interagissez directement avec l'API Web WhatsApp
  • Développer des projets basés sur TypeScript et JavaScript
  • Ajoutez une fonctionnalité de messagerie à vos propres applications

Installation

avec npm
npm install baileys

Pour commencer

Pour commencer à utiliser cette bibliothèque, vous pouvez d'abord consulter le guide actuel sur https://baileys.wiki. Vous pouvez également accéder aux informations de base en accédant à l'ancienne documentation du projet depuis le fichier README sur GitHub ou depuis la page d'accueil de NPM.
