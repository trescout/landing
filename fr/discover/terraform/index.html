Gérez votre infrastructure avec du code

Développé par HashiCorp, Terraform définit l'infrastructure comme du code, permettant de la créer de manière sûre et prévisible. Écrit en langage Go, cet outil convertit les interfaces de programmation d'application (API) en fichiers de configuration déclaratifs, permettant aux équipes de gérer les processus d'infrastructure sous contrôle de version.

Installation

Ajouter un robinet HashiCorp
brew tap hashicorp/tap
macOS (Homebrew)
brew install hashicorp/tap/terraform
Image Docker
docker pull hashicorp/terraform

Exécution

Vérifier la version
terraform -version

Pour commencer

Pour commencer à utiliser Terraform, vous pouvez visiter les pages de documentation sur le site officiel. Pour l'installation et les étapes de base, il est recommandé de suivre les guides de démarrage sur la plateforme d'apprentissage de HashiCorp.
