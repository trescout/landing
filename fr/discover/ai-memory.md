# Mémoire permanente pour agents de codage d’intelligence artificielle

Écrit en Rust, ai-memory propose une solution de mémoire à long terme pour les agents d'intelligence artificielle. Il prend en charge la continuité des interfaces de ligne de commande (CLI) utilisées dans les processus de développement logiciel en facilitant le transfert de données entre différents fournisseurs d'agents.

## Ce que ça vous apporte
- Maintient le contexte entre les différents agents d'IA
- Assure la continuité des processus de développement
- Fonctionne avec de nombreux outils de codage

## Pour commencer
Pour commencer à utiliser l'outil, visitez la page officielle sur GitHub et téléchargez la version adaptée à votre système d'exploitation. Vous pouvez apprendre à intégrer l'outil aux agents de codage qu'il prend en charge en consultant les fichiers de documentation pertinents pour connaître les détails d'installation et de configuration.
