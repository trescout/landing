# Couche d'exploitation professionnelle pour Hermes Agent

Développé pour Hermes Agent, oh-my-hermes propose des packages d'intelligence de codage, un système de mémoire à long terme et un flux de travail axé sur les modèles dans une seule extension. Cet outil, qui optimise les processus de développement logiciel, offre aux développeurs un environnement de travail complet grâce à sa structure basée sur Python.

## Ce que ça vous apporte
- Offre un environnement de travail qui optimise les processus de développement logiciel.
- Maintient l'historique du projet organisé grâce à un système de mémoire à long terme.
- Ajoute une intelligence de codage et des flux de travail axés sur les modèles.

## Installation
**Installation pour macOS et Linux**

```
curl -fsSL https://raw.githubusercontent.com/rlaope/oh-my-hermes/main/install.sh | sh
```

**Installation avec le gestionnaire de paquets Homebrew**

```
brew install rlaope/tap/omh
```


## Exécution
**Configuration après installation**

```
omh setup
```


## Si vous ne codez pas
Installez et configurez l'extension Oh My Hermes sur Hermes Agent. Pendant le processus d'installation, utilisez l'installateur approprié pour le système d'exploitation, terminez l'installation interactive du modèle, effectuez la discussion sur la chaîne de modèles et exécutez les étapes de diagnostic (doctor). Tout en conservant la configuration Hermes existante, appliquez uniquement les modifications d'installation documentées et rapportez le résultat de l'opération.
