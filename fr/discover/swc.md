# Construisez vos projets Web à la vitesse de Rust

Développé avec le langage Rust, SWC offre une plateforme de compilation et de regroupement rapide pour les projets Web. Il accélère les processus de développement Web modernes en traitant les fichiers JavaScript et TypeScript avec des performances élevées.

## Ce que ça vous apporte

- Traite les fichiers JavaScript et TypeScript à grande vitesse

- Accélère les processus de développement Web modernes

## Installation

**Dépendances du projet (npm)**

```
npm i -D @swc/core
```

**Global via npm**

```
npm install -g @swc/cli @swc/core
```

## Exécution

**Compiler TypeScript**

```
swc index.ts -o index.js
```
