# Gérez les modèles d'IA dans une seule interface

Développée par Andrew Ng, aisuite est une bibliothèque Python qui permet de gérer différents fournisseurs d'IA générative via une seule interface. Il permet aux développeurs de basculer entre différents services de modèles sans apporter de modifications au code.

## Ce que ça vous apporte

- Gérez différents fournisseurs d’IA avec une seule interface
- Possibilité de basculer entre les modèles sans changer de code
- Définir les fonctions Python comme outils d'intelligence artificielle

## Installation

**Installation de base de la bibliothèque**

```
pip install aisuite               # base package, no provider SDKs
```

**Configuration avec tous les fournisseurs**

```
pip install 'aisuite[all]'        # with all provider SDKs
```
