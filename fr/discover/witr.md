# Découvrez l'origine des processus système

Witr est un outil de ligne de commande qui surveille les processus, les ports, les conteneurs ou les fichiers du système et détermine à partir de quelle source ils ont été démarrés. Ce logiciel, qui permet aux utilisateurs de suivre les activités sur le système, offre à la fois une prise en charge de ligne de commande (CLI) et d'interface utilisateur textuelle (TUI).

## Ce que ça vous apporte
- Montre étape par étape pourquoi les processus fonctionnent
- Surveille en détail les activités des conteneurs et des ports
- Facilite la surveillance du système grâce à une interface interactive

## Installation
**Installation rapide pour les systèmes Unix**

```
curl -fsSL https://raw.githubusercontent.com/pranshuparmar/witr/main/install.sh | bash
```

**Installation avec le gestionnaire de paquets Homebrew**

```
brew install witr
```


## Si vous ne codez pas
Je veux comprendre à partir de quelle source un processus, un port ou un conteneur exécuté dans mon système a été démarré et sa chaîne d'exécution sur le système. Comment puis-je utiliser l'outil witr pour surveiller ce processus et détecter pourquoi il est en cours d'exécution ?
