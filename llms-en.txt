# TreScout (English Index)

> TreScout scans GitHub, Hacker News, and HuggingFace daily, filters the noise using multi-agent AI, and delivers structured tech digests.

## AI Crawlers & API Access

Every dictionary term and open-source project page on TreScout is served as both HTML and plain Markdown:
- Append `.md` to any dictionary or discover URL to fetch raw Markdown (e.g. https://trescout.com/dictionary/rag.md).
- Use `Accept: text/markdown` HTTP request headers.
