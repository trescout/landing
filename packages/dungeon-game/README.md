# The Open Source Dungeon · Terminal Roguelike Game (TreScout)

A fast, zero-dependency, turn-based ANSI Roguelike RPG game built directly for your terminal.

---

## 🎮 How to Play

Launch directly with Node.js:

```bash
node packages/dungeon-game/bin/play.js
```

Or via npx:
```bash
npx trescout-dungeon
```

### ⚔️ Mechanics:
* **Heroes & Stats:** HP, XP, Level, Weapons (`Ripgrep Sword`), Shields (`Rust Shield`), Potions (`Ollama Flask`).
* **Enemies:** Merge Conflict Monsters, Memory Leak Dragons, Dependency Hell Devils, OOM Killer Titans.
* **Turns:** `[1]` Attack, `[2]` Use Health Potion, `[3]` Advance to Next Floor, `[q]` Quit.
