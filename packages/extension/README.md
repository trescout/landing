# TreScout New Tab · Browser Extension (Manifest V3)

A minimalist, developer-focused New Tab extension for Chrome, Brave, Edge, and Firefox. Displays daily tech intelligence, live clock, and a curated trending open-source tool with 1-click install command copying on every new tab.

---

## 🛠️ How to Install in Chrome / Brave / Edge (Developer Mode)

1. Open `chrome://extensions` in your browser.
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked** (Paketlenmemiş öğe yükle).
4. Select the directory:
   `/absolute/path/to/trescout-landing/packages/extension`
5. Open a new tab and enjoy daily open-source discovery!

---

## 🔒 Privacy & Performance
* **100% Offline-First:** Works without network; zero telemetry or cookies.
* **Instant:** Sub-millisecond load time.
