# ¿Qué es Local-first Code Intelligence Graph?

Es un sistema que mapea las relaciones de piezas de código en proyectos de software en su computadora local sin necesidad de Internet.

## Definición
Este sistema conecta todos los archivos y funciones de su código base como una red. Sus datos permanecen privados porque se ejecutan directamente en su dispositivo en lugar de conectarse a Internet. Le ayuda a comprender la estructura de su código y navegar rápidamente en proyectos complejos.

## Cómo funciona
Está integrado en su entorno de desarrollo de software y crea una red de relaciones escaneando su código. Cuando cambia una función, le muestra instantáneamente a qué archivos afectará este cambio.

## Dónde se usa
Se utiliza en proyectos de software complejos, desarrollo de software corporativo donde la privacidad está a la vanguardia y en situaciones que requieren trabajo fuera de línea.

## Suele confundirse con
Puede confundirse con herramientas generales de análisis de código o servicios de indexación de código basados ​​en Internet.

## Preguntas frecuentes
**¿Por qué se llama "primero local"?**
Porque todo el proceso de análisis se realiza directamente en su propio ordenador, no en servidores en la nube.

**¿Funcionará cuando no tenga internet?**
Sí, el sistema no necesita conexión a Internet porque funciona completamente de forma local.
