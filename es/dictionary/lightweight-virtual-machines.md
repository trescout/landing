# ¿Qué es Lightweight Virtual Machines?

Pequeños ordenadores virtuales que se ejecutan rápidamente utilizando sólo los recursos necesarios y ocupan muy poco espacio.

## Definición
Las computadoras virtuales tradicionales pueden ser pesadas y lentas. Las máquinas virtuales ligeras, por otro lado, son pequeños entornos de software diseñados para realizar sólo las tareas más básicas y están libres de cargas innecesarias.

## Cómo funciona
El sistema utiliza los recursos de la computadora host con mucho cuidado, convirtiendo solo la pequeña cantidad de espacio necesaria en una máquina virtual.

## Dónde se usa
Se utiliza en la computación en la nube para ejecutar aplicaciones rápidamente o proporcionar aislamiento de seguridad.

## Suele confundirse con
Se puede confundir con máquinas virtuales completas (Máquinas Virtuales), pero arrancan mucho más rápido.

## Preguntas frecuentes
**¿Por qué debería elegir el ligero?**
Como consume menos recursos, puedes realizar más operaciones al mismo tiempo.

**¿Son seguras las máquinas virtuales ligeras?**
Sí, aísla las aplicaciones entre sí ya que cada una se ejecuta en su propio espacio pequeño.
