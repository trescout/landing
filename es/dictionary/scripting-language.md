# ¿Qué es Scripting Language?

*Desarrollo · Última actualización: 23 de octubre de 2026*

Tipo de lenguaje de programación que se utiliza para automatizar procesos de software y ejecutar tareas rápidamente, el cual generalmente no requiere compilación.

## Definición

Los lenguajes de scripting son aquellos que un intérprete ejecuta línea por línea, en lugar de compilarse previamente a código de máquina como los lenguajes tradicionales. Por lo general, se prefieren para conectar sistemas existentes entre sí, automatizar tareas rutinarias o añadir dinamismo a las páginas web. Python, JavaScript y Bash se encuentran entre los lenguajes de scripting más populares.

***Analogía:** En lugar de ser la copia final montada de principio a fin de una película, se parece más a un texto teatral práctico que los actores siguen paso a paso en el escenario.*

## Cómo funciona

El desarrollador escribe el código y da directamente la orden de ejecución. Un software intermediario (intérprete) lee este código al instante y lo transmite como comandos al sistema operativo o al navegador. Como no hay un paso de compilación, el ciclo de desarrollo y pruebas avanza de forma sumamente rápida.

## Dónde se usa

Se utiliza con frecuencia para automatizar tareas rutinarias en la administración de sistemas, crear interfaces interactivas en navegadores web y en flujos de trabajo de análisis de datos.

## Suele confundirse con

Se suele confundir con los lenguajes de programación de sistemas. Mientras que los lenguajes de sistemas como C o Rust se compilan para ofrecer un alto rendimiento directamente a nivel de hardware, los lenguajes de scripting se centran en la practicidad y la velocidad de desarrollo.

## Preguntas y respuestas

**¿Son lentos los lenguajes de scripting?**

En cuanto a la potencia de procesamiento puro, suelen ser más lentos en comparación con los lenguajes directamente compilados; sin embargo, gracias a las optimizaciones modernas, son más que suficientes para la mayoría de las tareas cotidianas y aplicaciones web.

**¿Es Python un lenguaje de scripting?**

Sí, Python es tanto un lenguaje de programación de propósito general como un lenguaje de scripting potente y ampliamente utilizado.
