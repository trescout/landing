# ¿Qué es I/O?

> Input/Output

El proceso por el cual un sistema informático recibe y envía datos del mundo exterior.

## Definición
La E/S es un proceso de E/S cuando una computadora recibe texto del teclado, descarga datos de Internet o imprime algo en la pantalla. El sistema establece todo tipo de comunicación con el exterior a través de este canal. Es como los "sentidos y las manos" de la computadora.

## Cómo funciona
Los datos ingresan al sistema desde los dispositivos de entrada (teclado, sensor), son procesados ​​por el procesador y enviados a los dispositivos de salida (pantalla, parlantes).

## Dónde se usa
Es un concepto fundamental en todos los programas informáticos y las interacciones de hardware.

## Preguntas frecuentes
**¿Por qué la E/S es un cuello de botella?**
Incluso si el procesador funciona muy rápido, si la velocidad de entrada o salida de datos (por ejemplo, la velocidad del disco) es lenta, el sistema tiene que esperar.
