# ¿Qué es Free Tier?

Es el nivel de entrada de un servicio que se ofrece de forma gratuita con funciones limitadas.

## Definición
Es un modelo de prueba que ofrecen las empresas para acostumbrar a los usuarios al sistema. Suele ser un paquete en el que se restringe una determinada cuota de uso o algunas funciones avanzadas. Cuando aumenta la necesidad, los usuarios cambian a planes pagos.

## Cómo funciona
El usuario crea una cuenta y el sistema define automáticamente límites gratuitos. Cuando se alcanza el límite, el sistema le advierte y solicita una actualización.

## Dónde se usa
Es común en servicios de software (SaaS), API de IA y plataformas en la nube.

## Suele confundirse con
No confundir con software completamente gratuito; es parte de un modelo de negocio.

## Preguntas frecuentes
**¿Ilimitado?**
No, normalmente existen restricciones basadas en la cantidad de uso o las funciones.

**¿Cuándo tengo que pagar una tarifa?**
Pagas cuando excedes tus límites o necesitas funciones más avanzadas.
