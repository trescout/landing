# ¿Qué es API?

> Application Programming Interface

Es un puente digital que permite que dos software diferentes se comuniquen entre sí.

## Definición
API es un lenguaje estándar que permite que el software se comunique entre sí. Permite que una aplicación ponga sus capacidades a disposición de otras aplicaciones.

## Cómo funciona
Un software envía una solicitud a una dirección específica. Otro software recibe esta solicitud, la procesa y devuelve el resultado. Este proceso está completamente basado en reglas y es automático.

## Dónde se usa
Se utiliza en aplicaciones meteorológicas para recuperar datos del centro meteorológico o para acceder a modelos de inteligencia artificial a través de Internet.

## Suele confundirse con
Se confunde con el sitio web en sí, pero la API está diseñada para que las máquinas hablen con las máquinas, no con los humanos.

## Preguntas frecuentes
**¿Cualquiera puede usar la API?**
Generalmente el acceso se proporciona mediante autorización con una clave, por lo que es un proceso controlado.

**¿Por qué la API es segura?**
Dado que solo permite compartir datos permitidos, solo abre la parte relevante del sistema, no todo el sistema.
