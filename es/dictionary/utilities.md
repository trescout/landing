# ¿Qué es Utilities?

Pequeño software útil que facilita el mantenimiento, gestión o funciones básicas del ordenador.

## Definición
No se trata de grandes aplicaciones, sino de pequeñas herramientas que facilitan tu trabajo. Realizan tareas como comprimir archivos, limpiar el sistema o ajustar la configuración de red.

## Cómo funciona
Por lo general, se centran en un único propósito y trabajan silenciosamente en segundo plano para mantener el sistema en orden.

## Dónde se usa
Están ubicados dentro de los sistemas operativos o en pequeños paquetes de utilidades.

## Suele confundirse con
No confundir con el software principal; Estas son herramientas que apoyan el funcionamiento del software principal.

## Preguntas frecuentes
**¿Son necesarias todas las utilidades?**
Depende de sus necesidades, pero los conceptos básicos (limpieza, seguridad) son importantes para la salud del sistema.

**¿Es el software de utilidad una aplicación?**
Sí, pero es una aplicación más específica y de menor escala.
