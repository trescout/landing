# ¿Qué es Open-Source Clones?

Son versiones similares de software popular creadas copiando públicamente sus códigos fuente.

## Definición
Las copias de código abierto toman la lógica o la apariencia de un software exitoso y lo convierten en algo que cualquiera puede desarrollar libremente. Esto permite a las comunidades crear sus propias alternativas donde el software original es pago o cerrado. Así, se pueden utilizar herramientas con características similares en el mundo del software sin depender de una única empresa.

## Cómo funciona
Los desarrolladores toman el código fuente del proyecto original y lo utilizan como base para sus propios proyectos. Luego realizan sus propias mejoras o cambios en este código. El producto resultante es una nueva versión muy similar al original pero respaldada por la comunidad.

## Dónde se usa
Se utiliza en el mundo del software cuando se desarrollan herramientas alternativas o se crean versiones más accesibles de un software en particular.

## Suele confundirse con
Puede confundirse con el término simplemente "Clonar", pero este término cubre específicamente aquellos que son de código abierto y están impulsados ​​por la comunidad.

## Preguntas frecuentes
**¿Son legales las copias de código abierto?**
Si la licencia del software original lo permite, entonces sí, es completamente legal.

**¿Por qué debería utilizar una copia y no el original?**
Generalmente se prefieren porque son más rentables, puede cambiarlos según sus necesidades u ofrecen una estructura más gratuita.
