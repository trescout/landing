Cloud Computing Arquitectura, modelos e ingeniería de sistemas

Cloud computing (computación en la nube) es la entrega bajo demanda de recursos informáticos como servidores, almacenamiento, bases de datos y redes a través de internet con pago por uso.

Definición, Origen Etimológico y Fundamentos

La expresión cloud computing se popularizó a partir de diagramas de redes de telecomunicaciones en la década de 1990, donde la infraestructura subyacente se simbolizaba con un dibujo de nube. Permite sustituir centros de datos locales por servicios elásticos accesibles mediante API.

Modelos de Servicio y Despliegue (IaaS, PaaS, SaaS, Serverless)

Los servicios en la nube se clasifican habitualmente en cuatro categorías principales:

  • IaaS (Infraestructura como Servicio): Servidores virtuales, almacenamiento escalable y redes definidas por software (AWS EC2, Google Compute Engine).
  • PaaS (Plataforma como Servicio): Entornos gestionados para desplegar aplicaciones sin ocuparse de parches del sistema operativo (Heroku, Render).
  • SaaS (Software como Servicio): Programas informáticos completos servidos en la web para el usuario final (Google Workspace, Salesforce).
  • Serverless / FaaS: Arquitecturas orientadas a eventos donde el código se ejecuta únicamente cuando se recibe una petición (AWS Lambda, Cloudflare Workers).

Arquitectura de Sistemas: Hipervisores, Contenedores y Teorema CAP

A nivel técnico, la computación en la nube se fundamenta en virtualización y consistencia distribuida:

  • Hipervisores y Contenedores: Los hipervisores Tipo 1 (KVM, ESXi) crean máquinas virtuales completas, mientras que los contenedores (Docker, containerd) comparten el kernel del host garantizando máxima ligereza.
  • Teorema CAP y Consenso: Los clústeres globales deben resolver los compromisos entre Consistencia, Disponibilidad y Tolerancia a particiones utilizando protocolos como Raft o Paxos.

Factores Económicos, Ecológicos y Geopolíticos

La adopción de la nube transforma los gastos de capital (CapEx) en gastos operativos flexibles (OpEx), haciendo imprescindible la disciplina FinOps para controlar costes de transferencia. Además, las normativas de soberanía de datos exigen aislamiento geográfico del almacenamiento cifrado.

Confusiones habituales

  • Cloud Computing vs Alojamiento Web tradicional: El alojamiento web convencional asigna recursos estáticos en servidores fijos, mientras que la nube ofrece escalabilidad horizontal automática en múltiples zonas de disponibilidad.
  • Nube Privada vs Servidor Local: Disponer de un servidor físico en la oficina no es una nube privada sin una plataforma de aprovisionamiento automatizada por API.
La computación en la nube funciona como la red de suministro eléctrico: en lugar de mantener un generador propio de combustible en el sótano, se conecta el enchufe a la red y se abona solo el consumo exacto.

Preguntas frecuentes

¿Cuáles son los principales beneficios de la computación en la nube?

Escalabilidad elástica, alta disponibilidad sin interrupciones, menor carga de mantenimiento de hardware físico y despliegue global rápido.

¿Qué diferencia existe entre multi-cloud y nube híbrida?

Multi-cloud utiliza dos o más proveedores públicos de manera simultánea, mientras que la nube híbrida enlaza infraestructuras locales propias con centros de datos públicos.

¿Cómo se optimizan los costes en la nube?

Aplicando metodologías FinOps, reduciendo recursos infrautilizados, usando instancias spot y contratando planes de capacidad reservada.
