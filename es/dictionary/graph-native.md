# ¿Qué es Graph-native?

Es un diseño de sistema basado en una estructura en la que los datos se conectan entre sí a través de nodos.

## Definición
Mientras que las bases de datos tradicionales almacenan información en tablas, este enfoque conecta datos como un mapa de red. Coloca las relaciones entre la información en el centro del sistema desde el principio. De esta forma, consultar conexiones complejas se vuelve mucho más rápido y natural.

## Cómo funciona
Cuando crea su modelo de datos, define objetos y sus interacciones como puntos y líneas. Siguiendo estas líneas, el sistema encuentra enlaces ocultos entre datos en cuestión de segundos.

## Dónde se usa
Se utiliza en análisis complejos de redes sociales, sistemas de recomendación y aplicaciones que gestionan grandes masas de información interconectada.

## Suele confundirse con
Frecuentemente se confunde con las bases de datos relacionales tradicionales; Sin embargo, este sistema establece relaciones en la etapa de diseño, no más tarde.

## Preguntas frecuentes
**¿Por qué debería elegir este método?**
Este método es la forma más eficaz si las relaciones entre los datos son tan importantes como los datos mismos.
