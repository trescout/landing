# ¿Qué es Shell?

Es una interfaz que le permite controlar la computadora escribiendo comandos de texto directamente en lugar de una interfaz gráfica.

## Definición
Actúa como un puente entre usted y el núcleo del sistema operativo. Puede administrar archivos, ejecutar programas y cambiar la configuración del sistema escribiendo comandos desde el teclado en lugar de usar un mouse. Es el espacio de trabajo más básico y potente para desarrolladores de software.

## Cómo funciona
Abres una pantalla negra y escribes ciertos comandos allí. Por ejemplo, cuando escribe 'ls' y presiona Intro, se le presentará una lista de todos los archivos en la carpeta en la que se encuentra actualmente.

## Dónde se usa
Está integrado en todos los sistemas de Linux, macOS y Windows; Es indispensable para los procesos de desarrollo de software.

## Suele confundirse con
Se confunde con la terminal; terminal es la ventana que muestra esta interfaz y shell es el intérprete de comandos que se ejecuta dentro de esa ventana.

## Preguntas frecuentes
**¿Es difícil aprender Shell?**
Puede parecer un poco desconocido al principio, pero una vez que aprende algunos comandos básicos, administrar la computadora se vuelve mucho más rápido.
