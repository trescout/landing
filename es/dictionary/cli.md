# ¿Qué es CLI?

*Glosario · Dev · Última actualización: 3 de junio de 2026*

> Command Line Interface

Es un método de dar órdenes al ordenador a través de textos escritos.

## Definición

CLI es un método para administrar la computadora escribiendo comandos basados ​​en texto en lugar de hacer clic con el mouse. Es una herramienta de control rápida y muy poderosa, especialmente para desarrolladores de software.

***Analogía:** Es como si el chef dictara directamente una receta personalizada, en lugar de elegir una comida de un menú.*

## Cómo funciona

Se abre una pantalla negra y allí se escriben ciertos comandos. La computadora lee estos comandos y los ejecuta instantáneamente.

## Dónde se usa

Se utiliza en procesos de desarrollo de software, gestión de servidores y para ejecutar modelos de inteligencia artificial en el ordenador local.

## Suele confundirse con

Se confunde con una interfaz gráfica (GUI), pero la CLI está completamente basada en texto y ofrece mucha más personalización.

## Preguntas frecuentes

**¿Es necesario aprender CLI?**

Aunque no es imprescindible para la mayoría de herramientas modernas, aporta una gran velocidad para trabajar a nivel profesional.

**¿Qué sucede si escribo el comando incorrecto?**

El sistema suele dar errores, pero también hay comandos críticos que requieren precaución.
