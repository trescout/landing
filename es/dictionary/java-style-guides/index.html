¿Qué es Java Style Guides?

Un conjunto de estándares y reglas que se utilizan para garantizar que los códigos escritos en Java estén organizados y sean legibles.

Definición

Estas guías garantizan que los desarrolladores hablen el mismo idioma y que todos entiendan fácilmente el código. Documentos como la Guía de estilo de Google Java y las convenciones de código Sun especifican cada detalle, desde los nombres de las variables hasta el uso de espacios. Un buen código es un código que no sólo puede ejecutar una computadora, sino que también un humano puede leer.

Analogía: Es como las reglas ortográficas y la guía ortográfica de un idioma; Si todos siguen las mismas reglas, el texto será mucho más fácil de leer.

Cómo funciona

Los programadores utilizan estas guías como lista de verificación al escribir código. Las herramientas automatizadas pueden verificar si su código cumple con estos estándares.

Dónde se usa

Se utiliza en proyectos de software corporativo, proyectos de código abierto y revisiones de código dentro del equipo.

Suele confundirse con

No confundir con la funcionalidad del código; Estas guías regulan la apariencia del código, no cómo funciona.

Preguntas frecuentes

¿Por qué debería seguir estas reglas?

Es necesario que sus compañeros de equipo comprendan rápidamente su código y encuentren errores más fácilmente.

¿Qué guía debo elegir?

Por lo general, debes seguir las pautas estándar establecidas por el proyecto o la institución para la que trabajas.
