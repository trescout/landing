# ¿Qué es Adversarial Analysis?

Son pruebas de seguridad realizadas imitando ataques maliciosos para encontrar los puntos débiles de un sistema.

## Definición
Este método se utiliza para comprender qué tan duradero es un software o una inteligencia artificial. Los expertos en seguridad envían deliberadamente información incorrecta o engañosa para que el sistema cometa errores o eluda sus defensas. El objetivo es prever cómo reaccionará el sistema en caso de un ataque real.

## Cómo funciona
Se envían al sistema datos inesperados, comandos incorrectos o preguntas manipuladoras. Se analizan las respuestas dadas por el sistema y donde se mapean las vulnerabilidades de seguridad.

## Dónde se usa
Se utiliza para garantizar la seguridad de modelos de inteligencia artificial, auditorías de ciberseguridad y procesos de desarrollo de software.

## Suele confundirse con
No debe confundirse simplemente con depurar; Aquí, la atención se centra en la presencia de un actor malicioso.

## Preguntas frecuentes
**¿Por qué hacemos esta prueba?**
Se hace para probar el sistema ante atacantes reales y cerrar sus vulnerabilidades.

**¿Cómo funciona en la inteligencia artificial?**
La resistencia se mide haciendo al modelo preguntas que lo engañarán o lo obligarán a responder de manera poco ética.
