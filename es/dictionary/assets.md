# ¿Qué es Assets?

Es el conjunto de todas las partes digitales que componen un proyecto.

## Definición
Cualquier recurso externo que utilice al desarrollar software o juegos se denomina "activos". Estos no son el código en sí, sino los materiales auxiliares que necesita el código. Son la materia prima visual, sonora o estructural de un proyecto.

## Cómo funciona
Se guardan en carpetas separadas dentro de los archivos de su proyecto y puede llamarlos haciendo referencia a estos archivos mientras escribe el código.

## Dónde se usa
Se utiliza en todos los proyectos de desarrollo de juegos, diseño web y aplicaciones móviles.

## Preguntas frecuentes
**¿Los archivos de código se consideran activos?**
Generalmente no, mientras que el código se considera la estructura principal; Los elementos visuales, los sonidos y los modelos 3D se clasifican como activos.
