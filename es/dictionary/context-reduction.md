# ¿Qué es Context Reduction?

Es el proceso de resumir la enorme información proporcionada a la inteligencia artificial purificándola de detalles innecesarios para que el modelo funcione más rápido y con mayor precisión.

## Definición
La cantidad de información que los modelos de inteligencia artificial pueden procesar al mismo tiempo es limitada. La reducción de contexto mejora el rendimiento del modelo al preservar información importante y limpiar partes innecesarias que distraerán el modelo. Este proceso reduce los costos y garantiza que las respuestas estén más enfocadas.

## Cómo funciona
Los datos entrantes pasan primero por un algoritmo de filtrado o resumen. Luego, solo se presenta al sistema la información básica necesaria para que el modelo tome una decisión.

## Dónde se usa
Se utiliza en sistemas RAG, análisis de documentos de gran tamaño y conversaciones de larga duración.

## Suele confundirse con
No se trata solo de acortar los datos, sino de elegirlos sabiamente y formatearlos en un formato que el modelo pueda comprender.

## Preguntas frecuentes
**¿Habrá pérdida de información?**
Cuando se hace correctamente, sólo se descartan las piezas innecesarias, a las que llamamos ruido, pero si se ajusta incorrectamente se pueden perder detalles importantes.
