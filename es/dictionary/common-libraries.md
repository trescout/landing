# ¿Qué es Common Libraries?

Paquetes de código preparados previamente para que los desarrolladores de software puedan realizar fácilmente operaciones utilizadas con frecuencia.

## Definición
Se trata de soluciones listas para usar que se utilizan para evitar reinventar la rueda cada vez que se desarrolla software. Estas bibliotecas le permiten realizar muchas tareas complejas, desde operaciones matemáticas hasta gestión de archivos, con un solo comando. Agregarlo a su proyecto ahorra tiempo y reduce el riesgo de errores.

## Cómo funciona
Incluye la biblioteca que necesita en su proyecto y llama a las funciones listas para usar en su propio código.

## Dónde se usa
Se utiliza en casi todos los proyectos de software, como el procesamiento de datos, las conexiones de red o la creación de interfaces visuales.

## Suele confundirse con
Se puede confundir con Framework; El marco dibuja el esqueleto del proyecto y la biblioteca le ofrece solo la herramienta que necesita.

## Preguntas frecuentes
**¿Todas las bibliotecas son seguras?**
No, como cualquier código externo, se debe verificar que las bibliotecas estén actualizadas y sean confiables.

**¿Puedo hacer mi propia biblioteca?**
Sí, puedes empaquetar los códigos que usas con frecuencia y reutilizarlos en tus otros proyectos.
