# ¿Qué es Dashboard?

*Glosario · Dev · Última actualización: 22 de junio de 2026*

Panel que permite realizar un seguimiento visual de datos y estadísticas complejas en una sola pantalla.

## Definición

El tablero es como un panel de control digital. Resume el estado actual, el rendimiento y los datos importantes de un sistema o aplicación con gráficos o tablas. Simplifica la información compleja y permite comprenderla rápidamente.

***Analogía:** Es como el tablero de un automóvil; Puede ver la velocidad, el estado del combustible y la temperatura del motor de un vistazo.*

## Cómo funciona

Generalmente se alimenta de una fuente de la que se recopilan datos. Los desarrolladores de software presentan estos datos al usuario mediante bibliotecas de visualización. Sólo miras la pantalla y analizas qué está pasando y cómo.

## Dónde se usa

Se utiliza en el mundo empresarial para realizar un seguimiento de gráficos de ventas, monitorear el rendimiento del servidor o para aplicaciones de presupuesto personal.

## Suele confundirse con

Puede confundirse con informes, pero el panel proporciona datos en vivo e interactivos.

## Preguntas frecuentes

**¿El panel muestra datos en vivo?**

Sí, normalmente refleja el estado actual del sistema al instante.

**¿Alguien puede hacer un tablero?**

Sí, puedes visualizar tus propios datos con herramientas sencillas.
