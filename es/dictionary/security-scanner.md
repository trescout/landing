# ¿Qué es Security Scanner?

*Glosario · Dev · Última actualización: 15 de junio de 2026*

Es una herramienta que detecta automáticamente vulnerabilidades en software o sistemas de red.

## Definición

Un escáner de seguridad examina sus sistemas digitales como un detective. Comprueba si has dejado abiertas las puertas o ventanas de tu sistema e informa de tus vulnerabilidades ante posibles ciberataques. Estas herramientas escanean códigos de software complejos o tráfico de red para encontrar errores que el ojo humano podría pasar por alto.

***Analogía:** Es como si un experto en seguridad profesional revisara todas las cerraduras de puertas y ventanas antes de ingresar a su casa.*

## Cómo funciona

Conecta el escáner a su sistema e inicia un escaneo. La herramienta compara archivos o paquetes de red en su sistema con bases de datos de amenazas conocidas. Le presenta una lista de cada situación sospechosa que encuentra y, por lo general, le brinda sugerencias sobre cómo cerrar la brecha.

## Dónde se usa

Se utiliza en procesos de desarrollo de software, gestión de servidores y auditorías de ciberseguridad de empresas.

## Suele confundirse con

Se utiliza con el mismo propósito que el escaneo de vulnerabilidades, pero este término se centra directamente en el vehículo.

## Preguntas frecuentes

**¿El escáner de seguridad encuentra todas las vulnerabilidades?**

No, sólo puede encontrar vulnerabilidades definidas en la base de datos o que se ajustan a ciertos patrones.

**¿Estas herramientas ralentizan el sistema?**

Pueden utilizar recursos del sistema durante análisis en profundidad, por lo que normalmente se ejecutan durante las horas de menor actividad.
