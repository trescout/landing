# ¿Qué es Markdown?

*Glosario · Dev · Última actualización: 3 de junio de 2026*

Un lenguaje de formato ligero utilizado para dar formato al texto, permitiendo escribir con caracteres simples.

## Definición

Markdown es un lenguaje de marcado ligero y sencillo para formatear textos sin escribir códigos complejos. Le permite realizar ediciones como títulos, listas o letras en negrita mientras escribe con unos pocos caracteres simples.

***Analogía:** Es como formatear rápidamente, como tomar notas con un bolígrafo sobre papel, en lugar de jugar con los menús en un editor de texto.*

## Cómo funciona

Se añaden al texto caracteres como asteriscos o signos de almohadilla. Por ejemplo, cuando pones un asterisco al principio y al final de una palabra, el sistema la convierte automáticamente a texto en cursiva.

## Dónde se usa

Es el método preferido por los desarrolladores de software al escribir documentación, crear contenido en aplicaciones para tomar notas o sitios web.

## Suele confundirse con

Se confunde con HTML, pero mientras HTML es mucho más complejo y detallado, Markdown está diseñado únicamente para mejorar la legibilidad.

## Preguntas frecuentes

**¿Por qué debería utilizar Markdown en lugar de Word?**

Markdown es mucho más rápido, distrae menos y se puede ver fácilmente en cualquier plataforma.

**¿Cómo abro archivos Markdown?**

Puedes abrirlo con cualquier editor de texto, pero puedes leerlo formateado más fácilmente con visores especiales.
