¿Qué es Clean Code?

El código limpio es el código que los humanos pueden leer.

Definición y origen de la palabra

La máquina ejecuta todos los códigos, un humano no puede leer todos los códigos. Un nombre significativo, una función pequeña y un flujo simple aportan legibilidad. Robert Martin es el nombre de referencia de esta disciplina.

Analogía: Es como tener los estantes de una biblioteca ordenados por género y autor.

¿Cómo saberlo y utilizarlo en la vida diaria?

Equipo: Base de código común.
Revisión: Comprobación de legibilidad.
Cuidado: Volviendo al código antiguo.

Profundidad técnica y arquitectura

Principios:

Nombre: El nombre que expresa la intención.
Dimensión: Función laboral única.
De nuevo: La pieza común está en un solo lugar.

Ejemplo:

# önce
def h(a, b):
    return a + a*b
# sonra
def indirimli_fiyat(fiyat, oran):
    return fiyat + fiyat * oran

Regla: ejecutar el código es el primer paso, leer el código es el segundo paso.

Uso en diferentes disciplinas

Mesa: Área de trabajo ordenada.
Estantes: Ordenado por género y autor.
Jardín: Arreglo de ramas podadas.

Preguntas frecuentes

¿No es suficiente con trabajar?

No es suficiente. El código de trabajo se guarda hoy, el código de lectura se guarda mañana.

¿Lo ralentiza?

Al principio si, en mantenimiento no. Genera dinero en total.

¿Cómo se mide?

Con tiempo de revisión y tasa de error. El número por sí solo no es suficiente.

¿Por dónde empezar?

De nombre y función. El código tocado se borra.
