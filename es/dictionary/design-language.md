# ¿Qué es Design Language?

Es un conjunto de reglas que mantienen consistente el mundo visual y la experiencia del usuario de un producto.

## Definición
Los lenguajes de diseño son estándares establecidos sobre cómo debe verse y sentirse un software o producto. Garantiza que elementos como paletas de colores, fuentes, formas de botones y uso del espaciado sean compatibles entre sí. De esta forma, el usuario se encuentra con una interfaz familiar y habitual cada vez que abre la aplicación.

## Cómo funciona
Los diseñadores crean una guía y los desarrolladores ponen estas reglas en código. Esto evita que el diseño se deteriore cada vez que se agrega una nueva característica. Gracias a esta coherencia, los usuarios aprenden la aplicación más fácilmente.

## Dónde se usa
Se utiliza en sitios web, aplicaciones móviles y todas las plataformas digitales donde se crea la identidad de marca.

## Suele confundirse con
No es sólo un tema visual, es un sistema que cubre toda la lógica de interacción de un producto.

## Preguntas frecuentes
**¿Por qué es importante?**
Evita que el usuario se confunda al utilizar la aplicación y proporciona una experiencia profesional.

**¿Qué significa para los desarrolladores de software?**
Elimina la necesidad de realizar un nuevo diseño cada vez y permite un progreso rápido combinando piezas predefinidas.
