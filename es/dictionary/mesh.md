# ¿Qué es Mesh?

Múltiples dispositivos o servicios interconectados intercambian datos sin necesidad de un punto central.

## Definición
En la estructura de malla, cada nodo puede comunicarse directamente entre sí. El sistema es más duradero porque no depende de un servidor central. Incluso si un nodo cae, los datos continúan transmitiéndose a través de otras rutas.

## Cómo funciona
Los dispositivos o servicios se descubren entre sí y establecen una red entre ellos.

## Dónde se usa
Se utiliza en redes inalámbricas, sistemas domésticos inteligentes y arquitecturas de microservicios.

## Preguntas frecuentes
**¿Cuál es la ventaja de las redes en malla?**
Al no estar conectados a un único punto, el riesgo de colapso del sistema es mucho menor.
