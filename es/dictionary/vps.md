# ¿Qué es VPS?

> Virtual Private Server

Es el uso de un potente servidor físico en Internet alquilándolo como ordenador privado.

## Definición
VPS se crea mediante un software que divide un servidor enorme en partes pequeñas. Cada parte opera independientemente de otros usuarios porque tiene su propio sistema operativo y recursos. De esta forma podrás instalar y gestionar cualquier software que desees como si tuvieras tu propio servidor.

## Cómo funciona
Alquila un VPS de un proveedor de la nube, luego se conecta a su servidor mediante métodos de acceso remoto y realiza las configuraciones deseadas.

## Dónde se usa
Se utiliza para alojar sitios web, configurar sistemas personales en la nube o crear entornos de prueba.

## Suele confundirse con
Puede confundirse con hosting compartido; En el alojamiento compartido, compartes recursos con otros, mientras que en VPS, los recursos que se te asignan están garantizados.

## Preguntas frecuentes
**¿Se requieren conocimientos técnicos para gestionar VPS?**
Sí, se requieren conocimientos técnicos básicos para la administración del servidor y la configuración de seguridad.
