# ¿Qué es Instances?

Es cada copia independiente de un software o sistema que se ejecuta al mismo tiempo.

## Definición
En el mundo de la informática, cuando inicias un programa, se crea una 'instancia' de ese programa en la memoria. Si abres tres ventanas diferentes del mismo programa, habrás ejecutado tres copias (instancias) distintas de ese programa. Cada una es independiente de las demás y mantiene sus propios datos.

## Cómo funciona
Los recursos del sistema reservan un espacio separado para cada copia. De esta manera, si ocurre un error en una copia o el programa se bloquea, las otras copias pueden seguir funcionando sin verse afectadas.

## Dónde se usa
Se utiliza con mucha frecuencia en la computación en la nube, la gestión de servidores y los servidores de juegos.

## Suele confundirse con
No debe confundirse con el programa en sí (código fuente); el código fuente es único, mientras que las copias en ejecución pueden ser ilimitadas.

## Preguntas frecuentes
**¿Por qué ejecutamos más de una copia?**
Se utiliza para distribuir la carga, aumentar la seguridad o gestionar las tareas de diferentes usuarios al mismo tiempo.
