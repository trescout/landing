# ¿Qué es Home Server?

Es un servidor personal siempre activo que maneja tareas como compartir archivos y administrar medios de dispositivos domésticos.

## Definición
Es una computadora que funciona 24 horas al día, 7 días a la semana y juega un papel central en tu hogar. Le permite crear su propia nube, hacer copias de seguridad de sus archivos o administrar contenido multimedia dentro del hogar.

## Cómo funciona
Se crea instalando el software necesario en una computadora vieja, dispositivos pequeños como Raspberry Pi o hardware de servidor especial.

## Dónde se usa
Se utiliza en servidores de medios, administración de hogares inteligentes y sistemas de respaldo personal.

## Suele confundirse con
Puede confundirse con una simple computadora de escritorio, pero este dispositivo está especializado para trabajar y brindar un servicio continuo.

## Preguntas frecuentes
**¿Por qué necesito un servidor?**
Para obtener control total sobre sus datos y evitar tarifas de suscripción.

**¿Consume mucha electricidad?**
Consume muy poca energía cuando se utiliza con dispositivos pequeños (como Raspberry Pi).
