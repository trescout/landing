# ¿Qué es Superset?

Es una estructura más completa que incluye todas las características de un sistema existente y agrega nuevas capacidades.

## Definición
Cuando algo es un superconjunto, significa que incluye todo lo que está debajo de él. Por ejemplo, otro lenguaje, que es un superconjunto de un lenguaje de programación, puede ejecutar todo el código del primer lenguaje pero ofrece nuevas características adicionales. Esto se utiliza para mejorar el sistema manteniendo la compatibilidad con versiones anteriores.

## Cómo funciona
Al diseñar un nuevo lenguaje o herramienta, se conservan las reglas existentes y se construyen nuevas capas sobre ellas para no alterar los hábitos de los usuarios antiguos.

## Dónde se usa
Se utiliza con frecuencia en lenguajes de programación (por ejemplo, TypeScript es un superconjunto de JavaScript) y arquitecturas de software.

## Preguntas frecuentes
**¿Es ventajoso utilizar superconjunto?**
Sí, porque te permite cambiar a nuevas tecnologías sin desechar los códigos escritos con el sistema antiguo.
