# ¿Qué es User Interface?

> UI

Es el área de control y visualización visual que permite al usuario interactuar con un dispositivo o software.

## Definición
Es el puente entre usted y un software en el mundo digital. Todo lo que ve, como botones, menús, íconos y cuadros de texto, es parte de esta interfaz. Una buena interfaz le permite realizar fácilmente incluso operaciones complejas.

## Cómo funciona
Los diseñadores dibujan estas pantallas analizando lo que necesitan los usuarios. Luego, los desarrolladores de software transforman estos dibujos en una estructura que funciona con códigos. El diseño visual resultante traduce sus comandos a un idioma que la computadora puede entender.

## Dónde se usa
Aparece en aplicaciones de su teléfono inteligente, en sitios web o en las pantallas táctiles de sus dispositivos domésticos inteligentes.

## Suele confundirse con
A menudo se confunde con el backend del software, pero la interfaz es sólo la parte que ves.

## Preguntas frecuentes
**¿Son UI y UX lo mismo?**
No, la UI cubre las partes visuales (color, botón), mientras que la UX trata sobre cómo se siente el usuario y qué tan cómodo se siente al usar esa interfaz.
