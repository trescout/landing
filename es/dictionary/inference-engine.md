# ¿Qué es Inference Engine?

Un motor de software que utiliza un modelo de inteligencia artificial entrenado para producir predicciones o resultados basados en los nuevos datos que se le proporcionan.

## Definición
Una vez entrenados los modelos de inteligencia artificial, el mecanismo que funciona en segundo plano mientras se utilizan en vivo se denomina motor de inferencia. Este motor proporciona respuestas rápidas y precisas a las preguntas utilizando los pesos del modelo. El cerebro del modelo es este motor, las cuerdas vocales que le permiten hablar.

## Cómo funciona
Los archivos de modelo se cargan en el sistema y el motor de inferencia procesa las solicitudes entrantes optimizando estos archivos. Garantiza que la respuesta le llegue mediante el uso de recursos de hardware (GPU/CPU) de la manera más eficiente.

## Dónde se usa
Está disponible en servicios de IA, API basadas en la nube y aplicaciones de IA que se ejecutan localmente.

## Suele confundirse con
Se confunde con el modelo mismo; El modelo es la información, el motor es el sistema que utiliza esta información.

## Preguntas frecuentes
**¿Por qué utilizamos un motor separado?**
Porque los modelos en bruto son muy grandes; Los motores los aceleran y optimizan.

**¿Afecta mi velocidad?**
Sí, un buen motor de inferencia hace que el modelo responda más rápido.
