# ¿Qué es Data Logger?

Es un dispositivo electrónico que registra y almacena datos de sensores a intervalos regulares.

## Definición
Un registrador de datos monitorea constantemente los cambios físicos en su entorno y almacena esta información junto con marcas de tiempo. Estos dispositivos se suelen utilizar para rastrear datos como la temperatura, la humedad o el movimiento. Estos datos recopilados luego se analizan para comprender cómo funciona el sistema.

## Cómo funciona
Colocas el dispositivo donde quieres monitorearlo y este escribe datos en su memoria interna o en una computadora. Luego podrá abrir estos registros y examinar lo que sucedió en el pasado.

## Dónde se usa
Se utiliza para monitorear el estado de las máquinas en fábricas, rastrear resultados de experimentos en laboratorios o medir el consumo de energía en sistemas domésticos inteligentes.

## Suele confundirse con
Se puede confundir con una base de datos, pero este dispositivo es más bien el hardware físico en la etapa de recopilación de datos sin procesar.

## Preguntas frecuentes
**¿Cómo almacena datos un registrador de datos?**
Generalmente se guarda en una tarjeta de memoria interna o directamente en la base de datos de una computadora a la que está conectado.

**¿Cada sensor es un registrador de datos?**
No, el sensor simplemente detecta los datos; El registrador de datos es una unidad superior que asocia estos datos con el tiempo y los registra.
