# ¿Qué es Working Memory?

Es el área de la memoria a corto plazo donde la inteligencia artificial guarda temporalmente la información durante el procesamiento.

## Definición
La memoria de trabajo es donde la IA mantiene activo el contexto actual y los datos necesarios mientras realiza una tarea. Esta información suele borrarse cuando finaliza la tarea o cambia el contexto.

## Cómo funciona
Ocurre cuando el modelo mantiene datos de entrada y resultados intermedios en su memoria para un acceso rápido dentro del ciclo de procesamiento actual.

## Dónde se usa
Se utiliza para preservar el historial de chat y procesos de razonamiento complejos.

## Suele confundirse con
Su diferencia con la memoria a largo plazo es que se limita únicamente a la tarea actual.

## Preguntas frecuentes
**¿Qué sucede si la memoria de trabajo se llena?**
El modelo comienza a olvidar información antigua o puede perder contexto.
