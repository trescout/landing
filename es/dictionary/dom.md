# ¿Qué es DOM?

*Desarrollo · Última actualización: 19 de noviembre de 2026*

> Document Object Model

Estructura jerárquica que permite al navegador procesar y gestionar el contenido de las páginas web.

## Definición

El DOM es el sistema que permite almacenar los sitios web en la memoria en segundo plano con una estructura de árbol. Convierte las etiquetas HTML en objetos que lenguajes como JavaScript pueden modificar fácilmente. Así, pueden ocurrir eventos dinámicos, como que la página cambie sin recargarse al hacer clic en un botón.

***Analogía:** Es como el plano arquitectónico de un edificio. Cuando quieres hacer un cambio en la instalación eléctrica o de agua, en lugar de romper las paredes principales, miras el plano para encontrar la válvula o el cable correspondiente y actuar sobre él.*

## Cómo funciona

En el momento en que el navegador descarga y lee el código del sitio web, crea esta estructura jerárquica en la memoria. Al escribir código, los desarrolladores pueden apuntar a esta estructura para actualizar instantáneamente el texto o las imágenes de la página. Cada etiqueta HTML se posiciona como una rama o una hoja de este árbol.

## Dónde se usa

Funciona continuamente en segundo plano en todos los sitios web y aplicaciones web modernos que se ejecutan en navegadores web.

## Suele confundirse con

Se puede confundir con el código HTML bruto que proviene del servidor. Mientras que el HTML es solo un documento de texto, el DOM es la versión en la que el navegador ha transformado ese documento en un objeto vivo.

## Preguntas y respuestas

**¿Existe el DOM en todos los sitios web?**

Sí, esta estructura siempre opera detrás de cada página visual abierta en el navegador.

**¿Se puede modificar el DOM directamente?**

Es posible cambiar esta estructura al instante y dar vida a la página utilizando JavaScript.
