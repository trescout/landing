# ¿Qué es DNS?

*Desarrollo · Última actualización: 23 de octubre de 2026*

> Domain Name System

Es el sistema de directorio global que traduce los nombres de dominio de Internet a direcciones IP numéricas que permiten que las computadoras se encuentren entre sí.

## Definición

El Sistema de Nombres de Dominio (DNS) es un protocolo de red que permite el uso de nombres de sitios web significativos en lugar de direcciones IP complejas que serían difíciles de recordar para las personas. Cuando escribe una dirección en su navegador, los servidores DNS entran en acción para asociar este nombre con la dirección IP del servidor correcto. Como uno de los pilares fundamentales de la infraestructura de Internet, garantiza una comunicación ininterrumpida.

***Analogía:** Es similar a buscar el nombre de una persona en la agenda telefónica para obtener su número y realizar la llamada a través de ese número.*

## Cómo funciona

Cuando un usuario ingresa un nombre de dominio en el navegador, la solicitud se transmite primero a la caché DNS local y luego, progresivamente, a los servidores DNS autorizados. Cuando se encuentra la dirección IP correcta, se devuelve al navegador y se establece la conexión. Este proceso de consulta suele completarse en milisegundos.

## Dónde se usa

Se utiliza al acceder a sitios web, en infraestructuras de transmisión de correo electrónico y en el enrutamiento entre servidores en la nube.

## Suele confundirse con

A menudo se confunde con el concepto de dirección IP. La dirección IP es la identidad numérica real del dispositivo, mientras que el DNS es el sistema que asocia esta identidad con nombres legibles para los humanos.

## Preguntas y respuestas

**¿Se puede acceder a Internet si el DNS colapsa?**

Los nombres de dominio no se pueden resolver, pero si se conocen las direcciones IP directas de los sitios, se puede acceder a ellos a través del navegador.

**¿Qué es la caché DNS?**

Es el almacenamiento temporal en el dispositivo de las direcciones IP de los sitios visitados con frecuencia; por lo tanto, se elimina la necesidad de consultar al servidor cada vez.
