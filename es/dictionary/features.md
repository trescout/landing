# ¿Qué es Features?

Las distintas capacidades y funciones que un software o producto ofrece a los usuarios.

## Definición
Las características son características que definen lo que puede hacer una aplicación. Por ejemplo, en una aplicación de edición de fotografías, "corregir ojos rojos" o "aplicar un filtro" son funciones. Estas características incorporan los beneficios que el producto proporciona al usuario.

## Cómo funciona
Los desarrolladores deciden qué funciones agregar al software analizando las necesidades de los usuarios. Estas funciones están codificadas, probadas y ofrecidas al usuario con actualizaciones.

## Dónde se usa
Se utiliza frecuentemente en procesos de desarrollo de software, reuniones de gestión de productos y promociones de aplicaciones.

## Suele confundirse con
Puede confundirse con Herramienta; Una característica es parte del producto, mientras que una herramienta es un ayudante externo que se utiliza para realizar el trabajo.

## Preguntas frecuentes
**¿Todas las funciones son buenas?**
No, a veces agregar demasiadas funciones complica la aplicación y crea bloatware.
