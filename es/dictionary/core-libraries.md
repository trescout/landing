# ¿Qué es Core Libraries?

*Glosario · Dev · Última actualización: 7 de agosto de 2026*

Son paquetes de código estándar que un software necesita para realizar sus funciones básicas.

## Definición

Las bibliotecas principales son bibliotecas de código listas para usar que contienen los componentes básicos más básicos de un lenguaje o plataforma de programación. Estas bibliotecas permiten a los desarrolladores realizar rápidamente operaciones estándar en lugar de escribir código desde cero cada vez. Al igual que las columnas de los cimientos de un edificio, son piezas indispensables que garantizan que el software sobreviva y funcione correctamente.

***Analogía:** Es como las especias básicas y los utensilios de cocina básicos en una cocina; No hace falta que inventes la sal cada vez que cocinas, puedes completar la receta con estas herramientas básicas que tienes a mano.*

## Cómo funciona

Al incluir estas bibliotecas en sus proyectos, los desarrolladores pueden manejar operaciones matemáticas complejas, gestión de datos u operaciones de archivos con comandos de una sola línea.

## Dónde se usa

Se utiliza en casi todos los lenguajes de programación y desarrollos de sistemas operativos.

## Suele confundirse con

Puede confundirse con Framework o SDK, pero las bibliotecas principales se refieren a la funcionalidad básica y los frameworks se refieren a un esqueleto de aplicación más amplio.

## Preguntas frecuentes

**¿Por qué son importantes las bibliotecas principales?**

Acelera el proceso de desarrollo de software, reduce los errores y garantiza un funcionamiento del código más estable.
