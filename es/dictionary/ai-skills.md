# ¿Qué es AI Skills?

> Skills

Capacidades o herramientas especiales que utilizan los modelos de IA para realizar una tarea específica.

## Definición
Son habilidades o herramientas especiales que utilizan los modelos de inteligencia artificial para realizar una tarea específica. Estas capacidades permiten que el modelo realice tareas concretas, como buscar en Internet o ejecutar código, en lugar de simplemente producir texto.

## Cómo funciona
El modelo aprende a utilizar conjuntos de comandos especiales o herramientas definidas para él. Activa estas herramientas cuando es necesario, procesa los datos y presenta el resultado al usuario.

## Dónde se usa
Se utiliza en asistentes inteligentes, herramientas de análisis de datos y software que automatiza tareas complejas.

## Suele confundirse con
A menudo se confunde con las capacidades generales de la IA, pero se trata de herramientas especializadas que se añaden para realizar un trabajo específico.

## Preguntas frecuentes
**¿Todos los modelos de IA tienen habilidades de IA?**
No, sólo los modelos equipados con estas capacidades o autorizados para conducir tienen estas capacidades.

**¿Se pueden agregar estas habilidades más adelante?**
Sí, se pueden agregar nuevas capacidades a un modelo con la infraestructura y las conexiones API adecuadas.
