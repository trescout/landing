# ¿Qué es Auto-fallback?

*Glosario · Dev · Última actualización: 25 de julio de 2026*

Cuando ocurre un error en un sistema o el método principal falla, el sistema cambia automáticamente a un método alternativo o más seguro.

## Definición

El respaldo automático garantiza que el sistema no se "rinda". Por ejemplo, cuando su modelo de IA más avanzado no responde, el sistema cambia automáticamente a un modelo más rápido pero más simple para completar el proceso. Esta es una medida de seguridad fundamental para garantizar que la experiencia del usuario continúe sin interrupciones.

***Analogía:** Es como cuando falla el motor principal de tu auto, automáticamente cambia al motor eléctrico con batería de respaldo y no te deja tirado.*

## Cómo funciona

El software incluye una regla de "si no funciona, haz esto". El sistema verifica constantemente el estado y activa el método de respaldo cada vez que el método principal devuelve un código de error.

## Dónde se usa

Se utiliza en servicios de inteligencia artificial, conexiones de red y gestión de servidores.

## Suele confundirse con

Es similar al manejo de errores; Sin embargo, el respaldo automático se refiere directamente a una solución alternativa.

## Preguntas frecuentes

**¿Esta característica causa lentitud?**

A veces, el proceso de transición puede provocar un retraso de milisegundos, pero es mejor que detener completamente el sistema.

**¿Siempre funciona?**

Si el método de copia de seguridad también es defectuoso, el sistema seguirá fallando, por lo que las copias de seguridad también deben ser fiables.
