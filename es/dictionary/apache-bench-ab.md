# ¿Qué es ab (ApacheBench)?

*Glosario · Dev · Última actualización: 1 de octubre de 2026*

> ApacheBench

Una herramienta de prueba de rendimiento sencilla que sirve para medir cuántas personas puede soportar un servidor web al mismo tiempo.

## Definición

Cuando creas un sitio web, te preguntas cuántos visitantes puede soportar al mismo tiempo. ApacheBench, o ab para abreviar, se ejecuta desde la línea de comandos y envía cientos de solicitudes falsas a tu servidor simultáneamente. De este modo, puedes ver de antemano cuándo tu servidor se va a bloquear o ralentizar.

***Analogía:** Es como hacer una prueba de entrada simultánea para ver si la puerta de una cafetería que acabas de abrir resistirá cuando cien personas se agolpen en la entrada al mismo tiempo.*

## Cómo funciona

Abres la pantalla de la terminal y escribes los comandos que especifican la dirección web que quieres probar y cuántas solicitudes deseas enviar. La herramienta te proporciona un informe numérico con la cantidad de transacciones que puedes realizar por segundo.

## Dónde se usa

Se utiliza para medir el rendimiento del servidor, justo antes de que se espere una gran ola de tráfico o para realizar una prueba de velocidad después de la optimización del sistema.

## Preguntas frecuentes

**¿Imita a un usuario real?**

No exactamente, solo bombardea el objetivo con solicitudes muy rápido, una tras otra.

**¿Solo funciona en servidores Apache?**

No, aunque se llame ApacheBench, puede probar cualquier dirección web accesible en internet.
