# ¿Qué es Multi-tenancy?

*Glosario · Dev · Última actualización: 30 de junio de 2026*

Es la capacidad de un solo software de brindar servicios independientes a muchos usuarios o empresas diferentes al mismo tiempo.

## Definición

Piense en un edificio de apartamentos; Todos usan el mismo edificio, pero cada uno tiene su propio apartamento. En el mundo del software, multitenencia significa que diferentes clientes que comparten el mismo servidor y el mismo programa trabajan en sus propias áreas sin ver los datos de los demás.

***Analogía:** Es como en un hotel donde todos usan el mismo edificio y la misma piscina, pero cada uno tiene su propia habitación privada.*

## Cómo funciona

El software asigna a cada usuario una "etiqueta" única en la base de datos. El sistema relaciona una solicitud de un usuario solo con datos con esa etiqueta, por lo que no hay confusión.

## Dónde se usa

Se utiliza en plataformas SaaS (software como servicio), aplicaciones basadas en la nube y software de gestión empresarial.

## Suele confundirse con

Puede confundirse con un servidor compartido; Sin embargo, lo que se comparte aquí no es sólo el hardware, sino también la estructura lógica del software.

## Preguntas frecuentes

**¿Por qué utilizar un solo programa?**

Porque instalar un programa independiente para cada usuario es muy costoso y difícil de gestionar; Es mucho más fácil actualizar desde un único centro.
