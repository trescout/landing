# ¿Qué es Nameservers?

Es una guía telefónica que convierte los nombres de sitios web utilizados por las personas en direcciones numéricas que las computadoras entienden.

## Definición
Cada sitio web en Internet tiene en realidad un equivalente numérico llamado dirección IP. El servidor de nombres, cuando escribe un nombre en su navegador, dirige este nombre a la dirección IP relevante, lo que le permite llegar al servidor correcto. Este es el sistema de libreta de direcciones de Internet.

## Cómo funciona
Cuando escribe una dirección web, su computadora pregunta a los servidores de nombres: ¿Cuál es la dirección numérica de este nombre? El servidor de nombres devuelve la respuesta y su navegador se conecta a esa dirección.

## Dónde se usa
Está ubicado centralmente en la configuración de nombres de dominio y en las infraestructuras de los proveedores de servicios de Internet.

## Suele confundirse con
Puede confundirse con hosting; El alojamiento es donde se almacenan los archivos de su sitio y el servidor de nombres es el camino para llegar allí.

## Preguntas frecuentes
**¿Qué hace cambiar la configuración del servidor de nombres?**
Por lo general, cuando mueve su sitio web a un servidor diferente, actualiza esta configuración para que el tráfico vaya a la nueva ubicación.

**¿Qué pasa si el servidor de nombres falla?**
No puede acceder a sitios web por su nombre porque su navegador de Internet no puede encontrar dónde se encuentra el sitio.
