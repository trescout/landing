¿Qué es Native Binaries?

Son archivos de programa compilados para ejecutarse directamente en un sistema operativo y una arquitectura de procesador espec\u00edficos.

Definición

Los binarios nativos son archivos que permiten que el c\u00f3digo escrito sea comprendido directamente por el hardware de la computadora sin necesidad de ningn software intermediario. Dado que estos archivos se preparan espec\u00edficamente para el sistema operativo y el tipo de procesador de destino, ofrecen el mximo rendimiento. A diferencia de lenguajes como Java o Python, no requieren una mquina virtual o un intrprete instalado en la computadora para funcionar.

Analogía: Puedes comparar esto con conversar directamente con una persona que habla tu misma lengua materna sin necesidad de un traductor. No hay pérdida de tiempo y te comunicas directamente.

Cómo funciona

Los desarrolladores convierten su código escrito directamente en lenguaje de máquina con la ayuda de herramientas llamadas compiladores. Durante este proceso, se especifica el hardware de destino y el compilador genera un archivo compuesto por ceros y unos que solo ese hardware puede entender. Este archivo resultante se puede ejecutar directamente haciendo doble clic en él por parte del usuario.

Dónde se usa

Se utilizan con frecuencia en la programación de sistemas, motores de juegos y sistemas empotrados donde la velocidad y la eficiencia son críticas. Además, las herramientas de línea de comandos modernas y las aplicaciones de escritorio de ejecución rápida que examinas en TreScout también se distribuyen generalmente con esta estructura.

Suele confundirse con

Se confunden con los archivos de código intermedio que se ejecutan en una máquina virtual. Mientras que los archivos de código intermedio necesitan un intermediario para ejecutarse en cualquier computadora, los binarios nativos solo se ejecutan directamente en el sistema específico para el que fueron creados.

Preguntas frecuentes

\u00bfFuncionan los binarios nativos en todas las computadoras?

No. Solo funcionan en el sistema operativo y la arquitectura de procesador para los que fueron compilados. Por ejemplo, un archivo compilado para Windows no se puede ejecutar directamente en una computadora Mac.

\u00bfQu\u00e9 lenguajes producen binarios nativos?

Los lenguajes de programacin de sistemas como Rust, C++, Go y Zig estn diseados para producir binarios nativos directamente.
