# ¿Qué es Code Review?

Es el proceso en el que los desarrolladores de software examinan los códigos de los demás para encontrar errores y mejorar la calidad.

## Definición
La revisión de código es la verificación del código en un proyecto de software por parte de otro ojo antes de incluirlo en la estructura principal. Este proceso es fundamental no solo para la depuración, sino también para que el equipo aprenda del estilo de codificación de cada uno y mantenga los estándares. En el mundo de TreScout, este es un filtro de control de calidad que garantiza la calidad del código.

## Cómo funciona
El desarrollador envía su código, otros miembros del equipo revisan el código, comentan y solicitan correcciones si es necesario. Una vez aprobado el código, se agrega al proyecto principal.

## Dónde se usa
Es una práctica estándar en plataformas como GitHub, GitLab y en procesos de desarrollo de software empresarial.

## Suele confundirse con
A diferencia de las pruebas automatizadas que solo prueban si el código funciona, aquí entran en juego la lógica y la estética humanas.

## Preguntas frecuentes
**¿Por qué no está automatizado?**
Las herramientas automatizadas pueden encontrar errores, pero sólo los humanos pueden evaluar completamente la alineación de la lógica del código con los objetivos comerciales.

**¿No es una pérdida de tiempo?**
Aunque al principio lleva tiempo, a la larga ahorra mucho tiempo, ya que evita errores importantes que pueden ocurrir más adelante.
