# ¿Qué es Code Coverage?

*Glosario · Dev · Última actualización: 3 de agosto de 2026*

Una métrica que mide la cantidad de pruebas de software de código escrito que realmente se ejecutan y verifican.

## Definición

Escribimos pruebas para comprender si cada línea de código que escribe en un proyecto de software funciona sin errores. La cobertura de código calcula qué porcentaje de su código tocan estas pruebas. Una proporción alta significa que su código es más seguro y está probado.

***Analogía:** Es como comprobar qué porcentaje de las preguntas de un examen respondiste; Cuantas más preguntas analice, mejor podrá evaluar sus conocimientos.*

## Cómo funciona

Durante el proceso de desarrollo de software se ejecutan herramientas de prueba automatizadas. Estas herramientas monitorean cada línea de su código y marcan las líneas por las que pasa la prueba. Finalmente, le brinda un informe como "85% del código probado".

## Dónde se usa

Se utiliza en procesos de desarrollo de software, líneas CI/CD e informes de control de calidad.

## Preguntas frecuentes

**¿Es siempre buena una cobertura de código del 100 por ciento?**

No, sólo muestra que el código funciona; no garantiza cubrir errores lógicos o todos los escenarios.

**¿Cómo mido esto?**

Se puede medir automáticamente con bibliotecas de prueba adecuadas para el lenguaje de programación que utilice (por ejemplo, cobertura.py para Python).
