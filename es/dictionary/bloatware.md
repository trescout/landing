# ¿Qué es Bloatware?

Son software preinstalados en el ordenador o teléfono, que suelen ocupar espacio innecesario y ralentizar el sistema.

## Definición
El bloatware son aplicaciones que se incluyen con el dispositivo cuando lo compras, pero no lo utilizas la mayor parte del tiempo. Este software puede ejecutarse en segundo plano, ocupando el procesador, agotando la batería y llenando espacio de almacenamiento. Estos software, que los fabricantes añaden al dispositivo debido a publicidad o acuerdos de preinstalación, suelen afectar negativamente a la experiencia del usuario.

## Cómo funciona
Viene con el sistema operativo del dispositivo y, a veces, el usuario no puede eliminarlo fácilmente.

## Dónde se usa
Se encuentra en teléfonos inteligentes, computadoras portátiles y paquetes de software preinstalados.

## Suele confundirse con
No confundir con las aplicaciones requeridas del sistema; Bloatware es software que no es opcional y crea ineficiencia.

## Preguntas frecuentes
**¿Cómo me deshago del bloatware?**
Puede deshacerse de él desactivando la aplicación desde el menú de configuración o reinstalando el dispositivo con un sistema operativo limpio.
