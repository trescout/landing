# ¿Qué es Object Storage System?

Es un método de almacenamiento a gran escala que guarda datos con identificadores únicos en lugar de carpetas de archivos.

## Definición
El sistema de archivos de su computadora tradicional es como una estructura de árbol; avanza en forma de carpetas dentro de carpetas. El almacenamiento de objetos, por otro lado, trata los datos como un objeto y les asigna una identidad única. De esta manera, en lugar de seguir rutas de carpetas para acceder a los datos, puede acceder a ellos rápidamente utilizando directamente esa identidad.

## Cómo funciona
Cuando los datos se cargan en el sistema, se convierten en un objeto y se les añaden algunas descripciones (metadatos). Cuando los necesita, llama a este objeto a través de su identidad.

## Dónde se usa
Se utiliza en servicios de almacenamiento en la nube, copias de seguridad de grandes volúmenes de datos y en la entrega de contenido multimedia.

## Suele confundirse con
Puede confundirse con los sistemas de archivos de disco duro normales; sin embargo, este sistema está diseñado para datos mucho más grandes.

## Preguntas frecuentes
**¿Por qué no utiliza carpetas?**
Porque gestionar miles de millones de datos en una estructura de carpetas es muy lento, mientras que el sistema de objetos es mucho más rápido.
