# ¿Qué es Runner Images?

*Glosario · Dev · Última actualización: 27 de septiembre de 2026*

Paquetes de entorno virtual listos para usar que contienen todas las configuraciones y archivos necesarios para que se ejecute el software.

## Definición

Las imágenes de Runner son archivos de plantilla que contienen todo el sistema operativo, las bibliotecas y las herramientas necesarias para probar o ejecutar un software. Gracias a estos paquetes, sus códigos se ejecutan exactamente en el mismo entorno en todas las computadoras y se elimina la excusa de "estaba funcionando en mi computadora".

***Analogía:** Es como una sala de examen cerrada con todos los bolígrafos, reglas y papel que necesitas para estudiar; Cuando entras todo está listo.*

## Cómo funciona

Los sistemas automatizados o servidores en la nube reciben este archivo de plantilla, lo activan en segundos y ejecutan pruebas u operaciones de software dentro de esta área segura.

## Dónde se usa

Se utiliza ampliamente en segundo plano en procesos de integración continua y pruebas automáticas.

## Suele confundirse con

No confundir con aplicaciones persistentes que se instalan directamente en el servidor en vivo; Estos suelen ser entornos temporales y basados ​​en tareas.

## Preguntas frecuentes

**¿Por qué utilizamos imágenes listas?**

Le ahorra la molestia de configurar un entorno desde cero cada vez y garantiza que cada prueba se ejecute en las mismas condiciones.
