# ¿Qué es Xcode?

Es el entorno de desarrollo de software oficial utilizado para desarrollar aplicaciones para dispositivos Apple (iPhone, Mac, iPad).

## Definición
Xcode es un conjunto de herramientas completo que Apple ofrece a los desarrolladores. Incluye un editor para escribir código, herramientas visuales para diseñar cómo se verá la aplicación y mecanismos de prueba para encontrar errores. Es la única forma oficial de desarrollar aplicaciones en el mundo Apple.

## Cómo funciona
Está instalado en su computadora Mac. Usted escribe los códigos de su aplicación aquí usando lenguajes Swift u Objective-C, prueba su aplicación y la carga en la tienda.

## Dónde se usa
Sólo funciona en el sistema operativo macOS.

## Suele confundirse con
Se diferencia de otros editores de código de uso general por ser específico del ecosistema de Apple.

## Preguntas frecuentes
**¿Puedo usar Xcode en una computadora con Windows?**
No, Xcode sólo se ejecuta en el sistema operativo macOS de Apple.
