# ¿Qué es Batch Processing?

Es la ejecución automática de muchas operaciones en segundo plano como grupo, en lugar de una por una.

## Definición
El procesamiento por lotes es un método utilizado por los sistemas informáticos para gestionar de manera eficiente cargas de trabajo intensivas. En lugar de procesarse inmediatamente, las transacciones se recopilan en una cola y se procesan todas a la vez en el momento adecuado. De esta manera, los recursos del sistema se utilizan de manera más uniforme.

## Cómo funciona
El sistema acumula los datos entrantes en una carpeta o base de datos. Cuando llega la hora designada o la cola está llena, un software recibe y procesa secuencialmente estos datos. El usuario no ve que estas operaciones se realizan en segundo plano.

## Dónde se usa
Se utiliza en el entrenamiento de modelos de inteligencia artificial, análisis de big data, sistemas de pago de salarios y envío de correo electrónico.

## Suele confundirse con
Puede confundirse con el procesamiento en tiempo real; El procesamiento en tiempo real reacciona inmediatamente, mientras que el procesamiento por lotes espera.

## Preguntas frecuentes
**¿Por qué procesamos en masa?**
Es un método más eficiente para no cansar el sistema y reducir costes.

**¿Cuál es el margen de error?**
Si ocurre un error dentro de un grupo, el sistema generalmente informa qué datos dieron el error y continúa procesando el resto.
