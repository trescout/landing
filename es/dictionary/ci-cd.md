# ¿Qué es CI/CD?

> Continuous Integration / Continuous Deployment

Es el proceso que garantiza que las actualizaciones de software se prueben y publiquen automáticamente.

## Definición
Es una línea de producción automática establecida para garantizar que el código escrito por los desarrolladores de software llegue al usuario sin errores. La integración continua (CI) garantiza que el código se ensambla y prueba constantemente, y la implementación continua (CD) garantiza que este código se transfiera automáticamente al sistema en vivo.

## Cómo funciona
Cuando envía su código al sistema, el sistema ejecuta primero pruebas automatizadas. Si las pruebas tienen éxito, empaqueta su código y lo prepara para su lanzamiento.

## Dónde se usa
Se utiliza en equipos de desarrollo de software modernos, especialmente en aplicaciones que lanzan actualizaciones rápidamente.

## Suele confundirse con
Puede confundirse con un proceso de prueba puramente manual, pero se trata de un flujo completamente automatizado.

## Preguntas frecuentes
**¿Por qué es tan importante?**
Evita que se active código defectuoso y aumenta la velocidad de desarrollo.

**¿Debería ser siempre automático?**
Generalmente sí, pero se pueden agregar pasos de aprobación manual para actualizaciones críticas.
