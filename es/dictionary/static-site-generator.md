# ¿Qué es Static Site Generator?

Una herramienta que toma contenido y plantillas ya preparados y los convierte en páginas web fijas listas para ser presentadas al usuario.

## Definición
Los sitios web tradicionales extraen información de la base de datos de cada visitante. El generador de sitios estáticos, por otro lado, realiza este proceso una vez, crea las páginas con anticipación y envía solo los archivos listos al visitante. Esto garantiza que su sitio se cargue muy rápidamente y sea más seguro.

## Cómo funciona
Escribes tu contenido en Markdown o archivos similares. La herramienta combina estos contenidos con plantillas de diseño y produce archivos HTML. También subes estos archivos a Internet.

## Dónde se usa
Con frecuencia se prefiere en blogs, sitios de documentación y portafolios personales.

## Suele confundirse con
Se mezcla con CMS (Sistema de gestión de contenidos); CMS utiliza una base de datos, mientras que esta herramienta solo produce archivos.

## Preguntas frecuentes
**¿Cómo actualizo mi sitio?**
Al cambiar el contenido y ejecutar la herramienta nuevamente, genera y carga nuevos archivos.

**¿No se requiere base de datos?**
No, no requiere una base de datos, lo que lo hace muy rápido.
