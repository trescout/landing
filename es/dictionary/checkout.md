# ¿Qué es Checkout?

Es la etapa final donde se realizan las transacciones de pago y aprobación al final de un proceso de compra.

## Definición
El checkout es el lugar donde el proceso de compra de los productos que agregas a tu carrito se oficializa en el mundo digital. En esta etapa se verifica la información del usuario, se recibe el pago y se registra el pedido en el sistema. Este es el punto donde un flujo de datos técnicamente seguro es más crítico.

## Cómo funciona
El usuario presiona el botón 'comprar', el sistema transmite la información de pago encriptada a la red bancaria, recibe la confirmación y se devuelve un número de pedido al usuario.

## Dónde se usa
Se encuentra en sitios de comercio electrónico, pantallas de compra dentro de aplicaciones y paneles de suscripción.

## Suele confundirse con
No confundir con agregar al carrito; El carrito es una preparación, el pago es un resultado.

## Preguntas frecuentes
**¿Por qué es tan importante el pago?**
Porque aquí se procesan tanto datos financieros como se vive el momento más sensible cuando el usuario completa la decisión de compra.
