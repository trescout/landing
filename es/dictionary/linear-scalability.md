# ¿Qué es Linear Scalability?

*Glosario · Data · Última actualización: 28 de julio de 2026*

A medida que aumenta la cantidad de recursos agregados al sistema, el rendimiento aumenta al mismo ritmo.

## Definición

Se refiere a la capacidad de crecimiento de un sistema. Si su sistema puede hacer el doble de trabajo cuando agrega el doble de servidores, el sistema es linealmente escalable. Esta es la mayor prueba de que el sistema puede crecer manteniendo su eficiencia.

***Analogía:** Es como cuando pones dos tractores en lugar de uno para arar un campo, el trabajo se hace el doble de rápido; Si no hay pérdida de eficiencia, estás escalando linealmente.*

## Cómo funciona

La arquitectura del sistema está diseñada para dividir la carga de trabajo en partes y distribuirla a diferentes recursos.

## Dónde se usa

Sistemas de computación en la nube, bases de datos y servicios web de alto tráfico.

## Suele confundirse con

No se trata sólo de "ser rápido", sino de que el aumento del rendimiento es proporcional al aumento de los recursos.

## Preguntas frecuentes

**¿Por qué no todos los sistemas pueden escalar linealmente?**

Porque a medida que el sistema crece, aumenta la carga de comunicación entre las partes, lo que puede desperdiciar algunos de los recursos agregados.
