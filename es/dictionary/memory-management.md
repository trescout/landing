# ¿Qué es Memory Management?

Es la colocación y limpieza periódica de datos para utilizar la memoria temporal de la computadora de manera eficiente.

## Definición
La RAM, que es la memoria temporal de las computadoras, tiene un espacio limitado. La gestión de la memoria es una gestión del sistema que decide qué datos permanecerán en la memoria durante cuánto tiempo y cómo se eliminarán cuando finalice.

## Cómo funciona
Mientras los programas se ejecutan, escriben los datos que necesitan en la memoria. El sistema realiza un seguimiento de estos datos y borra lo que ya no es necesario, dejando espacio para nuevos datos.

## Dónde se usa
Se ejecuta en segundo plano en sistemas operativos, motores de juegos y todo el software que requiere un alto rendimiento.

## Suele confundirse con
No confundir con almacenamiento (disco duro); Este proceso sólo afecta a la memoria temporal (RAM).

## Preguntas frecuentes
**¿Qué pasa si la gestión de la memoria es deficiente?**
La computadora puede ralentizarse, congelarse o los programas pueden fallar y cerrarse.

**¿Debería hacer esto?**
La mayoría de los lenguajes modernos hacen esto automáticamente, pero es posible que sea necesario realizar una verificación manual si está desarrollando software a nivel de sistema.
