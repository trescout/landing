# ¿Qué es Pull Request?

*Desarrollo · Última actualización: 5 de noviembre de 2026*

> PR

Una solicitud en la que un desarrollador presenta los cambios que desea añadir a un repositorio de código para su revisión y aprobación.

## Definición

Un Pull Request permite que los cambios realizados en el código sean revisados por otros miembros del equipo antes de ser integrados en el proyecto principal. Gracias a este proceso, los errores se detectan a tiempo y se protege la calidad del código. Es uno de los pilares de los procesos de desarrollo de software colaborativo.

***Analogía:** Es como si un autor presentara un nuevo capítulo que desea añadir a un libro al editor o al editor jefe para su aprobación.*

## Cómo funciona

El desarrollador completa su mejora en su propia rama de trabajo y la envía al repositorio. Luego, abre un Pull Request para invitar a sus compañeros de equipo a revisar el código. Tras la revisión, se corrigen los comentarios recibidos y, una vez obtenida la aprobación, el código se fusiona con la rama principal.

## Dónde se usa

Se utiliza en la gestión de proyectos de software en plataformas de control de versiones como GitHub, GitLab y Bitbucket.

## Suele confundirse con

Puede confundirse con el concepto de Git Push. Mientras que Git Push sube los cambios de código al servidor, un Pull Request inicia un proceso de revisión y debate para que dichos cambios se fusionen con el código principal.

## Preguntas y respuestas

**¿Por qué es importante un Pull Request?**

Mejora la calidad del código, facilita el intercambio de conocimientos dentro del equipo y evita que el código defectuoso llegue al sistema en producción.

**¿Se puede rechazar un Pull Request?**

Sí, si el código no cumple con los estándares o si hay deficiencias, puede ser rechazado o se puede solicitar una revisión para corregirlo.
