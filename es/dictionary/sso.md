# ¿Qué es SSO?

*Glosario · Dev · Última actualización: 26 de junio de 2026*

> Single Sign-On

Es un sistema que te permite iniciar sesión en muchas aplicaciones diferentes al mismo tiempo con un único nombre de usuario y contraseña.

## Definición

SSO elimina la molestia de recordar contraseñas independientes para cada aplicación. Una vez que inicias sesión, el sistema te reconoce y te permite acceder a otras aplicaciones de forma segura. Esto aumenta la comodidad del usuario y simplifica la gestión de la seguridad.

***Analogía:** Es como tener una única tarjeta de acceso al entrar a un edificio que abre las puertas de todas las habitaciones del edificio.*

## Cómo funciona

Seleccione un proveedor de autenticación (Proveedor de identidad). Conecte sus aplicaciones a este proveedor. Cuando el usuario inicia sesión, el proveedor envía una confirmación a la aplicación que dice "esta persona está autorizada".

## Dónde se usa

Se utiliza en software corporativo y opciones de inicio de sesión con Google o Facebook.

## Suele confundirse con

No debe confundirse simplemente con herramientas de almacenamiento de contraseñas (Administrador de contraseñas); SSO es un protocolo de autenticación.

## Preguntas frecuentes

**¿Es seguro?**

Sí, pero debes garantizar muy bien la seguridad de tu cuenta principal porque esa cuenta abre todas las puertas.

**¿Todas las aplicaciones admiten SSO?**

No, la aplicación debe estar configurada para admitir este protocolo.
