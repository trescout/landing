# ¿Qué es Sandbox?

*Glosario · Dev · Última actualización: 16 de junio de 2026*

Es un área de trabajo aislada donde se pueden probar nuevos software o códigos de forma segura sin dañar el sistema principal.

## Definición

Un sandbox es un área de juegos en su computadora o servidor que funciona como si estuviera en un entorno real, pero está desconectado del mundo exterior. Los errores cometidos aquí o la ejecución de códigos peligrosos nunca pueden dañar su sistema real. Puede restablecer fácilmente este campo cuando finalice el experimento.

***Analogía:** Es como un arenero en un parque infantil; Los niños pueden construir y destruir cualquier castillo que quieran allí, pero el orden general del parque no se ve afectado.*

## Cómo funciona

Cuando los desarrolladores de software desarrollan una nueva función o abren un archivo sospechoso, lo ejecutan en un entorno limitado. Si el sistema falla, solo se ve afectada esa pequeña área de pruebas, dejando su computadora intacta.

## Dónde se usa

Se utiliza en pruebas de seguridad cibernética, etapas de desarrollo de software y para que los navegadores ejecuten sitios web de forma segura.

## Suele confundirse con

Se puede mezclar con máquinas virtuales; Un arenero es un espacio de aislamiento que generalmente es más liviano y especializado para una aplicación particular.

## Preguntas frecuentes

**¿Por qué es necesaria una caja de arena?**

Es necesario comprender si un software desconocido está infectado o ver si un código nuevo dañará el sistema.

**¿Se pueden filtrar datos fuera del sandbox?**

Un sandbox bien estructurado restringe por completo la comunicación con el mundo exterior y evita fugas.
