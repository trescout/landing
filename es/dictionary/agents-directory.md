# ¿Qué es Agents Directory?

*Glosario · AI · Última actualización: 11 de octubre de 2026*

Es una estructura de carpetas especializada en proyectos de software que mantiene unidos los comportamientos, las herramientas y las reglas de los agentes de inteligencia artificial.

## Definición

Agents directory es el directorio que alberga las instrucciones y las conexiones de herramientas de los agentes de inteligencia artificial diseñados para diferentes tareas en una base de código. Le permite organizar los límites de las tareas y los patrones de comportamiento de múltiples asistentes autónomos que trabajan en su proyecto en un solo lugar estándar. Las herramientas de desarrollo y los motores de orquestación escanean este directorio para reconocer automáticamente los agentes específicos de su proyecto.

***Analogía:** Es similar a la carpeta de recursos humanos en una empresa, donde la descripción del puesto, las autorizaciones y los manuales de orientación de cada empleado especialista se mantienen ordenados.*

## Cómo funciona

Los desarrolladores suelen crear una carpeta llamada .agents o agents en el directorio raíz del proyecto. Dentro de esta carpeta se añaden archivos de configuración para cada agente que escribe pruebas, revisa código o prepara documentación. Las herramientas de desarrollo asistidas por agentes leen estos archivos para determinar qué roles asumirá el agente y qué funciones podrá invocar.

## Dónde se usa

Se utiliza con frecuencia en entornos de desarrollo de software basados en agentes, plataformas de orquestación de inteligencia artificial y editores de código modernos.

## Suele confundirse con

Se puede confundir con el concepto general de 'agent workspace' (espacio de trabajo del agente): mientras que el espacio de trabajo se refiere a la memoria temporal y los archivos transitorios que el agente utiliza mientras realiza un trabajo, el agents directory es el directorio de archivos persistente donde se almacenan las definiciones de código fuente y reglas de los agentes.

## Preguntas frecuentes

**¿Los agentes de inteligencia artificial no pueden funcionar sin esta carpeta?**

Pueden funcionar, pero tendría que especificar manualmente las instrucciones del sistema y las herramientas utilizables de cada agente uno por uno; la estructura de directorios automatiza y estandariza este proceso.

**¿Los agentes de la carpeta pueden comunicarse entre sí automáticamente?**

Pueden hacerlo: los sistemas con arquitectura multiagente enumeran los agentes en este directorio y los utilizan como guía para delegar una tarea a otro agente.
