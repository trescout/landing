# ¿Qué es Interoperability?

Es la capacidad de diferentes sistemas o software para intercambiar datos entre sí sin problemas.

## Definición
La interoperabilidad es la comprensión de dos sistemas escritos en diferentes idiomas o con diferentes tecnologías hablando un idioma común. Por ejemplo, es gracias a esta capacidad que un programa de contabilidad puede comunicarse automáticamente con los sistemas bancarios. Esta característica permite que las tecnologías formen un ecosistema sin depender unas de otras.

## Cómo funciona
Normalmente, las API se entregan utilizando formatos de datos estándar (como JSON) y protocolos comunes.

## Dónde se usa
Es de vital importancia en software empresarial, dispositivos IoT y grandes proyectos donde se combinan diferentes servicios.

## Preguntas frecuentes
**¿Por qué no todos los sistemas tienen esta característica?**
A veces las empresas quieren mantener sus sistemas cerrados o diferentes tecnologías no son técnicamente compatibles entre sí.
