# ¿Qué es Resolver Load Balancing?

Es el proceso de prevenir la sobrecarga del sistema mediante la distribución de consultas de direcciones de Internet a múltiples servidores.

## Definición
Cuando el tráfico de Internet es muy intenso, un solo servidor no puede atender todas las consultas. Este método evita que el sistema falle al redirigir las consultas a diferentes servidores como un policía de tráfico. Esto asegura una conexión rápida e ininterrumpida en todo momento.

## Cómo funciona
Instale un software de equilibrio de carga y distribuya las consultas DNS entrantes por igual entre los servidores que defina.

## Dónde se usa
Se utiliza en sitios web grandes e infraestructuras de red de alto tráfico.

## Suele confundirse con
Puede confundirse simplemente con la agrupación de servidores, pero este método se centra específicamente en gestionar el tráfico de consultas.

## Preguntas frecuentes
**¿Se acelerará el sitio gracias a este sistema?**
Sí, los tiempos de respuesta son más cortos ya que se reduce la carga del servidor.

**¿Qué sucede si un solo servidor deja de funcionar?**
El equilibrador de carga mantiene el sitio en funcionamiento redirigiendo a otros servidores.
