# ¿Qué es Graph-native Infrastructure?

*Glosario · Data · Última actualización: 8 de agosto de 2026*

Es una estructura especial de almacenamiento de datos diseñada en base a conexiones directas entre datos.

## Definición

A diferencia de las tablas tradicionales, este sistema mantiene datos en forma de nodos y líneas interconectados. Las relaciones entre la información son tan importantes como los datos mismos. De esta manera, se pueden realizar análisis de redes complejos muy rápidamente.

***Analogía:** Es como crear un mapa creando hipervínculos directos de un tema a otro, en lugar de organizar los archivos de una biblioteca en orden alfabético.*

## Cómo funciona

Los datos están vinculados entre sí mediante punteros, por lo que no es necesario escanear toda la lista para pasar de un dato a otro.

## Dónde se usa

Se utiliza en análisis de redes sociales, sistemas de detección de fraude y gráficos de conocimiento complejos.

## Suele confundirse con

No confundir con las bases de datos relacionales clásicas (SQL); porque aquí la relación no es parte del cuadro, sino la base de la estructura.

## Preguntas frecuentes

**¿Por qué debería elegir esta estructura?**

Esta estructura es mucho más rápida si necesita consultar relaciones profundas y complejas entre datos en segundos.
