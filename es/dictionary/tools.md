# ¿Qué es Tools?

Son funciones o herramientas auxiliares que permiten que el software interactúe con el mundo exterior para realizar determinadas operaciones.

## Definición
En el mundo de la IA, las "herramientas" permiten al modelo realizar tareas que no puede realizar por sí solo (como buscar en Internet, usar una calculadora o leer un archivo). Cuando el modelo necesita utilizar una herramienta, lo hace como una llamada a función. Esto permite al agente pasar de un sistema que simplemente produce texto a un asistente que interactúa con el mundo.

## Cómo funciona
Agregue instrucciones (indicaciones del sistema) que le indiquen a su agente qué herramienta usar y cuándo. Defina claramente el formato de entrada y salida de la herramienta para que el modelo no cometa errores.

## Dónde se usa
Se utiliza en sistemas basados ​​en agentes, herramientas de automatización y sistemas RAG.

## Suele confundirse con
Es similar a los complementos; Las herramientas son funciones que suelen estar integradas a nivel de código, mientras que los complementos ofrecen funciones más completas.

## Preguntas frecuentes
**¿Puede la inteligencia artificial elegir vehículos por sí sola?**
Sí, los agentes avanzados pueden decidir qué herramienta resolverá qué problema.

**¿Cómo hago mi propio vehículo?**
Puede hacerlo escribiendo una función y definiéndola para el agente a través de una API o biblioteca.
