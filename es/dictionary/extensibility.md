# ¿Qué es Extensibility?

La idoneidad de un sistema para desarrollarse agregando nuevas características sin alterar su estructura básica.

## Definición
Extensibilidad significa que un software es flexible. Puede agregar nuevas capacidades a través de complementos o módulos sin tocar el código principal del software. Esto asegura la longevidad del sistema.

## Cómo funciona
El sistema está diseñado con una 'interfaz' que aceptará módulos externos.

## Dónde se usa
Se utiliza en complementos de navegador, sistemas de gestión de contenidos (como WordPress) y software para grandes empresas.

## Preguntas frecuentes
**¿Todos los programas son extensibles?**
No, si el software no está diseñado con esta flexibilidad desde el principio, agregarlo más adelante puede resultar muy difícil.
