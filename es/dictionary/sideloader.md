# ¿Qué es Sideloader?

Es la herramienta o método que permite instalar aplicaciones en su dispositivo directamente desde un archivo, fuera de las tiendas de aplicaciones oficiales.

## Definición
Normalmente, para instalar una aplicación en un teléfono o computadora, se utilizan puertas oficiales como Apple App Store o Google Play. Sideloader desactiva estas puertas, permitiéndole instalar manualmente en su dispositivo un archivo de aplicación descargado de Internet. Este método se utiliza para acceder a software que no se encuentra en las tiendas oficiales o que aún no ha sido aprobado.

## Cómo funciona
Debe activar la opción 'permitir la instalación desde fuentes desconocidas' en la configuración de su dispositivo. Luego, inicia el proceso de instalación abriendo el archivo de instalación que descargó de Internet (por ejemplo, .apk para Android).

## Dónde se usa
Es común verlo en teléfonos Android, en aplicaciones en fase de prueba de desarrolladores de software personalizado o en dispositivos de usuarios que desean eludir restricciones.

## Suele confundirse con
Puede confundirse con el sideloading (la acción de cargar).

## Preguntas frecuentes
**¿Es seguro usar Sideloader?**
Dado que no cuenta con el escaneo de seguridad de las tiendas oficiales, debe prestar mucha atención a la fuente del archivo que descarga.

**¿Funciona en todos los dispositivos?**
Funciona en la mayoría de los sistemas abiertos, pero en sistemas cerrados como Apple, a veces pueden ser necesarios permisos especiales o jailbreak.
