# ¿Qué es Cloning?

*Glosario · Dev · Última actualización: 26 de junio de 2026*

Es el proceso de duplicar un proyecto de software o datos completos copiándolos en otra ubicación.

## Definición

La clonación se utiliza especialmente en el mundo del software para descargar la versión actual de un proyecto a su propia computadora. De esta forma tienes una copia del proyecto con todo su historial y archivos. De esta manera, podrás realizar cambios en el proyecto original sin dañarlo.

***Analogía:** Es como fotocopiar un libro; El original permanece en su lugar y usted tiene una copia con la que trabajar.*

## Cómo funciona

Por lo general, copia el enlace al proyecto usando el comando 'clonar' a través de un sistema de control de versiones (como git). El sistema descarga todos los archivos a su dispositivo.

## Dónde se usa

Se utiliza al importar proyectos de código abierto desde plataformas como GitHub a su propia computadora.

## Suele confundirse con

Puede confundirse con copia de seguridad; La clonación es más bien una copia que se realiza con el fin de trabajar en ella.

## Preguntas frecuentes

**¿Cambia el proyecto original?**

No, los cambios que realice en su copia no afectarán el proyecto original.

**¿Se requiere una conexión a Internet?**

Sólo se requiere copia en ese momento; Luego podrá trabajar sin conexión.
