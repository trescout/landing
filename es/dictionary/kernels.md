# ¿Qué es Kernels?

*Glosario · Dev · Última actualización: 30 de julio de 2026*

La parte más básica del sistema operativo que gestiona la comunicación entre el hardware y el software de la computadora.

## Definición

El kernel es el corazón de un sistema operativo. Es la primera pieza que se carga en la memoria cuando se enciende la computadora y controla qué software puede acceder al procesador, la memoria y otro hardware y cuándo. Cuando un usuario abre una aplicación, esa aplicación se comunica con el hardware a través del kernel, no directamente.

***Analogía:** Es como la recepción de un hotel; Gestiona el acceso y la distribución de las habitaciones (hardware) para todos los huéspedes (software).*

## Cómo funciona

Traduce las operaciones solicitadas por el software en comandos que el hardware puede entender y transmite los resultados del hardware al software.

## Dónde se usa

Se encuentra en el centro de todos los sistemas operativos como Windows, Linux y macOS.

## Suele confundirse con

No confundir con el sistema operativo en su conjunto; El kernel es sólo la capa de gestión más básica.

## Preguntas frecuentes

**¿Qué pasa si el kernel falla?**

Todo el sistema se detiene y la computadora se apaga, lo que a menudo genera errores como una "pantalla azul".

**¿El kernel de cada sistema operativo es diferente?**

Sí, por ejemplo, el kernel de Linux y el kernel de Windows tienen arquitecturas diferentes.
