# ¿Qué es Common User Passwords Profiler?

> CUPS

Es una herramienta que identifica vulnerabilidades de seguridad mediante el análisis de contraseñas débiles que la gente usa con frecuencia.

## Definición
Esta herramienta recopila los errores que cometen las personas al crear contraseñas (por ejemplo, usar '123456' o 'contraseña') en una base de datos. Los expertos en ciberseguridad utilizan estas listas para comprobar la facilidad con la que se puede descifrar un sistema. Su propósito es demostrar el peligro de las contraseñas débiles.

## Cómo funciona
Compara las contraseñas del sistema con esta lista común. Si hay una coincidencia, se informa que el sistema es débil.

## Dónde se usa
Se utiliza en auditorías de ciberseguridad y procesos de creación de políticas de contraseñas.

## Suele confundirse con
Puede confundirse con listas de palabras; Esta herramienta es un motor de análisis que utiliza esas listas.

## Preguntas frecuentes
**¿Puedo probar mi propia contraseña?**
Sí, pero debes hacerlo con herramientas confiables y en tus propios sistemas.
