# ¿Qué es Serialization?

Es el proceso de convertir estructuras de datos complejas en texto sin formato o matriz de bytes que se puede almacenar o transmitir.

## Definición
Es necesario traducir en línea recta los objetos almacenados de forma compleja en la memoria de la computadora (por ejemplo, un perfil de usuario) para poder enviarlos a través de Internet o guardarlos en un archivo. Este proceso se llama serialización. Cuando la otra parte recibe estos datos, realiza una "deserialización" y los restaura a su antigua estructura compleja.

## Cómo funciona
Los datos generalmente se convierten a JSON, XML o formatos binarios más rápidos. De esta forma, se conserva la estructura original de los datos y se vuelven portátiles entre diferentes sistemas.

## Dónde se usa
Se utiliza en comunicaciones API, registros de bases de datos y en la creación de archivos guardados en juegos.

## Preguntas frecuentes
**¿Por qué necesitamos la serialización?**
Los datos en la memoria de la computadora sólo son significativos para el programa actual. Para enviar datos a otra computadora o disco, necesitamos convertirlos a un formato universal.
