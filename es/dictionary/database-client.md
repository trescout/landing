# ¿Qué es Database Client?

*Glosario · Dev · Última actualización: 29 de septiembre de 2026*

Un programa intermediario que le permite acceder y administrar información en la base de datos.

## Definición

El cliente de base de datos le permite conectarse a los datos almacenados en servidores a través de una interfaz visual. Le permite examinar tablas, escribir consultas y organizar datos. Es una de las herramientas de software más básicas que se utilizan para administrar la base de datos sin escribir código.

***Analogía:** Es como un panel de control inteligente que le muestra dónde están las cajas fuertes de un almacén y le permite bloquearlas y desbloquearlas.*

## Cómo funciona

El cliente transmite los comandos o clics escritos en la interfaz de usuario al servidor de la base de datos. Las respuestas del servidor se muestran en la pantalla en forma de tablas o listas legibles.

## Dónde se usa

Es ampliamente utilizado en procesos de desarrollo de software, estudios de análisis de datos y gestión de servidores.

## Suele confundirse con

No confundir con el servidor de base de datos que almacena los datos en sí; El cliente es sólo la interfaz y la herramienta de gestión.

## Preguntas frecuentes

**¿Qué programas se conocen como clientes de bases de datos?**

Software como DBeaver, pgAdmin o MySQL Workbench entran en esta categoría.
