# ¿Qué es System Programming Language?

Es un lenguaje potente que se utiliza para desarrollar software de nivel básico, como un sistema operativo o un controlador de hardware.

## Definición
Son lenguajes que pueden comunicarse directamente con el hardware de la computadora y brindar control total sobre la administración de la memoria. Son muy rápidos pero menos tolerantes a cometer errores.

## Cómo funciona
Estos lenguajes permiten gestionar hasta el más mínimo detalle el funcionamiento del hardware.

## Dónde se usa
Se utiliza en sistemas operativos (Windows, Linux), motores de juegos y servidores de alto rendimiento.

## Suele confundirse con
No confundir con los lenguajes web; Si bien los lenguajes web se ocupan más de la interfaz de usuario, estos se ocupan del hardware.

## Preguntas frecuentes
**¿Qué idiomas entran en esta categoría?**
C, C++ y Rust son los ejemplos más conocidos.

**¿Por qué no todo el mundo utiliza estos idiomas?**
Es difícil de aprender y requiere una codificación muy cuidadosa.
