# ¿Qué es API Gateway?

Es una puerta de entrada central que atiende todas las solicitudes del mundo exterior, las dirige a los lugares correctos y realiza controles de seguridad.

## Definición
Las aplicaciones modernas constan de muchas partes diferentes. API Gateway es como un policía de tráfico parado frente a todas estas piezas. Recibe la solicitud entrante, comprueba quién la envió y la reenvía al servicio correspondiente.

## Cómo funciona
Supervisa el tráfico entrante, garantiza la seguridad, restringe las solicitudes si es necesario y devuelve los resultados al usuario.

## Dónde se usa
Se utiliza en grandes sistemas de software con arquitectura de microservicio.

## Suele confundirse con
No es sólo un enrutador; También asume funciones de seguridad y gestión.

## Preguntas frecuentes
**¿Por qué es necesario esto?**
En lugar de abrir cada servicio de forma individual al exterior, gestionarlo desde un único punto aporta seguridad y orden.
