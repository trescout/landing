# ¿Qué es PWA?

*Glosario · Dev · Última actualización: 26 de junio de 2026*

> Progressive Web App

Son páginas web que funcionan a través de un navegador de Internet pero que pueden instalarse en su teléfono o computadora como una aplicación.

## Definición

La tecnología PWA proporciona funciones similares a aplicaciones para sitios web. Tienen la capacidad de trabajar sin conexión, enviar notificaciones y acceder al hardware del dispositivo. Se puede instalar directamente desde el navegador sin necesidad de una tienda de aplicaciones adicional.

***Analogía:** Es una versión "disfrazada" de un sitio web que actúa como si fuera una aplicación personalizada para su teléfono.*

## Cómo funciona

Desarrolle un sitio web y agréguele un pequeño archivo de fondo llamado "trabajador de servicios". Cuando el usuario visita su sitio, puede instalar la aplicación haciendo clic en "Agregar a la pantalla de inicio" a través del navegador.

## Dónde se usa

Se utiliza con frecuencia en sitios de noticias, plataformas de comercio electrónico y aplicaciones de widgets simples.

## Suele confundirse con

No confundir con aplicaciones nativas; PWA es en realidad un sitio web.

## Preguntas frecuentes

**¿Se descarga de la App Store?**

No, se carga directamente a través del navegador.

**¿Funcionará cuando no tenga internet?**

Sí, gracias a la función de almacenamiento en caché, las funciones básicas pueden funcionar incluso si no hay Internet.
