# ¿Qué es Code Intelligence Graph?

Es un mapa detallado que muestra las relaciones de todos los archivos, funciones y variables en un proyecto de software.

## Definición
En grandes proyectos de software, los códigos se distribuyen en miles de archivos. Code Intelligence Graph conecta esta estructura compleja como una red. Por lo tanto, la inteligencia artificial puede comprender fácilmente a qué otras partes afectará un cambio realizado en una parte del código.

## Cómo funciona
Las herramientas de desarrollo de software escanean su proyecto, marcan cada parte como un nodo y registran las conexiones entre ellas. Esta base de datos se utiliza para brindarle sugerencias o encontrar errores mientras escribe código.

## Dónde se usa
Se utiliza en editores de código modernos, herramientas de desarrollo de software basadas en inteligencia artificial y gestión de proyectos a gran escala.

## Suele confundirse con
No es sólo una lista de archivos o una simple estructura de carpetas; También incluye las relaciones lógicas del código.

## Preguntas frecuentes
**¿Por qué es necesario esto?**
Porque en proyectos muy grandes, es imposible rastrear manualmente dónde un cambio causará errores.
