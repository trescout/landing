# ¿Qué es Cloud Native?

Es un enfoque para diseñar y administrar aplicaciones para que se ejecuten con la mayor eficiencia en el entorno de la nube.

## Definición
Este enfoque no consiste simplemente en cargar un software en la nube, sino en construirlo utilizando las características de flexibilidad, escalabilidad y durabilidad que ofrece la nube. La aplicación se divide en partes para adaptarse a la estructura dinámica de la nube.

## Cómo funciona
Las aplicaciones se colocan en contenedores y se gestionan con herramientas de gestión automática. Así, cuando el tráfico aumenta, la aplicación puede aumentar su capacidad por sí sola.

## Dónde se usa
Se utiliza en servicios web modernos, aplicaciones a gran escala y arquitecturas de microservicios.

## Preguntas frecuentes
**¿Por qué es importante?**
Ya que garantiza que la aplicación siempre sobreviva y crezca rápidamente.
