# ¿Qué es Memory API?

*Glosario · Dev · Última actualización: 3 de junio de 2026*

Puerto que permite al software agregar datos a la memoria de inteligencia artificial o consultar información existente.

## Definición

Es el punto de conexión que permite al software agregar datos a la memoria de la inteligencia artificial o consultar información existente. Esta interfaz permite a los desarrolladores proporcionar fácilmente memoria a largo plazo a la IA.

***Analogía:** Es como un mostrador de información especial que se utiliza para agregar o buscar libros en una biblioteca.*

## Cómo funciona

El desarrollador envía comandos al motor de memoria a través de API. Con estos comandos, la información se guarda, actualiza o recupera cuando es necesario.

## Dónde se usa

Lo utilizan los desarrolladores de software que desarrollan aplicaciones de inteligencia artificial para hacer que la aplicación sea más inteligente.

## Suele confundirse con

Se confunde con las operaciones de bases de datos, pero se trata de gestión de memoria específicamente en un formato que los modelos de inteligencia artificial entienden.

## Preguntas frecuentes

**¿Cualquiera puede utilizar la API de memoria?**

Si tiene conocimientos de desarrollo de software, puede seguir la documentación proporcionada e integrarla en sus aplicaciones.

**¿Qué se puede almacenar con esta API?**

Cualquier información que la inteligencia artificial necesite recordar, como preferencias del usuario, conversaciones pasadas, detalles del proyecto.
