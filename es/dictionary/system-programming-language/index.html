¿Qué es System Programming Language?

Lenguaje de programación de sistemas (su equivalente en turco: sistem programlama dili) son lenguajes que se comunican con el hardware.

Definición y origen de la palabra

Ofrecen un control total en la gestión de memoria, se ejecutan rápidamente y tienen baja tolerancia a errores. C, C++ y Rust son ejemplos conocidos. Los sistemas operativos, controladores y motores de juegos se escriben con estos lenguajes.

Analogía: Es como meterse con el motor y la transmisión en lugar de pintar la carrocería.

¿Cómo saberlo y utilizarlo en la vida diaria?

Sistema operativo: Kernel y controladores.
Juego: Núcleo del motor.
Presentador: Servicios de alto tráfico.

Profundidad técnica y arquitectura

Características:

Control de memoria: Asignación y liberación manual.
Abstracción de coste cero: Principio de Rust.
Compilación: Directamente a código máquina.

Primer programa:

fn main() {
    println!("merhaba");
}

El precio es la disciplina: un error de puntero causa un fallo, la advertencia del compilador se toma en serio.

Cosas frecuentemente mezcladas

Se cree que son lenguajes web. Ellos se ocupan de la interfaz, estos del hardware. Uno es el escaparate, el otro es el motor.

Uso en diferentes disciplinas

Motor: Mecánica, no carrocería.
Base: La estructura portante del edificio.
Esqueleto: El armazón del cuerpo.

Preguntas frecuentes

¿Cuáles se incluyen?

C, C++ y Rust son los más conocidos. Go y Zig también se acercan a esta categoría.

¿Por qué no todo el mundo lo usa?

Es difícil de aprender y requiere atención. Tiene un costo en eficiencia.

¿Con cuál se debe empezar?

Rust es moderno y orientativo. C es un clásico para sentar bases.

¿Se puede escribir web?

Se puede, pero no es práctico. El trabajo correcto se hace con el lenguaje correcto.
