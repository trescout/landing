# ¿Qué es Stealth Headless Browser?

Un navegador invisible que evita ser detectado como robot al eludir los firewalls de los sitios web.

## Definición
Son programas que no tienen una pantalla como los navegadores estándar, pero visitan sitios imitando el comportamiento de un usuario humano. Gracias a su función 'stealth' (sigilosa), pueden eludir los sistemas de bloqueo de robots utilizados por los sitios. De esta manera, las operaciones de recopilación de datos continúan sin interrupciones al parecer un usuario normal.

## Cómo funciona
El navegador se configura para mostrar detalles como la resolución de pantalla, los movimientos del ratón y la firma del software de manera que parezcan comportamiento humano.

## Dónde se usa
Se utiliza en procesos como el web scraping, pruebas automatizadas y seguimiento de precios.

## Suele confundirse con
Navegador Headless

## Preguntas frecuentes
**¿Por qué no usamos un navegador normal?**
Los navegadores normales consumen demasiados recursos y no pueden realizar miles de operaciones en segundo plano al mismo tiempo.
