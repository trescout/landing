# ¿Qué es Continuous Integration?

> CI

Es el proceso que garantiza que los errores se detecten tempranamente combinando y probando automáticamente los códigos escritos por los desarrolladores de software.

## Definición
La integración continua (CI) garantiza que los códigos se envíen con frecuencia a un sistema central durante el proceso de desarrollo de software y se sometan a pruebas automáticas allí. De esta manera, si el código escrito por un desarrollador de software entra en conflicto con el código de otros, se nota inmediatamente. Los errores se resuelven antes de que se hagan más grandes, mientras aún están en desarrollo.

## Cómo funciona
Tan pronto como el desarrollador carga su código en el sistema, los robots que se ejecutan en segundo plano compilan automáticamente el código y ejecutan pruebas predeterminadas.

## Dónde se usa
Es una práctica estándar en grandes equipos de software y ciclos de desarrollo de software modernos (DevOps).

## Preguntas frecuentes
**¿Por qué no hacemos pruebas manuales?**
Las pruebas manuales son lentas y propensas a errores humanos; CI, por otro lado, trabaja con la misma meticulosidad en cada cambio.
