# ¿Qué es ROM?

> Read-Only Memory

Es un tipo de memoria permanente de solo lectura que conserva la información en su interior incluso cuando la computadora está apagada.

## Definición
La ROM contiene las instrucciones básicas necesarias para encender la computadora o dispositivo. Este tipo de memoria está diseñado para almacenar datos de forma permanente y el usuario no puede cambiarlos fácilmente durante el uso normal. Es donde el "cerebro" del dispositivo sabe qué hacer cuando se despierta por primera vez.

## Cómo funciona
Cuando presiona el botón de encendido del dispositivo, el procesador primero lee las instrucciones en la ROM. Estas instrucciones le indican cómo se debe instalar el sistema operativo.

## Dónde se usa
Se encuentra en las pantallas de presentación de los teléfonos inteligentes, las placas base de las computadoras y los sistemas integrados.

## Suele confundirse con
Está mezclado con RAM; La RAM es temporal y se elimina cuando se apaga la computadora, mientras que la ROM es permanente.

## Preguntas frecuentes
**¿Por qué no se puede cambiar la información en la ROM?**
Porque las reglas básicas de funcionamiento del dispositivo están protegidas para evitar su eliminación accidental o corrupción.
