# ¿Qué es Toolchain Bootstrapping?

Es el proceso de mejorar gradualmente una herramienta de software hasta que alcance la capacidad de compilarse o construirse por sí misma.

## Definición
En el mundo del software, para crear una herramienta desde cero a menudo se necesita otra herramienta. Bootstrapping es un método para romper este ciclo creando primero una versión pequeña y simple y luego usando esta versión para producir versiones más complejas y avanzadas. Es una especie de arte autodidacta de fabricación de herramientas.

## Cómo funciona
Primero, se escribe una pieza básica de código y este código se hace ejecutable por sí solo. Luego, se establece un entorno de desarrollo completo realizando adiciones a esta estructura básica.

## Dónde se usa
Se utiliza con frecuencia en el desarrollo de compiladores de lenguajes de programación y herramientas de sistemas operativos.

## Preguntas frecuentes
**¿Por qué es tan complicado?**
Es necesario eliminar por completo la dependencia externa al construir algo desde cero.
