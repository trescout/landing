# ¿Qué es Service Mesh Manager?

Es la herramienta que gestiona y controla cómo las diferentes partes de sistemas de software complejos se comunican entre sí.

## Definición
Las aplicaciones grandes constan de cientos de servicios pequeños. Es difícil para estos servicios comunicarse de forma segura y sin errores. Las herramientas de administrador monitorean este tráfico, garantizan la seguridad e intervienen cuando surgen problemas.

## Cómo funciona
Observa todo el tráfico de la red a través de un pequeño software integrado en el sistema y lo dirige según reglas predeterminadas.

## Dónde se usa
Se utiliza en arquitecturas de software a gran escala nativas de la nube.

## Suele confundirse con
No es sólo una puerta de enlace, sino una estructura integral que gestiona todo el tráfico entre servicios.

## Preguntas frecuentes
**¿Por qué no lo gestionamos manualmente?**
La gestión manual es imposible cuando existen cientos de servicios; Estas herramientas reducen el margen de error a cero.
