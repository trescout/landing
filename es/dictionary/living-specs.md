# ¿Qué es Living Specs?

*Desarrollo · Última actualización: 27 de octubre de 2026*

Estos son requisitos técnicos que se actualizan automáticamente con el código durante el proceso de desarrollo de software y reflejan el estado actual del proyecto.

## Definición

La documentación tradicional se vuelve obsoleta a medida que avanza el proyecto, pero este método hace que la documentación forme parte del código. Estos requisitos se actualizan cada vez que se realiza un cambio en el software. De esta manera, los desarrolladores siempre tienen una hoja de ruta actualizada.

***Analogía:** Es como tener un mapa de una ciudad en una pantalla digital que se actualiza automáticamente a medida que se construyen las carreteras.*

## Cómo funciona

Gracias a los comentarios en el código o a las herramientas automatizadas, los documentos técnicos se mantienen sincronizados con la versión actual del código.

## Dónde se usa

Se utiliza para gestionar la complejidad en grandes proyectos de software y trabajo en equipo.

## Suele confundirse con

Se diferencia de los documentos técnicos tradicionales que son estáticos y quedan obsoletos con el tiempo.

## Preguntas y respuestas

**¿Por qué no utilizamos documentos estáticos?**

Porque los documentos estáticos quedan obsoletos muy rápidamente y pueden engañar a los desarrolladores.

**¿Es esto difícil de instalar?**

Requiere herramientas de automatización pero ahorra mucho tiempo a largo plazo.
