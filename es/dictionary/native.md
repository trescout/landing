# ¿Qué es Native?

Es cuando un software ha sido creado específicamente para el sistema operativo del dispositivo en el que se ejecuta y diseñado para ofrecer el máximo rendimiento.

## Definición
Las aplicaciones nativas pueden acceder directamente al hardware y al sistema operativo del dispositivo. Funcionan de manera más rápida y fluida porque hablan el idioma del dispositivo sin necesidad de otra capa. Por lo general, utilizan las características únicas de ese dispositivo a plena capacidad.

## Cómo funciona
Los desarrolladores escriben código utilizando las herramientas de desarrollo de software propias del dispositivo. De esta manera, la aplicación puede utilizar directamente todas las posibilidades que ofrece el sistema operativo. No hay retrasos porque no hay una capa de traducción intermedia.

## Dónde se usa
Aparecen en las tiendas de aplicaciones de los teléfonos inteligentes, en el software a nivel de sistema operativo y en los juegos que requieren un alto rendimiento.

## Suele confundirse con
Las aplicaciones basadas en web o las aplicaciones híbridas utilizan una capa intermedia, como un navegador, para comunicarse con el dispositivo.

## Preguntas frecuentes
**¿Es siempre mejor una aplicación nativa?**
En términos de rendimiento, generalmente sí, pero su desarrollo lleva más tiempo y es necesario escribir código por separado para cada dispositivo.

**¿Cómo funcionan las aplicaciones no nativas?**
Por lo general, funcionan dentro de un navegador o a través de una capa de traducción, lo que a veces puede causar ralentizaciones.
