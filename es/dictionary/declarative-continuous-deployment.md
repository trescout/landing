# ¿Qué es Declarative Continuous Deployment?

Es el método que define el estado final del sistema y garantiza que las actualizaciones alcancen automáticamente este objetivo.

## Definición
No le interesa cómo actualizar el sistema, sino cuál debería ser el resultado. Simplemente diga "deje que el sistema esté en este estado" y las herramientas tomarán todos los pasos necesarios para capturar este estado. Esto evita actualizaciones manuales erróneas.

## Cómo funciona
Prepara un archivo de configuración. El sistema automático lee este archivo, lo compara con la situación actual y realiza los ajustes necesarios para cerrar la brecha.

## Dónde se usa
Se utiliza en aplicaciones basadas en la nube y en la gestión de servidores a gran escala.

## Suele confundirse con
Puede confundirse con métodos imperativos (orientados a comandos); En ese método, cuentas cada paso uno por uno.

## Preguntas frecuentes
**¿Por qué deberíamos elegir este método?**
Minimiza el error humano y garantiza que el sistema permanezca siempre en el estado deseado.

**¿Qué pasa si cometo un error?**
El sistema se da cuenta de que ha definido el estado incorrecto y normalmente vuelve al estado anterior de funcionamiento.
