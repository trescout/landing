# ¿Qué es Architecture Diagrams?

Son diagramas visuales que muestran los componentes de un sistema de software complejo y sus relaciones entre sí.

## Definición
Los diagramas de arquitectura de software le brindan una vista panorámica de cómo funciona un proyecto. Se utiliza para comprender qué parte se encuentra en cada lugar, cómo fluyen los datos y la estructura general del sistema. También es una gran herramienta para explicar el sistema a personas sin conocimientos técnicos.

## Cómo funciona
A menudo se utilizan cuadros, flechas y líneas. Los cuadros representan partes del software y las flechas representan el tráfico de datos o la interacción entre estas partes.

## Dónde se usa
Se utiliza en procesos de desarrollo de software, reuniones de equipo y documentación técnica.

## Suele confundirse con
Puede confundirse con diagramas de flujo; Sin embargo, los diagramas arquitectónicos muestran más la estructura del sistema y los diagramas de flujo muestran los pasos de un proceso.

## Preguntas frecuentes
**¿Necesito saber el código para dibujar estos diagramas?**
No, existen muchas herramientas de visualización que funcionan con arrastrar y soltar.

**¿Por qué es tan importante?**
Reduce la complejidad del sistema y permite que todos los miembros del equipo sueñen lo mismo.
