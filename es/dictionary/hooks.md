# ¿Qué es Hooks?

Son puntos de conexión que permiten intervenir y realizar operaciones personalizadas en momentos específicos durante el proceso de ejecución del software.

## Definición
Son puertas especiales que los desarrolladores dejan al ejecutar un software para poder inyectar su propio código en el flujo principal. De esta manera, sin modificar el programa principal, puede hacer que sus propios comandos se ejecuten cuando ocurre un evento específico. Por ejemplo, puede usar un hook para indicar que se realice una copia de seguridad automáticamente cuando se guarda un archivo.

## Cómo funciona
Los desarrolladores de software colocan marcas dentro del código principal del tipo 'cuando llegues aquí, ejecuta esta función'. Usted conecta su propio código a estas marcas para personalizar el proceso. Gracias a este método, incluso si el software principal se actualiza, las funciones que usted añadió siguen funcionando.

## Dónde se usa
Se encuentran frecuentemente en el trasfondo de sitios web, marcos de desarrollo de aplicaciones y sistemas de complementos.

## Suele confundirse con
Pueden confundirse con los complementos (plugins); mientras que los hooks son más bien un punto de conexión a nivel de código, los complementos ofrecen características de mayor alcance.

## Preguntas frecuentes
**¿Por qué no cambiamos directamente el código principal?**
Cambiar el código principal provoca que todos sus cambios se eliminen cuando se actualiza el software; los hooks, en cambio, no se ven afectados por las actualizaciones.
