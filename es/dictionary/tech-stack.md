# ¿Qué es Tech Stack?

Es la colección de todos los lenguajes, bases de datos y herramientas utilizadas para construir un proyecto de software.

## Definición
Es la "pila de tecnología" que se utiliza al crear una aplicación. Por ejemplo, un idioma para el lado visible del sitio web, otra herramienta para la base de datos que se ejecuta en segundo plano y los servidores que los conectan forman parte de esta pila.

## Cómo funciona
Al planificar el proyecto se decide qué idioma, qué base de datos y qué servidor se utilizarán. Estas elecciones determinan el ritmo y la capacidad del proyecto.

## Dónde se usa
Se define durante la fase de arquitectura de los proyectos de desarrollo de software.

## Preguntas frecuentes
**¿Por qué es importante la selección de la pila?**
Porque afecta directamente la rapidez con la que crecerá el proyecto y la facilidad con la que se desarrollará.
