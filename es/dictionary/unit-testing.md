# ¿Qué es Unit Testing?

*Glosario · Dev · Última actualización: 14 de junio de 2026*

Es un método de prueba que verifica si las partes más pequeñas del software funcionan correctamente por sí solas.

## Definición

Es la prueba básica que se realiza para garantizar que cada función o método funcione sin errores durante el desarrollo del software. Puedes pensar en ello como comprobar las piezas de un gran rompecabezas una por una. Si las piezas pequeñas están intactas, aumenta la fiabilidad de todo el sistema.

***Analogía:** Es como fabricar un coche y comprobar que sólo la parte del pistón del motor se mueve suavemente; Confirmas la precisión de la pieza antes de conducir todo el coche.*

## Cómo funciona

Los desarrolladores escriben escenarios de prueba específicos para cada fragmento de código. Estos escenarios verifican automáticamente si el código proporciona el resultado esperado a la entrada esperada. Si la prueba falla, queda inmediatamente claro qué pequeña pieza es la culpable.

## Dónde se usa

Se utiliza al comienzo del proceso de desarrollo de software, mientras se escribe el código o inmediatamente después de escribirlo.

## Suele confundirse con

Puede confundirse con las pruebas de un extremo a otro; Si bien prueba todo el sistema, las pruebas unitarias se centran en una sola parte.

## Preguntas frecuentes

**¿Por qué debería probar cada parte?**

Para detectar errores muy temprano y prevenir problemas importantes que ocurrirán en todo el sistema más adelante.

**¿Se hace automáticamente?**

Sí, el desarrollador suele automatizarlo mediante herramientas de prueba.
