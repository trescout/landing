# ¿Qué es Identity Provider?

Servicio central que verifica la información de inicio de sesión del usuario y proporciona acceso seguro a las aplicaciones.

## Definición
Le permite probar su identidad a través de un sistema central, en lugar de crear una nueva contraseña cada vez para una aplicación. La aplicación le pregunta a este servicio quién es usted y obtiene confirmación.

## Cómo funciona
El usuario inicia sesión, el servicio se autentica y envía una clave de inicio de sesión a la aplicación.

## Dónde se usa
Se utiliza en sistemas locales, estructuras SSO (Single Sign-On) y aplicaciones web modernas.

## Suele confundirse con
No es sólo un administrador de contraseñas, es una autoridad de autenticación.

## Preguntas frecuentes
**¿Es seguro?**
Sí, es más seguro porque no proporcionas tu contraseña a todas las aplicaciones.

**¿Qué pasa si el sistema falla?**
Al tratarse de un servicio central, se puede interrumpir el acceso a todas las aplicaciones conectadas.
