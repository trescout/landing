# ¿Qué es Memory System?

Es la arquitectura de almacenamiento la que permite a la inteligencia artificial recordar interacciones pasadas, preferencias del usuario y datos.

## Definición
El sistema de memoria permite que la inteligencia artificial acceda no solo a la conversación actual sino también a información pasada. Gracias a este sistema, la inteligencia artificial no olvida quién eres ni lo que dijiste antes. Esto es fundamental para una experiencia de usuario personalizada y consistente.

## Cómo funciona
El sistema guarda las conversaciones en bases de datos vectoriales o archivos de memoria especiales. Cuando se hace una nueva pregunta, el sistema primero escanea su memoria y encuentra y utiliza información relevante.

## Dónde se usa
Se utiliza en asistentes personales, herramientas de inteligencia artificial que rastrean proyectos a largo plazo y robots de atención al cliente.

## Suele confundirse con
Se puede confundir con la ventana de contexto; La ventana de contexto es la memoria a corto plazo, mientras que el sistema de memoria es la memoria permanente o a largo plazo.

## Preguntas frecuentes
**¿Se puede borrar la memoria?**
Sí, la mayoría de los sistemas tienen la opción de borrar los datos del usuario o restablecer la memoria.

**¿La inteligencia artificial recuerda todo?**
Sólo se recuerda la información que el sistema puede guardar o que se considera importante.
