# ¿Qué es Text Generation Model?

Es un modelo de inteligencia artificial que produce textos significativos siguiendo una oración o tema inicial determinado.

## Definición
Estos modelos se entrenan con cantidades masivas de datos de texto, aprendiendo la estructura, la lógica y el conocimiento del idioma. Cuando le das un tema, puede formar oraciones y completar un párrafo o artículo adivinando cuál debería ser la siguiente palabra. No sólo puede escribir texto, sino que también puede traducir o realizar tareas como resumir.

## Cómo funciona
El usuario ingresa un comando y el modelo crea el texto de continuación más lógico utilizando sus propias probabilidades estadísticas.

## Dónde se usa
Se utiliza en chatbots, herramientas de redacción de contenidos y sistemas de redacción de correos electrónicos.

## Suele confundirse con
Es casi idéntico a LLM (Large Language Model), pero este término enfatiza que la atención se centra únicamente en la producción de texto.

## Preguntas frecuentes
**¿Siempre escribe correctamente?**
No, a veces puede inventar información poco realista, esto se llama alucinación.

**¿Escribe sólo en turco?**
Puede producir texto en muchos idiomas del mundo, dependiendo de los datos con los que esté entrenado.
