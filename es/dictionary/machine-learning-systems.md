# ¿Qué es Machine Learning Systems?

*Glosario · AI · Última actualización: 3 de julio de 2026*

Son sistemas informáticos que aprenden por sí solos analizando datos y pueden hacer predicciones más precisas con el tiempo.

## Definición

Estos sistemas aprenden reglas por sí solos extrayendo ejemplos de datos en lugar de programarlos explícitamente. Una vez entrenado, utiliza experiencias pasadas para hacer predicciones cuando se enfrenta a datos nuevos y nunca vistos. Mejoran su rendimiento con el tiempo con un flujo constante de datos.

***Analogía:** Es como un niño que toca el fuego una vez, aprende que arde, sin tener que decírtelo una y otra vez, y no vuelve a tocarlo nunca más.*

## Cómo funciona

Se le dan al modelo grandes conjuntos de datos, el modelo encuentra patrones en estos datos y crea un modelo matemático para producir un resultado.

## Dónde se usa

Se utiliza en sistemas de recomendación, detección de fraude, análisis de salud y vehículos autónomos.

## Preguntas frecuentes

**¿En qué se diferencia de la inteligencia artificial?**

El aprendizaje automático es una subrama de la inteligencia artificial centrada en aprender a partir de datos; No todas las inteligencias artificiales utilizan el aprendizaje automático.
