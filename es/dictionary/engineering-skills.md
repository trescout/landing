# ¿Qué es Engineering Skills?

Es la capacidad de diseñar y construir sistemas utilizando la lógica y las matemáticas para resolver problemas complejos.

## Definición
No se trata sólo de escribir código, es el proceso de planificar cómo resolver un problema de manera más eficiente. Esta habilidad tiene como objetivo crear un todo funcional uniendo partes. La perspectiva de ingeniería le permite aprovechar al máximo los recursos limitados disponibles.

## Cómo funciona
Primero divida el problema en partes más pequeñas, luego elija la solución lógica más adecuada para cada parte y combine estas partes para que funcionen juntas.

## Dónde se usa
Se utiliza en todo el desarrollo de software, diseño arquitectónico y procesos generales de resolución de problemas.

## Suele confundirse con
Puede confundirse simplemente con las habilidades de codificación, mientras que la codificación es solo la parte de aplicación de este proceso.

## Preguntas frecuentes
**¿Cualquiera puede adquirir habilidades de ingeniería?**
Sí, es una habilidad que se desarrolla con el tiempo practicando el pensamiento sistemático.

**¿Me será útil aunque no sea desarrollador de software?**
Definitivamente facilita la resolución de problemas complejos en todos los ámbitos de la vida.
