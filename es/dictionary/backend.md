# ¿Qué es Backend?

Es la parte de una aplicación que no es visible para el usuario, donde se procesan los datos y que se ejecuta en el servidor.

## Definición
Los botones o menús que ves al entrar en un sitio web son el frontend. En segundo plano, la parte que realiza todo el trabajo pesado, como verificar tus contraseñas, extraer información de la base de datos o procesar pagos, es el backend. El usuario solo ve el resultado, mientras que el backend es la cocina donde se prepara dicho resultado.

## Cómo funciona
El código que se ejecuta en el servidor recibe las solicitudes entrantes, se comunica con la base de datos y, tras realizar las operaciones lógicas necesarias, envía el resultado de vuelta al usuario.

## Dónde se usa
Se encuentra en todas las aplicaciones web modernas, en el trasfondo de las aplicaciones móviles y en los sistemas de API.

## Suele confundirse con
Puede confundirse con el frontend; el frontend interactúa contigo, mientras que el backend hace el trabajo.

## Preguntas frecuentes
**¿Por qué ejecutamos código en el backend?**
Porque es necesario garantizar la seguridad de los datos y realizar cálculos complejos sin sobrecargar el dispositivo del usuario.
