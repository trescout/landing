# ¿Qué es Debugger?

Es una herramienta de depuración que permite encontrar y corregir errores en el software mediante un seguimiento paso a paso.

## Definición
Es un programa de utilidad especial que te permite introducirte en el código durante el proceso de desarrollo de software y ver en directo cómo funciona cada línea. El código escrito por los programadores no siempre funciona correctamente la primera vez y puede provocar bloqueos inesperados o resultados incorrectos. El depurador te permite detener la ejecución del código en el punto que desees, examinar los valores de las variables en ese momento e identificar la fuente del error con precisión.

## Cómo funciona
Colocas un punto de interrupción en una línea específica de tu código. Cuando ejecutas el programa, se detiene exactamente en esa línea y tú avanzas paso a paso para observar en directo qué variable se corrompe y cuándo.

## Dónde se usa
Se utiliza con frecuencia en entornos de desarrollo de software, herramientas de desarrollo de navegadores web y análisis de errores en segundo plano de sistemas complejos.

## Suele confundirse con
Se puede confundir con un compilador. Mientras que el compilador traduce todo el código a lenguaje de máquina, el depurador se centra en encontrar errores lógicos dentro del código en ejecución.

## Preguntas frecuentes
**¿No puedo depurar sin usar un depurador?**
También puedes buscar errores añadiendo continuamente comandos de impresión de texto en pantalla dentro del código, pero este método es muy lento en proyectos grandes y no ofrece información tan detallada como un depurador.

**¿Qué es un punto de interrupción (breakpoint)?**
Es una marca que colocas en la línea donde deseas que el código se pause mientras se ejecuta; cuando el depurador llega aquí, congela el programa.
