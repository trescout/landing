# ¿Qué es Terminal File Manager?

*Glosario · Dev · Última actualización: 27 de julio de 2026*

Una herramienta que le permite administrar sus archivos solo a través de la línea de comando en lugar de ventanas visuales.

## Definición

Estas herramientas le permiten copiar, mover o eliminar archivos con atajos de teclado sin usar el mouse. Te permite operar muy rápidamente sin el peso de una interfaz gráfica.

***Analogía:** Es un sistema que te permite tener el libro que deseas frente a ti con solo presionar un botón, en lugar de subir las estanterías de una escalera en una biblioteca.*

## Cómo funciona

Abres la terminal y ejecutas el programa. Aparecen dos paneles en la pantalla y puede navegar entre archivos con las teclas de flecha del teclado.

## Dónde se usa

Se utiliza en la gestión de servidores o en procesos de desarrollo de software donde es necesario editar archivos muy rápidamente.

## Suele confundirse con

No debe confundirse con 'shell', que simplemente dice comandos; Esta herramienta ofrece una interfaz de edición visual.

## Preguntas frecuentes

**¿Es difícil aprender?**

Puede que al principio te lleve algo de tiempo memorizar los atajos, pero una vez que te acostumbras a ellos, se vuelve muy rápido.

**¿Funciona en todos los sistemas operativos?**

Generalmente es muy común en Linux y macOS.
