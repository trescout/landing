# ¿Qué es Gamification?

Es el uso de mecánicas de juego para motivar al usuario en áreas ajenas al juego.

## Definición
Es un método para agregar elementos del juego como acumular puntos, subir de nivel, tablas de clasificación o ganar insignias a las aplicaciones diarias para que las personas no se aburran mientras realizan una tarea. El objetivo es fidelizar a los usuarios.

## Cómo funciona
Cuando el usuario completa una tarea, activas el mecanismo de recompensa en su cerebro dándole una recompensa virtual.

## Dónde se usa
Es muy común en aplicaciones de aprendizaje de idiomas, rastreadores de actividad física y software de capacitación corporativa.

## Preguntas frecuentes
**¿Se puede gamificar todo?**
Técnicamente sí, pero si no se construye correctamente, puede molestar al usuario en lugar de motivarlo.
