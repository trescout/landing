# ¿Qué es Bash Script?

Es una secuencia de comandos que automatiza operaciones de varios pasos que deben realizarse en la computadora recopilándolas en un solo archivo.

## Definición
El script Bash le permite combinar los comandos que escribe uno por uno en la línea de comandos de la computadora y almacenarlos en un solo archivo. Cuando ejecuta este archivo, todos los comandos que contiene se ejecutan de forma secuencial y sin errores. Es una de las mayores ayudas para los desarrolladores de software, especialmente para acelerar tareas repetitivas.

## Cómo funciona
Abres un archivo de texto y escribes los comandos que deseas ejecutar uno debajo del otro. Una vez que guarde el archivo y lo haga ejecutable, iniciará todo el proceso con un solo clic o comando.

## Dónde se usa
Se utiliza frecuentemente en la gestión de servidores, operaciones de respaldo o procesos de instalación de software.

## Preguntas frecuentes
**¿Por qué debería utilizar un guión en lugar de escribirlo a mano?**
Reduce el margen de error y le permite realizar la misma operación a la misma velocidad cada vez.
