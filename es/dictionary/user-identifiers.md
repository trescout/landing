# ¿Qué es User Identifiers?

*Glosario · Dev · Última actualización: 27 de junio de 2026*

Son marcadores de identidad únicos que se utilizan para distinguir a cada usuario en los sistemas digitales.

## Definición

Estos son códigos especiales o nombres de usuario asignados al sistema para reconocerte cuando ingresas a una aplicación. Gracias a estos identificadores, el sistema puede presentarle sus transacciones, configuraciones y datos anteriores específicamente sin mezclarlos. Puede pensar en ello como si fuera su número de membresía en una biblioteca.

***Analogía:** Es como un pase que se utiliza para entrar a un edificio; Cuando escaneas la tarjeta, el guardia de seguridad sabe instantáneamente quién eres y a qué pisos puedes ingresar.*

## Cómo funciona

Cuando se registra o inicia sesión en el sistema, se crea automáticamente en segundo plano y se relaciona con usted en la base de datos.

## Dónde se usa

Se utiliza para el seguimiento de usuarios en sitios web, aplicaciones móviles y software corporativo.

## Suele confundirse con

Se puede confundir con un nombre de usuario, pero se trata de una estructura más técnica y general que permite que el sistema te reconozca.

## Preguntas frecuentes

**¿Por qué obtengo una identificación diferente para cada sistema?**

Por su seguridad; No utilizar su identidad en un sistema en otro sistema mantiene sus datos más seguros.
