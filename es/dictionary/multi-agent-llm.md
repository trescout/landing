# ¿Qué es Multi-agent LLM?

*Glosario · AI · Última actualización: 3 de junio de 2026*

Es un sistema de trabajo en el que múltiples modelos de inteligencia artificial cooperan para resolver tareas complejas.

## Definición

En la estructura LLM de múltiples agentes, cada unidad de IA tiene una experiencia específica. Estas unidades se comunican entre sí y completan diferentes partes de un proyecto. Las tareas complejas que serían difíciles para un solo modelo se resuelven mucho más rápido y sin errores combinando modelos especializados.

***Analogía:** Es como en un set de cine, donde el director, el guionista, el iluminador y el actor realizan sus propias tareas y se apoyan mutuamente para crear una película conjunta.*

## Cómo funciona

Un modelo maestro distribuye tareas. Otros modelos trabajan en sus propias áreas de especialización, como escribir código, realizar investigaciones o control de calidad, y transmiten los resultados al modelo principal.

## Dónde se usa

Se utiliza en procesos de desarrollo de software, análisis de datos complejos y flujos de trabajo autónomos.

## Suele confundirse con

A diferencia de un modelo único de inteligencia artificial, aquí existe trabajo en equipo y división del trabajo.

## Preguntas frecuentes

**¿Por qué un modelo no es suficiente?**

Algunas obras tienen varias capas; Tener un modelo que escriba código y verifique toda la seguridad aumenta el margen de error.

**¿Cómo se llevan las modelos?**

Se comunican enviándose mensajes entre sí mediante comandos predefinidos y formatos de intercambio de datos.
