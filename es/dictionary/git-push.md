# ¿Qué es Git Push?

Es el proceso de cargar los cambios de software que realiza en su computadora local a un servidor compartido en Internet.

## Definición
Cuando desarrollas software, escribes y editas tus códigos en tu propia computadora. El comando 'push' se utiliza para compartir estos cambios con el resto del equipo. De esta forma, todas las actualizaciones que realices se envían a un repositorio central.

## Cómo funciona
Se hace escribiendo el comando 'git push' a través de la terminal o el editor de código.

## Dónde se usa
Se utiliza en procesos de desarrollo de software, especialmente en plataformas como GitHub o GitLab.

## Suele confundirse con
Se confunde con git pull; Mientras pull recupera el código de Internet, push lo envía a Internet.

## Preguntas frecuentes
**¿Qué pasa si no empujo?**
Los cambios que realices permanecerán solo en tu computadora y tu equipo no podrá verlos.
