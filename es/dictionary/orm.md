# ¿Qué es ORM?

*Glosario · Dev · Última actualización: 9 de julio de 2026*

> Object-Relational Mapping

Es un puente que convierte tablas de bases de datos en objetos en código.

## Definición

Le permite utilizar estos datos como objetos en un lenguaje de programación, en lugar de lidiar con tablas complejas en la base de datos mientras desarrolla software. De esta manera, puede administrar datos sin escribir consultas complejas como SQL. Hace que su código sea más legible y manejable.

***Analogía:** Piense en los datos sin procesar de la base de datos como cuadros; ORM es como un ayudante que abre estas cajas por usted y convierte los elementos que contiene en objetos que puede usar directamente.*

## Cómo funciona

Funciona como una capa entre la base de datos y el código de la aplicación. Cuando guarda datos en su código, traduce esta operación en la consulta SQL adecuada en segundo plano. De esta manera, incluso si la estructura de la base de datos cambia, sólo necesitará cambiar ligeramente el código.

## Dónde se usa

Se utiliza con frecuencia en aplicaciones web, software empresarial y proyectos con uso intensivo de bases de datos.

## Suele confundirse con

Puede confundirse con el controlador de la base de datos; El controlador proporciona la conexión sin formato, mientras que el ORM facilita esta conexión.

## Preguntas frecuentes

**¿Por qué debería utilizar ORM?**

Acelera las operaciones de la base de datos y reduce los errores de código.

**¿Reduce el rendimiento?**

Para consultas muy complejas, el SQL manual a veces puede ser más rápido, pero en la mayoría de los casos la comodidad vale la pena.
