# ¿Qué es Continuous Deployment?

> CD

Los códigos que pasan la prueba se activan automáticamente sin ninguna intervención humana.

## Definición
Es un método que acelera el proceso de desarrollo de software. Tan pronto como escribes tu código, pasa por pruebas automáticas y, si no hay obstáculos, se carga directamente en el sistema utilizado por los usuarios. Garantiza que el software se actualice constantemente eliminando los procesos de aprobación manuales.

## Cómo funciona
El desarrollador envía el código al sistema, el sistema ejecuta pruebas automatizadas y, si tiene éxito, el código se transfiere al servidor en vivo.

## Dónde se usa
Aplicaciones web modernas, plataformas SaaS y productos digitales que requieren actualizaciones rápidas.

## Suele confundirse con
Puede confundirse con Entrega Continua; En Delivery, la fase de puesta en marcha puede requerir una aprobación manual, mientras que en Deployment es completamente automática.

## Preguntas frecuentes
**¿Qué pasa si cometemos un error?**
El sistema intenta detectar el error antes de que se active, gracias a pruebas automáticas, pero aún conlleva riesgos; por lo que las pruebas deben ser muy sólidas.
