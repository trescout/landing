# ¿Qué es Application?

*Glosario · Dev · Última actualización: 22 de septiembre de 2026*

La aplicación es un software de usuario que realiza un trabajo específico.

## Definición y origen de la palabra

Todo, desde escribir texto hasta editar fotografías, se realiza a través de una aplicación. Se ejecuta en el sistema operativo y ofrece una interfaz visual. La analogía de la casa es adecuada: el sistema es la casa, las aplicaciones son sus muebles.

***Analogía:** Si consideramos el sistema operativo como los cimientos de la casa y las paredes, las aplicaciones son los muebles y elementos del interior.*

## ¿Cómo saberlo y utilizarlo en la vida diaria?

**Teléfono:** Mensajería y banca.
**De oficina:** Oficina y diseño.
**Web:** Los que se abren en el navegador.

## Profundidad técnica y arquitectura

Tipos:

**Nativo:** Específico del dispositivo, rápido y totalmente autorizado.
**Web:** Ejecutándose en el navegador, no requiere instalación.
**PWA:** En el medio, web descargable.

La distribución es desde la tienda o la web. Se solicitan permisos en el primer inicio y se lee la política de privacidad.

## Cosas frecuentemente mezcladas

Se considera un sistema operativo. El sistema gestiona el dispositivo, la aplicación hace un trabajo. Los controladores son software pero no aplicaciones.

## Uso en diferentes disciplinas

**Muebles:** Artículos dentro de la casa.
**Aparato de cocina:** Dispositivos de una sola tarea.
**Accesorio de coche:** Pieza instalada más tarde.

## Preguntas frecuentes

**¿La aplicación y el software son iguales?**

La aplicación es un subconjunto del software. Cada aplicación es software, no todo software es una aplicación.

**¿Cómo actualizar aplicaciones?**

Automático o manual de tienda. Los web se actualizan al inicio.

**¿Cuál es la diferencia entre web y nativo?**

Native es rápido y totalmente autorizado, no requiere instalación web. PWA se pone al día.

**¿Es necesaria la tienda?**

Práctico para distribución, no obligatorio. La distribución web y empresarial son alternativas.
