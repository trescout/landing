# ¿Qué es SDK?

*Glosario · Dev · Última actualización: 16 de junio de 2026*

> Software Development Kit

Es un conjunto de herramientas y bibliotecas que facilitan a los desarrolladores de software el desarrollo de aplicaciones para una plataforma específica.

## Definición

SDK es una especie de kit de desarrollo. Contiene herramientas, documentos y códigos de muestra listos para usar que le facilitan la escritura de código. En lugar de escribir todo desde cero para utilizar las funciones de una plataforma, combina las piezas ya preparadas que ofrece este kit.

***Analogía:** Es una caja de armario que se compra de una marca de muebles; Contiene no sólo tablas, sino también tornillos, llave Allen y guía de montaje. El SDK es esa caja que contiene todo lo que necesitas para crear software.*

## Cómo funciona

El desarrollador descarga el SDK correspondiente a su computadora y hace referencia a estas herramientas mientras codifica. Por tanto, puede manejar operaciones complejas con comandos de una sola línea.

## Dónde se usa

Se utiliza en el desarrollo de aplicaciones móviles, integrando un modelo de inteligencia artificial en su propia aplicación o en motores de juegos.

## Suele confundirse con

Mezclado con API; La API es una puerta, el SDK es toda la caja de herramientas que le permite atravesar esa puerta y configurar la casa.

## Preguntas frecuentes

**¿Todos los SDK son gratuitos?**

La mayoría son gratuitas, pero algunas plataformas específicas pueden cobrar tarifas de licencia por el uso del SDK.

**¿No se puede escribir una aplicación sin SDK?**

Se puede escribir, pero hay que codificar todo desde cero, lo que lleva demasiado tiempo.
