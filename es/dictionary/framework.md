# ¿Qué es Framework?

Es un conjunto de estructuras y reglas listas para usar que se utilizan para acelerar el trabajo al desarrollar software.

## Definición
Una estructura es como el esqueleto de un edificio. En lugar de crear todo desde cero usted mismo, puede utilizar este marco y agregarle sus propias funciones. Reduce los errores y acelera el proceso al ofrecer a los desarrolladores de software un estado de funcionamiento estándar.

## Cómo funciona
Para realizar un trabajo específico (por ejemplo, crear un sitio web), los desarrolladores eligen un marco adecuado para ese campo. Escriben sus códigos según las reglas determinadas por este marco y se benefician de las herramientas listas para usar que ofrece el sistema.

## Dónde se usa
Se utiliza con frecuencia en el desarrollo de sitios web, aplicaciones móviles y software de inteligencia artificial.

## Suele confundirse con
Se puede mezclar con bibliotecas; Una biblioteca es una herramienta a la que llamas, un marco es una estructura dentro de la cual trabajas.

## Preguntas frecuentes
**¿Por qué debería utilizar marcos?**
Para evitar reinventar la rueda y escribir código estándar más seguro.

**¿Es necesario un marco para cada proyecto?**
No, en proyectos muy pequeños y simples, a veces sólo los códigos básicos pueden ser suficientes.
