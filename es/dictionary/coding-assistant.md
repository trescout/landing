# ¿Qué es Coding Assistant?

Es un asistente respaldado por inteligencia artificial que le ofrece sugerencias durante el proceso de desarrollo de software, acelera la escritura de código y detecta errores.

## Definición
El asistente de codificación es una herramienta inteligente que comprende el contexto del código que escribe y predice lo que desea escribir en la siguiente línea. Puede completar bloques de código complejos por usted, encontrar errores lógicos en el código que escribe o brindar ejemplos de una biblioteca que no conoce.

## Cómo funciona
Generalmente se instala como un complemento en el editor de código que estás utilizando. Cuando empiezas a escribir código, se ejecuta en segundo plano y muestra sugerencias en gris; Si confirma, completará el código por usted.

## Dónde se usa
Se utiliza en proyectos de software diarios, cuando se aprende un nuevo idioma o cuando se crean prototipos rápidos para proyectos grandes.

## Suele confundirse con
Se puede confundir con el 'Agente AI' que realiza todo el proyecto de forma completamente autónoma; El asistente suele actuar bajo su dirección.

## Preguntas frecuentes
**¿Escribe todo el código?**
No, un asistente es sólo un ayudante; Siempre tienes el control.

**¿Es seguro?**
Depende de la política de privacidad de la herramienta con la que compartes tu código, debes tener cuidado al compartir datos confidenciales.
