# ¿Qué es Clone?

Es el proceso de copiar todos los archivos y el historial de un proyecto de software en Internet a su propia computadora.

## Definición
Significa descargar un proyecto de código abierto, generalmente disponible en plataformas como GitHub, a su entorno local para que pueda trabajar en él o revisarlo. Más que simplemente descargar archivos, esto muestra todo el historial de desarrollo del proyecto.

## Cómo funciona
Se realiza a través de la línea de comando usando el comando 'git clone' y la dirección del proyecto.

## Dónde se usa
Es el primer proceso que realizan los desarrolladores de software antes de iniciar el proyecto.

## Preguntas frecuentes
**¿Puedo cambiar el proyecto después de la clonación?**
Sí, puedes realizar los cambios que quieras en la copia en tu propia computadora, pero no afectará el proyecto original.
