# ¿Qué es DNS Resolver?

*Desarrollo · Última actualización: 19 de noviembre de 2026*

El sistema que traduce los nombres de los sitios web a las direcciones numéricas que las computadoras entienden.

## Definición

Cuando escribes una dirección de internet en tu navegador, tu computadora no sabe directamente en qué servidor se ejecuta ese nombre. El resolutor DNS entra en juego en este punto y busca en la gigantesca guía telefónica que funciona en segundo plano. Traduce la dirección web legible para los humanos a la dirección IP que permite que las máquinas se encuentren entre sí.

***Analogía:** Es similar a buscar el nombre de un amigo en la guía telefónica para encontrar su número de teléfono real.*

## Cómo funciona

Cuando escribes una dirección en tu navegador y presionas la tecla Enter, la solicitud va primero al sistema resolutor de tu proveedor de internet o de un servicio externo. El resolutor pregunta a otros servidores hasta que encuentra la dirección correspondiente y devuelve la dirección IP encontrada a tu computadora.

## Dónde se usa

Funciona continuamente en segundo plano en todas las comunicaciones de red, navegadores de internet y configuraciones de servidores.

## Suele confundirse con

Se puede confundir con el término general de DNS, pero este término se refiere directamente al servidor o mecanismo de software que realiza el proceso de resolución de direcciones.

## Preguntas y respuestas

**¿Este sistema funciona siempre que me conecto a internet?**

Sí, este proceso de traducción se realiza en segundo plano para cada dirección de sitio web que escribes en tu navegador.

**¿Usar un resolutor diferente afecta la velocidad?**

Los sistemas de resolución externos de funcionamiento rápido pueden mejorar el tiempo de carga de los sitios web en milisegundos.
