# ¿Qué es Desktop Client?

*Glosario · Dev · Última actualización: 20 de julio de 2026*

Es una aplicación de software que se instala en su computadora y se ejecuta directamente en el entorno de escritorio.

## Definición

A diferencia de las aplicaciones web que se ejecutan a través del navegador, interactúa directamente con su sistema operativo. Proporciona un acceso más profundo a los recursos de hardware y, en general, ofrece una experiencia más estable. Puede realizar sus funciones básicas incluso sin conexión a Internet.

***Analogía:** Visitar un sitio web es como entrar a una tienda; pero la aplicación de escritorio es como instalar esa tienda en tu propia casa.*

## Cómo funciona

Descarga el archivo de instalación de la aplicación y lo instala en su computadora. La aplicación realiza sus tareas accediendo a su sistema de archivos y hardware tanto como lo permita su sistema operativo.

## Dónde se usa

Se utiliza en sistemas operativos, programas de oficina y herramientas de desarrollo de software profesionales.

## Suele confundirse con

Puede confundirse con aplicaciones web; Mientras que las aplicaciones web dependen del navegador, el cliente de escritorio funciona de forma independiente.

## Preguntas frecuentes

**¿Es siempre mejor una aplicación de escritorio?**

Para tareas que requieren mayor rendimiento y acceso a hardware, sí, pero en términos de portabilidad, las aplicaciones web son más prácticas.
