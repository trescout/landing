# ¿Qué es Fork?

El proceso de hacer una copia de un proyecto de software existente y comenzar a realizar nuevos cambios de forma independiente.

## Definición
En el mundo del código abierto, una bifurcación le permite copiar una copia exacta de un proyecto escrito por otra persona en su propia cuenta o dominio. Una vez que tenga esta copia, podrá modificarla como desee, agregar nuevas funciones o seguir su propia dirección sin estar atado al proyecto original.

## Cómo funciona
Al presionar el botón correspondiente en las plataformas de alojamiento de código, copia todo el historial y los archivos del proyecto en su propio espacio.

## Dónde se usa
Se utiliza cuando se contribuye a proyectos de código abierto o cuando se desea personalizar un software existente para un propósito diferente.

## Suele confundirse con
No debe confundirse con el proceso de clonación, que simplemente descarga el proyecto al ordenador y lo examina; El proceso de bifurcación crea una propiedad nueva e independiente en el lado del servidor.

## Preguntas frecuentes
**¿Recibiré actualizaciones del proyecto original después de la bifurcación?**
No viene automáticamente, pero también puedes transferir las novedades del proyecto original a tu propia copia.
