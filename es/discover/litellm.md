# Gestione los modelos de inteligencia artificial de forma centralizada

LiteLLM es una pasarela de IA (AI gateway) que unifica más de 100 interfaces de modelos de lenguaje grandes (LLM) en un único formato estándar. Facilita la transición entre diferentes proveedores de modelos al ofrecer a los desarrolladores de software funciones como el seguimiento de costes, el equilibrio de carga y barreras de seguridad (guardrails).

## Qué aporta

- Evita la complejidad del código al unificar más de cien proveedores de LLM (Modelos de Lenguaje Grandes) en un único formato estándar.
- Elimina la necesidad de reescribir su base de código al cambiar entre modelos de inteligencia artificial.
- Ofrece una infraestructura de gestión de nivel empresarial con herramientas como claves virtuales, seguimiento de presupuestos y equilibrio de carga.

## Instalación

**instalar la biblioteca de Python del lenguaje de prog**

```
uv add litellm
```

## Ejecución

**Iniciar el servidor de pasarela**

```
uv tool install 'litellm[proxy]'
litellm --model gpt-4o
```
