# Infraestructura para modelos recursivos de inteligencia artificial.

Desarrollado para modelos de lenguaje recursivo, rlm es una biblioteca de inferencia plug-and-play que admite diferentes entornos limitados. Esta herramienta basada en Python estandariza procesos complejos de modelos de lenguaje, haciéndolos más fáciles de integrar en diferentes sistemas.

## Qué aporta
- Gestión de contexto de longitud infinita
- Arquitectura plug-and-play que se ejecuta en un entorno de código
- Integración segura con diferentes entornos sandbox

## Instalación
**Instalación rápida**

```
pip install rlms
```

**Instalación manual**

```
curl -LsSf https://astral.sh/uv/install.sh | sh
uv init && uv venv --python 3.12  # change version as needed
uv pip install -e .
```


## Ejecución
**Ejecución de prueba rápida**

```
make quickstart
```


## Si no programa
Utilizando la biblioteca RLM, cree una estructura que permita al modelo de lenguaje desglosar la entrada, analizarla y realizar llamadas recursivas dentro de sí mismo. Al crear una instancia de la clase RLM, defina la configuración del modelo que utiliza como backend y permita que el modelo interactúe con el entorno de código para resolver tareas complejas.
