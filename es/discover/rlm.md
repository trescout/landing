# Infraestructura para modelos recursivos de inteligencia artificial.

Desarrollado para modelos de lenguaje recursivo, rlm es una biblioteca de inferencia plug-and-play que admite diferentes entornos limitados. Esta herramienta basada en Python estandariza procesos complejos de modelos de lenguaje, haciéndolos más fáciles de integrar en diferentes sistemas.

## Qué aporta

- Gestión de contexto de longitud infinita
- Arquitectura plug-and-play que se ejecuta en un entorno de código
- Integración segura con diferentes entornos sandbox
