Busque rastros de ciberataques en dispositivos móviles

Mobile Verification Toolkit es una herramienta de informática forense utilizada para detectar brechas de seguridad en dispositivos móviles. Desarrollada en el lenguaje Python, este software analiza los datos del dispositivo para revelar posibles rastros de ciberataques.

Qué aporta

  • Recopila rastros forenses en dispositivos Android e iOS
  • Busca rastros de campañas de programas espía conocidos
  • Realiza análisis de seguridad con herramientas de línea de comandos

Instalación

Instalar con pip
pip3 install mvt
Instalar con uv
uv tool install mvt

Ejecución

Crear script de completado
mvt completion bash
