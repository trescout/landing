# Desarrollo de estándares en proyectos de inteligencia artificial

OpenSpec es una biblioteca TypeScript que admite procesos de desarrollo basados en especificaciones para asistentes de código de inteligencia artificial. Garantiza la estandarización de los requisitos técnicos durante las etapas de desarrollo de software y un progreso más controlado de los procesos de producción de código.

## Qué aporta

- Estandariza los requisitos técnicos antes de escribir código.
- Controla el proceso de desarrollo con inteligencia artificial
- Archiva cambios en una estructura de carpetas organizada

## Instalación

**Instalar la herramienta globalmente**

```
npm install -g @fission-ai/openspec@latest
```

## Ejecución

**Iniciar en el directorio del proyecto**

```
openspec init
```

Repositorio: https://github.com/Fission-AI/OpenSpec. Sigue las instrucciones oficiales del archivo README de este repositorio para la instalación y ejecución.

Antes de empezar, comprueba en qué sistema operativo estamos y si las herramientas necesarias (ej. Python, Node.js, Git, Docker) están instaladas. Instala las que falten paso a paso según este sistema.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.

Dime qué debería ver en la pantalla al final de cada paso. Si ocurre un error, te pegaré el mensaje de error tal cual y lo solucionaremos juntos.
