Plataforma de análisis y datos SEO de código abierto

Open SEO ofrece una alternativa de código abierto a herramientas pagas como Semrush y Ahrefs. Este software, desarrollado para analizar datos de optimización de motores de búsqueda (SEO), tiene como objetivo hacer que los procesos sean transparentes con su infraestructura basada en TypeScript.

Qué aporta

  • Paga sólo por lo que usas, sin cuotas de suscripción
  • Análisis de datos SEO directo con agentes de inteligencia artificial
  • Seguimiento de palabras clave y auditoría técnica del sitio

Instalación

Agregar capacidades a un agente de IA
npx skills add every-app/open-seo --skill '*'
Instalación local con Docker
docker compose pull
docker compose up -d
