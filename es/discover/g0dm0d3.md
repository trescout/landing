# Interfaz de interacción de IA sin restricciones

G0DM0D3 es una interfaz de chat de IA liberada que tiene como objetivo eludir las capas de seguridad de los modelos de lenguajes grandes. Desarrollado con TypeScript, este proyecto de código abierto permite a los usuarios interactuar con modelos sin restricciones.

## Qué aporta

- Múltiples análisis comparativos con más de 60 modelos.
- Soporte para ejecutar modelos en hardware local
- Motor de mezcla de entradas para pruebas del equipo rojo.

## Instalación

**Clona el repositorio e inícialo en el servidor local.**

```
# Clone the repository
git clone https://github.com/elder-plinius/G0DM0D3.git
cd G0DM0D3

# Open directly in your browser
open index.html
# or serve locally
python3 -m http.server 8000
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Usando la interfaz G0DM0D3, active el motor ULTRAPLINIAN, que ejecuta múltiples modelos a través de los proveedores de modelos que especifique (OpenRouter, Venice o servidor local). Aplicar técnicas de mezcla de entradas en lengua pársel para las investigaciones de mi equipo rojo y configurar automáticamente los parámetros de muestreo que mejor se adapten al contexto de la consulta con la función AutoTune.
