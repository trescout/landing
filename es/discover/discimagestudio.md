# Herramienta de grabado visual para discos ópticos

Disc Image Studio es una herramienta multiplataforma de creación e impresión de imágenes de disco que permite grabar imágenes visibles a simple vista en DVDs, CDs y discos Blu-ray de una sola capa. Desarrollado en C#, este software permite procesar gráficos personalizados en la superficie del disco utilizando cualquier unidad óptica grabable.

## Qué aporta

- Procesa gráficos personalizados visibles a simple vista en la superficie de discos DVD, CD y Blu-ray.
- Ofrece herramientas avanzadas de procesamiento de imágenes y sombreado para crear patrones en la superficie del disco.
- Tiene una estructura multiplataforma capaz de ejecutarse en Windows, Linux y macOS.

## Ejecución

**Iniciar la interfaz de línea de comandos**

```
dotnet run --project src/DiscImageStudio.Cli -c Release -- --help
```
