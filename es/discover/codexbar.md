# Monitorear los límites de uso de IA

CodexBar es una herramienta que permite ver los datos de uso de OpenAI Codex y Claude Code sin necesidad de iniciar sesión. Desarrollada con lenguaje Swift, esta aplicación facilita a los desarrolladores el seguimiento de las estadísticas de consumo en herramientas de codificación compatibles con IA.

- ★ 20.633
- Swift
- GitHub Trending · 2026-07-06

## Qué aporta
- Vea instantáneamente los límites de uso de todos los servicios de inteligencia artificial en la barra de menú
- Sigue los tiempos de reinicio del servicio con una cuenta regresiva
- No almacena contraseñas porque utiliza sesiones existentes, está orientado a la privacidad.

## Instalación
**Instalación con cerveza casera**

```
brew install --cask codexbar
```
