# Ahorre dinero acortando las respuestas de la IA

Caveman es un paquete de capacidades desarrollado para Claude Code que reduce el consumo de tokens en un 65 por ciento al simplificar el uso del lenguaje del modelo de inteligencia artificial. Esta herramienta tiene como objetivo reducir los costos de procesamiento al reducir comandos complejos a una estructura de lenguaje primitivo.

- ★ 102.818
- JavaScript
- GitHub Trending · 2026-07-03

## Qué aporta
- Ahorra hasta un 65% de tokens en respuestas de IA.
- Elimina palabras innecesarias sin sacrificar la precisión técnica.
- Reduce los costos de transacción y aumenta la velocidad de respuesta.

## Instalación
**Configuración para macOS, Linux y WSL**

```
curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.sh | bash
```

**instalación para ventanas**

```
irm https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.ps1 | iex
```


## Ejecución
**Activar el modo**

```
/caveman
```


## Si no programa
A partir de ahora, da tus respuestas en modo Cavernícola. Elimine las palabras de relleno innecesarias y conserve únicamente la información concisa y los detalles técnicos. Redacte sus respuestas en oraciones cortas, concisas y fragmentadas; pero continúe transmitiendo bloques de código, comandos y mensajes de error completos y precisos.
