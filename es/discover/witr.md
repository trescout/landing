# Descubra el origen de los procesos del sistema

Witr es una herramienta de línea de comandos que monitorea procesos, puertos, contenedores o archivos en el sistema y determina qué fuente los inició. Este software, que permite a los usuarios realizar un seguimiento de las actividades en el sistema, ofrece soporte tanto de línea de comandos (CLI) como de interfaz de usuario basada en texto (TUI).

## Qué aporta

- Muestra paso a paso por qué funcionan los procesos.
- Supervisa en detalle las actividades portuarias y de contenedores
- Facilita el monitoreo del sistema con una interfaz interactiva

## Instalación

**Instalación rápida para sistemas Unix.**

```
curl -fsSL https://raw.githubusercontent.com/pranshuparmar/witr/main/install.sh | bash
```

**Instalación con el administrador de paquetes Homebrew**

```
brew install witr
```
