# Herramienta de recopilación de inteligencia de código abierto

SpiderFoot es una herramienta de Python que automatiza la recopilación de inteligencia de código abierto (OSINT) para procesos de mapeo de superficies de ataque y inteligencia de amenazas. Permite detectar vulnerabilidades de seguridad en activos digitales mediante la integración de varias fuentes de datos.

## Qué aporta

- Recopilación automática de datos con más de 200 módulos.
- Interfaz basada en web o soporte de línea de comando
- Mapeo completo de la superficie de ataque para activos digitales

## Instalación

**Instalación de la versión estable**

```
wget https://github.com/smicallef/spiderfoot/archive/v4.0.tar.gz
 tar zxvf v4.0.tar.gz
 cd spiderfoot-4.0
 pip3 install -r requirements.txt
 python3 ./sf.py -l 127.0.0.1:5001
```

**Instalación de la versión de desarrollo.**

```
git clone https://github.com/smicallef/spiderfoot.git
 cd spiderfoot
 pip3 install -r requirements.txt
 python3 ./sf.py -l 127.0.0.1:5001
```
