# Depuración del navegador para IA

Desarrollado para Chrome DevTools, este servidor permite codificar agentes de inteligencia artificial para gestionar procesos de depuración basados en el navegador. Trabajando a través del Protocolo de contexto modelo, esta herramienta permite a los agentes inspeccionar directamente aplicaciones web y automatizar procesos de depuración.

## Qué aporta

- Controla el navegador en vivo directamente
- Automatización de análisis de rendimiento
- Revisar solicitudes de red y errores de consola

## Instalación

**Global con npm**

```
npm install -g chrome-devtools-mcp
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Conéctese a mi sesión activa del navegador utilizando el servidor MCP de Chrome DevTools y analice los datos de rendimiento de mi aplicación web. Verifique las solicitudes de red, examine los errores de la consola y realice los pasos de depuración necesarios para solucionar cualquier problema que encuentre.
