Entorno de oficina para agentes de inteligencia artificial

Munder-Difflin es un mecanismo que permite que múltiples agentes de inteligencia artificial trabajen juntos en sistemas locales. Desarrollada con TypeScript, esta herramienta facilita la gestión de sistemas de agentes autónomos que comparten tareas complejas en un entorno local.

  • ★ 1.669
  • TypeScript
  • GitHub Trending · 2026-08-18

Qué aporta

  • Coordina herramientas de IA basadas en terminales como un equipo autónomo.
  • Permite a los agentes obtener memoria a largo plazo y la capacidad de enviarse mensajes entre sí.
  • Ofrece la oportunidad de seguir los procesos de trabajo de los agentes a través de una interfaz visual de oficina.

Instalación

Descargue e inicie la aplicación
git clone https://github.com/chaitanyagiri/munder-difflin.git
cd munder-difflin
npm install        # postinstall rebuilds node-pty against Electron's ABI
npm run dev        # launches the Electron app with hot reload

Ejecución

Creación y vista previa del lanzamiento de producción.
npm run build      # production build via electron-vite
npm run preview    # preview the production build

Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Asigne a mis agentes que trabajan en Munder Difflin la siguiente tarea: crear un equipo utilizando herramientas de inteligencia artificial basadas en terminales existentes, distribuir tareas a través de un agente administrador llamado Michael y completar todos los procesos de forma autónoma almacenándolos en una capa de memoria común.
