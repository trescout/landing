# Encuentre modelos de IA que se adapten a su hardware

Desarrollado con el lenguaje Rust, llmfit escanea cientos de grandes modelos y proveedores de lenguajes y te permite identificar aquellos compatibles con tu hardware con un solo comando. La herramienta automatiza el proceso de búsqueda de modelos que mejor se adapten a los recursos del sistema local.

## Qué aporta

- Detecta automáticamente modelos compatibles con tu sistema
- Ordena por memoria, velocidad y calidad.
- Proporciona una gestión sencilla con una interfaz interactiva

## Instalación

**Instalación para macOS o Linux**

```
brew install AlexsJones/llmfit/llmfit
```

**Instalación rápida**

```
curl -fsSL https://llmfit.axjns.dev/install.sh | sh
```

## Ejecución

**Iniciando la interfaz interactiva**

```
llmfit
```
