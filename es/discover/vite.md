# Entorno de desarrollo rápido para proyectos web.

Vite ofrece un entorno de desarrollo rápido y una herramienta de creación para proyectos web modernos. Funciona como una herramienta de frontend que reduce los tiempos de espera en el proceso de desarrollo mediante el uso de módulos ES nativos.

## Qué aporta

- Inicio instantáneo del servidor gracias a los módulos ES nativos
- Proceso de desarrollo ininterrumpido con reemplazo rápido de módulos
- Empaquetado de código optimizado para producción

## Instalación

**Crear proyecto Vite**

```
npm create vite@latest my-app
cd my-app
npm install
```

## Ejecución

**Iniciar servidor de desarrollo**

```
npm run dev
```
