# Nodo de IA para Windows

OpenClaw ofrece una suite de administración integrada en el sistema operativo Windows a través del nodo de Windows, la aplicación de la bandeja del sistema, la biblioteca compartida y la extensión de la paleta de comandos PowerToys. Desarrollada en lenguaje C#, esta herramienta tiene como objetivo estandarizar el acceso a los recursos del sistema y los flujos de trabajo de los usuarios.

## Qué aporta

- Proporciona acceso rápido al asistente de inteligencia artificial OpenClaw a través de la bandeja del sistema.
- Ofrece puerta de enlace local y gestión de conexiones en Windows.
- Permite sesiones en vivo, uso y seguimiento de nodos con el centro de comando.

## Ejecución

**Lanzamiento de la aplicación nativa**

```
.\run-app-local.ps1
```

**La conexión WebSocket a través de CLI es correcta**

```
dotnet run --project src/OpenClaw.Cli -- --help
```
