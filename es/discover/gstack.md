# Fábrica de desarrollo de software con inteligencia artificial

Gstack es un sistema basado en la configuración Claude Code de Garry Tan y consta de 23 herramientas especializadas que desempeñan diferentes roles, como director ejecutivo, diseñador y gerente de ingeniería. Esta estructura basada en TypeScript ofrece flujos de trabajo definidos para automatizar los procesos de desarrollo de software.

## Instalación

**Descargue e instale la herramienta en su computadora**

```
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/gstack
cd ~/gstack && ./setup
```

## Si no programa

Pegue esto en su agente (Claude Code · Codex · Antigravity)

Ahora sois mi equipo de ingeniería virtual. Analizar mi proyecto usando las herramientas de Gstack, determinar mi estrategia con /office-hours, crear mi plan de trabajo con /autoplan y verificar la calidad del código con /review. Automatice todas las etapas del proceso de desarrollo de software actuando como director ejecutivo, diseñador y gerente de ingeniería.

Repositorio: https://github.com/garrytan/gstack. Sigue las instrucciones oficiales del archivo README de este repositorio para la instalación y ejecución.

Antes de empezar, comprueba en qué sistema operativo estamos y si las herramientas necesarias (ej. Python, Node.js, Git, Docker) están instaladas. Instala las que falten paso a paso según este sistema.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.

Dime qué debería ver en la pantalla al final de cada paso. Si ocurre un error, te pegaré el mensaje de error tal cual y lo solucionaremos juntos.
