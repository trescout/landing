# Radar personal de seguimiento de noticias con inteligencia artificial

Thysrael/Horizon es una herramienta de seguimiento de noticias que recopila, filtra y resume noticias de diferentes fuentes utilizando inteligencia artificial. Este software, que prepara boletines diarios en inglés y chino, ayuda a los usuarios a gestionar el flujo de información presentando los contenidos junto con el contexto y las discusiones de la comunidad.

- ★ 12.645
- Python
- GitHub Trending · 2026-11-05

## Qué aporta

- Recopila y filtra automáticamente noticias de diferentes fuentes.
- Prepara boletines de resumen diarios en inglés y chino.
- Presenta las noticias junto con el contexto y las discusiones de la comunidad.

## Instalación

**Clonación e instalación del proyecto**

```
git clone https://github.com/Thysrael/Horizon.git
cd Horizon

# Install with uv (recommended)
uv sync

# Install test/development extras when needed
uv sync --extra dev

# Or with pip
pip install -e .
```

## Ejecución

**Iniciar el asistente**

```
uv run horizon-wizard
```
