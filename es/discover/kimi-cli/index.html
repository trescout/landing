Desarrollo asistido por IA en la terminal

Desarrollado por Moonshot AI, Kimi CLI es un agente de inteligencia artificial que funciona a través de una interfaz de línea de comandos (CLI). Esta herramienta basada en Python está diseñada para automatizar las interacciones de la línea de comandos en los procesos de desarrollo de software.

Qué aporta

  • Capacidad para leer y editar código.
  • Ejecutar comandos a través de terminal
  • Búsqueda web y planificación autónoma.

Instalación

Configuración del entorno de desarrollo
git clone https://github.com/MoonshotAI/kimi-cli.git
cd kimi-cli

make prepare  # prepare the development environment

Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Quiero que trabajes como agente de desarrollo dentro de la terminal. Mientras realizo mis tareas de desarrollo de software, leo y edito mis archivos de código, ejecuto los comandos de shell necesarios y planifico procesos de forma autónoma buscando en Internet cuando los necesito.
