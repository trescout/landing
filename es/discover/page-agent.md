# Gestionar interfaces web con lenguaje natural

Desarrollado por Alibaba, page-agent es un agente de interfaz gráfica de usuario en la página que permite controlar interfaces web con comandos de lenguaje natural. Escrita en TypeScript, esta herramienta ofrece un mecanismo de control basado en navegador para automatizar las interacciones web.

- ★ 28.366
- TypeScript
- GitHub Trending · 2026-06-26

## Qué aporta
- No se requieren extensiones de navegador ni Python
- Representación DOM basada en texto en lugar de captura de pantalla
- Integración con sus propios modelos de IA

## Instalación
**Instalación a través de NPM**

```
npm install page-agent
```


## Si no programa
Quiero gestionar interacciones en la página web con comandos de lenguaje natural usando PageAgent. Quiero que realice operaciones como hacer clic en botones de la página, completar formularios o ingresar datos usando el modelo de inteligencia artificial que he determinado.
