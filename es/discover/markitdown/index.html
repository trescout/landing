Prepara tus documentos para la inteligencia artificial

MarkItDown (Microsoft); Es una herramienta ligera de Python que convierte Word, PDF, PowerPoint, Excel y más en texto Markdown limpio que los modelos de lenguaje grandes pueden leer fácilmente. Convierte conservando títulos, listas y tablas dentro del documento.

  • ★ 170.726
  • Python
  • MIT
  • GitHub Trending · 29 May 2026

Nota de TreScout: Convierte archivos de Word, PDF y Excel en texto sin formato antes de enviarlos a la inteligencia artificial. Las tablas y los diseños complejos no siempre salen limpios; es necesario revisar el resultado; lo cual es mucho mejor que copiar y pegar manualmente.

Actualizaciones

  • 2 de agosto de 2026: Estrellas 128,420 → 170,726, última versión v0.1.7 (29 de julio de 2026).

Qué aporta

  • Convierte sus documentos en textos claros que la inteligencia artificial puede procesar.
  • Conserva las estructuras de encabezado, lista y tabla.
  • Ideal para tus procesos RAG y análisis de textos.

Instalación

Instalar desde PyPI (todas las funciones)
pip install 'markitdown[all]'

Ejecución

Convertir archivo a Markdown
markitdown belge.pdf > belge.md

Uso de ejemplo

informe.pdf · presentación.pptx · tabla.xlsx

Instalación + uso

Instale MarkItDown usando el comando pip install 'markitdown[all]' en la terminal, luego convierta un archivo PDF, Word, Excel o PowerPoint a Markdown ejecutando el comando 'markitdown filename.pdf > document.md'.
