# Herramienta de descarga de medios todo en uno

Omniget es una aplicación de escritorio de código abierto que permite descargar vídeos, música y libros de más de 1.800 plataformas. Con un reproductor de cursos, un lector de libros electrónicos y una biblioteca de música integrados, esta herramienta realiza las operaciones de descarga a través de una interfaz gráfica sin necesidad de utilizar la terminal.

## Qué aporta

- Descarga vídeos, música y libros electrónicos de más de 1.800 plataformas
- Ofrece herramientas integradas para reproducir y gestionar el contenido descargado
- Se gestiona fácilmente a través de una interfaz gráfica sin usar la terminal

## Instalación

**instalación para ventanas**

```
winget install -e --id tonhowtf.OmniGet
```

**configuración para macos**

```
brew install --cask tonhowtf/tap/omniget
```
