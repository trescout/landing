# Motor de astrología de código abierto ziwei doushu

Renhuai123/ziwei-doushu es un motor de TypeScript de código abierto que calcula cartas astrológicas de Ziwei Doushu basado en el sistema Tianji de Ni Haixia. El proyecto ofrece un amplio conjunto de datos de interpretación astrológica de 13 dimensiones (v4.0) que cubre fechas entre 1950 y 2026.

## Qué aporta

- Ofrece seiscientas setenta y cinco mil 命盘 (cartas natales) y un conjunto de datos de interpretación astrológica de trece dimensiones.
- Realiza cálculos de cartas en tiempo real y corrección de tiempo solar.
- Contiene un motor de astrología completo basado en el sistema Tianji de Ni Haixia.

## Instalación

**Clonar y preparar el proyecto**

```
git clone https://github.com/Renhuai123/ziwei-doushu.git
cd ziwei-doushu

# 安装依赖
npm install

# 配置环境变量（只看排盘可以跳过；AI 配置仅在你自己实现了 /api/* 接口时才用得上）
cp .env.example .env.local

# 启动开发服务器
npm run dev
```
