# Guía para gestionar tu propio servidor

La Guía de autohospedaje ofrece una guía completa para alojar y administrar aplicaciones de software en redes locales o servidores web dedicados. Proporciona recursos técnicos sobre temas como computación en la nube, modelos de lenguaje grandes, automatización y configuración de redes.

## Qué aporta
- Métodos de alojamiento de software en la red local.
- Información de configuración de hardware y servidor
- Gestión de herramientas de automatización y nube.

## Instalación
**Configuración de la interfaz del chatbot**

```
git clone https://github.com/mckaywrigley/chatbot-ui.git
```

**Instalando dependencias**

```
npm i
```


## Ejecución
**Iniciando el entorno de desarrollo**

```
npm run dev
```
