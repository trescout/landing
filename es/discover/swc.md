# Construya sus proyectos web a la velocidad de Rust

Desarrollado con el lenguaje Rust, SWC ofrece una plataforma de compilación y agrupación rápida para proyectos web. Acelera los procesos de desarrollo web modernos mediante el procesamiento de archivos JavaScript y TypeScript con alto rendimiento.

## Qué aporta
- Procesa archivos JavaScript y TypeScript a alta velocidad
- Proporciona infraestructura de alto rendimiento desarrollada con lenguaje Rust.
- Acelera los procesos de desarrollo web modernos

## Instalación
**Instalar dependencia del proyecto (npm)**

```
npm i -D @swc/core
```

**Global con npm**

```
npm install -g @swc/cli @swc/core
```


## Ejecución
**Compilar archivo TypeScript**

```
swc index.ts -o index.js
```
