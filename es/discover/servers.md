# Servidores de ejemplo para agentes de inteligencia artificial

Los servidores del Protocolo de Contexto de Modelo (MCP) permiten que los modelos de inteligencia artificial generativa accedan a fuentes de datos externos y herramientas a través de una interfaz estándar. Este protocolo permite que diferentes aplicaciones de inteligencia artificial se conecten de manera segura y coherente con bases de datos o herramientas de software.

## Qué aporta

- Permite que sus modelos de lenguaje grande (LLM) accedan de forma segura a archivos locales, almacenes de datos y memoria persistente.
- Puede conectar sus aplicaciones de inteligencia artificial con fuentes de datos externas revisando los ejemplos de servidores de referencia.
- Accede a plantillas listas para usar para desarrollar sus propios servidores utilizando diferentes kits de desarrollo de software (SDK).

## Instalación

**Instalación e inicio del servidor Git**

```
# With uvx
uvx mcp-server-git

# With pip
pip install mcp-server-git
python -m mcp_server_git
```

## Ejecución

**Ejecución del servidor de memoria**

```
npx -y @modelcontextprotocol/server-memory
```
