# Wifit3

Wifit3 es una herramienta de Python desarrollada para probar la seguridad de redes inalámbricas, que funciona únicamente con dispositivos USB y es compatible con diferentes sistemas operativos. Es una alternativa multiplataforma a Wifite, un popular software de seguridad que automatiza los procesos de auditoría de redes.
