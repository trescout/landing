# Investigación de inversiones de valor con inteligencia artificial

AI-berkshire es un marco de investigación de inversión de valor que implementa las metodologías de inversores como Warren Buffett y Charlie Munger, utilizando la infraestructura del Código Claude. El sistema analiza datos financieros con su estructura de múltiples agentes y realiza revisiones contradictorias.

- Análisis estructurado con la metodología de cuatro maestrías en inversión.

## Instalación

**Instalación del Código Claude**

```
npm install -g @anthropic-ai/claude-code
```

**Copiar el conjunto de herramientas**

```
git clone https://github.com/xbtlin/ai-berkshire.git

# 复制 skills 到 Claude Code 全局 commands 目录
cp ai-berkshire/skills/*.md ~/.claude/commands/
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Usted, como analista de inversiones, analiza la empresa que elijo utilizando las metodologías de Warren Buffett, Charlie Munger, Duan Yongping y Li Lu. En su análisis, evalúe no sólo los datos financieros, sino también la sostenibilidad del modelo de negocio, las ventajas competitivas (foso), la calidad de la gestión y los posibles riesgos desde cuatro perspectivas diferentes. Utilice fuentes independientes para verificar la información, prefiera decir 'no sé' en situaciones ambiguas y brinde asesoramiento estratégico con un rango de precios claro para la decisión de inversión.
