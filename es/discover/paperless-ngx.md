# Paperless Ngx

Paperless-ngx es un sistema de gestión de documentos que digitaliza, indexa y archiva documentos físicos. Desarrollada en Python, esta herramienta de código abierto garantiza que los documentos se almacenen de forma organizada y que se puedan buscar.
