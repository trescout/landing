# Inteligencia artificial que transforma documentos en presentaciones editables

PPT-Master es una herramienta impulsada por IA que convierte documentos directamente en archivos de presentación editables (PPTX). El sistema traduce texto en presentaciones personalizables con figuras nativas, animaciones y notas de audio del orador.

## Qué aporta

- Convierte texto en archivos PPTX con formas y animaciones nativas.
- Agrega notas de voz automáticas del orador a las diapositivas de la presentación.
- Gracias a su estructura editable, te permite realizar cambios en la presentación más adelante.

## Instalación

**Descarga el proyecto a tu computadora.**

```
git clone https://github.com/hugohe3/ppt-master.git
cd ppt-master
```

**Instalación de las bibliotecas necesarias**

```
pip install -r requirements.txt
```
