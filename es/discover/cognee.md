# Memoria permanente para su agente de IA

Cognee es una plataforma de código abierto que proporciona memoria a largo plazo entre sesiones a agentes de inteligencia artificial. Permite a los agentes almacenar y recuperar datos de forma estructurada, utilizando un motor de gráficos de conocimiento autohospedado.

## Instalación

**Instalación del paquete**

```
uv pip install cognee
```

## Ejecución

**Uso básico**

```
cognee-cli remember "Cognee turns documents into AI memory."
```

**Iniciando la interfaz**

```
cognee-cli -ui
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Al usar Cognee, quiero almacenar mis datos en una estructura de gráfico de conocimiento y permitir que mi agente recupere estos datos manteniéndolos en su memoria a largo plazo. Cree un flujo de trabajo que me permita memorizar datos con la función cognee.remember() y generar respuestas significativas basadas en estos datos con cognee.recall().
