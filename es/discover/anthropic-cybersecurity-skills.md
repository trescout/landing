# Habilidades de ciberseguridad para la IA

754 habilidades de ciberseguridad ya preparadas desarrolladas para agentes de inteligencia artificial; Cubre 26 dominios de seguridad diferentes y está asignado a 5 marcos centrales, como MITRE ATT&CK, NIST CSF, MITRE ATLAS. Claude Code funciona en más de 20 plataformas como GitHub Copilot, Codex, Cursor y Gemini CLI. (A pesar de su nombre, no es un proyecto oficial de Anthropic, sino un esfuerzo comunitario independiente).

- ★ 31.872
- Python
- Apache-2.0
- GitHub Trending · 26 May 2026

## Qué aporta
- Le da al agente los reflejos de un analista experimentado: sabe qué herramienta utilizar y cuándo.
- Las capacidades son compatibles con marcos de seguridad reconocidos (como MITRE, NIST).
- 26 áreas de seguridad diferentes, desde análisis forense hasta seguridad en la nube.
- Se puede utilizar en más de 20 plataformas de IA sin estar vinculado a una sola herramienta.

## Instalación
**Clonar repositorio oficial**

```
git clone https://github.com/mukul975/Anthropic-Cybersecurity-Skills.git
```


## Cómo empezar
Empaquetado en el estándar agentkills.io; Puedes agregarlo como una habilidad a tu asistente de IA. Los pasos de inicio rápido están disponibles en el repositorio. Valide cada capacidad en su contexto antes de la producción.

## ¿Cómo instalar, cómo utilizar?
Agregue esta biblioteca comunitaria de habilidades de ciberseguridad a Claude Code ejecutando 'npx skills add mukul975/Anthropic-Cybersecurity-Skills' en la terminal (tenga en cuenta que este no es el proyecto oficial de Anthropic), luego indique qué habilidades de seguridad están listas para usar.
