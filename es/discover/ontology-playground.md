# Diseñe ontologías de IA con Ontology-Playground

Desarrollada por Microsoft, Ontology-Playground es una aplicación web de código abierto que se utiliza para aprender ontologías y crear diseños visuales en Microsoft Fabric IQ. Esta herramienta completamente estática permite a los usuarios diseñar modelos de ontología, exportarlos en formato RDF/XML y compartir diagramas interactivos.

## Qué aporta

- Cree modelos de ontología con interfaz visual.
- Exportar a formato RDF/XML
- Explora datos con diagramas interactivos

## Instalación

**Instalación del proyecto en un entorno local.**

```
cd Ontology-Playground
npm install
```

**Iniciando el servidor de desarrollo**

```
npm run dev
```

## Si no programa

Pegue esto en su agente (Claude Code · Codex · Antigravity)

Quiero diseñar una ontología usando Ontology-Playground. Cargue la plantilla inicial seleccionando un campo como Comercio minorista, Atención médica o Finanzas. Luego, agregue nuevos tipos de entidades a esta plantilla, defina las relaciones entre ellos y muéstreme los pasos que necesito para exportar este modelo que creé en formato RDF/XML.

Repositorio: https://github.com/microsoft/Ontology-Playground. Sigue las instrucciones oficiales del archivo README de este repositorio para la instalación y ejecución.

Antes de empezar, comprueba en qué sistema operativo estamos y si las herramientas necesarias (ej. Python, Node.js, Git, Docker) están instaladas. Instala las que falten paso a paso según este sistema.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.

Dime qué debería ver en la pantalla al final de cada paso. Si ocurre un error, te pegaré el mensaje de error tal cual y lo solucionaremos juntos.
