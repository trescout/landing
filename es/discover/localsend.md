# Compartir archivos de forma segura entre dispositivos

LocalSend es una aplicación de código abierto que permite compartir archivos entre diferentes sistemas operativos. Crea una alternativa independiente de la plataforma a la función AirDrop que ofrecen los dispositivos Apple.

- ★ 88.401
- Dart
- GitHub Trending · 2026-08-13

## Qué aporta
- Transferencia rápida de archivos sin necesidad de conexión a Internet
- Comunicación perfecta entre diferentes sistemas operativos
- Transferencia de datos segura con cifrado HTTPS
