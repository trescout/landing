# Comparte archivos y mensajes en una red local

Comparte archivos y mensajes entre dispositivos cercanos en una red local. LocalSend funciona sin conexión a internet ni servidor de terceros y utiliza cifrado HTTPS.

- ★ 88.882
- GitHub Trending · 2026-08-13

## ¿Qué hace esta herramienta?
LocalSend es una aplicación gratuita y de código abierto para compartir archivos y mensajes entre dispositivos Windows, macOS, Linux, Android e iOS en una red local. Utiliza una API REST y cifrado HTTPS, sin exigir una cuenta ni inicio de sesión.

## ¿Para quién es?
Personas que quieren compartir archivos o mensajes entre dispositivos conectados a la misma red local, incluso con sistemas operativos distintos.

## Qué no esperar
Personas que necesitan transferir archivos entre redes diferentes por internet o esperan actualizaciones automáticas dentro de la aplicación.

## Aspectos destacados
- Funciona sin conexión a internet ni servidor de terceros.
- Es compatible con Windows, macOS, Linux, Android e iOS.
- No requiere crear una cuenta ni iniciar sesión.
- Utiliza una API REST y cifrado HTTPS para la comunicación local.

## Primer flujo de uso
- Instala la versión adecuada para tu dispositivo desde el sitio oficial, una tienda de aplicaciones o un gestor de paquetes.
- Conecta los dispositivos que quieras usar a la misma red local.
- Si hay problemas de conexión, comprueba en el firewall el tráfico entrante TCP y UDP en el puerto 53317.
- Elige un archivo o mensaje en la aplicación e inicia la transferencia.
