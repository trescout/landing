# Espacio de trabajo para agentes de codificación de inteligencia artificial

PI-Desktop es un agente de codificación de inteligencia artificial desarrollado con un principio de trabajo de prioridad local (local-first). Con su arquitectura basada en Electron (marco de desarrollo de aplicaciones de escritorio) y Rust (lenguaje de programación de sistemas), ofrece un entorno de desarrollo de software personalizable donde los usuarios pueden instalar sus propios complementos.

- ★ 1.990
- TypeScript
- GitHub Trending · 2026-09-10

## Qué aporta
- Gestione diferentes modelos de inteligencia artificial desde una única interfaz.
- Controle los permisos del agente para editar archivos y ejecutar comandos.
- Personalice el entorno de desarrollo con complementos y capacidades.

## Instalación
**Compilando desde el código fuente**

```
git clone https://github.com/vastsa/PI-Desktop.git
cd PI-Desktop

pnpm install

cargo build -p host-core
pnpm build:js

pnpm dev
```


## Ejecución
**Iniciar en modo de desarrollo**

```
pnpm dev
```
