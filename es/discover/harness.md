# Agentes expertos en diseño para Claude Code

Utilizando el sistema de equipo de agentes de Claude Code, Harness divide misiones complejas en equipos coordinados de agentes especializados. Con el comando 'Configurar un arnés para', diseña el equipo y las habilidades necesarias para ti.

## Qué aporta

- Divide misiones complejas en equipos de agentes especializados.
- Desarrolla las habilidades que los equipos necesitan.
- Automatiza los flujos de trabajo.

## Cómo empezar

Agregado como habilidad a Claude Code; Luego, puedes pedirles que establezcan un equipo de agentes para el área que desees.

## ¿Cómo instalar, cómo utilizar?

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Instale el complemento Harness ejecutando los comandos '/plugin Marketplace add revfactory/harness' y luego '/plugin install Harness@harness-marketplace' en Claude Code, luego pídale que configure un equipo de agentes de inteligencia artificial adecuado para mi proyecto diciendo "Crear un arnés para este proyecto".

**Código Claude · mercado + instalación**

```
/plugin marketplace add revfactory/harness
/plugin install harness@harness-marketplace
```
