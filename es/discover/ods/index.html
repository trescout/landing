Transforma tu ordenador en un servidor local de inferencia de IA

Osmantic/ODS dota a ordenadores personales de inferencia local de LLMs, canalizaciones RAG vectoriales y orquestación de agentes sin depender de la nube.

Qué obtienes

  • Privacidad absoluta y ejecución local: Ejecute modelos de IA en su propio hardware sin enviar datos a plataformas en la nube.
  • RAG integrado con búsqueda vectorial: Indexe notas privadas y proyectos de software para realizar búsquedas semánticas precisas.
  • Capacidades multimodales unificadas: Reúne generación de texto, transcripción con Whisper, síntesis de voz y creación de imágenes.
  • API local compatible con OpenAI: Redirija sus aplicaciones de IA favoritas a su servidor ODS local cambiando la URL de conexión.
  • Flujos de trabajo con agentes autónomos: Diseñe agentes capaces de interactuar con herramientas del sistema para resolver tareas complejas.

Instalación

Clonar el repositorio e instalar paquete
git clone https://github.com/Osmantic/ODS.git
cd ODS
pip install -e .

Ejecución

Iniciar el servidor local de IA
python -m ods.server --port 8000
# Web paneline http://localhost:8000 adresinden erişin

Arquitectura técnica y principio de funcionamiento

Osmantic/ODS opera una arquitectura modular que coordina inferencia local e indexación vectorial:

  • Motor de inferencia local (llama.cpp & vLLM): Carga modelos en formato GGUF con mínimo consumo de memoria y cuantización optimizada.
  • Base de datos vectorial embebida: Almacenamiento vectorial ligero con ChromaDB y SQLite para indexación y búsqueda documental.
  • Cola de tareas asíncrona y máquina de estados: Coordina bucles de razonamiento en múltiples fases y llamadas a herramientas del sistema.

Flujos de trabajo RAG locales y canalizaciones de agentes privados

ODS permite desplegar soluciones de IA avanzadas preservando la soberanía total de la información:

  • Análisis de documentos confidenciales: Consulte contratos y balances contables de forma segura mediante RAG sin exposición externa.
  • Asistente de programación privado: Indexe código propietario para habilitar sugerencias locales en editores como VS Code o Cursor.
  • Procesamiento en segundo plano con agentes: Programe tareas periódicas para examinar, resumir y transformar archivos locales.

Preguntas frecuentes

  • ¿Funciona totalmente sin conexión a internet? Sí. Una vez descargados los pesos, ODS puede operar en entornos aislados (air-gapped) sin conectividad de red.
  • ¿Qué formatos de modelos son compatibles? Es compatible con modelos cuantizados en GGUF (Llama 3, Mistral, Qwen) y formatos estándar de HuggingFace.
  • ¿Incluye interfaz gráfica en el navegador? Sí. Incorpora un panel web para administrar modelos, subir archivos e interactuar con agentes de chat locales.
  • ¿Puede ejecutarse en CPU sin tarjeta gráfica dedicada? Sí. Gracias a llama.cpp aprovecha instrucciones AVX2/AVX-512 para ofrecer buen rendimiento en CPU convencional.
