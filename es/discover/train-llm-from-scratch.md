# Entrene su propio modelo LLM desde cero

train-llm-from-scratch ofrece un método simple, paso a paso, para entrenar un modelo de lenguaje grande desde cero, desde la descarga del conjunto de datos hasta la generación de texto. Es un recurso práctico para tu proceso de aprendizaje.

- ★ 8.864
- Jupyter Notebook
- MIT
- GitHub Trending · 30 May 2026

## ¿Qué aprendes?
- Flujo de un extremo a otro que cubre la descarga de datos, la capacitación y la producción de textos.
- Método de aplicación basado en el funcionamiento interno del LLM.
- Uso práctico con portátiles de uso directo.

## ¿Cómo instalar, cómo utilizar?
**Repositorio de clones**

```
git clone https://github.com/FareedKhan-dev/train-llm-from-scratch.git
cd train-llm-from-scratch
```

**Instalar dependencias**

```
pip install -r requirements.txt
```
