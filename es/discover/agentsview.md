# Supervise sus agentes de codificación con inteligencia artificial

Agentsview es una herramienta de monitoreo que proporciona inteligencia de sesión local y datos analíticos para agentes de codificación. Este software, que admite más de veinte agentes, incluidos Claude Code y Codex, promete un rendimiento más rápido en comparación con la herramienta ccusage.

## Qué aporta

- Monitoriza las sesiones de todos tus agentes codificadores de inteligencia artificial desde un único centro.
- Calcule rápidamente las cantidades y los costos de los tokens usados.
- Proteja la privacidad manteniendo sus datos en su computadora local.

## Instalación

**macOS/Linux**

```
curl -fsSL https://agentsview.io/install.sh | bash
```

**ventanas**

```
powershell -ExecutionPolicy ByPass -c "irm https://agentsview.io/install.ps1 | iex"
```

## Ejecución

**Iniciar el servidor y acceder a la interfaz**

```
agentsview serve
```

**Ver resumen de costos diarios**

```
agentsview usage daily
```
