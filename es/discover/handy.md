# Transcriba su voz de forma local

cjpais/Handy es una aplicación de voz a texto gratuita y de código abierto que funciona completamente sin conexión. Desarrollada en Rust, esta herramienta ofrece una arquitectura extensible que permite a los usuarios procesar datos de voz de forma local.

## Qué aporta

- Convierte sus conversaciones en texto al instante sin necesidad de conexión a internet
- Protege su privacidad personal al no enviar datos de voz a servidores en la nube
- Escribe directamente en el campo de texto activo presionando un acceso directo configurable desde el teclado

## Instalación

**Sistemas Linux basados en Debian o Ubuntu**

```
sudo apt install ./Handy_*.deb
```
