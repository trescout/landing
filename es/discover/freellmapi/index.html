Agregue 34 proveedores LLM gratuitos bajo una API OpenAI unificada

FreeLLMAPI unifica 34 proveedores gratuitos de modelos de lenguaje bajo una interfaz compatible con OpenAI con enrutamiento inteligente y tolerancia a fallos.

  • ★ 21.410
  • TypeScript
  • GitHub Trending · 2026-08-28

Actualizaciones

  • 28 de agosto de 2026: 21.410 estrellas, integrando 34 proveedores gratuitos de IA con streaming en tiempo real.

Qué obtienes

  • 34 proveedores de modelos gratuitos: Pasarela unificada con Google Gemini, Groq, Cloudflare Workers AI y HuggingFace sin coste de suscripción.
  • Compatibilidad directa con la API de OpenAI: Punto de enlace /v1/chat/completions listo para usar con LangChain, LlamaIndex y librerías estándar.
  • Enrutamiento inteligente y tolerancia a fallos: Conmuta automáticamente a un proveedor alternativo si se alcanza un límite de peticiones o surge un error.
  • Streaming mediante Server-Sent Events (SSE): Reciba respuestas token por token en tiempo real con latencia mínima.
  • Despliegue ligero y versátil: Ejecutable mediante Docker o Node.js en segundos tanto en local como en servidores remotos.

Instalación

Clonar el repositorio e instalar dependencias
git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
npm install

Ejecución

Iniciar servidor y enviar consulta
npm start
# OpenAI uyumlu istek:
curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Merhaba!"}]}'

Arquitectura técnica y principio de funcionamiento

FreeLLMAPI opera como un proxy inverso que traduce peticiones con formato OpenAI a esquemas específicos de cada proveedor:

  • Capa de adaptadores de proveedores: Normaliza llamadas heterogéneas REST y WebSocket en respuestas JSON conformes a OpenAI.
  • Balanceo de carga y control de cuotas: Supervisa límites de tasa para dirigir peticiones a los modelos con mejor tiempo de respuesta.
  • Caché en memoria y reintentos automáticos: Almacena en caché consultas repetitivas y reintenta conexiones ante fallos temporales.

Enrutamiento de modelos y resiliencia ante fallos

Los desarrolladores utilizan FreeLLMAPI para realizar pruebas avanzadas sin incurrir en costes de API:

  • Evaluación comparativa de modelos: Envíe consultas idénticas a varios motores para medir precisión y tiempos de respuesta.
  • Prototipado y MVPs con coste cero: Construya aplicaciones con inteligencia artificial sin necesidad de tarjetas de crédito o claves de pago.
  • Continuidad con canalizaciones de reserva: Evite caídas en la aplicación redirigiendo dinámicamente el tráfico a modelos secundarios.

Preguntas frecuentes

  • ¿Necesito comprar claves de API para utilizar FreeLLMAPI? No. La herramienta agrupa 34 proveedores que ofrecen capas gratuitas o inferencia pública sin suscripciones.
  • ¿Qué modelos de lenguaje son compatibles? Es compatible con familias como Llama 3, Mistral, Gemma y puntos de acceso gratuitos de Google Gemini.
  • ¿Es apto para la privacidad corporativa? FreeLLMAPI opera localmente, si bien cada proveedor gratuito externo aplica sus propias políticas de privacidad.
  • ¿Funciona con LangChain o CrewAI? Sí. Al cumplir las especificaciones de OpenAI, basta con establecer la baseURL en localhost:3000/v1 para integrarlo al instante.
