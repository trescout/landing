# Contratos inteligentes que funcionan con datos de Internet.

GenLayer es una capa de ejecución descentralizada que permite que los contratos inteligentes interactúen directamente con datos en Internet. Esta plantilla (repetitiva) permite a los desarrolladores utilizar TypeScript para crear aplicaciones que se ejecutan en blockchain y pueden procesar datos externos.

- ★ 15.737
- TypeScript
- GitHub Trending · 2026-08-18

## Qué aporta
- Desarrollar contratos inteligentes que accedan directamente a datos de Internet
- Integre procesos de predicción y verificación impulsados por IA
- Acelere el desarrollo con herramientas de prueba rápidas

## Instalación
**Preparando el entorno Python**

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Iniciando la interfaz**

```
cd frontend
npm install
npm run dev
```


## Si no programa
Desarrolle un contrato inteligente GenLayer para mí. Este contrato debería poder extraer datos actualizados de Internet y tomar decisiones lógicas procesando estos datos con modelos de inteligencia artificial. Asegúrese de que el código cumpla con las reglas de linter para estar libre de errores y cree casos de prueba que se ejecuten directamente en la memoria para obtener comentarios rápidos durante el proceso de desarrollo.
