# Guía para intercambiar caras en imágenes

Faceswap basado en Python es un software de código abierto que permite reemplazar rostros en imágenes utilizando tecnología deepfake. Permite a los usuarios realizar operaciones de intercambio de caras en videos e imágenes.

- ★ 57.204
- Python
- GitHub Trending · 2026-07-30

## Qué aporta
- Cambio de rostro en imágenes y vídeos.
- Entrenamiento con modelos de aprendizaje profundo
- Extracción de rostros en contenido visual.

## Instalación
**Repositorio de clones**

```
git clone --depth 1 https://github.com/deepfakes/faceswap.git && cd faceswap
```


## Ejecución
**Asistente de configuración**

```
python setup.py
```
