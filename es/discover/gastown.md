# Gestión del espacio de trabajo para agentes de IA

Gas Town ofrece una infraestructura que permite que diferentes agentes de inteligencia artificial trabajen juntos como un administrador de espacio de trabajo de múltiples agentes. Desarrollada con el lenguaje Go, esta herramienta centraliza la coordinación entre agentes y la gestión de recursos en flujos de trabajo complejos.

## Qué aporta

- Coordina múltiples agentes de inteligencia artificial desde un único centro.
- Evite que los agentes pierdan contexto al reiniciar.
- Persista los procesos de negocio con almacenamiento basado en Git.

## Instalación

**Instalación con cerveza casera**

```
brew install gastown
```

**Crear un espacio de trabajo**

```
gt install ~/gt --git
```

## Ejecución

**Iniciando sesión de alcalde**

```
gt mayor attach
```

## Si no programa

Pegue esto en su agente (Claude Code · Codex · Antigravity)

Comencé una sesión de 'Alcalde' en mi espacio de trabajo de Gas Town. Quiero que analices mis proyectos actuales y las tareas en las que estoy trabajando, identifiques brechas en los flujos de trabajo actuales y crees un plan de siguiente paso para los procesos en curso. Priorizar el trabajo revisando las estructuras de 'plataforma' existentes y los registros de 'cuentas' para garantizar la coordinación entre agentes.

Repositorio: https://github.com/gastownhall/gastown. Sigue las instrucciones oficiales del archivo README de este repositorio para la instalación y ejecución.

Antes de empezar, comprueba en qué sistema operativo estamos y si las herramientas necesarias (ej. Python, Node.js, Git, Docker) están instaladas. Instala las que falten paso a paso según este sistema.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.

Dime qué debería ver en la pantalla al final de cada paso. Si ocurre un error, te pegaré el mensaje de error tal cual y lo solucionaremos juntos.
