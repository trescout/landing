# Tiempo de ejecución moderno de JavaScript y TypeScript

Deno es un entorno de ejecución moderno diseñado para lenguajes JavaScript y TypeScript. Desarrollada en lenguaje Rust, esta herramienta ofrece una infraestructura alternativa a la plataforma tradicional Node.js con su estructura orientada a la seguridad y el rendimiento.

- ★ 108.357
- Rust
- GitHub Trending · 2026-08-05

## Qué aporta
- Ejecuta de forma segura los lenguajes JavaScript, TypeScript y WebAssembly.
- Proporciona un alto rendimiento con su motor V8 y lenguaje Rust.
- Ofrece una infraestructura moderna y práctica para el desarrollo de servidores web.

## Instalación
**Instalación en sistemas Mac o Linux**

```
curl -fsSL https://deno.land/install.sh | sh
```

**Instalación con Homebrew en Mac**

```
brew install deno
```


## Ejecución
**Iniciando el archivo del servidor preparado**

```
deno run --allow-net server.ts
```
