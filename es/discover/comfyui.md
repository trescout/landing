# Inteligencia artificial modular en la producción visual

ComfyUI es una herramienta de visualización modular que proporciona una interfaz basada en nodos para modelos de difusión. Permite a los usuarios diseñar procesos complejos de procesamiento de imágenes con un diagrama de flujo visual y administrar estos procesos a través de API.

## Qué aporta

- Diseñe flujos de trabajo complejos sin escribir código con una interfaz basada en nodos.
- Crea imágenes, videos, audio y modelos 3D en una sola plataforma.
- Integre capacidades de inteligencia artificial en sus procesos de producción con soporte API.

## Instalación

**Instalación mediante línea de comando**

```
pip install comfy-cli
comfy install
```
