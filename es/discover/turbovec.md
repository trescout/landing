# Indexación de vectores de alto rendimiento con Rust

Construido sobre la infraestructura TurboQuant, turbovec es una herramienta de índice de vectores de alto rendimiento desarrollada con el lenguaje Rust. Gracias a los enlaces de Python, permite a los desarrolladores realizar operaciones de búsqueda basadas en vectores de forma rápida y eficiente.

## Qué aporta
- Reduce el uso de memoria al comprimir altamente los datos vectoriales.
- Proporciona adición instantánea de datos y búsqueda rápida sin requerir una fase de capacitación.
- Mantiene el rendimiento realizando operaciones de filtrado durante la búsqueda.

## Instalación
**Instalación para Python**

```
pip install turbovec
```

**Instalación para óxido**

```
cargo add turbovec
```
