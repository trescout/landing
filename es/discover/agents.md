# Agentes de IA de voz en tiempo real

LiveKit Agents es un marco de Python que se utiliza para desarrollar agentes de inteligencia artificial de audio y video en tiempo real. Permite a los desarrolladores crear interacciones de voz de baja latencia, lo que facilita la creación de sistemas de inteligencia artificial que respondan como los humanos.

## Qué aporta

- Crea interacciones vocales que producen respuestas similares a las humanas.
- El servidor de medios WebRTC es totalmente compatible con LiveKit.
- Admite llamadas telefónicas e intercambio de datos multimodo.

## Instalación

**Instalación de la biblioteca base**

```
pip install "livekit-agents[openai,deepgram,cartesia]"
```

**Agregar habilidades para el asistente de IA**

```
npx skills add livekit/agent-skills --skill livekit-agents
```
