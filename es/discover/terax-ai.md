# Entorno de desarrollo de IA orientado a terminales

Terax-ai, como entorno de desarrollo local de inteligencia artificial orientado a terminales (espacio de trabajo de desarrollo nativo de IA), llama la atención por su estructura de bajo tamaño de 7 megabytes. Desarrollada con TypeScript, esta herramienta ofrece a los desarrolladores la oportunidad de codificar con inteligencia artificial directamente a través del terminal.

- ★ 8.790
- TypeScript
- GitHub Trending · 2026-07-05

## Qué aporta
- Estructura ligera y rápida con un tamaño de 7-8 MB.
- Integración de IA con modelos nativos y soporte API
- Terminal acelerado por GPU y editor de código

## Instalación
**Iniciando el entorno de desarrollo**

```
pnpm install
pnpm tauri dev          # development
```


## Si no programa
Crear mensajes del sistema específicos para mi proyecto usando el panel de inteligencia artificial en Terax y administrar la memoria del proyecto a través del archivo TERAX.md. Acepte o rechace diferencias impulsadas por IA para ediciones de código y realice tareas de varios pasos con aprobación usando el modo de plan.
