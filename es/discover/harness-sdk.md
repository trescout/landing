# Kit de desarrollo para agentes de inteligencia artificial

Harness SDK es un kit de desarrollo de código abierto que ofrece control y gestión de extremo a extremo para agentes de inteligencia artificial. Compatible con los lenguajes Python y TypeScript, esta herramienta permite estandarizar agentes a nivel de producción que se ejecutan en diferentes modelos e infraestructuras en la nube.

## Qué aporta
- Es totalmente compatible con los lenguajes Python y TypeScript
- Admite diferentes modelos de inteligencia artificial e infraestructuras en la nube
- Ofrece memoria, gestión de sesiones e integración de herramientas

## Instalación
**Instalación con Python**

```
pip install strands-harness
```

**Instalación con TypeScript**

```
npm install @strands-agents/harness
```
