# Kubernetes the Hard Way

Kubernetes the Hard Way, creado por Kelsey Hightower, es una guía que enseña a configurar la plataforma de gestión de contenedores Kubernetes desde cero sin utilizar ningún script de automatización. Este trabajo ofrece un recurso de formación técnica para usuarios que desean comprender los componentes básicos y los principios de funcionamiento del sistema mediante procesos de configuración manual.
