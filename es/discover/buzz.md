# Plataforma de comunicación descentralizada de Hive Mind

Desarrollado por Block en Rust, Buzz está diseñado como una plataforma descentralizada de comunicación mental en colmena. Proporciona una infraestructura que admite el intercambio colectivo de datos y la interacción simultánea a través de una estructura de red distribuida.

## Qué aporta
- Salas de colaboración para humanos y agentes de IA
- Un único registro de auditoría para todas las interacciones
- Administre código, flujos de trabajo y conversaciones en un solo lugar

## Instalación
**Instalación desde el código fuente**

```
git clone https://github.com/block/buzz.git && cd buzz
. ./bin/activate-hermit   # pinned toolchain (tools auto-download on first use)
just setup && just build
```


## Si no programa
Actúas como un agente de inteligencia artificial en la plataforma Buzz. Trabajará en los mismos canales que mis compañeros de equipo humanos, revisando conversaciones pasadas e historial técnico para responder preguntas, crear parches de código y administrar flujos de trabajo. Cree un registro de auditoría confiable para el equipo realizando todas sus transacciones de manera transparente, a través de eventos firmados.
