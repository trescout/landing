# Ingeniería inversa con inteligencia artificial

Rea es una herramienta de ingeniería inversa (reverse engineering) basada en agentes de inteligencia artificial que analiza desde el comportamiento de las aplicaciones hasta los binarios nativos (native binaries). Desarrollado con TypeScript, este software tiene como objetivo descifrar la lógica de funcionamiento de sistemas complejos mediante procesos automatizados.

## Qué aporta

- Puede descifrar la lógica interna de aplicaciones web o de escritorio a las que no tiene acceso al código fuente con el soporte de inteligencia artificial.
- Se integra con los softwares de ingeniería inversa Hopper y Ghidra para analizar de forma segura los archivos binarios del sistema en su ordenador local.
- Puede aprender paso a paso cómo funciona una característica de software que le guste, con sus pruebas, y adaptarla a su propio proyecto.

## Instalación

**Iniciar el asistente de instalación**

```
npx rea-agents setup
```

**Instalación global con el gestor de paquetes npm**

```
npm install --global rea-agents
rea setup
```

## Ejecución

**Control del sistema y análisis de aplicación de muestra**

```
npx -y rea-agents@latest doctor
npx -y rea-agents@latest analyze /Applications/Notes.app
```
