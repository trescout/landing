## Qué aporta

- Puede entrenar modelos con 8 mil millones de parámetros en computadoras portátiles con 4 GB de memoria gráfica.
- Con el método de flujo de capas, no tiene que lidiar con instalaciones complejas superando restricciones de hardware.
- Podrás gestionar todo el proceso de formación a través de un único archivo de configuración.

## Instalación

**Configuración básica**

```
pip install "soup-cli[train]"
```

**Configuración con todas las funciones**

```
pip install "soup-cli[all]"
```

## Ejecución

**Empezar a entrenar**

```
soup init --template chat
soup train
```
