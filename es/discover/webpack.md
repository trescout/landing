# Paquete de módulos para proyectos web

Webpack es un paquete que agrupa JavaScript y otros activos web para ejecutarlos en el navegador. Permite cargar aplicaciones cuando sea necesario, gracias a la función de división de código que divide los módulos en partes manejables.

- ★ 65.959
- JavaScript
- GitHub Trending · 2026-08-05

## Qué aporta
- Combina archivos JavaScript para ejecutarse en el navegador.
- Reduce el tiempo de carga de la aplicación con su función de división de código.
- Puede preprocesar diferentes tipos de archivos como TypeScript.

## Instalación
**instalar con npm**

```
npm install --save-dev webpack
```

**instalación con hilo**

```
yarn add webpack --dev
```
