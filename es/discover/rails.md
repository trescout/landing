# Entorno de desarrollo para aplicaciones web basadas en bases de datos

Ruby on Rails es un entorno de desarrollo web (framework) basado en la arquitectura Modelo-Vista-Controlador (Model-View-Controller), utilizado para desarrollar aplicaciones web respaldadas por bases de datos. Su objetivo es estandarizar los procesos ofreciendo a los desarrolladores todas las herramientas necesarias en un solo lugar.
