# Estilo de cuadros

Checkstyle es una herramienta de análisis que ayuda a los programadores de Java a desarrollar software que cumpla con los estándares de codificación establecidos. Controla la calidad del código admitiendo estándares como la Guía de estilo de Google Java y las convenciones de código Sun.
