# Inteligencia artificial que se desarrolla a través de interacciones de usuarios

Desarrollado por NousResearch, Hermes Agent ofrece una infraestructura de agente autónomo que aprende de las interacciones del usuario y se desarrolla con el tiempo. Este sistema basado en Python utiliza el aprendizaje continuo para crear flujos de trabajo personalizados.

## Qué aporta
- Capacidades autónomas que evolucionan con el tiempo aprendiendo de las interacciones del usuario.
- Oportunidad de trabajar integrado con plataformas como Telegram, Discord y Slack.
- Capacidad de cambiar entre diferentes modelos de inteligencia artificial sin cambiar el código.

## Instalación
**Instalación para Linux, macOS y WSL2**

```
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```


## Ejecución
**Iniciando la interfaz**

```
hermes
```
