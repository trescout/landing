# Habilidades de experto en seguridad para Claude

Claude-Red es una biblioteca de habilidades de seguridad ofensiva integradas en el sistema de capacidades del modelo de inteligencia artificial Claude. Su objetivo es automatizar las pruebas de seguridad ofreciendo metodologías de nivel experto en temas como la inyección SQL y la evasión de sistemas de protección de puntos finales.

- Python

## Qué aporta
- Proporciona acceso a metodologías de seguridad ofensiva
- Convierte al modelo de inteligencia artificial en un experto en pruebas de penetración
- Carga automáticamente las habilidades necesarias

## Instalación
**Descargar todas las habilidades**

```
git clone https://github.com/SnailSploit/claude-red ~/.claude/skills/claude-red
```

**Instalación interactiva**

```
./install.sh                           # interactive
./install.sh --target ~/.claude/skills # explicit target
./install.sh --category web            # single category
```
