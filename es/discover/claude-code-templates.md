# Configuraciones listas para usar para Claude Code

Las plantillas de Claude Code proporcionan una interfaz de línea de comandos (CLI) para la herramienta Claude Code que simplifica la configuración y el monitoreo. Esta herramienta basada en Python estandariza el control de los desarrolladores sobre el asistente de codificación y la gestión del flujo de trabajo.

## Qué aporta
- Más de cien agentes de IA listos para usar y acceso a comandos
- Rápida integración y gestión de enlaces para servicios externos.
- Análisis y seguimiento en tiempo real para sesiones de desarrollo.

## Instalación
**Iniciar configuración interactiva**

```
npx claude-code-templates@latest
```

**Instalación de componentes personalizados**

```
npx claude-code-templates@latest --agent development-tools/code-reviewer --yes
```


## Ejecución
**Ver análisis de sesión**

```
npx claude-code-templates@latest --analytics
```

**Abrir el panel de seguimiento del chat**

```
npx claude-code-templates@latest --chats
```
