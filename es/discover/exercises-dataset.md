# Conjunto de datos de ejercicios físicos multilingües

El conjunto de datos de ejercicios (conjunto de datos de ejercicios) compartido por Hasaneyldrm ofrece 433 movimientos físicos diferentes con nombres, grupos de músculos objetivo, equipos e instrucciones visuales. Este recurso integral proporciona una infraestructura de datos estructurada para quienes desarrollan aplicaciones de tecnología deportiva.

- Guía lista para la integración de API y bases de datos

## Cómo empezar

Esta herramienta no requiere ninguna instalación. Después de descargar los archivos de la página de GitHub a su computadora, puede revisar los ejercicios abriendo el archivo 'index.html' con cualquier navegador de Internet y acceder a la base de datos y a la guía de instalación de API abriendo el archivo 'setup.html'.
