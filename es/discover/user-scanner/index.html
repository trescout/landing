Desarrollado con Python, User-Scanner es una herramienta de inteligencia de código abierto (OSINT) que recopila datos de más de 465 fuentes diferentes a través de una única dirección de correo electrónico o nombre de usuario. Diseñado para investigadores de seguridad y rastreadores digitales, el software ofrece un análisis de datos en profundidad con una amplia gama de vectores de escaneo.
