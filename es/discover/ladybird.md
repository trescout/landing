# Navegador web independiente Ladybird

Ladybird es un nuevo navegador web desarrollado independientemente de los principales motores de navegador existentes. Escrito en C++, este proyecto tiene como objetivo proporcionar una alternativa de código abierto basada en estándares de Internet.

- ★ 65.040
- C++
- GitHub Trending · 2026-08-09

## Qué aporta
- Ofrece una nueva estructura independiente de los motores de navegador existentes.
- Proporciona una alternativa de código abierto basada en estándares de Internet.
- Tiene como objetivo una experiencia de navegación segura y duradera con su arquitectura multiprocesamiento.
