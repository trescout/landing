# Proyecto de navegador y motor independiente

Ladybird es un proyecto independiente de navegador web y motor de navegador basado en los estándares web. El README oficial lo describe como pre-alpha y destinado únicamente a desarrolladores; su arquitectura multiproceso separa las conexiones de red y la decodificación de imágenes.

## ¿Qué hace esta herramienta?
Ladybird es un proyecto de código abierto de navegador y motor de navegador. Funciona en Linux, macOS, Windows con WSL2 y otros sistemas similares a Unix. El sitio del proyecto señala como objetivo una primera versión Alpha en 2026 para Linux y macOS, mientras que la guía de compilación requiere Qt 6.9+, un compilador compatible con C++23, Rust y CMake 3.30+.

## ¿Para quién es?
Desarrolladores que quieren estudiar tecnologías de navegadores, contribuir al proyecto o compilar el código fuente en un entorno de desarrollo.

## Qué no esperar
Personas que buscan un navegador estable para el uso diario.

## Aspectos destacados
- Proyecto independiente de navegador y motor basado en los estándares web.
- Arquitectura multiproceso con procesos separados para conexiones de red y decodificación de imágenes.
- Procesos renderer de pestañas ejecutados en sandbox.
- Licencia BSD-2-Clause.

## Instalación
**Clona el código fuente**

```

```

**Entra en el directorio del proyecto**

```
cd ladybird
```


## Ejecución
**Compila y ejecuta**

```

```
