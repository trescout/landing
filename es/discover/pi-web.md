# Interfaz web para agente de codificación Pi

Pi-web ofrece una interfaz de usuario mejorada basada en web (UI web) para el agente de codificación Pi. Esta herramienta, escrita en lenguaje TypeScript, permite gestionar los procesos de codificación a través de una interfaz visual.

## Qué aporta

- Escanee visualmente sesiones de codificación pasadas
- Vista previa de archivos a través del navegador
- Administre la configuración del modelo y la capacidad desde la interfaz

## Instalación

**Puesta en marcha rápida sin instalación**

```
npx @agegr/pi-web@latest
```

**Subir globalmente**

```
npm install -g @agegr/pi-web
pi-web
```
