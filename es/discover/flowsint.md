# Visualización de amenazas cibernéticas basada en gráficos

Flowsint ofrece una plataforma de investigación visual, flexible y extensible basada en gráficos para analistas e investigadores de ciberseguridad. Desarrollada con TypeScript, esta herramienta facilita la visualización y el análisis de conjuntos de datos complejos.

## Qué aporta
- Analizar relaciones entre entidades en una interfaz gráfica visual.
- Procese datos de IP, dominio y redes sociales con enriquecedores automáticos
- Garantizar una alta confidencialidad almacenando todos los datos en la máquina local

## Instalación
**Comandos de configuración**

```
git clone https://github.com/reconurge/flowsint.git
cd flowsint
make prod
```


## Ejecución
**Iniciando el entorno de desarrollo**

```
make dev
```
