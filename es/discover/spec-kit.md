# Desarrollo basado en especificaciones con inteligencia artificial

Publicado por GitHub, spec-kit ofrece las herramientas necesarias para iniciar procesos de desarrollo basados en especificaciones. Esta biblioteca basada en Python facilita la integración de especificaciones técnicas definidas durante la fase de desarrollo de software en los procesos de código.

## Qué aporta

- Convierte especificaciones técnicas en procesos de código ejecutable.
- Proporciona resultados consistentes y predecibles durante la fase de desarrollo de software.
- Aumenta la velocidad de desarrollo al trabajar integrado con agentes de codificación de IA.

## Instalación

**Instalación de la herramienta CLI**

```
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@vX.Y.Z
```

## Ejecución

**Comenzando el proyecto**

```
specify init my-project --integration copilot
cd my-project
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Cuando utilice un agente de codificación de IA, defina los estándares de calidad y rendimiento utilizando el comando /speckit.constitution para determinar las líneas base del proyecto. Luego, explique los objetivos de la aplicación que desea crear con /speckit.specify, especifique su arquitectura técnica con /speckit.plan y, finalmente, cree la lista de tareas con /speckit.tasks y desarrolle la aplicación con el comando /speckit.implement.
