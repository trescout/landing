# Crea modelos tridimensionales a partir de imágenes.

Modly es una aplicación de escritorio que crea modelos 3D a partir de imágenes y realiza todas las operaciones en la tarjeta gráfica local (GPU). Esta herramienta, que funciona sin necesidad de conexión a Internet, lleva el proceso de modelado apoyado en inteligencia artificial a los ordenadores personales.

- ★ 7.347
- TypeScript
- GitHub Trending · 2026-08-14

## Qué aporta
- Convierte fotos a modelos 3D en la computadora local
- Funciona completamente sin conexión y no requiere conexión a Internet
- Ofrece una estructura flexible que se puede ampliar con modelos externos.

## Instalación
**Instalando dependencias**

```
npm install
```

**Preparando la infraestructura de Python**

```
cd api
python -m venv .venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate  # Linux / macOS
pip install -r requirements.txt
```


## Ejecución
**Iniciando la aplicación**

```
# Windows
launch.bat

# Linux / macOS
./launch.sh
```


## Si no programa
Quiero convertir una imagen en un modelo 3D usando la aplicación Modly. Ayúdame a configurar el flujo 'Imagen -> Generar malla -> Agregar a escena' yendo a la pestaña 'Flujos de trabajo' en la aplicación. Luego permítanme comenzar la generación del modelo 3D seleccionando el flujo de trabajo relevante en la pestaña "Generar". Si recibo un error, ¿cómo puedo analizar el problema en la sección 'Configuración/Registros/Errores'?
