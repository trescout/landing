## ¿Qué hace esta herramienta?
Clean Code JavaScript es una guía de código abierto que adapta los famosos principios de 'Clean Code' de Robert C. Martin al ecosistema de JavaScript. Ilustra estándares para escribir código legible, reutilizable y sostenible con JavaScript moderno.

## ¿Para quién es?
Para aquellos que desean mejorar la calidad de su código JavaScript y desarrollar software sostenible bajo estándares profesionales.

## Qué no esperar
Para principiantes absolutos que aún no conocen el lenguaje JavaScript ni siquiera a un nivel básico.

## Aspectos destacados
- Adapta los principios tradicionales de la ingeniería de software a JavaScript.
- Presenta prácticas de código bueno y malo de forma comparativa, una al lado de la otra.
- Proporciona un amplio alcance, desde la nomenclatura de variables hasta la gestión de errores.

## Primer flujo de uso
- Visite el repositorio oficial de GitHub para revisar la tabla de contenidos.
- Lea los ejemplos de código 'Malo' (Bad) y 'Bueno' (Good) para los conceptos que le resulten especialmente difíciles.
- Ponga en práctica los principios aprendidos aplicándolos en sus propios proyectos.
