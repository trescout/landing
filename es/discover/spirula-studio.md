# Spirula Studio

Spirula Studio es una herramienta educativa multiplataforma que convierte vídeos en representaciones de escenas tridimensionales (3D Gaussian Splatting) y las transforma en mallas (mesh). El software ofrece un entorno de trabajo compatible con diferentes fabricantes de hardware mediante el uso de interfaces gráficas Vulkan o CUDA.
