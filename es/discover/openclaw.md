# El asistente de inteligencia artificial personal que se ejecuta en tu dispositivo

Openclaw es una herramienta de automatización basada en inteligencia artificial capaz de realizar tareas en diferentes sistemas operativos y plataformas. Desarrollado con TypeScript, este software permite a los usuarios estandarizar y automatizar operaciones en la computadora.

## Qué aporta

- Mantienes tus datos, memoria e información de cuentas completamente seguros en tu propia computadora.
- Puedes chatear con tu asistente a través de las aplicaciones de mensajería WhatsApp, Telegram, Discord y la herramienta de comunicación laboral Slack.
- Puedes gestionar fácilmente diferentes modelos de inteligencia artificial y herramientas del sistema local desde un único centro.

## Instalación

**Ejecutar el script de instalación automática (ma**

```
# macOS / Linux / WSL2
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Globalmente con el administrador de paquetes de Node.js, npm**

```
npm install -g openclaw@latest --allow-scripts=openclaw
```
