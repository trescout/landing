# Plataforma que combina diseño y software

Penpot es una herramienta de diseño de código abierto que fortalece la colaboración entre diseñadores y desarrolladores. Gracias a su interfaz basada en vectores, permite gestionar los procesos de diseño de forma integrada con la fase de codificación.

- ★ 57.989
- Clojure
- GitHub Trending · 2026-06-18

## Qué aporta
- Integra procesos de diseño con código.
- Ofrece estándares abiertos y tokens de diseño.
- Proporciona colaboración en equipo en tiempo real

## Instalación
**Descargue el archivo de redacción oficial**

```
curl -o docker-compose.yaml https://raw.githubusercontent.com/penpot/penpot/main/docker/images/docker-compose.yaml
```


## Ejecución
**Inicio (http://localhost:9001)**

```
docker compose -p penpot -f docker-compose.yaml up -d
```
