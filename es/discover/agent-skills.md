# Dar talento de ingeniería a agentes de inteligencia artificial

Esta biblioteca, desarrollada para agentes de codificación de inteligencia artificial, ofrece habilidades de ingeniería a nivel de producción. Proporciona herramientas estandarizadas para aumentar la capacidad técnica de los agentes que automatizan los procesos de desarrollo de software.

- ★ 91.114
- Shell
- GitHub Trending · 2026-06-10

## Qué aporta
- Proporciona flujos de trabajo de ingeniería profesionales a agentes de inteligencia artificial.
- Automatiza los procesos de desarrollo de software con pasos estandarizados.
- Disciplina los procesos de prueba y revisión para mejorar la calidad del código.

## Instalación
**Instalación local para Claude Code**

```
git clone https://github.com/addyosmani/agent-skills.git
claude --plugin-dir /path/to/agent-skills
```


## Si no programa
Quiero que trabajes como ingeniero de software. Usando la biblioteca Agent Skills, aplico los comandos /spec, /plan, /build, /test, /review, /code-simplify y /ship de acuerdo con los estándares en cada etapa de mi proceso de desarrollo de software. Produzca código siguiendo flujos de trabajo, puntos de control de calidad y mejores prácticas de ingeniería.
