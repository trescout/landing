# Editor de vídeo con IA para macOS

Palmier Pro fue desarrollado como un editor de video que se ejecuta en el sistema operativo macOS y ofrece herramientas de edición compatibles con inteligencia artificial. Esta aplicación, escrita en lenguaje Swift, tiene como objetivo combinar flujos de trabajo basados ​​en inteligencia artificial con el rendimiento del sistema local.

## Qué aporta
- Producción de vídeo y visual con inteligencia artificial en línea de tiempo.
- Integración con Claude, Codex y Cursor a través de MCP
- Rendimiento Swift nativo para dispositivos Apple Silicon

## Cómo empezar
- Fuente oficial →
Descargue e instale la aplicación Palmier Pro en su dispositivo macOS usando el enlace de descarga en la página oficial de GitHub. Después de ejecutar la aplicación, puede iniciar sesión para utilizar herramientas de inteligencia artificial o configurar integraciones MCP desde el menú Ayuda dentro de la aplicación.
