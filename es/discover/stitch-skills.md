# Capacidades de diseño para agentes de IA

Desarrollada por Google Labs, Stitch Skills es una biblioteca de habilidades de agente diseñada para funcionar con el servidor Stitch MCP. Siguiendo estándares abiertos, esta biblioteca tiene como objetivo estandarizar los flujos de trabajo para agentes de codificación como Gemini CLI y Cursor.

## Qué aporta

- Flujo de trabajo estandarizado entre código y diseño.
- Generación automática de componentes React y React Native
- Extraiga y gestione sistemas de diseño a partir del código.

## Instalación

**Instalación para Claude Code**

```
npx plugins add google-labs-code/stitch-skills --scope project --target claude-code
```

**Configuración del cursor**

```
npx plugins add google-labs-code/stitch-skills --scope workspace --target cursor
```

## Ejecución

**Ver comandos de ayuda**

```
npx plugins --help

npx skills --help
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Analizar mi código de interfaz existente usando la biblioteca Stitch Skills e importarlo a un proyecto de Stitch. Luego, cree componentes de React utilizando este sistema de diseño y verifique que el proyecto cumpla con los estándares de diseño.
