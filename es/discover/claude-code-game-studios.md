# Estudio de videojuegos completo impulsado por inteligencia artificial

Claude-Code-Game-Studios es un proyecto que tiene como objetivo transformar la herramienta de desarrollo de software Claude Code en un estudio de juegos integral. Ofrece un sistema de coordinación que imita la jerarquía de un estudio real utilizando 49 agentes de inteligencia artificial y 72 habilidades de flujo de trabajo (workflow skills).

## Qué aporta

- Ofrece la oportunidad de gestionar todos los procesos, desde el diseño de juegos hasta la fase de pruebas, con equipos de inteligencia artificial.
- Crea una jerarquía de estudio disciplinada gracias a agentes de inteligencia artificial especializados.
- Proporciona estándares de codificación listos para usar y mecanismos de control para motores de juegos populares.
