# Convierta documentos PDF para IA

Desarrollado por AllenAI, olmocr es un conjunto de herramientas que convierte documentos PDF en formatos de texto adecuados para modelos de lenguaje grandes. Este software facilita los procesos de preparación de conjuntos de datos al proporcionar un procesamiento lineal de estructuras de documentos complejas.

- ★ 19.259
- Python
- GitHub Trending · 2026-07-02

## Qué aporta
- Convierte formatos de imagen y PDF para limpiar texto Markdown
- Procesa ecuaciones, tablas y diseños complejos en el orden de lectura correcto.
- Borra automáticamente la información del encabezado y pie de página

## Instalación
**Instalación de dependencias del sistema**

```
sudo apt-get update
sudo apt-get install poppler-utils ttf-mscorefonts-installer msttcorefonts fonts-crosextra-caladea fonts-crosextra-carlito gsfonts lcdf-typetools
```

**Creando un entorno Python**

```
conda create -n olmocr python=3.11
conda activate olmocr
```
