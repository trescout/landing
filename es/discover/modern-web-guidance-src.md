# Calibra las guías de desarrollo web moderno

GoogleChrome/modern-web-guidance-src es un repositorio de recursos que contiene el código y la documentación necesarios para crear, calibrar y evaluar guías de desarrollo web moderno. Desarrollado en TypeScript, este proyecto permite gestionar contenidos de guías orientados a los estándares web.

## Qué aporta

- Reemplaza los antiguos hábitos de escritura de código de los agentes de codificación de inteligencia artificial con los estándares web actuales.
- Importa guías de desarrollo listas para usar, enfocadas en la compatibilidad con navegadores y el rendimiento, directamente al contexto del agente.
- Prioriza las características nativas del navegador y las soluciones ligeras en lugar de bibliotecas innecesarias.

## Instalación

**Instalación con asistente interactivo**

```
npx modern-web-guidance@latest install
```

**Instalación alternativa opcional**

```
npx modern-web-guidance@latest install --choose
```

## Ejecución

**Búsqueda de guías y reemplazo de estructuras antiguas en el código**

```
# Search for relevant guides
npx modern-web-guidance@latest search "animate a dialog modal backdrop"

# Retrieve a guide by ID
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"

# Scan a codebase for legacy patterns to modernize
npx modern-web-guidance@latest legacy-scan .
```
