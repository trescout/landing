Modelo que analiza los mercados financieros

Kronos es un modelo básico diseñado para analizar los patrones únicos de los mercados financieros. Se centra en analizar la compleja estructura de los datos de mercado y se utiliza en estudios de finanzas cuantitativas y aprendizaje automático.

Instalación

Clonar repositorio oficial
git clone https://github.com/shiyu-coder/Kronos.git
cd Kronos
pip install -r requirements.txt

Ejecución

Ejecutar predicción de ejemplo
python examples/prediction_example.py

¿Qué hace?

  • Proporciona la base para modelar patrones de mercado.
  • Se puede ajustar como modelo básico.
  • Proporciona una base sólida para la investigación y la PNL financiera.

nota honesta

Este es un modelo de investigación; No es un consejo de inversión ni una herramienta de obtención de ingresos ya preparada. Eres responsable de las decisiones financieras.

¿Cómo instalar, cómo utilizar?

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Instale el modelo de pronóstico financiero de Kronos: descargue el repositorio y ejecute 'pip install -r requisitos.txt' en él, luego ejecute el script 'python ejemplos/prediction_example.py' para generar un pronóstico de precios en datos de línea K (gráfico de velas) y graficar el resultado.
