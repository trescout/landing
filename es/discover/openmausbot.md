# Equipo de bots de inteligencia artificial centrado en el chat

OpenMausBot es una alternativa de código abierto a Grok Bot que te permite crear tu propio equipo de bots de inteligencia artificial dentro de aplicaciones de chat. El software incluye compatibilidad con una máquina virtual que los bots pueden utilizar.

- ★ 7.628
- TypeScript
- GitHub Trending · 2026-10-30

## Actualizaciones

- **30 de octubre de 2026:** Estrellas 7,621 → 7,628, última versión v0.1.134 (30 de octubre de 2026).

## Qué aporta

- Puedes gestionar tu propio equipo de bots de inteligencia artificial a través de Electron, la infraestructura de aplicaciones de escritorio.
- Puedes almacenar tu historial de chat y tus datos en tu ordenador local en lugar de en la nube.
- Puedes asignar diferentes modelos de inteligencia artificial a tus bots mediante la integración de la herramienta de interfaz de línea de comandos (CLI).

## Instalación

**Instalación y ejecución del paquete OpenMausBot**

```
npm install -g openmausbot
openmausbot
```
