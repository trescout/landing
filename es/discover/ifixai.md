# Audite agentes de inteligencia artificial

iFixAi es una herramienta de auditoría independiente que verifica si los agentes de inteligencia artificial cumplen correctamente con las tareas asignadas. Desarrollado en lenguaje Python, este sistema analiza la precisión de los procesos en menos de dos minutos, ya sea ejecutado por un humano o por el propio agente.

## Qué aporta

- Prueba si sus agentes de inteligencia artificial están realizando sus tareas correctamente.
- Ofrece un informe de análisis detallado en menos de dos minutos.
- Detecta con antelación las vulnerabilidades del sistema y los errores pasados por alto.

## Instalación

**Instalar el paquete**

```
pip install "ifixai[openai]"   # or anthropic, gemini, etc.: install the provider extra you'll test
```

**Abra el asistente de instalación**

```
ifixai setup                    # arrow-key wizard: pick provider, model, judge, suite → writes ifixai.yaml
```

## Ejecución

**Ejecute la herramienta**

```
ifixai run                      # no flags needed; reports land in ./ifixai-results/
```
