Espacio de trabajo unificado para agentes de IA

holaOS es un espacio de trabajo de código abierto que combina diferentes agentes de inteligencia artificial (Claude Code, Codex) con tus herramientas, aplicaciones y archivos en una memoria común. Con más de 100 integraciones y compatibilidad con Model Link Protocol (MCP), permite a los usuarios administrar sus propios modelos (BYOK) o modelos integrados en una única interfaz.

Qué aporta

  • Ejecuta diferentes agentes como Claude Code y Codex en una única interfaz con memoria compartida.
  • Con un solo clic se conecta a más de 50 herramientas comerciales populares como Gmail, Notion y Slack.
  • Puede utilizar modelos de IA integrados o agregar sus propias claves API.

Instalación

Comando de instalación rápida
curl -fsSL https://raw.githubusercontent.com/holaboss-ai/holaOS/refs/heads/main/scripts/install.sh | bash -s -- --launch

Ejecución

Iniciando el entorno de desarrollo
npm run desktop:dev
