# Seguimiento de ubicación a través de números de móvil y nombres de usuario

GhostTrack, basado en Python, es una herramienta que permite el seguimiento de la ubicación a través de números de móvil. Este software de código abierto fue desarrollado para detectar los datos geográficos del número objetivo.

- ★ 14.877
- GitHub Trending · 2026-06-08

## Qué aporta
- Detecta datos de geolocalización de números móviles
- Recopila información a través de nombres de usuario de redes sociales.
- Funciona integrado con herramientas auxiliares para el seguimiento de direcciones IP.

## Instalación
**Clonar + dependencias (Linux · Python 3)**

```
git clone https://github.com/HunxByts/GhostTrack.git && cd GhostTrack && pip3 install -r requirements.txt
```


## Ejecución
**correr**

```
python3 GhostTR.py
```
