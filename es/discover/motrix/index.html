Gestor de descargas moderno y completo

Motrix es un gestor de descargas integral desarrollado con TypeScript que satisface todas las necesidades de descarga de archivos. Ofrece a los usuarios la oportunidad de gestionar diferentes protocolos como HTTP, FTP y BitTorrent a través de una única interfaz.

Actualizaciones

Qué aporta

  • Gestiona los protocolos HTTP, FTP y BitTorrent desde una única interfaz
  • Limita las velocidades de descarga y ofrece gestión avanzada de sesiones.
  • Inicia descargas con un solo clic con complementos del navegador

Instalación

Instalación de la interfaz de línea de comando
npm install -g @motrix/cli

Ejecución

Iniciando la descarga del archivo
motrix add https://example.com/file.iso --save-dir ~/Downloads

Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Ayúdame a administrar las tareas de descarga usando la interfaz de línea de comandos de Motrix. Utilice 'motrix list' para ver la lista de descargas, 'motrix add [URL] --save-dir [DIRECTORIO]' para agregar un nuevo archivo y 'motrix watch --stats' para seguir el progreso de la descarga en vivo. Si necesito conectarme a un servidor remoto, active el comando 'motrix pair'.
