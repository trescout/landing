# Análisis de vídeo con inteligencia artificial

Claude-video es una herramienta de Python que le da al modelo Claude la capacidad de analizar contenido de video. Al descargar vídeos, dividirlos en fotogramas y convertirlos en texto (transcripción), el software lleva los datos visuales a un formato que el modelo de inteligencia artificial puede procesar.

- ★ 16.553
- Python
- GitHub Trending · 2026-07-07

## Qué aporta
- Analiza vídeos fotograma a fotograma.
- Produce automáticamente subtítulos y transcripciones.
- Procesa videos locales o en línea.

## Instalación
**Instalación general**

```
npx skills add bradautomates/claude-video -g
```


## Ejecución
**Iniciar análisis de vídeo**

```
/watch https://youtu.be/dQw4w9WgXcQ what happens at the 30 second mark?
```


## Si no programa
Quiero que analices el video que compartí usando la herramienta Claude Video. Responde el contenido del vídeo, sus momentos importantes y las preguntas que hago, en base a los fotogramas visuales del vídeo y la transcripción del audio. Si no hay subtítulos en el video, convierta el audio a texto usando Whisper API y analícelo examinando los detalles visuales (fotogramas).
