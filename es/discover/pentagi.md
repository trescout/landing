# Inteligencia artificial para pruebas de penetración autónomas

Desarrollado con el lenguaje Go, Pentagi ofrece un sistema de agentes de inteligencia artificial (agentes de IA) totalmente autónomos que pueden realizar pruebas de penetración complejas. El sistema tiene como objetivo estandarizar flujos de trabajo autónomos para detectar y explotar vulnerabilidades.

- ★ 21.475
- Go
- GitHub Trending · 2026-07-10

## Qué aporta
- Pruebas de seguridad totalmente autónomas en entorno Sandboxed Docker
- Soporte para más de 20 herramientas profesionales como Nmap y SQLmap.
- Monitoreo detallado del sistema con Grafana y Prometheus

## Ejecución
**Iniciar el servicio**

```
curl -O https://raw.githubusercontent.com/vxcontrol/pentagi/master/docker-compose.yml
docker compose up -d
```
