# Gestión de inteligencia artificial múltiple en terminal.

Desarrollado con el lenguaje Rust, herdr funciona como un agente multiplexor que se ejecuta en el terminal. Esta herramienta permite a los usuarios gestionar múltiples agentes de inteligencia artificial simultáneamente en el entorno del terminal.

- ★ 9.203
- Rust
- GitHub Trending · 2026-07-01

## Qué aporta
- Gestiona múltiples agentes de inteligencia artificial simultáneamente en un único terminal.
- Supervise instantáneamente el estado de trabajo de los agentes con indicadores de colores.
- Mantenga las sesiones ejecutándose en segundo plano incluso si se pierde la conexión.

## Instalación
**Instalación para Linux y macOS**

```
curl -fsSL https://herdr.dev/install.sh | sh
```


## Ejecución
**Iniciando la herramienta**

```
herdr
```


## Si no programa
Quiero gestionar todos mis agentes de inteligencia artificial que se ejecutan en el terminal desde un único centro y ver instantáneamente el estado de funcionamiento (en espera, en ejecución, completado) de cada uno de ellos. Utilice Herdr para ayudarme a configurar estos agentes para separarlos en diferentes espacios de trabajo y pestañas para que los procesos continúen en segundo plano incluso si cierro la terminal.
