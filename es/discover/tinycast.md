# Lanzador de aplicaciones ligero para macOS

Tinycast es un lanzador de aplicaciones ligero, gestor de atajos y herramienta de historial de portapapeles desarrollado para el sistema operativo macOS. Este software nativo, escrito en Swift, tiene como objetivo acelerar los flujos de trabajo de escritorio utilizando los recursos del sistema de manera eficiente.

- ★ 6.290
- Swift
- GitHub Trending · 2026-09-18

## Qué aporta
- Software nativo que utiliza los recursos del sistema de manera eficiente
- Soporte para ejecutar extensiones de Raycast directamente
- Gestión de historial de portapapeles y plantillas de texto

## Instalación
**Añadir el repositorio al sistema**

```
brew trust --tap abue-ammar/tinycast   # required for third-party taps
brew tap abue-ammar/tinycast
```


## Si no programa
Para activar las funciones de inteligencia artificial en Tinycast, defina su propia clave API o la información de una cuenta de IA configurada desde el menú de Ajustes. Después de este proceso, podrá iniciar chats directamente desde la paleta y realizar operaciones rápidas como corrección gramatical, resumen o traducción en textos seleccionados.
