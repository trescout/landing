# Sistema de inicio de sesión japonés compatible con inteligencia artificial

Desarrollado con el lenguaje Rust, Karukan es un sistema de método de entrada japonés (Japanese Input Method System) que utiliza un motor de conversión neuronal kana-kanji para sistemas operativos Linux y macOS. El software va más allá de los métodos tradicionales y ofrece un enfoque basado en inteligencia artificial para los procesos de conversión de texto.

## Qué aporta

- Conversión kana-kanji neuronal basada en GPT-2
- Conversión de texto en vivo en tiempo real mientras escribes
- motor de predicción inteligente que aprende las elecciones del usuario

## Cómo empezar

Para usarlo con fcitx5 en Linux, debes seguir los pasos de instalación en los archivos README en la carpeta karukan-fcitx5, y para macOS en la carpeta karukan-macos. Dado que los archivos de modelo se descargarán automáticamente desde Hugging Face la primera vez que se utilicen, el proceso de conversión inicial puede tardar algún tiempo.
