# Entrene y ejecute modelos de IA locales

Unsloth es una biblioteca que acelera el entrenamiento y ejecución de modelos de lenguaje grandes (LLM) y modelos de difusión en un entorno nativo. Hace que los procesos de ajuste de modelos populares sean más accesibles al optimizar el uso de la memoria.

- ★ 75.531
- Python
- GitHub Trending · 2026-08-14

## Qué aporta
- Ejecute modelos de lenguaje grandes y herramientas de renderizado en su computadora local.
- Realice procesos de ajuste dos veces más rápido y con un 70% menos de uso de memoria.
- Integre agentes de desarrollo de software como Claude Code con sus modelos nativos.

## Instalación
**Configuración para macOS, Linux y WSL**

```
curl -fsSL https://unsloth.ai/install.sh | sh
```


## Ejecución
**Iniciar el agente de desarrollo de software**

```
unsloth start claude
```
