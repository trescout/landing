# Aporta originalidad a los diseños de IA

Hallmark es un archivo de estilo desarrollado para reducir el impacto del contenido estándar producido por inteligencia artificial (AI slop) en el diseño. Claude Code garantiza que las interfaces utilizadas en herramientas como Cursor y Codex adquieran una estética única y humana.

- ★ 26.349
- CSS
- GitHub Trending · 2026-07-13

## Qué aporta
- Evita la estética estándar de la IA
- Crea interfaces únicas con veinte temas diferentes.
- Audita y rediseña los códigos existentes.

## Instalación
**Añadir vehículo**

```
npx skills add nutlope/hallmark
```


## Si no programa
Cree un diseño de interfaz único que no parezca creado por IA utilizando el archivo de estilo Hallmark. Evite las plantillas estándar en el diseño, elija la adecuada entre veinte temas diferentes y cree una estructura única que superará cincuenta y siete pruebas de calidad.
