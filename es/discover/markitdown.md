# Prepara tus documentos para la inteligencia artificial

MarkItDown (Microsoft); Es una herramienta ligera de Python que convierte Word, PDF, PowerPoint, Excel y más en texto Markdown limpio que los modelos de lenguaje grandes pueden leer fácilmente. Convierte conservando títulos, listas y tablas dentro del documento.

## Qué aporta

- Convierte sus documentos en textos claros que la inteligencia artificial puede procesar.
- Conserva las estructuras de encabezado, lista y tabla.
- Ideal para tus procesos RAG y análisis de textos.

## Instalación

**Instalar desde PyPI (todas las funciones)**

```
pip install 'markitdown[all]'
```

## Ejecución

**Convertir archivo a Markdown**

```
markitdown belge.pdf > belge.md
```

## Uso de ejemplo

informe.pdf · presentación.pptx · tabla.xlsx
