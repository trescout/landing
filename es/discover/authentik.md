# Gestión central de identidades para sus aplicaciones

Authentik es una plataforma de seguridad de código abierto que proporciona autenticación centralizada y gestión de acceso para aplicaciones. Al combinar procesos de autenticación complejos en un único punto, ofrece una transición segura entre diferentes servicios.

## Qué aporta

- Proporciona transición segura entre diferentes servicios desde un único punto
- Admite protocolos estándar como SAML y OAuth2
- Escalable desde pequeños proyectos hasta sistemas de gran escala.

## Cómo empezar

Para la instalación, vaya a la página de documentación en el sitio web oficial. Puede elegir Docker Compose para instalaciones pequeñas o de prueba y Kubernetes para estructuras a gran escala. También es posible realizar la instalación a través de AWS o utilizar la tienda de aplicaciones DigitalOcean.
