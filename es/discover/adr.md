# Seguridad para agentes de IA empresarial

Desarrollado por Uber, ADR protege a los agentes corporativos de IA con observabilidad, evaluaciones comparativas de seguridad y métodos de detección de amenazas. El software ofrece un marco de seguridad desarrollado para aumentar la seguridad de los sistemas de inteligencia artificial.

- ★ 1.123
- Python
- GitHub Trending · 2026-08-05

## Qué aporta
- Supervisa las acciones realizadas por los agentes de IA, lo que le permite comprender qué hacen y por qué lo hacen.
- Prueba la seguridad de los agentes con más de 300 misiones contra 17 técnicas de ataque diferentes.
- Utiliza una arquitectura de dos etapas para detectar sesiones sospechosas.

## Instalación
**Preparando el sistema de detección**

```
git clone https://github.com/uber/ADR
cd ADR/Detection
uv sync
export ANTHROPIC_API_KEY="..." OPENAI_API_KEY="..."
```
