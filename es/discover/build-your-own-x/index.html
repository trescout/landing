Construya sus propias tecnologías desde cero

Build Your Own es una colección de guías paso a paso que le permiten reescribir sus tecnologías favoritas, como bases de datos, sistemas operativos, Git, Docker y lenguajes de programación, desde cero. Ofrece una experiencia de aprendizaje mediante la práctica, en consonancia con la filosofía de Feynman de "No puedo entender lo que no puedo crear".

Nota de TreScout: El repositorio de aprendizaje no es una herramienta para instalar: recopila tutoriales para escribir su propia base de datos, shell o Git desde cero. Es la forma más eficaz si realmente quieres entender una tecnología, pero no es un trabajo de dos horas por la tarde; cada guía lleva días.
