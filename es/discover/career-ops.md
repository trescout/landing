# Gestiona tu carrera con inteligencia artificial

Utilizando la infraestructura de Claude Code, Career-Ops automatiza los procesos de búsqueda de empleo respaldados por inteligencia artificial con 14 modos de habilidades diferentes. El sistema centraliza funciones como la gestión de lotes y la creación de currículums a través de un panel de control basado en Go.

## Qué aporta
- Filtre las ofertas de trabajo calificándolas en 10 dimensiones diferentes
- Crear un currículum compatible con ATS específico para la descripción del trabajo
- Gestión del proceso de solicitud de empleo por lotes a través de terminal

## Instalación
**Configuración básica**

```
git clone https://github.com/santifer/career-ops.git
cd career-ops && npm install
npx playwright install chromium
```

**Control del sistema**

```
npm run doctor
```
