# Enlaces de descarga directa desde servicios en la nube

LinkSwift es una herramienta que utiliza una infraestructura basada en JavaScript para obtener enlaces de descarga directa de archivos desde diversos servicios de almacenamiento en la nube. El software admite ocho plataformas en la nube populares diferentes, tales como Baidu Netdisk, Alibaba Cloud Drive, China Mobile Cloud y Quark Drive.

## Qué aporta

- Genera enlaces de descarga directa de archivos desde nueve servicios de almacenamiento en la nube diferentes, incluidos Baidu, Alibaba Cloud y Quark.
- Ofrece la posibilidad de transferir los enlaces obtenidos a programas como el gestor de descargas IDM o la herramienta de descarga de archivos Aria2.
- Simplifica la interfaz web de los servicios en la nube compatibles, eliminando la necesidad de instalar las aplicaciones de escritorio oficiales.

## Cómo empezar

Para utilizarlo, primero debe instalar en su navegador la extensión del administrador de scripts de usuario Tampermonkey. A continuación, puede añadir el script a su navegador haciendo clic en el enlace de instalación con extensión ".user.js" compartido en la página de GitHub o ScriptCat del proyecto. Una vez instalado el script, al acceder a un sitio de almacenamiento en la nube compatible, el menú de descarga directa aparecerá automáticamente en la interfaz.
