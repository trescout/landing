# Herramienta de gestión de alta velocidad para proyectos en Python

Desarrollado en el lenguaje de programación Rust, uv es una herramienta de alta velocidad diseñada para gestionar paquetes y proyectos de Python. Ofrece una alternativa centrada en el rendimiento a los gestores de paquetes tradicionales (pip, pip-tools).

## Qué aporta

- Completa las operaciones de gestión de paquetes entre 10 y 100 veces más rápido que las herramientas tradicionales.
- El lenguaje de programación descarga versiones de Python en tu ordenador y las organiza según tus proyectos.
- Realiza por sí solo las funciones de herramientas como pip, el gestor de paquetes que administra las dependencias de las bibliotecas.

## Instalación

**Instalación para macOS y Linux**

```
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**instalación para ventanas**

```
# On Windows.
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## Ejecución

**Actualizar la herramienta**

```
uv self update
```
