# Desarrollo web full-stack con Vue

Nuxt es un marco completo que se utiliza para desarrollar aplicaciones basadas en Vue. Ofrecida con soporte TypeScript, esta herramienta optimiza la representación del lado del servidor y los procesos de creación de sitios estáticos.

- ★ 60.726
- TypeScript
- GitHub Trending · 2026-07-12

## Qué aporta
- Representación del lado del servidor y generación de sitios estáticos
- Enrutamiento automático y división de código
- Entorno de desarrollo configurado con TypeScript

## Instalación
**Crear un nuevo proyecto**

```
npm create nuxt@latest <my-project>
```
