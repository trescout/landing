# Estudio de sonido con inteligencia artificial trabajando en un entorno local.

Voicebox es un estudio de voz de inteligencia artificial de código abierto que permite a los usuarios realizar clonación de voz, dictado y creación de contenido. Desarrollada con el lenguaje TypeScript, esta plataforma ofrece herramientas integrales para gestionar procesos de procesamiento de audio en el entorno nativo.

## Qué aporta

- Transcribe tu propia voz o la de otra persona en segundos.
- Proporciona voz en off y dictado natural en 23 idiomas diferentes.
- Proteja la privacidad manteniendo todos los datos de audio en su computadora local.

## Instalación

**Instalación desde el código fuente**

```
git clone https://github.com/jamiepine/voicebox.git
cd voicebox

just setup   # creates Python venv, installs all deps
just dev     # starts backend + desktop app
```
