# Agente de codificación de inteligencia artificial

QwenLM/qwen-code es un agente de codificación de inteligencia artificial de código abierto que funciona en la terminal, el editor, el escritorio y el navegador. Desarrollado en TypeScript, esta herramienta tiene como objetivo respaldar los procesos de desarrollo de software en diferentes plataformas.

## Qué aporta

- Te permite programar en la terminal, el escritorio, el navegador y el editor
- Ofrece flujos de trabajo dinámicos con memoria automática, capacidades y subagentes
- Utiliza diferentes servicios de inteligencia artificial y modelos locales con soporte multiprotocolo

## Instalación

**Instalación con NPM**

```
npm install -g @qwen-code/qwen-code@latest
```

**Instalación con Homebrew**

```
brew install qwen-code
```

## Ejecución

**Iniciar**

```
qwen
```
