# Gestiona tus agentes de IA desde la web

Hermes WebUI es una interfaz que le permite administrar agentes Hermes AI a través de un navegador web o dispositivos móviles. Le permite rastrear y controlar las interacciones de los agentes desde un único centro.

- ★ 16.850
- Python

- GitHub Trending · 1 Haziran 2026

## Qué aporta
- Administre sus agentes a través del navegador o el dispositivo móvil.
- Supervise todas las interacciones desde un punto central.
- Disfrute de la interfaz sencilla y fácil de usar.

## ¿Cómo instalar, cómo utilizar?
**Clonar y ejecutar bootstrap**

```
git clone https://github.com/nesquena/hermes-webui.git hermes-webui
cd hermes-webui
python3 bootstrap.py
```

**Ejecutar con script de inicio**

```
./start.sh
```
