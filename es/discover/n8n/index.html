Descubrir · GitHub · N8n

Automatice los flujos de trabajo entre aplicaciones

n8n es una plataforma de automatización de flujo de trabajo que fluye entre diferentes aplicaciones y procesos de automatización de negocios. Combinando una interfaz visual con un código personalizado escrito, esta herramienta puede rodar tanto na nuvem quanto en su propio servidor, con soporte para más de 400 integraciones.

Actualizaciones

  • 23 de agosto de 2026: Estrellas 201,890 → 201,895, última versión n8n@2.35.7 (21 de agosto de 2026).

Qué aporta

  • Diseñe procesos comerciales complejos con una interfaz visual
  • Conecte más de 1500 aplicaciones y servicios diferentes
  • Ejecute de forma segura en su propio servidor o en la nube

Instalación

Script de instalación rápida
curl -fsSL https://get.n8n.io | sh
Instalación manual con Docker
docker volume create n8n_data
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

Ejecución

Acceso a la interfaz
http://localhost:5678
