# Servidor de IA para computadoras Mac

Omlx es un servidor de inferencia de modelo de lenguaje grande (LLM) que admite procesamiento por lotes continuo y almacenamiento en caché SSD para procesadores Apple Silicon. Esta herramienta, administrada a través de la barra de menú de macOS, ofrece la oportunidad de ejecutar modelos de alto rendimiento en hardware local.

## Qué aporta
- Ejecutando modelos de alto rendimiento en procesadores Apple Silicon
- Gestión eficiente de la memoria con almacenamiento en caché SSD
- Fácil control del servidor desde la barra de menú

## Instalación
**Instalación con cerveza casera**

```
brew tap jundot/omlx https://github.com/jundot/omlx
brew install jundot/omlx/omlx
```


## Ejecución
**Iniciando el servicio en segundo plano**

```
omlx start
```
