# Herramienta de inteligencia artificial que escribe artículos académicos automáticamente

Desarrollado por Google Research, PaperOrchestra es un marco multi-agente que convierte ideas crudas y registros de experimentos en borradores en formato LaTeX académico. El software apoya la redacción de artículos de investigación automatizando la revisión de literatura y los procesos de generación de imágenes.

## Qué aporta

- Convierte ideas crudas en formato académico
- Realiza la revisión de literatura automáticamente
- Genera las imágenes y gráficos necesarios

## Instalación

**Configuración del entorno necesario**

```
conda create -n paper_orchestra python=3.11
    conda activate paper_orchestra
    pip install -r requirements.txt
```

## Ejecución

**Ejecución mediante script**

```
./paper_writing_cli.sh
```

**Ejecución mediante la línea de comandos**

```
python paper_writing_cli.py \
  --raw_materials_dir /path_to_your_raw_materials/ \
  --latex_template_dir /path_to_your_latex_template/ \
  --output_dir /path_to_your_output_folder/ \
  --use_plotting true
```
