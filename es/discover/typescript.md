# Error al comprobar proyectos de JavaScript

TypeScript, un superconjunto del lenguaje JavaScript, permite la verificación de errores durante la fase de compilación del código. Admite procesos de desarrollo de software más confiables y escalables con su función de escritura estática.

- ★ 110.042
- TypeScript
- GitHub Trending · 2026-07-11

## Qué aporta
- Comprobación de errores al escribir código
- Fiabilidad con identificación de tipo estática
- Procesos de desarrollo de software escalables

## Instalación
**instalación global con npm**

```
npm install -g typescript
```

**Agregar como dependencia del proyecto**

```
npm install --save-dev typescript
```


## Ejecución
**Compilar archivo TypeScript**

```
tsc index.ts
```
