- Crear modelos de ingresos basados en suscripción

- Boletín rápido y gestión de miembros

## Instalación

**Instalar la herramienta de línea de comando**

```
npm install ghost-cli -g
```

## Ejecución

**Iniciar instalación local**

```
ghost install local
```

**Iniciar la instalación en el servidor.**

```
ghost install
```
