# Plataforma moderna de contenidos y newsletters

Ghost es una plataforma tecnológica independiente para publicaciones modernas, membresías, suscripciones y boletines informativos por correo electrónico.

- ★ 55.071
- JavaScript
- GitHub Trending · 2026-08-22

## Qué aporta
- Crear modelos de ingresos basados en suscripción
- Publicación de contenidos moderna y profesional.
- Boletín rápido y gestión de miembros

## Instalación
**Instalar la herramienta de línea de comando**

```
npm install ghost-cli -g
```


## Ejecución
**Iniciar instalación local**

```
ghost install local
```

**Iniciar la instalación en el servidor.**

```
ghost install
```
