Entorno de aprendizaje por refuerzo para la robótica Microduck

Desarrollado por Pollen Robotics, microduck_rl proporciona entornos de aprendizaje por refuerzo basados en MuJoCo y mjlab para el robot bípedo Microduck.

  • ★ 1.001
  • Python
  • GitHub Trending · 2026-08-31

Actualizaciones

  • 31 de agosto de 2026: 1.001 estrellas, con motor de física MuJoCo mjlab y tareas de locomoción.

Qué obtienes

  • Simulación física de alta fidelidad en MuJoCo: Cálculo en tiempo real de pares articulares, fricción y dinámicas de contacto con el suelo.
  • Entornos de locomoción preparados: Funciones de recompensa optimizadas para marcha estable, equilibrio y superación de desniveles.
  • Transferencia directa Sim-to-Real: Políticas con aleatorización de dominio listas para su implementación en robots físicos.
  • Conjunto de algoritmos RL modernos: Compatible con Proximal Policy Optimization (PPO) y SAC.
  • Visualización 3D interactiva: Supervise la trayectoria y marcha del robot en tiempo real en el visor gráfico de la simulación.

Instalación

Clonar el repositorio e instalar entorno de simulación
git clone https://github.com/pollen-robotics/microduck_rl.git
cd microduck_rl
pip install -e .

Ejecución

Ejecutar entrenamiento o visualización de políticas
python -m microduck_rl.train --task walk
# Eğitilen politikayı simülatörde izleme:
python -m microduck_rl.enjoy --checkpoint checkpoint.pt

Arquitectura técnica y principio de funcionamiento

microduck_rl conecta el motor de física MuJoCo con la API de Gymnasium mediante mjlab:

  • Capa cinemática en MuJoCo y mjlab: Modelos declarativos MJCF/XML con cinemática articular, actuadores y propiedades inerciales.
  • Espacios de acción y observación Gymnasium: Vectores normalizados para consignas de par motor y telemetría de sensores IMU.
  • Aleatorización de dominio: Modifica dinámicamente masas, rozamientos y latencias para garantizar resistencia ante perturbaciones reales.

Simulación de física y políticas de control robótico

Investigadores de robótica aprovechan microduck_rl para diseñar controladores estables sin riesgo de daños en el hardware:

  • Cero riesgos para el hardware durante el aprendizaje: Evite averías en servomotores y caídas realizando la exploración en el simulador.
  • Entrenamiento acelerado en paralelo: Ejecute simulaciones a velocidades muy superiores al tiempo real para finalizar el entrenamiento en pocas horas.
  • Diseño de terrenos y obstáculos complejos: Incorpore pendientes, escalones y superficies irregulares para evaluar la capacidad de adaptación.

Preguntas frecuentes

  • ¿Se necesita el robot físico Microduck para usar esta librería? No. La biblioteca se ejecuta íntegramente en el simulador MuJoCo sin necesidad de disponer del robot físico.
  • ¿Es indispensable contar con GPU? MuJoCo ofrece excelente rendimiento en CPU, aunque una GPU compatible con CUDA reduce de forma notable los tiempos de entrenamiento.
  • ¿Cómo se traslada la política entrenada al robot real? El archivo de salida en formato ONNX o PyTorch se transfiere al procesador integrado del robot para gobernar los actuadores.
  • ¿Se puede adaptar a otros robots? Aunque está optimizado para Microduck, la arquitectura modular con mjlab admite adaptaciones a otros robots bípedos o cuadrúpedos.
