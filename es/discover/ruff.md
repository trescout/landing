# Linteador y formateador rápido de Python

Ruff es un linter y formateador de código Python extremadamente rápido desarrollado con el lenguaje de programación Rust. Se utiliza para mejorar la calidad del código y acelerar los procesos de formato en el desarrollo de software.

## Qué aporta

- Funciona decenas de veces más rápido en comparación con las herramientas existentes
- Combina las operaciones de análisis y formato de código en una sola herramienta
- Ofrece soporte de corrección automática de errores en proyectos de Python

## Instalación

**instalar con pip**

```
pip install ruff
```

**instalación con ultravioleta**

```
uv tool install ruff@latest
```

## Ejecución

**ejecutar análisis de código**

```
ruff check
```

**ejecutar formato de código**

```
ruff format
```
