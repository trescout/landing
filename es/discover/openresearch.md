# Espacio de trabajo de inteligencia artificial que acelera los procesos de investigación

AlphaXiv es un marco que le permite ejecutar agentes de investigación paralelos utilizando diferentes modelos de inteligencia artificial. Desarrollada en el lenguaje Rust, esta herramienta de código abierto tiene como objetivo acelerar los procesos de recopilación de datos en investigaciones académicas y técnicas.

## Qué aporta

- Crea sesiones de agentes independientes y paralelas para diferentes ideas de investigación.
- Proporciona trazabilidad al mantener juntos los resultados de los experimentos, los registros y los cambios de código.
- Gestiona ciclos de investigación de forma autónoma en su computadora local o en servidores remotos.

## Instalación

**Instalación en macOS o Linux**

```
curl -LsSf https://openresearch.sh/install.sh | sh
```

## Ejecución

**Iniciar el panel local**

```
orx up
```

## Si no programa

Pegue esto en su agente (Claude Code · Codex · Antigravity)

Quiero iniciar un proyecto de investigación en OpenResearch. Utilizando un agente de inteligencia artificial como Claude Code o OpenCode, quiero que realices una revisión bibliográfica, desarrolles hipótesis y diseñes experimentos para probar dichas hipótesis. A lo largo del trabajo, gestiona el proceso de forma autónoma registrando todos los hallazgos, resultados de experimentos y cambios de código en el espacio de trabajo local de OpenResearch.

Repositorio: https://github.com/alphaXiv/OpenResearch. Sigue las instrucciones oficiales del archivo README de este repositorio para la instalación y ejecución.

Antes de empezar, comprueba en qué sistema operativo estamos y si las herramientas necesarias (ej. Python, Node.js, Git, Docker) están instaladas. Instala las que falten paso a paso según este sistema.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.

Dime qué debería ver en la pantalla al final de cada paso. Si ocurre un error, te pegaré el mensaje de error tal cual y lo solucionaremos juntos.
