# Automatización de dispositivos móviles con inteligencia artificial

Mobile-mcp es un servidor de Protocolo de Contexto de Modelo (Model Context Protocol) que realiza tareas de automatización y extracción de datos en dispositivos móviles y simuladores. Esta herramienta permite que los modelos de inteligencia artificial interactúen directamente con las plataformas iOS y Android para ejecutar tareas.

- ★ 8.439
- TypeScript
- GitHub Trending · 2026-09-27

## Qué aporta
- Realizar pruebas de aplicaciones en dispositivos iOS y Android
- escanear automáticamente elementos de la pantalla y extraer datos estructurados
- gestionar emuladores y simuladores a través de una única interfaz

## Instalación
**Instalación con Claude**

```
claude mcp add mobile-mcp -- npx -y @mobilenext/mobile-mcp@latest
```

**Ejecución directa**

```
npx @mobilenext/mobile-mcp@latest
```


## Ejecución
**Iniciar servidor**

```
npx @mobilenext/mobile-mcp@latest
```


## Si no programa
Enumera las aplicaciones en los dispositivos móviles conectados y escanea los elementos en pantalla utilizando el servidor del Protocolo de Contexto de Modelo (Model Context Protocol) que se comunica con las herramientas de desarrollo móvil en mi computadora.
