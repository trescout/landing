# Entrenamiento de IA en Apple Neural Engine

Desarrollado por Maderix, ANE permite realizar el entrenamiento de redes neuronales en Apple Neural Engine a través de interfaces de programación de aplicaciones privadas (API privadas) obtenidas mediante ingeniería inversa. Este estudio permite utilizar directamente el hardware de Apple en procesos de entrenamiento de modelos de inteligencia artificial.

## Qué aporta
- Entrenamiento directo de redes neuronales en hardware de Apple
- Evitar restricciones de hardware con API personalizadas

## Cómo empezar
Este proyecto es un estudio de investigación que tiene como objetivo entrenar redes neuronales directamente en el hardware de Apple. Al descargar los archivos del proyecto desde el repositorio oficial de GitHub a su computadora, puede examinar cómo se utilizan las API especiales obtenidas mediante ingeniería inversa y realizar sus propios experimentos.
