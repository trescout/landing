# Descargar sitios web al disco local

El descargador de sitios web, desarrollado por AhmadIbrahiim, permite descargar todos los códigos fuente y activos de un sitio web a la computadora local usando Node.js. La herramienta se utiliza para archivar todo el sitio, incluidos archivos JavaScript, hojas de estilo e imágenes.

- ★ 4.223
- HTML
- GitHub Trending · 2026-07-08

## Qué aporta
- Archiva todos los recursos del sitio web
- Organiza enlaces para verlos sin conexión
- Guarda imágenes y archivos de estilo.

## Cómo empezar
- Fuente oficial →
Para comenzar a utilizar la herramienta, descargue los códigos de la página de GitHub a su computadora. Luego vaya a la carpeta del proyecto a través de la terminal, instale las dependencias necesarias e inicie la aplicación. Después de que se ejecute la aplicación, puede comenzar a descargarla accediendo a su dirección local a través de su navegador.
