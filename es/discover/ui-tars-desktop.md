# Interfaz de inteligencia artificial que gestiona tu ordenador

Desarrollado por ByteDance, UI-TARS es una infraestructura de agente de código abierto que integra modelos de IA multimodal con interfaces de escritorio. Este sistema permite la creación de agentes (agentes de IA) que realizan tareas de forma autónoma en la computadora mediante el procesamiento de datos visuales.

## Qué aporta

- Realice de forma autónoma tareas de escritorio y navegador
- Flujo de trabajo similar al humano mediante el procesamiento de datos visuales
- Integración total con modelos de IA multimodales

## Instalación

**Instalación global**

```
npm install @agent-tars/cli@latest -g
```

**Operación directa**

```
npx @agent-tars/cli@latest
```

## Ejecución

**Inicializar con el proveedor del modelo**

```
agent-tars --provider volcengine --model doubao-1-5-thinking-vision-pro-250428 --apiKey your-api-key
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Describe una tarea compleja que quieras que realice en mi computadora o navegador. Por ejemplo, podría pedirte que vayas a un sitio web específico e introduzcas datos o gestiones un proceso de reserva de vuelo. Analice la interfaz visual y complete los pasos de forma autónoma.
