# Reproducción de medios a través del navegador

Stremio es una aplicación de reproductor multimedia que combina diferentes proveedores de contenido en una sola interfaz. Esta versión basada en web permite a los usuarios ver series y películas a través del navegador sin necesidad de realizar ninguna instalación.

- ★ 13.631
- JavaScript
- GitHub Trending · 2026-09-07

## Qué aporta
- Reúne diferentes proveedores de contenido en una sola interfaz
- Sincroniza el historial de visualización y la biblioteca entre dispositivos
- Permite la transmisión de video a la televisión con Chromecast

## Instalación
**Configuración del entorno de desarrollo local**

```
pnpm install
pnpm start
```

**Instalación de contenedor con Docker**

```
docker build -t stremio-web .
docker run -p 8080:8080 stremio-web
```
