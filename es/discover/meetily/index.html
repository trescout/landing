Asistente de IA local que protege tus datos

Meetily es un asistente de reuniones de código abierto que procesa grabaciones de reuniones localmente y no requiere una conexión a la nube. Desarrollada en Rust, la aplicación ofrece transcripción de voz rápida, diario del hablante y capacidades de resumen con modelos de idioma local.

Qué aporta

  • Toda la transcripción y resumen de audio se realiza en su dispositivo.
  • No requiere conexión a la nube, tus datos no salen de tu computadora.
  • Funciona con modelos locales como Ollama o tus propios endpoints.

Instalación

Instalación desde código fuente en Linux
git clone https://github.com/Zackriya-Solutions/meeting-minutes
cd meeting-minutes/frontend
pnpm install
./build-gpu.sh
