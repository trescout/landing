# Copiar repositorios en flujos de trabajo de GitHub

Desarrollado por GitHub, Actions/Checkout es una herramienta que automatiza los procesos de checkout del repositorio en procesos de desarrollo de software. La integración continua permite transferir el código fuente al entorno de trabajo en flujos de trabajo.

## Actualizaciones

## Qué aporta

- Transferir el código fuente al entorno de trabajo.
- Operaciones automáticas de copia de almacén.
- Gestión segura de credenciales

## Cómo empezar

Puedes habilitar la herramienta para descargar tu repositorio al espacio de trabajo agregando la línea - uses: action/checkout@v7 a la sección de pasos de tu archivo de flujo de trabajo de GitHub Actions. Puede personalizar el comportamiento de la copia definiendo parámetros como profundidad de búsqueda o submódulos bajo el bloque with según sus necesidades.
