# Copiar repositorios en flujos de trabajo de GitHub

Desarrollado por GitHub, Actions/Checkout es una herramienta que automatiza los procesos de checkout del repositorio en procesos de desarrollo de software. La integración continua permite transferir el código fuente al entorno de trabajo en flujos de trabajo.
