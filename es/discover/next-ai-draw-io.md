# Creación automática de diagramas con inteligencia artificial.

Esta aplicación basada en Next.js combina la herramienta de diagramación draw.io con capacidades de IA generativa. Los usuarios pueden crear diagramas visuales mediante comandos de lenguaje natural y editar sus diagramas existentes con soporte de inteligencia artificial.

## Qué aporta
- Dibuja diagramas profesionales con comandos de lenguaje natural.
- Convierta imágenes existentes y archivos PDF en diagramas
- Visualice rápidamente la arquitectura y los diagramas de flujo de la nube

## Instalación
**instalación local**

```
git clone https://github.com/DayuanJiang/next-ai-draw-io
cd next-ai-draw-io
npm install
cp env.example .env.local
```


## Ejecución
**Iniciando el servidor de desarrollo**

```
npm run dev
```


## Si no programa
Quiero que crees un diagrama de flujo. Visualice el proceso de autenticación de usuarios, incluido el inicio de sesión, la autenticación multifactor y la gestión de sesiones.
