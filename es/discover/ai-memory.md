# Memoria permanente para agentes codificadores de inteligencia artificial.

Escrita en Rust, ai-memory ofrece una solución de memoria a largo plazo para agentes de inteligencia artificial. Admite la continuidad de las interfaces de línea de comandos (CLI) utilizadas en los procesos de desarrollo de software al facilitar la transferencia de datos entre diferentes proveedores de agentes.

## Qué aporta
- Mantiene el contexto entre diferentes agentes de IA.
- Proporciona continuidad en los procesos de desarrollo.
- Funciona con muchas herramientas de codificación

## Cómo empezar
Para comenzar a utilizar la herramienta, visite la página oficial en GitHub y descargue la versión adecuada para su sistema operativo. Puede aprender cómo integrar la herramienta con los agentes de codificación que admite revisando los archivos de documentación relevantes para obtener detalles de instalación y configuración.
