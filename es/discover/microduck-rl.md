# micropato rl

Desarrollado por Pollen Robotics, microduck_rl ofrece entornos de formación de aprendizaje reforzado para la plataforma de robótica Microduck. Esta biblioteca basada en Python facilita el desarrollo de algoritmos de control robótico en la herramienta de simulación basada en física mjlab.
