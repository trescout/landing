# Conjunto de herramientas de oficina de código abierto

Univer es una plataforma de código abierto que combina herramientas de oficina como hojas de cálculo, documentos y presentaciones en un solo tiempo de ejecución (runtime). Ofrece una estructura modular diseñada para facilitar la interacción de los agentes de inteligencia artificial (AI agents) con el software de oficina.

## Qué aporta

- Incrusta experiencias de hojas de cálculo, documentos y presentaciones en tu propia aplicación.
- Ejecuta operaciones de procesamiento de datos con la misma arquitectura en el navegador o en el lado del servidor.
- Combina solo las características que necesitas con una arquitectura de complementos modular.

## Instalación

**Clonar el Repositorio y el Entorno de Desarrollo B**

```
git clone https://github.com/dream-num/univer.git
cd univer
pnpm install
pnpm dev
```
