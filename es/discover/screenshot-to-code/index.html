Convierta capturas de pantalla en código de trabajo

Screenshot-to-code es una herramienta de software que analiza archivos de captura de pantalla y los convierte en código HTML, Tailwind, React o Vue limpio. Permite a los desarrolladores traducir rápidamente diseños de interfaz en fragmentos de código funcionales.

  • ★ 75.377
  • Python
  • GitHub Trending · 2026-08-28

Qué aporta

  • Traduce capturas de pantalla y archivos de diseño a HTML limpio o código React
  • Convierte grabaciones de sitios web en prototipos funcionales
  • Tailwind admite CSS y varias bibliotecas de interfaz populares

Instalación

Instalación rápida con Docker
echo "OPENAI_API_KEY=sk-your-key" > .env
docker-compose up -d --build
Iniciando la interfaz
cd frontend
pnpm install
pnpm dev

Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Analice la captura de pantalla y cree una estructura de código limpia y funcional que refleje exactamente el diseño de la imagen. Prepare la salida en formato HTML o React usando Tailwind CSS. Extraiga los logotipos y recursos reales de la imagen e inclúyalos en el código, codificando todos los elementos del diseño de forma responsiva.
