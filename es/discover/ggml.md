# Biblioteca de tensores para modelos de inteligencia artificial

ggml-org/ggml es una biblioteca de tensores desarrollada en C++ para modelos de aprendizaje automático. El software facilita la ejecución de modelos de inteligencia artificial al ofrecer ejemplos sencillos y claros para operaciones básicas como la multiplicación de matrices.

## Qué aporta

- Ofrece operaciones de tensores de alto rendimiento en C y C++ sin dependencias externas.
- Puede ejecutarse en la unidad central de procesamiento CPU, la unidad de procesamiento gráfico GPU y entornos de navegador.
- Reduce el uso de memoria con formatos de cuantización que reducen el tamaño de los datos.

## Instalación

**Compilando desde el código fuente**

```
git clone https://github.com/ggml-org/ggml
cd ggml

mkdir build && cd build
cmake ..
cmake --build . --config Release -j 8
```
