## Qué aporta

- se ejecuta localmente en tu ordenador

## Instalación

**descargar e instalar el proyecto**

```
git clone https://github.com/makecindy/cindy.git
cd cindy
git lfs pull
pnpm install
```

## Ejecución

**la aplicación de escritorio con cuenta global**

```
pnpm restart:desktop:remote --region=global
```
