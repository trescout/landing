# Infraestructura escalable para agentes de inteligencia artificial

Agent Substrate es el sistema central que proporciona una infraestructura escalable para agentes de inteligencia artificial.

- ★ 1.276
- Go
- GitHub Trending · 2026-08-20

## Qué aporta
- Lanza agentes en segundos con baja latencia
- Proporciona persistencia al preservar la memoria y el estado del sistema de archivos.
- Ejecuta muchos agentes simultáneamente con recursos limitados.

## Ejecución
**Envío de una solicitud al mostrador de muestras.**

```
curl -X POST -H "Host: my-counter-1.demo.actors.resources.substrate.ate.dev" -i http://localhost:8000/
```
