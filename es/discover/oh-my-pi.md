# Codificación apoyada por inteligencia artificial en el terminal

Oh-my-pi es un agente de codificación de inteligencia artificial que se ejecuta en un entorno de terminal y automatiza los procesos de edición de código. La herramienta tiene como objetivo optimizar los flujos de trabajo de desarrollo de software con funciones como el protocolo de servidor de idiomas (LSP), la integración del navegador y la gestión de subagentes.

## Qué aporta
- Automatiza los procesos de edición de código al llevar funciones IDE al terminal.
- Con la integración de LSP, realiza operaciones como cambio de nombre y seguimiento de referencias sin ningún error.
- Resuelve problemas en el sitio interactuando directamente con herramientas de depuración.

## Instalación
**Instalación para macOS y Linux**

```
curl -fsSL https://omp.sh/install | sh
```

**Instalación a través de este**

```
bun install -g @oh-my-pi/pi-coding-agent
```


## Ejecución
**Configurar complementos de shell**

```
# zsh — add to ~/.zshrc (or write the output into a file on your $fpath)
eval "$(omp completions zsh)"

# bash — add to ~/.bashrc
eval "$(omp completions bash)"

# fish
omp completions fish > ~/.config/fish/completions/omp.fish
```
