# Interfaz alternativa de código abierto para YouTube

Invidious es una interfaz alternativa de código abierto para YouTube. El README oficial menciona el uso sin anuncios ni seguimiento, sin requerir JavaScript, con suscripciones independientes de Google y opciones de importación y exportación de datos.

- ★ 22.400
- GitHub Trending · 2026-08-02

## ¿Qué hace esta herramienta?
Invidious ofrece una interfaz alternativa para YouTube y no utiliza las API oficiales de YouTube. Puedes elegir una instancia pública o alojar la tuya siguiendo la documentación de instalación. El proyecto utiliza la licencia AGPL-3.0 y ofrece una API documentada para desarrolladores.

## ¿Para quién es?
Personas que quieren una interfaz alternativa para YouTube, suscripciones independientes de Google o una instancia autoalojada.

## Qué no esperar
Personas que necesitan específicamente una solución basada en las API oficiales de YouTube.

## Aspectos destacados
- Menciona el uso sin anuncios ni seguimiento y sin requerir JavaScript.
- Admite suscripciones independientes de Google.
- Ofrece opciones para importar y exportar datos.
- Incluye una API documentada para desarrolladores.

## Primer flujo de uso
- Elige una instancia pública de Invidious si solo quieres utilizar el servicio.
- Si quieres autoalojarlo, consulta primero la documentación oficial de instalación.
- Para el método actual con Docker, prepara PostgreSQL e Invidious Companion.
- Reserva al menos 20 GB de espacio en disco y 2 GB de RAM libre para tu instalación.

## Instalación
**Clona el repositorio**

```

```

**Entra en el directorio del proyecto**

```

```


## Ejecución
**Inicia Docker Compose**

```
docker compose up -d
```
