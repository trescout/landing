# Ver videos sin anuncios y seguimiento

Invidious es una interfaz de código abierto desarrollada como alternativa a la plataforma YouTube. Ofrece a los usuarios una experiencia de visualización de vídeos que no contiene anuncios ni rastrea datos.

- ★ 22.400
- Crystal
- GitHub Trending · 2026-08-02

## Qué aporta
- Mira vídeos de YouTube sin anuncios ni seguimiento de datos
- Suscríbete a canales sin necesidad de una cuenta de Google
- Reproduzca la reproducción de audio en segundo plano con poco uso de datos

## Instalación
**Obtenga el repositorio y redacte el archivo**

```
git clone --depth 1 https://github.com/iv-org/invidious.git && cd invidious
```


## Ejecución
**empezar**

```
docker compose up -d
```
