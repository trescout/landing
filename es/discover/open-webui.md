# Una interfaz única para tus modelos de inteligencia artificial

open-webui es una interfaz amigable que permite interactuar con modelos de inteligencia artificial como Ollama y la API de OpenAI. Ofrece una interfaz web desarrollada para gestionar modelos de lenguaje locales o basados en la nube.

## Qué aporta

- Puedes gestionar todos tus modelos de inteligencia artificial, tanto locales como basados en la nube, en una sola pantalla web.
- Puedes subir tus propios documentos al sistema para realizar preguntas y respuestas sobre tus textos y hacer búsquedas en internet.
- Puedes utilizar herramientas de generación de imágenes, búsqueda por voz, gestión de calendario y toma de notas sin salir del área de chat.

## Instalación

**Instalación con pip, el gestor de paquetes de Python**

```
pip install open-webui
```

## Ejecución

**Iniciar con Docker, la herramienta de contenerización de software**

```
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```
