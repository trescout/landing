## Instalación

**macOS (Homebrew)**

```
brew install nginx
```

**Ubuntu / Debian**

```
sudo apt update && sudo apt install -y nginx
```

## Ejecución

**Iniciar servidor web**

```
sudo systemctl start nginx
```
