# Prepare datos web para IA

Crawl4AI; es un rastreador y raspador web de código abierto optimizado para modelos de lenguaje grandes. Convierte páginas web en formatos limpios y estructurados (Markdown, etc.) que los modelos de inteligencia artificial pueden procesar fácilmente.

## Qué aporta

- Convierte el contenido web a un formato limpio y compatible con la IA.
- Especialmente optimizado para procesos LLM.
- Es rápido y de código abierto.

## Instalación

**pip (PyPI)**

```
pip install crawl4ai
```

## Ejecución

**Escanear página web y preparar para IA**

```
crawl4ai-download
```

## Instalación (comando único)

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Ayúdame a instalar un rastreador web de código abierto llamado Crawl4AI; Probémoslo instalándolo con 'pip install -U crawl4ai', luego ejecutando 'crawl4ai-setup' y convirtiendo una página web a Markdown compatible con LLM con el comando 'crwl https://www.nbcnews.com/business -o markdown'.
