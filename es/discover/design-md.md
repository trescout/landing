# Introducir sistemas de diseño a la IA

Desarrollado por Google Labs, DESIGN.md proporciona una especificación de formato estructurado para pasar credenciales visuales a agentes de codificación. Este estándar garantiza que los agentes de inteligencia artificial comprendan los sistemas de diseño de manera consistente y permanente.

## Qué aporta

- Almacena decisiones de diseño en formato estructurado.
- Proporciona una guía visual consistente para los agentes codificadores.
- Comprueba automáticamente si hay errores e inconsistencias en el diseño.

## Instalación

**Instalar el paquete**

```
npm install @google/design.md
```

**Instalar para Windows**

```
npm install "@google/design.md"
```

## Ejecución

**Validar el archivo de diseño**

```
npx @google/design.md lint DESIGN.md
```

**Comparando dos archivos de diseño**

```
npx @google/design.md diff DESIGN.md DESIGN-v2.md
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Revisar el archivo DESIGN.md que define la identidad visual y el sistema de diseño de mi proyecto. Cíñete a esta estructura en todos los códigos que crees haciendo referencia a la paleta de colores, las reglas de tipografía, los valores de espacio y las definiciones de componentes en este archivo. Utilice valores directamente del sistema de diseño y evite crear inconsistencias visuales.
