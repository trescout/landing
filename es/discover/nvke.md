# Gestión de Kubernetes para tarjetas gráficas Nvidia

NVIDIA Kubernetes Engine (NVKE) ofrece un plano de gestión (management plane) que permite administrar clústeres de Kubernetes con aceleración de GPU en servidores bare metal. Desarrollada en Go, esta herramienta funciona sobre una infraestructura de Docker con compatibilidad para TPM virtual, simplificando los procesos de instalación de clústeres y creación de cargas de trabajo.
