# Marco de aplicación para agentes de IA

Desarrollado por BuilderIO, agent-native es un marco TypeScript centrado en la creación de aplicaciones nativas para agentes de inteligencia artificial. Permite a los desarrolladores integrar flujos de trabajo basados ​​en agentes directamente en la arquitectura de la aplicación.

## Qué aporta

- Sincroniza el agente y la interfaz de usuario en una única base de datos.
- Totalmente compatible con bases de datos SQL y hosting con tecnología Nitro
- Le permite definir su código una vez y usarlo en CLI, API e interfaz

## Instalación

**Crear un proyecto**

```
npx @agent-native/core@latest create my-platform
cd my-platform
pnpm install
pnpm dev
```

**Agregue talento ya preparado**

```
npx @agent-native/core@latest skills add visual-plan
```

## Si no programa

Pegue esto en su agente (Claude Code · Codex · Antigravity)

Quiero definir una acción para mi aplicación utilizando el marco Agent-Native. Usando la función defineAction, ayúdame a crear una estructura que procesará los datos entrantes en la base de datos y será accesible tanto para la interfaz de usuario como para el agente de inteligencia artificial.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.
