# Plataforma de negociación algorítmica de alto rendimiento

Nautilus Trader es un motor comercial con una arquitectura determinista basada en eventos, desarrollado en lenguaje Rust. Ofrece soluciones de infraestructura de nivel de producción para sistemas financieros de alto rendimiento.

- ★ 26.536
- Rust
- GitHub Trending · 2026-06-18

## Qué aporta
- Infraestructura comercial rápida y segura basada en Rust
- Transición de la investigación a la vida sin cambios de código
- Soporte para múltiples intercambios y clases de activos

## Instalación
**Instalación estándar**

```
pip install -U nautilus_trader
```

**Instalación desde repositorio de paquetes privado**

```
pip install -U nautilus_trader --index-url=https://packages.nautechsystems.io/simple
```
