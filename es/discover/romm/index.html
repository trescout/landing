Gestiona tu propia biblioteca de juegos

Romm es un administrador de biblioteca de juegos diseñado para organizar archivos de juegos (ROM) y jugar directamente a través del navegador, que puedes alojar en tu propio servidor. Desarrollada con lenguaje Python, esta herramienta ofrece la oportunidad de administrar y jugar colecciones de juegos con una interfaz visual.

Qué aporta

  • Soporte para juegos directos en el navegador.
  • Metadatos automáticos y mejora visual.

Instalación

Obtener un archivo de redacción de muestra
curl -o docker-compose.yml https://raw.githubusercontent.com/rommapp/romm/master/examples/docker-compose.example.yml

Ejecución

empezar
docker compose up -d
