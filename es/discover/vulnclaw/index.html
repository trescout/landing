Pruebas de penetración automáticas con inteligencia artificial

VulnClaw automatiza los procesos de pruebas de penetración utilizando agentes de inteligencia artificial y la cadena de herramientas del protocolo de contexto modelo. La herramienta procesa comandos en lenguaje natural y realiza pasos de recopilación de información, escaneo de vulnerabilidades, explotación y generación de informes de un extremo a otro.

Instalación

Instalación vía PyPI
pip install vulnclaw
Instalación desde el código fuente
git clone https://github.com/Unclecheng-li/VulnClaw.git
cd VulnClaw
pip install -e .

Ejecución

Inicio rápido
vulnclaw
Escaneo dirigido
vulnclaw run <target>

Eres un probador de penetración. Utilizando la herramienta VulnClaw, recopile información sobre el sistema de destino, realice escaneo de vulnerabilidades y pasos de explotación.
