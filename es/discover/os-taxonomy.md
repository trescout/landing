# Mapa de conexiones de los temas de educación primaria

withmarbleapp/os-taxonomy es una biblioteca desarrollada en el lenguaje JavaScript que organiza las clasificaciones de sistemas operativos. Permite a los desarrolladores de software definir diferentes datos de sistemas operativos en una estructura estándar.

- ★ 6.389
- JavaScript
- GitHub Trending · 2026-10-20

## Qué aporta

- Explore más de 1.500 microtemas a nivel de primaria con rangos de edad y criterios de éxito.
- Cree rutas de aprendizaje paso a paso siguiendo más de 3.200 relaciones de prerrequisitos entre temas.
- Acceda directamente a enfoques pedagógicos en ciencias y matemáticas y a ejemplos de actividades en el aula.

## Ejecución

**Validación de datos y ejecución de pruebas**

```
node scripts/validate.mjs
node --test scripts/teaching-research.test.mjs
```
