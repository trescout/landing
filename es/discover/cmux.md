# Terminal inteligente y automatización para macOS

cmux, una terminal de macOS basada en Ghostty, ofrece pestañas verticales y soporte de notificaciones para agentes de codificación de inteligencia artificial. Enfocada en la gestión de multitarea y la programabilidad, esta herramienta ayuda a los desarrolladores a organizar sus entornos de trabajo.

## Qué aporta
- Ofrece soporte de notificaciones para agentes de codificación de inteligencia artificial
- Organiza el espacio de trabajo con pestañas verticales y horizontales
- Incluye un navegador integrado con una API programable mediante scripts

## Instalación
**Instalación con Homebrew**

```
brew tap manaflow-ai/cmux
brew install --cask cmux
```


## Ejecución
**Actualización de la aplicación**

```
brew upgrade --cask cmux
```
