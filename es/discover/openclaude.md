# Gestión de inteligencia artificial a través de la terminal

OpenClaude es una interfaz de inteligencia artificial flexible que puede ejecutarse en cualquier tipo de hardware y utilizar diferentes fuentes de datos. Este proyecto de código abierto, desarrollado con el lenguaje TypeScript, permite a los usuarios ejecutar modelos de inteligencia artificial personalizados en su propia infraestructura.

## Qué aporta

- Combina modelos de inteligencia artificial locales y basados en la nube en una sola interfaz.
- Ejecuta tareas como la gestión de archivos, búsqueda y codificación desde la terminal.
- Configura fácilmente diferentes proveedores con una instalación guiada fácil de usar.

## Instalación

**Instalación general**

```
npm install -g @gitlawb/openclaude@latest
```

## Ejecución

**Iniciando la herramienta**

