# Gestione la configuración de modelos de inteligencia artificial desde una sola pantalla

Codex-X es una herramienta de interfaz visual de escritorio y línea de comandos escrita en Rust, desarrollada para gestionar modelos de OpenAI Codex. El software centraliza la experiencia del desarrollador con funciones como gestión de API, sincronización de sesiones, inyección de prompts y gestión de habilidades (skills).

## Qué aporta

- Gestione fácilmente plantillas de prompts y complementos a través de la interfaz
- Cambie rápidamente entre diferentes proveedores de inteligencia artificial
- Realice un seguimiento del historial de sesiones y las tendencias de uso de tokens

## Instalación

**Instalando dependencias**

```
pnpm install
```

## Ejecución

**Iniciando el entorno de desarrollo**

```
pnpm dev
```

**Compilación de la aplicación de escritorio**

```
pnpm --dir apps/desktop tauri build
```

Ayúdame a instalar y ejecutar la aplicación en mi entorno local para configurar mis claves API y sincronizar mi historial de sesiones.

Repositorio: https://github.com/yynxxxxx/Codex-X. Sigue las instrucciones oficiales del archivo README de este repositorio para la instalación y ejecución.

Antes de empezar, comprueba en qué sistema operativo estamos y si las herramientas necesarias (ej. Python, Node.js, Git, Docker) están instaladas. Instala las que falten paso a paso según este sistema.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.

Si se necesita una clave API, no me pidas que la escriba en el chat. Muéstrame cómo añadirla al archivo .env y asegúrate de que este archivo no se suba a Git.

Dime qué debería ver en la pantalla al final de cada paso. Si ocurre un error, te pegaré el mensaje de error tal cual y lo solucionaremos juntos.
