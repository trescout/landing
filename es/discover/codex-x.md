# Gestione la configuración de modelos de inteligencia artificial desde una sola pantalla

Codex-X es una herramienta de interfaz visual de escritorio y línea de comandos escrita en Rust, desarrollada para gestionar modelos de OpenAI Codex. El software centraliza la experiencia del desarrollador con funciones como gestión de API, sincronización de sesiones, inyección de prompts y gestión de habilidades (skills).

- ★ 3.999
- GitHub Trending · 2026-09-20

## Qué aporta
- Gestione fácilmente plantillas de prompts y complementos a través de la interfaz
- Cambie rápidamente entre diferentes proveedores de inteligencia artificial
- Realice un seguimiento del historial de sesiones y las tendencias de uso de tokens

## Instalación
**Instalando dependencias**

```
pnpm install
```


## Ejecución
**Iniciando el entorno de desarrollo**

```
pnpm dev
```

**Compilación de la aplicación de escritorio**

```
pnpm --dir apps/desktop tauri build
```


## Si no programa
Quiero reunir las plantillas de prompts y la configuración de proveedores que preparé para mi asistente de codificación de IA usando Codex-X en una única interfaz visual.
