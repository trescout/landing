# Marco de desarrollo de software de vuelo de la NASA

Desarrollado por la NASA, F´ es un marco de código abierto diseñado para software de vuelo y sistemas integrados. Escrita en C++, esta estructura ofrece un entorno de desarrollo modular para naves espaciales y sistemas complejos.

## Qué aporta

- Estructura modular para naves espaciales y sistemas integrados.
- Entorno de desarrollo rápido de software basado en componentes
- Generación automática de código y herramientas de prueba integradas.

## Instalación

**Instalación de la herramienta Bootstrap**

```

## Ejecución

**Crear un nuevo proyecto**

```
