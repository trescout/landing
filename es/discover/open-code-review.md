# Revisión de código de precisión impulsada por IA

La herramienta de revisión de código fuente abierto desarrollada por Alibaba combina canalizaciones deterministas y agentes de modelo de lenguaje grande (LLM) en una estructura híbrida. Equipada con reglas de seguridad de software y capacidades de interpretación basada en líneas, la herramienta está escrita en lenguaje Go y ofrece una infraestructura compatible con OpenAI y Anthropic.

## Qué aporta

- Detección precisa de errores basada en líneas
- Alta eficiencia con bajo consumo de tokens
- Resultados estables con pipelines deterministas

## Instalación

**Instale la herramienta CLI globalmente**

```
npm install -g @alibaba-group/open-code-review
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Revise mis cambios actuales de Git usando la herramienta Open Code Review. Analice archivos en el código base, detecte errores línea por línea y cree comentarios estructurados. Minimice los falsos positivos siguiendo reglas deterministas durante el proceso de revisión y céntrese solo en errores críticos de seguridad o lógica.
