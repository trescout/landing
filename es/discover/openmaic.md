# OpenMAIC

OpenMAIC es una plataforma de aprendizaje inmersiva que simula múltiples interacciones de agentes de IA con un solo clic. Esta herramienta de código abierto, desarrollada con TypeScript, permite a los usuarios experimentar un entorno de aula interactivo con diferentes modelos de agentes.
