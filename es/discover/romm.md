# Centralice su biblioteca de juegos

Romm es un administrador de bibliotecas de juegos que le permite organizar su colección de juegos retro a través de una interfaz web moderna y elegante.

- ★ 12.170
- GitHub Trending · 2026-07-04

## ¿Qué hace esta herramienta?
Romm es un administrador de bibliotecas de juegos que puede alojar directamente en su propio servidor, permitiéndole organizar su colección de juegos retro a través de una interfaz web moderna y elegante. Obtiene automáticamente los metadatos de los juegos mediante la integración con IGDB.

## ¿Para quién es?
Entusiastas de los juegos retro que desean convertir archivos de juegos dispersos en un archivo centralizado y visualmente rico.

## Qué no esperar
Aquellos que deseen realizar compras de juegos digitales o que busquen un cliente para gestionar plataformas actuales.

## Aspectos destacados
- Ofrece una interfaz de biblioteca moderna accesible a través del navegador.
- Descarga automáticamente información como la portada del juego, la fecha de lanzamiento y la descripción.
- Proporciona soporte multiusuario y seguimiento del historial de juego.

## Primer flujo de uso
- Descargue los archivos Docker y Docker Compose necesarios para Romm.
- Genere las claves necesarias para el acceso a la API y agréguelas al archivo de configuración.
- Inicie el servicio montando el directorio donde se encuentran sus archivos de juego.
- Acceda a la interfaz web para iniciar el primer escaneo de la biblioteca.

## Instalación
**Obtener un archivo de redacción de muestra**

```
curl -o docker-compose.yml https://raw.githubusercontent.com/rommapp/romm/master/examples/docker-compose.example.yml
```


## Ejecución
**empezar**

```
docker compose up -d
```
