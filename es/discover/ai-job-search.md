# Solicitud de empleo automática con Claude Code

Utilizando la infraestructura de Claude Code, ai-job-search ofrece un marco que automatiza el proceso de búsqueda de empleo. La herramienta analiza el perfil del usuario y realiza tareas como edición de currículum, redacción de cartas de presentación y preparación de entrevistas con el apoyo de inteligencia artificial.

## Qué aporta

- Prepara CV y carta de presentación según tu perfil personal.
- Analiza ofertas de trabajo y otorga puntuaciones de idoneidad.
- Proporciona orientación para la preparación de la entrevista.

## Instalación

**Descargar herramientas de búsqueda de empleo**

```
cd .agents/skills/jobbank-search/cli && bun install && cd ../../../..
cd .agents/skills/jobdanmark-search/cli && bun install && cd ../../../..
cd .agents/skills/jobindex-search/cli && bun install && cd ../../../..
cd .agents/skills/jobnet-search/cli && bun install && cd ../../../..
cd .agents/skills/linkedin-search/cli && bun install && cd ../../../..
```

## Ejecución

**Iniciar configuración de perfil**

```
/setup
```

**Explorar ofertas de trabajo**

```
/scrape
```

## Si no programa

Pegue esto en su agente (Claude Code · Codex · Antigravity)

Cree su perfil usando el comando /setup mientras está en Claude Code. Luego, enumere las ofertas de trabajo adecuadas con el comando /scrape y utilice el comando /apply para crear un borrador de su CV y ​​una carta de presentación para la oferta de trabajo que seleccionó. Durante el proceso, solicite a la inteligencia artificial que evalúe su compatibilidad con el anuncio y brinde comentarios para la preparación de la entrevista.
