Previsión de IA para series temporales

El Time Series Foundation Model, desarrollado por Google Research, ofrece una estructura previamente entrenada para el pronóstico de series de tiempo. El modelo está diseñado para proporcionar capacidades predictivas generales en diferentes conjuntos de datos.

Qué aporta

  • Predicción rápida con modelo base previamente entrenado
  • Soporte de longitud de contexto de 16k
  • Adaptación a diferentes conjuntos de datos con estructura flexible.

Instalación

Instalación vía PyPI
pip install timesfm[torch]
# Or with Flax
pip install timesfm[flax]
# And when XReg is needed
pip install timesfm[xreg]
instalación local
git clone https://github.com/google-research/timesfm.git
    cd timesfm
