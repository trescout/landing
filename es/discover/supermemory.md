# Memoria inteligente para inteligencia artificial

Supermemory ofrece un motor de memoria altamente escalable y una API diseñada para la era de la inteligencia artificial. Le permite agregar una capa de memoria persistente y consultable a sus aplicaciones.

- ★ 28.943
- TypeScript
- MIT
- GitHub Trending · 1 Haziran 2026

## Qué aporta
- Agrega una capa de memoria persistente a su aplicación.
- Soporte de arquitectura escalable.
- Fácil integración vía API.

## Instalación
****

```
npm install supermemory
```


## Ejecución
****

```
npx -y install-mcp@latest https://mcp.supermemory.ai/mcp --client claude --oauth=yes
```


## ¿Cómo instalar, cómo utilizar?
Instale supermemoria para agregar memoria persistente a mi asistente de IA: conecte el servidor MCP a Claude con el comando 'npx -y install-mcp@latest https://mcp.supermemory.ai/mcp --client claude --oauth=yes' y verifique que esté funcionando.
