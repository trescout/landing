# Gestión YAML para proyectos C++

yaml-cpp es una biblioteca para el lenguaje de programación C++ que analiza y emite datos en formato YAML. Permite a los desarrolladores de software administrar archivos de configuración y realizar operaciones de serialización de datos.

## Qué aporta
- Cumplimiento total de los estándares YAML 1.2
- Soporte de análisis y renderizado de datos
- Compilación multiplataforma con CMake

## Instalación
**macOS (hecho en casa)**

```
brew install yaml-cpp
```


## Cómo empezar
- Fuente oficial →
Para comenzar a utilizar la herramienta, primero debe descargar e instalar el software CMake desde su sitio web oficial. Luego puede ejecutar los comandos de configuración de CMake creando una carpeta de 'compilación' en el directorio de código fuente de su proyecto o integrarla en su proyecto usando la función FetchContent de CMake. Para obtener ejemplos de uso detallados y documentación de API, puede consultar la sección Wiki en la página de GitHub.
