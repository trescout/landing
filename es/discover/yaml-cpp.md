# Gestión YAML para proyectos C++

yaml-cpp es una biblioteca para el lenguaje de programación C++ que analiza y emite datos en formato YAML. Permite a los desarrolladores de software administrar archivos de configuración y realizar operaciones de serialización de datos.

## Qué aporta

- Cumplimiento total de los estándares YAML 1.2
- Soporte de análisis y renderizado de datos
- Compilación multiplataforma con CMake

**macOS (Homebrew)**
