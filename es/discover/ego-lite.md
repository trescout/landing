# Navegador concurrente para agentes de IA

Ego-lite es un navegador que permite trabajar simultáneamente a usuarios y agentes de inteligencia artificial. Esta herramienta basada en JavaScript tiene como objetivo llevar a cabo la interacción entre humanos y máquinas en paralelo en el mismo entorno del navegador.

- ★ 11.904
- JavaScript
- GitHub Trending · 2026-07-24

## Qué aporta
- Los agentes y los usuarios se ejecutan en el mismo navegador sin conflictos
- Protege las sesiones importando datos de Chrome
- Finalización de tareas más rápida con estructura basada en JavaScript

## Instalación
**Agregando habilidades**

```
npx skills add citrolabs/ego-lite
```


## Ejecución
**Iniciar una tarea**

```
ego-browser follow @ego_agent on x.com for me
```


## Si no programa
Configure ego lite para mí: https://github.com/citrolabs/ego-lite. Lea `skills/ego-browser/references/install.md` y siga los pasos para instalar ego lite.
