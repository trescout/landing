# Configura una plataforma de búsqueda y reproducción de video en línea

LibreSpark/LibreTV es un proyecto de software basado en TypeScript que te permite configurar un sitio web de películas y series en un minuto utilizando métodos como Docker. Ofrece una infraestructura que permite a los usuarios crear rápidamente sus propias plataformas de contenido.

## Qué aporta

- busca películas y series de diferentes fuentes desde un solo lugar
- mira transmisiones de televisión por internet en formato m3u y m3u8
- guarda tu historial de visualización y dónde lo dejaste en tu navegador

## Instalación

**instalación rápida con docker**

```
docker compose pull && docker compose up -d
```

## Ejecución

**ejecutar compilando desde el código fuente**

```
npm install
PASSWORD=your-password npm run build
PASSWORD=your-password npm start   # 监听 8080
```
