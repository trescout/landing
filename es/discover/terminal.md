# Experiencia moderna en la línea de comandos de Windows

Microsoft está combinando Windows Terminal y la consola tradicional de Windows bajo un mismo techo. Este proyecto de código abierto, desarrollado en lenguaje C++, reestructura la experiencia de la línea de comandos con una interfaz moderna y pestañas personalizables.

## Qué aporta
- Interfaz moderna y personalizable
- Soporte para múltiples pestañas
- Rendimiento mejorado de la línea de comandos

## Instalación
**Ventanas (ala)**

```
winget install Microsoft.WindowsTerminal
```


## Ejecución
**Ejecutar desde la línea de comando**

```
wt
```


## Cómo empezar
- Fuente oficial →
Puede descargar fácilmente la aplicación Windows Terminal desde Microsoft Store. Alternativamente, puede descargar manualmente la versión actual desde la página de Lanzamientos en GitHub o instalarla en su computadora usando administradores de paquetes como Winget, Chocolatey o Scoop.
