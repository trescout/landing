# Gestión de tareas asincrónicas con inteligencia artificial

pi-subagents es una biblioteca TypeScript desarrollada para gestionar procesos de delegación de subagente asincrónicos en la plataforma Pi. Facilita la distribución de cargas de trabajo complejas a los subagentes.

- ★ 3.411
- TypeScript
- Lisans: yok
- GitHub Trending · 1 Haziran 2026

## Qué aporta
- Distribuye la carga de trabajo a los subagentes.
- Proporciona ejecución asincrónica y paralela.
- Funciona totalmente integrado con la plataforma Pi.

## ¿Cómo instalar, cómo utilizar?
**instalar con pi**

```
pi install npm:pi-subagents
```

**Ejecutar un subagente**

```
/run <ajan> [görev]
```

**Ejecutar agentes en paralelo**

```
/parallel ajan1 "görev1" -> ajan2 "görev2"
```
