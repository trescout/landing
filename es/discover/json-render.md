# JSON Render

Desarrollado por Vercel Labs, json-render es un marco de trabajo (framework) que transforma estructuras de datos en componentes visuales para flujos de interfaces generativas (generative UI). Permite a los desarrolladores presentar datos estructurados provenientes de modelos de inteligencia artificial como elementos dinámicos e interactivos en interfaces web.
