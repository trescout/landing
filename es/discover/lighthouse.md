# Juega Banjo Kazooie en sistemas modernos

Lighthouse es una herramienta de cobertura de código desarrollada en lenguaje C y diseñada para sistemas de bajo nivel. Proporciona datos a los desarrolladores para la depuración y optimización del rendimiento mediante el análisis de qué bloques de código se ejecutan durante los procesos de prueba del software.

## Qué aporta
- Proporciona soporte de plataforma moderna con archivos de juegos originales.
- Ofrece soporte para mods y paquetes en varios idiomas
- Incluye controlador personalizable y configuración de gráficos.

## Cómo empezar
Descargue la versión Lighthouse desde la página oficial de lanzamientos de GitHub y extraiga los archivos en una carpeta. Después de verificar su propio archivo de juego (ROM), seleccione su archivo de juego ejecutando lighthouse.exe en Windows, lighthouse.appimage en Linux o lighthouse en macOS.
