# Marco de estilo para un diseño de interfaz rápido

Tailwind CSS es un marco de hojas de estilo (marco CSS) centrado en el desarrollo rápido de interfaces de usuario. Permite la creación rápida de interfaces originales al ofrecer clases de bajo nivel en lugar de componentes de diseño ya preparados.

- ★ 96.949
- TypeScript
- GitHub Trending · 2026-08-05

## Qué aporta
- Crea diseños únicos con clases de bajo nivel.
- Desarrollar interfaces sin tener que lidiar con componentes prefabricados
- Proporcionar una gestión de estilo rápida en proyectos web modernos.

## Instalación
**con npm**

```
npm install tailwindcss @tailwindcss/cli
```


## Ejecución
**Generar CSS**

```
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```
