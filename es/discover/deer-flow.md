# Agente de IA para tareas complejas

Desarrollado por ByteDance, Deer-Flow es un marco superagente de código abierto diseñado para realizar tareas de larga duración. Sistema; Puede investigar y codificar de forma autónoma flujos de trabajo complejos utilizando sandbox, gestión de memoria y subagentes.

- ★ 78.818
- Python
- GitHub Trending · 2026-06-22

## Qué aporta
- Capacidad autónoma de investigación y codificación.
- Trabajar en un entorno sandbox seguro
- Memoria a largo plazo y manejo de subagentes.

## Instalación
**Clonando el repositorio**

```
git clone https://github.com/bytedance/deer-flow.git
   cd deer-flow
```

**Iniciar el asistente de configuración**

```
make setup
```


## Ejecución
**Lanzando con Docker**

```
make docker-init    # Pull sandbox image (only once or when image updates)
make docker-start   # Start services (auto-detects sandbox mode from config.yaml)
```


## Si no programa
Clono el repositorio de DeerFlow en mi computadora y luego ejecute el comando make setup para completar la configuración necesaria para el entorno de desarrollo local. Ayúdame a configurar opciones como el proveedor de LLM, las preferencias de búsqueda web y la configuración de seguridad durante el asistente de configuración.
