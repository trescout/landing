# Añade capacidades de IA a tus notas de Obsidiana

Obsidian-skills permite a los agentes de inteligencia artificial realizar operaciones en la aplicación para tomar notas Obsidian utilizando la interfaz de línea de comandos (CLI) y formatos de archivo abiertos. Esta herramienta automatiza la gestión de información personal al permitir a los agentes leer y editar formatos como Markdown y JSON Canvas.

## Qué aporta
- Permite a los agentes de inteligencia artificial leer y organizar sus notas.
- Admite formatos de archivo como Markdown y JSON Canvas.
- Establece procesos de automatización en la aplicación de toma de notas Obsidian.

## Instalación
**instalación con npx**

```
npx skills add git@github.com:kepano/obsidian-skills.git
```

**Instalación para OpenCode**

```
git clone https://github.com/kepano/obsidian-skills.git ~/.opencode/skills/obsidian-skills
```


## Si no programa
Utilizo la herramienta Obsidian-skills para gestionar mis notas de Obsidian. Utilice este conjunto de habilidades para editar archivos Markdown en mis notas, actualizar el contenido de JSON Canvas o realizar las acciones necesarias a través de la interfaz de línea de comandos de Obsidian CLI. Quiero que crees un flujo de gestión de información eficiente, especialmente preservando las estructuras, conexiones y características complejas de mis notas.
