Directrices de Karpathy para agentes de código

Este paquete de directrices se describe como derivado de las observaciones de Andrej Karpathy sobre los fallos de codificación de los LLM. Ofrece opciones como plugin de Claude Code, CLAUDE.md por proyecto y regla para Cursor.

  • ★ 205.391
  • GitHub Trending · 2026-08-23

¿Qué hace esta herramienta?

Andrej Karpathy Skills no es un modelo independiente ni un runtime de agente de código. Proporciona un CLAUDE.md y directrices con formato de plugin para orientar a agentes de código existentes, organizadas en cuatro principios: pensar antes de programar, priorizar la sencillez, hacer cambios quirúrgicos y ejecutar con objetivos verificables.

¿Para quién es?

Desarrolladores que utilizan Claude Code o Cursor y quieren añadir directrices a nivel de proyecto o de herramienta.

Qué no esperar

Personas que buscan un LLM independiente, un editor de código, un runtime de agente o una aplicación lista para usar.

Aspectos destacados

  • Utiliza un CLAUDE.md y un enfoque de plugin para orientar a agentes de código.
  • Define cuatro principios para un trabajo deliberado y verificable.
  • Incluye opciones de configuración para Claude Code y Cursor.
  • El README indica una licencia MIT.

Primer flujo de uso

  1. Lee el README del repositorio y elige la opción adecuada para tu herramienta: plugin de Claude Code, CLAUDE.md del proyecto o regla de Cursor.
  2. Para usarlo a nivel de proyecto, añade las directrices al CLAUDE.md de tu proyecto según las indicaciones del repositorio.
  3. Revisa las directrices según las necesidades de tu proyecto antes de utilizarlas.

Inicio seguro

Este paquete orienta a los agentes; aun así debes verificar el código generado, el alcance de los cambios y los resultados de las pruebas.

Primer prompt

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Primero indica el plan, las incertidumbres y los archivos afectados por esta tarea. Después propone el enfoque más sencillo y realiza solo los cambios necesarios para el objetivo.
