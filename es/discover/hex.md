# Dictado local que convierte la voz en texto al instante

Desarrollado en Rust, Hex es una herramienta de dictado por voz local que funciona en los sistemas operativos Mac, Windows y Linux. Permite a los usuarios hablar manteniendo presionada una tecla y convertir lo que dicen en texto.

## Qué aporta

- Cuando hablas manteniendo presionada la tecla de acceso directo, tu voz se transcribe instantáneamente como texto en la aplicación abierta.
- Descarga el modelo de voz en tu dispositivo la primera vez que se ejecuta y evita que tus datos salgan de tu ordenador.
- Funciona de manera local en sistemas Mac, Windows y Linux.

## Cómo empezar

Para empezar a utilizar la aplicación Hex, puedes descargar el archivo de instalación o el paquete DMG adecuado para tu sistema operativo desde la tabla de descargas oficial. Después de instalar y ejecutar el archivo, puedes empezar a hablar manteniendo presionada la tecla de acceso directo.
