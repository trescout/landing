# Evitar envíos de códigos incorrectos

Desarrollada con el lenguaje Go, no-mistakes es una herramienta de línea de comandos diseñada para evitar que los desarrolladores de software envíen código defectuoso (git push). Al ejecutarse en el entorno de desarrollo local, proporciona una capa de seguridad que evita que se introduzcan cambios no deseados en el código base.

## Qué aporta

- Evita que los códigos defectuosos lleguen al servidor remoto
- Verificación automática y generación limpia de relaciones públicas.
- Revisión segura de código en un espacio de trabajo aislado

## Instalación

**Descarga la herramienta a tu computadora**

```
curl -fsSL https://raw.githubusercontent.com/kunchenguid/no-mistakes/main/docs/install.sh | sh
```

## Ejecución

**Iniciar el proyecto**

```
no-mistakes init
```

**Envía tu código a través de la puerta segura**

```
git push no-mistakes
```
