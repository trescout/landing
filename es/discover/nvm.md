# Administre fácilmente las versiones de Node.js

Node Version Manager es una herramienta de línea de comandos que permite a los desarrolladores administrar múltiples versiones de Node.js en sus sistemas. Con su estructura de script de shell (script bash) compatible con POSIX, facilita la realización de transiciones rápidas de versiones entre diferentes proyectos.

## Qué aporta
- Cambie rápidamente entre diferentes versiones de Node.js
- Trabaje sin problemas en shells compatibles con POSIX
- Instale fácilmente versiones de Node.js específicas del proyecto

## Instalación
**Instalación usando cURL**

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
```

**Instalación usando wget**

```
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
```


## Ejecución
**Instalación y uso de la versión Node.js**

```
nvm install 24
```
