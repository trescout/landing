# Acelere los procesos de prueba en proyectos Python

Pytest es un marco de pruebas que admite una amplia gama de pruebas en proyectos de Python, desde pruebas unitarias a pequeña escala hasta pruebas funcionales complejas. Se ha convertido en una herramienta estándar en los procesos de desarrollo de software gracias a su estructura que permite a los desarrolladores escribir pruebas más completas con menos código.

## Qué aporta
- Permite escribir pruebas unitarias y funcionales completas con menos código.
- Ayuda a analizar las pruebas rápidamente proporcionando información detallada en el momento del error.
- Se adapta fácilmente a diferentes necesidades con su amplio soporte enchufable y su estructura modular.

## Instalación
**pip (PyPI)**

```
pip install pytest
```


## Ejecución
**Ejecutar pruebas**

```
pytest
```
