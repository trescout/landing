Simulación de aula interactiva con múltiples agentes de IA

Desarrollado por investigadores de Tsinghua, OpenMAIC conecta agentes de IA con roles de docentes, alumnos y observadores en un aula interactiva simulada.

Actualizaciones

Qué obtienes

  • Arquitectura multiagente basada en roles: Interacciones dinámicas entre agentes LLM que actúan como profesores, alumnos curiosos y moderadores.
  • Interfaz de clase visual y de audio: Entorno inmersivo con pizarra virtual, flujo de preguntas y respuestas y síntesis de voz (TTS).
  • Plan de estudio adaptable: Suba documentos PDF o apuntes para diseñar clases interactivas de forma automática.
  • Simulación con un solo clic: Controle la orquestación de agentes mediante una interfaz web moderna sin escribir código.
  • Compatibilidad con modelos abiertos: Conecte Ollama, vLLM o APIs en la nube para asignar a los agentes el modelo de IA que prefiera.

Instalación

Clonar el repositorio e instalar dependencias
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install

Ejecución

Iniciar servidor de desarrollo interactivo
pnpm run dev
# Tarayıcıda http://localhost:3000 adresini açın

Arquitectura técnica y principio de funcionamiento

OpenMAIC opera sobre un bucle de diálogo orientado a eventos que coordina los agentes:

  • Motor de orquestración conversacional: Coordinador central que regula turnos de palabra, ritmo de debate y contexto compartido.
  • Gestión de memoria y contexto: Mantiene el estado de la pizarra virtual, dudas planteadas y el progreso de la lección.
  • Streaming WebSocket de baja latencia: Transmite réplicas de los agentes, estados de ánimo y animaciones a la interfaz web en tiempo real.

Dinámica de aula multiagente y simulaciones de roles

OpenMAIC abre posibilidades innovadoras en tecnología educativa e investigación de IA multiagente:

  • Entornos de debate socrático: Fomente el pensamiento crítico del usuario mediante debates guiados por agentes con diferentes puntos de vista.
  • Tutoría personalizada adaptativa: Adapte la profundidad de las explicaciones al ritmo de comprensión del estudiante en tiempo real.
  • Investigación de dinámicas sociales de agentes: Analice la colaboración y la formación de consenso entre modelos de lenguaje autónomos.

Preguntas frecuentes

  • ¿Requiere OpenMAIC una GPU local? Solo se necesita GPU si ejecuta modelos locales con Ollama; con APIs en la nube funciona en cualquier equipo convencional.
  • ¿El usuario puede intervenir por voz? Sí. La integración WebRTC permite participar activamente con el micrófono en las discusiones de clase.
  • ¿Cuántos agentes pueden coincidir en la clase? La experiencia está optimizada para entre 3 y 8 agentes simultáneos, configurable según sus preferencias.
  • ¿Qué formatos de archivo se pueden cargar? Admite archivos de texto plano, Markdown y documentos PDF para alimentar los contenidos educativos.
