Crear una lista de contraseñas específicas

Common User Passwords Profiler es una herramienta de Python para crear listas de contraseñas específicas. Prepara archivos de diccionario personalizados (listas de palabras) analizando ciertos datos del usuario.

  • ★ 6.161
  • Python
  • GitHub Trending · 2026-07-01

Qué aporta

  • Prepara diccionarios personalizados analizando los datos del usuario.
  • Ofrece la oportunidad de crear un perfil orientado a objetivos con preguntas interactivas.
  • Analiza las coincidencias de nombre de usuario y contraseña predeterminadas con la base de datos de Alecto.

Instalación

Repositorio de clones
git clone --depth 1 https://github.com/Mebus/cupp.git && cd cupp

Ejecución

Ejecutar en modo interactivo
python3 cupp.py -i
