# Administre su servidor personal en la nube

CasaOS ofrece un sistema de nube personal de código abierto que facilita la administración de aplicaciones basadas en Docker. Esta interfaz, desarrollada con el lenguaje Go, permite a los usuarios gestionar de forma sencilla sus servidores a través de un panel visual.

## Qué aporta
- Instale aplicaciones Docker con un solo clic
- Gestiona archivos con una interfaz visual
- Monitorear los recursos del servidor con un widget

## Instalación
**comando de instalación**

```
curl -fsSL https://get.casaos.io | sudo bash
```


## Ejecución
**comando de actualización**

```
curl -fsSL https://get.casaos.io/update | sudo bash
```
