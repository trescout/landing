# Inteligencia empresarial automatizada con inteligencia artificial

Desarrollada por Canner, WrenAI es una herramienta de inteligencia empresarial generativa (BI generativa) de código abierto que exporta datos automáticamente en paneles y gráficos al convertir el lenguaje natural en consultas de bases de datos (texto a SQL). La plataforma proporciona procesos de análisis de datos confiables para agentes de IA a través de una capa de contexto manejable que admite más de veinte fuentes de datos.

## Qué aporta
- Genera consultas SQL confiables desde lenguaje natural
- Convierte automáticamente datos en paneles
- Admite más de 22 fuentes de datos

## Instalación
**Instalación CLI**

```
pip install wrenai                      # core (DuckDB included)
pip install "wrenai[postgres,memory]"   # add per-datasource and memory extras as needed
```

**Configuración de código auxiliar para cliente AI**

```
npx skills add Canner/WrenAI            # auto-detects Claude Code, Cursor, Cline, Codex, …
```


## Si no programa
Configure mi conexión a la base de datos usando WrenAI, cree el esqueleto del proyecto y ejecute mi primera consulta. Luego, enriquezca el contexto incluyendo los datos de lógica empresarial en la carpeta sin formato de mi proyecto.
