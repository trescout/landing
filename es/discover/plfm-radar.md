# Radar de matriz en fase de código abierto

PLFM RADAR es un sistema de radar de matriz en fase de código abierto y de bajo costo que opera a una frecuencia de 10,5 GHz. Este proyecto basado en hardware utiliza software de control desarrollado con lenguaje PLSQL para hacer accesibles las tecnologías de detección de radiofrecuencia.

## Qué aporta
- Opciones de alcance de 3 km y 20 km
- Capacidad de dirección electrónica del haz
- Procesamiento de señal avanzado basado en FPGA

## Cómo empezar
Este proyecto es un sistema integral que consta de componentes de hardware y software. Para comenzar, puede acceder a los esquemas de hardware, los archivos de software FPGA y la interfaz de usuario basada en Python revisando la documentación en la página de GitHub. Se recomienda seguir los informes técnicos y los resultados de la simulación en las carpetas pertinentes para la instalación y uso del proyecto.
