# Motor para la ejecución y servicio rápido de modelos de inteligencia artificial

vllm-project/vllm es un motor de inferencia y servicio para grandes modelos de lenguaje (LLM) que ofrece un alto rendimiento y eficiencia de memoria. Desarrollado en Python, esta herramienta tiene como objetivo acelerar los procesos de ejecución de los modelos de inteligencia artificial.

## Qué aporta

- ofrece gestión pagedattention que proporciona eficiencia de memoria
- funciona de manera compatible con los modelos populares de Hugging Face
- incluye compatibilidad con servidores API compatibles con OpenAI

## Instalación

**instalación de vllm**

```
uv pip install vllm
vllm download-kernels  # precompiled kernels for faster startup
```
