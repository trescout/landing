# Gestiona tu propio archivo multimedia

LunaTV es un proyecto desarrollado con el lenguaje TypeScript que ofrece una interfaz de visualización multimedia de código abierto. Este software, que no está destinado a uso comercial, permite a los usuarios ver sus propios contenidos multimedia en una estructura organizada.

- ★ 10.021
- TypeScript
- GitHub Trending · 2026-09-08

## Qué aporta
- Posibilidad de ver contenidos multimedia personales en una interfaz organizada
- Sincronización del historial de visualización y favoritos entre dispositivos
- Experiencia de visualización portátil a través del navegador sin necesidad de instalación

## Cómo empezar
Esta herramienta funciona con la tecnología de contenedorización de software llamada Docker. Para la instalación, puede ir a la sección '部署' (Despliegue) en la página de GitHub del proyecto y utilizar los archivos de Docker Compose o realizar una instalación con un solo clic a través de plataformas en la nube como Zeabur. Tenga en cuenta que el proyecto viene con una interfaz vacía y que debe agregar sus propias fuentes multimedia.
