# Genere modelos 3D de alta calidad a partir de imágenes

Desarrollado por Microsoft, TRELLIS es una arquitectura de representación latente estructurada que transforma texto o entradas visuales en modelos tridimensionales (3D). Esta tecnología utiliza métodos de IA generativa para crear activos 3D de alta calidad de forma rápida y compacta.

## Qué aporta

- Crea recursos 3D detallados y texturizados a partir de una sola imagen.
- Procesa con éxito estructuras complejas y superficies abiertas.
- Proporciona resultados realistas con PBR, materiales de visualización basados ​​en la física.

## Instalación

**Clonar el repositorio**

```
git clone -b main https://github.com/microsoft/TRELLIS.2.git --recursive
    cd TRELLIS.2
```

**Instalar dependencias**

```
. ./setup.sh --new-env --basic --flash-attn --nvdiffrast --nvdiffrec --cumesh --o-voxel --flexgemm
```
