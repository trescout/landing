# Gestión de ingresos con inteligencia artificial

AiToEarn es una plataforma basada en TypeScript que permite a los usuarios gestionar sus procesos de monetización a través de automatizaciones impulsadas por IA. El proyecto ofrece una infraestructura abierta a los desarrolladores combinando la ejecución autónoma de tareas y modelos de ingresos basados ​​en inteligencia artificial.

## Qué aporta

- Gestiona los procesos de creación de contenido y publicación automática respaldados por inteligencia artificial.
- Permite generar ingresos a partir de contenidos con modelos CPS, CPE y CPM.
- Ofrece interacción simultánea y gestión de seguidores en múltiples plataformas de redes sociales.

## Instalación

**Configuración rápida con Docker**

```
git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn
docker compose up -d
```

**Instalación del complemento OpenClaw**

```
npx -y @aitoearn/openclaw-plugin-cli
```

## Ejecución

**Lanzando con Docker**

```
docker compose up -d
```
