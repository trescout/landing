# Acceso a inteligencia artificial desde la línea de comandos

Desarrollado por Google, gemini-cli es una herramienta de código abierto que proporciona acceso directo al modelo de inteligencia artificial Gemini a través de la terminal. El software permite a los usuarios crear peticiones (prompts) de IA de manera rápida y ligera en un entorno de línea de comandos.

## Qué aporta

- Puedes examinar y editar tus bases de código directamente desde la línea de comandos.
- Puedes generar nuevas aplicaciones a partir de imágenes o documentos de texto.
- Puedes automatizar tus tareas repetitivas frecuentes mediante scripts de comandos.

## Instalación

**Instalación global con el gestor de paquetes npm**

```
npm install -g @google/gemini-cli
```

**Instalación con el gestor de paquetes Homebrew**

```
brew install gemini-cli
```

## Ejecución

**Ejecución directa sin necesidad de instalación**

```
# Using npx (no installation required)
npx @google/gemini-cli
```
