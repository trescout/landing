# Administrar solicitudes de extracción masivas

Desarrollado por GitHub, gh-stack es una herramienta de línea de comandos que facilita la creación y gestión de solicitudes de extracción apiladas durante el proceso de desarrollo de software. Su objetivo es acelerar el proceso de revisión dividiendo los cambios de código complejos en partes pequeñas e independientes.

## Qué aporta

- Divide grandes cambios de código en partes pequeñas y manejables
- Organiza automáticamente las dependencias entre solicitudes de extracción
- Facilita las operaciones de rebase para mantener actualizadas las sucursales dentro de la pila.

## Instalación

**Instalación de la herramienta**

```
gh extension install github/gh-stack
```

**Habilitar el soporte de IA**

```
gh skill install github/gh-stack
```

## Ejecución

**Comenzando una nueva pila**

```
gh stack init
```

**Agregar una nueva capa a la pila**

```
gh stack add api-endpoints
```
