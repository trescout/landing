# Estructuras de datos y algoritmos con animaciones.

Hola 算法 es una plataforma educativa de código abierto que enseña estructuras de datos y algoritmos con visualizaciones animadas. El proyecto estandariza el proceso de aprendizaje al ofrecer soporte para numerosos lenguajes de programación y ejemplos de código ejecutable con un solo clic.
