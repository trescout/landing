# Configuración moderna para sistemas Linux.

Desarrollado por Basecamp, Omarchy es una herramienta de configuración moderna y original para sistemas operativos Linux. Ofrece un enfoque basado en scripts de shell para estandarizar las instalaciones del sistema y facilitar la administración.

## Qué aporta
- Simplifique la gestión estandarizando las configuraciones del sistema
- Personaliza la experiencia del usuario con temas únicos.
- Funciona integrado con herramientas de desarrollo y aplicaciones de terminal.
