# Registro rápido para proyectos C++

spdlog es una biblioteca de registro muy rápida desarrollada para el lenguaje de programación C++. Ofrece gestión de resultados de alto rendimiento para acelerar los procesos de depuración y monitoreo en proyectos de software.

## Qué aporta
- Gestión de registros de alto rendimiento
- Salida a diferentes destinos como archivo, consola y depurador.
- El nivel de registro dinámico cambia en tiempo de ejecución

## Instalación
**macOS (hecho en casa)**

```
brew install spdlog
```


## Cómo empezar
Para incluirlo en su proyecto, simplemente copie la carpeta de inclusión de la página de GitHub a su directorio de trabajo. Alternativamente, puede instalar la biblioteca usando el comando apropiado para su sistema a través de administradores de paquetes como Debian, Homebrew o vcpkg.
