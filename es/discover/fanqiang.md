# Evite la censura de Internet con Kotlin

El proyecto Fanqiang es una herramienta de entrada escrita en Kotlin, desarrollada para evitar la censura de Internet. Es un software de código abierto diseñado para proporcionar a los usuarios acceso a recursos de red limitados.

- ★ 49.405
- Kotlin
- GitHub Trending · 2026-06-12

## Qué aporta
- Proporciona acceso a guías completas de acceso a la red para diferentes sistemas operativos y dispositivos.
- Proporciona guías de configuración y uso para diversos protocolos y herramientas de red.
- Incluye métodos para eludir las restricciones de red en diferentes plataformas, como consolas de juegos y navegadores.
