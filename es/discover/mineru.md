# Convierta sus documentos para IA

MinerU convierte formatos de documentos complejos como PDF y Office a formato Markdown o JSON adecuado para modelos de lenguaje grandes. Esta herramienta tiene como objetivo hacer que los datos no estructurados estén disponibles en flujos de trabajo basados ​​en agentes.

- ★ 77.695
- Python
- GitHub Trending · 2026-06-26

## Qué aporta
- Convierte archivos PDF y Office a lenguaje de marcado
- Prepara datos no estructurados para los flujos de trabajo de los agentes.
- Convierte formatos de documentos complejos a salida JSON

## Instalación
**Instalación estándar**

```
pip install --upgrade pip
pip install uv
uv pip install -U "mineru[all]"
```

**Instalación del desarrollador**

```
git clone https://github.com/opendatalab/MinerU.git
cd MinerU
uv pip install -e .[all]
```
