# Plantillas de IA para servicios financieros

Esta biblioteca de Python publicada por Anthropic ofrece plantillas listas para usar y ejemplos de código para desarrollar aplicaciones de inteligencia artificial para la industria de servicios financieros. Su objetivo es guiar a los desarrolladores que desean automatizar los procesos de generación de informes y análisis de datos financieros.

- ★ 37.453
- GitHub Trending · 2026-09-21

## Qué aporta
- Automatiza los procesos de banca de inversión y gestión de activos.
- Ofrece complementos listos para usar y plantillas API
- Le permite realizar estudios de mercado y modelos financieros.

## Instalación
**Implementar agente administrado**

```
export ANTHROPIC_API_KEY=sk-ant-...
scripts/deploy-managed-agent.sh gl-reconciler
```


## Si no programa
Instale el complemento Claude Cowork para crear análisis financieros y modelos de valoración e iniciar procesos de investigación de mercado y evaluación de ingresos.
