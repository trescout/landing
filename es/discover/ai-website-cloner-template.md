# Copia de sitios web con inteligencia artificial

El clonador de sitios web con inteligencia artificial (AI website cloner), desarrollado por JCodesMore, permite copiar sitios web existentes con un solo comando utilizando agentes de codificación basados en TypeScript. Esta herramienta utiliza la generación de código impulsada por IA para automatizar los procesos de diseño y desarrollo web.

## Qué aporta
- Convierte sitios web existentes al código base Next.js
- Extrae automáticamente elementos y activos de diseño.
- Reconstruye componentes en paralelo

## Instalación
**Clonar el repositorio**

```
git clone https://github.com/YOUR-USERNAME/YOUR-NEW-REPOSITORY.git
   cd YOUR-NEW-REPOSITORY
```

**Instalar dependencias**

```
npm install
```


## Si no programa
Con este proyecto, analice el sitio web de destino, extraiga elementos y activos de diseño, escriba propiedades de componentes y ejecute renderizadores paralelos para reconstruirlo en la estructura Next.js.
