Guía de inteligencia artificial para pruebas de penetración

Reverse-skill ofrece un paquete de enrutamiento respaldado por inteligencia artificial para procesos de ingeniería inversa y pruebas de penetración. Con sus funciones de arranque de cadena de herramientas y base de conocimientos de desarrollo propio, Claude Code se integra con herramientas de codificación como Cursor y Cline.

Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Utilice este proyecto como guía en una tarea de prueba de penetración o ingeniería inversa. Antes de realizar su tarea, revise las instrucciones en el archivo README_AI.md, cumpla con las reglas de enrutamiento en el archivo RULES.md e inicie el flujo de trabajo determinando la metodología correcta a través de MASTER-ROUTING.md.
