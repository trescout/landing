# Mensajería segura vía Bluetooth sin internet

Bitchat-android ofrece una experiencia de mensajería descentralizada que no requiere conexión a Internet, utilizando tecnología de malla Bluetooth. La aplicación, desarrollada en lenguaje Kotlin, permite a los usuarios establecer una comunicación tipo IRC a través de la red local.

- ★ 7.424
- Kotlin
- GitHub Trending · 2026-07-27

## Qué aporta
- Comunicación sin internet con tecnología Bluetooth mesh
- Mensajería descentralizada y cifrada de extremo a extremo
- Privacidad sin necesidad de cuenta ni número de teléfono

## Instalación
**Copie el repositorio a su computadora**

```
git clone https://github.com/permissionlesstech/bitchat-android.git
   cd bitchat-android
```
