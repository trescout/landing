# Interfaces rápidas y compatibles con inteligencia artificial

Solid es una biblioteca de JavaScript declarativa para crear interfaces de usuario. En lugar de utilizar un Modelo de Objeto de Documento Virtual (Virtual DOM), compila las plantillas directamente en nodos reales del Modelo de Objeto de Documento (DOM) para realizar actualizaciones con reactividad de grano fino (fine-grained reactivity).

## Qué aporta

- La estructura de gestión de interfaces gana velocidad actualizando directamente los nodos reales del navegador en lugar de usar un Virtual DOM.
- Minimiza la carga en el procesador al ejecutar los componentes una sola vez.
- Renueva solo las pequeñas partes afectadas mediante su estructura que realiza un seguimiento automático de los cambios de datos.

## Instalación

**Creación de un nuevo proyecto con plantilla predefinida**

```
npx degit solidjs/templates/solid-v2/basic my-app
cd my-app
npm install
npm run dev
```

## Ejecución

**Incluir la herramienta de desarrollo en el proyecto de Vite**

```
npm i solid-js @solidjs/web
npm i -D vite @solidjs/vite-plugin
```
