# Mapea tu base de código a la inteligencia artificial

Codegraph es una herramienta de grafo de conocimiento (knowledge graph) local que preindexa las bases de código para presentarlas a los modelos de IA. Al sincronizar automáticamente los cambios de código, permite que los asistentes de programación como Claude Code o Cursor utilicen menos tokens y llamadas a herramientas.

## Qué aporta

- Crea un grafo de conocimiento local que permite a los modelos de IA consumir menos tokens al programar.
- Sincroniza automáticamente los cambios de código en segundo plano, manteniendo el índice siempre actualizado.
- Conecta herramientas como el asistente de programación Cursor directamente con la arquitectura de tu proyecto.

## Instalación

**Instalación global con el gestor de paquetes npm**

```
npm i -g @colbymchenry/codegraph
```

## Ejecución

**Ejecución y vinculación directa de la herramienta con npx**

```
npx @colbymchenry/codegraph
```
