# Formato rápido y estructurado para el intercambio de datos.

Desarrollados por Google, los buffers de protocolo son un formato de intercambio de datos independiente del idioma que se utiliza para serializar datos estructurados. Este mecanismo proporciona una transferencia de datos binarios rápida y eficiente en la comunicación entre sistemas.

## Qué aporta
- Transferencia eficiente de datos binarios entre sistemas.
- Serialización de datos independiente del idioma
- Estructura de datos flexible y extensible

## Instalación
**macOS (hecho en casa)**

```
brew install protobuf
```


## Ejecución
**compilar esquema**

```
protoc --cpp_out=. dosya.proto
```
