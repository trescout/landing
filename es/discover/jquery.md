jQuery es una librería de JavaScript que facilita la creación de elementos interactivos en páginas web. Ofrece herramientas que simplifican la manipulación del Modelo de Objeto de Documento (DOM) y la gestión de eventos para los desarrolladores.

## Qué aporta

## Instalación

**Instala las dependencias y compila el proyecto**

```
cd jquery
npm install
npm run build
```

**Genera todos los archivos de versión**

```
npm run build:all
```
