# Convertir códigos HTML a vídeo

Desarrollado por Heygen, Hyperframes ofrece un marco que convierte códigos HTML directamente en video. Diseñada para facilitar a los agentes de inteligencia artificial la producción de contenido visual, esta herramienta convierte interfaces basadas en web en formato de vídeo.

## Qué aporta
- Producción de vídeo con HTML y CSS.
- Trabajo compatible con agentes de inteligencia artificial.
- Llevando su propio sistema de diseño al vídeo

## Instalación
**Configuración para agente de IA**

```
npx skills add heygen-com/hyperframes
```

**Instalación manual de CLI**

```
npx hyperframes init my-video
cd my-video
npx hyperframes preview      # preview in browser with live reload
npx hyperframes render       # render to MP4
```


## Ejecución
**Vista previa y renderizado**

```
npx hyperframes preview      # preview in browser with live reload
npx hyperframes render       # render to MP4
```
