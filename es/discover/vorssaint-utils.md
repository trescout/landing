# Herramienta de barra de menús modular para macOS

Vorssaint-utils es un conjunto de herramientas de barra de menús de código abierto desarrollado para el sistema operativo macOS. Combina y ofrece muchas funciones diferentes, como control de audio basado en aplicaciones, monitorización del sistema, organización de ventanas y portapapeles, en una sola interfaz.

## Qué aporta

- proporciona control de audio, monitorización del sistema y gestión de ventanas con un solo icono en la barra de menús
- ejecuta solo los módulos necesarios eliminando las características no utilizadas
- no requiere cuenta, no recopila datos y no requiere suscripción
