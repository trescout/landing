# Desarrolle aplicaciones empresariales sin escribir código

ToolJet es una plataforma de creación de aplicaciones de código abierto para desarrollar herramientas internas, paneles y agentes de inteligencia artificial. Esta infraestructura basada en JavaScript permite a las empresas digitalizar flujos de trabajo complejos al reducir la necesidad de escribir código.

## Qué aporta
- Diseño rápido de interfaz visual con método de arrastrar y soltar.
- Fácil integración con bases de datos, API y servicios en la nube
- Flujos de trabajo flexibles con soporte para JavaScript y Python

## Instalación
**Instalación local con Docker**

```
docker run \
  --name tooljet \
  --restart unless-stopped \
  -p 80:80 \
  --platform linux/amd64 \
  -v tooljet_data:/var/lib/postgresql/13/main \
  tooljet/try:ee-lts-latest
```


## Si no programa
Ayúdame a crear un panel de operaciones internas de arrastrar y soltar conectado a una base de datos utilizando más de 60 componentes listos para usar en ToolJet.
