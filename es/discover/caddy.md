# Configure un servidor https automático

Caddy es un servidor web extensible escrito en Go que ofrece gestión automática de certificados HTTPS. Simplifica la configuración y la seguridad de los sitios web al admitir los protocolos HTTP/1, HTTP/2 y HTTP/3.

- ★ 76.784
- Go
- GitHub Trending · 2026-10-05

## Qué aporta
- Ofrece gestión automática de certificados HTTPS de forma predeterminada
- Compatible con los protocolos HTTP/1, HTTP/2 y HTTP/3
- Funciona en cualquier lugar sin requerir dependencias externas

## Ejecución
**compilacion**

```
git clone "https://github.com/caddyserver/caddy.git"
cd caddy/cmd/caddy/
go build
```
