## Qué aporta

- Muestra contenido de Twitter sin ejecutar JavaScript
- Oculta la dirección IP del usuario y la huella digital del navegador
- Es mucho más rápido y ligero que la interfaz estándar de Twitter.

## Instalación

**Instalación con Docker**

```
docker run -v $(pwd)/nitter.conf:/src/nitter.conf -d --network host zedeus/nitter:latest
```

**Lanzamiento con Docker Compose**

```
docker-compose up -d
```
