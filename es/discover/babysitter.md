# Gestiona tus agentes de IA sin errores

Babysitter proporciona un mecanismo de control determinista para que una fuerza laboral de agentes de inteligencia artificial pueda realizar tareas complejas sin errores ni alucinaciones.

## Qué aporta

- Supervisa la fuerza laboral del agente.
- Reduce el riesgo de alucinaciones y errores.
- Proporciona un flujo determinista y predecible.

## ¿Cómo instalar, cómo utilizar?

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Instale el complemento Babysitter en Claude Code usando los comandos 'claude plugin Marketplace add a5c-ai/babysitter' seguido de 'claude plugin install --scope user babysitter@a5c.ai', luego inicie un flujo de trabajo controlado paso a paso con el comando '/babysitter:call'.

**Código Claude · mercado + instalación**

```
claude plugin marketplace add a5c-ai/babysitter
claude plugin install --scope user babysitter@a5c.ai
```

**Ejecutar tarea con TDD**

```
claude "/babysitter:call implement user authentication with TDD"
```
