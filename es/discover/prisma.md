# Gestión de bases de datos para proyectos Node.js

Prisma es una herramienta de mapeo relacional de objetos (ORM) que simplifica las interacciones de bases de datos para proyectos Node.js y TypeScript. Su estructura, que admite diferentes sistemas de bases de datos, permite a los desarrolladores crear consultas de bases de datos con seguridad de tipos.

- Crear consultas de bases de datos con seguridad de tipos
- Modelado y migración de datos declarativos
- Interfaz gráfica para visualización de datos.

## Instalación

**Instalación de paquetes requeridos**

```
npm install prisma --save-dev
npm install @prisma/client
```

## Ejecución

**Iniciar un servidor de base de datos local**

```
npx prisma dev
```

**Crear una base de datos basada en la nube**

```
npx create-db --interactive
```
