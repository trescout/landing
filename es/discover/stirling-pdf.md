# Edición integral de PDF en su propio servidor

Stirling-PDF es una herramienta de procesamiento de documentos de código abierto que permite a los usuarios editar archivos PDF en cualquier dispositivo. Desarrollada con TypeScript, esta aplicación centraliza los procesos de gestión de documentos ejecutándose en servidores locales.

- ★ 89.027
- TypeScript
- GitHub Trending · 2026-06-23

## Qué aporta
- Más de 50 herramientas diferentes de edición de PDF
- Tratamiento local de sus datos sin enviarlos a servicios externos
- Fácil acceso a través del navegador o escritorio

## Instalación
****

```
docker run -d --name stirling-pdf -p 127.0.0.1:8080:8080 -v ./stirling-data:/configs --restart unless-stopped docker.stirlingpdf.com/stirlingtools/stirling-pdf:latest
```


## Ejecución
****

```
http://localhost:8080
```
