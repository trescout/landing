# Integración de IA para TradingView

TradingView-mcp conecta Claude Code con la aplicación de escritorio TradingView, lo que le permite automatizar los procesos de análisis de gráficos. Esta integración permite a los usuarios personalizar los flujos de trabajo de análisis técnico a través del contexto del modelo impulsado por IA (Protocolo de contexto del modelo).

## Qué aporta

- Codificación y depuración de Pine Script con inteligencia artificial
- Gestión automática de dibujos y análisis en el gráfico.
- Controle alertas de precios y símbolos mediante comando

## Instalación

**Descarga de archivos e instalación.**

```
git clone https://github.com/tradesdontlie/tradingview-mcp.git
cd tradingview-mcp
npm install
```

**Lanzamiento en macOS**

```
./scripts/launch_tv_debug_mac.sh
```

## Ejecución

**Uso directo a través de CLI**

```
# Install globally (optional)
npm link

# Or run directly
node src/cli/index.js <command>
```
