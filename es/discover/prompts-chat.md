# Biblioteca de prompts para modelos de inteligencia artificial

Prompts.chat es una plataforma de código abierto donde los usuarios comparten y descubren prompts preparados para modelos de inteligencia artificial. Esta herramienta, que puede alojar en su propio servidor para uso corporativo, le permite gestionar bibliotecas de prompts con un enfoque centrado en la privacidad.

## Qué aporta

- Amplio archivo de prompts compatible con modelos modernos de inteligencia artificial
- Posibilidad de alojamiento en servidor privado para necesidades corporativas
- Libro de formación interactivo y gratuito sobre ingeniería de prompts

## Instalación

**Inicio rápido**

```
npx prompts.chat new my-prompt-library
cd my-prompt-library
```

**Instalación manual**

```
git clone https://github.com/f/prompts.chat.git
cd prompts.chat
npm install && npm run setup
```

## Ejecución

**Iniciar la interfaz de línea de comandos**
