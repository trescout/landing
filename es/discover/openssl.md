# Biblioteca de seguridad que cifra el tráfico de red

OpenSSL es una biblioteca de seguridad de propósito general utilizada para cifrar el tráfico de red. Es una herramienta de software de código abierto que admite los protocolos Seguridad de la Capa de Transporte (TLS), TLS de Datagramas (DTLS) y QUIC.

- realiza operaciones de cifrado y firma
