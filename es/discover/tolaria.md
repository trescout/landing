# Aplicación de escritorio de base de conocimientos Markdown

Tolaria es una aplicación de escritorio desarrollada para gestionar bases de conocimiento basadas en Markdown. Escrita en TypeScript, esta herramienta facilita mantener organizados los sistemas de notas y documentación personal.

## Qué aporta

- Proporciona gestión de notas portátil con archivos de rebajas.
- Ofrece control total de versiones con integración de Git.
- Protege la propiedad de los datos con soporte para trabajo fuera de línea.

## Instalación

**Dependencias para Arch/Manjaro**

```
sudo pacman -S --needed webkit2gtk-4.1 base-devel curl wget file openssl \
    appmenu-gtk-module libappindicator-gtk3 librsvg
```

**Dependencias para Debian/Ubuntu**

```
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
    libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev \
    libsoup-3.0-dev patchelf
```

## Ejecución

**Iniciando el entorno de desarrollo**

```
pnpm install
pnpm dev
```

**Ejecute la aplicación de escritorio**

```
pnpm tauri dev
```
