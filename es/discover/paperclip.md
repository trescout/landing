# Centro de gestión de agentes de IA

Paperclip es una plataforma de código abierto que le permite administrar agentes de IA en el lugar de trabajo a través de una única interfaz. Desarrollada con TypeScript, esta herramienta permite controlar los flujos de trabajo de los agentes utilizados para diferentes tareas desde un punto central.

## Qué aporta

- Administre múltiples agentes de IA desde una única interfaz.
- Controlar de forma centralizada el presupuesto y las tareas de los agentes.
- Haga que los flujos de trabajo sean rastreables como un administrador de tareas.

## Instalación

**Instalación rápida**

```
curl -fsSL https://paperclip.ing/install.sh | bash -s -- --no-prompt --no-onboard
paperclipai onboard --yes
```

**Instalación del desarrollador**

```
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev
```
