¿Qué hace esta herramienta?

CS249r Book es un libro de texto completo y de código abierto que se centra en ejecutar modelos de aprendizaje automático en dispositivos con recursos limitados. Explora en profundidad los temas de TinyML y la computación de aprendizaje profundo eficiente (efficient deep learning computing).

¿Para quién es?

Estudiantes e investigadores que deseen integrar modelos de aprendizaje profundo en dispositivos de borde (edge devices).

Qué no esperar

Aquellos interesados únicamente en el desarrollo web o que aún no poseen los fundamentos de aprendizaje automático.

Aspectos destacados

  • Ofrece un recurso fundamental sobre TinyML y temas de aprendizaje profundo eficiente.
  • Explica técnicas de optimización de modelos para dispositivos con hardware limitado.
  • Es un libro de texto de código abierto con calidad académica.

Primer flujo de uso

  1. Visite el repositorio oficial de GitHub para acceder a la versión más reciente del libro.
  2. Descargue el PDF o la versión web correspondiente en su dispositivo.
  3. Configure los entornos de Python y PyTorch recomendados para probar los ejemplos de código del libro.

Inicio seguro

Los ejemplos de código del libro son para fines educativos; debe realizar sus propias pruebas de seguridad y rendimiento antes de llevarlos directamente a un entorno de producción.
