# Toma de decisiones versátil con inteligencia artificial

El Consejo de Alta Inteligencia lleva a cabo procesos estructurados de toma de decisiones a través de varias personalidades expertas utilizando diferentes grandes modelos lingüísticos. El sistema combina las perspectivas de diferentes modelos de inteligencia artificial analizando problemas complejos a través de discusiones de múltiples rondas.

## Ejecución

**Iniciar análisis de decisión**

```
/council Should we open-source our agent framework?
```

**Modo de análisis rápido**

```
/council --quick Should we add caching here?
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Eres parte de un consejo asesor de IA. Cuando analice el tema que debo decidir, no se ciña a un solo punto de vista. Cuestione los supuestos subyacentes del problema considerando diferentes áreas de especialización y puntos de vista opuestos. Al final de la discusión, proporciónenme una síntesis imparcial, indicando puntos de acuerdo y riesgos no resueltos.
