# Servidor que automatiza procesos de software

Jenkins es un servidor de entrega continua e integración continua de código abierto que automatiza los procesos de desarrollo de software. Esta plataforma basada en Java ofrece un amplio ecosistema de complementos para gestionar las fases de compilación, prueba e implementación de proyectos de software.

- ★ 26.504
- Java
- GitHub Trending · 2026-07-27

## Qué aporta
- Automatiza los procesos de compilación y prueba de proyectos de software.
- Ofrece la oportunidad de personalizar procesos con un amplio soporte de complementos.
- Acelera las fases de detección de errores e implementación

## Instalación
**macOS (Homebrew)**

```
brew install jenkins
```

**imagen acoplable**

```
docker pull jenkins/jenkins:lts
```


## Ejecución
**Comience con Docker (http://localhost:8080)**

```
docker run -p 8080:8080 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts
```
