# Herramientas que aprovechan la biblioteca estándar de C++

Desarrollado por Google, Abseil ofrece fragmentos de código fuente abierto que complementan la biblioteca estándar de C++. Esta biblioteca proporciona estructuras de datos y algoritmos básicos para mejorar la capacidad de mantenimiento y el rendimiento del código en proyectos de software complejos.

- ★ 18.043
- C++
- GitHub Trending · 2026-07-11

## Qué aporta
- Proporciona algoritmos y estructuras de datos subyacentes compatibles con C++17.
- Proporciona fragmentos de código confiables probados en proyectos de Google.
- Completa la funcionalidad que falta en la biblioteca estándar.

## Instalación
**macOS (hecho en casa)**

```
brew install abseil
```
