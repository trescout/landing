# Plataforma de código abierto para modelos de inteligencia artificial

Desarrollado por Google, TensorFlow es una biblioteca de código abierto utilizada para crear y entrenar modelos de aprendizaje automático (machine learning). Permite a los desarrolladores diseñar redes neuronales complejas y desplegar estos modelos de forma escalable.

- ★ 200.552
- C++
- GitHub Trending · 2026-09-27

## Qué aporta
- Permite crear y desplegar aplicaciones de aprendizaje automático
- Ofrece interfaces estables para los lenguajes de programación Python y C++
- Aloja un ecosistema flexible con compatibilidad para GPU y CPU

## Instalación
**Para instalar la biblioteca**

```
pip install tensorflow
```

**Para instalar solo la versión que incluye CPU**

```
pip install tensorflow-cpu
```


## Ejecución
**Para iniciar el entorno de Python**

```
python
```
