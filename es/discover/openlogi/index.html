Descubrir · GitHub · OpenLogi

Gestión de código abierto para dispositivos Logitech

OpenLogi es una alternativa nativa, de código abierto y centrada en el uso local a Logitech Options+, escrita en Rust. Permite configurar botones, DPI y SmartShift sin cuenta ni telemetría.

Qué aporta

  • Proporciona control local sin crear una cuenta.
  • Asigna atajos personalizados a todas las teclas.
  • Ofrece soporte multiplataforma, incluido Linux.

Instalación

Instalación estándar con Homebrew
brew install --cask openlogi
Sigue la última versión
brew tap aprilnea/tap
brew install --cask aprilnea/tap/openlogi@latest
