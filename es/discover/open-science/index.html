Entorno de trabajo de inteligencia artificial para la investigación científica

Open Science, desarrollado por AIPOCH, ofrece un entorno de trabajo de inteligencia artificial de tipo local-first y agnóstico al modelo para la investigación científica. El software combina cuadernos de Python y R con conexiones de datos, permitiendo que los procesos científicos se lleven a cabo de manera reproducible.

Qué aporta

  • Realice análisis científicos reproducibles ejecutando código en Python y R
  • Genere informes, tablas y gráficos automáticos conectándose a fuentes de datos científicos
  • Gestione todo el proceso, desde la revisión bibliográfica hasta la simulación, con agentes de inteligencia artificial locales

Instalación

Instalación local desde el código fuente
git clone https://github.com/aipoch/open-science.git
cd open-science
npm install
npm run dev
Modo de desarrollo de interfaz web
npm run build:web
npm run dev:web

Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Ayúdame en mi proceso de investigación científica. Apóyame escribiendo código en Python o R mientras realizo revisiones bibliográficas, desarrollo hipótesis y llevo a cabo procesos de análisis de datos. Entiende mis objetivos de investigación y, mediante la lectura de archivos, búsquedas en la web y consultas de datos científicos, genera resultados, tablas y gráficos trazables.
