# Sistema que coordina agentes de inteligencia artificial

Escrito en lenguaje Clojure, Swarm Forge es una herramienta para coordinar múltiples agentes de IA desde un solo centro. El software ofrece una estructura simple para gestionar procesos complejos donde diferentes agentes deben trabajar de forma colaborativa.

## Qué aporta

- Gestiona múltiples agentes de inteligencia artificial desde un único centro
- Monitorear agentes simultáneamente con multiplexor de terminal Tmux
- Ofrece flujos de trabajo personalizables específicos del proyecto

## Instalación

**Descargar y preparar la rama de trabajo.**

```
BRANCH=four-pack
curl -L "https://github.com/unclebob/swarm-forge/archive/refs/heads/${BRANCH}.tar.gz" | tar -xz --strip-components=1
```

## Ejecución

**Inicialización del sistema**

```
./swarm
```
