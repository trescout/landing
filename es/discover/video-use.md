# Edición automática de vídeo con inteligencia artificial

La biblioteca de uso de video permite a los agentes de codificación automatizar los procesos de edición de video. Esta herramienta basada en Python acelera los flujos de trabajo al realizar tareas de edición visual mediante comandos de software.

- ★ 19.784
- Python
- GitHub Trending · 2026-06-29

## Qué aporta
- Elimina automáticamente palabras de relleno y espacios silenciosos.
- Aplica efectos de desvanecimiento profesionales a las transiciones de audio.
- Realiza edición de color y subtítulos respaldada por inteligencia artificial.

## Instalación
**Clonando el repositorio e instalando dependencias**

```
git clone https://github.com/browser-use/video-use ~/Developer/video-use
ln -sfn ~/Developer/video-use ~/.claude/skills/video-use
```


## Ejecución
**Acceso a la carpeta de videos**

```
cd /path/to/your/videos
claude
```


## Si no programa
Configure https://github.com/browser-use/video-use por mí. Lea install.md primero para instalar este repositorio, conecte ffmpeg, registre la habilidad con cualquier agente que esté ejecutando y configure la clave API de ElevenLabs. Pídame que la pegue cuando la necesite. Luego lea SKILL.md para uso diario y lea siempre helpers/ porque ahí es donde se encuentran los guiones de edición. Después de la instalación, no transcribas nada por tu cuenta · solo dime que está listo y espera a que coloque el material en una carpeta.
