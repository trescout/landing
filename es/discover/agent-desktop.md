# Herramienta de control de escritorio para agentes de inteligencia artificial

Desarrollado por Vercel Labs, agent-desktop es una interfaz de línea de comandos (CLI) que permite a los agentes de inteligencia artificial leer y gestionar aplicaciones de escritorio a través del árbol de accesibilidad del sistema operativo. Escrita en Rust, esta herramienta tiene como objetivo mejorar las capacidades de uso de computadoras (computer use) de los agentes.

## Qué aporta

- Lee aplicaciones de escritorio a través del árbol de accesibilidad del sistema operativo
- Opera sobre los elementos sin necesidad de coincidencia de píxeles
- Produce respuestas rápidas y estructuradas en formato JSON

## Instalación

**Instalar con el gestor de paquetes**

```
npm install -g agent-desktop
agent-desktop version
```

**Añadir habilidad**

```
npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop
```
