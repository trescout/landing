# Editor arquitectónico 3D basado en web

Pascalorg/editor basado en TypeScript permite a los usuarios crear y compartir proyectos arquitectónicos tridimensionales a través del navegador. El software tiene como objetivo hacer que los procesos de diseño arquitectónico sean accesibles a través de una interfaz basada en web.

- ★ 20.706
- TypeScript
- GitHub Trending · 2026-07-29

## Qué aporta
- Modelado arquitectónico 3D con React Three Fiber
- Visualización de alto rendimiento con soporte WebGPU
- Gestión de estado y escenario central basada en Zustand

## Instalación
**Instalar los paquetes necesarios**

```
npm install @pascal-app/core @pascal-app/viewer @pascal-app/editor @pascal-app/nodes
```


## Ejecución
**Iniciar el servidor de desarrollo**

```
bun dev
```


## Si no programa
Quiero crear una escena arquitectónica usando Pascal Editor. Ayúdame a construir una estructura 3D básica usando los paquetes @pascal-app/core y @pascal-app/viewer incluidos en la arquitectura del proyecto. Explíqueme paso a paso cómo configurar los enlaces useScene y useViewer para administrar el estado de la escena, definir la jerarquía de nodos (sitio, edificio, nivel) e integrar un componente NodeRenderer en la escena.
