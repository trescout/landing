# Tu equipo de inteligencia artificial que trabaja en tu escritorio

Orkas es un equipo de inteligencia artificial de código abierto que se ejecuta en ordenadores de escritorio y convierte objetivos en listas de tareas. Al coordinar dieciséis agentes expertos integrados y varios modelos de codificación, esta aplicación ofrece un espacio de trabajo con prioridad local en macOS y Windows.

## Qué aporta

- Ejecuta tareas de investigación, contenido, diseño y codificación con dieciséis agentes expertos integrados.
- Mantiene en su memoria tus proyectos, reglas y archivos para evitar que empieces desde cero cada vez.
- Avanza tus procesos de trabajo de forma ordenada mediante automatizaciones programadas y listas de tareas.

## Instalación

**Clona el repositorio del proyecto y ejecútalo**

```
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```
