# CMS visual moderno en su propio servidor

Instatic es un moderno sistema de gestión de contenido visual (CMS) autohospedado basado en TypeScript. Permite a los usuarios ejecutar la interfaz de administración de contenido en sus propios servidores con un proceso de instalación rápido.

- ★ 7.891
- TypeScript
- GitHub Trending · 2026-07-01

## Qué aporta
- Consolide toda la gestión de contenidos en un único servidor
- Edite páginas directamente con IA
- Produzca resultados HTML limpios y rápidos

## Instalación
**Instalación rápida con Docker**

```
INSTATIC_IMAGE=ghcr.io/corebunch/instatic:latest docker compose -f compose.prod.yml -f compose.sqlite.yml up -d
```


## Si no programa
Utilizando el agente de inteligencia artificial en la interfaz de edición de páginas, cree nodos editables que cumplan con los criterios de diseño especificados, tengan una estructura HTML semántica y estén formateados con CSS. Permita que el agente se integre con modelos como Claude, OpenAI u OpenRouter para crear automáticamente la estructura de la página y los componentes de contenido.
