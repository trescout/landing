# Desarrolla inteligencia artificial con Claude Code

Esta guía visual de Claude Code ofrece una amplia gama de ejemplos, desde conceptos básicos hasta configuraciones avanzadas de agentes. Su objetivo es acelerar los procesos de codificación de los usuarios y estandarizar las prácticas de desarrollo de aplicaciones a través de plantillas copiables.

## Qué aporta
- Integrar las funciones de Claude Code en los flujos de trabajo.

## Instalación
**Clonando el directorio y copiando el primer comando**

```
# 1. Clone the guide
git clone https://github.com/luongnv89/claude-howto.git
cd claude-howto

# 2. Copy your first slash command
mkdir -p /path/to/your-project/.claude/commands
cp 01-slash-commands/optimize.md /path/to/your-project/.claude/commands/
```

**Instalación de gancho**

```
mkdir -p ~/.claude/hooks
cp 06-hooks/*.sh ~/.claude/hooks/
chmod +x ~/.claude/hooks/*.sh
```


## Ejecución
**Primer intento de comando**

```
# 3. Try it — in Claude Code, type:
# /optimize
```
