# Reanudar evaluación con inteligencia artificial

El agente de contratación es un agente de inteligencia artificial (agente de IA) diseñado para evaluar y calificar currículums. Esta herramienta, desarrollada con lenguaje Python, tiene como objetivo automatizar los procesos de selección de candidatos en los procesos de selección.

- ★ 6.694
- Python
- GitHub Trending · 2026-06-25

## Qué aporta
- Analiza automáticamente currículums en formato PDF.
- Enriquece a los candidatos con datos de GitHub.
- Proporciona un informe de puntuación justo y explicable.

## Instalación
**Descargando e instalando los archivos necesarios**

```
git clone https://github.com/interviewstreet/hiring-agent
cd hiring-agent

python -m venv .venv
# Linux or macOS
source .venv/bin/activate
# Windows
# .venv\Scripts\activate

pip install -r requirements.txt
```


## Ejecución
**Iniciar revisión de currículum**

```
python score.py /path/to/resume.pdf
```


## Si no programa
Actúe como reclutador y analice los datos del currículum proporcionado y las contribuciones técnicas en GitHub. Calificar los proyectos, habilidades técnicas y experiencia laboral del candidato según criterios objetivos. Al calificar, considere la calidad del código del candidato en GitHub, la frecuencia de las contribuciones y la relevancia de sus proyectos para las aplicaciones del mundo real. En última instancia, cree un informe de evaluación transparente y justo que destaque las fortalezas y debilidades del candidato.
