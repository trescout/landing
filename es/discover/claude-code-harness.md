# Desarrollo disciplinado con Claude Code

Claude Code Harness introduce la disciplina de planificar, hacer, revisar y entregar, frenando la tendencia a que el trabajo crudo de los agentes se desmorone. Evita que los planes se pierdan en el chat, limita las pruebas y garantiza una producción de código más consistente. Aunque Claude se centra en el código, también ofrece rutas de integración para Codex y OpenCode.

## Instalación

**Global con npm**

```
npm install -g claude-code-harness
```

## Cómo empezar

Integrado en Claude Code con instalación en el repositorio; luego implementa el ciclo de planificar, hacer y revisar.

## ¿Cómo instalar, cómo utilizar?

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Configure este flujo de trabajo disciplinado en Claude Code ejecutando '/plugin Marketplace add Chachamaru127/claude-code-harness', luego '/plugin install claude-code-harness@claude-code-harness-marketplace' y '/harness-setup', luego comience con '/harness-plan'.
