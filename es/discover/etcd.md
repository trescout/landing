# Almacén de clave-valor para sistemas distribuidos

etcd es un almacén de clave-valor confiable diseñado para almacenar datos críticos en sistemas distribuidos. Desarrollado en el lenguaje Go, este sistema se centra en garantizar la consistencia de los datos dentro de arquitecturas distribuidas.

## Qué aporta

- almacena de forma segura datos críticos en sistemas distribuidos
- alcanza decenas de miles de operaciones de escritura por segundo
- ofrece cifrado TLS automático y autenticación de certificados de cliente
