# Herramienta de orquestación para agentes de inteligencia artificial

Desarrollado por Google, Ax es un entorno de ejecución de orquestación de código abierto para agentes de inteligencia artificial. Escrita en Go, esta infraestructura facilita la gestión y ejecución de flujos de trabajo agénticos complejos.

- ★ 12.083
- GitHub Trending · 2026-09-23

## Qué aporta
- Te permite gestionar miles de millones de cargas de trabajo de inteligencia artificial autónomas.
- Te permite ejecutar agentes en un entorno de zona aislada (sandbox) seguro y aislado.
- Ofrece una configuración rápida y declarativa mediante archivos YAML.

## Instalación
**Instalación de la herramienta CLI**

```
go install github.com/google/ax/cmd/ax@latest
```

**Implementación del plano de control**

```
make deploy AX_IMAGE_REPO=<your-registry>
```


## Si no programa
Quiero instalar la herramienta AX, desarrollada por Google y que proporciona orquestación para agentes de inteligencia artificial. Primero, instale la herramienta de línea de comandos ejecutando el comando `go install github.com/google/ax/cmd/ax@latest`. A continuación, implemente el plano de control utilizando el comando `make deploy AX_IMAGE_REPO=<your-registry>`.
