# Descarga rápida de vídeos a través de la terminal

Yoinks es una herramienta para descargar cualquier vídeo a través de la terminal (línea de comandos) sin anuncios ni redirecciones. Desarrollado con TypeScript, este software ofrece un método práctico para transferir archivos de vídeo directamente al almacenamiento local.

- ★ 4.173
- TypeScript
- GitHub Trending · 2026-10-02

## Qué aporta
- Descarga vídeos de más de 1800 sitios como YouTube, Instagram y TikTok
- Guarda directamente en el almacenamiento local sin anuncios ni botones de descarga falsos
- Ofrece la posibilidad de elegir la resolución del vídeo o descargar solo el archivo de audio

## Instalación
**Instalación global**

```
npm install -g yoinks
```

**Funcionamiento sin instalación**

```
npx yoinks
```


## Ejecución
**Iniciar con el enlace del vídeo**

```
yoinks https://youtu.be/dQw4w9WgXcQ
```

**Iniciar con un menú interactivo**

```
yoinks
```


## Si no programa
Quiero descargar vídeos de plataformas como YouTube, X, Instagram o TikTok. Utilizando esta herramienta que funciona en la terminal, configúrala para que guarde el enlace del vídeo que proporcione directamente en mi carpeta de descargas local y me ofrezca opciones de resolución. Asegúrate de que el proceso de descarga sea limpio, sin anuncios ni redirecciones durante la operación.
