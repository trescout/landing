# Gestione modelos de IA en una única interfaz

Desarrollada por Andrew Ng, aisuite es una biblioteca de Python que permite gestionar diferentes proveedores de IA generativa a través de una única interfaz. Permite a los desarrolladores cambiar entre varios servicios modelo sin realizar cambios en el código.

## Qué aporta

- Gestione diferentes proveedores de IA con una única interfaz
- Capacidad de cambiar entre modelos sin cambiar el código
- Definición de funciones de Python como herramientas para inteligencia artificial

## Instalación

**Instalación básica de la biblioteca**

```
pip install aisuite               # base package, no provider SDKs
```

**Configuración con todos los proveedores**

```
pip install 'aisuite[all]'        # with all provider SDKs
```
