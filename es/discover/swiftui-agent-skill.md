# Especialización en SwiftUI para tu asistente de inteligencia artificial

SwiftUI-Agent-Skill ofrece paquetes de habilidades (skills) dedicados a modelos de IA para la herramienta de desarrollo de interfaces SwiftUI. Este recurso ayuda a que los asistentes de código de IA como Claude Code y Codex creen componentes de SwiftUI de manera más coherente y rápida.

## Qué aporta

- Permite que la IA audite los errores de rendimiento y accesibilidad en el código escrito con SwiftUI, la biblioteca de interfaces de Apple.
- Evita que los grandes modelos de lenguaje utilicen interfaces de programación de aplicaciones (API) antiguas y previene problemas con los lectores de pantalla.
- Se integra fácilmente en los asistentes de código Claude Code y Codex para aportar estándares de código modernos.

## Instalación

**Entorno Node con el gestor de paquetes Homebrew**

```
brew install node
```

**Habilidad SwiftUI Pro al asist de IA**

```
npx skills add https://github.com/twostraws/swiftui-agent-skill --skill swiftui-pro
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Si el entorno de ejecución de software Node no está instalado en mi ordenador, instálalo usando el comando 'brew install node'.
