# Asistente de inteligencia artificial para investigación académica

Academic Research Skills es una biblioteca de Python desarrollada para Claude Code que automatiza los procesos académicos en las etapas de investigación, redacción, revisión, edición y finalización. Esta herramienta tiene como objetivo estandarizar los flujos de trabajo académicos en Claude Code, una herramienta de programación asistida por inteligencia artificial.

- ★ 45.232
- Python
- GitHub Trending · 2026-09-02

## Qué aporta
- Gestiona el proceso de redacción de artículos académicos de principio a fin
- Automatiza los procesos de búsqueda y verificación de referencias
- Mejora la calidad de la redacción y revisa los textos

## Instalación
**Añadir la extensión desde la tienda**

```
/plugin marketplace add Imbad0202/academic-research-skills
```

**Instalar la extensión**

```
/plugin install academic-research-skills
```


## Ejecución
**Planificación de artículos**

```
/ars-plan
```


## Si no programa
Quiero utilizar el complemento Academic Research Skills para gestionar mi proceso de investigación académica. Inicia un diálogo socrático para crear la estructura de mi artículo y ayúdame a gestionar el proceso determinando en qué etapa de mi investigación me encuentro.
