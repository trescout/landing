# Base de datos escalable para sistemas distribuidos

Apache Cassandra es una base de datos transaccional distribuida de código abierto que proporciona escalabilidad lineal y tolerancia a fallas sin causar pérdida de rendimiento en hardware estándar o infraestructuras de nube. Este sistema, desarrollado en lenguaje Java, está diseñado para procesos de gestión de datos a gran escala que requieren alta disponibilidad.

- ★ 10.004
- Java
- GitHub Trending · 2026-07-28

## Qué aporta

- Distribuye datos automáticamente entre varias máquinas.
- Fácil gestión de datos con lenguaje de consulta CQL similar a SQL.
- Proporciona alta disponibilidad y tolerancia a fallos.

## Instalación

**macOS (Homebrew)**

```
brew install cassandra
```

**imagen acoplable**

```
docker pull cassandra
```

## Ejecución

**Lanzar con Docker**

```
docker run -p 9042:9042 cassandra
```
