# Capacidades web nativas para su agente de IA

Wigolo es una herramienta que proporciona capacidades de búsqueda, extracción de datos y rastreo local para agentes de codificación de inteligencia artificial. Este sistema, que funciona sobre el protocolo de contexto modelo (MCP), proporciona investigación gratuita sin dependencia de la nube y sin necesidad de una clave API.

## Qué aporta

- Búsqueda y escaneo gratuitos sin necesidad de clave API
- Procesamiento y almacenamiento en caché de datos locales independientes de la nube
- Integración directa con herramientas de IA populares

## Instalación

**Iniciando la instalación del agente**

```
npx wigolo init --agents=<your-agent>
```

**Comprobación del estado del sistema**

```
npx wigolo doctor
```
