# Agente autónomo de IA para el desarrollo de software

Prime-Agent, desarrollado por PrimeIntellect, es un agente de aprendizaje por refuerzo autorreparable para procesos de desarrollo de software y tareas autónomas a largo plazo. Escrita en TypeScript, esta herramienta tiene como objetivo aumentar la eficiencia del desarrollo de software mediante la automatización de flujos de trabajo complejos.

## Qué aporta

- Ejecuta tareas de larga duración ininterrumpidamente en segundo plano.
- Automatiza los procesos de codificación y gestión de archivos.
- Ofrece capacidad de aprendizaje por refuerzo de autocuración.

## Instalación

**Descargue e instale la herramienta en su computadora**

```
curl -fsSL https://app.primeintellect.ai/prime-agent/install.sh | sh
```

## Ejecución

**Iniciar el agente en el directorio de trabajo**

```
prime-agent
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Usted actúa como Agente Principal. Utilice el entorno IPython para gestionar flujos de trabajo de desarrollo de software complejos, realizar operaciones de archivos y realizar un seguimiento de tareas autónomas de larga duración en el directorio de mi proyecto. Trabaje en paralelo creando subagentes cuando sea necesario, haga que lo aprendido sea permanente con el comando /refine y complete objetivos dentro de los presupuestos establecidos con el modo /autonomous. Actúe siempre respetando los permisos de usuario y los límites de seguridad al realizar transacciones.
