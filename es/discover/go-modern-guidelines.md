# Ir a pautas modernas

go-modern-guidelines, publicado por JetBrains, es una guía que ayuda a los asistentes de codificación de inteligencia artificial a escribir software conforme a los estándares actuales de Go...

## Qué aporta

- Permite que los modelos de IA utilicen las funciones actuales de Go
- Prefiere métodos modernos y eficientes a patrones de código antiguos.
- Detecta automáticamente la versión Go del proyecto y adapta las características del idioma en consecuencia

## Instalación

**Agregar mercado para Junie**

```
/extensions marketplace add JetBrains/go-modern-guidelines
```

**Instalación del complemento para Junie**

```
/extensions install modern-go-guidelines
```

## Ejecución

**Ejecutar guía sobre Claude Code**

```

```

## Si no programa

Pegue esto en su agente (Claude Code · Codex · Antigravity)

De ahora en adelante, utilice estándares Go modernos al escribir código. Considere la versión de Go en el archivo go.mod del proyecto, optando por las últimas características del lenguaje y adiciones a la biblioteca estándar desde la versión 1.0 a 1.27. Utilice funciones como `max(a, b)` en lugar de bloques `if-else`, métodos modernos como `slices.Contains` en lugar de bucles manuales y patrones actualizados como `cmp.Or` en lugar de comprobaciones nulas.

Repositorio: https://github.com/JetBrains/go-modern-guidelines. Sigue las instrucciones oficiales del archivo README de este repositorio para la instalación y ejecución.

Antes de empezar, comprueba en qué sistema operativo estamos y si las herramientas necesarias (ej. Python, Node.js, Git, Docker) están instaladas. Instala las que falten paso a paso según este sistema.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.

Dime qué debería ver en la pantalla al final de cada paso. Si ocurre un error, te pegaré el mensaje de error tal cual y lo solucionaremos juntos.
