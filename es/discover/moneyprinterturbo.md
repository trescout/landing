# Produzca vídeos de IA con un solo clic

MoneyPrinterTurbo produce automáticamente videos cortos utilizando modelos de lenguaje grandes a partir de un tema o palabra clave que usted proporcione. Combina texto, subtítulos, música de fondo y elementos visuales. (El nombre tiene fines de marketing; es una herramienta de producción de contenidos, no una máquina para "imprimir dinero").

## Qué aporta

- Crea edición automática utilizando texto, subtítulos, música y elementos visuales.
- Es fácil de usar gracias a su interfaz web.
- Permite la producción de videos por lotes y múltiples.

## Instalación

**Clonar repositorio oficial**

```
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
```

## Ejecución

**Iniciar con Docker Compose**

```
docker-compose up
```

**Iniciar interfaz web**

```
uv run streamlit run ./webui/Main.py --browser.gatherUsageStats=False
```

## nota honesta

Requiere una clave API del modelo AI + instalación para funcionar; Es posible que se cobre el uso de API. Es responsabilidad del usuario asegurarse de que los videos producidos cumplan con los derechos de autor y las reglas de la plataforma.
