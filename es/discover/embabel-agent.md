# Agentes inteligentes de IA en Java

Embabel es un marco diseñado para desarrollar agentes de inteligencia artificial que se ejecutan en la máquina virtual Java (JVM). Esta estructura, escrita en Kotlin, facilita la integración de capacidades de IA generativa en ecosistemas de software empresarial.

## Qué aporta

- Integra modelos de inteligencia artificial con sistemas empresariales basados en Java y Kotlin.
- Resuelve tareas complejas de forma dinámica con capacidad de planificación automática.
- Gracias a una sólida verificación de tipos, gestiona la interacción del código y la inteligencia artificial sin errores.

**Clonar y ejecutar instancias**
