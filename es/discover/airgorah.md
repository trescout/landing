# Auditoría de seguridad para redes inalámbricas

Desarrollado en el lenguaje Rust, Airgorah es un software utilizado para auditar la seguridad de redes inalámbricas. Ofrece la capacidad de realizar pruebas de seguridad como monitorear el tráfico de red cercano, detectar dispositivos conectados a puntos de acceso y descifrar contraseñas.

## Qué aporta

- Puedes monitorear el tráfico de redes inalámbricas cercanas y detectar los dispositivos conectados.
- Puedes capturar datos de protocolo de enlace (handshake) de la red y claves de seguridad.
- Puedes probar la resistencia de las contraseñas de los puntos de acceso.

## Cómo empezar

Para instalar y utilizar el software, puedes seguir las guías ubicadas en las páginas oficiales de la Wiki del proyecto. Para que la aplicación funcione, necesitas una tarjeta de red inalámbrica que admita el modo monitor en el sistema operativo Linux.
