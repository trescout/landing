# Inteligencia artificial que ejecuta código en tu computadora

Open Interpreter ofrece un agente de codificación que automatiza los procesos de desarrollo de software ejecutando código en el entorno informático local. Diseñada para trabajar con modelos de lenguajes de bajo costo, esta herramienta permite ejecutar tareas complejas directamente desde la terminal.

- ★ 67.509
- Rust
- GitHub Trending · 2026-07-16

## Qué aporta
- Automatiza procesos de software a través del terminal local.
- Es compatible con modelos de idiomas de bajo costo.
- Ofrece la posibilidad de probar aplicaciones web y nativas.

## Instalación
**Instalación para macOS y Linux**

```
curl -fsSL https://www.openinterpreter.com/install | sh
```


## Ejecución
**Iniciar sesión**

```
i
```


## Si no programa
Quiero que actúes como agente codificador en mi computadora. Espero que automatice tareas complejas ejecutando código en mi entorno local y probando aplicaciones web o locales cuando sea necesario. Utilizar estructuras que optimicen modelos de bajo costo al realizar transacciones y ejecutar mis comandos de forma segura a través del terminal.
