# Gestione agentes de inteligencia artificial con estándares de equipo

Desarrollado por Tencent, teamai-cli es una herramienta de desarrollo de software que permite a los equipos interactuar con herramientas de inteligencia artificial a través de una interfaz de línea de comandos (CLI). Esta herramienta tiene como objetivo digitalizar los procesos de trabajo de los equipos integrando capacidades de inteligencia artificial generativa (generative AI) en sus flujos de trabajo.

- ★ 3.405
- TypeScript
- GitHub Trending · 2026-09-10

## Qué aporta
- Define reglas de colaboración y habilidades para todos los miembros del equipo.
- Funciona de manera compatible con herramientas de inteligencia artificial como Claude Code y Cursor.
- Sincroniza automáticamente las actualizaciones realizadas con todos los miembros del equipo.

## Instalación
**Instale la herramienta en su computadora**

```
npm install -g teamai-cli
```


## Ejecución
**Conecte el repositorio del equipo a su proyecto**

```
teamai init https://github.com/yourorg/yourrepo
```
