# Espacio de trabajo local para agentes de IA

Apache Maka es un espacio de trabajo local diseñado para agentes de inteligencia artificial. Ele fornece rastreabilidade dos procesos do agente gravando mensajes, chamadas de vehículos y decisiones de permiso em un registro orientado a anexos.

- ★ 2.064
- TypeScript
- GitHub Trending · 2026-08-22

## Qué aporta
- Almacena datos de forma segura en su computadora local
- Registra el historial de transacciones y llamadas de vehículos.
- Ofrece herramientas nativas como edición de archivos y ejecución de comandos.

## Instalación
**Iniciando el entorno de desarrollo**

```
git clone https://github.com/apache/maka.git
cd maka
npm ci
npm run dev
```

**Crear todos los espacios de trabajo**

```
npm run dev:full
```


## Ejecución
**Iniciar la interfaz del terminal**

```
npm run cli:dev
```


## Si no programa
En el espacio de trabajo de Maka, necesitas analizar un proyecto, organizar los archivos usando las herramientas necesarias y mantener todas tus acciones en un registro rastreable. Controle los permisos en todo su flujo de trabajo, conserve los mensajes del modelo y administre el proceso de manera recuperable en caso de errores.
