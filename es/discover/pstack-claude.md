# Mejora los resultados de tus agentes de inteligencia artificial

Pstack-claude es una biblioteca de automatización que adapta las funciones principales de la herramienta de desarrollo de software Cursor para diferentes modelos y plataformas de inteligencia artificial. Permite a los desarrolladores ejecutar flujos de trabajo de agentes de inteligencia artificial complejos de manera estándar en varios entornos de ejecución.

- ★ 1.340
- JavaScript
- GitHub Trending · 2026-10-05

## Qué aporta
- mantiene tu código breve, simple y verificado
- adaptado para diferentes modelos y plataformas de inteligencia artificial
- se ejecuta localmente y no tiene servidores ni telemetría

## Cómo empezar
Puedes comenzar ejecutando los comandos de complemento correspondientes a través de tu plataforma Claude Code, Codex o Pi. Puedes consultar la documentación para conocer los pasos detallados de instalación compartida.
