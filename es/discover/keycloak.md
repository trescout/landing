# Gestión central de identidades para sus aplicaciones

Keycloak ofrece soluciones de gestión de acceso e identidad de código abierto para aplicaciones y servicios modernos. Esta plataforma basada en Java se utiliza para estandarizar los procesos centralizados de autenticación y autorización.

## Qué aporta
- Estandariza los procesos de autenticación de usuarios.
- Proporciona una sólida gestión de identidad y autorización.
- Aumenta sin esfuerzo la seguridad de las aplicaciones.

## Instalación
**Toma la imagen oficial**

```
docker pull quay.io/keycloak/keycloak
```


## Ejecución
**Iniciar en modo desarrollo**

```
docker run -p 8080:8080 -e KC_BOOTSTRAP_ADMIN_USERNAME=admin -e KC_BOOTSTRAP_ADMIN_PASSWORD=admin quay.io/keycloak/keycloak start-dev
```
