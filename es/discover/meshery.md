# Gestione infraestructuras nativas de la nube

Meshery es una plataforma de gestión de malla de servicios diseñada para la gestión de infraestructuras nativas de la nube. La plataforma permite realizar procesos de configuración, gestión del ciclo de vida y análisis de rendimiento en entornos de nube complejos desde un único centro.

## Qué aporta
- Gestión central de infraestructura y aplicaciones basadas en Kubernetes
- Oportunidad de diseño visual sin tener que lidiar con archivos YAML complejos
- Operación consistente entre múltiples proveedores y clústeres de nube

## Instalación
**Guión de bash**

```
curl -L https://meshery.io/install | bash -
```


## Ejecución
**CLI**

```
mesheryctl system start
```
