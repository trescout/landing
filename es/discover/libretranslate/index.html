Descubrir · GitHub · LibreTranslate

Servicio de traducción gratuito en su propio servidor

LibreTranslate ofrece una interfaz de traducción automática (API) gratuita y de código abierto. Esta herramienta basada en Python, que puede alojar en su propio servidor, le permite trabajar sin conexión a Internet.

Actualizaciones

  • 2 de agosto de 2026: Estrellas 15,075 → 15,834, última versión v1.9.6 (26 de mayo de 2026).

Qué aporta

  • Deshazte de servicios dependientes como Google o Azure
  • Traducir sin conexión sin conexión a Internet
  • Utilice un motor de traducción completamente abierto y gratuito

Instalación

vía pip (PyPI)
pip install libretranslate
con ventana acoplable
docker run -p 5000:5000 libretranslate/libretranslate

Ejecución

Iniciar servidor de traducción
libretranslate
Iniciar servidor de traducción
libretranslate --port 5000
