# URL persistente para el entorno de desarrollo local

Portless, desarrollado por Vercel Labs, convierte los números de puerto utilizados en entornos de desarrollo local en direcciones URL persistentes y con nombre. Esta herramienta permite tanto a los desarrolladores como a los agentes de inteligencia artificial autónomos interactuar más fácilmente con los servicios locales.

## Qué aporta

- Convierte números de puerto variables en direcciones con nombres memorables
- Proporciona soporte automático para HTTPS y HTTP/2
- Crea una URL separada para cada paquete en estructuras monorepo

## Instalación

**Instalación general**

```
npm install -g portless
```

**Instalación basada en proyectos**

```
npm install -D portless
```

## Ejecución

**Inicia la aplicación con una URL con nombre**

```
portless myapp next dev
```
