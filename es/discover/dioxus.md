# Aplicaciones multiplataforma con Rust

Dioxus es un framework de Rust que permite desarrollar aplicaciones de extremo a extremo (fullstack) con una única base de código para plataformas web, de escritorio y móviles. Estandariza la experiencia de desarrollo de aplicaciones en el ecosistema Rust al acelerar el proceso de creación de la interfaz de usuario con su estructura basada en componentes similar a React.

## Qué aporta
- Desarrollo de aplicaciones web, de escritorio y móviles con una única base de código
- Proceso de desarrollo rápido con actualización de código instantánea
- Estructura de componentes similar a React y soporte de pila completa con seguridad de tipos

## Instalación
**Instalar la herramienta CLI**

```
curl -fsSL https://dioxuslabs.com/install.sh | bash
```

**Método de instalación alternativo**

```
cargo install --git https://github.com/DioxusLabs/dioxus dioxus-cli --locked
```


## Ejecución
**Iniciando la aplicación**

```
dx serve
```

**Empaquetando la aplicación**

```
dx bundle
```
