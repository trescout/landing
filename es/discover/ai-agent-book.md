# Guía para agentes de inteligencia artificial.

Este libro de código abierto sobre agentes de inteligencia artificial (agentes de IA) cubre de manera integral los principios de diseño y las aplicaciones de ingeniería. Además de la información teórica, incluye códigos de aplicación divididos en secciones y archivos PDF compilados.

## Qué aporta
- Conozca los principios de funcionamiento de los agentes de inteligencia artificial.
- Adquiera habilidades prácticas con ejemplos de código prácticos
- Explore los procesos de diseño e ingeniería de agentes

```
cd book && bash build_pdf.sh
```


## Si no programa
Eres un experto en desarrollo de agentes de inteligencia artificial. Explícame paso a paso cómo configurar el sistema de memoria de un agente e integrar herramientas externas (llamada a herramientas), según la fórmula 'Agente = LLM + Contexto + Herramientas'. Explicar con ejemplos qué enfoques de ingeniería debo utilizar para optimizar la gestión del contexto, especialmente en procesos RAG (Recuperación-Generación Aumentada).
