# Cree una imagen de Windows 11 ligera y personalizada

ntdevlabs/tiny11builder es una aplicación de WinUI diseñada para crear versiones más pequeñas y personalizadas del sistema operativo Windows 11. Desarrollada en C#, esta herramienta permite a los usuarios ajustar el tamaño de las imágenes del sistema según sus necesidades.

## Qué aporta

- Puede eliminar de la imagen del sistema operativo las aplicaciones preinstaladas y las características innecesarias del sistema.
- Puede elegir modos preconfigurados de Tiny11 según sus necesidades o seleccionar individualmente los componentes que desea eliminar.
- Con la opción de aceleración de procesos, puede reducir el tiempo del proceso de creación de la imagen y reanudar las operaciones interrumpidas desde donde se guardaron.

## Cómo empezar

Descargue el archivo comprimido adecuado para su sistema informático desde la página oficial de lanzamientos en GitHub. Extraiga todo el contenido del archivo en una carpeta, abra el archivo ejecutable con permisos de administrador y siga los pasos.
