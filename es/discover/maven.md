# Gestión de proyectos para proyectos Java.

Apache Maven es una herramienta de comprensión y gestión de proyectos (herramienta de automatización de compilación) que gestiona los procesos de creación de software en proyectos basados en Java. Utiliza la estructura del modelo de objetos del proyecto para estandarizar el ciclo de vida del desarrollo de software.

## Qué aporta
- Estandariza los procesos de creación de software.
- Proporciona gestión centralizada con el modelo de objetos del proyecto.
- Gestiona los procesos de informes y documentación.

## Instalación
**macOS (hecho en casa)**

```
brew install maven
```

**imagen acoplable**

```
docker pull maven
```


## Ejecución
**compilar el proyecto**

```
mvn package
```
