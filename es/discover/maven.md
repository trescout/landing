# Estándar de compilación para proyectos Java

Maven es una herramienta potente que estandariza la compilación, la gestión de dependencias y el ciclo de vida del proyecto en proyectos basados en Java.

## ¿Qué hace esta herramienta?
Maven es una potente herramienta de gestión de proyectos que estandariza la compilación, la gestión de dependencias y el ciclo de vida del proyecto en proyectos basados en Java. Automatiza los procesos de desarrollo definiendo la estructura del proyecto a través de un archivo POM (Project Object Model).

## ¿Para quién es?
Para aquellos que desean gestionar dependencias de bibliotecas complejas en proyectos Java y crear procesos de compilación estándar y repetibles.

## Qué no esperar
Para aquellos que trabajan fuera del ecosistema Java o que necesitan pasos de compilación no estándar y totalmente personalizados.

## Aspectos destacados
- Descarga automáticamente las dependencias de las bibliotecas a través de un repositorio central.
- Divide los pasos de compilación, prueba y empaquetado del proyecto en etapas estándar.
- Simplifica la gestión de proyectos grandes y multimódulo.

## Primer flujo de uso
- Asegúrese de tener un entorno Java compatible instalado en su sistema.
- Descargue Apache Maven desde su sitio web oficial y añada la carpeta de instalación a la ruta del sistema.
- Verifique la instalación ejecutando el comando de control de versión en su terminal.
- Para comenzar un nuevo proyecto, prepare la estructura básica de directorios con la herramienta de creación.

## Instalación
**macOS (Homebrew)**

```
brew install maven
```

**imagen acoplable**

```
docker pull maven
```


## Ejecución
**compilar el proyecto**

```
mvn package
```
