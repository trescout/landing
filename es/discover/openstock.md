# Siga los datos del mercado de valores de forma gratuita

OpenStock es una alternativa de código abierto a las costosas plataformas de intercambio. Ofrece seguimiento de precios en tiempo real, alertas personalizadas y análisis de la empresa. Es accesible para todos y gratuito para siempre.

- ★ 14.018
- TypeScript
- AGPL-3.0
- GitHub Trending · 26 May 2026

## Qué aporta
- Realiza un seguimiento de los precios en tiempo real.
- Envía notificaciones personalizadas.
- Proporciona análisis detallados para empresas.
- Elimina la necesidad de plataformas costosas.

## ¿Cómo utilizar?
Puede utilizar el sitio ya preparado (openstock-ods.vercel.app) directamente o instalarlo en su propio servidor.

## ¿Cómo instalar, cómo utilizar?
**Repositorio de clones**

```
git clone https://github.com/Open-Dev-Society/OpenStock.git
cd OpenStock
```

**Instalar dependencias**

```
pnpm install
```

**Iniciar servidor de desarrollo**

```
pnpm dev
```
