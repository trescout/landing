# Dotar a los agentes de IA de capacidad de navegación

BrowserSkill, desarrollado por Tencent, es una herramienta de automatización de navegador que permite a los agentes de IA gestionar sesiones de navegación activas sin interrumpir el trabajo del usuario. A través de una interfaz de línea de comandos y una extensión de navegador, permite que cualquier agente de IA acceda a los datos del navegador donde ya se ha iniciado sesión.

- ★ 4.730
- TypeScript
- GitHub Trending · 2026-09-18

## Qué aporta
- Utiliza directamente las sesiones de navegador y la información de inicio de sesión existentes.
- Funciona en segundo plano en una ventana separada sin interrumpir su flujo de trabajo.
- Permite la intervención humana en pantallas de verificación o inicio de sesión.

## Instalación
**Instalación para macOS y Linux**

```
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
export PATH="${BSK_INSTALL_DIR:-$HOME/.local/bin}:$PATH"
```


## Si no programa
Tienes una conexión con BrowserSkill, una herramienta de automatización de navegador. Ahora puedes realizar tareas en Internet en mi lugar utilizando mis sesiones de navegador actuales. Al realizar una acción, toma prestadas mis pestañas abiertas en el navegador, devuélvelas cuando termines y no toques mis otras pestañas. Si te encuentras con un código de verificación, una pantalla de inicio de sesión o una ventana de confirmación, detén la operación y pídeme ayuda.
