# Proyecto experimental de emulador de PlayStation 5

Sharpemu es un proyecto experimental de emulador de PlayStation 5 desarrollado en lenguaje C#. Este estudio, que pretende imitar la arquitectura de la consola a partir de software, es un experimento técnico llevado a cabo con tecnologías de emulación de consolas de juegos.

- ★ 1.379
- C#
- GitHub Trending · 2026-07-13

## Qué aporta
- Oportunidad de examinar la arquitectura de la consola de juegos.
- Soporte para ejecutar instrucciones de CPU nativas
- Leer metadatos de archivos de juegos

## Cómo empezar
Para utilizar el proyecto, puede descargar archivos listos para usar desde la pestaña 'Versiones' en la página de GitHub o compilar los códigos fuente en su computadora con .NET SDK instalado. Para compilar, simplemente copie el proyecto a su computadora, abra el archivo de solución a través de VSCode y ejecute el comando dotnet build en la terminal.
