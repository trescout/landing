# Editor de vídeo de escritorio de código abierto

Clypra es una aplicación de edición de vídeo de código abierto desarrollada con Tauri, React y TypeScript. El software tiene como objetivo ofrecer funciones avanzadas que se encuentran en las herramientas de edición de video pagas como una alternativa gratuita.

## Qué aporta
- Procesamiento de vídeo de alto rendimiento acelerado por hardware
- Línea de tiempo multipista con precisión de fotograma
- Subtitulado y edición automáticos impulsados por IA

## Instalación
**Instalación con Homebrew en macOS**

```
brew install AIEraDev/tap/clypra
```
