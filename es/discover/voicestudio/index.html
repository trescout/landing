Realiza clonación de voz y doblaje de forma local

VoiceStudio es una plataforma de procesamiento de audio de código abierto que realiza tareas como clonación de voz, doblaje y transcripción sin necesidad de internet. Ofrece una alternativa que funciona localmente al servicio de síntesis de voz ElevenLabs y admite 646 idiomas.

Qué aporta

  • Realiza clonación de voz y doblaje sin necesidad de conexión a internet
  • Obtén soporte para síntesis de voz y conversión de texto a voz en 646 idiomas diferentes
  • Garantiza total privacidad manteniendo tus datos en tu propia computadora

Instalación

Ejecución desde el código fuente
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun install
bun run desktop
