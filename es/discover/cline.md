# Agente de inteligencia artificial que automatiza los procesos de desarrollo de software

Cline es un agente de codificación autónomo que automatiza los procesos de desarrollo de software. Se integra en los proyectos de los desarrolladores a través de una extensión de IDE, un kit de desarrollo de software (SDK) o una interfaz de línea de comandos (CLI).

- ★ 68.647
- TypeScript
- GitHub Trending · 2026-09-18

## Qué aporta
- Realiza ediciones de código coordinadas en todo el proyecto
- Ejecuta comandos a través de la terminal y monitorea las salidas en tiempo real
- Mantiene el proceso de desarrollo bajo control con modos de planificación y ejecución

## Instalación
**Instalación de la interfaz de línea de comandos**

```
npm i -g cline
```

**Instalación del kit de desarrollo de software**

```
npm install @cline/sdk
```


## Ejecución
**Inicio de tareas con un equipo de agentes múltiples**

```
cline --team-name auth-sprint "Plan and implement user authentication with tests"
```
