# React, la biblioteca para crear interfaces de usuario

React es una biblioteca de JavaScript diseñada para simplificar los procesos de desarrollo de interfaces mediante la creación de interfaces de usuario web y nativas. Esta biblioteca ofrece a los desarrolladores la oportunidad de construir interfaces de usuario complejas en una estructura más organizada.

## Qué aporta

- Te permite construir interfaces de usuario complejas con una estructura basada en componentes.
- Actualiza de manera eficiente los componentes correctos cuando los datos cambian.
- Se puede añadir de forma gradual a proyectos existentes.
