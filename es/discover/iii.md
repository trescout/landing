# Administre sus servicios en tiempo real

iii es un método para crear, ampliar y monitorear todos los servicios en su pila de backend (cola, cron, HTTP, estado, observabilidad, agentes, sandbox) en tiempo real. Hace que piezas que normalmente presentan dificultades de integración separadas sean manejables desde un solo punto.

- ★ 18.662
- Rust
- Lisans: yok
- GitHub Trending · 28 May 2026

## Qué aporta
- Gestión de colas, cron, HTTP y estado en un solo lugar.
- Oportunidad de trazabilidad en tiempo real.
- Soporte para agentes y sandbox.
- Reduce la complejidad en los procesos de integración.

## Cómo empezar
Para comenzar y acceder a la documentación, puede visitar iii.dev.

## ¿Cómo instalar, cómo utilizar?
**Crear proyecto**

```
iii project init myapp
```

**arrancar el motor**

```
cd myapp
iii
```

**Agregar trabajador (habilidad)**

```
iii worker add queue
```

**Instalar el SDK de Node.js**

```
npm install iii-sdk
```
