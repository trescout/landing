# Herramienta de automatización de navegador para agentes de inteligencia artificial

Desarrollado por Vercel Labs, agent-browser es una interfaz de línea de comandos (CLI) que proporciona automatización de navegador para agentes de inteligencia artificial. Escrita en Rust, esta herramienta permite leer páginas como un árbol de accesibilidad e interactuar con elementos web a través de la línea de comandos.

## Qué aporta

- Lee las páginas en formato de texto como un árbol de accesibilidad
- Interactúa con elementos web a través de la línea de comandos
- Gestiona el navegador comando por comando con el servidor en segundo plano

## Instalación

**Configuración general**

```
npm install -g agent-browser
agent-browser install           # download Chrome for Testing (first time only)
```

## Ejecución

**Inicio rápido**

```
agent-browser open example.com
```
