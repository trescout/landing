Mapeo de código abierto basado en la nube

GeoLibre es una plataforma liviana de sistema de información geográfica (SIG) basada en la nube diseñada para visualizar, explorar y analizar datos geográficos. Desarrollada con TypeScript, esta herramienta puede ejecutarse en navegadores web, computadoras de escritorio, dispositivos móviles y portátiles Jupyter.

Qué aporta

  • Análisis de geodatos sin instalación en el navegador
  • Compatibilidad con escritorio, dispositivos móviles y Jupyter
  • Procesamiento de datos local y confidencial

Instalación

vía pip (PyPI)
pip install GeoLibre

Cómo empezar

No necesitas ninguna instalación para comenzar a usar GeoLibre. Puede acceder a la versión web a través de su navegador o visitar la página de descarga en el sitio web oficial para descargar el instalador para su sistema operativo de escritorio.
