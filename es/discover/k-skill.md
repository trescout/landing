# Ofrezca a su agente de IA capacidades nativas

NomaDamas/k-skill es una biblioteca diseñada para proporcionar a los agentes de IA habilidades locales en un contexto cultural. Ofrece conjuntos de habilidades personalizadas que permiten a los agentes interactuar con los usuarios de forma más natural y de acuerdo con códigos culturales.

## Qué aporta

- Permite a los agentes de IA utilizar servicios locales específicos de Turquía
- Realiza consultas automáticas sobre transporte, datos públicos y trabajo diario.
- Se integra directamente sin necesidad de software de cliente adicional

## Instalación

**Para instalar todas las capacidades**

```
npx --yes skills add NomaDamas/k-skill --all -g
```

**Para instalar una habilidad específica**

```
npx --yes skills add NomaDamas/k-skill --skill srt-booking -g
```
