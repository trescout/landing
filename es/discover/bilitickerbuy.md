# Agiliza los procesos de compra de billetes de Bilibili

Esta herramienta basada en Python que automatiza los procesos de compra de membresías de Bilibili es un asistente de compra de entradas diseñado para acelerar los procesos de compra de entradas. Permite a los usuarios obtener productos en stock limitados en la plataforma más rápido.

## Qué aporta
- Automatiza la compra de billetes a través de Bilibili
- Aumenta la velocidad de captura de productos de stock limitado
- Una práctica herramienta de utilidad para uso personal.

## Instalación
**Instalación automática para Linux macOS**

```
curl -fsSL https://raw.githubusercontent.com/mikumifa/biliTickerBuy/main/install.sh | sh
```

**vía pip (PyPI)**

```
pip install biliTickerBuy
```
