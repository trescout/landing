# Aplicación multiplataforma con un único código

Desarrollado por Google, Flutter le permite crear rápidamente interfaces de usuario para plataformas móviles, web y de escritorio utilizando una única base de código. Este marco de código abierto, basado en el lenguaje de programación Dart, es ampliamente preferido para desarrollar aplicaciones visualmente ricas y de alto rendimiento.

## Qué aporta
- Soporte móvil, web y de escritorio con una única base de código
- Función de recarga en caliente que le permite ver cambios instantáneos
- Gráficos de alto rendimiento acelerados por hardware

## Instalación
**macOS (Homebrew)**

```
brew install --cask flutter
```


## Ejecución
**Validar controles de entorno**

```
flutter doctor
```

**Crear y ejecutar nuevo proyecto**

```
flutter create my_app
cd my_app
flutter run
```
