# Supervise sus datos de Tesla en su propio servidor

Desarrollada para propietarios de vehículos Tesla, Teslamate es una aplicación de registro de datos que le permite alojar datos en su propio servidor. Esta herramienta de código abierto, escrita en lenguaje Elixir, visualiza y presenta estadísticas detalladas, como el historial de conducción y los datos de carga, al usuario.

## Qué aporta
- Analice los datos de conducción y carga en detalle
- Supervisar el estado y la eficiencia de la batería
- Obtenga control total de los datos en su servidor personal

## Instalación
**Cree el archivo docker-compose.yml de la guía oficial (la contraseña de la base de datos y la clave de cifrado son suyas)**

```
docker compose pull
```


## Ejecución
**Inicio (http://localhost:4000)**

```
docker compose up -d
```
