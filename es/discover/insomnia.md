# Administre fácilmente solicitudes de API modernas

Insomnia es un cliente de interfaz de programación de aplicaciones (API) de código abierto que admite los protocolos GraphQL, REST, WebSockets, SSE y gRPC. El software ofrece soporte multiplataforma con opciones de almacenamiento Git, locales y basadas en la nube.

## Qué aporta
- Soporte para depurar protocolos populares como GraphQL, REST y gRPC
- Opciones flexibles de almacenamiento local, Git o basado en la nube
- Diseño de API visual con editor OpenAPI integrado

## Instalación
**macOS (hecho en casa)**

```
brew install --cask insomnia
```

**Paquete Linux Snap (editor de Insomnia)**

```
sudo snap install insomnia
```


## Cómo empezar
- Fuente oficial →
Para comenzar a usar Insomnia, puede ir al sitio web oficial https://insomnia.rest y descargar y ejecutar el archivo de instalación adecuado para su sistema operativo. Puede comenzar a usar la aplicación con su función nativa Scratch Pad sin crear una cuenta, o crear una cuenta gratuita para obtener más funciones.
