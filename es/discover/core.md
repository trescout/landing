# Plataforma domótica controlada localmente

Home Assistant es una plataforma de domótica de código abierto que prioriza el control local y la privacidad. Este sistema, desarrollado con lenguaje Python, permite a los usuarios gestionar sus dispositivos inteligentes a través de una red central.

## Qué aporta
- Gestiona tus dispositivos inteligentes desde un único centro
- Proteja la privacidad de sus datos con control local
- Añadir nuevos dispositivos con estructura modular

## Instalación
**con pip (entorno virtual Python)**

```
pip install homeassistant
```

**con ventana acoplable**

```
docker run -d --name homeassistant --privileged --restart=unless-stopped --network=host ghcr.io/home-assistant/home-assistant:stable
```


## Ejecución
**Inicie el servidor Home Assistant Core**

```
hass
```


## Cómo empezar
- Fuente oficial →
Visita home-assistant.io para comenzar la configuración. Puede instalar el sistema en su dispositivo siguiendo los pasos apropiados para su Raspberry Pi o servidor local a través de la sección de instrucciones de instalación en el sitio.
