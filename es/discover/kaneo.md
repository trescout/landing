# Gestión de proyectos sencilla y rápida

Kaneo es una herramienta de gestión de proyectos de código abierto desarrollada con una interfaz orientada al usuario. Escrita en TypeScript, la plataforma tiene como objetivo crear flujos de trabajo sin complejidad.

- ★ 8.402
- TypeScript
- GitHub Trending · 2026-08-01

## Qué aporta
- Interfaz limpia, libre de desorden
- Alojamiento en tu propio servidor con control de datos
- Experiencia de trabajo rápida orientada al rendimiento

## Instalación
**instalación automática**

```
curl -fsSL https://assets.kaneo.app/install.sh | sh
drim setup
```


## Ejecución
**Iniciando el entorno de desarrollo**

```
# Clone and install dependencies
git clone https://github.com/usekaneo/kaneo.git
cd kaneo
pnpm install

# Create a .env file in the root with required environment variables
# See ENVIRONMENT_SETUP.md for detailed instructions

# Start development servers
pnpm dev
```
