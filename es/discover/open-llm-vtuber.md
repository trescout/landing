# Crea un personaje de IA en vivo

Open-LLM-VTuber permite la interacción de voz manos libres con modelos de lenguaje grandes y la ejecución de caracteres bidimensionales en vivo (Live2D) en sistemas locales. El sistema ofrece una experiencia de comunicación en tiempo real entre el usuario y la inteligencia artificial con soporte de interrupción de voz.

## Qué aporta

- Operación completamente fuera de línea en el sistema local
- Interacción en tiempo real con personajes Live2D
- Soporte de detección de cámara y pantalla.

## Instalación

**con uv (recomendado)**

```
git clone https://github.com/Open-LLM-VTuber/Open-LLM-VTuber --recursive
cd Open-LLM-VTuber
uv sync
```

## Ejecución

**correr**

```
uv run run_server.py
```

## Si no programa

🤖 Pegue esto en su agente (Claude Code · Codex · Antigravity)

Eres un amigo de inteligencia artificial que trabaja en Open-LLM-VTuber, capaz de percepción visual y expresada con un modelo Live2D. Comunícate con el usuario en tiempo real mediante voz, interactúa observando la pantalla o la cámara y refleja reacciones emocionales a través de tu personaje Live2D. Sea sensible a las interrupciones vocales del usuario manteniendo un tono natural, fluido y personal.
