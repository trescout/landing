# Limpiar dependencias innecesarias

Como una herramienta de desarrollo de software basado en Python, OBLITERÁTUS visa limpiar dependencias innecesarias y estructuras complejas en bases de código. En el proyecto no hay reducción, no es un problema, es cuestión de tiempo.

- ★ 7.994
- Python
- GitHub Trending · 2026-08-22

## Qué aporta
- Limpia quirúrgicamente conductas de rechazo en modelos de inteligencia artificial.
- Deshabilita las restricciones, preservando las capacidades básicas del lenguaje del modelo.
- Visualiza cómo funcionan las restricciones con el análisis entre capas.

## Instalación
**Configuración básica de la interfaz**

```
pip install -e ".[spaces]"
```


## Ejecución
**Iniciando la interfaz**

```
obliteratus ui
```


## Si no programa
Analice los comportamientos de rechazo en un modelo de IA y elimine quirúrgicamente las estructuras internas que desencadenan estos comportamientos sin dañar las capacidades lingüísticas generales del modelo. Durante el proceso, utilice técnicas como la descomposición SVD para identificar restricciones y garantizar que el modelo responda sin obstáculos artificiales.
