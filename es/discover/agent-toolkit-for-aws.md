# Conjunto de herramientas de AWS para agentes de IA

AWS ha lanzado un conjunto de herramientas que incluye servidores, habilidades y complementos de Model Context Protocol para facilitar la interacción de los agentes de IA con la infraestructura de la nube. Este desarrollo proporciona una estructura estandarizada que permite a los agentes operar directamente en los servicios de AWS.

## Qué aporta
- Interacción directa y segura con los servicios de AWS
- Capacidades estandarizadas para agentes de IA
- Complementos listos para usar para la gestión de infraestructura en la nube

**Agregar capacidades**

```
npx skills add aws/agent-toolkit-for-aws/skills
```


## Si no programa
Ayúdame a desarrollar, implementar y administrar aplicaciones en AWS. Interactúe con los servicios de AWS utilizando las capacidades del Agent Toolkit for AWS, realice las configuraciones necesarias y realice operaciones en la infraestructura de la nube de acuerdo con los estándares.
