Lenguaje de programación rápido y confiable.

Desarrollado por Google, el lenguaje de programación Go es un lenguaje de programación de sistema de código abierto diseñado para crear software escalable y de alto rendimiento. Es ampliamente preferido en las infraestructuras modernas de computación en la nube por su gestión de concurrencia y sus rápidos tiempos de compilación.

Nota de TreScout: El programa que escribes sale como un solo archivo, copias ese archivo al servidor y lo ejecutas, no necesitas instalar nada más. A cambio, el lenguaje se mantiene deliberadamente simple: escribes el mismo error una y otra vez. Bueno para escribir servicios de servidor y herramientas de línea de comandos, lo obliga a modelar reglas comerciales complejas.

Qué aporta

  • Estructura de código simple y comprensible.
  • Capacidad de trabajo de alto rendimiento.
  • Eficiencia para sistemas en la nube modernos

Instalación

macOS (hecho en casa)
brew install go
Ventanas (ala)
winget install GoLang.Go
