# Terminal de trading autónomo impulsado por inteligencia artificial

CloddsBot es un agente de trading de inteligencia artificial de código abierto que opera de forma autónoma en más de 1000 mercados. Basado en Claude, este software ejecuta procesos de compra y venta automatizados en varios intercambios de criptomonedas y plataformas de predicción (Polymarket, Binance) mediante gestión de riesgos y protocolos de pago de máquina a máquina.

- ★ 1.873
- TypeScript
- GitHub Trending · 2026-09-11

## Qué aporta
- Trading automatizado en más de 1000 mercados
- Cartera y estrategias gestionables mediante lenguaje natural
- Integración completa con 21 plataformas de mensajería diferentes

## Instalación
**Instalación rápida**

```
npm install -g clodds --loglevel=error
clodds onboard
```

**Instalación desde el código fuente**

```
git clone https://github.com/alsk1992/CloddsBot.git && cd CloddsBot
npm install && cp .env.example .env
# Add ANTHROPIC_API_KEY to .env
npm run build && npm start
```


## Ejecución
**Iniciando la interfaz**

```
clodds start
```


## Si no programa
Eres un asistente de trading. Quiero que utilices CloddsBot para realizar análisis en mercados de criptomonedas y plataformas de predicción con más de 118 estrategias. Aplicando las reglas de gestión de riesgos, gestiona las operaciones de compra y venta automatizadas dentro del presupuesto que he establecido y preséntame informes monitoreando los datos del mercado.
