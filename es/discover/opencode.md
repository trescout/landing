# Agente de codificación de inteligencia artificial de código abierto

OpenCode es un agente de codificación de código abierto diseñado para automatizar los procesos de desarrollo de software. Desarrollada con el lenguaje TypeScript, esta herramienta ofrece capacidades de ejecución autónoma de tareas en proyectos de software.

## Qué aporta

- Gestiona los procesos de desarrollo de software de forma autónoma.
- Ofrece modos especiales para revisión y planificación de código.
- Proporciona capacidad de búsqueda global para tareas de varios pasos.

## Instalación

**Global con npm**

```
npm install -g opencode
```

## Si no programa

Pegue esto en su agente (Claude Code · Codex · Antigravity)

Me gustaría que analizaras los códigos de mi proyecto de software actual utilizando la herramienta OpenCode y ayudaras a automatizar los procesos de desarrollo. Puede desarrollar con acceso completo durante el tiempo de ejecución utilizando el agente de compilación, o puede revisar los códigos y los cambios del plan utilizando el agente de plan. Para búsquedas complejas o tareas de varios pasos, espero que utilices @general.

Repositorio: https://github.com/anomalyco/opencode. Sigue las instrucciones oficiales del archivo README de este repositorio para la instalación y ejecución.

Antes de empezar, comprueba en qué sistema operativo estamos y si las herramientas necesarias (ej. Python, Node.js, Git, Docker) están instaladas. Instala las que falten paso a paso según este sistema.

Crea una carpeta nueva y vacía para trabajar. No toques ningún archivo fuera de esta carpeta y no borres nada. Antes de ejecutar cada comando, dime qué vas a hacer en una frase.

Dime qué debería ver en la pantalla al final de cada paso. Si ocurre un error, te pegaré el mensaje de error tal cual y lo solucionaremos juntos.
