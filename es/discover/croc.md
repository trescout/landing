# Transferencia de archivos segura y sencilla

Croc es una herramienta que proporciona transferencia segura de archivos y datos entre dos computadoras mediante cifrado de extremo a extremo. Este software, desarrollado con el lenguaje de programación Go, utiliza un mecanismo de retransmisión temporal para facilitar el proceso de transferencia.

## Qué aporta
- Transmisión de datos cifrada de extremo a extremo
- Compatibilidad entre diferentes sistemas operativos
- Reanudar transferencias interrumpidas desde donde las dejaron

## Instalación
**Instalación general**

```
curl https://getcroc.schollz.com | bash
```

**Instalación en MacOS**

```
brew install croc
```


## Ejecución
**enviar archivo**

```
croc send [file(s)-or-folder]
```

**recibir archivos**

```
croc code-phrase
```
