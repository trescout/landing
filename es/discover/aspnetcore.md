# Plataforma para aplicaciones web empresariales

ASP.NET Core es un marco .NET multiplataforma que se utiliza para desarrollar aplicaciones web modernas basadas en la nube en Windows, macOS y Linux. Esta estructura, desarrollada en lenguaje C#, permite crear servicios web escalables y de alto rendimiento.

## Qué aporta
- Operación multiplataforma en Windows, macOS y Linux
- Desarrollo de aplicaciones escalables y basadas en la nube
- Estructura de componentes modular con bajo uso de recursos.

## Instalación
**macOS (hecho en casa)**

```
brew install --cask dotnet-sdk
```

**Ventanas (ala)**

```
winget install Microsoft.DotNet.SDK.10
```


## Ejecución
**Crear y ejecutar un nuevo proyecto ASP.NET Core**

```
dotnet new webapi -n MyWebApp
cd MyWebApp
dotnet run
```
