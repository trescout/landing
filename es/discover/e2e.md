# Automatiza tus pruebas de extremo a extremo

Un marco de trabajo (framework) de nueva generación basado en TypeScript que automatiza los procesos de pruebas de extremo a extremo (end-to-end testing) para aplicaciones web y móviles. Permite a los desarrolladores verificar rápidamente las interfaces de usuario de las aplicaciones en diferentes plataformas.

- ★ 6.873
- TypeScript
- GitHub Trending · 2026-10-05

## Qué aporta
- Escribe pruebas definiendo objetivos en lenguaje natural
- Graba acciones y reutilízalas en ejecuciones posteriores
- Verifica la interfaz de usuario en aplicaciones web y móviles

## Instalación
**Iniciar Configuración**

```
npx e2e init
```


## Si no programa
Utiliza la herramienta de pruebas para configurar pruebas automatizadas con pasos escritos en lenguaje natural para mi aplicación web o móvil y genera el archivo de configuración.
