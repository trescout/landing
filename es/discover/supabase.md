# Base de datos de código abierto y backend

Supabase es una alternativa de código abierto a Firebase, construida sobre PostgreSQL. Ofrece servicios en tiempo real.

- ★ 107.669
- GitHub Trending · 2026-07-04

## ¿Qué hace esta herramienta?
Supabase es un servicio de backend de código abierto construido sobre PostgreSQL. Ofrece funciones listas para usar como suscripciones a bases de datos en tiempo real, autenticación, almacenamiento y funciones de borde (edge functions).

## ¿Para quién es?
Para aquellos que desean acelerar el proceso de desarrollo de backend sin renunciar al poder de una base de datos relacional y centrarse directamente en sus productos.

## Qué no esperar
Desarrolladores que solo necesitan bases de datos basadas en documentos o que desean evitar por completo el uso de SQL.

## Aspectos destacados
- Proporciona una base de datos PostgreSQL estándar y completa para cada proyecto.
- Admite la sincronización de datos en tiempo real lista para usar.
- Puede utilizarse en su propio servidor o como un servicio en la nube gestionado.

## Primer flujo de uso
- Cree un nuevo proyecto a través del panel de Supabase o en su entorno local.
- Cree sus tablas y configure las políticas de seguridad.
- Instale la biblioteca cliente oficial para el lenguaje que utilizará en su proyecto.
- Ejecute su primera consulta de base de datos añadiendo sus claves de API a su aplicación.

## Instalación
**macOS (Homebrew)**

```
brew install supabase/tap/supabase
```

**agregar como dependencia de desarrollo con npm**

```
npm install -D supabase
```


## Ejecución
**Iniciar el entorno de desarrollo local de Supabase**

```
supabase init
supabase start
```
