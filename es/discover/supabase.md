# Plataforma de desarrollo Postgres de código abierto

Supabase es una plataforma de desarrollo que ofrece infraestructura de bases de datos Postgres para desarrollar aplicaciones web, móviles y de inteligencia artificial. Con su estructura de código abierto, proporciona gestión de bases de datos y servicios de backend necesarios para acelerar los procesos de desarrollo de aplicaciones.

- ★ 107.669
- TypeScript
- GitHub Trending · 2026-07-04

## Qué aporta
- Ofrece infraestructura de base de datos Postgres lista para usar
- Proporciona API y autenticación automáticas.
- Incluye inteligencia artificial y soporte vectorial.

## Instalación
**macOS (hecho en casa)**

```
brew install supabase/tap/supabase
```

**agregar como dependencia de desarrollo con npm**

```
npm install -D supabase
```


## Ejecución
**Iniciar el entorno de desarrollo local de Supabase**

```
supabase init
supabase start
```
