# Interfaz ligera para proyectos C++

Dear ImGui es una biblioteca de interfaz gráfica de usuario liviana para proyectos de C++ que funciona con dependencias mínimas. Permite a los desarrolladores de software crear una interfaz sencilla en procesos rápidos de creación de prototipos y desarrollo de herramientas.

## Qué aporta
- Estructura simple que no requiere dependencias externas.
- Creación rápida de prototipos y desarrollo de herramientas.
- Bajo consumo de memoria y procesador.

## Cómo empezar
- Fuente oficial →
Para iniciar su proyecto, simplemente agregue todos los archivos .cpp y .h que comiencen con imgui en el repositorio de GitHub a su proyecto existente. Luego, puede comenzar a crear su propia interfaz gráfica examinando las aplicaciones de muestra en la carpeta backends.
