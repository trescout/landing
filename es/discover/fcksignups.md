# Herramientas de código abierto que no requieren registro

FckSignups es una lista que reúne herramientas basadas en navegador de código abierto que no solicitan registro ni membresía al usuario. Centraliza en un solo recurso servicios digitales a los que los desarrolladores de software y los usuarios finales pueden acceder rápidamente sin crear una cuenta.

## Qué aporta

- Proporciona acceso a herramientas sin necesidad de registro o correo electrónico
- Ofrece una lista segura que no incluye seguimiento de datos ni monitoreo
- Incluye herramientas en diferentes categorías como diseño, desarrollo y productividad

## Instalación

**Ejecución en entorno local**

```
git clone https://github.com/BraveOPotato/FckSignups.git && \
cd FckSignups && \
npm install && \
npm run dev
```
