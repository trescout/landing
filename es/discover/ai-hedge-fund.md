# Agentes de inteligencia artificial para estrategias de inversión

El fondo de cobertura de IA utiliza agentes autónomos para automatizar los procesos de análisis del mercado financiero y gestión de activos. Este proyecto basado en Python ofrece un modelo de equipo de inteligencia artificial que desarrolla estrategias de inversión procesando datos de mercado.

## Qué aporta
- Agentes autónomos analizando datos del mercado financiero.
- Modelado representando diferentes escuelas de inversión.
- Posibilidad de probar estrategias con datos históricos.

## Instalación
**Clonando el repositorio**

```
git clone https://github.com/virattt/ai-hedge-fund.git
cd ai-hedge-fund
```

**Instalando dependencias**

```
poetry install
```


## Ejecución
**Iniciar análisis de inversión**

```
poetry run python src/main.py --ticker AAPL,MSFT,NVDA
```


## Si no programa
Esta herramienta utiliza agentes autónomos que imitan las estrategias de inversores famosos como Warren Buffett, Peter Lynch y Michael Burry para analizar los mercados financieros. Al proporcionar ciertos símbolos bursátiles (por ejemplo, AAPL, MSFT) a los agentes de IA, puede examinar cómo estos agentes evalúan los datos del mercado, los indicadores fundamentales y el análisis técnico y toman decisiones con la lógica de un fondo mutuo.
