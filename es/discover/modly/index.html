Crea modelos tridimensionales a partir de imágenes.

Modly es una aplicación de escritorio que crea modelos 3D a partir de imágenes y realiza todas las operaciones en la tarjeta gráfica local (GPU). Esta herramienta, que funciona sin necesidad de conexión a Internet, lleva el proceso de modelado apoyado en inteligencia artificial a los ordenadores personales.

Qué aporta

  • Convierte fotos a modelos 3D en la computadora local
  • Funciona completamente sin conexión y no requiere conexión a Internet
  • Ofrece una estructura flexible que se puede ampliar con modelos externos.

Instalación

Instalando dependencias
npm install
Preparando la infraestructura de Python
cd api
python -m venv .venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate  # Linux / macOS
pip install -r requirements.txt

Ejecución

Iniciando la aplicación
# Windows
launch.bat

# Linux / macOS
./launch.sh
