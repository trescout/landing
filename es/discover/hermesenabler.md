# Habilita las esferas de Hermès para Apple Watch

pookjw/HermesEnabler es un software que hace que las esferas de reloj Hermès estén disponibles en todos los dispositivos Apple Watch con versiones de watchOS compatibles. Esta herramienta, que se puede compilar con Xcode en macOS o instalar con herramientas de carga de aplicaciones como Sideloadly, requiere un Apple Watch enlazado a un iPhone.

## Qué aporta

- usar esferas personalizadas en relojes compatibles
- soporte para los sistemas operativos macOS y Windows
- ofrecer una instalación paso a paso a través de la aplicación del reloj

## Cómo empezar

Puedes realizar la instalación en macOS utilizando la herramienta de carga de aplicaciones Sideloadly o el software de desarrollo Xcode. En el lado de Windows, puedes utilizar el software de la comunidad WatchBridge. Puedes descargar los archivos de instalación desde la página oficial de GitHub y seguir la guía.
