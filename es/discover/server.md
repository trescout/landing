# Servidor de música digital de código abierto

Music Assistant es un administrador de biblioteca multimedia de código abierto que combina diferentes servicios de transmisión digital y parlantes conectados en una sola interfaz. Este software de servidor basado en Python permite la creación de un sistema central de gestión de música en dispositivos en funcionamiento constante.

## Qué aporta
- Combina diferentes servicios de transmisión digital en una sola interfaz
- Le permite controlar de forma centralizada todos los altavoces conectados
- Proporciona soporte de automatización al trabajar completamente integrado con Home Assistant

## Instalación
**estibador**

```
docker run --network host --privileged -v ma-data:/data ghcr.io/music-assistant/server
```
