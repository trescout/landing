# Biblioteca de libros electrónicos digitales en varias categorías

jbiaojerry/ebook-treasure-chest es un proyecto de biblioteca digital que reúne enlaces de descarga de libros electrónicos en varias categorías. El proyecto tiene como objetivo proporcionar acceso a contenidos dentro de aplicaciones de lectura populares (帆书, 微信读书, 京东读书, 喜马拉雅).

## Qué aporta

- Obtén acceso en un solo lugar a enlaces de descarga de miles de libros electrónicos.
- Puedes descargar libros en tres opciones de formatos diferentes: epub, mobi y azw3.
- Gracias a la interfaz de búsqueda, puedes encontrar obras instantáneamente por título, autor o categoría.

## Cómo empezar

No necesitas la línea de comandos para beneficiarte del proyecto. Puedes visitar la página web oficial alojada en la plataforma de alojamiento de código GitHub y escribir el nombre del libro o el autor en el cuadro de búsqueda. Si lo deseas, puedes examinar los archivos de categoría para acceder al enlace de descarga del libro electrónico que desees.
