# Agentes de inteligencia artificial que desarrollan software autónomo

Desarrollado por ColeMurray, background-agents es un sistema de codificación de agentes en segundo plano de código abierto basado en TypeScript. Permite a los desarrolladores crear agentes de inteligencia artificial (agentes de IA) que ejecutan procesos autónomos dentro de las aplicaciones.

- ★ 2.329
- TypeScript
- GitHub Trending · 2026-07-13

## Qué aporta
- Ejecutar tareas autónomas en segundo plano
- Acceso a entornos de desarrollo completos
- Trabajo integrado vía Slack y GitHub

## Instalación
**Instalando dependencias**

```
# .openinspect/setup.sh (provisioning)
#!/bin/bash
npm install
pip install -r requirements.txt
```


## Ejecución
**Iniciando el ambiente de trabajo**

```
# .openinspect/start.sh (runtime startup)
#!/bin/bash
docker compose up -d postgres redis
```
