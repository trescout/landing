# Guía de desarrollo de software con proyectos aplicados.

El aprendizaje basado en proyectos es una lista que reúne recursos que enseñan procesos de desarrollo de software a través de proyectos aplicados. Ofrece una guía completa para quienes desean desarrollar aplicaciones del mundo real con diferentes lenguajes de programación.

## Qué aporta
- Ofrece recursos de aprendizaje orientados a proyectos para diferentes lenguajes de programación.
- Enseña paso a paso los procesos de desarrollo de aplicaciones desde cero.
- Muestra cómo configurar sistemas complejos, como sistemas operativos y bases de datos.
