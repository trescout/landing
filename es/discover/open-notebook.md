# Asistente de inteligencia artificial con tus propios datos

Open-notebook ofrece una alternativa de código abierto a Google NotebookLM, que permite a los usuarios realizar análisis de notas personalizables con tecnología de inteligencia artificial sobre sus propios datos. Desarrollado con TypeScript, este proyecto proporciona mayor flexibilidad y un conjunto de funciones ampliado en comparación con la plataforma original.

## Qué aporta
- Analiza tus datos en un entorno completamente local, manteniéndolos confidenciales.
- Obtenga una selección de modelos flexible de más de 18 proveedores de IA.
- Cree podcasts profesionales a partir de sus archivos PDF, vídeo y audio.

## Instalación
**Descargue el archivo de configuración**

```
curl -o docker-compose.yml https://raw.githubusercontent.com/lfnovo/open-notebook/main/docker-compose.yml
```


## Ejecución
**Servicios de inicio**

```
docker compose up -d
```


## Si no programa
Quiero instalar la herramienta Open Notebook. Docker Desktop está instalado. Primero, necesito descargar el archivo docker-compose.yml con el comando curl y luego cambiar la sección OPEN_NOTEBOOK_ENCRYPTION_KEY en el archivo con una contraseña única. En la última etapa, necesito completar la instalación ejecutando el comando docker compose up -d. ¿Hay otras configuraciones o pasos a los que debo prestar atención en este proceso?
