# Libro de texto de programación de sistemas de código abierto

El coursebook preparado por la Universidad de Illinois es un libro de texto de código abierto que explica los fundamentos de la programación de sistemas (systems programming). Este recurso, presentado en formato TeX, proporciona un material educativo integral para quienes desean aprender procesos de desarrollo de software de bajo nivel.
