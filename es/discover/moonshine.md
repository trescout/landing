# Herramientas de voz de IA en tiempo real

Moonshine ofrece voz a texto de baja latencia, reconocimiento de intenciones y capacidades de texto a voz para interfaces de voz y agentes de inteligencia artificial. Esta biblioteca, desarrollada en lenguaje C++, tiene como objetivo optimizar los procesos de procesamiento de audio en tiempo real.

## Qué aporta

- Procesamiento de audio rápido y discreto que se ejecuta en el dispositivo
- Baja latencia optimizada para transmisiones en vivo
- Capacidad para convertir voz en texto y texto en audio.

## Instalación

**Instalación con Python**

```
pip install moonshine-voice
moonshine-voice mic --language en
```

**Instalación de frambuesa pi**

```
sudo pip install --break-system-packages moonshine-voice
 moonshine-voice mic --language en
```

## Ejecución

**Transcripción en vivo a través del micrófono.**

```
moonshine-voice mic --language en
```
