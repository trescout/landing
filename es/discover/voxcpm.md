# Diseño de sonido multilingüe sin token

VoxCPM; Es un modelo TTS de código abierto sin tokenizador desarrollado para la producción de voz multilingüe, diseño de sonido creativo y clonación de voz realista.

- ★ 34.774
- Python
- Apache-2.0
- GitHub Trending · 30 May 2026

## Instalación
****

```
pip install voxcpm
```


## Ejecución
****

```
voxcpm design --text "VoxCPM2 brings studio-quality multilingual speech synthesis." --output out.wav
```


## ¿Qué ofrece?
- Producción de habla multilingüe y natural.
- Diseño de sonido creativo y original.
- Clonación de voz de alta precisión.

## nota de responsabilidad

## ¿Cómo instalar, cómo utilizar?
Ejecute 'pip install voxcpm' para instalar la herramienta de conversión de texto a voz VoxCPM, luego genere un archivo de audio con el comando 'voxcpm design --text "Hello world" --output out.wav'; Si quiero, clonar ese sonido usando 'voxcpm clone' con un archivo de sonido de referencia.
