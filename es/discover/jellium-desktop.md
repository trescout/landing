# Acceso de escritorio a su biblioteca multimedia Jellyfin

Jellium-desktop es un cliente de escritorio no oficial desarrollado en Rust para el servidor de medios Jellyfin. El software ofrece una interfaz nativa que permite a los usuarios acceder a bibliotecas multimedia directamente a través del sistema operativo.

- ★ 1.342
- Rust
- GitHub Trending · 2026-07-20

## Qué aporta

- Acceda a su servidor multimedia Jellyfin a través de la aplicación nativa
- Reproducción multimedia optimizada con infraestructura CEF y MPV
- Soporte de interfaz nativa en Windows, macOS y Linux

## Cómo empezar

Puede utilizar los enlaces de descarga en la página de GitHub para comenzar a utilizar la aplicación Jellium Desktop. Después de descargar la versión adecuada para su sistema operativo (Windows, macOS o Linux), instale la aplicación en su sistema ejecutando el archivo de instalación y acceda ingresando la información de su servidor Jellyfin.
