# Escaneo de seguridad automático con inteligencia artificial

Strix es una herramienta de seguridad basada en inteligencia artificial (herramienta de seguridad AI) de código abierto diseñada para detectar y corregir vulnerabilidades de seguridad en aplicaciones. Este sistema, desarrollado con lenguaje Python, automatiza los procesos de escaneo y corrección de vulnerabilidades en los procesos de desarrollo de software.

## Qué aporta
- Detecta automáticamente vulnerabilidades en aplicaciones.
- Genera informes de seguridad verificables.
- Se puede integrar en procesos CI/CD

## Instalación
**Instalación y configuración de Strix**

```
curl -sSL https://strix.ai/install | bash
```


## Ejecución
**Iniciar el análisis de seguridad inicial**

```
strix --target ./app-directory
```


## Si no programa
Realice un análisis de seguridad completo en el objetivo que especifiqué utilizando la herramienta Strix. Configure mis claves API requeridas al iniciar el escaneo e informe los hallazgos con evidencia verificable. Analice las vulnerabilidades en el directorio de mi aplicación o en la URL que especifique y proporcione un informe detallado que contenga hallazgos y sugerencias de soluciones.
