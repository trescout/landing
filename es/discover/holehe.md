# Encuentra cuentas registradas por correo electrónico

Holehe es una herramienta de Python que consulta si una dirección de correo electrónico ingresada se utiliza en plataformas populares como Twitter e Instagram. Detecta la información de la cuenta asociada con el correo electrónico relevante mediante funciones de restablecimiento de contraseña.

- ★ 13.530
- Python
- GitHub Trending · 2026-08-14

## Qué aporta
- Consulta por correo electrónico en más de 120 plataformas.
- No enviar notificaciones a la dirección de correo electrónico de destino
- Detectado usando funciones de restablecimiento de contraseña

## Instalación
**Instalación con PyPI**

```
pip3 install holehe
```

**Instalación a través de GitHub**

```
git clone https://github.com/megadose/holehe.git
cd holehe/
python3 setup.py install
```


## Ejecución
**Consulta por correo electrónico**

```
holehe test@gmail.com
```


## Si no programa
Usando la herramienta Holehe, verifique en qué plataformas está registrada la dirección [E-MAIL_ADRESI] y presente los resultados en una lista.
