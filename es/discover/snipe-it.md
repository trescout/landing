# Gestión de licencias y activos empresariales

Snipe-IT es un sistema de gestión de código abierto para rastrear activos de tecnología de la información y licencias de software. Esta plataforma, desarrollada con lenguaje PHP, permite a las instituciones organizar registros de inventario y ciclos de uso en un entorno digital.

- ★ 14.843
- PHP
- GitHub Trending · 2026-07-30

## Qué aporta
- Monitoreo del ciclo de vida de los activos de TI
- Seguimiento centralizado de licencias de software
- digitalización de registros de débito de hardware

## Instalación
**Toma la imagen oficial**

```
docker pull grokability/snipe-it
```


## Ejecución
**empezar**

```
docker compose up -d
```
