# Simulador espacial global en tiempo real

Gods-eye-view es un simulador de inteligencia espacial que visualiza datos satelitales en tiempo real en un globo 3D basado en navegador. Desarrollado con JavaScript, este proyecto de código abierto permite a los usuarios examinar datos en vivo de todo el mundo a través de una interfaz fotorrealista.

- ★ 14.902
- JavaScript
- GitHub Trending · 2026-08-28

## Qué aporta
- Vea datos de vuelos, barcos y satélites en vivo desde la Tierra en un globo 3D.
- Haz marcas en el mapa y cambia a diferentes modos de sensor con comandos de voz.
- Explora el mundo desde la perspectiva de la cabina al entrar en un avión real.

## Instalación
**Instalación e inicio de dependencias**

```
npm install
npm run dev -- --host localhost --port 4173
```


## Si no programa
Ayúdame a instalar el proyecto en mi computadora en https://github.com/bilawalsidhu/gods-eye-view en GitHub. Explique paso a paso cómo obtener la clave API de Google Maps y colocarla en un archivo .env. También ayúdame a configurar la alerta de facturación y la cuota de uso de la clave de Google. Finalmente, inicie el servidor de desarrollo y ábralo en el navegador. No soy un desarrollador de software, explico cada acción que realiza en un lenguaje sencillo y asegúrese de obtener mi aprobación antes de tomar cualquier paso que pueda implicar gastar dinero.
