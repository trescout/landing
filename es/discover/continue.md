# Soporte de inteligencia artificial para procesos de codificación

Continuar es un agente de codificación de código abierto diseñado para automatizar los procesos de desarrollo de software. Permite a los desarrolladores escribir, depurar y refactorizar código dentro del IDE utilizando sus modelos de lenguaje nativo (LLM).

- ★ 35.282
- GitHub Trending · 2026-06-18

**Nota de TreScout:** Asistente de inteligencia artificial que te ayuda a escribir código. La diferencia con los asistentes prefabricados es que usted decide qué modelo usar: conecta su propia clave o un modelo que se ejecuta en su computadora, su código no se filtrará. A cambio, la instalación y la selección del modelo se convierten en su trabajo, la experiencia no es tan refinada como la de los productos disponibles en el mercado.

## Qué aporta

- Acelera los procesos de codificación y depuración.
- Proporciona un espacio de trabajo seguro con modelos en el idioma local.
- Se integra con entornos de desarrollo de software como VS Code y JetBrains

## Instalación

**Instalación CLI con npm (Global)**

```
npm i -g @continuedev/cli
```

**Instalar como extensión de VS Code**

```
code --install-extension Continue.continue
```

**Global con npm**

```
npm install -g continue
```

## Ejecución

**Ejecutar agente Continue desde CLI**

```
cn
```
