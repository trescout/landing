# Copy repositories in GitHub workflows

Developed by GitHub, actions/checkout is a tool that automates repository checkout processes in software development processes. Continuous integration enables the source code to be transferred to the working environment in workflows.

## What you get

- Transferring the source code to the working environment
- Automatic warehouse copy operations
- Secure credential management

## Getting started

You can enable the tool to download your repository to the workspace by adding the - uses: actions/checkout@v7 line to the steps section of your GitHub Actions workflow file. You can customize the copy behavior by defining parameters such as fetch-depth or submodules under the with block according to your need.
