# Modular menu bar utility for macOS

Vorssaint-utils is an open-source menu bar toolset developed for the macOS operating system. It combines many different functions such as application-based audio control, system monitoring, window management, and clipboard history into a single interface.

## What you get

- provides audio control, system monitoring, and window management with a single menu bar icon
- runs only the required modules by removing unused features
- requires no account, collects no data, and has no subscriptions
