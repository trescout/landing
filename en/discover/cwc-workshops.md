# Hands-on workshop for artificial intelligence agents

These workshops shared by Anthropic show developers in practice the processes of creating artificial intelligence agents capable of computer use. TypeScript-based examples include technical frameworks that allow models to manage complex tasks by interacting with on-screen interfaces.

## What you get

- Constructing multi-agent systems with capabilities and MCP
- Giving agents permanent memory and learning abilities
- Evaluation-driven agent development processes

This tool includes material from the Code with Claude workshops hosted by Anthropic. To get started, visit the official cwc-workshops repository on GitHub and navigate to the folder that interests you and follow the instructions there.
