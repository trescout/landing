# Open source SEO data and analytics platform

Open SEO offers an open source alternative to paid tools like Semrush and Ahrefs. This software, developed to analyze search engine optimization (SEO) data, aims to make processes transparent with its TypeScript-based infrastructure.

- ★ 12,234
- TypeScript

## What you get
- Pay only for what you use, with no subscription fees
- Direct SEO data analysis with artificial intelligence agents
- Keyword tracking and technical site audit

## Installation
**Adding capabilities to an AI agent**

```
npx skills add every-app/open-seo --skill '*'
```

**Local installation with Docker**

```
docker compose pull
docker compose up -d
```
