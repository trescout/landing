# Rapid tool integration for AI

FastMCP is a Python-based framework that makes it easy to develop Model Context Protocol (MCP) servers and clients. It enables developers to quickly integrate between AI models and native tools.

- ★ 27,483
- Python
- GitHub Trending · 2026-07-21

## What you get
- Easily turns Python functions into AI tools
- Automatically creates schema, validation and documentation
- Speeds up server, client and application development processes

## Installation
**installation with uv**

```
uv pip install fastmcp
```
