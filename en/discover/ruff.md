# An extremely fast Python linter and code formatter

Ruff is an extremely fast Python linter and code formatter written in the Rust programming language. It is used to improve code quality and speed up formatting processes in software development workflows.

## What you get

- Operates tens of times faster compared to existing tools
- Combines linting and formatting into a single tool
- Offers automatic fix support for Python projects

## Installation

**install with pip**

```
pip install ruff
```

**installation with uv**

```
uv tool install ruff@latest
```

## Running it

**running code linting**

```
ruff check
```

**running code formatting**

```
ruff format
```
