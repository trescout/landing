# Investment management with autonomous AI

AutoHedge is a framework that uses swarm intelligence and AI agents to automate market analysis, risk management, and trading operations. It allows users to create their own autonomous hedge funds in minutes.

- ★ 5,980
- Python
- GitHub Trending · 2026-09-07

## What you get
- Automates market analysis and risk management
- Works with multiple expert AI agents
- Can perform fully autonomous trading on Solana

## Installation
**Install the library on your computer**

```
pip install -U autohedge
```


## Running it
**Launch the investment fund system**

```
autohedge
```
