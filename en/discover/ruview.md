# Gain Spatial Intelligence with WiFi Signals

RuView provides real-time spatial intelligence, vital sign tracking and presence detection without a camera, using ordinary WiFi signals. It is an open source project developed with Rust.

- ★ 90,838
- Rust

- GitHub Trending · 30 May 2026

## What does it offer?
- Presence and motion detection without using a camera.
- Monitoring vital signs (breathing and pulse).
- Real-time spatial intelligence.

## How to install, how to use?
**Pull the Docker image**

```
docker pull ruvnet/wifi-densepose:latest
```

**Run with Docker (simulation, no hardware required)**

```
docker run -p 3000:3000 ruvnet/wifi-densepose:latest
```

**Python package (PyPI)**

```
pip install ruview
```
