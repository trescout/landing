# Fast video downloading via terminal

Yoinks is a tool for downloading any video via the terminal without ads or redirects. Developed with TypeScript, this software offers a practical method for transferring video files directly to local storage.

## What you get

- Downloads videos from over 1800 sites such as YouTube, Instagram, and TikTok
- Saves directly to local storage without ads or fake download buttons
- Offers the ability to select video resolution or extract audio only

## Installation

**Global installation**

```
npm install -g yoinks
```

**Operation without installation**

```
npx yoinks
```

## Running it

**Start with video link**

```
yoinks https://youtu.be/dQw4w9WgXcQ
```

**Start with interactive menu**

```
yoinks
```
