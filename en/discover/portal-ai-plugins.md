# Bring Spotify portal data to your coding assistant

Developed by Spotify, portal-ai-plugins integrates the Spotify Portal system into AI-powered coding tools like Claude Code, Codex, Cursor, and pi. Written in TypeScript, these plugins make it easier for developers to access Spotify-sourced data within their working environments.
