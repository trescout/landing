- Offers permanent memory that recalls past sessions
- Self-learning system that automatically manages tasks

## Installation

**Starting the interactive setup wizard**

```
npx ruflo@latest init wizard
```

**Installing Ruflo globally**

```
npm install -g ruflo@latest
```
