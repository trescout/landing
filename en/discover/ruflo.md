# Orchestration layer for AI agents

Ruflo is an agent orchestration layer for deploying intelligent agent swarms, coordinating autonomous workflows, and building conversational AI systems.

- ★ 70,299
- TypeScript
- GitHub Trending · 2026-08-22

## What you get
- Allows agents to collaborate with each other
- Offers permanent memory that recalls past sessions
- Self-learning system that automatically manages tasks

## Installation
**Starting the interactive setup wizard**

```
npx ruflo@latest init wizard
```

**Installing Ruflo globally**

```
npm install -g ruflo@latest
```


## If you don't write code
You are in an integrated work environment with Ruflo. Optimize your workflow by using Ruflo's tools, memory features, and agent swarms to perform tasks. Self-improve next steps by learning from successful patterns and coordinate with other agents to manage complex tasks.
