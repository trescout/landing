# Professional video production with artificial intelligence

OpenMontage is an open source agent-based system that turns AI coding assistants into a full-fledged video production studio. This Python-based platform automates video production processes with 12 different pipelines and more than 500 agent skills.

## What you get
- Automatic scenario, visual and sound editing
- Video compilation from stock footage and open archives
- Step-by-step approved production planning

## Installation
**Basic setup**

```
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup
```
