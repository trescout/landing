# Connect your AI agents to interfaces

AG-UI is an open-source and event-driven communication protocol that connects AI agents to user interfaces. It simplifies application integrations by enabling developers to establish a standard data flow between AI agents and user interfaces.

## What you get

- Establishes real-time state synchronization between agents and user interfaces
- Adapts to different data transport methods with its flexible event-driven architecture
- Supports generative interfaces and human-in-the-loop collaboration processes
