# Ready-to-use configuration set for Claude Code

Claude Code is a toolkit containing agents, commands, and hooks designed to accelerate AI-powered development processes. It brings together all the components necessary to automate software development workflows under a single roof.

## What you get

- Provides ready-to-use agents and commands that automate software development processes.
- Prevents context loss with cross-session memory management.
- Automates standards such as TDD (Test Driven Development) and security audits.

It is recommended to first understand the core philosophy by reading the 'Shorthand Guide' and 'Longform Guide' on the project's GitHub page. For installation, you can install the plugin directly from within Claude Code as a marketplace plugin or start using it by moving the necessary files to your own directory using the commands above.
