# Calibrate modern web development guides

GoogleChrome/modern-web-guidance-src is a source repository containing the code and documentation required for creating, calibrating, and evaluating modern web development guides. Developed in TypeScript, this project enables the management of guide content targeting web standards.

## What you get

- Replaces outdated coding habits of AI coding agents with current web standards.
- Directly imports browser compatibility and performance-focused ready-to-use development guides into the agent's context.
- Prioritizes the browser's built-in features and lightweight solutions instead of unnecessary libraries.

## Installation

**Setup with interactive wizard**

```
npx modern-web-guidance@latest install
```

**Alternative installation with options**

```
npx modern-web-guidance@latest install --choose
```

## Running it

**Guide search and outdated structures in code**

```
# Search for relevant guides
npx modern-web-guidance@latest search "animate a dialog modal backdrop"

# Retrieve a guide by ID
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"

# Scan a codebase for legacy patterns to modernize
npx modern-web-guidance@latest legacy-scan .
```
