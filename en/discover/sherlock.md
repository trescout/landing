# Search for usernames across different networks

Developed in Python, sherlock-project/sherlock is a tool that scans social media accounts across different networks using usernames. The project offers community-maintained package supports for various platforms such as Debian, Ubuntu, Homebrew, Kali, and BlackArch.

## What you get

- Scan your specified usernames across more than four hundred social networks at once.
- Query multiple usernames simultaneously and save the results as a text file.
- Gain access via various operating systems and system packages.
