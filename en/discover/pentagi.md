# Artificial intelligence for autonomous penetration testing

Developed with the Go language, Pentagi offers a system of fully autonomous artificial intelligence agents (AI agents) that can perform complex penetration testing. The system aims to standardize autonomous workflows to detect and exploit vulnerabilities.

- ★ 21,475
- Go
- GitHub Trending · 2026-07-10

## What you get
- Fully autonomous security tests in Sandboxed Docker environment
- Support for more than 20 professional tools such as Nmap and SQLmap
- Detailed system monitoring with Grafana and Prometheus

## Running it
**Start the service**

```
curl -O https://raw.githubusercontent.com/vxcontrol/pentagi/master/docker-compose.yml
docker compose up -d
```
