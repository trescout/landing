# Lightweight interface for C++ projects

Dear ImGui is a lightweight graphical user interface library for C++ projects that works with minimal dependencies. It allows software developers to create a simple interface in rapid prototyping and tool development processes.

## What you get

- Simple structure that does not require external dependencies
- Rapid prototyping and tool development
- Low memory and processor consumption

## Getting started

To start your project, simply add all .cpp and .h files starting with imgui in the GitHub repository into your existing project. Then, you can start creating your own graphical interface by examining the sample applications in the backends folder.
