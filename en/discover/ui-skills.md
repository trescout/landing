# Interface skills for design engineers

Developed for design engineers, ui-skills brings together the technical skills and competencies needed in user interface (UI) development processes. This TypeScript-based resource offers a competency map for professionals transitioning from interface design to coding.

- ★ 7,867
- TypeScript
- GitHub Trending · 2026-07-17

## What you get
- Technical competence map in interface development processes
- Bridging the gap between design and coding
- Access skill sets via command line

## Installation
**Starting the tool**

```
npx ui-skills start
```

**List categories**

```
npx ui-skills categories
```


## Running it
**View a specific category**

```
npx ui-skills list --category motion
```

**Acquire the skill**

```
npx ui-skills get baseline-ui
```
