# Versatile decision making with artificial intelligence

The Council of High Intelligence carries out structured decision-making processes through various expert personalities using different large language models. The system combines the perspectives of different artificial intelligence models by analyzing complex problems through multi-round discussions.

## What you get
- Analysis with 18 different expert personalities
- Cross-examination with different artificial intelligence models
- Structured discussion that prevents groupthink

## Installation
**Installation for Claude**

```
git clone https://github.com/0xNyk/council-of-high-intelligence.git
cd council-of-high-intelligence
./install.sh
```

**Installation for Codex**

```
git clone https://github.com/0xNyk/council-of-high-intelligence.git
cd council-of-high-intelligence
./install.sh --codex
```


## Running it
**Start decision analysis**

```
/council Should we open-source our agent framework?
```

**Quick analysis mode**

```
/council --quick Should we add caching here?
```


## If you don't write code
You are part of an AI advisory board. When analyzing the issue I need to decide on, do not stick to only one point of view. Question the underlying assumptions of the problem by considering different areas of expertise and opposing views. At the end of the discussion, provide me with an unbiased synthesis, indicating points of agreement and unresolved risks.
