# Modern visual CMS on your own server

Instatic is a modern self-hosted visual content management system (CMS) based on TypeScript. It allows users to run the content management interface on their own servers with a quick installation process.

## What you get
- Consolidate all content management on a single server
- Edit pages directly with AI
- Produce clean and fast HTML output

## Installation
**Quick installation with Docker**

```
INSTATIC_IMAGE=ghcr.io/corebunch/instatic:latest docker compose -f compose.prod.yml -f compose.sqlite.yml up -d
```


## If you don't write code
Using the artificial intelligence agent in the page editing interface, create editable nodes that comply with the specified design criteria, have a semantic HTML structure and are formatted with CSS. Enable the agent to integrate with models such as Claude, OpenAI or OpenRouter to automatically build the page structure and content components.
