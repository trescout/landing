# AI workspace that accelerates research processes

AlphaXiv is a framework that allows you to run parallel research agents using different AI models. Developed in Rust, this open-source tool aims to accelerate data collection processes in academic and technical research.

## What you get

- Creates independent and parallel agent sessions for different research ideas.
- Provides traceability by keeping experiment results, logs, and code changes together.
- Autonomously manages research cycles on your local computer or remote servers.
