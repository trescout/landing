# Map your codebase to AI

Codegraph is a local knowledge graph tool that pre-indexes codebases and serves them to AI models. By automatically syncing code changes, it enables coding assistants like Claude Code or Cursor to use fewer tokens and tool calls.

- ★ 73,076
- C
- GitHub Trending · 2026-10-01

## What you get
- Creates a local knowledge graph that enables AI models to consume fewer tokens while coding.
- Keeps the index always up to date by automatically syncing code changes in the background.
- Directly connects tools like the coding assistant Cursor with your project's architecture.

## Installation
**Global installation with the npm package manager**

```
npm i -g @colbymchenry/codegraph
```


## Running it
**Running and linking the tool directly with npx**

```
npx @colbymchenry/codegraph
```


## If you don't write code
Install the Codegraph tool in my project by running the command `npm i -g @colbymchenry/codegraph` via the npm package manager. Then, complete the process by running the command `npx @colbymchenry/codegraph` to configure AI assistants.
