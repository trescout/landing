# Sample servers for artificial intelligence agents

Model Context Protocol (MCP) servers enable generative artificial intelligence models to access external data sources and tools through a standard interface. This protocol allows different artificial intelligence applications to securely and consistently connect with databases or software tools.

- TypeScript

## What you get
- You ensure your large language models (LLMs) securely access local files, data stores, and persistent memory.
- You can connect your artificial intelligence applications with external data sources by examining reference server examples.
- You access ready-made templates to develop your own servers using different software development kits (SDKs).

## Installation
**Installing and starting the Git server**

```
# With uvx
uvx mcp-server-git

# With pip
pip install mcp-server-git
python -m mcp_server_git
```


## Running it
**Running the memory server**

```
npx -y @modelcontextprotocol/server-memory
```
