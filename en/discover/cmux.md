# Smart Terminal and Automation for macOS

cmux, a Ghostty-based macOS terminal, offers vertical tabs and notification support for AI coding agents. Focused on multitasking and programmability, this tool helps developers organize their workspaces.

## What you get
- Offers notification support for AI coding agents
- Organizes the workspace with vertical and horizontal tabs
- Includes a built-in browser hosting a scriptable API

## Installation
**Installation with Homebrew**

```
brew tap manaflow-ai/cmux
brew install --cask cmux
```
