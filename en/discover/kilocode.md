# Versatile AI coding agent

Kilo is an all-in-one agent-based engineering platform designed to accelerate software development processes. It standardizes the application creation, distribution and iteration processes through an open source software development agent (coding agent).

- ★ 27,110
- TypeScript
- GitHub Trending · 2026-06-19

## What you get
- Ability to switch between more than 500 models
- VS Code, JetBrains and CLI support
- Natural language code generation and debugging

## Installation
**install with npm**

```
npm install -g @kilocode/cli
```

**Installation with Homebrew**

```
brew install Kilo-Org/tap/kilo
```


## Running it
**Starting the tool**

```
kilo
```

**Autonomous operating mode**

```
kilo run --auto "run tests and fix any failures"
```


## If you don't write code
As a software development agent, I need you to manage my natural language code generation, debugging, or architecture planning processes in my current project directory. I want you to choose the one that best suits my task among the more than 500 models offered by Kilo, review the codes you have written with your own self-audit mechanism, and deliver them in accordance with performance and security standards.
