Server side development with JavaScript

Node.js offers a runtime environment that allows JavaScript code to be run outside the browser. Based on the V8 engine, this platform is used to develop scalable network applications on the server side.

  • ★ 118,797
  • JavaScript

TreScout note: The standard way to run JavaScript on the server side. Using the same language on both sides is a great convenience for the team; The price is that the dependency tree swells rapidly and version management becomes your job.
