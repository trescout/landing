# Visual and native debugging tool

Developed by Epic Games, raddebugger is a native and visual debugger written in the C language. Offering multi-process support, this tool operates in user mode to help software developers identify application bugs.

## What you get

- You can easily identify software bugs in your applications with Raddebugger, a debugger featuring a visual interface.
- Thanks to the code linking tool RAD Linker, you can shorten compilation times in large software projects.
- With the custom data format RDI, you can quickly convert debugging information and gain performance.

## Getting started

You can download pre-compiled binaries suitable for your system from the releases section on the project's GitHub page. By following the user manual inside the downloaded folder, you can start running the tool immediately.
