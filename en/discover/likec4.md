# Visualize your software architecture with live diagrams

Likec4 is a tool that visualizes software architecture directly from the source code and enables the creation of live diagrams. It aims for the continuity of technical documentation through architectural diagrams that are updated simultaneously with the code base.

## What you get
- It creates architectural schemas that are updated simultaneously with your code base.
- It offers a flexible and customizable modeling language based on the C4 model.
- It ensures documentation continuity by managing visualization processes through code.
