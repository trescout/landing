# Multi-protocol tool for hardware analysis

ESP32-Bit-Pirate is a hardware hacking tool that supports multiple communication protocols via a web-based command line interface (CLI). This system, developed in C++ language, facilitates hardware analysis processes by managing different protocols on a single platform.

## What you get
- Manage protocols such as I2C, SPI, UART and 1-Wire
- Interaction with radio frequencies, Bluetooth and Wi-Fi
- Hardware debugging via web-based interface

## Getting started
- Official source →
Install the software suitable for your device through your browser using the Web Flasher tool on the official website. Then, access the command line interface by connecting to your device with a serial terminal application or browser-based Web Serial terminal.
