# Customize the Unturned game

SmartlyDressedGames shared the U3-SDK software development kit developed for the open world zombie survival game Unturned as open source. These source codes, prepared in C# language, allow community members to customize and develop the game.

## Getting started
- Official source →
Download or copy the project to your computer. Then install the specified Unity 2022.3.62f3 version via Unity Hub and make sure that the Unturned game is installed on Steam. Finally, you can start the project by opening it with the Unity editor and going to the Assets/GameStartup.unity scene.
