Monitor your coding agents with artificial intelligence

Agentsview is a monitoring tool that provides local-first session intelligence and analytics data for coding agents. This software, which supports more than twenty agents, including Claude Code and Codex, promises faster performance compared to the ccusage tool.

What you get

  • Monitor the sessions of all your artificial intelligence coding agents from a single center.
  • Quickly calculate used token amounts and costs.
  • Protect privacy by keeping your data on your local computer.

Installation

macOS/Linux
curl -fsSL https://agentsview.io/install.sh | bash
Windows
powershell -ExecutionPolicy ByPass -c "irm https://agentsview.io/install.ps1 | iex"

Running it

Starting the server and accessing the interface
agentsview serve
View daily cost summary
agentsview usage daily
