# Desktop access to your Jellyfin media library

Jellium-desktop is an unofficial desktop client developed in Rust for the media server Jellyfin. The software offers a native interface that allows users to access their media libraries directly through the operating system.

- ★ 1,342

## What you get

- Access your Jellyfin media server via native app
- Optimized media playback with CEF and MPV infrastructure
- Native interface support on Windows, macOS and Linux
