# A single interface for your AI models

open-webui is a user-friendly interface that allows interacting with AI models such as Ollama and OpenAI API. It offers a web-based interface developed to manage local or cloud-based language models.

## What you get

- You can manage all local and cloud-based AI models on a single web screen.
- You can upload your own documents to the system to perform Q&A over your texts and search the internet.
- You can use image generation, voice search, calendar management, and note-taking tools without leaving the chat area.

## Installation

**Installation with Python package manager pip**

```
pip install open-webui
```

## Running it

**Start with software containerization tool Docker**

```
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```
