AI workflows with visual interface

Langflow is a Python-based development platform that offers a visual interface for building AI-powered agents and workflows. Users can design and deploy complex language model applications using drag-and-drop without writing code.

  • ★ 155,555
  • Python

TreScout note: You set up the AI ​​workflow by connecting boxes, without writing code. Quick to try and demonstrate the idea; As the flow grows, the visual schematic becomes unreadable and version tracking becomes difficult, at which point it is necessary to switch to code.
