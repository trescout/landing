# Chat-focused AI bot team

OpenMausBot is an open-source Grok Bot alternative that allows you to create your own AI bot team within chat applications. The software comes with virtual machine support that the bots can use.

## What you get

- You can manage your own AI bot team via Electron, the desktop application infrastructure.
- You can store your chat history and data locally on your computer instead of the cloud.
- You can assign different AI models to your bots with command-line interface CLI integration.

## Installation

**Installing and running the OpenMausBot package**

```
npm install -g openmausbot
openmausbot
```
