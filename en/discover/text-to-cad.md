# Automated design with artificial intelligence

Text-to-CAD tools are a collection of agent skills developed to automate robotics and hardware design processes. This JavaScript-based library allows complex engineering models to be created with natural language commands.

## What you get
- Create complex CAD models with natural language
- Preparing robotic structure and simulation files
- Native CAD preview support via browser

## Installation
**Installation with Skills CLI**

```
npx skills install earthtojake/text-to-cad
```
