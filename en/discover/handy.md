# Transcribe your voice locally

cjpais/Handy is a free and open-source speech-to-text application that runs entirely offline. Developed in Rust, this tool offers an extensible architecture allowing users to process voice data locally.

## What you get

- Instantly transcribe your speech to text without needing an internet connection
- Protects your personal privacy by not sending voice data to cloud servers
- Types directly into the active text field by pressing a keyboard shortcut you define

## Installation

**Debian or Ubuntu-based Linux systems**

```
sudo apt install ./Handy_*.deb
```
