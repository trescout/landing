# YAML management for C++ projects

yaml-cpp is a library for the C++ programming language that parses and emitters data in YAML format. It allows software developers to manage configuration files and perform data serialization operations.

- C++

## What you get
- Full compliance with YAML 1.2 standards
- Data parsing and rendering support
- Cross-platform compilation with CMake

## Installation
**macOS (Homebrew)**

```
brew install yaml-cpp
```
