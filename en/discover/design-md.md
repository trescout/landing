# Introduce design systems to AI

Developed by Google Labs, DESIGN.md provides a structured format specification for passing visual credentials to coding agents. This standard ensures that design systems are understood consistently and permanently by artificial intelligence agents.

## What you get

- Stores design decisions in structured format
- Provides consistent visual guidance for coding agents
- Automatically checks for design errors and inconsistencies

## Installation

**Install the package**

```
npm install @google/design.md
```

**Install for Windows**

```
npm install "@google/design.md"
```

## Running it

**Validate the design file**

```
npx @google/design.md lint DESIGN.md
```

**Comparing two design files**

```
npx @google/design.md diff DESIGN.md DESIGN-v2.md
```
