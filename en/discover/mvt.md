# Search for traces of cyber attacks on mobile devices

Mobile Verification Toolkit is a forensic tool used to detect security breaches on mobile devices. Developed in Python, this software analyzes device data to uncover potential traces of cyber attacks.

- ★ 15,221
- GitHub Trending · 2026-09-22

## What you get
- Collects forensic artifacts on Android and iOS devices
- Scans for traces of known spyware campaigns
- Performs security analysis with command-line tools

## Installation
**install with pip**

```
pip3 install mvt
```

**install with uv**

```
uv tool install mvt
```


## Running it
**Generate completion script**

```
mvt completion bash
```
