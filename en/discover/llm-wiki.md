# Create an automated AI wiki from your documents

LLM Wiki is a cross-platform desktop application that automatically organizes documents into an interconnected knowledge base. Unlike traditional retrieval-augmented generation (RAG) methods, it creates a persistent wiki from your sources, keeping data incrementally updated.

- ★ 18,359
- TypeScript
- GitHub Trending · 2026-09-11

## What you get
- Analyzes documents and converts them into interconnected wiki pages
- Keeps data continuously updated with a persistent memory structure
- Fully compatible with Obsidian note-taking software

## Getting started
Download it to your computer by following the installation steps on the project's GitHub page. Ensure that Node.js and Rust development environments are installed, then you can install the necessary dependencies via the command line and launch the application.
