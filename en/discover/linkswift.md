# Direct download links from cloud services

LinkSwift is a tool that obtains direct file download links from various cloud storage services using a JavaScript-based infrastructure. The software supports eight different popular cloud platforms, including Baidu Netdisk, Alibaba Cloud Drive, China Mobile Cloud, and Quark Drive.

## What you get

- Generates direct file download links from nine different cloud storage services, including Baidu, Alibaba Cloud, and Quark.
- Offers the ability to export the obtained links to software such as the download manager IDM or the file download tool Aria2.
- Streamlines the web interfaces of supported cloud services, eliminating the need to install official desktop applications.

## Getting started

To use it, you first need to install the userscript manager Tampermonkey extension in your browser. Then, you can add the script to your browser by clicking the installation link with the ".user.js" extension shared on the project's GitHub or ScriptCat page. Once the script is installed, when you visit a supported cloud storage site, the direct download menu will automatically appear in the interface.
