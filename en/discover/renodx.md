# Modern HDR support for older games

Renodx is a conversion engine that adds high dynamic range (HDR) support to older DirectX games. This tool, which allows developers to adapt game graphics to modern display standards, uses shader language (HLSL) to improve visual quality.

## What you get

- Upgrades older game graphics to modern display standards
- Enhances visual quality by modifying in-game shaders
- Provides broad game compatibility thanks to the Reshade plugin system

## Getting started

To start using the tool, you can review the list of available mods on the project's Wiki page on GitHub or check out the utilities section on the official page to download developer tools. It is recommended to follow the documentation pages for installation and usage details.
