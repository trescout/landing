# Set up an online video search and streaming platform

LibreSpark/LibreTV is a TypeScript-based software project that allows you to set up a movie and TV series site in under a minute using methods like Docker. It provides an infrastructure that enables users to quickly build their own content platforms.

- ★ 18,500
- TypeScript
- GitHub Trending · 2026-10-16

## What you get

- search for movies and TV series from different sources in one place
- watch internet television broadcasts in m3u and m3u8 formats
- save your watch history and where you left off in your browser

## Installation

**quick installation with docker**

```
docker compose pull && docker compose up -d
```

## Running it

**running by compiling from source**

```
npm install
PASSWORD=your-password npm run build
PASSWORD=your-password npm start   # 监听 8080
```
