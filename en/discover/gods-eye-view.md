# Real-time global spatial simulator

Gods-eye-view is a spatial intelligence simulator that visualizes real-time satellite data on a browser-based 3D globe. Developed with JavaScript, this open-source project allows users to examine live data on Earth through a photorealistic interface.

## What you get

- Monitor live flight, ship, and satellite data on Earth on a 3D globe.
- Make markings on the map with voice commands and switch between different sensor modes.
- Explore the world from a cockpit perspective by entering live aircraft.

## Installation

**Installing dependencies and starting**

```
npm install
npm run dev -- --host localhost --port 4173
```
