# Train and run local AI models

Unsloth is a library that accelerates the training and execution of large language models (LLM) and diffusion models in a native environment. It makes fine-tuning processes of popular models more accessible by optimizing memory usage.

## What you get

- Run large language models and rendering tools on your local computer.
- Perform fine-tuning processes twice as fast and with 70% less memory usage.
- Integrate software development agents like Claude Code with your native models.

## Installation

**Setup for macOS, Linux and WSL**

```
curl -fsSL https://unsloth.ai/install.sh | sh
```

## Running it

**Starting the software development agent**

```
unsloth start claude
```
