# Web interface for coding agents

T3Code is a toolset developed to improve and standardize code quality in TypeScript-based projects. It provides automation support to developers in type safety and code editing processes.

## What you get
- Codex, Claude, Cursor and OpenCode support
- Visual code management via browser
- Quick installation and operating options

## Installation
**Installation on macOS**

```
brew install --cask t3-code
```


## Running it
**Operation without installation**

```
npx t3@latest
```


## If you don't write code
Using the T3 Code tool, configure one of the Codex, Claude, Cursor or OpenCode providers and launch the coding agent interface. After completing the authentication process of the provider you have chosen, run the tool and start receiving coding support on your projects.
