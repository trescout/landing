Manage Your Services in Real Time

iii is a method of creating, extending and monitoring all services in your backend stack (queue, cron, HTTP, state, observability, agents, sandbox) in real time. It makes parts that normally present separate integration difficulties manageable from a single point.

What you get

  • Queue, cron, HTTP and state management in one place.
  • Real-time traceability opportunity.
  • Agent and sandbox support.
  • It reduces complexity in integration processes.

Getting started

To get started and access documentation, you can visit iii.dev.

How to install, how to use?

🤖 Paste this into your AI agent (Claude Code · Codex · Antigravity)

To try iii, first create a project with 'iii project init myapp', do 'cd myapp' and start the engine with the 'iii' command, then add capabilities with commands like 'iii worker add queue' and connect them all in the same live system; If SDK is required, install 'npm install iii-sdk'.

Create project
iii project init myapp
start engine
cd myapp
iii
Add worker (skill)
iii worker add queue
Install Node.js SDK
npm install iii-sdk
