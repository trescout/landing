# Open source office toolset

Univer is an open source platform that combines office tools such as spreadsheets, documents and presentations in a single runtime. It offers a modular structure designed to facilitate the interaction of artificial intelligence agents (AI agents) with office software.

- ★ 21,590
- GitHub Trending · 2026-09-23

## What you get
- Embed spreadsheet, document, and presentation experiences into your own application.
- Run data processing operations with the same architecture in the browser or server side.
- Bring together only the features you need with modular plug-in architecture.

## Installation
**Clone Repository and Create Development Environment B**

```
git clone https://github.com/dream-num/univer.git
cd univer
pnpm install
pnpm dev
```


## If you don't write code
To run the Univer project locally, clone the repository with the git clone https://github.com/dream-num/univer.git command in the terminal, then run the pnpm dev command after installing the dependencies with cd univer and pnpm install.
