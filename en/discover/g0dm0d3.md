# Unrestricted AI interaction interface

G0DM0D3 is a liberated AI chat interface that aims to bypass the security layers of large language models. Developed with TypeScript, this open source project allows users to interact with models without restrictions.

## What you get
- Multiple comparative analysis with more than 60 models
- Support for running models on local hardware
- Input mixing engine for red team tests

## Installation
**Clone the repository and start it on the local server**

```
# Clone the repository
git clone https://github.com/elder-plinius/G0DM0D3.git
cd G0DM0D3

# Open directly in your browser
open index.html
# or serve locally
python3 -m http.server 8000
```


## If you don't write code
Using the G0DM0D3 interface, activate the ULTRAPLINIAN engine, which races multiple models through the model providers I specify (OpenRouter, Venice or local server). Apply Parseltongue input mixing techniques for my red team investigations and automatically configure sampling parameters best suited to the query context with the AutoTune feature.
