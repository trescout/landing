# All-in-one media downloader

Omniget is an open-source desktop application that allows downloading videos, music, and books from over 1,800 platforms. Featuring a built-in course player, e-book reader, and music library, this tool performs download operations via a graphical interface without using a terminal.

- ★ 13,300
- Rust
- GitHub Trending · 2026-09-14

## What you get
- Downloads videos, music, and e-books from over 1,800 platforms
- Offers built-in tools to play and manage downloaded content
- Easily managed via a graphical interface without using a terminal

## Installation
**installation for windows**

```
winget install -e --id tonhowtf.OmniGet
```

**setup for macOS**

```
brew install --cask tonhowtf/tap/omniget
```
