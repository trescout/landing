# Produce AI videos with one click

MoneyPrinterTurbo automatically produces short videos using large language models from a topic or keyword you provide. It combines text, subtitles, background music and visuals. (The name is for marketing purposes, it is a content production tool, not a 'money printing' machine.)

## What you get
- It creates automatic editing using text, subtitles, music and visuals.
- It is easy to use thanks to its web interface.
- It allows batch and multiple video production.

## How to install, how to use?
**Clone repository**

```
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

**Launch with Docker**

```
cd MoneyPrinterTurbo
docker-compose up
```

**Run web interface (with uv)**

```
uv run streamlit run ./webui/Main.py --browser.gatherUsageStats=False
```
