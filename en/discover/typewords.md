# Memorize English words with your typing speed

TypeWords is a typing exercise tool that allows users to improve their typing speed while practicing English through its Vue-based interface. The software turns every keystroke into a learning step, supporting language skills through gamification.

## What you get

- Performs smart word repetition based on memory curves
- Offers bilingual comparative study opportunities with textbooks and articles
- Automatically tracks misspelled words and adds them to a review list

## Getting started

You do not need to perform any installation to start using the tool; you can go to https://typewords.cc from your browser and start practicing immediately. If you want to run it on your own computer, after installing the Node.js software development environment, you can download the project's source code from GitHub and start it on your local server by installing the necessary dependencies via the terminal.
