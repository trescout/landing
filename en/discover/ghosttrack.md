# Location tracking via mobile numbers and usernames

Python-based GhostTrack is a tool that allows location tracking via mobile numbers. This open source software was developed to detect the geographical data of the target number.

## What you get

- Detects geolocation data of mobile numbers
- Collects information through social media usernames
- Works integrated with auxiliary tools for IP address tracking
