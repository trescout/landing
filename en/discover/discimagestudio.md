# Visual etching tool for optical discs

Disc Image Studio is a cross-platform disc image creation and burning tool that allows you to etch naked-eye visible images onto the surface of DVDs, CDs, and single-layer Blu-ray discs. Developed in C#, this software enables you to process custom graphics onto the disc surface using any writable optical drive.

## What you get

- Etches custom graphics visible to the naked eye onto the surface of DVD, CD, and Blu-ray discs.
- Offers advanced image processing and shading tools to create patterns on the disc surface.
- Features a cross-platform architecture capable of running on Windows, Linux, and macOS.

## Running it

**Launch command line interface**

```
dotnet run --project src/DiscImageStudio.Cli -c Release -- --help
```
