# Create a targeted password list

Common User Passwords Profiler is a Python tool for creating targeted password lists. It prepares customized dictionary files (wordlists) by analyzing specific user data.

- ★ 6,161
- Python
- GitHub Trending · 2026-07-01

## What you get

- It prepares customized dictionaries by analyzing user data.
- It offers the opportunity to create a target-oriented profile with interactive questions.
- Parses default username and password matches with the Alecto database.

## Installation

**Clone repository**

```
git clone --depth 1 https://github.com/Mebus/cupp.git && cd cupp
```

## Running it

**Run in interactive mode**

```
python3 cupp.py -i
```
