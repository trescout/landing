# Artificial intelligence support for coding processes

Continue is an open source coding agent designed to automate software development processes. It allows developers to write, debug and refactor code within the IDE using their native language models (LLM).

- ★ 35,282
- GitHub Trending · 2026-06-18

## What you get
- Speeds up coding and debugging processes
- Provides a safe workspace with local language models
- Integrates with software development environments such as VS Code and JetBrains

## Installation
**CLI installation with npm (Global)**

```
npm i -g @continuedev/cli
```

**Installation as VS Code add-on**

```
code --install-extension Continue.continue
```

****

```
npm install -g continue
```


## Running it
**Run Continue agent via CLI**

```
cn
```
