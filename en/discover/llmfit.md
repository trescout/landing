# Find AI models that fit your hardware

Developed with the Rust language, llmfit scans hundreds of large language models and providers and allows you to identify those compatible with your hardware with a single command. The tool automates the process of finding models that best suit local system resources.

## What you get
- Automatically detects models compatible with your system
- Sorts by memory, speed and quality
- Provides easy management with interactive interface

## Installation
**Installation for macOS or Linux**

```
brew install AlexsJones/llmfit/llmfit
```

**Quick installation**

```
curl -fsSL https://llmfit.axjns.dev/install.sh | sh
```


## Running it
**Starting the interactive interface**

```
llmfit
```
