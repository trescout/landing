# Common semantic standard for data platforms

Apache Ossie is an industry initiative that aims to standardize the exchange of semantic metadata between analytics, artificial intelligence and business intelligence (BI) platforms. This project facilitates data integration by creating a vendor-independent, single source of truth between different platforms.

## What you get

- Provides consistent definitions across different data tools
- Creates a single source of truth, independent of vendor
- Increases compatibility between AI and business intelligence tools

## Getting started

Apache Ossie is a standards specification rather than a software installation. You can obtain information about how the data tools you use can be made compatible with this standard by examining the technical documents and schema files under the core-spec folder on the project's GitHub page.
