# Monitor your Tesla data on your own server

Developed for Tesla vehicle owners, Teslamate is a data logger application that allows you to host data on your own server. This open source tool, written in Elixir language, visualizes and presents detailed statistics such as driving history and charging data to the user.

## What you get
- Analyze driving and charging data in detail
- Monitor battery health and efficiency
- Get full data control on your personal server

## Installation
**Create the docker-compose.yml file from the official guide (database password and encryption key are yours)**

```
docker compose pull
```


## Running it
**Start (http://localhost:4000)**

```
docker compose up -d
```
