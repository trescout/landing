# Personal AI news tracking radar

Thysrael/Horizon is a news tracking tool that collects, filters, and summarizes news from various sources using artificial intelligence. Preparing daily bulletins in English and Chinese, this software helps users manage their information flow by presenting content along with context and community discussions.

## What you get

- Automatically collects and filters news from various sources.
- Prepares daily summary bulletins in English and Chinese.
- Presents news along with context and community discussions.

## Installation

**Cloning and installing the project**

```
git clone https://github.com/Thysrael/Horizon.git
cd Horizon

# Install with uv (recommended)
uv sync

# Install test/development extras when needed
uv sync --extra dev

# Or with pip
pip install -e .
```

## Running it

**Starting the wizard**

```
uv run horizon-wizard
```
