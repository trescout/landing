# High performance for AI models

OpenVINO is an open-source toolkit used to optimize and deploy inference processes of artificial intelligence models. Developed in C++, this platform enables models to run more efficiently on different hardware.

## What you get

- Optimizes the processing speed of deep learning models.
- Ensures efficiency on hardware such as central processing units (CPUs) and graphics processing units (GPUs).
- Supports models prepared with the model development library PyTorch and the machine learning platform TensorFlow.
