# Query your codes with artificial intelligence

Do you have a 200,000-line code base or a huge document archive that you don't recognize? Understand Anything turns all of this content into a map that you can dive into and ask questions. It works compatible with Claude Code, Codex, Antigravity and Gemini CLI.

## What you get
- You can solve a project you are unfamiliar with within minutes.
- You can instantly produce content with the "Prepare a guide for beginners" command.
- “Where is this feature and how does it work?” You can learn the details by asking:
- You turn your own document and note archive into an interactive question-answer system without needing coding knowledge.

## Just write this and ask:
- What does this project do, how does it work?
- Create an onboarding guide for a beginner.
- What exactly does that file do, what are its dependencies?

## Why is it on the agenda?
Because it is at the center of the "understanding code and information by asking AI" trend. Beyond being a standalone application, it is included as an add-on to the assistants you use (such as Claude Code, Codex, Gemini CLI). The fact that it was starred by more than 4,700 developers in one day is a testament to the intense interest it has received.

## Boundaries · honestly
- It's not magic: the quality of the answers depends on the AI model you use.
- In very large and messy projects, the initial scan may take time.
- You'll need to set up an AI assistant (and often open an account).
