# Open-source AI CRM for WhatsApp

DeskcommCRM is an open-source customer relationship management (CRM) platform developed for businesses that sell via chat. With WhatsApp integration and built-in AI agents, it offers a self-hostable alternative to commercial software with similar functionality (Kommo, Octadesk, Intercom).

- ★ 1,491
- TypeScript
- GitHub Trending · 2026-09-12

## What you get
- Provides automated sales and customer management via WhatsApp.
- Offers full control over your data by hosting it on your own server.
- Allows access to all features without paying monthly fees.

## Installation
**Initiating server setup**

```
curl -fsSL https://raw.githubusercontent.com/melgarafael/DeskcommCRM/main/hostgator-setup-kit/comecar.sh | bash
```

**Completing installation on VPS**

```
git clone https://github.com/melgarafael/DeskcommCRM.git
cd DeskcommCRM
bash hostgator-setup-kit/install.sh
```
