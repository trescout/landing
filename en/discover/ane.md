# AI training in Apple Neural Engine

Developed by Maderix, ANE allows neural network training to be performed on the Apple Neural Engine through private application programming interfaces (private APIs) obtained by reverse engineering. This study makes it possible to directly use Apple hardware in artificial intelligence model training processes.

## Getting started

This project is a research study that aims to train neural networks directly on Apple hardware. By downloading the project files from the official repository on GitHub to your computer, you can examine how the special APIs obtained by reverse engineering are used and conduct your own experiments.
