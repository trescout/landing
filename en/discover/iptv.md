# Watch world television in one center

The iptv-org project, which gathers public television channels around the world in a single center, presents television broadcast over internet protocol (IPTV) lists as an organized dataset. Developed with TypeScript, this open source collection standardizes users' access to publications in different countries.

## What you get

## Getting started
- Official source →
You don't need any installation to use this tool. Copy the link to the project's main playlist, https://iptv-org.github.io/iptv/index.m3u, and start watching by pasting it into the network stream or URL opening section of any video player that supports live streaming.
