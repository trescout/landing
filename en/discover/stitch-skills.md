# Design capabilities for AI agents

Developed by Google Labs, Stitch Skills is an agent skills library designed to work with the Stitch MCP server. Following open standards, this library aims to standardize workflows for coding agents such as Gemini CLI and Cursor.

## What you get
- Standardized workflow between code and design
- Automatic React and React Native component generation
- Extract and manage design systems from code

## Installation
**Installation for Claude Code**

```
npx plugins add google-labs-code/stitch-skills --scope project --target claude-code
```

**Setup for cursor**

```
npx plugins add google-labs-code/stitch-skills --scope workspace --target cursor
```


## Running it
**View help commands**

```
npx plugins --help

npx skills --help
```
