Asynchronous network programming library

Asio is a C++ library developed for asynchronous I/O operations. It provides a portable gateway (network abstraction) for network programming and low-level system tasks.

  • C++

What you get

  • Perform asynchronous input and output operations
  • Establishing a portable network programming infrastructure
  • Managing low-level system tasks

Installation

macOS (Homebrew)
brew install asio

Getting started

Asio is a C++ library. To start using it, you can visit https://think-async.com/ or follow the path doc/index.html in the file you downloaded to access the API documentation and tutorial guides.
