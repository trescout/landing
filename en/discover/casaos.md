# Manage your personal cloud server

CasaOS offers an open source personal cloud system that makes it easy to manage Docker-based applications. This interface, developed with the Go language, allows users to simply manage their servers via a visual panel.

## What you get
- Install Docker applications in one click
- Manage files with a visual interface
- Monitor server resources with widget

## Installation
**installation command**

```
curl -fsSL https://get.casaos.io | sudo bash
```


## Running it
**update command**

```
curl -fsSL https://get.casaos.io/update | sudo bash
```
