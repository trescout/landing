Turn your tablet into Android Auto screen

The headunit-revived project provides an application that allows viewing the Android Auto interface on different screens. This software, developed in Kotlin language, provides an alternative display solution for in-vehicle infotainment systems.

  • ★ 1,484
  • Kotlin
  • GitHub Trending · 2026-06-25

What you get

  • Use your Android tablet or phone as an in-car display
  • Wired connection support via USB
  • Reliable wireless connection with Wireless Helper

Getting started

Download the app to your device via Google Play Store or Amazon Appstore. For wireless connection, it is recommended that you also install the 'Wireless Helper' application on your phone. For detailed installation steps and connection settings, you can review the Wiki section on the GitHub page.
