# AI access from the command line

Developed by Google, gemini-cli is an open-source tool that provides direct access to the Gemini AI model via the terminal. The software allows users to quickly and lightweightly create AI prompts within a command-line environment.

## What you get

- You can inspect and edit your codebases directly from the command line.
- You can generate new applications from images or text documents.
- You can automate your repetitive tasks with command scripts.

## Installation

**Global installation with the npm package manager**

```
npm install -g @google/gemini-cli
```

**Installation via the Homebrew package manager**

```
brew install gemini-cli
```

## Running it

**Direct execution without installation**

```
# Using npx (no installation required)
npx @google/gemini-cli
```
