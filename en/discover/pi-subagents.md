# Asynchronous task management with artificial intelligence

pi-subagents is a TypeScript library developed to manage asynchronous subagent delegation processes on the Pi platform. It makes it easy to distribute complex workloads to sub-agents.

## What you get
- It distributes the workload to sub-agents.
- Provides asynchronous and parallel execution.
- It works fully integrated with the Pi platform.

## How to install, how to use?
**install with pi**

```
pi install npm:pi-subagents
```

**Run a sub-agent**

```
/run <ajan> [görev]
```

**Run agents in parallel**

```
/parallel ajan1 "görev1" -> ajan2 "görev2"
```
