# Manage your career with artificial intelligence

Using the Claude Code infrastructure, career-ops automates artificial intelligence-supported job search processes with 14 different skill modes. The system centralizes functions such as batch management and resume creation through a Go-based control panel.

- ★ 63,452
- JavaScript
- GitHub Trending · 2026-06-07

## What you get
- Filter job postings by scoring them in 10 different dimensions
- Creating an ATS compatible resume specific to the job description
- Mass job application process management via terminal

## Installation
**Basic Setup**

```
git clone https://github.com/santifer/career-ops.git
cd career-ops && npm install
npx playwright install chromium
```

**System Control**

```
npm run doctor
```


## Running it
**Launch with Claude**

```
claude
```
