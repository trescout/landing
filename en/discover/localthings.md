# Control Samsung home appliances from the local network

mbillow/localthings allows you to control Samsung home appliances over your local network using the Home Assistant smart home management platform, without requiring a cloud account. Developed in Python, this tool brings control over your devices directly to your local network.

## What you get

- Requires no cloud account or internet connection
- Communicates directly with devices over the local network
- Fully compatible with the Home Assistant home automation platform

## Getting started

You can download it by searching for LocalThings in the Integrations section using the community add-on store called HACS. Alternatively, you can copy the custom_components folder to your Home Assistant configuration directory and then restart the Home Assistant software.
