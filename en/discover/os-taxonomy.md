# Connection map of primary school learning topics

withmarbleapp/os-taxonomy is a library developed in JavaScript that organizes operating system classifications. It allows software developers to define different operating system data in a standard structure.

## What you get

- Explore over 1,500 micro-topics at the primary school level with age ranges and success criteria.
- Create step-by-step learning paths by tracking over 3,200 prerequisite relationships between topics.
- Gain direct access to pedagogical approaches and sample in-class activities in science and mathematics.

**Data validation and running tests**
