# Open source digital music server

Music Assistant is an open-source media library manager that combines different digital streaming services and connected speakers into a single interface. This Python-based server software enables the creation of a central music management system on constantly operating devices.

- ★ 3,018
- GitHub Trending · 2026-06-13

## What you get
- Combines different digital broadcast services in one interface
- Allows you to centrally control all connected speakers
- It provides automation support by working fully integrated with Home Assistant

## Installation
**docker**

```
docker run --network host --privileged -v ma-data:/data ghcr.io/music-assistant/server
```
