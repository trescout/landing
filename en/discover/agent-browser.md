# Browser automation tool for AI agents

Developed by Vercel Labs, agent-browser is a command-line interface (CLI) that provides browser automation for AI agents. Written in Rust, this tool allows reading pages as an accessibility tree and interacting with web elements via the command line.

## What you get

- Reads pages as text in the form of an accessibility tree
- Interacts with web elements via the command line
- Manages the browser command by command with a background server

## Installation

**General Setup**

```
npm install -g agent-browser
agent-browser install           # download Chrome for Testing (first time only)
```

## Running it

**Quick Start**

```
agent-browser open example.com
```
