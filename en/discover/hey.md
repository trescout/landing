# Load testing tool for web servers

Developed in Go, hey is a load testing tool used to measure the performance of web servers. It offers a modern and fast alternative to the classic benchmarking tool ApacheBench (ab).

- ★ 20,370
- Go
- GitHub Trending · 2026-09-29

## What you get
- Easily sends request loads to web applications.
- Determines the number of concurrent workers and the total number of requests.
- Supports HTTP/2 endpoints and reports the results.
