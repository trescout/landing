# Graph-based cyber threat visualization

Flowsint offers a visual, flexible and extensible graph-based investigation platform for cybersecurity analysts and researchers. Developed with TypeScript, this tool makes it easier to visualize and analyze complex data sets.

## What you get

- Analyze relationships between entities in a visual graph interface
- Process IP, domain and social media data with automatic enrichers
- Ensuring high confidentiality by storing all data on the local machine

## Installation

**Setup commands**

```
git clone https://github.com/reconurge/flowsint.git
cd flowsint
make prod
```

## Running it

**Starting the development environment**

```
make dev
```
