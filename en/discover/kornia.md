# Computer vision for artificial intelligence

Kornia is a differentiable computer vision library developed for spatial AI applications. Running on the PyTorch deep learning framework, this tool enables the integration of image processing and geometric vision algorithms into artificial intelligence workflows.

## What you get

- It accelerates operations by running image processing and geometric computations on the graphics processing unit (GPU).
- Thanks to its differentiable structure, it connects directly to model trainings built with the PyTorch deep learning framework.
- It offers data augmentation, edge detection, and ready-made visual analysis models under a single roof.
