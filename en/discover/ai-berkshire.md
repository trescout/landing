# Value investment research with artificial intelligence

AI-berkshire is a value investing research framework that implements the methodologies of investors such as Warren Buffett and Charlie Munger, using the Claude Code infrastructure. The system analyzes financial data with its multi-agent structure and conducts adversarial reviews.

## What you get
- Structured analysis with the methodology of four investment masters
- Oppositional in-depth investigation with multiple AI agents
- High accuracy and error checking in numerical data

## Installation
**Claude Code installation**

```
npm install -g @anthropic-ai/claude-code
```

**Copy the toolset**

```
git clone https://github.com/xbtlin/ai-berkshire.git

# 复制 skills 到 Claude Code 全局 commands 目录
cp ai-berkshire/skills/*.md ~/.claude/commands/
```
