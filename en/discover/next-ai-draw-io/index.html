Automatic diagram creation with artificial intelligence

This Next.js-based application combines diagramming tool draw.io with generative AI capabilities. Users can create visual diagrams through natural language commands and edit their existing diagrams with artificial intelligence support.

  • TypeScript
  • GitHub Trending · 2026-07-12

Updates

  • August 2, 2026: Stars 33,359 → 33,999, latest release v0.4.16 (May 21, 2026).

What you get

  • Draw professional diagrams with natural language commands
  • Convert existing images and PDF files into diagrams
  • Quickly visualize cloud architecture and flowcharts

Installation

local installation
git clone https://github.com/DayuanJiang/next-ai-draw-io
cd next-ai-draw-io
npm install
cp env.example .env.local

Running it

Starting the development server
npm run dev
