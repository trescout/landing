# Watching videos without ads and tracking

Invidious is an open source interface developed as an alternative to the YouTube platform. It offers users a video watching experience that does not contain ads and does not track data.

- ★ 22,400
- Crystal
- GitHub Trending · 2026-08-02

## What you get
- Watch YouTube videos without ads and data tracking
- Subscribe to channels without needing a Google account
- Play audio playback in the background with low data usage

## Installation
**Get the repository and compose file**

```
git clone --depth 1 https://github.com/iv-org/invidious.git && cd invidious
```


## Running it
**start**

```
docker compose up -d
```
