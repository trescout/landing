## What does this tool do?

Invidious provides an alternative interface to YouTube and does not use the official YouTube APIs. You can choose a public instance or host your own by following the separate installation documentation. The project is licensed under AGPL-3.0 and provides a documented developer API.

## Who it is for

People who want an alternative YouTube interface, subscriptions independent from Google or a self-hosted instance.

## What not to expect

People who specifically need a solution built on the official YouTube APIs.

## Highlights

- Lists use without ads or tracking and without requiring JavaScript.
- Supports subscriptions independent from Google.
- Provides data import and export options.
- Includes a documented developer API.

## First-use flow

1. Choose a public Invidious instance if you only want to use the service.
2. If you plan to self-host it, read the official installation documentation first.
3. For the current Docker path, prepare PostgreSQL and Invidious Companion.
4. Plan for at least 20 GB of disk space and 2 GB of free RAM for your own installation.
