# Open-Source Alternative Interface for YouTube

Invidious is an open-source alternative interface for YouTube. The official README lists use without ads or tracking, no JavaScript requirement, subscriptions independent from Google, and data import and export.

## Installation
**Clone the repository**

```
git clone https://github.com/iv-org/invidious.git
```

**Enter the project directory**

```
cd invidious
```


## Running it
**Start Docker Compose**

```
docker compose up -d
```


## What does this tool do?
Invidious provides an alternative interface to YouTube and does not use the official YouTube APIs. You can choose a public instance or host your own by following the separate installation documentation. The project is licensed under AGPL-3.0 and provides a documented developer API.

## Who it is for
People who want an alternative YouTube interface, subscriptions independent from Google or a self-hosted instance.

## What not to expect
People who specifically need a solution built on the official YouTube APIs.

## Highlights
- Lists use without ads or tracking and without requiring JavaScript.
- Supports subscriptions independent from Google.
- Provides data import and export options.
- Includes a documented developer API.

## First-use flow
- Choose a public Invidious instance if you only want to use the service.
- If you plan to self-host it, read the official installation documentation first.
- For the current Docker path, prepare PostgreSQL and Invidious Companion.
- Plan for at least 20 GB of disk space and 2 GB of free RAM for your own installation.
