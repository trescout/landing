# Play Banjo Kazooie on modern systems

Lighthouse is a code coverage tool developed in C language and designed for low-level systems. It provides data to developers for debugging and performance optimization by analyzing which code blocks are run during the software's testing processes.

## Getting started

Download the Lighthouse version from the official GitHub releases page and extract the files into a folder. After verifying your own game file (ROM), select your game file by running lighthouse.exe on Windows, lighthouse.appimage on Linux, or lighthouse on macOS.
