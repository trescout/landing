# Duck robot powered by artificial intelligence models

Developed by Pollen Robotics, microduck is a 25-centimeter bipedal duck robot project powered by the Rockchip RK3566 processor. Written in Rust, the software manages fifteen servos via neural policies to handle the robot's movement and control processes.

## What you get

- Runs the entire control mechanism of the bipedal robot, which is 25 centimeters in size.
- Manages walking, rolling, object picking, and getting up movements thanks to artificial intelligence policies.
- With its architecture developed in the Rust programming language, it provides motor control and camera streaming via the live streaming protocol WebRTC.
