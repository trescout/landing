# Integrate DeepSeek models into your tools

shared on GitHub, awesome-deepseek-agent is a resource collection that lists artificial intelligence agents (AI agents) developed with DeepSeek models and tools in this field. It brings together projects and integrations that help developers build autonomous systems using the DeepSeek infrastructure.

## What you get

- Access installation guides for popular AI agents
- Possibility to use DeepSeek models in coding assistants
- Configuration support for autonomous systems and terminal-based vehicles

## Getting started

First you need to get an API key through DeepSeek Platform. Then, review the table on the GitHub page and click on the guide link next to the tool you want to use. Each guide details the steps you need to install your chosen tool and configure it with DeepSeek models.
