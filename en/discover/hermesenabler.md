# Enable Hermès watch faces for Apple Watch

pookjw/HermesEnabler is a software that makes Hermès watch faces available on all Apple Watch devices with supported watchOS versions. This tool, which can be compiled with Xcode on macOS or installed using app sideloading tools like Sideloadly, requires an Apple Watch paired with an iPhone.

## What you get

- using custom watch faces on supported watches
- supporting macOS and Windows operating systems
- providing step-by-step installation via the watch app

## Getting started

You can install it on macOS using the Sideloadly app sideloading tool or Xcode developer software. On Windows, you can use the community tool WatchBridge. You can download the installation files from the official GitHub page and follow the guide.
