# Run local AI models on your computer

Magnitude is an open-source inference server that integrates with existing AI agents and allows you to run local models suited to your hardware. It works compatibly with coding assistants like Cline and various open-source models, making it easy to leverage local computing power.

## What you get

- Automatically identifies the best local models for your hardware
- Works completely offline without an internet connection
- Integrates with AI assistants to eliminate token costs

## Installation

**Install the CLI tool and start the setup**

```
npm i -g @magnitudedev/cli
magnitude setup
```
