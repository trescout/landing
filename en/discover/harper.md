# Privacy-oriented offline grammar checker

Harper offers an offline and privacy-oriented grammar checker developed with the Rust language. This open source tool aims to create a high-performance and safe alternative in text analysis processes.

## What you get
- Quickly checks text in milliseconds
- Protects privacy by processing your data locally
- Offers high performance with low memory usage

**macOS (Homebrew)**

```
brew install harper
```
