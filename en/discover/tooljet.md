# Develop enterprise applications without writing code

ToolJet is an open source application creation platform for developing in-house tools, dashboards and artificial intelligence agents. This JavaScript-based infrastructure enables businesses to digitize complex workflows by reducing the need to write code.

## What you get
- Fast visual interface design with drag and drop method
- Easy integration with database, API and cloud services
- Flexible workflows with JavaScript and Python support

## Installation
**Local installation with Docker**

```
docker run \
  --name tooljet \
  --restart unless-stopped \
  -p 80:80 \
  --platform linux/amd64 \
  -v tooljet_data:/var/lib/postgresql/13/main \
  tooljet/try:ee-lts-latest
```
