# ODS

Osmantic/ODS is an open-source platform that transforms personal computers into AI servers capable of tasks such as large language model (LLM) inference, audio processing, and image generation. The software enables the creation of retrieval-augmented generation (RAG) and intelligent agent workflows running on local hardware.
