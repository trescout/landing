# Manage your own media archive

LunaTV is a project developed with the TypeScript language that offers an open-source media viewing interface. This software, which is closed to commercial use, allows users to watch their own media content in an organized structure.

- ★ 10,021
- TypeScript
- GitHub Trending · 2026-09-08

## What you get
- Opportunity to watch personal media content in an organized interface
- Syncing watch history and favorites across devices
- Portable viewing experience that does not require installation via browser

## Getting started
This tool runs with software containerization technology called Docker. For installation, you can go to the 'Deployment' section on the project's GitHub page to use Docker Compose files or perform a one-click installation via cloud platforms like Zeabur. Keep in mind that the project comes with an empty interface and you need to add your own media sources.
