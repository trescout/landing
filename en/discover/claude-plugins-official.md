# Plugins for Claude coding assistant

Anthropic offers an official directory that collects high-quality plugins developed for Claude Code in a single center. This Python-based structure allows developers to share and discover tools prepared for coding assistants in a standard format.

## Getting started

You can browse available plugins using the '/plugin > Discover' menu in the Claude Code interface. To install plugins, simply use the command '/plugin install {plugin-name}@claude-plugins-official' in the Claude Code command line.
