# Generate long videos consistently

Developed by Meituan, LongCat-Video is a video generation framework used to consistently create long videos. This tool enables the production of longer-duration and high-quality video content while maintaining visual consistency.

- ★ 8,892
- Python
- GitHub Trending · 2026-10-04

## What you get

- You can generate long-duration new content from text, images, or existing videos.
- You can get outputs without color shifting and quality degradation in videos lasting minutes.
- You can create audio-aligned character animations using audio files.

## Installation

**Downloading the code repository to the computer**

```
git clone --single-branch --branch main https://github.com/meituan-longcat/LongCat-Video
cd LongCat-Video
```

**Downloading model weights**

```
pip install "huggingface_hub[cli]"
huggingface-cli download meituan-longcat/LongCat-Video --local-dir ./weights/LongCat-Video
huggingface-cli download meituan-longcat/LongCat-Video-Avatar --local-dir ./weights/LongCat-Video-Avatar
huggingface-cli download meituan-longcat/LongCat-Video-Avatar-1.5 --local-dir ./weights/LongCat-Video-Avatar-1.5
```
