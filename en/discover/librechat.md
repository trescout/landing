# Bring all AI models together in a single interface

LibreChat is an open-source chat platform that combines different AI models and tools into a single interface. This software, which users can host on their own servers, offers a personalized AI experience with features such as model switching and multi-user authentication.

## What you get

- Manage different AI models from a single dashboard
- Set up a secure and private chat environment on your own server
- Use advanced tools such as file processing and web searching
