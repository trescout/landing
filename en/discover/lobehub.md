# Operations management with artificial intelligence agents

LobeHub enables creating an AI team operations that works 24 hours a day, 7 days a week, by managing artificial intelligence agents through recruitment, scheduling and reporting processes. The platform offers an administrative interface that automates workflows by organizing different agents from a single center.

## What you get
- Managing all artificial intelligence agents from a single center
- Inter-agent cooperation and task distribution
- Support for over 10,000 tools and plugins

## Installation
**macOS desktop (Homebrew)**

```
brew install --cask lobehub
```

**Docker image**

```
docker pull lobehub/lobehub
```


## Running it
**Launch with Docker**

```
docker compose up -d
```
