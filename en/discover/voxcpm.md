## Installation

**Install via PyPI**

```
pip install voxcpm
```

## Running it

**Generate speech from text**

```
voxcpm design --text "VoxCPM2 brings studio-quality multilingual speech synthesis." --output out.wav
```

## What does it offer?

- Multilingual and natural speech production.
- Creative and original sound design.
- High accuracy voice cloning.

## Responsibility note
