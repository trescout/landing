# Unified workspace for AI agents

holaOS is an open source workspace that combines different artificial intelligence agents (Claude Code, Codex) with your tools, applications and files over a common memory. With over 100 integrations and Model Link Protocol (MCP) support, it enables users to manage their own models (BYOK) or built-in models in a single interface.

## What you get

- It runs different agents such as Claude Code and Codex in a single interface with shared memory.
- One-click connects to more than 50 popular business tools like Gmail, Notion, and Slack.
- You can use built-in AI models or add your own API keys.

## Installation

**Quick install command**

```
curl -fsSL https://raw.githubusercontent.com/holaboss-ai/holaOS/refs/heads/main/scripts/install.sh | bash -s -- --launch
```

## Running it

**Starting the development environment**

```
npm run desktop:dev
```
