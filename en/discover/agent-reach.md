# Give your AI agent internet capability

Agent-Reach is a command line interface (CLI) tool that gives AI agents the ability to scan the entire internet and read content. It provides direct access to pull data from platforms like Twitter, Reddit, and GitHub without paying any application programming interface (API) fees.

## What you get
- It provides free access to platforms such as Twitter, Reddit and GitHub.
- It reads YouTube videos and RSS feeds directly.
- It eliminates complex installation processes with automatic configuration.

## Installation
**Python (pip)**

```
pip install agent-reach
```


## Running it
**Set up channels**

```
agent-reach install
```

**Status check**

```
agent-reach doctor
```
