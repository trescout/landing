# Artificial intelligence supported Japanese login system

Developed with the Rust language, Karukan is a Japanese input method system (Japanese Input Method System) that uses a neural kana-kanji conversion engine for Linux and macOS operating systems. The software goes beyond traditional methods and offers an artificial intelligence-based approach to text conversion processes.

## What you get

- GPT-2 based neural kana-kanji conversion
- Real-time live text conversion as you type
- smart prediction engine that learns user choices

## Getting started

To use it with fcitx5 on Linux, you must follow the installation steps in the README files in the karukan-fcitx5 folder, and for macOS in the karukan-macos folder. Since model files will be automatically downloaded from Hugging Face on first use, the initial conversion process may take some time.
