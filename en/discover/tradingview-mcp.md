# AI integration for TradingView

TradingView-mcp connects Claude Code with the TradingView desktop application, allowing you to automate chart analysis processes. This integration allows users to personalize technical analysis workflows through AI-powered model context (Model Context Protocol).

## What you get

- Pine Script coding and debugging with artificial intelligence
- Automatic drawing and analysis management on the chart
- Control price alerts and symbols by command

## Installation

**Downloading files and installation**

```
git clone https://github.com/tradesdontlie/tradingview-mcp.git
cd tradingview-mcp
npm install
```

**Launching on macOS**

```
./scripts/launch_tv_debug_mac.sh
```

## Running it

**Direct use via CLI**

```
# Install globally (optional)
npm link

# Or run directly
node src/cli/index.js <command>
```
