# Artificial intelligence for long-term missions

GLM-5 offers a framework that aims to move software development processes from vibe coding to structured agent-based engineering. This system standardizes software development workflows through artificial intelligence agents (AI agents) that can manage complex tasks autonomously.

- Uninterrupted long-term operation with 1 million token capacity
- Autonomous planning in complex software engineering tasks
- Balance of performance and speed with adjustable thinking effort

## Installation
**Set up presentation infrastructure with vLLM**

```
pip install vllm
```

**Download model weights with Hugging Face CLI**

```
hf download zai-org/GLM-5.2-FP8
```


## Running it
**start vLLM server**

```
vllm serve zai-org/GLM-5.2-FP8
```
