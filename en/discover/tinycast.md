# Lightweight application launcher for macOS

Tinycast is a lightweight application launcher, shortcut manager, and clipboard history tool developed for the macOS operating system. Written in Swift, this native software aims to accelerate desktop workflows by using system resources efficiently.

- ★ 6,290
- Swift
- GitHub Trending · 2026-09-18

## What you get
- Native software that uses system resources efficiently
- Support for running Raycast extensions directly
- Clipboard history and text snippet management

## Installation
**Adding the repository to the system**

```
brew trust --tap abue-ammar/tinycast   # required for third-party taps
brew tap abue-ammar/tinycast
```


## If you don't write code
To activate AI features in Tinycast, define your own API key or installed AI account credentials via the Settings menu. After this process, you can start chats directly from the palette and perform quick operations such as grammar correction, summarization, or translation on selected text.
