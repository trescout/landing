# Concurrent browser for AI agents

Ego-lite is a browser that allows users and artificial intelligence agents to work simultaneously. This JavaScript-based tool aims to carry out human and machine interaction in parallel in the same browser environment.

- ★ 11,904
- JavaScript
- GitHub Trending · 2026-07-24

## What you get
- Agents and users run in the same browser without conflict
- Protects sessions by importing Chrome data
- Faster task completion with JavaScript-based structure

## Installation
**Adding skills**

```
npx skills add citrolabs/ego-lite
```


## Running it
**Start a task**

```
ego-browser follow @ego_agent on x.com for me
```
