# Mobile device automation with artificial intelligence

Mobile-mcp is a Model Context Protocol server that performs automation and web scraping operations on mobile devices and simulators. This tool enables artificial intelligence models to interact directly with iOS and Android platforms to execute tasks.

- ★ 7,665
- TypeScript
- GitHub Trending · 2026-09-27

## What you get
- Performing application testing on iOS and Android devices
- automatically scanning screen elements and extracting structured data
- managing emulators and simulators through a single interface

## Installation

