# Professional operating layer for Hermes Agent

Developed for Hermes Agent, oh-my-hermes offers coding intelligence, a long-term memory system, and model-driven workflow packages in a single plugin. This tool, which optimizes software development processes, provides developers with a comprehensive working environment through its Python-based structure.

## What you get
- Provides a working environment that optimizes software development processes.
- Keeps project history organized with a long-term memory system.
- Adds coding intelligence and model-driven workflows.

## Installation
**Installation for macOS and Linux**

```
curl -fsSL https://raw.githubusercontent.com/rlaope/oh-my-hermes/main/install.sh | sh
```

**Installation with Homebrew package manager**

```
brew install rlaope/tap/omh
```


## Running it
**Post-installation configuration**

```
omh setup
```
