# SwiftUI expertise for your AI assistant

SwiftUI-Agent-Skill offers specialized skill packages (skills) for AI models tailored to the UI development tool SwiftUI. This resource helps AI coding assistants like Claude Code and Codex build SwiftUI components more consistently and quickly.

## What you get

- Allows AI to audit performance and accessibility bugs in code written with Apple's UI framework SwiftUI.
- Prevents large language models from using legacy application programming interfaces (APIs) and avoids screen reader issues.
- Easily integrates into coding assistants like Claude Code and Codex to provide modern code standards.

## Installation

**Node environment via package manager Homebrew**

```
brew install node
```

**SwiftUI Pro skill to AI assista**

```
npx skills add https://github.com/twostraws/swiftui-agent-skill --skill swiftui-pro
```
