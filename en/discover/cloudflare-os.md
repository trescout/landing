# A custom AI workspace for your company

Cloudflare introduced an agent workspace that supports document generation, application development, and running AI agents with internal data. Running on Cloudflare Workers, this platform provides a development environment integrated with enterprise systems.

## What you get
- You can produce presentations or small personal applications by giving commands to AI agents.
- You can prevent security leaks by running the created applications in isolated environments.
- Thanks to the security layer, you can audit and approve the actions performed by the agents.
