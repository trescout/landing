# Create custom jquery builds

jQuery is a JavaScript library that makes it easy to create interactive elements on web pages. It offers tools that simplify document object model (DOM) manipulation and event management for developers.

## What you get

- Build your own custom jquery library.
- Reduce the size by removing modules you do not need.
- Generate all release files in bulk.

## Installation

**Install dependencies and build the project**

```
cd jquery
npm install
npm run build
```

**Generate all release files**

```
npm run build:all
```
