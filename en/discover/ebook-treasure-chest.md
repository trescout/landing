# Digital e-book library in various categories

jbiaojerry/ebook-treasure-chest is a digital library project that brings together e-book download links in various categories. The project aims to provide access to content within popular reading applications (帆书, 微信读书, 京东读书, 喜马拉雅).

## What you get

- Get single-point access to download links for thousands of e-books.
- You can download books in three different format options such as epub, mobi, and azw3.
- Thanks to the search interface, you can instantly find works by title, author, or category.

## Getting started

You do not need a command line to benefit from the project. You can visit the official web page hosted on the code hosting platform GitHub and type the book name or author in the search box. If you wish, you can review the category files and access the download link of the e-book you want.
