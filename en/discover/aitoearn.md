# Revenue management with artificial intelligence

AiToEarn is a TypeScript-based platform that enables users to manage their monetization processes through AI-powered automations. The project offers an open infrastructure to developers by combining autonomous task execution and artificial intelligence-based earning models.

- ★ 24,551
- TypeScript
- GitHub Trending · 2026-06-08

## What you get
- It manages artificial intelligence-supported content creation and automatic publishing processes.
- It enables generating income from content with CPS, CPE and CPM models.
- It offers simultaneous interaction and follower management on multiple social media platforms.

## Installation
**Quick Setup with Docker**

```
git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn
docker compose up -d
```

**OpenClaw Plugin Installation**

```
npx -y @aitoearn/openclaw-plugin-cli
```


## Running it
**Launching with Docker**

```
docker compose up -d
```
