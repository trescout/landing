# Manage cloud native infrastructures

Meshery is a service mesh management platform designed for the management of cloud native infrastructures. The platform enables configuration, lifecycle management and performance analysis processes in complex cloud environments to be carried out from a single center.

## What you get
- Central management of Kubernetes-based infrastructure and applications
- Visual design opportunity without dealing with complex YAML files
- Consistent operation across multiple cloud providers and clusters

## Installation
**Bash Script**

```
curl -L https://meshery.io/install | bash -
```


## Running it
**CLI**

```
mesheryctl system start
```
