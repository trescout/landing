# Markdown knowledge base desktop application

Tolaria is a desktop application developed for managing Markdown-based knowledge bases. Written in TypeScript, this tool makes it easy to keep personal documentation and notes systems organized.

- ★ 19,403
- TypeScript
- GitHub Trending · 2026-06-08

## What you get
- Provides portable note management with markdown files.
- Offers full version control with Git integration.
- Protects data ownership with offline work support.

## Installation
**Dependencies for Arch/Manjaro**

```
sudo pacman -S --needed webkit2gtk-4.1 base-devel curl wget file openssl \
    appmenu-gtk-module libappindicator-gtk3 librsvg
```

**Dependencies for Debian/Ubuntu**

```
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
    libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev \
    libsoup-3.0-dev patchelf
```


## Running it
**Starting the development environment**

```
pnpm install
pnpm dev
```

**Run the desktop app**

```
pnpm tauri dev
```
