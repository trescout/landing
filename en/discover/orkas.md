# An AI team running on your desktop

Orkas is an open-source AI team that runs on desktop computers and turns goals into to-do lists. Coordinating sixteen built-in expert agents and various coding models, this application provides a local-first workspace on macOS and Windows.

## What you get

- Executes research, content, design, and coding tasks with sixteen built-in expert agents.
- Remembers your projects, rules, and files, preventing you from starting from scratch every time.
- Advances your workflows regularly with scheduled automations and task lists.

## Installation

**Clone the project repository and run it**

```
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```
