# Artificial intelligence interface that manages your computer

Developed by ByteDance, UI-TARS is an open source agent infrastructure that integrates multimodal AI models with desktop interfaces. This system enables the creation of agents (AI agents) that autonomously perform tasks on the computer by processing visual data.

- Autonomously perform desktop and browser tasks
- Human-like workflow by processing visual data
- Full integration with multi-modal AI models

## Installation
**Global installation**

```
npm install @agent-tars/cli@latest -g
```

**Direct operation**

```
npx @agent-tars/cli@latest
```


## Running it
**Initialize with model provider**

```
agent-tars --provider volcengine --model doubao-1-5-thinking-vision-pro-250428 --apiKey your-api-key
```


## If you don't write code
Describe a complex task you want me to perform on my computer or browser. For example, I might ask you to go to a specific website and enter data or manage a flight booking process. Please analyze the visual interface and complete the steps autonomously.
