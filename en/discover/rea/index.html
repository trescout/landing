Reverse engineering with artificial intelligence

Rea is an AI agent-based reverse engineering tool that analyzes everything from application behavior to native binaries. Developed in TypeScript, this software aims to decode the working logic of complex systems through automated processes.

What you get

  • You can decipher the internal logic of desktop or web applications whose source code you do not have access to, with AI support.
  • By integrating with reverse engineering software Hopper and Ghidra, you can securely inspect binary system files on your local computer.
  • You can learn step-by-step with evidence how a software feature you like works and adapt it to your own project.

Installation

Starting the setup wizard
npx rea-agents setup
Global installation with the npm package manager
npm install --global rea-agents
rea setup

Running it

System check and sample application analysis
npx -y rea-agents@latest doctor
npx -y rea-agents@latest analyze /Applications/Notes.app
