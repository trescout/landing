# AI-powered code review for Claude Code

Developed by OpenAI, the Codex plugin is used on Claude Code to automate code review processes and provide task delegation. This tool allows the integration of different artificial intelligence models (large language models) in software development workflows.

## What you get
- Automates code review processes
- Delegates tasks to the Codex model
- Manages long-running jobs in the background

## Installation
**Install the Codex pack**

```
npm install -g @openai/codex
```


## Running it
**Start first review**

```
/codex:review
```


## If you don't write code
Start a review of my existing code using the Codex plugin within Claude Code and report the findings. If there's a complex task, delegate it to Codex with the /codex:rescue command and run it in the background, allowing me to track progress with /codex:status.
