# Comprehensive PDF editing on your own server

Stirling-PDF is an open source document processing tool that allows users to edit PDF files on any device. Developed with TypeScript, this application centralizes document management processes by running on local servers.

- ★ 89,027
- TypeScript
- GitHub Trending · 2026-06-23

## What you get
- More than 50 different PDF editing tools
- Local processing of your data without sending it to external services
- Easy access via browser or desktop

## Installation
****

```
docker run -d --name stirling-pdf -p 127.0.0.1:8080:8080 -v ./stirling-data:/configs --restart unless-stopped docker.stirlingpdf.com/stirlingtools/stirling-pdf:latest
```


## Running it
****

```
http://localhost:8080
```
