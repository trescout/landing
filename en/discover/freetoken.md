# Large artificial intelligence models on personal computers

FlashML-org/FreeToken is a library that enables running data center-scale large artificial intelligence models quickly and efficiently on personal computers. It allows users to run Mixture of Experts (MoE) models with over 290 billion parameters at interactive speeds on standard hardware.

## What you get

- Combines used hardware resources into a single artificial intelligence infrastructure.
- Provides dynamic resource management between GPU memory VRAM and main memory.
- Runs large Mixture of Experts architecture MoE models on local devices at interactive speeds.
