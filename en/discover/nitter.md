## What you get
- Displays Twitter content without running JavaScript
- Hides user IP address and browser fingerprint
- It is much faster and lighter than the standard Twitter interface

## Installation
**Installation with Docker**

```
docker run -v $(pwd)/nitter.conf:/src/nitter.conf -d --network host zedeus/nitter:latest
```

**Launching with Docker Compose**

```
docker-compose up -d
```
