# Desktop control tool for AI agents

Developed by Vercel Labs, agent-desktop is a command-line interface (CLI) that enables AI agents to read and manage desktop applications via the operating system's accessibility tree. Written in Rust, this tool aims to enhance the computer use capabilities of agents.

## What you get

- Reads desktop applications via the operating system accessibility tree
- Interacts with elements without requiring pixel matching
- Generates fast and structured responses in JSON format

## Installation

**Install with package manager**

```
npm install -g agent-desktop
agent-desktop version
```

**Add skill**

```
npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop
```
