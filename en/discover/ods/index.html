Turn your PC into a local AI inference and agent server

Open-source Osmantic/ODS equips personal workstations with local LLM inference, vector-powered RAG pipelines, and autonomous agent orchestration without cloud dependencies.

  • Python

Updates

What you get

  • Complete privacy and local execution: Run AI models strictly on local GPUs and CPUs with zero telemetry or remote cloud exposure.
  • Built-in Retrieval-Augmented Generation (RAG): Index and semantically query private notes, enterprise documentation, and code repositories.
  • Multimodal capability suite: Combines LLM generation, Whisper audio transcription, speech synthesis, and image creation in one engine.
  • OpenAI-compatible local gateway: Seamlessly redirect existing AI tools and developer frameworks to your local machine via API parity.
  • Autonomous agent workflows: Orchestrate multi-step task chains equipped with local tool access and autonomous reasoning loops.

Installation

Clone repository and install package
git clone https://github.com/Osmantic/ODS.git
cd ODS
pip install -e .

Running it

Start local AI server process
python -m ods.server --port 8000
# Web paneline http://localhost:8000 adresinden erişin

Technical architecture and working principle

Osmantic/ODS operates a modular micro-service architecture coordinating local inference and vector indexing:

  • Local inference engine (llama.cpp & vLLM): Loads GGUF and GPU weight formats with minimal memory overhead and optimized quantization.
  • Embedded vector store: Lightweight vector storage powered by ChromaDB and SQLite for fast chunking and document retrieval.
  • Async task queue and state machine: Orchestrates multi-turn reasoning loops and native tool-calling execution states.

Local RAG workflows and private agent pipelines

ODS allows organizations to deploy powerful AI pipelines while preserving absolute data sovereignty:

  • Confidential document intelligence: Query proprietary contracts and financial spreadsheets securely via local RAG without cloud risks.
  • Private code assistant integration: Index enterprise repositories to drive local code completions in editors like VS Code and Cursor.
  • Autonomous background processing: Schedule background agent tasks that inspect, summarize, and convert local filesystem datasets.

Frequently asked questions

  • Does it operate completely offline in air-gapped setups? Yes. Once model weights are locally downloaded, ODS operates in completely offline, air-gapped enterprise environments.
  • Which model architectures and formats are supported? Supports GGUF-quantized models (Llama 3, Mistral, Qwen, DeepSeek) as well as unquantized HuggingFace formats.
  • Does ODS include a browser interface? Yes. It features an integrated web dashboard to manage models, upload documents, and interact with private chat agents.
  • Can it execute on CPU hardware without a dedicated GPU? Yes. Powered by llama.cpp, ODS leverages AVX2/AVX-512 CPU vector instructions for performant CPU inference.
