# Large language models educational roadmap

mlabonne/llm-course is a comprehensive educational resource containing roadmaps and Colab notebooks for those looking to enter the field of large language models (LLMs). This project offers a curriculum that guides learners from foundational to advanced levels of AI models.

- ★ 84,301
- GitHub Trending · 2026-10-19

## What you get

- Understanding the architecture of language models starting from foundational mathematics and artificial neural networks
- Optimizing open-source models through fine-tuning and quantization
- Running experiments directly without installation via pre-configured Google Colab cloud notebooks

## Getting started

You do not need to install software on your computer to use this project. You can explore the topics on the GitHub repository or the DeepWiki documentation page and click on the Google Colab link of the section that interests you to run the exercises directly in your browser.
