# Web interface for Pi coding agent

Pi-web offers an improved web-based user interface (web UI) for the Pi coding agent. This tool, written in TypeScript language, makes it possible to manage coding processes through a visual interface.

## What you get

- Visually scan past coding sessions
- Preview files via browser
- Manage model and capability settings from the interface

## Installation

**Quick start-up without installation**

```

```

**Upload globally**

```

```
