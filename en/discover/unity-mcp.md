# Unity management with artificial intelligence

Unity MCP provides a bridge between large language models and the Unity editor, allowing asset management, scene control and code editing processes to be automated. This tool, which works through the Model Server Protocol (Model Context Protocol), allows artificial intelligence assistants to directly intervene in game development workflows.

## Getting started
- Official source →
Open your Unity project and go to the Package Manager window. Click 'Add package from git URL' and paste the address https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main. After the installation is completed, go to the 'MCP for Unity' tab under the Window menu and complete the configuration settings.
