# Kubernetes the Hard Way

Prepared by Kelsey Hightower, Kubernetes the Hard Way is a guide that teaches how to set up the container management platform Kubernetes from scratch without using any automation scripts. This work provides a technical training resource for users who want to understand the core components and operating principles of the system through manual configuration processes.
