# Save money by shortening AI responses

Caveman is a capability package developed for Claude Code that reduces token consumption by 65 percent by simplifying the language use of the artificial intelligence model. This tool aims to reduce processing costs by reducing complex commands to a primitive language structure.

- ★ 97,574
- JavaScript
- GitHub Trending · 2026-07-03

## What you get
- Saves up to 65% tokens on AI responses.
- Eliminates unnecessary words without sacrificing technical accuracy.
- It reduces transaction costs and increases response speed.

## Installation
**Setup for macOS, Linux and WSL**

```
curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.sh | bash
```

**installation for windows**

```
irm https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.ps1 | iex
```


## Running it
**Activate the mode**

```
/caveman
```


## If you don't write code
From now on, give your answers in Caveman mode. Remove unnecessary filler words, keep only the concise information and technical details. Compose your answers in short, concise and fragmented sentences; but continue to convey complete and precise code blocks, commands and error messages.
