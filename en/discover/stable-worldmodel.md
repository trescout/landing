# Accelerate World Model Research

stable-worldmodel; It is a platform that ensures that research on 'world models' is repeatable and comparable. It particularly focuses on research and evaluation processes.

## What does it do?
- Making research reproducible.
- Providing a standard assessment environment.
- Not an end user tool, but a direct solution for research.

## How to install, how to use?
**Install from PyPI (all plugins)**

```
pip install 'stable-worldmodel[all]'
```

**List cached datasets**

```
swm datasets
```
