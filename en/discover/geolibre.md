# Cloud-based open source mapping

GeoLibre is a lightweight, cloud-based geographic information system (GIS) platform designed to visualize, explore, and analyze geographic data. Developed with TypeScript, this tool can run on web browsers, desktop, mobile devices and Jupyter notebooks.

You don't need any installation to start using GeoLibre. You can access the web version through your browser or visit the download page on the official website to download the installer for your desktop operating system.
