# Safe software infrastructure for TypeScript

Effect-TS is a library ecosystem that enables building scalable and highly fault-tolerant applications with TypeScript. It standardizes software development processes by leveraging functional programming principles to manage complex workflows.

## What you get
- Centralizes error handling and data validation processes in a single place.
- Makes scheduling and concurrency management safe.
- Provides official plugins for different databases and runtime environments.

## Installation
**Adding the package to the project**

```
npm install effect
```


## If you don't write code
I want to include the Effect library in my TypeScript-based project. Perform the necessary installation using the 'npm install effect' command and ensure that the 'strict' type-checking setting is enabled in 'tsconfig.json'.
