# Give your AI agent native capabilities

NomaDamas/k-skill is a library designed to provide AI agents with local skills in a cultural context. It offers customized skill sets that enable agents to interact with users more naturally and in accordance with cultural codes.

## What you get

- Enables AI agents to use local services specific to Türkiye
- Performs automatic queries on transportation, public data and daily work
- Integrates directly without the need for extra client software

## Installation

**To install all capabilities**

```
npx --yes skills add NomaDamas/k-skill --all -g
```

**To install a specific ability**

```
npx --yes skills add NomaDamas/k-skill --skill srt-booking -g
```
