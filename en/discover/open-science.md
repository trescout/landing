# AI workspace for scientific research

Developed by AIPOCH, Open Science offers a local-first and model-agnostic AI workspace for scientific research. The software combines Python and R notebooks with data connections, enabling scientific processes to be conducted in a reproducible manner.

- ★ 4,013
- TypeScript
- GitHub Trending · 2026-09-07

## What you get
- Perform reproducible scientific analyses by running Python and R code
- Create automated reports, tables, and charts by connecting to scientific data sources
- Manage the entire process from literature review to simulation with local-first AI agents

## Installation
**Local installation from source code**

```
git clone https://github.com/aipoch/open-science.git
cd open-science
npm install
npm run dev
```

**Web interface development mode**

```
npm run build:web
npm run dev:web
```
