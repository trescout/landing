# Kubernetes management for Nvidia graphics cards

NVIDIA Kubernetes Engine (NVKE) offers a management plane that provides GPU-accelerated Kubernetes cluster management on bare metal servers. Developed in Go, this tool runs on Docker infrastructure with virtual TPM support, simplifying cluster installation and workload creation processes.
