# Multiple artificial intelligence management in terminal

Developed with the Rust language, herdr functions as an agent multiplexer running on the terminal. This tool allows users to manage multiple artificial intelligence agents simultaneously in the terminal environment.

- ★ 9,203
- Rust
- GitHub Trending · 2026-07-01

## What you get
- Manage multiple artificial intelligence agents simultaneously on a single terminal.
- Instantly monitor the working status of agents with colored indicators.
- Keep sessions running in the background even if the connection is lost.

## Installation
**Installation for Linux and macOS**

```
curl -fsSL https://herdr.dev/install.sh | sh
```


## Running it
**Starting the tool**

```
herdr
```
