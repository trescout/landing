# Fast and reliable programming language

Developed by Google, the Go programming language is an open source system programming language designed to create high-performance and scalable software. It is widely preferred in modern cloud computing infrastructures with its concurrency management and fast compilation times.

**TreScout note:** The program you write comes out as a single file, you copy that file to the server and run it, you do not need to install anything else. In return, the language is kept deliberately simple: You type the same error check over and over again. Good for writing server service and command line tool, forces you to model complex business rules.

## What you get

- Simple and understandable code structure
- High performance working capacity
- Efficiency for modern cloud systems

## Installation

**macOS (Homebrew)**

```
brew install go
```

**Windows (winget)**

```
winget install GoLang.Go
```

## Running it

**Verify version**

```
go version
```
