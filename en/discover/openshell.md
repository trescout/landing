# Secure environment for AI agents

Developed by NVIDIA, OpenShell provides a secure and privacy-focused runtime environment for autonomous AI agents. Written in Rust, this infrastructure aims to create a secure execution space by isolating agents' access to system resources.

- ★ 11,092
- Rust
- GitHub Trending · 2026-09-29

## What you get
- Runs AI agents in an isolated sandbox environment
- Limits file and network access with rules
- Enhances security by masking credentials

## Installation
**Install Tool and Create Demo Environment**

```
curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh
openshell sandbox create --name demo
```


## Running it
**Add Capabilities**

```
npx skills add NVIDIA/OpenShell
```


## If you don't write code
You can use the following commands to install and test the OpenShell tool: curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh and then create a demo environment by running the openshell sandbox create --name demo command.
