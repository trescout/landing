# Secure file sharing between devices

LocalSend is an open source application that allows file sharing between different operating systems. It creates a platform-independent alternative to the AirDrop feature offered by Apple devices.

## What you get
- Fast file transfer without requiring an internet connection
- Seamless communication between different operating systems
- Secure data transfer with HTTPS encryption
