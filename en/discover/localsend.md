# Share Files and Messages on a Local Network

Share files and messages between nearby devices on a local network. LocalSend works without an internet connection or third-party server and uses HTTPS encryption.

- ★ 88,882
- GitHub Trending · 2026-08-13

## What does this tool do?
LocalSend is a free, open-source app for sharing files and messages across Windows, macOS, Linux, Android and iOS devices on a local network. It uses a REST API and HTTPS encryption and does not require an account or login.

## Who it is for
People who want to share files or messages between devices on the same local network, including devices with different operating systems.

## What not to expect
People who need to transfer files between different networks over the internet or expect automatic in-app updates.

## Highlights
- Works without an internet connection or third-party server.
- Supports Windows, macOS, Linux, Android and iOS.
- Does not require an account or login.
- Uses a REST API and HTTPS encryption for local communication.

## First-use flow
- Install the version for your device from the official website, an app store or a package manager.
- Connect the devices you want to use to the same local network.
- If a connection fails, check incoming TCP and UDP traffic on port 53317 in your firewall.
- Choose a file or message in the app and start the transfer.
