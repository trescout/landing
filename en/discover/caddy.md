# Set up an automatic https server

Caddy is an extensible web server written in Go that provides automatic HTTPS certificate management. It simplifies website setup and security by supporting HTTP/1, HTTP/2, and HTTP/3 protocols.

## What you get
- Provides automatic HTTPS certificate management by default
- Supports HTTP/1, HTTP/2, and HTTP/3 protocols
- Runs anywhere without external dependencies

## Running it
**Compilation**

```
git clone "https://github.com/caddyserver/caddy.git"
cd caddy/cmd/caddy/
go build
```
