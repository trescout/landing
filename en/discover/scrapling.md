# Extract your data with flexible web scraping

Scrapling is an adaptable web scraping framework that can handle scale from a single request to large-scale crawling jobs. It aims to ensure high adaptability even if the page structure changes. It is Python based.

## What you get
- Comprehensive tool that can perform large-scale scanning with a single request.
- Automatic adaptation to page changes.
- Fast and open source structure.

**Using pip (PyPI)**

```
pip install scrapling
```


## Installation (single command)
Help me install the open source web scraping library called Scrapling; Install it with 'pip install "scrapling[fetchers]"' and run the 'scrapling install' command, then let's extract the content of a web page to a Markdown file with the 'scrapling extract get https://example.com content.md' command.
