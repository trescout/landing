# Repair and enhance your videos

Kruk2/jasna is a video restoration tool developed to improve videos. Written in Python, this project automates the technical processes aimed at enhancing image quality.

## What you get

- Automatically detects mosaic areas in videos and cleans them without degrading the rest of the image
- Repairs only the sections you specify using its editing tool instead of processing the entire video
- Provides an instant preview of the corrected footage without saving a new file, thanks to its built-in video player

## Getting started

Download the package suitable for your operating system and graphics processor from the releases section on the GitHub page. Extract the downloaded archive into a local folder whose file path contains no Turkish or special characters. If you are using Windows, you can access the graphical interface by running the jasna.exe application in the folder.
