# Apollo 11 guidance computer source codes

The original source code of the command and lunar module guidance computer (Guidance Computer) used in the Apollo 11 mission has been made available on GitHub with assembly language. The software documents the technical details of the calculation algorithms used in the first manned mission to land on the Moon.

## What you get
- Access to original software codes for the Moon landing
- Review of command and lunar module guidance algorithms
- Exploring historical assembly language software architecture

## Getting started
This repository was created to archive the original source codes of the guidance computer used in the Apollo 11 mission. You can browse the Comanche055 or Luminary099 folders on GitHub to review the codes, and visit the official website of the Virtual AGC project to get detailed information about the compilation processes.
