# AI coding agent

QwenLM/qwen-code is an open-source coding AI agent that runs on terminal, editor, desktop, and browser. Developed with the TypeScript language, this tool aims to support software development processes across different platforms.

## What you get

- Enables you to code on terminal, desktop, browser, and editor
- Offers dynamic workflows with automatic memory, capabilities, and sub-agents
- Uses different AI services and local models with multi-protocol support

## Installation

**Installation with NPM**

```
npm install -g @qwen-code/qwen-code@latest
```

**Installation with Homebrew**

```
brew install qwen-code
```

## Running it

**Initialization**

```
qwen
```
