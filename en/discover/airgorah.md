# Security auditing for wireless networks

Developed in Rust, Airgorah is software used to audit wireless network security. It offers the ability to perform security tests such as monitoring nearby network traffic, detecting devices connected to access points, and cracking passwords.

## What you get

- You can monitor nearby wireless network traffic and detect connected devices.
- You can capture network handshake data and security keys.
- You can test the password strength of access points.

## Getting started

To install and use the software, you can follow the guides in the project's official Wiki pages. For the application to work, you need a wireless network card that supports monitor mode on the Linux operating system.
