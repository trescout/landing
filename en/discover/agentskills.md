# Give standard capabilities to AI agents

Agent Skills is a technical specification and documentation project that standardizes the skills used by artificial intelligence agents while performing their tasks. This Python-based structure aims to facilitate capability sharing and interoperability between different agent systems.

## Getting started

Agent Skills is a standard rather than a software installation. To get started, you can review the official documentation at agentskills.io, browse the examples directory on GitHub to see sample capabilities, and start building your capabilities in this standard format folder structure.
