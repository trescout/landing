# Your personal AI assistant running on your device

Openclaw is an AI-based automation tool capable of executing tasks across different operating systems and platforms. Developed with TypeScript, this software enables users to standardize and automate operations on their computers.

## What you get

- Keep your data, memory, and account information completely secure on your own computer.
- You can chat with your assistant via messaging apps WhatsApp, Telegram, Discord, and business communication tool Slack.
- You can easily manage different AI models and local system tools from a single center.

## Installation

**Running the automated installation script (ma**

```
# macOS / Linux / WSL2
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Globally with the Node.js package manager npm**

```
npm install -g openclaw@latest --allow-scripts=openclaw
```
