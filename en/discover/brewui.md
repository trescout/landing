# Visual interface for macOS package management

Homebrew is a command-line tool used to manage software packages on the macOS operating system. BrewUI is an official desktop application that allows you to manage the complex commands of this tool through a graphical user interface (GUI).

- ★ 2,014
- Swift
- GitHub Trending · 2026-09-16

## What you get
- Manage software packages without using the command line
- Track Homebrew operations with a transparent interface
- Easy installation with a native SwiftUI-based macOS application

## Installation
**Install the application**

```
brew install --cask homebrew-app
```
