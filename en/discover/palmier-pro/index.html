AI video editor for macOS

Palmier Pro was developed as a video editor that runs on the macOS operating system and offers artificial intelligence-supported editing tools. This application, written in Swift language, aims to combine artificial intelligence-based workflows with local system performance.

Getting started

Download and install the Palmier Pro app on your macOS device using the download link on the official GitHub page. After running the application, you can log in to use artificial intelligence tools or configure MCP integrations from the Help menu within the application.
