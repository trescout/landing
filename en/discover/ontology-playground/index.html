Design AI ontologies with Ontology-Playground

Developed by Microsoft, Ontology-Playground is an open source web application used to learn ontologies and create visual designs on Microsoft Fabric IQ. This completely static tool allows users to design ontology models, export them in RDF/XML format and share interactive diagrams.

  • ★ 1,806
  • TypeScript
  • GitHub Trending · 2026-07-21

What you get

  • Create ontology models with visual interface
  • Export to RDF/XML format
  • Explore data with interactive diagrams

Installation

Installing the project in a local environment
cd Ontology-Playground
npm install
Starting the development server
npm run dev
