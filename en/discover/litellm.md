# Manage AI models centrally

LiteLLM is an AI gateway that unifies more than 100 large language model (LLM) interfaces into a single standard format. It makes it easy to switch between different model providers by offering software developers features such as cost tracking, load balancing, and guardrails.

## What you get

- Prevents code clutter by unifying more than a hundred LLM (Large Language Model) providers into a single standard format.
- Eliminates the need to rewrite your codebase when switching between AI models.
- Offers an enterprise-grade management infrastructure with tools such as virtual keys, budget tracking, and load balancing.

## Installation

**programming language Python library inst**

```
uv add litellm
```

## Running it

**Starting the gateway server**

```
uv tool install 'litellm[proxy]'
litellm --model gpt-4o
```
