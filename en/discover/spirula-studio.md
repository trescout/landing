# Spirula Studio

Spirula Studio is a cross-platform educational tool that converts videos into three-dimensional scene representations (3D Gaussian Splatting) and converts them into meshes. The software provides a working environment compatible with different hardware manufacturers using Vulkan or CUDA graphical interfaces.
