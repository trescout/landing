Secure Netcat tunnelling over Tailscale mesh networks

Tailcat brings classic netcat utility to the Tailscale VPN mesh overlay, enabling zero-port-forwarding, encrypted peer-to-peer data transmission.

  • Go
  • GitHub Trending · 2026-08-28

Updates

  • August 28, 2026: 2,435 stars, powered by native WireGuard encryption and embedded tsnet library.

What you get

  • Zero port forwarding required: Establish direct communication across NAT barriers and strict firewalls without open inbound ports.
  • End-to-end WireGuard encryption: Secure all TCP and raw socket traffic with automated Tailscale mutual authentication and WireGuard crypto.
  • Embedded tsnet architecture: Runs as an autonomous Tailscale node via tsnet without requiring the system-wide Tailscale daemon.
  • Piped file and stream transport: Stream tar archives, gzip payloads, or raw disk images between machines via standard stdin/stdout pipes.
  • Network diagnostics and probing: Test port reachability and debug remote microservice connections using familiar netcat CLI semantics.

Installation

Install directly via Go toolchain
go install tailscale.com/cmd/tailcat@latest

Running it

Start listening server and connect client
# Sunucu düğümde dinle:
tailcat -l 8080
# İstemci düğümden bağlan:
tailcat hedef-node 8080

Technical architecture and working principle

Tailcat bridges conventional netcat semantics with Tailscale's userspace networking library tsnet:

  • tsnet userspace networking: Establishes an in-process VPN interface without requiring root privileges or virtual TUN devices.
  • MagicDNS hostname resolution: Connect to nodes instantly using natural Tailscale machine hostnames rather than raw IP addresses.
  • DERP relay traversal: Maintains reliable encrypted data transmission via encrypted DERP relays when direct P2P connections are blocked.

Secure mesh tunnelling and end-to-end scenarios

Tailcat provides engineers and system administrators with agile solutions without complex VPN setup:

  • Instant encrypted file transfers: Receive via `tailcat -l 9000 > backup.tar.gz` and send via `tailcat target 9000 < backup.tar.gz` without extra setup.
  • Ad-hoc HTTP service sharing: Share a local development server with peers across your tailnet mesh via a single terminal invocation.
  • Embedded device and IoT access: Safely stream telemetry and diagnostic commands to remote Raspberry Pi devices on residential connections.

Frequently asked questions

  • Is a system-wide Tailscale client required? No. Tailcat embeds the tsnet engine internally, connecting directly to your Tailscale mesh as an independent node without system services.
  • Is data truly encrypted end-to-end? Yes. Tailcat leverages the WireGuard protocol core of the Tailscale network, ensuring direct peer-to-peer authenticated encryption.
  • Does Tailcat support UDP transport? Tailcat is primarily engineered for TCP streams and socket tunneling, replicating classic netcat's reliable TCP streaming.
  • How does authentication work? On first run, Tailcat prints an interactive auth URL in your terminal or accepts a pre-authenticated TAILSCALE_AUTHKEY environment variable.
