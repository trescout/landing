# Create a live AI character

Open-LLM-VTuber enables hands-free voice interaction with large language models and running live two-dimensional (Live2D) characters on local systems. The system offers a real-time communication experience between the user and artificial intelligence with voice interruption support.

## What you get
- Completely offline operation on local system
- Real-time interaction with Live2D characters
- Camera and screen detection support

## Installation
**with uv (recommended)**

```
git clone https://github.com/Open-LLM-VTuber/Open-LLM-VTuber --recursive
cd Open-LLM-VTuber
uv sync
```


## Running it
**run**

```
uv run run_server.py
```
