# Artificial intelligence that transforms documents into editable presentations

PPT-Master is an AI-powered tool that converts documents directly into editable presentation files (PPTX). The system translates text into customizable presentations with native figures, animations, and audio speaker notes.

- ★ 51,323
- Python
- GitHub Trending · 2026-06-28

## What you get
- Converts text into PPTX files with native shapes and animations.
- Adds automatic voice speaker notes to presentation slides.
- Thanks to its editable structure, it allows you to make changes to the presentation later.

## Installation
**Download the project to your computer**

```
git clone https://github.com/hugohe3/ppt-master.git
cd ppt-master
```

**Installing the required libraries**

```
pip install -r requirements.txt
```
