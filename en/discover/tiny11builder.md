# Create lightweight and customized Windows 11 images

ntdevlabs/tiny11builder is a WinUI application used to create smaller and customized versions of the Windows 11 operating system. Developed in C#, this tool allows users to size system images according to their own needs.

## What you get

- You can remove pre-installed apps and unnecessary system features from the operating system image.
- You can select ready-made Tiny11 modes according to your needs or specify components to be removed one by one.
- With the process acceleration option, you can shorten the image creation process and resume interrupted processes from where they were saved.
