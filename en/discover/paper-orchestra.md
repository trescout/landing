# AI tool that automatically writes academic papers

Developed by Google Research, PaperOrchestra is a multi-agent framework that transforms raw ideas and experiment logs into academic-format LaTeX drafts. The software supports research paper writing by automating literature review and image generation processes.

## What you get

- Converts raw ideas into academic format
- Automates the literature review
- Generates necessary visuals and graphics

## Installation

**Setting up the required environment**

```
conda create -n paper_orchestra python=3.11
    conda activate paper_orchestra
    pip install -r requirements.txt
```

## Running it

**Running with the script**

```
./paper_writing_cli.sh
```

**Running via the command line**

```
python paper_writing_cli.py \
  --raw_materials_dir /path_to_your_raw_materials/ \
  --latex_template_dir /path_to_your_latex_template/ \
  --output_dir /path_to_your_output_folder/ \
  --use_plotting true
```
