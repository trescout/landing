# High-throughput and memory-efficient inference and serving engine for AI models

vllm-project/vllm is an inference and serving engine that provides high throughput and memory efficiency for large language models (LLMs). Developed in Python, this tool aims to accelerate the execution processes of artificial intelligence models.

## What you get

- offers PagedAttention management providing memory efficiency
- works compatibly with popular Hugging Face models
- includes OpenAI-compatible API server support
