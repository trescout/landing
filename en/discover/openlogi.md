# Open source management for Logitech devices

OpenLogi is a native-first, open-source alternative to Logitech Options+ written in Rust. Configures buttons, DPI, and SmartShift without requiring accounting or telemetry.

## What you get

- Provides local control without creating an account
- Assigns custom shortcuts to all keys
- Offers multi-platform support including Linux

## Installation

**Standard installation with Homebrew**

```
brew install --cask openlogi
```

**Follow the latest version**

```
brew tap aprilnea/tap
brew install --cask aprilnea/tap/openlogi@latest
```
