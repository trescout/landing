Visualize your data in one interface

Grafana is an open source observability and data visualization platform that combines metrics, logs, and traces from different data sources in a single interface. It allows analysis of complex data sets by integrating with many systems such as Prometheus, Elasticsearch and PostgreSQL.

Installation

macOS (Homebrew)
brew install grafana
with Docker
docker run -d -p 3000:3000 --name=grafana grafana/grafana

Running it

Start as homebrew service
brew services start grafana

Getting started

To start using Grafana, visit the official website grafana.com/get. You can review the documents on grafana.com/docs/grafana/latest/setup-grafana/installation/ to access the installation guides that suit your needs.
