# Orchestration tool for artificial intelligence agents

Developed by Google, Ax is an open-source orchestration runtime for artificial intelligence agents. Written in Go, this infrastructure facilitates the management and execution of complex agentic workflows.

- ★ 13,086
- GitHub Trending · 2026-09-23

## What you get
- Enables you to manage billions of autonomous AI workloads.
- Allows you to run agents in a secure and isolated sandbox environment.
- Offers fast and declarative configuration with YAML files.

## Installation
**Installing the CLI tool**

```
go install github.com/google/ax/cmd/ax@latest
```

**Deploying the control plane**

```
make deploy AX_IMAGE_REPO=<your-registry>
```
