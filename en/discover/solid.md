# AI-friendly fast interfaces

Solid is a declarative JavaScript library used for building user interfaces. Instead of using a Virtual DOM, it compiles templates directly into real DOM nodes, performing updates with fine-grained reactivity.

## What you get

- The interface management structure gains speed by updating real browser nodes directly instead of using a Virtual DOM.
- Minimizes CPU load by running components only once.
- Refreshes only the affected small parts with its structure that automatically tracks data changes.

## Installation

**Create a new project with a ready template**

```
npx degit solidjs/templates/solid-v2/basic my-app
cd my-app
npm install
npm run dev
```

## Running it

**Include the development tool in the Vite project**

```
npm i solid-js @solidjs/web
npm i -D vite @solidjs/vite-plugin
```
