# Open source project management platform

Plane is an open source project management platform that brings together task management, sprint planning and documentation processes. Developed as an alternative to enterprise tools such as Jira and Linear, this platform allows teams to organize workflows through a central interface.

- ★ 57,579
- TypeScript
- GitHub Trending · 2026-06-18

## What you get
- Track tasks and product roadmaps in a central interface
- Dividing complex projects into manageable modules and cycles
- AI-powered documentation and analysis tools

## Installation
**Download installation script**

```
curl -fsSL -o setup.sh https://github.com/makeplane/plane/releases/latest/download/setup.sh
```

**Make it executable**

```
chmod +x setup.sh
```


## Running it
**Start installation (2 from menu)**

```
./setup.sh
```
