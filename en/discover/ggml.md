# Tensor library for artificial intelligence models

ggml-org/ggml is a tensor library developed in C++ for machine learning models. The software facilitates running artificial intelligence models by providing simple and clear examples for operations such as basic matrix multiplication.

## What you get

- Delivers high-performance tensor operations using C and C++ without external dependencies.
- Can run on central processing units (CPU), graphics processing units (GPU), and browser environments.
- Reduces memory usage with quantization formats that decrease data size.

## Installation

**Compiling from source code**

```
git clone https://github.com/ggml-org/ggml
cd ggml

mkdir build && cd build
cmake ..
cmake --build . --config Release -j 8
```
