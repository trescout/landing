Tool that provides access to restricted platforms

Zapret-discord-youtube is a tool that aims to provide access to restricted platforms by encrypting network traffic or using packet fragmentation methods. It was developed specifically to overcome access barriers to services such as Discord and YouTube.

Getting started

Download the archive file by going to the latest version link on the official GitHub page. Unblock the archive in its properties and extract its contents to a folder that does not contain special characters or the Cyrillic alphabet. You can then run strategies or install services using the .bat files in the folder.
