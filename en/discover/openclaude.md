# AI management via terminal

OpenClaude is a flexible AI interface that can run on any hardware and utilize different data sources. Developed in TypeScript, this open-source project allows users to run customized AI models on their own infrastructure.

## What you get

- Combines cloud-based and local AI models into a single interface.
- Executes tasks such as file management, search, and coding from the terminal.
- Easily configures different providers with a user-friendly guided setup.
