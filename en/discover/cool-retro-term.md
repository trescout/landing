# Terminal experience with a vintage screen look

Cool-retro-term is a terminal emulator that mimics the look of old-school cathode ray tube (CRT) monitors. Developed with the QML language, this software adds a nostalgic visual aesthetic to the modern command-line experience.

## What you get
- Offers the nostalgic look of old cathode ray tube monitors
- Provides customization over colors, fonts, and visual effects
- Runs as a lightweight and stylish terminal emulator on modern operating systems

## Getting started
To use the latest version on your Linux or macOS operating system, you can go to the Releases page on GitHub and download the AppImage or dmg file. Alternatively, you can install it via the official package repositories of many distributions such as Ubuntu, Fedora, or Arch.
