# Saving tokens in AI code review

Code-review-graph analyzes the code base and creates a locally focused code intelligence map for artificial intelligence tools. This structure makes artificial intelligence-supported code review processes more efficient by using context reduction methods in large projects.

- ★ 29,487
- Python
- GitHub Trending · 2026-07-18

## What you get
- Analyzes the code base and presents only relevant files to artificial intelligence
- Significantly reduces token consumption in large projects
- Automatically manages updates by analyzing the impact of changes

## Installation
**Basic Setup**

```
pip install code-review-graph
```

**Auto Configuration**

```
code-review-graph install
```


## Running it
**Creating the Code Map**

```
code-review-graph build
```
