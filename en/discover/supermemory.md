# Smart memory for artificial intelligence

Supermemory offers a highly scalable memory engine and API designed for the age of artificial intelligence. It allows you to add a persistent and queryable memory layer to your applications.

- ★ 28,924
- TypeScript
- MIT

## What you get
- It adds a persistent memory layer to your application.
- Scalable architecture support.
- Easy integration via API.

## How to install, how to use?
**Install SDK (Node or Python)**

```
npm install supermemory    # ya da: pip install supermemory
```

**Connect MCP server to AI client**

```
npx -y install-mcp@latest https://mcp.supermemory.ai/mcp --client claude --oauth=yes
```
