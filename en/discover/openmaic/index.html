Interactive multi-agent classroom simulation with AI

Developed by Tsinghua researchers, OpenMAIC connects multi-agent AI personas including teachers, students, and observers in an interactive simulated classroom.

  • ★ 25,572
  • TypeScript
  • GitHub Trending · 2026-08-31

Updates

What you get

  • Role-based multi-agent architecture: Dynamic interactions between specialized LLM agents acting as teachers, inquisitive students, and summarizers.
  • Visual and audio classroom interface: Immersive learning environment featuring virtual whiteboards, Q&A streams, and speech synthesis (TTS).
  • Customizable lesson curriculum: Upload custom PDF documents or lecture notes to automatically generate interactive learning curricula.
  • One-click simulation engine: Manage complex multi-agent orchestrations via an intuitive modern web UI without coding requirements.
  • Open-weight model compatibility: Connect Ollama, vLLM, or hosted LLM endpoints to power classroom personas with any preferred model.

Technical architecture and working principle

OpenMAIC operates on an event-driven conversational loop coordinating multi-agent dynamics:

  • Conversational orchestration engine: Central coordinator regulating speaking turns, debate pacing, and context retention across agents.
  • Shared memory and context manager: Maintains shared virtual whiteboard states, student inquiries, and lesson memory across sessions.
  • Low-latency WebSocket streaming: Streams agent dialogue tokens, sentiment metadata, and classroom animations instantly to web clients.

Multi-agent classroom dynamics and role simulations

OpenMAIC enables groundbreaking applications across educational technology and multi-agent AI research:

  • Socratic debate environments: Simulate diverse intellectual perspectives to stimulate critical thinking through agent-led debates.
  • Adaptive personal tutoring: Tailor explanation depth dynamically to the student's mastery level using specialized teacher personas.
  • Multi-agent social dynamics research: Empirically analyze collaboration, consensus forming, and peer dynamics among autonomous language models.

Frequently asked questions

  • Does OpenMAIC require a local GPU? A dedicated GPU is required only if running local inference via Ollama or vLLM; hosted API endpoints (OpenAI, Gemini, Groq) run effortlessly on any machine.
  • Can human users participate via voice? Yes. Built-in WebRTC audio streaming enables users to speak directly into the simulated classroom discussions.
  • How many agents can participate simultaneously? Default configurations optimize dynamics between 3 to 8 agents, though classes can be expanded depending on computational quotas.
  • What courseware formats are supported? Users can upload plain text, Markdown notes, or PDF textbooks directly into the knowledge retrieval pipeline.
