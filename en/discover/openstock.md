# Follow Stock Market Data for Free

OpenStock is an open source alternative to expensive exchange platforms. It offers real-time price tracking, personalized alerts and company analytics. It is accessible to everyone and free forever.

- ★ 14,018
- TypeScript
- AGPL-3.0
- GitHub Trending · 26 May 2026

## What you get
- It tracks real-time prices.
- Sends personalized notifications.
- It provides detailed analysis for companies.
- It eliminates the need for expensive platforms.

## Installation
**Clone GitHub repository**

```
git clone https://github.com/Open-Dev-Society/OpenStock.git
cd OpenStock
pnpm install
```


## Running it
**Start development server**

```
pnpm dev
```


## How to use?
You can use the ready-made site (openstock-ods.vercel.app) directly or install it on your own server.
