# Design expert agents for Claude Code

Using Claude Code's agent team system, Harness divides complex missions into coordinated teams of specialized agents. With the command 'Set up a harness for', it designs the required team and skills for you.

## What you get

- Divides complex missions into teams of specialized agents.
- It develops the skills that teams need.
- Automates workflows.

## Getting started

Added as a skill to Claude Code; Then, you can ask them to establish a team of agents for the area you want.

## How to install, how to use?

🤖 Paste this into your AI agent (Claude Code · Codex · Antigravity)

Install the Harness plugin by running the commands '/plugin marketplace add revfactory/harness' and then '/plugin install harness@harness-marketplace' in Claude Code, then ask it to set up an artificial intelligence agent team suitable for my project by saying "Create a harness for this project".

**Claude Code · marketplace + installation**

```
/plugin marketplace add revfactory/harness
/plugin install harness@harness-marketplace
```
