# Artificial Intelligence Supported Engineering Processes

Compound Engineering; Claude Code is an official add-on for Codex and Cursor. Its basic philosophy is clear: each engineering task should make the next one easier, not harder. To this end, it offers AI capabilities and agents that improve the development process.

- ★ 24,485
- TypeScript
- MIT
- GitHub Trending · 29 May 2026

## What you get
- Each task makes the next easier, so your productivity increases cumulatively.
- Provides ready-made skills and agents.
- Easily adapts to multiple AI environments.

## Getting started
You can install it as an add-on to your AI assistant, then incorporate the skills and agents into your workflow.

## How to install, how to use?
**Claude Code · marketplace + installation**

```
/plugin marketplace add EveryInc/compound-engineering-plugin
/plugin install compound-engineering
```

**Prepare the project after installation**

```
/ce-setup
```
