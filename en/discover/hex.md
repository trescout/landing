# Local dictation that instantly converts voice to text

Developed in Rust, Hex is a native voice dictation tool that runs on Mac, Windows, and Linux operating systems. It allows users to speak by holding down a key and converts what they say into text.

## What you get

- When you speak by holding down the shortcut key, it instantly streams your voice as text into the active application.
- Downloads the speech model to your device upon first run and prevents your data from leaving your computer.
- Runs natively on Mac, Windows, and Linux systems.

## Getting started

To start using the Hex application, you can download the installation file or DMG package suitable for your operating system from the official downloads table. After installing and running the file, you can start speaking by holding down the shortcut key.
