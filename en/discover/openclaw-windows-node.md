# AI node for Windows

OpenClaw offers an integrated management suite on the Windows operating system through the Windows node, system tray application, shared library and PowerToys command palette extension. Developed in C# language, this tool aims to standardize access to system resources and user workflows.

## What you get

- Provides quick access to the OpenClaw artificial intelligence assistant via the system tray.
- It offers local gateway and connection management on Windows.
- It allows live sessions, usage and node tracking with the command center.

## Running it

**Native app launch**

```
.\run-app-local.ps1
```

**WebSocket connection via CLI is correct**

```
dotnet run --project src/OpenClaw.Cli -- --help
```
