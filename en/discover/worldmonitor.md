# Real-time global intelligence dashboard

Worldmonitor offers a real-time global intelligence dashboard that combines AI-powered news compilation and geopolitical monitoring features in a single interface. This tool, which provides infrastructure monitoring and situational awareness, facilitates analysis processes by visualizing complex data flows.

- ★ 78,032
- TypeScript
- GitHub Trending · 2026-06-20

## What you get
- Summarizing more than 500 news sources with artificial intelligence
- Visual analysis with 3D globe and WebGL map support
- Combination of economic, military and geopolitical data in a single interface

## Installation
**Basic setup**

```
git clone https://github.com/koala73/worldmonitor.git
cd worldmonitor
npm install
npm run dev
```


## Running it
**Variant based operation**

```
npm run dev:tech       # tech.worldmonitor.app
npm run dev:finance    # finance.worldmonitor.app
npm run dev:commodity  # commodity.worldmonitor.app
npm run dev:happy      # happy.worldmonitor.app
npm run dev:energy     # energy.worldmonitor.app
```
