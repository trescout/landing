# Fast Linux virtualization on Mac

Developed by Apple, container allows creating and running Linux containers using lightweight virtual machines on Mac. Written in Swift language, the tool offers performance optimized for Apple silicon architecture.

## What you get
- It runs Linux containers as lightweight virtual machines on Mac devices with Apple silicon processors.
- It allows you to extract and use OCI-compliant container images from standard registries.
- It is written in Swift language and offers high performance using macOS virtualization features.
