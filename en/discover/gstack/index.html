Software development factory with artificial intelligence

Gstack is a system based on Garry Tan's Claude Code configuration and consists of 23 specialized tools that play different roles such as CEO, designer, engineering manager. This TypeScript-based structure offers defined workflows to automate software development processes.

Installation

Download and install the tool on your computer
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/gstack
cd ~/gstack && ./setup

If you don't write code

🤖 Paste this into your AI agent (Claude Code · Codex · Antigravity)

You are now my virtual engineering team. Analyze my project using Gstack tools, determine my strategy with /office-hours, create my work plan with /autoplan, and check the code quality with /review. Automate all stages of the software development process by acting as a CEO, designer and engineering manager.
