# Native web capabilities to your AI agent

Wigolo is a tool that provides local-first search, data extraction and crawling capabilities for artificial intelligence coding agents. This system, which works over the model context protocol (MCP), provides free research without cloud dependency and without requiring an API key.

## What you get
- Free search and scan with no API key required
- Cloud-agnostic local data processing and caching
- Direct integration with popular AI tools

## Installation
**Starting agent installation**

```
npx wigolo init --agents=<your-agent>
```

**Checking system health**

```
npx wigolo doctor
```


## If you don't write code
Use Wigolo to research the web, pull data, and synthesize your findings by citing sources. When performing transactions, stick to the local-first working principle, use basic tools that do not require an API key, and report your results in a structured way.
