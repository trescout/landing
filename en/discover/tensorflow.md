# Open source platform for artificial intelligence models

Developed by Google, TensorFlow is an open source library used to create and train machine learning models. It allows developers to design complex neural networks and deploy these models in a scalable manner.

## What you get
- Enables building and deploying machine learning applications
- Provides stable interfaces for Python and C++ programming languages
- It hosts a flexible ecosystem with GPU and CPU support

## Installation
**To install the library**

```
pip install tensorflow
```

**To install the CPU-only version**

```
pip install tensorflow-cpu
```


## Running it
**To start the Python environment**

```
python
```
