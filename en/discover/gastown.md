# Workspace management for AI agents

Gas Town offers an infrastructure that enables different artificial intelligence agents to work together as a multi-agent workspace manager. Developed with the Go language, this tool centralizes inter-agent coordination and resource management in complex workflows.

- ★ 17,403
- Go
- GitHub Trending · 2026-07-06

## What you get
- Coordinate multiple artificial intelligence agents from a single center.
- Prevent agents from losing context on reboots.
- Persist business processes with Git-based storage.

## Installation
**Installation with Homebrew**

```
brew install gastown
```

**Create a workspace**

```
gt install ~/gt --git
```


## Running it
**Starting Mayor session**

```
gt mayor attach
```
