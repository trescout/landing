# Experimental PlayStation 5 emulator project

Sharpemu is an experimental PlayStation 5 emulator project developed in C# language. This study, which aims to imitate the console architecture on a software basis, is a technical experiment carried out on game console emulation technologies.

## What you get
- Opportunity to examine game console architecture
- Support for running native CPU instructions
- Reading metadata from game files

## Getting started
To use the project, you can download ready-made files from the 'Releases' tab on the GitHub page or compile the source codes on your computer with .NET SDK installed. To compile, simply copy the project to your computer, open the solution file via VSCode, and run the dotnet build command in the terminal.
