# Multilingual fitness exercise dataset

The exercise dataset (exercises-dataset) shared by Hasaneyldrm offers 433 different fitness movements with names, target muscle groups, equipment and visual instructions. This comprehensive resource provides a structured data infrastructure for those developing sports technology applications.

## What you get

- Structured data for 1,324 different fitness exercises
- Step-by-step application instructions in 6 languages ​​including Turkish
- Ready guide for database and API integration

## Getting started

This tool does not require any installation. After downloading the files on the GitHub page to your computer, you can review the exercises by opening the 'index.html' file with any internet browser, and access the database and API installation guide by opening the 'setup.html' file.
