# Open source phased array radar

PLFM RADAR is a low-cost and open source phased array radar system operating at a frequency of 10.5 GHz. This hardware-based project uses control software developed with PLSQL language to make radio frequency sensing technologies accessible.

## What you get
- 3 km and 20 km range options
- Electronic beam steering capability
- FPGA based advanced signal processing

## Getting started
This project is a comprehensive system consisting of hardware and software components. To get started, you can access the hardware schematics, FPGA software files and Python-based user interface by reviewing the documentation on the GitHub page. It is recommended that you follow the technical reports and simulation outputs in the relevant folders for the installation and use of the project.
