# Artificial Intelligence Developing through User Interactions

Developed by NousResearch, Hermes Agent offers an autonomous agent infrastructure that learns from user interactions and develops over time. This Python-based system uses continuous learning to create personalized workflows.

## What you get
- Autonomous capabilities that evolve over time by learning from user interactions.
- Opportunity to work integrated with platforms such as Telegram, Discord and Slack.
- Ability to switch between different artificial intelligence models without changing the code.

## Installation
**Installation for Linux, macOS and WSL2**

```
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```


## Running it
**Starting the interface**

```
hermes
```
