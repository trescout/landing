# Web-based 3D architectural editor

TypeScript-based pascalorg/editor allows users to create and share three-dimensional architectural projects via the browser. The software aims to make architectural design processes accessible through a web-based interface.

- ★ 21,794
- TypeScript
- GitHub Trending · 2026-07-29

## What you get
- 3D architectural modeling with React Three Fiber
- High-performance visualization with WebGPU support
- Zustand-based central stage and status management

## Installation
**Install required packages**

```
npm install @pascal-app/core @pascal-app/viewer @pascal-app/editor @pascal-app/nodes
```


## Running it
**Start the development server**

```
bun dev
```
