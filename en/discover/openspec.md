# Standard development in artificial intelligence projects

OpenSpec is a TypeScript library that supports spec-driven development processes for artificial intelligence code assistants. It ensures standardization of technical requirements during software development stages and a more controlled progress of code production processes.

## What you get
- Standardizes technical requirements before writing code
- Controls the development process with artificial intelligence
- Archives changes in an organized folder structure

## Installation
**Install the tool globally**

```
npm install -g @fission-ai/openspec@latest
```


## Running it
**Launch in project directory**

```
openspec init
```
