# Artificial intelligence memory that combines business tools

Macro is a workspace that combines business tools such as email, chat, documents and task management with a common artificial intelligence memory. Developed with the Rust language, this platform connects different workflows in a single interface.

## What you get
- It collects e-mail, chat, tasks and documents in a single interface.
- It creates a common team memory by connecting all data together.
- It enables AI agents to act on company data.
