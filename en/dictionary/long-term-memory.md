# What is Long-term Memory?

Artificial intelligence stores past information and experiences for a long time and remembers them when needed.

## Overview
Artificial intelligence models normally have a short-term memory (context window). Long-term memory goes beyond this limit, allowing the model to remember topics or preferences you talked about days or months ago.

*Analogy: It is like the difference between a person's short-term memory and taking notes in a diary and reading that diary years later.*

## How it works
Data is usually stored in a vector database. When artificial intelligence needs something, it queries this database and recalls the relevant information into its memory.

## Where it is used
It is used in personal assistants, artificial intelligence working on long-term projects, and customer service bots.

## Commonly confused with
It may be confused with the context window, but the context window only covers the current conversation.

## Frequently asked questions
**Does this memory last forever?**
Yes, the information is stored permanently unless the database is deleted.

**How to protect privacy?**
Data is usually kept on the user's own storage or in an encrypted form.
