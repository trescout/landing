What is Jupyter Notebook?

It is an interactive work environment where you can add notes, graphs and visualizations while writing code.

Overview

Jupyter Notebook is a browser-based tool used especially in data science and artificial intelligence projects. It allows you to write your code in small chunks, run it instantly, and see the results immediately. It can be organized like a diary or lecture notes, as you can add not only code but also texts explaining what this code does.

Analogy: Think of a recipe book; There are notes explaining how the dish is made, and there is a stove that allows you to try that recipe right there in the kitchen.

How it works

It is generally used with the Python language. You type your code into a cell, press 'run' and the output appears right below. When you're done, you can share this file with others and have them follow the same steps.

Where it is used

It is used when analyzing data, training artificial intelligence models, or testing an algorithm step by step.

Commonly confused with

It can be confused with a regular text editor or coding program (IDE); but the biggest difference with Jupyter is that the code and the result are intertwined.

Frequently asked questions

Can it only run Python?

No, although it is based on Python, it also has plugins for different languages.

What is the file extension?

It is usually saved with the .ipynb extension.
