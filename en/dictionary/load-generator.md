# What is Load Generator?

A tool that generates artificial user traffic to measure how much traffic a system can handle.

## Overview
Imagine thousands of people accessing the site at the same time before your software projects go live. You can't wait for real people to test this situation; This is where the load generator comes into play. It throws out artificial requests to push your system to its limits and see where it will crash.

*Analogy: They are like testing machines that release thousands of model cars onto the road at the same time to test the durability of a newly opened highway.*

## How it works
It works by commanding the target website or server to click, send data, or make requests in a short period of time. It reports the responses received and the server's reaction under this pressure.

## Where it is used
It is frequently used in stress tests, server capacity planning and performance improvement processes before websites are launched.

## Commonly confused with
It can be confused with penetration testing tools for finding security vulnerabilities; The purpose here is not to break the system, but to weigh how much load it can carry.

## Frequently asked questions
**How does it differ from real user traffic?**
It is completely automatic and repeats predetermined scenarios much faster and more voluminously than humans.

**Could it crash the system?**
Yes, if you exceed the capacity limit you can temporarily slow down or crash the system under test.
