# What is Declarative?

*Development · Last updated: November 19, 2026*

A coding approach where the programmer specifies what needs to be done, while the software handles how it is done.

## Overview

Declarative programming is a method of describing the final result you want to achieve rather than giving step-by-step instructions to the computer. You simply state what you want, and the underlying system chooses and takes the most suitable path to reach that result.

***Analogy:** It is like getting into a taxi and just giving the address instead of telling the driver step by step which street to turn into. How the road is traveled is left to the driver's expertise.*

## How it works

Instead of dealing with loops or temporary variables when writing code, you use the rules provided by ready-made libraries. For example, when developing an interface, you define how the screen should look based on the state of the data, and the browser manages the changes in the background by itself.

## Where it is used

It is widely used in modern web frameworks, database query languages, and cloud infrastructure management tools.

## Commonly confused with

It is often confused with the imperative programming approach, which requires you to write every single step one by one.

## Questions and answers

**Why is declarative code preferred?**

It allows you to write less code and increases code readability, reducing the risk of making errors.

**Is it only used in artificial intelligence projects?**

No, it is a widespread philosophy in the general software development world.
