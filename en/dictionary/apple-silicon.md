# What is Apple Silicon?

It is a high-performance and low-energy processor architecture designed specifically for computers by Apple.

## Overview
Unlike traditional processors, Apple Silicon combines the processor, graphics unit and memory on a single chip. This design allows data to be moved much faster between units. As a result, devices heat less and consume less battery while offering much higher performance.

*Analogy: You can think of it as units that do work in different buildings moving to the same office and giving files directly to each other instead of shouting at each other.*

## How it works
It is built on ARM architecture. Apple has optimized this architecture by making it perfectly compatible with its own software.

## Where it is used
It is used in modern MacBook, iMac and iPad models.

## Frequently asked questions
**Will legacy apps run on Apple Silicon?**
Yes, legacy applications run smoothly thanks to a translation layer called Rosetta 2.

**Why does it get less hot?**
Because its energy efficiency is very high, the processor does the same job by consuming less power.
