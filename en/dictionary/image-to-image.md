# What is Image-to-Image?

*Artificial Intelligence · Last updated: October 23, 2026*

It is an artificial intelligence process that generates a new and transformed image by taking an existing image as a reference.

## Overview

Image-to-image refers to artificial intelligence techniques that generate a new output by altering the style, structure, or details of an input image. Unlike text-to-image generation, it allows you to reinterpret the content while preserving the composition of an existing picture. AI models analyze the object boundaries and color distributions in the input image to create new pixel arrangements in line with the prompts you provide.

***Analogy:** It is similar to a painter taking an existing charcoal drawing and turning it into an oil painting while keeping the same outlines.*

## How it works

The system breaks down the reference image you upload into mathematical representation layers. Then, it makes modifications in the latent space of the AI model based on the style transfer or drawing prompts you specify. In the final stage, solver algorithms process this new representation data to generate the final visual output.

## Where it is used

It is widely preferred in photo editing software, game graphic design, and concept art production.

## Commonly confused with

It can be confused with the concept of Text-to-Image. While Text-to-Image generates visuals from scratch based solely on text prompts, Image-to-Image strictly uses a reference image as an input.

## Questions and answers

**Does the structure of the original image get completely distorted when using Image-to-Image?**

It depends on the model settings and input parameters. Thanks to the transformation rate you determine, you can easily control the fidelity degree of the original image.

**Is it possible to turn a two-dimensional sketch into a realistic photo?**

Yes, turning drawing sketches or simple doodles into high-resolution photos is one of the most common use cases for this method.
