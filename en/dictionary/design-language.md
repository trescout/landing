# What is Design Language?

It is a set of rules that keeps the visual world and user experience of a product consistent.

## Overview
Design languages ​​are established standards for how a software or product should look and feel. It ensures that elements such as color palettes, fonts, button shapes, and use of spacing are compatible with each other. In this way, the user encounters a familiar and regular interface every time he opens the application.

*Analogy: It is like the colors and furniture style used in the interior architecture of a house being harmonious in all rooms; Instead of using a modern style in the kitchen and a classic style in the living room, you create unity.*

## How it works
Designers create a guide and developers put these rules into code. This prevents the design from deteriorating every time a new feature is added. Thanks to this consistency, users learn the application more easily.

## Where it is used
It is used on websites, mobile applications and all digital platforms where brand identity is created.

## Commonly confused with
It is not just a visual theme, it is a system that covers the entire interaction logic of a product.

## Frequently asked questions
**Why is it important?**
It prevents the user from confusion while using the application and provides a professional experience.

**What does it mean for software developers?**
It eliminates the need to make a new design every time and enables rapid progress by combining predefined parts.
