# What is Sandbox?

*Dictionary · Dev · Last updated: June 16, 2026*

It is an isolated work area where new software or codes can be tested safely without damaging the main system.

## Overview

A sandbox is a playground on your computer or server that operates as if it were in a real environment, but is disconnected from the outside world. Mistakes made here or dangerous codes run can never harm your main system. You can easily reset this field when the experiment is finished.

***Analogy:** It is like a sandbox in a children's playground; Children can build and destroy any castle they want there, but the general order of the park is not affected.*

## How it works

When software developers develop a new feature or open a suspicious file, they run it in a sandbox. If the system crashes, only that small sandbox area is affected, leaving your computer intact.

## Where it is used

It is used in cyber security tests, software development stages and for browsers to run websites securely.

## Commonly confused with

Can be mixed with virtual machines; A sandbox is an insulation space that is generally lighter and specialized for a particular application.

## Frequently asked questions

**Why is a sandbox necessary?**

It is necessary to understand whether an unknown software is infected or to see if new code will break the system.

**Can data leak out of the sandbox?**

A well-structured sandbox completely restricts communication with the outside world and prevents leakage.
