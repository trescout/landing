# What is Cross-platform?

*Development · Last updated: October 14, 2026*

A type of software that can run smoothly across different operating systems or devices.

## Overview

Software developers sometimes want to create applications that work on both computers and phones by using a single codebase instead of writing separate code for each device. This approach saves time and makes maintenance easier.

***Analogy:** It is like a smart suitcase that can travel by bicycle, car, and on foot.*

## How it works

Codes written on a common infrastructure are translated into the target device's language and executed.

## Where it is used

It is widely used in mobile and desktop application development projects.

## Commonly confused with

It differs in this aspect from native applications trapped on a single device.

## Frequently asked questions

**Why is it preferred?**

It reduces costs and speeds up the development process.
