# What is Dynamic Tiling?

*Development · Last updated: November 3, 2026*

It is the automatic and orderly arrangement of open windows on a computer screen without overlapping.

## Overview

Instead of resizing windows one by one with a mouse, it divides the screen space mathematically to allow windows to place themselves automatically. It is one of the most practical ways to use the screen efficiently and work keyboard-focused for developers and advanced users. When a new window opens or closes, windows are instantly resized and aligned so that no empty space is left.

***Analogy:** It is like assigning custom compartments of the exact right size to each document on a desk instead of stacking them on top of each other.*

## How it works

Special software called window managers divides the screen using a row and column logic, automatically placing new windows according to rules.

## Where it is used

You frequently encounter it in Linux desktop environments, specialized window managers, and tiling-enabled operating system extensions.

## Commonly confused with

It is often confused with the free drag-and-drop logic of traditional windowed interfaces, but here everything is automated.

## Questions and answers

**Is it hard to work without using a mouse?**

It takes some getting used to at first, but shortly after, it allows you to work much faster using keyboard shortcuts.

**Which operating systems have it?**

It is especially common in the Linux world, but it can also be used on macOS and Windows with third-party tools.
