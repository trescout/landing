# What is DNS Tunneling?

It is a method of secretly passing Internet traffic through the system normally used to find addresses.

## Overview
DNS is like the internet's address book. This method attempts to bypass firewalls by hiding data in the query lines of this ledger. It is very difficult to detect because it looks like normal internet traffic.

*Analogy: It is like sending a letter by writing the contents of the letter on the envelope as if it were the address, instead of sending it to the regular mailbox.*

## How it works
The data is divided into small pieces and sent to the server by embedding them in DNS queries, and these pieces are combined again on the other side.

## Where it is used
It is used to access the internet in cyber security attacks or restricted networks.

## Commonly confused with
It may be confused with VPN, but VPN encrypts all traffic while DNS tunneling only uses address queries.

## Frequently asked questions
**Is this method safe?**
It is generally viewed as a threat by security experts.

**Why is it difficult to prevent?**
Because DNS is the cornerstone of the internet and blocking it can stop the network from working.
