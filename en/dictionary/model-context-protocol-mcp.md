# What is Model Context Protocol?

**Full Name:** Model Context Protocol

**Category:** ai

## Overview
Yapay zeka modellerinin farklı veri kaynaklarıyla ve araçlarla güvenli bir şekilde konuşmasını sağlayan standart bir bağlantı dilidir.
