# What is Workspace?

*Development · Last updated: October 29, 2026*

It is a digital workspace where users manage projects, artificial intelligence models, and development tools under a single roof.

## Overview

A workspace is a digital environment that brings together all the files, configurations, and tools needed in software development or content creation processes. In artificial intelligence systems, a workspace limits the local directories and memory context that models can access. This way, users do not experience data confusion when switching between projects.

***Analogy:** It is similar to a tidy desk that only contains the documents and tools for the project you are currently working on.*

## How it works

The user or agent sets the relevant project folder as the root directory. The system automatically indexes the code, configurations, and data sources within this folder and includes them in the workspace.

## Where it is used

It is used in code editors, artificial intelligence agent platforms, and cloud-based development environments.

## Commonly confused with

It is different from an agent workspace; while an agent workspace is an isolation zone where only one agent performs tasks, a general workspace covers the entire user project.

## Questions and answers

**What does workspace isolation provide?**

It prevents the code, environment variables, and contexts of different projects from getting mixed up.

**How do artificial intelligence agents use the workspace?**

They generate code with a comprehensive understanding of the project by reading and editing the files within the workspace.
