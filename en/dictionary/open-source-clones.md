# What is Open-Source Clones?

They are similar versions of popular software created by publicly copying their source codes.

## Overview
Open source copies take the logic or look of a successful software and turn it into something that anyone can freely develop. This allows communities to create their own alternatives where the original software is paid or closed. Thus, tools with similar features can be used in the software world without being dependent on a single company.

*Analogy: It's like a chef making his much-loved secret recipe available to the public, and everyone can take it and cook it by adding spices to their own taste.*

## How it works
Developers take the source code of the original project and use it as the basis for their own projects. They then make their own improvements or changes to this code. The resulting product is a new version that is very similar to the original but supported by the community.

## Where it is used
It is used in the software world when developing alternative tools or creating more accessible versions of a particular software.

## Commonly confused with
It may be confused with the term simply 'Clone' but this term specifically covers those that are open source and community driven.

## Frequently asked questions
**Are open source copies legal?**
If the license of the original software allows it, then yes, it is completely legal.

**Why should I use a copy and not the original?**
They are generally preferred because they are more cost-effective, you can change them according to your own needs, or they offer a more free structure.
