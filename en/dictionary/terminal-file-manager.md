# What is Terminal File Manager?

A tool that allows you to manage your files only via the command line instead of visual windows.

## Overview
These tools allow you to copy, move or delete files with keyboard shortcuts without using your mouse. It allows you to operate very quickly without the weight of a graphical interface.

*Analogy: It is a system that allows you to have the book you want in front of you by just pressing a button, instead of climbing the shelves with a ladder in a library.*

## How it works
You open the terminal and run the program. Two panels appear on the screen, and you can navigate between files with the keyboard arrow keys.

## Where it is used
It is used when managing servers or in software development processes where you need to edit files very quickly.

## Commonly confused with
It should not be confused with 'shell', which just says commands; This tool offers a visual editing interface.

## Frequently asked questions
**Is it difficult to learn?**
It may take some time to memorize the shortcuts at first, but once you get used to them, it becomes very fast.

**Does it work on every operating system?**
It is generally very common on Linux and macOS.
