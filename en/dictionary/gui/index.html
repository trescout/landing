What is GUI?

Graphical User Interface

It is an interface that allows you to manage computer programs visually with icons, menus and windows instead of typing text.

Overview

GUI is the visual layer that makes technology accessible to everyone. It allows someone who does not know how to code to control the computer by clicking the mouse. It is the cornerstone of modern operating systems.

Analogy: Instead of a chef (code) cooking complex dishes in a restaurant's kitchen, he is like a waiter and a menu card that allows you to choose from the menu and order.

How it works

Every button, window, and icon you see on your screen is a GUI element. When you click a button, codes running in the background receive this visual command and start the relevant process.

Where it is used

It's found in smartphones, computer operating systems, and every mobile app you use.

Commonly confused with

Contrasts with CLI (Command Line Interface); In CLI, only text is written, while in GUI, visuality is at the forefront.

Frequently asked questions

Does every software have a GUI?

No, some professional tools only work text-based (CLI).

Does GUI affect performance?

Drawing visual elements requires processing power, so text-based interfaces are sometimes preferred on very simple systems.
