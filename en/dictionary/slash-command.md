# What is Slash Command?

*Development · Last updated: November 17, 2026*

These are short commands that users initiate with a forward slash in a chat or command-line interface.

## Overview

They are shortcuts starting with a forward slash used to perform quick actions in the software world. For example, instead of typing help or settings in a chat window, it allows you to run these commands in a single stroke. It enables you to quickly trigger the ready-made capabilities offered by the interface without having to remember them.

***Analogy:** It is like ordering directly from the waiter by a code name instead of reading the menu at a restaurant for a long time.*

## How it works

When you type the forward slash character into the interface, the system automatically brings up a list of available commands. When you type the rest and press enter, the underlying program executes a lengthy process in a single stroke. You will frequently encounter them in chat windows and developer tools.

## Where it is used

They are frequently used in chatbots, terminal windows, and AI-powered code editors.

## Commonly confused with

They are often confused with normal chat messages, but thanks to the special character at the beginning, they are perceived directly as a command rather than ordinary text.

## Questions and answers

**Why is a forward slash used?**

This character was chosen as a standard so that the system can easily distinguish between normal text and commands.

**Can we write our own command?**

Yes, many software platforms allow you to define your own custom shortcut commands.
