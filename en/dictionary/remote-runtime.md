# What is Remote Runtime?

*Development · Last updated: October 18, 2026*

It is an execution environment that allows software, code scripts, or artificial intelligence operations to be run on a remote server infrastructure instead of a local computer.

## Overview

A remote runtime is a system that keeps the processor, memory, and library dependencies required by an application ready on a cloud-based server, independent of the user's physical device. While you write and edit your code on your own computer, you perform heavy compilation and execution steps in this external environment. Thanks to this structure, developers and autonomous AI agents can execute code without consuming local resources or creating security risks.

***Analogy:** It is similar to sending an order slip to a professional industrial kitchen remotely and watching the meal being prepared there, instead of cooking a complex and smoky dish in your home kitchen.*

## How it works

Your local client or code editor connects to the remote server over the network and transfers the code snippets to be executed. The container or virtual machine in the remote environment processes these commands in its own isolated environment. The resulting console outputs, error reports, or data results are transmitted back to your local screen in real-time.

## Where it is used

It is frequently used in secure code execution sandboxes within AI coding tools, web-based development platforms, and machine learning training steps that require high hardware specifications.

## Commonly confused with

It is confused with a local runtime. While a local environment uses your computer's hardware directly, a remote environment executes all operations on an external server in the cloud.

## Frequently asked questions

**Is a constant internet connection required to use a remote runtime?**

Yes, a stable internet connection is essential for synchronizing code and outputs with the remote machine.

**Why is a remote runtime preferred for AI agents?**

It is preferred to prevent random code generated and tested by agents from damaging the developer's own computer and to create an isolated security zone.
