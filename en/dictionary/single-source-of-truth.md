# What is Single Source of Truth?

*Dictionary · Data · Last updated: July 17, 2026*

> SSOT

It is the principle that all data is managed from a single reliable center and everyone has access to the same information.

## Overview

If there are different files or different numbers for the same information in an institution, confusion arises. A single source of truth ensures that data is updated in only one place and that everyone can use that updated data. This eliminates data inconsistency.

***Analogy:** It's like all employees in a company looking at one main clock tower to set their clocks; everyone sees the same time.*

## How it works

A central database or cloud system is established. All departments write data here and read it from here. So 'which file was up to date?' The question becomes history.

## Where it is used

It is mandatory in enterprise software, financial systems and projects where large teams work.

## Commonly confused with

It can be confused with the central database; This is a management principle rather than a technique.

## Frequently asked questions

**Why is this principle difficult?**

Because all departments must adapt to the same system and be disciplined.

**What happens if it fails?**

It leads to wrong decisions and loss of time within the organization.
