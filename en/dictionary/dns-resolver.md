# What is DNS Resolver?

*Development · Last updated: November 19, 2026*

The system that translates website names into numerical addresses that computers understand.

## Overview

When you type a web address into your browser, your computer does not directly know which server that name is running on. The DNS resolver steps in at this point, searching through the massive phone book running in the background. It translates human-readable web addresses into IP addresses that allow machines to find each other.

***Analogy:** It is similar to searching for a friend's name in a phone book to find their actual phone number.*

## How it works

When you type an address into your browser and press Enter, the request first goes to the resolver system of your internet service provider or an external service. The resolver queries other servers until it finds the relevant address and sends the found IP address back to your computer.

## Where it is used

It runs continuously in the background across all network communications, web browsers, and server configurations.

## Commonly confused with

It can be confused with the general term DNS, but this term refers directly to the server or software mechanism that performs the address resolution process.

## Questions and answers

**Does this system always run when I go online?**

Yes, this translation process is performed in the background for every website address you type into your browser.

**Does using a different resolver affect speed?**

Fast-working external resolver systems can improve website loading times on a millisecond basis.
