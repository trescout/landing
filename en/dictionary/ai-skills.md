# What is AI Skills?

> Skills

Special capabilities or tools that AI models use to perform a specific task.

## Overview
They are special abilities or tools that artificial intelligence models use to perform a specific task. These capabilities enable the model to perform concrete tasks, such as searching the internet or executing code, rather than just producing text.

*Analogy: While a food processor only has a mixing feature, it's like adding a slicing or grating attachment to it to make it do more work.*

## How it works
The model learns to use special command sets or tools defined for it. It triggers these tools when needed, processes the data and presents the result to the user.

## Where it is used
It is used in smart assistants, data analysis tools, and software that automates complex tasks.

## Commonly confused with
It is often confused with general AI capabilities, but these are specialized tools added to do a specific job.

## Frequently asked questions
**Do every AI model have AI Skills?**
No, only models equipped with these capabilities or authorized to drive have these capabilities.

**Can these skills be added later?**
Yes, new capabilities can be added to a model with the appropriate infrastructure and API connections.
