# What is Page Agent?

It is a special artificial intelligence assistant that scans web pages and performs actions such as clicking or entering data on behalf of the user.

## Overview
Page Agent is a digital assistant that runs on the browser. Not only can he read text, he can press buttons, fill out forms and navigate between pages. It is designed to navigate complex websites like a human.

*Analogy: It is like a digital assistant that guides someone lost on a website and fills out forms instead.*

## How it works
It works as an add-on or background application installed in your browser. You tell it what to do, and it analyzes the elements on the web page and carries out the steps one by one.

## Where it is used
It is used when tracking prices on e-commerce sites, filling out forms or collecting data over the web.

## Commonly confused with
It can be confused with general-purpose AI agent models, but this is only web browser focused.

## Frequently asked questions
**Is Page Agent safe?**
It can't take action outside areas you've authorized, but you should still be careful when working with your sensitive data.

**Does it work on every website?**
It usually works on standard web structures, but may have difficulty on sites with very complex security measures.
