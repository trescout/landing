# What is NVKE?

*Development · Last updated: November 8, 2026*

It is a control platform used to orchestrate AI workloads and GPU clusters in NVIDIA-powered cloud infrastructures.

## Overview

NVKE is an infrastructure solution that undertakes the orchestration of GPU clusters optimized especially for the training and inference of large AI models. It manages the sharing, communication, and resource allocation of graphics processors on servers. It enables high-performance computing processes to run uninterrupted.

***Analogy:** It is similar to a central control tower that coordinates hundreds of autonomous carriers in a massive logistics center so they operate without colliding, at full capacity, and in the correct sequence.*

## How it works

NVKE monitors the hardware statuses of GPU nodes in the cluster in real time. It routes incoming training or inference requests for AI models to the most suitable graphics processors. It works integrated with hardware acceleration layers and high-speed network components to minimize bottlenecks in data flow.

## Where it is used

It is used in AI data centers, GPU cloud infrastructures, and the server farms of organizations conducting large-scale deep learning research.

## Commonly confused with

It can be confused with standard Kubernetes. While standard Kubernetes focuses on general CPU-based container management, NVKE focuses directly on the NVIDIA GPU hardware architecture and AI workloads.

## Questions and answers

**Is it mandatory to own physical GPUs to use NVKE?**

No. Management layers like NVKE can run both on physical servers in local data centers and in GPU environments provided by cloud providers.

**Why is NVKE different from classic cluster managers?**

While classic managers consider CPU and memory balance, platforms of this type center around critical AI parameters such as GPU memory, NVLink bandwidth, and CUDA acceleration.
