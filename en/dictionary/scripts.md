# What is Scripts?

They are short command sequences prepared for the computer to perform certain tasks automatically.

## Overview
Scripts are text-based scripts used to speed up or automate certain tasks rather than rewriting an entire complex software program. They are like short recipes given to a cook; The computer follows the steps in this recipe in order. They are generally preferred to handle repetitive manual tasks with a single click.

*Analogy: It's like leaving a note in a food processor saying 'mix this for 5 minutes, then stop'; The robot reads the note and does as told.*

## How it works
They are usually written in a simple text editor and run by an interpreter program. They do not require a complex software development process, you just need to write down the steps of the work to be done in order.

## Where it is used
They are used for routine tasks such as backing up files, converting data, or changing system settings.

## Commonly confused with
Not to be confused with full-fledged software or complex applications; scripts are more helpful and task-oriented.

## Frequently asked questions
**Do I need to be a programmer to write scripts?**
No, anyone who can understand basic logic can automate their daily tasks by writing simple scripts.

**What is the difference between script and application?**
While applications generally have a more comprehensive and complex structure, scripts generally focus on doing a single job.
