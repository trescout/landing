# What is Security Scanner?

It is a tool that automatically detects vulnerabilities in software or network systems.

## Overview
A security scanner examines your digital systems like a detective. It checks whether you have left the doors or windows in your system open and reports your vulnerabilities against possible cyber attacks. These tools scan complex software code or network traffic to find errors that the human eye might miss.

*Analogy: It's like a professional security expert checking all door locks and windows before entering your home.*

## How it works
You connect the scanner to your system and start a scan. The tool compares files or network packets on your system with known threat databases. It presents you with a list of every suspicious situation it finds, and usually gives you suggestions on how to close the gap.

## Where it is used
It is used in software development processes, server management and cyber security audits of companies.

## Commonly confused with
It is used for the same purpose as Vulnerability Scanning, but this term focuses directly on the vehicle.

## Frequently asked questions
**Does the security scanner find every vulnerability?**
No, it can only find vulnerabilities that are defined in the database or that fit certain patterns.

**Do these tools slow down the system?**
They can use system resources during in-depth scans, which is why they are usually run during off-peak hours.
