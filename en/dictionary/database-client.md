# What is Database Client?

A tool program that allows you to access and manage information in the database.

## Overview
A database client allows you to connect to data stored on servers via a graphical interface. It enables you to inspect tables, write queries, and edit data. It is one of the most fundamental software tools used to manage a database without writing code.

*Analogy: It is like a smart control panel that shows where the boxes in a warehouse are located and allows you to lock and unlock them.*

## How it works
Commands or clicks made in the user interface are transmitted by the client to the database server. Responses from the server are displayed on the screen as readable tables or lists.

## Where it is used
It is widely used in software development processes, data analytics studies, and server management.

## Commonly confused with
It should not be confused with the database server that stores the data itself; the client is merely an interface and management tool.

## Frequently asked questions
**Which programs are known as database clients?**
Software such as DBeaver, pgAdmin, or MySQL Workbench falls into this category.
