# What is Server Hardening?

It is the process of reducing the risk of attack by turning off unnecessary features on a server and tightening security settings.

## Overview
It is an attempt to reduce the surface area of ​​the server as much as possible. It includes steps such as turning off unused services, changing default passwords, and configuring firewalls. The goal is to close doors through which an attacker can sneak in.

*Analogy: It is not enough to lock the doors of a house; it is like turning the house into a castle by taking all security measures such as ironing the windows and installing the alarm system.*

## How it works
Close unnecessary ports on the server, upgrade software to the latest version, restrict user permissions to prevent unauthorized access, and perform regular security scans.

## Where it is used
It is used in cloud servers, on-premises data centers, and cybersecurity operations.

## Commonly confused with
It is not the same as just installing a firewall; hardening is a much more comprehensive security process.

## Frequently asked questions
**How often should I harden my server?**
It should be constantly reviewed when system updates and new service installations are made.
