# What is Telemetry?

Technical data automatically collected from a system regarding the usage and errors of a software.

## Overview
These are reports sent by applications to developers about how the software is performing. Thanks to this data, developers can understand which features are used the most or where the application crashes. For users, it is usually a data stream that flows silently in the background.

*Analogy: It is like the sensors inside a car constantly reporting the engine temperature and fuel status to the driver's dashboard.*

## How it works
Small pieces of code embedded into the software transmit this information to a secure server when specific events occur.

## Where it is used
It is used for software debugging, improving user experience, and performance monitoring.

## Commonly confused with
logging

## Frequently asked questions
**Does it affect my privacy?**
Generally, anonymous data is collected, but you can check which data is being sent in the settings section.
