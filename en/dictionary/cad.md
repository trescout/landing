# What is CAD?

*Dictionary · Dev · Last updated: October 5, 2026*

> Computer-Aided Design

A system that enables engineers and architects to create technical drawings and three-dimensional designs using computers.

## Overview

CAD, or computer-aided design, allows physical objects to be precisely drawn and modeled in a digital environment. It moves the long and tedious processes previously done on paper at drawing tables onto a computer screen. Many things, from machine parts to buildings, are designed using these systems.

***Analogy:** It is like a magical digital drafting table that replaces the paper and pencil in an architect's hand, allowing you to fix mistakes with a single click instead of using an eraser.*

## How it works

The program records lines, angles, and surfaces as mathematical coordinates. The designer can rotate the object, cut through to look inside, or test how it will react to real-world physical laws.

## Where it is used

It is frequently used when drawing building plans in construction projects, designing engine parts in automobile factories, or modeling the outer casing of a phone.

## Frequently asked questions

**Does CAD only work in three dimensions?**

No, it was formerly used only for two-dimensional technical drawings, but today it is capable of full-fledged three-dimensional modeling.

**Which professions use CAD?**

Primarily architects and mechanical engineers, along with industrial designers and interior architects, use these tools extensively.
