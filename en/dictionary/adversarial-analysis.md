# What is Adversarial Analysis?

It is security testing performed by imitating malicious attacks to find the weak points of a system.

## Overview
This method is used to understand how durable a software or artificial intelligence is. Security experts deliberately send incorrect or misleading input to make the system make mistakes or bypass its defenses. The aim is to foresee how the system will react in the event of a real attack.

*Analogy: It's like pretending to be a castle guard and trying to sneak in to test the walls of a castle.*

## How it works
Unexpected data, incorrect commands or manipulative questions are sent to the system. The responses given by the system are analyzed and where the security vulnerabilities are mapped.

## Where it is used
It is used to ensure the security of artificial intelligence models, cyber security audits and software development processes.

## Commonly confused with
Not to be confused with just debugging; Here, the focus is on the presence of a malicious actor.

## Frequently asked questions
**Why are we doing this test?**
It is done to test the system before real attackers and close its vulnerabilities.

**How does it work in artificial intelligence?**
Resistance is measured by asking the model questions that will deceive it or force it to respond unethically.
