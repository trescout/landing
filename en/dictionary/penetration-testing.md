# What is Penetration Testing?

*Dictionary · Dev · Last updated: July 1, 2026*

These are controlled cyber attack attempts made by experts to test the security of systems.

## Overview

Also known as penetration testing, this method is done to find weak points in a computer system before malicious actors do. Security experts force the system's doors by pretending to be a real attacker. In this way, it is measured how durable the system is.

***Analogy:** It's like locking the door of your house, calling a locksmith and saying 'try to open the door, let's see how easy it opens'.*

## How it works

Experts first map the system, then identify vulnerabilities and report vulnerabilities by trying to exploit them.

## Where it is used

It is regularly applied on companies' websites, servers and critical software infrastructures.

## Commonly confused with

It can be confused with real cyber attacks; However, this process is completely legal and controlled.

## Frequently asked questions

**Will this test damage the system?**

No, since it is done in a controlled environment, it has no purpose other than increasing the security of the system.
