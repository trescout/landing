# What is CLI Agent?

> Command Line Interface Agent

It is software that automatically manages operations and performs tasks on behalf of the user via the computer's command line.

## Overview
CLI agents write commands and read the output for you in the black-screen command line world. They can perform technical tasks such as file management, system installations or server configurations without waiting for your commands. They manage complex system tasks using the terminal like a human.

*Analogy: It's like a digital mechanic who gets under the hood of the computer and fixes the engine with only the instructions you give it.*

## How it works
You grant access to your terminal; It also lists files, updates packages or solves problems by checking logs.

## Where it is used
It is used in server management, software distribution processes and complex system automation.

## Commonly confused with
It can be confused with a simple 'script' or 'shell' script; agents have the ability to make decisions based on outcomes.

## Frequently asked questions
**Is it safe?**
Terminal is a highly authorized tool, so you should only run agents you trust.

**What commands does it use?**
It uses standard terminal commands supported by your operating system.
