# What is Computer Vision Library?

They are ready-made software tools that enable computers to process and make sense of visual data.

## Overview
These libraries contain the mathematical calculations required for an artificial intelligence to recognize objects in photos, distinguish faces or follow movements in videos. Instead of writing complex algorithms from scratch, programmers add vision to their applications by using these ready-made libraries. It is almost like a ready-made set of glasses and magnifiers in the hands of a software developer.

*Analogy: It's like a cook buying ready-chopped canned tomatoes from the market and adding them to the dish, instead of growing tomatoes from scratch each time; It speeds up your work a lot.*

## How it works
Developers include these libraries in their projects and submit the photo to the library. The library divides the image into its pixels and analyzes the patterns within it, giving you results such as 'there is a cat here'.

## Where it is used
It is used in security cameras, autonomous vehicles and facial recognition systems in phones.

## Commonly confused with
It can be confused with image processing software, but it is a library, so it is a developer tool, not an end user interface.

## Frequently asked questions
**Can these libraries see everything?**
No, they can only recognize certain types of objects for which they have been trained or programmed.

**Is it necessary to know mathematics to use it?**
Basic knowledge of code is sufficient as libraries hide complex mathematics.
