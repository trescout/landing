# What is Amazon Web Services?

> Amazon Web Services

A huge cloud platform where you can rent IT services such as servers, storage and databases over the internet.

## Overview
Instead of installing your own physical servers, it allows you to use Amazon's massive data centers around the world by renting them over the internet. You can increase the capacity when you need it and reduce it when you're done.

*Analogy: It's like buying electricity from the grid instead of building your own power plant; You only pay for what you use.*

## How it works
You use it by creating virtual machines and databases via the web interface or software tools.

## Where it is used
It is used in the background of almost all modern websites and applications.

## Commonly confused with
It is not just a website hosting service; It is a much more comprehensive infrastructure service.

## Frequently asked questions
**Why should I use AWS?**
To instantly have a professional level infrastructure without dealing with hardware costs.
