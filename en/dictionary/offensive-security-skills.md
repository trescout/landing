# What is Offensive Security Skills?

It is the ability to perform security tests by thinking like an attacker to find vulnerabilities in systems.

## Overview
Offensive security skills aim to find the weak points of software or a network before malicious actors discover them. In this process, you attempt to bypass the system's defensive walls and report the security vulnerabilities. This approach allows you to build stronger protective shields by learning attack methods instead of just defending.

*Analogy: It is similar to a guard tasked with protecting a castle trying to secretly climb the castle walls to identify weak points.*

## How it works
You start by learning network protocols and web technologies in depth. Then, you stress-test systems in controlled environments using penetration testing tools. You keep this skill constantly updated by documenting the vulnerabilities you find and developing recommendations for patching them.

## Where it is used
It is used in cybersecurity companies, security teams of large technology firms, and independent security consulting projects.

## Commonly confused with
Unlike defensive security, here you actively try to trigger vulnerabilities.

## Frequently asked questions
**Is this skill legal?**
Yes, but only on the condition that you perform tests on systems for which you have received permission and within legal boundaries.

**Is it the same as being a hacker?**
The methods are similar, but the goal is not to cause harm, but to make systems more secure.
