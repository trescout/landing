# What is Keybindings?

It is the process of assigning specific tasks or commands to keyboard keys.

## Overview
It allows you to quickly perform operations without touching the mouse while using software. For example, pressing 'Ctrl+C' to copy text is a keybinding definition. This speeds up users' workflow and increases efficiency.

*Analogy: It's like changing the radio channel or turning on cruise control with the buttons on the steering wheel of a car.*

## How it works
Which key combination will do what is determined in the settings section of the software or through a configuration file.

## Where it is used
It is definitely present in code editors, games and professional design tools.

## Commonly confused with
It can be confused with dial keys, but dial keys are mostly for dial-up interfaces.

## Frequently asked questions
**Can I create my own shortcut?**
Yes, most modern editors and applications allow this customization.
