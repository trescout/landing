# What is IRC?

> Internet Relay Chat

An old and simple messaging system that allows real-time correspondence over the Internet.

## Overview
IRC is a server-based text chat protocol that has been used since the early days of the Internet. Unlike modern applications, it is very lightweight and only text-oriented. It still remains popular among technical communities.

*Analogy: It is a very old but effective communication room where everyone gathers at different tables and talks in a virtual coffeehouse.*

## How it works
You connect to an IRC server, enter a channel, and start typing. All messages are delivered instantly and no logs are kept.

## Where it is used
It is used in open source software projects, technical support groups, and nostalgic communities.

## Commonly confused with
The difference from modern tools like Discord or Slack is that it doesn't have visual or file sharing features.

## Frequently asked questions
**Is IRC safe?**
In its basic form it is passwordless, but nowadays it can be secured with SSL/TLS.

**Why is it still used?**
It is preferred because it is fast, light and very easy to install.
