# What is Prompt Injection?

*Dictionary · AI · Last updated: September 27, 2026*

These are deceptive commands given to trick artificial intelligence into bypassing its security rules.

## Overview

Prompt injection is a deception method used by malicious actors to bypass the security filters of artificial intelligence systems. It aims to trick the model into performing harmful operations it normally shouldn't do through specially designed wordplay.

***Analogy:** It is like trying to convince a smart doorman·whom you need to tell a secret word to unlock·to let you in even though you don't know the word, by tricking him.*

## How it works

Attackers instruct the model as if they are writing a new scenario that bends the rules. Falling for this crafty guidance, the model forgets its security barriers and starts generating unwanted outputs.

## Where it is used

It appears as a security vulnerability in chatbots, AI-powered customer service, and all public applications utilizing large language models.

## Commonly confused with

It differs from classical hacking methods because it uses everyday language and wordplay instead of computer code.

## Frequently asked questions

**Does prompt injection work on every AI model?**

As models evolve and additional security layers are added, closing these vulnerabilities becomes harder, but new methods can always emerge.
