# What is LLM API?

> Large Language Model Application Programming Interface

It is a bridge that allows developers to add the capabilities of artificial intelligence models to their own applications.

## Overview
Instead of running an artificial intelligence model directly on your own computer, it is a connection point that allows you to ask questions to this model and receive answers over the internet. Developers can use this interface to make their own programs communicate with artificial intelligence. In other words, while you are developing an application, you do not have to perform the model's complex calculations on your own server; you use a ready-made service.

*Analogy: It is like going to a restaurant and, instead of going into the kitchen to cook the meal yourself, placing your order with the waiter and waiting for the prepared meal to arrive at your table.*

## How it works
The developer sends a 'request' to the model. The model processes this request and returns the result as a 'response'. This process takes place over a standard internet protocol.

## Where it is used
It is used in chatbots, automated content generators, and all AI-powered web applications.

## Commonly confused with
It is not the LLM itself, but the door that provides access to it.

## Frequently asked questions
**Can anyone use an LLM API?**
Yes, but you usually need to pay a fee or obtain a key (API key).

**What is the difference from a model running on my own computer?**
You need hardware power on your own computer, whereas in API usage, the entire load is on the server on the other side.
