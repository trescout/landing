# What is CLI?

*Dictionary · Dev · Last updated: June 3, 2026*

> Command Line Interface

It is a method of giving commands to the computer through written texts.

## Overview

CLI is a method of managing the computer by typing text-based commands instead of clicking with the mouse. It is fast and a very powerful control tool, especially for software developers.

***Analogy:** It's like having the chef dictate a custom recipe directly, rather than choosing a meal from a menu.*

## How it works

A black screen opens and certain commands are typed there. The computer reads these commands and executes them instantly.

## Where it is used

It is used in software development processes, server management and to run artificial intelligence models on the local computer.

## Commonly confused with

It's confused with a graphical interface (GUI), but the CLI is entirely text-based and offers much more customization.

## Frequently asked questions

**Is it necessary to learn CLI?**

Although it is not essential for most modern tools, it gives great speed for working at a professional level.

**What happens if I type the wrong command?**

The system usually gives errors, but there are also critical commands that require caution.
