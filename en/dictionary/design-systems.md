# What is Design Systems?

It is a standard library of colors, fonts, and components used to ensure consistency in the design of an application.

## Overview
In large projects, there are dozens of different pages. If you design each page separately, there will be confusion. Design systems are a set of rules that ensure that the entire application speaks a single language.

*Analogy: It's like a Lego set; You have predetermined pieces (colors, buttons, fonts) and you build the application by combining these pieces.*

## How it works
Designers and developers come together and make rules like 'our button will always be blue and round'. These rules are converted into a library. Instead of starting from scratch when creating a new page, software developers use ready-made parts from this library.

## Where it is used
It is used in large-scale software companies and all digital products that aim for a consistent user experience.

## Commonly confused with
It could be confused with a mere 'style guide', but design systems are not just a booklet, they are pieces cast directly into the code.

## Frequently asked questions
**Why should we use a design system?**
To maintain the same appearance throughout the application and save time when adding new features.
