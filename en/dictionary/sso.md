# What is SSO?

> Single Sign-On

It is a system that allows you to log in to many different applications at the same time with a single username and password.

## Overview
SSO eliminates the hassle of remembering separate passwords for each application. Once you log in, the system recognizes you and allows you to access other applications securely. This both increases user comfort and simplifies security management.

*Analogy: It's like having a single access card when you enter a building opens the doors to all rooms in the building.*

## How it works
Select an authentication provider (Identity Provider). Connect your applications to this provider. When the user logs in, the provider sends a confirmation to the application saying 'this person is authorized'.

## Where it is used
It is used in corporate software and login options with Google or Facebook.

## Commonly confused with
It should not be confused with just password storage tools (Password Manager); SSO is an authentication protocol.

## Frequently asked questions
**Is it safe?**
Yes, but you need to ensure the security of your main account very well because that account opens all doors.

**Does every application support SSO?**
No, the application must be configured to support this protocol.
