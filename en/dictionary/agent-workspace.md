# What is Agent Workspace?

It is a secure digital workspace where AI agents can create and edit files and run tools to perform assigned tasks.

## Overview
An agent workspace is an isolated environment designed for autonomous AI assistants to operate freely without human intervention. In this space, the AI agent can write code, read and update files, and fetch data from the internet. For security purposes, this space is typically completely isolated from the host system.

*Analogy: You can think of this like a glass-protected special cabinet equipped with all kinds of tools, where a chemist can perform hazardous experiments without harming the main laboratory.*

## How it works
When an AI agent starts a task, the system creates a temporary or permanent folder and processing area for it. The agent handles its tasks by using the toolbox in this area (APIs, browsers, code compilers). When the task is completed, the resulting outputs are presented to the user and the workspace is cleaned up.

## Where it is used
It is used in AI-powered coding tools, automated data analysis systems, and complex file editing tasks. These spaces are particularly essential to prevent self-operating software testing agents from harming the main system.

## Commonly confused with
It should not be confused with a development environment: While a development environment is designed for humans to write code, an agent workspace is entirely optimized for AI software to operate autonomously.

## Frequently asked questions
**Can the AI agent break out of this workspace and harm my computer?**
No, agent workspaces are generally established within protected sandboxes and their connection to the outside world is restricted.

**Can I see the files in the workspace myself?**
Yes, thanks to TreScout integrations, you can monitor all file movements and changes in the agent's workspace in real time.
