# What is Memory System?

It is the storage architecture that enables artificial intelligence to remember past interactions, user preferences and data.

## Overview
Memory system allows artificial intelligence to access not only the current conversation but also past information. Thanks to this system, artificial intelligence does not forget who you are or what you said before. This is critical for a personalized and consistent user experience.

*Analogy: It is like a person keeping a diary; He takes notes of what is said and turns the pages to remember when he needs it.*

## How it works
The system saves conversations in vector databases or special memory files. When a new question is asked, the system first scans its memory and finds and uses relevant information.

## Where it is used
It is used in personal assistants, artificial intelligence tools that track long-term projects, and customer service bots.

## Commonly confused with
It can be confused with context window; context window is short-term memory while memory system is permanent or long-term memory.

## Frequently asked questions
**Can memory be erased?**
Yes, most systems have the option to clear user data or reset memory.

**Does artificial intelligence remember everything?**
Only information that the system is allowed to save or that is deemed important is remembered.
