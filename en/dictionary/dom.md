# What is DOM?

*Development · Last updated: November 19, 2026*

> Document Object Model

The hierarchical structure that enables the content on web pages to be processed and managed by the browser.

## Overview

DOM is the system that allows websites to be stored in memory in the background as a tree structure. It converts HTML tags into objects that languages like JavaScript can easily modify. Thus, dynamic events such as a page changing without a reload when you click a button can occur.

***Analogy:** It is like the architectural blueprint of a building. When you want to make a change to the electrical or plumbing system, instead of breaking down the actual walls, you look at the plan to find the relevant valve or cable and intervene.*

## How it works

As soon as the browser downloads and reads the code of a website, it builds this hierarchical structure in memory. While writing code, developers can target this structure to update text or images on the page instantly. Every HTML tag is positioned like a branch or a leaf of this tree.

## Where it is used

It operates continuously in the background in all modern websites and web applications running in web browsers.

## Commonly confused with

It can be confused with the raw HTML code coming from the server. While HTML is just a text document, the DOM is the browser's transformed version of that document into a live object.

## Questions and answers

**Does the DOM exist on every website?**

Yes, this structure definitely runs behind every visual page opened in the browser.

**Can the DOM be modified directly?**

It is possible to change this structure instantly and animate the page using JavaScript.
