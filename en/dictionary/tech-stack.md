# What is Tech Stack?

It is the collection of all languages, databases and tools used to build a software project.

## Overview
It is the 'technology stack' used when building an application. For example, one language for the visible side of the website, another tool for the database running in the background, and the servers that connect them are part of this stack.

*Analogy: It is like the sum of the kitchen equipment, menu cards and service style you choose when opening a restaurant.*

## How it works
When planning the project, it is decided which language, which database and which server will be used. These choices determine the pace and capacity of the project.

## Where it is used
It is defined during the architecture phase of software development projects.

## Frequently asked questions
**Why is stack selection important?**
Because it directly affects how quickly the project will grow and how easily it will be developed.
