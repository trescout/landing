# What is Bluetooth Mesh?

Wireless communication technology that allows multiple devices to connect to each other and establish a network in a wide area.

## Overview
Bluetooth Mesh is a structure that allows devices to transfer data not only to each other but also to all other devices on the network. In this way, communication can be established in a wide area without the need for a central point. It is especially used to trigger each other in smart home systems.

*Analogy: It is like people in a room whispering to each other and transmitting the message to the farthest, everyone is both receiver and transmitter.*

## How it works
When devices join the network, they automatically recognize each other. The command coming from one device reaches the destination by jumping over the others. This structure ensures that the network continues to operate even if a single device fails.

## Where it is used
It is used in smart lighting systems, industrial sensor networks and large office automation.

## Commonly confused with
Standard Bluetooth connection is only between two devices, while Mesh connects all devices together.

## Frequently asked questions
**Does Bluetooth Mesh require internet?**
No, the devices establish a local network among themselves.

**Is its range limited?**
As the number of devices increases, the coverage area of ​​the network also expands.
