# What is Computer Use?

It is the ability of artificial intelligence to see the screen and manage the computer using a mouse and keyboard, just like a human.

## Overview
This technology allows AI to interact with the computer interface like a user, not just type text. Artificial intelligence detects windows, buttons and menus on the screen; then performs actions such as clicking, typing, or dragging. In this way, it becomes possible to automate complex software processes.

*Analogy: You can think of it as if an assistant is sitting in front of the computer and doing the work for you by holding the mouse and pressing the keyboard.*

## How it works
Artificial intelligence takes a snapshot of the screen, analyzes it and decides what action needs to be taken. It then sends this decision as a command to the computer's operating system. You just watch the result.

## Where it is used
It is used in tasks that require complex data entry, when browsing websites, or in tasks that use multiple applications together.

## Commonly confused with
It is very close to the concept of AI Agent, but Computer Use is a specific set of capabilities that focus specifically on on-screen interface control.

## Frequently asked questions
**Is this feature safe?**
It's safe as long as you can control what operations you allow the AI ​​to perform, but human approval is always recommended for critical operations.
