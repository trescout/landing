What is ROM?

Read-Only Memory

It is a type of read-only permanent memory that preserves the information inside even when the computer is turned off.

Overview

ROM contains the basic instructions needed to turn on the computer or device. This type of memory is designed to store data permanently and cannot be easily changed by the user during normal use. It's where the device's 'brain' knows what to do when it first wakes up.

Analogy: It is like the printed version of a book; You can read the text inside, but you cannot delete or rewrite the pages.

How it works

When you press the device's power button, the processor first reads the instructions in the ROM. These instructions tell you how the operating system should be installed.

Where it is used

It is found in the splash screens of smartphones, computer motherboards and embedded systems.

Commonly confused with

It is mixed with RAM; RAM is temporary and is deleted when the computer is turned off, while ROM is permanent.

Frequently asked questions

Why can't the information in ROM be changed?

Because the basic operating rules of the device are protected to prevent accidental deletion or corruption.
