# What is Pull Request?

*Development · Last updated: November 5, 2026*

> PR

A request where a developer submits changes they want to add to a code repository for review and approval.

## Overview

A Pull Request allows changes made to the code to be reviewed by other team members before being merged into the main project. Through this process, errors are detected early, and code quality is maintained. It is one of the cornerstones of collaborative software development processes.

***Analogy:** It is like an author submitting a new chapter they want to add to a book to a publisher or editor for approval.*

## How it works

The developer completes their development in their own working branch and pushes it to the repository. Then, they open a Pull Request to invite team members to review the code. Feedback provided after the review is addressed, and once approved, the code is merged into the main branch.

## Where it is used

It is used in the management of software projects on version control platforms such as GitHub, GitLab, and Bitbucket.

## Commonly confused with

It can be confused with the Git Push concept. While Git Push uploads code changes to the server, a Pull Request initiates a review and discussion process for these changes to be merged into the main code.

## Questions and answers

**Why is a Pull Request important?**

It improves code quality, facilitates knowledge sharing within the team, and prevents faulty code from reaching the live system.

**Can a Pull Request be rejected?**

Yes, if the code does not meet standards or has deficiencies, it can be rejected or revisions can be requested for it to be corrected.
