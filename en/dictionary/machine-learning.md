# What is Machine Learning?

It is technology that enables computers to learn on their own by learning from data.

## Overview
Machine Learning means showing the computer many examples and allowing it to find the rules itself, instead of coding everything one by one. For example, when you show thousands of cat photos to a computer, it learns the answer to the question 'what is a cat' through its own experience.

*Analogy: It's like teaching fruits to a child by constantly showing him an apple and saying 'this is an apple'; After a while, when the child sees the apple, he says its name.*

## How it works
Data sets are collected, the model is trained on this data, and its predictive ability is improved over time.

## Where it is used
It is in email filters, recommendation systems, and the basis of artificial intelligence.

## Commonly confused with
Artificial intelligence is a broader concept, while machine learning is a method used to create this intelligence.

## Frequently asked questions
**Can he learn everything?**
It can only learn patterns related to the data it has, it cannot predict something that is not in the data.

**Why is it so popular?**
Because it can do complex tasks in seconds, using data, that people cannot code for hours.
