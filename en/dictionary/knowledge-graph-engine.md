# What is Knowledge Graph Engine?

Software infrastructure that establishes complex connections between information and enables it to be queried.

## Overview
Think of information not just as a list, but as an interrelated network. Knowledge Graph Engine connects this data with relationships such as 'who, with whom, where, when' and enables you to find meaningful results within this huge network.

*Analogy: Instead of arranging the books in a library randomly, it is like tying all the books together according to their subjects, authors and references to each other.*

## How it works
It stores data as nodes (objects) and edges (relationships). When you make a query, it crawls the network and brings you the most relevant links.

## Where it is used
It is used in Google search results, recommendation systems, and complex enterprise data analysis.

## Commonly confused with
It can be confused with standard databases, but the focus here is on the relationship between the data, not the data itself.

## Frequently asked questions
**Why would I use this instead of the regular database?**
It is much faster to discover deep relationships between data.

**Is it complicated?**
It requires expertise to set up and manage, but the insight it offers is invaluable.
