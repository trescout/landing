# What is Design Vocabulary?

*Development · Last updated: October 29, 2026*

It is a set of visual terms and rules that AI agents use to ensure consistency when designing interfaces.

## Overview

A design vocabulary is a series of standard terms that an AI agent refers to when generating visual interfaces and components. Color codes, typography rules, button styles, and layout patterns are defined in this vocabulary. This way, the system adheres to a common design language instead of generating designs from scratch every time.

***Analogy:** It is like a guide of standard symbols and a color palette that an architecture firm uses in all its drawings.*

## How it works

Developers add predefined component rules to the agent's system prompt or configuration files. When the agent generates code, it refers to these rules to correctly match component names and styles.

## Where it is used

It is used in generative interface systems, automated front-end coding tools, and enterprise design systems.

## Commonly confused with

It is different from a design system; while a design system encompasses code libraries, a design vocabulary is a conceptual map of terms that enables agents to understand these components.

## Questions and answers

**Why is a design vocabulary necessary?**

It is necessary to prevent AI agents from compromising interface integrity by using different styles in every code generation.

**How is a design vocabulary created?**

Component names and visual rules in the existing design system are converted into text-based templates and defined for the agent.
