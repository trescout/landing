# What is Design System?

It is the set of design standards and components used when developing applications.

## Overview
They are libraries of rules, color palettes, fonts, and ready-made components created to maintain the visual and functional consistency of a digital product. Using this system, developers and designers do not design from scratch every time. In this way, every button or menu in the application works and appears the same way.

*Analogy: It is like a list of standard recipes and kitchen equipment used by a food chain to achieve the same taste and presentation in every branch.*

## How it works
Designers first determine the basic elements (color, typography). Then, combining components (buttons, forms) are created from these elements. Developers add these components to their projects as code libraries and use them when they need them.

## Where it is used
It is used in websites, mobile applications and large enterprise software projects.

## Commonly confused with
It may be confused with the 'Style Guide', which is just a visual guide; The design system is a much broader and more functional version of this.

## Frequently asked questions
**Why do we need a design system?**
It is necessary to gain speed and deliver the same user experience throughout the application.

**Who is responsible for the design system?**
It is a living document that is typically managed jointly by designers and front-end developers.
