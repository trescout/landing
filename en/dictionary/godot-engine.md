# What is Godot Engine?

It is a completely free and open source software platform used for game development.

## Overview
Godot Engine is a powerful game engine that allows you to make both 2D and 3D games. With its user-friendly interface and its own proprietary coding language, it is very popular for those new to the world of game development. Thanks to its open source nature, it offers a free development environment where everyone can contribute.

*Analogy: Godot is to a game developer what the canvas and paints are to a painter; It allows him to translate his dream world into digital media.*

## How it works
Users place objects in the scene, code the characters' movements, and determine the rules of the game. The engine turns all these designs into software that the player can play.

## Where it is used
It is used by independent game developers in PC, console and mobile game projects.

## Commonly confused with
Unlike other commercial game engines, it is completely free and does not charge any licensing fees.

## Frequently asked questions
**Do I need to know code?**
Learning basic code logic makes your job much easier, but thanks to visual tools, you can also do many things without code.

**What kind of games can be made?**
You can develop anything from simple puzzle games to complex 3D adventure games.
