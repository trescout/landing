# What is Event-based?

*Development · Last updated: November 17, 2026*

An architecture based on the principle that the system is triggered and operates when a specific state or action occurs.

## Overview

It is one of the approaches that determines how things work in the background in the software world. Unlike the classical method, instead of waiting in line, it is like a bell that notifies you when something happens. For example, when a user presses a button, the system wakes up and performs the necessary work.

***Analogy:** It is like the indoor chime ringing when the doorbell is pressed; the system waits quietly until you press it and springs into action the moment it is pressed.*

## How it works

When building this architecture, developers define triggers that listen for specific events. When data arrives or an operation finishes, the relevant function is automatically called.

## Where it is used

It is frequently used in modern web applications, instant messaging services, and background data streams.

## Commonly confused with

It can be confused with continuously running and looping structures; here, there is no constant checking, it only reacts when an event occurs.

## Questions and answers

**Why is it preferred?**

It is quite efficient because it does not waste resources and only runs when needed.
