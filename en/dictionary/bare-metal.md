# What is Bare Metal?

*Development · Last updated: November 8, 2026*

It is a server infrastructure that runs directly on physical hardware without any virtualization layer on top of it.

## Overview

Bare metal refers to the architecture where software and the operating system run directly on physical server hardware. There is no additional layer in between, such as a virtual machine or hypervisor, that divides the hardware. This structure ensures that all hardware resources are dedicated to a single user and maximum performance is achieved.

***Analogy:** It is similar to renting a detached house entirely instead of renting an apartment in a building. All rooms and resources of the house belong solely to you, and you are not affected by the neighbors' resource usage or noise.*

## How it works

The operating system is installed directly onto the physical disk of the server. The processor, memory, and storage units process commands directly without an intermediate software layer. In TreScout analyses, bare metal systems stand out for artificial intelligence training and large database loads that require high processing power.

## Where it is used

It is used in high-performance computing projects, large databases, and latency-sensitive systems. It is also preferred to get maximum efficiency from GPU power during intensive AI model training.

## Commonly confused with

It is often confused with virtual servers. While hardware is divided via software and offered to multiple users in virtual servers, the entire hardware is allocated to a single user in bare metal systems.

## Questions and answers

**What is the main difference between a bare metal server and a virtual server?**

In virtual servers, hardware is divided by a virtualization layer and resources are shared. In bare metal servers, physical hardware is directly and entirely allocated to a single system.

**When should bare metal servers be preferred?**

You can prefer them when you need the highest processor performance and want to prevent virtualization-related latencies.
