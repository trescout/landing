# What is Sideloader?

It is a tool or method that allows you to install applications directly onto your device via a file, bypassing official app stores.

## Overview
Normally, you use official gateways like the Apple App Store or Google Play to install applications on a phone or computer. A sideloader bypasses these gateways, allowing you to manually install an application file you downloaded from the internet onto your device. This method is used to access software that is not available in official stores or has not yet been approved.

*Analogy: If official stores are the main entrance of a building, a sideloader is like entering the building through a window or the back door.*

## How it works
You need to enable the 'allow installation from unknown sources' option in your device's settings. Then, you start the installation process by opening the installation file you downloaded from the internet (for example, .apk for Android).

## Where it is used
It is frequently seen on Android phones, in applications being tested by custom software developers, or on the devices of users who want to bypass restrictions.

## Commonly confused with
It can be confused with sideloading (the act of installing).

## Frequently asked questions
**Is it safe to use a sideloader?**
Since there is no security screening from official stores, you must be very careful about the source of the file you download.

**Does it work on every device?**
It works on most open systems, but on closed systems like Apple, special permissions or a jailbreak may sometimes be required.
