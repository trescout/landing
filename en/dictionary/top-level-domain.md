# What is Top-level Domain?

> TLD

It is the extension found at the very end of internet addresses that indicates the type or country of the site.

## Overview
It is the rightmost part of an internet address that comes after the dot. For example, expressions like .com, .org, or .tr are domain name extensions. These extensions help us understand whether the site is commercial, a non-profit organization, or belongs to a specific country.

*Analogy: It is like the zip code in a home address; it allows you to understand which neighborhood or city the house is in.*

## How it works
When setting up a website or browsing the internet, these extensions are used automatically. Thanks to this extension, your browser correctly finds the server of the site you want to visit and establishes the connection.

## Where it is used
It appears in the address bars of web browsers and during domain name purchase processes.

## Commonly confused with
It can be confused with a domain name; the domain name is the entire name of the site, whereas this is only the final part.

## Frequently asked questions
**Why are there different extensions?**
It is used to keep the internet world organized and to categorize the identities of sites.

**Can anyone get any extension they want?**
Generally yes, but some extensions like .gov are exclusive to government institutions.
