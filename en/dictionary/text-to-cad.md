# What is Text-to-CAD?

> Text to Computer-Aided Design

It is a technology that automatically creates three-dimensional technical drawings using written text commands.

## Overview
Text-to-CAD allows the user to obtain professional-level 3D models by saying a simple sentence such as 'design a wooden-look table with four legs'. It performs drawing operations that take hours in traditional CAD software, in seconds with the help of artificial intelligence. This technology significantly speeds up engineering and design processes.

*Analogy: You just tell an architect how the building will look and he immediately puts all the technical plans in front of you; Text-to-CAD is exactly this magical process.*

## How it works
The user enters a command that specifies the properties of the model. Artificial intelligence analyzes this text, converts it into geometric data and produces a printable or editable 3D file format.

## Where it is used
It is used in industrial design, game development, 3D printing and architectural projects.

## Commonly confused with
It should not be confused with image generators; they just draw pictures, this produces engineering data.

## Frequently asked questions
**Can the produced models be used directly on the 3D printer?**
Yes, most systems produce files suitable for direct 3D printing.

**Will this technology replace engineers?**
No, it is a utility tool that allows engineers to do faster prototyping.
