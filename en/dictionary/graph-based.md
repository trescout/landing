# What is Graph-based?

*Data & Infra · Last updated: November 5, 2026*

A structure or approach that represents data and the relationships between them using nodes and edges.

## Overview

Graph-based structures treat complex datasets not just as objects, but together with the connections between objects. Nodes symbolize elements, while edges symbolize the relationships between these elements. Therefore, compared to traditional tabular structures, it allows you to perform much deeper and faster relationship analysis.

***Analogy:** You can think of users on a social media network as points, and follow or friendship connections as lines connecting these points.*

## How it works

Data is modeled in the form of objects and connections between them. Instead of joining tables when querying, the system scans relationships by directly following these lines. Thus, multi-layered relationships can be queried with high performance.

## Where it is used

It is frequently preferred in social network analyses, fraud detection systems, recommendation engines, and knowledge graphs.

## Commonly confused with

It can be confused with relational databases. While relational systems store data in rows and columns, graph-based structures directly focus on the connection of objects with each other.

## Questions and answers

**What is the biggest advantage of the graph-based data structure?**

It is the ability to quickly query complex and deeply related data without experiencing performance loss.

**In which cases does it make sense to use a graph-based structure?**

It should be preferred in scenarios where the connections between data are as critically important as the data itself.
